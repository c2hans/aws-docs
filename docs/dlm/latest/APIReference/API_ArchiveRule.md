# ArchiveRule
<a name="API_ArchiveRule"></a>

 **[Custom snapshot policies only]** Specifies a snapshot archiving rule for a schedule.

## Contents
<a name="API_ArchiveRule_Contents"></a>

 ** RetainRule **   <a name="dlm-Type-ArchiveRule-RetainRule"></a>
Information about the retention period for the snapshot archiving rule.
Type: [ArchiveRetainRule](API_ArchiveRetainRule.md) object
Required: Yes
