# Tag
<a name="API_Tag"></a>

Specifies a tag for a resource.

## Contents
<a name="API_Tag_Contents"></a>

 ** Key **   <a name="dlm-Type-Tag-Key"></a>
The tag key.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 500.
Pattern: `[\p{all}]*`
Required: Yes

 ** Value **   <a name="dlm-Type-Tag-Value"></a>
The tag value.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 500.
Pattern: `[\p{all}]*`
Required: Yes
