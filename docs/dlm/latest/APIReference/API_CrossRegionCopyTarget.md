# CrossRegionCopyTarget
<a name="API_CrossRegionCopyTarget"></a>

 **[Default policies only]** Specifies a destination Region for cross-Region copy actions.

## Contents
<a name="API_CrossRegionCopyTarget_Contents"></a>

 ** TargetRegion **   <a name="dlm-Type-CrossRegionCopyTarget-TargetRegion"></a>
The target Region, for example `us-east-1`.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 16.
Pattern: `([a-z]+-){2,3}\d`
Required: No
