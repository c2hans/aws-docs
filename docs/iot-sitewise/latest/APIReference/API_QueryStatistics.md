# QueryStatistics
<a name="API_QueryStatistics"></a>

Contains statistics about a completed query execution.

## Contents
<a name="API_QueryStatistics_Contents"></a>

 ** bytesScanned **   <a name="iotsitewise-Type-QueryStatistics-bytesScanned"></a>
The total number of bytes scanned during query execution.
Type: Long
Required: Yes

 ** executionTimeInMillis **   <a name="iotsitewise-Type-QueryStatistics-executionTimeInMillis"></a>
The total query execution time, in milliseconds.
Type: Long
Required: Yes

 ** rowCount **   <a name="iotsitewise-Type-QueryStatistics-rowCount"></a>
The total number of rows returned by the query.
Type: Long
Required: Yes
