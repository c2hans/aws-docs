# Measurement
<a name="API_Measurement"></a>

Contains an asset measurement property. For more information, see [Measurements](https://docs.aws.amazon.com/iot-sitewise/latest/userguide/asset-properties.html#measurements) in the * AWS IoT SiteWise User Guide*.

## Contents
<a name="API_Measurement_Contents"></a>

 ** processingConfig **   <a name="iotsitewise-Type-Measurement-processingConfig"></a>
The processing configuration for the given measurement property. You can configure measurements to be kept at the edge or forwarded to the AWS Cloud. By default, measurements are forwarded to the cloud.
Type: [MeasurementProcessingConfig](API_MeasurementProcessingConfig.md) object
Required: No
