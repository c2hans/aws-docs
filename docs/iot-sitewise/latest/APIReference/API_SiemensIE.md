# SiemensIE
<a name="API_SiemensIE"></a>

Contains details for a SiteWise Edge gateway that runs on a Siemens Industrial Edge Device.

## Contents
<a name="API_SiemensIE_Contents"></a>

 ** iotCoreThingName **   <a name="iotsitewise-Type-SiemensIE-iotCoreThingName"></a>
The name of the AWS IoT Thing for your SiteWise Edge gateway.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `^[a-zA-Z0-9:_-]+$`
Required: Yes
