# DatasetEnrichment
<a name="API_DatasetEnrichment"></a>

Contains the enrichment status information for a dataset across data types.

## Contents
<a name="API_DatasetEnrichment_Contents"></a>

 ** video **   <a name="iotsitewise-Type-DatasetEnrichment-video"></a>
The enrichment status for video data in the dataset.
Type: [DatasetEnrichmentEntry](API_DatasetEnrichmentEntry.md) object
Required: No
