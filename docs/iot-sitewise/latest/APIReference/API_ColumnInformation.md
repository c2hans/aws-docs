# ColumnInformation
<a name="API_ColumnInformation"></a>

Contains metadata about a column in the query results.

## Contents
<a name="API_ColumnInformation_Contents"></a>

 ** name **   <a name="iotsitewise-Type-ColumnInformation-name"></a>
The name of the column.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes

 ** type **   <a name="iotsitewise-Type-ColumnInformation-type"></a>
The data type of the column. Valid values are STRING, DOUBLE, BOOLEAN, INTEGER, TIMESTAMP, and VARIANT.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: Yes
