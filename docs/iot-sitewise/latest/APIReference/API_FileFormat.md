# FileFormat
<a name="API_FileFormat"></a>

The file format of the data in S3.

## Contents
<a name="API_FileFormat_Contents"></a>

 ** annotation **   <a name="iotsitewise-Type-FileFormat-annotation"></a>
The annotation format configuration.
Type: [Annotation](API_Annotation.md) object
Required: No

 ** csv **   <a name="iotsitewise-Type-FileFormat-csv"></a>
The file is in .CSV format.
Type: [Csv](API_Csv.md) object
Required: No

 ** mp4 **   <a name="iotsitewise-Type-FileFormat-mp4"></a>
The MP4 format configuration.
Type: [Mp4](API_Mp4.md) object
Required: No

 ** parquet **   <a name="iotsitewise-Type-FileFormat-parquet"></a>
The file is in parquet format.
Type: [Parquet](API_Parquet.md) object
Required: No
