# DetailedPipelineError
<a name="API_DetailedPipelineError"></a>

Contains a detailed error entry for granular troubleshooting of pipeline failures.

## Contents
<a name="API_DetailedPipelineError_Contents"></a>

 ** code **   <a name="iotsitewise-Type-DetailedPipelineError-code"></a>
The error code.
Type: String
Valid Values: `VALIDATION_ERROR | INTERNAL_FAILURE | EXECUTION_ERROR | TIMED_OUT`
Required: Yes

 ** message **   <a name="iotsitewise-Type-DetailedPipelineError-message"></a>
The associated error message.
Type: String
Required: Yes
