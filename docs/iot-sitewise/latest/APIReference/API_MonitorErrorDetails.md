# MonitorErrorDetails
<a name="API_MonitorErrorDetails"></a>

Contains AWS IoT SiteWise Monitor error details.

## Contents
<a name="API_MonitorErrorDetails_Contents"></a>

 ** code **   <a name="iotsitewise-Type-MonitorErrorDetails-code"></a>
The error code.
Type: String
Valid Values: `INTERNAL_FAILURE | VALIDATION_ERROR | LIMIT_EXCEEDED`
Required: No

 ** message **   <a name="iotsitewise-Type-MonitorErrorDetails-message"></a>
The error message.
Type: String
Required: No
