# Scenario Discovery
<a name="scenario-discovery"></a>

Scenario Discovery is an agentic data curation solution within AWS IoT SiteWise for autonomous systems. Use Scenario Discovery to find edge cases, build balanced training datasets, reduce manual labeling effort, and integrate with simulation tools.
