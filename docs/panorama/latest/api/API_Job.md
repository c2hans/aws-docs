# Job
<a name="API_Job"></a>

A job for a device.

## Contents
<a name="API_Job_Contents"></a>

 ** DeviceId **   <a name="panorama-Type-Job-DeviceId"></a>
The target device's ID.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `[a-zA-Z0-9\-\_]+`
Required: No

 ** JobId **   <a name="panorama-Type-Job-JobId"></a>
The job's ID.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `[a-zA-Z0-9\-\_]+`
Required: No
