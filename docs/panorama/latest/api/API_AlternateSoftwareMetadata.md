# AlternateSoftwareMetadata
<a name="API_AlternateSoftwareMetadata"></a>

Details about a beta appliance software update.

## Contents
<a name="API_AlternateSoftwareMetadata_Contents"></a>

 ** Version **   <a name="panorama-Type-AlternateSoftwareMetadata-Version"></a>
The appliance software version.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No
