# OpenIdConfiguration
<a name="API_OpenIdConfiguration"></a>

Contains OpenID Connect (OIDC) parameters for use with Microsoft Intune. For more information about using Connector for SCEP for Microsoft Intune, see [Using Connector for SCEP for Microsoft Intune](https://docs.aws.amazon.com/privateca/latest/userguide/scep-connector.htmlconnector-for-scep-intune.html).

## Contents
<a name="API_OpenIdConfiguration_Contents"></a>

 ** Audience **   <a name="pcaconnectorscep-Type-OpenIdConfiguration-Audience"></a>
The audience value to copy into your Microsoft Entra app registration's OIDC.
Type: String
Required: No

 ** Issuer **   <a name="pcaconnectorscep-Type-OpenIdConfiguration-Issuer"></a>
The issuer value to copy into your Microsoft Entra app registration's OIDC.
Type: String
Required: No

 ** Subject **   <a name="pcaconnectorscep-Type-OpenIdConfiguration-Subject"></a>
The subject value to copy into your Microsoft Entra app registration's OIDC.
Type: String
Required: No
