# Connect Customer

Connect Customer is a solution that builds, manages, and continuously improves customer experiences at any scale.

- [Administrator Guide](/connect/latest/adminguide/what-is-amazon-connect.html): Helps you get started using Connect Customer. Learn how to provision, configure, monitor, and scale a virtual contact center.
- [Developer Guide](/connect/latest/devguide/what-is-connect-dev.html): Provides developer guidance for building with Connect Customer, including API best practices, flow language reference, rules function language, and testing language.
- [Connect Customer API Reference](/connect/latest/APIReference/Welcome.html): Describes API operations, including Connect AI agents, AppIntegrations Service, Amazon Participant Service, Cases, Contact Lens, Customer Profiles, Outbound Campaigns, and Voice ID.
- [Connect Customer Agent Workspace Developer Guide](/agentworkspace/latest/devguide/what-is-service.html): Helps you get started with developing third-party apps in the Connect Customer Agent Workspace.
