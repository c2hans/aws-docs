# Analytics data lake actions
<a name="analyticsdataset-api"></a>

These APIs are in preview release for Connect Customer and are subject to change.

 The following API actions are available for analytics datasets:
+ [AssociateAnalyticsDataSet](https://docs.aws.amazon.com/connect/latest/APIReference/API_AssociateAnalyticsDataSet.html)
+ [BatchAssociateAnalyticsDataSet](https://docs.aws.amazon.com/connect/latest/APIReference/API_BatchAssociateAnalyticsDataSet.html)
+ [BatchDisassociateAnalyticsDataSet](https://docs.aws.amazon.com/connect/latest/APIReference/API_BatchDisassociateAnalyticsDataSet.html)
+ [DisassociateAnalyticsDataSet](https://docs.aws.amazon.com/connect/latest/APIReference/API_DisassociateAnalyticsDataSet.html)
+ [ListAnalyticsDataAssociations](https://docs.aws.amazon.com/connect/latest/APIReference/API_ListAnalyticsDataAssociations.html)
