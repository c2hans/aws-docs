# ResumeContact
<a name="contact-actions-updatecontactresumecontact"></a>

Resumes a contact from a paused state.

## Parameter object
<a name="updatecontactresumecontact-parameter"></a>

No parameters are expected.

## Results and conditions
<a name="updatecontactresumecontact-results"></a>

None.

## Errors
<a name="updatecontactresumecontact-errors"></a>
+ NoMatchingError - if no other Error matches.

## Restrictions
<a name="updatecontactresumecontact-restrictions"></a>

None. This action can be used everywhere.
