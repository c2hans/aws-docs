# Document history for the Amazon Connect Developer Guide
<a name="doc-history"></a>

The following table describes the documentation releases for Amazon Connect.

| Change | Description | Date |
| --- |--- |--- |
| [Touchpoint SDKs for iOS and Android](#doc-history) | Added documentation for the native Touchpoint SDKs for iOS and Android, which you can use to add Amazon Connect Customer chat, voice, and Live Sync to mobile apps. | October 30, 2026 |
| [Initial release](#doc-history) | Initial release of the Amazon Connect Developer Guide. This guide provides developer-focused content including API best practices, the Connect flow language, rules function language, and testing language. | May 15, 2026 |
