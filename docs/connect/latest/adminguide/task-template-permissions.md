# Grant users permissions to create task templates in Connect Customer
<a name="task-template-permissions"></a>

Assign the **Routing**, **Task templates** permissions to enable a user to create task templates.

For information about how to add more permissions to an existing security profile, see [Update security profiles in Connect Customer](update-security-profiles.md).

By default, the **Admin** security profile already has permissions to perform all task activities.
