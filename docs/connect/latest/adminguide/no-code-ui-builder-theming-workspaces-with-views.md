# Apply workspace themes to views
<a name="no-code-ui-builder-theming-workspaces-with-views"></a>

Views in a workspace can inherit the theme of the workspace or use their own styles. The following rules apply:
+ When a workspace theme is set, a view's primary, secondary, and neutral colors and its components use the theme unless you customize them.
+ Global colors that you set on a view in the UI builder take precedence over the workspace theme.
+ Styles that you set on a component take precedence over the workspace theme.
+ Custom component colors stay the same across workspaces.
