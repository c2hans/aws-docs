# Customize the theme of the agent workspace
<a name="customize-theme-agent-workspace"></a>

By default, the agent workspace uses a Connect Customer theme, which includes the logo, favicon, font family, and color palette. You can use themes to customize the visual appearance of the agent workspace so it aligns with the brand identity of your organization. To customize the visual appearance of the agent workspace, [create a workspace](amazon-connect-workspaces.md), [customize its theme](custom-theme.md), and assign it to your agents.

![The agent workspace with a custom theme.](http://docs.aws.amazon.com/connect/latest/adminguide/images/agent-workspace-custom-theme.png)

Agents can choose between light and dark modes to match their preference. To change modes, open the user settings at the top right of the agent workspace.

![The agent workspace in light mode.](http://docs.aws.amazon.com/connect/latest/adminguide/images/agent-workspace-light-mode.png)

![The agent workspace in dark mode.](http://docs.aws.amazon.com/connect/latest/adminguide/images/agent-workspace-dark-mode.png)
