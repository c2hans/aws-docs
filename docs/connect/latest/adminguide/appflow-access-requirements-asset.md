# Amazon AppFlow access requirements in Customer Profiles
<a name="appflow-access-requirements-asset"></a>

Use the following Amazon AppFlow access requirements to create and delete Salesforce integrations with Connect Customer Customer Profiles:
+ `appflow:CreateFlow`
+ `appflow:DeleteFlow`
