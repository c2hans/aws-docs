# Amazon AppFlow access requirements in Customer Profiles
<a name="appflow-access-requirements-case"></a>

Use the following Amazon AppFlow access requirements to create and delete Zendesk and ServiceNow integrations with Connect Customer Customer Profiles:
+ `appflow:CreateFlow`
+ `appflow:DeleteFlow`
