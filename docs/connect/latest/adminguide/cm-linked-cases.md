# Link related cases in Connect Customer
<a name="cm-linked-cases"></a>

The **Linked Cases** tab of a case lists the cases that are linked to it, with their reference number, title, status, assigned user, and last updated date. Choose a case title to open the linked case in a new tab.

![The Linked Cases tab of a case, with the Unlink and Add linked case buttons.](https://docs.aws.amazon.com/connect/latest/adminguide/images/cases-linked-cases-tab.png)

+ To link another case, choose **Add linked case**. This requires the **Cases** - **Edit** permission.
+ To remove links, select one or more linked cases, and then choose **Unlink**. This requires the **Linked cases** - **Delete** permission. You can't undo this action.

When you merge cases, the primary and secondary cases are linked to each other automatically. For more information, see [Merge cases in Cases](case-merge.md).
