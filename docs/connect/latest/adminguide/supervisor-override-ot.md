# Connect Customer contact center supervisor ability to override approval for overtime and time off
<a name="supervisor-override-ot"></a>

Managers can override the system approval for OT/VTO and force decline a request by choosing on the vertical ellipsis next to the agent name. This option is shown in the following image of the **Overtime** pane.

![The overtime pane, the ellipses next to an agent name.](http://docs.aws.amazon.com/connect/latest/adminguide/images/supervisor-override-wfm.png)
