# Generate logs for published flows in Connect Customer
<a name="logs"></a>

After your flow is published live, you can use flow logs to help analyze flows and quickly find errors your customers encounter. If needed, you can roll back to a previous version of the flow.

For more information about using flow logs, see [Use flow logs to track events in Connect Customer flows](about-contact-flow-logs.md).
