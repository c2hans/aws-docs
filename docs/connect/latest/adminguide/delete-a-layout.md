# Delete a layout
<a name="delete-a-layout"></a>

Remove layouts that you no longer need from the **Profile layouts** page.

1. On the **Profile layouts** page, select the layout you want to remove.

1. Choose **Delete**.

1. Confirm the deletion. This action can't be undone.
