# EvaluationTranscriptPointOfInterest
<a name="API_EvaluationTranscriptPointOfInterest"></a>

Information about the point of interest in transcript provided to evaluation.

## Contents
<a name="API_EvaluationTranscriptPointOfInterest_Contents"></a>

 ** MillisecondOffsets **   <a name="connect-Type-EvaluationTranscriptPointOfInterest-MillisecondOffsets"></a>
Offset in milliseconds from the beginning of transcript.
Type: [EvaluationSuggestedAnswerTranscriptMillisecondOffsets](API_EvaluationSuggestedAnswerTranscriptMillisecondOffsets.md) object
Required: No

 ** TranscriptSegment **   <a name="connect-Type-EvaluationTranscriptPointOfInterest-TranscriptSegment"></a>
Segment of transcript.
Type: String
Required: No
