# LambdaIntegrationSummary
<a name="API_connect-outbound-campaigns-v2_LambdaIntegrationSummary"></a>

The summary of the integration with Lambda.

## Contents
<a name="API_connect-outbound-campaigns-v2_LambdaIntegrationSummary_Contents"></a>

 ** functionArn **   <a name="connect-Type-connect-outbound-campaigns-v2_LambdaIntegrationSummary-functionArn"></a>
The Amazon Resource Name (ARN) of the Lambda function configured for this integration.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 140.
Pattern: `arn:aws[a-zA-Z-]*:lambda:[a-z]{2}(-gov)?-[a-z]+-\d:\d{12}:function:([a-zA-Z0-9-_]+)(:([a-zA-Z0-9-_]+))?`
Required: Yes
