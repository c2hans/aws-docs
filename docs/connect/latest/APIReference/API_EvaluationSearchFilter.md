# EvaluationSearchFilter
<a name="API_EvaluationSearchFilter"></a>

Filters to be applied to search results.

## Contents
<a name="API_EvaluationSearchFilter_Contents"></a>

 ** AttributeFilter **   <a name="connect-Type-EvaluationSearchFilter-AttributeFilter"></a>
An object that can be used to specify tag conditions.
Type: [ControlPlaneAttributeFilter](API_ControlPlaneAttributeFilter.md) object
Required: No

 ** ContactEvaluationAttributeFilter **   <a name="connect-Type-EvaluationSearchFilter-ContactEvaluationAttributeFilter"></a>
An object that can be used to specify tag conditions and attribute conditions for contact evaluations.
Type: [ContactEvaluationAttributeFilter](API_ContactEvaluationAttributeFilter.md) object
Required: No
