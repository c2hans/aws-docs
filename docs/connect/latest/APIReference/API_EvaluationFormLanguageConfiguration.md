# EvaluationFormLanguageConfiguration
<a name="API_EvaluationFormLanguageConfiguration"></a>

Language configuration for an evaluation form.

## Contents
<a name="API_EvaluationFormLanguageConfiguration_Contents"></a>

 ** FormLanguage **   <a name="connect-Type-EvaluationFormLanguageConfiguration-FormLanguage"></a>
The language for the evaluation form.
Type: String
Valid Values: `de-DE | en-US | es-ES | fr-FR | it-IT | pt-BR | ja-JP | ko-KR | zh-CN`
Required: No
