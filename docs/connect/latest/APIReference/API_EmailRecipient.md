# EmailRecipient
<a name="API_EmailRecipient"></a>

Information about the email recipient

## Contents
<a name="API_EmailRecipient_Contents"></a>

 ** Address **   <a name="connect-Type-EmailRecipient-Address"></a>
Address of the email recipient.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No

 ** DisplayName **   <a name="connect-Type-EmailRecipient-DisplayName"></a>
Display name of the email recipient.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
