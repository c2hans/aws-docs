# RealTimeContactAnalysisCharacterInterval
<a name="API_RealTimeContactAnalysisCharacterInterval"></a>

Begin and end offsets for a part of text.

## Contents
<a name="API_RealTimeContactAnalysisCharacterInterval_Contents"></a>

 ** BeginOffsetChar **   <a name="connect-Type-RealTimeContactAnalysisCharacterInterval-BeginOffsetChar"></a>
The beginning of the character interval.
Type: Integer
Valid Range: Minimum value of 0.
Required: Yes

 ** EndOffsetChar **   <a name="connect-Type-RealTimeContactAnalysisCharacterInterval-EndOffsetChar"></a>
The end of the character interval.
Type: Integer
Valid Range: Minimum value of 0.
Required: Yes
