# Attendee
<a name="API_connect-participant_Attendee"></a>

The attendee information, including attendee ID and join token.

## Contents
<a name="API_connect-participant_Attendee_Contents"></a>

 ** AttendeeId **   <a name="connect-Type-connect-participant_Attendee-AttendeeId"></a>
The Amazon Chime SDK attendee ID.
Type: String
Required: No

 ** JoinToken **   <a name="connect-Type-connect-participant_Attendee-JoinToken"></a>
The join token used by the Amazon Chime SDK attendee.
Type: String
Required: No
