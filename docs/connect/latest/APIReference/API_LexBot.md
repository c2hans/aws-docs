# LexBot
<a name="API_LexBot"></a>

Configuration information of an Amazon Lex bot.

## Contents
<a name="API_LexBot_Contents"></a>

 ** LexRegion **   <a name="connect-Type-LexBot-LexRegion"></a>
The AWS Region where the Amazon Lex bot was created.
Type: String
Length Constraints: Maximum length of 60.
Required: Yes

 ** Name **   <a name="connect-Type-LexBot-Name"></a>
The name of the Amazon Lex bot.
Type: String
Length Constraints: Maximum length of 50.
Required: Yes
