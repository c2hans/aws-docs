# CrossChannelWorkloadBehavior
<a name="API_CrossChannelWorkloadBehavior"></a>

Defines the cross-channel and workload type routing behavior that allows an agent working on a contact to be offered a contact from a different channel or workload type.

## Contents
<a name="API_CrossChannelWorkloadBehavior_Contents"></a>

 ** ChannelWorkloadBehaviorType **   <a name="connect-Type-CrossChannelWorkloadBehavior-ChannelWorkloadBehaviorType"></a>
Specifies the routing behavior for an agent handling their current channel and workload type.
Type: String
Valid Values: `ROUTE_CURRENT_CHANNEL_CURRENT_WORKLOADTYPE_ONLY | ROUTE_CURRENT_CHANNEL_ANY_WORKLOADTYPE_ONLY | ROUTE_ANY_CHANNEL_ANY_WORKLOAD_TYPE`
Required: No
