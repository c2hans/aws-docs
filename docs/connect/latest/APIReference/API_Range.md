# Range
<a name="API_Range"></a>

An Object to define the minimum and maximum proficiency levels.

## Contents
<a name="API_Range_Contents"></a>

 ** MaxProficiencyLevel **   <a name="connect-Type-Range-MaxProficiencyLevel"></a>
The maximum proficiency level of the range.
Type: Float
Valid Range: Minimum value of 1.0. Maximum value of 5.0.
Required: No

 ** MinProficiencyLevel **   <a name="connect-Type-Range-MinProficiencyLevel"></a>
The minimum proficiency level of the range.
Type: Float
Valid Range: Minimum value of 1.0. Maximum value of 5.0.
Required: No
