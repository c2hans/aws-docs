# HoursOfOperationSummary
<a name="API_HoursOfOperationSummary"></a>

Contains summary information about hours of operation for a contact center.

## Contents
<a name="API_HoursOfOperationSummary_Contents"></a>

 ** Arn **   <a name="connect-Type-HoursOfOperationSummary-Arn"></a>
The Amazon Resource Name (ARN) of the hours of operation.
Type: String
Required: No

 ** Id **   <a name="connect-Type-HoursOfOperationSummary-Id"></a>
The identifier of the hours of operation.
Type: String
Required: No

 ** LastModifiedRegion **   <a name="connect-Type-HoursOfOperationSummary-LastModifiedRegion"></a>
The AWS Region where this resource was last modified.
Type: String
Pattern: `[a-z]{2}(-[a-z]+){1,2}(-[0-9])?`
Required: No

 ** LastModifiedTime **   <a name="connect-Type-HoursOfOperationSummary-LastModifiedTime"></a>
The timestamp when this resource was last modified.
Type: Timestamp
Required: No

 ** Name **   <a name="connect-Type-HoursOfOperationSummary-Name"></a>
The name of the hours of operation.
Type: String
Required: No
