# DeviceInfo
<a name="API_DeviceInfo"></a>

Information regarding the device.

## Contents
<a name="API_DeviceInfo_Contents"></a>

 ** OperatingSystem **   <a name="connect-Type-DeviceInfo-OperatingSystem"></a>
Operating system that the participant used for the call.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 128.
Required: No

 ** PlatformName **   <a name="connect-Type-DeviceInfo-PlatformName"></a>
Name of the platform that the participant used for the call.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 128.
Required: No

 ** PlatformVersion **   <a name="connect-Type-DeviceInfo-PlatformVersion"></a>
Version of the platform that the participant used for the call.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 128.
Required: No
