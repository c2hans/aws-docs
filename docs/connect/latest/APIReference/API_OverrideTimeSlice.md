# OverrideTimeSlice
<a name="API_OverrideTimeSlice"></a>

The start time or end time for an hours of operation override.

## Contents
<a name="API_OverrideTimeSlice_Contents"></a>

 ** Hours **   <a name="connect-Type-OverrideTimeSlice-Hours"></a>
The hours.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 23.
Required: Yes

 ** Minutes **   <a name="connect-Type-OverrideTimeSlice-Minutes"></a>
The minutes.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 59.
Required: Yes
