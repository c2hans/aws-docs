# AnswerMachineDetectionConfig
<a name="API_AnswerMachineDetectionConfig"></a>

Configuration of the answering machine detection.

## Contents
<a name="API_AnswerMachineDetectionConfig_Contents"></a>

 ** AwaitAnswerMachinePrompt **   <a name="connect-Type-AnswerMachineDetectionConfig-AwaitAnswerMachinePrompt"></a>
Wait for the answering machine prompt.
Type: Boolean
Required: No

 ** EnableAnswerMachineDetection **   <a name="connect-Type-AnswerMachineDetectionConfig-EnableAnswerMachineDetection"></a>
The flag to indicate if answer machine detection analysis needs to be performed for a voice call. If set to `true`, `TrafficType` must be set as `CAMPAIGN`.
Type: Boolean
Required: No
