# ChannelContext
<a name="API_connect-outbound-campaigns-v2_ChannelContext"></a>

Contains channel-specific context for the event trigger, currently scoped to web notifications.

## Contents
<a name="API_connect-outbound-campaigns-v2_ChannelContext_Contents"></a>

 ** webNotificationContext **   <a name="connect-Type-connect-outbound-campaigns-v2_ChannelContext-webNotificationContext"></a>
The web notification context, including session and browser identifiers.
Type: [WebNotificationContext](API_connect-outbound-campaigns-v2_WebNotificationContext.md) object
Required: No
