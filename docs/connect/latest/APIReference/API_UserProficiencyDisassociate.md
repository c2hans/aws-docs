# UserProficiencyDisassociate
<a name="API_UserProficiencyDisassociate"></a>

Information about proficiency to be disassociated from the user.

## Contents
<a name="API_UserProficiencyDisassociate_Contents"></a>

 ** AttributeName **   <a name="connect-Type-UserProficiencyDisassociate-AttributeName"></a>
The name of user's proficiency.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: Yes

 ** AttributeValue **   <a name="connect-Type-UserProficiencyDisassociate-AttributeValue"></a>
The value of user's proficiency.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: Yes
