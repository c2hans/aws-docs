# HierarchyLevel
<a name="API_HierarchyLevel"></a>

Contains information about a hierarchy level.

## Contents
<a name="API_HierarchyLevel_Contents"></a>

 ** Arn **   <a name="connect-Type-HierarchyLevel-Arn"></a>
The Amazon Resource Name (ARN) of the hierarchy level.
Type: String
Required: No

 ** Id **   <a name="connect-Type-HierarchyLevel-Id"></a>
The identifier of the hierarchy level.
Type: String
Required: No

 ** LastModifiedRegion **   <a name="connect-Type-HierarchyLevel-LastModifiedRegion"></a>
The AWS Region where this resource was last modified.
Type: String
Pattern: `[a-z]{2}(-[a-z]+){1,2}(-[0-9])?`
Required: No

 ** LastModifiedTime **   <a name="connect-Type-HierarchyLevel-LastModifiedTime"></a>
The timestamp when this resource was last modified.
Type: Timestamp
Required: No

 ** Name **   <a name="connect-Type-HierarchyLevel-Name"></a>
The name of the hierarchy level.
Type: String
Required: No
