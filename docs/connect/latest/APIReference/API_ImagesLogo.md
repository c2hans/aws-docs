# ImagesLogo
<a name="API_ImagesLogo"></a>

Contains logo image configuration for workspace themes.

## Contents
<a name="API_ImagesLogo_Contents"></a>

 ** Default **   <a name="connect-Type-ImagesLogo-Default"></a>
The default logo image displayed in the workspace.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 254.
Pattern: `.*\\S.*`
Required: No

 ** Favicon **   <a name="connect-Type-ImagesLogo-Favicon"></a>
The favicon image displayed in the browser tab.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 254.
Pattern: `.*\\S.*`
Required: No
