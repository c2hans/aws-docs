# WorkspaceThemePalette
<a name="API_WorkspaceThemePalette"></a>

Contains color palette configuration for different areas of a workspace.

## Contents
<a name="API_WorkspaceThemePalette_Contents"></a>

 ** Canvas **   <a name="connect-Type-WorkspaceThemePalette-Canvas"></a>
The color configuration for the canvas area.
Type: [PaletteCanvas](API_PaletteCanvas.md) object
Required: No

 ** Header **   <a name="connect-Type-WorkspaceThemePalette-Header"></a>
The color configuration for the header area.
Type: [PaletteHeader](API_PaletteHeader.md) object
Required: No

 ** Navigation **   <a name="connect-Type-WorkspaceThemePalette-Navigation"></a>
The color configuration for the navigation area.
Type: [PaletteNavigation](API_PaletteNavigation.md) object
Required: No

 ** Primary **   <a name="connect-Type-WorkspaceThemePalette-Primary"></a>
The primary color configuration used throughout the workspace.
Type: [PalettePrimary](API_PalettePrimary.md) object
Required: No
