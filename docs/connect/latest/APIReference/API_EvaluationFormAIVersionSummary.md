# EvaluationFormAIVersionSummary
<a name="API_EvaluationFormAIVersionSummary"></a>

Contains the name and lifecycle information for an AI version that you can use when creating or updating an evaluation form.

## Contents
<a name="API_EvaluationFormAIVersionSummary_Contents"></a>

 ** AIVersionLifecycle **   <a name="connect-Type-EvaluationFormAIVersionSummary-AIVersionLifecycle"></a>
The lifecycle information for this AI version, including its status and availability dates.
Type: [EvaluationFormAIVersionLifecycle](API_EvaluationFormAIVersionLifecycle.md) object
Required: Yes

 ** AIVersionName **   <a name="connect-Type-EvaluationFormAIVersionSummary-AIVersionName"></a>
The name of the AI version.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes
