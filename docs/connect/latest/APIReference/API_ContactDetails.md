# ContactDetails
<a name="API_ContactDetails"></a>

A map of string key/value pairs that contain user-defined attributes which are lightly typed within the contact. This object is used only for task contacts.

## Contents
<a name="API_ContactDetails_Contents"></a>

 ** Description **   <a name="connect-Type-ContactDetails-Description"></a>
Teh description of the contact details.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: No

 ** Name **   <a name="connect-Type-ContactDetails-Name"></a>
The name of the contact details.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: No
