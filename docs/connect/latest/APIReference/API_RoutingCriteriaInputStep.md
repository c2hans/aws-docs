# RoutingCriteriaInputStep
<a name="API_RoutingCriteriaInputStep"></a>

Step defines the list of agents to be routed or route based on the agent requirements such as ProficiencyLevel, Name, or Value.

## Contents
<a name="API_RoutingCriteriaInputStep_Contents"></a>

 ** Expiry **   <a name="connect-Type-RoutingCriteriaInputStep-Expiry"></a>
An object to specify the expiration of a routing step.
Type: [RoutingCriteriaInputStepExpiry](API_RoutingCriteriaInputStepExpiry.md) object
Required: No

 ** Expression **   <a name="connect-Type-RoutingCriteriaInputStep-Expression"></a>
A tagged union to specify expression for a routing step.
Type: [Expression](API_Expression.md) object
Required: No
