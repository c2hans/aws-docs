# HierarchyGroupCondition
<a name="API_HierarchyGroupCondition"></a>

A leaf node condition which can be used to specify a hierarchy group condition.

## Contents
<a name="API_HierarchyGroupCondition_Contents"></a>

 ** HierarchyGroupMatchType **   <a name="connect-Type-HierarchyGroupCondition-HierarchyGroupMatchType"></a>
The type of hierarchy group match.
Type: String
Valid Values: `EXACT | WITH_CHILD_GROUPS`
Required: No

 ** Value **   <a name="connect-Type-HierarchyGroupCondition-Value"></a>
The value in the hierarchy group condition.
Type: String
Required: No
