# KinesisStreamConfig
<a name="API_KinesisStreamConfig"></a>

Configuration information of a Kinesis data stream.

## Contents
<a name="API_KinesisStreamConfig_Contents"></a>

 ** StreamArn **   <a name="connect-Type-KinesisStreamConfig-StreamArn"></a>

Type: String
Required: Yes
