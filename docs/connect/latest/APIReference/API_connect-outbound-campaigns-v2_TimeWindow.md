# TimeWindow
<a name="API_connect-outbound-campaigns-v2_TimeWindow"></a>

Contains information about a time window.

## Contents
<a name="API_connect-outbound-campaigns-v2_TimeWindow_Contents"></a>

 ** openHours **   <a name="connect-Type-connect-outbound-campaigns-v2_TimeWindow-openHours"></a>
The open hours configuration.
Type: [OpenHours](API_connect-outbound-campaigns-v2_OpenHours.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes

 ** restrictedPeriods **   <a name="connect-Type-connect-outbound-campaigns-v2_TimeWindow-restrictedPeriods"></a>
The restricted periods configuration.
Type: [RestrictedPeriods](API_connect-outbound-campaigns-v2_RestrictedPeriods.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: No
