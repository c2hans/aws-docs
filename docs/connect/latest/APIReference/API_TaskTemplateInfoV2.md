# TaskTemplateInfoV2
<a name="API_TaskTemplateInfoV2"></a>

Information about the task template used to create this contact.

## Contents
<a name="API_TaskTemplateInfoV2_Contents"></a>

 ** Arn **   <a name="connect-Type-TaskTemplateInfoV2-Arn"></a>
The Amazon Resource Name (ARN) of the task template used to create this contact.
Type: String
Required: No

 ** Name **   <a name="connect-Type-TaskTemplateInfoV2-Name"></a>
The name of the task template used to create this contact.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No
