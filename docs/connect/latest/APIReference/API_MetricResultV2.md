# MetricResultV2
<a name="API_MetricResultV2"></a>

Contains information about the metric results.

## Contents
<a name="API_MetricResultV2_Contents"></a>

 ** Collections **   <a name="connect-Type-MetricResultV2-Collections"></a>
The set of metrics.
Type: Array of [MetricDataV2](API_MetricDataV2.md) objects
Required: No

 ** Dimensions **   <a name="connect-Type-MetricResultV2-Dimensions"></a>
The dimension for the metrics.
Type: String to string map
Required: No

 ** MetricInterval **   <a name="connect-Type-MetricResultV2-MetricInterval"></a>
The interval period with the start and end time for the metrics.
Type: [MetricInterval](API_MetricInterval.md) object
Required: No
