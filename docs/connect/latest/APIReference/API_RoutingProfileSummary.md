# RoutingProfileSummary
<a name="API_RoutingProfileSummary"></a>

Contains summary information about a routing profile.

## Contents
<a name="API_RoutingProfileSummary_Contents"></a>

 ** Arn **   <a name="connect-Type-RoutingProfileSummary-Arn"></a>
The Amazon Resource Name (ARN) of the routing profile.
Type: String
Required: No

 ** Id **   <a name="connect-Type-RoutingProfileSummary-Id"></a>
The identifier of the routing profile.
Type: String
Required: No

 ** LastModifiedRegion **   <a name="connect-Type-RoutingProfileSummary-LastModifiedRegion"></a>
The AWS Region where this resource was last modified.
Type: String
Pattern: `[a-z]{2}(-[a-z]+){1,2}(-[0-9])?`
Required: No

 ** LastModifiedTime **   <a name="connect-Type-RoutingProfileSummary-LastModifiedTime"></a>
The timestamp when this resource was last modified.
Type: Timestamp
Required: No

 ** Name **   <a name="connect-Type-RoutingProfileSummary-Name"></a>
The name of the routing profile.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 127.
Required: No
