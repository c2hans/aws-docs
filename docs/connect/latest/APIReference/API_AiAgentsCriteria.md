# AiAgentsCriteria
<a name="API_AiAgentsCriteria"></a>

AI Agent search criteria definitions.

## Contents
<a name="API_AiAgentsCriteria_Contents"></a>

 ** Criteria **   <a name="connect-Type-AiAgentsCriteria-Criteria"></a>
The list of criteria based on AI Agent metadata.
Type: Array of [AiAgentSearchCriteria](API_AiAgentSearchCriteria.md) objects
Array Members: Minimum number of 0 items. Maximum number of 1 item.
Required: No
