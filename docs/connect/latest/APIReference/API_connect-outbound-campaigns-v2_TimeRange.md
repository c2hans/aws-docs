# TimeRange
<a name="API_connect-outbound-campaigns-v2_TimeRange"></a>

Contains information about a time range.

## Contents
<a name="API_connect-outbound-campaigns-v2_TimeRange_Contents"></a>

 ** endTime **   <a name="connect-Type-connect-outbound-campaigns-v2_TimeRange-endTime"></a>
The end time of the time range.
Type: String
Pattern: `T\d{2}:\d{2}`
Required: Yes

 ** startTime **   <a name="connect-Type-connect-outbound-campaigns-v2_TimeRange-startTime"></a>
The start time of the time range.
Type: String
Pattern: `T\d{2}:\d{2}`
Required: Yes
