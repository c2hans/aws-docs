# EvaluationFormValidationFindingItem
<a name="API_EvaluationFormValidationFindingItem"></a>

Information about an evaluation form item affected by a validation finding.

## Contents
<a name="API_EvaluationFormValidationFindingItem_Contents"></a>

 ** Property **   <a name="connect-Type-EvaluationFormValidationFindingItem-Property"></a>
The specific property of the evaluation form item that the finding relates to.
Type: String
Required: No

 ** RefId **   <a name="connect-Type-EvaluationFormValidationFindingItem-RefId"></a>
The identifier of the evaluation form item (question or section) affected by the finding.
Type: String
Required: No
