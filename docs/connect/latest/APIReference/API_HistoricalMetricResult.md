# HistoricalMetricResult
<a name="API_HistoricalMetricResult"></a>

<a name="API_HistoricalMetricResult_Contents"></a>

Type: Array of [HistoricalMetricData](API_HistoricalMetricData.md) objects
Required: No

 ** Dimensions **   <a name="connect-Type-HistoricalMetricResult-Dimensions"></a>
The dimension for the metrics.
Type: [Dimensions](API_Dimensions.md) object
Required: No
