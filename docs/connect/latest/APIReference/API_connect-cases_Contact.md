# Contact
<a name="API_connect-cases_Contact"></a>

An object that represents an Connect Customer contact object.

## Contents
<a name="API_connect-cases_Contact_Contents"></a>

 ** contactArn **   <a name="connect-Type-connect-cases_Contact-contactArn"></a>
A unique identifier of a contact in Connect Customer.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 500.
Required: Yes
