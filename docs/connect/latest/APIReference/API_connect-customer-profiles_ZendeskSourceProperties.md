# ZendeskSourceProperties
<a name="API_connect-customer-profiles_ZendeskSourceProperties"></a>

The properties that are applied when using Zendesk as a flow source.

## Contents
<a name="API_connect-customer-profiles_ZendeskSourceProperties_Contents"></a>

 ** Object **   <a name="connect-Type-connect-customer-profiles_ZendeskSourceProperties-Object"></a>
The object specified in the Zendesk flow source.
Type: String
Length Constraints: Maximum length of 512.
Pattern: `\S+`
Required: Yes
