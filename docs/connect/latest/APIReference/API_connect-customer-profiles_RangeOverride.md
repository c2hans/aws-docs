# RangeOverride
<a name="API_connect-customer-profiles_RangeOverride"></a>

Overrides the original range on a calculated attribute definition.

## Contents
<a name="API_connect-customer-profiles_RangeOverride_Contents"></a>

 ** Start **   <a name="connect-Type-connect-customer-profiles_RangeOverride-Start"></a>
The start time of when to include objects.
Type: Integer
Required: Yes

 ** Unit **   <a name="connect-Type-connect-customer-profiles_RangeOverride-Unit"></a>
The unit for start and end.
Type: String
Valid Values: `DAYS`
Required: Yes

 ** End **   <a name="connect-Type-connect-customer-profiles_RangeOverride-End"></a>
The end time of when to include objects.
Type: Integer
Required: No
