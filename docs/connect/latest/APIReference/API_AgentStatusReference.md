# AgentStatusReference
<a name="API_AgentStatusReference"></a>

Information about the agent's status.

## Contents
<a name="API_AgentStatusReference_Contents"></a>

 ** StatusArn **   <a name="connect-Type-AgentStatusReference-StatusArn"></a>
The Amazon Resource Name (ARN) of the agent's status.
Type: String
Required: No

 ** StatusName **   <a name="connect-Type-AgentStatusReference-StatusName"></a>
The name of the agent status.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 127.
Required: No

 ** StatusStartTimestamp **   <a name="connect-Type-AgentStatusReference-StatusStartTimestamp"></a>
The start timestamp of the agent's status.
Type: Timestamp
Required: No
