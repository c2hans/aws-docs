# PostAcceptTimeoutConfig
<a name="API_PostAcceptTimeoutConfig"></a>

Countdown timer configuration after the agent accepted the contact.

## Contents
<a name="API_PostAcceptTimeoutConfig_Contents"></a>

 ** DurationInSeconds **   <a name="connect-Type-PostAcceptTimeoutConfig-DurationInSeconds"></a>
Duration in seconds for the countdown timer after the agent accepted the contact.
Type: Integer
Valid Range: Minimum value of 0.
Required: Yes
