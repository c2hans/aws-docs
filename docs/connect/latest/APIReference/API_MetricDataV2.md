# MetricDataV2
<a name="API_MetricDataV2"></a>

Contains the name, thresholds, and metric filters.

## Contents
<a name="API_MetricDataV2_Contents"></a>

 ** Metric **   <a name="connect-Type-MetricDataV2-Metric"></a>
The metric name or metricId, thresholds, and metric filters of the returned metric.
Type: [MetricV2](API_MetricV2.md) object
Required: No

 ** Value **   <a name="connect-Type-MetricDataV2-Value"></a>
The corresponding value of the metric returned in the response.
Type: Double
Required: No
