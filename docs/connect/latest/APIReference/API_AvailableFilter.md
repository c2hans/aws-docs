# AvailableFilter
<a name="API_AvailableFilter"></a>

A filter that is available for use with the metric. Part of an AvailableFilterList that describes the filters that are available for use with the metric.

## Contents
<a name="API_AvailableFilter_Contents"></a>

 ** Id **   <a name="connect-Type-AvailableFilter-Id"></a>
The identifier of the filter.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No

 ** Type **   <a name="connect-Type-AvailableFilter-Type"></a>
The type of the filter. Valid values: `METRIC_LEVEL` \| `RESOURCE_LEVEL`.
Type: String
Valid Values: `METRIC_LEVEL | RESOURCE_LEVEL`
Required: No
