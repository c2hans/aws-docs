# ConnectionData
<a name="API_ConnectionData"></a>

Information required to join the call.

## Contents
<a name="API_ConnectionData_Contents"></a>

 ** Attendee **   <a name="connect-Type-ConnectionData-Attendee"></a>
The attendee information, including attendee ID and join token.
Type: [Attendee](API_Attendee.md) object
Required: No

 ** Meeting **   <a name="connect-Type-ConnectionData-Meeting"></a>
A meeting created using the Amazon Chime SDK.
Type: [Meeting](API_Meeting.md) object
Required: No
