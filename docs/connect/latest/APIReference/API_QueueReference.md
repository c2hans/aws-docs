# QueueReference
<a name="API_QueueReference"></a>

Contains information about a queue resource for which metrics are returned.

## Contents
<a name="API_QueueReference_Contents"></a>

 ** Arn **   <a name="connect-Type-QueueReference-Arn"></a>
The Amazon Resource Name (ARN) of the queue.
Type: String
Required: No

 ** Id **   <a name="connect-Type-QueueReference-Id"></a>
The identifier of the queue.
Type: String
Required: No
