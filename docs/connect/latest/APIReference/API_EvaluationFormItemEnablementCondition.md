# EvaluationFormItemEnablementCondition
<a name="API_EvaluationFormItemEnablementCondition"></a>

A condition for item enablement.

## Contents
<a name="API_EvaluationFormItemEnablementCondition_Contents"></a>

 ** Operands **   <a name="connect-Type-EvaluationFormItemEnablementCondition-Operands"></a>
Operands of the enablement condition.
Type: Array of [EvaluationFormItemEnablementConditionOperand](API_EvaluationFormItemEnablementConditionOperand.md) objects
Required: Yes

 ** Operator **   <a name="connect-Type-EvaluationFormItemEnablementCondition-Operator"></a>
The operator to be used to be applied to operands if more than one provided.
Type: String
Valid Values: `OR | AND`
Required: No
