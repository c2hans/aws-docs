# EvaluationReviewRequestComment
<a name="API_EvaluationReviewRequestComment"></a>

A comment provided when requesting an evaluation review.

## Contents
<a name="API_EvaluationReviewRequestComment_Contents"></a>

 ** Comment **   <a name="connect-Type-EvaluationReviewRequestComment-Comment"></a>
The text content of the review request comment.
Type: String
Length Constraints: Maximum length of 500.
Required: No

 ** CreatedBy **   <a name="connect-Type-EvaluationReviewRequestComment-CreatedBy"></a>
The user who created the evaluation review request comment.
Type: String
Required: No

 ** CreatedTime **   <a name="connect-Type-EvaluationReviewRequestComment-CreatedTime"></a>
The timestamp when the evaluation review request comment was created.
Type: Timestamp
Required: No
