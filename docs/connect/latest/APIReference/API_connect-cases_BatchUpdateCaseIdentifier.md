# BatchUpdateCaseIdentifier
<a name="API_connect-cases_BatchUpdateCaseIdentifier"></a>

Identifies a case to update in a `BatchUpdateCase` request.

## Contents
<a name="API_connect-cases_BatchUpdateCaseIdentifier_Contents"></a>

 ** caseIdentifier **   <a name="connect-Type-connect-cases_BatchUpdateCaseIdentifier-caseIdentifier"></a>
The identifier of the case to update. Specify either the case ID or the reference ID.
Type: [CaseIdentifierUnion](API_connect-cases_CaseIdentifierUnion.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes
