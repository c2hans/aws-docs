# ContactSearchSummaryAgentInfo
<a name="API_ContactSearchSummaryAgentInfo"></a>

Information about the agent who accepted the contact.

## Contents
<a name="API_ContactSearchSummaryAgentInfo_Contents"></a>

 ** ConnectedToAgentTimestamp **   <a name="connect-Type-ContactSearchSummaryAgentInfo-ConnectedToAgentTimestamp"></a>
The timestamp when the contact was connected to the agent.
Type: Timestamp
Required: No

 ** Id **   <a name="connect-Type-ContactSearchSummaryAgentInfo-Id"></a>
The identifier of the agent who accepted the contact.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
