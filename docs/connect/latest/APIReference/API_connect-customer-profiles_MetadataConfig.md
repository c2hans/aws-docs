# MetadataConfig
<a name="API_connect-customer-profiles_MetadataConfig"></a>

Configuration for metadata to include in recommendation responses.

## Contents
<a name="API_connect-customer-profiles_MetadataConfig_Contents"></a>

 ** MetadataColumns **   <a name="connect-Type-connect-customer-profiles_MetadataConfig-MetadataColumns"></a>
A list of metadata column names from your Items dataset to include in the recommendation response.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Length Constraints: Minimum length of 1. Maximum length of 150.
Required: No
