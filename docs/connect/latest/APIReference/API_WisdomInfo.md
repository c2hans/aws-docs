# WisdomInfo
<a name="API_WisdomInfo"></a>

Information about Connect Customer Wisdom.

## Contents
<a name="API_WisdomInfo_Contents"></a>

 ** AiAgents **   <a name="connect-Type-WisdomInfo-AiAgents"></a>
The array of AI agents involved in the contact.
Type: Array of [AiAgentInfo](API_AiAgentInfo.md) objects
Required: No

 ** SessionArn **   <a name="connect-Type-WisdomInfo-SessionArn"></a>
The Amazon Resource Name (ARN) of the Wisdom session.
Type: String
Required: No
