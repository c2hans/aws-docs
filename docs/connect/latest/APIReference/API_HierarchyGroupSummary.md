# HierarchyGroupSummary
<a name="API_HierarchyGroupSummary"></a>

Contains summary information about a hierarchy group.

## Contents
<a name="API_HierarchyGroupSummary_Contents"></a>

 ** Arn **   <a name="connect-Type-HierarchyGroupSummary-Arn"></a>
The Amazon Resource Name (ARN) of the hierarchy group.
Type: String
Required: No

 ** Id **   <a name="connect-Type-HierarchyGroupSummary-Id"></a>
The identifier of the hierarchy group.
Type: String
Required: No

 ** LastModifiedRegion **   <a name="connect-Type-HierarchyGroupSummary-LastModifiedRegion"></a>
The AWS Region where this resource was last modified.
Type: String
Pattern: `[a-z]{2}(-[a-z]+){1,2}(-[0-9])?`
Required: No

 ** LastModifiedTime **   <a name="connect-Type-HierarchyGroupSummary-LastModifiedTime"></a>
The timestamp when this resource was last modified.
Type: Timestamp
Required: No

 ** Name **   <a name="connect-Type-HierarchyGroupSummary-Name"></a>
The name of the hierarchy group.
Type: String
Required: No
