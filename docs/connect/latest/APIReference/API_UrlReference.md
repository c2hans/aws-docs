# UrlReference
<a name="API_UrlReference"></a>

The URL reference.

## Contents
<a name="API_UrlReference_Contents"></a>

 ** Name **   <a name="connect-Type-UrlReference-Name"></a>
Identifier of the URL reference.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Required: No

 ** Value **   <a name="connect-Type-UrlReference-Value"></a>
A valid URL.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 4096.
Required: No
