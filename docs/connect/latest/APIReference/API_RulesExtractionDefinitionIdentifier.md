# RulesExtractionDefinitionIdentifier
<a name="API_RulesExtractionDefinitionIdentifier"></a>

An identifier that references an extraction definition resource.

## Contents
<a name="API_RulesExtractionDefinitionIdentifier_Contents"></a>

 ** Identifier **   <a name="connect-Type-RulesExtractionDefinitionIdentifier-Identifier"></a>
The identifier of the extraction definition.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes
