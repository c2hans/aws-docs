# ConnectionCredentials
<a name="API_connect-participant_ConnectionCredentials"></a>

Connection credentials.

## Contents
<a name="API_connect-participant_ConnectionCredentials_Contents"></a>

 ** ConnectionToken **   <a name="connect-Type-connect-participant_ConnectionCredentials-ConnectionToken"></a>
The connection token.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1000.
Required: No

 ** Expiry **   <a name="connect-Type-connect-participant_ConnectionCredentials-Expiry"></a>
The expiration of the token.
It's specified in ISO 8601 format: yyyy-MM-ddThh:mm:ss.SSSZ. For example, 2019-11-08T02:41:28.172Z.
Type: String
Required: No
