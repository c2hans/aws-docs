# ParticipantConfiguration
<a name="API_ParticipantConfiguration"></a>

 The configuration of the participant.

## Contents
<a name="API_ParticipantConfiguration_Contents"></a>

 ** ResponseMode **   <a name="connect-Type-ParticipantConfiguration-ResponseMode"></a>
 The mode in which responses should be sent to the participant.
Type: String
Valid Values: `INCREMENTAL | COMPLETE`
Required: No
