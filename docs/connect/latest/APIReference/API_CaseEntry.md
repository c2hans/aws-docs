# CaseEntry
<a name="API_CaseEntry"></a>

Information about a case associated with a contact.

## Contents
<a name="API_CaseEntry_Contents"></a>

 ** CaseId **   <a name="connect-Type-CaseEntry-CaseId"></a>
Unique identifier of the case in UUID format.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 36.
Required: No

 ** CaseReferenceNumber **   <a name="connect-Type-CaseEntry-CaseReferenceNumber"></a>
A friendly number for the case. Reference numbers are not guaranteed to be unique.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 50.
Required: No
