# RealTimeContactAnalysisCategoryDetails
<a name="API_RealTimeContactAnalysisCategoryDetails"></a>

Provides information about the category rule that was matched.

## Contents
<a name="API_RealTimeContactAnalysisCategoryDetails_Contents"></a>

 ** PointsOfInterest **   <a name="connect-Type-RealTimeContactAnalysisCategoryDetails-PointsOfInterest"></a>
List of PointOfInterest - objects describing a single match of a rule.
Type: Array of [RealTimeContactAnalysisPointOfInterest](API_RealTimeContactAnalysisPointOfInterest.md) objects
Array Members: Minimum number of 0 items. Maximum number of 5 items.
Required: Yes
