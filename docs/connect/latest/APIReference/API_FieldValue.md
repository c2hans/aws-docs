# FieldValue
<a name="API_FieldValue"></a>

Object for case field values.

## Contents
<a name="API_FieldValue_Contents"></a>

 ** Id **   <a name="connect-Type-FieldValue-Id"></a>
Unique identifier of a field.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 500.
Required: Yes

 ** Value **   <a name="connect-Type-FieldValue-Value"></a>
Union of potential field value types.
Type: [FieldValueUnion](API_FieldValueUnion.md) object
Required: Yes
