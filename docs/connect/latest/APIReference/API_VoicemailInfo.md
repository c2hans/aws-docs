# VoicemailInfo

Information about the voicemails recorded for a voice contact.

## Contents
<a name="API_VoicemailInfo_Contents"></a>

 ** NumberOfVoicemails **   <a name="connect-Type-VoicemailInfo-NumberOfVoicemails"></a>
The number of voicemails recorded for the contact. Valid range is 1-3.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 3.
Required: No
