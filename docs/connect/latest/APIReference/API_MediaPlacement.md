# MediaPlacement
<a name="API_MediaPlacement"></a>

A set of endpoints used by clients to connect to the media service group for an Amazon Chime SDK meeting.

## Contents
<a name="API_MediaPlacement_Contents"></a>

 ** AudioFallbackUrl **   <a name="connect-Type-MediaPlacement-AudioFallbackUrl"></a>
The audio fallback URL.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2000.
Required: No

 ** AudioHostUrl **   <a name="connect-Type-MediaPlacement-AudioHostUrl"></a>
The audio host URL.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2000.
Required: No

 ** EventIngestionUrl **   <a name="connect-Type-MediaPlacement-EventIngestionUrl"></a>
The event ingestion URL to which you send client meeting events.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2000.
Required: No

 ** SignalingUrl **   <a name="connect-Type-MediaPlacement-SignalingUrl"></a>
The signaling URL.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2000.
Required: No

 ** TurnControlUrl **   <a name="connect-Type-MediaPlacement-TurnControlUrl"></a>
The turn control URL.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2000.
Required: No
