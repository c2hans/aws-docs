# BooleanCondition
<a name="API_BooleanCondition"></a>

A boolean search condition for Search APIs.

## Contents
<a name="API_BooleanCondition_Contents"></a>

 ** ComparisonType **   <a name="connect-Type-BooleanCondition-ComparisonType"></a>
Boolean property comparison type.
Type: String
Valid Values: `IS_TRUE | IS_FALSE`
Required: No

 ** FieldName **   <a name="connect-Type-BooleanCondition-FieldName"></a>
A name of the property to be searched.
Type: String
Required: No
