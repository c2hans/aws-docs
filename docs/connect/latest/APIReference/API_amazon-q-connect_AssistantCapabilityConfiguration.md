# AssistantCapabilityConfiguration
<a name="API_amazon-q-connect_AssistantCapabilityConfiguration"></a>

 ** type **   <a name="connect-Type-amazon-q-connect_AssistantCapabilityConfiguration-type"></a>

Type: String
Valid Values: `V1 | V2`
Required: No
