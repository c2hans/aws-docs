# AnalyticsDataSetsResult
<a name="API_AnalyticsDataSetsResult"></a>

Information about datasets that are available to associate with: `DataSetId`, `DataSetName`.

## Contents
<a name="API_AnalyticsDataSetsResult_Contents"></a>

 ** DataSetId **   <a name="connect-Type-AnalyticsDataSetsResult-DataSetId"></a>
The identifier of the dataset.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No

 ** DataSetName **   <a name="connect-Type-AnalyticsDataSetsResult-DataSetName"></a>
The name of the dataset.
Type: String
Required: No
