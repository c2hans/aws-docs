# CurrentMetricResult
<a name="API_CurrentMetricResult"></a>

Contains information about a set of real-time metrics.

<a name="API_CurrentMetricResult_Contents"></a>

 ** Collections **   <a name="connect-Type-CurrentMetricResult-Collections"></a>
The set of metrics.
Type: Array of [CurrentMetricData](API_CurrentMetricData.md) objects
Required: No

 ** Dimensions **   <a name="connect-Type-CurrentMetricResult-Dimensions"></a>
The dimensions for the metrics.
Type: [Dimensions](API_Dimensions.md) object
Required: No
