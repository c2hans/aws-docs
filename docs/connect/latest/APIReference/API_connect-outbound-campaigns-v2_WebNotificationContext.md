# WebNotificationContext
<a name="API_connect-outbound-campaigns-v2_WebNotificationContext"></a>

Contains metadata for a web notification channel event trigger.

## Contents
<a name="API_connect-outbound-campaigns-v2_WebNotificationContext_Contents"></a>

 ** browserId **   <a name="connect-Type-connect-outbound-campaigns-v2_WebNotificationContext-browserId"></a>
The browser identifier for the web notification event trigger. Maximum length of 36 characters.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 36.
Required: No

 ** sessionId **   <a name="connect-Type-connect-outbound-campaigns-v2_WebNotificationContext-sessionId"></a>
The session identifier for the web notification event trigger. Maximum length of 36 characters.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 36.
Required: No
