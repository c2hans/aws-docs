# SummaryConfiguration
<a name="API_SummaryConfiguration"></a>

The summary configuration for conversational analytics.

## Contents
<a name="API_SummaryConfiguration_Contents"></a>

 ** SummaryModes **   <a name="connect-Type-SummaryConfiguration-SummaryModes"></a>
The summary modes that determine what type of summarization is generated. Valid values: `PostContact` \| `AutomatedInteraction` \| `ContactChain`.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 2 items.
Valid Values: `PostContact | AutomatedInteraction | ContactChain`
Required: Yes
