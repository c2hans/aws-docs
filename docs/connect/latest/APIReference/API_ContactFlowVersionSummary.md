# ContactFlowVersionSummary
<a name="API_ContactFlowVersionSummary"></a>

A summary of a flow version's metadata.

## Contents
<a name="API_ContactFlowVersionSummary_Contents"></a>

 ** Arn **   <a name="connect-Type-ContactFlowVersionSummary-Arn"></a>
The Amazon Resource Name (ARN) of the view version.
Type: String
Required: No

 ** Version **   <a name="connect-Type-ContactFlowVersionSummary-Version"></a>
The identifier of the flow version.
Type: Long
Valid Range: Minimum value of 1.
Required: No

 ** VersionDescription **   <a name="connect-Type-ContactFlowVersionSummary-VersionDescription"></a>
The description of the flow version.
Type: String
Required: No
