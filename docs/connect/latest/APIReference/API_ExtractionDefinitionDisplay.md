# ExtractionDefinitionDisplay
<a name="API_ExtractionDefinitionDisplay"></a>

The display configuration for an extraction definition.

## Contents
<a name="API_ExtractionDefinitionDisplay_Contents"></a>

 ** Label **   <a name="connect-Type-ExtractionDefinitionDisplay-Label"></a>
The label displayed in the agent workspace for this extraction definition.
Type: String
Length Constraints: Maximum length of 25.
Required: No
