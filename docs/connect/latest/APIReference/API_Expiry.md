# Expiry
<a name="API_Expiry"></a>

An object to specify the expiration of a routing step.

## Contents
<a name="API_Expiry_Contents"></a>

 ** DurationInSeconds **   <a name="connect-Type-Expiry-DurationInSeconds"></a>
The number of seconds to wait before expiring the routing step.
Type: Integer
Required: No

 ** ExpiryTimestamp **   <a name="connect-Type-Expiry-ExpiryTimestamp"></a>
The timestamp indicating when the routing step expires.
Type: Timestamp
Required: No
