# QueueInfo
<a name="API_QueueInfo"></a>

If this contact was queued, this contains information about the queue.

## Contents
<a name="API_QueueInfo_Contents"></a>

 ** EnqueueTimestamp **   <a name="connect-Type-QueueInfo-EnqueueTimestamp"></a>
The timestamp when the contact was added to the queue.
Type: Timestamp
Required: No

 ** Id **   <a name="connect-Type-QueueInfo-Id"></a>
The unique identifier for the queue.
Type: String
Required: No
