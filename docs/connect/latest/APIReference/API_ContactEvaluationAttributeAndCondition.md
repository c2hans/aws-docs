# ContactEvaluationAttributeAndCondition
<a name="API_ContactEvaluationAttributeAndCondition"></a>

A list of conditions which would be applied together with an `AND` condition.

## Contents
<a name="API_ContactEvaluationAttributeAndCondition_Contents"></a>

 ** AttributeConditions **   <a name="connect-Type-ContactEvaluationAttributeAndCondition-AttributeConditions"></a>
A list of attribute conditions to apply.
Type: Array of [ContactEvaluationAttributeCondition](API_ContactEvaluationAttributeCondition.md) objects
Required: No

 ** TagConditions **   <a name="connect-Type-ContactEvaluationAttributeAndCondition-TagConditions"></a>
A list of tag conditions to apply.
Type: Array of [TagCondition](API_TagCondition.md) objects
Required: No
