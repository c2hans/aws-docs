# EvaluationSuggestedAnswerTranscriptMillisecondOffsets
<a name="API_EvaluationSuggestedAnswerTranscriptMillisecondOffsets"></a>

The milliseconds offset for transcript reference in suggested answer.

## Contents
<a name="API_EvaluationSuggestedAnswerTranscriptMillisecondOffsets_Contents"></a>

 ** BeginOffsetMillis **   <a name="connect-Type-EvaluationSuggestedAnswerTranscriptMillisecondOffsets-BeginOffsetMillis"></a>
Offset in milliseconds from the beginning of the transcript.
Type: Integer
Valid Range: Minimum value of 0.
Required: Yes
