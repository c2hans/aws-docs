# SearchableSegmentAttributesCriteria
<a name="API_SearchableSegmentAttributesCriteria"></a>

The search criteria based on searchable segment attribute key and values to search on.

## Contents
<a name="API_SearchableSegmentAttributesCriteria_Contents"></a>

 ** Key **   <a name="connect-Type-SearchableSegmentAttributesCriteria-Key"></a>
The key containing a searchable segment attribute.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: Yes

 ** Values **   <a name="connect-Type-SearchableSegmentAttributesCriteria-Values"></a>
The list of values to search for within a searchable segment attribute.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 20 items.
Length Constraints: Minimum length of 0. Maximum length of 128.
Required: Yes
