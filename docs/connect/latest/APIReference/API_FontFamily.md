# FontFamily
<a name="API_FontFamily"></a>

Contains font family configuration for workspace themes.

## Contents
<a name="API_FontFamily_Contents"></a>

 ** Default **   <a name="connect-Type-FontFamily-Default"></a>
The default font family to use in the workspace theme.
Type: String
Valid Values: `Arial | Courier New | Georgia | Times New Roman | Trebuchet | Verdana`
Required: No
