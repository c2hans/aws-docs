# FlowAssociationSummary
<a name="API_FlowAssociationSummary"></a>

Information about flow associations.

## Contents
<a name="API_FlowAssociationSummary_Contents"></a>

 ** FlowId **   <a name="connect-Type-FlowAssociationSummary-FlowId"></a>
The identifier of the flow.
Type: String
Required: No

 ** ResourceId **   <a name="connect-Type-FlowAssociationSummary-ResourceId"></a>
The identifier of the resource.
Type: String
Required: No

 ** ResourceType **   <a name="connect-Type-FlowAssociationSummary-ResourceType"></a>
The type of resource association.
Type: String
Valid Values: `VOICE_PHONE_NUMBER`
Required: No
