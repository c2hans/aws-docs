# OutboundEmailConfig
<a name="API_OutboundEmailConfig"></a>

 ** OutboundEmailAddressId **   <a name="connect-Type-OutboundEmailConfig-OutboundEmailAddressId"></a>

Length Constraints: Minimum length of 1. Maximum length of 500.
Required: No
