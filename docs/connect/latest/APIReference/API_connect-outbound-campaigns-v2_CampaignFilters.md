# CampaignFilters
<a name="API_connect-outbound-campaigns-v2_CampaignFilters"></a>

Contains the filters to apply when retrieving campaigns.

## Contents
<a name="API_connect-outbound-campaigns-v2_CampaignFilters_Contents"></a>

 ** instanceIdFilter **   <a name="connect-Type-connect-outbound-campaigns-v2_CampaignFilters-instanceIdFilter"></a>
The identifier of the Connect Customer instance. You can find the `instanceId` in the ARN of the instance.
Type: [InstanceIdFilter](API_connect-outbound-campaigns-v2_InstanceIdFilter.md) object
Required: No
