# ValidationExceptionField

An input field that failed validation.

## Contents
<a name="API_connect-scheduling_ValidationExceptionField_Contents"></a>

 ** Message **   <a name="connect-Type-connect-scheduling_ValidationExceptionField-Message"></a>
A message describing why the field failed validation.
Type: String
Required: Yes

 ** Name **   <a name="connect-Type-connect-scheduling_ValidationExceptionField-Name"></a>
The path to the field that failed validation, using JSON pointer-style dotted notation for nested members.
Type: String
Required: Yes
