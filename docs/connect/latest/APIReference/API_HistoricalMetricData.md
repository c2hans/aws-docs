# HistoricalMetricData
<a name="API_HistoricalMetricData"></a>

Contains the data for a historical metric.

## Contents
<a name="API_HistoricalMetricData_Contents"></a>

 ** Metric **   <a name="connect-Type-HistoricalMetricData-Metric"></a>
Information about the metric.
Type: [HistoricalMetric](API_HistoricalMetric.md) object
Required: No

 ** Value **   <a name="connect-Type-HistoricalMetricData-Value"></a>
The value of the metric.
Type: Double
Required: No
