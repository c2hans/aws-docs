# TimeoutConfig
<a name="API_connect-outbound-campaigns-v2_TimeoutConfig"></a>

Contains preview outbound mode timeout configuration.

## Contents
<a name="API_connect-outbound-campaigns-v2_TimeoutConfig_Contents"></a>

 ** durationInSeconds **   <a name="connect-Type-connect-outbound-campaigns-v2_TimeoutConfig-durationInSeconds"></a>
Duration in seconds for the countdown timer.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 300.
Required: Yes
