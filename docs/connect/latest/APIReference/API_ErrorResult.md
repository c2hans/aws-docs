# ErrorResult
<a name="API_ErrorResult"></a>

This API is in preview release for Connect Customer and is subject to change.

List of errors for dataset association failures.

## Contents
<a name="API_ErrorResult_Contents"></a>

 ** ErrorCode **   <a name="connect-Type-ErrorResult-ErrorCode"></a>
The error code.
Type: String
Required: No

 ** ErrorMessage **   <a name="connect-Type-ErrorResult-ErrorMessage"></a>
The corresponding error message for the error code.
Type: String
Required: No
