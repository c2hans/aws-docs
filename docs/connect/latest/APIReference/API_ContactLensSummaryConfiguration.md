# ContactLensSummaryConfiguration
<a name="API_ContactLensSummaryConfiguration"></a>

The conversational analytics summary configuration for a contact.

## Contents
<a name="API_ContactLensSummaryConfiguration_Contents"></a>

 ** SummaryModes **   <a name="connect-Type-ContactLensSummaryConfiguration-SummaryModes"></a>
The conversational analytics summary modes enabled for the contact. Valid values: `PostContact` \| `AutomatedInteraction` \| `ContactChain`.
Type: Array of strings
Required: No
