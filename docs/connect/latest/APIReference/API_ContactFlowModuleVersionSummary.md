# ContactFlowModuleVersionSummary
<a name="API_ContactFlowModuleVersionSummary"></a>

Contains information about a version.

## Contents
<a name="API_ContactFlowModuleVersionSummary_Contents"></a>

 ** Arn **   <a name="connect-Type-ContactFlowModuleVersionSummary-Arn"></a>
The Amazon Resource Name (ARN) of the flow module version.
Type: String
Required: No

 ** Version **   <a name="connect-Type-ContactFlowModuleVersionSummary-Version"></a>
The version of the flow module.
Type: Long
Valid Range: Minimum value of 1.
Required: No

 ** VersionDescription **   <a name="connect-Type-ContactFlowModuleVersionSummary-VersionDescription"></a>
The description of the flow module version.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 500.
Pattern: `.*\S.*`
Required: No
