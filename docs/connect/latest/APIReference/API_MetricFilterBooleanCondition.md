# MetricFilterBooleanCondition
<a name="API_MetricFilterBooleanCondition"></a>

A boolean comparison condition for metric filters.

## Contents
<a name="API_MetricFilterBooleanCondition_Contents"></a>

 ** Comparison **   <a name="connect-Type-MetricFilterBooleanCondition-Comparison"></a>
The comparison operator. Valid values: `IS_TRUE` (matches when the field is true) \| `IS_FALSE` (matches when the field is false).
Type: String
Valid Values: `IS_TRUE | IS_FALSE`
Required: Yes
