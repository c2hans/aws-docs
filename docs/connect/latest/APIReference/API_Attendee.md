# Attendee
<a name="API_Attendee"></a>

The attendee information, including attendee ID and join token.

## Contents
<a name="API_Attendee_Contents"></a>

 ** AttendeeId **   <a name="connect-Type-Attendee-AttendeeId"></a>
The Amazon Chime SDK attendee ID.
Type: String
Required: No

 ** JoinToken **   <a name="connect-Type-Attendee-JoinToken"></a>
The join token used by the Amazon Chime SDK attendee.
Type: String
Required: No
