# AttributeValueItem
<a name="API_connect-customer-profiles_AttributeValueItem"></a>

<a name="API_connect-customer-profiles_AttributeValueItem_Contents"></a>

 ** Value **   <a name="connect-Type-connect-customer-profiles_AttributeValueItem-Value"></a>
An individual value belonging to the given attribute.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No
