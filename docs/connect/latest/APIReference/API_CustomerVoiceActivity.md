# CustomerVoiceActivity
<a name="API_CustomerVoiceActivity"></a>

Information about customer’s voice activity.

## Contents
<a name="API_CustomerVoiceActivity_Contents"></a>

 ** GreetingEndTimestamp **   <a name="connect-Type-CustomerVoiceActivity-GreetingEndTimestamp"></a>
Timestamp that measures the end of the customer greeting from an outbound voice call.
Type: Timestamp
Required: No

 ** GreetingStartTimestamp **   <a name="connect-Type-CustomerVoiceActivity-GreetingStartTimestamp"></a>
Timestamp that measures the beginning of the customer greeting from an outbound voice call.
Type: Timestamp
Required: No
