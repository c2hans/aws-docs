# SentimentConfiguration
<a name="API_SentimentConfiguration"></a>

The sentiment configuration for conversational analytics.

## Contents
<a name="API_SentimentConfiguration_Contents"></a>

 ** Behavior **   <a name="connect-Type-SentimentConfiguration-Behavior"></a>
Controls whether sentiment analysis is applied to the analytics output. Valid values: `Enable` \| `Disable`.
Type: String
Valid Values: `Enable | Disable`
Required: Yes
