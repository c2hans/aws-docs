# Receipt
<a name="API_connect-participant_Receipt"></a>

The receipt for the message delivered to the recipient.

## Contents
<a name="API_connect-participant_Receipt_Contents"></a>

 ** DeliveredTimestamp **   <a name="connect-Type-connect-participant_Receipt-DeliveredTimestamp"></a>
The time when the message was delivered to the recipient.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No

 ** ReadTimestamp **   <a name="connect-Type-connect-participant_Receipt-ReadTimestamp"></a>
The time when the message was read by the recipient.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No

 ** RecipientParticipantId **   <a name="connect-Type-connect-participant_Receipt-RecipientParticipantId"></a>
The identifier of the recipient of the message.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
