# EvaluationContactParticipant
<a name="API_EvaluationContactParticipant"></a>

Information about a contact participant in the evaluation.

## Contents
<a name="API_EvaluationContactParticipant_Contents"></a>

 ** ContactParticipantId **   <a name="connect-Type-EvaluationContactParticipant-ContactParticipantId"></a>
The identifier for the contact participant.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 500.
Required: No

 ** ContactParticipantRole **   <a name="connect-Type-EvaluationContactParticipant-ContactParticipantRole"></a>
The role of the contact participant.
Type: String
Valid Values: `AGENT | SYSTEM | CUSTOM_BOT | CUSTOMER`
Required: No
