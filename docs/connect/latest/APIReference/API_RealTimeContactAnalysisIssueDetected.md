# RealTimeContactAnalysisIssueDetected
<a name="API_RealTimeContactAnalysisIssueDetected"></a>

Potential issues that are detected based on an artificial intelligence analysis of each turn in the conversation.

## Contents
<a name="API_RealTimeContactAnalysisIssueDetected_Contents"></a>

 ** TranscriptItems **   <a name="connect-Type-RealTimeContactAnalysisIssueDetected-TranscriptItems"></a>
List of the transcript items (segments) that are associated with a given issue.
Type: Array of [RealTimeContactAnalysisTranscriptItemWithContent](API_RealTimeContactAnalysisTranscriptItemWithContent.md) objects
Required: Yes
