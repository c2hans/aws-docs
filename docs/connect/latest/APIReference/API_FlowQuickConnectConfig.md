# FlowQuickConnectConfig
<a name="API_FlowQuickConnectConfig"></a>

 Configuration for quick connect.

## Contents
<a name="API_FlowQuickConnectConfig_Contents"></a>

 ** ContactFlowId **   <a name="connect-Type-FlowQuickConnectConfig-ContactFlowId"></a>
 The contact flow ID for the quick connect configuration.
Type: String
Length Constraints: Maximum length of 500.
Required: Yes
