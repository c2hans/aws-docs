# RestrictedPeriods
<a name="API_connect-outbound-campaigns-v2_RestrictedPeriods"></a>

Contains information about restricted periods.

## Contents
<a name="API_connect-outbound-campaigns-v2_RestrictedPeriods_Contents"></a>

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** restrictedPeriodList **   <a name="connect-Type-connect-outbound-campaigns-v2_RestrictedPeriods-restrictedPeriodList"></a>
The restricted period list.
Type: Array of [RestrictedPeriod](API_connect-outbound-campaigns-v2_RestrictedPeriod.md) objects
Required: No
