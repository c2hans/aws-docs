# EngagementPreferences
<a name="API_connect-customer-profiles_EngagementPreferences"></a>

Object that defines users preferred methods of engagement.

## Contents
<a name="API_connect-customer-profiles_EngagementPreferences_Contents"></a>

 ** Email **   <a name="connect-Type-connect-customer-profiles_EngagementPreferences-Email"></a>
A list of email-related contact preferences
Type: Array of [ContactPreference](API_connect-customer-profiles_ContactPreference.md) objects
Required: No

 ** Phone **   <a name="connect-Type-connect-customer-profiles_EngagementPreferences-Phone"></a>
A list of phone-related contact preferences
Type: Array of [ContactPreference](API_connect-customer-profiles_ContactPreference.md) objects
Required: No
