# IncrementalPullConfig
<a name="API_connect-customer-profiles_IncrementalPullConfig"></a>

Specifies the configuration used when importing incremental records from the source.

## Contents
<a name="API_connect-customer-profiles_IncrementalPullConfig_Contents"></a>

 ** DatetimeTypeFieldName **   <a name="connect-Type-connect-customer-profiles_IncrementalPullConfig-DatetimeTypeFieldName"></a>
A field that specifies the date time or timestamp field as the criteria to use when importing incremental records from the source.
Type: String
Length Constraints: Maximum length of 256.
Pattern: `.*`
Required: No
