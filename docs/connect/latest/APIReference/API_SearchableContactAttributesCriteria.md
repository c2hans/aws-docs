# SearchableContactAttributesCriteria
<a name="API_SearchableContactAttributesCriteria"></a>

The search criteria based on user-defined contact attribute key and values to search on.

## Contents
<a name="API_SearchableContactAttributesCriteria_Contents"></a>

 ** Key **   <a name="connect-Type-SearchableContactAttributesCriteria-Key"></a>
The key containing a searchable user-defined contact attribute.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: Yes

 ** Values **   <a name="connect-Type-SearchableContactAttributesCriteria-Values"></a>
The list of values to search for within a user-defined contact attribute.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 20 items.
Length Constraints: Minimum length of 0. Maximum length of 100.
Required: Yes
