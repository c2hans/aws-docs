# AutoEvaluationDetails
<a name="API_AutoEvaluationDetails"></a>

Details about automated evaluations.

## Contents
<a name="API_AutoEvaluationDetails_Contents"></a>

 ** AutoEvaluationEnabled **   <a name="connect-Type-AutoEvaluationDetails-AutoEvaluationEnabled"></a>
Whether automated evaluation is enabled.
Type: Boolean
Required: Yes

 ** AutoEvaluationStatus **   <a name="connect-Type-AutoEvaluationDetails-AutoEvaluationStatus"></a>
The status of the contact auto-evaluation.
Type: String
Valid Values: `IN_PROGRESS | FAILED | SUCCEEDED`
Required: No
