# ChatMetrics
<a name="API_ChatMetrics"></a>

Information about how agent, bot, and customer interact in a chat contact.

## Contents
<a name="API_ChatMetrics_Contents"></a>

 ** AgentMetrics **   <a name="connect-Type-ChatMetrics-AgentMetrics"></a>
Information about agent interactions in a contact.
Type: [ParticipantMetrics](API_ParticipantMetrics.md) object
Required: No

 ** ChatContactMetrics **   <a name="connect-Type-ChatMetrics-ChatContactMetrics"></a>
Information about the overall participant interactions at the contact level.
Type: [ChatContactMetrics](API_ChatContactMetrics.md) object
Required: No

 ** CustomerMetrics **   <a name="connect-Type-ChatMetrics-CustomerMetrics"></a>
Information about customer interactions in a contact.
Type: [ParticipantMetrics](API_ParticipantMetrics.md) object
Required: No
