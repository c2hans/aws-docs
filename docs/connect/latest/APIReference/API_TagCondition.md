# TagCondition
<a name="API_TagCondition"></a>

A leaf node condition which can be used to specify a tag condition, for example, `HAVE BPO = 123`.

## Contents
<a name="API_TagCondition_Contents"></a>

 ** TagKey **   <a name="connect-Type-TagCondition-TagKey"></a>
The tag key in the tag condition.
Type: String
Required: No

 ** TagValue **   <a name="connect-Type-TagCondition-TagValue"></a>
The tag value in the tag condition.
Type: String
Required: No
