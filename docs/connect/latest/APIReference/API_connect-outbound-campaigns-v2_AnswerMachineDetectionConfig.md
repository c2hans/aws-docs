# AnswerMachineDetectionConfig
<a name="API_connect-outbound-campaigns-v2_AnswerMachineDetectionConfig"></a>

Contains answering machine detection configuration.

## Contents
<a name="API_connect-outbound-campaigns-v2_AnswerMachineDetectionConfig_Contents"></a>

 ** enableAnswerMachineDetection **   <a name="connect-Type-connect-outbound-campaigns-v2_AnswerMachineDetectionConfig-enableAnswerMachineDetection"></a>
Enables answering machine detection.
Type: Boolean
Required: Yes

 ** awaitAnswerMachinePrompt **   <a name="connect-Type-connect-outbound-campaigns-v2_AnswerMachineDetectionConfig-awaitAnswerMachinePrompt"></a>
Whether or not waiting for an answer machine prompt is enabled.
Type: Boolean
Required: No
