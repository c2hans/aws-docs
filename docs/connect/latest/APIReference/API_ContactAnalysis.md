# ContactAnalysis
<a name="API_ContactAnalysis"></a>

A structure that defines search criteria for contacts using analysis outputs from Connect Customer Contact Lens.

## Contents
<a name="API_ContactAnalysis_Contents"></a>

 ** Transcript **   <a name="connect-Type-ContactAnalysis-Transcript"></a>
Search criteria based on transcript analyzed by Connect Customer Contact Lens.
Type: [Transcript](API_Transcript.md) object
Required: No
