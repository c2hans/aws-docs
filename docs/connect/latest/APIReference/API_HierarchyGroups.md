# HierarchyGroups
<a name="API_HierarchyGroups"></a>

Information about the agent hierarchy. Hierarchies can be configured with up to five levels.

## Contents
<a name="API_HierarchyGroups_Contents"></a>

 ** Level1 **   <a name="connect-Type-HierarchyGroups-Level1"></a>
The group at level one of the agent hierarchy.
Type: [AgentHierarchyGroup](API_AgentHierarchyGroup.md) object
Required: No

 ** Level2 **   <a name="connect-Type-HierarchyGroups-Level2"></a>
The group at level two of the agent hierarchy.
Type: [AgentHierarchyGroup](API_AgentHierarchyGroup.md) object
Required: No

 ** Level3 **   <a name="connect-Type-HierarchyGroups-Level3"></a>
The group at level three of the agent hierarchy.
Type: [AgentHierarchyGroup](API_AgentHierarchyGroup.md) object
Required: No

 ** Level4 **   <a name="connect-Type-HierarchyGroups-Level4"></a>
The group at level four of the agent hierarchy.
Type: [AgentHierarchyGroup](API_AgentHierarchyGroup.md) object
Required: No

 ** Level5 **   <a name="connect-Type-HierarchyGroups-Level5"></a>
The group at level five of the agent hierarchy.
Type: [AgentHierarchyGroup](API_AgentHierarchyGroup.md) object
Required: No
