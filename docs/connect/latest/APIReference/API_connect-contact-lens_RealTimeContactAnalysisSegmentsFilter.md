# RealTimeContactAnalysisSegmentsFilter
<a name="API_connect-contact-lens_RealTimeContactAnalysisSegmentsFilter"></a>

A filter that restricts the segments returned by `ListRealtimeContactAnalysisSegments`. It supports filtering category segments by the tags on the rules that create them, which enforces tag-based access control on the categories a caller can view.

## Contents
<a name="API_connect-contact-lens_RealTimeContactAnalysisSegmentsFilter_Contents"></a>

 ** CategoriesAttributeFilter **   <a name="connect-Type-connect-contact-lens_RealTimeContactAnalysisSegmentsFilter-CategoriesAttributeFilter"></a>
A filter applied to category segments based on the tags of the rules that create the matched categories.
Type: [CategoriesAttributeFilter](API_connect-contact-lens_CategoriesAttributeFilter.md) object
Required: No
