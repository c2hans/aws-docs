# ConversationalAnalytics
<a name="API_ConversationalAnalytics"></a>

Contains the conversational analytics configuration and state for a contact.

## Contents
<a name="API_ConversationalAnalytics_Contents"></a>

 ** Configuration **   <a name="connect-Type-ConversationalAnalytics-Configuration"></a>
The conversational analytics settings that apply to the contact.
Type: [ConversationalAnalyticsConfiguration](API_ConversationalAnalyticsConfiguration.md) object
Required: No

 ** ContactAnalysisReferenceState **   <a name="connect-Type-ConversationalAnalytics-ContactAnalysisReferenceState"></a>
The current state of conversational analytics processing for the contact.
Type: [ContactAnalysisReferenceState](API_ContactAnalysisReferenceState.md) object
Required: No
