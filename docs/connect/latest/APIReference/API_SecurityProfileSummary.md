# SecurityProfileSummary
<a name="API_SecurityProfileSummary"></a>

Contains information about a security profile.

## Contents
<a name="API_SecurityProfileSummary_Contents"></a>

 ** Arn **   <a name="connect-Type-SecurityProfileSummary-Arn"></a>
The Amazon Resource Name (ARN) of the security profile.
Type: String
Required: No

 ** Id **   <a name="connect-Type-SecurityProfileSummary-Id"></a>
The identifier of the security profile.
Type: String
Required: No

 ** LastModifiedRegion **   <a name="connect-Type-SecurityProfileSummary-LastModifiedRegion"></a>
The AWS Region where this resource was last modified.
Type: String
Pattern: `[a-z]{2}(-[a-z]+){1,2}(-[0-9])?`
Required: No

 ** LastModifiedTime **   <a name="connect-Type-SecurityProfileSummary-LastModifiedTime"></a>
The timestamp when this resource was last modified.
Type: Timestamp
Required: No

 ** Name **   <a name="connect-Type-SecurityProfileSummary-Name"></a>
The name of the security profile.
Type: String
Required: No
