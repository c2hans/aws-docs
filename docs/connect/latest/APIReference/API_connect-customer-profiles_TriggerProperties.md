# TriggerProperties
<a name="API_connect-customer-profiles_TriggerProperties"></a>

Specifies the configuration details that control the trigger for a flow. Currently, these settings only apply to the Scheduled trigger type.

## Contents
<a name="API_connect-customer-profiles_TriggerProperties_Contents"></a>

 ** Scheduled **   <a name="connect-Type-connect-customer-profiles_TriggerProperties-Scheduled"></a>
Specifies the configuration details of a schedule-triggered flow that you define.
Type: [ScheduledTriggerProperties](API_connect-customer-profiles_ScheduledTriggerProperties.md) object
Required: No
