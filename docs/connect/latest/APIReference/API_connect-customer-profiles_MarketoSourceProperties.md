# MarketoSourceProperties
<a name="API_connect-customer-profiles_MarketoSourceProperties"></a>

The properties that are applied when Marketo is being used as a source.

## Contents
<a name="API_connect-customer-profiles_MarketoSourceProperties_Contents"></a>

 ** Object **   <a name="connect-Type-connect-customer-profiles_MarketoSourceProperties-Object"></a>
The object specified in the Marketo flow source.
Type: String
Length Constraints: Maximum length of 512.
Pattern: `\S+`
Required: Yes
