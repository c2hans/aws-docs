# OperationalHour
<a name="API_OperationalHour"></a>

Information about the hours of operations with the effective override applied.

## Contents
<a name="API_OperationalHour_Contents"></a>

 ** End **   <a name="connect-Type-OperationalHour-End"></a>
The end time that your contact center closes.
Type: [OverrideTimeSlice](API_OverrideTimeSlice.md) object
Required: No

 ** Start **   <a name="connect-Type-OperationalHour-Start"></a>
The start time that your contact center opens.
Type: [OverrideTimeSlice](API_OverrideTimeSlice.md) object
Required: No
