# Meeting
<a name="API_Meeting"></a>

A meeting created using the Amazon Chime SDK.

## Contents
<a name="API_Meeting_Contents"></a>

 ** MediaPlacement **   <a name="connect-Type-Meeting-MediaPlacement"></a>
The media placement for the meeting.
Type: [MediaPlacement](API_MediaPlacement.md) object
Required: No

 ** MediaRegion **   <a name="connect-Type-Meeting-MediaRegion"></a>
The AWS Region in which you create the meeting.
Type: String
Required: No

 ** MeetingFeatures **   <a name="connect-Type-Meeting-MeetingFeatures"></a>
The configuration settings of the features available to a meeting.
Type: [MeetingFeaturesConfiguration](API_MeetingFeaturesConfiguration.md) object
Required: No

 ** MeetingId **   <a name="connect-Type-Meeting-MeetingId"></a>
The Amazon Chime SDK meeting ID.
Type: String
Required: No
