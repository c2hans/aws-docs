# Endpoint
<a name="API_Endpoint"></a>

Information about the endpoint.

## Contents
<a name="API_Endpoint_Contents"></a>

 ** Address **   <a name="connect-Type-Endpoint-Address"></a>
Address of the endpoint.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No

 ** Type **   <a name="connect-Type-Endpoint-Type"></a>
Type of the endpoint.
Type: String
Valid Values: `TELEPHONE_NUMBER | VOIP | CONTACT_FLOW | CONNECT_PHONENUMBER_ARN | EMAIL_ADDRESS`
Required: No
