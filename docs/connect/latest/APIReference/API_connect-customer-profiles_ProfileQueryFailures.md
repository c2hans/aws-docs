# ProfileQueryFailures
<a name="API_connect-customer-profiles_ProfileQueryFailures"></a>

Object that holds failures for membership.

## Contents
<a name="API_connect-customer-profiles_ProfileQueryFailures_Contents"></a>

 ** Message **   <a name="connect-Type-connect-customer-profiles_ProfileQueryFailures-Message"></a>
A message describing the failure.
Type: String
Required: Yes

 ** ProfileId **   <a name="connect-Type-connect-customer-profiles_ProfileQueryFailures-ProfileId"></a>
The profile id the failure belongs to.
Type: String
Required: Yes

 ** Status **   <a name="connect-Type-connect-customer-profiles_ProfileQueryFailures-Status"></a>
The status describing the failure.
Type: Integer
Required: No
