# CommonAttributeAndCondition
<a name="API_CommonAttributeAndCondition"></a>

A list of conditions which would be applied together with an `AND` condition.

## Contents
<a name="API_CommonAttributeAndCondition_Contents"></a>

 ** TagConditions **   <a name="connect-Type-CommonAttributeAndCondition-TagConditions"></a>
A leaf node condition which can be used to specify a tag condition.
Type: Array of [TagCondition](API_TagCondition.md) objects
Required: No
