# PredefinedAttributeSummary
<a name="API_PredefinedAttributeSummary"></a>

Summary of a predefined attribute.

## Contents
<a name="API_PredefinedAttributeSummary_Contents"></a>

 ** LastModifiedRegion **   <a name="connect-Type-PredefinedAttributeSummary-LastModifiedRegion"></a>
Last modified region.
Type: String
Pattern: `[a-z]{2}(-[a-z]+){1,2}(-[0-9])?`
Required: No

 ** LastModifiedTime **   <a name="connect-Type-PredefinedAttributeSummary-LastModifiedTime"></a>
Last modified time.
Type: Timestamp
Required: No

 ** Name **   <a name="connect-Type-PredefinedAttributeSummary-Name"></a>
The name of the predefined attribute.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No
