# DisconnectDetails
<a name="API_DisconnectDetails"></a>

Information about the call disconnect experience.

## Contents
<a name="API_DisconnectDetails_Contents"></a>

 ** PotentialDisconnectIssue **   <a name="connect-Type-DisconnectDetails-PotentialDisconnectIssue"></a>
Indicates the potential disconnection issues for a call. This field is not populated if the service does not detect potential issues.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 128.
Required: No
