# SuccessfulBatchAssociationSummary
<a name="API_SuccessfulBatchAssociationSummary"></a>

Contains information about a resource that was successfully associated with a workspace in a batch operation.

## Contents
<a name="API_SuccessfulBatchAssociationSummary_Contents"></a>

 ** ResourceArn **   <a name="connect-Type-SuccessfulBatchAssociationSummary-ResourceArn"></a>
The Amazon Resource Name (ARN) of the resource that was successfully associated.
Type: String
Required: No
