# GranularAccessControlConfiguration
<a name="API_GranularAccessControlConfiguration"></a>

Contains granular access control configuration for security profiles, including data table access permissions.

## Contents
<a name="API_GranularAccessControlConfiguration_Contents"></a>

 ** DataTableAccessControlConfiguration **   <a name="connect-Type-GranularAccessControlConfiguration-DataTableAccessControlConfiguration"></a>
The access control configuration for data tables.
Type: [DataTableAccessControlConfiguration](API_DataTableAccessControlConfiguration.md) object
Required: No
