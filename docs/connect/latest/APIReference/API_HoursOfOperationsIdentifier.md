# HoursOfOperationsIdentifier
<a name="API_HoursOfOperationsIdentifier"></a>

Identifier for a hours of operations resource: ARN, ID, Name

## Contents
<a name="API_HoursOfOperationsIdentifier_Contents"></a>

 ** Id **   <a name="connect-Type-HoursOfOperationsIdentifier-Id"></a>
Unique identifier of the hours of operation.
Type: String
Required: Yes

 ** Name **   <a name="connect-Type-HoursOfOperationsIdentifier-Name"></a>
Name of the hours of operation
Type: String
Length Constraints: Minimum length of 1. Maximum length of 127.
Required: Yes

 ** Arn **   <a name="connect-Type-HoursOfOperationsIdentifier-Arn"></a>
Amazon Resource Name (ARN) of the hours of operations.
Type: String
Required: No
