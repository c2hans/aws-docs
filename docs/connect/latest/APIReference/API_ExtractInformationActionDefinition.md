# ExtractInformationActionDefinition
<a name="API_ExtractInformationActionDefinition"></a>

Information about the extract information action, which references extraction definitions to use when extracting structured data from customer interactions.

## Contents
<a name="API_ExtractInformationActionDefinition_Contents"></a>

 ** RulesExtractionDefinitions **   <a name="connect-Type-ExtractInformationActionDefinition-RulesExtractionDefinitions"></a>
The list of extraction definition identifiers that specify what data to extract.
Type: Array of [RulesExtractionDefinitionIdentifier](API_RulesExtractionDefinitionIdentifier.md) objects
Required: Yes
