# EvaluationReviewNotificationRecipient
<a name="API_EvaluationReviewNotificationRecipient"></a>

Information about a recipient who should be notified when an evaluation review is requested.

## Contents
<a name="API_EvaluationReviewNotificationRecipient_Contents"></a>

 ** Type **   <a name="connect-Type-EvaluationReviewNotificationRecipient-Type"></a>
The type of notification recipient.
Type: String
Valid Values: `USER_ID`
Required: Yes

 ** Value **   <a name="connect-Type-EvaluationReviewNotificationRecipient-Value"></a>
The value associated with the notification recipient type.
Type: [EvaluationReviewNotificationRecipientValue](API_EvaluationReviewNotificationRecipientValue.md) object
Required: Yes
