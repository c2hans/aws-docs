# SignInConfig
<a name="API_SignInConfig"></a>

The distribution that determines which AWS Regions should be used to sign in agents in to both the instance and its replica(s).

## Contents
<a name="API_SignInConfig_Contents"></a>

 ** Distributions **   <a name="connect-Type-SignInConfig-Distributions"></a>
Information about traffic distributions.
Type: Array of [SignInDistribution](API_SignInDistribution.md) objects
Required: Yes
