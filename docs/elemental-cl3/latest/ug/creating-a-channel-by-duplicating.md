# Creating a channel by duplicating an existing channel
<a name="creating-a-channel-by-duplicating"></a>

**To create a channel by duplicating an existing channel**

1. On the Conductor Live main menu, choose **Channels**.

1. In the list of channels, find the channel that you want to duplicate. Choose the **Duplicate** icon.

   The **Duplicate Channel** page appears. It shows the values from the source channel, including any [channel parameters](creating-a-profile-with-channel-parameters.md) and their current values.

1. Make changes and choose **Save**.
