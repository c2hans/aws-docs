# Deleting an MPTS
<a name="delete-mpts"></a>

1. On the Conductor Live main menu, choose **MPTS**.

1. Look for the MPTS you want. If the MPTS is listed twice, it has been set up for [output listening](worker-nodes-other-resiliency.md#es-resiliency-opl). Find the MPTS that is marked as Primary, and select it by ID or by name.

1. If necessary, select **Stop** to stop the MPTS.

1. Select the **Delete** icon to the right of the MPTS.
