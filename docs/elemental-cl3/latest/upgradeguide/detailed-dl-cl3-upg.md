# Downloading Conductor Live Software
<a name="detailed-dl-cl3-upg"></a>

These are the detailed steps for downloading software files from the [AWS Elemental Support Center](https://console.aws.amazon.com/elemental-appliances-software/home?region=us-east-1#/supportcenter).

1. Log in to the [AWS Elemental Support Center](https://console.aws.amazon.com/elemental-appliances-software/home?region=us-east-1#/supportcenter) with the email address that you used to receive your activation email and your password.

1. From the home page, click **Software and Licenses** on the right.

1. From the **Download Central Home**, choose **Your Entitlements** from the **Software & Entitlements** menu.

1. On **Your Entitlements**, your orders are listed from newest to oldest. In the **Activation Key** column, choose the link for the product that you're downloading.

1. On **Order Detail**, choose the plus sign for the package listed in the **Product Description** column to expand the order details. Then choose the product and version that you wish to download.

1. In the list of available files, choose the file you want to download.

1. On **Product Download**, select the check box next to the file you want to download. Then click **Download Selected Files**.

1. If you are prompted to install the NetSession Interface download manager, click **download the installer** and run the executable.

1. Select a location and save the files. Note the file location for later.
