# Data Types
<a name="API_Types"></a>

The Application Auto Scaling API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Alarm](API_Alarm.md)
+  [CapacityForecast](API_CapacityForecast.md)
+  [CustomizedMetricSpecification](API_CustomizedMetricSpecification.md)
+  [LoadForecast](API_LoadForecast.md)
+  [MetricDimension](API_MetricDimension.md)
+  [NotScaledReason](API_NotScaledReason.md)
+  [PredefinedMetricSpecification](API_PredefinedMetricSpecification.md)
+  [PredictiveScalingCustomizedMetricSpecification](API_PredictiveScalingCustomizedMetricSpecification.md)
+  [PredictiveScalingMetric](API_PredictiveScalingMetric.md)
+  [PredictiveScalingMetricDataQuery](API_PredictiveScalingMetricDataQuery.md)
+  [PredictiveScalingMetricDimension](API_PredictiveScalingMetricDimension.md)
+  [PredictiveScalingMetricSpecification](API_PredictiveScalingMetricSpecification.md)
+  [PredictiveScalingMetricStat](API_PredictiveScalingMetricStat.md)
+  [PredictiveScalingPolicyConfiguration](API_PredictiveScalingPolicyConfiguration.md)
+  [PredictiveScalingPredefinedLoadMetricSpecification](API_PredictiveScalingPredefinedLoadMetricSpecification.md)
+  [PredictiveScalingPredefinedMetricPairSpecification](API_PredictiveScalingPredefinedMetricPairSpecification.md)
+  [PredictiveScalingPredefinedScalingMetricSpecification](API_PredictiveScalingPredefinedScalingMetricSpecification.md)
+  [ScalableTarget](API_ScalableTarget.md)
+  [ScalableTargetAction](API_ScalableTargetAction.md)
