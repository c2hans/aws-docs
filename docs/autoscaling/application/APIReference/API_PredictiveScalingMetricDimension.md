# PredictiveScalingMetricDimension
<a name="API_PredictiveScalingMetricDimension"></a>

 Describes the dimension of a metric.

## Contents
<a name="API_PredictiveScalingMetricDimension_Contents"></a>

 ** Name **   <a name="autoscaling-Type-PredictiveScalingMetricDimension-Name"></a>
 The name of the dimension.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `[\u0020-\uD7FF\uE000-\uFFFD\uD800\uDC00-\uDBFF\uDFFF\r\n\t]*`
Required: Yes

 ** Value **   <a name="autoscaling-Type-PredictiveScalingMetricDimension-Value"></a>
 The value of the dimension.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `[\u0020-\uD7FF\uE000-\uFFFD\uD800\uDC00-\uDBFF\uDFFF\r\n\t]*`
Required: Yes
