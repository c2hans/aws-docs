# PredictiveScalingCustomizedMetricSpecification
<a name="API_PredictiveScalingCustomizedMetricSpecification"></a>

 Represents a CloudWatch metric of your choosing for a predictive scaling policy.

## Contents
<a name="API_PredictiveScalingCustomizedMetricSpecification_Contents"></a>

 ** MetricDataQueries **   <a name="autoscaling-Type-PredictiveScalingCustomizedMetricSpecification-MetricDataQueries"></a>
 One or more metric data queries to provide data points for a metric specification.
Type: Array of [PredictiveScalingMetricDataQuery](API_PredictiveScalingMetricDataQuery.md) objects
Required: Yes
