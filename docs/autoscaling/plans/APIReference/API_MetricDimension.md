# MetricDimension
<a name="API_MetricDimension"></a>

Represents a dimension for a customized metric.

## Contents
<a name="API_MetricDimension_Contents"></a>

 ** Name **   <a name="autoscaling-Type-MetricDimension-Name"></a>
The name of the dimension.
Type: String
Required: Yes

 ** Value **   <a name="autoscaling-Type-MetricDimension-Value"></a>
The value of the dimension.
Type: String
Required: Yes
