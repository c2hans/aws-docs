# MetricDimension
<a name="API_MetricDimension"></a>

Describes the dimension of a metric.

## Contents
<a name="API_MetricDimension_Contents"></a>

 ** Name **
The name of the dimension.
Type: String
Required: Yes

 ** Value **
The value of the dimension.
Type: String
Required: Yes
