# Legacy Topic workspace
<a name="legacy-topics-workspace"></a>

After you open a legacy Topic, the workspace displays four tabs:
+ **Summary** — Shows suggestions for improving the Topic, engagement metrics and KPIs, and the datasets included in the Topic.
+ **Data** — Shows all the fields included in the Topic. Configure field metadata (names, descriptions, synonyms, semantic types, aggregations) to make the Topic natural-language-friendly.
+ **User Activity** — Shows all questions received and the overall feedback for each question.
+ **Verified Answers** — Shows questions that you have preconfigured visuals for.
