# Using voice mode (Preview)

**Note**
Voice mode is in Preview for AWS Quick and is subject to change. Preview features are not typically recommended for critical or production workloads.

With voice mode, you talk to AWS Quick and it answers out loud. Voice mode is available in the desktop application and in the mobile app for iOS and Android. It uses the same connected sources, permissions, and agents as chat.

## To start voice mode
<a name="voice-mode-start"></a>

To start voice mode, do one of the following:
+ On desktop, choose the voice mode icon in the chat input. The microphone icon is dictation, which types what you say into the chat input.
+ On iOS or Android, open a chat and tap the voice mode icon.

## Approvals
<a name="voice-mode-approvals"></a>

When Quick needs your approval to send, publish, or change something, it shows an approval card. Choose the card to allow or deny the action. Spoken approvals aren't available in the preview.

## Limits
<a name="voice-mode-limits"></a>

Voice mode has the following limits:
+ Voice mode is available in the US East (N. Virginia) and US West (Oregon) Regions.
+ A voice session ends after 15 minutes without a turn.

## Troubleshooting
<a name="voice-mode-troubleshooting"></a>

If you have trouble with voice mode, try the following:
+ If Quick can't hear you, check that AWS Quick has access to your microphone in your system settings.
+ If you don't see voice mode, update AWS Quick to the latest version. Your administrator might have turned off voice mode.
