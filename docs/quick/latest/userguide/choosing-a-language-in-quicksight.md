# Choosing a language in AWS Quick

You can choose the language for the AWS Quick user interface, set separately for each user. On your first sign-in, Quick picks a language from your browser preferences and your history with localized AWS websites. You can change it at any time: choose your profile icon in the bottom left, and then choose **Settings**, **Appearance and language**, **Language**.

Quick supports the following languages:

**Languages available in the AWS Quick user interface**

| Official name | Language code | Localized name | Agentic features |
| --- | --- | --- | --- |
| Dansk | da-DK | Danish | No |
| Deutsch (Deutschland) | de-DE | German | Yes |
| English (US) | en-US | English | Yes |
| Español (España) | es-ES | Spanish | No |
| Français (France) | fr-FR | French | No |
| Italiano (Italia) | it-IT | Italian | No |
| Nederlands (Nederland) | nl-NL | Dutch | No |
| Norsk bokmål | nb-NO | Norwegian | No |
| Português (Brasil) | pt-BR | Portuguese | No |
| Suomi | fi-FI | Finnish | No |
| Svenska (Sverige) | sv-SE | Swedish | No |
| 日本語 | ja-JP | Japanese | Yes |
| 한국어 | ko-KR | Korean | No |
| 中文 (中国) | zh-CN | Simplified Chinese | Yes |
| 中文 (台灣) | zh-TW | Traditional Chinese | Yes |
| Tiếng Việt | vi-VN | Vietnamese | Yes |

The Agentic features column uses the following values:

**Agentic features column values**

| Value | Description |
| --- | --- |
| Yes | Quick translates the user interface and responds in the language of your query across all agentic features. |
| No | Quick translates only the user interface elements. |

The following questions answer how Quick language support applies across agentic features.

**Which features does Quick support in my language?**

For any language marked Yes in the preceding table, Quick responds in the language of your query across all agentic features: chat, research reports, apps, scheduled tasks, generated files (such as PPTX, PDF, Excel, CSV, and DOCX), dashboard and dataset Q&A, web search, and Q&A over your knowledge bases and files in spaces.

**Is voice mode available in other languages?**

Voice mode is in preview and available in English only.

**Which languages does Quick support for files in spaces and knowledge bases?**

Indexing and retrieval of files in spaces and connected knowledge bases is the only capability that depends on your AWS Region and the language of your files. All other agentic features work in every AWS Region where Quick agentic features are available. If your language and AWS Region aren't listed in the following table, Quick still answers in your language, but it might not reliably find or cite your files in that language. For the full list of Quick AWS Regions, see [AWS Regions and related information](regions.md).

**Languages supported for indexing and retrieval of files in spaces and knowledge bases**

| Language | AWS Regions where Quick indexes and retrieves your files |
| --- | --- |
| English | All AWS Regions |
| Chinese | US East (N. Virginia), Asia Pacific (Singapore), Asia Pacific (Tokyo) |
| German | US East (N. Virginia), Europe (Frankfurt), Europe (Ireland) |
| Japanese | US East (N. Virginia), Asia Pacific (Tokyo) |
| Vietnamese | US East (N. Virginia), Asia Pacific (Singapore), Asia Pacific (Tokyo) |
