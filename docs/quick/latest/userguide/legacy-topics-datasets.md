# Working with datasets in a legacy Topic
<a name="legacy-topics-datasets"></a>

You can add additional datasets to a legacy Topic, remove datasets, set refresh schedules, and add calculated fields, filters, and named entities.
+ **Adding datasets** — On the Summary page, choose Data, then under Datasets, choose Add datasets.
+ **Removing datasets** — On the Summary page, choose Data, then under Datasets, choose the dataset menu and select Remove from topic.
+ **Refreshing datasets** — You can set a refresh schedule or manually refresh datasets in a legacy Topic. For SPICE datasets, you can sync with the SPICE refresh schedule.
+ **Calculated fields** — Create new fields using combinations of existing fields with supported functions.
+ **Filters** — Add filters to support questions that map to multiple values in the data.
+ **Named entities** — Create collections of fields that display together in an answer (for example, an "Address" entity combining Branch Name, State, and City).
