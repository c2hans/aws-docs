# Embedding the AWS Quick Sight Q search bar (Classic)
<a name="embedding-quicksight-q"></a>

|  |
| --- |
|    Intended audience:  AWS Quick developers  |

**Note**
The embedded AWS Quick Sight Q search bar provides the classic AWS Quick Sight Q&A experience. AWS Quick Sight integrates with Amazon Q Business to launch a new Generative Q&A experience. Developers are recommended to use the new Generative Q&A experience. For more information on the embedded Generative Q&A experience, see [Embedding the Amazon Q in AWS Quick Sight Generative Q&A experience](https://docs.aws.amazon.com/quicksight/latest/user/embedding-gen-bi.html).

Use the following topics to learn about embedding the AWS Quick Sight Q search bar with the AWS Quick Sight APIs.
