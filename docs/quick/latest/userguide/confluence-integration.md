# Atlassian Confluence Cloud integration
<a name="confluence-integration"></a>

Use the Atlassian Confluence Cloud integration to perform actions on Confluence content, or to create knowledge bases from Confluence spaces, pages, and blog posts for AI-powered search and Q&A.

## Integration capabilities
<a name="confluence-integration-capabilities"></a>

**Action connector**
Create and update Confluence pages, and search Confluence content through Atlassian API calls.

**Knowledge base**
Index Confluence pages, blog posts, and space content. Amazon Quick agents can then search and answer questions about the content. Optionally enable document-level access controls to ensure users only see answers from content they are authorized to access in Confluence.
