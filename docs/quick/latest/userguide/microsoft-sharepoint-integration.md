# Microsoft SharePoint integration
<a name="microsoft-sharepoint-integration"></a>

With the Microsoft SharePoint integration, you can manage SharePoint lists, items, and files. You can also create knowledge bases from SharePoint content for AI-powered search and Q&A.

## What you can do
<a name="sharepoint-integration-capabilities"></a>

**Action connector**
Manage SharePoint lists, items, files, and Excel workbooks through Microsoft Graph API calls.

**Knowledge base**
Index SharePoint document libraries, sites, and pages. Amazon Quick agents can then search and answer questions about the content. Amazon Quick supports two setup methods: user-managed setup for quick configuration, and admin-managed setup with service credentials for document-level access control.
