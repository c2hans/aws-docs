# Security best practices
<a name="byo-bedrock-kb-security"></a>
+ Use cross-account resource policies with specific role ARNs rather than granting access to entire accounts.
+ Regularly review the resource policies attached to your managed knowledge bases.
+ Monitor access patterns and review audit logs regularly.
