# Identity and access management in Quick
<a name="identity"></a>

|  |
| --- |
|    Applies to: Enterprise Edition and Standard Edition  |

|  |
| --- |
|    Intended audience:  System administrators and Amazon Quick administrators  |

You can use the following tools for identity and access to Quick:
+ [IAM Identity Center](https://docs.aws.amazon.com/quicksight/latest/user/sec-identity-management-identity-center.html)
+ [IAM federation](https://docs.aws.amazon.com/quicksight/latest/user/security.html)
+ [AWS Directory Service for Microsoft Active Directory](https://docs.aws.amazon.com/quicksight/latest/user/aws-directory-service.html)
+ [SAML-based single sign-on](https://docs.aws.amazon.com/quicksuite/latest/userguide/iam-federation.html)
+ [Multifactor authentication (MFA)](https://docs.aws.amazon.com/quicksight/latest/user/using-multi-factor-authentication-mfa.html)

**Note**
In the following regions, Amazon Quick accounts can only use [IAM Identity Center](https://docs.aws.amazon.com/quicksight/latest/user/sec-identity-management-identity-center.html) for identity and access management.
`af-south-1` Africa (Cape Town)
`ap-southeast-3` Asia Pacific (Jakarta)
`ap-southeast-5` Asia Pacific (Malaysia)
`eu-south-1` Europe (Milan)
`eu-central-2` Europe (Zurich)
