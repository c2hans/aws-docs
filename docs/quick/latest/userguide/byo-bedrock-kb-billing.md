# Billing
<a name="byo-bedrock-kb-billing"></a>

The knowledge base owner is charged for Amazon Bedrock usage costs, including retrieval requests and data ingestion. AWS Quick subscription costs are billed separately based on your AWS Quick user subscriptions. There are no additional charges from AWS Quick for connecting an Amazon Bedrock managed knowledge base.
