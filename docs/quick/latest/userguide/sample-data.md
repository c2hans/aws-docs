# Sample data
<a name="sample-data"></a>

To get a first look at how Amazon Quick Sight works, you can explore Amazon Quick Sight using the following sample data:
+ [B2b sales data](samples/b2b-sales.csv.zip)
+ [Business overview data](samples/business-overview.csv.zip) (revenue)
+ [ML insights data](samples/ml-insights.csv.zip)
+ [People overview data](samples/people-overview.csv.zip) (human resources)
+ [Sales pipeline data](samples/sales-pipeline.csv.zip)
+ [Web and social media analytics data](samples/web-and-social-analytics.csv.zip) (marketing)

Also, a variety of datasets are available free online that you can use with Amazon Quick Sight, for example the [AWS public datasets](https://aws.amazon.com/public-datasets/). These datasets come in a variety of formats.
