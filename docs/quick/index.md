# Amazon Quick Documentation

Amazon Quick is a comprehensive, generative AI-powered business intelligence platform that makes it easy to analyze data, create visualizations, automate workflows, and collaborate across your organization. The service combines traditional business intelligence capabilities with modern AI assistance, requiring no machine learning expertise to use. You can connect to diverse data sources, create interactive dashboards, build intelligent automations, and get immediate insights through natural language conversations with AI agents.

- [User Guide](/quick/latest/userguide/what-is.html): Describes all Amazon Quick concepts and features, and provides instructions on using these features in the Amazon Quick web application.
- [Developer Guide](/quicksight/latest/developerguide/welcome.html): Provides usage examples of API operations for Amazon Quick Sight and procedural walkthroughs of common tasks.
- [API Reference](/quicksight/latest/APIReference/Welcome.html): Provides descriptions, syntax, example requests, and sample responses for all of the operations available in Amazon Quick Sight, plus details on data types and errors.
- [Amazon Quick Sight in the AWS CLI Reference](/cli/latest/reference/quicksight/index.html): Describes all the command line interface (CLI) commands for Amazon Quick Sight in detail. Provides all syntax. Also provides examples for the most common commands.
