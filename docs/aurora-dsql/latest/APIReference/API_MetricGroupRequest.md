# MetricGroupRequest
<a name="API_MetricGroupRequest"></a>

A metric group to enable for advanced monitoring.

## Contents
<a name="API_MetricGroupRequest_Contents"></a>

 ** metricGroup **   <a name="auroradsql-Type-MetricGroupRequest-metricGroup"></a>
The name of the metric group to enable.
Type: String
Valid Values: `STATEMENT_STATISTICS`
Required: Yes
