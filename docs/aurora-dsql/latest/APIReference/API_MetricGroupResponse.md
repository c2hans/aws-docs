# MetricGroupResponse
<a name="API_MetricGroupResponse"></a>

A metric group that you enabled for advanced monitoring on a cluster.

## Contents
<a name="API_MetricGroupResponse_Contents"></a>

 ** metricGroup **   <a name="auroradsql-Type-MetricGroupResponse-metricGroup"></a>
The name of the metric group that you enabled.
Type: String
Valid Values: `STATEMENT_STATISTICS`
Required: Yes
