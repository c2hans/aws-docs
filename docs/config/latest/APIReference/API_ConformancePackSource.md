# ConformancePackSource
<a name="API_ConformancePackSource"></a>

Provides the identifier of the managed conformance pack that AWS Config deploys in your account.

## Contents
<a name="API_ConformancePackSource_Contents"></a>

 ** SourceIdentifier **   <a name="config-Type-ConformancePackSource-SourceIdentifier"></a>
A predefined identifier for a managed conformance pack. The identifier specifies which managed conformance pack AWS Config deploys in your account.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes
