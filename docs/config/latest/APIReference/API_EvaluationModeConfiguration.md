# EvaluationModeConfiguration
<a name="API_EvaluationModeConfiguration"></a>

The configuration object for AWS Config rule evaluation mode. The supported valid values are Detective or Proactive.

## Contents
<a name="API_EvaluationModeConfiguration_Contents"></a>

 ** Mode **   <a name="config-Type-EvaluationModeConfiguration-Mode"></a>
The mode of an evaluation. The valid values are Detective or Proactive.
Type: String
Valid Values: `DETECTIVE | PROACTIVE`
Required: No
