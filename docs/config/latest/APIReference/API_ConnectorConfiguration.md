# ConnectorConfiguration
<a name="API_ConnectorConfiguration"></a>

The provider-specific configuration for connecting to the third-party cloud service provider. You must specify exactly one provider configuration.

## Contents
<a name="API_ConnectorConfiguration_Contents"></a>

 ** azure **   <a name="config-Type-ConnectorConfiguration-azure"></a>
The configuration for an Azure connector.
Type: [AzureConnectorConfiguration](API_AzureConnectorConfiguration.md) object
Required: No
