# ComplianceSummaryByResourceType
<a name="API_ComplianceSummaryByResourceType"></a>

The number of AWS resources of a specific type that are compliant or noncompliant, up to a maximum of 100 for each.

## Contents
<a name="API_ComplianceSummaryByResourceType_Contents"></a>

 ** ComplianceSummary **   <a name="config-Type-ComplianceSummaryByResourceType-ComplianceSummary"></a>
The number of AWS resources that are compliant or noncompliant, up to a maximum of 100 for each.
Type: [ComplianceSummary](API_ComplianceSummary.md) object
Required: No

 ** ResourceType **   <a name="config-Type-ComplianceSummaryByResourceType-ResourceType"></a>
The type of AWS resource.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
