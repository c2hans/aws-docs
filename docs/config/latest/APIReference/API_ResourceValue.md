# ResourceValue
<a name="API_ResourceValue"></a>

The dynamic value of the resource.

## Contents
<a name="API_ResourceValue_Contents"></a>

 ** Value **   <a name="config-Type-ResourceValue-Value"></a>
The value is a resource ID.
Type: String
Valid Values: `RESOURCE_ID`
Required: Yes
