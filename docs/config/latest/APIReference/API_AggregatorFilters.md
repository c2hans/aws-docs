# AggregatorFilters
<a name="API_AggregatorFilters"></a>

An object to filter the data you specify for an aggregator.

## Contents
<a name="API_AggregatorFilters_Contents"></a>

 ** ResourceType **   <a name="config-Type-AggregatorFilters-ResourceType"></a>
An object to filter the configuration recorders based on the resource types in scope for recording.
Type: [AggregatorFilterResourceType](API_AggregatorFilterResourceType.md) object
Required: No

 ** ServicePrincipal **   <a name="config-Type-AggregatorFilters-ServicePrincipal"></a>
An object to filter service-linked configuration recorders in an aggregator based on the linked AWS service.
Type: [AggregatorFilterServicePrincipal](API_AggregatorFilterServicePrincipal.md) object
Required: No
