# AggregateConformancePackComplianceCount
<a name="API_AggregateConformancePackComplianceCount"></a>

The number of conformance packs that are compliant and noncompliant.

## Contents
<a name="API_AggregateConformancePackComplianceCount_Contents"></a>

 ** CompliantConformancePackCount **   <a name="config-Type-AggregateConformancePackComplianceCount-CompliantConformancePackCount"></a>
Number of compliant conformance packs.
Type: Integer
Required: No

 ** NonCompliantConformancePackCount **   <a name="config-Type-AggregateConformancePackComplianceCount-NonCompliantConformancePackCount"></a>
Number of noncompliant conformance packs.
Type: Integer
Required: No
