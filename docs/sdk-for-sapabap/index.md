# AWS SDK for SAP ABAP

AWS SDK for SAP ABAP provides an interface to Amazon Web Services in ABAP. Using the SDK, you can build SAP applications on top of Amazon S3, Amazon EC2, DynamoDB, and more.

- [AWS SDK for SAP ABAP Developer Guide](/sdk-for-sapabap/latest/developer-guide/home.html): Introduces AWS SDK for SAP ABAP and provides information about using the SDK, including code examples for a number of services.
- [API Reference](/sdk-for-sap-abap/v1/api/latest/index.html): Describes the API operations of AWS SDK for SAP ABAP in detail. The guide also provides sample requests, responses, and errors for the supported web services protocols.
- [Code Library](/code-library/latest/ug/): A collection of code examples that show you how to use AWS SDKs with AWS. It is organized by service and by SDK to help you find the examples you need.
- [AWS Code Examples Repository](https://github.com/awsdocs/aws-doc-sdk-examples): Contains code and other types of examples to accelerate your development of applications that work with AWS services. The examples show how to perform tasks for AWS services using supported programming languages and technologies.
