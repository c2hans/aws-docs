# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

Stores information about a field in a request that caused an exception.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="PCS-Type-ValidationExceptionField-message"></a>
The message body of the exception.
Type: String
Required: Yes

 ** name **   <a name="PCS-Type-ValidationExceptionField-name"></a>
The name of the exception.
Type: String
Required: Yes
