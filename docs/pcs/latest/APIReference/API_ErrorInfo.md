# ErrorInfo
<a name="API_ErrorInfo"></a>

 ** code **   <a name="PCS-Type-ErrorInfo-code"></a>
The short-form error code.
Type: String
Required: No

 ** message **   <a name="PCS-Type-ErrorInfo-message"></a>

Type: String
Required: No
