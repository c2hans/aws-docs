# SlurmAuthKey
<a name="API_SlurmAuthKey"></a>

The shared Slurm key for authentication, also known as the **cluster secret**.

## Contents
<a name="API_SlurmAuthKey_Contents"></a>

 ** secretArn **   <a name="PCS-Type-SlurmAuthKey-secretArn"></a>
The Amazon Resource Name (ARN) of the shared Slurm key.
Type: String
Required: Yes

 ** secretVersion **   <a name="PCS-Type-SlurmAuthKey-secretVersion"></a>
The version of the shared Slurm key.
Type: String
Required: Yes
