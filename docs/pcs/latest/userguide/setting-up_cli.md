# Install the AWS CLI for AWS PCS
<a name="setting-up_cli"></a>

You must use the latest version of the AWS CLI. For information, see [Install or update to the latest version of the AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) in the *AWS Command Line Interface User Guide for Version 2*.

You must configure the AWS CLI. For more information, see [Configure the AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-configure.html) in the *AWS Command Line Interface User Guide for Version 2*.

Enter the following command at a command prompt to check your AWS CLI; it should display help information.

```
aws pcs help
```
