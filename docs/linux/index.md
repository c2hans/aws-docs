# Amazon Linux Documentation

Amazon Linux is a portfolio of modern Linux-based high performance operating systems that are security-focused and stable.

## Amazon Linux 2023

Amazon Linux 2023 is the current version of Amazon Linux.

- [Amazon Linux 2023 User Guide](/linux/al2023/ug/): Describes key concepts of Amazon Linux 2023 (AL2023) and provides instructions for using the features of AL2023.
- [Amazon Linux 2023 Release Notes](/linux/al2023/release-notes/): Describes features and changes included with Amazon Linux 2023 releases.

## Previous generations of Amazon Linux

- [Amazon Linux 2 User Guide](/linux/al2/ug/): Describes key concepts of Amazon Linux 2 (AL2) and provides instructions for using the features of AL2. AL2 is no longer the current version of Amazon Linux.
- [Amazon Linux 2 Release Notes](/AL2/latest/relnotes): Describes features and changes included with Amazon Linux 2 releases.
- [Amazon Linux 1 User Guide](/linux/al1/ug/): Describes key concepts of Amazon Linux 1 (AL1). AL1 is no longer supported. If you are moving from another version of Linux, use AL2023.
