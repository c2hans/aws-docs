# Query Package Support with the AL2023 Support Info Plugin
<a name="dnf-supportinfo-plugin"></a>

The dnf-plugin-support-info package provides the `dnf supportinfo` command. Use this command to query lifecycle and support information for packages: find out whether a package is currently supported, what severity levels receive patches, and when support status changes. The following topics describe how to use the plugin, how to migrate scripts from v1 to v2 output, and the structure of the underlying support info data.
