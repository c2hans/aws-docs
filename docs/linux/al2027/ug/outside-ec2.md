# Using Amazon Linux 2027 outside of Amazon EC2
<a name="outside-ec2"></a>

**AL2027 Preview**
AL2027 is currently available for preview. It is intended for evaluation and testing only and is not recommended for production workloads.

 The Amazon Linux 2027 container images can be run in compatible container runtime environments. For more information on how to use Amazon Linux 2027 inside a container, see [AL2027 in containers](container.md).

 Amazon Linux 2027 (AL2027) can also be run as a virtualized guest outside of directly being run on Amazon EC2. There are currently KVM (`qcow2`), VMware (`OVA`), and Hyper-V (`vhdx`) images available.
