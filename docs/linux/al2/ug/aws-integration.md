# AWS integration in AL2
<a name="aws-integration"></a>

## AWS command line tools
<a name="amazon-linux-aws-command-line-tools"></a>

The AWS Command Line Interface (AWS CLI) is an open source tool that provides a consistent interface to interact with AWS services using commands in your command-line shell. For more information, see [What is the AWS Command Line Interface?](https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-welcome.html) in the *AWS Command Line Interface User Guide*.

AL2 and AL1 have version 1 of the AWS CLI preinstalled. The current release of Amazon Linux, AL2023, has version 2 of the AWS CLI preinstalled. For more information about using the AWS CLI on AL2023, see [Get started with AL2023](https://docs.aws.amazon.com/linux/al2023/ug/get-started.html) in the *Amazon Linux 2023 User Guide*.
