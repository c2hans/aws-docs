# TxtMethodConfig
<a name="API_TxtMethodConfig"></a>

 Configuration for TXT record-based domain verification method.

## Contents
<a name="API_TxtMethodConfig_Contents"></a>

 ** name **   <a name="vpclattice-Type-TxtMethodConfig-name"></a>
 The name of the TXT record that must be created for domain verification.
Type: String
Required: Yes

 ** value **   <a name="vpclattice-Type-TxtMethodConfig-value"></a>
 The value that must be added to the TXT record for domain verification.
Type: String
Required: Yes
