# FixedResponseAction
<a name="API_FixedResponseAction"></a>

Describes an action that returns a custom HTTP response.

## Contents
<a name="API_FixedResponseAction_Contents"></a>

 ** statusCode **   <a name="vpclattice-Type-FixedResponseAction-statusCode"></a>
The HTTP response code. Only `404` and `500` status codes are supported.
Type: Integer
Valid Range: Minimum value of 100. Maximum value of 599.
Required: Yes
