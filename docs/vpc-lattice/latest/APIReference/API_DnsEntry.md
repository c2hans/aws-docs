# DnsEntry
<a name="API_DnsEntry"></a>

Describes the DNS information of a service.

## Contents
<a name="API_DnsEntry_Contents"></a>

 ** domainName **   <a name="vpclattice-Type-DnsEntry-domainName"></a>
The domain name of the service.
Type: String
Required: No

 ** hostedZoneId **   <a name="vpclattice-Type-DnsEntry-hostedZoneId"></a>
The ID of the hosted zone.
Type: String
Required: No
