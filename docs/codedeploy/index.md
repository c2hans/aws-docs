# AWS CodeDeploy Documentation

AWS CodeDeploy is a deployment service that enables developers to automate the deployment of applications to instances and to update the applications as required.

- [User Guide](/codedeploy/latest/userguide/): Describes how to get started and deploy applications using AWS CodeDeploy.
- [API Reference](/codedeploy/latest/APIReference/): Describes all the API operations for AWS CodeDeploy. Also provides sample requests, responses, and errors for the supported web services protocols.
- [AWS CLI Reference for AWS CodeDeploy](/cli/latest/reference/deploy/index.html): Describes the AWS CLI commands that you can use to automate deployments.
