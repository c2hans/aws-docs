# AWS B2B Data Interchange Documentation

AWS B2B Data Interchange enables automated exchange of EDI-based business-critical transactions at cloud scale, with elasticity, and pay-as-you-go pricing.

- [AWS B2B Data Interchange User Guide](/b2bi/latest/userguide): Describes all B2B Data Interchange concepts and provides instructions on using the various features with the console, the command line interface, and the AWS B2B Data Interchange API.
- [AWS B2B Data Interchange API Reference](/b2bi/latest/APIReference): Describes all API operations for AWS B2B Data Interchange in detail. Also provides sample requests, responses, and errors for the supported web service protocols.
