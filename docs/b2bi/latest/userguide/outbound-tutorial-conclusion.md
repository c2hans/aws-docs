# Next steps
<a name="outbound-tutorial-conclusion"></a>

This outbound tutorial provides a complete foundation for generating X12 EDI documents from JSON data using AWS B2B Data Interchange. You can extend this setup by adding more transaction sets, creating additional outbound transformations, or integrating with AWS Transfer Family for automated EDI transmission to trading partners.

For additional learning resources, see:
+ [AWS B2B Data Interchange concepts](b2bi-concepts.md) for detailed information about AWS B2B Data Interchange components
+ [Supported X12 transaction sets](x12-transaction-sets.md) for supported transaction sets
+ [Inbound EDI tutorial](inbound-edi-tutorial.md) for inbound EDI processing
+ For a self-paced learning experience, go through the [EDI document exchange with AWS B2B Data Interchange Workshop](https://catalog.workshops.aws/getting-started-b2b-data-interchange/), created by the B2B Data Interchange service team. In this workshop, you learn how to receive and transform EDI documents from your business partners using AWS B2B Data Interchange and AWS Transfer Family.
