# GetTransformerJob
<a name="API_GetTransformerJob"></a>

Returns the details of the transformer run, based on the Transformer job ID.

**Note**
If 30 days have elapsed since your transformer job was started, the system deletes it. So, if you run `GetTransformerJob` and supply a `transformerId` and `transformerJobId` for a job that was started more than 30 days previously, you receive a 404 response.

## Request Syntax
<a name="API_GetTransformerJob_RequestSyntax"></a>

```
{
   "transformerId": "{{string}}",
   "transformerJobId": "{{string}}"
}
```

## Request Parameters
<a name="API_GetTransformerJob_RequestParameters"></a>

For information about the parameters that are common to all actions, see [Common Parameters](CommonParameters.md).

The request accepts the following data in JSON format.

 ** [transformerId](#API_GetTransformerJob_RequestSyntax) **   <a name="b2bi-GetTransformerJob-request-transformerId"></a>
Specifies the system-assigned unique identifier for the transformer.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Pattern: `[a-zA-Z0-9_-]+`
Required: Yes

 ** [transformerJobId](#API_GetTransformerJob_RequestSyntax) **   <a name="b2bi-GetTransformerJob-request-transformerJobId"></a>
Specifies the unique, system-generated identifier for a transformer run.
Type: String
Length Constraints: Fixed length of 25.
Pattern: `[a-zA-Z0-9_-]+`
Required: Yes

## Response Syntax
<a name="API_GetTransformerJob_ResponseSyntax"></a>

```
{
   "message": "string",
   "outputFiles": [
      {
         "bucketName": "string",
         "key": "string"
      }
   ],
   "status": "string"
}
```

## Response Elements
<a name="API_GetTransformerJob_ResponseElements"></a>

If the action is successful, the service sends back an HTTP 200 response.

The following data is returned in JSON format by the service.

 ** [message](#API_GetTransformerJob_ResponseSyntax) **   <a name="b2bi-GetTransformerJob-response-message"></a>
Returns an optional error message, which gets populated when the job is not run successfully.
Type: String

 ** [outputFiles](#API_GetTransformerJob_ResponseSyntax) **   <a name="b2bi-GetTransformerJob-response-outputFiles"></a>
Returns the location for the output files. If the caller specified a directory for the output, then this contains the full path to the output file, including the file name generated by the service.
Type: Array of [S3Location](API_S3Location.md) objects

 ** [status](#API_GetTransformerJob_ResponseSyntax) **   <a name="b2bi-GetTransformerJob-response-status"></a>
Returns the current state of the transformer job, either `running`, `succeeded`, or `failed`.
Type: String
Valid Values: `running | succeeded | failed`
