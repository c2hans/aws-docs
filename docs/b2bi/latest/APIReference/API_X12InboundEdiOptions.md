# X12InboundEdiOptions
<a name="API_X12InboundEdiOptions"></a>

Contains options specific to processing inbound X12 EDI files.

## Contents
<a name="API_X12InboundEdiOptions_Contents"></a>

 ** acknowledgmentOptions **   <a name="b2bi-Type-X12InboundEdiOptions-acknowledgmentOptions"></a>
Specifies acknowledgment options for inbound X12 EDI files. These options control how functional and technical acknowledgments are handled.
Type: [X12AcknowledgmentOptions](API_X12AcknowledgmentOptions.md) object
Required: No
