# SampleDocumentKeys
<a name="API_SampleDocumentKeys"></a>

An array of the Amazon S3 keys used to identify the location for your sample documents.

## Contents
<a name="API_SampleDocumentKeys_Contents"></a>

 ** input **   <a name="b2bi-Type-SampleDocumentKeys-input"></a>
An array of keys for your input sample documents.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: No

 ** output **   <a name="b2bi-Type-SampleDocumentKeys-output"></a>
An array of keys for your output sample documents.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: No
