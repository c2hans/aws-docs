# InputFileSource
<a name="API_InputFileSource"></a>

The input file to use for an outbound transformation.

## Contents
<a name="API_InputFileSource_Contents"></a>

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** fileContent **   <a name="b2bi-Type-InputFileSource-fileContent"></a>
Specify the input contents, as a string, for the source of an outbound transformation.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 5000000.
Required: No
