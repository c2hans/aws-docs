# Amazon Nova Documentation

Amazon Nova is a group of foundation models to generate or understand the contents text, images, and videos

## Amazon Nova 2.0

Amazon Nova 2.0 introduces significant enhancements including Nova 2.0 Omni (multimodal understanding and generation), Nova 2.0 Lite and Pro (improved reasoning with extended thinking), Nova Sonic 2.0 (conversational speech), enhanced image generation and editing capabilities, built-in tools (web grounding and code interpreter), structured output support, and improved document and video understanding. The developer guide is organized by developer workflow for easier navigation.
