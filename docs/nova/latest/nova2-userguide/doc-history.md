# Document history for the Amazon Nova Developer Guide
<a name="doc-history"></a>

The following table describes the documentation releases for Amazon Nova 2.0.

| Change | Description | Date |
| --- |--- |--- |
| [SageMaker Python SDK documentation update](#doc-history) | Replaced Nova Forge SDK documentation pages with SageMaker Python SDK v3 documentation covering model customization, evaluation, and deployment. | August 6, 2026 |
| [Updated Amazon Nova 2 Sonic documentation](#doc-history) | Added a [release notes](https://docs.aws.amazon.com/nova/latest/nova2-userguide/release-notes.html) page. Increased [conversation history](https://docs.aws.amazon.com/nova/latest/nova2-userguide/sonic-chat-history.html) limits to 50 KB per message and 200 KB total. Added defensive [tool use](https://docs.aws.amazon.com/nova/latest/nova2-userguide/sonic-tool-configuration.html) guidance. | June 22, 2026 |
| [Initial release of Amazon Nova 2.0](#doc-history) | Initial release of the Amazon Nova 2.0 Developer Guide with new models: Nova 2 Lite, Nova 2 Sonic and Nova Multimodal Embeddings. This guide introduces enhanced multimodal capabilities, reasoning features and improved performance across all model tiers. | December 2, 2025 |
