# Create Amazon Nova resources with AWS CloudFormation
<a name="creating-resources-with-cloudformation"></a>

When deploying Amazon Nova models through Amazon Bedrock with CloudFormation, follow all CloudFormation guidance at [Create Amazon Bedrock resources with CloudFormation](https://docs.aws.amazon.com/bedrock/latest/userguide/creating-resources-with-cloudformation.html).

For more information, including examples of JSON and YAML templates for YOUR-RESOURCE-PLURAL, see the [YOUR-SERVICE-RESOURCE-TOPNODE-IN-CLOUDFORMATION, modify this link in the local-phrases.ent file](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/aws-template-resource-type-ref.html) in the *AWS CloudFormation User Guide*.
