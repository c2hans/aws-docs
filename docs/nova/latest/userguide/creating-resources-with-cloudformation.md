# Create Amazon Bedrock resources with AWS CloudFormation
<a name="creating-resources-with-cloudformation"></a>

**Note**
This documentation is for Version 1. is now available with new models and enhanced capabilities. New features and documentation updates are published in the User Guide. For information about CloudFormation with , visit [Create resources with CloudFormation](https://docs.aws.amazon.com/nova/latest/nova2-userguide/creating-resources-with-cloudformation.html).

When deploying Amazon Bedrock models through Amazon Bedrock with CloudFormation, follow all CloudFormation guidance at [Create Amazon Bedrock resources with CloudFormation](https://docs.aws.amazon.com/bedrock/latest/userguide/creating-resources-with-cloudformation.html).

For more information, including examples of JSON and YAML templates for [Amazon Bedrock agents](https://docs.aws.amazon.com/bedrock/latest/userguide/agents.html) or [Amazon Bedrock knowledge bases](https://docs.aws.amazon.com/bedrock/latest/userguide/knowledge-base.html), see the [Amazon Bedrock resource type reference](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/AWS_Bedrock.html) in the *AWS CloudFormation User Guide*.
