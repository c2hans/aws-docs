# AWS Agent Registry Documentation

AWS Agent Registry is an agentic platform for building, deploying, and operating agents securely at scale using any framework and foundation model. Use Agent Registry to enable agents to take actions across tools and data with the right permissions and governance, run agents securely at scale, and monitor agent performance and quality in production without infrastructure management.

## Console and SDKs

- [Agent Registry Console](https://console.aws.amazon.com/agent-registry): Access the Agent Registry console.
- [Agent Registry Data Plane SDK](https://docs.aws.amazon.com/boto3/latest/reference/services/agent-registry.html): AWS SDK for Python (boto3) for the Agent Registry data plane.
- [Agent Registry Control Plane SDK](https://docs.aws.amazon.com/boto3/latest/reference/services/agent-registry-control.html): AWS SDK for Python (boto3) for the Agent Registry control plane.
