# Using the Service Catalog console
<a name="enduser-dashboard"></a>

You can use the Service Catalog console to see a list of products and provisioned products.

You can launch products, and then view, update, or delete the products you provisioned.

**To view the Service Catalog console**
+ Sign in to the AWS Management Console and open the Service Catalog console at [https://console.aws.amazon.com/servicecatalog/](https://console.aws.amazon.com/servicecatalog/).
