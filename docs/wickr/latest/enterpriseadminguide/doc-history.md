This guide provides documentation for Wickr Enterprise. If you're using AWS Wickr, see [AWS Wickr Administration Guide](https://docs.aws.amazon.com/wickr/latest/adminguide/what-is-wickr.html).

# Document history
<a name="doc-history"></a>

The following table describes the documentation releases for Wickr Enterprise.

| Change | Description | Date |
| --- |--- |--- |
| [Global Federation now supports restricted federation and admins can view usage analytics in the Admin Console](#doc-history) |  Global Federation now supports restricted federation. For more information, see [Global Federation](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/global-federation.html). Additionally, network administrators can now view their usage analytics on the Analytics dashboard in the Network Administrator Console. For more information, see [Analytics dashboard](https://docs.aws.amazon.com/wickr/latest/enterpriseadminguide/analytics-dashboard.html). | March 29, 2024 |
| [Initial release](#doc-history) | Initial release of the Wickr Enterprise Administration Guide | March 18, 2024 |
