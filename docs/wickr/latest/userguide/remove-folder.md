# Remove a folder or file in the Wickr client
<a name="remove-folder"></a>

Moderators can remove a folder or file from a room in the Wickr client.

To remove a folder or file from a room, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2).

1. In the navigation pane, find and choose the room or group where you want to delete a folder.

1. Choose the **Files** tab at the top of the room in Wickr client.

1. On desktop, select the message options (three-dot) menu on the right side of the folder or file you want to remove. On mobile, long-press the folder or file you want to move.

1. In the message options menu, choose **Remove From Room**.

1. Choose **Yes** in the pop-up window to remove the folder or file.
**Note**
Removing a folder also removes all the files and subfolders within the folder.
