# Save a file in the Wickr client
<a name="save-file"></a>

Moderators can save a file to a room in the Wickr client.

To save a file in a room, complete the following steps.

1. Sign in to the Wickr client. For more information, see [Sign in to the Wickr client](getting-started.md#sign-in-step2).

1. In the navigation pane, choose the room or group where you want to save a file.

1. On desktop, select the message options (three-dot) menu on the right side of the file you want to save.

   On mobile, long-press the file you want to save.

1. In the message options menu, choose **Save to Room**.

   The saved files are available under the **Files** tab, in the default folder **Saved from Messages**.
