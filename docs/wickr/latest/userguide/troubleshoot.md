# Troubleshoot issues with AWS Wickr
<a name="troubleshoot"></a>

The following topics can help you troubleshoot common issues with AWS Wickr. If the steps in this section don't resolve your issue, contact your Wickr network administrator.

If you are an administrator, see the [AWS Wickr Administrator Guide](https://docs.aws.amazon.com/wickr/latest/adminguide/troubleshoot.html) for additional troubleshooting steps. If you cannot resolve the issue through self-service, open a case in the [AWS Support Center](https://console.aws.amazon.com/support/home).

**Topics**
+ [Troubleshoot login and registration issues](troubleshoot-enduser.md)
+ [Troubleshoot voice and video call issues](troubleshoot-calls.md)
+ [Troubleshoot message delivery issues](troubleshoot-messages.md)
+ [Troubleshoot network and connectivity issues](troubleshoot-network.md)
