# ReadReceiptConfig
<a name="API_ReadReceiptConfig"></a>

Configuration for read receipts at the network level, controlling whether senders can see when their messages have been read.

## Contents
<a name="API_ReadReceiptConfig_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** status **   <a name="wickr-Type-ReadReceiptConfig-status"></a>
The read receipt status mode for the network.
Type: String
Valid Values: `DISABLED | ENABLED | FORCE_ENABLED`
Required: No
