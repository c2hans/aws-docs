# AWS Wickr Documentation

AWS Wickr is an end-to-end encrypted, enterprise communications service that enables secure one-to-one chats, group messaging, calling, file sharing, screen sharing, and more.

## AWS Wickr

- [Administration Guide](/wickr/latest/adminguide/): Describes key concepts of Wickr and provides instructions for configuring the service and adding users.
- [User Guide](/wickr/latest/userguide/): Describes how to download the Wickr client and get started with accepting invitations, creating rooms, and messaging.
- [Bots and Integrations Guide](/wickr/latest/wickrio/): Describes how to set up Wickr bots, which allow external services and workflows to communicate with Wickr users.
- [API Reference](/wickr/latest/APIReference/): Describes all the API operations for Wickr administrators to programmatically manage their networks. Allowed operations include managing network settings, users, security groups, and bots.

## Wickr Enterprise

- [Administration Guide](/wickr/latest/enterpriseadminguide/): Describes key concepts of self-hosted Wickr Enterprise and provides instructions for configuring the service and adding users.
- [Automated Install Guide](/wickr/latest/wickrenterpriseinstall/): Describes how to automatically deploy self-hosted Wickr Enterprise with AWS CDK.

## Wickr Enterprise Release Notes

- [Infrastructure](/wickr/latest/enterpriseadminguide/infra-release-notes.html): Describes the Enterprise infrastructure versions that are supported by Wickr Enterprise.
- [Clients](/wickr/latest/enterpriseadminguide/clients-release-notes.html): Describes the client versions that are supported by Wickr Enterprise.
- [Bots](/wickr/latest/enterpriseadminguide/bots-release-notes.html): Describes the bot versions that are supported by Wickr Enterprise.
