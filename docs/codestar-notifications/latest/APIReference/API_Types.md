# Data Types
<a name="API_Types"></a>

The AWS CodeStar Notifications API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [EventTypeSummary](API_EventTypeSummary.md)
+  [ListEventTypesFilter](API_ListEventTypesFilter.md)
+  [ListNotificationRulesFilter](API_ListNotificationRulesFilter.md)
+  [ListTargetsFilter](API_ListTargetsFilter.md)
+  [NotificationRuleSummary](API_NotificationRuleSummary.md)
+  [Target](API_Target.md)
+  [TargetSummary](API_TargetSummary.md)
