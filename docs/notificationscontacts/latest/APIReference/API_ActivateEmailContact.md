# ActivateEmailContact
<a name="API_ActivateEmailContact"></a>

Activates an email contact using an activation code. This code is in the activation email sent to the email address associated with this email contact.

## Request Syntax
<a name="API_ActivateEmailContact_RequestSyntax"></a>

```
PUT /emailcontacts/{{arn}}/activate/{{code}} HTTP/1.1
```

## URI Request Parameters
<a name="API_ActivateEmailContact_RequestParameters"></a>

The request uses the following URI parameters.

 ** [arn](#API_ActivateEmailContact_RequestSyntax) **   <a name="notificationscontacts-ActivateEmailContact-request-uri-arn"></a>
The Amazon Resource Name (ARN) of the resource.
Pattern: `arn:[a-z-]{3,10}:notifications-contacts::[0-9]{12}:emailcontact/[a-z0-9]{27}`
Required: Yes

 ** [code](#API_ActivateEmailContact_RequestSyntax) **   <a name="notificationscontacts-ActivateEmailContact-request-uri-code"></a>
The activation code for this email contact.
An email contact has a maximum of five activation attempts. Activation codes expire after 12 hours and are generated by the [SendActivationCode](https://docs.aws.amazon.com/notificationscontacts/latest/APIReference/API_SendActivationCode.html) API action.
Length Constraints: Fixed length of 7.
Pattern: `[a-z0-9]{7}`
Required: Yes

## Request Body
<a name="API_ActivateEmailContact_RequestBody"></a>

The request does not have a request body.
