# Amazon SQS policy quotas
<a name="quotas-policies"></a>

The following table lists quotas related to policies.

| Name | Maximum |
| --- | --- |
| Bytes | 8,192 |
| Conditions | 10 |
| Principals | 50 |
| Statements | 20 |
| Actions per statement | 7 |
