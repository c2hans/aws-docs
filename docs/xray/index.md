# AWS X-Ray Documentation

AWS X-Ray makes it easy for developers to analyze the behavior of their distributed applications by providing request tracing, exception collection, and profiling capabilities.

- [Developer Guide](/xray/latest/devguide/aws-xray.html): Describes how to get started and instrument your applications using AWS X-Ray.
- [API Reference](/xray/latest/api/Welcome.html): Describes all API operations for AWS X-Ray in detail. Also provides details of request and response syntax and errors for the supported web services protocols.
- [AWS X-Ray SDK for Java API Reference](/xray-sdk-for-java/latest/javadoc/): Describes all of the classes included in the AWS X-Ray SDK for Java.
- [AWS X-Ray SDK for Ruby API Reference](/xray-sdk-for-ruby/latest/reference/): Describes all of the classes included in the AWS X-Ray SDK for Ruby.
- [AWS X-Ray SDK for .NET API Reference](/xray-sdk-for-dotnet/latest/reference/): Describes all of the .NET Framework classes included in the AWS X-Ray SDK for .NET.
