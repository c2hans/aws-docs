# Alias
<a name="API_Alias"></a>

An alias for an edge.

## Contents
<a name="API_Alias_Contents"></a>

 ** Name **   <a name="xray-Type-Alias-Name"></a>
The canonical name of the alias.
Type: String
Required: No

 ** Names **   <a name="xray-Type-Alias-Names"></a>
A list of names for the alias, including the canonical name.
Type: Array of strings
Required: No

 ** Type **   <a name="xray-Type-Alias-Type"></a>
The type of the alias.
Type: String
Required: No
