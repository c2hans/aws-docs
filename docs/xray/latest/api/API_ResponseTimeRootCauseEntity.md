# ResponseTimeRootCauseEntity
<a name="API_ResponseTimeRootCauseEntity"></a>

A collection of segments and corresponding subsegments associated to a response time warning.

## Contents
<a name="API_ResponseTimeRootCauseEntity_Contents"></a>

 ** Coverage **   <a name="xray-Type-ResponseTimeRootCauseEntity-Coverage"></a>
The type and messages of the exceptions.
Type: Double
Required: No

 ** Name **   <a name="xray-Type-ResponseTimeRootCauseEntity-Name"></a>
The name of the entity.
Type: String
Required: No

 ** Remote **   <a name="xray-Type-ResponseTimeRootCauseEntity-Remote"></a>
A flag that denotes a remote subsegment.
Type: Boolean
Required: No
