# UnprocessedTraceSegment
<a name="API_UnprocessedTraceSegment"></a>

Information about a segment that failed processing.

## Contents
<a name="API_UnprocessedTraceSegment_Contents"></a>

 ** ErrorCode **   <a name="xray-Type-UnprocessedTraceSegment-ErrorCode"></a>
The error that caused processing to fail.
Type: String
Required: No

 ** Id **   <a name="xray-Type-UnprocessedTraceSegment-Id"></a>
The segment's ID.
Type: String
Required: No

 ** Message **   <a name="xray-Type-UnprocessedTraceSegment-Message"></a>
The error message.
Type: String
Required: No
