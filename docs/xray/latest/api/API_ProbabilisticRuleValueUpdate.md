# ProbabilisticRuleValueUpdate
<a name="API_ProbabilisticRuleValueUpdate"></a>

 Update to the indexing rule configuration for probabilistic sampling.

## Contents
<a name="API_ProbabilisticRuleValueUpdate_Contents"></a>

 ** DesiredSamplingPercentage **   <a name="xray-Type-ProbabilisticRuleValueUpdate-DesiredSamplingPercentage"></a>
 Configured sampling percentage of traceIds. Note that sampling can be subject to limits to ensure completeness of data.
Type: Double
Required: Yes
