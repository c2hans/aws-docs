# ResourceGroupTag
<a name="API_ResourceGroupTag"></a>

This data type is used as one of the elements of the [ResourceGroup](API_ResourceGroup.md) data type.

## Contents
<a name="API_ResourceGroupTag_Contents"></a>

 ** key **   <a name="Inspector-Type-ResourceGroupTag-key"></a>
A tag key.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** value **   <a name="Inspector-Type-ResourceGroupTag-value"></a>
The value assigned to a tag key.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
