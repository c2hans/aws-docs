# MonthlySchedule
<a name="API_MonthlySchedule"></a>

A monthly schedule.

## Contents
<a name="API_MonthlySchedule_Contents"></a>

 ** day **   <a name="inspector2-Type-MonthlySchedule-day"></a>
The monthly schedule's day.
Type: String
Valid Values: `SUN | MON | TUE | WED | THU | FRI | SAT`
Required: Yes

 ** startTime **   <a name="inspector2-Type-MonthlySchedule-startTime"></a>
The monthly schedule's start time.
Type: [Time](API_Time.md) object
Required: Yes
