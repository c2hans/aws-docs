# AwsEcsMetadataDetails
<a name="API_AwsEcsMetadataDetails"></a>

Metadata about tasks where an image was in use.

## Contents
<a name="API_AwsEcsMetadataDetails_Contents"></a>

 ** detailsGroup **   <a name="inspector2-Type-AwsEcsMetadataDetails-detailsGroup"></a>
The details group information for a task in a cluster.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes

 ** taskDefinitionArn **   <a name="inspector2-Type-AwsEcsMetadataDetails-taskDefinitionArn"></a>
The task definition ARN.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: Yes
