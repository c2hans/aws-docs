# ResourceStringFilter
<a name="API_ResourceStringFilter"></a>

A resource string filter for a software bill of materials report.

## Contents
<a name="API_ResourceStringFilter_Contents"></a>

 ** comparison **   <a name="inspector2-Type-ResourceStringFilter-comparison"></a>
The filter's comparison.
Type: String
Valid Values: `EQUALS | NOT_EQUALS`
Required: Yes

 ** value **   <a name="inspector2-Type-ResourceStringFilter-value"></a>
The filter's value.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes
