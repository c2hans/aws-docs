# UpdateGitLabSelfManagedIntegrationDetail
<a name="API_UpdateGitLabSelfManagedIntegrationDetail"></a>

Contains details required to update an integration with a self-managed GitLab instance.

## Contents
<a name="API_UpdateGitLabSelfManagedIntegrationDetail_Contents"></a>

 ** authCode **   <a name="inspector2-Type-UpdateGitLabSelfManagedIntegrationDetail-authCode"></a>
The authorization code received from the self-managed GitLab instance to update the integration.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes
