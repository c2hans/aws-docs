# Step
<a name="API_Step"></a>

Details about the step associated with a finding.

## Contents
<a name="API_Step_Contents"></a>

 ** componentId **   <a name="inspector2-Type-Step-componentId"></a>
The component ID.
Type: String
Required: Yes

 ** componentType **   <a name="inspector2-Type-Step-componentType"></a>
The component type.
Type: String
Required: Yes

 ** componentArn **   <a name="inspector2-Type-Step-componentArn"></a>
The component ARN. The ARN can be null and is not displayed in the AWS console.
Type: String
Required: No
