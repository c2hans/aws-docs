# CisStringFilter
<a name="API_CisStringFilter"></a>

The CIS string filter.

## Contents
<a name="API_CisStringFilter_Contents"></a>

 ** comparison **   <a name="inspector2-Type-CisStringFilter-comparison"></a>
The comparison value of the CIS string filter.
Type: String
Valid Values: `EQUALS | PREFIX | NOT_EQUALS`
Required: Yes

 ** value **   <a name="inspector2-Type-CisStringFilter-value"></a>
The value of the CIS string filter.
Type: String
Required: Yes
