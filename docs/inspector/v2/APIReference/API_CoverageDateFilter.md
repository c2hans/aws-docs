# CoverageDateFilter
<a name="API_CoverageDateFilter"></a>

Contains details of a coverage date filter.

## Contents
<a name="API_CoverageDateFilter_Contents"></a>

 ** endInclusive **   <a name="inspector2-Type-CoverageDateFilter-endInclusive"></a>
A timestamp representing the end of the time period to filter results by.
Type: Timestamp
Required: No

 ** startInclusive **   <a name="inspector2-Type-CoverageDateFilter-startInclusive"></a>
A timestamp representing the start of the time period to filter results by.
Type: Timestamp
Required: No
