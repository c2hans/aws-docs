# ContainerRepositoryMetadata
<a name="API_ContainerRepositoryMetadata"></a>

Contains metadata about a container repository associated with a covered resource.

## Contents
<a name="API_ContainerRepositoryMetadata_Contents"></a>

 ** name **   <a name="inspector2-Type-ContainerRepositoryMetadata-name"></a>
The name of the container repository.
Type: String
Required: No

 ** scanFrequency **   <a name="inspector2-Type-ContainerRepositoryMetadata-scanFrequency"></a>
The scan frequency for the container repository.
Type: String
Required: No
