# Ec2ConfigurationState
<a name="API_Ec2ConfigurationState"></a>

Details about the state of the EC2 scan configuration for your environment.

## Contents
<a name="API_Ec2ConfigurationState_Contents"></a>

 ** scanModeState **   <a name="inspector2-Type-Ec2ConfigurationState-scanModeState"></a>
An object that contains details about the state of the Amazon EC2 scan mode.
Type: [Ec2ScanModeState](API_Ec2ScanModeState.md) object
Required: No

 ** vmScannerState **   <a name="inspector2-Type-Ec2ConfigurationState-vmScannerState"></a>
An object that contains details about the state of the Amazon Inspector VM scanner.
Type: [VMScannerState](API_VMScannerState.md) object
Required: No
