# Cvss2
<a name="API_Cvss2"></a>

The Common Vulnerability Scoring System (CVSS) version 2 details for the vulnerability.

## Contents
<a name="API_Cvss2_Contents"></a>

 ** baseScore **   <a name="inspector2-Type-Cvss2-baseScore"></a>
The CVSS v2 base score for the vulnerability.
Type: Double
Required: No

 ** scoringVector **   <a name="inspector2-Type-Cvss2-scoringVector"></a>
The scoring vector associated with the CVSS v2 score.
Type: String
Length Constraints: Minimum length of 0.
Required: No
