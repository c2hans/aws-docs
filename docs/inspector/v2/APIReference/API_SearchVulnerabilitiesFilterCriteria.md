# SearchVulnerabilitiesFilterCriteria
<a name="API_SearchVulnerabilitiesFilterCriteria"></a>

Details on the criteria used to define the filter for a vulnerability search.

## Contents
<a name="API_SearchVulnerabilitiesFilterCriteria_Contents"></a>

 ** vulnerabilityIds **   <a name="inspector2-Type-SearchVulnerabilitiesFilterCriteria-vulnerabilityIds"></a>
The IDs for specific vulnerabilities.
Type: Array of strings
Array Members: Fixed number of 1 item.
Pattern: `CVE-[12][0-9]{3}-[0-9]{1,10}`
Required: Yes
