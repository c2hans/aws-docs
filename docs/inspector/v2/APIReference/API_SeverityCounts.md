# SeverityCounts
<a name="API_SeverityCounts"></a>

An object that contains the counts of aggregated finding per severity.

## Contents
<a name="API_SeverityCounts_Contents"></a>

 ** all **   <a name="inspector2-Type-SeverityCounts-all"></a>
The total count of findings from all severities.
Type: Long
Required: No

 ** critical **   <a name="inspector2-Type-SeverityCounts-critical"></a>
The total count of critical severity findings.
Type: Long
Required: No

 ** high **   <a name="inspector2-Type-SeverityCounts-high"></a>
The total count of high severity findings.
Type: Long
Required: No

 ** informational **   <a name="inspector2-Type-SeverityCounts-informational"></a>
The total count of informational severity findings.
Type: Long
Required: No

 ** low **   <a name="inspector2-Type-SeverityCounts-low"></a>
The total count of low severity findings.
Type: Long
Required: No

 ** medium **   <a name="inspector2-Type-SeverityCounts-medium"></a>
The total count of medium severity findings.
Type: Long
Required: No

 ** untriaged **   <a name="inspector2-Type-SeverityCounts-untriaged"></a>
The total count of untriaged findings.
Type: Long
Required: No
