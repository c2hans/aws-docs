# GitHubEnterpriseServerAppRegistrationDetail

Contains the details required to register the GitHub App on the GitHub Enterprise Server instance.

## Contents
<a name="API_GitHubEnterpriseServerAppRegistrationDetail_Contents"></a>

 ** manifestCode **   <a name="inspector2-Type-GitHubEnterpriseServerAppRegistrationDetail-manifestCode"></a>
The manifest code used to register the GitHub App on the GitHub Enterprise Server instance.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `[a-zA-Z0-9._~+/-]+`
Required: Yes
