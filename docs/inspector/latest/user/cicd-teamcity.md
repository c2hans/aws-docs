# Using the Amazon Inspector TeamCity plugin
<a name="cicd-teamcity"></a>

**Note**
 The Amazon Inspector TeamCity plugin is discontinued and archived on GitHub.

 The Amazon Inspector TeamCity plugin leverages the Amazon Inspector SBOM Generator binary and Amazon Inspector Scan API to produce detailed reports at the end of your build, so you can investigate and remediate risk before deployment. With the Amazon Inspector TeamCity plugin, you can add Amazon Inspector vulnerability scans to your TeamCity pipeline. Amazon Inspector vulnerability scans can be configured to pass or fail pipeline executions based on the number and severity of vulnerabilities detected. You can view the archived version of the Amazon Inspector TeamCity plugin on GitHub at [https://github.com/aws/amazon-inspector-container-image-scanner-teamcity-plugin](https://github.com/aws/amazon-inspector-container-image-scanner-teamcity-plugin).
