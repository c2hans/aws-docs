# Conclusion
<a name="conclusion"></a>

This guide covered requirements and provided an example configuration for using AWS Transform MGN for lift-and-shift migration of servers from secured on-premises networks to AWS over private connectivity (AWS VPN or AWS Direct Connect). This is a typical scenario for many corporate migrations. The guide also provided guidance on ways to test by using automated or manual deployment, and monitoring and troubleshooting connectivity issues if they arise.
