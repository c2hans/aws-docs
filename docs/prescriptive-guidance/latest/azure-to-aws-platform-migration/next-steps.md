# Next steps
<a name="next-steps"></a>

## Next Steps
<a name="next-steps.f088d312-6b53-5656-a257-16dba786dd48"></a>

1. **Assess your engagement scope. **Determine whether your migration assessment has sufficient scale to benefit from AI-assisted documentation.

1. **Set up the repository structure.** Run the Phase 1 prompts to create the directory structure, business domains, epics, user stories, and acceptance criteria files.

1. **Run source environment extraction.** Use the Phase 2 prompts to generate extraction scripts, then execute them against your source environment to produce the structured CSV data that feeds the entire methodology.

1. **Start with one subscription.** Run the Phase 3 cloud resource analysis prompt for a single subscription. Validate the output manually before scaling to all subscriptions.

1. **Begin transcript indexing immediately.** From the first stakeholder meeting, create companion indexes and maintain the root index. This investment compounds over the engagement.
