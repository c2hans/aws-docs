# Next steps in using Amazon Q Developer
<a name="next-steps"></a>

With the knowledge gained from this guide, you can use Amazon Q Developer effectively in your coding workflow. Install the AWS Toolkit in your preferred IDE ([Visual Studio Code](https://docs.aws.amazon.com/toolkit-for-vscode) or [JetBrains](https://docs.aws.amazon.com/toolkit-for-jetbrains/)), and begin exploring the generative AI-powered code generation and recommendations from Amazon Q Developer.

An effective way to learn more about Amazon Q Developer is to gain hands-on experience with your own code. As you integrate Amazon Q into your development lifecycle, refer to this guide for best practices, troubleshooting, and real-world examples.

Additionally, stay informed by reviewing the AWS blogs and developer guides listed in [Resources](resources.md). These resources provide the latest updates, best practices, and insights to help you get the most from Amazon Q Developer.
