# Training an image classification model
<a name="training"></a>

This section describes the different AWS services and features that you can use to train an image classification model. There are five options for training models in AWS:
+ [Amazon Rekognition](rekognition.md)
+ [Amazon Rekognition Custom Labels](rekognition-custom-labels.md)
+ [Amazon SageMaker AI Canvas](sagemaker-canvas.md)
+ [Amazon SageMaker AI endpoints](sagemaker.md)
+ [Custom training jobs](custom-training-jobs.md) in Amazon Elastic Kubernetes Service (Amazon EKS) or Amazon Elastic Container Service (Amazon ECS)
