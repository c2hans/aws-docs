# Tools
<a name="teradata-tools"></a>

Teradata offers the following tools:
+ [Teradata Vantage Console](https://docs.teradata.com/r/Teradata-VantageCloud-Enterprise/Vantage-Console) provides an integrated user experience for analysts, developers, and operations. You can start using the Vantage Console after provisioning your cloud system.
+ [Teradata Data Mover](https://www.teradata.com/Resources/Brochures/Teradata-Data-Mover) enables you to automate, control, and monitor the data movement between Teradata environments.
+ [Teradata QueryGrid](https://www.teradata.com/Products/Ecosystem-Management/IntelliSphere/QueryGrid) enables analytics across a heterogeneous analytical ecosystem.
+ [Teradata Tools and Utilities (TTU)](https://downloads.teradata.com/download/tools) provides a full collection of Teradata Client tools, including load and unload utilities, open interfaces, and connectivity drivers.
