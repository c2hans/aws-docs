# Migrating on-premises Teradata Vantage environments to Teradata VantageCloud Enterprise on AWS
<a name="introduction"></a>

*Battulga Purevragchaa, Amazon Web Services*

*Catherine Adams and Jimmy Hayes, Teradata*

This guide provides an overview of options and considerations for migrating your on-premises Teradata Vantage environment to Teradata VantageCloud Enterprise on AWS. [Teradata VantageCloud Enterprise on AWS](https://www.teradata.com/Cloud/AWS) combines the powerful and flexible analytics platform of Teradata Vantage with the global reach and scalability of AWS infrastructure. You can use this guide to gain a better understanding of the data migration process and to help you choose a data migration approach that meets your organization's business and IT requirements. The guide also includes reference architectures that you can use as templates to build your own migration architecture. This guide is intended for technical decision makers, business decision makers, and [AWS Services Partners](https://aws.amazon.com/partners/services-tiers/).
