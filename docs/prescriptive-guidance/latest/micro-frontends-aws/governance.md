# Governance

Multiple personas typically work on micro-frontends, and each one works under different constraints toward common business goals. While communication and collaboration between people are key to success, overcommunicating and implementing overly complicated processes slow the development cycle. This decreases morale and lowers quality.

Companies that successfully implement micro-frontends by using multiple teams create mechanisms to balance autonomy with alignment. They empower decision makers to take action locally and to escalate hierarchically only when needed. Mechanisms include the following:
+ [API contracts](api-contracts.md)
+ [Cross-interactivity using events](cross-interactivity.md)
+ [Balancing autonomy with alignment](balance-autonomy-alignment.md)
+ [Feature flags](feature-flags.md)
+ [Service discovery](discovery.md)
