# Phases of migration
<a name="phases"></a>

AWS migration experts approach database migration in four phases:
+ Phase 1: Prepare
+ Phase 2: Plan
+ Phase 3: Migrate
+ Phase 4: Operate and optimize the target environment

Oracle databases come in various sizes for various use cases, based on the type of application that is running. Each application has different requirements, so take these into consideration when you identify the potential migration path. The following sections discuss various scenarios that can help you decide how to proceed on your migration journey.
