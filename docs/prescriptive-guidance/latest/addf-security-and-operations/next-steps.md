# Next steps
<a name="next-steps"></a>

This guide reviewed the security and operations best practices and considerations when deploying the Autonomous Driving Data Framework (ADDF) in your AWS Cloud environment. This guide reviews the shared responsibility model between the ADDF user, the ADDF core team, and AWS so that you understand your role and responsibilities for setting up and operating ADDF securely. It also includes recommendations for operating ADDF securely through its lifecycle, including environment-specific recommendations.

We recommend that you familiarize yourself with the resources in the [Resources](resources.md) section. When you are ready, you can set up ADDF according to the instructions in the [ADDF Deployment Guide](https://github.com/awslabs/autonomous-driving-data-framework/blob/main/docs/deployment_guide.md) (GitHub).

As you set up and operate ADDF, if you think that deployment framework needs improvement or further security hardening, please contribute your changes to the ADDF repository through a pull request. For more information, see [Open-source security reviews and contributions](addf-security-review-process.md#open-source-sec-reviews).
