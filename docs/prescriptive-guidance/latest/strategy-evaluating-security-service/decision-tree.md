# Decision tree for adopting an AWS security service
<a name="decision-tree"></a>

The following image shows a decision tree that you can use to evaluate whether your organization should adopt an AWS security service. The decision tree is divided into two sections: [Company context](company-context.md) and [AWS security service evaluation](service-evaluation.md). The first section, *Company context*, is designed to evaluate your current control or solution, if it exists. You proceed to the second section, *AWS security service evaluation*, if you don't have a current solution or if your current control or solution doesn't meet your business or technical requirements. In the *AWS security service evaluation* section, you determine whether the AWS service meets those requirements.
