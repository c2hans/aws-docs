# Source and target architecture
<a name="source-and-target-architecture"></a>

The following sections describe the source and target architecture of an OpenText migration to the AWS Cloud. This includes the components of a typical OpenText Customer Experience platform implementation, the target AWS architecture, a high-level migration process, and the most common migration strategy (7 Rs) for each component type.
