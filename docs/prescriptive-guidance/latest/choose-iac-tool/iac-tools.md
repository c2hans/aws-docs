# IaC tools
<a name="iac-tools"></a>

This guide explores five different IaC tools that can be used to provision AWS resources. It compares these tools and guides you through the process of choosing one that meets the needs of your team, organization, and cloud talent. The key is to align the chosen IaC tool with your organization goals and the skillsets of your developers.

In this section, you learn more about how each tool works and about its advantages and disadvantages. For example, some tools can only be used in the AWS Cloud, and they're not well suited for multi-cloud or hybrid-cloud deployments. Others require knowledge of specialized programming languages, and others support common programming languages. Evaluate the advantages and disadvantages of each tool, and consider what would be the best fit for your organization.

This section discusses the following IaC tools:
+ [AWS CloudFormation](cloudformation.md)
+ [AWS Serverless Application Model (AWS SAM)](aws-sam.md)
+ [AWS Cloud Development Kit (AWS CDK)](aws-cdk.md)
+ [HashiCorp Terraform](terraform.md)
+ [Pulumi](pulumi.md)
