# Objectives and benefits
<a name="targeted-business-outcomes"></a>

By implementing the configuration set up in this guide, you can achieve the following outcomes:
+ An Amazon VPC IP Address Manager (IPAM) that manages the entire organization's CIDRs
+ A hub-and-spoke networking model configured with AWS Transit Gateway
+ A network firewall for inspecting traffic
+ A single entry point for all applications through a centralized inbound endpoint in a network firewall
+ A single VPC exit for internet traffic
+ A single place where you can manage DNS resolution
+ Improved security across your organization
+ A single place where you can control the routing of traffic across the entire organization
+ Secure access to VPC endpoints
