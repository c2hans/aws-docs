# AWS storage for VMware professionals
<a name="introduction"></a>

*Phani Lingamallu and Hakan Yildirim, Amazon Web Services*

Moving from VMware to AWS requires both technical and organizational changes. While AWS provides operational benefits, organizations typically face two main challenges: helping teams learn new technical skills and managing organizational changes. Success depends on training your workforce and adjusting your operational processes. To help with this transition, start by assessing your team's current skills, creating a training plan, and developing processes that support cloud operations.

## Intended audience
<a name="intended-audience"></a>

This guide helps VMware professionals, storage administrators, cloud architects, and operations personnel migrate their IT infrastructure to AWS. To use this guide, you need experience with storage technologies and tools for managing on-premises infrastructure.

## Objectives
<a name="objectives"></a>

This guide provides a comprehensive approach for how to use AWS storage services and migrate VMware workloads from on-premises environments to the AWS Cloud. It also helps VMware administrators understand AWS storage options and explains how to scale resources and manage costs.
