# FAQ
<a name="faq"></a>

## Do all supply chains use the same metrics?
<a name="q1"></a>

No, many supply chains use the same metrics, but not all. This is because each organization sets up their supply chain differently, and organizations might prioritize different metrics based on their business objectives.

## When using currencies in calculations, such as for cost or price, how can I verify that I have the correct values?
<a name="q2"></a>

In general, verifying with your finance team is the best way to clarify which currency value should be used.
