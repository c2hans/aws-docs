# Document history
<a name="doc-history"></a>

The following table describes significant changes to this strategy.

|
|
| **Change** | **Description** | **Date** |
| --- |--- |--- |
| Removed CloudEndure Migration service | We removed references to the CloudEndure Migration service. AWS Transform MGN is the primary migration service recommended for lift-and-shift migrations to the AWS Cloud. | May 11, 2022 |
| Updated name of AWS solution | We updated the name of the referenced AWS solution from *CloudEndure Migration Factory* to *Cloud Migration Factory*. | May 2, 2022 |
| Updated resources | We updated the *Introduction* and [Resources](resources.md) sections with the latest documents in the large migration series. | March 8, 2022 |
| Initial publication | — | September 16, 2021 |
