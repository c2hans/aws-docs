# Next steps
<a name="whats-next"></a>

The process described in this guide helps you identify and prioritize database candidates that you can migrate to open-source database engines such as PostgreSQL or MySQL with minimal effort. After you have the list of databases, you can plan the migration. For more information, follow the links in the [Resources](resources.md) section.

Database migration can be a challenging project that requires expertise and tools. You can accelerate your migration and time to results through partnership. [AWS Database Migration Service Partners](https://aws.amazon.com/dms/partners/) have the required expertise to help customers migrate to the cloud easily and securely. These Partners have the expertise for both homogeneous migrations such as Oracle to Oracle, and heterogeneous migrations between different database platforms, such as Oracle to Amazon Aurora or Microsoft SQL Server to MySQL.

Based on your requirements and preferences, you can use AWS Partners to handle the complete migration or to help with only some aspects of the migration. In addition, you can use tools and solutions provided by AWS Partners to help with the migration. For a complete catalog of migration tools and solutions, see [AWS Partner tools and solutions](https://docs.aws.amazon.com/prescriptive-guidance/latest/migration-tools/partner-tools.html).
