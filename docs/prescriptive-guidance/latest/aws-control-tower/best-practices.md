# Best practices
<a name="best-practices"></a>

The following best practices and use cases can help you as you work with AWS Control Tower.
+ If you have a use case in mind but are not sure where to start, choose **Get personalized guidance** on the AWS Control Tower dashboard.
+ Set up repeatable and manageable patterns for networks in AWS.
+ Extend your security posture, integrate with external or existing identity providers, and centralize logging systems.
+ Use other AWS services, such as [AWS Application Migration Service](https://aws.amazon.com/application-migration-service/), with AWS Control Tower to assist in workload migration.
