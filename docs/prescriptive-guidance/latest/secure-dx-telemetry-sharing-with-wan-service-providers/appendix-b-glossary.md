# Appendix B: Glossary
+ **BGP: **Border Gateway Protocol — Dynamic routing protocol used for Direct Connect peering.
+ **CPO: **Cloud Provisioning Office — Entity managing cloud service provisioning in isolated partition environments.
+ **DX: **Direct Connect — AWS service providing dedicated, private network connections from customer premises to AWS.
+ **ESP: **Enterprise Service Provider — Organization providing managed network services to the customer.
+ **ExternalId: **A unique, customer-specific value used in IAM trust policies to mitigate the confused deputy problem during cross-account role assumption. AWS does not treat the ExternalId as a secret.
+ **LAG: **Link Aggregation Group — Multiple Direct Connect connections bundled together for increased bandwidth and redundancy.
+ **MTTR: **Mean Time to Recovery — The average elapsed time from incident detection to service restoration.
+ **NHI: **Network Health Indicator — A CloudWatch Network Synthetic Monitor metric that isolates fault location (AWS vs. on-premises).
+ **OAM: **Observability Access Manager — AWS service for configuring CloudWatch cross-account observability between monitoring and source accounts.
+ **VIF: **Virtual Interface — A logical connection provisioned over a physical Direct Connect connection (private, public, or transit).
+ **WSP: **WAN Service Provider — Organization providing wide-area network transport and connectivity services.
