# Key dependencies and risks
<a name="key-dependencies-and-risks"></a>

Consider the following dependencies that might delay migration.

|
|
| Dependency | Impact if delayed |
| --- |--- |
| AWS account access and permissions | Blocks environment setup |
| Application owner availability | Delays dependency mapping |
| Network connectivity establishment | Blocks integration testing |
| Security team sign-offs | Blocks go-live |
| Change advisory board approvals | Delays cutover scheduling |
