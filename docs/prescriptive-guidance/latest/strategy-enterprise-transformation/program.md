# AWS Enterprise Transformation program
<a name="program"></a>

The AWS Enterprise Transformation program follows the cloud journey lifecycle, and is based on best practices and lessons learned from AWScustomers and industries. The program is anchored and tailored to your organization's cloud transformation success to date. It uses the AWS Enterprise Transformation Framework to guide you in developing organizational alignment between IT and lines of business, and applying best practices and mechanisms for business strategy, culture, people, operations, and cloud financial management.

Setting a solid foundation with measurable key performance indicators (KPIs) is critical to program success. The program begins with a *Prioritize* phase, where you conduct rapid transformation readiness discovery to produce a strategic program business objective and a high-level plan. This is followed by a *Ready* phase, where you validate the plan through experimentation, identify success patterns, and produce a detailed roadmap. This leads you to an *Enable* phase, where you implement the roadmap and operationalize new ways of working. You then move into a *Transform* phase, where you replicate success patterns for scale, and build lasting digital culture capabilities for sustained innovation.
