# Applying the AWS Well-Architected Framework to Amazon WorkSpaces Applications
<a name="introduction"></a>

*Mohamed Wali, Amazon Web Services*

This guide covers best practices for applying the [AWS Well-Architected Framework ](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html)when you use [Amazon WorkSpaces Applications](https://aws.amazon.com/appstream2/). WorkSpaces Applications is a fully managed application streaming service that enables you to stream desktop applications to users without rewriting them.

The AWS Well-Architected Framework helps cloud architects build secure, high-performing, resilient, and efficient infrastructures for a variety of applications and workloads. It also provides a consistent approach for users and AWS Partners to evaluate architectures and implement scalable designs.

The AWS Well-Architected Framework is built around six pillars:
+ Operational excellence
+ Security
+ Reliability
+ Performance efficiency
+ Cost optimization
+ Sustainability

This guide discusses how these pillars and best practices apply to using WorkSpaces Applications.

## Intended audience
<a name="audience"></a>

This guide is for:
+ Cloud architects and engineers who design and implement WorkSpaces Applications solutions, and need to ensure that their architectures follow AWS Well-Architected Framework best practices.
+ IT operations teams that manage and maintain WorkSpaces Applications environments; handle fleet management, scaling, and monitoring; and need to optimize costs and performance.
+ Organizations or businesses that are considering or already using WorkSpaces Applications, want to stream desktop applications to their users, and need to build secure, high-performing, resilient, and efficient infrastructures.

## Objectives
<a name="objectives"></a>

Following the best practices in this guide helps you:
+ Build a secure, high-performing, resilient, and efficient infrastructure for streaming desktop applications in the AWS Cloud.
+ Apply a consistent approach when evaluating WorkSpaces Applications architectures and implementing scalable designs.
