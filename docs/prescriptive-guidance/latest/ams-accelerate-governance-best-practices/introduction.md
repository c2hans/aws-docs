# AMS Accelerate operations plan governance best practices
<a name="introduction"></a>

*Marta Tari, Amazon Web Services*

This guide covers governance best practices for the [AWS Managed Services (AMS) Accelerate operations plan](https://docs.aws.amazon.com/managedservices/latest/accelerate-guide/what-is-ams-op-plans.html#what-is-ams-op-plans-acc). It also outlines the key differences in governance responsibilities between the [AWS Support](https://aws.amazon.com/premiumsupport/?nc=sn&loc=0) and [AMS Accelerate](https://docs.aws.amazon.com/managedservices/latest/accelerate-guide/what-is-acc.html) support models.

**Note**
For information about the AMS Advanced operations plan, see [AMS Advanced operations plan](https://docs.aws.amazon.com/managedservices/latest/accelerate-guide/what-is-ams-op-plans.html#what-is-ams-op-plans-ams) in the *AMS Advanced User Guide*.

## Targeted business outcomes
<a name="overview"></a>

This guide helps you understand and follow the governance best practices for the AMS Accelerate operations plan. It also helps you understand the governance responsibility differences between the AWS Support and AMS Accelerate support models.
