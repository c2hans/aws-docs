# FAQ
<a name="faq"></a>

## What languages does AMS Accelerate support?
<a name="what-languages-does-ams-accelerate-support-.7f9a4dac-8284-5e46-9a26-77f0bef12f46"></a>

AMS Accelerate support is currently provided in English only.

## How do AWS Partners and AMS work together?
<a name="how-do-aws-partners-and-ams-work-together-.0d09abfb-eceb-5b6d-8770-365a9a98dffc"></a>

AMS provides AWS Partners infrastructure management and helps them to scale their operations through automation. AMS works closely with AWS Partners in the majority of customer engagements to provide end-to-end cloud solutions, such as migration consulting and application management.

**Note**
 For answers to other frequently asked questions about AMS, see [AWS Managed Services FAQs](https://aws.amazon.com/managed-services/faqs/). If you're looking for a single vendor to provide both application and infrastructure management, [contact an AWS Partner](https://aws.amazon.com/managed-services/partners/).
