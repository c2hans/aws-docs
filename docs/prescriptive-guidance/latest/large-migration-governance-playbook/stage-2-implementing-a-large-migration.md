# Stage 2: Implementing a large migration
<a name="stage-2-implementing-a-large-migration"></a>

In the previous stage, you established all of the tools, templates, plans, and processes that you need to govern the migration. In this stage, you use those assets to effectively manage and oversee the migration. This stage begins when the migration team begins migrating waves to the AWS Cloud. You repeat the gates in this stage for each wave or for a group of sequential waves.

Stage 2 consists of the following tasks:
+ [Task: Schedule recurring meetings](task-schedule-meetings-stage2.md)
+ [Task: Completing the communication gates](task-follow-communication-gates.md)
  + [Gate 1: Create T-minus schedule for the wave](task-follow-communication-gates.md#gate-tminus-schedule)
  + [Gate 2: T-28 commit meeting](task-follow-communication-gates.md#gate-t28)
  + [Gate 3: T-21 communication](task-follow-communication-gates.md#gate-t21)
  + [Gate 4: T-14 checkpoint meeting](task-follow-communication-gates.md#gate-t14)
  + [Gate 5: T-7 communication](task-follow-communication-gates.md#gate-t7)
  + [Gate 6: T-1 go or no-go meeting](task-follow-communication-gates.md#gate-t1)
  + [Gate 7: T-0 cutover meeting](task-follow-communication-gates.md#gate-t0)
  + [Gate 8: Hypercare period start](task-follow-communication-gates.md#gate-hypercare-start)
  + [Gate 9: Hypercare period end](task-follow-communication-gates.md#gate-hypercare-end)
