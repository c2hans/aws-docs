# Namespace resource quotas (prevent waste)
<a name="namespace-resource-quotas-prevent-waste"></a>

Cap resource consumption per namespace to prevent any single team or environment from over-provisioning and inflating cluster-wide costs. For sample commands to Namespace resource quota to cap consumption and prevent over-provisioning, see [this GitHub repository](https://github.com/aws-samples/sample-eks-cost-optimization-guide/blob/main/10-additional-strategies/namespace-resource-quota.yaml)
