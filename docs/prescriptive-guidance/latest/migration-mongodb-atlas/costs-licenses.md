# Costs and licensing
<a name="costs-licenses"></a>

The pricing for MongoDB Atlas includes the following costs:
+ Cluster configuration costs
+ Data transfer costs
+ Costs for subscriptions and additional services
+ Backup costs

For more information, see [Manage Billing](https://docs.atlas.mongodb.com/billing/) in the MongoDB documentation.

MongoDB Atlas can be purchased directly from AWS Marketplace, which simplifies the billing process. You can choose from the following MongoDB offerings in AWS Marketplace:
+ [MongoDB Atlas (pay-as-you-go)](https://aws.amazon.com/marketplace/pp/prodview-pp445qepfdy34?sr=0-2&ref_=beagle&applicationId=AWSMPContessa)
+ [MongoDB Atlas for Government (US)](https://www.mongodb.com/products/platform/atlas-for-government)
+ [MongoDB Enterprise Advanced for AWS GovCloud](https://aws.amazon.com/marketplace/pp/prodview-izui66iqhb7ue?sr=0-3&ref_=beagle&applicationId=AWSMPContessa)
+ [MongoDB Professional Services](https://aws.amazon.com/marketplace/pp/prodview-hdelmkf7yknny?sr=0-1&ref_=beagle&applicationId=AWSMPContessa)
