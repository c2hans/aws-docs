# Network capacity planning for large VDI migrations
<a name="network-capacity-planning"></a>

Large-scale VDI deployments can add a significant amount of network traffic to resources deployed in the AWS Cloud and on premises. This includes traffic generated by:
+ Microsoft Active Directory
+ Logging and monitoring
+ Application traffic
+ Operating system (OS) and software patching
+ Access to file servers
+ Remote connections from VDI to other resources
+ Email and internet activities from VDI users

Depending on your network configuration, some or all of this traffic can route back to on premises. This adds networking load to [AWS Direct Connect](https://docs.aws.amazon.com/directconnect/latest/UserGuide/Welcome.html) or VPN connections, firewalls, and other network equipment in the path.

Define a base-load network capacity profile for a VDI. Work with the networking team to develop a capacity plan. This helps you avoid any bottlenecks or other negative effects to network traffic to other applications over the same cloud connection.

Repeating spike events, such as patch day or malware signature updates, should be taken into consideration. If possible, evaluate a rolling deployment for these events.
