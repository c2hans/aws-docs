# Governance and access control
<a name="governance"></a>

Apache Iceberg integrates with AWS Lake Formation to simplify data governance. This integration allows data lake administrators to assign cell-level access permissions to Iceberg tables. For an example of querying Iceberg tables by using Amazon Athena and AWS Lake Formation, see the AWS blog post [Interact with Apache Iceberg tables using Amazon Athena and cross account fine-grained permissions using AWS Lake Formation](https://aws.amazon.com/blogs/big-data/interact-with-apache-iceberg-tables-using-amazon-athena-and-cross-account-fine-grained-permissions-using-aws-lake-formation/).
