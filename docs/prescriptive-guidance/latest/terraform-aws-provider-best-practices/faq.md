# FAQ
<a name="faq"></a>

**Q. **Why focus on the AWS Provider?

**A.** The AWS Provider is a widely used and complex provider for provisioning infrastructure in Terraform. Following these best practices helps you optimize your use of the provider in the AWS environment.

**Q. **I'm new to Terraform. Can I use this guide?

**A.** The guide is for people who are new to Terraform as well as more advanced practitioners who want to expand their skills. The practices improve workflows for users at any stage of learning.

**Q.** What are some key best practices covered?

**A.** Key best practices include [using IAM roles over access keys](https://docs.aws.amazon.com/prescriptive-guidance/latest/terraform-aws-provider-best-practices/security.html#iam-roles), [pinning versions](https://docs.aws.amazon.com/prescriptive-guidance/latest/terraform-aws-provider-best-practices/version.html#version-check), [automated testing](https://docs.aws.amazon.com/prescriptive-guidance/latest/terraform-aws-provider-best-practices/best-practices-for-testing.html), [remote state locking](https://docs.aws.amazon.com/prescriptive-guidance/latest/terraform-aws-provider-best-practices/backend.html#amazon-s3), [credential rotation](https://docs.aws.amazon.com/prescriptive-guidance/latest/terraform-aws-provider-best-practices/security.html#continuous-monitoring), [contributing back to providers](https://docs.aws.amazon.com/prescriptive-guidance/latest/terraform-aws-provider-best-practices/version.html#contribute-providers), and [logically organizing code bases](https://docs.aws.amazon.com/prescriptive-guidance/latest/terraform-aws-provider-best-practices/structure.html).

**Q.** Where can I learn more about Terraform?

**A.** The [Resources](resources.md) section includes links to the official HashiCorp Terraform documentation and community forums. Use the links to learn more about advanced Terraform workflows.
