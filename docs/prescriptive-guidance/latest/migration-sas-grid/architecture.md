# Architecture
<a name="architecture"></a>

Building the appropriate SAS Grid architecture is a critical step to ensure that migration and performance will meet your users' expectations. For your migration effort to meet this guide's assumptions, the target environment for SAS Grid Manager on AWS must be an equivalent match in terms of operating system and software versions as well as major machine specifications.
