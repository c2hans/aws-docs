# Migration phases
<a name="migration-phases"></a>

This guide covers migrating both Oracle single-instance databases and Oracle Real Application Clusters (Oracle RAC) databases as the source and target. If the source and target are Oracle RAC, you can increase the parallelism for each migration step.
