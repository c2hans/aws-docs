# Key challenges in a cloud adoption journey
<a name="cloud-transformation-challenges"></a>

According to [Digital Transformation Is Not About Technology](https://hbr.org/2019/03/digital-transformation-is-not-about-technology) (Harvard Business Review), almost 70% of investments spent on digital transformation are estimated to go to waste. Decision makers and executives can become paralyzed by choice when formulating their digital and cloud strategy. They might find that they are unsure of where to start or how comprehensive to make their cloud adoption strategy. Sometimes, they can't clearly articulate the value that the cloud can bring to their organization and customers, or they don't know how to shape their organization's operations around the cloud. The following are some of the key challenges that decision makers face when migrating to cloud. These challenges are organized by their corresponding AWS Cloud Adoption Framework (AWS CAF) perspectives.

|
|
| AWS CAF perspective | Challenges and questions |
| --- |--- |
| Business | + Should I scale existing businesses? Should I create new business models or revenue streams by experimenting with new technologies?<br />+ What transformation levers can maximize ROI from the cloud adoption journey? |
| People | + How do I reorganize my workforce to facilitate successful migration or modernization of workloads?<br />+ How do I equip my business and IT workforce to understand the capabilities of the cloud? How can I help them upskill? |
| Governance<br />  | + How should we assess gaps in the current governance framework to unlock the potential in the cloud?<br />+ What mechanisms should I set up to track, control, and charge back costs associated with the cloud adoption journey? What approach helps my organization build governance at scale? |
| Platform<br />  | + Which migration strategies, such as rehost, refactor, or retire, should I pick for each workload? If I decide to use a hybrid cloud model, how do I integrate on-premises workloads with workloads in the cloud?<br />+ What is the right modernization approach?<br />+ I want to modernize a monolithic application to a software as a service (SaaS) application. How should I proceed? |
| Security<br />  | + How do I assess security vulnerabilities in a cloud environment?<br />+ How do I establish security guardrails that help protect data in the cloud and help my organization meet regulatory, compliance, and security requirements? How do we take advantage of cloud technologies that can proactively detect security risks? |
| Operations<br />  | + How do I manage operations seamlessly in a hybrid cloud environment?<br />+ How do I use cloud-native capabilities and automations so that I don't operate workloads as if they were in an on-premises data center? |
