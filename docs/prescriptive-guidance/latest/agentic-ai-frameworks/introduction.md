# Agentic AI frameworks, platforms, protocols, and tools on AWS
<a name="introduction"></a>

*Aaron Sempf, Joshua Samuel, and Ansley Verzosa, Amazon Web Services*

Agentic AI is a paradigm at the intersection of AI, distributed systems, and software engineering. It's a class of intelligent systems composed of autonomous, asynchronous software agents that use AI models and integrate with tools and resources. The agents exhibit agency: they perceive context, reason over goals, make decisions, and take purposeful actions on behalf of users or systems. These agents operate independently, often collaboratively, within distributed environments and are designed to pursue delegated objectives with embedded intelligence, memory, and intent.

On AWS, organizations can use agentic AI to automate complex workflows, enhance decision-making, and create more responsive systems. This guide describes the key components that you need to build agentic AI solutions:
+ [Frameworks](frameworks.md) profiles current agentic AI frameworks, including reviews of their benefits and use cases. Learn how these frameworks reduce undifferentiated heavy lifting across patterns, protocols, and tools. Understand key selection criteria to choose the right framework for your requirements.
+ [Platforms](agentic-ai-platforms.md) provides an overview of agentic AI platforms (managed agent, open source orchestration, and hybrid) and considerations for selection or design.
+ [Protocols](agentic-protocols.md) explores standardized communication protocols for agent interactions. Agent-to-agent protocols are emerging, such as the open source Model Context Protocol (MCP) and Agent2Agent (A2A), along with other proprietary implementations. Discover how common protocols enable different agents to interact.
+ [Tools](tools.md) provides information about protocol-based tools, framework-native tools, and meta-tools. Organizations can build a toolkit that integrates with the key systems in their workflows, enabling both end-user and server-based agentic workflows.

## Intended audience
<a name="intended-audience"></a>

This guide is for architects, developers, and technology leaders who want to use AI-driven software agents in cloud-native applications.

## Objectives
<a name="objectives"></a>

This guide helps you do the following:
+ Compare agentic AI frameworks to select the one that meets your use case requirements.
+ Learn about agentic AI services that provide capabilities to turn individual agents into coordinated, adaptive systems.
+ Understand the advantages of open protocols for building sustainable agentic AI architectures.
+ Create a tool integration strategy that meets your requirements when you build agent systems.
