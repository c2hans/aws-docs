# Best practices and recommendations
<a name="network-best-practices-and-recommendations"></a>

1. **Zero trust networking** – Verify every network connection, even within your Amazon VPC

1. **Micro-segmentation** – Isolate AI workloads in dedicated network segments.

1. **Continuous monitoring** – Monitor all network traffic for anomalies and policy violations.

1. **Regular testing** – Conduct network penetration testing specific to AI workloads.

1. **Documentation** – Maintain network diagrams and security control documentation.
