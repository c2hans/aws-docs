# FAQ
<a name="faq"></a>

## Can I apply Lambda event filtering and partial batch responses to my existing Lambda and Amazon SQS application?
<a name="can-i-apply-lambda-event-filtering-and-partial-batch-responses-to-my-existing-lambda-and-amazon-sqs-application-.c53d238f-7457-5132-84ae-61ea5ed3e6a9"></a>

Yes, just make sure that you follow the implementation best practices outlined in this guide.

## Are the Lambda event filtering and partial batch responses features limited to specific programming languages?
<a name="are-the-lambda-event-filtering-and-partial-batch-responses-features-limited-to-specific-programming-languages-.5f1a1c90-087d-506f-af7b-5cf1516aad0d"></a>

No, the features discussed in this guide are supported in any programming language that Lambda currently supports.

## Can I use these features with the AWS Cloud Development Kit (AWS CDK)?
<a name="can-i-use-these-features-with-the-aws-cloud-development-kit--aws-cdk--.88b6f058-86bf-5527-af37-2ae8672ce1e2"></a>

Yes, all of the features described in this guide are supported by the AWS CDK.
