# Targeted business outcomes
<a name="targeted-business-outcomes"></a>

This guide can help you and your organization achieve the following objectives:
+ Set up an enterprise-level design pattern that can help you align your IaC and EDP implementations as part of your AWS Cloud journey.
+ Keep code repository resources and physical resources in sync with each other in the AWS Cloud.
+ Seamlessly integrate your DevOps and production monitoring teams so that you can avoid blind spots related to resource creation and updates in AWS CloudFormation.
+ Save time by quickly restoring applications to a working state and avoid the financial costs caused by a service outage.
+ Enforce strict security for production systems involving automation.
+ Achieve higher system availability by using automated responses that meet real-time requirements.
