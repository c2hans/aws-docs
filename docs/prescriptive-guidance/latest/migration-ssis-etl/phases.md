# Migration phases
<a name="phases"></a>

Migrating SSIS ETL processes to the AWS Cloud consists of four major phases: discover, analyze, determine approach, and implement.

![Four phases of migrating SSIS ETL processes to AWS](http://docs.aws.amazon.com/prescriptive-guidance/latest/migration-ssis-etl/images/guide-img/ae5b08b7-f641-4524-9650-6ac5a0f71dd9/images/b4264807-d303-4287-8dc8-7e196967a486.png)

These phases are discussed in the following sections:
+ [Discovery phase](discover.md)
+ [Analysis phase](analyze.md)
+ [Determining the migration approach](approach.md)
+ [Implementation phase](implement.md)
