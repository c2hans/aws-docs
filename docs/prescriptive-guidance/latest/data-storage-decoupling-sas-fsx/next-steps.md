# Next steps
<a name="next-steps"></a>

We recommend that you take the following next steps to decouple your data storage from your SAS servers:

1. Monitor your SAS application to understand usage pattern and data volumes.

1. Understand how Amazon FSx for Windows File Server works and its cost structure.

1. Plan sufficient time for pre-migration testing.

1. Plan for a maintenance window to complete the migration.
