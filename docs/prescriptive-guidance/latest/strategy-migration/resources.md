# Resources
<a name="resources"></a>

## Guides
<a name="guides"></a>

The following guides on the AWS Prescriptive Guidance website provide more information about the technical and non-technical aspects of accelerating your migration to the cloud at scale.
+ [Evaluating migration readiness](https://docs.aws.amazon.com/prescriptive-guidance/latest/migration-readiness/)
+ [Application portfolio assessment guide for AWS Cloud migration](https://docs.aws.amazon.com/prescriptive-guidance/latest/application-portfolio-assessment-guide/)
+ [Tools for migrating to the ](https://docs.aws.amazon.com/prescriptive-guidance/latest/migration-tools/)AWS Cloud
+ [Setting up an agile program to accelerate cloud migrations](https://docs.aws.amazon.com/prescriptive-guidance/latest/migration-program-implementation/)
+ [Setting up a secure and scalable multi-account AWS environment](https://docs.aws.amazon.com/prescriptive-guidance/latest/migration-aws-environment/)
+ [Modernizing operations in the cloud](https://docs.aws.amazon.com/prescriptive-guidance/latest/migration-operations-integration/)
+ [Accelerating cloud adoption through culture, change, and leadership](https://docs.aws.amazon.com/prescriptive-guidance/latest/migration-ocm/)

## Patterns
<a name="patterns"></a>

AWS Prescriptive Guidance patterns provide tools, architectures, and step-by-step guidance for implementing the methodologies for the migration strategy. You'll also find patterns that support other initiatives, such as cloud-native or security projects. You can [view all patterns](https://docs.aws.amazon.com/prescriptive-guidance/latest/patterns/) or use the filtering options and search query field on the [AWS Prescriptive Guidance website](https://aws.amazon.com/prescriptive-guidance/) to find patterns of interest.
