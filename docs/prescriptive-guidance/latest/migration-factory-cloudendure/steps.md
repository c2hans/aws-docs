# The Cloud Migration Factory migration process
<a name="steps"></a>

The Cloud Migration Factory process consists of five main steps. These are discussed in the following sections:
+ [Step 1. Prepare the CSV file and import the data into Cloud Migration Factory](step1.md)
+ [Step 2. Build the servers](step2.md)
+ [Step 3. Validate the migration](step3.md)
+ [Step 4. Perform migration boot-up testing](step4.md)
+ [Step 5. Cut over to the new server instances on AWS](step5.md)

**Important**
The automation scripts for the migration steps described in this guide require Cloud Migration Factory. To get Cloud Migration Factory, see the [AWS Cloud Migration Factory Solution](https://aws.amazon.com/solutions/implementations/cloud-migration-factory-on-aws/)** **on the AWS Solutions website. If you have any questions, email AWS Professional Services at *migration-factory-support@amazon.com*.
