# Identity management and access control
<a name="identity-management"></a>

This first step when transitioning to a multi-account architecture is to set up your new account structure within an organization. Then you can add users and configure their access to the accounts. This section describes approaches for managing human access into multiple AWS account and consists of the following tasks:

1. [Set up an organization](set-up-organization.md)

1. [Create a landing zone](create-landing-zone.md)

1. [Add organizational units](add-organizational-units.md)

1. [Add initial users](add-initial-users.md)

1. [Manage member accounts](manage-member-accounts.md)
