# Best practices
<a name="best-practices"></a>

When implementing a wave-based refactoring approach, it's a best practice to do the following:
+ Make sure that your organization's business subject-matter experts are involved with the decision-making process from the start.
+ Make sure that you share the capability matrix that's created during the discovery phase in a way that allows multiple teams to reference and update the spreadsheet.
+ Establish a clear timeline for completing each phase of the process.
