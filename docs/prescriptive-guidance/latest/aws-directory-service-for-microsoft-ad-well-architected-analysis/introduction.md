# Best practices for applying the AWS Well-Architected Framework to AWS Managed Microsoft AD
<a name="introduction"></a>

*Mohamed Wali, Amazon Web Services*

## Overview
<a name="overview"></a>

This guide covers best practices for applying the [AWS Well-Architected Framework](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html) when using [AWS Directory Service for Microsoft Active Directory](https://docs.aws.amazon.com/directoryservice/latest/admin-guide/directory_microsoft_ad.html) (AWS Managed Microsoft AD).

This framework helps cloud architects build secure, high-performing, resilient, and efficient infrastructure for a variety of applications and workloads. It also provides a consistent approach for customers and AWS Partners to evaluate architectures and implement scalable designs.

The AWS Well-Architected Framework is built around six pillars:
+ Operational excellence
+ Security
+ Reliability
+ Performance efficiency
+ Cost optimization
+ Sustainability

## Targeted business outcomes
<a name="targeted-business-outcomes"></a>

This guide helps you do the following:
+ Build secure, high-performing, resilient, and efficient infrastructure for running directory-aware workloads in the AWS Cloud.
+ Apply a consistent approach when evaluating AWS Managed Microsoft AD architectures and implementing scalable designs.
