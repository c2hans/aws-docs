# Storage
<a name="storage-main"></a>

Choosing the right storage for your Microsoft workloads is a critical architectural decision. As part of the decision-making process, we recommend that you develop a storage plan and determine functional requirements for your applications and services. This section provides an overview of the following storage options that could factor into your planning:
+ [Amazon Elastic Block Store (Amazon EBS)](storage-main-ebs.md)
+ [Amazon FSx](storage-fsx.md)
+ [AWS Storage Gateway](storage-main-storage-gateway.md)
