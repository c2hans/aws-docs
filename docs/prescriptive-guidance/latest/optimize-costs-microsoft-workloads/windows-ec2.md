# Windows on Amazon EC2
<a name="windows-ec2"></a>

[Amazon Elastic Compute Cloud (Amazon EC2)](https://aws.amazon.com/ec2/) is a flexible and scalable cloud computing service that's designed for running your Windows workloads. You can use Amazon EC2 to deploy, manage, and scale your Windows Server workloads on the secure, reliable, highly available, and adaptable infrastructure of the AWS Cloud. Consider the following key benefits of running Windows workloads on Amazon EC2:
+ **Scalability** – Amazon EC2 enables you to scale your Windows workloads to accommodate changing requirements. You can create new Amazon EC2 instances to handle increased demand, and terminate the instances when you no longer need them. You pay only for the resources that you use.
+ **Flexibility** – Windows on Amazon EC2 supports a wide range of instance types for various workload requirements, from general-purpose instances to memory-optimized or compute-optimized instances. This flexibility helps you choose an instance type that fits your specific Windows-based applications, so you can improve performance and reduce costs.
+ **Security** – AWS provides multiple layers of security for your Windows workloads, including network firewalls, data encryption, and access controls. These features help you protect your applications and data, and you control your security settings and configurations.
+ **Cost efficiency** – The pay-as-you-go pricing model enables you to pay only for the resources that you use, which reduces the need for upfront investments in hardware and software. This model also helps you optimize your costs, reduce capital expenditures, and increase operational efficiency. It's a pricing model that can suit businesses of many sizes.
