## Tools
<a name="tools.a2b1da9a-6084-50e0-88d5-5604875345bd"></a>
+ [AWS CodeBuild](https://docs.aws.amazon.com/codebuild/latest/userguide/welcome.html) and [AWS CodePipeline](https://docs.aws.amazon.com/codepipeline/latest/userguide/welcome.html) help you build continuous integration and continuous development (CI/CD) pipelines on the AWS Cloud.
+ [AWS DataSync](https://docs.aws.amazon.com/datasync/latest/userguide/what-is-datasync.html) – DataSync helps replicate on-premises file stores to the AWS Cloud.
+ [AWS DMS ](https://docs.aws.amazon.com/dms/latest/userguide/Welcome.html)– AWS Database Migration Service (AWS DMS) helps replicate data from on-premises databases to Amazon RDS databases or databases on Amazon EC2.
+ [AWS Systems Manager-based automated upgrades](https://docs.aws.amazon.com/AWSEC2/latest/WindowsGuide/automated-upgrades.html) help upgrade Windows 2008 and SQL Server 2008 on the AWS Cloud.
+ [AWS SCT](https://docs.aws.amazon.com/SchemaConversionTool/latest/userguide/CHAP_Welcome.html) – AWS Schema Conversion Tool helps convert database schema from commercial to open-source databases.
+ [Application Migration Service](https://docs.aws.amazon.com/mgn/latest/ug/what-is-application-migration-service.html) – AWS Application Migration Service is a highly automated lift-and-shift (rehost) solution that simplifies, expedites, and reduces the cost of migrating applications to AWS.
+ [Windows to Linux replatforming assistant for Microsoft SQL Server databases](https://docs.aws.amazon.com/AWSEC2/latest/WindowsGuide/replatform-sql-server.html) is a replatforming tool.
