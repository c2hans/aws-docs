# Events, logs, and audit trails
<a name="events-logs-audit"></a>

Monitoring DB [instance metrics](database-instance-monitoring.md) and [OS metrics](os-monitoring.md), analyzing the trends and comparing metrics to baseline values, and generating alerts when values breach defined thresholds are all necessary and best practices that help you achieve and maintain the reliability, availability, performance, and security of your Amazon RDS DB instances. However, a complete solution must also monitor database events, log files, and audit trails of MySQL and MariaDB databases.
