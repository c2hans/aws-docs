# DeleteFileEntry
<a name="API_DeleteFileEntry"></a>

A file that is deleted as part of a commit.

## Contents
<a name="API_DeleteFileEntry_Contents"></a>

 ** filePath **   <a name="CodeCommit-Type-DeleteFileEntry-filePath"></a>
The full path of the file to be deleted, including the name of the file.
Type: String
Required: Yes
