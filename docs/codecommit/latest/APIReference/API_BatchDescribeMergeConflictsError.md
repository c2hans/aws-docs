# BatchDescribeMergeConflictsError
<a name="API_BatchDescribeMergeConflictsError"></a>

Returns information about errors in a BatchDescribeMergeConflicts operation.

## Contents
<a name="API_BatchDescribeMergeConflictsError_Contents"></a>

 ** exceptionName **   <a name="CodeCommit-Type-BatchDescribeMergeConflictsError-exceptionName"></a>
The name of the exception.
Type: String
Required: Yes

 ** filePath **   <a name="CodeCommit-Type-BatchDescribeMergeConflictsError-filePath"></a>
The path to the file.
Type: String
Required: Yes

 ** message **   <a name="CodeCommit-Type-BatchDescribeMergeConflictsError-message"></a>
The message provided by the exception.
Type: String
Required: Yes
