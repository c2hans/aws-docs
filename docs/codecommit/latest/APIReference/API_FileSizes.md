# FileSizes
<a name="API_FileSizes"></a>

Information about the size of files in a merge or pull request.

## Contents
<a name="API_FileSizes_Contents"></a>

 ** base **   <a name="CodeCommit-Type-FileSizes-base"></a>
The size of a file in the base of a merge or pull request.
Type: Long
Required: No

 ** destination **   <a name="CodeCommit-Type-FileSizes-destination"></a>
The size of a file in the destination of a merge or pull request.
Type: Long
Required: No

 ** source **   <a name="CodeCommit-Type-FileSizes-source"></a>
The size of a file in the source of a merge or pull request.
Type: Long
Required: No
