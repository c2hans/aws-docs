# PullRequestStatusChangedEventMetadata
<a name="API_PullRequestStatusChangedEventMetadata"></a>

Information about a change to the status of a pull request.

## Contents
<a name="API_PullRequestStatusChangedEventMetadata_Contents"></a>

 ** pullRequestStatus **   <a name="CodeCommit-Type-PullRequestStatusChangedEventMetadata-pullRequestStatus"></a>
The changed status of the pull request.
Type: String
Valid Values: `OPEN | CLOSED`
Required: No
