# Data Types

The AWS Abuse Signal API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [ReportData](API_ReportData.md)
+  [ReportStatusListItem](API_ReportStatusListItem.md)
+  [SubmissionRequirement](API_SubmissionRequirement.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
