# ValidationExceptionField

Describes one specific validation failure for an input member.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="abusesignal-Type-ValidationExceptionField-message"></a>
A detailed description of the validation failure.
Type: String
Required: Yes

 ** path **   <a name="abusesignal-Type-ValidationExceptionField-path"></a>
A JSON Pointer expression to the structure member whose value failed to satisfy the modeled constraints.
Type: String
Required: Yes
