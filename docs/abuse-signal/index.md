# AWS Abuse Signal API

AWS Abuse Signal API provides programmatic means to report suspected abuse of AWS resources. You can use the API to submit abuse reports about AWS resources and to track the status of your reports. AWS Trust & Safety uses the information that you provide to investigate and try to resolve the incident that you reported.

- [User Guide](/abuse-signal/latest/userguide/): Learn how to submit and track abuse reports with AWS Abuse Signal API, including the report format (XARF), the submission workflow, security, and quotas.
- [API Reference](/abuse-signal/latest/APIReference/): API actions, request and response syntax, parameters, data types, and errors for the AWS Abuse Signal API.
