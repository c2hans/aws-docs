# AWS SDK for Kotlin Documentation

The AWS SDK for Kotlin provides Kotlin APIs for Amazon Web Services infrastructure services. Using the SDK, you can build applications on top of Amazon S3, Amazon EC2, Amazon DynamoDB, and more.

## Latest version

- [Developer Guide](/sdk-for-kotlin/latest/developer-guide/): Describes the features of the AWS SDK for Kotlin and how to use them.
- [AWS SDK for Kotlin API Reference](/sdk-for-kotlin/api/latest/): Describes the API operations of the AWS SDK for Kotlin in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
- [Smithy for Kotlin API Reference](/smithy-kotlin/api/latest/): Describes generic Smithy for Kotlin common functionality and base types used by the AWS SDK for Kotlin.
