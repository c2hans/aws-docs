# AuthConfigUpdate
<a name="API_AuthConfigUpdate"></a>

The updated authentication configuration details for a connector destination.

## Contents
<a name="API_AuthConfigUpdate_Contents"></a>

 ** GeneralAuthorizationUpdate **   <a name="managedintegrations-Type-AuthConfigUpdate-GeneralAuthorizationUpdate"></a>

Type: [GeneralAuthorizationUpdate](API_GeneralAuthorizationUpdate.md) object
Required: No

 ** oAuthUpdate **   <a name="managedintegrations-Type-AuthConfigUpdate-oAuthUpdate"></a>
The updated OAuth configuration settings for the authentication configuration.
Type: [OAuthUpdate](API_OAuthUpdate.md) object
Required: No
