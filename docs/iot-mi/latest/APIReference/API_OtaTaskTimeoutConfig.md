# OtaTaskTimeoutConfig
<a name="API_OtaTaskTimeoutConfig"></a>

Over-the-air (OTA) task timeout config.

## Contents
<a name="API_OtaTaskTimeoutConfig_Contents"></a>

 ** InProgressTimeoutInMinutes **   <a name="managedintegrations-Type-OtaTaskTimeoutConfig-InProgressTimeoutInMinutes"></a>
Specifies the amount of time the device has to finish execution of this task. The timeout interval can be anywhere between 1 minute and 7 days.
Type: Long
Valid Range: Minimum value of 1. Maximum value of 10080.
Required: No
