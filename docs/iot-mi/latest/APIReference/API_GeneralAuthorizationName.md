# GeneralAuthorizationName
<a name="API_GeneralAuthorizationName"></a>

The General Authorization reference by authorization material name.

## Contents
<a name="API_GeneralAuthorizationName_Contents"></a>

 ** AuthMaterialName **   <a name="managedintegrations-Type-GeneralAuthorizationName-AuthMaterialName"></a>
The name of the authorization material.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Pattern: `[a-zA-Z0-9=_+/-]+`
Required: No
