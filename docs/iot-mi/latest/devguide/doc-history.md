# Document history for the Managed Integrations Developer Guide
<a name="doc-history"></a>

The following table describes the documentation releases for Managed Integrations.

| Change | Description | Date |
| --- |--- |--- |
| [Updated notifications and device discovery documentation](#doc-history) | Added the `iotMiArrivalTimestamp` field to the `DEVICE_EVENT` notification payload.
