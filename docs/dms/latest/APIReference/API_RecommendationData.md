# RecommendationData
<a name="API_RecommendationData"></a>

Provides information about the target engine for the specified source database.

## Contents
<a name="API_RecommendationData_Contents"></a>

 ** RdsEngine **   <a name="DMS-Type-RecommendationData-RdsEngine"></a>
The recommendation of a target Amazon RDS database engine.
Type: [RdsRecommendation](API_RdsRecommendation.md) object
Required: No
