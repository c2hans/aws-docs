# ExportMetadataModelAssessmentResultEntry
<a name="API_ExportMetadataModelAssessmentResultEntry"></a>

Provides information about an exported metadata model assessment.

## Contents
<a name="API_ExportMetadataModelAssessmentResultEntry_Contents"></a>

 ** ObjectURL **   <a name="DMS-Type-ExportMetadataModelAssessmentResultEntry-ObjectURL"></a>
The URL for the object containing the exported metadata model assessment.
Type: String
Required: No

 ** S3ObjectKey **   <a name="DMS-Type-ExportMetadataModelAssessmentResultEntry-S3ObjectKey"></a>
The object key for the object containing the exported metadata model assessment.
Type: String
Required: No
