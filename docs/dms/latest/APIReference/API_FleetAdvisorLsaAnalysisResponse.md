# FleetAdvisorLsaAnalysisResponse
<a name="API_FleetAdvisorLsaAnalysisResponse"></a>

Describes a large-scale assessment (LSA) analysis run by a Fleet Advisor collector.

## Contents
<a name="API_FleetAdvisorLsaAnalysisResponse_Contents"></a>

 ** LsaAnalysisId **   <a name="DMS-Type-FleetAdvisorLsaAnalysisResponse-LsaAnalysisId"></a>
The ID of an LSA analysis run by a Fleet Advisor collector.
Type: String
Required: No

 ** Status **   <a name="DMS-Type-FleetAdvisorLsaAnalysisResponse-Status"></a>
The status of an LSA analysis run by a Fleet Advisor collector.
Type: String
Required: No
