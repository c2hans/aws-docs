# DatabaseShortInfoResponse
<a name="API_DatabaseShortInfoResponse"></a>

Describes a database in a Fleet Advisor collector inventory.

## Contents
<a name="API_DatabaseShortInfoResponse_Contents"></a>

 ** DatabaseEngine **   <a name="DMS-Type-DatabaseShortInfoResponse-DatabaseEngine"></a>
The database engine of a database in a Fleet Advisor collector inventory, for example `PostgreSQL`.
Type: String
Required: No

 ** DatabaseId **   <a name="DMS-Type-DatabaseShortInfoResponse-DatabaseId"></a>
The ID of a database in a Fleet Advisor collector inventory.
Type: String
Required: No

 ** DatabaseIpAddress **   <a name="DMS-Type-DatabaseShortInfoResponse-DatabaseIpAddress"></a>
The IP address of a database in a Fleet Advisor collector inventory.
Type: String
Required: No

 ** DatabaseName **   <a name="DMS-Type-DatabaseShortInfoResponse-DatabaseName"></a>
The name of a database in a Fleet Advisor collector inventory.
Type: String
Required: No
