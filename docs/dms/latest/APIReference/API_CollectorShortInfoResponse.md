# CollectorShortInfoResponse
<a name="API_CollectorShortInfoResponse"></a>

Briefly describes a Fleet Advisor collector.

## Contents
<a name="API_CollectorShortInfoResponse_Contents"></a>

 ** CollectorName **   <a name="DMS-Type-CollectorShortInfoResponse-CollectorName"></a>
The name of the Fleet Advisor collector.
Type: String
Required: No

 ** CollectorReferencedId **   <a name="DMS-Type-CollectorShortInfoResponse-CollectorReferencedId"></a>
The reference ID of the Fleet Advisor collector.
Type: String
Required: No
