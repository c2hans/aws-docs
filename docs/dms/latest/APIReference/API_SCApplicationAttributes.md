# SCApplicationAttributes
<a name="API_SCApplicationAttributes"></a>

Provides information that defines a schema conversion application.

## Contents
<a name="API_SCApplicationAttributes_Contents"></a>

 ** S3BucketPath **   <a name="DMS-Type-SCApplicationAttributes-S3BucketPath"></a>
The path for the Amazon S3 bucket that the application uses for exporting assessment reports.
Type: String
Required: No

 ** S3BucketRoleArn **   <a name="DMS-Type-SCApplicationAttributes-S3BucketRoleArn"></a>
The ARN for the role the application uses to access its Amazon S3 bucket.
Type: String
Required: No
