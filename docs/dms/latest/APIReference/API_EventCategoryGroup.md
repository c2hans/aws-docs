# EventCategoryGroup
<a name="API_EventCategoryGroup"></a>

Lists categories of events subscribed to, and generated by, the applicable AWS DMS resource type. This data type appears in response to the [`DescribeEventCategories`](https://docs.aws.amazon.com/dms/latest/APIReference/API_EventCategoryGroup.html) action.

## Contents
<a name="API_EventCategoryGroup_Contents"></a>

 ** EventCategories **   <a name="DMS-Type-EventCategoryGroup-EventCategories"></a>
 A list of event categories from a source type that you've chosen.
Type: Array of strings
Required: No

 ** SourceType **   <a name="DMS-Type-EventCategoryGroup-SourceType"></a>
 The type of AWS DMS resource that generates events.
Valid values: replication-instance \| replication-server \| security-group \| replication-task
Type: String
Required: No
