# BatchStartRecommendationsErrorEntry
<a name="API_BatchStartRecommendationsErrorEntry"></a>

Provides information about the errors that occurred during the analysis of the source database.

## Contents
<a name="API_BatchStartRecommendationsErrorEntry_Contents"></a>

 ** Code **   <a name="DMS-Type-BatchStartRecommendationsErrorEntry-Code"></a>
The code of an error that occurred during the analysis of the source database.
Type: String
Required: No

 ** DatabaseId **   <a name="DMS-Type-BatchStartRecommendationsErrorEntry-DatabaseId"></a>
The identifier of the source database.
Type: String
Required: No

 ** Message **   <a name="DMS-Type-BatchStartRecommendationsErrorEntry-Message"></a>
The information about the error.
Type: String
Required: No
