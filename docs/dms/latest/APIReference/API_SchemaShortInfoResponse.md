# SchemaShortInfoResponse
<a name="API_SchemaShortInfoResponse"></a>

Describes a schema in a Fleet Advisor collector inventory.

## Contents
<a name="API_SchemaShortInfoResponse_Contents"></a>

 ** DatabaseId **   <a name="DMS-Type-SchemaShortInfoResponse-DatabaseId"></a>
The ID of a database in a Fleet Advisor collector inventory.
Type: String
Required: No

 ** DatabaseIpAddress **   <a name="DMS-Type-SchemaShortInfoResponse-DatabaseIpAddress"></a>
The IP address of a database in a Fleet Advisor collector inventory.
Type: String
Required: No

 ** DatabaseName **   <a name="DMS-Type-SchemaShortInfoResponse-DatabaseName"></a>
The name of a database in a Fleet Advisor collector inventory.
Type: String
Required: No

 ** SchemaId **   <a name="DMS-Type-SchemaShortInfoResponse-SchemaId"></a>
The ID of a schema in a Fleet Advisor collector inventory.
Type: String
Required: No

 ** SchemaName **   <a name="DMS-Type-SchemaShortInfoResponse-SchemaName"></a>
The name of a schema in a Fleet Advisor collector inventory.
Type: String
Required: No
