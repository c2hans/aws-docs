# RdsRecommendation
<a name="API_RdsRecommendation"></a>

Provides information that describes a recommendation of a target engine on Amazon RDS.

## Contents
<a name="API_RdsRecommendation_Contents"></a>

 ** RequirementsToTarget **   <a name="DMS-Type-RdsRecommendation-RequirementsToTarget"></a>
Supplemental information about the requirements to the recommended target database on Amazon RDS.
Type: [RdsRequirements](API_RdsRequirements.md) object
Required: No

 ** TargetConfiguration **   <a name="DMS-Type-RdsRecommendation-TargetConfiguration"></a>
Supplemental information about the configuration of the recommended target database on Amazon RDS.
Type: [RdsConfiguration](API_RdsConfiguration.md) object
Required: No
