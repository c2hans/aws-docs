# ReplicationTaskAssessmentRunProgress
<a name="API_ReplicationTaskAssessmentRunProgress"></a>

The progress values reported by the `AssessmentProgress` response element.

## Contents
<a name="API_ReplicationTaskAssessmentRunProgress_Contents"></a>

 ** IndividualAssessmentCompletedCount **   <a name="DMS-Type-ReplicationTaskAssessmentRunProgress-IndividualAssessmentCompletedCount"></a>
The number of individual assessments that have completed, successfully or not.
Type: Integer
Required: No

 ** IndividualAssessmentCount **   <a name="DMS-Type-ReplicationTaskAssessmentRunProgress-IndividualAssessmentCount"></a>
The number of individual assessments that are specified to run.
Type: Integer
Required: No
