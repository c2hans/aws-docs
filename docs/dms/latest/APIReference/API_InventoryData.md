# InventoryData
<a name="API_InventoryData"></a>

Describes a Fleet Advisor collector inventory.

## Contents
<a name="API_InventoryData_Contents"></a>

 ** NumberOfDatabases **   <a name="DMS-Type-InventoryData-NumberOfDatabases"></a>
The number of databases in the Fleet Advisor collector inventory.
Type: Integer
Required: No

 ** NumberOfSchemas **   <a name="DMS-Type-InventoryData-NumberOfSchemas"></a>
The number of schemas in the Fleet Advisor collector inventory.
Type: Integer
Required: No
