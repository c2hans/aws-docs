# ReplicationInstanceTaskLog
<a name="API_ReplicationInstanceTaskLog"></a>

Contains metadata for a replication instance task log.

## Contents
<a name="API_ReplicationInstanceTaskLog_Contents"></a>

 ** ReplicationInstanceTaskLogSize **   <a name="DMS-Type-ReplicationInstanceTaskLog-ReplicationInstanceTaskLogSize"></a>
The size, in bytes, of the replication task log.
Type: Long
Required: No

 ** ReplicationTaskArn **   <a name="DMS-Type-ReplicationInstanceTaskLog-ReplicationTaskArn"></a>
The Amazon Resource Name (ARN) of the replication task.
Type: String
Required: No

 ** ReplicationTaskName **   <a name="DMS-Type-ReplicationInstanceTaskLog-ReplicationTaskName"></a>
The name of the replication task.
Type: String
Required: No
