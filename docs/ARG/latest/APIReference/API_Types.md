# Data Types
<a name="API_Types"></a>

The AWS Resource Groups API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AccountSettings](API_AccountSettings.md)
+  [FailedResource](API_FailedResource.md)
+  [Group](API_Group.md)
+  [GroupConfiguration](API_GroupConfiguration.md)
+  [GroupConfigurationItem](API_GroupConfigurationItem.md)
+  [GroupConfigurationParameter](API_GroupConfigurationParameter.md)
+  [GroupFilter](API_GroupFilter.md)
+  [GroupIdentifier](API_GroupIdentifier.md)
+  [GroupingStatusesItem](API_GroupingStatusesItem.md)
+  [GroupQuery](API_GroupQuery.md)
+  [ListGroupingStatusesFilter](API_ListGroupingStatusesFilter.md)
+  [ListGroupResourcesItem](API_ListGroupResourcesItem.md)
+  [ListTagSyncTasksFilter](API_ListTagSyncTasksFilter.md)
+  [PendingResource](API_PendingResource.md)
+  [QueryError](API_QueryError.md)
+  [ResourceFilter](API_ResourceFilter.md)
+  [ResourceIdentifier](API_ResourceIdentifier.md)
+  [ResourceQuery](API_ResourceQuery.md)
+  [ResourceStatus](API_ResourceStatus.md)
+  [TagSyncTaskItem](API_TagSyncTaskItem.md)
