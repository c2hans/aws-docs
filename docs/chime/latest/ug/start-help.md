# Using the Amazon Chime help
<a name="start-help"></a>

Amazon Chime provides the following types of help:
+ The Help Center, a set of release notes and blog post.
+ The Amazon Chime User Guide, comprehensive how-to steps for using Amazon Chime.

The following steps explain how to start both types of help.

**To start the Help Center**

1. Open the ellipsis menu next to your name and choose **Help**.

1. As needed, search for a solution to your issue, or use the Forward and Back controls at the bottom of the page.

**To start the user guide**

1. Open the ellipsis menu next to your name and choose **Help**.

1. Choose **Documentation**.

1. On the **Amazon Chime Documentation** page, choose **User Guide**.
