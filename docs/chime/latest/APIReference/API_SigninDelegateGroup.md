# SigninDelegateGroup
<a name="API_SigninDelegateGroup"></a>

An Active Directory (AD) group whose members are granted permission to act as delegates.

## Contents
<a name="API_SigninDelegateGroup_Contents"></a>

 ** GroupName **   <a name="chime-Type-SigninDelegateGroup-GroupName"></a>
The group name.
Type: String
Pattern: `.*\S.*`
Required: No
