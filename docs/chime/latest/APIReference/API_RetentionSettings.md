# RetentionSettings
<a name="API_RetentionSettings"></a>

The retention settings for an Amazon Chime Enterprise account that determine how long to retain items such as chat-room messages and chat-conversation messages.

## Contents
<a name="API_RetentionSettings_Contents"></a>

 ** ConversationRetentionSettings **   <a name="chime-Type-RetentionSettings-ConversationRetentionSettings"></a>
The chat conversation retention settings.
Type: [ConversationRetentionSettings](API_ConversationRetentionSettings.md) object
Required: No

 ** RoomRetentionSettings **   <a name="chime-Type-RetentionSettings-RoomRetentionSettings"></a>
The chat room retention settings.
Type: [RoomRetentionSettings](API_RoomRetentionSettings.md) object
Required: No
