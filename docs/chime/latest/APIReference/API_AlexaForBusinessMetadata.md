# AlexaForBusinessMetadata
<a name="API_AlexaForBusinessMetadata"></a>

The Alexa for Business metadata associated with an Amazon Chime user, used to integrate Alexa for Business with a device.

## Contents
<a name="API_AlexaForBusinessMetadata_Contents"></a>

 ** AlexaForBusinessRoomArn **   <a name="chime-Type-AlexaForBusinessMetadata-AlexaForBusinessRoomArn"></a>
The ARN of the room resource.
Type: String
Required: No

 ** IsAlexaForBusinessEnabled **   <a name="chime-Type-AlexaForBusinessMetadata-IsAlexaForBusinessEnabled"></a>
Starts or stops Alexa for Business.
Type: Boolean
Required: No
