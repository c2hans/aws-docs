# ApplicationPolicies
<a name="API_ApplicationPolicies"></a>

Application policies describe what the certificate can be used for.

## Contents
<a name="API_ApplicationPolicies_Contents"></a>

 ** Policies **   <a name="PcaConnectorAd-Type-ApplicationPolicies-Policies"></a>
Application policies describe what the certificate can be used for.
Type: Array of [ApplicationPolicy](API_ApplicationPolicy.md) objects
Array Members: Minimum number of 1 item. Maximum number of 100 items.
Required: Yes

 ** Critical **   <a name="PcaConnectorAd-Type-ApplicationPolicies-Critical"></a>
Marks the application policy extension as critical.
Type: Boolean
Required: No
