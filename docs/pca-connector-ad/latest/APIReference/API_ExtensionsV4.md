# ExtensionsV4
<a name="API_ExtensionsV4"></a>

Certificate extensions for v4 template schema

## Contents
<a name="API_ExtensionsV4_Contents"></a>

 ** KeyUsage **   <a name="PcaConnectorAd-Type-ExtensionsV4-KeyUsage"></a>
The key usage extension defines the purpose (e.g., encipherment, signature) of the key contained in the certificate.
Type: [KeyUsage](API_KeyUsage.md) object
Required: Yes

 ** ApplicationPolicies **   <a name="PcaConnectorAd-Type-ExtensionsV4-ApplicationPolicies"></a>
Application policies specify what the certificate is used for and its purpose.
Type: [ApplicationPolicies](API_ApplicationPolicies.md) object
Required: No
