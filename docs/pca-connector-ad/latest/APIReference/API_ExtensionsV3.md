# ExtensionsV3
<a name="API_ExtensionsV3"></a>

Certificate extensions for v3 template schema

## Contents
<a name="API_ExtensionsV3_Contents"></a>

 ** KeyUsage **   <a name="PcaConnectorAd-Type-ExtensionsV3-KeyUsage"></a>
The key usage extension defines the purpose (e.g., encipherment, signature, certificate signing) of the key contained in the certificate.
Type: [KeyUsage](API_KeyUsage.md) object
Required: Yes

 ** ApplicationPolicies **   <a name="PcaConnectorAd-Type-ExtensionsV3-ApplicationPolicies"></a>
Application policies specify what the certificate is used for and its purpose.
Type: [ApplicationPolicies](API_ApplicationPolicies.md) object
Required: No
