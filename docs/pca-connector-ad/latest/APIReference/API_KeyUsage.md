# KeyUsage
<a name="API_KeyUsage"></a>

The key usage extension defines the purpose (e.g., encipherment, signature) of the key contained in the certificate.

## Contents
<a name="API_KeyUsage_Contents"></a>

 ** UsageFlags **   <a name="PcaConnectorAd-Type-KeyUsage-UsageFlags"></a>
The key usage flags represent the purpose (e.g., encipherment, signature) of the key contained in the certificate.
Type: [KeyUsageFlags](API_KeyUsageFlags.md) object
Required: Yes

 ** Critical **   <a name="PcaConnectorAd-Type-KeyUsage-Critical"></a>
Sets the key usage extension to critical.
Type: Boolean
Required: No
