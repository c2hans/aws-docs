# ExportSummary
<a name="API_ExportSummary"></a>

Summary statuses of an archive export job.

## Contents
<a name="API_ExportSummary_Contents"></a>

 ** ExportId **   <a name="sesmailmanager-Type-ExportSummary-ExportId"></a>
The unique identifier of the export job.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No

 ** Status **   <a name="sesmailmanager-Type-ExportSummary-Status"></a>
The current status of the export job.
Type: [ExportStatus](API_ExportStatus.md) object
Required: No
