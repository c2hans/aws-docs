# IngressPointPasswordConfiguration
<a name="API_IngressPointPasswordConfiguration"></a>

The password configuration of the ingress endpoint resource.

## Contents
<a name="API_IngressPointPasswordConfiguration_Contents"></a>

 ** PreviousSmtpPasswordExpiryTimestamp **   <a name="sesmailmanager-Type-IngressPointPasswordConfiguration-PreviousSmtpPasswordExpiryTimestamp"></a>
The previous password expiry timestamp of the ingress endpoint resource.
Type: Timestamp
Required: No

 ** PreviousSmtpPasswordVersion **   <a name="sesmailmanager-Type-IngressPointPasswordConfiguration-PreviousSmtpPasswordVersion"></a>
The previous password version of the ingress endpoint resource.
Type: String
Required: No

 ** SmtpPasswordVersion **   <a name="sesmailmanager-Type-IngressPointPasswordConfiguration-SmtpPasswordVersion"></a>
The current password expiry timestamp of the ingress endpoint resource.
Type: String
Required: No
