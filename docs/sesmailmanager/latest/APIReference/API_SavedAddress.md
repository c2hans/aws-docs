# SavedAddress
<a name="API_SavedAddress"></a>

An address that is a member of an address list.

## Contents
<a name="API_SavedAddress_Contents"></a>

 ** Address **   <a name="sesmailmanager-Type-SavedAddress-Address"></a>
The email or domain that constitutes the address.
Type: String
Length Constraints: Minimum length of 3. Maximum length of 320.
Required: Yes

 ** CreatedTimestamp **   <a name="sesmailmanager-Type-SavedAddress-CreatedTimestamp"></a>
The timestamp of when the address was added to the address list.
Type: Timestamp
Required: Yes
