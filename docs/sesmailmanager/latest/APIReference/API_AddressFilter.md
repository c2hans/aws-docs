# AddressFilter
<a name="API_AddressFilter"></a>

Filtering options for ListMembersOfAddressList operation.

## Contents
<a name="API_AddressFilter_Contents"></a>

 ** AddressPrefix **   <a name="sesmailmanager-Type-AddressFilter-AddressPrefix"></a>
Filter to limit the results to addresses having the provided prefix.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 320.
Required: No
