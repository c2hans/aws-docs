# SearchSummary
<a name="API_SearchSummary"></a>

Summary details of an archive search job.

## Contents
<a name="API_SearchSummary_Contents"></a>

 ** SearchId **   <a name="sesmailmanager-Type-SearchSummary-SearchId"></a>
The unique identifier of the search job.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No

 ** Status **   <a name="sesmailmanager-Type-SearchSummary-Status"></a>
The current status of the search job.
Type: [SearchStatus](API_SearchStatus.md) object
Required: No
