# PublicNetworkConfiguration
<a name="API_PublicNetworkConfiguration"></a>

Specifies the network configuration for the public ingress point.

## Contents
<a name="API_PublicNetworkConfiguration_Contents"></a>

 ** IpType **   <a name="sesmailmanager-Type-PublicNetworkConfiguration-IpType"></a>
The IP address type for the public ingress point. Valid values are IPV4 and DUAL\_STACK.
Type: String
Valid Values: `IPV4 | DUAL_STACK`
Required: Yes
