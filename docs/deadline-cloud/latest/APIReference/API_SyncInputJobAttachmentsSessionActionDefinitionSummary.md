# SyncInputJobAttachmentsSessionActionDefinitionSummary
<a name="API_SyncInputJobAttachmentsSessionActionDefinitionSummary"></a>

 ** stepId **   <a name="deadlinecloud-Type-SyncInputJobAttachmentsSessionActionDefinitionSummary-stepId"></a>
The step ID for the sync input job attachments session action summary.
Type: String
Pattern: `step-[0-9a-f]{32}`
Required: No
