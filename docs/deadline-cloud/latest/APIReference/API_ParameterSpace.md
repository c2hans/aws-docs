# ParameterSpace
<a name="API_ParameterSpace"></a>

The details of a search for two or more step parameters.

## Contents
<a name="API_ParameterSpace_Contents"></a>

 ** parameters **   <a name="deadlinecloud-Type-ParameterSpace-parameters"></a>
The parameters to search for.
Type: Array of [StepParameter](API_StepParameter.md) objects
Required: Yes

 ** combination **   <a name="deadlinecloud-Type-ParameterSpace-combination"></a>
The combination expression to use in the search.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1280.
Required: No
