# AssignedSyncInputJobAttachmentsSessionActionDefinition
<a name="API_AssignedSyncInputJobAttachmentsSessionActionDefinition"></a>

The assigned session action definition for syncing input job attachments.

<a name="API_AssignedSyncInputJobAttachmentsSessionActionDefinition_Contents"></a>

 ** stepId **   <a name="deadlinecloud-Type-AssignedSyncInputJobAttachmentsSessionActionDefinition-stepId"></a>
The step ID for the assigned sync input job attachments session action.
Type: String
Pattern: `step-[0-9a-f]{32}`
Required: No
