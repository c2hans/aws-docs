# AcceleratorTotalMemoryMiBRange
<a name="API_AcceleratorTotalMemoryMiBRange"></a>

Defines the maximum and minimum amount of memory, in MiB, to use for the accelerator.

## Contents
<a name="API_AcceleratorTotalMemoryMiBRange_Contents"></a>

 ** min **   <a name="deadlinecloud-Type-AcceleratorTotalMemoryMiBRange-min"></a>
The minimum amount of memory to use for the accelerator, measured in MiB.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 2147483647.
Required: Yes

 ** max **   <a name="deadlinecloud-Type-AcceleratorTotalMemoryMiBRange-max"></a>
The maximum amount of memory to use for the accelerator, measured in MiB.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 2147483647.
Required: No
