# FleetSoftwareAddOn
<a name="API_FleetSoftwareAddOn"></a>

Software that the service installs on worker hosts in a service-managed fleet.

## Contents
<a name="API_FleetSoftwareAddOn_Contents"></a>

 ** name **   <a name="deadlinecloud-Type-FleetSoftwareAddOn-name"></a>
The name of the software add-on. The supported value is `docker`.
Type: String
Valid Values: `docker`
Required: Yes
