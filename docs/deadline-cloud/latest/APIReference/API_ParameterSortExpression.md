# ParameterSortExpression
<a name="API_ParameterSortExpression"></a>

Organizes parameters according to your specifications.

## Contents
<a name="API_ParameterSortExpression_Contents"></a>

 ** name **   <a name="deadlinecloud-Type-ParameterSortExpression-name"></a>
The parameter name to sort by.
Type: String
Required: Yes

 ** sortOrder **   <a name="deadlinecloud-Type-ParameterSortExpression-sortOrder"></a>
The sort order for the parameter.
Type: String
Valid Values: `ASCENDING | DESCENDING`
Required: Yes
