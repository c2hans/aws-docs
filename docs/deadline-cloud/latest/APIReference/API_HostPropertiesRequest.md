# HostPropertiesRequest
<a name="API_HostPropertiesRequest"></a>

The host property details.

## Contents
<a name="API_HostPropertiesRequest_Contents"></a>

 ** hostName **   <a name="deadlinecloud-Type-HostPropertiesRequest-hostName"></a>
The host name.
Type: String
Pattern: `[a-zA-Z0-9_\.\-]{0,255}`
Required: No

 ** ipAddresses **   <a name="deadlinecloud-Type-HostPropertiesRequest-ipAddresses"></a>
The IP address of the host.
Type: [IpAddresses](API_IpAddresses.md) object
Required: No
