# TaskRunManifestPropertiesRequest
<a name="API_TaskRunManifestPropertiesRequest"></a>

The output manifest properties reported by the worker agent for a completed task run.

## Contents
<a name="API_TaskRunManifestPropertiesRequest_Contents"></a>

 ** outputManifestHash **   <a name="deadlinecloud-Type-TaskRunManifestPropertiesRequest-outputManifestHash"></a>
The hash value of the file.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No

 ** outputManifestPath **   <a name="deadlinecloud-Type-TaskRunManifestPropertiesRequest-outputManifestPath"></a>
The manifest file path.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: No
