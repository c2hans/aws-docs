# MemoryMiBRange
<a name="API_MemoryMiBRange"></a>

The range of memory in MiB.

## Contents
<a name="API_MemoryMiBRange_Contents"></a>

 ** min **   <a name="deadlinecloud-Type-MemoryMiBRange-min"></a>
The minimum amount of memory (in MiB).
Type: Integer
Valid Range: Minimum value of 512. Maximum value of 2147483647.
Required: Yes

 ** max **   <a name="deadlinecloud-Type-MemoryMiBRange-max"></a>
The maximum amount of memory (in MiB).
Type: Integer
Valid Range: Minimum value of 512. Maximum value of 2147483647.
Required: No
