# FleetCapabilities
<a name="API_FleetCapabilities"></a>

The amounts and attributes of fleets.

## Contents
<a name="API_FleetCapabilities_Contents"></a>

 ** amounts **   <a name="deadlinecloud-Type-FleetCapabilities-amounts"></a>
Amount capabilities of the fleet.
Type: Array of [FleetAmountCapability](API_FleetAmountCapability.md) objects
Array Members: Minimum number of 1 item. Maximum number of 25 items.
Required: No

 ** attributes **   <a name="deadlinecloud-Type-FleetCapabilities-attributes"></a>
Attribute capabilities of the fleet.
Type: Array of [FleetAttributeCapability](API_FleetAttributeCapability.md) objects
Array Members: Minimum number of 1 item. Maximum number of 25 items.
Required: No
