# StepRequiredCapabilities
<a name="API_StepRequiredCapabilities"></a>

The details of required step capabilities.

## Contents
<a name="API_StepRequiredCapabilities_Contents"></a>

 ** amounts **   <a name="deadlinecloud-Type-StepRequiredCapabilities-amounts"></a>
The capability amounts that the step requires.
Type: Array of [StepAmountCapability](API_StepAmountCapability.md) objects
Array Members: Minimum number of 0 items. Maximum number of 25 items.
Required: Yes

 ** attributes **   <a name="deadlinecloud-Type-StepRequiredCapabilities-attributes"></a>
The capability attributes that the step requires.
Type: Array of [StepAttributeCapability](API_StepAttributeCapability.md) objects
Array Members: Minimum number of 0 items. Maximum number of 25 items.
Required: Yes
