# DependencyCounts
<a name="API_DependencyCounts"></a>

The number of dependencies for the consumer.

## Contents
<a name="API_DependencyCounts_Contents"></a>

 ** consumersResolved **   <a name="deadlinecloud-Type-DependencyCounts-consumersResolved"></a>
The number of consumers resolved.
Type: Integer
Required: Yes

 ** consumersUnresolved **   <a name="deadlinecloud-Type-DependencyCounts-consumersUnresolved"></a>
The number of unresolved consumers.
Type: Integer
Required: Yes

 ** dependenciesResolved **   <a name="deadlinecloud-Type-DependencyCounts-dependenciesResolved"></a>
The number of resolved dependencies.
Type: Integer
Required: Yes

 ** dependenciesUnresolved **   <a name="deadlinecloud-Type-DependencyCounts-dependenciesUnresolved"></a>
The number of unresolved dependencies.
Type: Integer
Required: Yes
