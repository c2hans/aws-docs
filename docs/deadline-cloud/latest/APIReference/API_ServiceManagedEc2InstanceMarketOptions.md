# ServiceManagedEc2InstanceMarketOptions
<a name="API_ServiceManagedEc2InstanceMarketOptions"></a>

The details of the Amazon EC2 instance market options for a service managed fleet.

## Contents
<a name="API_ServiceManagedEc2InstanceMarketOptions_Contents"></a>

 ** type **   <a name="deadlinecloud-Type-ServiceManagedEc2InstanceMarketOptions-type"></a>
The Amazon EC2 instance type.
Type: String
Valid Values: `on-demand | spot | wait-and-save`
Required: Yes
