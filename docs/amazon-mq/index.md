# Amazon MQ Documentation

Amazon MQ is a managed message broker service that makes it easy to set up and operate message brokers in the cloud. Amazon MQ provides interoperability with your existing applications and services. Amazon MQ works with your existing applications and services without the need to manage, operate, or maintain your own messaging system.

- [Developer Guide](/amazon-mq/latest/developer-guide/welcome.html): Provides a conceptual overview of Amazon MQ and includes detailed instructions for creating and managing brokers and migrating from on-premises brokers.
- [REST API Reference](/amazon-mq/latest/api-reference/welcome.html): Describes all REST APIs for Amazon MQ and provides HTTP methods, example request and response schemas, and a full list of parameters.
- [Amazon MQ in the AWS CLI Reference](/cli/latest/reference/mq/index.html): Describes the AWS CLI commands that you can use to work with message brokers.
- [Migration Guide](/amazon-mq/latest/migration-guide/): Describes migrating commercial, on-premises message brokers to Amazon MQ.
