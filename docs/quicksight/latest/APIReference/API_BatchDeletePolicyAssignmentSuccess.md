# BatchDeletePolicyAssignmentSuccess

A principal that no longer has the policy after a `BatchDeletePolicyAssignmentByPolicy` request, including a principal that didn't have the policy.

## Contents
<a name="API_BatchDeletePolicyAssignmentSuccess_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** PrincipalArn **   <a name="QS-Type-BatchDeletePolicyAssignmentSuccess-PrincipalArn"></a>
The ARN of the principal.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Pattern: `arn:.+`
Required: Yes
