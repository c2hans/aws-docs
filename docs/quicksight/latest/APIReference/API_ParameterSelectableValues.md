# ParameterSelectableValues
<a name="API_ParameterSelectableValues"></a>

A list of selectable values that are used in a control.

## Contents
<a name="API_ParameterSelectableValues_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** LinkToDataSetColumn **   <a name="QS-Type-ParameterSelectableValues-LinkToDataSetColumn"></a>
The column identifier that fetches values from the data set.
Type: [ColumnIdentifier](API_ColumnIdentifier.md) object
Required: No

 ** Values **   <a name="QS-Type-ParameterSelectableValues-Values"></a>
The values that are used in `ParameterSelectableValues`.
Type: Array of strings
Array Members: Maximum number of 50000 items.
Required: No
