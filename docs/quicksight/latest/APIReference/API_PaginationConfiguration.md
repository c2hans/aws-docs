# PaginationConfiguration
<a name="API_PaginationConfiguration"></a>

The pagination configuration for a table visual or boxplot.

## Contents
<a name="API_PaginationConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** PageNumber **   <a name="QS-Type-PaginationConfiguration-PageNumber"></a>
Indicates the page number.
Type: Long
Valid Range: Minimum value of 0.
Required: Yes

 ** PageSize **   <a name="QS-Type-PaginationConfiguration-PageSize"></a>
Indicates how many items render in one page.
Type: Long
Required: Yes
