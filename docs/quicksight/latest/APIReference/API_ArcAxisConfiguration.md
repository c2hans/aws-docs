# ArcAxisConfiguration
<a name="API_ArcAxisConfiguration"></a>

The arc axis configuration of a `GaugeChartVisual`.

## Contents
<a name="API_ArcAxisConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Range **   <a name="QS-Type-ArcAxisConfiguration-Range"></a>
The arc axis range of a `GaugeChartVisual`.
Type: [ArcAxisDisplayRange](API_ArcAxisDisplayRange.md) object
Required: No

 ** ReserveRange **   <a name="QS-Type-ArcAxisConfiguration-ReserveRange"></a>
The reserved range of the arc axis.
Type: Integer
Required: No
