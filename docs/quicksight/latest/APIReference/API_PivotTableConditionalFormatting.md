# PivotTableConditionalFormatting
<a name="API_PivotTableConditionalFormatting"></a>

The conditional formatting for a `PivotTableVisual`.

## Contents
<a name="API_PivotTableConditionalFormatting_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ConditionalFormattingOptions **   <a name="QS-Type-PivotTableConditionalFormatting-ConditionalFormattingOptions"></a>
Conditional formatting options for a `PivotTableVisual`.
Type: Array of [PivotTableConditionalFormattingOption](API_PivotTableConditionalFormattingOption.md) objects
Array Members: Maximum number of 500 items.
Required: No
