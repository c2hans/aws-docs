# TileLayoutStyle
<a name="API_TileLayoutStyle"></a>

The display options for the layout of tiles on a sheet.

## Contents
<a name="API_TileLayoutStyle_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Gutter **   <a name="QS-Type-TileLayoutStyle-Gutter"></a>
The gutter settings that apply between tiles.
Type: [GutterStyle](API_GutterStyle.md) object
Required: No

 ** Margin **   <a name="QS-Type-TileLayoutStyle-Margin"></a>
The margin settings that apply around the outside edge of sheets.
Type: [MarginStyle](API_MarginStyle.md) object
Required: No
