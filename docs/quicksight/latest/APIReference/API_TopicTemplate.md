# TopicTemplate
<a name="API_TopicTemplate"></a>

The definition for a `TopicTemplate`.

## Contents
<a name="API_TopicTemplate_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Slots **   <a name="QS-Type-TopicTemplate-Slots"></a>
The slots for the `TopicTemplate`.
Type: Array of [Slot](API_Slot.md) objects
Required: No

 ** TemplateType **   <a name="QS-Type-TopicTemplate-TemplateType"></a>
The template type for the `TopicTemplate`.
Type: String
Length Constraints: Maximum length of 256.
Required: No
