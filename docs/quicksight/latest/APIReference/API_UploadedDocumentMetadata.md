# UploadedDocumentMetadata
<a name="API_UploadedDocumentMetadata"></a>

Metadata for an uploaded document associated with a custom instruction.

## Contents
<a name="API_UploadedDocumentMetadata_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Name **   <a name="QS-Type-UploadedDocumentMetadata-Name"></a>
The name of the uploaded document.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 127.
Required: No
