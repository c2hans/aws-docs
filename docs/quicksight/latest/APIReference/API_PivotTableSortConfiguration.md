# PivotTableSortConfiguration
<a name="API_PivotTableSortConfiguration"></a>

The sort configuration for a `PivotTableVisual`.

## Contents
<a name="API_PivotTableSortConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FieldSortOptions **   <a name="QS-Type-PivotTableSortConfiguration-FieldSortOptions"></a>
The field sort options for a pivot table sort configuration.
Type: Array of [PivotFieldSortOptions](API_PivotFieldSortOptions.md) objects
Array Members: Maximum number of 200 items.
Required: No
