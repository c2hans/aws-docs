# AssetBundleImportJobResourceIdOverrideConfiguration
<a name="API_AssetBundleImportJobResourceIdOverrideConfiguration"></a>

An optional structure that configures resource ID overrides for the import job.

## Contents
<a name="API_AssetBundleImportJobResourceIdOverrideConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** PrefixForAllResources **   <a name="QS-Type-AssetBundleImportJobResourceIdOverrideConfiguration-PrefixForAllResources"></a>
An option to request a CloudFormation variable for a prefix to be prepended to each resource's ID before import. The prefix is only added to the asset IDs and does not change the name of the asset.
Type: String
Required: No
