# TableConditionalFormatting
<a name="API_TableConditionalFormatting"></a>

The conditional formatting for a `PivotTableVisual`.

## Contents
<a name="API_TableConditionalFormatting_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ConditionalFormattingOptions **   <a name="QS-Type-TableConditionalFormatting-ConditionalFormattingOptions"></a>
Conditional formatting options for a `PivotTableVisual`.
Type: Array of [TableConditionalFormattingOption](API_TableConditionalFormattingOption.md) objects
Array Members: Maximum number of 500 items.
Required: No
