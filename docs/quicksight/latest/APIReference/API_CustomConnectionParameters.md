# CustomConnectionParameters
<a name="API_CustomConnectionParameters"></a>

The parameters that are required to connect to a custom connection data source.

## Contents
<a name="API_CustomConnectionParameters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ConnectionType **   <a name="QS-Type-CustomConnectionParameters-ConnectionType"></a>
The type of custom connector.
Type: String
Required: No
