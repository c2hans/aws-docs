# Palette
<a name="API_Palette"></a>

The color palette.

## Contents
<a name="API_Palette_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Background **   <a name="QS-Type-Palette-Background"></a>
The background color.
Type: String
Pattern: `^#[A-F0-9]{6}$`
Required: No

 ** Foreground **   <a name="QS-Type-Palette-Foreground"></a>
The foreground color.
Type: String
Pattern: `^#[A-F0-9]{6}$`
Required: No
