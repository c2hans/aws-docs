# UserLimitsEntry
<a name="API_UserLimitsEntry"></a>

Identifies a user for the `BatchDescribeUserLimits` operation.

## Contents
<a name="API_UserLimitsEntry_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** namespace **   <a name="QS-Type-UserLimitsEntry-namespace"></a>
The namespace of the user.
Type: String
Required: Yes

 ** userName **   <a name="QS-Type-UserLimitsEntry-userName"></a>
The name of the user.
Type: String
Required: Yes
