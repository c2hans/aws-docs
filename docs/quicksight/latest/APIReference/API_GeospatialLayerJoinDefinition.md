# GeospatialLayerJoinDefinition
<a name="API_GeospatialLayerJoinDefinition"></a>

The custom actions for a layer.

## Contents
<a name="API_GeospatialLayerJoinDefinition_Contents"></a>

In the following list, the required parameters are described first.

 ** ColorField **   <a name="QS-Type-GeospatialLayerJoinDefinition-ColorField"></a>

Type: [GeospatialLayerColorField](API_GeospatialLayerColorField.md) object
