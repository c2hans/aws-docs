# TemplateSourceAnalysis
<a name="API_TemplateSourceAnalysis"></a>

The source analysis of the template.

## Contents
<a name="API_TemplateSourceAnalysis_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Arn **   <a name="QS-Type-TemplateSourceAnalysis-Arn"></a>
The Amazon Resource Name (ARN) of the resource.
Type: String
Required: Yes

 ** DataSetReferences **   <a name="QS-Type-TemplateSourceAnalysis-DataSetReferences"></a>
A structure containing information about the dataset references used as placeholders in the template.
Type: Array of [DataSetReference](API_DataSetReference.md) objects
Array Members: Minimum number of 1 item.
Required: Yes
