# TableStyleTarget
<a name="API_TableStyleTarget"></a>

The table style target.

## Contents
<a name="API_TableStyleTarget_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** CellType **   <a name="QS-Type-TableStyleTarget-CellType"></a>
The cell type of the table style target.
Type: String
Valid Values: `TOTAL | METRIC_HEADER | VALUE`
Required: Yes
