# GaugeChartFieldWells
<a name="API_GaugeChartFieldWells"></a>

The field well configuration of a `GaugeChartVisual`.

## Contents
<a name="API_GaugeChartFieldWells_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** TargetValues **   <a name="QS-Type-GaugeChartFieldWells-TargetValues"></a>
The target value field wells of a `GaugeChartVisual`.
Type: Array of [MeasureField](API_MeasureField.md) objects
Array Members: Maximum number of 200 items.
Required: No

 ** Values **   <a name="QS-Type-GaugeChartFieldWells-Values"></a>
The value field wells of a `GaugeChartVisual`.
Type: Array of [MeasureField](API_MeasureField.md) objects
Array Members: Maximum number of 200 items.
Required: No
