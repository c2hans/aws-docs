# TopicConfiguration
<a name="API_TopicConfiguration"></a>

The configuration of a topic.

## Contents
<a name="API_TopicConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ColumnGroupSchemaList **   <a name="QS-Type-TopicConfiguration-ColumnGroupSchemaList"></a>
The list of column group schemas in the topic configuration.
Type: Array of [ColumnGroupSchema](API_ColumnGroupSchema.md) objects
Array Members: Maximum number of 500 items.
Required: No

 ** DataSetSchema **   <a name="QS-Type-TopicConfiguration-DataSetSchema"></a>
Topic schema.
Type: [DataSetSchema](API_DataSetSchema.md) object
Required: No

 ** Placeholder **   <a name="QS-Type-TopicConfiguration-Placeholder"></a>
The placeholder for the topic configuration.
Type: String
Required: No
