# PivotTableConfiguration
<a name="API_PivotTableConfiguration"></a>

The configuration for a `PivotTableVisual`.

## Contents
<a name="API_PivotTableConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DashboardCustomizationVisualOptions **   <a name="QS-Type-PivotTableConfiguration-DashboardCustomizationVisualOptions"></a>
The options that define customizations available to dashboard readers for a specific visual
Type: [DashboardCustomizationVisualOptions](API_DashboardCustomizationVisualOptions.md) object
Required: No

 ** FieldOptions **   <a name="QS-Type-PivotTableConfiguration-FieldOptions"></a>
The field options for a pivot table visual.
Type: [PivotTableFieldOptions](API_PivotTableFieldOptions.md) object
Required: No

 ** FieldWells **   <a name="QS-Type-PivotTableConfiguration-FieldWells"></a>
The field wells of the visual.
Type: [PivotTableFieldWells](API_PivotTableFieldWells.md) object
Required: No

 ** Interactions **   <a name="QS-Type-PivotTableConfiguration-Interactions"></a>
The general visual interactions setup for a visual.
Type: [VisualInteractionOptions](API_VisualInteractionOptions.md) object
Required: No

 ** PaginatedReportOptions **   <a name="QS-Type-PivotTableConfiguration-PaginatedReportOptions"></a>
The paginated report options for a pivot table visual.
Type: [PivotTablePaginatedReportOptions](API_PivotTablePaginatedReportOptions.md) object
Required: No

 ** SortConfiguration **   <a name="QS-Type-PivotTableConfiguration-SortConfiguration"></a>
The sort configuration for a `PivotTableVisual`.
Type: [PivotTableSortConfiguration](API_PivotTableSortConfiguration.md) object
Required: No

 ** TableOptions **   <a name="QS-Type-PivotTableConfiguration-TableOptions"></a>
The table options for a pivot table visual.
Type: [PivotTableOptions](API_PivotTableOptions.md) object
Required: No

 ** Tooltip **   <a name="QS-Type-PivotTableConfiguration-Tooltip"></a>
The display options for the visual tooltip.
Type: [TooltipOptions](API_TooltipOptions.md) object
Required: No

 ** TotalOptions **   <a name="QS-Type-PivotTableConfiguration-TotalOptions"></a>
The total options for a pivot table visual.
Type: [PivotTableTotalOptions](API_PivotTableTotalOptions.md) object
Required: No
