# DataSourceErrorInfo
<a name="API_DataSourceErrorInfo"></a>

Error information for the data source creation or update.

## Contents
<a name="API_DataSourceErrorInfo_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Message **   <a name="QS-Type-DataSourceErrorInfo-Message"></a>
Error message.
Type: String
Required: No

 ** Type **   <a name="QS-Type-DataSourceErrorInfo-Type"></a>
Error type.
Type: String
Valid Values: `ACCESS_DENIED | COPY_SOURCE_NOT_FOUND | TIMEOUT | ENGINE_VERSION_NOT_SUPPORTED | UNKNOWN_HOST | GENERIC_SQL_FAILURE | CONFLICT | UNKNOWN`
Required: No
