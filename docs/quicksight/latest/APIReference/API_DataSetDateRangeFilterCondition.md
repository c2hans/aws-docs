# DataSetDateRangeFilterCondition
<a name="API_DataSetDateRangeFilterCondition"></a>

A filter condition that filters date values within a specified range.

## Contents
<a name="API_DataSetDateRangeFilterCondition_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** IncludeMaximum **   <a name="QS-Type-DataSetDateRangeFilterCondition-IncludeMaximum"></a>
Whether to include the maximum value in the filter range.
Type: Boolean
Required: No

 ** IncludeMinimum **   <a name="QS-Type-DataSetDateRangeFilterCondition-IncludeMinimum"></a>
Whether to include the minimum value in the filter range.
Type: Boolean
Required: No

 ** RangeMaximum **   <a name="QS-Type-DataSetDateRangeFilterCondition-RangeMaximum"></a>
The maximum date value for the range filter.
Type: [DataSetDateFilterValue](API_DataSetDateFilterValue.md) object
Required: No

 ** RangeMinimum **   <a name="QS-Type-DataSetDateRangeFilterCondition-RangeMinimum"></a>
The minimum date value for the range filter.
Type: [DataSetDateFilterValue](API_DataSetDateFilterValue.md) object
Required: No
