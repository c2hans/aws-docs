# ReferenceLineDynamicDataConfiguration
<a name="API_ReferenceLineDynamicDataConfiguration"></a>

The dynamic configuration of the reference line data configuration.

## Contents
<a name="API_ReferenceLineDynamicDataConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Calculation **   <a name="QS-Type-ReferenceLineDynamicDataConfiguration-Calculation"></a>
The calculation that is used in the dynamic data.
Type: [NumericalAggregationFunction](API_NumericalAggregationFunction.md) object
Required: Yes

 ** Column **   <a name="QS-Type-ReferenceLineDynamicDataConfiguration-Column"></a>
The column that the dynamic data targets.
Type: [ColumnIdentifier](API_ColumnIdentifier.md) object
Required: Yes

 ** MeasureAggregationFunction **   <a name="QS-Type-ReferenceLineDynamicDataConfiguration-MeasureAggregationFunction"></a>
The aggregation function that is used in the dynamic data.
Type: [AggregationFunction](API_AggregationFunction.md) object
Required: No
