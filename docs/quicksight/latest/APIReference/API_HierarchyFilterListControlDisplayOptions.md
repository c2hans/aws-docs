# HierarchyFilterListControlDisplayOptions
<a name="API_HierarchyFilterListControlDisplayOptions"></a>

The display options of a control.

## Contents
<a name="API_HierarchyFilterListControlDisplayOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** InfoIconLabelOptions **   <a name="QS-Type-HierarchyFilterListControlDisplayOptions-InfoIconLabelOptions"></a>
The configuration of info icon label options.
Type: [SheetControlInfoIconLabelOptions](API_SheetControlInfoIconLabelOptions.md) object
Required: No

 ** SearchOptions **   <a name="QS-Type-HierarchyFilterListControlDisplayOptions-SearchOptions"></a>
The configuration of the search options in a hierarchy list control.
Type: [HierarchyFilterListControlSearchOptions](API_HierarchyFilterListControlSearchOptions.md) object
Required: No

 ** TitleOptions **   <a name="QS-Type-HierarchyFilterListControlDisplayOptions-TitleOptions"></a>
The options to configure the title visibility, name, and font size.
Type: [LabelOptions](API_LabelOptions.md) object
Required: No
