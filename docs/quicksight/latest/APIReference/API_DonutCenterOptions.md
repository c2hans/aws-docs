# DonutCenterOptions
<a name="API_DonutCenterOptions"></a>

The label options of the label that is displayed in the center of a donut chart. This option isn't available for pie charts.

## Contents
<a name="API_DonutCenterOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** LabelVisibility **   <a name="QS-Type-DonutCenterOptions-LabelVisibility"></a>
Determines the visibility of the label in a donut chart. In the Quick Sight console, this option is called `'Show total'`.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
