# ColumnSchema
<a name="API_ColumnSchema"></a>

The column schema.

## Contents
<a name="API_ColumnSchema_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DataType **   <a name="QS-Type-ColumnSchema-DataType"></a>
The data type of the column schema.
Type: String
Required: No

 ** GeographicRole **   <a name="QS-Type-ColumnSchema-GeographicRole"></a>
The geographic role of the column schema.
Type: String
Required: No

 ** Name **   <a name="QS-Type-ColumnSchema-Name"></a>
The name of the column schema.
Type: String
Required: No
