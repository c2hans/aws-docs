# GeospatialCategoricalDataColor
<a name="API_GeospatialCategoricalDataColor"></a>

The categorical data color for a single category.

## Contents
<a name="API_GeospatialCategoricalDataColor_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Color **   <a name="QS-Type-GeospatialCategoricalDataColor-Color"></a>
The color and opacity values for the category data color.
Type: String
Pattern: `^#[A-F0-9]{6}(?:[A-F0-9]{2})?$`
Required: Yes

 ** DataValue **   <a name="QS-Type-GeospatialCategoricalDataColor-DataValue"></a>
The data value for the category data color.
Type: String
Required: Yes
