# JoinKeyProperties
<a name="API_JoinKeyProperties"></a>

Properties associated with the columns participating in a join.

## Contents
<a name="API_JoinKeyProperties_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** UniqueKey **   <a name="QS-Type-JoinKeyProperties-UniqueKey"></a>
A value that indicates that a row in a table is uniquely identified by the columns in a join key. This is used by Quick Sight to optimize query performance.
Type: Boolean
Required: No
