# SheetStyle
<a name="API_SheetStyle"></a>

The theme display options for sheets.

## Contents
<a name="API_SheetStyle_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Background **   <a name="QS-Type-SheetStyle-Background"></a>
The background for sheets.
Type: [SheetBackgroundStyle](API_SheetBackgroundStyle.md) object
Required: No

 ** Tile **   <a name="QS-Type-SheetStyle-Tile"></a>
The display options for tiles.
Type: [TileStyle](API_TileStyle.md) object
Required: No

 ** TileLayout **   <a name="QS-Type-SheetStyle-TileLayout"></a>
The layout options for tiles.
Type: [TileLayoutStyle](API_TileLayoutStyle.md) object
Required: No
