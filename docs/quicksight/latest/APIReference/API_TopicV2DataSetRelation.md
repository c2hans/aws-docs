# TopicV2DataSetRelation
<a name="API_TopicV2DataSetRelation"></a>

A structure that represents a relation between two data sets of a topic.

## Contents
<a name="API_TopicV2DataSetRelation_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Left **   <a name="QS-Type-TopicV2DataSetRelation-Left"></a>
The left endpoint of the data set relation.
Type: [TopicV2DataSetRelationEndpoint](API_TopicV2DataSetRelationEndpoint.md) object
Required: Yes

 ** Right **   <a name="QS-Type-TopicV2DataSetRelation-Right"></a>
The right endpoint of the data set relation.
Type: [TopicV2DataSetRelationEndpoint](API_TopicV2DataSetRelationEndpoint.md) object
Required: Yes
