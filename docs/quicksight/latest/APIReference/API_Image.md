# Image
<a name="API_Image"></a>

The logo image.

## Contents
<a name="API_Image_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** GeneratedImageUrl **   <a name="QS-Type-Image-GeneratedImageUrl"></a>
The URL that points to the generated logo image.
Type: String
Required: No

 ** Source **   <a name="QS-Type-Image-Source"></a>
The source of the logo image.
Type: [ImageSource](API_ImageSource.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: No
