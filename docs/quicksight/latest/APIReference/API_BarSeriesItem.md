# BarSeriesItem
<a name="API_BarSeriesItem"></a>

The series item configuration of a `BarChartVisual`.

This is a union type structure. For this structure to be valid, only one of the attributes can be defined.

## Contents
<a name="API_BarSeriesItem_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DataFieldBarSeriesItem **   <a name="QS-Type-BarSeriesItem-DataFieldBarSeriesItem"></a>
The data field series item configuration of a `BarChartVisual`.
Type: [DataFieldBarSeriesItem](API_DataFieldBarSeriesItem.md) object
Required: No

 ** FieldBarSeriesItem **   <a name="QS-Type-BarSeriesItem-FieldBarSeriesItem"></a>
The field series item configuration of a `BarChartVisual`.
Type: [FieldBarSeriesItem](API_FieldBarSeriesItem.md) object
Required: No
