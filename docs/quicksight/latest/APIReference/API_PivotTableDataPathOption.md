# PivotTableDataPathOption
<a name="API_PivotTableDataPathOption"></a>

The data path options for the pivot table field options.

## Contents
<a name="API_PivotTableDataPathOption_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DataPathList **   <a name="QS-Type-PivotTableDataPathOption-DataPathList"></a>
The list of data path values for the data path options.
Type: Array of [DataPathValue](API_DataPathValue.md) objects
Array Members: Maximum number of 20 items.
Required: Yes

 ** Width **   <a name="QS-Type-PivotTableDataPathOption-Width"></a>
The width of the data path option.
Type: String
Required: No
