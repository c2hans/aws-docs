# GaugeChartConditionalFormattingOption
<a name="API_GaugeChartConditionalFormattingOption"></a>

Conditional formatting options of a `GaugeChartVisual`.

## Contents
<a name="API_GaugeChartConditionalFormattingOption_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Arc **   <a name="QS-Type-GaugeChartConditionalFormattingOption-Arc"></a>
The options that determine the presentation of the arc of a `GaugeChartVisual`.
Type: [GaugeChartArcConditionalFormatting](API_GaugeChartArcConditionalFormatting.md) object
Required: No

 ** PrimaryValue **   <a name="QS-Type-GaugeChartConditionalFormattingOption-PrimaryValue"></a>
The conditional formatting for the primary value of a `GaugeChartVisual`.
Type: [GaugeChartPrimaryValueConditionalFormatting](API_GaugeChartPrimaryValueConditionalFormatting.md) object
Required: No
