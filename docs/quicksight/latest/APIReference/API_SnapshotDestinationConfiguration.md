# SnapshotDestinationConfiguration
<a name="API_SnapshotDestinationConfiguration"></a>

A structure that contains information on the Amazon S3 destinations of the generated snapshot.

## Contents
<a name="API_SnapshotDestinationConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** S3Destinations **   <a name="QS-Type-SnapshotDestinationConfiguration-S3Destinations"></a>
 A list of `SnapshotS3DestinationConfiguration` objects that contain Amazon S3 destination configurations. This structure can hold a maximum of 1 `S3DestinationConfiguration`.
Type: Array of [SnapshotS3DestinationConfiguration](API_SnapshotS3DestinationConfiguration.md) objects
Array Members: Fixed number of 1 item.
Required: No
