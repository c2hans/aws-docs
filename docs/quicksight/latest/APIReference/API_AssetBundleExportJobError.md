# AssetBundleExportJobError
<a name="API_AssetBundleExportJobError"></a>

Describes an error that occurred during an Asset Bundle export job.

## Contents
<a name="API_AssetBundleExportJobError_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Arn **   <a name="QS-Type-AssetBundleExportJobError-Arn"></a>
The ARN of the resource whose processing caused an error.
Type: String
Required: No

 ** Message **   <a name="QS-Type-AssetBundleExportJobError-Message"></a>
A description of the error.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Type **   <a name="QS-Type-AssetBundleExportJobError-Type"></a>
The specific error type of the error that occurred.
Type: String
Pattern: `.*\S.*`
Required: No
