# AuroraPostgreSqlParameters
<a name="API_AuroraPostgreSqlParameters"></a>

Parameters for Amazon Aurora PostgreSQL-Compatible Edition.

## Contents
<a name="API_AuroraPostgreSqlParameters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Database **   <a name="QS-Type-AuroraPostgreSqlParameters-Database"></a>
The Amazon Aurora PostgreSQL database to connect to.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** Host **   <a name="QS-Type-AuroraPostgreSqlParameters-Host"></a>
The Amazon Aurora PostgreSQL-Compatible host to connect to.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes

 ** Port **   <a name="QS-Type-AuroraPostgreSqlParameters-Port"></a>
The port that Amazon Aurora PostgreSQL is listening on.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 65535.
Required: Yes
