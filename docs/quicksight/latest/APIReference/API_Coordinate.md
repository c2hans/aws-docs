# Coordinate
<a name="API_Coordinate"></a>

The preference coordinate for the geocode preference.

## Contents
<a name="API_Coordinate_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Latitude **   <a name="QS-Type-Coordinate-Latitude"></a>
The latitude coordinate value for the geocode preference.
Type: Double
Valid Range: Minimum value of -90.0. Maximum value of 90.0.
Required: Yes

 ** Longitude **   <a name="QS-Type-Coordinate-Longitude"></a>
The longitude coordinate value for the geocode preference.
Type: Double
Valid Range: Minimum value of -180.0. Maximum value of 180.0.
Required: Yes
