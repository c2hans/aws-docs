# AssetBundleImportJobDataSetOverrideParameters
<a name="API_AssetBundleImportJobDataSetOverrideParameters"></a>

The override parameters for a single dataset that is being imported.

## Contents
<a name="API_AssetBundleImportJobDataSetOverrideParameters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DataSetId **   <a name="QS-Type-AssetBundleImportJobDataSetOverrideParameters-DataSetId"></a>
The ID of the dataset to apply overrides to.
Type: String
Required: Yes

 ** DataSetRefreshProperties **   <a name="QS-Type-AssetBundleImportJobDataSetOverrideParameters-DataSetRefreshProperties"></a>
The refresh properties of a dataset.
Type: [DataSetRefreshProperties](API_DataSetRefreshProperties.md) object
Required: No

 ** Name **   <a name="QS-Type-AssetBundleImportJobDataSetOverrideParameters-Name"></a>
A new name for the dataset.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: No
