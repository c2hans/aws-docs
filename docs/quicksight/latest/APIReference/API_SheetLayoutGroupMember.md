# SheetLayoutGroupMember
<a name="API_SheetLayoutGroupMember"></a>

A member of a sheet layout group.

## Contents
<a name="API_SheetLayoutGroupMember_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Id **   <a name="QS-Type-SheetLayoutGroupMember-Id"></a>
The unique identifier of the group member.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Pattern: `[\w\-]+`
Required: Yes

 ** Type **   <a name="QS-Type-SheetLayoutGroupMember-Type"></a>
The type of the group member.
Type: String
Valid Values: `ELEMENT | GROUP`
Required: Yes
