# DataSetConfiguration
<a name="API_DataSetConfiguration"></a>

Dataset configuration.

## Contents
<a name="API_DataSetConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ColumnGroupSchemaList **   <a name="QS-Type-DataSetConfiguration-ColumnGroupSchemaList"></a>
A structure containing the list of column group schemas.
Type: Array of [ColumnGroupSchema](API_ColumnGroupSchema.md) objects
Array Members: Maximum number of 500 items.
Required: No

 ** DataSetSchema **   <a name="QS-Type-DataSetConfiguration-DataSetSchema"></a>
Dataset schema.
Type: [DataSetSchema](API_DataSetSchema.md) object
Required: No

 ** Placeholder **   <a name="QS-Type-DataSetConfiguration-Placeholder"></a>
Placeholder.
Type: String
Required: No
