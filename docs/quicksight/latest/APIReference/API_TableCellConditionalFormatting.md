# TableCellConditionalFormatting
<a name="API_TableCellConditionalFormatting"></a>

The cell conditional formatting option for a table.

## Contents
<a name="API_TableCellConditionalFormatting_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FieldId **   <a name="QS-Type-TableCellConditionalFormatting-FieldId"></a>
The field ID of the cell for conditional formatting.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: Yes

 ** TextFormat **   <a name="QS-Type-TableCellConditionalFormatting-TextFormat"></a>
The text format of the cell for conditional formatting.
Type: [TextConditionalFormat](API_TextConditionalFormat.md) object
Required: No
