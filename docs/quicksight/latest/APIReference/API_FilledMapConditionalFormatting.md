# FilledMapConditionalFormatting
<a name="API_FilledMapConditionalFormatting"></a>

The conditional formatting of a `FilledMapVisual`.

## Contents
<a name="API_FilledMapConditionalFormatting_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ConditionalFormattingOptions **   <a name="QS-Type-FilledMapConditionalFormatting-ConditionalFormattingOptions"></a>
Conditional formatting options of a `FilledMapVisual`.
Type: Array of [FilledMapConditionalFormattingOption](API_FilledMapConditionalFormattingOption.md) objects
Array Members: Maximum number of 200 items.
Required: Yes
