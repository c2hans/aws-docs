# CollectiveConstant
<a name="API_CollectiveConstant"></a>

A structure that represents a collective constant.

<a name="API_CollectiveConstant_Contents"></a>

**Note**

 ** ValueList **   <a name="QS-Type-CollectiveConstant-ValueList"></a>
