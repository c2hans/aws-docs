# WaterfallChartGroupColorConfiguration
<a name="API_WaterfallChartGroupColorConfiguration"></a>

The color configuration for individual groups within a waterfall visual.

## Contents
<a name="API_WaterfallChartGroupColorConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** NegativeBarColor **   <a name="QS-Type-WaterfallChartGroupColorConfiguration-NegativeBarColor"></a>
Defines the color for the negative bars of a waterfall chart.
Type: String
Pattern: `^#[A-F0-9]{6}$`
Required: No

 ** PositiveBarColor **   <a name="QS-Type-WaterfallChartGroupColorConfiguration-PositiveBarColor"></a>
Defines the color for the positive bars of a waterfall chart.
Type: String
Pattern: `^#[A-F0-9]{6}$`
Required: No

 ** TotalBarColor **   <a name="QS-Type-WaterfallChartGroupColorConfiguration-TotalBarColor"></a>
Defines the color for the total bars of a waterfall chart.
Type: String
Pattern: `^#[A-F0-9]{6}$`
Required: No
