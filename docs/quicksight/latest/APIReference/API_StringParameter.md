# StringParameter
<a name="API_StringParameter"></a>

A string parameter.

## Contents
<a name="API_StringParameter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Name **   <a name="QS-Type-StringParameter-Name"></a>
A display name for a string parameter.
Type: String
Pattern: `.*\S.*`
Required: Yes

 ** Values **   <a name="QS-Type-StringParameter-Values"></a>
The values of a string parameter.
Type: Array of strings
Required: Yes
