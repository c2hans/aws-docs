# HierarchyFilterLevel
<a name="API_HierarchyFilterLevel"></a>

One level of the drill-down path of a `HierarchyFilter`.

## Contents
<a name="API_HierarchyFilterLevel_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Column **   <a name="QS-Type-HierarchyFilterLevel-Column"></a>
The column that this level of the hierarchy drills down by. This column must belong to the same dataset as `HierarchyFilter$Column`.
Type: [ColumnIdentifier](API_ColumnIdentifier.md) object
Required: Yes
