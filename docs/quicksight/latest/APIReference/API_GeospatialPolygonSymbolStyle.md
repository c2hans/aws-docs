# GeospatialPolygonSymbolStyle
<a name="API_GeospatialPolygonSymbolStyle"></a>

The polygon symbol style for a polygon layer.

## Contents
<a name="API_GeospatialPolygonSymbolStyle_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FillColor **   <a name="QS-Type-GeospatialPolygonSymbolStyle-FillColor"></a>
The color and opacity values for the fill color.
Type: [GeospatialColor](API_GeospatialColor.md) object
Required: No

 ** StrokeColor **   <a name="QS-Type-GeospatialPolygonSymbolStyle-StrokeColor"></a>
The color and opacity values for the stroke color.
Type: [GeospatialColor](API_GeospatialColor.md) object
Required: No

 ** StrokeWidth **   <a name="QS-Type-GeospatialPolygonSymbolStyle-StrokeWidth"></a>
The width of the border stroke.
Type: [GeospatialLineWidth](API_GeospatialLineWidth.md) object
Required: No
