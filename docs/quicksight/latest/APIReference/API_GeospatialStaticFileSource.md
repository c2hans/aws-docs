# GeospatialStaticFileSource
<a name="API_GeospatialStaticFileSource"></a>

The source properties for a geospatial static file.

## Contents
<a name="API_GeospatialStaticFileSource_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** StaticFileId **   <a name="QS-Type-GeospatialStaticFileSource-StaticFileId"></a>
The ID of the static file.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Pattern: `[\w\-]+`
Required: Yes
