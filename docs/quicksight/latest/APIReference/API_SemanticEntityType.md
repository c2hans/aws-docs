# SemanticEntityType
<a name="API_SemanticEntityType"></a>

A structure that represents a semantic entity type.

## Contents
<a name="API_SemanticEntityType_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SubTypeName **   <a name="QS-Type-SemanticEntityType-SubTypeName"></a>
The semantic entity sub type name.
Type: String
Length Constraints: Maximum length of 256.
Required: No

 ** TypeName **   <a name="QS-Type-SemanticEntityType-TypeName"></a>
The semantic entity type name.
Type: String
Length Constraints: Maximum length of 256.
Required: No

 ** TypeParameters **   <a name="QS-Type-SemanticEntityType-TypeParameters"></a>
The semantic entity type parameters.
Type: String to string map
Key Length Constraints: Maximum length of 256.
Value Length Constraints: Maximum length of 256.
Required: No
