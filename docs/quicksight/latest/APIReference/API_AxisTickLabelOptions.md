# AxisTickLabelOptions
<a name="API_AxisTickLabelOptions"></a>

The tick label options of an axis.

## Contents
<a name="API_AxisTickLabelOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** LabelOptions **   <a name="QS-Type-AxisTickLabelOptions-LabelOptions"></a>
Determines whether or not the axis ticks are visible.
Type: [LabelOptions](API_LabelOptions.md) object
Required: No

 ** RotationAngle **   <a name="QS-Type-AxisTickLabelOptions-RotationAngle"></a>
The rotation angle of the axis tick labels.
Type: Double
Required: No
