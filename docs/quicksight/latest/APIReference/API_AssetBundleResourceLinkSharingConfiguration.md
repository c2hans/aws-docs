# AssetBundleResourceLinkSharingConfiguration
<a name="API_AssetBundleResourceLinkSharingConfiguration"></a>

A structure that contains the configuration of a shared link to an Amazon Quick Sight dashboard.

## Contents
<a name="API_AssetBundleResourceLinkSharingConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Permissions **   <a name="QS-Type-AssetBundleResourceLinkSharingConfiguration-Permissions"></a>
A list of link sharing permissions for the dashboards that you want to apply overrides to.
Type: [AssetBundleResourcePermissions](API_AssetBundleResourcePermissions.md) object
Required: No
