# KPIConditionalFormattingOption
<a name="API_KPIConditionalFormattingOption"></a>

The conditional formatting options of a KPI visual.

## Contents
<a name="API_KPIConditionalFormattingOption_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ActualValue **   <a name="QS-Type-KPIConditionalFormattingOption-ActualValue"></a>
The conditional formatting for the actual value of a KPI visual.
Type: [KPIActualValueConditionalFormatting](API_KPIActualValueConditionalFormatting.md) object
Required: No

 ** ComparisonValue **   <a name="QS-Type-KPIConditionalFormattingOption-ComparisonValue"></a>
The conditional formatting for the comparison value of a KPI visual.
Type: [KPIComparisonValueConditionalFormatting](API_KPIComparisonValueConditionalFormatting.md) object
Required: No

 ** PrimaryValue **   <a name="QS-Type-KPIConditionalFormattingOption-PrimaryValue"></a>
The conditional formatting for the primary value of a KPI visual.
Type: [KPIPrimaryValueConditionalFormatting](API_KPIPrimaryValueConditionalFormatting.md) object
Required: No

 ** ProgressBar **   <a name="QS-Type-KPIConditionalFormattingOption-ProgressBar"></a>
The conditional formatting for the progress bar of a KPI visual.
Type: [KPIProgressBarConditionalFormatting](API_KPIProgressBarConditionalFormatting.md) object
Required: No
