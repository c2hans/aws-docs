# FilledMapAggregatedFieldWells
<a name="API_FilledMapAggregatedFieldWells"></a>

The aggregated field well of the filled map.

## Contents
<a name="API_FilledMapAggregatedFieldWells_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Geospatial **   <a name="QS-Type-FilledMapAggregatedFieldWells-Geospatial"></a>
The aggregated location field well of the filled map. Values are grouped by location fields.
Type: Array of [DimensionField](API_DimensionField.md) objects
Array Members: Maximum number of 1 item.
Required: No

 ** Values **   <a name="QS-Type-FilledMapAggregatedFieldWells-Values"></a>
The aggregated color field well of a filled map. Values are aggregated based on location fields.
Type: Array of [MeasureField](API_MeasureField.md) objects
Array Members: Maximum number of 1 item.
Required: No
