# CustomInstruction
<a name="API_CustomInstruction"></a>

A custom instruction that provides guidance on how the dataset should be consumed.

<a name="API_CustomInstruction_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** InlineCustomInstruction **   <a name="QS-Type-CustomInstruction-InlineCustomInstruction"></a>
An inline custom instruction containing text and optional uploaded document metadata.
Type: [InlineCustomInstruction](API_InlineCustomInstruction.md) object
Required: No
