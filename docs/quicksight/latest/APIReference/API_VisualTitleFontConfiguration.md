# VisualTitleFontConfiguration
<a name="API_VisualTitleFontConfiguration"></a>

Configures the display properties of the visual title.

## Contents
<a name="API_VisualTitleFontConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FontConfiguration **   <a name="QS-Type-VisualTitleFontConfiguration-FontConfiguration"></a>
Configures the display properties of the given text.
Type: [FontConfiguration](API_FontConfiguration.md) object
Required: No

 ** TextAlignment **   <a name="QS-Type-VisualTitleFontConfiguration-TextAlignment"></a>
Determines the alignment of visual title.
Type: String
Valid Values: `LEFT | CENTER | RIGHT | AUTO`
Required: No

 ** TextTransform **   <a name="QS-Type-VisualTitleFontConfiguration-TextTransform"></a>
Determines the text transformation of visual title.
Type: String
Valid Values: `CAPITALIZE`
Required: No
