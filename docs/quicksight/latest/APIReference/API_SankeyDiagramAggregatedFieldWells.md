# SankeyDiagramAggregatedFieldWells
<a name="API_SankeyDiagramAggregatedFieldWells"></a>

The field well configuration of a sankey diagram.

## Contents
<a name="API_SankeyDiagramAggregatedFieldWells_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Destination **   <a name="QS-Type-SankeyDiagramAggregatedFieldWells-Destination"></a>
The destination field wells of a sankey diagram.
Type: Array of [DimensionField](API_DimensionField.md) objects
Array Members: Maximum number of 200 items.
Required: No

 ** Source **   <a name="QS-Type-SankeyDiagramAggregatedFieldWells-Source"></a>
The source field wells of a sankey diagram.
Type: Array of [DimensionField](API_DimensionField.md) objects
Array Members: Maximum number of 200 items.
Required: No

 ** Weight **   <a name="QS-Type-SankeyDiagramAggregatedFieldWells-Weight"></a>
The weight field wells of a sankey diagram.
Type: Array of [MeasureField](API_MeasureField.md) objects
Array Members: Maximum number of 200 items.
Required: No
