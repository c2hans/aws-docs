# SnapshotJobErrorInfo
<a name="API_SnapshotJobErrorInfo"></a>

An object that contains information on the error that caused the snapshot job to fail.

For more information, see [DescribeDashboardSnapshotJobResult API](https://docs.aws.amazon.com/quicksight/latest/APIReference/API_DescribeDashboardSnapshotJobResult.html).

## Contents
<a name="API_SnapshotJobErrorInfo_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ErrorMessage **   <a name="QS-Type-SnapshotJobErrorInfo-ErrorMessage"></a>
The error message.
Type: String
Required: No

 ** ErrorType **   <a name="QS-Type-SnapshotJobErrorInfo-ErrorType"></a>
The error type.
Type: String
Required: No
