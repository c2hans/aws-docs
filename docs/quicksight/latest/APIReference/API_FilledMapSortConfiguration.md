# FilledMapSortConfiguration
<a name="API_FilledMapSortConfiguration"></a>

The sort configuration of a `FilledMapVisual`.

<a name="API_FilledMapSortConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** CategorySort **   <a name="QS-Type-FilledMapSortConfiguration-CategorySort"></a>
The sort configuration of the location fields.
Type: Array of [FieldSortOptions](API_FieldSortOptions.md) objects
Array Members: Maximum number of 100 items.
Required: No
