# AssetBundleImportJobError
<a name="API_AssetBundleImportJobError"></a>

Describes an error that occurred within an Asset Bundle import execution.

## Contents
<a name="API_AssetBundleImportJobError_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Arn **   <a name="QS-Type-AssetBundleImportJobError-Arn"></a>
The ARN of the resource whose processing caused an error.
Type: String
Required: No

 ** Message **   <a name="QS-Type-AssetBundleImportJobError-Message"></a>
A description of the error.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Type **   <a name="QS-Type-AssetBundleImportJobError-Type"></a>
The specific error type or the error that occurred.
Type: String
Pattern: `.*\S.*`
Required: No
