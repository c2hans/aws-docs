# ListControlDisplayOptions
<a name="API_ListControlDisplayOptions"></a>

The display options of a control.

## Contents
<a name="API_ListControlDisplayOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** InfoIconLabelOptions **   <a name="QS-Type-ListControlDisplayOptions-InfoIconLabelOptions"></a>
The configuration of info icon label options.
Type: [SheetControlInfoIconLabelOptions](API_SheetControlInfoIconLabelOptions.md) object
Required: No

 ** SearchOptions **   <a name="QS-Type-ListControlDisplayOptions-SearchOptions"></a>
The configuration of the search options in a list control.
Type: [ListControlSearchOptions](API_ListControlSearchOptions.md) object
Required: No

 ** SelectAllOptions **   <a name="QS-Type-ListControlDisplayOptions-SelectAllOptions"></a>
The configuration of the `Select all` options in a list control.
Type: [ListControlSelectAllOptions](API_ListControlSelectAllOptions.md) object
Required: No

 ** TitleOptions **   <a name="QS-Type-ListControlDisplayOptions-TitleOptions"></a>
The options to configure the title visibility, name, and font size.
Type: [LabelOptions](API_LabelOptions.md) object
Required: No
