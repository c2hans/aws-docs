# GeospatialCircleSymbolStyle
<a name="API_GeospatialCircleSymbolStyle"></a>

The properties for a circle symbol style.

## Contents
<a name="API_GeospatialCircleSymbolStyle_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** CircleRadius **   <a name="QS-Type-GeospatialCircleSymbolStyle-CircleRadius"></a>
The radius of the circle.
Type: [GeospatialCircleRadius](API_GeospatialCircleRadius.md) object
Required: No

 ** FillColor **   <a name="QS-Type-GeospatialCircleSymbolStyle-FillColor"></a>
The color and opacity values for the fill color.
Type: [GeospatialColor](API_GeospatialColor.md) object
Required: No

 ** StrokeColor **   <a name="QS-Type-GeospatialCircleSymbolStyle-StrokeColor"></a>
The color and opacity values for the stroke color.
Type: [GeospatialColor](API_GeospatialColor.md) object
Required: No

 ** StrokeWidth **   <a name="QS-Type-GeospatialCircleSymbolStyle-StrokeWidth"></a>
The width of the stroke (border).
Type: [GeospatialLineWidth](API_GeospatialLineWidth.md) object
Required: No
