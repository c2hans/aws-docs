# ColumnSemanticType
<a name="API_ColumnSemanticType"></a>

The semantic type information for a column in the new data preparation experience.

## Contents
<a name="API_ColumnSemanticType_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** GeographicalRole **   <a name="QS-Type-ColumnSemanticType-GeographicalRole"></a>
The geographical role of the column in the new data preparation experience.
Type: String
Valid Values: `COUNTRY | STATE | COUNTY | CITY | POSTCODE | LONGITUDE | LATITUDE`
Required: No
