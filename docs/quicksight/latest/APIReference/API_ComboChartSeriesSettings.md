# ComboChartSeriesSettings
<a name="API_ComboChartSeriesSettings"></a>

Options that determine the presentation of a series in the visual.

## Contents
<a name="API_ComboChartSeriesSettings_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BorderSettings **   <a name="QS-Type-ComboChartSeriesSettings-BorderSettings"></a>
Border settings for the bar series in the visual.
Type: [BorderSettings](API_BorderSettings.md) object
Required: No

 ** DecalSettings **   <a name="QS-Type-ComboChartSeriesSettings-DecalSettings"></a>
Decal settings for the series in the visual.
Type: [DecalSettings](API_DecalSettings.md) object
Required: No

 ** LineStyleSettings **   <a name="QS-Type-ComboChartSeriesSettings-LineStyleSettings"></a>
Line styles options for the line series in the visual.
Type: [LineChartLineStyleSettings](API_LineChartLineStyleSettings.md) object
Required: No

 ** MarkerStyleSettings **   <a name="QS-Type-ComboChartSeriesSettings-MarkerStyleSettings"></a>
Marker styles options for the line series in the visual.
Type: [LineChartMarkerStyleSettings](API_LineChartMarkerStyleSettings.md) object
Required: No
