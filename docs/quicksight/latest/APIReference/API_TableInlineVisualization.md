# TableInlineVisualization
<a name="API_TableInlineVisualization"></a>

The inline visualization of a specific type to display within a chart.

## Contents
<a name="API_TableInlineVisualization_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DataBars **   <a name="QS-Type-TableInlineVisualization-DataBars"></a>
The configuration of the inline visualization of the data bars within a chart.
Type: [DataBarsOptions](API_DataBarsOptions.md) object
Required: No

 ** Sparklines **   <a name="QS-Type-TableInlineVisualization-Sparklines"></a>
The configuration of the inline visualization of the sparklines within a chart.
Type: [SparklinesOptions](API_SparklinesOptions.md) object
Required: No
