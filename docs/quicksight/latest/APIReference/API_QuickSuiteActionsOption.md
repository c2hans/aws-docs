# QuickSuiteActionsOption
<a name="API_QuickSuiteActionsOption"></a>

Determines if Actions in Amazon Quick Suite are enabled in a dashboard..

## Contents
<a name="API_QuickSuiteActionsOption_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AvailabilityStatus **   <a name="QS-Type-QuickSuiteActionsOption-AvailabilityStatus"></a>
Availability status.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: No
