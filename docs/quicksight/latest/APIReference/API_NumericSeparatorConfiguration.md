# NumericSeparatorConfiguration
<a name="API_NumericSeparatorConfiguration"></a>

The options that determine the numeric separator configuration.

## Contents
<a name="API_NumericSeparatorConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DecimalSeparator **   <a name="QS-Type-NumericSeparatorConfiguration-DecimalSeparator"></a>
Determines the decimal separator.
Type: String
Valid Values: `COMMA | DOT | SPACE`
Required: No

 ** ThousandsSeparator **   <a name="QS-Type-NumericSeparatorConfiguration-ThousandsSeparator"></a>
The options that determine the thousands separator configuration.
Type: [ThousandSeparatorOptions](API_ThousandSeparatorOptions.md) object
Required: No
