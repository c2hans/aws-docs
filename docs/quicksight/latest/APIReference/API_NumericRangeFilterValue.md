# NumericRangeFilterValue
<a name="API_NumericRangeFilterValue"></a>

The value input pf the numeric range filter.

## Contents
<a name="API_NumericRangeFilterValue_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Parameter **   <a name="QS-Type-NumericRangeFilterValue-Parameter"></a>
The parameter that is used in the numeric range.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Pattern: `^[a-zA-Z0-9]+$`
Required: No

 ** StaticValue **   <a name="QS-Type-NumericRangeFilterValue-StaticValue"></a>
The static value of the numeric range filter.
Type: Double
Required: No
