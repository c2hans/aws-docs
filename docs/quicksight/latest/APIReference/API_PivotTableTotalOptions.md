# PivotTableTotalOptions
<a name="API_PivotTableTotalOptions"></a>

The total options for a pivot table visual.

## Contents
<a name="API_PivotTableTotalOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ColumnSubtotalOptions **   <a name="QS-Type-PivotTableTotalOptions-ColumnSubtotalOptions"></a>
The column subtotal options.
Type: [SubtotalOptions](API_SubtotalOptions.md) object
Required: No

 ** ColumnTotalOptions **   <a name="QS-Type-PivotTableTotalOptions-ColumnTotalOptions"></a>
The column total options.
Type: [PivotTotalOptions](API_PivotTotalOptions.md) object
Required: No

 ** RowSubtotalOptions **   <a name="QS-Type-PivotTableTotalOptions-RowSubtotalOptions"></a>
The row subtotal options.
Type: [SubtotalOptions](API_SubtotalOptions.md) object
Required: No

 ** RowTotalOptions **   <a name="QS-Type-PivotTableTotalOptions-RowTotalOptions"></a>
The row total options.
Type: [PivotTotalOptions](API_PivotTotalOptions.md) object
Required: No
