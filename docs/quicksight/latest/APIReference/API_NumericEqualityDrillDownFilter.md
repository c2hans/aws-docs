# NumericEqualityDrillDownFilter
<a name="API_NumericEqualityDrillDownFilter"></a>

The numeric equality type drill down filter.

## Contents
<a name="API_NumericEqualityDrillDownFilter_Contents"></a>

In the following list, the required parameters are described first.

 ** Column **   <a name="QS-Type-NumericEqualityDrillDownFilter-Column"></a>

Type: [ColumnIdentifier](API_ColumnIdentifier.md) object
Required: Yes

 ** Value **   <a name="QS-Type-NumericEqualityDrillDownFilter-Value"></a>
The value of the double input numeric drill down filter.
Type: Double
Required: Yes
