# BoxPlotOptions
<a name="API_BoxPlotOptions"></a>

The options of a box plot visual.

## Contents
<a name="API_BoxPlotOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AllDataPointsVisibility **   <a name="QS-Type-BoxPlotOptions-AllDataPointsVisibility"></a>
Determines the visibility of all data points of the box plot.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No

 ** OutlierVisibility **   <a name="QS-Type-BoxPlotOptions-OutlierVisibility"></a>
Determines the visibility of the outlier in a box plot.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No

 ** StyleOptions **   <a name="QS-Type-BoxPlotOptions-StyleOptions"></a>
The style options of the box plot.
Type: [BoxPlotStyleOptions](API_BoxPlotStyleOptions.md) object
Required: No
