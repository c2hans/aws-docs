# BookmarksConfigurations
<a name="API_BookmarksConfigurations"></a>

The bookmarks configuration of an embedded dashboard.

## Contents
<a name="API_BookmarksConfigurations_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Enabled **   <a name="QS-Type-BookmarksConfigurations-Enabled"></a>
A Boolean value that determines whether a user can bookmark an embedded dashboard.
Type: Boolean
Required: Yes
