# StaticFileSource
<a name="API_StaticFileSource"></a>

The source of the static file.

## Contents
<a name="API_StaticFileSource_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** S3Options **   <a name="QS-Type-StaticFileSource-S3Options"></a>
The structure that contains the Amazon S3 location to download the static file from.
Type: [StaticFileS3SourceOptions](API_StaticFileS3SourceOptions.md) object
Required: No

 ** UrlOptions **   <a name="QS-Type-StaticFileSource-UrlOptions"></a>
The structure that contains the URL to download the static file from.
Type: [StaticFileUrlSourceOptions](API_StaticFileUrlSourceOptions.md) object
Required: No
