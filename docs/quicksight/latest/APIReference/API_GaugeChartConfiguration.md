# GaugeChartConfiguration
<a name="API_GaugeChartConfiguration"></a>

The configuration of a `GaugeChartVisual`.

## Contents
<a name="API_GaugeChartConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ColorConfiguration **   <a name="QS-Type-GaugeChartConfiguration-ColorConfiguration"></a>
The color configuration of a `GaugeChartVisual`.
Type: [GaugeChartColorConfiguration](API_GaugeChartColorConfiguration.md) object
Required: No

 ** DataLabels **   <a name="QS-Type-GaugeChartConfiguration-DataLabels"></a>
The data label configuration of a `GaugeChartVisual`.
Type: [DataLabelOptions](API_DataLabelOptions.md) object
Required: No

 ** FieldWells **   <a name="QS-Type-GaugeChartConfiguration-FieldWells"></a>
The field well configuration of a `GaugeChartVisual`.
Type: [GaugeChartFieldWells](API_GaugeChartFieldWells.md) object
Required: No

 ** GaugeChartOptions **   <a name="QS-Type-GaugeChartConfiguration-GaugeChartOptions"></a>
The options that determine the presentation of the `GaugeChartVisual`.
Type: [GaugeChartOptions](API_GaugeChartOptions.md) object
Required: No

 ** Interactions **   <a name="QS-Type-GaugeChartConfiguration-Interactions"></a>
The general visual interactions setup for a visual.
Type: [VisualInteractionOptions](API_VisualInteractionOptions.md) object
Required: No

 ** TooltipOptions **   <a name="QS-Type-GaugeChartConfiguration-TooltipOptions"></a>
The tooltip configuration of a `GaugeChartVisual`.
Type: [TooltipOptions](API_TooltipOptions.md) object
Required: No

 ** VisualPalette **   <a name="QS-Type-GaugeChartConfiguration-VisualPalette"></a>
The visual palette configuration of a `GaugeChartVisual`.
Type: [VisualPalette](API_VisualPalette.md) object
Required: No
