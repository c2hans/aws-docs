# ItemsLimitConfiguration
<a name="API_ItemsLimitConfiguration"></a>

The limit configuration of the visual display for an axis.

## Contents
<a name="API_ItemsLimitConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ItemsLimit **   <a name="QS-Type-ItemsLimitConfiguration-ItemsLimit"></a>
The limit on how many items of a field are showed in the chart. For example, the number of slices that are displayed in a pie chart.
Type: Long
Required: No

 ** OtherCategories **   <a name="QS-Type-ItemsLimitConfiguration-OtherCategories"></a>
The `Show other` of an axis in the chart. Choose one of the following options:
+  `INCLUDE`
+  `EXCLUDE`
Type: String
Valid Values: `INCLUDE | EXCLUDE`
Required: No
