# DropDownControlDisplayOptions
<a name="API_DropDownControlDisplayOptions"></a>

The display options of a control.

## Contents
<a name="API_DropDownControlDisplayOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** InfoIconLabelOptions **   <a name="QS-Type-DropDownControlDisplayOptions-InfoIconLabelOptions"></a>
The configuration of info icon label options.
Type: [SheetControlInfoIconLabelOptions](API_SheetControlInfoIconLabelOptions.md) object
Required: No

 ** SelectAllOptions **   <a name="QS-Type-DropDownControlDisplayOptions-SelectAllOptions"></a>
The configuration of the `Select all` options in a dropdown control.
Type: [ListControlSelectAllOptions](API_ListControlSelectAllOptions.md) object
Required: No

 ** TitleOptions **   <a name="QS-Type-DropDownControlDisplayOptions-TitleOptions"></a>
The options to configure the title visibility, name, and font size.
Type: [LabelOptions](API_LabelOptions.md) object
Required: No
