# NamespaceError
<a name="API_NamespaceError"></a>

Errors that occur during namespace creation.

## Contents
<a name="API_NamespaceError_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Message **   <a name="QS-Type-NamespaceError-Message"></a>
The message for the error.
Type: String
Required: No

 ** Type **   <a name="QS-Type-NamespaceError-Type"></a>
The error type.
Type: String
Valid Values: `PERMISSION_DENIED | INTERNAL_SERVICE_ERROR`
Required: No
