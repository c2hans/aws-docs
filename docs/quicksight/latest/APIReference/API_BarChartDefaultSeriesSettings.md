# BarChartDefaultSeriesSettings
<a name="API_BarChartDefaultSeriesSettings"></a>

The options that determine the default presentation of all bar series in `BarChartVisual`.

## Contents
<a name="API_BarChartDefaultSeriesSettings_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BorderSettings **   <a name="QS-Type-BarChartDefaultSeriesSettings-BorderSettings"></a>
Border settings for all bar series in the visual.
Type: [BorderSettings](API_BorderSettings.md) object
Required: No

 ** DecalSettings **   <a name="QS-Type-BarChartDefaultSeriesSettings-DecalSettings"></a>
Decal settings for all bar series in the visual.
Type: [DecalSettings](API_DecalSettings.md) object
Required: No
