# TableFieldLinkConfiguration
<a name="API_TableFieldLinkConfiguration"></a>

The link configuration of a table field URL.

## Contents
<a name="API_TableFieldLinkConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Content **   <a name="QS-Type-TableFieldLinkConfiguration-Content"></a>
The URL content (text, icon) for the table link configuration.
Type: [TableFieldLinkContentConfiguration](API_TableFieldLinkContentConfiguration.md) object
Required: Yes

 ** Target **   <a name="QS-Type-TableFieldLinkConfiguration-Target"></a>
The URL target (new tab, new window, same tab) for the table link configuration.
Type: String
Valid Values: `NEW_TAB | NEW_WINDOW | SAME_TAB`
Required: Yes
