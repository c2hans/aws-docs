# TextConditionalFormat
<a name="API_TextConditionalFormat"></a>

The conditional formatting for the text.

## Contents
<a name="API_TextConditionalFormat_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BackgroundColor **   <a name="QS-Type-TextConditionalFormat-BackgroundColor"></a>
The conditional formatting for the text background color.
Type: [ConditionalFormattingColor](API_ConditionalFormattingColor.md) object
Required: No

 ** Icon **   <a name="QS-Type-TextConditionalFormat-Icon"></a>
The conditional formatting for the icon.
Type: [ConditionalFormattingIcon](API_ConditionalFormattingIcon.md) object
Required: No

 ** TextColor **   <a name="QS-Type-TextConditionalFormat-TextColor"></a>
The conditional formatting for the text color.
Type: [ConditionalFormattingColor](API_ConditionalFormattingColor.md) object
Required: No
