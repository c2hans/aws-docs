# Layout
<a name="API_Layout"></a>

A `Layout` defines the placement of elements within a sheet.

For more information, see [Types of layout](https://docs.aws.amazon.com/quicksight/latest/user/types-of-layout.html) in the *Amazon Quick Suite User Guide*.

This is a union type structure. For this structure to be valid, only one of the attributes can be defined.

## Contents
<a name="API_Layout_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Configuration **   <a name="QS-Type-Layout-Configuration"></a>
The configuration that determines what the type of layout for a sheet.
Type: [LayoutConfiguration](API_LayoutConfiguration.md) object
Required: Yes
