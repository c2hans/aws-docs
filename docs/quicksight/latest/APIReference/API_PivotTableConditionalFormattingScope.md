# PivotTableConditionalFormattingScope
<a name="API_PivotTableConditionalFormattingScope"></a>

The scope of the cell for conditional formatting.

## Contents
<a name="API_PivotTableConditionalFormattingScope_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Role **   <a name="QS-Type-PivotTableConditionalFormattingScope-Role"></a>
The role (field, field total, grand total) of the cell for conditional formatting.
Type: String
Valid Values: `FIELD | FIELD_TOTAL | GRAND_TOTAL`
Required: No
