# StatePersistenceConfigurations
<a name="API_StatePersistenceConfigurations"></a>

The state perssitence configuration of an embedded dashboard.

## Contents
<a name="API_StatePersistenceConfigurations_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Enabled **   <a name="QS-Type-StatePersistenceConfigurations-Enabled"></a>
Determines if a Quick Sight dashboard's state persistence settings are turned on or off.
Type: Boolean
Required: Yes
