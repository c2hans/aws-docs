# ReadClientCredentialsDetails
<a name="API_ReadClientCredentialsDetails"></a>

Read-only details for OAuth2 client credentials, containing non-sensitive configuration information.

## Contents
<a name="API_ReadClientCredentialsDetails_Contents"></a>

**Note**
In the following list, the required parameters are described first.

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** ReadClientCredentialsGrantDetails **   <a name="QS-Type-ReadClientCredentialsDetails-ReadClientCredentialsGrantDetails"></a>
The read-only client credentials grant configuration details.
Type: [ReadClientCredentialsGrantDetails](API_ReadClientCredentialsGrantDetails.md) object
Required: No
