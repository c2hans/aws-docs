# NumericAxisOptions
<a name="API_NumericAxisOptions"></a>

The options for an axis with a numeric field.

## Contents
<a name="API_NumericAxisOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Range **   <a name="QS-Type-NumericAxisOptions-Range"></a>
The range setup of a numeric axis.
Type: [AxisDisplayRange](API_AxisDisplayRange.md) object
Required: No

 ** Scale **   <a name="QS-Type-NumericAxisOptions-Scale"></a>
The scale setup of a numeric axis.
Type: [AxisScale](API_AxisScale.md) object
Required: No
