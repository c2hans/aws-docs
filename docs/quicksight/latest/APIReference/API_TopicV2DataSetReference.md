# TopicV2DataSetReference
<a name="API_TopicV2DataSetReference"></a>

A structure that represents a data set reference of a topic.

## Contents
<a name="API_TopicV2DataSetReference_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DataSetArn **   <a name="QS-Type-TopicV2DataSetReference-DataSetArn"></a>
The Amazon Resource Name (ARN) of the data set.
Type: String
Required: Yes

 ** DataSetName **   <a name="QS-Type-TopicV2DataSetReference-DataSetName"></a>
The name of the data set.
Type: String
Length Constraints: Maximum length of 256.
Required: No
