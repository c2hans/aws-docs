# GeospatialGradientStepColor
<a name="API_GeospatialGradientStepColor"></a>

The gradient step color for a single step.

## Contents
<a name="API_GeospatialGradientStepColor_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Color **   <a name="QS-Type-GeospatialGradientStepColor-Color"></a>
The color and opacity values for the gradient step color.
Type: String
Pattern: `^#[A-F0-9]{6}(?:[A-F0-9]{2})?$`
Required: Yes

 ** DataValue **   <a name="QS-Type-GeospatialGradientStepColor-DataValue"></a>
The data value for the gradient step color.
Type: Double
Required: Yes
