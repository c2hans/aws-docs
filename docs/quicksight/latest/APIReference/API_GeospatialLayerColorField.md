# GeospatialLayerColorField
<a name="API_GeospatialLayerColorField"></a>

The color field that defines a gradient or categorical style.

## Contents
<a name="API_GeospatialLayerColorField_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ColorDimensionsFields **   <a name="QS-Type-GeospatialLayerColorField-ColorDimensionsFields"></a>
A list of color dimension fields.
Type: Array of [DimensionField](API_DimensionField.md) objects
Array Members: Maximum number of 1 item.
Required: No

 ** ColorValuesFields **   <a name="QS-Type-GeospatialLayerColorField-ColorValuesFields"></a>
A list of color measure fields.
Type: Array of [MeasureField](API_MeasureField.md) objects
Array Members: Maximum number of 1 item.
Required: No
