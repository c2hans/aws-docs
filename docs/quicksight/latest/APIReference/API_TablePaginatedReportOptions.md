# TablePaginatedReportOptions
<a name="API_TablePaginatedReportOptions"></a>

The paginated report options for a table visual.

## Contents
<a name="API_TablePaginatedReportOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** OverflowColumnHeaderVisibility **   <a name="QS-Type-TablePaginatedReportOptions-OverflowColumnHeaderVisibility"></a>
The visibility of repeating header rows on each page.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No

 ** VerticalOverflowVisibility **   <a name="QS-Type-TablePaginatedReportOptions-VerticalOverflowVisibility"></a>
The visibility of printing table overflow across pages.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
