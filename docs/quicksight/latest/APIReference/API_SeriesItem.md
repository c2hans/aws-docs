# SeriesItem
<a name="API_SeriesItem"></a>

The series item configuration of a line chart.

This is a union type structure. For this structure to be valid, only one of the attributes can be defined.

## Contents
<a name="API_SeriesItem_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DataFieldSeriesItem **   <a name="QS-Type-SeriesItem-DataFieldSeriesItem"></a>
The data field series item configuration of a line chart.
Type: [DataFieldSeriesItem](API_DataFieldSeriesItem.md) object
Required: No

 ** FieldSeriesItem **   <a name="QS-Type-SeriesItem-FieldSeriesItem"></a>
The field series item configuration of a line chart.
Type: [FieldSeriesItem](API_FieldSeriesItem.md) object
Required: No
