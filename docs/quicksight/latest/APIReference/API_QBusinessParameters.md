# QBusinessParameters
<a name="API_QBusinessParameters"></a>

The parameters that are required to connect to an Amazon Q Business data source.

## Contents
<a name="API_QBusinessParameters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ApplicationArn **   <a name="QS-Type-QBusinessParameters-ApplicationArn"></a>
The Amazon Resource Name (ARN) of the Amazon Q Business application.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1284.
Pattern: `^arn:[-a-z0-9]*:qbusiness:[-a-z0-9]*:[0-9]{12}:application/.+`
Required: Yes
