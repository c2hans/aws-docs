# GeospatialMapState
<a name="API_GeospatialMapState"></a>

The map state properties for a map.

## Contents
<a name="API_GeospatialMapState_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Bounds **   <a name="QS-Type-GeospatialMapState-Bounds"></a>
The bound options (north, south, west, east) of the geospatial window options.
Type: [GeospatialCoordinateBounds](API_GeospatialCoordinateBounds.md) object
Required: No

 ** MapNavigation **   <a name="QS-Type-GeospatialMapState-MapNavigation"></a>
Enables or disables map navigation for a map.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: No
