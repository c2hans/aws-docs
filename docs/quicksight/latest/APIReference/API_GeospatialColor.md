# GeospatialColor
<a name="API_GeospatialColor"></a>

The visualization properties for solid, gradient, and categorical colors.

## Contents
<a name="API_GeospatialColor_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Categorical **   <a name="QS-Type-GeospatialColor-Categorical"></a>
The visualization properties for the categorical color.
Type: [GeospatialCategoricalColor](API_GeospatialCategoricalColor.md) object
Required: No

 ** Gradient **   <a name="QS-Type-GeospatialColor-Gradient"></a>
The visualization properties for the gradient color.
Type: [GeospatialGradientColor](API_GeospatialGradientColor.md) object
Required: No

 ** Solid **   <a name="QS-Type-GeospatialColor-Solid"></a>
The visualization properties for the solid color.
Type: [GeospatialSolidColor](API_GeospatialSolidColor.md) object
Required: No
