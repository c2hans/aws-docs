# S3TablesParameters
<a name="API_S3TablesParameters"></a>

The parameters for S3 Tables.

## Contents
<a name="API_S3TablesParameters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** TableBucketArn **   <a name="QS-Type-S3TablesParameters-TableBucketArn"></a>
The Amazon Resource Name (ARN) of the S3 Tables bucket.
Type: String
Pattern: `^(arn:aws[-a-z0-9]*:[a-z0-9]+:[-a-z0-9]*:[0-9]{12}:bucket/[a-zA-Z0-9-_]{3,63})$`
Required: No
