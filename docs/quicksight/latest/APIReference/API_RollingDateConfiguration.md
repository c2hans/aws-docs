# RollingDateConfiguration
<a name="API_RollingDateConfiguration"></a>

The rolling date configuration of a date time filter.

## Contents
<a name="API_RollingDateConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Expression **   <a name="QS-Type-RollingDateConfiguration-Expression"></a>
The expression of the rolling date configuration.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Required: Yes

 ** DataSetIdentifier **   <a name="QS-Type-RollingDateConfiguration-DataSetIdentifier"></a>
The data set that is used in the rolling date configuration.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: No
