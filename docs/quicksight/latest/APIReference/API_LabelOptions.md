# LabelOptions
<a name="API_LabelOptions"></a>

The share label options for the labels.

## Contents
<a name="API_LabelOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** CustomLabel **   <a name="QS-Type-LabelOptions-CustomLabel"></a>
The text for the label.
Type: String
Required: No

 ** FontConfiguration **   <a name="QS-Type-LabelOptions-FontConfiguration"></a>
The font configuration of the label.
Type: [FontConfiguration](API_FontConfiguration.md) object
Required: No

 ** Visibility **   <a name="QS-Type-LabelOptions-Visibility"></a>
Determines whether or not the label is visible.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
