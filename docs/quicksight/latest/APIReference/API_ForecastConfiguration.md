# ForecastConfiguration
<a name="API_ForecastConfiguration"></a>

The forecast configuration that is used in a line chart's display properties.

## Contents
<a name="API_ForecastConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ForecastProperties **   <a name="QS-Type-ForecastConfiguration-ForecastProperties"></a>
The forecast properties setup of a forecast in the line chart.
Type: [TimeBasedForecastProperties](API_TimeBasedForecastProperties.md) object
Required: No

 ** Scenario **   <a name="QS-Type-ForecastConfiguration-Scenario"></a>
The forecast scenario of a forecast in the line chart.
Type: [ForecastScenario](API_ForecastScenario.md) object
Required: No
