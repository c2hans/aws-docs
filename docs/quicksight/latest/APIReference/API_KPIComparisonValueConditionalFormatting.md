# KPIComparisonValueConditionalFormatting
<a name="API_KPIComparisonValueConditionalFormatting"></a>

The conditional formatting for the comparison value of a KPI visual.

## Contents
<a name="API_KPIComparisonValueConditionalFormatting_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Icon **   <a name="QS-Type-KPIComparisonValueConditionalFormatting-Icon"></a>
The conditional formatting of the comparison value's icon.
Type: [ConditionalFormattingIcon](API_ConditionalFormattingIcon.md) object
Required: No

 ** TextColor **   <a name="QS-Type-KPIComparisonValueConditionalFormatting-TextColor"></a>
The conditional formatting of the comparison value's text color.
Type: [ConditionalFormattingColor](API_ConditionalFormattingColor.md) object
Required: No
