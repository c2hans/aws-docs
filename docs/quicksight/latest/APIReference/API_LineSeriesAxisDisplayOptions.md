# LineSeriesAxisDisplayOptions
<a name="API_LineSeriesAxisDisplayOptions"></a>

The series axis configuration of a line chart.

## Contents
<a name="API_LineSeriesAxisDisplayOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AxisOptions **   <a name="QS-Type-LineSeriesAxisDisplayOptions-AxisOptions"></a>
The options that determine the presentation of the line series axis.
Type: [AxisDisplayOptions](API_AxisDisplayOptions.md) object
Required: No

 ** MissingDataConfigurations **   <a name="QS-Type-LineSeriesAxisDisplayOptions-MissingDataConfigurations"></a>
The configuration options that determine how missing data is treated during the rendering of a line chart.
Type: Array of [MissingDataConfiguration](API_MissingDataConfiguration.md) objects
Array Members: Maximum number of 100 items.
Required: No
