# AxisScale
<a name="API_AxisScale"></a>

The scale setup options for a numeric axis display.

This is a union type structure. For this structure to be valid, only one of the attributes can be defined.

## Contents
<a name="API_AxisScale_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Linear **   <a name="QS-Type-AxisScale-Linear"></a>
The linear axis scale setup.
Type: [AxisLinearScale](API_AxisLinearScale.md) object
Required: No

 ** Logarithmic **   <a name="QS-Type-AxisScale-Logarithmic"></a>
The logarithmic axis scale setup.
Type: [AxisLogarithmicScale](API_AxisLogarithmicScale.md) object
Required: No
