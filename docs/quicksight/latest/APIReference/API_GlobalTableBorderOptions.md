# GlobalTableBorderOptions
<a name="API_GlobalTableBorderOptions"></a>

Determines the border options for a table visual.

## Contents
<a name="API_GlobalTableBorderOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SideSpecificBorder **   <a name="QS-Type-GlobalTableBorderOptions-SideSpecificBorder"></a>
Determines the options for side specific border.
Type: [TableSideBorderOptions](API_TableSideBorderOptions.md) object
Required: No

 ** UniformBorder **   <a name="QS-Type-GlobalTableBorderOptions-UniformBorder"></a>
Determines the options for uniform border.
Type: [TableBorderOptions](API_TableBorderOptions.md) object
Required: No
