# CustomActionNavigationOperation
<a name="API_CustomActionNavigationOperation"></a>

The navigation operation that navigates between different sheets in the same analysis.

This is a union type structure. For this structure to be valid, only one of the attributes can be defined.

## Contents
<a name="API_CustomActionNavigationOperation_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** LocalNavigationConfiguration **   <a name="QS-Type-CustomActionNavigationOperation-LocalNavigationConfiguration"></a>
The configuration that chooses the navigation target.
Type: [LocalNavigationConfiguration](API_LocalNavigationConfiguration.md) object
Required: No
