# ActionConnectorError
<a name="API_ActionConnectorError"></a>

Contains error information for an action connector that is in an error state.

## Contents
<a name="API_ActionConnectorError_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Message **   <a name="QS-Type-ActionConnectorError-Message"></a>
The error message describing what went wrong with the action connector.
Type: String
Required: No

 ** Type **   <a name="QS-Type-ActionConnectorError-Type"></a>
The type or category of the error.
Type: String
Valid Values: `INTERNAL_FAILURE`
Required: No
