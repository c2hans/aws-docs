# DefaultGridLayoutConfiguration
<a name="API_DefaultGridLayoutConfiguration"></a>

The options that determine the default settings for a grid layout configuration.

## Contents
<a name="API_DefaultGridLayoutConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** CanvasSizeOptions **   <a name="QS-Type-DefaultGridLayoutConfiguration-CanvasSizeOptions"></a>
Determines the screen canvas size options for a grid layout.
Type: [GridLayoutCanvasSizeOptions](API_GridLayoutCanvasSizeOptions.md) object
Required: Yes
