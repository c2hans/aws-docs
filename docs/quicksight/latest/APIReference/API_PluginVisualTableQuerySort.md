# PluginVisualTableQuerySort
<a name="API_PluginVisualTableQuerySort"></a>

The table query sorting options for the plugin visual.

## Contents
<a name="API_PluginVisualTableQuerySort_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ItemsLimitConfiguration **   <a name="QS-Type-PluginVisualTableQuerySort-ItemsLimitConfiguration"></a>
The maximum amount of data to be returned by a query.
Type: [PluginVisualItemsLimitConfiguration](API_PluginVisualItemsLimitConfiguration.md) object
Required: No

 ** RowSort **   <a name="QS-Type-PluginVisualTableQuerySort-RowSort"></a>
Determines how data is sorted in the response.
Type: Array of [FieldSortOptions](API_FieldSortOptions.md) objects
Array Members: Maximum number of 100 items.
Required: No
