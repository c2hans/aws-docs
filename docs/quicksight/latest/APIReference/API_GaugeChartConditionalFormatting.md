# GaugeChartConditionalFormatting
<a name="API_GaugeChartConditionalFormatting"></a>

The conditional formatting of a `GaugeChartVisual`.

## Contents
<a name="API_GaugeChartConditionalFormatting_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ConditionalFormattingOptions **   <a name="QS-Type-GaugeChartConditionalFormatting-ConditionalFormattingOptions"></a>
Conditional formatting options of a `GaugeChartVisual`.
Type: Array of [GaugeChartConditionalFormattingOption](API_GaugeChartConditionalFormattingOption.md) objects
Array Members: Maximum number of 100 items.
Required: No
