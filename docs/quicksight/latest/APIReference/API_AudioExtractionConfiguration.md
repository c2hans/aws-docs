# AudioExtractionConfiguration
<a name="API_AudioExtractionConfiguration"></a>

The configuration for audio extraction from knowledge base documents.

## Contents
<a name="API_AudioExtractionConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** audioExtractionStatus **   <a name="QS-Type-AudioExtractionConfiguration-audioExtractionStatus"></a>
The status of audio extraction. Valid values are ENABLED and DISABLED.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
