# RegisteredUserConsoleFeatureConfigurations
<a name="API_RegisteredUserConsoleFeatureConfigurations"></a>

The feature configurations of an embedded Amazon Quick Sight console.

## Contents
<a name="API_RegisteredUserConsoleFeatureConfigurations_Contents"></a>

**Note**
In the following list, the required parameters are described first.

Type: [AmazonQInQuickSightConsoleConfigurations](API_AmazonQInQuickSightConsoleConfigurations.md) object
Required: No

Required: No
