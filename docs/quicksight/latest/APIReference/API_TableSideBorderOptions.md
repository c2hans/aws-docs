# TableSideBorderOptions
<a name="API_TableSideBorderOptions"></a>

The side border options for a table.

## Contents
<a name="API_TableSideBorderOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Bottom **   <a name="QS-Type-TableSideBorderOptions-Bottom"></a>
The table border options of the bottom border.
Type: [TableBorderOptions](API_TableBorderOptions.md) object
Required: No

 ** InnerHorizontal **   <a name="QS-Type-TableSideBorderOptions-InnerHorizontal"></a>
The table border options of the inner horizontal border.
Type: [TableBorderOptions](API_TableBorderOptions.md) object
Required: No

 ** InnerVertical **   <a name="QS-Type-TableSideBorderOptions-InnerVertical"></a>
The table border options of the inner vertical border.
Type: [TableBorderOptions](API_TableBorderOptions.md) object
Required: No

 ** Left **   <a name="QS-Type-TableSideBorderOptions-Left"></a>
The table border options of the left border.
Type: [TableBorderOptions](API_TableBorderOptions.md) object
Required: No

 ** Right **   <a name="QS-Type-TableSideBorderOptions-Right"></a>
The table border options of the right border.
Type: [TableBorderOptions](API_TableBorderOptions.md) object
Required: No

 ** Top **   <a name="QS-Type-TableSideBorderOptions-Top"></a>
The table border options of the top border.
Type: [TableBorderOptions](API_TableBorderOptions.md) object
Required: No
