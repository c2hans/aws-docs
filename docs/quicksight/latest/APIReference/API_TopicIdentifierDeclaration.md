# TopicIdentifierDeclaration
<a name="API_TopicIdentifierDeclaration"></a>

A topic.

## Contents
<a name="API_TopicIdentifierDeclaration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Identifier **   <a name="QS-Type-TopicIdentifierDeclaration-Identifier"></a>
The identifier of the topic, typically the topic's name.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: Yes

 ** TopicArn **   <a name="QS-Type-TopicIdentifierDeclaration-TopicArn"></a>
The Amazon Resource Name (ARN) of the topic.
Type: String
Required: Yes
