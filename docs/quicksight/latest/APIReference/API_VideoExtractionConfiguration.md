# VideoExtractionConfiguration
<a name="API_VideoExtractionConfiguration"></a>

The configuration for video extraction from knowledge base documents.

## Contents
<a name="API_VideoExtractionConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** videoExtractionStatus **   <a name="QS-Type-VideoExtractionConfiguration-videoExtractionStatus"></a>
The status of video extraction. Valid values are ENABLED and DISABLED.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes

 ** videoExtractionType **   <a name="QS-Type-VideoExtractionConfiguration-videoExtractionType"></a>
The type of video extraction to perform.
Type: String
Valid Values: `AUDIO_TRANSCRIPTION_ONLY | VISUAL_CONTENT_AND_AUDIO_TRANSCRIPTION`
Required: No
