# StaticFileUrlSourceOptions
<a name="API_StaticFileUrlSourceOptions"></a>

In the following list, the required parameters are described first.

 ** Url **   <a name="QS-Type-StaticFileUrlSourceOptions-Url"></a>

Required: Yes
