# DashboardCustomizationSummaryConfigurations
<a name="API_DashboardCustomizationSummaryConfigurations"></a>

The dashboard customization summary configuration for an embedded Quick Sight dashboard.

## Contents
<a name="API_DashboardCustomizationSummaryConfigurations_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Enabled **   <a name="QS-Type-DashboardCustomizationSummaryConfigurations-Enabled"></a>
The enabled status of the dashboard customization summary configuration for an embedded Quick Sight dashboard.
Type: Boolean
Required: Yes
