# AssetBundleImportJobOverrideValidationStrategy
<a name="API_AssetBundleImportJobOverrideValidationStrategy"></a>

An optional parameter that overrides the validation strategy for all analyses and dashboards before the resource is imported.

## Contents
<a name="API_AssetBundleImportJobOverrideValidationStrategy_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** StrictModeForAllResources **   <a name="QS-Type-AssetBundleImportJobOverrideValidationStrategy-StrictModeForAllResources"></a>
A Boolean value that indicates whether to import all analyses and dashboards under strict or lenient mode.
Type: Boolean
Required: No
