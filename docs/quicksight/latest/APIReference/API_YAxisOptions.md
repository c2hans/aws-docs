# YAxisOptions
<a name="API_YAxisOptions"></a>

The options that are available for a single Y axis in a chart.

## Contents
<a name="API_YAxisOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** YAxis **   <a name="QS-Type-YAxisOptions-YAxis"></a>
The Y axis type to be used in the chart.
If you choose `PRIMARY_Y_AXIS`, the primary Y Axis is located on the leftmost vertical axis of the chart.
Type: String
Valid Values: `PRIMARY_Y_AXIS`
Required: Yes
