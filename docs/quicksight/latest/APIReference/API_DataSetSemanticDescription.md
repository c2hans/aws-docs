# DataSetSemanticDescription
<a name="API_DataSetSemanticDescription"></a>

A description structure for dataset-level semantic metadata.

## Contents
<a name="API_DataSetSemanticDescription_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Text **   <a name="QS-Type-DataSetSemanticDescription-Text"></a>
The descriptive text for the dataset.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 500.
Required: Yes
