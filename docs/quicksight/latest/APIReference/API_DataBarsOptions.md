# DataBarsOptions
<a name="API_DataBarsOptions"></a>

The options for data bars.

## Contents
<a name="API_DataBarsOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FieldId **   <a name="QS-Type-DataBarsOptions-FieldId"></a>
The field ID for the data bars options.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: Yes

 ** NegativeColor **   <a name="QS-Type-DataBarsOptions-NegativeColor"></a>
The color of the negative data bar.
Type: String
Pattern: `^#[A-F0-9]{6}$`
Required: No

 ** PositiveColor **   <a name="QS-Type-DataBarsOptions-PositiveColor"></a>
The color of the positive data bar.
Type: String
Pattern: `^#[A-F0-9]{6}$`
Required: No
