# TableConditionalFormattingOption
<a name="API_TableConditionalFormattingOption"></a>

Conditional formatting options for a `PivotTableVisual`.

## Contents
<a name="API_TableConditionalFormattingOption_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Cell **   <a name="QS-Type-TableConditionalFormattingOption-Cell"></a>
The cell conditional formatting option for a table.
Type: [TableCellConditionalFormatting](API_TableCellConditionalFormatting.md) object
Required: No

 ** Row **   <a name="QS-Type-TableConditionalFormattingOption-Row"></a>
The row conditional formatting option for a table.
Type: [TableRowConditionalFormatting](API_TableRowConditionalFormatting.md) object
Required: No
