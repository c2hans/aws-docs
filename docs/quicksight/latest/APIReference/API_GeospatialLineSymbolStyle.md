# GeospatialLineSymbolStyle
<a name="API_GeospatialLineSymbolStyle"></a>

The symbol style for a line layer.

## Contents
<a name="API_GeospatialLineSymbolStyle_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FillColor **   <a name="QS-Type-GeospatialLineSymbolStyle-FillColor"></a>
The color and opacity values for the fill color.
Type: [GeospatialColor](API_GeospatialColor.md) object
Required: No

 ** LineWidth **   <a name="QS-Type-GeospatialLineSymbolStyle-LineWidth"></a>
The width value for a line.
Type: [GeospatialLineWidth](API_GeospatialLineWidth.md) object
Required: No
