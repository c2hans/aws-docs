# PerformanceConfiguration
<a name="API_PerformanceConfiguration"></a>

The configuration for the performance optimization of the dataset that contains a `UniqueKey` configuration.

## Contents
<a name="API_PerformanceConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** UniqueKeys **   <a name="QS-Type-PerformanceConfiguration-UniqueKeys"></a>
A `UniqueKey` configuration.
Type: Array of [UniqueKey](API_UniqueKey.md) objects
Array Members: Fixed number of 1 item.
Required: No
