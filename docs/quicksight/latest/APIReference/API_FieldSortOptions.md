# FieldSortOptions
<a name="API_FieldSortOptions"></a>

The field sort options in a chart configuration.

## Contents
<a name="API_FieldSortOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ColumnSort **   <a name="QS-Type-FieldSortOptions-ColumnSort"></a>
The sort configuration for a column that is not used in a field well.
Type: [ColumnSort](API_ColumnSort.md) object
Required: No

 ** FieldSort **   <a name="QS-Type-FieldSortOptions-FieldSort"></a>
The sort configuration for a field in a field well.
Type: [FieldSort](API_FieldSort.md) object
Required: No
