# GeospatialMapConfiguration
<a name="API_GeospatialMapConfiguration"></a>

The configuration of a `GeospatialMapVisual`.

## Contents
<a name="API_GeospatialMapConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FieldWells **   <a name="QS-Type-GeospatialMapConfiguration-FieldWells"></a>
The field wells of the visual.
Type: [GeospatialMapFieldWells](API_GeospatialMapFieldWells.md) object
Required: No

 ** Interactions **   <a name="QS-Type-GeospatialMapConfiguration-Interactions"></a>
The general visual interactions setup for a visual.
Type: [VisualInteractionOptions](API_VisualInteractionOptions.md) object
Required: No

 ** Legend **   <a name="QS-Type-GeospatialMapConfiguration-Legend"></a>
The legend display setup of the visual.
Type: [LegendOptions](API_LegendOptions.md) object
Required: No

 ** MapStyleOptions **   <a name="QS-Type-GeospatialMapConfiguration-MapStyleOptions"></a>
The map style options of the geospatial map.
Type: [GeospatialMapStyleOptions](API_GeospatialMapStyleOptions.md) object
Required: No

 ** PointStyleOptions **   <a name="QS-Type-GeospatialMapConfiguration-PointStyleOptions"></a>
The point style options of the geospatial map.
Type: [GeospatialPointStyleOptions](API_GeospatialPointStyleOptions.md) object
Required: No

 ** Tooltip **   <a name="QS-Type-GeospatialMapConfiguration-Tooltip"></a>
The tooltip display setup of the visual.
Type: [TooltipOptions](API_TooltipOptions.md) object
Required: No

 ** VisualPalette **   <a name="QS-Type-GeospatialMapConfiguration-VisualPalette"></a>
The visual display options for the visual palette.
Type: [VisualPalette](API_VisualPalette.md) object
Required: No

 ** WindowOptions **   <a name="QS-Type-GeospatialMapConfiguration-WindowOptions"></a>
The window options of the geospatial map.
Type: [GeospatialWindowOptions](API_GeospatialWindowOptions.md) object
Required: No
