# SheetImageTooltipConfiguration
<a name="API_SheetImageTooltipConfiguration"></a>

The tooltip configuration for a sheet image.

## Contents
<a name="API_SheetImageTooltipConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** TooltipText **   <a name="QS-Type-SheetImageTooltipConfiguration-TooltipText"></a>
The text that appears in the tooltip.
Type: [SheetImageTooltipText](API_SheetImageTooltipText.md) object
Required: No

 ** Visibility **   <a name="QS-Type-SheetImageTooltipConfiguration-Visibility"></a>
The visibility of the tooltip.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
