# CustomActionFilterOperation
<a name="API_CustomActionFilterOperation"></a>

The filter operation that filters data included in a visual or in an entire sheet.

## Contents
<a name="API_CustomActionFilterOperation_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SelectedFieldsConfiguration **   <a name="QS-Type-CustomActionFilterOperation-SelectedFieldsConfiguration"></a>
The configuration that chooses the fields to be filtered.
Type: [FilterOperationSelectedFieldsConfiguration](API_FilterOperationSelectedFieldsConfiguration.md) object
Required: Yes

 ** TargetVisualsConfiguration **   <a name="QS-Type-CustomActionFilterOperation-TargetVisualsConfiguration"></a>
The configuration that chooses the target visuals to be filtered.
Type: [FilterOperationTargetVisualsConfiguration](API_FilterOperationTargetVisualsConfiguration.md) object
Required: Yes
