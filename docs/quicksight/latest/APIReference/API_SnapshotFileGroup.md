# SnapshotFileGroup
<a name="API_SnapshotFileGroup"></a>

A structure that contains the information on the snapshot files.

## Contents
<a name="API_SnapshotFileGroup_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Files **   <a name="QS-Type-SnapshotFileGroup-Files"></a>
A list of `SnapshotFile` objects that contain the information on the snapshot files that need to be generated. This structure can hold 1 configuration at a time.
Type: Array of [SnapshotFile](API_SnapshotFile.md) objects
Array Members: Fixed number of 1 item.
Required: No
