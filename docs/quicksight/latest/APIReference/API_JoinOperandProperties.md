# JoinOperandProperties
<a name="API_JoinOperandProperties"></a>

Properties that control how columns are handled for a join operand, including column name overrides.

## Contents
<a name="API_JoinOperandProperties_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** OutputColumnNameOverrides **   <a name="QS-Type-JoinOperandProperties-OutputColumnNameOverrides"></a>
A list of column name overrides to apply to the join operand's output columns.
Type: Array of [OutputColumnNameOverride](API_OutputColumnNameOverride.md) objects
Array Members: Minimum number of 1 item. Maximum number of 2048 items.
Required: Yes
