# TopicReference
<a name="API_TopicReference"></a>

Topic reference.

## Contents
<a name="API_TopicReference_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** TopicArn **   <a name="QS-Type-TopicReference-TopicArn"></a>
Topic Amazon Resource Name (ARN).
Type: String
Required: Yes

 ** TopicPlaceholder **   <a name="QS-Type-TopicReference-TopicPlaceholder"></a>
Topic placeholder.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: Yes
