# FreeFormLayoutScreenCanvasSizeOptions
<a name="API_FreeFormLayoutScreenCanvasSizeOptions"></a>

The options that determine the sizing of the canvas used in a free-form layout.

## Contents
<a name="API_FreeFormLayoutScreenCanvasSizeOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** OptimizedViewPortWidth **   <a name="QS-Type-FreeFormLayoutScreenCanvasSizeOptions-OptimizedViewPortWidth"></a>
The width that the view port will be optimized for when the layout renders.
Type: String
Required: Yes
