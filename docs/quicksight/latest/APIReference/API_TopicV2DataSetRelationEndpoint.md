# TopicV2DataSetRelationEndpoint
<a name="API_TopicV2DataSetRelationEndpoint"></a>

A structure that represents an endpoint of a data set relation of a topic.

## Contents
<a name="API_TopicV2DataSetRelationEndpoint_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ColumnNames **   <a name="QS-Type-TopicV2DataSetRelationEndpoint-ColumnNames"></a>
The names of the columns that are used in the data set relation.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 5 items.
Required: Yes

 ** DataSetArn **   <a name="QS-Type-TopicV2DataSetRelationEndpoint-DataSetArn"></a>
The Amazon Resource Name (ARN) of the data set at this endpoint of the relation.
Type: String
Required: Yes
