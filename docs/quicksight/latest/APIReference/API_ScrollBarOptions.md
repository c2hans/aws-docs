# ScrollBarOptions
<a name="API_ScrollBarOptions"></a>

The visual display options for a data zoom scroll bar.

## Contents
<a name="API_ScrollBarOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Visibility **   <a name="QS-Type-ScrollBarOptions-Visibility"></a>
The visibility of the data zoom scroll bar.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No

 ** VisibleRange **   <a name="QS-Type-ScrollBarOptions-VisibleRange"></a>
The visibility range for the data zoom scroll bar.
Type: [VisibleRangeOptions](API_VisibleRangeOptions.md) object
Required: No
