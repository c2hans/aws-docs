# SqlServerParameters
<a name="API_SqlServerParameters"></a>

The parameters for SQL Server.

## Contents
<a name="API_SqlServerParameters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Database **   <a name="QS-Type-SqlServerParameters-Database"></a>
Database.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** Host **   <a name="QS-Type-SqlServerParameters-Host"></a>
Host.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes

 ** Port **   <a name="QS-Type-SqlServerParameters-Port"></a>
Port.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 65535.
Required: Yes
