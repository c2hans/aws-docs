# RadarChartSortConfiguration
<a name="API_RadarChartSortConfiguration"></a>

The sort configuration of a `RadarChartVisual`.

## Contents
<a name="API_RadarChartSortConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** CategoryItemsLimit **   <a name="QS-Type-RadarChartSortConfiguration-CategoryItemsLimit"></a>
The category items limit for a radar chart.
Type: [ItemsLimitConfiguration](API_ItemsLimitConfiguration.md) object
Required: No

 ** CategorySort **   <a name="QS-Type-RadarChartSortConfiguration-CategorySort"></a>
The category sort options of a radar chart.
Type: Array of [FieldSortOptions](API_FieldSortOptions.md) objects
Array Members: Maximum number of 100 items.
Required: No

 ** ColorItemsLimit **   <a name="QS-Type-RadarChartSortConfiguration-ColorItemsLimit"></a>
The color items limit of a radar chart.
Type: [ItemsLimitConfiguration](API_ItemsLimitConfiguration.md) object
Required: No

 ** ColorSort **   <a name="QS-Type-RadarChartSortConfiguration-ColorSort"></a>
The color sort configuration of a radar chart.
Type: Array of [FieldSortOptions](API_FieldSortOptions.md) objects
Array Members: Maximum number of 100 items.
Required: No
