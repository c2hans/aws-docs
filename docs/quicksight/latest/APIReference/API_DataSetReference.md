# DataSetReference
<a name="API_DataSetReference"></a>

Dataset reference.

## Contents
<a name="API_DataSetReference_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DataSetArn **   <a name="QS-Type-DataSetReference-DataSetArn"></a>
Dataset Amazon Resource Name (ARN).
Type: String
Required: Yes

 ** DataSetPlaceholder **   <a name="QS-Type-DataSetReference-DataSetPlaceholder"></a>
Dataset placeholder.
Type: String
Pattern: `.*\S.*`
Required: Yes
