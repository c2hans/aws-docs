# PivotTablePaginatedReportOptions
<a name="API_PivotTablePaginatedReportOptions"></a>

The paginated report options for a pivot table visual.

## Contents
<a name="API_PivotTablePaginatedReportOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** OverflowColumnHeaderVisibility **   <a name="QS-Type-PivotTablePaginatedReportOptions-OverflowColumnHeaderVisibility"></a>
The visibility of the repeating header rows on each page.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No

 ** VerticalOverflowVisibility **   <a name="QS-Type-PivotTablePaginatedReportOptions-VerticalOverflowVisibility"></a>
The visibility of the printing table overflow across pages.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
