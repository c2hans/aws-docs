# VisualSubtitleLabelOptions
<a name="API_VisualSubtitleLabelOptions"></a>

The subtitle label options for a visual.

## Contents
<a name="API_VisualSubtitleLabelOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FormatText **   <a name="QS-Type-VisualSubtitleLabelOptions-FormatText"></a>
The long text format of the subtitle label, such as plain text or rich text.
Type: [LongFormatText](API_LongFormatText.md) object
Required: No

 ** Visibility **   <a name="QS-Type-VisualSubtitleLabelOptions-Visibility"></a>
The visibility of the subtitle label.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
