# GridLayoutConfiguration
<a name="API_GridLayoutConfiguration"></a>

The configuration for a grid layout. Also called a tiled layout.

Visuals snap to a grid with standard spacing and alignment. Dashboards are displayed as designed, with options to fit to screen or view at actual size.

## Contents
<a name="API_GridLayoutConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Elements **   <a name="QS-Type-GridLayoutConfiguration-Elements"></a>
The elements that are included in a grid layout.
Type: Array of [GridLayoutElement](API_GridLayoutElement.md) objects
Array Members: Maximum number of 430 items.
Required: Yes

 ** CanvasSizeOptions **   <a name="QS-Type-GridLayoutConfiguration-CanvasSizeOptions"></a>
Configuration options for the canvas of a grid layout.
Type: [GridLayoutCanvasSizeOptions](API_GridLayoutCanvasSizeOptions.md) object
Required: No
