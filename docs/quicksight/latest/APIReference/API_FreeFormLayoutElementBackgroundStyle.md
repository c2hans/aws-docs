# FreeFormLayoutElementBackgroundStyle
<a name="API_FreeFormLayoutElementBackgroundStyle"></a>

The background style configuration of a free-form layout element.

## Contents
<a name="API_FreeFormLayoutElementBackgroundStyle_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Color **   <a name="QS-Type-FreeFormLayoutElementBackgroundStyle-Color"></a>
The background color of a free-form layout element.
Type: String
Pattern: `^#[A-F0-9]{6}(?:[A-F0-9]{2})?$`
Required: No

 ** Visibility **   <a name="QS-Type-FreeFormLayoutElementBackgroundStyle-Visibility"></a>
The background visibility of a free-form layout element.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
