# TileStyle
<a name="API_TileStyle"></a>

Display options related to tiles on a sheet.

## Contents
<a name="API_TileStyle_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BackgroundColor **   <a name="QS-Type-TileStyle-BackgroundColor"></a>
The background color of a tile.
Type: String
Required: No

 ** Border **   <a name="QS-Type-TileStyle-Border"></a>
The border around a tile.
Type: [BorderStyle](API_BorderStyle.md) object
Required: No

 ** BorderRadius **   <a name="QS-Type-TileStyle-BorderRadius"></a>
The border radius of a tile.
Type: String
Length Constraints: Maximum length of 50.
Required: No

 ** Padding **   <a name="QS-Type-TileStyle-Padding"></a>
The padding of a tile.
Type: String
Length Constraints: Maximum length of 200.
Required: No
