# SnapshotJobResultFileGroup
<a name="API_SnapshotJobResultFileGroup"></a>

A structure that contains information on the generated snapshot file groups.

## Contents
<a name="API_SnapshotJobResultFileGroup_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Files **   <a name="QS-Type-SnapshotJobResultFileGroup-Files"></a>
 A list of `SnapshotFile` objects.
Type: Array of [SnapshotFile](API_SnapshotFile.md) objects
Array Members: Fixed number of 1 item.
Required: No

 ** S3Results **   <a name="QS-Type-SnapshotJobResultFileGroup-S3Results"></a>
 A list of `SnapshotJobS3Result` objects.
Type: Array of [SnapshotJobS3Result](API_SnapshotJobS3Result.md) objects
Required: No
