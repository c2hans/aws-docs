# ComboChartDefaultSeriesSettings
<a name="API_ComboChartDefaultSeriesSettings"></a>

The options that determine the default presentation of all series in `ComboChartVisual`.

## Contents
<a name="API_ComboChartDefaultSeriesSettings_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BorderSettings **   <a name="QS-Type-ComboChartDefaultSeriesSettings-BorderSettings"></a>
Border settings for all bar series in the visual.
Type: [BorderSettings](API_BorderSettings.md) object
Required: No

 ** DecalSettings **   <a name="QS-Type-ComboChartDefaultSeriesSettings-DecalSettings"></a>
Decal settings for all series in the visual.
Type: [DecalSettings](API_DecalSettings.md) object
Required: No

 ** LineStyleSettings **   <a name="QS-Type-ComboChartDefaultSeriesSettings-LineStyleSettings"></a>
Line styles options for all line series in the visual.
Type: [LineChartLineStyleSettings](API_LineChartLineStyleSettings.md) object
Required: No

 ** MarkerStyleSettings **   <a name="QS-Type-ComboChartDefaultSeriesSettings-MarkerStyleSettings"></a>
Marker styles options for all line series in the visual.
Type: [LineChartMarkerStyleSettings](API_LineChartMarkerStyleSettings.md) object
Required: No
