# SpatialStaticFile
<a name="API_SpatialStaticFile"></a>

A static file that contains the geospatial data.

## Contents
<a name="API_SpatialStaticFile_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** StaticFileId **   <a name="QS-Type-SpatialStaticFile-StaticFileId"></a>
The ID of the spatial static file.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Pattern: `[\w\-]+`
Required: Yes

 ** Source **   <a name="QS-Type-SpatialStaticFile-Source"></a>
The source of the spatial static file.
Type: [StaticFileSource](API_StaticFileSource.md) object
Required: No
