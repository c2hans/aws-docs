# AssetBundleImportJobTopicV2OverrideParameters
<a name="API_AssetBundleImportJobTopicV2OverrideParameters"></a>

The override parameters for a single topic that is being imported.

## Contents
<a name="API_AssetBundleImportJobTopicV2OverrideParameters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** TopicId **   <a name="QS-Type-AssetBundleImportJobTopicV2OverrideParameters-TopicId"></a>
The ID of the topic that you want to apply overrides to.
Type: String
Required: Yes

 ** Description **   <a name="QS-Type-AssetBundleImportJobTopicV2OverrideParameters-Description"></a>
A new description for the topic.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `.*\S.*`
Required: No

 ** Name **   <a name="QS-Type-AssetBundleImportJobTopicV2OverrideParameters-Name"></a>
A new name for the topic.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: No
