# RelativeDateTimeControlDisplayOptions
<a name="API_RelativeDateTimeControlDisplayOptions"></a>

The display options of a control.

## Contents
<a name="API_RelativeDateTimeControlDisplayOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DateTimeFormat **   <a name="QS-Type-RelativeDateTimeControlDisplayOptions-DateTimeFormat"></a>
Customize how dates are formatted in controls.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: No

 ** InfoIconLabelOptions **   <a name="QS-Type-RelativeDateTimeControlDisplayOptions-InfoIconLabelOptions"></a>
The configuration of info icon label options.
Type: [SheetControlInfoIconLabelOptions](API_SheetControlInfoIconLabelOptions.md) object
Required: No

 ** TitleOptions **   <a name="QS-Type-RelativeDateTimeControlDisplayOptions-TitleOptions"></a>
The options to configure the title visibility, name, and font size.
Type: [LabelOptions](API_LabelOptions.md) object
Required: No
