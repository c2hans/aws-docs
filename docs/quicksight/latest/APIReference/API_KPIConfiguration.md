# KPIConfiguration
<a name="API_KPIConfiguration"></a>

The configuration of a KPI visual.

## Contents
<a name="API_KPIConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FieldWells **   <a name="QS-Type-KPIConfiguration-FieldWells"></a>
The field well configuration of a KPI visual.
Type: [KPIFieldWells](API_KPIFieldWells.md) object
Required: No

 ** Interactions **   <a name="QS-Type-KPIConfiguration-Interactions"></a>
The general visual interactions setup for a visual.
Type: [VisualInteractionOptions](API_VisualInteractionOptions.md) object
Required: No

 ** KPIOptions **   <a name="QS-Type-KPIConfiguration-KPIOptions"></a>
The options that determine the presentation of a KPI visual.
Type: [KPIOptions](API_KPIOptions.md) object
Required: No

 ** SortConfiguration **   <a name="QS-Type-KPIConfiguration-SortConfiguration"></a>
The sort configuration of a KPI visual.
Type: [KPISortConfiguration](API_KPISortConfiguration.md) object
Required: No
