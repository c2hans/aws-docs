# GeospatialMapStyleOptions
<a name="API_GeospatialMapStyleOptions"></a>

The map style options of the geospatial map.

## Contents
<a name="API_GeospatialMapStyleOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BaseMapStyle **   <a name="QS-Type-GeospatialMapStyleOptions-BaseMapStyle"></a>
The base map style of the geospatial map.
Type: String
Valid Values: `LIGHT_GRAY | DARK_GRAY | STREET | IMAGERY`
Required: No
