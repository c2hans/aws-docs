# GeospatialLayerMapConfiguration
<a name="API_GeospatialLayerMapConfiguration"></a>

The map definition that defines map state, map style, and geospatial layers.

## Contents
<a name="API_GeospatialLayerMapConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Interactions **   <a name="QS-Type-GeospatialLayerMapConfiguration-Interactions"></a>
The general visual interactions setup for visual publish options
Type: [VisualInteractionOptions](API_VisualInteractionOptions.md) object
Required: No

 ** Legend **   <a name="QS-Type-GeospatialLayerMapConfiguration-Legend"></a>
The options for the legend setup of a visual.
Type: [LegendOptions](API_LegendOptions.md) object
Required: No

 ** MapLayers **   <a name="QS-Type-GeospatialLayerMapConfiguration-MapLayers"></a>
The geospatial layers to visualize on the map.
Type: Array of [GeospatialLayerItem](API_GeospatialLayerItem.md) objects
Required: No

 ** MapState **   <a name="QS-Type-GeospatialLayerMapConfiguration-MapState"></a>
The map state properties for the map.
Type: [GeospatialMapState](API_GeospatialMapState.md) object
Required: No

 ** MapStyle **   <a name="QS-Type-GeospatialLayerMapConfiguration-MapStyle"></a>
The map style properties for the map.
Type: [GeospatialMapStyle](API_GeospatialMapStyle.md) object
Required: No
