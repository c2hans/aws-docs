# DefaultInteractiveLayoutConfiguration
<a name="API_DefaultInteractiveLayoutConfiguration"></a>

The options that determine the default settings for interactive layout configuration.

## Contents
<a name="API_DefaultInteractiveLayoutConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FreeForm **   <a name="QS-Type-DefaultInteractiveLayoutConfiguration-FreeForm"></a>
The options that determine the default settings of a free-form layout configuration.
Type: [DefaultFreeFormLayoutConfiguration](API_DefaultFreeFormLayoutConfiguration.md) object
Required: No

 ** Grid **   <a name="QS-Type-DefaultInteractiveLayoutConfiguration-Grid"></a>
The options that determine the default settings for a grid layout configuration.
Type: [DefaultGridLayoutConfiguration](API_DefaultGridLayoutConfiguration.md) object
Required: No
