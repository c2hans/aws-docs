# ComparisonConfiguration
<a name="API_ComparisonConfiguration"></a>

The comparison display configuration of a KPI or gauge chart.

## Contents
<a name="API_ComparisonConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ComparisonFormat **   <a name="QS-Type-ComparisonConfiguration-ComparisonFormat"></a>
The format of the comparison.
Type: [ComparisonFormatConfiguration](API_ComparisonFormatConfiguration.md) object
Required: No

 ** ComparisonMethod **   <a name="QS-Type-ComparisonConfiguration-ComparisonMethod"></a>
The method of the comparison. Choose from the following options:
+  `DIFFERENCE`
+  `PERCENT_DIFFERENCE`
+  `PERCENT`
Type: String
Valid Values: `DIFFERENCE | PERCENT_DIFFERENCE | PERCENT`
Required: No
