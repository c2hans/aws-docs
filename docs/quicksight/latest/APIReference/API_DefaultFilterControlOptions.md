# DefaultFilterControlOptions
<a name="API_DefaultFilterControlOptions"></a>

The option that corresponds to the control type of the filter.

## Contents
<a name="API_DefaultFilterControlOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DefaultDateTimePickerOptions **   <a name="QS-Type-DefaultFilterControlOptions-DefaultDateTimePickerOptions"></a>
The default options that correspond to the filter control type of a `DateTimePicker`.
Type: [DefaultDateTimePickerControlOptions](API_DefaultDateTimePickerControlOptions.md) object
Required: No

 ** DefaultDropdownOptions **   <a name="QS-Type-DefaultFilterControlOptions-DefaultDropdownOptions"></a>
The default options that correspond to the `Dropdown` filter control type.
Type: [DefaultFilterDropDownControlOptions](API_DefaultFilterDropDownControlOptions.md) object
Required: No

 ** DefaultListOptions **   <a name="QS-Type-DefaultFilterControlOptions-DefaultListOptions"></a>
The default options that correspond to the `List` filter control type.
Type: [DefaultFilterListControlOptions](API_DefaultFilterListControlOptions.md) object
Required: No

 ** DefaultRelativeDateTimeOptions **   <a name="QS-Type-DefaultFilterControlOptions-DefaultRelativeDateTimeOptions"></a>
The default options that correspond to the `RelativeDateTime` filter control type.
Type: [DefaultRelativeDateTimeControlOptions](API_DefaultRelativeDateTimeControlOptions.md) object
Required: No

 ** DefaultSliderOptions **   <a name="QS-Type-DefaultFilterControlOptions-DefaultSliderOptions"></a>
The default options that correspond to the `Slider` filter control type.
Type: [DefaultSliderControlOptions](API_DefaultSliderControlOptions.md) object
Required: No

 ** DefaultTextAreaOptions **   <a name="QS-Type-DefaultFilterControlOptions-DefaultTextAreaOptions"></a>
The default options that correspond to the `TextArea` filter control type.
Type: [DefaultTextAreaControlOptions](API_DefaultTextAreaControlOptions.md) object
Required: No

 ** DefaultTextFieldOptions **   <a name="QS-Type-DefaultFilterControlOptions-DefaultTextFieldOptions"></a>
The default options that correspond to the `TextField` filter control type.
Type: [DefaultTextFieldControlOptions](API_DefaultTextFieldControlOptions.md) object
Required: No
