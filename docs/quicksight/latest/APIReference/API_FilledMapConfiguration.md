# FilledMapConfiguration
<a name="API_FilledMapConfiguration"></a>

The configuration for a `FilledMapVisual`.

## Contents
<a name="API_FilledMapConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FieldWells **   <a name="QS-Type-FilledMapConfiguration-FieldWells"></a>
The field wells of the visual.
Type: [FilledMapFieldWells](API_FilledMapFieldWells.md) object
Required: No

 ** Interactions **   <a name="QS-Type-FilledMapConfiguration-Interactions"></a>
The general visual interactions setup for a visual.
Type: [VisualInteractionOptions](API_VisualInteractionOptions.md) object
Required: No

 ** Legend **   <a name="QS-Type-FilledMapConfiguration-Legend"></a>
The legend display setup of the visual.
Type: [LegendOptions](API_LegendOptions.md) object
Required: No

 ** MapStyleOptions **   <a name="QS-Type-FilledMapConfiguration-MapStyleOptions"></a>
The map style options of the filled map visual.
Type: [GeospatialMapStyleOptions](API_GeospatialMapStyleOptions.md) object
Required: No

 ** SortConfiguration **   <a name="QS-Type-FilledMapConfiguration-SortConfiguration"></a>
The sort configuration of a `FilledMapVisual`.
Type: [FilledMapSortConfiguration](API_FilledMapSortConfiguration.md) object
Required: No

 ** Tooltip **   <a name="QS-Type-FilledMapConfiguration-Tooltip"></a>
The tooltip display setup of the visual.
Type: [TooltipOptions](API_TooltipOptions.md) object
Required: No

 ** WindowOptions **   <a name="QS-Type-FilledMapConfiguration-WindowOptions"></a>
The window options of the filled map visual.
Type: [GeospatialWindowOptions](API_GeospatialWindowOptions.md) object
Required: No
