# ColumnSemanticProperty
<a name="API_ColumnSemanticProperty"></a>

A semantic property for a column.

## Contents
<a name="API_ColumnSemanticProperty_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AdditionalNotes **   <a name="QS-Type-ColumnSemanticProperty-AdditionalNotes"></a>
Additional notes for the column.
Type: [AdditionalNotes](API_AdditionalNotes.md) object
Required: No

 ** Description **   <a name="QS-Type-ColumnSemanticProperty-Description"></a>
A description of the column.
Type: [ColumnDescription](API_ColumnDescription.md) object
Required: No

 ** SemanticType **   <a name="QS-Type-ColumnSemanticProperty-SemanticType"></a>
The semantic type of the column.
Type: [ColumnSemanticType](API_ColumnSemanticType.md) object
Required: No
