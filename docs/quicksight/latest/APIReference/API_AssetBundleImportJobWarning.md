# AssetBundleImportJobWarning
<a name="API_AssetBundleImportJobWarning"></a>

Describes a warning that occurred during an Asset Bundle import job.

## Contents
<a name="API_AssetBundleImportJobWarning_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Arn **   <a name="QS-Type-AssetBundleImportJobWarning-Arn"></a>
The ARN of the resource that the warning occurred for.
Type: String
Required: No

 ** Message **   <a name="QS-Type-AssetBundleImportJobWarning-Message"></a>
A description of the warning that occurred during an Asset Bundle import job.
Type: String
Pattern: `.*\S.*`
Required: No
