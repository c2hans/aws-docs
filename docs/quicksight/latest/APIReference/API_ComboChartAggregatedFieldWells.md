# ComboChartAggregatedFieldWells
<a name="API_ComboChartAggregatedFieldWells"></a>

The aggregated field wells of a combo chart.

## Contents
<a name="API_ComboChartAggregatedFieldWells_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BarValues **   <a name="QS-Type-ComboChartAggregatedFieldWells-BarValues"></a>
The aggregated `BarValues` field well of a combo chart.
Type: Array of [MeasureField](API_MeasureField.md) objects
Array Members: Maximum number of 200 items.
Required: No

 ** Category **   <a name="QS-Type-ComboChartAggregatedFieldWells-Category"></a>
The aggregated category field wells of a combo chart.
Type: Array of [DimensionField](API_DimensionField.md) objects
Array Members: Maximum number of 200 items.
Required: No

 ** Colors **   <a name="QS-Type-ComboChartAggregatedFieldWells-Colors"></a>
The aggregated colors field well of a combo chart.
Type: Array of [DimensionField](API_DimensionField.md) objects
Array Members: Maximum number of 200 items.
Required: No

 ** LineValues **   <a name="QS-Type-ComboChartAggregatedFieldWells-LineValues"></a>
The aggregated `LineValues` field well of a combo chart.
Type: Array of [MeasureField](API_MeasureField.md) objects
Array Members: Maximum number of 200 items.
Required: No
