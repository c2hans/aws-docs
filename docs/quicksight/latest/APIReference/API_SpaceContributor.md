# SpaceContributor
<a name="API_SpaceContributor"></a>

A contributor to an Amazon QuickSight space.

## Contents
<a name="API_SpaceContributor_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** rawFileSizeBytes **   <a name="QS-Type-SpaceContributor-rawFileSizeBytes"></a>
The raw file size in bytes contributed by the user.
Type: Long
Required: Yes

 ** percentage **   <a name="QS-Type-SpaceContributor-percentage"></a>
The percentage of total contributions made by the user.
Type: Double
Required: No

 ** userName **   <a name="QS-Type-SpaceContributor-userName"></a>
The user name of the contributor.
Type: String
Required: No
