# SliderControlDisplayOptions
<a name="API_SliderControlDisplayOptions"></a>

The display options of a control.

## Contents
<a name="API_SliderControlDisplayOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** InfoIconLabelOptions **   <a name="QS-Type-SliderControlDisplayOptions-InfoIconLabelOptions"></a>
The configuration of info icon label options.
Type: [SheetControlInfoIconLabelOptions](API_SheetControlInfoIconLabelOptions.md) object
Required: No

 ** TitleOptions **   <a name="QS-Type-SliderControlDisplayOptions-TitleOptions"></a>
The options to configure the title visibility, name, and font size.
Type: [LabelOptions](API_LabelOptions.md) object
Required: No
