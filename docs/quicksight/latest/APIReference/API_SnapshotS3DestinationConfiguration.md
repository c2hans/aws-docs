# SnapshotS3DestinationConfiguration
<a name="API_SnapshotS3DestinationConfiguration"></a>

A structure that describes the Amazon S3 settings to use to save the generated dashboard snapshot.

## Contents
<a name="API_SnapshotS3DestinationConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BucketConfiguration **   <a name="QS-Type-SnapshotS3DestinationConfiguration-BucketConfiguration"></a>
A structure that contains details about the Amazon S3 bucket that the generated dashboard snapshot is saved in.
Type: [S3BucketConfiguration](API_S3BucketConfiguration.md) object
Required: Yes
