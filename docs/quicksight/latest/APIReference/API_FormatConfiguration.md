# FormatConfiguration
<a name="API_FormatConfiguration"></a>

The formatting configuration for all types of field.

## Contents
<a name="API_FormatConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DateTimeFormatConfiguration **   <a name="QS-Type-FormatConfiguration-DateTimeFormatConfiguration"></a>
Formatting configuration for `DateTime` fields.
Type: [DateTimeFormatConfiguration](API_DateTimeFormatConfiguration.md) object
Required: No

 ** NumberFormatConfiguration **   <a name="QS-Type-FormatConfiguration-NumberFormatConfiguration"></a>
Formatting configuration for number fields.
Type: [NumberFormatConfiguration](API_NumberFormatConfiguration.md) object
Required: No

 ** StringFormatConfiguration **   <a name="QS-Type-FormatConfiguration-StringFormatConfiguration"></a>
Formatting configuration for string fields.
Type: [StringFormatConfiguration](API_StringFormatConfiguration.md) object
Required: No
