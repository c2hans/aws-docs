# RenameColumnOperation
<a name="API_RenameColumnOperation"></a>

A transform operation that renames a column.

## Contents
<a name="API_RenameColumnOperation_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ColumnName **   <a name="QS-Type-RenameColumnOperation-ColumnName"></a>
The name of the column to be renamed.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** NewColumnName **   <a name="QS-Type-RenameColumnOperation-NewColumnName"></a>
The new name for the column.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes
