# IntegerParameter
<a name="API_IntegerParameter"></a>

An integer parameter.

## Contents
<a name="API_IntegerParameter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Name **   <a name="QS-Type-IntegerParameter-Name"></a>
The name of the integer parameter.
Type: String
Pattern: `.*\S.*`
Required: Yes

 ** Values **   <a name="QS-Type-IntegerParameter-Values"></a>
The values for the integer parameter.
Type: Array of longs
Required: Yes
