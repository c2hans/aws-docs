# HierarchyFilterListControlSearchOptions
<a name="API_HierarchyFilterListControlSearchOptions"></a>

The configuration of the search options in a hierarchy list control.

## Contents
<a name="API_HierarchyFilterListControlSearchOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Visibility **   <a name="QS-Type-HierarchyFilterListControlSearchOptions-Visibility"></a>
The visibility configuration of the search options in a hierarchy list control.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
