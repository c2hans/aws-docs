# DashboardCustomizationVisualOptions
<a name="API_DashboardCustomizationVisualOptions"></a>

The options that define customizations available to dashboard readers for a specific visual

## Contents
<a name="API_DashboardCustomizationVisualOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FieldsConfiguration **   <a name="QS-Type-DashboardCustomizationVisualOptions-FieldsConfiguration"></a>
The configuration that controls field customization options available to dashboard readers for a visual.
Type: [VisualCustomizationFieldsConfiguration](API_VisualCustomizationFieldsConfiguration.md) object
Required: No
