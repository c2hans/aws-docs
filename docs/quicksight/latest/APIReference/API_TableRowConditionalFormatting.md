# TableRowConditionalFormatting
<a name="API_TableRowConditionalFormatting"></a>

The conditional formatting of a table row.

## Contents
<a name="API_TableRowConditionalFormatting_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BackgroundColor **   <a name="QS-Type-TableRowConditionalFormatting-BackgroundColor"></a>
The conditional formatting color (solid, gradient) of the background for a table row.
Type: [ConditionalFormattingColor](API_ConditionalFormattingColor.md) object
Required: No

 ** TextColor **   <a name="QS-Type-TableRowConditionalFormatting-TextColor"></a>
The conditional formatting color (solid, gradient) of the text for a table row.
Type: [ConditionalFormattingColor](API_ConditionalFormattingColor.md) object
Required: No
