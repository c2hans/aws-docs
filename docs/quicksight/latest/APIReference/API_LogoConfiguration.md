# LogoConfiguration
<a name="API_LogoConfiguration"></a>

The logo configuration.

## Contents
<a name="API_LogoConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AltText **   <a name="QS-Type-LogoConfiguration-AltText"></a>
The alt text for the logo.
Type: String
Required: Yes

 ** LogoSet **   <a name="QS-Type-LogoConfiguration-LogoSet"></a>
A set of configured logos.
Type: [LogoSetConfiguration](API_LogoSetConfiguration.md) object
Required: Yes
