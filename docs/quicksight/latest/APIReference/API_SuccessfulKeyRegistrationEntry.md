# SuccessfulKeyRegistrationEntry
<a name="API_SuccessfulKeyRegistrationEntry"></a>

A success entry that occurs when a `KeyRegistration` job is successfully applied to the Quick Sight account.

## Contents
<a name="API_SuccessfulKeyRegistrationEntry_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** KeyArn **   <a name="QS-Type-SuccessfulKeyRegistrationEntry-KeyArn"></a>
The ARN of the AWS KMS key that is associated with the `SuccessfulKeyRegistrationEntry` entry.
Type: String
Required: Yes

 ** StatusCode **   <a name="QS-Type-SuccessfulKeyRegistrationEntry-StatusCode"></a>
The HTTP status of a `SuccessfulKeyRegistrationEntry` entry.
Type: Integer
Required: Yes
