# BoxPlotStyleOptions
<a name="API_BoxPlotStyleOptions"></a>

The style options of the box plot.

## Contents
<a name="API_BoxPlotStyleOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FillStyle **   <a name="QS-Type-BoxPlotStyleOptions-FillStyle"></a>
The fill styles (solid, transparent) of the box plot.
Type: String
Valid Values: `SOLID | TRANSPARENT`
Required: No
