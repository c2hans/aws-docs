# WaterfallChartAggregatedFieldWells
<a name="API_WaterfallChartAggregatedFieldWells"></a>

The field well configuration of a waterfall visual.

## Contents
<a name="API_WaterfallChartAggregatedFieldWells_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Breakdowns **   <a name="QS-Type-WaterfallChartAggregatedFieldWells-Breakdowns"></a>
The breakdown field wells of a waterfall visual.
Type: Array of [DimensionField](API_DimensionField.md) objects
Array Members: Maximum number of 200 items.
Required: No

 ** Categories **   <a name="QS-Type-WaterfallChartAggregatedFieldWells-Categories"></a>
The category field wells of a waterfall visual.
Type: Array of [DimensionField](API_DimensionField.md) objects
Array Members: Maximum number of 200 items.
Required: No

 ** Values **   <a name="QS-Type-WaterfallChartAggregatedFieldWells-Values"></a>
The value field wells of a waterfall visual.
Type: Array of [MeasureField](API_MeasureField.md) objects
Array Members: Maximum number of 200 items.
Required: No
