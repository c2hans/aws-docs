# TableFieldCustomTextContent
<a name="API_TableFieldCustomTextContent"></a>

The custom text content (value, font configuration) for the table link content configuration.

## Contents
<a name="API_TableFieldCustomTextContent_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FontConfiguration **   <a name="QS-Type-TableFieldCustomTextContent-FontConfiguration"></a>
The font configuration of the custom text content for the table URL link content.
Type: [FontConfiguration](API_FontConfiguration.md) object
Required: Yes

 ** Value **   <a name="QS-Type-TableFieldCustomTextContent-Value"></a>
The string value of the custom text content for the table URL link content.
Type: String
Required: No
