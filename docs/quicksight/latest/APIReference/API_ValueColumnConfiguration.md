# ValueColumnConfiguration
<a name="API_ValueColumnConfiguration"></a>

Configuration for how to handle value columns in pivot operations, including aggregation settings.

## Contents
<a name="API_ValueColumnConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AggregationFunction **   <a name="QS-Type-ValueColumnConfiguration-AggregationFunction"></a>
The aggregation function to apply when multiple values map to the same pivoted cell.
Type: [DataPrepAggregationFunction](API_DataPrepAggregationFunction.md) object
Required: No
