# DecimalDatasetParameterDefaultValues
<a name="API_DecimalDatasetParameterDefaultValues"></a>

The default values of a decimal parameter.

## Contents
<a name="API_DecimalDatasetParameterDefaultValues_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** StaticValues **   <a name="QS-Type-DecimalDatasetParameterDefaultValues-StaticValues"></a>
A list of static default values for a given decimal parameter.
Type: Array of doubles
Array Members: Minimum number of 1 item. Maximum number of 32 items.
Required: No
