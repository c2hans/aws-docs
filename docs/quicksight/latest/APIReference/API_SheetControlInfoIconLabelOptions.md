# SheetControlInfoIconLabelOptions
<a name="API_SheetControlInfoIconLabelOptions"></a>

A control to display info icons for filters and parameters.

## Contents
<a name="API_SheetControlInfoIconLabelOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** InfoIconText **   <a name="QS-Type-SheetControlInfoIconLabelOptions-InfoIconText"></a>
 The text content of info icon.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No

 ** Visibility **   <a name="QS-Type-SheetControlInfoIconLabelOptions-Visibility"></a>
The visibility configuration of info icon label options.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
