# KPIConditionalFormatting
<a name="API_KPIConditionalFormatting"></a>

The conditional formatting of a KPI visual.

## Contents
<a name="API_KPIConditionalFormatting_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ConditionalFormattingOptions **   <a name="QS-Type-KPIConditionalFormatting-ConditionalFormattingOptions"></a>
The conditional formatting options of a KPI visual.
Type: Array of [KPIConditionalFormattingOption](API_KPIConditionalFormattingOption.md) objects
Array Members: Maximum number of 100 items.
Required: No
