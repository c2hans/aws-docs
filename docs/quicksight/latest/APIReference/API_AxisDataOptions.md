# AxisDataOptions
<a name="API_AxisDataOptions"></a>

The data options for an axis.

This is a union type structure. For this structure to be valid, only one of the attributes can be defined.

## Contents
<a name="API_AxisDataOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DateAxisOptions **   <a name="QS-Type-AxisDataOptions-DateAxisOptions"></a>
The options for an axis with a date field.
Type: [DateAxisOptions](API_DateAxisOptions.md) object
Required: No

 ** NumericAxisOptions **   <a name="QS-Type-AxisDataOptions-NumericAxisOptions"></a>
The options for an axis with a numeric field.
Type: [NumericAxisOptions](API_NumericAxisOptions.md) object
Required: No
