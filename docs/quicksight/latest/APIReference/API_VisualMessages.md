# VisualMessages
<a name="API_VisualMessages"></a>

The messages that are displayed on a visual under specific conditions, such as when the visual returns no data.

## Contents
<a name="API_VisualMessages_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** NoDataMessage **   <a name="QS-Type-VisualMessages-NoDataMessage"></a>
The message that is displayed on a visual when there is no data to display.
Type: [VisualMessageConfiguration](API_VisualMessageConfiguration.md) object
Required: No
