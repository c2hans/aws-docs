# GeocoderHierarchy
<a name="API_GeocoderHierarchy"></a>

The preference hierarchy for the geocode preference.

## Contents
<a name="API_GeocoderHierarchy_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** City **   <a name="QS-Type-GeocoderHierarchy-City"></a>
The city value for the preference hierarchy.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 3000.
Required: No

 ** Country **   <a name="QS-Type-GeocoderHierarchy-Country"></a>
The country value for the preference hierarchy.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 3000.
Required: No

 ** County **   <a name="QS-Type-GeocoderHierarchy-County"></a>
The county/district value for the preference hierarchy.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 3000.
Required: No

 ** PostCode **   <a name="QS-Type-GeocoderHierarchy-PostCode"></a>
The postcode value for the preference hierarchy.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 3000.
Required: No

 ** State **   <a name="QS-Type-GeocoderHierarchy-State"></a>
The state/region value for the preference hierarchy.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 3000.
Required: No
