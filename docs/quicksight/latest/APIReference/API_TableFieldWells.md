# TableFieldWells
<a name="API_TableFieldWells"></a>

The field wells for a table visual.

This is a union type structure. For this structure to be valid, only one of the attributes can be defined.

## Contents
<a name="API_TableFieldWells_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** TableAggregatedFieldWells **   <a name="QS-Type-TableFieldWells-TableAggregatedFieldWells"></a>
The aggregated field well for the table.
Type: [TableAggregatedFieldWells](API_TableAggregatedFieldWells.md) object
Required: No

 ** TableUnaggregatedFieldWells **   <a name="QS-Type-TableFieldWells-TableUnaggregatedFieldWells"></a>
The unaggregated field well for the table.
Type: [TableUnaggregatedFieldWells](API_TableUnaggregatedFieldWells.md) object
Required: No
