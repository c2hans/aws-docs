# GeocodePreference
<a name="API_GeocodePreference"></a>

The geocode preference.

## Contents
<a name="API_GeocodePreference_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Preference **   <a name="QS-Type-GeocodePreference-Preference"></a>
The preference definition for the geocode preference.
Type: [GeocodePreferenceValue](API_GeocodePreferenceValue.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes

 ** RequestKey **   <a name="QS-Type-GeocodePreference-RequestKey"></a>
The unique request key for the geocode preference.
Type: [GeocoderHierarchy](API_GeocoderHierarchy.md) object
Required: Yes
