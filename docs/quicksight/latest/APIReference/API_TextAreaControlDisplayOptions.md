# TextAreaControlDisplayOptions
<a name="API_TextAreaControlDisplayOptions"></a>

The display options of a control.

## Contents
<a name="API_TextAreaControlDisplayOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** InfoIconLabelOptions **   <a name="QS-Type-TextAreaControlDisplayOptions-InfoIconLabelOptions"></a>
The configuration of info icon label options.
Type: [SheetControlInfoIconLabelOptions](API_SheetControlInfoIconLabelOptions.md) object
Required: No

 ** PlaceholderOptions **   <a name="QS-Type-TextAreaControlDisplayOptions-PlaceholderOptions"></a>
The configuration of the placeholder options in a text area control.
Type: [TextControlPlaceholderOptions](API_TextControlPlaceholderOptions.md) object
Required: No

 ** TitleOptions **   <a name="QS-Type-TextAreaControlDisplayOptions-TitleOptions"></a>
The options to configure the title visibility, name, and font size.
Type: [LabelOptions](API_LabelOptions.md) object
Required: No
