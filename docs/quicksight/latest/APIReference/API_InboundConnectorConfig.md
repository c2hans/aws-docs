# InboundConnectorConfig

The configuration of an inbound connector, including its type.

## Contents
<a name="API_InboundConnectorConfig_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** InboundConnectorType **   <a name="QS-Type-InboundConnectorConfig-InboundConnectorType"></a>
The type of the inbound connector. You can't change the type after the connector is created.
Type: String
Valid Values: `QUICK_DESKTOP`
Required: Yes
