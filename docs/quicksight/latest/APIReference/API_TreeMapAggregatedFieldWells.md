# TreeMapAggregatedFieldWells
<a name="API_TreeMapAggregatedFieldWells"></a>

Aggregated field wells of a tree map.

## Contents
<a name="API_TreeMapAggregatedFieldWells_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Colors **   <a name="QS-Type-TreeMapAggregatedFieldWells-Colors"></a>
The color field well of a tree map. Values are grouped by aggregations based on group by fields.
Type: Array of [MeasureField](API_MeasureField.md) objects
Array Members: Maximum number of 1 item.
Required: No

 ** Groups **   <a name="QS-Type-TreeMapAggregatedFieldWells-Groups"></a>
The group by field well of a tree map. Values are grouped based on group by fields.
Type: Array of [DimensionField](API_DimensionField.md) objects
Array Members: Maximum number of 1 item.
Required: No

 ** Sizes **   <a name="QS-Type-TreeMapAggregatedFieldWells-Sizes"></a>
The size field well of a tree map. Values are aggregated based on group by fields.
Type: Array of [MeasureField](API_MeasureField.md) objects
Array Members: Maximum number of 1 item.
Required: No
