# ImageExtractionConfiguration
<a name="API_ImageExtractionConfiguration"></a>

The configuration for image extraction from knowledge base documents.

## Contents
<a name="API_ImageExtractionConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** imageExtractionStatus **   <a name="QS-Type-ImageExtractionConfiguration-imageExtractionStatus"></a>
The status of image extraction. Valid values are ENABLED and DISABLED.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
