# InboundConnectorApplicationAssociationSummary

An association between an inbound connector and an access control application.

## Contents
<a name="API_InboundConnectorApplicationAssociationSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AccessControlApplicationArn **   <a name="QS-Type-InboundConnectorApplicationAssociationSummary-AccessControlApplicationArn"></a>
The ARN of the associated access control application.
Type: String
Required: Yes

 ** CreatedTime **   <a name="QS-Type-InboundConnectorApplicationAssociationSummary-CreatedTime"></a>
The time when the association was created.
Type: Timestamp
Required: Yes
