# ReadNoneConnectionMetadata
<a name="API_ReadNoneConnectionMetadata"></a>

Read-only metadata for connections that do not require authentication credentials.

## Contents
<a name="API_ReadNoneConnectionMetadata_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BaseEndpoint **   <a name="QS-Type-ReadNoneConnectionMetadata-BaseEndpoint"></a>
The base endpoint URL for connections that do not require authentication.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 8192.
Pattern: `https://.*`
Required: Yes
