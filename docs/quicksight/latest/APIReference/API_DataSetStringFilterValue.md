# DataSetStringFilterValue
<a name="API_DataSetStringFilterValue"></a>

Represents a string value used in filter conditions.

## Contents
<a name="API_DataSetStringFilterValue_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** StaticValue **   <a name="QS-Type-DataSetStringFilterValue-StaticValue"></a>
A static string value used for filtering.
Type: String
Length Constraints: Maximum length of 512.
Required: No
