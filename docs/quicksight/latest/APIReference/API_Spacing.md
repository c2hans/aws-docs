# Spacing
<a name="API_Spacing"></a>

The configuration of spacing (often a margin or padding).

## Contents
<a name="API_Spacing_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Bottom **   <a name="QS-Type-Spacing-Bottom"></a>
Define the bottom spacing.
Type: String
Required: No

 ** Left **   <a name="QS-Type-Spacing-Left"></a>
Define the left spacing.
Type: String
Required: No

 ** Right **   <a name="QS-Type-Spacing-Right"></a>
Define the right spacing.
Type: String
Required: No

 ** Top **   <a name="QS-Type-Spacing-Top"></a>
Define the top spacing.
Type: String
Required: No
