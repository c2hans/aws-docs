# AxisLabelReferenceOptions
<a name="API_AxisLabelReferenceOptions"></a>

The reference that specifies where the axis label is applied to.

## Contents
<a name="API_AxisLabelReferenceOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Column **   <a name="QS-Type-AxisLabelReferenceOptions-Column"></a>
The column that the axis label is targeted to.
Type: [ColumnIdentifier](API_ColumnIdentifier.md) object
Required: Yes

 ** FieldId **   <a name="QS-Type-AxisLabelReferenceOptions-FieldId"></a>
The field that the axis label is targeted to.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: Yes
