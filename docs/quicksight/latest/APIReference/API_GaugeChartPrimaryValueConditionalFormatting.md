# GaugeChartPrimaryValueConditionalFormatting
<a name="API_GaugeChartPrimaryValueConditionalFormatting"></a>

The conditional formatting for the primary value of a `GaugeChartVisual`.

## Contents
<a name="API_GaugeChartPrimaryValueConditionalFormatting_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Icon **   <a name="QS-Type-GaugeChartPrimaryValueConditionalFormatting-Icon"></a>
The conditional formatting of the primary value icon.
Type: [ConditionalFormattingIcon](API_ConditionalFormattingIcon.md) object
Required: No

 ** TextColor **   <a name="QS-Type-GaugeChartPrimaryValueConditionalFormatting-TextColor"></a>
The conditional formatting of the primary value text color.
Type: [ConditionalFormattingColor](API_ConditionalFormattingColor.md) object
Required: No
