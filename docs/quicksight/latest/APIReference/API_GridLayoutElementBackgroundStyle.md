# GridLayoutElementBackgroundStyle
<a name="API_GridLayoutElementBackgroundStyle"></a>

The background style configuration of a grid layout element.

## Contents
<a name="API_GridLayoutElementBackgroundStyle_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Color **   <a name="QS-Type-GridLayoutElementBackgroundStyle-Color"></a>
The background color of a grid layout element.
Type: String
Pattern: `^#[A-F0-9]{6}(?:[A-F0-9]{2})?$`
Required: No

 ** Visibility **   <a name="QS-Type-GridLayoutElementBackgroundStyle-Visibility"></a>
The background visibility of a grid layout element.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
