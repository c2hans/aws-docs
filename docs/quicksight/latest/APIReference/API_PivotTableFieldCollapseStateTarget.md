# PivotTableFieldCollapseStateTarget
<a name="API_PivotTableFieldCollapseStateTarget"></a>

The target of a pivot table field collapse state.

## Contents
<a name="API_PivotTableFieldCollapseStateTarget_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FieldDataPathValues **   <a name="QS-Type-PivotTableFieldCollapseStateTarget-FieldDataPathValues"></a>
The data path of the pivot table's header. Used to set the collapse state.
Type: Array of [DataPathValue](API_DataPathValue.md) objects
Array Members: Maximum number of 20 items.
Required: No

 ** FieldId **   <a name="QS-Type-PivotTableFieldCollapseStateTarget-FieldId"></a>
The field ID of the pivot table that the collapse state needs to be set to.
Type: String
Required: No
