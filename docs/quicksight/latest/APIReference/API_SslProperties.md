# SslProperties
<a name="API_SslProperties"></a>

Secure Socket Layer (SSL) properties that apply when Quick Sight connects to your underlying data source.

## Contents
<a name="API_SslProperties_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DisableSsl **   <a name="QS-Type-SslProperties-DisableSsl"></a>
A Boolean option to control whether SSL should be disabled.
Type: Boolean
Required: No
