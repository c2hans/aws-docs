# DataPathValue
<a name="API_DataPathValue"></a>

The data path that needs to be sorted.

## Contents
<a name="API_DataPathValue_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DataPathType **   <a name="QS-Type-DataPathValue-DataPathType"></a>
The type configuration of the field.
Type: [DataPathType](API_DataPathType.md) object
Required: No

 ** FieldId **   <a name="QS-Type-DataPathValue-FieldId"></a>
The field ID of the field that needs to be sorted.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: No

 ** FieldValue **   <a name="QS-Type-DataPathValue-FieldValue"></a>
The actual value of the field that needs to be sorted.
Type: String
Length Constraints: Maximum length of 2048.
Required: No
