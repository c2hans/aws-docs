# FailedToUpdateAssociation
<a name="API_FailedToUpdateAssociation"></a>

Information about a per-ARN failure when updating agent associations.

## Contents
<a name="API_FailedToUpdateAssociation_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Arn **   <a name="QS-Type-FailedToUpdateAssociation-Arn"></a>
The ARN that could not be added or removed.
Type: String
Required: No

 ** ErrorCode **   <a name="QS-Type-FailedToUpdateAssociation-ErrorCode"></a>
The error code for the failure.
Type: String
Required: No

 ** ErrorMessage **   <a name="QS-Type-FailedToUpdateAssociation-ErrorMessage"></a>
A description of the failure.
Type: String
Required: No
