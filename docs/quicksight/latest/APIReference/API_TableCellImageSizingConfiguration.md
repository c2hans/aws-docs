# TableCellImageSizingConfiguration
<a name="API_TableCellImageSizingConfiguration"></a>

The sizing options for the table image configuration.

## Contents
<a name="API_TableCellImageSizingConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** TableCellImageScalingConfiguration **   <a name="QS-Type-TableCellImageSizingConfiguration-TableCellImageScalingConfiguration"></a>
The cell scaling configuration of the sizing options for the table image configuration.
Type: String
Valid Values: `FIT_TO_CELL_HEIGHT | FIT_TO_CELL_WIDTH | DO_NOT_SCALE`
Required: No
