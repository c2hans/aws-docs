# RegisteredUserDashboardFeatureConfigurations
<a name="API_RegisteredUserDashboardFeatureConfigurations"></a>

The feature configuration for an embedded dashboard.

## Contents
<a name="API_RegisteredUserDashboardFeatureConfigurations_Contents"></a>

**Note**
In the following list, the required parameters are described first.

Required: No

Type: [DashboardCustomizationSummaryConfigurations](API_DashboardCustomizationSummaryConfigurations.md) object
Required: No

 ** RecentSnapshots **   <a name="QS-Type-RegisteredUserDashboardFeatureConfigurations-RecentSnapshots"></a>
