# RowInfo
<a name="API_RowInfo"></a>

Information about rows for a data set SPICE ingestion.

## Contents
<a name="API_RowInfo_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** RowsDropped **   <a name="QS-Type-RowInfo-RowsDropped"></a>
The number of rows that were not ingested.
Type: Long
Required: No

 ** RowsIngested **   <a name="QS-Type-RowInfo-RowsIngested"></a>
The number of rows that were ingested.
Type: Long
Required: No

 ** TotalRowsInDataset **   <a name="QS-Type-RowInfo-TotalRowsInDataset"></a>
The total number of rows in the dataset.
Type: Long
Required: No
