# AssetBundleExportJobResourceIdOverrideConfiguration
<a name="API_AssetBundleExportJobResourceIdOverrideConfiguration"></a>

An optional structure that configures resource ID overrides for the export job.

## Contents
<a name="API_AssetBundleExportJobResourceIdOverrideConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** PrefixForAllResources **   <a name="QS-Type-AssetBundleExportJobResourceIdOverrideConfiguration-PrefixForAllResources"></a>
An option to request a CloudFormation variable for a prefix to be prepended to each resource's ID before import. The prefix is only added to the asset IDs and does not change the name of the asset.
Type: Boolean
Required: No
