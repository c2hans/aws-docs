# SnapshotUserConfigurationRedacted
<a name="API_SnapshotUserConfigurationRedacted"></a>

A structure that contains information about the users that the dashboard snapshot is generated for. Sensitive user information is excluded.

## Contents
<a name="API_SnapshotUserConfigurationRedacted_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AnonymousUsers **   <a name="QS-Type-SnapshotUserConfigurationRedacted-AnonymousUsers"></a>
 An array of records that describe anonymous users that the dashboard snapshot is generated for. Sensitive user information is excluded.
Type: Array of [SnapshotAnonymousUserRedacted](API_SnapshotAnonymousUserRedacted.md) objects
Array Members: Fixed number of 1 item.
Required: No
