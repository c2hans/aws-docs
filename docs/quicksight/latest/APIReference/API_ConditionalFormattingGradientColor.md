# ConditionalFormattingGradientColor
<a name="API_ConditionalFormattingGradientColor"></a>

Formatting configuration for gradient color.

## Contents
<a name="API_ConditionalFormattingGradientColor_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Color **   <a name="QS-Type-ConditionalFormattingGradientColor-Color"></a>
Determines the color.
Type: [GradientColor](API_GradientColor.md) object
Required: Yes

 ** Expression **   <a name="QS-Type-ConditionalFormattingGradientColor-Expression"></a>
The expression that determines the formatting configuration for gradient color.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Required: Yes
