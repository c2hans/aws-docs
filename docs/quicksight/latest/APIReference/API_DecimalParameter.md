# DecimalParameter
<a name="API_DecimalParameter"></a>

A decimal parameter.

## Contents
<a name="API_DecimalParameter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Name **   <a name="QS-Type-DecimalParameter-Name"></a>
A display name for the decimal parameter.
Type: String
Pattern: `.*\S.*`
Required: Yes

 ** Values **   <a name="QS-Type-DecimalParameter-Values"></a>
The values for the decimal parameter.
Type: Array of doubles
Required: Yes
