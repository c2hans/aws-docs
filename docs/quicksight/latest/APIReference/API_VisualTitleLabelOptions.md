# VisualTitleLabelOptions
<a name="API_VisualTitleLabelOptions"></a>

The title label options for a visual.

## Contents
<a name="API_VisualTitleLabelOptions_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FormatText **   <a name="QS-Type-VisualTitleLabelOptions-FormatText"></a>
The short text format of the title label, such as plain text or rich text.
Type: [ShortFormatText](API_ShortFormatText.md) object
Required: No

 ** Visibility **   <a name="QS-Type-VisualTitleLabelOptions-Visibility"></a>
The visibility of the title label.
Type: String
Valid Values: `HIDDEN | VISIBLE`
Required: No
