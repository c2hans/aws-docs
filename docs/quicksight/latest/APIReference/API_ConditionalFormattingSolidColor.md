# ConditionalFormattingSolidColor
<a name="API_ConditionalFormattingSolidColor"></a>

Formatting configuration for solid color.

## Contents
<a name="API_ConditionalFormattingSolidColor_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Expression **   <a name="QS-Type-ConditionalFormattingSolidColor-Expression"></a>
The expression that determines the formatting configuration for solid color.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Required: Yes

 ** Color **   <a name="QS-Type-ConditionalFormattingSolidColor-Color"></a>
Determines the color.
Type: String
Pattern: `^#[A-F0-9]{6}$`
Required: No
