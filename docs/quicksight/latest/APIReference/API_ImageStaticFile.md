# ImageStaticFile
<a name="API_ImageStaticFile"></a>

A static file that contains an image.

## Contents
<a name="API_ImageStaticFile_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** StaticFileId **   <a name="QS-Type-ImageStaticFile-StaticFileId"></a>
The ID of the static file that contains an image.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Pattern: `[\w\-]+`
Required: Yes

 ** Source **   <a name="QS-Type-ImageStaticFile-Source"></a>
The source of the image static file.
Type: [StaticFileSource](API_StaticFileSource.md) object
Required: No
