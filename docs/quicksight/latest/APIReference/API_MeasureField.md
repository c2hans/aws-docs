# MeasureField
<a name="API_MeasureField"></a>

The measure (metric) type field.

## Contents
<a name="API_MeasureField_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** CalculatedMeasureField **   <a name="QS-Type-MeasureField-CalculatedMeasureField"></a>
The calculated measure field only used in pivot tables.
Type: [CalculatedMeasureField](API_CalculatedMeasureField.md) object
Required: No

 ** CategoricalMeasureField **   <a name="QS-Type-MeasureField-CategoricalMeasureField"></a>
The measure type field with categorical type columns.
Type: [CategoricalMeasureField](API_CategoricalMeasureField.md) object
Required: No

 ** DateMeasureField **   <a name="QS-Type-MeasureField-DateMeasureField"></a>
The measure type field with date type columns.
Type: [DateMeasureField](API_DateMeasureField.md) object
Required: No

 ** NumericalMeasureField **   <a name="QS-Type-MeasureField-NumericalMeasureField"></a>
The measure type field with numerical type columns.
Type: [NumericalMeasureField](API_NumericalMeasureField.md) object
Required: No
