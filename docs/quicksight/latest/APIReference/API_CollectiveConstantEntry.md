# CollectiveConstantEntry
<a name="API_CollectiveConstantEntry"></a>

The definition for a `CollectiveConstantEntry`.

## Contents
<a name="API_CollectiveConstantEntry_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ConstantType **   <a name="QS-Type-CollectiveConstantEntry-ConstantType"></a>
The `ConstantType` of a `CollectiveConstantEntry`.
Type: String
Valid Values: `SINGULAR | RANGE | COLLECTIVE`
Required: No

 ** Value **   <a name="QS-Type-CollectiveConstantEntry-Value"></a>
The value of a `CollectiveConstantEntry`.
Type: String
Length Constraints: Maximum length of 1024.
Required: No
