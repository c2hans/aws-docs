# GeospatialSolidColor
<a name="API_GeospatialSolidColor"></a>

The definition for a solid color.

## Contents
<a name="API_GeospatialSolidColor_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Color **   <a name="QS-Type-GeospatialSolidColor-Color"></a>
The color and opacity values for the color.
Type: String
Pattern: `^#[A-F0-9]{6}(?:[A-F0-9]{2})?$`
Required: Yes

 ** State **   <a name="QS-Type-GeospatialSolidColor-State"></a>
Enables and disables the view state of the color.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: No
