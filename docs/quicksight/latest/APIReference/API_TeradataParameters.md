# TeradataParameters
<a name="API_TeradataParameters"></a>

The parameters for Teradata.

## Contents
<a name="API_TeradataParameters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Database **   <a name="QS-Type-TeradataParameters-Database"></a>
Database.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** Host **   <a name="QS-Type-TeradataParameters-Host"></a>
Host.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes

 ** Port **   <a name="QS-Type-TeradataParameters-Port"></a>
Port.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 65535.
Required: Yes
