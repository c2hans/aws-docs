# ConfluenceParameters
<a name="API_ConfluenceParameters"></a>

The parameters that are required to connect to a Confluence data source

## Contents
<a name="API_ConfluenceParameters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ConfluenceUrl **   <a name="QS-Type-ConfluenceParameters-ConfluenceUrl"></a>
The URL of the Confluence site to connect to.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes
