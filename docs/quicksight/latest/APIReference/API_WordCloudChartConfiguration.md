# WordCloudChartConfiguration
<a name="API_WordCloudChartConfiguration"></a>

The configuration of a word cloud visual.

## Contents
<a name="API_WordCloudChartConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** CategoryLabelOptions **   <a name="QS-Type-WordCloudChartConfiguration-CategoryLabelOptions"></a>
The label options (label text, label visibility, and sort icon visibility) for the word cloud category.
Type: [ChartAxisLabelOptions](API_ChartAxisLabelOptions.md) object
Required: No

 ** FieldWells **   <a name="QS-Type-WordCloudChartConfiguration-FieldWells"></a>
The field wells of the visual.
Type: [WordCloudFieldWells](API_WordCloudFieldWells.md) object
Required: No

 ** Interactions **   <a name="QS-Type-WordCloudChartConfiguration-Interactions"></a>
The general visual interactions setup for a visual.
Type: [VisualInteractionOptions](API_VisualInteractionOptions.md) object
Required: No

 ** SortConfiguration **   <a name="QS-Type-WordCloudChartConfiguration-SortConfiguration"></a>
The sort configuration of a word cloud visual.
Type: [WordCloudSortConfiguration](API_WordCloudSortConfiguration.md) object
Required: No

 ** WordCloudOptions **   <a name="QS-Type-WordCloudChartConfiguration-WordCloudOptions"></a>
The options for a word cloud visual.
Type: [WordCloudOptions](API_WordCloudOptions.md) object
Required: No
