# ControlTitleFontConfiguration
<a name="API_ControlTitleFontConfiguration"></a>

Configures the display properties of the control title.

## Contents
<a name="API_ControlTitleFontConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FontConfiguration **   <a name="QS-Type-ControlTitleFontConfiguration-FontConfiguration"></a>
Configures the font settings for the control title.
Type: [FontConfiguration](API_FontConfiguration.md) object
Required: No

 ** TextAlignment **   <a name="QS-Type-ControlTitleFontConfiguration-TextAlignment"></a>
Determines the alignment of the control title.
Type: String
Valid Values: `LEFT | CENTER | RIGHT | AUTO`
Required: No
