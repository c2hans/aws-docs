# BarChartSeriesSettings
<a name="API_BarChartSeriesSettings"></a>

Options that determine the presentation of a bar series in the visual.

## Contents
<a name="API_BarChartSeriesSettings_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BorderSettings **   <a name="QS-Type-BarChartSeriesSettings-BorderSettings"></a>
Border settings for the bar series.
Type: [BorderSettings](API_BorderSettings.md) object
Required: No

 ** DecalSettings **   <a name="QS-Type-BarChartSeriesSettings-DecalSettings"></a>
Decal settings for the bar series.
Type: [DecalSettings](API_DecalSettings.md) object
Required: No
