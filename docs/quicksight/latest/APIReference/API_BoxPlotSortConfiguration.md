# BoxPlotSortConfiguration
<a name="API_BoxPlotSortConfiguration"></a>

The sort configuration of a `BoxPlotVisual`.

## Contents
<a name="API_BoxPlotSortConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** CategorySort **   <a name="QS-Type-BoxPlotSortConfiguration-CategorySort"></a>
The sort configuration of a group by fields.
Type: Array of [FieldSortOptions](API_FieldSortOptions.md) objects
Array Members: Maximum number of 100 items.
Required: No

 ** PaginationConfiguration **   <a name="QS-Type-BoxPlotSortConfiguration-PaginationConfiguration"></a>
The pagination configuration of a table visual or box plot.
Type: [PaginationConfiguration](API_PaginationConfiguration.md) object
Required: No
