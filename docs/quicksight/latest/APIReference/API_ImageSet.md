# ImageSet
<a name="API_ImageSet"></a>

The image set.

## Contents
<a name="API_ImageSet_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Original **   <a name="QS-Type-ImageSet-Original"></a>
The original image.
Type: [Image](API_Image.md) object
Required: Yes

 ** Height32 **   <a name="QS-Type-ImageSet-Height32"></a>
The image with the height set to 32 pixels.
Type: [Image](API_Image.md) object
Required: No

 ** Height64 **   <a name="QS-Type-ImageSet-Height64"></a>
The image with the height set to 64 pixels.
Type: [Image](API_Image.md) object
Required: No
