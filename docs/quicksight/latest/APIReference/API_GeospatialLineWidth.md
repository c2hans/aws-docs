# GeospatialLineWidth
<a name="API_GeospatialLineWidth"></a>

The width properties for a line.

## Contents
<a name="API_GeospatialLineWidth_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** LineWidth **   <a name="QS-Type-GeospatialLineWidth-LineWidth"></a>
The positive value for the width of a line.
Type: Double
Valid Range: Minimum value of 0.
Required: No
