# TableSemanticMetadata
<a name="API_TableSemanticMetadata"></a>

Column-level semantic metadata for a semantic table.

## Contents
<a name="API_TableSemanticMetadata_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ColumnMetadata **   <a name="QS-Type-TableSemanticMetadata-ColumnMetadata"></a>
A list of column semantic metadata entries.
Type: Array of [SharedColumnSemanticMetadata](API_SharedColumnSemanticMetadata.md) objects
Array Members: Minimum number of 1 item. Maximum number of 2000 items.
Required: No
