# WordCloudSortConfiguration
<a name="API_WordCloudSortConfiguration"></a>

The sort configuration of a word cloud visual.

## Contents
<a name="API_WordCloudSortConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** CategoryItemsLimit **   <a name="QS-Type-WordCloudSortConfiguration-CategoryItemsLimit"></a>
The limit on the number of groups that are displayed in a word cloud.
Type: [ItemsLimitConfiguration](API_ItemsLimitConfiguration.md) object
Required: No

 ** CategorySort **   <a name="QS-Type-WordCloudSortConfiguration-CategorySort"></a>
The sort configuration of group by fields.
Type: Array of [FieldSortOptions](API_FieldSortOptions.md) objects
Array Members: Maximum number of 100 items.
Required: No
