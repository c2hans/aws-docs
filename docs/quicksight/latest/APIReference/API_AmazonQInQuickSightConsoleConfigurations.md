# AmazonQInQuickSightConsoleConfigurations
<a name="API_AmazonQInQuickSightConsoleConfigurations"></a>

A collection of Amazon Q feature configurations in an embedded Quick Sight console.

## Contents
<a name="API_AmazonQInQuickSightConsoleConfigurations_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DataQnA **   <a name="QS-Type-AmazonQInQuickSightConsoleConfigurations-DataQnA"></a>
Adds generative Q&A capabilitiees to an embedded Quick Sight console.
Type: [DataQnAConfigurations](API_DataQnAConfigurations.md) object
Required: No

 ** DataStories **   <a name="QS-Type-AmazonQInQuickSightConsoleConfigurations-DataStories"></a>
Adds the data stories feature to an embedded Quick Sight console.
Type: [DataStoriesConfigurations](API_DataStoriesConfigurations.md) object
Required: No

 ** ExecutiveSummary **   <a name="QS-Type-AmazonQInQuickSightConsoleConfigurations-ExecutiveSummary"></a>
Adds the executive summaries feature to an embedded Quick Sight console.
Type: [ExecutiveSummaryConfigurations](API_ExecutiveSummaryConfigurations.md) object
Required: No

 ** GenerativeAuthoring **   <a name="QS-Type-AmazonQInQuickSightConsoleConfigurations-GenerativeAuthoring"></a>
Adds the generative BI authoring experience to an embedded Quick Sight console.
Type: [GenerativeAuthoringConfigurations](API_GenerativeAuthoringConfigurations.md) object
Required: No
