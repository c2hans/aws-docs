# ForecastScenario
<a name="API_ForecastScenario"></a>

The forecast scenario of a forecast in the line chart.

## Contents
<a name="API_ForecastScenario_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** WhatIfPointScenario **   <a name="QS-Type-ForecastScenario-WhatIfPointScenario"></a>
The what-if analysis forecast setup with the target date.
Type: [WhatIfPointScenario](API_WhatIfPointScenario.md) object
Required: No

 ** WhatIfRangeScenario **   <a name="QS-Type-ForecastScenario-WhatIfRangeScenario"></a>
The what-if analysis forecast setup with the date range.
Type: [WhatIfRangeScenario](API_WhatIfRangeScenario.md) object
Required: No
