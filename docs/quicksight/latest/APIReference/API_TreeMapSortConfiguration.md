# TreeMapSortConfiguration
<a name="API_TreeMapSortConfiguration"></a>

The sort configuration of a tree map.

## Contents
<a name="API_TreeMapSortConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** TreeMapGroupItemsLimitConfiguration **   <a name="QS-Type-TreeMapSortConfiguration-TreeMapGroupItemsLimitConfiguration"></a>
The limit on the number of groups that are displayed.
Type: [ItemsLimitConfiguration](API_ItemsLimitConfiguration.md) object
Required: No

 ** TreeMapSort **   <a name="QS-Type-TreeMapSortConfiguration-TreeMapSort"></a>
The sort configuration of group by fields.
Type: Array of [FieldSortOptions](API_FieldSortOptions.md) objects
Array Members: Maximum number of 100 items.
Required: No
