# LogoSet
<a name="API_LogoSet"></a>

A set of logos.

## Contents
<a name="API_LogoSet_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Primary **   <a name="QS-Type-LogoSet-Primary"></a>
The primary logo.
Type: [ImageSet](API_ImageSet.md) object
Required: Yes

 ** Favicon **   <a name="QS-Type-LogoSet-Favicon"></a>
The favicon logo.
Type: [ImageSet](API_ImageSet.md) object
Required: No
