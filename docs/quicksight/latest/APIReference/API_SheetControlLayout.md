# SheetControlLayout
<a name="API_SheetControlLayout"></a>

A grid layout to define the placement of sheet control.

## Contents
<a name="API_SheetControlLayout_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Configuration **   <a name="QS-Type-SheetControlLayout-Configuration"></a>
The configuration that determines the elements and canvas size options of sheet control.
Type: [SheetControlLayoutConfiguration](API_SheetControlLayoutConfiguration.md) object
Required: Yes
