# VisualSubtitleFontConfiguration
<a name="API_VisualSubtitleFontConfiguration"></a>

Configures the display properties of the visual sub-title.

## Contents
<a name="API_VisualSubtitleFontConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FontConfiguration **   <a name="QS-Type-VisualSubtitleFontConfiguration-FontConfiguration"></a>
Configures the display properties of the given text.
Type: [FontConfiguration](API_FontConfiguration.md) object
Required: No

 ** TextAlignment **   <a name="QS-Type-VisualSubtitleFontConfiguration-TextAlignment"></a>
Determines the alignment of visual sub-title.
Type: String
Valid Values: `LEFT | CENTER | RIGHT | AUTO`
Required: No

 ** TextTransform **   <a name="QS-Type-VisualSubtitleFontConfiguration-TextTransform"></a>
Determines the text transformation of visual sub-title.
Type: String
Valid Values: `CAPITALIZE`
Required: No
