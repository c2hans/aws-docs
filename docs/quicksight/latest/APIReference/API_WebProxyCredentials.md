# WebProxyCredentials
<a name="API_WebProxyCredentials"></a>

The credentials for authenticating with a web proxy server.

## Contents
<a name="API_WebProxyCredentials_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** WebProxyPassword **   <a name="QS-Type-WebProxyCredentials-WebProxyPassword"></a>
The password for authenticating with the web proxy server.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes

 ** WebProxyUsername **   <a name="QS-Type-WebProxyCredentials-WebProxyUsername"></a>
The username for authenticating with the web proxy server.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: Yes
