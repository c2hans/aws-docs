# SheetBackgroundStyle
<a name="API_SheetBackgroundStyle"></a>

The background configuration for sheets.

## Contents
<a name="API_SheetBackgroundStyle_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Color **   <a name="QS-Type-SheetBackgroundStyle-Color"></a>
The solid color background option for sheets.
Type: String
Required: No

 ** Gradient **   <a name="QS-Type-SheetBackgroundStyle-Gradient"></a>
The gradient background option for sheets.
Type: String
Required: No
