# GeospatialLayerDefinition
<a name="API_GeospatialLayerDefinition"></a>

The definition properties for a geospatial layer.

## Contents
<a name="API_GeospatialLayerDefinition_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** LineLayer **   <a name="QS-Type-GeospatialLayerDefinition-LineLayer"></a>
The definition for a line layer.
Type: [GeospatialLineLayer](API_GeospatialLineLayer.md) object
Required: No

 ** PointLayer **   <a name="QS-Type-GeospatialLayerDefinition-PointLayer"></a>
The definition for a point layer.
Type: [GeospatialPointLayer](API_GeospatialPointLayer.md) object
Required: No

 ** PolygonLayer **   <a name="QS-Type-GeospatialLayerDefinition-PolygonLayer"></a>
The definition for a polygon layer.
Type: [GeospatialPolygonLayer](API_GeospatialPolygonLayer.md) object
Required: No
