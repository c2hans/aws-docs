# UnaggregatedField
<a name="API_UnaggregatedField"></a>

The unaggregated field for a table.

## Contents
<a name="API_UnaggregatedField_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Column **   <a name="QS-Type-UnaggregatedField-Column"></a>
The column that is used in the `UnaggregatedField`.
Type: [ColumnIdentifier](API_ColumnIdentifier.md) object
Required: Yes

 ** FieldId **   <a name="QS-Type-UnaggregatedField-FieldId"></a>
The custom field ID.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: Yes

 ** FormatConfiguration **   <a name="QS-Type-UnaggregatedField-FormatConfiguration"></a>
The format configuration of the field.
Type: [FormatConfiguration](API_FormatConfiguration.md) object
Required: No
