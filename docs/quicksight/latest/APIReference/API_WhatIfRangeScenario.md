# WhatIfRangeScenario
<a name="API_WhatIfRangeScenario"></a>

Provides the forecast to meet the target for a particular date range.

## Contents
<a name="API_WhatIfRangeScenario_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** EndDate **   <a name="QS-Type-WhatIfRangeScenario-EndDate"></a>
The end date in the date range that you need the forecast results for.
Type: Timestamp
Required: Yes

 ** StartDate **   <a name="QS-Type-WhatIfRangeScenario-StartDate"></a>
The start date in the date range that you need the forecast results for.
Type: Timestamp
Required: Yes

 ** Value **   <a name="QS-Type-WhatIfRangeScenario-Value"></a>
The target value that you want to meet for the provided date range.
Type: Double
Required: Yes
