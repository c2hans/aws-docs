# AssetBundleExportJobWarning
<a name="API_AssetBundleExportJobWarning"></a>

Describes a warning that occurred during an Asset Bundle export job.

## Contents
<a name="API_AssetBundleExportJobWarning_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Arn **   <a name="QS-Type-AssetBundleExportJobWarning-Arn"></a>
The ARN of the resource whose processing caused a warning.
Type: String
Required: No

 ** Message **   <a name="QS-Type-AssetBundleExportJobWarning-Message"></a>
A description of the warning.
Type: String
Pattern: `.*\S.*`
Required: No
