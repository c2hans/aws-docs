# PolicyDescription
<a name="API_PolicyDescription"></a>

Information about a policy.

## Contents
<a name="API_PolicyDescription_Contents"></a>

 ** PolicyAttributeDescriptions.member.N **
The policy attributes.
Type: Array of [PolicyAttributeDescription](API_PolicyAttributeDescription.md) objects
Required: No

 ** PolicyName **
The name of the policy.
Type: String
Required: No

 ** PolicyTypeName **
The name of the policy type.
Type: String
Required: No
