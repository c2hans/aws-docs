# ListenerDescription
<a name="API_ListenerDescription"></a>

The policies enabled for a listener.

## Contents
<a name="API_ListenerDescription_Contents"></a>

 ** Listener **
The listener.
Type: [Listener](API_Listener.md) object
Required: No

 ** PolicyNames.member.N **
The policies. If there are no policies enabled, the list is empty.
Type: Array of strings
Required: No
