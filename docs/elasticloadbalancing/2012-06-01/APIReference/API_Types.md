# Data Types
<a name="API_Types"></a>

The Elastic Load Balancing API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AccessLog](API_AccessLog.md)
+  [AdditionalAttribute](API_AdditionalAttribute.md)
+  [AppCookieStickinessPolicy](API_AppCookieStickinessPolicy.md)
+  [BackendServerDescription](API_BackendServerDescription.md)
+  [ConnectionDraining](API_ConnectionDraining.md)
+  [ConnectionSettings](API_ConnectionSettings.md)
+  [CrossZoneLoadBalancing](API_CrossZoneLoadBalancing.md)
+  [HealthCheck](API_HealthCheck.md)
+  [Instance](API_Instance.md)
+  [InstanceState](API_InstanceState.md)
+  [LBCookieStickinessPolicy](API_LBCookieStickinessPolicy.md)
+  [Limit](API_Limit.md)
+  [Listener](API_Listener.md)
+  [ListenerDescription](API_ListenerDescription.md)
+  [LoadBalancerAttributes](API_LoadBalancerAttributes.md)
+  [LoadBalancerDescription](API_LoadBalancerDescription.md)
+  [Policies](API_Policies.md)
+  [PolicyAttribute](API_PolicyAttribute.md)
+  [PolicyAttributeDescription](API_PolicyAttributeDescription.md)
+  [PolicyAttributeTypeDescription](API_PolicyAttributeTypeDescription.md)
+  [PolicyDescription](API_PolicyDescription.md)
+  [PolicyTypeDescription](API_PolicyTypeDescription.md)
+  [SourceSecurityGroup](API_SourceSecurityGroup.md)
+  [Tag](API_Tag.md)
+  [TagDescription](API_TagDescription.md)
+  [TagKeyOnly](API_TagKeyOnly.md)
