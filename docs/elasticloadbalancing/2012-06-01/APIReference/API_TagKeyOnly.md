# TagKeyOnly
<a name="API_TagKeyOnly"></a>

The key of a tag.

## Contents
<a name="API_TagKeyOnly_Contents"></a>

 ** Key **
The name of the key.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `^([\p{L}\p{Z}\p{N}_.:/=+\-@]*)$`
Required: No
