# PolicyTypeDescription
<a name="API_PolicyTypeDescription"></a>

Information about a policy type.

## Contents
<a name="API_PolicyTypeDescription_Contents"></a>

 ** Description **
A description of the policy type.
Type: String
Required: No

 ** PolicyAttributeTypeDescriptions.member.N **
The description of the policy attributes associated with the policies defined by Elastic Load Balancing.
Type: Array of [PolicyAttributeTypeDescription](API_PolicyAttributeTypeDescription.md) objects
Required: No

 ** PolicyTypeName **
The name of the policy type.
Type: String
Required: No
