# Cipher
<a name="API_Cipher"></a>

Information about a cipher used in a policy.

## Contents
<a name="API_Cipher_Contents"></a>

 ** Name **
The name of the cipher.
Type: String
Required: No

 ** Priority **
The priority of the cipher.
Type: Integer
Required: No
