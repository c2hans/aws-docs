# RulePriorityPair
<a name="API_RulePriorityPair"></a>

Information about the priorities for the rules for a listener.

## Contents
<a name="API_RulePriorityPair_Contents"></a>

 ** Priority **
The rule priority.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 50000.
Required: No

 ** RuleArn **
The Amazon Resource Name (ARN) of the rule.
Type: String
Required: No
