# ZonalCapacityReservationState
<a name="API_ZonalCapacityReservationState"></a>

The capacity reservation status for each Availability Zone.

## Contents
<a name="API_ZonalCapacityReservationState_Contents"></a>

 ** AvailabilityZone **
Information about the Availability Zone.
Type: String
Required: No

 ** EffectiveCapacityUnits **
The number of effective capacity units.
Type: Double
Required: No

 ** State **
The state of the capacity reservation.
Type: [CapacityReservationStatus](API_CapacityReservationStatus.md) object
Required: No
