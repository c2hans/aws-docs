# CapacityReservationStatus
<a name="API_CapacityReservationStatus"></a>

The status of a capacity reservation.

## Contents
<a name="API_CapacityReservationStatus_Contents"></a>

 ** Code **
The status code.
Type: String
Valid Values: `provisioned | pending | rebalancing | failed`
Required: No

 ** Reason **
The reason code for the status.
Type: String
Required: No
