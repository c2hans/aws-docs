# Security in ELB for Envoy

Elastic Load Balancing for Envoy (ELB for Envoy) runs your Envoy proxies on infrastructure that the service operates. This chapter describes how security responsibilities are shared between you and AWS, how your proxy data is protected, how to control access with IAM, and how to log API activity.
