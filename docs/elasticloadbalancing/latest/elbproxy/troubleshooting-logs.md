# Use logs to troubleshoot a proxy

Your proxy publishes Envoy process logs to CloudWatch Logs. Use these logs to investigate request failures and configuration problems. For more information about where the logs are published and how to view them, see [Proxy logs](monitoring-logs.md).

If the default log level doesn't show enough detail, raise it. For more information, see [Set the Envoy log level](monitoring-log-level.md).
