# ConfigurationFile

The configuration file for a proxy.

## Contents
<a name="API_ConfigurationFile_Contents"></a>

 ** configurationBytes **   <a name="elasticloadbalancing-Type-ConfigurationFile-configurationBytes"></a>
The contents of the configuration file.
Type: Base64-encoded binary data object
Length Constraints: Minimum length of 0. Maximum length of 1048576.
Required: Yes
