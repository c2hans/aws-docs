# ProxyConfiguration

The configuration for a proxy.

## Contents
<a name="API_ProxyConfiguration_Contents"></a>

 ** configurationArchive **   <a name="elasticloadbalancing-Type-ProxyConfiguration-configurationArchive"></a>
The configuration archive for the proxy. This is a bundle of the files referenced by the configuration file.
Type: [ConfigurationArchive](API_ConfigurationArchive.md) object
Required: No

 ** configurationFile **   <a name="elasticloadbalancing-Type-ProxyConfiguration-configurationFile"></a>
The configuration file for the proxy.
Type: [ConfigurationFile](API_ConfigurationFile.md) object
Required: No
