# AttributeDetails

A key-value attribute for a proxy, including its default value.

## Contents
<a name="API_AttributeDetails_Contents"></a>

 ** key **   <a name="elasticloadbalancing-Type-AttributeDetails-key"></a>
The key of the attribute.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes

 ** value **   <a name="elasticloadbalancing-Type-AttributeDetails-value"></a>
The value of the attribute.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Required: Yes

 ** defaultValue **   <a name="elasticloadbalancing-Type-AttributeDetails-defaultValue"></a>
The default value of the attribute.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Required: No
