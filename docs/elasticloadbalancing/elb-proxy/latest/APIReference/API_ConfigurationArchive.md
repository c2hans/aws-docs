# ConfigurationArchive

The configuration archive for a proxy. This is a bundle of the files referenced by the configuration file.

## Contents
<a name="API_ConfigurationArchive_Contents"></a>

 ** configurationBytes **   <a name="elasticloadbalancing-Type-ConfigurationArchive-configurationBytes"></a>
The contents of the configuration archive.
Type: Base64-encoded binary data object
Length Constraints: Minimum length of 0. Maximum length of 52428800.
Required: Yes
