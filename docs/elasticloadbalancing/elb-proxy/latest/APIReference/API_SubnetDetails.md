# SubnetDetails

The details of a subnet.

## Contents
<a name="API_SubnetDetails_Contents"></a>

 ** subnetId **   <a name="elasticloadbalancing-Type-SubnetDetails-subnetId"></a>
The ID of the subnet.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `subnet-.+`
Required: Yes
