# ProxyIpAddressingConfiguration

The IP addressing configuration for a proxy.

## Contents
<a name="API_ProxyIpAddressingConfiguration_Contents"></a>

 ** ipv4Addressability **   <a name="elasticloadbalancing-Type-ProxyIpAddressingConfiguration-ipv4Addressability"></a>
The IPv4 addressability setting for the proxy.
Type: String
Valid Values: `off | internet-facing | internal`
Required: Yes

 ** ipv6Addressability **   <a name="elasticloadbalancing-Type-ProxyIpAddressingConfiguration-ipv6Addressability"></a>
The IPv6 addressability setting for the proxy.
Type: String
Valid Values: `off | internet-facing | internal`
Required: Yes
