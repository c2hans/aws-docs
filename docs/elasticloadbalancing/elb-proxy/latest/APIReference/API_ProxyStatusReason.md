# ProxyStatusReason

A reason for the current status of a proxy.

## Contents
<a name="API_ProxyStatusReason_Contents"></a>

 ** code **   <a name="elasticloadbalancing-Type-ProxyStatusReason-code"></a>
The status reason code.
Type: String
Required: Yes

 ** message **   <a name="elasticloadbalancing-Type-ProxyStatusReason-message"></a>
The status reason message.
Type: String
Required: No

 ** target **   <a name="elasticloadbalancing-Type-ProxyStatusReason-target"></a>
The target resource of the status reason.
Type: String
Required: No
