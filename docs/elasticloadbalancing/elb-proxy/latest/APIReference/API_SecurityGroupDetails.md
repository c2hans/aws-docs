# SecurityGroupDetails

The details of a security group.

## Contents
<a name="API_SecurityGroupDetails_Contents"></a>

 ** securityGroupId **   <a name="elasticloadbalancing-Type-SecurityGroupDetails-securityGroupId"></a>
The ID of the security group.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `sg-.+`
Required: Yes
