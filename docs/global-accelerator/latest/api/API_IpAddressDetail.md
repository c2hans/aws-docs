# IpAddressDetail
<a name="API_IpAddressDetail"></a>

Detailed information for the IP addresses assigned to the Global Accelerator.

## Contents
<a name="API_IpAddressDetail_Contents"></a>

 ** IpAddress **   <a name="globalaccelerator-Type-IpAddressDetail-IpAddress"></a>
The static IP address.
Type: String
Length Constraints: Maximum length of 45.
Required: No

 ** NetworkZone **   <a name="globalaccelerator-Type-IpAddressDetail-NetworkZone"></a>
The network zone that the specified IP address is located on.
Type: String
Length Constraints: Maximum length of 24.
Required: No
