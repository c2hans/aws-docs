# Controlling access with IAM
<a name="controlling-access-with-iam"></a>

 You control which users and roles in your AWS account can access Security Incident Response through IAM policies. For information about configuring IAM permissions for Security Incident Response, see [Identity and Access Management](identity-and-access-management.md).

* **Skills for AI coding assistants (optional).** AWS publishes reusable skills for Security Incident Response. To see which apply, search the Agent Toolkit for AWS catalog with `aws agent-toolkit search-skills --search-query security-ir` — a documented, read-only AWS CLI command that searches the catalog and makes no changes.
