# ServiceProfile
<a name="API_ServiceProfile"></a>

Information about a service profile.

## Contents
<a name="API_ServiceProfile_Contents"></a>

 ** Arn **   <a name="iotwireless-Type-ServiceProfile-Arn"></a>
The Amazon Resource Name of the resource.
Type: String
Required: No

 ** Id **   <a name="iotwireless-Type-ServiceProfile-Id"></a>
The ID of the service profile.
Type: String
Length Constraints: Maximum length of 256.
Required: No

 ** Name **   <a name="iotwireless-Type-ServiceProfile-Name"></a>
The name of the resource.
Type: String
Length Constraints: Maximum length of 256.
Required: No
