# LteLocalId
<a name="API_LteLocalId"></a>

LTE local identification (local ID) information.

## Contents
<a name="API_LteLocalId_Contents"></a>

 ** Earfcn **   <a name="iotwireless-Type-LteLocalId-Earfcn"></a>
Evolved universal terrestrial radio access (E-UTRA) absolute radio frequency channel number (FCN).
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 262143.
Required: Yes

 ** Pci **   <a name="iotwireless-Type-LteLocalId-Pci"></a>
Physical cell ID.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 503.
Required: Yes
