# JoinEventConfiguration
<a name="API_JoinEventConfiguration"></a>

Join event configuration object for enabling or disabling topic.

## Contents
<a name="API_JoinEventConfiguration_Contents"></a>

 ** LoRaWAN **   <a name="iotwireless-Type-JoinEventConfiguration-LoRaWAN"></a>
Join event configuration object for enabling or disabling LoRaWAN related event topics.
Type: [LoRaWANJoinEventNotificationConfigurations](API_LoRaWANJoinEventNotificationConfigurations.md) object
Required: No

 ** WirelessDeviceIdEventTopic **   <a name="iotwireless-Type-JoinEventConfiguration-WirelessDeviceIdEventTopic"></a>
Denotes whether the wireless device ID join event topic is enabled or disabled.
Type: String
Valid Values: `Enabled | Disabled`
Required: No
