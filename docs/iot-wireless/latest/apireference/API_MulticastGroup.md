# MulticastGroup
<a name="API_MulticastGroup"></a>

A multicast group.

## Contents
<a name="API_MulticastGroup_Contents"></a>

 ** Arn **   <a name="iotwireless-Type-MulticastGroup-Arn"></a>
The arn of the multicast group.
Type: String
Length Constraints: Maximum length of 128.
Required: No

 ** Id **   <a name="iotwireless-Type-MulticastGroup-Id"></a>
The ID of the multicast group.
Type: String
Length Constraints: Maximum length of 256.
Required: No

 ** Name **   <a name="iotwireless-Type-MulticastGroup-Name"></a>
The name of the multicast group.
Type: String
Length Constraints: Maximum length of 256.
Required: No
