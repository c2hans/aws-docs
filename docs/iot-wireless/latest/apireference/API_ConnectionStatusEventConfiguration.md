# ConnectionStatusEventConfiguration
<a name="API_ConnectionStatusEventConfiguration"></a>

Connection status event configuration object for enabling or disabling topic.

## Contents
<a name="API_ConnectionStatusEventConfiguration_Contents"></a>

 ** LoRaWAN **   <a name="iotwireless-Type-ConnectionStatusEventConfiguration-LoRaWAN"></a>
Connection status event configuration object for enabling or disabling LoRaWAN related event topics.
Type: [LoRaWANConnectionStatusEventNotificationConfigurations](API_LoRaWANConnectionStatusEventNotificationConfigurations.md) object
Required: No

 ** WirelessGatewayIdEventTopic **   <a name="iotwireless-Type-ConnectionStatusEventConfiguration-WirelessGatewayIdEventTopic"></a>
Denotes whether the wireless gateway ID connection status event topic is enabled or disabled.
Type: String
Valid Values: `Enabled | Disabled`
Required: No
