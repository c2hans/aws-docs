# DefaultSessionParametersMulticast
<a name="API_DefaultSessionParametersMulticast"></a>

The default session parameters for the multicast group.

## Contents
<a name="API_DefaultSessionParametersMulticast_Contents"></a>

 ** DlDr **   <a name="iotwireless-Type-DefaultSessionParametersMulticast-DlDr"></a>
Downlink data rate.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 15.
Required: No

 ** DlFreq **   <a name="iotwireless-Type-DefaultSessionParametersMulticast-DlFreq"></a>
Downlink frequency.
Type: Integer
Valid Range: Minimum value of 100000000. Maximum value of 1000000000.
Required: No
