# CdmaLocalId
<a name="API_CdmaLocalId"></a>

CDMA local ID information, which corresponds to the local identification parameters of a CDMA cell.

## Contents
<a name="API_CdmaLocalId_Contents"></a>

 ** CdmaChannel **   <a name="iotwireless-Type-CdmaLocalId-CdmaChannel"></a>
CDMA channel information.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 4095.
Required: Yes

 ** PnOffset **   <a name="iotwireless-Type-CdmaLocalId-PnOffset"></a>
Pseudo-noise offset, which is a characteristic of the signal from a cell on a radio tower.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 511.
Required: Yes
