# SemtechGnssConfiguration
<a name="API_SemtechGnssConfiguration"></a>

Information about the Semtech GNSS solver configuration.

## Contents
<a name="API_SemtechGnssConfiguration_Contents"></a>

 ** Fec **   <a name="iotwireless-Type-SemtechGnssConfiguration-Fec"></a>
Whether forward error correction is enabled.
Type: String
Valid Values: `ROSE | NONE`
Required: Yes

 ** Status **   <a name="iotwireless-Type-SemtechGnssConfiguration-Status"></a>
The status indicating whether the solver is enabled.
Type: String
Valid Values: `Enabled | Disabled`
Required: Yes
