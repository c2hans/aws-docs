# Dimension
<a name="API_Dimension"></a>

The required list of dimensions for the metric.

## Contents
<a name="API_Dimension_Contents"></a>

 ** name **   <a name="iotwireless-Type-Dimension-name"></a>
The name of the dimension.
Type: String
Length Constraints: Maximum length of 256.
Valid Values: `DeviceId | GatewayId`
Required: No

 ** value **   <a name="iotwireless-Type-Dimension-value"></a>
The dimension's value.
Type: String
Length Constraints: Maximum length of 256.
Required: No
