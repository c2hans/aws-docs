# WcdmaLocalId
<a name="API_WcdmaLocalId"></a>

WCDMA local identification (local ID) information.

## Contents
<a name="API_WcdmaLocalId_Contents"></a>

 ** Psc **   <a name="iotwireless-Type-WcdmaLocalId-Psc"></a>
Primary Scrambling Code.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 511.
Required: Yes

 ** Uarfcndl **   <a name="iotwireless-Type-WcdmaLocalId-Uarfcndl"></a>
WCDMA UTRA Absolute RF Channel Number downlink.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 16383.
Required: Yes
