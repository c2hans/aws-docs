# SidewalkUpdateImportInfo
<a name="API_SidewalkUpdateImportInfo"></a>

Sidewalk object information for updating an import task.

## Contents
<a name="API_SidewalkUpdateImportInfo_Contents"></a>

 ** DeviceCreationFile **   <a name="iotwireless-Type-SidewalkUpdateImportInfo-DeviceCreationFile"></a>
The CSV file contained in an S3 bucket that's used for appending devices to an existing import task.
Type: String
Length Constraints: Maximum length of 1024.
Required: No
