# SidewalkEventNotificationConfigurations
<a name="API_SidewalkEventNotificationConfigurations"></a>

 `SidewalkEventNotificationConfigurations` object, which is the event configuration object for Sidewalk-related event topics.

## Contents
<a name="API_SidewalkEventNotificationConfigurations_Contents"></a>

 ** AmazonIdEventTopic **   <a name="iotwireless-Type-SidewalkEventNotificationConfigurations-AmazonIdEventTopic"></a>
Denotes whether the Amazon ID event topic is enabled or disabled.
Type: String
Valid Values: `Enabled | Disabled`
Required: No
