# LoRaWANGatewayVersion
<a name="API_LoRaWANGatewayVersion"></a>

LoRaWANGatewayVersion object.

## Contents
<a name="API_LoRaWANGatewayVersion_Contents"></a>

 ** Model **   <a name="iotwireless-Type-LoRaWANGatewayVersion-Model"></a>
The model number of the wireless gateway.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Required: No

 ** PackageVersion **   <a name="iotwireless-Type-LoRaWANGatewayVersion-PackageVersion"></a>
The version of the wireless gateway firmware.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 32.
Required: No

 ** Station **   <a name="iotwireless-Type-LoRaWANGatewayVersion-Station"></a>
The basic station version of the wireless gateway.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Required: No
