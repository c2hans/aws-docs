# LoRaWANFuotaTaskGetInfo
<a name="API_LoRaWANFuotaTaskGetInfo"></a>

The LoRaWAN information returned from getting a FUOTA task.

## Contents
<a name="API_LoRaWANFuotaTaskGetInfo_Contents"></a>

 ** RfRegion **   <a name="iotwireless-Type-LoRaWANFuotaTaskGetInfo-RfRegion"></a>
The frequency band (RFRegion) value.
Type: String
Length Constraints: Maximum length of 64.
Required: No

 ** StartTime **   <a name="iotwireless-Type-LoRaWANFuotaTaskGetInfo-StartTime"></a>
Start time of a FUOTA task.
Type: Timestamp
Required: No
