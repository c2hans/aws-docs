# SidewalkSingleStartImportInfo
<a name="API_SidewalkSingleStartImportInfo"></a>

Information about an import task created for an individual Sidewalk device.

## Contents
<a name="API_SidewalkSingleStartImportInfo_Contents"></a>

 ** Positioning **   <a name="iotwireless-Type-SidewalkSingleStartImportInfo-Positioning"></a>
The Positioning object of the Sidewalk device.
Type: [SidewalkPositioning](API_SidewalkPositioning.md) object
Required: No

 ** SidewalkManufacturingSn **   <a name="iotwireless-Type-SidewalkSingleStartImportInfo-SidewalkManufacturingSn"></a>
The Sidewalk manufacturing serial number (SMSN) of the device added to the import task.
Type: String
Length Constraints: Maximum length of 64.
Required: No
