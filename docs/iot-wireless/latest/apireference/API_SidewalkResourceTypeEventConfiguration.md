# SidewalkResourceTypeEventConfiguration
<a name="API_SidewalkResourceTypeEventConfiguration"></a>

Sidewalk resource type event configuration object for enabling or disabling topic.

## Contents
<a name="API_SidewalkResourceTypeEventConfiguration_Contents"></a>

 ** WirelessDeviceEventTopic **   <a name="iotwireless-Type-SidewalkResourceTypeEventConfiguration-WirelessDeviceEventTopic"></a>
Denotes whether the wireless device join event topic is enabled or disabled.
Type: String
Valid Values: `Enabled | Disabled`
Required: No
