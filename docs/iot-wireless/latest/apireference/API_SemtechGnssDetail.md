# SemtechGnssDetail
<a name="API_SemtechGnssDetail"></a>

Details of the Semtech GNSS solver object.

## Contents
<a name="API_SemtechGnssDetail_Contents"></a>

 ** Fec **   <a name="iotwireless-Type-SemtechGnssDetail-Fec"></a>
Whether forward error correction is enabled.
Type: String
Valid Values: `ROSE | NONE`
Required: No

 ** Provider **   <a name="iotwireless-Type-SemtechGnssDetail-Provider"></a>
The vendor of the solver object.
Type: String
Valid Values: `Semtech`
Required: No

 ** Status **   <a name="iotwireless-Type-SemtechGnssDetail-Status"></a>
The status indicating whether the solver is enabled.
Type: String
Valid Values: `Enabled | Disabled`
Required: No

 ** Type **   <a name="iotwireless-Type-SemtechGnssDetail-Type"></a>
The type of positioning solver used.
Type: String
Valid Values: `GNSS`
Required: No
