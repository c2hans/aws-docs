# SidewalkPositioning
<a name="API_SidewalkPositioning"></a>

The Positioning object of the Sidewalk device.

## Contents
<a name="API_SidewalkPositioning_Contents"></a>

 ** DestinationName **   <a name="iotwireless-Type-SidewalkPositioning-DestinationName"></a>
The location destination name of the Sidewalk device.
Type: String
Length Constraints: Maximum length of 128.
Pattern: `[a-zA-Z0-9-_]+`
Required: No
