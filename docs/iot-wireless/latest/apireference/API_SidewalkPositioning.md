# SidewalkPositioning

 ** DestinationName **   <a name="iotwireless-Type-SidewalkPositioning-DestinationName"></a>
The location destination name of the Sidewalk device.
Type: String
Length Constraints: Maximum length of 128.
Pattern: `[a-zA-Z0-9-_]+`
Required: No
