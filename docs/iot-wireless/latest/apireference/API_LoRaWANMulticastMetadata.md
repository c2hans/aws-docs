# LoRaWANMulticastMetadata
<a name="API_LoRaWANMulticastMetadata"></a>

<a name="API_LoRaWANMulticastMetadata_Contents"></a>

 ** FPort **   <a name="iotwireless-Type-LoRaWANMulticastMetadata-FPort"></a>
The Fport value.

Valid Range: Minimum value of 1. Maximum value of 223.
Required: No
