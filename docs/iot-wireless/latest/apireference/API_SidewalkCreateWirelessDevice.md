# SidewalkCreateWirelessDevice
<a name="API_SidewalkCreateWirelessDevice"></a>

Sidewalk object for creating a wireless device.

## Contents
<a name="API_SidewalkCreateWirelessDevice_Contents"></a>

 ** DeviceProfileId **   <a name="iotwireless-Type-SidewalkCreateWirelessDevice-DeviceProfileId"></a>
The ID of the Sidewalk device profile.
Type: String
Length Constraints: Maximum length of 256.
Required: No

 ** Positioning **   <a name="iotwireless-Type-SidewalkCreateWirelessDevice-Positioning"></a>
The Positioning object of the Sidewalk device.
Type: [SidewalkPositioning](API_SidewalkPositioning.md) object
Required: No

 ** SidewalkManufacturingSn **   <a name="iotwireless-Type-SidewalkCreateWirelessDevice-SidewalkManufacturingSn"></a>
The Sidewalk manufacturing serial number.
Type: String
Length Constraints: Maximum length of 64.
Required: No
