# LoRaWANGatewayMetadata
<a name="API_LoRaWANGatewayMetadata"></a>

LoRaWAN gateway metatdata.

## Contents
<a name="API_LoRaWANGatewayMetadata_Contents"></a>

 ** GatewayEui **   <a name="iotwireless-Type-LoRaWANGatewayMetadata-GatewayEui"></a>
The gateway's EUI value.
Type: String
Pattern: `^(([0-9A-Fa-f]{2}-){7}|([0-9A-Fa-f]{2}:){7}|([0-9A-Fa-f]{2}\s){7}|([0-9A-Fa-f]{2}){7})([0-9A-Fa-f]{2})$`
Required: No

 ** Rssi **   <a name="iotwireless-Type-LoRaWANGatewayMetadata-Rssi"></a>
The RSSI value.
Type: Double
Required: No

 ** Snr **   <a name="iotwireless-Type-LoRaWANGatewayMetadata-Snr"></a>
The SNR value.
Type: Double
Required: No
