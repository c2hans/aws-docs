# AWS IoT Wireless Documentation

AWS IoT Wireless provides secure, bi-directional communication for internet-connected wireless devices to connect to the AWS Cloud. The devices include LoRaWAN devices and gateways, and Sidewalk end devices.

- [Developer Guide](/iot-wireless/latest/developerguide/): Walks through how to set up AWS IoT Wireless and integrate it with other services.
- [AWS IoT Core for LoRaWAN](/iot-wireless/latest/developerguide/iot-lorawan.html): Describes how to configure wireless devices for AWS IoT Core for LoRaWAN.
- [AWS IoT Core for Amazon Sidewalk](/iot-wireless/latest/developerguide/iot-sidewalk.html): Describes how to configure wireless devices for AWS IoT Core for Amazon Sidewalk.
- [AWS IoT Wireless API Reference](/iot-wireless/latest/apireference/): Describes in detail all the API operations used by AWS IoT Core for LoRaWAN and AWS IoT Core for Amazon Sidewalk.
- [AWS IoT Wireless AWS CLI Reference](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/iotwireless/index.html): Describes the AWS CLI commands that you can use to administer and manipulate AWS IoT Wireless.
