# SecretsManagerCredentialsProvider
<a name="API_SecretsManagerCredentialsProvider"></a>

Contains a credentials secret that's stored in AWS Secrets Manager.

## Contents
<a name="API_SecretsManagerCredentialsProvider_Contents"></a>

 ** SecretId **   <a name="licensemanagerusersubscriptions-Type-SecretsManagerCredentialsProvider-SecretId"></a>
The ID of the Secrets Manager secret that contains credentials.
Type: String
Length Constraints: Minimum length of 1.
Required: No
