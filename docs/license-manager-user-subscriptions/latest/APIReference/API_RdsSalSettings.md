# RdsSalSettings
<a name="API_RdsSalSettings"></a>

Server settings that are specific to a Remote Desktop Services (RDS) license server.

## Contents
<a name="API_RdsSalSettings_Contents"></a>

 ** RdsSalCredentialsProvider **   <a name="licensemanagerusersubscriptions-Type-RdsSalSettings-RdsSalCredentialsProvider"></a>
The `CredentialsProvider` resource contains a reference to the credentials provider that's used for RDS license server user administration.
Type: [CredentialsProvider](API_CredentialsProvider.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes
