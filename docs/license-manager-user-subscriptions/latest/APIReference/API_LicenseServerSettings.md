# LicenseServerSettings
<a name="API_LicenseServerSettings"></a>

The settings to configure your license server.

## Contents
<a name="API_LicenseServerSettings_Contents"></a>

 ** ServerSettings **   <a name="licensemanagerusersubscriptions-Type-LicenseServerSettings-ServerSettings"></a>
The `ServerSettings` resource contains the settings for your server.
Type: [ServerSettings](API_ServerSettings.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes

 ** ServerType **   <a name="licensemanagerusersubscriptions-Type-LicenseServerSettings-ServerType"></a>
The type of license server.
Type: String
Valid Values: `RDS_SAL`
Required: Yes
