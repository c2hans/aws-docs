# DomainNetworkSettings
<a name="API_DomainNetworkSettings"></a>

Contains network settings for the Active Directory domain.

## Contents
<a name="API_DomainNetworkSettings_Contents"></a>

 ** Subnets **   <a name="licensemanagerusersubscriptions-Type-DomainNetworkSettings-Subnets"></a>
Contains a list of subnets that apply for the Active Directory domain.
Type: Array of strings
Array Members: Minimum number of 1 item.
Pattern: `subnet-[a-z0-9]{8,17}.*`
Required: Yes
