# Filter
<a name="API_Filter"></a>

A filter name and value pair that is used to return more specific results from a describe or list operation. You can use filters can be used to match a set of resources by specific criteria, such as tags, attributes, or IDs.

## Contents
<a name="API_Filter_Contents"></a>

 ** Attribute **   <a name="licensemanagerusersubscriptions-Type-Filter-Attribute"></a>
The name of an attribute to use as a filter.
Type: String
Required: No

 ** Operation **   <a name="licensemanagerusersubscriptions-Type-Filter-Operation"></a>
The type of search (For example, eq, geq, leq)
Type: String
Required: No

 ** Value **   <a name="licensemanagerusersubscriptions-Type-Filter-Value"></a>
Value of the filter.
Type: String
Required: No
