# AWS Sustainability Documentation

The AWS Sustainability service provides a suite of features to help you understand your environmental impact from using AWS services.

- [User Guide](/sustainability/latest/userguide): Provides an overview of AWS Sustainability, detailed feature descriptions, procedures for using the console, and an explanation of the methodology behind your environmental impact data.
- [API Reference](/sustainability/latest/APIReference): Describes all the API operations for AWS Sustainability in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
