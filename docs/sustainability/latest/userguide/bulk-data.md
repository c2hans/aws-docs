# Get your data in bulk
<a name="bulk-data"></a>

You have three options to access your data in bulk.

1. Download your data in csv format. See [CSV reports](csv-reports.md) for details.

1. Access your data via API. See the [AWS Sustainability API Reference](https://docs.aws.amazon.com/sustainability/latest/APIReference) for details.

1. For carbon emissions, you can also create a data export to S3 via Data Exports, a product in the Billing and Cost Management console. See [What is AWS Data Exports?](https://docs.aws.amazon.com/cur/latest/userguide/what-is-data-exports.html) for details.
