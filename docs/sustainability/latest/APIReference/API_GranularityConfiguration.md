# GranularityConfiguration
<a name="API_GranularityConfiguration"></a>

 Contains configuration for the fiscal year granularities (e.g., `YEARLY_FISCAL`, `QUARTERLY_FISCAL`.

## Contents
<a name="API_GranularityConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FiscalYearStartMonth **   <a name="sustainability-Type-GranularityConfiguration-FiscalYearStartMonth"></a>
 The month (1-12) when the fiscal year begins. Used for `YEARLY_FISCAL` and `QUARTERLY_FISCAL` granularity. Defaults to 1 (January).
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 12.
Required: No
