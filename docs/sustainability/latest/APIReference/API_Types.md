# Data Types
<a name="API_Types"></a>

The AWS Sustainability API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [DimensionEntry](API_DimensionEntry.md)
+  [Emissions](API_Emissions.md)
+  [EstimatedCarbonEmissions](API_EstimatedCarbonEmissions.md)
+  [EstimatedWaterAllocation](API_EstimatedWaterAllocation.md)
+  [FilterExpression](API_FilterExpression.md)
+  [GranularityConfiguration](API_GranularityConfiguration.md)
+  [TimePeriod](API_TimePeriod.md)
+  [WaterAllocation](API_WaterAllocation.md)
