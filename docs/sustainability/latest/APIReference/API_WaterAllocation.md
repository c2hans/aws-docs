# WaterAllocation
<a name="API_WaterAllocation"></a>

Represents a water allocation quantity with its value and unit of measurement.

## Contents
<a name="API_WaterAllocation_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Unit **   <a name="sustainability-Type-WaterAllocation-Unit"></a>
The unit of measurement for the allocation value.
Type: String
Valid Values: `m3`
Required: Yes

 ** Value **   <a name="sustainability-Type-WaterAllocation-Value"></a>
The numeric value of the allocation quantity.
Type: Double
Required: Yes
