# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

Describes a validation exception for a specific field.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="uxc-Type-ValidationExceptionField-message"></a>
A message describing the validation exception.
Type: String
Required: Yes

 ** path **   <a name="uxc-Type-ValidationExceptionField-path"></a>
The field name with the validation exception.
Type: String
Required: Yes
