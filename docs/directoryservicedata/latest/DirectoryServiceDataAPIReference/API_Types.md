# Data Types
<a name="API_Types"></a>

The AWS Directory Service Data API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AttributeValue](API_AttributeValue.md)
+  [Group](API_Group.md)
+  [GroupSummary](API_GroupSummary.md)
+  [Member](API_Member.md)
+  [User](API_User.md)
+  [UserSummary](API_UserSummary.md)
