# Data Types
<a name="API_Types"></a>

The IAM Toolbox (Preview) API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AttachedTo](API_AttachedTo.md)
+  [Evaluation](API_Evaluation.md)
+  [MatchedPolicy](API_MatchedPolicy.md)
+  [MatchedStatement](API_MatchedStatement.md)
+  [PolicyInfo](API_PolicyInfo.md)
