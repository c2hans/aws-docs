# Amazon Virtual Private Cloud Documentation

Amazon Virtual Private Cloud (Amazon VPC) enables you to provision a logically isolated section of the AWS Cloud where you can launch AWS resources in a virtual network that you've defined.

## Amazon VPC

- [User Guide](/vpc/latest/userguide/): Create and configure your virtual private cloud (VPC).
- [Peering Guide](/vpc/latest/peering/): Connect your VPC with other VPCs and access resources across VPCs.
- [Traffic Mirroring Guide](/vpc/latest/mirroring/): Capture and mirror network traffic for your Amazon EC2 instances.
- [Amazon VPC API Reference](/AWSEC2/latest/APIReference/OperationList-query-vpc.html): Get syntax and examples for VPC API actions.

## Amazon VPC IP Address Manager

Amazon VPC IP Address Manager (IPAM) automates your IP address management workflows. This includes assigning, tracking, troubleshooting, and auditing IP addresses across AWS Regions and accounts throughout your AWS Organization.

- [User Guide](/vpc/latest/ipam/): Create an IPAM and automate IP address management.
- [Amazon VPC IP Address Manager API Reference](/AWSEC2/latest/APIReference/operation-list-ipam.html): Get syntax and examples for the API actions.

## AWS PrivateLink

AWS PrivateLink establishes private connectivity between VPCs and services hosted on AWS or on-premises, without exposing data to the internet.

- [AWS PrivateLink Guide](/vpc/latest/privatelink): Configure VPC endpoints and VPC endpoint services.
- [AWS PrivateLink API Reference](/AWSEC2/latest/APIReference/operation-list-privatelink.html): Get syntax and examples for the API actions.

## AWS Transit Gateway

AWS Transit Gateway connects your VPCs and on-premises networks through a central hub.

- [Transit Gateway Guide](/vpc/latest/tgw/): Simplify your network architecture.
- [Transit Gateway API Reference](/AWSEC2/latest/APIReference/operation-list-tgw.html): Get syntax and examples for the API actions.

## AWS Network Manager

AWS Network Manager allows you to manage and monitor your AWS network environment from a centralized location, including creating global networks.

- [AWS Global Networks for Transit Gateways User Guide](/network-manager/latest/tgwnm): Create, manage, and visualize global networks for transit gateways across AWS accounts, Regions, and on premises.
- [AWS Cloud WAN](/network-manager/latest/cloudwan/): Create, visualize, and manage a core network within an AWS global network.
- [AWS Global Networks for Transit Gateways API Reference](/networkmanager/latest/APIReference/): Get syntax and examples for the API actions. AWS Cloud WAN and AWS Global Networks for Transit Gateways use the same namespace.
- [Reachability Analyzer Guide](/vpc/latest/reachability/): Analyze and debug network reachability between resources in your VPCs.
- [Infrastructure Performance Guide](/network-manager/latest/infrastructure-performance/): View network performance and latency across AWS Regions and Availability Zones.
- [Network Access Analyzer Guide](/vpc/latest/network-access-analyzer/): Identify unintended network access to resources in your VPCs.
- [AWS Network Manager API Reference](/AWSEC2/latest/APIReference/OperationList-query-networkmanager.html): Get syntax and examples for Reachability Analyzer, Infrastructure Performance, and Network Access Analyzer API actions.

## Amazon VPC Lattice

Amazon VPC Lattice is a fully managed application networking service that you use to connect, secure, and monitor all of your services across multiple accounts and virtual private clouds (VPCs).

- [User Guide](/vpc-lattice/latest/ug/): Provides an overview of Amazon VPC Lattice, detailed feature descriptions, and procedures for using the Amazon VPC Lattice console and the AWS CLI.
- [API Reference](/vpc-lattice/latest/APIReference/): Describes all of the API operations for Amazon VPC Lattice in detail. Also provides sample requests, responses, and errors for Amazon VPC Lattice API actions.
- [CLI Reference](/cli/latest/reference/vpc-lattice/): Describes the Amazon VPC Lattice CLI commands in the AWS CLI. Provides basic syntax, options, and usage examples for each command.
