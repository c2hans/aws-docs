# Asia/Oceania
<a name="registrar-tld-list-asiaoceania"></a>

You can use the following top-level domains (TLDs) for Asia and Oceania to register domains with Amazon Route 53.

[.au (Australia)](au.md) [.cc (Cocos (Keeling) Islands)](cc.md), [.co.nz (New Zealand)](co.nz.md), [.com.au (Australia)](com.au.md), [.com.sg (Republic of Singapore)](com.sg.md), [.fm (Federated States of Micronesia)](fm.md), [.in (India)](in.md), [.jp (Japan)](jp.md), [.io (British Indian Ocean Territory)](io.md), [.my (Malaysia)](my.md), [.net.au (Australia)](net.au.md), [.net.nz (New Zealand)](net.nz.md), [.nz (New Zealand)](nz.md), [.org.nz (New Zealand)](org.nz.md), [.pw (Palau)](pw.md), [.qa (Qatar)](qa.md), [.ru (Russian Federation)](ru.md), [.sg (Republic of Singapore)](sg.md)
