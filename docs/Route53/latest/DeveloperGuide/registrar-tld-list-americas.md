# Americas
<a name="registrar-tld-list-americas"></a>

You can use the following top-level domains (TLDs) for the Americas to register domains with Amazon Route 53.

[.ai (Anguilla)](ai.md), [.ca (Canada)](ca.md), [.cl (Chile)](cl.md), [.co (Colombia)](co.md), [.com.ar (Argentina)](com.ar.md), [.com.br (Brazil)](com.br.md), [.com.mx (Mexico)](com.mx.md), [.mx (Mexico)](mx.md), [.us (United States)](us.md), [.vc (Saint Vincent and the Grenadines)](vc.md), [.vg (British Virgin Islands)](vg.md)

[Return to index](registrar-tld-list.md#index)
