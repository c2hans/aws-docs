# Using AWS Cloud Map to create records and health checks
<a name="autonaming"></a>

To route internet traffic or Amazon VPC traffic to application components or microservices, use AWS Cloud Map. It automatically creates DNS records and, optionally, health checks. For more information, see the [AWS Cloud Map Developer Guide](https://docs.aws.amazon.com/cloud-map/latest/dg/).
