# TLDs that don't support privacy protection
<a name="privacy-protection-tld-support"></a>

The following TLDs do not support privacy protection. If your domain uses one of these TLDs, your contact information will be publicly visible in WHOIS queries:

Generic TLDs
.audio, .ceo, .diet, .flowers, .guitars, .hosting, .juegos, .property, .sexy

Geographic TLDs
.cl (Chile), .com.ar (Argentina), .com.au (Australia), .com.br (Brazil), .com.sg (Singapore), .de (Germany), .es (Spain), .in (India), .net.au (Australia), .qa (Qatar), .ru (Russia), .sg (Singapore), .us (United States), .vg (British Virgin Islands)

**Note**
This list includes the most common TLDs that don't support privacy protection. For complete and up-to-date information about privacy protection support for a specific TLD, see the individual TLD page in [Domains that you can register with Amazon Route 53](registrar-tld-list.md).
