# BatchDeleteFirewallRuleError
<a name="API_route53resolver_BatchDeleteFirewallRuleError"></a>

An error that occurred while deleting a firewall rule in a batch operation.

## Contents
<a name="API_route53resolver_BatchDeleteFirewallRuleError_Contents"></a>

 ** Code **   <a name="Route53Resolver-Type-route53resolver_BatchDeleteFirewallRuleError-Code"></a>
The error code for the failure.
Type: String
Required: No

 ** FirewallRule **   <a name="Route53Resolver-Type-route53resolver_BatchDeleteFirewallRuleError-FirewallRule"></a>
The firewall rule entry that caused the error.
Type: [DeleteFirewallRuleEntry](API_route53resolver_DeleteFirewallRuleEntry.md) object
Required: No

 ** Message **   <a name="Route53Resolver-Type-route53resolver_BatchDeleteFirewallRuleError-Message"></a>
A message that provides details about the error.
Type: String
Required: No
