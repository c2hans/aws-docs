# ValidationExceptionField
<a name="API_route53globalresolver_ValidationExceptionField"></a>

Information about a field that failed validation.

## Contents
<a name="API_route53globalresolver_ValidationExceptionField_Contents"></a>

 ** message **   <a name="Route53GlobalResolver-Type-route53globalresolver_ValidationExceptionField-message"></a>
The validation error message for the field.
Type: String
Required: Yes

 ** name **   <a name="Route53GlobalResolver-Type-route53globalresolver_ValidationExceptionField-name"></a>
The name of the field that failed validation.
Type: String
Required: Yes
