# Tag
<a name="API_route53profiles_Tag"></a>

 Tag for the Profile.

## Contents
<a name="API_route53profiles_Tag_Contents"></a>

 ** Key **   <a name="Route53Profiles-Type-route53profiles_Tag-Key"></a>
 Key associated with the `Tag`.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** Value **   <a name="Route53Profiles-Type-route53profiles_Tag-Value"></a>
 Value for the Tag.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: Yes
