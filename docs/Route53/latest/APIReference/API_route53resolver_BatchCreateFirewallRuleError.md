# BatchCreateFirewallRuleError
<a name="API_route53resolver_BatchCreateFirewallRuleError"></a>

An error that occurred while creating a firewall rule in a batch operation.

## Contents
<a name="API_route53resolver_BatchCreateFirewallRuleError_Contents"></a>

 ** Code **   <a name="Route53Resolver-Type-route53resolver_BatchCreateFirewallRuleError-Code"></a>
The error code for the failure.
Type: String
Required: No

 ** FirewallRule **   <a name="Route53Resolver-Type-route53resolver_BatchCreateFirewallRuleError-FirewallRule"></a>
The firewall rule entry that caused the error.
Type: [CreateFirewallRuleEntry](API_route53resolver_CreateFirewallRuleEntry.md) object
Required: No

 ** Message **   <a name="Route53Resolver-Type-route53resolver_BatchCreateFirewallRuleError-Message"></a>
A message that provides details about the error.
Type: String
Required: No
