# BatchUpdateFirewallRuleError
<a name="API_route53resolver_BatchUpdateFirewallRuleError"></a>

An error that occurred while updating a firewall rule in a batch operation.

## Contents
<a name="API_route53resolver_BatchUpdateFirewallRuleError_Contents"></a>

 ** Code **   <a name="Route53Resolver-Type-route53resolver_BatchUpdateFirewallRuleError-Code"></a>
The error code for the failure.
Type: String
Required: No

 ** FirewallRule **   <a name="Route53Resolver-Type-route53resolver_BatchUpdateFirewallRuleError-FirewallRule"></a>
The firewall rule entry that caused the error.
Type: [UpdateFirewallRuleEntry](API_route53resolver_UpdateFirewallRuleEntry.md) object
Required: No

 ** Message **   <a name="Route53Resolver-Type-route53resolver_BatchUpdateFirewallRuleError-Message"></a>
A message that provides details about the error.
Type: String
Required: No
