# SubscriptionTargetForm
<a name="API_SubscriptionTargetForm"></a>

The details of the subscription target configuration.

## Contents
<a name="API_SubscriptionTargetForm_Contents"></a>

 ** content **   <a name="datazone-Type-SubscriptionTargetForm-content"></a>
The content of the subscription target configuration.
Type: String
Required: Yes

 ** formName **   <a name="datazone-Type-SubscriptionTargetForm-formName"></a>
The form name included in the subscription target configuration.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `(?![0-9_])\w+$|^_\w*[a-zA-Z0-9]\w*`
Required: Yes
