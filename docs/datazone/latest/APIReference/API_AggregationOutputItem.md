# AggregationOutputItem
<a name="API_AggregationOutputItem"></a>

An aggregation output item.

## Contents
<a name="API_AggregationOutputItem_Contents"></a>

 ** count **   <a name="datazone-Type-AggregationOutputItem-count"></a>
The count of the aggregation output item.
Type: Integer
Required: No

 ** displayValue **   <a name="datazone-Type-AggregationOutputItem-displayValue"></a>
The display value of the aggregation. If the attribute being aggregated corresponds to the id of a public resource, the service automatically resolves the id to the provided display value.
Type: String
Required: No

 ** value **   <a name="datazone-Type-AggregationOutputItem-value"></a>
The attribute value of the aggregation output item.
Type: String
Required: No
