# Resource
<a name="API_Resource"></a>

The details of a provisioned resource of this Amazon DataZone environment.

## Contents
<a name="API_Resource_Contents"></a>

 ** type **   <a name="datazone-Type-Resource-type"></a>
The type of a provisioned resource of this Amazon DataZone environment.
Type: String
Required: Yes

 ** value **   <a name="datazone-Type-Resource-value"></a>
The value of a provisioned resource of this Amazon DataZone environment.
Type: String
Required: Yes

 ** name **   <a name="datazone-Type-Resource-name"></a>
The name of a provisioned resource of this Amazon DataZone environment.
Type: String
Required: No

 ** provider **   <a name="datazone-Type-Resource-provider"></a>
The provider of a provisioned resource of this Amazon DataZone environment.
Type: String
Required: No
