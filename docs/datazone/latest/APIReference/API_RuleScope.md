# RuleScope
<a name="API_RuleScope"></a>

The scope of a rule.

## Contents
<a name="API_RuleScope_Contents"></a>

 ** assetType **   <a name="datazone-Type-RuleScope-assetType"></a>
The asset type included in the rule scope.
Type: [AssetTypesForRule](API_AssetTypesForRule.md) object
Required: No

 ** dataProduct **   <a name="datazone-Type-RuleScope-dataProduct"></a>
The data product included in the rule scope.
Type: Boolean
Required: No

 ** project **   <a name="datazone-Type-RuleScope-project"></a>
The project included in the rule scope.
Type: [ProjectsForRule](API_ProjectsForRule.md) object
Required: No
