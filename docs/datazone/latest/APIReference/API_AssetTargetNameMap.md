# AssetTargetNameMap
<a name="API_AssetTargetNameMap"></a>

The name map for assets.

## Contents
<a name="API_AssetTargetNameMap_Contents"></a>

 ** assetId **   <a name="datazone-Type-AssetTargetNameMap-assetId"></a>
The identifier of the inventory asset.
Type: String
Pattern: `[a-zA-Z0-9_-]{1,36}`
Required: Yes

 ** targetName **   <a name="datazone-Type-AssetTargetNameMap-targetName"></a>
The target name in the asset target name map.
Type: String
Required: Yes
