# AttributeError
<a name="API_AttributeError"></a>

The attribute error.

## Contents
<a name="API_AttributeError_Contents"></a>

 ** attributeIdentifier **   <a name="datazone-Type-AttributeError-attributeIdentifier"></a>
The attribute ID as part of the attribute error.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes

 ** code **   <a name="datazone-Type-AttributeError-code"></a>
The code generated as part of the attribute error.
Type: String
Required: Yes

 ** message **   <a name="datazone-Type-AttributeError-message"></a>
The message generated as part of the attribute error.
Type: String
Required: Yes
