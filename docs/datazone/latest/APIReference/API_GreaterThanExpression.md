# GreaterThanExpression
<a name="API_GreaterThanExpression"></a>

Specifies whether the value is greater than an expression.

## Contents
<a name="API_GreaterThanExpression_Contents"></a>

 ** columnName **   <a name="datazone-Type-GreaterThanExpression-columnName"></a>
The name of the column.
Type: String
Required: Yes

 ** value **   <a name="datazone-Type-GreaterThanExpression-value"></a>
The value that might be greater than an expression.
Type: String
Required: Yes
