# FailureReason
<a name="API_FailureReason"></a>

The details of a resource deletion failure during a cascade deletion of the domain.

## Contents
<a name="API_FailureReason_Contents"></a>

 ** id **   <a name="datazone-Type-FailureReason-id"></a>
The identifier of the resource that failed to delete.
Type: String
Required: No

 ** message **   <a name="datazone-Type-FailureReason-message"></a>
The error message associated with the resource that failed to delete.
Type: String
Required: No
