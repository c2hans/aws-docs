# DomainUnitTarget
<a name="API_DomainUnitTarget"></a>

The target for the domain unit.

## Contents
<a name="API_DomainUnitTarget_Contents"></a>

 ** domainUnitId **   <a name="datazone-Type-DomainUnitTarget-domainUnitId"></a>
The ID of the domain unit.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `[a-z0-9_\-]+`
Required: Yes

 ** includeChildDomainUnits **   <a name="datazone-Type-DomainUnitTarget-includeChildDomainUnits"></a>
Specifies whether to apply a rule to the child domain units.
Type: Boolean
Required: No
