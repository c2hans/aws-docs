# AttributeInput
<a name="API_AttributeInput"></a>

The attribute input.

## Contents
<a name="API_AttributeInput_Contents"></a>

 ** attributeIdentifier **   <a name="datazone-Type-AttributeInput-attributeIdentifier"></a>
The ID of the attribute.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes

 ** forms **   <a name="datazone-Type-AttributeInput-forms"></a>
The metadata forms as part of the attribute input.
Type: Array of [FormInput](API_FormInput.md) objects
Array Members: Minimum number of 0 items. Maximum number of 10 items.
Required: Yes
