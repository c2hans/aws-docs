# GlueConnectionPatch
<a name="API_GlueConnectionPatch"></a>

The AWS Glue connection patch.

## Contents
<a name="API_GlueConnectionPatch_Contents"></a>

 ** authenticationConfiguration **   <a name="datazone-Type-GlueConnectionPatch-authenticationConfiguration"></a>
The authentication configuration of the AWS Glue connection patch.
Type: [AuthenticationConfigurationPatch](API_AuthenticationConfigurationPatch.md) object
Required: No

 ** connectionProperties **   <a name="datazone-Type-GlueConnectionPatch-connectionProperties"></a>
The properties of the AWS Glue connection patch.
Type: String to string map
Value Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: No

Required: No
