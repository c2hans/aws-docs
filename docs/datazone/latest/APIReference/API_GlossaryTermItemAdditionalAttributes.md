# GlossaryTermItemAdditionalAttributes
<a name="API_GlossaryTermItemAdditionalAttributes"></a>

The additional attributes of an Amazon DataZone glossary term.

## Contents
<a name="API_GlossaryTermItemAdditionalAttributes_Contents"></a>

 ** matchRationale **   <a name="datazone-Type-GlossaryTermItemAdditionalAttributes-matchRationale"></a>
List of rationales indicating why this item was matched by search.
Type: Array of [MatchRationaleItem](API_MatchRationaleItem.md) objects
Required: No
