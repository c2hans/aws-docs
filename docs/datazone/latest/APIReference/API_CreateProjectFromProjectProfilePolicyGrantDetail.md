# CreateProjectFromProjectProfilePolicyGrantDetail
<a name="API_CreateProjectFromProjectProfilePolicyGrantDetail"></a>

Specifies whether to create a project from project profile policy grant details.

## Contents
<a name="API_CreateProjectFromProjectProfilePolicyGrantDetail_Contents"></a>

 ** includeChildDomainUnits **   <a name="datazone-Type-CreateProjectFromProjectProfilePolicyGrantDetail-includeChildDomainUnits"></a>
Specifies whether to include child domain units when creating a project from project profile policy grant details
Type: Boolean
Required: No

 ** projectProfiles **   <a name="datazone-Type-CreateProjectFromProjectProfilePolicyGrantDetail-projectProfiles"></a>
Specifies project profiles when creating a project from project profile policy grant details
Type: Array of strings
Required: No
