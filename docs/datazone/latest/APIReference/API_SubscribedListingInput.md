# SubscribedListingInput
<a name="API_SubscribedListingInput"></a>

The published asset for which the subscription grant is to be created.

## Contents
<a name="API_SubscribedListingInput_Contents"></a>

 ** identifier **   <a name="datazone-Type-SubscribedListingInput-identifier"></a>
The identifier of the published asset for which the subscription grant is to be created.
Type: String
Pattern: `[a-zA-Z0-9_-]{1,36}`
Required: Yes
