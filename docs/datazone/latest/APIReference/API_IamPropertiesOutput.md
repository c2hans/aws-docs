# IamPropertiesOutput
<a name="API_IamPropertiesOutput"></a>

The IAM properties of a connection.

## Contents
<a name="API_IamPropertiesOutput_Contents"></a>

 ** environmentId **   <a name="datazone-Type-IamPropertiesOutput-environmentId"></a>
The environment ID of the connection.
Type: String
Required: No

 ** glueLineageSyncEnabled **   <a name="datazone-Type-IamPropertiesOutput-glueLineageSyncEnabled"></a>
Specifies whether AWS Glue lineage sync is enabled for a connection.
Type: Boolean
Required: No
