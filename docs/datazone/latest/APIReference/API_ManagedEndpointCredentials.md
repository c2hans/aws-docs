# ManagedEndpointCredentials
<a name="API_ManagedEndpointCredentials"></a>

The managed endpoint credentials of the EMR on EKS cluster.

## Contents
<a name="API_ManagedEndpointCredentials_Contents"></a>

 ** id **   <a name="datazone-Type-ManagedEndpointCredentials-id"></a>
The identifier of the managed endpoint credentials.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 64.
Required: No

 ** token **   <a name="datazone-Type-ManagedEndpointCredentials-token"></a>
The ARN of the managed endpoint credentials.
Type: String
Required: No
