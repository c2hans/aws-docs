# IamUserProfileDetails
<a name="API_IamUserProfileDetails"></a>

The details of the IAM user profile.

## Contents
<a name="API_IamUserProfileDetails_Contents"></a>

 ** arn **   <a name="datazone-Type-IamUserProfileDetails-arn"></a>
The ARN of the IAM user.
Type: String
Required: No

 ** groupProfileId **   <a name="datazone-Type-IamUserProfileDetails-groupProfileId"></a>
The identifier of the group profile associated with the IAM user profile. This links the user to a specific group profile within the Amazon DataZone domain.
Type: String
Required: No

 ** principalId **   <a name="datazone-Type-IamUserProfileDetails-principalId"></a>
The principal ID as part of the IAM user profile details.
Type: String
Required: No

 ** sessionName **   <a name="datazone-Type-IamUserProfileDetails-sessionName"></a>
The session name for IAM role sessions.
Type: String
Required: No
