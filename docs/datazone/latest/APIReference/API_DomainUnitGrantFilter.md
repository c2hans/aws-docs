# DomainUnitGrantFilter
<a name="API_DomainUnitGrantFilter"></a>

The grant filter for the domain unit. In the current release of Amazon DataZone, the only supported filter is the `allDomainUnitsGrantFilter`.

## Contents
<a name="API_DomainUnitGrantFilter_Contents"></a>

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** allDomainUnitsGrantFilter **   <a name="datazone-Type-DomainUnitGrantFilter-allDomainUnitsGrantFilter"></a>
Specifies a grant filter containing all domain units.
Type: [AllDomainUnitsGrantFilter](API_AllDomainUnitsGrantFilter.md) object
Required: No
