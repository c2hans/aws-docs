# LineageInfo
<a name="API_LineageInfo"></a>

The data lineage information.

## Contents
<a name="API_LineageInfo_Contents"></a>

 ** errorMessage **   <a name="datazone-Type-LineageInfo-errorMessage"></a>
The data lineage error message.
Type: String
Required: No

 ** eventId **   <a name="datazone-Type-LineageInfo-eventId"></a>
The data lineage event ID.
Type: String
Required: No

 ** eventStatus **   <a name="datazone-Type-LineageInfo-eventStatus"></a>
The data lineage event status.
Type: String
Valid Values: `REQUESTED | PROCESSING | SUCCESS | FAILED`
Required: No
