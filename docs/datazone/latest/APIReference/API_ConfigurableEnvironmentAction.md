# ConfigurableEnvironmentAction
<a name="API_ConfigurableEnvironmentAction"></a>

The configurable action of a Amazon DataZone environment.

## Contents
<a name="API_ConfigurableEnvironmentAction_Contents"></a>

 ** parameters **   <a name="datazone-Type-ConfigurableEnvironmentAction-parameters"></a>
The parameters of a configurable action in a Amazon DataZone environment.
Type: Array of [ConfigurableActionParameter](API_ConfigurableActionParameter.md) objects
Required: Yes

 ** type **   <a name="datazone-Type-ConfigurableEnvironmentAction-type"></a>
The type of a configurable action in a Amazon DataZone environment.
Type: String
Required: Yes

 ** auth **   <a name="datazone-Type-ConfigurableEnvironmentAction-auth"></a>
The authentication type of a configurable action of a Amazon DataZone environment.
Type: String
Valid Values: `IAM | HTTPS`
Required: No
