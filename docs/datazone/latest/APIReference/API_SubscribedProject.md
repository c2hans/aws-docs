# SubscribedProject
<a name="API_SubscribedProject"></a>

The project that has the subscription grant.

## Contents
<a name="API_SubscribedProject_Contents"></a>

 ** id **   <a name="datazone-Type-SubscribedProject-id"></a>
The identifier of the project that has the subscription grant.
Type: String
Pattern: `[a-zA-Z0-9_-]{1,36}`
Required: No

 ** name **   <a name="datazone-Type-SubscribedProject-name"></a>
The name of the project that has the subscription grant.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Pattern: `[\w -]+`
Required: No
