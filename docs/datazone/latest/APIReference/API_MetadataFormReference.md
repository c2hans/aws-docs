# MetadataFormReference
<a name="API_MetadataFormReference"></a>

The reference of a metadata form.

## Contents
<a name="API_MetadataFormReference_Contents"></a>

 ** typeIdentifier **   <a name="datazone-Type-MetadataFormReference-typeIdentifier"></a>
The type ID of the metadata form reference.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 385.
Pattern: `(?!\.)[\w\.]*\w`
Required: Yes

 ** typeRevision **   <a name="datazone-Type-MetadataFormReference-typeRevision"></a>
The type revision of the metadata form reference.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: Yes
