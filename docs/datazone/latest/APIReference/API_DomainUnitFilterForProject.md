# DomainUnitFilterForProject
<a name="API_DomainUnitFilterForProject"></a>

The domain unit filter of the project grant filter.

## Contents
<a name="API_DomainUnitFilterForProject_Contents"></a>

 ** domainUnit **   <a name="datazone-Type-DomainUnitFilterForProject-domainUnit"></a>
The domain unit ID to use in the filter.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `[a-z0-9_\-]+`
Required: Yes

 ** includeChildDomainUnits **   <a name="datazone-Type-DomainUnitFilterForProject-includeChildDomainUnits"></a>
Specifies whether to include child domain units.
Type: Boolean
Required: No
