# SubscribedUser
<a name="API_SubscribedUser"></a>

The subscribed user.

## Contents
<a name="API_SubscribedUser_Contents"></a>

 ** details **   <a name="datazone-Type-SubscribedUser-details"></a>
The subscribed user details.
Type: [UserProfileDetails](API_UserProfileDetails.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: No

 ** id **   <a name="datazone-Type-SubscribedUser-id"></a>
The ID of the subscribed user.
Type: String
Pattern: `([0-9a-f]{10}-|)[A-Fa-f0-9]{8}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{12}`
Required: No
