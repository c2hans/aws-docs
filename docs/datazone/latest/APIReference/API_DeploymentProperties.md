# DeploymentProperties
<a name="API_DeploymentProperties"></a>

The deployment properties of the Amazon DataZone blueprint.

## Contents
<a name="API_DeploymentProperties_Contents"></a>

 ** endTimeoutMinutes **   <a name="datazone-Type-DeploymentProperties-endTimeoutMinutes"></a>
The end timeout of the environment blueprint deployment.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 225.
Required: No

 ** startTimeoutMinutes **   <a name="datazone-Type-DeploymentProperties-startTimeoutMinutes"></a>
The start timeout of the environment blueprint deployment.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 225.
Required: No
