# SubscribedUserInput
<a name="API_SubscribedUserInput"></a>

The subscribed user.

## Contents
<a name="API_SubscribedUserInput_Contents"></a>

 ** identifier **   <a name="datazone-Type-SubscribedUserInput-identifier"></a>
The ID of the subscribed user.
Type: String
Pattern: `([0-9a-f]{10}-|)[A-Fa-f0-9]{8}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{12}`
Required: No
