# HyperPodPropertiesOutput
<a name="API_HyperPodPropertiesOutput"></a>

The hyper pod properties of a AWS Glue properties patch.

## Contents
<a name="API_HyperPodPropertiesOutput_Contents"></a>

 ** clusterName **   <a name="datazone-Type-HyperPodPropertiesOutput-clusterName"></a>
The cluster name the hyper pod properties.
Type: String
Required: Yes

 ** clusterArn **   <a name="datazone-Type-HyperPodPropertiesOutput-clusterArn"></a>
The cluster ARN of the hyper pod properties.
Type: String
Required: No

 ** orchestrator **   <a name="datazone-Type-HyperPodPropertiesOutput-orchestrator"></a>
The orchestrator of the hyper pod properties.
Type: String
Valid Values: `EKS | SLURM`
Required: No
