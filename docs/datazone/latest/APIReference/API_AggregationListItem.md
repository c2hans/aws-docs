# AggregationListItem
<a name="API_AggregationListItem"></a>

An aggregation list item.

## Contents
<a name="API_AggregationListItem_Contents"></a>

 ** attribute **   <a name="datazone-Type-AggregationListItem-attribute"></a>
An attribute on which to compute aggregations.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** displayValue **   <a name="datazone-Type-AggregationListItem-displayValue"></a>
The display value of the aggregation list item. Supported values include `value` and `glossaryTerm.name`.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No
