# MetadataFormEnforcementDetail
<a name="API_MetadataFormEnforcementDetail"></a>

The enforcement details of a metadata form.

## Contents
<a name="API_MetadataFormEnforcementDetail_Contents"></a>

 ** requiredMetadataForms **   <a name="datazone-Type-MetadataFormEnforcementDetail-requiredMetadataForms"></a>
The required metadata forms.
Type: Array of [MetadataFormReference](API_MetadataFormReference.md) objects
Array Members: Minimum number of 1 item. Maximum number of 5 items.
Required: No
