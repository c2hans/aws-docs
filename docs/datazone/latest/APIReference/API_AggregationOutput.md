# AggregationOutput
<a name="API_AggregationOutput"></a>

The aggregation for an attribute.

## Contents
<a name="API_AggregationOutput_Contents"></a>

 ** attribute **   <a name="datazone-Type-AggregationOutput-attribute"></a>
The attribute for this aggregation.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: No

 ** displayValue **   <a name="datazone-Type-AggregationOutput-displayValue"></a>
The display value of the aggregation output item.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No

 ** items **   <a name="datazone-Type-AggregationOutput-items"></a>
A list of aggregation output items.
Type: Array of [AggregationOutputItem](API_AggregationOutputItem.md) objects
Required: No
