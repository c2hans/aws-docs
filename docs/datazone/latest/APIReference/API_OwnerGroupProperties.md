# OwnerGroupProperties
<a name="API_OwnerGroupProperties"></a>

The properties of the domain unit owners group.

## Contents
<a name="API_OwnerGroupProperties_Contents"></a>

 ** groupIdentifier **   <a name="datazone-Type-OwnerGroupProperties-groupIdentifier"></a>
The ID of the domain unit owners group.
Type: String
Pattern: `.*(^([0-9a-f]{10}-|)[A-Fa-f0-9]{8}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{12}$|[\p{L}\p{M}\p{S}\p{N}\p{P}\t\n\r ]+).*`
Required: Yes
