# SubscribedGroupInput
<a name="API_SubscribedGroupInput"></a>

The details of the subscribed group.

## Contents
<a name="API_SubscribedGroupInput_Contents"></a>

 ** identifier **   <a name="datazone-Type-SubscribedGroupInput-identifier"></a>
The ID of the subscribed group.
Type: String
Pattern: `([0-9a-f]{10}-|)[A-Fa-f0-9]{8}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{4}-[A-Fa-f0-9]{12}`
Required: No
