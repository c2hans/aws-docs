# EnvironmentConfig
<a name="API_EnvironmentConfig"></a>

The environment configuration for a notebook run in Amazon SageMaker Unified Studio.

## Contents
<a name="API_EnvironmentConfig_Contents"></a>

 ** imageVersion **   <a name="datazone-Type-EnvironmentConfig-imageVersion"></a>
The image version for the notebook run environment.
Type: String
Required: No

 ** packageConfig **   <a name="datazone-Type-EnvironmentConfig-packageConfig"></a>
The package configuration for the notebook run environment.
Type: [PackageConfig](API_PackageConfig.md) object
Required: No
