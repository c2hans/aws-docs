# ConnectionCredentials
<a name="API_ConnectionCredentials"></a>

The credentials of a connection.

## Contents
<a name="API_ConnectionCredentials_Contents"></a>

 ** accessKeyId **   <a name="datazone-Type-ConnectionCredentials-accessKeyId"></a>
The access key ID of a connection.
Type: String
Required: No

 ** expiration **   <a name="datazone-Type-ConnectionCredentials-expiration"></a>
The expiration of the connection credentials.
Type: Timestamp
Required: No

 ** secretAccessKey **   <a name="datazone-Type-ConnectionCredentials-secretAccessKey"></a>
The secret access key of a connection.
Type: String
Required: No

 ** sessionToken **   <a name="datazone-Type-ConnectionCredentials-sessionToken"></a>
The session token of a connection credentials.
Type: String
Required: No
