# AdditionalAttributes
<a name="API_AdditionalAttributes"></a>

Additional details on the queried entity that can be requested in the response.

## Contents
<a name="API_AdditionalAttributes_Contents"></a>

 ** formNames **   <a name="datazone-Type-AdditionalAttributes-formNames"></a>
Names of forms on the query entity that can be requested in the response.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `(?![0-9_])\w+$|^_\w*[a-zA-Z0-9]\w*`
Required: No
