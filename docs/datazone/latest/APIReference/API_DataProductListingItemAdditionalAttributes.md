# DataProductListingItemAdditionalAttributes
<a name="API_DataProductListingItemAdditionalAttributes"></a>

The additional attributes of the asset of the data product.

## Contents
<a name="API_DataProductListingItemAdditionalAttributes_Contents"></a>

 ** forms **   <a name="datazone-Type-DataProductListingItemAdditionalAttributes-forms"></a>
The metadata forms of the asset of the data product.
Type: String
Required: No

 ** matchRationale **   <a name="datazone-Type-DataProductListingItemAdditionalAttributes-matchRationale"></a>
List of rationales indicating why this item was matched by search.
Type: Array of [MatchRationaleItem](API_MatchRationaleItem.md) objects
Required: No
