# FailureCause
<a name="API_FailureCause"></a>

Specifies the error message that is returned if the operation cannot be successfully completed.

## Contents
<a name="API_FailureCause_Contents"></a>

 ** message **   <a name="datazone-Type-FailureCause-message"></a>
The description of the error message.
Type: String
Required: No
