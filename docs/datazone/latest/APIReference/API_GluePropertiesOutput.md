# GluePropertiesOutput
<a name="API_GluePropertiesOutput"></a>

The properties of the AWS Glue connection.

## Contents
<a name="API_GluePropertiesOutput_Contents"></a>

 ** errorMessage **   <a name="datazone-Type-GluePropertiesOutput-errorMessage"></a>
The error message generated if the action is not completed successfully.
Type: String
Required: No

 ** status **   <a name="datazone-Type-GluePropertiesOutput-status"></a>
The status of a connection.
Type: String
Valid Values: `CREATING | CREATE_FAILED | DELETING | DELETE_FAILED | READY | UPDATING | UPDATE_FAILED | DELETED`
Required: No
