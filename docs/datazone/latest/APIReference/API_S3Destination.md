# S3Destination
<a name="API_S3Destination"></a>

The Amazon Simple Storage Service destination for a notebook export in Amazon SageMaker Unified Studio.

## Contents
<a name="API_S3Destination_Contents"></a>

 ** uri **   <a name="datazone-Type-S3Destination-uri"></a>
The Amazon Simple Storage Service URI of the exported notebook.
Type: String
Length Constraints: Minimum length of 6. Maximum length of 1024.
Pattern: `s3://.+`
Required: No
