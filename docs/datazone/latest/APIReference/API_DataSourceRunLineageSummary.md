# DataSourceRunLineageSummary
<a name="API_DataSourceRunLineageSummary"></a>

The run lineage summary of a data source.

## Contents
<a name="API_DataSourceRunLineageSummary_Contents"></a>

 ** importStatus **   <a name="datazone-Type-DataSourceRunLineageSummary-importStatus"></a>
The import status that's part of the run lineage summary of a data source.
Type: String
Valid Values: `IN_PROGRESS | SUCCESS | FAILED | PARTIALLY_SUCCEEDED`
Required: No
