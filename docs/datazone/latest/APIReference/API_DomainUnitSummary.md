# DomainUnitSummary
<a name="API_DomainUnitSummary"></a>

The summary of the domain unit.

## Contents
<a name="API_DomainUnitSummary_Contents"></a>

 ** id **   <a name="datazone-Type-DomainUnitSummary-id"></a>
The ID of the domain unit summary.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `[a-z0-9_\-]+`
Required: Yes

 ** name **   <a name="datazone-Type-DomainUnitSummary-name"></a>
The name of the domain unit summary.
Type: String
Required: Yes
