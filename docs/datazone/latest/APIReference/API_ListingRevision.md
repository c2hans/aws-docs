# ListingRevision
<a name="API_ListingRevision"></a>

A revision of an asset published in a Amazon DataZone catalog.

## Contents
<a name="API_ListingRevision_Contents"></a>

 ** id **   <a name="datazone-Type-ListingRevision-id"></a>
An identifier of a revision of an asset published in a Amazon DataZone catalog.
Type: String
Pattern: `[a-zA-Z0-9_-]{1,36}`
Required: Yes

 ** revision **   <a name="datazone-Type-ListingRevision-revision"></a>
The details of a revision of an asset published in a Amazon DataZone catalog.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: Yes
