# AuthorizationCodeProperties
<a name="API_AuthorizationCodeProperties"></a>

The authorization code properties of a connection.

## Contents
<a name="API_AuthorizationCodeProperties_Contents"></a>

 ** authorizationCode **   <a name="datazone-Type-AuthorizationCodeProperties-authorizationCode"></a>
The authorization code of a connection.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Required: No

 ** redirectUri **   <a name="datazone-Type-AuthorizationCodeProperties-redirectUri"></a>
The redirect URI of a connection.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 512.
Required: No
