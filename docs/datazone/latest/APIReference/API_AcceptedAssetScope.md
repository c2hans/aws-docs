# AcceptedAssetScope
<a name="API_AcceptedAssetScope"></a>

The accepted asset scope.

## Contents
<a name="API_AcceptedAssetScope_Contents"></a>

 ** assetId **   <a name="datazone-Type-AcceptedAssetScope-assetId"></a>
The asset ID of the accepted asset scope.
Type: String
Pattern: `[a-zA-Z0-9_-]{1,36}`
Required: Yes

 ** filterIds **   <a name="datazone-Type-AcceptedAssetScope-filterIds"></a>
The filter IDs of the accepted asset scope.
Type: Array of strings
Pattern: `[a-zA-Z0-9_-]{1,36}`
Required: Yes
