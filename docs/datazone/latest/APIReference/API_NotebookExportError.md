# NotebookExportError
<a name="API_NotebookExportError"></a>

The error details of a failed notebook export in Amazon SageMaker Unified Studio.

## Contents
<a name="API_NotebookExportError_Contents"></a>

 ** message **   <a name="datazone-Type-NotebookExportError-message"></a>
The error message. The maximum length is 256 characters.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: Yes
