# NotEqualToExpression
<a name="API_NotEqualToExpression"></a>

Specifies that a value is not equal to the expression.

## Contents
<a name="API_NotEqualToExpression_Contents"></a>

 ** columnName **   <a name="datazone-Type-NotEqualToExpression-columnName"></a>
The name of the column.
Type: String
Required: Yes

 ** value **   <a name="datazone-Type-NotEqualToExpression-value"></a>
The value that might not be equal to the expression.
Type: String
Required: Yes
