# LakehousePropertiesOutput
<a name="API_LakehousePropertiesOutput"></a>

The lakehouse properties of a connection.

## Contents
<a name="API_LakehousePropertiesOutput_Contents"></a>

 ** glueLineageSyncEnabled **   <a name="datazone-Type-LakehousePropertiesOutput-glueLineageSyncEnabled"></a>
Specifies whether Glue lineage sync is enabled for tables managed by Glue crawlers.
Type: Boolean
Required: No
