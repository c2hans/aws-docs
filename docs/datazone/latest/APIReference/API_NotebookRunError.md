# NotebookRunError
<a name="API_NotebookRunError"></a>

The error details of a failed notebook run in Amazon SageMaker Unified Studio.

## Contents
<a name="API_NotebookRunError_Contents"></a>

 ** message **   <a name="datazone-Type-NotebookRunError-message"></a>
The error message. The maximum length is 1024 characters.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: Yes
