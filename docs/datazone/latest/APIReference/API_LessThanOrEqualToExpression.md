# LessThanOrEqualToExpression
<a name="API_LessThanOrEqualToExpression"></a>

Specifies that a value is less than or equal to an expression.

## Contents
<a name="API_LessThanOrEqualToExpression_Contents"></a>

 ** columnName **   <a name="datazone-Type-LessThanOrEqualToExpression-columnName"></a>
The name of the column.
Type: String
Required: Yes

 ** value **   <a name="datazone-Type-LessThanOrEqualToExpression-value"></a>
The value that might be less than or equal to an expression.
Type: String
Required: Yes
