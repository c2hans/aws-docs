# RedshiftLineageSyncConfigurationInput
<a name="API_RedshiftLineageSyncConfigurationInput"></a>

The Amaon Redshift lineage sync configuration.

## Contents
<a name="API_RedshiftLineageSyncConfigurationInput_Contents"></a>

 ** enabled **   <a name="datazone-Type-RedshiftLineageSyncConfigurationInput-enabled"></a>
Specifies whether the Amaon Redshift lineage sync configuration is enabled.
Type: Boolean
Required: No

 ** schedule **   <a name="datazone-Type-RedshiftLineageSyncConfigurationInput-schedule"></a>
The schedule of the Amaon Redshift lineage sync configuration.
Type: [LineageSyncSchedule](API_LineageSyncSchedule.md) object
Required: No
