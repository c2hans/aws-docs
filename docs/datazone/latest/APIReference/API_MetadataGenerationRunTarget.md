# MetadataGenerationRunTarget
<a name="API_MetadataGenerationRunTarget"></a>

The asset for which metadata was generated.

## Contents
<a name="API_MetadataGenerationRunTarget_Contents"></a>

 ** identifier **   <a name="datazone-Type-MetadataGenerationRunTarget-identifier"></a>
The ID of the metadata generation run's target.
Type: String
Required: Yes

 ** type **   <a name="datazone-Type-MetadataGenerationRunTarget-type"></a>
The type of the asset for which metadata was generated.
Type: String
Valid Values: `ASSET`
Required: Yes

 ** revision **   <a name="datazone-Type-MetadataGenerationRunTarget-revision"></a>
The revision of the asset for which metadata was generated.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No
