# NotificationResource
<a name="API_NotificationResource"></a>

The details of the resource mentioned in a notification.

## Contents
<a name="API_NotificationResource_Contents"></a>

 ** id **   <a name="datazone-Type-NotificationResource-id"></a>
The ID of the resource mentioned in a notification.
Type: String
Required: Yes

 ** type **   <a name="datazone-Type-NotificationResource-type"></a>
The type of the resource mentioned in a notification.
Type: String
Valid Values: `PROJECT`
Required: Yes

 ** name **   <a name="datazone-Type-NotificationResource-name"></a>
The name of the resource mentioned in a notification.
Type: String
Required: No
