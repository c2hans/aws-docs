# LakehousePropertiesInput
<a name="API_LakehousePropertiesInput"></a>

The lakehouse properties of a connection.

## Contents
<a name="API_LakehousePropertiesInput_Contents"></a>

 ** glueLineageSyncEnabled **   <a name="datazone-Type-LakehousePropertiesInput-glueLineageSyncEnabled"></a>
Specifies whether to enable Glue lineage sync for tables managed by Glue crawlers.
Type: Boolean
Required: No
