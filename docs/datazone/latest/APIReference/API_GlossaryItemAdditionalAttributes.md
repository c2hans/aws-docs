# GlossaryItemAdditionalAttributes
<a name="API_GlossaryItemAdditionalAttributes"></a>

The additional attributes of an Amazon DataZone glossary.

## Contents
<a name="API_GlossaryItemAdditionalAttributes_Contents"></a>

 ** matchRationale **   <a name="datazone-Type-GlossaryItemAdditionalAttributes-matchRationale"></a>
List of rationales indicating why this item was matched by search.
Type: Array of [MatchRationaleItem](API_MatchRationaleItem.md) objects
Required: No
