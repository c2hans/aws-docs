# Data Types
<a name="API_Types"></a>

The AWS Data Pipeline API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Field](API_Field.md)
+  [InstanceIdentity](API_InstanceIdentity.md)
+  [Operator](API_Operator.md)
+  [ParameterAttribute](API_ParameterAttribute.md)
+  [ParameterObject](API_ParameterObject.md)
+  [ParameterValue](API_ParameterValue.md)
+  [PipelineDescription](API_PipelineDescription.md)
+  [PipelineIdName](API_PipelineIdName.md)
+  [PipelineObject](API_PipelineObject.md)
+  [Query](API_Query.md)
+  [Selector](API_Selector.md)
+  [Tag](API_Tag.md)
+  [TaskObject](API_TaskObject.md)
+  [ValidationError](API_ValidationError.md)
+  [ValidationWarning](API_ValidationWarning.md)
