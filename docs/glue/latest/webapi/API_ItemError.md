# ItemError
<a name="API_ItemError"></a>

An error that occurred when retrieving an iterable form item.

## Contents
<a name="API_ItemError_Contents"></a>

 ** Code **   <a name="Glue-Type-ItemError-Code"></a>
The error code.
Type: String
Required: No

 ** ItemIdentifier **   <a name="Glue-Type-ItemError-ItemIdentifier"></a>
The identifier of the item that caused the error.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1087.
Required: No

 ** Message **   <a name="Glue-Type-ItemError-Message"></a>
The error message.
Type: String
Required: No
