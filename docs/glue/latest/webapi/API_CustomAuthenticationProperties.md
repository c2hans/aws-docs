# CustomAuthenticationProperties
<a name="API_CustomAuthenticationProperties"></a>

Custom authentication configuration that allows for flexible authentication mechanisms beyond standard Basic and OAuth2 flows.

## Contents
<a name="API_CustomAuthenticationProperties_Contents"></a>

 ** AuthenticationParameters **   <a name="Glue-Type-CustomAuthenticationProperties-AuthenticationParameters"></a>
A map of custom authentication parameters that define the specific authentication mechanism and required properties.
Type: Array of [ConnectorProperty](API_ConnectorProperty.md) objects
Required: Yes
