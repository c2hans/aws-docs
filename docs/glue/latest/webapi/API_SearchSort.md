# SearchSort
<a name="API_SearchSort"></a>

The sort criteria for search results.

## Contents
<a name="API_SearchSort_Contents"></a>

 ** Attribute **   <a name="Glue-Type-SearchSort-Attribute"></a>
The attribute to sort by.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** Order **   <a name="Glue-Type-SearchSort-Order"></a>
The sort order. Valid values are `ASCENDING` and `DESCENDING`.
Type: String
Valid Values: `ASCENDING | DESCENDING`
Required: No
