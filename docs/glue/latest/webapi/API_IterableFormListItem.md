# IterableFormListItem
<a name="API_IterableFormListItem"></a>

A summary of an item in an iterable form.

## Contents
<a name="API_IterableFormListItem_Contents"></a>

 ** Description **   <a name="Glue-Type-IterableFormListItem-Description"></a>
The description of the item.
Type: String
Required: No

 ** GlossaryTerms **   <a name="Glue-Type-IterableFormListItem-GlossaryTerms"></a>
The identifiers of the glossary terms associated with the item.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Required: No

 ** ItemId **   <a name="Glue-Type-IterableFormListItem-ItemId"></a>
The unique identifier of the item.
Type: String
Required: No

 ** ItemName **   <a name="Glue-Type-IterableFormListItem-ItemName"></a>
The name of the item.
Type: String
Required: No
