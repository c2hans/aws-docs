# RecipeStep
<a name="API_RecipeStep"></a>

A recipe step used in a AWS Glue Studio data preparation recipe node.

## Contents
<a name="API_RecipeStep_Contents"></a>

 ** Action **   <a name="Glue-Type-RecipeStep-Action"></a>
The transformation action of the recipe step.
Type: [RecipeAction](API_RecipeAction.md) object
Required: Yes

 ** ConditionExpressions **   <a name="Glue-Type-RecipeStep-ConditionExpressions"></a>
The condition expressions for the recipe step.
Type: Array of [ConditionExpression](API_ConditionExpression.md) objects
Required: No
