# S3SourceAdditionalOptions
<a name="API_S3SourceAdditionalOptions"></a>

Specifies additional connection options for the Amazon S3 data store.

## Contents
<a name="API_S3SourceAdditionalOptions_Contents"></a>

 ** BoundedFiles **   <a name="Glue-Type-S3SourceAdditionalOptions-BoundedFiles"></a>
Sets the upper limit for the target number of files that will be processed.
Type: Long
Required: No

 ** BoundedSize **   <a name="Glue-Type-S3SourceAdditionalOptions-BoundedSize"></a>
Sets the upper limit for the target size of the dataset in bytes that will be processed.
Type: Long
Required: No
