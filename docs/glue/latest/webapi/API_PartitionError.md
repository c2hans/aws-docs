# PartitionError
<a name="API_PartitionError"></a>

Contains information about a partition error.

## Contents
<a name="API_PartitionError_Contents"></a>

 ** ErrorDetail **   <a name="Glue-Type-PartitionError-ErrorDetail"></a>
The details about the partition error.
Type: [ErrorDetail](API_ErrorDetail.md) object
Required: No

 ** PartitionValues **   <a name="Glue-Type-PartitionError-PartitionValues"></a>
The values that define the partition.
Type: Array of strings
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No
