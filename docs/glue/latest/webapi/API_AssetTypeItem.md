# AssetTypeItem
<a name="API_AssetTypeItem"></a>

A summary of an asset type.

## Contents
<a name="API_AssetTypeItem_Contents"></a>

 ** Id **   <a name="Glue-Type-AssetTypeItem-Id"></a>
The identifier of the asset type.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No

 ** Name **   <a name="Glue-Type-AssetTypeItem-Name"></a>
The name of the asset type.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `^(?![0-9_])\w+$|^_\w*[a-zA-Z0-9]\w*$`
Required: No
