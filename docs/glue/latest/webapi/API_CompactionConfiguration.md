# CompactionConfiguration
<a name="API_CompactionConfiguration"></a>

The configuration for a compaction optimizer. This configuration defines how data files in your table will be compacted to improve query performance and reduce storage costs.

## Contents
<a name="API_CompactionConfiguration_Contents"></a>

 ** icebergConfiguration **   <a name="Glue-Type-CompactionConfiguration-icebergConfiguration"></a>
The configuration for an Iceberg compaction optimizer.
Type: [IcebergCompactionConfiguration](API_IcebergCompactionConfiguration.md) object
Required: No
