# GlossaryItem
<a name="API_GlossaryItem"></a>

A summary of a business glossary.

## Contents
<a name="API_GlossaryItem_Contents"></a>

 ** Description **   <a name="Glue-Type-GlossaryItem-Description"></a>
The description of the glossary.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: No

 ** Id **   <a name="Glue-Type-GlossaryItem-Id"></a>
The unique identifier of the glossary.
Type: String
Required: No

 ** Name **   <a name="Glue-Type-GlossaryItem-Name"></a>
The name of the glossary.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
