# ProfilingResultsOptions
<a name="API_ProfilingResultsOptions"></a>

The configuration for writing profiling results.

## Contents
<a name="API_ProfilingResultsOptions_Contents"></a>

 ** CatalogTableConfig **   <a name="Glue-Type-ProfilingResultsOptions-CatalogTableConfig"></a>
The AWS Glue Data Catalog table configuration for storing the profiling results.
Type: [CatalogTableConfigOptions](API_CatalogTableConfigOptions.md) object
Required: No

 ** DistributionResults **   <a name="Glue-Type-ProfilingResultsOptions-DistributionResults"></a>
The configuration for writing distribution results.
Type: [DistributionResultsOptions](API_DistributionResultsOptions.md) object
Required: No

 ** WriteProfilingResultsEnabled **   <a name="Glue-Type-ProfilingResultsOptions-WriteProfilingResultsEnabled"></a>
Set to true to write profiling results.
Type: Boolean
Required: No
