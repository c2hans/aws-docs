# AmazonRedshiftAdvancedOption
<a name="API_AmazonRedshiftAdvancedOption"></a>

Specifies an optional value when connecting to the Redshift cluster.

## Contents
<a name="API_AmazonRedshiftAdvancedOption_Contents"></a>

 ** Key **   <a name="Glue-Type-AmazonRedshiftAdvancedOption-Key"></a>
The key for the additional connection option.
Type: String
Required: No

 ** Value **   <a name="Glue-Type-AmazonRedshiftAdvancedOption-Value"></a>
The value for the additional connection option.
Type: String
Required: No
