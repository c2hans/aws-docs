# DataQualityRuleResultsOptions
<a name="API_DataQualityRuleResultsOptions"></a>

The configuration for writing data quality rule results.

## Contents
<a name="API_DataQualityRuleResultsOptions_Contents"></a>

 ** CatalogTableConfig **   <a name="Glue-Type-DataQualityRuleResultsOptions-CatalogTableConfig"></a>
The AWS Glue Data Catalog table configuration for storing the rule results.
Type: [CatalogTableConfigOptions](API_CatalogTableConfigOptions.md) object
Required: No

 ** WriteDataQualityRuleResultsEnabled **   <a name="Glue-Type-DataQualityRuleResultsOptions-WriteDataQualityRuleResultsEnabled"></a>
Set to true to write data quality rule results.
Type: Boolean
Required: No
