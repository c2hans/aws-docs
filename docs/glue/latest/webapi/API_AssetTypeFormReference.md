# AssetTypeFormReference
<a name="API_AssetTypeFormReference"></a>

A reference to a form type that is included in an asset type.

## Contents
<a name="API_AssetTypeFormReference_Contents"></a>

 ** FormTypeIdentifier **   <a name="Glue-Type-AssetTypeFormReference-FormTypeIdentifier"></a>
The identifier of the referenced form type.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes
