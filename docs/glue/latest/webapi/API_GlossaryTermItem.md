# GlossaryTermItem
<a name="API_GlossaryTermItem"></a>

A summary of a glossary term.

## Contents
<a name="API_GlossaryTermItem_Contents"></a>

 ** Id **   <a name="Glue-Type-GlossaryTermItem-Id"></a>
The unique identifier of the glossary term.
Type: String
Required: No

 ** Name **   <a name="Glue-Type-GlossaryTermItem-Name"></a>
The name of the glossary term.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No

 ** ShortDescription **   <a name="Glue-Type-GlossaryTermItem-ShortDescription"></a>
The short description of the glossary term.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No
