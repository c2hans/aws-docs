# SchemaVersionErrorItem
<a name="API_SchemaVersionErrorItem"></a>

An object that contains the error details for an operation on a schema version.

## Contents
<a name="API_SchemaVersionErrorItem_Contents"></a>

 ** ErrorDetails **   <a name="Glue-Type-SchemaVersionErrorItem-ErrorDetails"></a>
The details of the error for the schema version.
Type: [ErrorDetails](API_ErrorDetails.md) object
Required: No

 ** VersionNumber **   <a name="Glue-Type-SchemaVersionErrorItem-VersionNumber"></a>
The version number of the schema.
Type: Long
Valid Range: Minimum value of 1. Maximum value of 100000.
Required: No
