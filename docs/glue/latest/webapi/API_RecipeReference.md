# RecipeReference
<a name="API_RecipeReference"></a>

A reference to a AWS Glue DataBrew recipe.

## Contents
<a name="API_RecipeReference_Contents"></a>

 ** RecipeArn **   <a name="Glue-Type-RecipeReference-RecipeArn"></a>
The ARN of the DataBrew recipe.
Type: String
Pattern: `([\u0009\u000B\u000C\u0020-\uD7FF\uE000-\uFFFD\uD800\uDC00-\uDBFF\uDFFF])*`
Required: Yes

 ** RecipeVersion **   <a name="Glue-Type-RecipeReference-RecipeVersion"></a>
The RecipeVersion of the DataBrew recipe.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 16.
Required: Yes
