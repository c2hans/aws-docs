# TimestampedInclusionAnnotation
<a name="API_TimestampedInclusionAnnotation"></a>

A timestamped inclusion annotation.

## Contents
<a name="API_TimestampedInclusionAnnotation_Contents"></a>

 ** LastModifiedOn **   <a name="Glue-Type-TimestampedInclusionAnnotation-LastModifiedOn"></a>
The timestamp when the inclusion annotation was last modified.
Type: Timestamp
Required: No

 ** Value **   <a name="Glue-Type-TimestampedInclusionAnnotation-Value"></a>
The inclusion annotation value.
Type: String
Valid Values: `INCLUDE | EXCLUDE`
Required: No
