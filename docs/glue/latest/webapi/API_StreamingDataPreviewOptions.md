# StreamingDataPreviewOptions
<a name="API_StreamingDataPreviewOptions"></a>

Specifies options related to data preview for viewing a sample of your data.

## Contents
<a name="API_StreamingDataPreviewOptions_Contents"></a>

 ** PollingTime **   <a name="Glue-Type-StreamingDataPreviewOptions-PollingTime"></a>
The polling time in milliseconds.
Type: Long
Valid Range: Minimum value of 10.
Required: No

 ** RecordPollingLimit **   <a name="Glue-Type-StreamingDataPreviewOptions-RecordPollingLimit"></a>
The limit to the number of records polled.
Type: Long
Valid Range: Minimum value of 1.
Required: No
