# ObservationResultsOptions
<a name="API_ObservationResultsOptions"></a>

The configuration for writing observation results.

## Contents
<a name="API_ObservationResultsOptions_Contents"></a>

 ** CatalogTableConfig **   <a name="Glue-Type-ObservationResultsOptions-CatalogTableConfig"></a>
The AWS Glue Data Catalog table configuration for storing the observation results.
Type: [CatalogTableConfigOptions](API_CatalogTableConfigOptions.md) object
Required: No

 ** WriteObservationResultsEnabled **   <a name="Glue-Type-ObservationResultsOptions-WriteObservationResultsEnabled"></a>
Set to true to write observation results.
Type: Boolean
Required: No
