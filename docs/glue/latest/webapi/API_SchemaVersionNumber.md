# SchemaVersionNumber
<a name="API_SchemaVersionNumber"></a>

A structure containing the schema version information.

## Contents
<a name="API_SchemaVersionNumber_Contents"></a>

 ** LatestVersion **   <a name="Glue-Type-SchemaVersionNumber-LatestVersion"></a>
The latest version available for the schema.
Type: Boolean
Required: No

 ** VersionNumber **   <a name="Glue-Type-SchemaVersionNumber-VersionNumber"></a>
The version number of the schema.
Type: Long
Valid Range: Minimum value of 1. Maximum value of 100000.
Required: No
