# AllowedValue
<a name="API_AllowedValue"></a>

An object representing a value allowed for a property.

## Contents
<a name="API_AllowedValue_Contents"></a>

 ** Value **   <a name="Glue-Type-AllowedValue-Value"></a>
The value allowed for the property.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** Description **   <a name="Glue-Type-AllowedValue-Description"></a>
A description of the allowed value.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: No
