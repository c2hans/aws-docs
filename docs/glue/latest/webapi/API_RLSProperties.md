# RLSProperties
<a name="API_RLSProperties"></a>

A structure that describes the default row-level security policy of a table.

## Contents
<a name="API_RLSProperties_Contents"></a>

 ** DefaultRLSPolicy **   <a name="Glue-Type-RLSProperties-DefaultRLSPolicy"></a>
The name of the default row-level security policy applied to the table.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `[\u0020-\uD7FF\uE000-\uFFFD\uD800\uDC00-\uDBFF\uDFFF\t]*`
Required: No
