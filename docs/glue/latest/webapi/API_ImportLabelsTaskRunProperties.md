# ImportLabelsTaskRunProperties
<a name="API_ImportLabelsTaskRunProperties"></a>

Specifies configuration properties for an importing labels task run.

## Contents
<a name="API_ImportLabelsTaskRunProperties_Contents"></a>

 ** InputS3Path **   <a name="Glue-Type-ImportLabelsTaskRunProperties-InputS3Path"></a>
The Amazon Simple Storage Service (Amazon S3) path from where you will import the labels.
Type: String
Required: No

 ** Replace **   <a name="Glue-Type-ImportLabelsTaskRunProperties-Replace"></a>
Indicates whether to overwrite your existing labels.
Type: Boolean
Required: No
