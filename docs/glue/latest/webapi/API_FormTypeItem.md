# FormTypeItem
<a name="API_FormTypeItem"></a>

A summary of a form type.

## Contents
<a name="API_FormTypeItem_Contents"></a>

 ** Id **   <a name="Glue-Type-FormTypeItem-Id"></a>
The identifier of the form type.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No

 ** Name **   <a name="Glue-Type-FormTypeItem-Name"></a>
The name of the form type.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `^[A-Z]\w*$`
Required: No
