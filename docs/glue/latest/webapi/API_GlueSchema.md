# GlueSchema
<a name="API_GlueSchema"></a>

Specifies a user-defined schema when a schema cannot be determined by AWS Glue.

## Contents
<a name="API_GlueSchema_Contents"></a>

 ** Columns **   <a name="Glue-Type-GlueSchema-Columns"></a>
Specifies the column definitions that make up a AWS Glue schema.
Type: Array of [GlueStudioSchemaColumn](API_GlueStudioSchemaColumn.md) objects
Required: No
