# DistributionResultsOptions
<a name="API_DistributionResultsOptions"></a>

The configuration for writing distribution results.

## Contents
<a name="API_DistributionResultsOptions_Contents"></a>

 ** CatalogTableConfig **   <a name="Glue-Type-DistributionResultsOptions-CatalogTableConfig"></a>
The AWS Glue Data Catalog table configuration for storing the distribution results.
Type: [CatalogTableConfigOptions](API_CatalogTableConfigOptions.md) object
Required: No

 ** WriteDistributionResultsEnabled **   <a name="Glue-Type-DistributionResultsOptions-WriteDistributionResultsEnabled"></a>
Set to true to write distribution results.
Type: Boolean
Required: No
