# IntegrationFilter
<a name="API_IntegrationFilter"></a>

A filter that can be used when invoking a `DescribeIntegrations` request.

## Contents
<a name="API_IntegrationFilter_Contents"></a>

 ** Name **   <a name="Glue-Type-IntegrationFilter-Name"></a>
The name of the filter.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: No

 ** Values **   <a name="Glue-Type-IntegrationFilter-Values"></a>
A list of filter values.
Type: Array of strings
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: No
