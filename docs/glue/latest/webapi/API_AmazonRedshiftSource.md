# AmazonRedshiftSource
<a name="API_AmazonRedshiftSource"></a>

Specifies an Amazon Redshift source.

## Contents
<a name="API_AmazonRedshiftSource_Contents"></a>

 ** Data **   <a name="Glue-Type-AmazonRedshiftSource-Data"></a>
Specifies the data of the Amazon Reshift source node.
Type: [AmazonRedshiftNodeData](API_AmazonRedshiftNodeData.md) object
Required: No

 ** Name **   <a name="Glue-Type-AmazonRedshiftSource-Name"></a>
The name of the Amazon Redshift source.
Type: String
Pattern: `([^\r\n])*`
Required: No
