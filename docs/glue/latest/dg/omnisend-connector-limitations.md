# Limitations and notes for the Omnisend connector
<a name="omnisend-connector-limitations"></a>

The following are limitations and notes for the Omnisend connector:
+ Omnisend is supported as a source only. Writing to Omnisend is not supported.
+ Job bookmarks are not supported.
