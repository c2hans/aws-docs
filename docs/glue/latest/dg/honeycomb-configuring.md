# Configuring Honeycomb
<a name="honeycomb-configuring"></a>

Before you can use AWS Glue to transfer data from Honeycomb, you must meet the following requirements:

## Minimum requirements
<a name="honeycomb-configuring-min-requirements"></a>
+ You have a Honeycomb account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have your Honeycomb `team` slug.
