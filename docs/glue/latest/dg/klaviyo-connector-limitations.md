# Limitations and notes for the Klaviyo connector
<a name="klaviyo-connector-limitations"></a>

The following are limitations and notes for the Klaviyo connector:
+ Klaviyo is supported as a source only. Writing to Klaviyo is not supported.
+ Job bookmarks are not supported.
