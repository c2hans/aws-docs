# Limitations and notes for the Kameleoon connector
<a name="kameleoon-connector-limitations"></a>

The following are limitations and notes for the Kameleoon connector:
+ Kameleoon is supported as a source only. Writing to Kameleoon is not supported.
+ Job bookmarks are not supported.
