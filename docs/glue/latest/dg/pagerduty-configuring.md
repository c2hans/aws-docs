# Configuring PagerDuty
<a name="pagerduty-configuring"></a>

Before you can use AWS Glue to transfer data from PagerDuty, you must meet the following requirements:

## Minimum requirements
<a name="pagerduty-configuring-min-requirements"></a>
+ You have a PagerDuty account with API access.
+ You have an AWS account with access to AWS Glue.
