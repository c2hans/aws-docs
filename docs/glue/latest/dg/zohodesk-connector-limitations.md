# Limitations and notes for the Zoho Desk connector
<a name="zohodesk-connector-limitations"></a>

The following are limitations and notes for the Zoho Desk connector:
+ Zoho Desk is supported as a source only. Writing to Zoho Desk is not supported.
+ Job bookmarks are not supported.
