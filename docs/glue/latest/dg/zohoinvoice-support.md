# AWS Glue support for Zoho Invoice
<a name="zohoinvoice-support"></a>

AWS Glue supports Zoho Invoice as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Zoho Invoice.

**Supported as a target?**
No.

**Supported Zoho Invoice API versions**
The connector uses the Zoho Invoice REST API v2 and v3 depending on the object. The API version is not configurable.
