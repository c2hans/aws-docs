# AWS Glue support for Webex
<a name="webex-support"></a>

AWS Glue supports Webex as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Webex.

**Supported as a target?**
No.

**Supported Webex API versions**
The following Webex API version is supported:
+ v1
