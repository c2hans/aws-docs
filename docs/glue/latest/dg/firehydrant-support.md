# AWS Glue support for FireHydrant
<a name="firehydrant-support"></a>

AWS Glue supports FireHydrant as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from FireHydrant.

**Supported as a target?**
No.

**Supported FireHydrant API versions**
The following FireHydrant API version is supported:
+ v1
