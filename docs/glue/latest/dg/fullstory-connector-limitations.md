# Limitations and notes for the Fullstory connector
<a name="fullstory-connector-limitations"></a>

The following are limitations and notes for the Fullstory connector:
+ Fullstory is supported as a source only. Writing to Fullstory is not supported.
+ Job bookmarks are not supported.
+ The connection URL can be the US endpoint (`api.fullstory.com`) or the EU endpoint (`api.eu1.fullstory.com`).
