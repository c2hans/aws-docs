# Configuring Ghost
<a name="ghost-configuring"></a>

Before you can use AWS Glue to transfer data from Ghost, you must meet the following requirements:

## Minimum requirements
<a name="ghost-configuring-min-requirements"></a>
+ You have a Ghost account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the base URL of your Ghost site.
