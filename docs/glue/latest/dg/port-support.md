# AWS Glue support for Port
<a name="port-support"></a>

AWS Glue supports Port as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Port.

**Supported as a target?**
No.

**Supported Port API versions**
The following Port API version is supported:
+ v1
