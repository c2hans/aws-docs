# Configuring Adyen
<a name="adyen-configuring"></a>

Before you can use AWS Glue to transfer data from Adyen, you must meet the following requirements:

## Minimum requirements
<a name="adyen-configuring-min-requirements"></a>
+ You have an Adyen account with API access.
+ You have an AWS account with access to AWS Glue.
