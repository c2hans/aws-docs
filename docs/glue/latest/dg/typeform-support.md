# AWS Glue support for Typeform
<a name="typeform-support"></a>

AWS Glue supports Typeform as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Typeform.

**Supported as a target?**
No.

**Supported Typeform API versions**
This connector is not tied to a specific Typeform API version.
