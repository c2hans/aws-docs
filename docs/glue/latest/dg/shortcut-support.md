# AWS Glue support for Shortcut
<a name="shortcut-support"></a>

AWS Glue supports Shortcut as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Shortcut.

**Supported as a target?**
No.

**Supported Shortcut API versions**
The following Shortcut API version is supported:
+ v3
