# Configuring Coda
<a name="coda-configuring"></a>

Before you can use AWS Glue to transfer data from Coda, you must meet the following requirements:

## Minimum requirements
<a name="coda-configuring-min-requirements"></a>
+ You have a Coda account with API access.
+ You have an AWS account with access to AWS Glue.
