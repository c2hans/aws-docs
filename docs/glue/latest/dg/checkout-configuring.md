# Configuring Checkout.com
<a name="checkout-configuring"></a>

Before you can use AWS Glue to transfer data from Checkout.com, you must meet the following requirements:

## Minimum requirements
<a name="checkout-configuring-min-requirements"></a>
+ You have a Checkout.com account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have your Checkout.com account subdomain. You enter it as the `SUBDOMAIN` value in the connection URL `https://{SUBDOMAIN}.api.checkout.com`.
