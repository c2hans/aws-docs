# Configuring Gusto
<a name="gusto-configuring"></a>

Before you can use AWS Glue to transfer data from Gusto, you must meet the following requirements:

## Minimum requirements
<a name="gusto-configuring-min-requirements"></a>
+ You have a Gusto account with API access.
+ You have an AWS account with access to AWS Glue.
