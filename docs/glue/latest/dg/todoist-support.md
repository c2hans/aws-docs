# AWS Glue support for Todoist
<a name="todoist-support"></a>

AWS Glue supports Todoist as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Todoist.

**Supported as a target?**
No.

**Supported Todoist API versions**
The following Todoist API version is supported:
+ v1
