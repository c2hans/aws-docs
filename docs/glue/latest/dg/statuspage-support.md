# AWS Glue support for Statuspage
<a name="statuspage-support"></a>

AWS Glue supports Statuspage as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Statuspage.

**Supported as a target?**
No.

**Supported Statuspage API versions**
The following Statuspage API version is supported:
+ v1
