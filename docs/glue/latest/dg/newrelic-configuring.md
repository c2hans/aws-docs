# Configuring New Relic
<a name="newrelic-configuring"></a>

Before you can use AWS Glue to transfer data from New Relic, you must meet the following requirements:

## Minimum requirements
<a name="newrelic-configuring-min-requirements"></a>
+ You have a New Relic account with API access.
+ You have an AWS account with access to AWS Glue.
