# Configuring Crisp
<a name="crisp-configuring"></a>

Before you can use AWS Glue to transfer data from Crisp, you must meet the following requirements:

## Minimum requirements
<a name="crisp-configuring-min-requirements"></a>
+ You have a Crisp account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the Crisp `websiteId` for the website you want to read.
