# Configuring Vercel
<a name="vercel-configuring"></a>

Before you can use AWS Glue to transfer data from Vercel, you must meet the following requirements:

## Minimum requirements
<a name="vercel-configuring-min-requirements"></a>
+ You have a Vercel account with API access.
+ You have an AWS account with access to AWS Glue.
