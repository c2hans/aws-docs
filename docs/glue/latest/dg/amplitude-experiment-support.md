# AWS Glue support for Amplitude Experiment
<a name="amplitude-experiment-support"></a>

AWS Glue supports Amplitude Experiment as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Amplitude Experiment.

**Supported as a target?**
No.

**Supported Amplitude Experiment API versions**
The following Amplitude Experiment API version is supported:
+ v1
