# Configuring Maxio
<a name="maxio-configuring"></a>

Before you can use AWS Glue to transfer data from Maxio, you must meet the following requirements:

## Minimum requirements
<a name="maxio-configuring-min-requirements"></a>
+ You have a Maxio account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the site subdomain used in the connection URL `https://{SUBDOMAIN}.chargify.com`.
