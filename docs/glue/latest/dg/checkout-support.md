# AWS Glue support for Checkout.com
<a name="checkout-support"></a>

AWS Glue supports Checkout.com as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Checkout.com.

**Supported as a target?**
No.

**Supported Checkout.com API versions**
This connector is not tied to a specific Checkout.com API version.
