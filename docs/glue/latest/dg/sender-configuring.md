# Configuring Sender
<a name="sender-configuring"></a>

Before you can use AWS Glue to transfer data from Sender, you must meet the following requirements:

## Minimum requirements
<a name="sender-configuring-min-requirements"></a>
+ You have a Sender account with API access.
+ You have an AWS account with access to AWS Glue.
