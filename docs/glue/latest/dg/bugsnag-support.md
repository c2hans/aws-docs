# AWS Glue support for BugSnag
<a name="bugsnag-support"></a>

AWS Glue supports BugSnag as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from BugSnag.

**Supported as a target?**
No.

**Supported BugSnag API versions**
This connector is not tied to a specific BugSnag API version.
