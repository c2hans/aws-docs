# Limitations and notes for the Gorgias connector
<a name="gorgias-connector-limitations"></a>

The following are limitations and notes for the Gorgias connector:
+ Gorgias is supported as a source only. Writing to Gorgias is not supported.
+ Job bookmarks are not supported.
