# Configuring Port
<a name="port-configuring"></a>

Before you can use AWS Glue to transfer data from Port, you must meet the following requirements:

## Minimum requirements
<a name="port-configuring-min-requirements"></a>
+ You have a Port account with API access.
+ You have an AWS account with access to AWS Glue.
