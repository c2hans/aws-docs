# AWS Glue support for Attio
<a name="attio-support"></a>

AWS Glue supports Attio as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Attio.

**Supported as a target?**
No.

**Supported Attio API versions**
The following Attio API version is supported:
+ v2
