# Configuring Attio
<a name="attio-configuring"></a>

Before you can use AWS Glue to transfer data from Attio, you must meet the following requirements:

## Minimum requirements
<a name="attio-configuring-min-requirements"></a>
+ You have an Attio account with API access.
+ You have an AWS account with access to AWS Glue.
