# Configuring Rollbar
<a name="rollbar-configuring"></a>

Before you can use AWS Glue to transfer data from Rollbar, you must meet the following requirements:

## Minimum requirements
<a name="rollbar-configuring-min-requirements"></a>
+ You have a Rollbar account with API access.
+ You have an AWS account with access to AWS Glue.
