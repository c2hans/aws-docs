# AWS Glue support for Adyen
<a name="adyen-support"></a>

AWS Glue supports Adyen as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Adyen.

**Supported as a target?**
No.

**Supported Adyen API versions**
The following Adyen API version is supported:
+ v3
