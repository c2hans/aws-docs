# AWS Glue support for Jenkins
<a name="jenkins-support"></a>

AWS Glue supports Jenkins as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Jenkins.

**Supported as a target?**
No.

**Supported Jenkins API versions**
This connector is not tied to a specific Jenkins API version.
