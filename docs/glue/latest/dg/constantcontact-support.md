# AWS Glue support for Constant Contact
<a name="constantcontact-support"></a>

AWS Glue supports Constant Contact as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Constant Contact.

**Supported as a target?**
No.

**Supported Constant Contact API versions**
The connector uses the Constant Contact REST API v1 and v3 depending on the object. The API version is not configurable.
