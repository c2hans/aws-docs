# Configuring Avalara
<a name="avalara-configuring"></a>

Before you can use AWS Glue to transfer data from Avalara, you must meet the following requirements:

## Minimum requirements
<a name="avalara-configuring-min-requirements"></a>
+ You have an Avalara account with API access.
+ You have an AWS account with access to AWS Glue.
