# Configuring Vonage
<a name="vonage-configuring"></a>

Before you can use AWS Glue to transfer data from Vonage, you must meet the following requirements:

## Minimum requirements
<a name="vonage-configuring-min-requirements"></a>
+ You have a Vonage account with API access.
+ You have an AWS account with access to AWS Glue.
