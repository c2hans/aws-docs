# AWS Glue support for Bitbucket
<a name="bitbucket-support"></a>

AWS Glue supports Bitbucket as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Bitbucket.

**Supported as a target?**
No.

**Supported Bitbucket API versions**
The following Bitbucket Cloud API version is supported:
+ 2.0
