# Configuring Harness
<a name="harness-configuring"></a>

Before you can use AWS Glue to transfer data from Harness, you must meet the following requirements:

## Minimum requirements
<a name="harness-configuring-min-requirements"></a>
+ You have a Harness account with API access.
+ You have an AWS account with access to AWS Glue.
