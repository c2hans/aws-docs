# Limitations and notes for the Coalesce connector
<a name="coalesce-connector-limitations"></a>

The following are limitations and notes for the Coalesce connector:
+ Coalesce is supported as a source only. Writing to Coalesce is not supported.
+ Job bookmarks are not supported.
