# Configuring Statuspage
<a name="statuspage-configuring"></a>

Before you can use AWS Glue to transfer data from Statuspage, you must meet the following requirements:

## Minimum requirements
<a name="statuspage-configuring-min-requirements"></a>
+ You have a Statuspage account with API access.
+ You have an AWS account with access to AWS Glue.
