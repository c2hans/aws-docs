# AWS Glue support for Sender
<a name="sender-support"></a>

AWS Glue supports Sender as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Sender.

**Supported as a target?**
No.

**Supported Sender API versions**
The following Sender API version is supported:
+ v2
