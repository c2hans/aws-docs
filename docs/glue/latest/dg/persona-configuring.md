# Configuring Persona
<a name="persona-configuring"></a>

Before you can use AWS Glue to transfer data from Persona, you must meet the following requirements:

## Minimum requirements
<a name="persona-configuring-min-requirements"></a>
+ You have a Persona account with API access.
+ You have an AWS account with access to AWS Glue.
