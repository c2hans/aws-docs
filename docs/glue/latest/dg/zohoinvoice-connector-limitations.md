# Limitations and notes for the Zoho Invoice connector
<a name="zohoinvoice-connector-limitations"></a>

The following are limitations and notes for the Zoho Invoice connector:
+ Zoho Invoice is supported as a source only. Writing to Zoho Invoice is not supported.
+ Job bookmarks are not supported.
