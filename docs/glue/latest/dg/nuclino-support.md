# AWS Glue support for Nuclino
<a name="nuclino-support"></a>

AWS Glue supports Nuclino as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Nuclino.

**Supported as a target?**
No.

**Supported Nuclino API versions**
The following Nuclino API version is supported:
+ v0
