# Configuring Copper
<a name="copper-configuring"></a>

Before you can use AWS Glue to transfer data from Copper, you must meet the following requirements:

## Minimum requirements
<a name="copper-configuring-min-requirements"></a>
+ You have a Copper account with API access.
+ You have an AWS account with access to AWS Glue.
