# Configuring Grafana
<a name="grafana-configuring"></a>

Before you can use AWS Glue to transfer data from Grafana, you must meet the following requirements:

## Minimum requirements
<a name="grafana-configuring-min-requirements"></a>
+ You have a Grafana account with API access.
+ You have an AWS account with access to AWS Glue.
