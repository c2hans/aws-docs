# Configuring Kommo
<a name="kommo-configuring"></a>

Before you can use AWS Glue to transfer data from Kommo, you must meet the following requirements:

## Minimum requirements
<a name="kommo-configuring-min-requirements"></a>
+ You have a Kommo account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the Kommo `INSTANCE_URL` value used to build the connection URL.
