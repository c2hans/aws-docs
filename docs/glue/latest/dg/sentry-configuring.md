# Configuring Sentry
<a name="sentry-configuring"></a>

Before you can use AWS Glue to transfer data from Sentry, you must meet the following requirements:

## Minimum requirements
<a name="sentry-configuring-min-requirements"></a>
+ You have a Sentry account with API access.
+ You have an AWS account with access to AWS Glue.
