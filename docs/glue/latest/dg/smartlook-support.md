# AWS Glue support for Smartlook
<a name="smartlook-support"></a>

AWS Glue supports Smartlook as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Smartlook.

**Supported as a target?**
No.

**Supported Smartlook API versions**
The following Smartlook API version is supported:
+ v1
