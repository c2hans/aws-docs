# Limitations and notes for the Amplitude Experiment connector
<a name="amplitude-experiment-connector-limitations"></a>

The following are limitations and notes for the Amplitude Experiment connector:
+ Amplitude Experiment is supported as a source only. Writing to Amplitude Experiment is not supported.
+ Job bookmarks are not supported.
