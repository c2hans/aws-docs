# AWS Glue support for Mollie
<a name="mollie-support"></a>

AWS Glue supports Mollie as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Mollie.

**Supported as a target?**
No.

**Supported Mollie API versions**
The following Mollie API version is supported:
+ v2
