# AWS Glue support for Gorgias
<a name="gorgias-support"></a>

AWS Glue supports Gorgias as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Gorgias.

**Supported as a target?**
No.

**Supported Gorgias API versions**
This connector is not tied to a specific Gorgias API version.
