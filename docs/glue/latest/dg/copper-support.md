# AWS Glue support for Copper
<a name="copper-support"></a>

AWS Glue supports Copper as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Copper.

**Supported as a target?**
No.

**Supported Copper API versions**
The following Copper API version is supported:
+ v1
