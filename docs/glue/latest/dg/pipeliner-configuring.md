# Configuring Pipeliner
<a name="pipeliner-configuring"></a>

Before you can use AWS Glue to transfer data from Pipeliner, you must meet the following requirements:

## Minimum requirements
<a name="pipeliner-configuring-min-requirements"></a>
+ You have a Pipeliner account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the Pipeliner `INSTANCE_HOST` value used to build the connection URL.
+ You have the Pipeliner `SPACE_ID` value used to build the connection URL.
