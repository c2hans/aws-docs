# Limitations and notes for the Ontraport connector
<a name="ontraport-connector-limitations"></a>

The following are limitations and notes for the Ontraport connector:
+ Ontraport is supported as a source only. Writing to Ontraport is not supported.
+ Job bookmarks are not supported.
