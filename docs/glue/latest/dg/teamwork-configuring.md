# Configuring Teamwork
<a name="teamwork-configuring"></a>

Before you can use AWS Glue to transfer data from Teamwork, you must meet the following requirements:

## Minimum requirements
<a name="teamwork-configuring-min-requirements"></a>
+ You have a Teamwork account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have your Teamwork site `SUBDOMAIN` (for example, {{subdomain}} in `{{subdomain}}.teamwork.com`).
