# Connecting to Nuclino in AWS Glue Studio
<a name="connecting-to-data-nuclino"></a>

Nuclino is a lightweight collaborative knowledge/docs workspace. Because you are a Nuclino user, you can connect AWS Glue to your Nuclino account. You can then use Nuclino as a data source in your AWS Glue ETL jobs to transfer data between Nuclino and AWS services or other supported applications.
