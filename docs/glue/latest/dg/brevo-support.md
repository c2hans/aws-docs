# AWS Glue support for Brevo
<a name="brevo-support"></a>

AWS Glue supports Brevo as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Brevo.

**Supported as a target?**
No.

**Supported Brevo API versions**
The following Brevo API version is supported:
+ v3
