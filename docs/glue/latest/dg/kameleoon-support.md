# AWS Glue support for Kameleoon
<a name="kameleoon-support"></a>

AWS Glue supports Kameleoon as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Kameleoon.

**Supported as a target?**
No.

**Supported Kameleoon API versions**
This connector is not tied to a specific Kameleoon API version.
