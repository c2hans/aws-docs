# Configuring Apollo
<a name="apollo-configuring"></a>

Before you can use AWS Glue to transfer data from Apollo, you must meet the following requirements:

## Minimum requirements
<a name="apollo-configuring-min-requirements"></a>
+ You have an Apollo account with API access.
+ You have an AWS account with access to AWS Glue.
