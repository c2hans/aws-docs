# Limitations and notes for the LogRocket connector
<a name="logrocket-connector-limitations"></a>

The following are limitations and notes for the LogRocket connector:
+ LogRocket is supported as a source only. Writing to LogRocket is not supported.
+ Job bookmarks are not supported.
