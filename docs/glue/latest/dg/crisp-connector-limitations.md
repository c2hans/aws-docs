# Limitations and notes for the Crisp connector
<a name="crisp-connector-limitations"></a>

The following are limitations and notes for the Crisp connector:
+ Crisp is supported as a source only. Writing to Crisp is not supported.
+ Job bookmarks are not supported.
+ Pagination is not supported. Each read returns only the first page of results.
