# AWS Glue support for Avalara
<a name="avalara-support"></a>

AWS Glue supports Avalara as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Avalara.

**Supported as a target?**
No.

**Supported Avalara API versions**
The following Avalara API versions are supported:
+ v2
