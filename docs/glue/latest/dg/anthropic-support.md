# AWS Glue support for Anthropic
<a name="anthropic-support"></a>

AWS Glue supports Anthropic as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Anthropic.

**Supported as a target?**
No.

**Supported Anthropic API versions**
The connector uses Anthropic REST API major version v1 with the 2023-06-01 version date. The same version applies to all entities, and neither the major version nor the version date is configurable.
