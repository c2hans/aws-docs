# Connecting to Port in AWS Glue Studio
<a name="connecting-to-data-port"></a>

Port (getport.io) is an Internal Developer Portal (IDP)—a software catalog \+ governance platform for platform-engineering teams. Because you are a Port user, you can connect AWS Glue to your Port account. You can then use Port as a data source in your AWS Glue ETL jobs to transfer data between Port and AWS services or other supported applications.
