# AWS Glue support for LiveChatAI
<a name="livechatai-support"></a>

AWS Glue supports LiveChatAI as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from LiveChatAI.

**Supported as a target?**
No.

**Supported LiveChatAI API versions**
The following LiveChatAI API version is supported:
+ v2
