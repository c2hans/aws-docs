# AWS Glue support for Trello
<a name="trello-support"></a>

AWS Glue supports Trello as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Trello.

**Supported as a target?**
No.

**Supported Trello API versions**
The following Trello API version is supported:
