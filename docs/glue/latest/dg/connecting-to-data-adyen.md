# Connecting to Adyen in AWS Glue Studio
<a name="connecting-to-data-adyen"></a>

Adyen is a global payments platform. Because you are an Adyen user, you can connect AWS Glue to your Adyen account. You can then use Adyen as a data source in your AWS Glue ETL jobs to transfer data between Adyen and AWS services or other supported applications.
