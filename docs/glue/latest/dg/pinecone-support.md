# AWS Glue support for Pinecone
<a name="pinecone-support"></a>

AWS Glue supports Pinecone as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Pinecone.

**Supported as a target?**
No.

**Supported Pinecone API versions**
The following Pinecone API version is supported:
+ 2026-07
