# AWS Glue support for Weaviate
<a name="weaviate-support"></a>

AWS Glue supports Weaviate as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Weaviate.

**Supported as a target?**
No.

**Supported Weaviate API versions**
The following Weaviate API version is supported:
+ v1
