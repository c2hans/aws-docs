# AWS Glue support for Coalesce
<a name="coalesce-support"></a>

AWS Glue supports Coalesce as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Coalesce.

**Supported as a target?**
No.

**Supported Coalesce API versions**
The connector uses the Coalesce REST API v1 and v2 depending on the object. The API version is not configurable.
