# AWS Glue support for Gusto
<a name="gusto-support"></a>

AWS Glue supports Gusto as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Gusto.

**Supported as a target?**
No.

**Supported Gusto API versions**
The connector uses the Gusto REST API 2026-06-15 and v1 depending on the object. The API version is not configurable.
