# AWS Glue support for GoCardless
<a name="gocardless-support"></a>

AWS Glue supports GoCardless as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from GoCardless.

**Supported as a target?**
No.

**Supported GoCardless API versions**
The following GoCardless API version is supported:
+ 2015-07-06
