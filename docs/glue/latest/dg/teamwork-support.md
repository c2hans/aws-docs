# AWS Glue support for Teamwork
<a name="teamwork-support"></a>

AWS Glue supports Teamwork as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Teamwork.

**Supported as a target?**
No.

**Supported Teamwork API versions**
The following Teamwork API version is supported:
+ v3
