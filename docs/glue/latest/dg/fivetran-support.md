# AWS Glue support for Fivetran
<a name="fivetran-support"></a>

AWS Glue supports Fivetran as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Fivetran.

**Supported as a target?**
No.

**Supported Fivetran API versions**
The following Fivetran API version is supported:
+ v1
