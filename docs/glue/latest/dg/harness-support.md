# AWS Glue support for Harness
<a name="harness-support"></a>

AWS Glue supports Harness as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Harness.

**Supported as a target?**
No.

**Supported Harness API versions**
This connector is not tied to a specific Harness API version.
