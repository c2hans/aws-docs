# AWS Glue support for Honeycomb
<a name="honeycomb-support"></a>

AWS Glue supports Honeycomb as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Honeycomb.

**Supported as a target?**
No.

**Supported Honeycomb API versions**
The following Honeycomb API version is supported:
+ v2
