# AWS Glue support for VWO
<a name="vwo-support"></a>

AWS Glue supports VWO as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from VWO.

**Supported as a target?**
No.

**Supported VWO API versions**
The following VWO API version is supported:
+ v2
