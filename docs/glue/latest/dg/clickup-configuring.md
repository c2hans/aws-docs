# Configuring ClickUp
<a name="clickup-configuring"></a>

Before you can use AWS Glue to transfer data from ClickUp, you must meet the following requirements:

## Minimum requirements
<a name="clickup-configuring-min-requirements"></a>
+ You have a ClickUp account with API access.
+ You have an AWS account with access to AWS Glue.
