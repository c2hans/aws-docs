# Connecting to Zoho Books in AWS Glue Studio
<a name="connecting-to-data-zohobooks"></a>

Zoho Books is cloud-based accounting software for growing businesses. Because you are a Zoho Books user, you can connect AWS Glue to your Zoho Books account. You can then use Zoho Books as a data source in your AWS Glue ETL jobs to transfer data between Zoho Books and AWS services or other supported applications.
