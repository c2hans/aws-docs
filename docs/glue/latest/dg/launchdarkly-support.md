# AWS Glue support for LaunchDarkly
<a name="launchdarkly-support"></a>

AWS Glue supports LaunchDarkly as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from LaunchDarkly.

**Supported as a target?**
No.

**Supported LaunchDarkly API versions**
The connector uses LaunchDarkly REST API v2 with API version `20240415` for all entities. The API version is not configurable.
