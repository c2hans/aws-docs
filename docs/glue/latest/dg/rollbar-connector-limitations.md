# Limitations and notes for the Rollbar connector
<a name="rollbar-connector-limitations"></a>

The following are limitations and notes for the Rollbar connector:
+ Rollbar is supported as a source only. Writing to Rollbar is not supported.
+ Job bookmarks are not supported.
