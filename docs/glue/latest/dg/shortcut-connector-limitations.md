# Limitations and notes for the Shortcut connector
<a name="shortcut-connector-limitations"></a>

The following are limitations and notes for the Shortcut connector:
+ Shortcut is supported as a source only. Writing to Shortcut is not supported.
+ Job bookmarks are not supported.
