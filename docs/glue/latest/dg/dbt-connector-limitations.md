# Limitations and notes for the dbt Cloud connector
<a name="dbt-connector-limitations"></a>

The following are limitations and notes for the dbt Cloud connector:
+ dbt Cloud is supported as a source only. Writing to dbt Cloud is not supported.
+ Job bookmarks are not supported.
