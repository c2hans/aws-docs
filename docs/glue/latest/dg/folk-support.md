# AWS Glue support for Folk
<a name="folk-support"></a>

AWS Glue supports Folk as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Folk.

**Supported as a target?**
No.

**Supported Folk API versions**
The connector uses Folk API version `2025-06-09` for all entities. The API version is not configurable.
