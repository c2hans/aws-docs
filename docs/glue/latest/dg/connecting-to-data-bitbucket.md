# Connecting to Bitbucket in AWS Glue Studio
<a name="connecting-to-data-bitbucket"></a>

Bitbucket is Atlassian's Git hosting with pull requests and CI/CD pipelines. Because you are a Bitbucket user, you can connect AWS Glue to your Bitbucket account. You can then use Bitbucket as a data source in your AWS Glue ETL jobs to transfer data between Bitbucket and AWS services or other supported applications.
