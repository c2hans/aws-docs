# AWS Glue support for dbt Cloud
<a name="dbt-support"></a>

AWS Glue supports dbt Cloud as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from dbt Cloud.

**Supported as a target?**
No.

**Supported dbt Cloud API versions**
The connector uses the dbt Cloud REST API v2 and v3 depending on the object. The API version is not configurable.
