# AWS Glue support for Webflow
<a name="webflow-support"></a>

AWS Glue supports Webflow as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Webflow.

**Supported as a target?**
No.

**Supported Webflow API versions**
The following Webflow API version is supported:
+ v2
