# Configuring Mollie
<a name="mollie-configuring"></a>

Before you can use AWS Glue to transfer data from Mollie, you must meet the following requirements:

## Minimum requirements
<a name="mollie-configuring-min-requirements"></a>
+ You have a Mollie account with API access.
+ You have an AWS account with access to AWS Glue.
