# Connecting to Nimble in AWS Glue Studio
<a name="connecting-to-data-nimble"></a>

Nimble is a relationship-focused CRM for contacts, companies, and deal pipelines (integrates with Microsoft 365 / Google Workspace). Because you are a Nimble user, you can connect AWS Glue to your Nimble account. You can then use Nimble as a data source in your AWS Glue ETL jobs to transfer data between Nimble and AWS services or other supported applications.
