# AWS Glue support for Pipeliner
<a name="pipeliner-support"></a>

AWS Glue supports Pipeliner as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Pipeliner.

**Supported as a target?**
No.

**Supported Pipeliner API versions**
The following Pipeliner API version is supported:
+ v100
