# Configuring Nuclino
<a name="nuclino-configuring"></a>

Before you can use AWS Glue to transfer data from Nuclino, you must meet the following requirements:

## Minimum requirements
<a name="nuclino-configuring-min-requirements"></a>
+ You have a Nuclino account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the Nuclino `workspaceId` for the workspace you want to read.
