# AWS Glue support for Re:amaze
<a name="reamaze-support"></a>

AWS Glue supports Re:amaze as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Re:amaze.

**Supported as a target?**
No.

**Supported Re:amaze API versions**
The following Re:amaze API version is supported:
+ v1
