# Configuring Front
<a name="front-configuring"></a>

Before you can use AWS Glue to transfer data from Front, you must meet the following requirements:

## Minimum requirements
<a name="front-configuring-min-requirements"></a>
+ You have a Front account with API access.
+ You have an AWS account with access to AWS Glue.
