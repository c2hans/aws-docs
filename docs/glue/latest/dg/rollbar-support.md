# AWS Glue support for Rollbar
<a name="rollbar-support"></a>

AWS Glue supports Rollbar as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Rollbar.

**Supported as a target?**
No.

**Supported Rollbar API versions**
The following Rollbar API version is supported:
+ v1
