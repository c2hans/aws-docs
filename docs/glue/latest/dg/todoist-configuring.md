# Configuring Todoist
<a name="todoist-configuring"></a>

Before you can use AWS Glue to transfer data from Todoist, you must meet the following requirements:

## Minimum requirements
<a name="todoist-configuring-min-requirements"></a>
+ You have a Todoist account with API access.
+ You have an AWS account with access to AWS Glue.
