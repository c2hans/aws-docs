# Configuring Trello
<a name="trello-configuring"></a>

Before you can use AWS Glue to transfer data from Trello, you must meet the following requirements:

## Minimum requirements
<a name="trello-configuring-min-requirements"></a>
+ You have a Trello account with API access.
+ You have an AWS account with access to AWS Glue.
