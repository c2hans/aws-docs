# AWS Glue support for Amplitude
<a name="amplitude-support"></a>

AWS Glue supports Amplitude as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Amplitude.

**Supported as a target?**
No.

**Supported Amplitude API versions**
The connector uses the Amplitude REST API v2 and v3 depending on the object. The API version is not configurable.
