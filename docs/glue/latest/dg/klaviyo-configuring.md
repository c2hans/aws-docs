# Configuring Klaviyo
<a name="klaviyo-configuring"></a>

Before you can use AWS Glue to transfer data from Klaviyo, you must meet the following requirements:

## Minimum requirements
<a name="klaviyo-configuring-min-requirements"></a>
+ You have a Klaviyo account with API access.
+ You have an AWS account with access to AWS Glue.
