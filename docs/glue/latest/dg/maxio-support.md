# AWS Glue support for Maxio
<a name="maxio-support"></a>

AWS Glue supports Maxio as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Maxio.

**Supported as a target?**
No.

**Supported Maxio API versions**
This connector is not tied to a specific Maxio API version.
