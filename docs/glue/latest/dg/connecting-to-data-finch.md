# Connecting to Finch in AWS Glue Studio
<a name="connecting-to-data-finch"></a>

Finch is a unified employment API that connects to hundreds of HRIS and payroll systems through one standardized data model. Because you are a Finch user, you can connect AWS Glue to your Finch account. You can then use Finch as a data source in your AWS Glue ETL jobs to transfer data between Finch and AWS services or other supported applications.
