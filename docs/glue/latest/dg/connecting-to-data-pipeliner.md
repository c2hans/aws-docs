# Connecting to Pipeliner in AWS Glue Studio
<a name="connecting-to-data-pipeliner"></a>

Pipeliner Cloud (now branded Coevera) is a CRM and sales-pipeline platform. Because you are a Pipeliner user, you can connect AWS Glue to your Pipeliner account. You can then use Pipeliner as a data source in your AWS Glue ETL jobs to transfer data between Pipeliner and AWS services or other supported applications.
