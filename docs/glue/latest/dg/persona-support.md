# AWS Glue support for Persona
<a name="persona-support"></a>

AWS Glue supports Persona as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Persona.

**Supported as a target?**
No.

**Supported Persona API versions**
The following Persona API version is supported:
+ 2025-12-08
