# Configuring Bitbucket
<a name="bitbucket-configuring"></a>

Before you can use AWS Glue to transfer data from Bitbucket, you must meet the following requirements:

## Minimum requirements
<a name="bitbucket-configuring-min-requirements"></a>
+ You have a Bitbucket Cloud account with API access. Bitbucket Data Center isn't supported.
+ You have an AWS account with access to AWS Glue.
