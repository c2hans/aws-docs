# Configuring BambooHR
<a name="bamboohr-configuring"></a>

Before you can use AWS Glue to transfer data from BambooHR, you must meet the following requirements:

## Minimum requirements
<a name="bamboohr-configuring-min-requirements"></a>
+ You have a BambooHR account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the BambooHR `companyDomain` value used to build the connection URL.
