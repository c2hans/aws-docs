# Configuring Brevo
<a name="brevo-configuring"></a>

Before you can use AWS Glue to transfer data from Brevo, you must meet the following requirements:

## Minimum requirements
<a name="brevo-configuring-min-requirements"></a>
+ You have a Brevo account with API access.
+ You have an AWS account with access to AWS Glue.
