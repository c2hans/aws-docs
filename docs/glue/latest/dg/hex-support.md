# AWS Glue support for Hex
<a name="hex-support"></a>

AWS Glue supports Hex as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Hex.

**Supported as a target?**
No.

**Supported Hex API versions**
The following Hex API version is supported:
+ v1
