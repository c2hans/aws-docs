# Configuring Rootly
<a name="rootly-configuring"></a>

Before you can use AWS Glue to transfer data from Rootly, you must meet the following requirements:

## Minimum requirements
<a name="rootly-configuring-min-requirements"></a>
+ You have a Rootly account with API access.
+ You have an AWS account with access to AWS Glue.
