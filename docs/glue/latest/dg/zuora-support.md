# AWS Glue support for Zuora
<a name="zuora-support"></a>

AWS Glue supports Zuora as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Zuora.

**Supported as a target?**
No.

**Supported Zuora API versions**
The following Zuora API version is supported:
+ v1
