# AWS Glue support for Miro
<a name="miro-support"></a>

AWS Glue supports Miro as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Miro.

**Supported as a target?**
No.

**Supported Miro API versions**
The following Miro API version is supported:
+ v2
