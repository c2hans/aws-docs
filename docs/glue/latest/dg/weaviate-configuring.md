# Configuring Weaviate
<a name="weaviate-configuring"></a>

Before you can use AWS Glue to transfer data from Weaviate, you must meet the following requirements:

## Minimum requirements
<a name="weaviate-configuring-min-requirements"></a>
+ You have a Weaviate account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the Weaviate `SUBDOMAIN` value used to build the connection URL.
