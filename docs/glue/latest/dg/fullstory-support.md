# AWS Glue support for Fullstory
<a name="fullstory-support"></a>

AWS Glue supports Fullstory as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Fullstory.

**Supported as a target?**
No.

**Supported Fullstory API versions**
The connector uses the Fullstory REST API v1 and v2 depending on the object. The API version is not configurable.
