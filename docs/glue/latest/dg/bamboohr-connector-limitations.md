# Limitations and notes for the BambooHR connector
<a name="bamboohr-connector-limitations"></a>

The following are limitations and notes for the BambooHR connector:
+ BambooHR is supported as a source only. Writing to BambooHR is not supported.
+ Job bookmarks are not supported.
