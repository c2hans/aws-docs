# AWS Glue support for Chargebee
<a name="chargebee-support"></a>

AWS Glue supports Chargebee as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Chargebee.

**Supported as a target?**
No.

**Supported Chargebee API versions**
The following Chargebee API version is supported:
+ v2
