# AWS Glue support for Coda
<a name="coda-support"></a>

AWS Glue supports Coda as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Coda.

**Supported as a target?**
No.

**Supported Coda API versions**
The following Coda API version is supported:
+ v1
