# AWS Glue support for Crisp
<a name="crisp-support"></a>

AWS Glue supports Crisp as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Crisp.

**Supported as a target?**
No.

**Supported Crisp API versions**
The following Crisp API version is supported:
+ v1
