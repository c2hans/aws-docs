# Configuring Postman
<a name="postman-configuring"></a>

Before you can use AWS Glue to transfer data from Postman, you must meet the following requirements:

## Minimum requirements
<a name="postman-configuring-min-requirements"></a>
+ You have a Postman account with API access.
+ You have an AWS account with access to AWS Glue.
