# AWS Glue support for ShipBob
<a name="shipbob-support"></a>

AWS Glue supports ShipBob as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from ShipBob.

**Supported as a target?**
No.

**Supported ShipBob API versions**
This connector is not tied to a specific ShipBob API version.
