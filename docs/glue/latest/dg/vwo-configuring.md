# Configuring VWO
<a name="vwo-configuring"></a>

Before you can use AWS Glue to transfer data from VWO, you must meet the following requirements:

## Minimum requirements
<a name="vwo-configuring-min-requirements"></a>
+ You have a VWO account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the VWO `accountId` value.
