# Configuring Paddle
<a name="paddle-configuring"></a>

Before you can use AWS Glue to transfer data from Paddle, you must meet the following requirements:

## Minimum requirements
<a name="paddle-configuring-min-requirements"></a>
+ You have a Paddle account with API access.
+ You have an AWS account with access to AWS Glue.
