# AWS Glue support for BambooHR
<a name="bamboohr-support"></a>

AWS Glue supports BambooHR as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from BambooHR.

**Supported as a target?**
No.

**Supported BambooHR API versions**
The following BambooHR API version is supported:
+ v1
