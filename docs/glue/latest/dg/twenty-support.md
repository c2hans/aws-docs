# AWS Glue support for Twenty CRM
<a name="twenty-support"></a>

AWS Glue supports Twenty CRM as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Twenty CRM.

**Supported as a target?**
No.

**Supported Twenty CRM API versions**
This connector is not tied to a specific Twenty CRM API version.
