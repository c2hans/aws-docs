# Configuring Tableau
<a name="tableau-configuring"></a>

Before you can use AWS Glue to transfer data from Tableau, you must meet the following requirements:

## Minimum requirements
<a name="tableau-configuring-min-requirements"></a>
+ You have a Tableau account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the Tableau `INSTANCE_HOST` and `SITE_ID` values used to build the connection URL.
