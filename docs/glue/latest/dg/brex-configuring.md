# Configuring Brex
<a name="brex-configuring"></a>

Before you can use AWS Glue to transfer data from Brex, you must meet the following requirements:

## Minimum requirements
<a name="brex-configuring-min-requirements"></a>
+ You have a Brex account with API access.
+ You have an AWS account with access to AWS Glue.
