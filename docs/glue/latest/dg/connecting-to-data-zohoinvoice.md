# Connecting to Zoho Invoice in AWS Glue Studio
<a name="connecting-to-data-zohoinvoice"></a>

Zoho Invoice is an online invoicing / accounts-receivable product. Because you are a Zoho Invoice user, you can connect AWS Glue to your Zoho Invoice account. You can then use Zoho Invoice as a data source in your AWS Glue ETL jobs to transfer data between Zoho Invoice and AWS services or other supported applications.
