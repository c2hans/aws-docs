# Configuring Re:amaze
<a name="reamaze-configuring"></a>

Before you can use AWS Glue to transfer data from Re:amaze, you must meet the following requirements:

## Minimum requirements
<a name="reamaze-configuring-min-requirements"></a>
+ You have a Re:amaze account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the Re:amaze `brand` value used to build the connection URL.
