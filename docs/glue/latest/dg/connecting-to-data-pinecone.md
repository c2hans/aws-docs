# Connecting to Pinecone in AWS Glue Studio
<a name="connecting-to-data-pinecone"></a>

Pinecone is a managed vector database. Because you are a Pinecone user, you can connect AWS Glue to your Pinecone account. You can then use Pinecone as a data source in your AWS Glue ETL jobs to transfer data between Pinecone and AWS services or other supported applications.
