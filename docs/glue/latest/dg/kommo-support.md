# AWS Glue support for Kommo
<a name="kommo-support"></a>

AWS Glue supports Kommo as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Kommo.

**Supported as a target?**
No.

**Supported Kommo API versions**
The following Kommo API version is supported:
+ v4
