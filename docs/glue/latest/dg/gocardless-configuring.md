# Configuring GoCardless
<a name="gocardless-configuring"></a>

Before you can use AWS Glue to transfer data from GoCardless, you must meet the following requirements:

## Minimum requirements
<a name="gocardless-configuring-min-requirements"></a>
+ You have a GoCardless account with API access.
+ You have an AWS account with access to AWS Glue.
