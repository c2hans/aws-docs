# Configuring Hex
<a name="hex-configuring"></a>

Before you can use AWS Glue to transfer data from Hex, you must meet the following requirements:

## Minimum requirements
<a name="hex-configuring-min-requirements"></a>
+ You have a Hex account with API access.
+ You have an AWS account with access to AWS Glue.
