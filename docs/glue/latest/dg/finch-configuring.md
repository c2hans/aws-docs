# Configuring Finch
<a name="finch-configuring"></a>

Before you can use AWS Glue to transfer data from Finch, you must meet the following requirements:

## Minimum requirements
<a name="finch-configuring-min-requirements"></a>
+ You have a Finch account with API access.
+ You have an AWS account with access to AWS Glue.
