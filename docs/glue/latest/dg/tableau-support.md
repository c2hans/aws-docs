# AWS Glue support for Tableau
<a name="tableau-support"></a>

AWS Glue supports Tableau as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Tableau.

**Supported as a target?**
No.

**Supported Tableau API versions**
This connector is not tied to a specific Tableau API version.
