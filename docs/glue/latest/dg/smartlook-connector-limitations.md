# Limitations and notes for the Smartlook connector
<a name="smartlook-connector-limitations"></a>

The following are limitations and notes for the Smartlook connector:
+ Smartlook is supported as a source only. Writing to Smartlook is not supported.
+ Job bookmarks are not supported.
+ The connection URL can be the EU endpoint (`api.eu.smartlook.cloud`) or the US endpoint (`api.us.smartlook.cloud`).
