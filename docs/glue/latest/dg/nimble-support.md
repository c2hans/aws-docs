# AWS Glue support for Nimble
<a name="nimble-support"></a>

AWS Glue supports Nimble as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Nimble.

**Supported as a target?**
No.

**Supported Nimble API versions**
The connector uses the Nimble REST API v1 and v2 depending on the object. The API version is not configurable.
