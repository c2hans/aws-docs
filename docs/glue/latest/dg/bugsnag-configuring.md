# Configuring BugSnag
<a name="bugsnag-configuring"></a>

Before you can use AWS Glue to transfer data from BugSnag, you must meet the following requirements:

## Minimum requirements
<a name="bugsnag-configuring-min-requirements"></a>
+ You have a BugSnag account with API access.
+ You have an AWS account with access to AWS Glue.
