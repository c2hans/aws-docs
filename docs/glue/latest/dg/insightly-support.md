# AWS Glue support for Insightly
<a name="insightly-support"></a>

AWS Glue supports Insightly as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Insightly.

**Supported as a target?**
No.

**Supported Insightly API versions**
This connector is not tied to a specific Insightly API version.
