# AWS Glue support for Airship
<a name="airship-support"></a>

AWS Glue supports Airship as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Airship.

**Supported as a target?**
No.

**Supported Airship API versions**
This connector is not tied to a specific Airship API version.
