# AWS Glue support for Calendly
<a name="calendly-support"></a>

AWS Glue supports Calendly as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Calendly.

**Supported as a target?**
No.

**Supported Calendly API versions**
This connector is not tied to a specific Calendly API version.
