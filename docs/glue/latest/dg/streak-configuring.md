# Configuring Streak
<a name="streak-configuring"></a>

Before you can use AWS Glue to transfer data from Streak, you must meet the following requirements:

## Minimum requirements
<a name="streak-configuring-min-requirements"></a>
+ You have a Streak account with API access.
+ You have an AWS account with access to AWS Glue.
