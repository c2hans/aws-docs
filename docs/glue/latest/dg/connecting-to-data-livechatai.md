# Connecting to LiveChatAI in AWS Glue Studio
<a name="connecting-to-data-livechatai"></a>

LiveChatAI is an AI customer-support chatbot platform. Because you are a LiveChatAI user, you can connect AWS Glue to your LiveChatAI account. You can then use LiveChatAI as a data source in your AWS Glue ETL jobs to transfer data between LiveChatAI and AWS services or other supported applications.
