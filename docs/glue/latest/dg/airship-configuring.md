# Configuring Airship
<a name="airship-configuring"></a>

Before you can use AWS Glue to transfer data from Airship, you must meet the following requirements:

## Minimum requirements
<a name="airship-configuring-min-requirements"></a>
+ You have an Airship account with API access.
+ You have an AWS account with access to AWS Glue.
+ You know which Airship data center hosts your account, which sets your connection URL: `https://go.urbanairship.com/api` (US) or `https://go.airship.eu/api` (EU).
