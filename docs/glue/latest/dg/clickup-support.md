# AWS Glue support for ClickUp
<a name="clickup-support"></a>

AWS Glue supports ClickUp as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from ClickUp.

**Supported as a target?**
No.

**Supported ClickUp API versions**
The following ClickUp API version is supported:
+ v2
