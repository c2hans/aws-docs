# Configuring DevRev
<a name="devrev-configuring"></a>

Before you can use AWS Glue to transfer data from DevRev, you must meet the following requirements:

## Minimum requirements
<a name="devrev-configuring-min-requirements"></a>
+ You have a DevRev account with API access.
+ You have an AWS account with access to AWS Glue.
