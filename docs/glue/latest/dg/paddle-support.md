# AWS Glue support for Paddle
<a name="paddle-support"></a>

AWS Glue supports Paddle as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Paddle.

**Supported as a target?**
No.

**Supported Paddle API versions**
This connector is not tied to a specific Paddle API version.
