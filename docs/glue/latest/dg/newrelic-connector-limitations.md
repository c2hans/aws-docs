# Limitations and notes for the New Relic connector
<a name="newrelic-connector-limitations"></a>

The following are limitations and notes for the New Relic connector:
+ New Relic is supported as a source only. Writing to New Relic is not supported.
+ Job bookmarks are not supported.
+ The connection URL can be the US endpoint (`api.newrelic.com/v2`) or the EU endpoint (`api.eu.newrelic.com/v2`).
