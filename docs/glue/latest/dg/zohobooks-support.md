# AWS Glue support for Zoho Books
<a name="zohobooks-support"></a>

AWS Glue supports Zoho Books as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Zoho Books.

**Supported as a target?**
No.

**Supported Zoho Books API versions**
The connector uses the Zoho Books REST API v2 and v3 depending on the object. The API version is not configurable.
