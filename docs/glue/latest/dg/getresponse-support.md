# AWS Glue support for GetResponse
<a name="getresponse-support"></a>

AWS Glue supports GetResponse as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from GetResponse.

**Supported as a target?**
No.

**Supported GetResponse API versions**
The following GetResponse API version is supported:
+ v3
