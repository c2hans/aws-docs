# Configuring Folk
<a name="folk-configuring"></a>

Before you can use AWS Glue to transfer data from Folk, you must meet the following requirements:

## Minimum requirements
<a name="folk-configuring-min-requirements"></a>
+ You have a Folk account with API access.
+ You have an AWS account with access to AWS Glue.
