# AWS Glue support for Zoho Desk
<a name="zohodesk-support"></a>

AWS Glue supports Zoho Desk as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Zoho Desk.

**Supported as a target?**
No.

**Supported Zoho Desk API versions**
The following Zoho Desk API version is supported:
+ v1
