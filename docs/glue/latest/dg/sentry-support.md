# AWS Glue support for Sentry
<a name="sentry-support"></a>

AWS Glue supports Sentry as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Sentry.

**Supported as a target?**
No.

**Supported Sentry API versions**
The following Sentry API version is supported:
+ v0
