# Limitations and notes for the Lemon Squeezy connector
<a name="lemon-squeezy-connector-limitations"></a>

The following are limitations and notes for the Lemon Squeezy connector:
+ Lemon Squeezy is supported as a source only. Writing to Lemon Squeezy is not supported.
+ Job bookmarks are not supported.
