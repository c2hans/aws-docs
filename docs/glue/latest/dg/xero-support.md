# AWS Glue support for Xero
<a name="xero-support"></a>

AWS Glue supports Xero as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Xero.

**Supported as a target?**
No.

**Supported Xero API versions**
This connector is not tied to a specific Xero API version.
