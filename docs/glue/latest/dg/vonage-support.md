# AWS Glue support for Vonage
<a name="vonage-support"></a>

AWS Glue supports Vonage as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Vonage.

**Supported as a target?**
No.

**Supported Vonage API versions**
This connector is not tied to a specific Vonage API version.
