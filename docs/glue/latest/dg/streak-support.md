# AWS Glue support for Streak
<a name="streak-support"></a>

AWS Glue supports Streak as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Streak.

**Supported as a target?**
No.

**Supported Streak API versions**
The connector uses the Streak REST API v1 and v2 depending on the object. The API version is not configurable.
