# Limitations and notes for the Mollie connector
<a name="mollie-connector-limitations"></a>

The following are limitations and notes for the Mollie connector:
+ Mollie is supported as a source only. Writing to Mollie is not supported.
+ Job bookmarks are not supported.
+ The Mollie connector is available only in AWS Regions in Europe.
