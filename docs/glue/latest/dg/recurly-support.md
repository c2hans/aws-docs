# AWS Glue support for Recurly
<a name="recurly-support"></a>

AWS Glue supports Recurly as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Recurly.

**Supported as a target?**
No.

**Supported Recurly API versions**
This connector is not tied to a specific Recurly API version.
