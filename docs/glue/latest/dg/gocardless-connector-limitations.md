# Limitations and notes for the GoCardless connector
<a name="gocardless-connector-limitations"></a>

The following are limitations and notes for the GoCardless connector:
+ GoCardless is supported as a source only. Writing to GoCardless is not supported.
+ Job bookmarks are not supported.
