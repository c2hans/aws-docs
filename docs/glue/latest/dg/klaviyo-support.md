# AWS Glue support for Klaviyo
<a name="klaviyo-support"></a>

AWS Glue supports Klaviyo as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Klaviyo.

**Supported as a target?**
No.

**Supported Klaviyo API versions**
The following Klaviyo API versions are supported:
+ 2024-10-15
