# AWS Glue support for Ghost
<a name="ghost-support"></a>

AWS Glue supports Ghost as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Ghost.

**Supported as a target?**
No.

**Supported Ghost API versions**
This connector is not tied to a specific Ghost API version.
