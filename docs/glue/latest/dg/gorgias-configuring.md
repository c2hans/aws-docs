# Configuring Gorgias
<a name="gorgias-configuring"></a>

Before you can use AWS Glue to transfer data from Gorgias, you must meet the following requirements:

## Minimum requirements
<a name="gorgias-configuring-min-requirements"></a>
+ You have a Gorgias account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have your Gorgias account subdomain. You enter it as the `SUBDOMAIN` value in the connection URL `https://{SUBDOMAIN}.gorgias.com/api`.
