# AWS Glue support for Lemon Squeezy
<a name="lemon-squeezy-support"></a>

AWS Glue supports Lemon Squeezy as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Lemon Squeezy.

**Supported as a target?**
No.

**Supported Lemon Squeezy API versions**
The following Lemon Squeezy API version is supported:
+ v1
