# AWS Glue support for SonarCloud
<a name="sonarcloud-support"></a>

AWS Glue supports SonarCloud as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from SonarCloud.

**Supported as a target?**
No.

**Supported SonarCloud API versions**
This connector is not tied to a specific SonarCloud API version.
