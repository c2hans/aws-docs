# AWS Glue support for Close CRM
<a name="close-support"></a>

AWS Glue supports Close CRM as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Close CRM.

**Supported as a target?**
No.

**Supported Close CRM API versions**
The following Close CRM API version is supported:
+ v1
