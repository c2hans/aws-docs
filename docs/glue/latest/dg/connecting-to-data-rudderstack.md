# Connecting to RudderStack in AWS Glue Studio
<a name="connecting-to-data-rudderstack"></a>

RudderStack is a customer data platform (CDP) for collecting and routing event data. Because you are a RudderStack user, you can connect AWS Glue to your RudderStack account. You can then use RudderStack as a data source in your AWS Glue ETL jobs to transfer data between RudderStack and AWS services or other supported applications.
