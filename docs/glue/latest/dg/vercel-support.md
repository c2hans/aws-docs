# AWS Glue support for Vercel
<a name="vercel-support"></a>

AWS Glue supports Vercel as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Vercel.

**Supported as a target?**
No.

**Supported Vercel API versions**
The connector uses the Vercel REST API v1, v10, v2, v3, v4, v5, v7, and v9 depending on the object. The API version is not configurable.
