# AWS Glue support for Rootly
<a name="rootly-support"></a>

AWS Glue supports Rootly as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Rootly.

**Supported as a target?**
No.

**Supported Rootly API versions**
The following Rootly API version is supported:
+ v1
