# Limitations and notes for the ShipBob connector
<a name="shipbob-connector-limitations"></a>

The following are limitations and notes for the ShipBob connector:
+ ShipBob is supported as a source only. Writing to ShipBob is not supported.
+ Job bookmarks are not supported.
