# Configuring Jenkins
<a name="jenkins-configuring"></a>

Before you can use AWS Glue to transfer data from Jenkins, you must meet the following requirements:

## Minimum requirements
<a name="jenkins-configuring-min-requirements"></a>
+ You have a Jenkins account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the Jenkins `INSTANCE_URL` value used to build the connection URL.
