# AWS Glue support for DevRev
<a name="devrev-support"></a>

AWS Glue supports DevRev as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from DevRev.

**Supported as a target?**
No.

**Supported DevRev API versions**
The connector uses the default public DevRev API version. The API version is not configurable.
