# Configuring Anthropic
<a name="anthropic-configuring"></a>

Before you can use AWS Glue to transfer data from Anthropic, you must meet the following requirements:

## Minimum requirements
<a name="anthropic-configuring-min-requirements"></a>
+ You have an Anthropic account with API access and either an Admin or Workspace API key.
+ You have an AWS account with access to AWS Glue.
