# Configuring ShipBob
<a name="shipbob-configuring"></a>

Before you can use AWS Glue to transfer data from ShipBob, you must meet the following requirements:

## Minimum requirements
<a name="shipbob-configuring-min-requirements"></a>
+ You have a ShipBob account with API access.
+ You have an AWS account with access to AWS Glue.
