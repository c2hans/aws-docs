# Configuring Miro
<a name="miro-configuring"></a>

Before you can use AWS Glue to transfer data from Miro, you must meet the following requirements:

## Minimum requirements
<a name="miro-configuring-min-requirements"></a>
+ You have a Miro account with API access.
+ You have an AWS account with access to AWS Glue.
