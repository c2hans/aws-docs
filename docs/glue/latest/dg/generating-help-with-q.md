# Generating help with AWS assistant
<a name="generating-help-with-q"></a>

AWS assistant help in the AWS Glue console provides context-aware, step-by-step guidance to help you complete tasks on the console page. When you choose the **AWS assistant help** link, the AWS assistant generates guidance that is relevant to your current task. You can ask follow-up questions directly in the same panel to get additional help without leaving the page.

**Note**
AWS assistant help requires AWS assistant permissions. If your account does not have the AWS assistant enabled, help links display as **Info** and open the standard static help panel. The console automatically detects your permissions and adjusts the experience accordingly.

## Disabling or enabling AWS assistant help
<a name="disabling-enabling-q-help"></a>

AWS assistant help is enabled by default and can be turned off at any time through your console settings.

**To disable AWS assistant help**

1. In the AWS Management Console, choose **User Settings**.

1. Choose **See all user settings**.

1. Choose **Edit setting management**.

1. Clear the **Enable AWS assistant help links** checkbox.

After you save your changes, help links display as **Info** and open the standard help panel on the right side of the page.

To re-enable AWS assistant help, follow the same steps and select the **Enable AWS assistant help links** checkbox. The change takes effect immediately.
