# AWS Glue support for Postman
<a name="postman-support"></a>

AWS Glue supports Postman as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Postman.

**Supported as a target?**
No.

**Supported Postman API versions**
This connector is not tied to a specific Postman API version.
