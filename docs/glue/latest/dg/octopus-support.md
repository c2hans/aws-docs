# AWS Glue support for Octopus Deploy
<a name="octopus-support"></a>

AWS Glue supports Octopus Deploy as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Octopus Deploy.

**Supported as a target?**
No.

**Supported Octopus Deploy API versions**
This connector is not tied to a specific Octopus Deploy API version.
