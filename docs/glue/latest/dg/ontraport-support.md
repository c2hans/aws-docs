# AWS Glue support for Ontraport
<a name="ontraport-support"></a>

AWS Glue supports Ontraport as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Ontraport.

**Supported as a target?**
No.

**Supported Ontraport API versions**
This connector is not tied to a specific Ontraport API version.
