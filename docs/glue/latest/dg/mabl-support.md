# AWS Glue support for mabl
<a name="mabl-support"></a>

AWS Glue supports mabl as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from mabl.

**Supported as a target?**
No.

**Supported mabl API versions**
This connector is not tied to a specific mabl API version.
