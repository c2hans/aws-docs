# AWS Glue support for Front
<a name="front-support"></a>

AWS Glue supports Front as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Front.

**Supported as a target?**
No.

**Supported Front API versions**
This connector is not tied to a specific Front API version.
