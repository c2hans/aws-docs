# Limitations and notes for the Constant Contact connector
<a name="constantcontact-connector-limitations"></a>

The following are limitations and notes for the Constant Contact connector:
+ Constant Contact is supported as a source only. Writing to Constant Contact is not supported.
+ Job bookmarks are not supported.
