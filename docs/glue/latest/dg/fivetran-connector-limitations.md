# Limitations and notes for the Fivetran connector
<a name="fivetran-connector-limitations"></a>

The following are limitations and notes for the Fivetran connector:
+ Fivetran is supported as a source only. Writing to Fivetran is not supported.
+ Job bookmarks are not supported.
