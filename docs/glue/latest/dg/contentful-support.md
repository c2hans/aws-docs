# AWS Glue support for Contentful
<a name="contentful-support"></a>

AWS Glue supports Contentful as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from Contentful.

**Supported as a target?**
No.

**Supported Contentful API versions**
This connector is not tied to a specific Contentful API version.
