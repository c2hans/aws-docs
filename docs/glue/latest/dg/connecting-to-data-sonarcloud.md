# Connecting to SonarCloud in AWS Glue Studio
<a name="connecting-to-data-sonarcloud"></a>

SonarCloud (SonarQube Cloud) is a static-code-analysis SaaS. Because you are a SonarCloud user, you can connect AWS Glue to your SonarCloud account. You can then use SonarCloud as a data source in your AWS Glue ETL jobs to transfer data between SonarCloud and AWS services or other supported applications.
