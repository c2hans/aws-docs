# Configuring Zuora
<a name="zuora-configuring"></a>

Before you can use AWS Glue to transfer data from Zuora, you must meet the following requirements:

## Minimum requirements
<a name="zuora-configuring-min-requirements"></a>
+ You have a Zuora account with API access.
+ You have an AWS account with access to AWS Glue.
