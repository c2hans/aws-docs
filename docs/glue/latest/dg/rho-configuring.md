# Configuring Rho
<a name="rho-configuring"></a>

Before you can use AWS Glue to transfer data from Rho, you must meet the following requirements:

## Minimum requirements
<a name="rho-configuring-min-requirements"></a>
+ You have a Rho account with API access.
+ You have an AWS account with access to AWS Glue.
