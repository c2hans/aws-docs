# Connecting to BambooHR in AWS Glue Studio
<a name="connecting-to-data-bamboohr"></a>

BambooHR is an HRIS (HR Information System) for small/mid-size companies—the system of record for employee data, org structure, job and compensation history, time off, time tracking, benefits, and recruiting (ATS). Because you are a BambooHR user, you can connect AWS Glue to your BambooHR account. You can then use BambooHR as a data source in your AWS Glue ETL jobs to transfer data between BambooHR and AWS services or other supported applications.
