# Configuring mabl
<a name="mabl-configuring"></a>

Before you can use AWS Glue to transfer data from mabl, you must meet the following requirements:

## Minimum requirements
<a name="mabl-configuring-min-requirements"></a>
+ You have a mabl account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the mabl `workspace_id` value.
