# AWS Glue support for TestRail
<a name="testrail-support"></a>

AWS Glue supports TestRail as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from TestRail.

**Supported as a target?**
No.

**Supported TestRail API versions**
The following TestRail API version is supported:
+ v2
