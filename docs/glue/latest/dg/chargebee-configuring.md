# Configuring Chargebee
<a name="chargebee-configuring"></a>

Before you can use AWS Glue to transfer data from Chargebee, you must meet the following requirements:

## Minimum requirements
<a name="chargebee-configuring-min-requirements"></a>
+ You have a Chargebee account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have your Chargebee site name. You enter it as the `SUBDOMAIN` value in the connection URL `https://{SUBDOMAIN}.chargebee.com/api/v2`.
