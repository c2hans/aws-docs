# Connecting to Close CRM in AWS Glue Studio
<a name="connecting-to-data-close"></a>

Close is a high-velocity inside-sales CRM for outbound teams. Because you are a Close CRM user, you can connect AWS Glue to your Close CRM account. You can then use Close CRM as a data source in your AWS Glue ETL jobs to transfer data between Close CRM and AWS services or other supported applications.
