# Configuring Recurly
<a name="recurly-configuring"></a>

Before you can use AWS Glue to transfer data from Recurly, you must meet the following requirements:

## Minimum requirements
<a name="recurly-configuring-min-requirements"></a>
+ You have a Recurly account with API access.
+ You have an AWS account with access to AWS Glue.
