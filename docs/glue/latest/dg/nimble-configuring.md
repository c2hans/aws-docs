# Configuring Nimble
<a name="nimble-configuring"></a>

Before you can use AWS Glue to transfer data from Nimble, you must meet the following requirements:

## Minimum requirements
<a name="nimble-configuring-min-requirements"></a>
+ You have a Nimble account with API access.
+ You have an AWS account with access to AWS Glue.
