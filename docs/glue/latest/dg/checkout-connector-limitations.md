# Limitations and notes for the Checkout.com connector
<a name="checkout-connector-limitations"></a>

The following are limitations and notes for the Checkout.com connector:
+ Checkout.com is supported as a source only. Writing to Checkout.com is not supported.
+ Job bookmarks are not supported.
