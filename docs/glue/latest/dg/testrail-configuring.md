# Configuring TestRail
<a name="testrail-configuring"></a>

Before you can use AWS Glue to transfer data from TestRail, you must meet the following requirements:

## Minimum requirements
<a name="testrail-configuring-min-requirements"></a>
+ You have a TestRail account with API access.
+ You have an AWS account with access to AWS Glue.
+ You have the TestRail `instance` value used to build the connection URL.
