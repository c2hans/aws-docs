# Limitations and notes for the Chargebee connector
<a name="chargebee-connector-limitations"></a>

The following are limitations and notes for the Chargebee connector:
+ Chargebee is supported as a source only. Writing to Chargebee is not supported.
+ Job bookmarks are not supported.
