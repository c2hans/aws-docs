# AWS Glue support for LogRocket
<a name="logrocket-support"></a>

AWS Glue supports LogRocket as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from LogRocket.

**Supported as a target?**
No.

**Supported LogRocket API versions**
This connector is not tied to a specific LogRocket API version.
