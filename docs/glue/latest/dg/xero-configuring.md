# Configuring Xero
<a name="xero-configuring"></a>

Before you can use AWS Glue to transfer data from Xero, you must meet the following requirements:

## Minimum requirements
<a name="xero-configuring-min-requirements"></a>
+ You have a Xero account with API access.
+ You have an AWS account with access to AWS Glue.
