# AWS Glue support for New Relic
<a name="newrelic-support"></a>

AWS Glue supports New Relic as follows:

**Supported as a source?**
Yes. You can use AWS Glue ETL jobs to query data from New Relic.

**Supported as a target?**
No.

**Supported New Relic API versions**
The following New Relic API version is supported:
+ v2
