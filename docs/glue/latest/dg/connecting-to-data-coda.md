# Connecting to Coda in AWS Glue Studio
<a name="connecting-to-data-coda"></a>

Coda is an all-in-one doc that combines documents, tables and apps. Because you are a Coda user, you can connect AWS Glue to your Coda account. You can then use Coda as a data source in your AWS Glue ETL jobs to transfer data between Coda and AWS services or other supported applications.
