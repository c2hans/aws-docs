# SummarizationConfiguration

Controls whether a generative summary of the document is produced.

## Contents
<a name="API_SummarizationConfiguration_Contents"></a>

 ** State **   <a name="Textract-Type-SummarizationConfiguration-State"></a>
Set to `ENABLED` to produce a summary, or `DISABLED` to omit it.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
