# BoundingBoxConfiguration

Controls whether bounding box geometry is returned in the extraction output.

## Contents
<a name="API_BoundingBoxConfiguration_Contents"></a>

 ** State **   <a name="Textract-Type-BoundingBoxConfiguration-State"></a>
Set to `ENABLED` to return bounding box geometry, or `DISABLED` to omit it.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
