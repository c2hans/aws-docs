# OutputFormat

Controls the format of the extraction output, including the text format and any additional file formats.

## Contents
<a name="API_OutputFormat_Contents"></a>

 ** AdditionalFileFormat **   <a name="Textract-Type-OutputFormat-AdditionalFileFormat"></a>
Controls whether an additional file format is produced alongside the primary output.
Type: [OutputAdditionalFileFormat](API_OutputAdditionalFileFormat.md) object
Required: Yes

 ** TextFormat **   <a name="Textract-Type-OutputFormat-TextFormat"></a>
Controls the text formats produced in the extraction output.
Type: [OutputTextFormat](API_OutputTextFormat.md) object
Required: Yes
