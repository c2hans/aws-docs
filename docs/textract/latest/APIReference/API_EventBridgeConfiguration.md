# EventBridgeConfiguration

Event bus settings for a job.

## Contents
<a name="API_EventBridgeConfiguration_Contents"></a>

 ** State **   <a name="Textract-Type-EventBridgeConfiguration-State"></a>
Set to `ENABLED` to send events to an event bus, or `DISABLED` to not send them.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
