# FigureCaptionConfiguration

Controls whether generative captions are produced for figures detected in the document.

## Contents
<a name="API_FigureCaptionConfiguration_Contents"></a>

 ** State **   <a name="Textract-Type-FigureCaptionConfiguration-State"></a>
Set to `ENABLED` to produce figure captions, or `DISABLED` to omit them.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
