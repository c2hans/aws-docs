# RunLogLocation
<a name="API_RunLogLocation"></a>

The URI for the run log.

<a name="API_RunLogLocation_Contents"></a>

 ** engineLogStream **   <a name="omics-Type-RunLogLocation-engineLogStream"></a>
The log stream ARN for the engine log.
