# ReadSetS3Access
<a name="API_ReadSetS3Access"></a>

 ** s3Uri **   <a name="omics-Type-ReadSetS3Access-s3Uri"></a>
The S3 URI for each read set file.
Type: String
Pattern: `s3://([a-z0-9][a-z0-9-.]{1,61}[a-z0-9])/(.{1,1024})`
Required: No
