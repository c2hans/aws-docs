# ConfluentPublicRegistryConfiguration
<a name="API_ConfluentPublicRegistryConfiguration"></a>

Authentication configuration for public Confluent Schema Registry via EventBridge Connection.

## Contents
<a name="API_ConfluentPublicRegistryConfiguration_Contents"></a>

 ** ConnectionArn **   <a name="eventbridgev2-Type-ConfluentPublicRegistryConfiguration-ConnectionArn"></a>
EventBridge Connection ARN that provides API Key or OAuth credentials for the registry.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1600.
Pattern: `arn:aws(-[a-z0-9]+)*:events:[a-z0-9-]+:\d{12}:connection/.+`
Required: Yes
