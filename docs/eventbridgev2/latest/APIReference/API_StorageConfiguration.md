# StorageConfiguration
<a name="API_StorageConfiguration"></a>

Event storage configuration for an event bus.

## Contents
<a name="API_StorageConfiguration_Contents"></a>

 ** RetentionPeriodInDays **   <a name="eventbridgev2-Type-StorageConfiguration-RetentionPeriodInDays"></a>
Number of days events are retained on the event bus.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 365.
Required: No
