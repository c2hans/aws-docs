# AWS Security Documentation

Cloud security at AWS is the highest priority. AWS customers benefit from data centers and network architectures that are built to meet the requirements of the most security-sensitive organizations. Use the following documentation to configure AWS services to meet your security and compliance objectives.

## Security information

- [Shared Responsibility Model](https://aws.amazon.com/compliance/shared-responsibility-model/): Security is a shared responsibility between AWS and you. The shared responsibility model describes this as security of the cloud and security in the cloud.
- [AWS Architecture Center Security Best Practices](https://aws.amazon.com/architecture/security-identity-compliance): Learn how to meet your security and compliance goals using AWS infrastructure and services.
- [Security Learning](https://aws.amazon.com/security/security-learning/): Security resources include security-related information in blog posts, whitepapers, tutorials, training, and more.
- [Solutions for Security, Identity, and Compliance](https://aws.amazon.com/solutions/security/): These solution implementation guides discuss architectural considerations and provide steps for deploying security and compliance features.
- [HIPAA Eligible Services](https://aws.amazon.com/compliance/hipaa-eligible-services-reference/): Lists HIPAA eligible services. Not all AWS services are HIPAA eligible.
- [Compliance Resources](https://aws.amazon.com/compliance/resources/): Workbooks and guides specific to industries and locations.
- [Security Compliance Management - AWS Artifact](https://aws.amazon.com/artifact/): Understand the shared responsibility model through the lens of compliance. Save time with on-demand access to AWS compliance reports and manage compliance agreements at scale.
- [Evaluating Resources with AWS Config Rules](/config/latest/developerguide/evaluate-config.html): The AWS Config service assesses how well your resource configurations comply with internal practices, industry guidelines, and regulations.
