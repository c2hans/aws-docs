# emr-spark-8.0.0-20260421
<a name="emr-eks-spark-8.0.0-20260421"></a>

Release label
Use `emr-spark-8.0.0-20260421` as the `--release-label` value in the [StartJobRun](https://docs.aws.amazon.com/emr-on-eks/latest/APIReference/API_StartJobRun.html) API.

Release notes
`emr-spark-8.0.0-20260421` was released in April 2026. This is the initial release of AWS runtime for Apache Spark 8.0.0.

Regions
You can use `emr-spark-8.0.0-20260421` in all Regions supported by Amazon EMR on EKS. For more information, see [Amazon EMR on EKS service endpoints](https://docs.aws.amazon.com/emr/latest/EMR-on-EKS-DevelopmentGuide/service-quotas.html#service-endpoints).
