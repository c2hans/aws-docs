# EMRContainersConfig
<a name="API_EMRContainersConfig"></a>

The EMR container configuration.

## Contents
<a name="API_EMRContainersConfig_Contents"></a>

 ** JobRunId **   <a name="EMR-Type-EMRContainersConfig-JobRunId"></a>
The Job run ID for the container configuration.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\u0020-\uD7FF\uE000-\uFFFD\uD800\uDC00-\uDBFF\uDFFF\r\n\t]*`
Required: No
