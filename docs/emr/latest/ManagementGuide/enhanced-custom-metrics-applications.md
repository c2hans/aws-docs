# Monitor Apache Spark applications on Amazon EMR with Amazon CloudWatch
<a name="enhanced-custom-metrics-applications"></a>

To improve a Spark application's efficiency, it's essential to monitor its performance and behavior. In the following blog post, a tutorial demonstrates in a step-by-step manner how to publish detailed Spark metrics from Amazon EMR to CloudWatch. This gives you the ability to identify bottlenecks while optimizing resource utilization: [Monitor Apache Spark applications on Amazon EMR with Amazon CloudWatch](https://aws.amazon.com/blogs/big-data/monitor-apache-spark-applications-on-amazon-emr-with-amazon-cloudwatch/)

For more information about CloudWatch, see [What is Amazon CloudWatch?](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.html).
