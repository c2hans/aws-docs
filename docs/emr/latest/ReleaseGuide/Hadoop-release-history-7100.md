# Amazon EMR 7.10.0 - Hadoop release notes
<a name="Hadoop-release-history-7100"></a>

## Amazon EMR 7.10.0 - Hadoop changes
<a name="Hadoop-release-history-7100-changes"></a>

| Type | Description |
| --- | --- |
| Improvement | Make S3A filesystem as the default filesystem for EMR. |
| Bug fix |  Disable `yarn.resourcemanager.decommissioning-nodes-watcher.wait-for-applications` by default |
| New Feature |  S3A now supports Lake Formation unfiltered access for EMR Serverless: [Lake Formation unfiltered access for EMR Serverless](https://docs.aws.amazon.com/emr/latest/EMR-Serverless-UserGuide/lake-formation-unfiltered-access.html). |
