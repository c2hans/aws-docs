# EnvironmentPropertyUpdates
<a name="API_EnvironmentPropertyUpdates"></a>

Describes updates to the execution property groups for a Managed Service for Apache Flink application or a Studio notebook.

## Contents
<a name="API_EnvironmentPropertyUpdates_Contents"></a>

 ** PropertyGroups **   <a name="APIReference-Type-EnvironmentPropertyUpdates-PropertyGroups"></a>
Describes updates to the execution property groups.
Type: Array of [PropertyGroup](API_PropertyGroup.md) objects
Array Members: Maximum number of 50 items.
Required: Yes
