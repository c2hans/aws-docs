# ApplicationMaintenanceConfigurationUpdate
<a name="API_ApplicationMaintenanceConfigurationUpdate"></a>

Describes the updated maintenance configuration for the application.

## Contents
<a name="API_ApplicationMaintenanceConfigurationUpdate_Contents"></a>

 ** ApplicationMaintenanceWindowStartTimeUpdate **   <a name="APIReference-Type-ApplicationMaintenanceConfigurationUpdate-ApplicationMaintenanceWindowStartTimeUpdate"></a>
The updated start time for the maintenance window.
Type: String
Length Constraints: Fixed length of 5.
Pattern: `([01][0-9]|2[0-3]):[0-5][0-9]`
Required: Yes
