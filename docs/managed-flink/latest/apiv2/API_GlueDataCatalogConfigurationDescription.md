# GlueDataCatalogConfigurationDescription
<a name="API_GlueDataCatalogConfigurationDescription"></a>

The configuration of the Glue Data Catalog that you use for Apache Flink SQL queries and table API transforms that you write in an application.

## Contents
<a name="API_GlueDataCatalogConfigurationDescription_Contents"></a>

 ** DatabaseARN **   <a name="APIReference-Type-GlueDataCatalogConfigurationDescription-DatabaseARN"></a>
The Amazon Resource Name (ARN) of the database.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Pattern: `arn:.*`
Required: Yes
