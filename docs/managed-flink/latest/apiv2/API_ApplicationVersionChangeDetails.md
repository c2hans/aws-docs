# ApplicationVersionChangeDetails
<a name="API_ApplicationVersionChangeDetails"></a>

Contains information about the version changes that the operation applied to the application.

## Contents
<a name="API_ApplicationVersionChangeDetails_Contents"></a>

 ** ApplicationVersionUpdatedFrom **   <a name="APIReference-Type-ApplicationVersionChangeDetails-ApplicationVersionUpdatedFrom"></a>
The new version that the application was updated to.
Type: Long
Valid Range: Minimum value of 1. Maximum value of 999999999.
Required: Yes

 ** ApplicationVersionUpdatedTo **   <a name="APIReference-Type-ApplicationVersionChangeDetails-ApplicationVersionUpdatedTo"></a>
The version that the operation execution applied to the applicartion.
Type: Long
Valid Range: Minimum value of 1. Maximum value of 999999999.
Required: Yes
