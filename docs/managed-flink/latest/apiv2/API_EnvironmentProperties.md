# EnvironmentProperties
<a name="API_EnvironmentProperties"></a>

Describes execution properties for a Managed Service for Apache Flink application.

## Contents
<a name="API_EnvironmentProperties_Contents"></a>

 ** PropertyGroups **   <a name="APIReference-Type-EnvironmentProperties-PropertyGroups"></a>
Describes the execution property groups.
Type: Array of [PropertyGroup](API_PropertyGroup.md) objects
Array Members: Maximum number of 50 items.
Required: Yes
