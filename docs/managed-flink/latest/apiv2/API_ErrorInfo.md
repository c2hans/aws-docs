# ErrorInfo
<a name="API_ErrorInfo"></a>

A description of the error that caused an operation to fail.

## Contents
<a name="API_ErrorInfo_Contents"></a>

 ** ErrorString **   <a name="APIReference-Type-ErrorInfo-ErrorString"></a>
An error message that is returned when an operation fails.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: No
