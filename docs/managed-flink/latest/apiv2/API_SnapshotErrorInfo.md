# SnapshotErrorInfo
<a name="API_SnapshotErrorInfo"></a>

A description of the error that caused a snapshot operation to fail.

## Contents
<a name="API_SnapshotErrorInfo_Contents"></a>

 ** ErrorCode **   <a name="APIReference-Type-SnapshotErrorInfo-ErrorCode"></a>
The error code that identifies the cause of the failure.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: No

 ** ErrorString **   <a name="APIReference-Type-SnapshotErrorInfo-ErrorString"></a>
An error message that is returned when an operation fails.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: No
