# ZeppelinMonitoringConfigurationDescription
<a name="API_ZeppelinMonitoringConfigurationDescription"></a>

The monitoring configuration for Apache Zeppelin within a Managed Service for Apache Flink Studio notebook.

## Contents
<a name="API_ZeppelinMonitoringConfigurationDescription_Contents"></a>

 ** LogLevel **   <a name="APIReference-Type-ZeppelinMonitoringConfigurationDescription-LogLevel"></a>
Describes the verbosity of the CloudWatch Logs for an application.
Type: String
Valid Values: `INFO | WARN | ERROR | DEBUG`
Required: No
