# DeployAsApplicationConfiguration
<a name="API_DeployAsApplicationConfiguration"></a>

The information required to deploy a Managed Service for Apache Flink Studio notebook as an application with durable state.

## Contents
<a name="API_DeployAsApplicationConfiguration_Contents"></a>

 ** S3ContentLocation **   <a name="APIReference-Type-DeployAsApplicationConfiguration-S3ContentLocation"></a>
The description of an Amazon S3 object that contains the Amazon Data Analytics application, including the Amazon Resource Name (ARN) of the S3 bucket, the name of the Amazon S3 object that contains the data, and the version number of the Amazon S3 object that contains the data.
Type: [S3ContentBaseLocation](API_S3ContentBaseLocation.md) object
Required: Yes
