# CatalogConfiguration
<a name="API_CatalogConfiguration"></a>

The configuration parameters for the default Amazon Glue database. You use this database for SQL queries that you write in a Managed Service for Apache Flink Studio notebook.

 ** GlueDataCatalogConfiguration **   <a name="APIReference-Type-CatalogConfiguration-GlueDataCatalogConfiguration"></a>

Type: [GlueDataCatalogConfiguration](API_GlueDataCatalogConfiguration.md) object
Required: Yes
