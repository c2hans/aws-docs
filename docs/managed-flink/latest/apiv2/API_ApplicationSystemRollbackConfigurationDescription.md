# ApplicationSystemRollbackConfigurationDescription
<a name="API_ApplicationSystemRollbackConfigurationDescription"></a>

 ** RollbackEnabled **   <a name="APIReference-Type-ApplicationSystemRollbackConfigurationDescription-RollbackEnabled"></a>

Type: Boolean
Required: Yes
