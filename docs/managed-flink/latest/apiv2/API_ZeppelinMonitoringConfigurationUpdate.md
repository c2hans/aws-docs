# ZeppelinMonitoringConfigurationUpdate
<a name="API_ZeppelinMonitoringConfigurationUpdate"></a>

Updates to the monitoring configuration for Apache Zeppelin within a Managed Service for Apache Flink Studio notebook.

## Contents
<a name="API_ZeppelinMonitoringConfigurationUpdate_Contents"></a>

 ** LogLevelUpdate **   <a name="APIReference-Type-ZeppelinMonitoringConfigurationUpdate-LogLevelUpdate"></a>
Updates to the logging level for Apache Zeppelin within a Managed Service for Apache Flink Studio notebook.
Type: String
Valid Values: `INFO | WARN | ERROR | DEBUG`
Required: Yes
