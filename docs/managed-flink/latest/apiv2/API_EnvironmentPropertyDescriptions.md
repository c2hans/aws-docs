# EnvironmentPropertyDescriptions
<a name="API_EnvironmentPropertyDescriptions"></a>

Describes the execution properties for an Apache Flink runtime.

## Contents
<a name="API_EnvironmentPropertyDescriptions_Contents"></a>

 ** PropertyGroupDescriptions **   <a name="APIReference-Type-EnvironmentPropertyDescriptions-PropertyGroupDescriptions"></a>
Describes the execution property groups.
Type: Array of [PropertyGroup](API_PropertyGroup.md) objects
Array Members: Maximum number of 50 items.
Required: No
