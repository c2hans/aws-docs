# DeployAsApplicationConfigurationDescription
<a name="API_DeployAsApplicationConfigurationDescription"></a>

The configuration information required to deploy an Amazon Data Analytics Studio notebook as an application with durable state.

## Contents
<a name="API_DeployAsApplicationConfigurationDescription_Contents"></a>

 ** S3ContentLocationDescription **   <a name="APIReference-Type-DeployAsApplicationConfigurationDescription-S3ContentLocationDescription"></a>
The location that holds the data required to specify an Amazon Data Analytics application.
Type: [S3ContentBaseLocationDescription](API_S3ContentBaseLocationDescription.md) object
Required: Yes
