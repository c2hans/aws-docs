# RegionalStatusDetail

Contains the progress detail for a single Region of a StackSet operation. This information is returned only by [DescribeStackSetOperation](API_DescribeStackSetOperation.md).

## Contents
<a name="API_RegionalStatusDetail_Contents"></a>

 ** Stages **
The progress information for the individual stages of the operation in this Region.
Type: [RegionalStages](API_RegionalStages.md) object
Required: No
