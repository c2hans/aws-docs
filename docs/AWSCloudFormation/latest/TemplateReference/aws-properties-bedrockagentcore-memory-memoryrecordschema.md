# AWS::BedrockAgentCore::Memory MemoryRecordSchema
<a name="aws-properties-bedrockagentcore-memory-memoryrecordschema"></a>

Schema for metadata on memory records generated by a strategy.

## Syntax
<a name="aws-properties-bedrockagentcore-memory-memoryrecordschema-syntax"></a>

To declare this entity in your CloudFormation template, use the following syntax:

### JSON
<a name="aws-properties-bedrockagentcore-memory-memoryrecordschema-syntax.json"></a>

```
{
  "[MetadataSchema](#cfn-bedrockagentcore-memory-memoryrecordschema-metadataschema)" : {{[ MetadataSchemaEntry, ... ]}}
}
```

### YAML
<a name="aws-properties-bedrockagentcore-memory-memoryrecordschema-syntax.yaml"></a>

```
  [MetadataSchema](#cfn-bedrockagentcore-memory-memoryrecordschema-metadataschema): {{
    - MetadataSchemaEntry}}
```

## Properties
<a name="aws-properties-bedrockagentcore-memory-memoryrecordschema-properties"></a>

`MetadataSchema`  <a name="cfn-bedrockagentcore-memory-memoryrecordschema-metadataschema"></a>
The metadata field definitions for this strategy.
*Required*: No
*Type*: Array of [MetadataSchemaEntry](aws-properties-bedrockagentcore-memory-metadataschemaentry.md)
*Minimum*: `1`
*Maximum*: `20`
*Update requires*: [No interruption](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-updating-stacks-update-behaviors.html#update-no-interrupt)
