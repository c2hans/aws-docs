# AWS::Lightsail::ExportSnapshotRecord
<a name="aws-resource-lightsail-exportsnapshotrecord"></a>

Describes an export snapshot record.

## Syntax
<a name="aws-resource-lightsail-exportsnapshotrecord-syntax"></a>

To declare this entity in your CloudFormation template, use the following syntax:

### JSON
<a name="aws-resource-lightsail-exportsnapshotrecord-syntax.json"></a>

```
{
  "Type" : "AWS::Lightsail::ExportSnapshotRecord"
}
```

### YAML
<a name="aws-resource-lightsail-exportsnapshotrecord-syntax.yaml"></a>

```
Type: AWS::Lightsail::ExportSnapshotRecord
```
