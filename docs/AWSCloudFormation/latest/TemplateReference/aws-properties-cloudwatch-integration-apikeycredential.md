# AWS::CloudWatch::Integration ApiKeyCredential
<a name="aws-properties-cloudwatch-integration-apikeycredential"></a>

API-key credential material that can be rotated in place on update.

## Syntax
<a name="aws-properties-cloudwatch-integration-apikeycredential-syntax"></a>

To declare this entity in your CloudFormation template, use the following syntax:

### JSON
<a name="aws-properties-cloudwatch-integration-apikeycredential-syntax.json"></a>

```
{
  "[ApiKeyValue](#cfn-cloudwatch-integration-apikeycredential-apikeyvalue)" : {{String}}
}
```

### YAML
<a name="aws-properties-cloudwatch-integration-apikeycredential-syntax.yaml"></a>

```
  [ApiKeyValue](#cfn-cloudwatch-integration-apikeycredential-apikeyvalue): {{String}}
```

## Properties
<a name="aws-properties-cloudwatch-integration-apikeycredential-properties"></a>

`ApiKeyValue`  <a name="cfn-cloudwatch-integration-apikeycredential-apikeyvalue"></a>
Property description not available.
*Required*: Yes
*Type*: String
*Minimum*: `1`
*Maximum*: `4096`
*Update requires*: [No interruption](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-updating-stacks-update-behaviors.html#update-no-interrupt)
