# AWS::VpcLattice::ServiceNetwork SharingConfig
<a name="aws-properties-vpclattice-servicenetwork-sharingconfig"></a>

Specify if the service network should be enabled for sharing.

## Syntax
<a name="aws-properties-vpclattice-servicenetwork-sharingconfig-syntax"></a>

To declare this entity in your CloudFormation template, use the following syntax:

### JSON
<a name="aws-properties-vpclattice-servicenetwork-sharingconfig-syntax.json"></a>

```
{
  "[enabled](#cfn-vpclattice-servicenetwork-sharingconfig-enabled)" : {{Boolean}}
}
```

### YAML
<a name="aws-properties-vpclattice-servicenetwork-sharingconfig-syntax.yaml"></a>

```
  [enabled](#cfn-vpclattice-servicenetwork-sharingconfig-enabled): {{Boolean}}
```

## Properties
<a name="aws-properties-vpclattice-servicenetwork-sharingconfig-properties"></a>

`enabled`  <a name="cfn-vpclattice-servicenetwork-sharingconfig-enabled"></a>
Specify if the service network should be enabled for sharing.
*Required*: Yes
*Type*: Boolean
*Update requires*: [Replacement](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-updating-stacks-update-behaviors.html#update-replacement)
