# Subscribe to CloudFormation Template Reference notifications
<a name="subscribe-notifications"></a>

For automatic alerts about changes to this guide, subscribe to the RSS feed on the CloudFormation Template Reference [Document history](doc-history.md) page. To subscribe to RSS updates, you must have an RSS plug-in enabled for the browser you are using.
