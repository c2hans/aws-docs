# AWS::SageMaker::TrialComponent MetadataProperties
<a name="aws-properties-sagemaker-trialcomponent-metadataproperties"></a>

Metadata properties of the tracking entity, trial, or trial component.

## Syntax
<a name="aws-properties-sagemaker-trialcomponent-metadataproperties-syntax"></a>

To declare this entity in your CloudFormation template, use the following syntax:

### JSON
<a name="aws-properties-sagemaker-trialcomponent-metadataproperties-syntax.json"></a>

```
{
  "[CommitId](#cfn-sagemaker-trialcomponent-metadataproperties-commitid)" : {{String}},
  "[GeneratedBy](#cfn-sagemaker-trialcomponent-metadataproperties-generatedby)" : {{String}},
  "[ProjectId](#cfn-sagemaker-trialcomponent-metadataproperties-projectid)" : {{String}},
  "[Repository](#cfn-sagemaker-trialcomponent-metadataproperties-repository)" : {{String}}
}
```

### YAML
<a name="aws-properties-sagemaker-trialcomponent-metadataproperties-syntax.yaml"></a>

```
  [CommitId](#cfn-sagemaker-trialcomponent-metadataproperties-commitid): {{String}}
  [GeneratedBy](#cfn-sagemaker-trialcomponent-metadataproperties-generatedby): {{String}}
  [ProjectId](#cfn-sagemaker-trialcomponent-metadataproperties-projectid): {{String}}
  [Repository](#cfn-sagemaker-trialcomponent-metadataproperties-repository): {{String}}
```

## Properties
<a name="aws-properties-sagemaker-trialcomponent-metadataproperties-properties"></a>

`CommitId`  <a name="cfn-sagemaker-trialcomponent-metadataproperties-commitid"></a>
The commit ID.
*Required*: No
*Type*: String
*Maximum*: `1024`
*Update requires*: [Replacement](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-updating-stacks-update-behaviors.html#update-replacement)

`GeneratedBy`  <a name="cfn-sagemaker-trialcomponent-metadataproperties-generatedby"></a>

*Required*: No
*Type*: String
*Maximum*: `1024`
*Update requires*: [Replacement](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-updating-stacks-update-behaviors.html#update-replacement)

`ProjectId`  <a name="cfn-sagemaker-trialcomponent-metadataproperties-projectid"></a>
The project ID.
*Required*: No
*Type*: String
*Maximum*: `1024`
*Update requires*: [Replacement](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-updating-stacks-update-behaviors.html#update-replacement)
