# AWS::SecurityHub::Insight BooleanFilter
<a name="aws-properties-securityhub-insight-booleanfilter"></a>

Boolean filter for querying findings.

  "[Value](#cfn-securityhub-insight-booleanfilter-value)" : {{Boolean}}
}
