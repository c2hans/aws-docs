# AWS::QuickSight::Template GeospatialLineStyle
<a name="aws-properties-quicksight-template-geospatiallinestyle"></a>

The visualization style for a line layer.

## Syntax
<a name="aws-properties-quicksight-template-geospatiallinestyle-syntax"></a>

To declare this entity in your CloudFormation template, use the following syntax:

### JSON
<a name="aws-properties-quicksight-template-geospatiallinestyle-syntax.json"></a>

```
{
  "[LineSymbolStyle](#cfn-quicksight-template-geospatiallinestyle-linesymbolstyle)" : {{GeospatialLineSymbolStyle}}
}
```

### YAML
<a name="aws-properties-quicksight-template-geospatiallinestyle-syntax.yaml"></a>

```
  [LineSymbolStyle](#cfn-quicksight-template-geospatiallinestyle-linesymbolstyle): {{
    GeospatialLineSymbolStyle}}
```

## Properties
<a name="aws-properties-quicksight-template-geospatiallinestyle-properties"></a>

`LineSymbolStyle`  <a name="cfn-quicksight-template-geospatiallinestyle-linesymbolstyle"></a>
The symbol style for a line style.
*Required*: No
*Type*: [GeospatialLineSymbolStyle](aws-properties-quicksight-template-geospatiallinesymbolstyle.md)
*Update requires*: [No interruption](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-updating-stacks-update-behaviors.html#update-no-interrupt)
