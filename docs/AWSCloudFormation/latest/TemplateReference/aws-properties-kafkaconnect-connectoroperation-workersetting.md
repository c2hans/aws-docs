# AWS::KafkaConnect::ConnectorOperation WorkerSetting
<a name="aws-properties-kafkaconnect-connectoroperation-workersetting"></a>

Details about worker setting of a connector

## Syntax
<a name="aws-properties-kafkaconnect-connectoroperation-workersetting-syntax"></a>

To declare this entity in your CloudFormation template, use the following syntax:

### JSON
<a name="aws-properties-kafkaconnect-connectoroperation-workersetting-syntax.json"></a>

```
{
  "[Capacity](#cfn-kafkaconnect-connectoroperation-workersetting-capacity)" : {{CapacityDescription}}
}
```

### YAML
<a name="aws-properties-kafkaconnect-connectoroperation-workersetting-syntax.yaml"></a>

```
  [Capacity](#cfn-kafkaconnect-connectoroperation-workersetting-capacity): {{
    CapacityDescription}}
```
