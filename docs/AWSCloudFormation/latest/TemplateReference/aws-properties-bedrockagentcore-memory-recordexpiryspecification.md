# AWS::BedrockAgentCore::Memory RecordExpirySpecification
<a name="aws-properties-bedrockagentcore-memory-recordexpiryspecification"></a>

Specifies the record expiry (long-term memory time-to-live) for a memory strategy. Provide exactly one of `recordExpiryDurationDays` or `action`. Set `recordExpiryDurationDays` to configure or update the time-to-live, or set `action` to `REMOVE` to remove a previously configured time-to-live.

<a name="aws-properties-bedrockagentcore-memory-recordexpiryspecification-syntax"></a>

<a name="aws-properties-bedrockagentcore-memory-recordexpiryspecification-syntax.json"></a>

```
{
  "[RecordExpiryDurationDays](#cfn-bedrockagentcore-memory-recordexpiryspecification-recordexpirydurationdays)" : {{Integer}}

```

## Properties
<a name="aws-properties-bedrockagentcore-memory-recordexpiryspecification-properties"></a>

`RecordExpiryDurationDays`  <a name="cfn-bedrockagentcore-memory-recordexpiryspecification-recordexpirydurationdays"></a>
The duration, in days, after which memory records generated by this strategy expire. The minimum is 31 days.
*Required*: Yes
*Type*: Integer
*Minimum*: `31`
*Update requires*: [No interruption](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-updating-stacks-update-behaviors.html#update-no-interrupt)
