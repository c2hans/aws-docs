# AWS::QuickSight::Theme FontSize
<a name="aws-properties-quicksight-theme-fontsize"></a>

The option that determines the text display size.

## Syntax
<a name="aws-properties-quicksight-theme-fontsize-syntax"></a>

To declare this entity in your CloudFormation template, use the following syntax:

### JSON
<a name="aws-properties-quicksight-theme-fontsize-syntax.json"></a>

```
{
  "[Absolute](#cfn-quicksight-theme-fontsize-absolute)" : {{String}}
}
```

### YAML
<a name="aws-properties-quicksight-theme-fontsize-syntax.yaml"></a>

```
  [Absolute](#cfn-quicksight-theme-fontsize-absolute): {{String}}
```

## Properties
<a name="aws-properties-quicksight-theme-fontsize-properties"></a>

`Absolute`  <a name="cfn-quicksight-theme-fontsize-absolute"></a>
The font size that you want to use in px.
*Required*: No
*Type*: String
*Update requires*: [No interruption](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-updating-stacks-update-behaviors.html#update-no-interrupt)
