# AWS::CleanRooms::IntermediateTable IntermediateTableAnalysisRulePolicy
<a name="aws-properties-cleanrooms-intermediatetable-intermediatetableanalysisrulepolicy"></a>

Contains the policy for an intermediate table analysis rule.

```
{
  "[V1](#cfn-cleanrooms-intermediatetable-intermediatetableanalysisrulepolicy-v1)" : {{IntermediateTableAnalysisRulePolicyV1}}
}
```

<a name="aws-properties-cleanrooms-intermediatetable-intermediatetableanalysisrulepolicy-syntax.yaml"></a>

