# AWS::Connect::ContactFlowModule ExternalInvocationConfiguration
<a name="aws-properties-connect-contactflowmodule-externalinvocationconfiguration"></a>

The external invocation configuration for the flow module

## Syntax
<a name="aws-properties-connect-contactflowmodule-externalinvocationconfiguration-syntax"></a>

To declare this entity in your CloudFormation template, use the following syntax:

### JSON
<a name="aws-properties-connect-contactflowmodule-externalinvocationconfiguration-syntax.json"></a>

```
{
  "[Enabled](#cfn-connect-contactflowmodule-externalinvocationconfiguration-enabled)" : {{Boolean}}
}
```

### YAML
<a name="aws-properties-connect-contactflowmodule-externalinvocationconfiguration-syntax.yaml"></a>

```
  [Enabled](#cfn-connect-contactflowmodule-externalinvocationconfiguration-enabled): {{Boolean}}
```

## Properties
<a name="aws-properties-connect-contactflowmodule-externalinvocationconfiguration-properties"></a>

`Enabled`  <a name="cfn-connect-contactflowmodule-externalinvocationconfiguration-enabled"></a>
Enable external invocation.
*Required*: No
*Type*: Boolean
*Update requires*: [No interruption](https://docs.aws.amazon.com/AWSCloudFormation/latest/UserGuide/using-cfn-updating-stacks-update-behaviors.html#update-no-interrupt)
