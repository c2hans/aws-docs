# HumanLoopOutput
<a name="API_HumanLoopOutput"></a>

Information about where the human output will be stored.

## Contents
<a name="API_HumanLoopOutput_Contents"></a>

 ** OutputS3Uri **   <a name="augmentedai-Type-HumanLoopOutput-OutputS3Uri"></a>
The location of the Amazon S3 object where Amazon Augmented AI stores your human loop output.
Type: String
Required: Yes
