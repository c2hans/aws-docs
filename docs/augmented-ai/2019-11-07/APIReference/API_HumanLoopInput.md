# HumanLoopInput
<a name="API_HumanLoopInput"></a>

An object containing the human loop input in JSON format.

## Contents
<a name="API_HumanLoopInput_Contents"></a>

 ** InputContent **   <a name="augmentedai-Type-HumanLoopInput-InputContent"></a>
Serialized input from the human loop. The input must be a string representation of a file in JSON format.
Type: String
Length Constraints: Maximum length of 3145728.
Required: Yes
