# Data Types
<a name="API_Types"></a>

The Amazon Augmented AI Runtime API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [HumanLoopDataAttributes](API_HumanLoopDataAttributes.md)
+  [HumanLoopInput](API_HumanLoopInput.md)
+  [HumanLoopOutput](API_HumanLoopOutput.md)
+  [HumanLoopSummary](API_HumanLoopSummary.md)
