# Using Libraries in Projects
<a name="bda-library-using-in-projects"></a>

This section describes how to associate Data Automation Libraries with your BDA projects to enable library functionality for content processing. When you associate a library with a project, all audio and video processing jobs executed through that project use the entities defined in the library to improve extraction accuracy.
