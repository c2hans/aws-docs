# `AWS::BedrockMantle` resources
<a name="cfn-mantle-resources"></a>

The `AWS::BedrockMantle` namespace contains resources for the `bedrock-mantle` endpoint. Currently, this namespace supports the `AWS::BedrockMantle::Project` resource.
