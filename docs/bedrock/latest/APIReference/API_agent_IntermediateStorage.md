# IntermediateStorage
<a name="API_agent_IntermediateStorage"></a>

A location for storing content from data sources temporarily as it is processed by custom components in the ingestion pipeline.

## Contents
<a name="API_agent_IntermediateStorage_Contents"></a>

 ** s3Location **   <a name="bedrock-Type-agent_IntermediateStorage-s3Location"></a>
An S3 bucket path.
Type: [S3Location](API_agent_S3Location.md) object
Required: Yes
