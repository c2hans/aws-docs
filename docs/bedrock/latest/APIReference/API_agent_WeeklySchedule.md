# WeeklySchedule
<a name="API_agent_WeeklySchedule"></a>

A weekly sync on a specified day of the week.

## Contents
<a name="API_agent_WeeklySchedule_Contents"></a>

 ** dayOfWeek **   <a name="bedrock-Type-agent_WeeklySchedule-dayOfWeek"></a>
The day of the week on which the weekly sync runs.
Type: String
Valid Values: `SUNDAY | MONDAY | TUESDAY | WEDNESDAY | THURSDAY | FRIDAY | SATURDAY`
Required: Yes
