# MonthlySchedule
<a name="API_agent_MonthlySchedule"></a>

A monthly sync on a specified day of the month.

## Contents
<a name="API_agent_MonthlySchedule_Contents"></a>

 ** dayOfMonth **   <a name="bedrock-Type-agent_MonthlySchedule-dayOfMonth"></a>
The day of the month on which the monthly sync runs.
Type: [DayOfMonth](API_agent_DayOfMonth.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes
