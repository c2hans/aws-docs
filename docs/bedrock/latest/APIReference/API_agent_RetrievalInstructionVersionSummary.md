# RetrievalInstructionVersionSummary
<a name="API_agent_RetrievalInstructionVersionSummary"></a>

A summary of one numbered version of a retrieval instruction, without the content.

## Contents
<a name="API_agent_RetrievalInstructionVersionSummary_Contents"></a>

 ** createdAt **   <a name="bedrock-Type-agent_RetrievalInstructionVersionSummary-createdAt"></a>
When this version was created.
Type: Timestamp
Required: Yes

 ** version **   <a name="bedrock-Type-agent_RetrievalInstructionVersionSummary-version"></a>
The version number.
Type: String
Pattern: `[1-9][0-9]{0,8}`
Required: Yes
