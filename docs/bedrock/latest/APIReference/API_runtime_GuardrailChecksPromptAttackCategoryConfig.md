# GuardrailChecksPromptAttackCategoryConfig
<a name="API_runtime_GuardrailChecksPromptAttackCategoryConfig"></a>

The configuration for a single prompt attack category to evaluate.

## Contents
<a name="API_runtime_GuardrailChecksPromptAttackCategoryConfig_Contents"></a>

 ** category **   <a name="bedrock-Type-runtime_GuardrailChecksPromptAttackCategoryConfig-category"></a>
The prompt attack category to evaluate.
Type: String
Valid Values: `JAILBREAK | PROMPT_INJECTION | PROMPT_LEAKAGE`
Required: Yes
