# AudioExtractionConfiguration
<a name="API_agent_AudioExtractionConfiguration"></a>

Configuration for audio extraction.

## Contents
<a name="API_agent_AudioExtractionConfiguration_Contents"></a>

 ** audioExtractionStatus **   <a name="bedrock-Type-agent_AudioExtractionConfiguration-audioExtractionStatus"></a>
Whether audio extraction is enabled or disabled.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
