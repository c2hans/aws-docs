# GuardrailChecksContentFilterCategoryConfig
<a name="API_runtime_GuardrailChecksContentFilterCategoryConfig"></a>

The configuration for a single content filter category to evaluate.

## Contents
<a name="API_runtime_GuardrailChecksContentFilterCategoryConfig_Contents"></a>

 ** category **   <a name="bedrock-Type-runtime_GuardrailChecksContentFilterCategoryConfig-category"></a>
The content filter category to evaluate.
Type: String
Valid Values: `VIOLENCE | HATE | SEXUAL | MISCONDUCT | INSULTS`
Required: Yes
