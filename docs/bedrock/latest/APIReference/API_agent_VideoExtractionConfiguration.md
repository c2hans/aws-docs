# VideoExtractionConfiguration
<a name="API_agent_VideoExtractionConfiguration"></a>

Configuration for video extraction.

## Contents
<a name="API_agent_VideoExtractionConfiguration_Contents"></a>

 ** videoExtractionStatus **   <a name="bedrock-Type-agent_VideoExtractionConfiguration-videoExtractionStatus"></a>
Whether video extraction is enabled or disabled.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
