# OutputConfiguration
<a name="API_data-automation_OutputConfiguration"></a>

Output configuration for ingestion jobs.

## Contents
<a name="API_data-automation_OutputConfiguration_Contents"></a>

 ** s3Uri **   <a name="bedrock-Type-data-automation_OutputConfiguration-s3Uri"></a>
S3 URI for output.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `s3://[a-z0-9][\.\-a-z0-9]{1,61}[a-z0-9](/.*)?`
Required: Yes
