# GuardrailChecksPromptAttackConfig
<a name="API_runtime_GuardrailChecksPromptAttackConfig"></a>

The configuration for the prompt attack check, specifying which categories to evaluate.

## Contents
<a name="API_runtime_GuardrailChecksPromptAttackConfig_Contents"></a>

 ** categories **   <a name="bedrock-Type-runtime_GuardrailChecksPromptAttackConfig-categories"></a>
The prompt attack categories to evaluate.
Type: Array of [GuardrailChecksPromptAttackCategoryConfig](API_runtime_GuardrailChecksPromptAttackCategoryConfig.md) objects
Array Members: Minimum number of 1 item. Maximum number of 3 items.
Required: Yes
