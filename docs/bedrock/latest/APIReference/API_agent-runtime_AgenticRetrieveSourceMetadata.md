# AgenticRetrieveSourceMetadata
<a name="API_agent-runtime_AgenticRetrieveSourceMetadata"></a>

Metadata about a retrieval source.

## Contents
<a name="API_agent-runtime_AgenticRetrieveSourceMetadata_Contents"></a>

 ** identifier **   <a name="bedrock-Type-agent-runtime_AgenticRetrieveSourceMetadata-identifier"></a>
The identifier of the retrieval source.
Type: String
Required: No

 ** retrievalType **   <a name="bedrock-Type-agent-runtime_AgenticRetrieveSourceMetadata-retrievalType"></a>
The type of retrieval source.
Type: String
Valid Values: `BedrockKnowledgeBase | BedrockAgentCoreMemory`
Required: No
