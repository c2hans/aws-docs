# GuardrailChecksContentFilterConfig
<a name="API_runtime_GuardrailChecksContentFilterConfig"></a>

The configuration for the content filter check, specifying which categories to evaluate.

## Contents
<a name="API_runtime_GuardrailChecksContentFilterConfig_Contents"></a>

 ** categories **   <a name="bedrock-Type-runtime_GuardrailChecksContentFilterConfig-categories"></a>
The content filter categories to evaluate.
Type: Array of [GuardrailChecksContentFilterCategoryConfig](API_runtime_GuardrailChecksContentFilterCategoryConfig.md) objects
Array Members: Minimum number of 1 item. Maximum number of 5 items.
Required: Yes
