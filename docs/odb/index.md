# Oracle Database@AWS Documentation

Oracle Database@AWS lets you migrate your Oracle Exadata workloads, including Oracle RAC workloads, to Oracle Exadata Database Service on Dedicated Infrastructure within AWS.

## User Guide

- [Oracle Database@AWS User Guide](/odb/latest/UserGuide/): Provides an overview of Oracle Database@AWS and instructions for getting started.

## References

- [Oracle Database@AWS in the AWS CLI Reference](/cli/latest/reference/odb/): Describes all the CLI commands for Oracle Database@AWS in detail. Provides all syntax. Also provides examples for the most common commands.
- [Oracle Database@AWS API Reference](/odb/latest/APIReference/): Describes all the API operations for Oracle Database@AWS in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
