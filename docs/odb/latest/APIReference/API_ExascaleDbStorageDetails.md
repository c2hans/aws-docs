# ExascaleDbStorageDetails
<a name="API_ExascaleDbStorageDetails"></a>

The storage details for an Exascale storage vault.

## Contents
<a name="API_ExascaleDbStorageDetails_Contents"></a>

 ** availableSizeInGBs **   <a name="odb-Type-ExascaleDbStorageDetails-availableSizeInGBs"></a>
The available storage size, in gigabytes (GB).
Type: Integer
Required: No

 ** totalSizeInGBs **   <a name="odb-Type-ExascaleDbStorageDetails-totalSizeInGBs"></a>
The total storage size, in gigabytes (GB).
Type: Integer
Required: No
