# SubscriptionError
<a name="API_SubscriptionError"></a>

Information about an error that occurred during the subscription process.

## Contents
<a name="API_SubscriptionError_Contents"></a>

 ** errorMessage **   <a name="odb-Type-SubscriptionError-errorMessage"></a>
A human-readable message that describes the subscription error.
Type: String
Required: No
