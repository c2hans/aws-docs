# GiMinorVersionSummary
<a name="API_GiMinorVersionSummary"></a>

Summary information about an Oracle Grid Infrastructure (GI) minor version.

## Contents
<a name="API_GiMinorVersionSummary_Contents"></a>

 ** version **   <a name="odb-Type-GiMinorVersionSummary-version"></a>
The GI minor version.
Type: String
Required: Yes

 ** gridImageId **   <a name="odb-Type-GiMinorVersionSummary-gridImageId"></a>
The Grid Infrastructure software image ID for this minor version.
Type: String
Required: No
