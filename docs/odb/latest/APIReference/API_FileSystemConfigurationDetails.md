# FileSystemConfigurationDetails
<a name="API_FileSystemConfigurationDetails"></a>

The configuration of a file system on a VM cluster.

## Contents
<a name="API_FileSystemConfigurationDetails_Contents"></a>

 ** fileSystemSizeInGBs **   <a name="odb-Type-FileSystemConfigurationDetails-fileSystemSizeInGBs"></a>
The size of the file system, in gigabytes (GB).
Type: Integer
Required: No

 ** mountPoint **   <a name="odb-Type-FileSystemConfigurationDetails-mountPoint"></a>
The mount point of the file system.
Type: String
Required: No
