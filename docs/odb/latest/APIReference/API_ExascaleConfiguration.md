# ExascaleConfiguration
<a name="API_ExascaleConfiguration"></a>

The Exascale storage configuration of an Exadata infrastructure.

## Contents
<a name="API_ExascaleConfiguration_Contents"></a>

 ** availableStorageSizeInGBs **   <a name="odb-Type-ExascaleConfiguration-availableStorageSizeInGBs"></a>
The amount of Exascale storage, in gigabytes (GB), that's available on the Exadata infrastructure.
Type: Integer
Required: No

 ** availableVmStorageSizeInGBs **   <a name="odb-Type-ExascaleConfiguration-availableVmStorageSizeInGBs"></a>
The amount of Exascale VM storage, in gigabytes (GB), that's available on the Exadata infrastructure.
Type: Integer
Required: No

 ** totalStorageSizeInGBs **   <a name="odb-Type-ExascaleConfiguration-totalStorageSizeInGBs"></a>
The total amount of Exascale storage, in gigabytes (GB), configured on the Exadata infrastructure.
Type: Integer
Required: No

 ** totalVmStorageSizeInGBs **   <a name="odb-Type-ExascaleConfiguration-totalVmStorageSizeInGBs"></a>
The total amount of Exascale VM storage, in gigabytes (GB), on the Exadata infrastructure. VM clusters use Exascale VM storage for their VM file systems and VM backups.
Type: Integer
Required: No
