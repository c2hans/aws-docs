# AutonomousDatabaseConnectionUrls
<a name="API_AutonomousDatabaseConnectionUrls"></a>

The connection URLs for accessing tools and services for an Autonomous Database.

## Contents
<a name="API_AutonomousDatabaseConnectionUrls_Contents"></a>

 ** apexUrl **   <a name="odb-Type-AutonomousDatabaseConnectionUrls-apexUrl"></a>
The URL for accessing Oracle Application Express (APEX) for the Autonomous Database.
Type: String
Required: No

 ** databaseTransformsUrl **   <a name="odb-Type-AutonomousDatabaseConnectionUrls-databaseTransformsUrl"></a>
The URL for accessing Oracle Database Transforms for the Autonomous Database.
Type: String
Required: No

 ** graphStudioUrl **   <a name="odb-Type-AutonomousDatabaseConnectionUrls-graphStudioUrl"></a>
The URL for accessing Oracle Graph Studio for the Autonomous Database.
Type: String
Required: No

 ** machineLearningNotebookUrl **   <a name="odb-Type-AutonomousDatabaseConnectionUrls-machineLearningNotebookUrl"></a>
The URL for accessing the Oracle Machine Learning notebook for the Autonomous Database.
Type: String
Required: No

 ** machineLearningUserManagementUrl **   <a name="odb-Type-AutonomousDatabaseConnectionUrls-machineLearningUserManagementUrl"></a>
The URL for accessing Oracle Machine Learning user management for the Autonomous Database.
Type: String
Required: No

 ** mongoDbUrl **   <a name="odb-Type-AutonomousDatabaseConnectionUrls-mongoDbUrl"></a>
The URL for accessing the MongoDB API for the Autonomous Database.
Type: String
Required: No

 ** ordsUrl **   <a name="odb-Type-AutonomousDatabaseConnectionUrls-ordsUrl"></a>
The URL for accessing Oracle REST Data Services (ORDS) for the Autonomous Database.
Type: String
Required: No

 ** spatialStudioUrl **   <a name="odb-Type-AutonomousDatabaseConnectionUrls-spatialStudioUrl"></a>
The URL for accessing Oracle Spatial Studio for the Autonomous Database.
Type: String
Required: No

 ** sqlDevWebUrl **   <a name="odb-Type-AutonomousDatabaseConnectionUrls-sqlDevWebUrl"></a>
The URL for accessing Oracle SQL Developer Web for the Autonomous Database.
Type: String
Required: No
