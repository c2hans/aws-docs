# VirtualNodeStatus
<a name="API_VirtualNodeStatus"></a>

An object that represents the current status of the virtual node.

## Contents
<a name="API_VirtualNodeStatus_Contents"></a>

 ** status **   <a name="appmesh-Type-VirtualNodeStatus-status"></a>
The current status of the virtual node.
Type: String
Valid Values: `ACTIVE | INACTIVE | DELETED`
Required: Yes
