# VirtualGatewayTlsValidationContextFileTrust
<a name="API_VirtualGatewayTlsValidationContextFileTrust"></a>

An object that represents a Transport Layer Security (TLS) validation context trust for a local file.

## Contents
<a name="API_VirtualGatewayTlsValidationContextFileTrust_Contents"></a>

 ** certificateChain **   <a name="appmesh-Type-VirtualGatewayTlsValidationContextFileTrust-certificateChain"></a>
The certificate trust chain for a certificate stored on the file system of the virtual node that the proxy is running on.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: Yes
