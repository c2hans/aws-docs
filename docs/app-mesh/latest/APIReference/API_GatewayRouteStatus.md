# GatewayRouteStatus
<a name="API_GatewayRouteStatus"></a>

An object that represents the current status of a gateway route.

## Contents
<a name="API_GatewayRouteStatus_Contents"></a>

 ** status **   <a name="appmesh-Type-GatewayRouteStatus-status"></a>
The current status for the gateway route.
Type: String
Valid Values: `ACTIVE | INACTIVE | DELETED`
Required: Yes
