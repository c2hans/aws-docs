# VirtualRouterStatus
<a name="API_VirtualRouterStatus"></a>

An object that represents the status of a virtual router.

## Contents
<a name="API_VirtualRouterStatus_Contents"></a>

 ** status **   <a name="appmesh-Type-VirtualRouterStatus-status"></a>
The current status of the virtual router.
Type: String
Valid Values: `ACTIVE | INACTIVE | DELETED`
Required: Yes
