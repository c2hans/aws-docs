# Tracking when you use AWS Application Migration Service to migrate without performing discovery
<a name="updates-tracking-wt-no-disco"></a>

If you did not perform discovery with an AWS discovery tool, then Migration Hub will add to the servers list a server that corresponds to the migration update, and automatically map the update to the server. You can group servers as applications and then start tracking the migration on the application’s details page in the **Migrate** section of the console. For more information, see [Step 3: Group servers as applications](gs-new-user-migration.md#migrate-wt-group-as-applications) and [Track the status of your migrations in AWS Migration Hub](migrate-wt-track.md).
