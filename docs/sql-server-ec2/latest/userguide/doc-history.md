# Document history for the Microsoft SQL Server on Amazon EC2 User Guide

The following table describes the documentation releases for Microsoft SQL Server on Amazon EC2.

| Change | Description | Date |
| --- |--- |--- |
| [EC2 High Availability for SQL Server](https://docs.aws.amazon.com/sql-server-ec2/latest/userguide/sql-high-availability.html) | Amazon EC2 High Availability for SQL Server allows you to configure instances running license-included SQL Server as part of a HA cluster to reduce licensing costs. | November 17, 2025 |
