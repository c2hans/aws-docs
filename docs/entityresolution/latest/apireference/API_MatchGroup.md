# MatchGroup
<a name="API_MatchGroup"></a>

The match group.

## Contents
<a name="API_MatchGroup_Contents"></a>

 ** matchId **   <a name="API-Type-MatchGroup-matchId"></a>
 The match ID.
Type: String
Required: Yes

 ** matchRule **   <a name="API-Type-MatchGroup-matchRule"></a>
 The match rule of the match group.
Type: String
Required: Yes

 ** records **   <a name="API-Type-MatchGroup-records"></a>
 The matched records.
Type: Array of [MatchedRecord](API_MatchedRecord.md) objects
Required: Yes
