# DeletedUniqueId
<a name="API_DeletedUniqueId"></a>

The deleted unique ID.

## Contents
<a name="API_DeletedUniqueId_Contents"></a>

 ** uniqueId **   <a name="API-Type-DeletedUniqueId-uniqueId"></a>
 The unique ID of the deleted item.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 780.
Pattern: `[a-zA-Z_0-9-+=/,]*`
Required: Yes
