# ProviderIdNameSpaceConfiguration
<a name="API_ProviderIdNameSpaceConfiguration"></a>

The provider configuration required for different ID namespace types.

<a name="API_ProviderIdNameSpaceConfiguration_Contents"></a>

Type: String
Required: No

 ** providerSourceConfigurationDefinition **   <a name="API-Type-ProviderIdNameSpaceConfiguration-providerSourceConfigurationDefinition"></a>

Type: JSON value
Required: No

 ** providerTargetConfigurationDefinition **   <a name="API-Type-ProviderIdNameSpaceConfiguration-providerTargetConfigurationDefinition"></a>
