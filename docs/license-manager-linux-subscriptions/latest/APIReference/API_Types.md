# Data Types
<a name="API_Types"></a>

The AWS License Manager Linux Subscriptions API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Filter](API_Filter.md)
+  [Instance](API_Instance.md)
+  [LinuxSubscriptionsDiscoverySettings](API_LinuxSubscriptionsDiscoverySettings.md)
+  [RegisteredSubscriptionProvider](API_RegisteredSubscriptionProvider.md)
+  [Subscription](API_Subscription.md)
