# Customizing AWS Coding Plugin for SAP ABAP
<a name="customizing"></a>

You customize AWS Coding Plugin for SAP ABAP ("Coding Plugin") in two ways: through steering, which shapes what Kiro knows about your organization and your SAP systems, and through the plug-in’s own Eclipse preferences.
