# Pricing
<a name="pricing"></a>

 AWS Coding Plugin for SAP ABAP is offered at no cost. You pay only for your consumption of Kiro credits. For plans, included credits, and overage rates, see [Pricing](https://kiro.dev/pricing/) in the Kiro documentation.
