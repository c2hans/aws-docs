# Document history for the Agent Toolkit for AWS User Guide
<a name="doc-history"></a>

The following table describes the documentation releases for Agent Toolkit for AWS.

| Change | Description | Date |
| --- |--- |--- |
| [Additional AWS Regions](#doc-history) | AWS MCP Server is now available in six additional AWS Regions: US West (Oregon), Asia Pacific (Singapore), Asia Pacific (Sydney), Asia Pacific (Tokyo), Europe (Ireland), and Europe (London). | September 30, 2026 |
| [Serverless capability](#doc-history) | Added documentation for AWS MCP Server capabilities, starting with the serverless capability, which provides read-only observability and troubleshooting for AWS Lambda functions and their connected resources. | August 25, 2026 |
| [OAuth 2.1 authentication support](#doc-history) | Added OAuth 2.1 authentication through AWS Sign-in. OAuth-compatible MCP clients can now connect directly to AWS MCP Server without local proxy software. Added new managed policy `AWSMCPSignInOAuthAccessPolicy` and OAuth condition keys for governance. | July 8, 2026 |
| [AWS CLI support](#doc-history) | The Agent Toolkit for AWS is now available in the AWS CLI. Added documentation for the `aws configure agent-toolkit` setup wizard and the `aws agent-toolkit` commands for installing, updating, removing, listing, and searching AWS skills from the AWS CLI. | June 8, 2026 |
| [Multi-profile support](#doc-history) | You can now configure multiple AWS profiles and switch between them on each tool call. | May 30, 2026 |
| [General availability of the Agent Toolkit for AWS](#doc-history) | The Agent Toolkit for AWS is now generally available, with agent skills, plugins, and rules files. The user guide has been restructured to cover all toolkit components. | April 30, 2026 |
| [Deployment SOPs updates](#doc-history) | Updated Deployment SOPs documentation with `deploy-supabase-app` guidance, and overall improved guidance. | February 18, 2026 |
| [Deployment SOPs](#doc-history) | Added content describing the Deployment SOPs now available in Agent Toolkit for AWS | January 26, 2026 |
| [Initial release](#doc-history) | Initial release of the Agent Toolkit for AWS User Guide | November 30, 2025 |
