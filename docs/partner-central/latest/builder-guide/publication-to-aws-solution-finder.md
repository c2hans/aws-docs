# Publish your solution to AWS Partner Solution Finder (PSF)
<a name="publication-to-aws-solution-finder"></a>

Your solution is published to the AWS Solution Finder automatically after the following prerequisites are met:

| Solution type | Prerequisites |
| --- | --- |
| Software Product, Managed Service, Consulting Service, Professional Service |  [See the AWS documentation website for more details](http://docs.aws.amazon.com/partner-central/latest/builder-guide/publication-to-aws-solution-finder.html)  |
| Hardware Product, Communications Product, Value-Added Resale AWS Service, Training Service, Distribution Service |  [See the AWS documentation website for more details](http://docs.aws.amazon.com/partner-central/latest/builder-guide/publication-to-aws-solution-finder.html)  |
