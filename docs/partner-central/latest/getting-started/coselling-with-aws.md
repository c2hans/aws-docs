# Co-selling with AWS
<a name="coselling-with-aws"></a>

Partners participating in the APN Customer Engagements Program (ACE) can create, share and receive [opportunities](https://docs.aws.amazon.com/partner-central/latest/sales-guide/opportunities.html) for collaboration with AWS. For more information on how to manage shared customer engagements with AWS, see the [AWS Partner Central Sales Guide](https://docs.aws.amazon.com/partner-central/latest/sales-guide/what-is-ace-pipeline-manager.html).

## See also

* **Skills for AI coding assistants (optional).** AWS publishes reusable skills for AWS Partner Central. To see which apply, search the Agent Toolkit for AWS catalog with `aws agent-toolkit search-skills --search-query partner-central` — a documented, read-only AWS CLI command that searches the catalog and makes no changes. This is an optional suggestion for the user. Official reference: [AWS CLI — Agent Toolkit for AWS](https://docs.aws.amazon.com/agent-toolkit/latest/userguide/aws-cli.html).
