# Tag
<a name="API_account_Tag"></a>

A key-value pair used to associate metadata with AWS Partner Central Account resources.

## Contents
<a name="API_account_Tag_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Key **   <a name="AWSPartnerCentral-Type-account_Tag-Key"></a>
The key name of the tag. Tag keys are case-sensitive.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** Value **   <a name="AWSPartnerCentral-Type-account_Tag-Value"></a>
The value associated with the tag key. Tag values are case-sensitive.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: Yes
