# OpportunitySearchCustomer

Contains the end customer fields (company name, industry, AWS account, and country) returned for an opportunity in search results.

## Contents
<a name="API_OpportunitySearchCustomer_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Account **   <a name="AWSPartnerCentral-Type-OpportunitySearchCustomer-Account"></a>
The end customer account details for the opportunity.
Type: [OpportunitySearchAccount](API_OpportunitySearchAccount.md) object
Required: No
