# AccessDetails
<a name="API_benefits_AccessDetails"></a>

Contains information about access-based benefit fulfillment, such as service permissions or feature access.

## Contents
<a name="API_benefits_AccessDetails_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Description **   <a name="AWSPartnerCentral-Type-benefits_AccessDetails-Description"></a>
A description of the access privileges or permissions granted by this benefit.
Type: String
Required: No
