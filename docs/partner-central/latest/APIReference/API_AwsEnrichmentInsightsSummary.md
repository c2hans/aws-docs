# AwsEnrichmentInsightsSummary

Computed values about the matched customer for an account in search results. It carries the fields that you can sort and filter by.

## Contents
<a name="API_AwsEnrichmentInsightsSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** MarketplaceEngagementScore **   <a name="AWSPartnerCentral-Type-AwsEnrichmentInsightsSummary-MarketplaceEngagementScore"></a>
The level of engagement of the customer with AWS Marketplace. Valid values are `High`, `Medium`, and `Low`.
Type: String
Required: No

 ** SolutionCategory **   <a name="AWSPartnerCentral-Type-AwsEnrichmentInsightsSummary-SolutionCategory"></a>
The category of the solution that AWS recommends for the customer.
Type: String
Required: No

 ** SolutionScore **   <a name="AWSPartnerCentral-Type-AwsEnrichmentInsightsSummary-SolutionScore"></a>
The likelihood that the customer adopts the recommended solution. Valid values are `High`, `Medium`, and `Low`.
Type: String
Required: No
