# EngagementSort
<a name="API_EngagementSort"></a>

Specifies the sorting parameters for listing Engagements.

## Contents
<a name="API_EngagementSort_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SortBy **   <a name="AWSPartnerCentral-Type-EngagementSort-SortBy"></a>
The field by which to sort the results.
Type: String
Valid Values: `CreatedDate`
Required: Yes

 ** SortOrder **   <a name="AWSPartnerCentral-Type-EngagementSort-SortOrder"></a>
The order in which to sort the results.
Type: String
Valid Values: `ASCENDING | DESCENDING`
Required: Yes
