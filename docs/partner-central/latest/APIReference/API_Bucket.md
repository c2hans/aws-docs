# Bucket

One group in an aggregation result. It includes the field values that define the group and the number of customer accounts in it.

## Contents
<a name="API_Bucket_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Count **   <a name="AWSPartnerCentral-Type-Bucket-Count"></a>
The number of customer accounts in this group.
Type: Integer
Required: Yes

 ** Values **   <a name="AWSPartnerCentral-Type-Bucket-Values"></a>
The field value that defines this group.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 2 items.
Required: Yes
