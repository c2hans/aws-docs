# AwsEnrichment

The information that we provide about the matched customer, in addition to the details that you supplied. Present only when `EnrichmentStatus` is `ENRICHED`.

## Contents
<a name="API_AwsEnrichment_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Customer **   <a name="AWSPartnerCentral-Type-AwsEnrichment-Customer"></a>
Information about the customer that AWS provides.
Type: [AwsEnrichmentCustomer](API_AwsEnrichmentCustomer.md) object
Required: No

 ** Insights **   <a name="AWSPartnerCentral-Type-AwsEnrichment-Insights"></a>
Insights that AWS computes for the customer.
Type: [AwsEnrichmentInsights](API_AwsEnrichmentInsights.md) object
Required: No
