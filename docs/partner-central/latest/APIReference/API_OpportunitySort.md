# OpportunitySort
<a name="API_OpportunitySort"></a>

Object that configures response sorting.

## Contents
<a name="API_OpportunitySort_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SortBy **   <a name="AWSPartnerCentral-Type-OpportunitySort-SortBy"></a>
Field name to sort by.
Type: String
Valid Values: `LastModifiedDate | Identifier | CustomerCompanyName | CreatedDate | TargetCloseDate`
Required: Yes

 ** SortOrder **   <a name="AWSPartnerCentral-Type-OpportunitySort-SortOrder"></a>
Sort order.
Default: `Descending`
Type: String
Valid Values: `ASCENDING | DESCENDING`
Required: Yes
