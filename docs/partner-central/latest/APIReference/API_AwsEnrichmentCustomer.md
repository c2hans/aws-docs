# AwsEnrichmentCustomer

Recorded facts that we hold about the matched customer, such as the industry, sector, company size, and region.

## Contents
<a name="API_AwsEnrichmentCustomer_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AccountName **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-AccountName"></a>
The name of the customer, as recorded by AWS.
Type: String
Required: No

 ** CompanySize **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-CompanySize"></a>
The size of the customer company.
Type: String
Required: No

 ** Country **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-Country"></a>
The country of the customer.
Type: String
Required: No

 ** CustomerAccountPlanningQualification **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-CustomerAccountPlanningQualification"></a>
Indicates whether the customer qualifies for account planning with AWS.
Type: String
Required: No

 ** EligiblePrograms **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-EligiblePrograms"></a>
The AWS programs that the customer is eligible for.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 50 items.
Required: No

 ** Geo **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-Geo"></a>
The geographic area of the customer, as classified by AWS.
Type: String
Required: No

 ** Industry **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-Industry"></a>
The industry of the customer, as classified by AWS.
Type: String
Required: No

 ** Region **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-Region"></a>
The region of the customer, as classified by AWS.
Type: String
Required: No

 ** Sector **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-Sector"></a>
The sector of the customer, as classified by AWS.
Type: String
Required: No

 ** Segment **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-Segment"></a>
The market segment of the customer, as classified by AWS.
Type: String
Required: No

 ** SubIndustry **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-SubIndustry"></a>
The sub-industry of the customer, as classified by AWS.
Type: String
Required: No

 ** SubRegion **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomer-SubRegion"></a>
The sub-region of the customer, as classified by AWS.
Type: String
Required: No
