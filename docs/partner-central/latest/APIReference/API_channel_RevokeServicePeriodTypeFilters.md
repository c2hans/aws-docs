# RevokeServicePeriodTypeFilters
<a name="API_channel_RevokeServicePeriodTypeFilters"></a>

Filters specific to revoke service period handshakes.

## Contents
<a name="API_channel_RevokeServicePeriodTypeFilters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** servicePeriodTypes **   <a name="AWSPartnerCentral-Type-channel_RevokeServicePeriodTypeFilters-servicePeriodTypes"></a>
Filter by service period types.
Type: Array of strings
Valid Values: `MINIMUM_NOTICE_PERIOD | FIXED_COMMITMENT_PERIOD`
Required: No
