# AwsProductOptimization
<a name="API_AwsProductOptimization"></a>

Specific optimization strategies partners can implement to reduce costs.

## Contents
<a name="API_AwsProductOptimization_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Description **   <a name="AWSPartnerCentral-Type-AwsProductOptimization-Description"></a>
Human-readable explanation of the optimization strategy.
Type: String
Required: Yes

 ** SavingsAmount **   <a name="AWSPartnerCentral-Type-AwsProductOptimization-SavingsAmount"></a>
Quantified cost savings achievable by implementing this optimization.
Type: String
Pattern: `(0|([1-9][0-9]{0,30}))(\.[0-9]{0,2})?`
Required: Yes
