# PartnerLedSupport
<a name="API_channel_PartnerLedSupport"></a>

Configuration for partner-led support plans.

## Contents
<a name="API_channel_PartnerLedSupport_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** coverage **   <a name="AWSPartnerCentral-Type-channel_PartnerLedSupport-coverage"></a>
The coverage level for partner-led support.
Type: String
Valid Values: `ENTIRE_ORGANIZATION | MANAGEMENT_ACCOUNT_ONLY`
Required: Yes

 ** tamLocation **   <a name="AWSPartnerCentral-Type-channel_PartnerLedSupport-tamLocation"></a>
The location of the Technical Account Manager (TAM).
Type: String
Required: Yes

 ** provider **   <a name="AWSPartnerCentral-Type-channel_PartnerLedSupport-provider"></a>
The provider of the partner-led support.
Type: String
Valid Values: `DISTRIBUTOR | DISTRIBUTION_SELLER`
Required: No
