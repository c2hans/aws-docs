# OpportunitySearchSort

Configures sorting of the search results.

## Contents
<a name="API_OpportunitySearchSort_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SortBy **   <a name="AWSPartnerCentral-Type-OpportunitySearchSort-SortBy"></a>
The field to sort the results by.
Type: String
Valid Values: `OpportunityId | Stage | ReviewStatus | CustomerCompanyName | LastModifiedDate | TargetCloseDate | CreatedDate | CountryCode | PartnerProjectTitle | OpportunityType | PartnerOpportunityIdentifier | Industry | AwsAccountId | Origin | NextStep | CosellMotion | OpportunityOwner | EngagementScore | EstimatedMrr | Tags | OfferId | OfferSetId | ApnPrograms`
Required: Yes

 ** SortOrder **   <a name="AWSPartnerCentral-Type-OpportunitySearchSort-SortOrder"></a>
The direction of the sort, either ascending or descending.
Type: String
Valid Values: `ASCENDING | DESCENDING`
Required: Yes
