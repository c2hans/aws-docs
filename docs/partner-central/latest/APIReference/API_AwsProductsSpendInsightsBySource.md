# AwsProductsSpendInsightsBySource
<a name="API_AwsProductsSpendInsightsBySource"></a>

Source-separated spend insights that provide independent analysis for AWS recommendations and partner estimates.

## Contents
<a name="API_AwsProductsSpendInsightsBySource_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AWS **   <a name="AWSPartnerCentral-Type-AwsProductsSpendInsightsBySource-AWS"></a>
AI-generated insights including recommended products from AWS.
Type: [AwsProductInsights](API_AwsProductInsights.md) object
Required: No

 ** Partner **   <a name="AWSPartnerCentral-Type-AwsProductsSpendInsightsBySource-Partner"></a>
Partner-sourced insights derived from Pricing Calculator URLs.
Type: [AwsProductInsights](API_AwsProductInsights.md) object
Required: No
