# OpportunitySearchOpportunityQuality

Curated opportunity quality: score only.

## Contents
<a name="API_OpportunitySearchOpportunityQuality_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Score **   <a name="AWSPartnerCentral-Type-OpportunitySearchOpportunityQuality-Score"></a>
A deal quality score (0-100) assigned to the opportunity.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 100.
Required: No
