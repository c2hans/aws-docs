# AwsEnrichmentCustomerSummary

Recorded facts about the matched customer for an account in search results. It carries the fields that you can filter and group by.

## Contents
<a name="API_AwsEnrichmentCustomerSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AccountPlanningQualification **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomerSummary-AccountPlanningQualification"></a>
Indicates whether the customer qualifies for account planning with AWS.
Type: String
Required: No

 ** Country **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomerSummary-Country"></a>
The country of the customer.
Type: String
Required: No

 ** EligiblePrograms **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomerSummary-EligiblePrograms"></a>
The AWS programs that the customer is eligible for.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 50 items.
Required: No

 ** Geo **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomerSummary-Geo"></a>
The geographic area of the customer, as classified by AWS.
Type: String
Required: No

 ** Industry **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomerSummary-Industry"></a>
The industry of the customer, as classified by AWS.
Type: String
Required: No

 ** Segment **   <a name="AWSPartnerCentral-Type-AwsEnrichmentCustomerSummary-Segment"></a>
The market segment of the customer, as classified by AWS.
Type: String
Required: No
