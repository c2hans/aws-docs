# ListRelationshipsSortBase
<a name="API_channel_ListRelationshipsSortBase"></a>

Base sorting configuration for relationships.

## Contents
<a name="API_channel_ListRelationshipsSortBase_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** sortBy **   <a name="AWSPartnerCentral-Type-channel_ListRelationshipsSortBase-sortBy"></a>
The field to sort by.
Type: String
Valid Values: `UpdatedAt`
Required: Yes

 ** sortOrder **   <a name="AWSPartnerCentral-Type-channel_ListRelationshipsSortBase-sortOrder"></a>
The sort order (ascending or descending).
Type: String
Valid Values: `Ascending | Descending`
Required: Yes
