# EngagementGroupSort

Configures sorting of the engagement groups returned by `ListEngagementGroups`.

## Contents
<a name="API_EngagementGroupSort_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SortBy **   <a name="AWSPartnerCentral-Type-EngagementGroupSort-SortBy"></a>
The field to sort the results by.
Type: String
Valid Values: `Count | UpdatedAt`
Required: Yes

 ** SortOrder **   <a name="AWSPartnerCentral-Type-EngagementGroupSort-SortOrder"></a>
The direction of the sort, either ascending or descending.
Type: String
Valid Values: `ASCENDING | DESCENDING`
Required: Yes
