# ManagedServicesAttestationTypeSort

Sorting options specific to managed services attestation channel contracts. Applies only to managed services attestation channel contracts.

## Contents
<a name="API_channel_ManagedServicesAttestationTypeSort_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** sortBy **   <a name="AWSPartnerCentral-Type-channel_ManagedServicesAttestationTypeSort-sortBy"></a>
The field to sort by.
Type: String
Valid Values: `UpdatedAt`
Required: Yes

 ** sortOrder **   <a name="AWSPartnerCentral-Type-channel_ManagedServicesAttestationTypeSort-sortOrder"></a>
The sort order (ascending or descending).
Type: String
Valid Values: `Ascending | Descending`
Required: Yes
