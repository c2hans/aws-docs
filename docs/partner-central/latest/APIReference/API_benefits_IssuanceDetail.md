# IssuanceDetail
<a name="API_benefits_IssuanceDetail"></a>

Represents detailed information about a specific issuance of benefit value.

## Contents
<a name="API_benefits_IssuanceDetail_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** IssuanceAmount **   <a name="AWSPartnerCentral-Type-benefits_IssuanceDetail-IssuanceAmount"></a>
The monetary amount or value that was issued in this specific issuance.
Type: [MonetaryValue](API_benefits_MonetaryValue.md) object
Required: No

 ** IssuanceId **   <a name="AWSPartnerCentral-Type-benefits_IssuanceDetail-IssuanceId"></a>
The unique identifier for this specific issuance.
Type: String
Required: No

 ** IssuedAt **   <a name="AWSPartnerCentral-Type-benefits_IssuanceDetail-IssuedAt"></a>
The timestamp when this specific issuance was processed.
Type: Timestamp
Required: No
