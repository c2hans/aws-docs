# NextStepsHistory
<a name="API_NextStepsHistory"></a>

Read-only; shows the last 50 values and change dates for the `NextSteps` field.

## Contents
<a name="API_NextStepsHistory_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Time **   <a name="AWSPartnerCentral-Type-NextStepsHistory-Time"></a>
Indicates the step execution time.
Type: Timestamp
Required: Yes

 ** Value **   <a name="AWSPartnerCentral-Type-NextStepsHistory-Value"></a>
Indicates the step's execution details.
Type: String
Required: Yes
