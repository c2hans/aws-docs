# RevenueShareProductAccountSummary

A per-type count of the AWS accounts associated with an AWS Marketplace product.

## Contents
<a name="API_prm_RevenueShareProductAccountSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AccountType **   <a name="AWSPartnerCentral-Type-prm_RevenueShareProductAccountSummary-AccountType"></a>
The type of AWS account list.
Type: String
Valid Values: `DEPLOYMENT | ORGANIZATION`
Required: Yes

 ** Count **   <a name="AWSPartnerCentral-Type-prm_RevenueShareProductAccountSummary-Count"></a>
The number of AWS accounts of this type.
Type: Integer
Valid Range: Minimum value of 0.
Required: Yes
