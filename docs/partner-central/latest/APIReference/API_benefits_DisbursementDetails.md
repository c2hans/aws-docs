# DisbursementDetails
<a name="API_benefits_DisbursementDetails"></a>

Contains information about disbursement-based benefit fulfillment, such as direct payments or reimbursements.

## Contents
<a name="API_benefits_DisbursementDetails_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DisbursedAmount **   <a name="AWSPartnerCentral-Type-benefits_DisbursementDetails-DisbursedAmount"></a>
The total amount that has been disbursed for this benefit allocation.
Type: [MonetaryValue](API_benefits_MonetaryValue.md) object
Required: No

 ** IssuanceDetails **   <a name="AWSPartnerCentral-Type-benefits_DisbursementDetails-IssuanceDetails"></a>
Detailed information about how the disbursement was issued and processed.
Type: [IssuanceDetail](API_benefits_IssuanceDetail.md) object
Required: No
