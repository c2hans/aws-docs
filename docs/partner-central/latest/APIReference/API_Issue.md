# Issue

An issue found with a customer account. It includes the severity, a machine-readable code, and a description.

## Contents
<a name="API_Issue_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Code **   <a name="AWSPartnerCentral-Type-Issue-Code"></a>
A code that identifies the type of issue.
Type: String
Required: No

 ** Message **   <a name="AWSPartnerCentral-Type-Issue-Message"></a>
A description of the issue.
Type: String
Required: No

 ** Severity **   <a name="AWSPartnerCentral-Type-Issue-Severity"></a>
The severity of the issue.
Type: String
Required: No
