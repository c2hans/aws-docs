# InvitationProspectingResultAws
<a name="API_InvitationProspectingResultAws"></a>

A subset of prospecting result data visible to invitation receivers. It includes customer account details and AI-generated insights.

## Contents
<a name="API_InvitationProspectingResultAws_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Customer **   <a name="AWSPartnerCentral-Type-InvitationProspectingResultAws-Customer"></a>
The prospected customer account details, including geographic classification, industry segmentation, company size, and program eligibility.
Type: [ProspectingResultCustomer](API_ProspectingResultCustomer.md) object
Required: No

 ** Insights **   <a name="AWSPartnerCentral-Type-InvitationProspectingResultAws-Insights"></a>
The AI-generated insights from the prospecting analysis, including marketplace engagement scoring, solution fit assessments, and solution categorization.
Type: [ProspectingInsights](API_ProspectingInsights.md) object
Required: No
