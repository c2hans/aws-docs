# Amendment
<a name="API_benefits_Amendment"></a>

Represents a specific change to be made to a benefit application field.

## Contents
<a name="API_benefits_Amendment_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FieldPath **   <a name="AWSPartnerCentral-Type-benefits_Amendment-FieldPath"></a>
The JSON path or field identifier specifying which field in the benefit application to modify.
Type: String
Required: Yes

 ** NewValue **   <a name="AWSPartnerCentral-Type-benefits_Amendment-NewValue"></a>
The new value to set for the specified field in the benefit application.
Type: String
Required: Yes
