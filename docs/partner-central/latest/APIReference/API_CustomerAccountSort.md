# CustomerAccountSort

The field to sort customer accounts by, and the sort direction.

## Contents
<a name="API_CustomerAccountSort_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SortBy **   <a name="AWSPartnerCentral-Type-CustomerAccountSort-SortBy"></a>
The field to sort the results by.
Type: String
Valid Values: `COMPANY_NAME | CREATED_DATE | LAST_MODIFIED_DATE | MARKETPLACE_ENGAGEMENT_SCORE | SOLUTION_SCORE`
Required: Yes

 ** SortOrder **   <a name="AWSPartnerCentral-Type-CustomerAccountSort-SortOrder"></a>
The direction of the sort, either ascending or descending.
Type: String
Valid Values: `ASCENDING | DESCENDING`
Required: Yes
