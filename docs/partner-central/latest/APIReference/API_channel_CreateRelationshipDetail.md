# CreateRelationshipDetail
<a name="API_channel_CreateRelationshipDetail"></a>

Contains details about a newly created relationship.

## Contents
<a name="API_channel_CreateRelationshipDetail_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** arn **   <a name="AWSPartnerCentral-Type-channel_CreateRelationshipDetail-arn"></a>
The Amazon Resource Name (ARN) of the created relationship.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1011.
Required: No

 ** id **   <a name="AWSPartnerCentral-Type-channel_CreateRelationshipDetail-id"></a>
The unique identifier of the created relationship.
Type: String
Length Constraints: Fixed length of 16.
Pattern: `rs-[a-z0-9]{13}`
Required: No
