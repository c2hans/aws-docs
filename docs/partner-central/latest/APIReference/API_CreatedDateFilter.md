# CreatedDateFilter
<a name="API_CreatedDateFilter"></a>

Filter for opportunities based on creation date range.

## Contents
<a name="API_CreatedDateFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AfterCreatedDate **   <a name="AWSPartnerCentral-Type-CreatedDateFilter-AfterCreatedDate"></a>
Filter opportunities created after this date.
Type: Timestamp
Required: No

 ** BeforeCreatedDate **   <a name="AWSPartnerCentral-Type-CreatedDateFilter-BeforeCreatedDate"></a>
Filter opportunities created before this date.
Type: Timestamp
Required: No
