# OpportunitySearchTeamMember

An opportunity team member surfaced in search: name and business title only, with no contact details.

## Contents
<a name="API_OpportunitySearchTeamMember_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BusinessTitle **   <a name="AWSPartnerCentral-Type-OpportunitySearchTeamMember-BusinessTitle"></a>
The team member's business title.
Type: String
Pattern: `(?s).{0,80}`
Required: No

 ** FirstName **   <a name="AWSPartnerCentral-Type-OpportunitySearchTeamMember-FirstName"></a>
The team member's first name.
Type: String
Pattern: `(?s).{0,80}`
Required: No

 ** LastName **   <a name="AWSPartnerCentral-Type-OpportunitySearchTeamMember-LastName"></a>
The team member's last name.
Type: String
Pattern: `(?s).{0,80}`
Required: No
