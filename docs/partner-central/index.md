# AWS Partner Central Documentation

AWS Partner Central is a portal for AWS Partners to manage their AWS Partner Network membership. Access partner benefits, programs, training, and resources to build, market, sell, and grow with AWS.

## Partner Central

- [Getting Started](/partner-central/latest/getting-started/): Describes how to get started with AWS Partner Central, including registration, onboarding, and navigation.
- [Builder Guide](/partner-central/latest/builder-guide/): Describes how to build, list, and validate products and services.
- [Sales Guide](/partner-central/latest/sales-guide/): Describes how to manage qualified leads and cosell opportunities.
- [Developer Guide](/partner-central/latest/developer-guide/): Provides developer-focused information about using the AWS Partner Central API, including making requests, authentication, signing requests, code examples, and error handling.
- [API Reference](/partner-central/latest/APIReference/): Describes the API operations for AWS Partner Central.

## Integrations

Integrations enable partners to perform both sell and cosell motions with AWS using familiar tools.

- [Partner CRM Integrations](/partner-central/latest/crm/): Describes how AWS Partners can build CRM integrations using APIs.
- [Partner Revenue Measurement](/PRM/latest/aws-prm-onboarding-guide/): Describes how AWS Partners can gain visibility into how their solutions impact AWS service consumption.
