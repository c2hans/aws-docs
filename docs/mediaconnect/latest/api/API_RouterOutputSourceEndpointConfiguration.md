# RouterOutputSourceEndpointConfiguration
<a name="API_RouterOutputSourceEndpointConfiguration"></a>

The configuration settings for a source endpoint that represents a router output.

## Contents
<a name="API_RouterOutputSourceEndpointConfiguration_Contents"></a>

 ** routerOutputArn **   <a name="mediaconnect-Type-RouterOutputSourceEndpointConfiguration-routerOutputArn"></a>
The Amazon Resource Name (ARN) of the router output that the source endpoint represents.
Type: String
Pattern: `arn:(aws[a-zA-Z-]*):mediaconnect:[a-z0-9-]+:[0-9]{12}:routerOutput:[a-z0-9]{12}`
Required: Yes
