# RouterOutputProcessors
<a name="API_RouterOutputProcessors"></a>

The processor settings for a router output. For more information, see [Using MediaConnect processors](https://docs.aws.amazon.com/mediaconnect/latest/ug/using-mediaconnect-processors.html) in the * AWS Elemental MediaConnect User Guide*.

## Contents
<a name="API_RouterOutputProcessors_Contents"></a>

 ** singleProgramTransportStreamPidMap **   <a name="mediaconnect-Type-RouterOutputProcessors-singleProgramTransportStreamPidMap"></a>
The configuration settings for remapping the identification numbers of elementary streams and program identifiers of a single-program transport stream.
Type: [SingleProgramTransportStreamPidMapConfiguration](API_SingleProgramTransportStreamPidMapConfiguration.md) object
Required: No
