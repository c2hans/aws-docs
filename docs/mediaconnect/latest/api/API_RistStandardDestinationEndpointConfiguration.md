# RistStandardDestinationEndpointConfiguration
<a name="API_RistStandardDestinationEndpointConfiguration"></a>

The configuration settings for a destination endpoint that uses the RIST protocol.

## Contents
<a name="API_RistStandardDestinationEndpointConfiguration_Contents"></a>

 ** destinationAddress **   <a name="mediaconnect-Type-RistStandardDestinationEndpointConfiguration-destinationAddress"></a>
The IP address on which the destination endpoint receives content.
Type: String
Required: Yes

 ** destinationIngestPort **   <a name="mediaconnect-Type-RistStandardDestinationEndpointConfiguration-destinationIngestPort"></a>
The port on which the destination endpoint receives content. The valid range is 1024 to 65531.
Type: Integer
Valid Range: Minimum value of 1024. Maximum value of 65531.
Required: Yes
