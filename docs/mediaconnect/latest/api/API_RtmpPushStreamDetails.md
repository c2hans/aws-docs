# RtmpPushStreamDetails
<a name="API_RtmpPushStreamDetails"></a>

Configuration details for an RTMP (Real-Time Messaging Protocol) router input stream, including the application and stream names.

## Contents
<a name="API_RtmpPushStreamDetails_Contents"></a>

 ** applicationName **   <a name="mediaconnect-Type-RtmpPushStreamDetails-applicationName"></a>
The name of the RTMP application.
Type: String
Required: Yes

 ** streamName **   <a name="mediaconnect-Type-RtmpPushStreamDetails-streamName"></a>
The name of the RTMP stream.
Type: String
Required: Yes
