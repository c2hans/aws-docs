# ConsumedResourceShareDetails
<a name="API_ConsumedResourceShareDetails"></a>

The cross-account sharing details for an endpoint that another account shares with this account.

## Contents
<a name="API_ConsumedResourceShareDetails_Contents"></a>

 ** ownerAccountId **   <a name="mediaconnect-Type-ConsumedResourceShareDetails-ownerAccountId"></a>
The ID of the AWS account that owns the shared endpoint.
Type: String
Required: Yes
