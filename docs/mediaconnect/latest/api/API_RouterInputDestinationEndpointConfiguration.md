# RouterInputDestinationEndpointConfiguration
<a name="API_RouterInputDestinationEndpointConfiguration"></a>

The configuration settings for a destination endpoint that represents a router input.

## Contents
<a name="API_RouterInputDestinationEndpointConfiguration_Contents"></a>

 ** routerInputArn **   <a name="mediaconnect-Type-RouterInputDestinationEndpointConfiguration-routerInputArn"></a>
The Amazon Resource Name (ARN) of the router input that the destination endpoint represents.
Type: String
Pattern: `arn:(aws[a-zA-Z-]*):mediaconnect:[a-z0-9-]+:[0-9]{12}:routerInput:[a-z0-9]{12}`
Required: Yes
