# ContentQualityAnalysisFeatureConfiguration
<a name="API_ContentQualityAnalysisFeatureConfiguration"></a>

Configures the content quality analysis features for the router input.

## Contents
<a name="API_ContentQualityAnalysisFeatureConfiguration_Contents"></a>

 ** blackFrames **   <a name="mediaconnect-Type-ContentQualityAnalysisFeatureConfiguration-blackFrames"></a>
Settings for black frames detection.
Type: [BlackFramesConfiguration](API_BlackFramesConfiguration.md) object
Required: No

 ** frozenFrames **   <a name="mediaconnect-Type-ContentQualityAnalysisFeatureConfiguration-frozenFrames"></a>
Settings for frozen frames detection.
Type: [FrozenFramesConfiguration](API_FrozenFramesConfiguration.md) object
Required: No

 ** silentAudio **   <a name="mediaconnect-Type-ContentQualityAnalysisFeatureConfiguration-silentAudio"></a>
Settings for silent audio detection.
Type: [SilentAudioConfiguration](API_SilentAudioConfiguration.md) object
Required: No
