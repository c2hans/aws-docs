# PublicDestinationEndpointNetworkingConfigurationAllowRule
<a name="API_PublicDestinationEndpointNetworkingConfigurationAllowRule"></a>

A rule that allows a specific CIDR block to connect to the public destination endpoint.

## Contents
<a name="API_PublicDestinationEndpointNetworkingConfigurationAllowRule_Contents"></a>

 ** cidr **   <a name="mediaconnect-Type-PublicDestinationEndpointNetworkingConfigurationAllowRule-cidr"></a>
The CIDR block that is allowed to connect to the destination endpoint, in CIDR notation.
Type: String
Pattern: `(?:[0-9]{1,3}\.){3}[0-9]{1,3}/([0-9]|[12][0-9]|3[0-2])`
Required: Yes
