# Disabling content quality analysis
<a name="disable-content-quality-analysis"></a>

You can disable the content quality analysis feature without losing your previously configured settings for individual metrics. If you re-enable content quality analysis in the future, your custom thresholds are preserved.

**Topics**
+ [Disabling for flows](disable-content-quality-analysis-flows.md)
+ [Disabling for router inputs](disable-content-quality-analysis-router-inputs.md)
