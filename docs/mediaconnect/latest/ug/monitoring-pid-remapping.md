# Monitoring PID remapping
<a name="monitoring-pid-remapping"></a>

MediaConnect publishes Amazon CloudWatch metrics for router outputs that use PID remapping, such as the number of mapped, dropped, and nulled PIDs. It also raises an alert on the router output when it drops a stream because it can't assign the PID. For more information, see [Router output metrics for PID remapping](monitor-with-cloudwatch-metrics-router-output-health.md#monitor-with-cloudwatch-metrics-router-output-pid-remapping).
