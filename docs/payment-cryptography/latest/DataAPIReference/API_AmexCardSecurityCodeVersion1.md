# AmexCardSecurityCodeVersion1
<a name="API_AmexCardSecurityCodeVersion1"></a>

Card data parameters that are required to generate a Card Security Code (CSC2) for an AMEX payment card.

## Contents
<a name="API_AmexCardSecurityCodeVersion1_Contents"></a>

 ** CardExpiryDate **   <a name="paymentcryptographydata-Type-AmexCardSecurityCodeVersion1-CardExpiryDate"></a>
The expiry date of a payment card.
Type: String
Length Constraints: Fixed length of 4.
Pattern: `[0-9]+`
Required: Yes
