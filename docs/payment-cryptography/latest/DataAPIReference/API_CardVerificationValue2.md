# CardVerificationValue2
<a name="API_CardVerificationValue2"></a>

Card data parameters that are required to verify Card Verification Value (CVV2) for the payment card.

## Contents
<a name="API_CardVerificationValue2_Contents"></a>

 ** CardExpiryDate **   <a name="paymentcryptographydata-Type-CardVerificationValue2-CardExpiryDate"></a>
The expiry date of a payment card.
Type: String
Length Constraints: Fixed length of 4.
Pattern: `[0-9]+`
Required: Yes
