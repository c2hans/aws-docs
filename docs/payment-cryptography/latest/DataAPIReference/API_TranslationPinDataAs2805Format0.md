# TranslationPinDataAs2805Format0
<a name="API_TranslationPinDataAs2805Format0"></a>

Parameters that are required for translation between AS2805 PIN format 0 translation.

## Contents
<a name="API_TranslationPinDataAs2805Format0_Contents"></a>

 ** PrimaryAccountNumber **   <a name="paymentcryptographydata-Type-TranslationPinDataAs2805Format0-PrimaryAccountNumber"></a>
The Primary Account Number (PAN) of the cardholder. A PAN is a unique identifier for a payment credit or debit card and associates the card to a specific account holder.
Type: String
Length Constraints: Minimum length of 12. Maximum length of 19.
Pattern: `[0-9]+`
Required: Yes
