# TranslationPinDataIsoFormat034
<a name="API_TranslationPinDataIsoFormat034"></a>

Parameters that are required for translation between ISO9564 PIN format 0,3,4 translation.

## Contents
<a name="API_TranslationPinDataIsoFormat034_Contents"></a>

 ** PrimaryAccountNumber **   <a name="paymentcryptographydata-Type-TranslationPinDataIsoFormat034-PrimaryAccountNumber"></a>
The Primary Account Number (PAN) of the cardholder. A PAN is a unique identifier for a payment credit or debit card and associates the card to a specific account holder.
Type: String
Length Constraints: Minimum length of 12. Maximum length of 19.
Pattern: `[0-9]+`
Required: Yes
