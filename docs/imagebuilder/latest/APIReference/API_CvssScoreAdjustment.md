# CvssScoreAdjustment
<a name="API_CvssScoreAdjustment"></a>

Details about an adjustment that Amazon Inspector made to the CVSS score for a finding.

## Contents
<a name="API_CvssScoreAdjustment_Contents"></a>

 ** metric **   <a name="imagebuilder-Type-CvssScoreAdjustment-metric"></a>
The metric that Amazon Inspector used to adjust the CVSS score.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No

 ** reason **   <a name="imagebuilder-Type-CvssScoreAdjustment-reason"></a>
The reason for the CVSS score adjustment.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No
