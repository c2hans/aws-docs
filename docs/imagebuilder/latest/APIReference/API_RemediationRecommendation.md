# RemediationRecommendation
<a name="API_RemediationRecommendation"></a>

Details about the recommended course of action to remediate the finding.

## Contents
<a name="API_RemediationRecommendation_Contents"></a>

 ** text **   <a name="imagebuilder-Type-RemediationRecommendation-text"></a>
The recommended course of action to remediate the finding.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No

 ** url **   <a name="imagebuilder-Type-RemediationRecommendation-url"></a>
A link to more information about the recommended remediation for this vulnerability.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No
