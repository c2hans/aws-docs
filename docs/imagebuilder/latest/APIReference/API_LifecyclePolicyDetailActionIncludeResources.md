# LifecyclePolicyDetailActionIncludeResources
<a name="API_LifecyclePolicyDetailActionIncludeResources"></a>

Specifies how the lifecycle policy should apply actions to selected resources.

## Contents
<a name="API_LifecyclePolicyDetailActionIncludeResources_Contents"></a>

 ** amis **   <a name="imagebuilder-Type-LifecyclePolicyDetailActionIncludeResources-amis"></a>
Specifies whether the lifecycle action should apply to distributed AMIs.
Type: Boolean
Required: No

 ** containers **   <a name="imagebuilder-Type-LifecyclePolicyDetailActionIncludeResources-containers"></a>
Specifies whether the lifecycle action should apply to distributed containers.
Type: Boolean
Required: No

 ** snapshots **   <a name="imagebuilder-Type-LifecyclePolicyDetailActionIncludeResources-snapshots"></a>
Specifies whether the lifecycle action should apply to snapshots associated with distributed AMIs.
Type: Boolean
Required: No
