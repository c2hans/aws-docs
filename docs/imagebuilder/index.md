# EC2 Image Builder Documentation

EC2 Image Builder is a fully-managed AWS service that makes it easier to automate the creation, management, and deployment of customized, secure, and up-to-date “golden” server images that are pre-installed and pre-configured with software and settings to meet specific IT standards.

- [EC2 Image Builder User Guide](/imagebuilder/latest/userguide/): Provides a conceptual overview of EC2 Image Builder and includes detailed instructions for how to get started and manage images.
- [EC2 Image Builder API Reference](/imagebuilder/latest/APIReference/): Describes all the API operations for EC2 Image Builder in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
- [EC2 Image Builder CLI Reference](/cli/latest/reference/imagebuilder/index.html): Describes the AWS CLI commands for EC2 Image Builder.
