# DirectorySizeUpdateSettings
<a name="API_DirectorySizeUpdateSettings"></a>

Contains the directory size configuration for update operations.

## Contents
<a name="API_DirectorySizeUpdateSettings_Contents"></a>

 ** DirectorySize **   <a name="DirectoryService-Type-DirectorySizeUpdateSettings-DirectorySize"></a>
The target directory size for the update operation.
Type: String
Valid Values: `Small | Large`
Required: No
