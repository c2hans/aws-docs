# Document history

The following table describes important changes to the *AWS Decision Guides*.

**Document history**

| Change | Description | Date |
| --- | --- | --- |
| Updated monitoring and observability service guide | Updated the AWS Monitoring and Observability decision guide to add Amazon CloudWatch Application Signals as a managed application performance monitoring option, including Transaction Search, Service Events, and Dynamic Instrumentation. Also refreshed Amazon Managed Service for Prometheus guidance and updated AWS X-Ray positioning. | November 20, 2026 |
| Updated CloudTrail or CloudWatch decision guide | Updated the CloudTrail or CloudWatch decision guide: noted that CloudTrail Lake is closed to new customers (existing customers continue) and pivoted the long-term event storage recommendation to Amazon CloudWatch for new workloads; added CloudWatch unified management and analytics, the Log Analytics console, and the Logs Infrequent Access class; and added CloudTrail Insights for data events, data-event aggregation, and Event Coverage. | November 20, 2026 |
| Updated analytics service guide | Updated the Choosing an AWS analytics service decision guide to show that capabilities such as SQL on Amazon S3, Apache Spark, zero-ETL, federated query, stream processing, and Apache Iceberg span multiple services. Added AWS Glue ETL and refreshed the covered services and getting-started resources. | November 19, 2026 |
| Updated generative AI service guide | Updated the Choosing an AWS generative AI service decision guide with the current generative AI lineup: a three-layer framing (assistants, building with Amazon Bedrock, and hosting or customizing models yourself), expanded Amazon Bedrock coverage (model customization, Custom Model Import, cross-Region inference, Knowledge Bases, Guardrails, and Amazon Bedrock AgentCore), Amazon SageMaker AI and SageMaker HyperPod hosting options, and refreshed infrastructure guidance (Trn3 UltraServers, Inf2, and P6 instances). | November 14, 2026 |
| Updated compute service guide | Updated the Choosing an AWS compute service decision guide to present AWS Lambda as three form factors (Event Functions, Web Functions, and MicroVMs) with Lambda Managed Instances as a capacity option, add Amazon EKS Auto Mode and Amazon EKS Hybrid Nodes, AWS Elastic Beanstalk Cluster Mode, single-rack AWS Outposts, Trn3 UltraServers, and Amazon ECS Managed Instances, and add a programming model and isolation criterion. | November 13, 2026 |
| Updated modern application strategy guide | Updated the Choosing a modern application strategy decision guide to refresh AWS App Runner availability guidance and add Amazon ECS Express Mode, AWS Transform for AI-assisted modernization, agentic architecture guidance (Amazon Bedrock AgentCore and the Strands Agents SDK), and AI-augmented development guidance (Kiro). | November 13, 2026 |
| Updated container service guide | Updated the Choosing an AWS container service decision guide to add Amazon EKS Capabilities, Amazon ECS Managed Instances, Amazon ECS native blue/green, linear, and canary deployments, Amazon ECS Service Connect zone-aware routing and Envoy access logs, Amazon EKS Auto Mode enhanced network security and GPU pricing, Fargate 32 vCPU support, and the Amazon ECR Archive storage class. Noted that AWS App Runner is closed to new customers and added Amazon ECS Express Mode. | November 11, 2026 |
| New Choosing a vector database on AWS guide | Added a decision guide to help customers choose an AWS vector database for generative AI workloads across managed RAG services, purpose-built vector search, in-memory vector search, and operational databases with vector search. | October 30, 2026 |
| Updated Choosing an AWS storage service guide | Refreshed the AWS storage decision guide: replaced the end-of-support AWS Snow Family with AWS Data Transfer Terminal as the offline migration path, added new Amazon S3 options (S3 Tables, S3 Vectors, S3 Files, and S3 Express One Zone), added Amazon FSx Intelligent-Tiering and Amazon EFS Archive, and added data residency and sovereignty, sustainability, and modern workloads decision criteria. | October 5, 2026 |
| Updated Lightsail, Elastic Beanstalk, or EC2 guide | Updated the Amazon Lightsail, AWS Elastic Beanstalk, or Amazon EC2 decision guide to add AWS Elastic Beanstalk Cluster Mode (container deployments on Amazon EKS), Amazon Lightsail compute-optimized and memory-optimized instance families, Amazon ECS Express Mode and Amazon EKS Auto Mode, an AWS App Runner end-of-support note, Amazon EC2 Graviton4 families, and AWS Elastic Beanstalk AI-powered environment analysis. | September 29, 2026 |
| Added serverless decision guide | Added a new decision guide: Choosing an AWS serverless service. Covers Lambda (Event Functions and MicroVMs), Fargate, API Gateway (HTTP, REST, and WebSocket APIs), AWS AppSync, Amazon SQS, Amazon SNS, EventBridge, Step Functions, DynamoDB, Amazon S3, Amazon Aurora Serverless, AWS Serverless Application Model, AWS Cloud Development Kit (AWS CDK), CloudWatch, and AWS X-Ray. Content converted from the deprecated AWS Serverless Developer Guide. | September 4, 2026 |
| Updated AWS Fargate or AWS Lambda guide | Updated the Fargate vs Lambda decision guide to reflect current service capabilities including Lambda durable functions, Managed Instances, SnapStart for Python and .NET, Fargate resource limit increases, container restart policies, predictive scaling, hybrid architecture guidance, and cost comparison. | August 21, 2026 |
| Initial publication | Initial publication of the consolidated decision guides reference. | July 31, 2026 |
