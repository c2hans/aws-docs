# Related resources
<a name="related-resources"></a>

To learn more, see these links:
+  [AWS Emulator on GitHub](https://github.com/aws/aws-emulator) – Get the source code.
+  [Product page on the AWS website](https://aws.amazon.com/products/developer-tools/emulator/) – Learn what the emulator does. Read answers to common questions.
+  [Releases on GitHub](https://github.com/aws/aws-emulator/releases) – See each release and its fidelity scores.
+  [Issues on GitHub](https://github.com/aws/aws-emulator/issues) – Report a bug, or a case where the emulator doesn’t act like AWS.
+  [aws-emulator-evaluation-suite on GitHub](https://github.com/aws/aws-emulator-evaluation-suite) – Get the fidelity tests and run them yourself.
+  [Agent Toolkit for AWS User Guide](https://docs.aws.amazon.com/agent-toolkit/latest/userguide/aws-cli.html) – Install the `aws-emulator` skill for AI coding agents.
