# Setting Up Captions with AWS Elemental Server
<a name="setting-up-captions"></a>

To include captions in your job, follow these steps in the order listed:

1. [Set the timecode source settings.](set-the-timecode-source-settings.md)

1. [Gather required captions information.](gather-required-captions-information.md)

1. [Choose a supported output captions format.](choose-a-supported-output-captions-format.md)

1. [Create input captions selectors.](create-input-caption-selectors.md)

1. [Set up captions in outputs.](including-captions-in-outputs.md)

For information about the files AWS Elemental Server generates from jobs that have captions in the outputs, see [About Captions Handling in Outputs](caption-handling.md).
