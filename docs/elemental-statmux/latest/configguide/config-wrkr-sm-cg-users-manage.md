# Manage Global Access Features
<a name="config-wrkr-sm-cg-users-manage"></a>

You can set some access features that apply globally to all users on the node.

**To manage access**

1. Log in to the AWS Elemental Statmux web interface using administrator credentials.

1. Go to the **Settings** page and choose **Authentication**.

1. Review the current values for the fields. Make any changes and choose **Save**.
