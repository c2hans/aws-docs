# View User Information
<a name="config-wrkr-sm-cg-users-view"></a>

Each user can log in to the web interface and view their own profile. Go to **Settings** > **User Profile**. The following information is displayed:
+ The features and controls of AWS Elemental Statmux that the user is allowed to use.
+ The user's API key.
