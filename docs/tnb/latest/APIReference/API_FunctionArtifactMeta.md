# FunctionArtifactMeta
<a name="API_FunctionArtifactMeta"></a>

Metadata for function package artifacts.

Artifacts are the contents of the package descriptor file and the state of the package.

## Contents
<a name="API_FunctionArtifactMeta_Contents"></a>

 ** overrides **   <a name="TNB-Type-FunctionArtifactMeta-overrides"></a>
Lists of function package overrides.
Type: Array of [ToscaOverride](API_ToscaOverride.md) objects
Required: No
