# ProblemDetails
<a name="API_ProblemDetails"></a>

Details related to problems with AWS TNB resources.

## Contents
<a name="API_ProblemDetails_Contents"></a>

 ** detail **   <a name="TNB-Type-ProblemDetails-detail"></a>
A human-readable explanation specific to this occurrence of the problem.
Type: String
Required: Yes

 ** title **   <a name="TNB-Type-ProblemDetails-title"></a>
A human-readable title of the problem type.
Type: String
Required: No
