# NetworkArtifactMeta
<a name="API_NetworkArtifactMeta"></a>

Metadata for network package artifacts.

Artifacts are the contents of the package descriptor file and the state of the package.

## Contents
<a name="API_NetworkArtifactMeta_Contents"></a>

 ** overrides **   <a name="TNB-Type-NetworkArtifactMeta-overrides"></a>
Lists network package overrides.
Type: Array of [ToscaOverride](API_ToscaOverride.md) objects
Required: No
