# GetSolInstantiatedVnfInfo
<a name="API_GetSolInstantiatedVnfInfo"></a>

Information about a network function.

A network instance is a single network created in AWS TNB that can be deployed and on which life-cycle operations (like terminate, update, and delete) can be performed.

## Contents
<a name="API_GetSolInstantiatedVnfInfo_Contents"></a>

 ** vnfState **   <a name="TNB-Type-GetSolInstantiatedVnfInfo-vnfState"></a>
State of the network function.
Type: String
Valid Values: `STARTED | STOPPED`
Required: No
