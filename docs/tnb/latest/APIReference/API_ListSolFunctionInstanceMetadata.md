# ListSolFunctionInstanceMetadata
<a name="API_ListSolFunctionInstanceMetadata"></a>

Lists network function instance metadata.

A network function instance is a function in a function package .

## Contents
<a name="API_ListSolFunctionInstanceMetadata_Contents"></a>

 ** createdAt **   <a name="TNB-Type-ListSolFunctionInstanceMetadata-createdAt"></a>
When the network function instance was created.
Type: Timestamp
Required: Yes

 ** lastModified **   <a name="TNB-Type-ListSolFunctionInstanceMetadata-lastModified"></a>
When the network function instance was last modified.
Type: Timestamp
Required: Yes
