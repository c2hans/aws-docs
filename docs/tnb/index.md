# AWS Telco Network Builder Documentation

AWS Telco Network Builder (AWS TNB) is a managed 5G network automation service that enables communication service providers to rapidly deploy and cost-effectively manage their 5G networks on AWS.

- [User Guide](/tnb/latest/ug/): Provides descriptions of AWS TNB concepts and includes instructions to deploy a network function and manage your network using the console and command line interface.

- [API Reference](/tnb/latest/APIReference/): Describes all the AWS TNB API actions to deploy a network function and manage your network.
