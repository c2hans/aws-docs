# AWS IAM Identity Center

IAM Identity Center provides one place where you can create or connect workforce users and centrally manage their access to all of their AWS accounts and applications. Workforce users benefit from a single sign-on experience and can use the AWS access portal to find all their assigned AWS accounts and applications.

- [IAM Identity Center User Guide](/singlesignon/latest/userguide/): Introduces you to IAM Identity Center and helps you set up and centrally manage workforce user access to all of their AWS accounts and applications. Also shows you how to audit and monitor user sign-ins.
- [IAM Identity Center API Reference](/singlesignon/latest/APIReference): Describes the API operations for IAM Identity Center.
- [IAM Identity Center SCIM Implementation Developer Guide](/singlesignon/latest/developerguide): Documents the implementation of the System for Cross-domain Identity Management (SCIM) v2.0 protocol in IAM Identity Center.
- [Identity Store API Reference](/singlesignon/latest/IdentityStoreAPIReference): Describes the API operations for the identity store that IAM Identity Center uses.
- [IAM Identity Center OIDC API Reference](/singlesignon/latest/OIDCAPIReference/): Describes the API operations for the IAM Identity Center OpenID Connect (OIDC) service.
- [IAM Identity Center Access Portal API Reference](/singlesignon/latest/PortalAPIReference/): Describes the API operations for the IAM Identity Center access portal service.
