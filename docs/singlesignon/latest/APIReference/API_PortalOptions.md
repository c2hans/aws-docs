# PortalOptions
<a name="API_PortalOptions"></a>

A structure that describes the options for the access portal associated with an application.

## Contents
<a name="API_PortalOptions_Contents"></a>

 ** SignInOptions **   <a name="singlesignon-Type-PortalOptions-SignInOptions"></a>
A structure that describes the sign-in options for the access portal.
Type: [SignInOptions](API_SignInOptions.md) object
Required: No

 ** Visibility **   <a name="singlesignon-Type-PortalOptions-Visibility"></a>
Indicates whether this application is visible in the access portal.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: No
