# OperationStatusFilter
<a name="API_OperationStatusFilter"></a>

Filters the operation status list based on the passed attribute value.

## Contents
<a name="API_OperationStatusFilter_Contents"></a>

 ** Status **   <a name="singlesignon-Type-OperationStatusFilter-Status"></a>
Filters the list operations result based on the status attribute.
Type: String
Valid Values: `IN_PROGRESS | FAILED | SUCCEEDED`
Required: No
