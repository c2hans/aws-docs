# ListAccountAssignmentsFilter
<a name="API_ListAccountAssignmentsFilter"></a>

A structure that describes a filter for account assignments.

## Contents
<a name="API_ListAccountAssignmentsFilter_Contents"></a>

 ** AccountId **   <a name="singlesignon-Type-ListAccountAssignmentsFilter-AccountId"></a>
The ID number of an AWS account that filters the results in the response.
Type: String
Length Constraints: Fixed length of 12.
Pattern: `\d{12}`
Required: No
