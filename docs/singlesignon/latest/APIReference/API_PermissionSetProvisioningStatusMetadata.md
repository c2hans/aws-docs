# PermissionSetProvisioningStatusMetadata
<a name="API_PermissionSetProvisioningStatusMetadata"></a>

Provides information about the permission set provisioning status.

## Contents
<a name="API_PermissionSetProvisioningStatusMetadata_Contents"></a>

 ** CreatedDate **   <a name="singlesignon-Type-PermissionSetProvisioningStatusMetadata-CreatedDate"></a>
The date that the permission set was created.
Type: Timestamp
Required: No

 ** RequestId **   <a name="singlesignon-Type-PermissionSetProvisioningStatusMetadata-RequestId"></a>
The identifier for tracking the request operation that is generated by the universally unique identifier (UUID) workflow.
Type: String
Length Constraints: Fixed length of 36.
Pattern: `\b[0-9a-f]{8}\b-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-\b[0-9a-f]{12}\b`
Required: No

 ** Status **   <a name="singlesignon-Type-PermissionSetProvisioningStatusMetadata-Status"></a>
The status of the permission set provisioning process.
Type: String
Valid Values: `IN_PROGRESS | FAILED | SUCCEEDED`
Required: No
