# InstanceAccessControlAttributeConfiguration
<a name="API_InstanceAccessControlAttributeConfiguration"></a>

Specifies the attributes to add to your attribute-based access control (ABAC) configuration.

## Contents
<a name="API_InstanceAccessControlAttributeConfiguration_Contents"></a>

 ** AccessControlAttributes **   <a name="singlesignon-Type-InstanceAccessControlAttributeConfiguration-AccessControlAttributes"></a>
Lists the attributes that are configured for ABAC in the specified IAM Identity Center instance.
Type: Array of [AccessControlAttribute](API_AccessControlAttribute.md) objects
Array Members: Minimum number of 0 items. Maximum number of 50 items.
Required: Yes
