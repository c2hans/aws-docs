# ListApplicationAssignmentsFilter
<a name="API_ListApplicationAssignmentsFilter"></a>

A structure that describes a filter for application assignments.

## Contents
<a name="API_ListApplicationAssignmentsFilter_Contents"></a>

 ** ApplicationArn **   <a name="singlesignon-Type-ListApplicationAssignmentsFilter-ApplicationArn"></a>
The ARN of an application.
Type: String
Length Constraints: Minimum length of 10. Maximum length of 1224.
Pattern: `arn:aws(-[a-z]{1,5}){0,3}:sso::\d{12}:application/(sso)?ins-[a-zA-Z0-9-.]{16}/apl-[a-zA-Z0-9]{16}`
Required: No
