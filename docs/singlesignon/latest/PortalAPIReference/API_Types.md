# Data Types
<a name="API_Types"></a>

The AWS IAM Identity Center API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AccountInfo](API_AccountInfo.md)
+  [RoleCredentials](API_RoleCredentials.md)
+  [RoleInfo](API_RoleInfo.md)
