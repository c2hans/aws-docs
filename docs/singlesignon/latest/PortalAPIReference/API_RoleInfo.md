# RoleInfo
<a name="API_RoleInfo"></a>

Provides information about the role that is assigned to the user.

## Contents
<a name="API_RoleInfo_Contents"></a>

 ** accountId **   <a name="singlesignon-Type-RoleInfo-accountId"></a>
The identifier of the AWS account assigned to the user.
Type: String
Required: No

 ** roleName **   <a name="singlesignon-Type-RoleInfo-roleName"></a>
The friendly name of the role that is assigned to the user.
Type: String
Required: No
