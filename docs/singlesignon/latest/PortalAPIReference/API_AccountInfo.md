# AccountInfo
<a name="API_AccountInfo"></a>

Provides information about your AWS account.

## Contents
<a name="API_AccountInfo_Contents"></a>

 ** accountId **   <a name="singlesignon-Type-AccountInfo-accountId"></a>
The identifier of the AWS account that is assigned to the user.
Type: String
Required: No

 ** accountName **   <a name="singlesignon-Type-AccountInfo-accountName"></a>
The display name of the AWS account that is assigned to the user.
Type: String
Required: No

 ** emailAddress **   <a name="singlesignon-Type-AccountInfo-emailAddress"></a>
The email address of the AWS account that is assigned to the user.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 254.
Required: No
