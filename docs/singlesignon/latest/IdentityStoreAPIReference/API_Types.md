# Data Types
<a name="API_Types"></a>

The Identity Store API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Address](API_Address.md)
+  [AlternateIdentifier](API_AlternateIdentifier.md)
+  [AttributeOperation](API_AttributeOperation.md)
+  [Email](API_Email.md)
+  [ExternalId](API_ExternalId.md)
+  [Filter](API_Filter.md)
+  [Group](API_Group.md)
+  [GroupMembership](API_GroupMembership.md)
+  [GroupMembershipExistenceResult](API_GroupMembershipExistenceResult.md)
+  [IdentityStore](API_IdentityStore.md)
+  [MemberId](API_MemberId.md)
+  [Name](API_Name.md)
+  [NetworkConfiguration](API_NetworkConfiguration.md)
+  [NetworkConfigurationDetails](API_NetworkConfigurationDetails.md)
+  [PhoneNumber](API_PhoneNumber.md)
+  [Photo](API_Photo.md)
+  [Role](API_Role.md)
+  [UniqueAttribute](API_UniqueAttribute.md)
+  [User](API_User.md)
