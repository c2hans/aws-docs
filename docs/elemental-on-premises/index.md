# AWS Elemental On-Premises Documentation

Use AWS Elemental appliances and software to encode and package video assets.

## Live Video Encoding

- [AWS Elemental Live](/elemental-live/): Guides for AWS Elemental Live, on-premises software for encoding live streaming content.
- [AWS Elemental Statmux](/elemental-live/): Guides for AWS Elemental Statmux, on-premises software for producing multiplexed live content.
- [AWS Elemental Conductor Live](/elemental-live/): Guides for AWS Elemental Conductor Live, on-premises software for managing a cluster of AWS Elemental Live and AWS Elemental Statmux nodes.

## Quote Confirmation and AWS Elemental Training

- [AWS Elemental Appliances and Software Quote Confirmation](/elemental-appliances-software/): Guide that describes how to use the AWS Management Console to place orders for AWS Elemental products.
- [Training with AWS Skill Builder](https://explore.skillbuilder.aws/learn/external-ecommerce;view=signin?ctldoc-catalog-0=field16-_30): AWS Skill Builder provides training courses for AWS Elemental products and services. Many courses are available in several languages.

## File-Based Video Processing and Video Delivery

- [AWS Elemental Server](/elemental-server/): Guides for AWS Elemental Server, on-premises software for encoding file-based video to produce video on demand (VOD).
- [AWS Elemental Conductor File](/elemental-server/): Guides for AWS Elemental Conductor File, on-premises software for managing a cluster of AWS Elemental Server nodes.
