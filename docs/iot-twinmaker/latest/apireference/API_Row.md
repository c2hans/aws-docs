# Row
<a name="API_Row"></a>

Represents a single row in the query results.

## Contents
<a name="API_Row_Contents"></a>

 ** rowData **   <a name="tm-Type-Row-rowData"></a>
The data in a row of query results.
Type: Array of JSON values
Required: No
