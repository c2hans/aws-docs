# AssetConfiguration
<a name="API_AssetConfiguration"></a>

The configuration for the asset, which can include tags.

## Contents
<a name="API_AssetConfiguration_Contents"></a>

 ** Tags **   <a name="dataexchange-Type-AssetConfiguration-Tags"></a>
The tags to be applied to assets created by the job.
Type: Array of [Tag](API_Tag.md) objects
Array Members: Minimum number of 0 items. Maximum number of 50 items.
Required: No
