# Tag
<a name="API_Tag"></a>

A tag consisting of a key-value pair that can be applied to a resource.

## Contents
<a name="API_Tag_Contents"></a>

 ** Key **   <a name="dataexchange-Type-Tag-Key"></a>
The key of the tag.
Type: String
Required: Yes

 ** Value **   <a name="dataexchange-Type-Tag-Value"></a>
The value of the tag.
Type: String
Required: Yes
