# AssetSourceEntry
<a name="API_AssetSourceEntry"></a>

The source of the assets.

## Contents
<a name="API_AssetSourceEntry_Contents"></a>

 ** Bucket **   <a name="dataexchange-Type-AssetSourceEntry-Bucket"></a>
The Amazon S3 bucket that's part of the source of the asset.
Type: String
Required: Yes

 ** Key **   <a name="dataexchange-Type-AssetSourceEntry-Key"></a>
The name of the object in Amazon S3 for the asset.
Type: String
Required: Yes
