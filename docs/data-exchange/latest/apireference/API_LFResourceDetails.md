# LFResourceDetails
<a name="API_LFResourceDetails"></a>

Details about the AWS Lake Formation resource (Table or Database) included in the AWS Lake Formation data permission.

## Contents
<a name="API_LFResourceDetails_Contents"></a>

 ** Database **   <a name="dataexchange-Type-LFResourceDetails-Database"></a>
Details about the database resource included in the AWS Lake Formation data permission.
Type: [DatabaseLFTagPolicy](API_DatabaseLFTagPolicy.md) object
Required: No

 ** Table **   <a name="dataexchange-Type-LFResourceDetails-Table"></a>
Details about the table resource included in the AWS Lake Formation data permission.
Type: [TableLFTagPolicy](API_TableLFTagPolicy.md) object
Required: No
