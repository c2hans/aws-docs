# OriginDetails
<a name="API_OriginDetails"></a>

<a name="API_OriginDetails_Contents"></a>

 ** DataGrantId **   <a name="dataexchange-Type-OriginDetails-DataGrantId"></a>
The ID of the data grant.
Type: String
Required: No

 ** ProductId **   <a name="dataexchange-Type-OriginDetails-ProductId"></a>
The product ID of the origin of the data set.
Type: String
Required: No
