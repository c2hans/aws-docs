# UpdateCognitoGroupConfiguration
<a name="API_UpdateCognitoGroupConfiguration"></a>

The user group entities from an Amazon Cognito user pool identity source.

## Contents
<a name="API_UpdateCognitoGroupConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** groupEntityType **   <a name="verifiedpermissions-Type-UpdateCognitoGroupConfiguration-groupEntityType"></a>
The name of the schema entity type that's mapped to the user pool group. Defaults to `AWS::CognitoGroup`.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 200.
Pattern: `([_a-zA-Z][_a-zA-Z0-9]*::)*[_a-zA-Z][_a-zA-Z0-9]*`
Required: Yes
