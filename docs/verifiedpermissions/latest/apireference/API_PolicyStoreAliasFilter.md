# PolicyStoreAliasFilter
<a name="API_PolicyStoreAliasFilter"></a>

Contains filters for the `ListPolicyStoreAliases` operation.

## Contents
<a name="API_PolicyStoreAliasFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** policyStoreId **   <a name="verifiedpermissions-Type-PolicyStoreAliasFilter-policyStoreId"></a>
The ID of the policy store to filter by. Only policy store aliases associated with this policy store are returned.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 200.
Pattern: `[a-zA-Z0-9-/_]*`
Required: No
