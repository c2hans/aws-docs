# Amazon Verified Permissions Documentation

Amazon Verified Permissions provides customer applications with the ability to control which users can perform which actions within the application. Verified Permissions uses policies written in the Cedar policy language to describe access using the standard PARX model: principal, actions, resource, and context.

## Amazon Verified Permissions

- [Amazon Verified Permissions User Guide](/verifiedpermissions/latest/userguide/): Introduces you to Amazon Verified Permissions. Explains how to create and manage authorization policies written in the Cedar policy language. Also explains how to create a schema that describes your application's authorization environment. The schema can include the principals, resources, and actions that are part of your application's operational flow. Finally, it explains how to use Verified Permissions from within your application to authorize your users' requests.
- [Amazon Verified Permissions API Reference](/verifiedpermissions/latest/apireference/): Describes the API operations for Amazon Verified Permissions in detail. It provides sample requests, responses, and errors for the supported web service protocols.

## Cedar policy language

- [Cedar Policy Language Reference Guide](https://docs.cedarpolicy.com/): Introduces you to the Cedar policy language. Describes the available language elements and the grammar that you use to combine them into a policy. The Cedar policy language is an open source project hosted on GitHub.
