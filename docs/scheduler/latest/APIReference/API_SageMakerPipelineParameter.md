# SageMakerPipelineParameter
<a name="API_SageMakerPipelineParameter"></a>

The name and value pair of a parameter to use to start execution of a SageMaker Model Building Pipeline.

## Contents
<a name="API_SageMakerPipelineParameter_Contents"></a>

 ** Name **   <a name="scheduler-Type-SageMakerPipelineParameter-Name"></a>
Name of parameter to start execution of a SageMaker Model Building Pipeline.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `[A-Za-z0-9\-_]*`
Required: Yes

 ** Value **   <a name="scheduler-Type-SageMakerPipelineParameter-Value"></a>
Value of parameter to start execution of a SageMaker Model Building Pipeline.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes
