# BorrowConfiguration
<a name="API_BorrowConfiguration"></a>

Details about a borrow configuration.

## Contents
<a name="API_BorrowConfiguration_Contents"></a>

 ** AllowEarlyCheckIn **   <a name="licensemanager-Type-BorrowConfiguration-AllowEarlyCheckIn"></a>
Indicates whether early check-ins are allowed.
Type: Boolean
Required: Yes

 ** MaxTimeToLiveInMinutes **   <a name="licensemanager-Type-BorrowConfiguration-MaxTimeToLiveInMinutes"></a>
Maximum time for the borrow configuration, in minutes.
Type: Integer
Required: Yes
