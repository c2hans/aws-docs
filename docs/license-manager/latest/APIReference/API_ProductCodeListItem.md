# ProductCodeListItem
<a name="API_ProductCodeListItem"></a>

A list item that contains a product code.

## Contents
<a name="API_ProductCodeListItem_Contents"></a>

 ** ProductCodeId **   <a name="licensemanager-Type-ProductCodeListItem-ProductCodeId"></a>
The product code ID
Type: String
Pattern: `^[A-Za-z0-9]{1,25}$`
Required: Yes

 ** ProductCodeType **   <a name="licensemanager-Type-ProductCodeListItem-ProductCodeType"></a>
The product code type
Type: String
Valid Values: `marketplace`
Required: Yes
