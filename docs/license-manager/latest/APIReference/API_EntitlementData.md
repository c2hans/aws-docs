# EntitlementData
<a name="API_EntitlementData"></a>

Data associated with an entitlement resource.

## Contents
<a name="API_EntitlementData_Contents"></a>

 ** Name **   <a name="licensemanager-Type-EntitlementData-Name"></a>
Entitlement data name.
Type: String
Required: Yes

 ** Unit **   <a name="licensemanager-Type-EntitlementData-Unit"></a>
Entitlement data unit.
Type: String

Required: No
