# ManagedResourceSummary
<a name="API_ManagedResourceSummary"></a>

Summary information about a managed resource.

## Contents
<a name="API_ManagedResourceSummary_Contents"></a>

 ** AssociationCount **   <a name="licensemanager-Type-ManagedResourceSummary-AssociationCount"></a>
Number of resources associated with licenses.
Type: Long
Required: No

 ** ResourceType **   <a name="licensemanager-Type-ManagedResourceSummary-ResourceType"></a>
Type of resource associated with a license.
Type: String
Valid Values: `EC2_INSTANCE | EC2_HOST | EC2_AMI | RDS | SYSTEMS_MANAGER_MANAGED_INSTANCE`
Required: No
