# InventoryFilter
<a name="API_InventoryFilter"></a>

An inventory filter.

## Contents
<a name="API_InventoryFilter_Contents"></a>

 ** Condition **   <a name="licensemanager-Type-InventoryFilter-Condition"></a>
Condition of the filter.
Type: String
Valid Values: `EQUALS | NOT_EQUALS | BEGINS_WITH | CONTAINS`
Required: Yes

 ** Name **   <a name="licensemanager-Type-InventoryFilter-Name"></a>
Name of the filter.
Type: String
Required: Yes

 ** Value **   <a name="licensemanager-Type-InventoryFilter-Value"></a>
Value of the filter.
Type: String
Required: No
