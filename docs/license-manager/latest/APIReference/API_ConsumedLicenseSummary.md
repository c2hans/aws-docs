# ConsumedLicenseSummary
<a name="API_ConsumedLicenseSummary"></a>

Details about license consumption.

## Contents
<a name="API_ConsumedLicenseSummary_Contents"></a>

 ** ConsumedLicenses **   <a name="licensemanager-Type-ConsumedLicenseSummary-ConsumedLicenses"></a>
Number of licenses consumed by the resource.
Type: Long
Required: No

 ** ResourceType **   <a name="licensemanager-Type-ConsumedLicenseSummary-ResourceType"></a>
Resource type of the resource consuming a license.
Type: String
Valid Values: `EC2_INSTANCE | EC2_HOST | EC2_AMI | RDS | SYSTEMS_MANAGER_MANAGED_INSTANCE`
Required: No
