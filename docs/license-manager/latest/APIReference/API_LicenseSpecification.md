# LicenseSpecification
<a name="API_LicenseSpecification"></a>

Details for associating a license configuration with a resource.

## Contents
<a name="API_LicenseSpecification_Contents"></a>

 ** LicenseConfigurationArn **   <a name="licensemanager-Type-LicenseSpecification-LicenseConfigurationArn"></a>
Amazon Resource Name (ARN) of the license configuration.
Type: String
Required: Yes

 ** AmiAssociationScope **   <a name="licensemanager-Type-LicenseSpecification-AmiAssociationScope"></a>
Scope of AMI associations. The possible value is `cross-account`.
Type: String
Required: No
