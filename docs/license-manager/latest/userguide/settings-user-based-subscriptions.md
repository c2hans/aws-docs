# User-based subscription settings in License Manager
<a name="settings-user-based-subscriptions"></a>

The following settings are available depending on which products you require for user-based subscriptions.

## AWS Managed Microsoft AD
<a name="settings-managed-ad"></a>

License Manager requires AWS Managed Microsoft AD to be configured before you can work with user-based subscriptions. For more information, see [Use License Manager user-based subscriptions for supported software products](user-based-subscriptions.md).

## Virtual private cloud
<a name="settings-vpc"></a>

License Manager requires your VPC to be configured, in addition to your AWS Managed Microsoft AD, when you use user-based subscriptions with Microsoft Office. For more information, see [Use License Manager user-based subscriptions for supported software products](user-based-subscriptions.md).
