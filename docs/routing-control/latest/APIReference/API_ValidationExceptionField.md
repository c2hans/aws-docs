# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="r53recovery-Type-ValidationExceptionField-message"></a>
Information about the validation exception.
Type: String
Required: Yes

 ** name **   <a name="r53recovery-Type-ValidationExceptionField-name"></a>
The field that had the validation exception.
Type: String
Required: Yes
