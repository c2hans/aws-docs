# Data Types
<a name="API_Types"></a>

The Route53 Recovery Cluster API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [RoutingControl](API_RoutingControl.md)
+  [UpdateRoutingControlStateEntry](API_UpdateRoutingControlStateEntry.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
