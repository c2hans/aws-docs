# Document history for the AWS Toolkit for JetBrains User Guide
<a name="doc-history"></a>

The following table lists key documentation updates for the *AWS Toolkit for JetBrains User Guide*.

For a detailed list of changes to the AWS Toolkit for JetBrains, see the [.changes](https://github.com/aws/aws-toolkit-jetbrains/tree/master/.changes) directory in the [aws/aws-toolkit-jetbrains](https://github.com/aws/aws-toolkit-jetbrains) repository on the GitHub website.

| Change | Description | Date |
| --- |--- |--- |
| [Updating firewalls and gateways to allow access](endpoints.md) | Lists of endpoints and resources that must be allow listed to access all service and features in the AWS Toolkit for JetBrains and Amazon Q for VS Code extensions. | March 20, 2025 |
| [Connect to AWS Authorization flow](#doc-history) | Content updated to reflect changes made to the connect to AWS authorization flow. UI updated to emphasize IAM access management. | April 30, 2024 |
| [Amazon Q JetBrains plugin](#doc-history) | Amazon CodeWhisperer is now a part of Amazon Q and Amazon Q is a separate plugin from the AWS Toolkit for JetBrains. Both the Amazon Q and AWS Toolkit for JetBrains plugins are accessible from the JetBrains Marketplace. | April 30, 2024 |
| [Amazon Virtual Private Cloud](#doc-history) | Updated Amazon CodeCatalyst content to reflect support for Amazon VPC. | February 24, 2024 |
| [CodeCatalyst SSO support](#doc-history) | Updated Amazon CodeCatalyst and Dev Environment content to reflect support for AWS IAM Identity Center. | January 21, 2024 |
| [Amazon CodeWhisperer chat and in-line code suggestions](#doc-history) | Updated content to reflect changes to the Amazon CodeWhisperer and Amazon Q chat release, as well as updates to in-line code suggestions. | November 26, 2023 |
| [AWS Toolkit for JetBrains in the JetBrains Marketplace](#doc-history) | Added links to the AWS Toolkit for JetBrains plugin and JetBrains Marketplace in the set up and installation topics of this user guide. | November 1, 2023 |
