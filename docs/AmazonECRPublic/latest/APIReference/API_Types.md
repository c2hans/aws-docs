# Data Types
<a name="API_Types"></a>

The Amazon Elastic Container Registry Public API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AuthorizationData](API_AuthorizationData.md)
+  [Image](API_Image.md)
+  [ImageDetail](API_ImageDetail.md)
+  [ImageFailure](API_ImageFailure.md)
+  [ImageIdentifier](API_ImageIdentifier.md)
+  [ImageTagDetail](API_ImageTagDetail.md)
+  [Layer](API_Layer.md)
+  [LayerFailure](API_LayerFailure.md)
+  [ReferencedImageDetail](API_ReferencedImageDetail.md)
+  [Registry](API_Registry.md)
+  [RegistryAlias](API_RegistryAlias.md)
+  [RegistryCatalogData](API_RegistryCatalogData.md)
+  [Repository](API_Repository.md)
+  [RepositoryCatalogData](API_RepositoryCatalogData.md)
+  [RepositoryCatalogDataInput](API_RepositoryCatalogDataInput.md)
+  [Tag](API_Tag.md)
