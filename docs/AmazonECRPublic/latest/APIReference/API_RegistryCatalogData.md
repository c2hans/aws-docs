# RegistryCatalogData
<a name="API_RegistryCatalogData"></a>

The metadata for a public registry.

## Contents
<a name="API_RegistryCatalogData_Contents"></a>

 ** displayName **   <a name="ecrpublic-Type-RegistryCatalogData-displayName"></a>
The display name for a public registry. This appears on the Amazon ECR Public Gallery.
Only accounts that have the verified account badge can have a registry display name.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 100.
Required: No
