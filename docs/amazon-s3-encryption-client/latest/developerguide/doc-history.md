# Document history for the Amazon S3 Encryption Client Developer Guide
<a name="doc-history"></a>

The following table describes significant changes to the Amazon S3 Encryption Client Developer Guide. In addition to these major changes, we also update the documentation frequently to improve the descriptions and examples, and to address the feedback that you send to us.

| Change | Description | Date |
| --- |--- |--- |
| [Amazon S3 Encryption Client for Python version 4.*x*](https://docs.aws.amazon.com/amazon-s3-encryption-client/latest/developerguide/python.html) | Added documentation for version 4.x of the Amazon S3 Encryption Client for Python. | April 7, 2026 |
| [Amazon S3 Encryption Client V4 Documentation](#doc-history) | Added V3-to-V4 migration guides for Java and Go, updated Terms and Concepts with key commitment, commitment policy, and instruction file definitions, added AES-GCM with key commitment to supported algorithms. | December 16, 2025 |
| [Amazon S3 Encryption Client for Go version 3.*x*](https://docs.aws.amazon.com/amazon-s3-encryption-client/latest/developerguide/go.html) | Added and updated documentation for version 3.*x* of the Amazon S3 Encryption Client for Go. | November 16, 2023 |
| [Initial release](#doc-history) | The initial release of this documentation describes version 3.*x* of the Amazon S3 Encryption Client for Java. | April 5, 2023 |
