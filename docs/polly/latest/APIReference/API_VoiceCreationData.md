# VoiceCreationData

The audio that you provide to create a custom voice.

## Contents
<a name="API_VoiceCreationData_Contents"></a>

 ** Recordings **   <a name="polly-Type-VoiceCreationData-Recordings"></a>
The recordings of the speaker. Each recording specifies its audio format and its audio source.
Type: Array of [Recording](API_Recording.md) objects
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Required: Yes
