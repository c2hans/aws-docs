# BatchAttachObjectResponse
<a name="API_BatchAttachObjectResponse"></a>

## Contents

 ** attachedObjectIdentifier **   <a name="amazoncds-Type-BatchAttachObjectResponse-attachedObjectIdentifier"></a>
