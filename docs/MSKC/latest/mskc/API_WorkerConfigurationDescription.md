# WorkerConfigurationDescription
<a name="API_WorkerConfigurationDescription"></a>

The description of the worker configuration.

## Contents
<a name="API_WorkerConfigurationDescription_Contents"></a>

 ** revision **   <a name="MSKC-Type-WorkerConfigurationDescription-revision"></a>
The revision of the worker configuration.
Type: Long
Required: No

 ** workerConfigurationArn **   <a name="MSKC-Type-WorkerConfigurationDescription-workerConfigurationArn"></a>
The Amazon Resource Name (ARN) of the worker configuration.
Type: String
Required: No
