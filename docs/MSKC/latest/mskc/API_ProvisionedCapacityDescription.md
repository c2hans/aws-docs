# ProvisionedCapacityDescription
<a name="API_ProvisionedCapacityDescription"></a>

The description of a connector's provisioned capacity.

## Contents
<a name="API_ProvisionedCapacityDescription_Contents"></a>

 ** mcuCount **   <a name="MSKC-Type-ProvisionedCapacityDescription-mcuCount"></a>
The number of microcontroller units (MCUs) allocated to each connector worker. The valid values are 1,2,4,8.
Type: Integer
Required: No

 ** workerCount **   <a name="MSKC-Type-ProvisionedCapacityDescription-workerCount"></a>
The number of workers that are allocated to the connector.
Type: Integer
Required: No
