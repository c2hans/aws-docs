# KafkaClusterClientAuthenticationDescription
<a name="API_KafkaClusterClientAuthenticationDescription"></a>

The client authentication information used in order to authenticate with the Apache Kafka cluster.

## Contents
<a name="API_KafkaClusterClientAuthenticationDescription_Contents"></a>

 ** authenticationType **   <a name="MSKC-Type-KafkaClusterClientAuthenticationDescription-authenticationType"></a>
The type of client authentication used to connect to the Apache Kafka cluster. Value NONE means that no client authentication is used.
Type: String
Valid Values: `NONE | IAM`
Required: No
