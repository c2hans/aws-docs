# KafkaClusterEncryptionInTransit
<a name="API_KafkaClusterEncryptionInTransit"></a>

Details of encryption in transit to the Apache Kafka cluster.

## Contents
<a name="API_KafkaClusterEncryptionInTransit_Contents"></a>

 ** encryptionType **   <a name="MSKC-Type-KafkaClusterEncryptionInTransit-encryptionType"></a>
The type of encryption in transit to the Apache Kafka cluster.
Type: String
Valid Values: `PLAINTEXT | TLS`
Required: Yes
