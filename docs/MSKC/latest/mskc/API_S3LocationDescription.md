# S3LocationDescription
<a name="API_S3LocationDescription"></a>

The description of the location of an object in Amazon S3.

## Contents
<a name="API_S3LocationDescription_Contents"></a>

 ** bucketArn **   <a name="MSKC-Type-S3LocationDescription-bucketArn"></a>
The Amazon Resource Name (ARN) of an S3 bucket.
Type: String
Required: No

 ** fileKey **   <a name="MSKC-Type-S3LocationDescription-fileKey"></a>
The file key for an object in an S3 bucket.
Type: String
Required: No

 ** objectVersion **   <a name="MSKC-Type-S3LocationDescription-objectVersion"></a>
The version of an object in an S3 bucket.
Type: String
Required: No
