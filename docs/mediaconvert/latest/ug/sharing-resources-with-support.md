# Sharing with Support
<a name="sharing-resources-with-support"></a>

When you contact Support for help with a MediaConvert job, and have an active support case, you can share your job's input files securely with the support team. When you create a share request, MediaConvert copies your job's input files to a secure location that only Support can access for troubleshooting.
