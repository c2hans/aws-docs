# AWS Elemental MediaConvert Documentation

AWS Elemental MediaConvert is a service that formats and compresses offline video content for delivery to televisions or connected devices. High-quality video transcoding makes it possible to create on-demand video assets for virtually any device.

- [User Guide](/mediaconvert/latest/ug/what-is.html): Describes the components and features that AWS Elemental MediaConvert provides and how to use them.
- [API Reference](/mediaconvert/latest/apireference/Welcome.html): Describes basic operations of AWS Elemental MediaConvert. Provides schema structure for job settings and detailed descriptions of encoding settings. Includes sample job requests.
- [SPEKE Documentation](/speke/latest/documentation/what-is-speke.html): Describes the Secure Packager and Encoder Key Exchange (SPEKE) DRM Interface. DRM platform key providers and encryptors and packagers of media content use SPEKE for content encryption.
