# Setting up CloudWatch Logs integration for Visual Studio
<a name="cloudwatch-log-setup"></a>

Before you can use the Amazon CloudWatch Logs integration with the AWS Toolkit with Amazon Q, you need an AWS account. You can create a new AWS account from the [AWS sign in](https://console.aws.amazon.com/console/home) site. Most of the CloudWatch Logs features that are available from the AWS Toolkit with Amazon Q are accessible with active AWS credentials. If a particular feature requires additional configuration, the requirements are included in the relevant sections of the [Working with CloudWatch Logs](https://docs.aws.amazon.com/toolkit-for-visual-studio/latest/user-guide/cloudwatch-log-overview.html) guide.

For additional information and options on setting up CloudWatch Logs, see the [Getting set up](https://docs.aws.amazon.com/AmazonCloudWatch/latest/logs/GettingSetup_cwl.html) section of the Amazon CloudWatch Logs guide.
