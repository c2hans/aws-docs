# Downloading the Toolkit for Visual Studio
<a name="downloads"></a>

You can download, install, and set up the Toolkit for Visual Studio through the Visual Studio Marketplace in your IDE. For detailed instructions, see the [Installing the AWS Toolkit for Visual Studio](https://docs.aws.amazon.com/toolkit-for-visual-studio/latest/user-guide/setup.html#install) section in the *Getting started* topic of this User Guide.

## Downloading the Toolkit from the Visual Studio Marketplace
<a name="download"></a>

Download the Toolkit for Visual Studio installation files by navigating to the **[AWS Visual Studio dowloads](http://aws.amazon.com/visualstudio/)** site in your web browser.

## Additional IDE Toolkits from AWS
<a name="toolkits"></a>

In addition to the Toolkit for Visual Studio, AWS also offers IDE Toolkits for VS Code and JetBrains.

**AWS Toolkit for Visual Studio Code links**
+ Follow this link to [Download the AWS Toolkit for Visual Studio Code](https://marketplace.visualstudio.com/items?itemName=AmazonWebServices.aws-toolkit-vscode) from the VS Code Marketplace.
+ To learn more about the AWS Toolkit for Visual Studio Code, see the [AWS Toolkit for Visual Studio Code](https://docs.aws.amazon.com/toolkit-for-vscode/latest/userguide/welcome.html) User Guide.

**AWS Toolkit for JetBrains links**
+ Follow this link to [Download the AWS Toolkit for JetBrains](https://marketplace.visualstudio.com/items?itemName=AmazonWebServices.aws-toolkit-vscode) from the JetBrains Marketplace.
+ To learn more about the AWS Toolkit for JetBrains, see the [AWS Toolkit for JetBrains](https://docs.aws.amazon.com/toolkit-for-vscode/latest/userguide/welcome.html) User Guide.
