# Amazon Q
<a name="amazonq"></a>

## What is Amazon Q
<a name="codewhisperer-intro"></a>

As of April 30th 2024, Amazon CodeWhisperer is now part of Amazon Q Developer, this includes inline code suggestions and security scans.

To learn more about working with Amazon Q Developer in the AWS Toolkit for Visual Studio, see the [Amazon Q Developer in IDEs](https://docs.aws.amazon.com/amazonq/latest/qdeveloper-ug/q-in-IDE.html) topic in the *Amazon Q Developer* User Guide. For detailed information about plans and pricing for Amazon Q, see the [Amazon Q pricing](http://aws.amazon.com/q/pricing) guide.
