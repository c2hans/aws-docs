# TrustedAdvisorCategorySpecificSummary
<a name="API_TrustedAdvisorCategorySpecificSummary"></a>

The container for summary information that relates to the category of the Trusted Advisor check.

## Contents
<a name="API_TrustedAdvisorCategorySpecificSummary_Contents"></a>

 ** costOptimizing **   <a name="AWSSupport-Type-TrustedAdvisorCategorySpecificSummary-costOptimizing"></a>
The summary information about cost savings for a Trusted Advisor check that is in the Cost Optimizing category.
Type: [TrustedAdvisorCostOptimizingSummary](API_TrustedAdvisorCostOptimizingSummary.md) object
