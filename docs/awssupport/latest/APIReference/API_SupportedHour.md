# SupportedHour
<a name="API_SupportedHour"></a>

Time range object with `startTime` and `endTime` range in RFC 3339 format. `'HH:mm:ss.SSS'`.

## Contents
<a name="API_SupportedHour_Contents"></a>

 ** endTime **   <a name="AWSSupport-Type-SupportedHour-endTime"></a>
 End Time. RFC 3339 format `'HH:mm:ss.SSS'`.
Type: String

 ** startTime **   <a name="AWSSupport-Type-SupportedHour-startTime"></a>
 Start Time. RFC 3339 format `'HH:mm:ss.SSS'`.
Type: String
