# DateInterval
<a name="API_DateInterval"></a>

Date and time (UTC) format in RFC 3339 : 'yyyy-MM-dd'T'HH:mm:ss.SSSZZ'.

## Contents
<a name="API_DateInterval_Contents"></a>

 ** endDateTime **   <a name="AWSSupport-Type-DateInterval-endDateTime"></a>
 End Date Time (UTC). RFC 3339 format : 'yyyy-MM-dd'T'HH:mm:ss.SSSZZ'.
Type: String
Length Constraints: Minimum length of 8. Maximum length of 30.

 ** startDateTime **   <a name="AWSSupport-Type-DateInterval-startDateTime"></a>
 A JSON object containing start and date time (UTC). Date and time format is RFC 3339 : 'yyyy-MM-dd'T'HH:mm:ss.SSSZZ'.
Type: String
Length Constraints: Minimum length of 8. Maximum length of 30.
