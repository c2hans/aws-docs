# TrustedAdvisorCostOptimizingSummary
<a name="API_TrustedAdvisorCostOptimizingSummary"></a>

The estimated cost savings that might be realized if the recommended operations are taken.

## Contents
<a name="API_TrustedAdvisorCostOptimizingSummary_Contents"></a>

 ** estimatedMonthlySavings **   <a name="AWSSupport-Type-TrustedAdvisorCostOptimizingSummary-estimatedMonthlySavings"></a>
The estimated monthly savings that might be realized if the recommended operations are taken.
Type: Double

 ** estimatedPercentMonthlySavings **   <a name="AWSSupport-Type-TrustedAdvisorCostOptimizingSummary-estimatedPercentMonthlySavings"></a>
The estimated percentage of savings that might be realized if the recommended operations are taken.
Type: Double
