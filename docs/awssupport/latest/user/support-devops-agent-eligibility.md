# Plan eligibility and credits
<a name="support-devops-agent-eligibility"></a>

You can enable AWS DevOps Agent from the Support Center Console if your account is on one of the following plans:
+ AWS Business Support\+
+ AWS Enterprise Support
+ AWS Unified Operations

Each plan includes a monthly allotment of AWS DevOps Agent usage credits. New activations include a 2-month free credit period. After that, your plan provides ongoing monthly credits toward AWS DevOps Agent usage. To view your current allotment and usage, open the Billing and Cost Management console at [https://console.aws.amazon.com/costmanagement/home#/credits](https://console.aws.amazon.com/costmanagement/home#/credits).
