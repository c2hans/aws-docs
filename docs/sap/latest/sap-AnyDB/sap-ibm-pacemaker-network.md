# Network
<a name="sap-ibm-pacemaker-network"></a>

Ensure that you have your network constructs set up to deploy resources related to SAP NetWeaver. If you haven’t already set up network components like Amazon VPC, subnets, and route tables, you can use AWS Quick Start for VPC to easily deploy scalable VPC architecture. See the [AWS Quick Start for VPC reference deployment guide](https://aws.amazon.com/quickstart/architecture/vpc/).

See the series of [VPC Subnet Zoning Pattern blogs](https://aws.amazon.com/blogs/awsforsap/vpc-subnet-zoning-patterns-for-sap-on-aws/) for VPC patterns that you should consider for SAP applications.
