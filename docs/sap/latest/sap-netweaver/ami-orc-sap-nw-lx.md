# Amazon Machine Image (AMI)
<a name="ami-orc-sap-nw-lx"></a>

You can deploy your SAP Oracle workload on Oracle Enterprise Linux 6.4 or later. A base AMI is required to launch an Amazon EC2 instance. You can create your own AMIs or obtain an Oracle Linux AMI from Oracle. For using AMIs from Oracle, see [Launch an Oracle Linux instance in AWS](https://community.oracle.com/tech/apps-infra/discussion/4417739/launch-an-oracle-linux-instance-in-aws). You can create your own Oracle Enterprise Linux image or use other images available at AWS Marketplace.
