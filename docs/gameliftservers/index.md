# Amazon GameLift Servers Documentation

Amazon GameLift Servers is a fully-managed service with multiplayer game server hosting capabilities. Using the AWS global footprint and game optimized GPU instances, publishers can deploy their game content in minutes, and players can start gaming in seconds without perceivable lag or having to wait for installs. With high-scaling game server and smooth gameplay streaming capabilities, Amazon GameLift Servers helps developers to build, scale, and deliver the world's most demanding games.

## Amazon GameLift Servers

Amazon GameLift Servers provides solutions for hosting session-based multiplayer game servers in the cloud, including a fully managed service for deploying, operating, and scaling game servers. Built on AWS global computing infrastructure, Amazon GameLift Servers helps you deliver high-performance, high-reliability, low-cost game servers while dynamically scaling your resource usage to meet player demand.

- [Amazon GameLift Servers Hosting Developer Guide](/gameliftservers/latest/developerguide/): Learn how to integrate and deploy games for hosting on Amazon GameLift Servers. The service manages game server deployment, operation, and scaling. You can deploy custom-built game servers or use Amazon GameLift Servers Realtime to configure lightweight game servers for your game.
- [Amazon GameLift Servers FlexMatch Developer Guide](/gameliftservers/latest/flexmatchguide/match-intro.html): Learn how to build custom matchmakers using Amazon GameLift Servers FlexMatch. Work with the FlexMatch rules language to fine-tune how players are matched into game sessions. Set up FlexMatch for games that use Amazon GameLift Servers managed hosting, or build a standalone FlexMatch solution to work with other hosting solutions.
- [Amazon GameLift Servers FleetIQ Developer Guide](/gameliftservers/latest/fleetiqguide/gsg-intro.html): Learn how to use FleetIQ with games that are already hosted on Amazon EC2 with Auto Scaling. FleetIQ optimizations for server availabililty make game hosting viable on low-cost Amazon EC2 Spot Instances.
- [Amazon GameLift Servers API Reference](/gameliftservers/latest/apireference): Look up all AWS SDK operations and data types for Amazon GameLift Servers. The API supports all Amazon GameLift Servers features, including managed hosting, Realtime, FleetIQ, and FlexMatch.
- [AWS CLI Reference for Amazon GameLift Servers](/cli/latest/reference/gamelift/index.html): Look up all AWS CLI commands for Amazon GameLift Servers features, including managed hosting, Realtime, FleetIQ, and FlexMatch.
- [SDK References](/gameliftservers/latest/developerguide/reference-intro.html): Look up complete documentation on the SDK for Amazon GameLift Servers. Use the server SDK to set up your custom-built game servers for hosting with Amazon GameLift Servers. Use the Realtime client SDK with your game clients to enable them to interact with Realtime Servers hosted on Amazon GameLift Servers.

## Amazon GameLift Streams

Amazon GameLift Streams helps developers stream games at up to 1080p resolution and 60 frames-per-second to any device with a browser. Using the AWS global footprint and game-optimized GPU instances, publishers can deploy and stream game content in minutes, without modifications, and players can start gaming in seconds without perceivable lag or having to wait for installs.
