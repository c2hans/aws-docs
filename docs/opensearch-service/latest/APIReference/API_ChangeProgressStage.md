# ChangeProgressStage
<a name="API_ChangeProgressStage"></a>

Progress details for each stage of a domain update.

## Contents
<a name="API_ChangeProgressStage_Contents"></a>

 ** Description **   <a name="opensearchservice-Type-ChangeProgressStage-Description"></a>
The description of the stage.
Type: String
Required: No

 ** LastUpdated **   <a name="opensearchservice-Type-ChangeProgressStage-LastUpdated"></a>
The most recent updated timestamp of the stage.
Type: Timestamp
Required: No

 ** Name **   <a name="opensearchservice-Type-ChangeProgressStage-Name"></a>
The name of the stage.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No

 ** Status **   <a name="opensearchservice-Type-ChangeProgressStage-Status"></a>
The status of the stage.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
