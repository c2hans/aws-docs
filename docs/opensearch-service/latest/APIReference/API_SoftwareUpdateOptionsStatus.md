# SoftwareUpdateOptionsStatus
<a name="API_SoftwareUpdateOptionsStatus"></a>

The status of the service software options for a domain.

## Contents
<a name="API_SoftwareUpdateOptionsStatus_Contents"></a>

 ** Options **   <a name="opensearchservice-Type-SoftwareUpdateOptionsStatus-Options"></a>
The service software update options for a domain.
Type: [SoftwareUpdateOptions](API_SoftwareUpdateOptions.md) object
Required: No

 ** Status **   <a name="opensearchservice-Type-SoftwareUpdateOptionsStatus-Status"></a>
The status of service software update options, including creation date and last updated date.
Type: [OptionStatus](API_OptionStatus.md) object
Required: No
