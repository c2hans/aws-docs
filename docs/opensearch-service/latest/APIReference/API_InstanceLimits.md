# InstanceLimits
<a name="API_InstanceLimits"></a>

Instance-related attributes that are available for a given instance type.

## Contents
<a name="API_InstanceLimits_Contents"></a>

 ** InstanceCountLimits **   <a name="opensearchservice-Type-InstanceLimits-InstanceCountLimits"></a>
Limits on the number of instances that can be created for a given instance type.
Type: [InstanceCountLimits](API_InstanceCountLimits.md) object
Required: No
