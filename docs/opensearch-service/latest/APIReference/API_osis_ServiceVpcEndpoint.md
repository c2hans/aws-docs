# ServiceVpcEndpoint
<a name="API_osis_ServiceVpcEndpoint"></a>

A container for information about VPC endpoints that were created to other services

## Contents
<a name="API_osis_ServiceVpcEndpoint_Contents"></a>

 ** ServiceName **   <a name="opensearchservice-Type-osis_ServiceVpcEndpoint-ServiceName"></a>
The name of the service for which a VPC endpoint was created.
Type: String
Valid Values: `OPENSEARCH_SERVERLESS`
Required: No

 ** VpcEndpointId **   <a name="opensearchservice-Type-osis_ServiceVpcEndpoint-VpcEndpointId"></a>
The unique identifier of the VPC endpoint that was created.
Type: String
Required: No
