# InstanceCountLimits
<a name="API_InstanceCountLimits"></a>

Limits on the number of instances that can be created in OpenSearch Service for a given instance type.

## Contents
<a name="API_InstanceCountLimits_Contents"></a>

 ** MaximumInstanceCount **   <a name="opensearchservice-Type-InstanceCountLimits-MaximumInstanceCount"></a>
The minimum allowed number of instances.
Type: Integer
Required: No

 ** MinimumInstanceCount **   <a name="opensearchservice-Type-InstanceCountLimits-MinimumInstanceCount"></a>
The maximum allowed number of instances.
Type: Integer
Required: No
