# AutoTune
<a name="API_AutoTune"></a>

Information about an Auto-Tune action. For more information, see [Auto-Tune for Amazon OpenSearch Service](https://docs.aws.amazon.com/opensearch-service/latest/developerguide/auto-tune.html).

<a name="API_AutoTune_Contents"></a>

 ** AutoTuneDetails **   <a name="opensearchservice-Type-AutoTune-AutoTuneDetails"></a>
Details about an Auto-Tune action.
Type: [AutoTuneDetails](API_AutoTuneDetails.md) object
Required: No

 ** AutoTuneType **   <a name="opensearchservice-Type-AutoTune-AutoTuneType"></a>

Type: String
Valid Values: `SCHEDULED_ACTION`
Required: No
