# ErrorDetails
<a name="API_ErrorDetails"></a>

Additional information if the package is in an error state. Null otherwise.

## Contents
<a name="API_ErrorDetails_Contents"></a>

 ** ErrorMessage **   <a name="opensearchservice-Type-ErrorDetails-ErrorMessage"></a>
A message describing the error.
Type: String
Required: No

 ** ErrorType **   <a name="opensearchservice-Type-ErrorDetails-ErrorType"></a>
The type of error that occurred.
Type: String
Required: No
