# DivergentItem
<a name="API_DivergentItem"></a>

An item that exists on both domains but whose contents differ.

## Contents
<a name="API_DivergentItem_Contents"></a>

 ** Fields **   <a name="opensearchservice-Type-DivergentItem-Fields"></a>
The fields of the item that differ.
Type: Array of [DivergentField](API_DivergentField.md) objects
Array Members: Maximum number of 100 items.
Required: No

 ** Name **   <a name="opensearchservice-Type-DivergentItem-Name"></a>
The name of the item.
Type: String
Length Constraints: Maximum length of 256.
Required: No
