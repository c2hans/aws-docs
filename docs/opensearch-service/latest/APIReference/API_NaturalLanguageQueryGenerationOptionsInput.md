# NaturalLanguageQueryGenerationOptionsInput
<a name="API_NaturalLanguageQueryGenerationOptionsInput"></a>

Container for parameters required to enable the natural language query generation feature.

## Contents
<a name="API_NaturalLanguageQueryGenerationOptionsInput_Contents"></a>

 ** DesiredState **   <a name="opensearchservice-Type-NaturalLanguageQueryGenerationOptionsInput-DesiredState"></a>
The desired state of the natural language query generation feature. Valid values are ENABLED and DISABLED.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: No
