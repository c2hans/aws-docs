# PipelineDestination
<a name="API_osis_PipelineDestination"></a>

An object representing the destination of a pipeline.

## Contents
<a name="API_osis_PipelineDestination_Contents"></a>

 ** Endpoint **   <a name="opensearchservice-Type-osis_PipelineDestination-Endpoint"></a>
The endpoint receiving data from the pipeline.
Type: String
Required: No

 ** ServiceName **   <a name="opensearchservice-Type-osis_PipelineDestination-ServiceName"></a>
The name of the service receiving data from the pipeline.
Type: String
Required: No
