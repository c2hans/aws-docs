# UseCaseStatus
<a name="API_UseCaseStatus"></a>

The status of the use case for the domain.

## Contents
<a name="API_UseCaseStatus_Contents"></a>

 ** Options **   <a name="opensearchservice-Type-UseCaseStatus-Options"></a>
The use case configured for the domain.
Type: String
Valid Values: `SEARCH | VECTOR | OBSERVABILITY | MIXED`
Required: Yes

 ** Status **   <a name="opensearchservice-Type-UseCaseStatus-Status"></a>
The current status of the use case for the domain.
Type: [OptionStatus](API_OptionStatus.md) object
Required: Yes
