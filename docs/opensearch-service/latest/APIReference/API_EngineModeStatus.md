# EngineModeStatus
<a name="API_EngineModeStatus"></a>

The status of the engine mode for the domain.

## Contents
<a name="API_EngineModeStatus_Contents"></a>

 ** Options **   <a name="opensearchservice-Type-EngineModeStatus-Options"></a>
The engine mode configured for the domain.
Type: String
Valid Values: `GENERAL | OPTIMIZED`
Required: Yes

 ** Status **   <a name="opensearchservice-Type-EngineModeStatus-Status"></a>
The current status of the engine mode for the domain.
Type: [OptionStatus](API_OptionStatus.md) object
Required: Yes
