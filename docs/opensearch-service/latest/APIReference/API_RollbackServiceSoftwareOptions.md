# RollbackServiceSoftwareOptions
<a name="API_RollbackServiceSoftwareOptions"></a>

Details about the rollback options for a service software update.

## Contents
<a name="API_RollbackServiceSoftwareOptions_Contents"></a>

 ** CurrentVersion **   <a name="opensearchservice-Type-RollbackServiceSoftwareOptions-CurrentVersion"></a>
The current service software version on the domain.
Type: String
Required: No

 ** Description **   <a name="opensearchservice-Type-RollbackServiceSoftwareOptions-Description"></a>
A description of the rollback status.
Type: String
Required: No

 ** NewVersion **   <a name="opensearchservice-Type-RollbackServiceSoftwareOptions-NewVersion"></a>
The service software version that the domain will roll back to.
Type: String
Required: No

 ** RollbackAvailable **   <a name="opensearchservice-Type-RollbackServiceSoftwareOptions-RollbackAvailable"></a>
Whether a service software rollback is available for the domain.
Type: Boolean
Required: No
