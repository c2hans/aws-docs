# ValidationFailure
<a name="API_ValidationFailure"></a>

A validation failure that occurred as the result of a pre-update validation check (verbose dry run) on a domain.

## Contents
<a name="API_ValidationFailure_Contents"></a>

 ** Code **   <a name="opensearchservice-Type-ValidationFailure-Code"></a>
The error code of the failure.
Type: String
Required: No

 ** Message **   <a name="opensearchservice-Type-ValidationFailure-Message"></a>
A message corresponding to the failure.
Type: String
Required: No
