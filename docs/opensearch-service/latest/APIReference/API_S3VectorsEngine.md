# S3VectorsEngine
<a name="API_S3VectorsEngine"></a>

Options for enabling S3 vectors engine features on the specified domain.

## Contents
<a name="API_S3VectorsEngine_Contents"></a>

 ** Enabled **   <a name="opensearchservice-Type-S3VectorsEngine-Enabled"></a>
Enables S3 vectors engine features.
Type: Boolean
Required: No
