# PipelineBlueprint
<a name="API_osis_PipelineBlueprint"></a>

Container for information about an OpenSearch Ingestion blueprint.

## Contents
<a name="API_osis_PipelineBlueprint_Contents"></a>

 ** BlueprintName **   <a name="opensearchservice-Type-osis_PipelineBlueprint-BlueprintName"></a>
The name of the blueprint.
Type: String
Required: No

 ** DisplayDescription **   <a name="opensearchservice-Type-osis_PipelineBlueprint-DisplayDescription"></a>
A description of the blueprint.
Type: String
Required: No

 ** DisplayName **   <a name="opensearchservice-Type-osis_PipelineBlueprint-DisplayName"></a>
The display name of the blueprint.
Type: String
Required: No

 ** PipelineConfigurationBody **   <a name="opensearchservice-Type-osis_PipelineBlueprint-PipelineConfigurationBody"></a>
The YAML configuration of the blueprint.
Type: String
Required: No

 ** Service **   <a name="opensearchservice-Type-osis_PipelineBlueprint-Service"></a>
The name of the service that the blueprint is associated with.
Type: String
Required: No

 ** UseCase **   <a name="opensearchservice-Type-osis_PipelineBlueprint-UseCase"></a>
The use case that the blueprint relates to.
Type: String
Required: No
