# EBSOptionsStatus
<a name="API_EBSOptionsStatus"></a>

The status of the EBS options for the specified OpenSearch Service domain.

## Contents
<a name="API_EBSOptionsStatus_Contents"></a>

 ** Options **   <a name="opensearchservice-Type-EBSOptionsStatus-Options"></a>
The configured EBS options for the specified domain.
Type: [EBSOptions](API_EBSOptions.md) object
Required: Yes

 ** Status **   <a name="opensearchservice-Type-EBSOptionsStatus-Status"></a>
The status of the EBS options for the specified domain.
Type: [OptionStatus](API_OptionStatus.md) object
Required: Yes
