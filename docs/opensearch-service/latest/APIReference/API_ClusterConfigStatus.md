# ClusterConfigStatus
<a name="API_ClusterConfigStatus"></a>

The cluster configuration status for a domain.

## Contents
<a name="API_ClusterConfigStatus_Contents"></a>

 ** Options **   <a name="opensearchservice-Type-ClusterConfigStatus-Options"></a>
Cluster configuration options for the specified domain.
Type: [ClusterConfig](API_ClusterConfig.md) object
Required: Yes

 ** Status **   <a name="opensearchservice-Type-ClusterConfigStatus-Status"></a>
The status of cluster configuration options for the specified domain.
Type: [OptionStatus](API_OptionStatus.md) object
Required: Yes
