# MigrationSource
<a name="API_MigrationSource"></a>

The source configuration for a migration, specifying the data source from which to export saved objects.

## Contents
<a name="API_MigrationSource_Contents"></a>

 ** datasourceArn **   <a name="opensearchservice-Type-MigrationSource-datasourceArn"></a>
The Amazon Resource Name (ARN) of the data source to migrate saved objects from.
Type: String
Length Constraints: Minimum length of 20. Maximum length of 2048.
Pattern: `.*`
Required: Yes
