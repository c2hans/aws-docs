# ServiceOptions
<a name="API_ServiceOptions"></a>

Options for the service, such as the supported Regions.

## Contents
<a name="API_ServiceOptions_Contents"></a>

 ** SupportedRegions **   <a name="opensearchservice-Type-ServiceOptions-SupportedRegions"></a>
The list of supported Regions for the service.
Type: Array of strings
Length Constraints: Minimum length of 5. Maximum length of 30.
Pattern: `[a-z][a-z0-9\-]+`
Required: No
