# RecurringCharge
<a name="API_RecurringCharge"></a>

Contains the specific price and frequency of a recurring charges for an OpenSearch Reserved Instance, or for a Reserved Instance offering.

## Contents
<a name="API_RecurringCharge_Contents"></a>

 ** RecurringChargeAmount **   <a name="opensearchservice-Type-RecurringCharge-RecurringChargeAmount"></a>
The monetary amount of the recurring charge.
Type: Double
Required: No

 ** RecurringChargeFrequency **   <a name="opensearchservice-Type-RecurringCharge-RecurringChargeFrequency"></a>
The frequency of the recurring charge.
Type: String
Required: No
