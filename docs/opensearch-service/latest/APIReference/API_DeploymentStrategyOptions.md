# DeploymentStrategyOptions
<a name="API_DeploymentStrategyOptions"></a>

Specifies the deployment strategy options for the domain.

## Contents
<a name="API_DeploymentStrategyOptions_Contents"></a>

 ** DeploymentStrategy **   <a name="opensearchservice-Type-DeploymentStrategyOptions-DeploymentStrategy"></a>
Specifies the deployment strategy for the domain. Valid values are `Default` and `CapacityOptimized`.
Type: String
Valid Values: `Default | CapacityOptimized`
Required: Yes
