# OffPeakWindowOptionsStatus
<a name="API_OffPeakWindowOptionsStatus"></a>

The status of [off-peak window](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_OffPeakWindow.html) options for a domain.

## Contents
<a name="API_OffPeakWindowOptionsStatus_Contents"></a>

 ** Options **   <a name="opensearchservice-Type-OffPeakWindowOptionsStatus-Options"></a>
The domain's off-peak window configuration.
Type: [OffPeakWindowOptions](API_OffPeakWindowOptions.md) object
Required: No

 ** Status **   <a name="opensearchservice-Type-OffPeakWindowOptionsStatus-Status"></a>
The current status of off-peak window options.
Type: [OptionStatus](API_OptionStatus.md) object
Required: No
