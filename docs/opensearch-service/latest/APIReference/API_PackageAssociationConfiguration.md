# PackageAssociationConfiguration
<a name="API_PackageAssociationConfiguration"></a>

The configuration for associating a package with a domain.

## Contents
<a name="API_PackageAssociationConfiguration_Contents"></a>

 ** KeyStoreAccessOption **   <a name="opensearchservice-Type-PackageAssociationConfiguration-KeyStoreAccessOption"></a>

Type: [KeyStoreAccessOption](API_KeyStoreAccessOption.md) object
Required: No
