# AdvancedSecurityOptionsStatus
<a name="API_AdvancedSecurityOptionsStatus"></a>

The status of fine-grained access control settings for a domain.

## Contents
<a name="API_AdvancedSecurityOptionsStatus_Contents"></a>

 ** Options **   <a name="opensearchservice-Type-AdvancedSecurityOptionsStatus-Options"></a>
Container for fine-grained access control settings.
Type: [AdvancedSecurityOptions](API_AdvancedSecurityOptions.md) object
Required: Yes

 ** Status **   <a name="opensearchservice-Type-AdvancedSecurityOptionsStatus-Status"></a>
Status of the fine-grained access control settings for a domain.
Type: [OptionStatus](API_OptionStatus.md) object
Required: Yes
