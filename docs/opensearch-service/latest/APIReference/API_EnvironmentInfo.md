# EnvironmentInfo
<a name="API_EnvironmentInfo"></a>

Information about the active domain environment.

## Contents
<a name="API_EnvironmentInfo_Contents"></a>

 ** AvailabilityZoneInformation **   <a name="opensearchservice-Type-EnvironmentInfo-AvailabilityZoneInformation"></a>
 A list of `AvailabilityZoneInfo` for the domain.
Type: Array of [AvailabilityZoneInfo](API_AvailabilityZoneInfo.md) objects
Required: No
