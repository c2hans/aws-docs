# CapabilityFailure
<a name="API_CapabilityFailure"></a>

Information about a capability failure.

## Contents
<a name="API_CapabilityFailure_Contents"></a>

 ** details **   <a name="opensearchservice-Type-CapabilityFailure-details"></a>
Additional details about the capability failure.
Type: String
Required: No

 ** reason **   <a name="opensearchservice-Type-CapabilityFailure-reason"></a>
The reason for the capability failure. Possible values: `KMS_KEY_INSUFFICIENT_PERMISSION`.
Type: String
Valid Values: `KMS_KEY_INSUFFICIENT_PERMISSION`
Required: No
