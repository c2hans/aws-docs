# SnapshotOptionsStatus
<a name="API_SnapshotOptionsStatus"></a>

Container for information about a daily automated snapshot for an OpenSearch Service domain.

## Contents
<a name="API_SnapshotOptionsStatus_Contents"></a>

 ** Options **   <a name="opensearchservice-Type-SnapshotOptionsStatus-Options"></a>
The daily snapshot options specified for the domain.
Type: [SnapshotOptions](API_SnapshotOptions.md) object
Required: Yes

 ** Status **   <a name="opensearchservice-Type-SnapshotOptionsStatus-Status"></a>
The status of a daily automated snapshot.
Type: [OptionStatus](API_OptionStatus.md) object
Required: Yes
