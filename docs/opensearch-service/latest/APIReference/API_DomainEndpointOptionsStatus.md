# DomainEndpointOptionsStatus
<a name="API_DomainEndpointOptionsStatus"></a>

The configured endpoint options for a domain and their current status.

## Contents
<a name="API_DomainEndpointOptionsStatus_Contents"></a>

 ** Options **   <a name="opensearchservice-Type-DomainEndpointOptionsStatus-Options"></a>
Options to configure the endpoint for a domain.
Type: [DomainEndpointOptions](API_DomainEndpointOptions.md) object
Required: Yes

 ** Status **   <a name="opensearchservice-Type-DomainEndpointOptionsStatus-Status"></a>
The status of the endpoint options for a domain.
Type: [OptionStatus](API_OptionStatus.md) object
Required: Yes
