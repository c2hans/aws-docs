# S3Statistics
<a name="API_S3Statistics"></a>

Processing statistics for the Amazon S3 objects in an ingestion source.

## Contents
<a name="API_S3Statistics_Contents"></a>

 ** objectsDiscovered **   <a name="opensearchserverless-Type-S3Statistics-objectsDiscovered"></a>
The number of Amazon S3 objects discovered for ingestion.
Type: Long
Required: No

 ** objectsFailed **   <a name="opensearchserverless-Type-S3Statistics-objectsFailed"></a>
The number of Amazon S3 objects that failed to be ingested.
Type: Long
Required: No

 ** objectsIngested **   <a name="opensearchserverless-Type-S3Statistics-objectsIngested"></a>
The number of Amazon S3 objects successfully ingested.
Type: Long
Required: No
