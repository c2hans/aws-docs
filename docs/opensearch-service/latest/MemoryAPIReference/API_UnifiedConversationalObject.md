# UnifiedConversationalObject

Conversation turns.

## Contents
<a name="API_UnifiedConversationalObject_Contents"></a>

 ** messages **   <a name="opensearchmemory-Type-UnifiedConversationalObject-messages"></a>
The conversation turns, in order. The order matters for extraction.
Type: Array of [Message](API_Message.md) objects
Array Members: Minimum number of 1 item. Maximum number of 100 items.
Required: Yes
