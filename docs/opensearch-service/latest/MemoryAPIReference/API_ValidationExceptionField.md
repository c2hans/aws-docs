# ValidationExceptionField

Information about a request field that failed validation.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="opensearchmemory-Type-ValidationExceptionField-message"></a>
A message that describes why the field failed validation.
Type: String
Required: Yes

 ** name **   <a name="opensearchmemory-Type-ValidationExceptionField-name"></a>
The field name.
Type: String
Required: Yes
