# Helper methods for mutual TLS
<a name="mtls-helper-methods-link"></a>

Use the `cf.mtls` helper functions in viewer request functions to rename, reformat, or combine client certificate headers before forwarding the request to your origin. For details, see [Helper methods for mutual TLS](mtls-helper-methods.md).
