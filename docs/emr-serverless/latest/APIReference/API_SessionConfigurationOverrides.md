# SessionConfigurationOverrides
<a name="API_SessionConfigurationOverrides"></a>

The configuration overrides for a session.

## Contents
<a name="API_SessionConfigurationOverrides_Contents"></a>

 ** runtimeConfiguration **   <a name="emrserverless-Type-SessionConfigurationOverrides-runtimeConfiguration"></a>
The runtime configuration for the session. Contains Spark configuration properties specified at session creation time.
Type: Array of [Configuration](API_Configuration.md) objects
Array Members: Minimum number of 0 items. Maximum number of 100 items.
Required: No
