# HlsConfiguration
<a name="API_HlsConfiguration"></a>

The configuration for HLS content.

## Contents
<a name="API_HlsConfiguration_Contents"></a>

 ** DualStackManifestEndpointPrefix **   <a name="mediatailor-Type-HlsConfiguration-DualStackManifestEndpointPrefix"></a>
The dual-stack (IPv4 and IPv6) URL that MediaTailor generates to initiate a playback session for devices that support Apple HLS. The session uses server-side reporting.
Type: String
Required: No

 ** ManifestEndpointPrefix **   <a name="mediatailor-Type-HlsConfiguration-ManifestEndpointPrefix"></a>
The URL that MediaTailor generates to initiate a playback session for devices that support Apple HLS. The session uses server-side reporting.
Type: String
Required: No
