# AWS Snowball Edge Documentation

The AWS Snowball Edge devices help customers who need to run operations in austere, non-data center environments, and in locations where there's no consistent network connectivity. You can use these devices to locally and cost-effectively access the storage and compute power of the AWS Cloud in places where an internet connection might not be an option.

- [AWS Snowball Edge Developer Guide](/snowball/latest/developer-guide/): Provides a conceptual overview of how to use an AWS Snowball Edge device. Includes guidance for local storage and compute, clustering, importing and exporting data into Amazon S3, and other device features. Device configuration options include storage optimized 210 TB and compute optimized.
- [AWS Snowball Edge API Reference](/snowball/latest/api-reference/): Describes all the API operations for AWS Snowball Edge in detail. Also provides sample requests, responses, and errors for the supported web service protocols.
