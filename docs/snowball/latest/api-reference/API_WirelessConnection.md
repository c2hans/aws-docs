# WirelessConnection
<a name="API_WirelessConnection"></a>

**Note**
 AWS Snowball Edge is no longer available to new customers. New customers should explore [AWS DataSync](https://aws.amazon.com/datasync/) for online transfers, [AWS Data Transfer Terminal](https://aws.amazon.com/data-transfer-terminal/) for secure physical transfers, or AWS Partner solutions. For edge computing, explore [AWS Outposts](https://aws.amazon.com/outposts/).

Configures the wireless connection on an AWS Snowball Edge device.

## Contents
<a name="API_WirelessConnection_Contents"></a>

 ** IsWifiEnabled **   <a name="Snowball-Type-WirelessConnection-IsWifiEnabled"></a>
Enables the Wi-Fi adapter on an AWS Snowball Edge device.
Type: Boolean
Required: No
