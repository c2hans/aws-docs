# QueryStringNames
<a name="API_QueryStringNames"></a>

Contains a list of query string names.

## Contents
<a name="API_QueryStringNames_Contents"></a>

 ** Quantity **   <a name="cloudfront-Type-QueryStringNames-Quantity"></a>
The number of query string names in the `Items` list.
Type: Integer
Required: Yes

 ** Items **   <a name="cloudfront-Type-QueryStringNames-Items"></a>
A list of query string names.
Type: Array of strings
Required: No
