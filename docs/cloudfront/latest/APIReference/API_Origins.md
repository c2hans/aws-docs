# Origins
<a name="API_Origins"></a>

Contains information about the origins for this distribution.

## Contents
<a name="API_Origins_Contents"></a>

 ** Items **   <a name="cloudfront-Type-Origins-Items"></a>
A list of origins.
Type: Array of [Origin](API_Origin.md) objects
Array Members: Minimum number of 1 item.
Required: Yes

 ** Quantity **   <a name="cloudfront-Type-Origins-Quantity"></a>
The number of origins for this distribution.
Type: Integer
Required: Yes
