# KeyPairIds
<a name="API_KeyPairIds"></a>

A list of CloudFront key pair identifiers.

## Contents
<a name="API_KeyPairIds_Contents"></a>

 ** Quantity **   <a name="cloudfront-Type-KeyPairIds-Quantity"></a>
The number of key pair identifiers in the list.
Type: Integer
Required: Yes

 ** Items **   <a name="cloudfront-Type-KeyPairIds-Items"></a>
A list of CloudFront key pair identifiers.
Type: Array of strings
Required: No
