# DeleteKeyRequestListItem
<a name="API_kvs_DeleteKeyRequestListItem"></a>

List item for keys to delete.

## Contents
<a name="API_kvs_DeleteKeyRequestListItem_Contents"></a>

 ** Key **   <a name="cloudfront-Type-kvs_DeleteKeyRequestListItem-Key"></a>
The key of the key-value pair to be deleted.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes
