# PutKeyRequestListItem
<a name="API_kvs_PutKeyRequestListItem"></a>

List item for key-value pair to put.

## Contents
<a name="API_kvs_PutKeyRequestListItem_Contents"></a>

 ** Key **   <a name="cloudfront-Type-kvs_PutKeyRequestListItem-Key"></a>
The key of the key-value pair list item to put.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes

 ** Value **   <a name="cloudfront-Type-kvs_PutKeyRequestListItem-Value"></a>
The value for the key-value pair to put.
Type: String
Required: Yes
