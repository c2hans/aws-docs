# StagingDistributionDnsNames
<a name="API_StagingDistributionDnsNames"></a>

The CloudFront domain name of the staging distribution.

## Contents
<a name="API_StagingDistributionDnsNames_Contents"></a>

 ** Quantity **   <a name="cloudfront-Type-StagingDistributionDnsNames-Quantity"></a>
The number of CloudFront domain names in your staging distribution.
Type: Integer
Required: Yes

 ** Items **   <a name="cloudfront-Type-StagingDistributionDnsNames-Items"></a>
The CloudFront domain name of the staging distribution.
Type: Array of strings
Required: No
