# KGKeyPairIds
<a name="API_KGKeyPairIds"></a>

A list of identifiers for the public keys that CloudFront can use to verify the signatures of signed URLs and signed cookies.

## Contents
<a name="API_KGKeyPairIds_Contents"></a>

 ** KeyGroupId **   <a name="cloudfront-Type-KGKeyPairIds-KeyGroupId"></a>
The identifier of the key group that contains the public keys.
Type: String
Required: No

 ** KeyPairIds **   <a name="cloudfront-Type-KGKeyPairIds-KeyPairIds"></a>
A list of CloudFront key pair identifiers.
Type: [KeyPairIds](API_KeyPairIds.md) object
Required: No
