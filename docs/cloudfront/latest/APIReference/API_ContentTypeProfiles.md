# ContentTypeProfiles
<a name="API_ContentTypeProfiles"></a>

Field-level encryption content type-profile.

## Contents
<a name="API_ContentTypeProfiles_Contents"></a>

 ** Quantity **   <a name="cloudfront-Type-ContentTypeProfiles-Quantity"></a>
The number of field-level encryption content type-profile mappings.
Type: Integer
Required: Yes

 ** Items **   <a name="cloudfront-Type-ContentTypeProfiles-Items"></a>
Items in a field-level encryption content type-profile mapping.
Type: Array of [ContentTypeProfile](API_ContentTypeProfile.md) objects
Required: No
