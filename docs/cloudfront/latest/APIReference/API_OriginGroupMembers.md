# OriginGroupMembers
<a name="API_OriginGroupMembers"></a>

A complex data type for the origins included in an origin group.

## Contents
<a name="API_OriginGroupMembers_Contents"></a>

 ** Items **   <a name="cloudfront-Type-OriginGroupMembers-Items"></a>
Items (origins) in an origin group.
Type: Array of [OriginGroupMember](API_OriginGroupMember.md) objects
Array Members: Fixed number of 2 items.
Required: Yes

 ** Quantity **   <a name="cloudfront-Type-OriginGroupMembers-Quantity"></a>
The number of origins in an origin group.
Type: Integer
Required: Yes
