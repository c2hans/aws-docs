# OriginGroups
<a name="API_OriginGroups"></a>

A complex data type for the origin groups specified for a distribution.

## Contents
<a name="API_OriginGroups_Contents"></a>

 ** Quantity **   <a name="cloudfront-Type-OriginGroups-Quantity"></a>
The number of origin groups.
Type: Integer
Required: Yes

 ** Items **   <a name="cloudfront-Type-OriginGroups-Items"></a>
The items (origin groups) in a distribution.
Type: Array of [OriginGroup](API_OriginGroup.md) objects
Required: No
