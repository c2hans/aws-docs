# ResponseHeadersPolicySummary
<a name="API_ResponseHeadersPolicySummary"></a>

Contains a response headers policy.

## Contents
<a name="API_ResponseHeadersPolicySummary_Contents"></a>

 ** ResponseHeadersPolicy **   <a name="cloudfront-Type-ResponseHeadersPolicySummary-ResponseHeadersPolicy"></a>
The response headers policy.
Type: [ResponseHeadersPolicy](API_ResponseHeadersPolicy.md) object
Required: Yes

 ** Type **   <a name="cloudfront-Type-ResponseHeadersPolicySummary-Type"></a>
The type of response headers policy, either `managed` (created by AWS) or `custom` (created in this AWS account).
Type: String
Valid Values: `managed | custom`
Required: Yes
