# ContinuousDeploymentPolicy
<a name="API_ContinuousDeploymentPolicy"></a>

A continuous deployment policy.

## Contents
<a name="API_ContinuousDeploymentPolicy_Contents"></a>

 ** ContinuousDeploymentPolicyConfig **   <a name="cloudfront-Type-ContinuousDeploymentPolicy-ContinuousDeploymentPolicyConfig"></a>
Contains the configuration for a continuous deployment policy.
Type: [ContinuousDeploymentPolicyConfig](API_ContinuousDeploymentPolicyConfig.md) object
Required: Yes

 ** Id **   <a name="cloudfront-Type-ContinuousDeploymentPolicy-Id"></a>
The identifier of the continuous deployment policy.
Type: String
Required: Yes

 ** LastModifiedTime **   <a name="cloudfront-Type-ContinuousDeploymentPolicy-LastModifiedTime"></a>
The date and time the continuous deployment policy was last modified.
Type: Timestamp
Required: Yes
