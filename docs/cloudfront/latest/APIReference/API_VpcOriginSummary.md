# VpcOriginSummary
<a name="API_VpcOriginSummary"></a>

A summary of the CloudFront VPC origin.

## Contents
<a name="API_VpcOriginSummary_Contents"></a>

 ** Arn **   <a name="cloudfront-Type-VpcOriginSummary-Arn"></a>
The VPC origin summary ARN.
Type: String
Required: Yes

 ** CreatedTime **   <a name="cloudfront-Type-VpcOriginSummary-CreatedTime"></a>
The VPC origin summary created time.
Type: Timestamp
Required: Yes

 ** Id **   <a name="cloudfront-Type-VpcOriginSummary-Id"></a>
The VPC origin summary ID.
Type: String
Required: Yes

 ** LastModifiedTime **   <a name="cloudfront-Type-VpcOriginSummary-LastModifiedTime"></a>
The VPC origin summary last modified time.
Type: Timestamp
Required: Yes

 ** Name **   <a name="cloudfront-Type-VpcOriginSummary-Name"></a>
The VPC origin summary name.
Type: String
Required: Yes

 ** OriginEndpointArn **   <a name="cloudfront-Type-VpcOriginSummary-OriginEndpointArn"></a>
The VPC origin summary origin endpoint ARN.
Type: String
Required: Yes

 ** Status **   <a name="cloudfront-Type-VpcOriginSummary-Status"></a>
The VPC origin summary status.
Type: String
Required: Yes
