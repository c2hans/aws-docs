# CookieNames
<a name="API_CookieNames"></a>

Contains a list of cookie names.

## Contents
<a name="API_CookieNames_Contents"></a>

 ** Quantity **   <a name="cloudfront-Type-CookieNames-Quantity"></a>
The number of cookie names in the `Items` list.
Type: Integer
Required: Yes

 ** Items **   <a name="cloudfront-Type-CookieNames-Items"></a>
A list of cookie names.
Type: Array of strings
Required: No
