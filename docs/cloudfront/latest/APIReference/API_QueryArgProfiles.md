# QueryArgProfiles
<a name="API_QueryArgProfiles"></a>

Query argument-profile mapping for field-level encryption.

## Contents
<a name="API_QueryArgProfiles_Contents"></a>

 ** Quantity **   <a name="cloudfront-Type-QueryArgProfiles-Quantity"></a>
Number of profiles for query argument-profile mapping for field-level encryption.
Type: Integer
Required: Yes

 ** Items **   <a name="cloudfront-Type-QueryArgProfiles-Items"></a>
Number of items for query argument-profile mapping for field-level encryption.
Type: Array of [QueryArgProfile](API_QueryArgProfile.md) objects
Required: No
