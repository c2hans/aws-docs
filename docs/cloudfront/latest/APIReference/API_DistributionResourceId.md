# DistributionResourceId
<a name="API_DistributionResourceId"></a>

The IDs for the distribution resources.

## Contents
<a name="API_DistributionResourceId_Contents"></a>

 ** DistributionId **   <a name="cloudfront-Type-DistributionResourceId-DistributionId"></a>
The ID of the multi-tenant distribution.
Type: String
Required: No

 ** DistributionTenantId **   <a name="cloudfront-Type-DistributionResourceId-DistributionTenantId"></a>
The ID of the distribution tenant.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No
