# InvalidationSummary
<a name="API_InvalidationSummary"></a>

A summary of an invalidation request.

## Contents
<a name="API_InvalidationSummary_Contents"></a>

 ** CreateTime **   <a name="cloudfront-Type-InvalidationSummary-CreateTime"></a>
The time that an invalidation request was created.
Type: Timestamp
Required: Yes

 ** Id **   <a name="cloudfront-Type-InvalidationSummary-Id"></a>
The unique ID for an invalidation request.
Type: String
Required: Yes

 ** Status **   <a name="cloudfront-Type-InvalidationSummary-Status"></a>
The status of an invalidation request.
Type: String
Required: Yes
