# OriginAccessControl
<a name="API_OriginAccessControl"></a>

A CloudFront origin access control, including its unique identifier.

## Contents
<a name="API_OriginAccessControl_Contents"></a>

 ** Id **   <a name="cloudfront-Type-OriginAccessControl-Id"></a>
The unique identifier of the origin access control.
Type: String
Required: Yes

 ** OriginAccessControlConfig **   <a name="cloudfront-Type-OriginAccessControl-OriginAccessControlConfig"></a>
The origin access control.
Type: [OriginAccessControlConfig](API_OriginAccessControlConfig.md) object
Required: No
