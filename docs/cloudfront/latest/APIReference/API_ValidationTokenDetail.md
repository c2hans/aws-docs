# ValidationTokenDetail
<a name="API_ValidationTokenDetail"></a>

Contains details about the validation token.

## Contents
<a name="API_ValidationTokenDetail_Contents"></a>

 ** Domain **   <a name="cloudfront-Type-ValidationTokenDetail-Domain"></a>
The domain name.
Type: String
Required: Yes

 ** RedirectFrom **   <a name="cloudfront-Type-ValidationTokenDetail-RedirectFrom"></a>
The domain to redirect from.
Type: String
Required: No

 ** RedirectTo **   <a name="cloudfront-Type-ValidationTokenDetail-RedirectTo"></a>
The domain to redirect to.
Type: String
Required: No
