# OriginRequestPolicySummary
<a name="API_OriginRequestPolicySummary"></a>

Contains an origin request policy.

## Contents
<a name="API_OriginRequestPolicySummary_Contents"></a>

 ** OriginRequestPolicy **   <a name="cloudfront-Type-OriginRequestPolicySummary-OriginRequestPolicy"></a>
The origin request policy.
Type: [OriginRequestPolicy](API_OriginRequestPolicy.md) object
Required: Yes

 ** Type **   <a name="cloudfront-Type-OriginRequestPolicySummary-Type"></a>
The type of origin request policy, either `managed` (created by AWS) or `custom` (created in this AWS account).
Type: String
Valid Values: `managed | custom`
Required: Yes
