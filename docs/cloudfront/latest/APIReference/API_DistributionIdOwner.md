# DistributionIdOwner

A structure that pairs a CloudFront distribution ID with its owning AWS account ID.

## Contents
<a name="API_DistributionIdOwner_Contents"></a>

 ** DistributionId **   <a name="cloudfront-Type-DistributionIdOwner-DistributionId"></a>
The ID of the distribution.
Type: String
Required: Yes

 ** OwnerAccountId **   <a name="cloudfront-Type-DistributionIdOwner-OwnerAccountId"></a>
The ID of the AWS account that owns the distribution.
Type: String
Required: Yes
