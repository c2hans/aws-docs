# StringSchemaConfig
<a name="API_StringSchemaConfig"></a>

The configuration for a string schema.

## Contents
<a name="API_StringSchemaConfig_Contents"></a>

 ** Required **   <a name="cloudfront-Type-StringSchemaConfig-Required"></a>
Whether the defined parameter is required.
Type: Boolean
Required: Yes

 ** Comment **   <a name="cloudfront-Type-StringSchemaConfig-Comment"></a>
A comment to describe the parameter.
Type: String
Required: No

 ** DefaultValue **   <a name="cloudfront-Type-StringSchemaConfig-DefaultValue"></a>
The default value of the parameter.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
