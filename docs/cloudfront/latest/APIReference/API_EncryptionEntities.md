# EncryptionEntities
<a name="API_EncryptionEntities"></a>

Complex data type for field-level encryption profiles that includes all of the encryption entities.

## Contents
<a name="API_EncryptionEntities_Contents"></a>

 ** Quantity **   <a name="cloudfront-Type-EncryptionEntities-Quantity"></a>
Number of field pattern items in a field-level encryption content type-profile mapping.
Type: Integer
Required: Yes

 ** Items **   <a name="cloudfront-Type-EncryptionEntities-Items"></a>
An array of field patterns in a field-level encryption content type-profile mapping.
Type: Array of [EncryptionEntity](API_EncryptionEntity.md) objects
Required: No
