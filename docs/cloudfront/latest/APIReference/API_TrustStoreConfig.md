# TrustStoreConfig
<a name="API_TrustStoreConfig"></a>

A trust store configuration.

## Contents
<a name="API_TrustStoreConfig_Contents"></a>

 ** TrustStoreId **   <a name="cloudfront-Type-TrustStoreConfig-TrustStoreId"></a>
The trust store ID.
Type: String
Required: Yes

 ** AdvertiseTrustStoreCaNames **   <a name="cloudfront-Type-TrustStoreConfig-AdvertiseTrustStoreCaNames"></a>
The configuration to use to advertise trust store CA names.
Type: Boolean
Required: No

 ** IgnoreCertificateExpiry **   <a name="cloudfront-Type-TrustStoreConfig-IgnoreCertificateExpiry"></a>
The configuration to use to ignore certificate expiration.
Type: Boolean
Required: No
