# Amazon Security Lake Documentation

Amazon Security Lake is a fully-managed security data lake service. You can use Security Lake to aggregate and centrally manage security-related log and event data at scale.

- [Amazon Security Lake User Guide](/security-lake/latest/userguide/): Provides detailed information and instructions for working with Amazon Security Lake.
- [Amazon Security Lake API Reference](/security-lake/latest/APIReference/): Describes the Amazon Security Lake API operations. Also provides example requests and responses for each operation.
- [Amazon Security Lake in the AWS CLI Reference](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/securitylake/index.html): Provides syntax and examples for the AWS CLI commands for use with Amazon Security Lake.
