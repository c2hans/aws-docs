# DataLakeUpdateException
<a name="API_DataLakeUpdateException"></a>

The details of the last `UpdateDataLake` or `DeleteDataLake` API request which failed.

## Contents
<a name="API_DataLakeUpdateException_Contents"></a>

 ** code **   <a name="securitylake-Type-DataLakeUpdateException-code"></a>
The reason code for the exception of the last `UpdateDataLake` or `DeleteDataLake` API request.
Type: String
Required: No

 ** reason **   <a name="securitylake-Type-DataLakeUpdateException-reason"></a>
The reason for the exception of the last `UpdateDataLake`or `DeleteDataLake` API request.
Type: String
Required: No
