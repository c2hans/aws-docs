# DataLakeLifecycleExpiration
<a name="API_DataLakeLifecycleExpiration"></a>

Provide expiration lifecycle details of Amazon Security Lake object.

## Contents
<a name="API_DataLakeLifecycleExpiration_Contents"></a>

 ** days **   <a name="securitylake-Type-DataLakeLifecycleExpiration-days"></a>
Number of days before data expires in the Amazon Security Lake object.
Type: Integer
Valid Range: Minimum value of 1.
Required: No
