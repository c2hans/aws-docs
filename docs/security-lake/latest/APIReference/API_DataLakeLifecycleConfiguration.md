# DataLakeLifecycleConfiguration
<a name="API_DataLakeLifecycleConfiguration"></a>

Provides lifecycle details of Amazon Security Lake object.

## Contents
<a name="API_DataLakeLifecycleConfiguration_Contents"></a>

 ** expiration **   <a name="securitylake-Type-DataLakeLifecycleConfiguration-expiration"></a>
Provides data expiration details of Amazon Security Lake object.
Type: [DataLakeLifecycleExpiration](API_DataLakeLifecycleExpiration.md) object
Required: No

 ** transitions **   <a name="securitylake-Type-DataLakeLifecycleConfiguration-transitions"></a>
Provides data storage transition details of Amazon Security Lake object.
Type: Array of [DataLakeLifecycleTransition](API_DataLakeLifecycleTransition.md) objects
Required: No
