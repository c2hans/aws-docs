# DataLakeEncryptionConfiguration
<a name="API_DataLakeEncryptionConfiguration"></a>

Provides encryption details of Amazon Security Lake object.

## Contents
<a name="API_DataLakeEncryptionConfiguration_Contents"></a>

 ** kmsKeyId **   <a name="securitylake-Type-DataLakeEncryptionConfiguration-kmsKeyId"></a>
The identifier of KMS encryption key used by Amazon Security Lake to encrypt the Security Lake object.
Type: String
Required: No
