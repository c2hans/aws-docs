# AcknowledgeDeadLetterQueueRecordsRequestEntry

A dead-letter record to acknowledge, identified by its receipt handle.

## Contents
<a name="API_AcknowledgeDeadLetterQueueRecordsRequestEntry_Contents"></a>

 ** ReceiptHandle **   <a name="Streams-Type-AcknowledgeDeadLetterQueueRecordsRequestEntry-ReceiptHandle"></a>
The receipt handle of the record to acknowledge, as returned by [ReceiveDeadLetterQueueRecords](API_ReceiveDeadLetterQueueRecords.md).
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes
