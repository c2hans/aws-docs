# PartitionSpec
<a name="API_PartitionSpec"></a>

Specifies how the destination table is partitioned.

## Contents
<a name="API_PartitionSpec_Contents"></a>

 ** PartitionFields **   <a name="Streams-Type-PartitionSpec-PartitionFields"></a>
The list of partition fields.
Type: Array of [PartitionField](API_PartitionField.md) objects
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Required: Yes
