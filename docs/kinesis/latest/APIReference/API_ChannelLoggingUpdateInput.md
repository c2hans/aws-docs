# ChannelLoggingUpdateInput
<a name="API_ChannelLoggingUpdateInput"></a>

The updated Amazon CloudWatch Logs configuration for a channel. Used in [UpdateChannel](API_UpdateChannel.md).

## Contents
<a name="API_ChannelLoggingUpdateInput_Contents"></a>

 ** CloudWatchLogs **   <a name="Streams-Type-ChannelLoggingUpdateInput-CloudWatchLogs"></a>
The updated Amazon CloudWatch Logs settings, including whether logging is enabled and the target log group and log stream.
Type: [CloudWatchLogsUpdateInput](API_CloudWatchLogsUpdateInput.md) object
Required: Yes
