# Document History for AWS KMS Cryptographic Details
<a name="doc-history"></a>

The following table describes important changes to the documentation for AWS Key Management Service Cryptographic Details. We also update the documentation frequently to address the feedback that you send to us.

| Change | Description | Date |
| --- |--- |--- |
| [Updated content](https://docs.aws.amazon.com/kms/latest/cryptographic-details/replicate-key-details.html) | Added details about the implementation of the AWS KMS `ReplicateKey` operation. | October 28, 2021 |
| [Documentation change](https://docs.aws.amazon.com/kms/latest/cryptographic-details/basic-concepts.html) | Replace the term *customer master key (CMK)* with *AWS KMS key* and *KMS key*. | August 30, 2021 |
| [Initial release](#doc-history) | Created this guide from the KMS Cryptographic Details technical paper | December 30, 2020 |
