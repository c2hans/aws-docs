# Data Types
<a name="API_Types"></a>

The AWS Key Management Service API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AliasListEntry](API_AliasListEntry.md)
+  [CustomKeyStoresListEntry](API_CustomKeyStoresListEntry.md)
+  [GrantConstraints](API_GrantConstraints.md)
+  [GrantListEntry](API_GrantListEntry.md)
+  [KeyLastUsageData](API_KeyLastUsageData.md)
+  [KeyListEntry](API_KeyListEntry.md)
+  [KeyMetadata](API_KeyMetadata.md)
+  [MultiRegionConfiguration](API_MultiRegionConfiguration.md)
+  [MultiRegionKey](API_MultiRegionKey.md)
+  [RecipientInfo](API_RecipientInfo.md)
+  [RotationsListEntry](API_RotationsListEntry.md)
+  [Tag](API_Tag.md)
+  [XksKeyConfigurationType](API_XksKeyConfigurationType.md)
+  [XksProxyAuthenticationCredentialType](API_XksProxyAuthenticationCredentialType.md)
+  [XksProxyConfigurationType](API_XksProxyConfigurationType.md)
