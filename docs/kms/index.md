# AWS Key Management Service Documentation

AWS Key Management Service (AWS KMS) is an encryption and key management service scaled for the cloud. AWS KMS keys and functionality are used by other AWS services, and you can use them to protect data in your own applications that use AWS.

- [Developer Guide](/kms/latest/developerguide/): Provides conceptual overviews of AWS Key Management Service and explains how to use it to protect data in your own applications that use AWS.
- [API Reference](/kms/latest/APIReference/): Describes in detail the API operations for AWS Key Management Service. Also provides sample requests, responses, and errors for the supported web services protocols.
- [AWS KMS in the AWS CLI Reference](/cli/latest/reference/kms/index.html): Describes the AWS Key Management Service commands that are available in the AWS Command Line Interface.
