# ListExportsRequestFilters
<a name="API_ListExportsRequestFilters"></a>

List exports request filters.

## Contents
<a name="API_ListExportsRequestFilters_Contents"></a>

 ** exportIDs **   <a name="mgn-Type-ListExportsRequestFilters-exportIDs"></a>
List exports request filters export ids.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 10 items.
Length Constraints: Fixed length of 24.
Pattern: `export-[0-9a-zA-Z]{17}`
Required: No
