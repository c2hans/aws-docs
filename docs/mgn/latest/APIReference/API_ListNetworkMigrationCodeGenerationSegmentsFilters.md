# ListNetworkMigrationCodeGenerationSegmentsFilters
<a name="API_ListNetworkMigrationCodeGenerationSegmentsFilters"></a>

Filters for listing code generation segments.

## Contents
<a name="API_ListNetworkMigrationCodeGenerationSegmentsFilters_Contents"></a>

 ** segmentIDs **   <a name="mgn-Type-ListNetworkMigrationCodeGenerationSegmentsFilters-segmentIDs"></a>
A list of segment IDs to filter by.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 10 items.
Length Constraints: Fixed length of 36.
Pattern: `[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}`
Required: No
