# SplitOperation
<a name="API_SplitOperation"></a>

An operation that splits a construct into multiple constructs with different CIDR blocks.

## Contents
<a name="API_SplitOperation_Contents"></a>

 ** splitConstructs **   <a name="mgn-Type-SplitOperation-splitConstructs"></a>
The list of split targets with their CIDR blocks.
Type: Array of [SplitConstruct](API_SplitConstruct.md) objects
Array Members: Fixed number of 2 items.
Required: No
