# SplitConstruct
<a name="API_SplitConstruct"></a>

A split target specifying the CIDR block for the new construct.

## Contents
<a name="API_SplitConstruct_Contents"></a>

 ** cidrBlock **   <a name="mgn-Type-SplitConstruct-cidrBlock"></a>
The CIDR block for the split construct.
Type: String
Pattern: `([0-9]{1,3}\.){3}[0-9]{1,3}/[0-9]{1,2}`
Required: No
