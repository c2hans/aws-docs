# MergeOperation
<a name="API_MergeOperation"></a>

An operation that merges constructs from different segments into the target construct.

## Contents
<a name="API_MergeOperation_Contents"></a>

 ** mergeConstructs **   <a name="mgn-Type-MergeOperation-mergeConstructs"></a>
The list of constructs to merge into the target.
Type: Array of [MergeConstruct](API_MergeConstruct.md) objects
Array Members: Fixed number of 1 item.
Required: No
