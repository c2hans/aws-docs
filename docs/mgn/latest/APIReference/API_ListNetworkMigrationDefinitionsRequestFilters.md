# ListNetworkMigrationDefinitionsRequestFilters
<a name="API_ListNetworkMigrationDefinitionsRequestFilters"></a>

Filters for listing network migration definitions.

## Contents
<a name="API_ListNetworkMigrationDefinitionsRequestFilters_Contents"></a>

 ** networkMigrationDefinitionIDs **   <a name="mgn-Type-ListNetworkMigrationDefinitionsRequestFilters-networkMigrationDefinitionIDs"></a>
A list of definition IDs to filter by.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 20 items.
Length Constraints: Fixed length of 21.
Pattern: `nmd-[0-9a-zA-Z]{17}`
Required: No
