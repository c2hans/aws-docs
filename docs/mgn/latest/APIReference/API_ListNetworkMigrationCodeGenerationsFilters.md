# ListNetworkMigrationCodeGenerationsFilters
<a name="API_ListNetworkMigrationCodeGenerationsFilters"></a>

Filters for listing code generation jobs.

## Contents
<a name="API_ListNetworkMigrationCodeGenerationsFilters_Contents"></a>

 ** jobIDs **   <a name="mgn-Type-ListNetworkMigrationCodeGenerationsFilters-jobIDs"></a>
A list of job IDs to filter by.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 10 items.
Length Constraints: Fixed length of 36.
Pattern: `[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}`
Required: No
