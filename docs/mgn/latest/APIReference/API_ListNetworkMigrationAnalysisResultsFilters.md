# ListNetworkMigrationAnalysisResultsFilters
<a name="API_ListNetworkMigrationAnalysisResultsFilters"></a>

Filters for listing network migration analysis results.

## Contents
<a name="API_ListNetworkMigrationAnalysisResultsFilters_Contents"></a>

 ** vpcIDs **   <a name="mgn-Type-ListNetworkMigrationAnalysisResultsFilters-vpcIDs"></a>
A list of VPC IDs to filter results by.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 10 items.
Pattern: `vpc-([0-9a-f]){8}(([0-9a-f]){9})?`
Required: No
