# Target storage configuration
<a name="target-storage"></a>

AWS Transform MGN supports two target storage types for replication. You can select the storage type that best suits your workload requirements:
+ **Amazon Elastic Block Store (Amazon EBS)** – The default storage type. For configuration details, see [Amazon EBS configuration](ebs-storage.md).
+ **Amazon FSx for NetApp ONTAP** – Enterprise file storage with NetApp ONTAP capabilities. For setup instructions, see [FSx for ONTAP configuration](fsx-ontap.md).
