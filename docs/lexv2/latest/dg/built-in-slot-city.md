# AMAZON.City
<a name="built-in-slot-city"></a>

Provides a list of local and world cities. The slot type recognizes common variations of city names. Amazon Lex V2 doesn't convert from a variation to an official name.

Examples:
+ New York
+ Reykjavik
+ Tokyo
+ Versailles
