# Iteration statement
<a name="ecma-iteration"></a>

Iteration statements can be any one of the following:

```
// Do..While statement
do {
   statements
} while (expressions)

// While Loop
while (expressions) {
   statements
}

// For Loop
for ([initialization]; [condition]; [final-expression])
   statement

// For..In
for (variable in object) {
  statement
}
```
