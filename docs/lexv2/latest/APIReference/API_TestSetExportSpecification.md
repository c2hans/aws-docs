# TestSetExportSpecification
<a name="API_TestSetExportSpecification"></a>

Contains information about the test set that is exported.

## Contents
<a name="API_TestSetExportSpecification_Contents"></a>

 ** testSetId **   <a name="lexv2-Type-TestSetExportSpecification-testSetId"></a>
The unique identifier of the test set.
Type: String
Length Constraints: Fixed length of 10.
Pattern: `^[0-9a-zA-Z]+$`
Required: Yes
