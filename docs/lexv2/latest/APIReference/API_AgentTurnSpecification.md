# AgentTurnSpecification
<a name="API_AgentTurnSpecification"></a>

 ** agentPrompt **   <a name="lexv2-Type-AgentTurnSpecification-agentPrompt"></a>

Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes
