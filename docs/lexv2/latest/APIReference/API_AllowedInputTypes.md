# AllowedInputTypes
<a name="API_AllowedInputTypes"></a>

Specifies the allowed input types.

## Contents
<a name="API_AllowedInputTypes_Contents"></a>

 ** allowAudioInput **   <a name="lexv2-Type-AllowedInputTypes-allowAudioInput"></a>
Indicates whether audio input is allowed.
Type: Boolean
Required: Yes

 ** allowDTMFInput **   <a name="lexv2-Type-AllowedInputTypes-allowDTMFInput"></a>
Indicates whether DTMF input is allowed.
Type: Boolean
Required: Yes
