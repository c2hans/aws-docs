# BuiltInIntentSortBy
<a name="API_BuiltInIntentSortBy"></a>

Specifies attributes for sorting a list of built-in intents.

## Contents
<a name="API_BuiltInIntentSortBy_Contents"></a>

 ** attribute **   <a name="lexv2-Type-BuiltInIntentSortBy-attribute"></a>
The attribute to use to sort the list of built-in intents.
Type: String
Valid Values: `IntentSignature`
Required: Yes

 ** order **   <a name="lexv2-Type-BuiltInIntentSortBy-order"></a>
The order to sort the list. You can specify ascending or descending order.
Type: String
Valid Values: `Ascending | Descending`
Required: Yes
