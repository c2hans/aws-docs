# AWS Transform for mainframe Runtime Error Codes related to SQL
<a name="ba-runtime-error-codes-s"></a>

SQL error codes, prefixed with `BA-S`.

| Key | Severity | Text | Additional details |
| --- | --- | --- | --- |
| BA-S0001 | Error | SQL Error: Failed to process column names. Check the SQL query syntax and ensure all column references are valid. |  |
| BA-S0002 | Error | SQL Error: Failed to process index. An I/O exception has occurred when getting blob to update it on table. |  |
| BA-S0003 | Error | SQL Error: Failed to update and save index metadata. Error while updating index and saving index into table. |  |
| BA-S0004 | Error | SQL Error: Failed to retrieve last record. Exception occurred while retrieving last record. |  |
| BA-S0005 | Error | SQL Error: Failed to load pages and indexes from table. |  |
| BA-S0006 | Error | SQL Error: Error Indexing data set. Record count mismatch during append indexing. |  |
| BA-S0007 | Error | SQL Error: Error while reading intermediate table for appending indexes on data set. |  |
| BA-S0008 | Error | SQL Error: Error while persisting indexes on table. |  |
