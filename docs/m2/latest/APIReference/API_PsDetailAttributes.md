The supported properties for a PS type data set.

## Contents
<a name="API_PsDetailAttributes_Contents"></a>

 ** encoding **   <a name="m2-Type-PsDetailAttributes-encoding"></a>
The character set encoding of the data set.
Type: String
Required: Yes

 ** format **   <a name="m2-Type-PsDetailAttributes-format"></a>
The format of the data set records.
Type: String
Required: Yes
