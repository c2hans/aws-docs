# RegisteredServiceNowDetails
<a name="API_RegisteredServiceNowDetails"></a>

Details specific to a registered ServiceNow instance.

## Contents
<a name="API_RegisteredServiceNowDetails_Contents"></a>

 ** instanceUrl **   <a name="devopsagent-Type-RegisteredServiceNowDetails-instanceUrl"></a>
The ServiceNow instance url
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `https://[a-zA-Z0-9]([a-zA-Z0-9.-]*[a-zA-Z0-9])\.service-now\.com/?`
Required: No
