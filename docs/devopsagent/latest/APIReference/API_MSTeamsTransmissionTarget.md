# MSTeamsTransmissionTarget
<a name="API_MSTeamsTransmissionTarget"></a>

Specifies the Microsoft Teams channels that receive different types of agent notifications.

## Contents
<a name="API_MSTeamsTransmissionTarget_Contents"></a>

 ** opsOncallTarget **   <a name="devopsagent-Type-MSTeamsTransmissionTarget-opsOncallTarget"></a>
The Microsoft Teams channel that receives notifications from the On-call Agent.
Type: [MSTeamsChannel](API_MSTeamsChannel.md) object
Required: No

 ** opsSRETarget **   <a name="devopsagent-Type-MSTeamsTransmissionTarget-opsSRETarget"></a>
The Microsoft Teams channel that receives notifications from the SRE Agent.
Type: [MSTeamsChannel](API_MSTeamsChannel.md) object
Required: No
