# RecommendationContent
<a name="API_RecommendationContent"></a>

Content of a recommendation

## Contents
<a name="API_RecommendationContent_Contents"></a>

 ** summary **   <a name="devopsagent-Type-RecommendationContent-summary"></a>
A brief summary of the recommendation.
Type: String
Required: Yes

 ** spec **   <a name="devopsagent-Type-RecommendationContent-spec"></a>
Agent-ready specification with detailed implementation steps
Type: String
Length Constraints: Minimum length of 0. Maximum length of 100000.
Required: No
