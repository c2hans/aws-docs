# AssetSourceUrlContent
<a name="API_AssetSourceUrlContent"></a>

Content for an asset sourced from an external URL.

## Contents
<a name="API_AssetSourceUrlContent_Contents"></a>

 ** url **   <a name="devopsagent-Type-AssetSourceUrlContent-url"></a>
The source URL to import asset content from
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Pattern: `https://.*`
Required: Yes
