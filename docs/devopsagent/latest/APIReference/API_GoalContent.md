# GoalContent
<a name="API_GoalContent"></a>

Content of a goal

## Contents
<a name="API_GoalContent_Contents"></a>

 ** description **   <a name="devopsagent-Type-GoalContent-description"></a>
A detailed description of the goal.
Type: String
Required: Yes

 ** objectives **   <a name="devopsagent-Type-GoalContent-objectives"></a>
The objectives to be achieved for this goal.
Type: String
Required: Yes
