# AssetVersionMetadata
<a name="API_AssetVersionMetadata"></a>

Metadata for a single version of an asset, including the version number and timestamps.

## Contents
<a name="API_AssetVersionMetadata_Contents"></a>

 ** createdAt **   <a name="devopsagent-Type-AssetVersionMetadata-createdAt"></a>
Timestamp when this asset version was created
Type: Timestamp
Required: Yes

 ** updatedAt **   <a name="devopsagent-Type-AssetVersionMetadata-updatedAt"></a>
Timestamp when this asset version was last updated
Type: Timestamp
Required: Yes

 ** version **   <a name="devopsagent-Type-AssetVersionMetadata-version"></a>
The version number of this asset
Type: Integer
Required: Yes
