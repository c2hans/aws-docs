# UserReference
<a name="API_UserReference"></a>

Reference to a user in the system

## Contents
<a name="API_UserReference_Contents"></a>

 ** userId **   <a name="devopsagent-Type-UserReference-userId"></a>
The unique identifier for the user
Type: String
Required: Yes

 ** userType **   <a name="devopsagent-Type-UserReference-userType"></a>
The type of user
Type: String
Valid Values: `IAM | IDC | IDP`
Required: Yes
