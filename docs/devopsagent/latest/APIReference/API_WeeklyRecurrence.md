# WeeklyRecurrence
<a name="API_WeeklyRecurrence"></a>

Weekly recurrence

## Contents
<a name="API_WeeklyRecurrence_Contents"></a>

 ** dayOfWeek **   <a name="devopsagent-Type-WeeklyRecurrence-dayOfWeek"></a>
Day of week the window recurs on
Type: String
Valid Values: `MONDAY | TUESDAY | WEDNESDAY | THURSDAY | FRIDAY | SATURDAY | SUNDAY`
Required: Yes
