# MSTeamsChannel
<a name="API_MSTeamsChannel"></a>

Represents a channel in a Microsoft Teams team that the DevOps Agent service can send notifications to.

## Contents
<a name="API_MSTeamsChannel_Contents"></a>

 ** channelId **   <a name="devopsagent-Type-MSTeamsChannel-channelId"></a>
The unique identifier of the Microsoft Teams channel, for example 19:abc123def456@thread.tacv2.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes

 ** channelName **   <a name="devopsagent-Type-MSTeamsChannel-channelName"></a>
The name of the Microsoft Teams channel.
Type: String
Required: Yes
