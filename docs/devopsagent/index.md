# AWS DevOps Agent

AWS DevOps Agent monitors AWS infrastructure, performs automated root cause analysis on operational events, runs remediation procedures, and configures preventive measures to maintain system reliability.

- [DevOps Agent User Guide](/devopsagent/latest/userguide/): This guide shows you how to set up and manage AWS DevOps Agent for automated infrastructure monitoring and remediation.
- [DevOps Agent API Reference](/devopsagent/latest/APIReference): Describes the API operations for DevOps Agent.
