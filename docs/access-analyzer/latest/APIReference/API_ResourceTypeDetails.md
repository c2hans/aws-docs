# ResourceTypeDetails
<a name="API_ResourceTypeDetails"></a>

Contains information about the total number of active cross-account and public findings for a resource type of an external access analyzer.

## Contents
<a name="API_ResourceTypeDetails_Contents"></a>

 ** totalActiveCrossAccount **   <a name="accessanalyzer-Type-ResourceTypeDetails-totalActiveCrossAccount"></a>
The total number of active cross-account findings for the resource type.
Type: Integer
Required: No

 ** totalActiveErrors **   <a name="accessanalyzer-Type-ResourceTypeDetails-totalActiveErrors"></a>
The total number of active errors for the resource type.
Type: Integer
Required: No

 ** totalActivePublic **   <a name="accessanalyzer-Type-ResourceTypeDetails-totalActivePublic"></a>
The total number of active public findings for the resource type.
Type: Integer
Required: No
