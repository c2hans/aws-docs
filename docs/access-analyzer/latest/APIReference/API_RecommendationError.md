# RecommendationError
<a name="API_RecommendationError"></a>

Contains information about the reason that the retrieval of a recommendation for a finding failed.

## Contents
<a name="API_RecommendationError_Contents"></a>

 ** code **   <a name="accessanalyzer-Type-RecommendationError-code"></a>
The error code for a failed retrieval of a recommendation for a finding.
Type: String
Required: Yes

 ** message **   <a name="accessanalyzer-Type-RecommendationError-message"></a>
The error message for a failed retrieval of a recommendation for a finding.
Type: String
Required: Yes
