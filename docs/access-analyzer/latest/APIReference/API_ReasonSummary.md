# ReasonSummary
<a name="API_ReasonSummary"></a>

Contains information about the reasoning why a check for access passed or failed.

## Contents
<a name="API_ReasonSummary_Contents"></a>

 ** description **   <a name="accessanalyzer-Type-ReasonSummary-description"></a>
A description of the reasoning of a result of checking for access.
Type: String
Required: No

 ** statementId **   <a name="accessanalyzer-Type-ReasonSummary-statementId"></a>
The identifier for the reason statement.
Type: String
Required: No

 ** statementIndex **   <a name="accessanalyzer-Type-ReasonSummary-statementIndex"></a>
The index number of the reason statement.
Type: Integer
Required: No
