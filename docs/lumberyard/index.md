# Amazon Lumberyard (No longer offered)

Amazon Lumberyard is no longer offered. Customers should instead use Open 3D Engine (O3DE), the official successor to Lumberyard. Open 3D Engine is a cross-platform, open-source game engine developed by a community (including Amazon and others), available under the Apache 2.0 license.

Amazon no longer offers Amazon Lumberyard binaries for download. You can access an archived version of the public GitHub repository for [Lumberyard source code](https://github.com/aws/lumberyard/) and the [Lumberyard User Guide](https://github.com/awsdocs/amazon-lumberyard-user-guide/). Lumberyard documentation is also available on request as a PDF. Current users of Lumberyard should plan on migrating their projects to [Open 3D Engine](https://o3de.org), the official successor to Lumberyard. See the [Lumberyard FAQ](https://aws.amazon.com/lumberyard/faq/) for more information. For current Lumberyard users and customers who need continued assistance or access to PDF distributions of the Lumberyard documentation, please [contact Amazon Lumberyard Support](https://pages.awscloud.com/Amazon-Game-Tech-Contact-Us.html).

- [Open 3D Engine](https://o3de.org): Open 3D Engine is an open-source, Apache 2.0-licensed simulation engine for building games and 3D worlds, maintained by a community of contributors.
- [Migrate from Lumberyard to Open 3D Engine](https://github.com/o3de/community/tree/main/Migration%20Guides/Lumberyard%20to%20O3DE): The Open 3D Engine project keeps a contributor-maintained guide to help developers using Amazon Lumberyard move to Open 3D Engine.
- [Amazon Lumberyard documentation archive](https://github.com/awsdocs/amazon-lumberyard-user-guide/): Access an archive of the Amazon Lumberyard documentation through our GitHub mirror.
