# AWS Startup Advisor

AWS Startup Advisor is your AI-powered build assistant, available as an extension for Claude Code, Cursor, VS Code, and Kiro or as a standalone experience on the web. It gives you and your coding agents tailored guidance on AI, architecture, costs, credits, security, and migration, matched to your startup's stack and stage. Whether you're starting from an idea or moving an existing app to AWS, it meets you where you build and adapts its recommendations as your startup grows.

- [User Guide](/startupadvisor/latest/userguide/): Learn how to use AWS Startup Advisor to get AWS-vetted guidance for architecture, cost, security, scalability, and migration. This guide covers installing the extension in your IDE, using AWS Startup Advisor on the web, the bundled skills, and the credits and cost tracker.
