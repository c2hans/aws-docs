# AWS Startup Advisor

AWS Startup Advisor gives startup founders and their AI coding agents the skills, tools, and knowledge to build, scale, migrate, and operate on AWS efficiently. AWS Startup Advisor is available as a plugin for Claude Code and Codex, an IDE extension for Cursor, VS Code, and Kiro, plus a web experience on startups.aws.com. It provides tailored guidance on AI, architecture, costs, credits, security, operations, and migration, matched to your startup's stack and stage. Whether you're starting from an idea or moving an existing app to AWS, AWS Startup Advisor meets you where you build and adapts its recommendations as your startup grows.

- [User Guide](/startupadvisor/latest/userguide/): Learn how to use AWS Startup Advisor to get AWS-vetted guidance for AI, architecture, costs, credits, security, operations, and migration. This guide covers installing and using the AWS Startup Advisor plugin and IDE extension, or accessing AWS Startup Advisor on the web, the bundled skills, features, and more.
