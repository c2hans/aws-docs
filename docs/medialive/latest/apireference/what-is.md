# What Is the AWS Elemental MediaLive API?
<a name="what-is"></a>

This is the AWS Elemental MediaLive REST API Reference. It provides information on the URL, request contents, and response contents of each AWS Elemental MediaLive REST operation.

We assume that you have the IAM permissions that you need to use AWS Elemental MediaLive via the REST API. We also assume that you are familiar with the features and operations of AWS Elemental MediaLive, as described in the [*AWS Elemental MediaLive User Guide*](https://docs.aws.amazon.com/medialive/latest/ug/what-is.html).
