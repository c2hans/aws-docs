# Creating an HLS output group
<a name="opg-hls"></a>

When you create a AWS Elemental MediaLive channel, you might want to include an HLS output group. For information about the use cases for an HLS output group, see [Containers, protocols, and downstream systems](outputs-supported-containers-downstream-systems.md). For information about choosing between an HLS and MediaPackage output group, see [Delivering to MediaPackage](delivering-to-mediapackage.md).
