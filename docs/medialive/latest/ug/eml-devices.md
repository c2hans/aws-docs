# Working with Link input device
<a name="eml-devices"></a>

A Link input device is the interface in MediaLive for an AWS Elemental Link *hardware device* that's connected to MediaLive. For general information about this hardware, see [Working with AWS Elemental Link](feature-elink.md).

For information about working with the Link input device in MediaLive, see [Setting up AWS Elemental Link](setup-devices.md).
