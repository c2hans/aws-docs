# Input types supported in MediaLive
<a name="inputs-supported-types"></a>

MediaLive supports the following input types. For more information about these types, see the sections that follow.
+ CDI
+ HLS
+ Link
+ MediaConnect
+ MediaConnect Router
+ MP4
+ RTMP Pull
+ RTMP Push
+ RTP
+ SDI
+ SMPTE 2110
+ SRT Caller
+ SRT Listener
+ TS
