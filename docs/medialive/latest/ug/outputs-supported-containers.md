# Output types supported in MediaLive
<a name="outputs-supported-containers"></a>

MediaLive supports the following containers. Each of these containers is a different type of output group.
+ Archive
+ CMAF Ingest
+ Frame Capture
+ HLS
+ MediaConnect Router
+ MediaPackage
+ Microsoft Smooth
+ Multiplex
+ RTMP
+ RTMPS
+ SRT
+ UDP
