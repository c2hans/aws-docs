# Codecs supported in MediaLive inputs
<a name="inputs-supported-list"></a>

MediaLive supports the following video codecs in sources:
+ H.264 (AVC)
+ H.265 (HEVC)
+ MPEG-2

MediaLive supports the following audio codecs in sources:
+ AAC
+ Dolby Digital
+ Dolby E wrapped in PCM
+ Dolby Digital Plus
+ MPEG Audio
+ PCM
