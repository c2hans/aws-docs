# Setting up users
<a name="emla-deploy-users"></a>

You must set up IAM users with permissions so that they can configure a MediaLive Anywhere cluster, and/or so that they can run channels on on-premises node hardware.

A user who is already set up as an IAM user or administrative user performs the tasks in this section.

**Topics**
+ [Create users and assign permissions](emla-deploy-users-permissions.md)
+ [Create special FAS policies](emla-deploy-users-ecs-permissions.md)
