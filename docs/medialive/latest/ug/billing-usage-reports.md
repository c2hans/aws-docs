# Understanding billing and usage reports in MediaLive
<a name="billing-usage-reports"></a>

When you view your AWS billing and usage reports in AWS Cost Explorer or AWS Cost and Usage Reports, MediaLive usage types appear as coded strings. This topic explains how to decode those strings so you can understand your MediaLive charges. For information about pricing rates, see [AWS Elemental MediaLive Pricing](https://aws.amazon.com/medialive/pricing/).
