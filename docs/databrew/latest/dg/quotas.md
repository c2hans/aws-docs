# Quotas for AWS Glue DataBrew
<a name="quotas"></a>

You can view your DataBrew service quotas in the [AWS Service Quotas](https://console.aws.amazon.com/servicequotas/home#!/services/databrew/quotas) console. You can also request a quota increase, for any quota that's adjustable.
