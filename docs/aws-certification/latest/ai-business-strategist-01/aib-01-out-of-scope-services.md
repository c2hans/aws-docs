# Out-of-scope AWS services and features
<a name="aib-01-out-of-scope-services"></a>

This exam focuses on AI strategy, governance, and business transformation rather than technical implementation. AWS services and features outside the in-scope list are out of scope, including but not limited to the following categories and services:
+ Infrastructure and compute (for example, Amazon EC2, AWS Lambda)
+ Networking and content delivery (for example, Amazon VPC, Amazon CloudFront)
+ Databases and storage (for example, Amazon RDS, Amazon S3)
+ Containers and orchestration (for example, Amazon Elastic Container Service [Amazon ECS], Amazon Elastic Kubernetes Service [Amazon EKS])
+ Developer tools and DevOps (for example, AWS CodePipeline, AWS CloudFormation)
+ Security implementation and configuration (for example, AWS Identity and Access Management [IAM] policy writing, AWS Key Management Service [AWS KMS])
+ Internet of Things (IoT), media, and other specialized services

Candidates are not expected to know how to configure, deploy, or administer any AWS service. The exam assesses the ability to understand AI services at a strategic level and make informed business decisions about their application.
