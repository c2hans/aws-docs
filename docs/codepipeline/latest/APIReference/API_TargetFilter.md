# TargetFilter
<a name="API_TargetFilter"></a>

Filters the list of targets.

## Contents
<a name="API_TargetFilter_Contents"></a>

 ** name **   <a name="CodePipeline-Type-TargetFilter-name"></a>
The name on which to filter.
Type: String
Valid Values: `TARGET_STATUS`
Required: No

 ** values **   <a name="CodePipeline-Type-TargetFilter-values"></a>
The values on which to filter.
Type: Array of strings
Length Constraints: Minimum length of 1.
Required: No
