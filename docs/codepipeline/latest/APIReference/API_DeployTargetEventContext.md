# DeployTargetEventContext
<a name="API_DeployTargetEventContext"></a>

The context for the event for the deploy action.

## Contents
<a name="API_DeployTargetEventContext_Contents"></a>

 ** message **   <a name="CodePipeline-Type-DeployTargetEventContext-message"></a>
The context message for the event for the deploy action.
Type: String
Required: No

 ** ssmCommandId **   <a name="CodePipeline-Type-DeployTargetEventContext-ssmCommandId"></a>
The command ID for the event for the deploy action.
Type: String
Required: No
