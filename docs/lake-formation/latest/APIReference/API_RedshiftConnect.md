# RedshiftConnect
<a name="API_RedshiftConnect"></a>

Configuration for enabling trusted identity propagation with Redshift Connect.

## Contents
<a name="API_RedshiftConnect_Contents"></a>

 ** Authorization **   <a name="lakeformation-Type-RedshiftConnect-Authorization"></a>
The authorization status for Redshift Connect. Valid values are ENABLED or DISABLED.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
