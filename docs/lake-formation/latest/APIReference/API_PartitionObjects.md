# PartitionObjects
<a name="API_PartitionObjects"></a>

A structure containing a list of partition values and table objects.

## Contents
<a name="API_PartitionObjects_Contents"></a>

 ** Objects **   <a name="lakeformation-Type-PartitionObjects-Objects"></a>
A list of table objects
Type: Array of [TableObject](API_TableObject.md) objects
Required: No

 ** PartitionValues **   <a name="lakeformation-Type-PartitionObjects-PartitionValues"></a>
A list of partition values.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 100 items.
Length Constraints: Maximum length of 1024.
Required: No
