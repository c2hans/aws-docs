# WriteOperation
<a name="API_WriteOperation"></a>

Defines an object to add to or delete from a governed table.

## Contents
<a name="API_WriteOperation_Contents"></a>

 ** AddObject **   <a name="lakeformation-Type-WriteOperation-AddObject"></a>
A new object to add to the governed table.
Type: [AddObjectInput](API_AddObjectInput.md) object
Required: No

 ** DeleteObject **   <a name="lakeformation-Type-WriteOperation-DeleteObject"></a>
An object to delete from the governed table.
Type: [DeleteObjectInput](API_DeleteObjectInput.md) object
Required: No
