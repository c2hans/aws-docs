# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

Validation exception message and name.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="artifact-Type-ValidationExceptionField-message"></a>
Message describing why the field failed validation.
Type: String
Required: Yes

 ** name **   <a name="artifact-Type-ValidationExceptionField-name"></a>
Name of validation exception.
Type: String
Required: Yes
