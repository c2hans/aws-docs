# Data Types
<a name="API_Types"></a>

The AWS Artifact API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AccountSettings](API_AccountSettings.md)
+  [AgreementSummary](API_AgreementSummary.md)
+  [Citation](API_Citation.md)
+  [CustomerAgreementSummary](API_CustomerAgreementSummary.md)
+  [InquiryContent](API_InquiryContent.md)
+  [InquiryDetail](API_InquiryDetail.md)
+  [InquiryFileContent](API_InquiryFileContent.md)
+  [InquirySummary](API_InquirySummary.md)
+  [QuerySummary](API_QuerySummary.md)
+  [ReportDetail](API_ReportDetail.md)
+  [ReportSummary](API_ReportSummary.md)
+  [ResponseVersion](API_ResponseVersion.md)
+  [TerminateCustomerAgreementSummary](API_TerminateCustomerAgreementSummary.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
