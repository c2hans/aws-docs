# AWS SDK for Python (Boto3) Documentation

The AWS SDK for Python (Boto3) provides a Python API for AWS infrastructure services. Using the SDK for Python (Boto), you can build applications on top of Amazon S3, Amazon EC2, Amazon DynamoDB, and more.
