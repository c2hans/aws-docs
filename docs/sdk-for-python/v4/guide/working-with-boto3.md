**Developer Preview**: This documentation covers the AWS SDK for Python v4, which is in Developer Preview and intended for evaluation and testing only. Do not use it for production workloads. For production applications, use the [AWS SDK for Python (Boto3)](https://docs.aws.amazon.com/boto3/latest/guide/quickstart.html). To understand the differences between the two SDKs, see [Choosing the right AWS SDK for Python](choosing-sdk.md).

# Working with AWS SDK for Python (Boto3)
<a name="working-with-boto3"></a>

If you have Boto3 code and want to evaluate the AWS SDK for Python v4, start with the following topics.
+ For the API-model and execution differences between the two SDKs, see [Key differences](working-with-boto3-differences.md).
+ For patterns that run both SDKs in one application, including configuration, synchronous and asynchronous code, and common pitfalls, see [Use both SDKs in one application](working-with-boto3-coexistence.md).
+ To rewrite individual Boto3 calls with the generated clients and types of the AWS SDK for Python v4, see [Convert AWS SDK for Python (Boto3) operations to the AWS SDK for Python v4](working-with-boto3-migration.md).
+ To decide which SDK fits your workload, see [Choosing the right AWS SDK for Python](choosing-sdk.md).
