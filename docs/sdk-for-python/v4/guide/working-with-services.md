# Working with AWS services

This chapter shows how to use the AWS SDK for Python v4 with Amazon DynamoDB, Amazon S3, Amazon SQS, Amazon SNS, and Amazon Bedrock Runtime. The examples use synchronous clients, except for event-stream operations, which require asynchronous clients. For more information about the two client types, see [Synchronous and asynchronous clients](using-sync-async.md).
