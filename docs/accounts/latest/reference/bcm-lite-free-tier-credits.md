# Earn additional credits
<a name="bcm-lite-free-tier-credits"></a>

**Warning**
We're currently releasing our new experience to a limited number of customers. You might not be able to access this experience yet.

If you are a new AWS customer, you can earn an additional USD $100 in credits regardless of your account plan by completing activities. These activities assist your learning of AWS services. You can find the activities in the Explore AWS widget on your AWS Console Home dashboard. All of these activities will incur AWS service charges that are deducted from your AWS Free Tier credits, however when you complete each activity, you receive USD $20 in credits.

**Activities to complete**
+ [Launch an instance using Amazon EC2](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/tutorial-launch-my-first-ec2-instance.html)
+ [Use a foundational model in the Amazon Bedrock playground](https://docs.aws.amazon.com/bedrock/latest/userguide/getting-started.html)
+ [Create a budget](https://docs.aws.amazon.com/cost-management/latest/userguide/budgets-create.html)
+ [Create a web app using Lambda](https://docs.aws.amazon.com/lambda/latest/dg/getting-started.html)
+ [Create an Amazon RDS database](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/CHAP_GettingStarted.CreatingConnecting.MariaDB.html)
