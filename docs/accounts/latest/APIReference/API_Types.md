# Data Types
<a name="API_Types"></a>

The AWS Account Management API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AlternateContact](API_AlternateContact.md)
+  [ContactInformation](API_ContactInformation.md)
+  [Region](API_Region.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
