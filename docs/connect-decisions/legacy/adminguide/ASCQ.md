# Amazon Q in AWS Supply Chain
<a name="ASCQ"></a>

The following APIs are used in Amazon Q in AWS Supply Chain.

```
scn:GetQMessage
scn:ListQMessages
scn:PutQMessageFeedback
scn:SendQMessage
scn:GetQEnablementStatus
scn:UpdateQEnablementStatus
```
