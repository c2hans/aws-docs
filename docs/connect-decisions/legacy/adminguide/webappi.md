# AWS Supply Chain web application APIs
<a name="webappi"></a>

 The APIs listed in this section are called by AWS Supply Chain applications on behalf of federated users. These APIs are not visible in the CloudTrail logs and are not captured in the *Service Authorization Reference* document, see [AWS Supply Chain](https://docs.aws.amazon.com/service-authorization/latest/reference/list_awssupplychain.html). Access to these APIs are controlled by AWS Supply Chain applications based on federated user role permissions. You shouldn’t try to control access to these APIs to prevent distrupting the AWS Supply Chain applications.
