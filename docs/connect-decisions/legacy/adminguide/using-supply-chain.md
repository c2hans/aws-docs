# Using the AWS Supply Chain
<a name="using-supply-chain"></a>

AWS Supply Chain is a cloud-based application that helps you gain visibility into your supply chain network, make informed decisions quickly, and improve supply chain resiliency. Using AWS Supply Chain, you can connect disparate data sources, generate insights using machine learning, and collaborate with internal teams and external partners. This section will walk you through some of AWS Supply Chain basic functions.
