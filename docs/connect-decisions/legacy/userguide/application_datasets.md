# Application datasets used in AWS Supply Chain Analytics
<a name="application_datasets"></a>

The following are the list of application datasets displayed in AWS Supply Chain Analytics.

- ** Demand Planning **
  - **Data entity:** Forecast / **Dataset name:** asc\_adp\_forecast / **Description:** Forecast generated by AWS Supply Chain's Demand Planning application.
  - **Data entity:** PlanningCycleAccuracy / **Dataset name:** asc\_adp\_planning\_cycle\_accuracy / **Description:** Forecast accuracy data generated by Demand Planning.

- ** Supply Planning **
  - **Data entity:** SupplyPlan / **Dataset name:** asc\_supply\_planning\_supply\_plan / **Description:** Replenishment plan generated by AWS Supply Chain's Supply Planning application.
  - **Data entity:** InboundOrderLine / **Dataset name:** asc\_supply\_planning\_inbound\_order\_line / **Description:** Data generated by AWS Supply Chain's Supply Planning application for Inbound\_order\_line.

- ** Insights **
  - **Data entity:** ProjectedInventory
  - **Dataset name:** asc\_insights\_projected\_inventory
  - **Description:** Projected inventory data generated by AWS Supply Chain's Insights application.

- ** Order Planning and Tracking **
  - **Data entity:** OrderLineInsights / **Dataset name:** asc\_insights\_order\_line\_insights / **Description:** Order line data generated by AWS Supply Chain's Order Planning and Tracking application.
  - **Data entity:** OrderInsights / **Dataset name:** asc\_insights\_order\_insights / **Description:** Order data generated by AWS Supply Chain's Order Planning and Tracking application.
