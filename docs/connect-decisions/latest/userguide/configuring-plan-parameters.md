# Configuring Plan Parameters
<a name="configuring-plan-parameters"></a>

## Configure an existing Supply Plan
<a name="configuring-plan-parameters-configure-existing-supply-plan"></a>

 You can navigate to plan configuration page by selecting **Configuration** from the meatball menu on the top of the planning hub or action menu from plan list. You can either manually update plan configuration change or chat with Decision Teammate to make the change.
