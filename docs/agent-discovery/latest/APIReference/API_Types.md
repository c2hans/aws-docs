# Data Types

The Agent Discovery API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [DescriptorEntry](API_DescriptorEntry.md)
+  [DescriptorSource](API_DescriptorSource.md)
+  [DescriptorSourceUrl](API_DescriptorSourceUrl.md)
+  [Identifier](API_Identifier.md)
+  [ProvenanceLink](API_ProvenanceLink.md)
+  [PublicRecord](API_PublicRecord.md)
+  [TrustManifest](API_TrustManifest.md)
