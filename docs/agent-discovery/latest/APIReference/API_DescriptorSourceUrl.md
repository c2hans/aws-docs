# DescriptorSourceUrl

A URL that hosts descriptor content.

## Contents
<a name="API_DescriptorSourceUrl_Contents"></a>

 ** url **   <a name="agentdiscovery-Type-DescriptorSourceUrl-url"></a>

Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: Yes
