# Data Types
<a name="API_Types"></a>

The Interconnect API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AttachPoint](API_AttachPoint.md)
+  [AttachPointDescriptor](API_AttachPointDescriptor.md)
+  [Bandwidths](API_Bandwidths.md)
+  [Connection](API_Connection.md)
+  [ConnectionSummary](API_ConnectionSummary.md)
+  [Environment](API_Environment.md)
+  [Provider](API_Provider.md)
+  [RemoteAccountIdentifier](API_RemoteAccountIdentifier.md)
