# AWS Managed Services Documentation

AWS Managed Services (AMS) helps you operate AWS more efficiently and securely. Leveraging AWS services and a growing library of automations, configurations, and run books, AMS can augment and optimize your operational capabilities in both new and existing AWS environments.

## AMS Accelerate Operations Plan

- [AMS Accelerate User Guide](/managedservices/latest/accelerate-guide/): Information about using the AMS Accelerate operations plan for providing operational capabilities such as monitoring, incident management, security guidance, patch support, and backup for new or existing AWS workloads. Includes getting started information.

## AMS Advanced Operations Plan

- [AMS Advanced User Guide](/managedservices/latest/userguide/): Information about using the AMS Advanced operations plan for both multi-account landing zone and single-account landing zone users. This includes an overview of the services AMS provides, details on using the AMS Advanced operations plan, and information about requests for change (RFCs) and change types.
- [AMS Advanced Onboarding Guide](/managedservices/latest/onboardingguide/): Information about onboarding to the AMS Advanced operations plan for both multi-account landing zone and single-account landing zone users, including questions, considerations, and service overviews.
- [AWS Managed Services Application Developers Guide](/managedservices/latest/appguide/): Information about developing applications within the AMS Advanced operations plan environment. This includes details about application migration with Workload Ingest or CFN Template migration, and a quick start section for multi-procedure tasks.
- [AMS Change Type Reference](/managedservices/latest/ctref/): Reference information about change types in the AMS Advanced operations plan, including console and CLI usage examples for each change type.
- [AMS Change Management API Reference](/managedservices/latest/ApiReference-cm/): Reference information for the change management API in the AMS Advanced operations plan.

## AMS Support Application Library

- [ECO Support Guide](/EDI/latest/eco-support-guide/): Information about EDI Cloud Operations (ECO), an AMS operations plan that offers end-to-end operational solutions and support for Energy Data Insights (EDI) on AWS
