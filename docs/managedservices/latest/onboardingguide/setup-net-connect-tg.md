# Centralized edge connectivity using Transit Gateway
<a name="setup-net-connect-tg"></a>

AWS Transit Gateway is a service that enables you to connect your Amazon Virtual Private Clouds (VPCs) and your on-premises networks to a single gateway. Transit Gateway can be used to consolidate your existing edge connectivity and route it through a single ingress/egress point. For more details, see [AWS Transit Gateway](https://aws.amazon.com/transit-gateway/).
