# Account onboarding process for Accelerate
<a name="acc-get-start-process"></a>

Onboarding an account into AMS Accelerate has four stages.

1. **[Step 1. Account discovery in Accelerate](acc-acct-disc.md)** assesses the current state of your account and identifies technical blockers for onboarding your account.

1. **[Step 2. Onboarding management resources in Accelerate](acc-get-mgmt-resource-onboard.md)** asks you to accept the terms and conditions; and create an onboarding role for AMS Accelerate cloud architects (CAs), who will assist you with setting a security baseline, and resolving issues as needed.

1. **[Step 3. Onboarding AMS features with default policies](acc-get-feature-config.md)** for Accelerate features, such as monitoring, patching, and backup.

1. **[Step 4. Customize features in Accelerate](acc-get-customize.md)** ensures that resources, including EC2 instances, are correctly configured for your application.
