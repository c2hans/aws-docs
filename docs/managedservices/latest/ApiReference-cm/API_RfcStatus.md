# RfcStatus
<a name="API_RfcStatus"></a>

An ID and name for the status of the RFC.

## Contents
<a name="API_RfcStatus_Contents"></a>

 ** Id **   <a name="amscm-Type-RfcStatus-Id"></a>
The ID of the status. Possible values: `Editing` \| `PendingApproval` \| `Scheduled` \| `InProgress` \| `Rejected` \| `Canceled` \| `Success` \| `Failure`
Type: String
Required: No

 ** Name **   <a name="amscm-Type-RfcStatus-Name"></a>
A name for the corresponding status ID.
Type: String
Required: No
