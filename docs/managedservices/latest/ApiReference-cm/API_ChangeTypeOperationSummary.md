# ChangeTypeOperationSummary
<a name="API_ChangeTypeOperationSummary"></a>

The operation values and change type IDs for a particular category, subcategory, and item value.

## Contents
<a name="API_ChangeTypeOperationSummary_Contents"></a>

 ** ChangeTypeId **   <a name="amscm-Type-ChangeTypeOperationSummary-ChangeTypeId"></a>
The ID of the change type that has the corresponding operation value.
Type: String
Required: No

 ** Operation **   <a name="amscm-Type-ChangeTypeOperationSummary-Operation"></a>
The operation value of the corresponding change type.
Type: String
Required: No
