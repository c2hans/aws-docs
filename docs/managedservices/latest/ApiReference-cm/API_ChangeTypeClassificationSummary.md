# ChangeTypeClassificationSummary
<a name="API_ChangeTypeClassificationSummary"></a>

The category, subcategory, item, and operation values of a change type.

## Contents
<a name="API_ChangeTypeClassificationSummary_Contents"></a>

 ** Category **   <a name="amscm-Type-ChangeTypeClassificationSummary-Category"></a>
The category value of the change type.
Type: String
Required: No

 ** ChangeTypeId **   <a name="amscm-Type-ChangeTypeClassificationSummary-ChangeTypeId"></a>
The unique ID of the change type, in the form ct-2ty5seo8rxfsc.
Type: String
Required: No

 ** Item **   <a name="amscm-Type-ChangeTypeClassificationSummary-Item"></a>
The item value of the change type.
Type: String
Required: No

 ** Operation **   <a name="amscm-Type-ChangeTypeClassificationSummary-Operation"></a>
The operation value of the change type.
Type: String
Required: No

 ** Subcategory **   <a name="amscm-Type-ChangeTypeClassificationSummary-Subcategory"></a>
The subcategory value of the change type.
Type: String
Required: No
