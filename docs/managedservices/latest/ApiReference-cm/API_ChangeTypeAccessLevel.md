# ChangeTypeAccessLevel
<a name="API_ChangeTypeAccessLevel"></a>

The access level of the change type.

## Contents
<a name="API_ChangeTypeAccessLevel_Contents"></a>

 ** Id **   <a name="amscm-Type-ChangeTypeAccessLevel-Id"></a>
The ID of change type access level. Possible values: `OpenAccess` \| `AwsOperatorInternalOnly`.
Type: String
Required: No

 ** Name **   <a name="amscm-Type-ChangeTypeAccessLevel-Name"></a>
The description of the kind of change type access level.
Type: String
Required: No
