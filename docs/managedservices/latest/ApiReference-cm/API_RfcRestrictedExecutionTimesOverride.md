# RfcRestrictedExecutionTimesOverride
<a name="API_RfcRestrictedExecutionTimesOverride"></a>

An ID and name for an option for overriding preset restrictions on execution of a change.

## Contents
<a name="API_RfcRestrictedExecutionTimesOverride_Contents"></a>

 ** Id **   <a name="amscm-Type-RfcRestrictedExecutionTimesOverride-Id"></a>
The ID of the override option.
Type: String
Required: No

 ** Name **   <a name="amscm-Type-RfcRestrictedExecutionTimesOverride-Name"></a>
A name for the corresponding override option.
Type: String
Required: No
