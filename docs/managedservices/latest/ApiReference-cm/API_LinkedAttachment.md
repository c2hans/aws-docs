# LinkedAttachment
<a name="API_LinkedAttachment"></a>

The list of attachments that are linked to the correspondence.

## Contents
<a name="API_LinkedAttachment_Contents"></a>

 ** AttachmentId **   <a name="amscm-Type-LinkedAttachment-AttachmentId"></a>
The `AttachmentId` of the linked attachment.
Type: String
Required: No

 ** CreatedBy **   <a name="amscm-Type-LinkedAttachment-CreatedBy"></a>
The Amazon Resource Name (ARN) of the user who created the attachment.
Type: String
Required: No

 ** CreatedTime **   <a name="amscm-Type-LinkedAttachment-CreatedTime"></a>
The date and time when the attachment was created.
Type: String
Required: No

 ** FileName **   <a name="amscm-Type-LinkedAttachment-FileName"></a>
The file name of the linked attachment.
Type: String
Required: No
