# ChangeTypeAutomationStatus
<a name="API_ChangeTypeAutomationStatus"></a>

The automation status of a change type (`Automated` or `Manual`).

## Contents
<a name="API_ChangeTypeAutomationStatus_Contents"></a>

 ** Id **   <a name="amscm-Type-ChangeTypeAutomationStatus-Id"></a>
The ID of the automation status of a change type. Possible values: `Automated` \| `Manual`
Type: String
Required: No

 ** Name **   <a name="amscm-Type-ChangeTypeAutomationStatus-Name"></a>
The description of the automation status (`Automated` or `Manual`).
Type: String
Required: No
