# RfcActionState
<a name="API_RfcActionState"></a>

The action state of the RFC.

## Contents
<a name="API_RfcActionState_Contents"></a>

 ** Id **   <a name="amscm-Type-RfcActionState-Id"></a>
The ID of the action state.
Valid values: `AwsOperatorAssigned | AwsActionPending | NoActionPending | CustomerActionPending | NotApplicable`
Type: String
Required: No

 ** Name **   <a name="amscm-Type-RfcActionState-Name"></a>
The name of the action state.
Type: String
Required: No
