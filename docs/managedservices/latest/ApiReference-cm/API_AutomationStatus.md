# AutomationStatus
<a name="API_AutomationStatus"></a>

Whether the change type is automated or manual.

## Contents
<a name="API_AutomationStatus_Contents"></a>

 ** Id **   <a name="amscm-Type-AutomationStatus-Id"></a>
The ID of change type automation type. Possible values: `Automated` \| `Manual`.
Type: String
Required: No

 ** Name **   <a name="amscm-Type-AutomationStatus-Name"></a>
The description of the change type automation type.
Type: String
Required: No
