# UserType
<a name="API_UserType"></a>

The type of owner of the correspondence, either customer or AWS operator.

## Contents
<a name="API_UserType_Contents"></a>

 ** Id **   <a name="amscm-Type-UserType-Id"></a>
The ID of the user type. Possible values: `Customer` \| `AwsOperator`.
Type: String
Required: No

 ** Name **   <a name="amscm-Type-UserType-Name"></a>
The description of the user type.
Type: String
Required: No
