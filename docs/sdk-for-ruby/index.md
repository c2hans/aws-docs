# AWS SDK for Ruby Documentation

The AWS SDK for Ruby helps you to get started building applications using Amazon Web Services infrastructure services, including Amazon S3, Amazon EC2, Amazon DynamoDB, and more.

## Latest version (Version 3)

- [Developer Guide](/sdk-for-ruby/v3/developer-guide/): The Developer Guide walks you through the getting-started process and how to work with various features of the AWS SDK for Ruby.
- [API Reference](/sdk-for-ruby/v3/api/): The API reference guide describes all of the API operations for the SDK. The guide also contains sample requests, responses, and errors for supported AWS services.

## Previous version (Version 2)

- [API Reference](/sdk-for-ruby/v2/api/): The API reference guide for version 2 of the AWS SDK for Ruby describes all the API operations for version 2 of the SDK. The guide also contains sample requests, responses, and errors for supported AWS services.
