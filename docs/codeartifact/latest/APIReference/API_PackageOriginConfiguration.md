# PackageOriginConfiguration
<a name="API_PackageOriginConfiguration"></a>

Details about the package origin configuration of a package.

## Contents
<a name="API_PackageOriginConfiguration_Contents"></a>

 ** restrictions **   <a name="codeartifact-Type-PackageOriginConfiguration-restrictions"></a>
A `PackageOriginRestrictions` object that contains information about the upstream and publish package origin configuration for the package.
Type: [PackageOriginRestrictions](API_PackageOriginRestrictions.md) object
Required: No
