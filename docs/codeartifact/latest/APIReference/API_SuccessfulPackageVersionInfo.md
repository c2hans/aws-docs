# SuccessfulPackageVersionInfo
<a name="API_SuccessfulPackageVersionInfo"></a>

 Contains the revision and status of a package version.

## Contents
<a name="API_SuccessfulPackageVersionInfo_Contents"></a>

 ** revision **   <a name="codeartifact-Type-SuccessfulPackageVersionInfo-revision"></a>
 The revision of a package version.
Type: String
Required: No

 ** status **   <a name="codeartifact-Type-SuccessfulPackageVersionInfo-status"></a>
 The status of a package version.
Type: String
Valid Values: `Published | Unfinished | Unlisted | Archived | Disposed | Deleted`
Required: No
