# Unsupported and excluded resource types
<a name="next-gen-troubleshoot-resource-types"></a>

Next generation Resilience Hub excludes certain resource types from discovery because they have no independent resilience value. If you expect a resource to appear in your discovered resources but it does not, it might be an excluded type.
