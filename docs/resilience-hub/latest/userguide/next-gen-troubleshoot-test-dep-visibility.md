# Not all dependencies visible in the test
<a name="next-gen-troubleshoot-test-dep-visibility"></a>

**Symptom:** Not all discovered dependencies are shown in the dropdown.

**Cause:** Dependencies are filtered per test to show only those relevant to the test's scope.

**Solution:** Each test shows a different subset. See the individual test pages for which dependencies are shown.
