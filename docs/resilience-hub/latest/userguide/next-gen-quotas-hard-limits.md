# Hard limits
<a name="next-gen-quotas-hard-limits"></a>

The following quotas cannot be increased.

| \# | Resource | Hard limit |
| --- | --- | --- |
| 1 | Systems per account per AWS Region (maximum) | 1,000 |
| 2 | Services per account per AWS Region (maximum) | 500 |
| 3 | Input sources per service (maximum) | 100 |
| 4 | Resources per service (maximum) | 1,000 |
| 5 | User journeys per system (maximum) | 100 |
| 6 | Cross-account role ARNs per service | 5 |
| 7 | Failure mode assessments included per service per month | 2 |
