# Enable new capabilities
<a name="next-gen-migration-step4"></a>

Take advantage of features not available in v1.

1. **Enable Dependency discovery** – Discover hidden dependencies between services and external resources.

1. **Set up Organizations** – Enable multi-account governance across your organization.

1. **Add performance conditions** – Define what "available" means beyond uptime using availability SLO conditions.
