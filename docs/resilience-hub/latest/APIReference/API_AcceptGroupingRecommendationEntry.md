# AcceptGroupingRecommendationEntry
<a name="API_AcceptGroupingRecommendationEntry"></a>

Indicates the grouping recommendation you have accepted to include in your application.

## Contents
<a name="API_AcceptGroupingRecommendationEntry_Contents"></a>

 ** groupingRecommendationId **   <a name="resiliencehub-Type-AcceptGroupingRecommendationEntry-groupingRecommendationId"></a>
Indicates the identifier of the grouping recommendation.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: Yes
