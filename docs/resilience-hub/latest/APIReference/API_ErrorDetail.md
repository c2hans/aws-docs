# ErrorDetail
<a name="API_ErrorDetail"></a>

Indicates the error that was encountered while importing a resource.

## Contents
<a name="API_ErrorDetail_Contents"></a>

 ** errorMessage **   <a name="resiliencehub-Type-ErrorDetail-errorMessage"></a>
Provides additional information about the error.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 500.
Required: No
