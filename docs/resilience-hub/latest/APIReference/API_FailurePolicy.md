# FailurePolicy
<a name="API_FailurePolicy"></a>

Defines a failure policy.

## Contents
<a name="API_FailurePolicy_Contents"></a>

 ** rpoInSecs **   <a name="resiliencehub-Type-FailurePolicy-rpoInSecs"></a>
Recovery Point Objective (RPO) in seconds.
Type: Integer
Valid Range: Minimum value of 0.
Required: Yes

 ** rtoInSecs **   <a name="resiliencehub-Type-FailurePolicy-rtoInSecs"></a>
Recovery Time Objective (RTO) in seconds.
Type: Integer
Valid Range: Minimum value of 0.
Required: Yes
