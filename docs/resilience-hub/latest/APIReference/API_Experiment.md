# Experiment
<a name="API_Experiment"></a>

Indicates the AWS FIS experiment detected while running an assessment.

## Contents
<a name="API_Experiment_Contents"></a>

 ** experimentArn **   <a name="resiliencehub-Type-Experiment-experimentArn"></a>
Amazon Resource Name (ARN) of the AWS FIS experiment.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No

 ** experimentTemplateId **   <a name="resiliencehub-Type-Experiment-experimentTemplateId"></a>
Identifier of the AWS FIS experiment template.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No
