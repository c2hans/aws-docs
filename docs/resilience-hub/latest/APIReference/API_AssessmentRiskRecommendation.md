# AssessmentRiskRecommendation
<a name="API_AssessmentRiskRecommendation"></a>

Indicates a specific risk identified in the AWS Resilience Hub assessment and the corresponding recommendation provided to address that risk.

**Note**
The assessment summary generated by large language models (LLMs) on Amazon Bedrock are only suggestions. The current level of generative AI technology is not perfect and LLMs are not infallible. Bias and incorrect answers, although rare, should be expected. Review each recommendation in the assessment summary before you use the output from an LLM.

**Note**
This property is available only in the US East (N. Virginia) Region.

## Contents
<a name="API_AssessmentRiskRecommendation_Contents"></a>

 ** appComponents **   <a name="resiliencehub-Type-AssessmentRiskRecommendation-appComponents"></a>
Indicates the Application Components (AppComponents) that were assessed as part of the assessment and are associated with the identified risk and recommendation.
This property is available only in the US East (N. Virginia) Region.
Type: Array of strings
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No

 ** recommendation **   <a name="resiliencehub-Type-AssessmentRiskRecommendation-recommendation"></a>
Indicates the recommendation provided by the AWS Resilience Hub to address the identified risks in the application.
This property is available only in the US East (N. Virginia) Region.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No

 ** risk **   <a name="resiliencehub-Type-AssessmentRiskRecommendation-risk"></a>
Indicates the description of the potential risk identified in the application as part of the AWS Resilience Hub assessment.
This property is available only in the US East (N. Virginia) Region.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No
