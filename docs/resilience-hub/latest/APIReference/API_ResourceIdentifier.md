# ResourceIdentifier
<a name="API_ResourceIdentifier"></a>

Defines a resource identifier for the drifted resource.

## Contents
<a name="API_ResourceIdentifier_Contents"></a>

 ** logicalResourceId **   <a name="resiliencehub-Type-ResourceIdentifier-logicalResourceId"></a>
Logical identifier of the drifted resource.
Type: [LogicalResourceId](API_LogicalResourceId.md) object
Required: No

 ** resourceType **   <a name="resiliencehub-Type-ResourceIdentifier-resourceType"></a>
Type of the drifted resource.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No
