# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

Describes a field that failed validation.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="ngresiliencehub-Type-ValidationExceptionField-message"></a>
The validation error message for the field.
Type: String
Required: Yes

 ** name **   <a name="ngresiliencehub-Type-ValidationExceptionField-name"></a>
The name of the field that failed validation.
Type: String
Required: Yes
