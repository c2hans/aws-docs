# UserJourneyChanges
<a name="API_UserJourneyChanges"></a>

Describes changes made to a user journey.

## Contents
<a name="API_UserJourneyChanges_Contents"></a>

 ** associatedServices **   <a name="ngresiliencehub-Type-UserJourneyChanges-associatedServices"></a>
Changes to the services associated with the user journey.
Type: [ServiceReferenceChanges](API_ServiceReferenceChanges.md) object
Required: No

 ** journeyDescription **   <a name="ngresiliencehub-Type-UserJourneyChanges-journeyDescription"></a>
Changes to the user journey description.
Type: [StringChange](API_StringChange.md) object
Required: No
