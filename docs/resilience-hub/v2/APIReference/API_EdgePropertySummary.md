# EdgePropertySummary
<a name="API_EdgePropertySummary"></a>

Contains property information for a service topology edge.

## Contents
<a name="API_EdgePropertySummary_Contents"></a>

 ** label **   <a name="ngresiliencehub-Type-EdgePropertySummary-label"></a>
Human-readable relationship description. Only present for LLM-inferred edges.
Type: String
Required: No

 ** topologyType **   <a name="ngresiliencehub-Type-EdgePropertySummary-topologyType"></a>
The topology type of the edge.
Type: String
Valid Values: `CONTAINMENT | DATA_FLOW | OBSERVABILITY | PERMISSIONS`
Required: No
