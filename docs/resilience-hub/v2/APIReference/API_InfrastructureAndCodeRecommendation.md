# InfrastructureAndCodeRecommendation
<a name="API_InfrastructureAndCodeRecommendation"></a>

An infrastructure and code recommendation to address a finding.

## Contents
<a name="API_InfrastructureAndCodeRecommendation_Contents"></a>

 ** suggestedChanges **   <a name="ngresiliencehub-Type-InfrastructureAndCodeRecommendation-suggestedChanges"></a>
The list of suggested changes.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 10 items.
Length Constraints: Minimum length of 0. Maximum length of 500.
Required: No
