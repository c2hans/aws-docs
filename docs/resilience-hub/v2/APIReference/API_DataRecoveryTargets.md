# DataRecoveryTargets
<a name="API_DataRecoveryTargets"></a>

Defines data recovery targets for a resilience policy.

## Contents
<a name="API_DataRecoveryTargets_Contents"></a>

 ** timeBetweenBackupsInMinutes **   <a name="ngresiliencehub-Type-DataRecoveryTargets-timeBetweenBackupsInMinutes"></a>
The target time between backups, in minutes.
Type: Integer
Valid Range: Minimum value of 0.
Required: No
