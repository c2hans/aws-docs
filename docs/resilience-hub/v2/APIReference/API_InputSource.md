# InputSource
<a name="API_InputSource"></a>

Identifies an input source by its identifier and type.

## Contents
<a name="API_InputSource_Contents"></a>

 ** identifier **   <a name="ngresiliencehub-Type-InputSource-identifier"></a>
The identifier of the input source.
Type: String
Required: Yes

 ** type **   <a name="ngresiliencehub-Type-InputSource-type"></a>
The type of the input source.
Type: String
Valid Values: `CFN_STACK | TAGS | EKS | TERRAFORM | DESIGN_FILE | MONITORING`
Required: Yes
