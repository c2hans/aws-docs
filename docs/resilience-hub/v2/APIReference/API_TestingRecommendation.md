# TestingRecommendation
<a name="API_TestingRecommendation"></a>

A testing recommendation to address a finding.

## Contents
<a name="API_TestingRecommendation_Contents"></a>

 ** suggestedChanges **   <a name="ngresiliencehub-Type-TestingRecommendation-suggestedChanges"></a>
The list of suggested testing changes.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 10 items.
Length Constraints: Minimum length of 0. Maximum length of 500.
Required: No
