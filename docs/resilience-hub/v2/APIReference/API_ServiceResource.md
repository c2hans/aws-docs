# ServiceResource
<a name="API_ServiceResource"></a>

Represents a resource associated with a service.

## Contents
<a name="API_ServiceResource_Contents"></a>

 ** resource **   <a name="ngresiliencehub-Type-ServiceResource-resource"></a>
The resource details.
Type: [Resource](API_Resource.md) object
Required: Yes

 ** resourceIdentifier **   <a name="ngresiliencehub-Type-ServiceResource-resourceIdentifier"></a>
The identifier of the resource.
Type: String
Required: Yes

 ** inputSource **   <a name="ngresiliencehub-Type-ServiceResource-inputSource"></a>
The input source that discovered the resource.
Type: [InputSource](API_InputSource.md) object
Required: No
