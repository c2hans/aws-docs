# QueryDataPoint
<a name="API_QueryDataPoint"></a>

A data point in a dependency query range.

## Contents
<a name="API_QueryDataPoint_Contents"></a>

 ** queryCount **   <a name="ngresiliencehub-Type-QueryDataPoint-queryCount"></a>
The number of queries at this data point.
Type: Long
Required: Yes

 ** timestamp **   <a name="ngresiliencehub-Type-QueryDataPoint-timestamp"></a>
The timestamp of the data point.
Type: Timestamp
Required: Yes
