# AvailabilitySlo
<a name="API_AvailabilitySlo"></a>

Defines the availability service level objective (SLO) for a resilience policy.

## Contents
<a name="API_AvailabilitySlo_Contents"></a>

 ** target **   <a name="ngresiliencehub-Type-AvailabilitySlo-target"></a>
The target availability percentage, expressed as a value between 0 and 100.
Type: Double
Valid Range: Minimum value of 0. Maximum value of 100.
Required: No
