# PolicySharingRevokedMetadata
<a name="API_PolicySharingRevokedMetadata"></a>

Contains details about a policy for which organization sharing was revoked, including the number of services that were affected.

## Contents
<a name="API_PolicySharingRevokedMetadata_Contents"></a>

 ** affectedServiceCount **   <a name="ngresiliencehub-Type-PolicySharingRevokedMetadata-affectedServiceCount"></a>
The number of services that were using the policy when sharing was revoked.
Type: Integer
Required: No
