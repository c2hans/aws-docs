# TestRunReportConfiguration
<a name="API_TestRunReportConfiguration"></a>

A snapshot of the report configuration captured onto a test run from the service when the run was started.

## Contents
<a name="API_TestRunReportConfiguration_Contents"></a>

 ** reportOutput **   <a name="ngresiliencehub-Type-TestRunReportConfiguration-reportOutput"></a>
The output destinations for generated reports.
Type: Array of [ReportOutputConfiguration](API_ReportOutputConfiguration.md) objects
Array Members: Fixed number of 1 item.
Required: Yes
