# ServiceReference
<a name="API_ServiceReference"></a>

A reference to a service by ID and name.

## Contents
<a name="API_ServiceReference_Contents"></a>

 ** serviceId **   <a name="ngresiliencehub-Type-ServiceReference-serviceId"></a>
The identifier of the referenced service.
Type: String
Required: No

 ** serviceName **   <a name="ngresiliencehub-Type-ServiceReference-serviceName"></a>
The name of the referenced service.
Type: String
Required: No
