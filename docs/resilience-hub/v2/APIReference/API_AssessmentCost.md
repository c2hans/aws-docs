# AssessmentCost
<a name="API_AssessmentCost"></a>

Represents the cost of running a failure mode assessment.

## Contents
<a name="API_AssessmentCost_Contents"></a>

 ** amount **   <a name="ngresiliencehub-Type-AssessmentCost-amount"></a>
The cost amount for the assessment.
Type: Double
Required: No

 ** currency **   <a name="ngresiliencehub-Type-AssessmentCost-currency"></a>
The currency of the assessment cost.
Type: String
Valid Values: `USD`
Required: No
