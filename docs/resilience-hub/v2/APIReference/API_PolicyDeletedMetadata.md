# PolicyDeletedMetadata
<a name="API_PolicyDeletedMetadata"></a>

Contains details about a policy that was deleted, including the number of services that were affected.

## Contents
<a name="API_PolicyDeletedMetadata_Contents"></a>

 ** affectedServiceCount **   <a name="ngresiliencehub-Type-PolicyDeletedMetadata-affectedServiceCount"></a>
The number of services that were using the policy when it was deleted.
Type: Integer
Required: No
