# SystemUserJourneyDeletedMetadata
<a name="API_SystemUserJourneyDeletedMetadata"></a>

Metadata for a system user journey deleted event.

## Contents
<a name="API_SystemUserJourneyDeletedMetadata_Contents"></a>

 ** associatedServicesAtDeletion **   <a name="ngresiliencehub-Type-SystemUserJourneyDeletedMetadata-associatedServicesAtDeletion"></a>
The services that were associated at the time of deletion.
Type: Array of [ServiceReference](API_ServiceReference.md) objects
Required: No

 ** userJourneyName **   <a name="ngresiliencehub-Type-SystemUserJourneyDeletedMetadata-userJourneyName"></a>
The name of the deleted user journey.
Type: String
Required: No
