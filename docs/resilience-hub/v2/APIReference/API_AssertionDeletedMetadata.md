# AssertionDeletedMetadata
<a name="API_AssertionDeletedMetadata"></a>

<a name="API_AssertionDeletedMetadata_Contents"></a>

 ** assertionId **   <a name="ngresiliencehub-Type-AssertionDeletedMetadata-assertionId"></a>
The unique identifier of the deleted assertion.
Type: String
Required: No

 ** assertionName **   <a name="ngresiliencehub-Type-AssertionDeletedMetadata-assertionName"></a>

Type: String
Required: No
