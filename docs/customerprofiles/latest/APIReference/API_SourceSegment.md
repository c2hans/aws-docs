# SourceSegment
<a name="API_connect-customer-profiles_SourceSegment"></a>

The source segments to build off of.

## Contents
<a name="API_connect-customer-profiles_SourceSegment_Contents"></a>

 ** SegmentDefinitionName **   <a name="connect-Type-connect-customer-profiles_SourceSegment-SegmentDefinitionName"></a>
The unique name of the segment definition.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Pattern: `^[a-zA-Z0-9_-]+$`
Required: No
