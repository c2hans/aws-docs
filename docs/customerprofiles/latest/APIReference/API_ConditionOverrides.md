# ConditionOverrides
<a name="API_connect-customer-profiles_ConditionOverrides"></a>

An object to override the original condition block of a calculated attribute.

## Contents
<a name="API_connect-customer-profiles_ConditionOverrides_Contents"></a>

 ** Range **   <a name="connect-Type-connect-customer-profiles_ConditionOverrides-Range"></a>
The relative time period over which data is included in the aggregation for this override.
Type: [RangeOverride](API_connect-customer-profiles_RangeOverride.md) object
Required: No
