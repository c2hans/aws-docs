# Readiness
<a name="API_connect-customer-profiles_Readiness"></a>

Information indicating if the Calculated Attribute is ready for use by confirming all historical data has been processed and reflected.

## Contents
<a name="API_connect-customer-profiles_Readiness_Contents"></a>

 ** Message **   <a name="connect-Type-connect-customer-profiles_Readiness-Message"></a>
Any customer messaging.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1000.
Required: No

 ** ProgressPercentage **   <a name="connect-Type-connect-customer-profiles_Readiness-ProgressPercentage"></a>
Approximately how far the Calculated Attribute creation is from completion.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 100.
Required: No
