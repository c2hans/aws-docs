# ScheduledExecutions
<a name="API_connect-customer-profiles_ScheduledExecutions"></a>

Information about scheduled execution timestamps.

## Contents
<a name="API_connect-customer-profiles_ScheduledExecutions_Contents"></a>

 ** LastExecutedAt **   <a name="connect-Type-connect-customer-profiles_ScheduledExecutions-LastExecutedAt"></a>
The timestamp of the last successful scheduled execution.
Type: Timestamp
Required: No

 ** NextExecutedAt **   <a name="connect-Type-connect-customer-profiles_ScheduledExecutions-NextExecutedAt"></a>
The timestamp of the next scheduled execution.
Type: Timestamp
Required: No
