# SegmentSort
<a name="API_connect-customer-profiles_SegmentSort"></a>

Defines how segments should be sorted and ordered in the results.

## Contents
<a name="API_connect-customer-profiles_SegmentSort_Contents"></a>

 ** Attributes **   <a name="connect-Type-connect-customer-profiles_SegmentSort-Attributes"></a>
A list of attributes used to sort the segments and their ordering preferences.
Type: Array of [SortAttribute](API_connect-customer-profiles_SortAttribute.md) objects
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Required: Yes
