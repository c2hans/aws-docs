# EventsConfig
<a name="API_connect-customer-profiles_EventsConfig"></a>

Configuration settings that define how events are processed and tracked.

## Contents
<a name="API_connect-customer-profiles_EventsConfig_Contents"></a>

 ** EventParametersList **   <a name="connect-Type-connect-customer-profiles_EventsConfig-EventParametersList"></a>
A list of event parameters configurations that specify how different event types should be handled.
Type: Array of [EventParameters](API_connect-customer-profiles_EventParameters.md) objects
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Required: Yes
