# JobStats
<a name="API_connect-customer-profiles_JobStats"></a>

Statistics about the Identity Resolution Job.

## Contents
<a name="API_connect-customer-profiles_JobStats_Contents"></a>

 ** NumberOfMatchesFound **   <a name="connect-Type-connect-customer-profiles_JobStats-NumberOfMatchesFound"></a>
The number of matches found.
Type: Long
Required: No

 ** NumberOfMergesDone **   <a name="connect-Type-connect-customer-profiles_JobStats-NumberOfMergesDone"></a>
The number of merges completed.
Type: Long
Required: No

 ** NumberOfProfilesReviewed **   <a name="connect-Type-connect-customer-profiles_JobStats-NumberOfProfilesReviewed"></a>
The number of profiles reviewed.
Type: Long
Required: No
