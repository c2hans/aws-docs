# SegmentGroupStructure
<a name="API_connect-customer-profiles_SegmentGroupStructure"></a>

Contains all groups of the segment definition.

## Contents
<a name="API_connect-customer-profiles_SegmentGroupStructure_Contents"></a>

 ** Groups **   <a name="connect-Type-connect-customer-profiles_SegmentGroupStructure-Groups"></a>
Holds the list of groups within the segment definition.
Type: Array of [Group](API_connect-customer-profiles_Group.md) objects
Required: No

 ** Include **   <a name="connect-Type-connect-customer-profiles_SegmentGroupStructure-Include"></a>
Define whether to include or exclude the profiles that fit the segment criteria.
Type: String
Valid Values: `ALL | ANY | NONE`
Required: No
