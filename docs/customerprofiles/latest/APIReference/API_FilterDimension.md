# FilterDimension
<a name="API_connect-customer-profiles_FilterDimension"></a>

Contains the map of attribute names to attribute dimensions.

## Contents
<a name="API_connect-customer-profiles_FilterDimension_Contents"></a>

 ** Attributes **   <a name="connect-Type-connect-customer-profiles_FilterDimension-Attributes"></a>
Is the attribute within the FilterDimension map
Type: String to [FilterAttributeDimension](API_connect-customer-profiles_FilterAttributeDimension.md) object map
Key Length Constraints: Minimum length of 1. Maximum length of 64.
Key Pattern: `^[a-zA-Z0-9_.-]+$`
Required: Yes
