# ServiceNowSourceProperties
<a name="API_connect-customer-profiles_ServiceNowSourceProperties"></a>

The properties that are applied when ServiceNow is being used as a source.

## Contents
<a name="API_connect-customer-profiles_ServiceNowSourceProperties_Contents"></a>

 ** Object **   <a name="connect-Type-connect-customer-profiles_ServiceNowSourceProperties-Object"></a>
The object specified in the ServiceNow flow source.
Type: String
Length Constraints: Maximum length of 512.
Pattern: `\S+`
Required: Yes
