# AppflowIntegrationWorkflowMetrics
<a name="API_connect-customer-profiles_AppflowIntegrationWorkflowMetrics"></a>

Workflow specific execution metrics for `APPFLOW_INTEGRATION` workflow.

## Contents
<a name="API_connect-customer-profiles_AppflowIntegrationWorkflowMetrics_Contents"></a>

 ** RecordsProcessed **   <a name="connect-Type-connect-customer-profiles_AppflowIntegrationWorkflowMetrics-RecordsProcessed"></a>
Number of records processed in `APPFLOW_INTEGRATION` workflow.
Type: Long
Required: Yes

 ** StepsCompleted **   <a name="connect-Type-connect-customer-profiles_AppflowIntegrationWorkflowMetrics-StepsCompleted"></a>
Total steps completed in `APPFLOW_INTEGRATION` workflow.
Type: Long
Required: Yes

 ** TotalSteps **   <a name="connect-Type-connect-customer-profiles_AppflowIntegrationWorkflowMetrics-TotalSteps"></a>
Total steps in `APPFLOW_INTEGRATION` workflow.
Type: Long
Required: Yes
