# PointInTimeRecovery
<a name="API_PointInTimeRecovery"></a>

Point-in-time recovery (PITR) helps protect your Amazon Keyspaces tables from accidental write or delete operations by providing you continuous backups of your table data.

For more information, see [Point-in-time recovery](https://docs.aws.amazon.com/keyspaces/latest/devguide/PointInTimeRecovery.html) in the *Amazon Keyspaces Developer Guide*.

## Contents
<a name="API_PointInTimeRecovery_Contents"></a>

 ** status **   <a name="keyspaces-Type-PointInTimeRecovery-status"></a>
The options are:
+  `status=ENABLED`
+  `status=DISABLED`
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
