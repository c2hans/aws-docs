# AccessDeniedException
<a name="API_AccessDeniedException"></a>

You don't have sufficient access permissions to perform this action.

HTTP Status Code returned: 400

## Contents
<a name="API_AccessDeniedException_Contents"></a>

 ** message **   <a name="keyspaces-Type-AccessDeniedException-message"></a>
You don't have the required permissions to perform this operation. Verify your IAM permissions and try again.
Type: String
Required: No
