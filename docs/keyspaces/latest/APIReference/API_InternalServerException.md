# InternalServerException
<a name="API_InternalServerException"></a>

Amazon Keyspaces was unable to fully process this request because of an internal server error.

HTTP Status Code returned: 500

## Contents
<a name="API_InternalServerException_Contents"></a>

 ** message **   <a name="keyspaces-Type-InternalServerException-message"></a>
An internal service error occurred. Retry your request. If the problem persists, contact AWS Support.
Type: String
Required: No
