# ReplicaAutoScalingSpecification
<a name="API_ReplicaAutoScalingSpecification"></a>

The auto scaling settings of a multi-Region table in the specified AWS Region.

## Contents
<a name="API_ReplicaAutoScalingSpecification_Contents"></a>

 ** autoScalingSpecification **   <a name="keyspaces-Type-ReplicaAutoScalingSpecification-autoScalingSpecification"></a>
The auto scaling settings for a multi-Region table in the specified AWS Region.
Type: [AutoScalingSpecification](API_AutoScalingSpecification.md) object
Required: No

 ** region **   <a name="keyspaces-Type-ReplicaAutoScalingSpecification-region"></a>
The AWS Region.
Type: String
Length Constraints: Minimum length of 2. Maximum length of 25.
Required: No
