# KeyspacesMetadata
<a name="API_KeyspacesMetadata"></a>

Contains metadata information associated with Amazon Keyspaces cells and rows.

## Contents
<a name="API_KeyspacesMetadata_Contents"></a>

 ** expirationTime **   <a name="keyspaces-Type-KeyspacesMetadata-expirationTime"></a>
The time at which the associated data will expire, based on the time-to-live (TTL) setting.
Type: String
Required: No

 ** writeTime **   <a name="keyspaces-Type-KeyspacesMetadata-writeTime"></a>
The timestamp at which the associated data was written to the database.
Type: String
Required: No
