# Data Types
<a name="API_Types"></a>

The Amazon Keyspaces Streams API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [IteratorDescription](API_IteratorDescription.md)
+  [KeyspacesCell](API_KeyspacesCell.md)
+  [KeyspacesCellMapDefinition](API_KeyspacesCellMapDefinition.md)
+  [KeyspacesCellValue](API_KeyspacesCellValue.md)
+  [KeyspacesMetadata](API_KeyspacesMetadata.md)
+  [KeyspacesRow](API_KeyspacesRow.md)
+  [Record](API_Record.md)
+  [SequenceNumberRange](API_SequenceNumberRange.md)
+  [Shard](API_Shard.md)
+  [ShardFilter](API_ShardFilter.md)
+  [Stream](API_Stream.md)
