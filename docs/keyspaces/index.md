# Amazon Keyspaces (for Apache Cassandra) Documentation

Amazon Keyspaces (for Apache Cassandra) is a scalable, highly available, and managed Apache Cassandra–compatible database service.

- [/keyspaces/latest/devguide/](/keyspaces/latest/devguide/)
- [CQL Language Reference](/keyspaces/latest/devguide/cql.html): Describes supported Cassandra Query Language (CQL) elements, syntax for Data Definition Language (DDL) and Data Manipulation Language (DML) statements, and lists supported built-in functions for Amazon Keyspaces in detail.
- [API Reference](/keyspaces/latest/APIReference/): Describes supported API operations in the AWS SDK for Amazon Keyspaces in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
- [Streams API Reference](/keyspaces/latest/StreamsAPIReference/): Describes the AWS SDK for Amazon Keyspaces Streams API operations in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
- [Amazon Keyspaces Code Examples Repository](https://github.com/aws-samples/amazon-keyspaces-examples): Contains code examples and other types of examples to help accelerate your development of Amazon Keyspaces applications. The examples demonstrate common service implementations and infrastructure patterns using various programming languages and supported technologies.
