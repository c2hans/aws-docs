# Configuring custom domain for your portal
<a name="custom-domains"></a>

You can configure a custom domain for a WorkSpaces Secure Browser portal to enable access through your own domain name instead of the default portal URL. This feature allows you to provide users with a more integrated experience using a domain that aligns with your organization's branding.

**Overview**

Custom domain allows you to personalize the following aspects of the user experience:
+ **Branded portal access** - Users access your portal through your organization's domain instead of the default AWS endpoint.
+ **Consistent user experience** - Maintain brand consistency by using familiar domain names that align with your organization.

**Note**
To customize the visual appearance and branding elements of your portal, see [Branding customization in Amazon WorkSpaces Secure Browser](branding-customization.md).
