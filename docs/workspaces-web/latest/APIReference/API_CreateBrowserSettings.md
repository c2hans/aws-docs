# CreateBrowserSettings
<a name="API_CreateBrowserSettings"></a>

Creates a browser settings resource that can be associated with a web portal. Once associated with a web portal, browser settings control how the browser will behave once a user starts a streaming session for the web portal.

## Request Syntax
<a name="API_CreateBrowserSettings_RequestSyntax"></a>

```
POST /browserSettings HTTP/1.1
Content-type: application/json

{
   "additionalEncryptionContext": {
      "{{string}}" : "{{string}}"
   },
   "browserPolicy": "{{string}}",
   "clientToken": "{{string}}",
   "customerManagedKey": "{{string}}",
   "tags": [
      {
         "Key": "{{string}}",
         "Value": "{{string}}"
      }
   ],
   "webContentFilteringPolicy": {
      "allowedUrls": [ "{{string}}" ],
      "blockedCategories": [ "{{string}}" ],
      "blockedUrls": [ "{{string}}" ]
   }
}
```

## URI Request Parameters
<a name="API_CreateBrowserSettings_RequestParameters"></a>

The request does not use any URI parameters.

## Request Body
<a name="API_CreateBrowserSettings_RequestBody"></a>

The request accepts the following data in JSON format.

 ** [additionalEncryptionContext](#API_CreateBrowserSettings_RequestSyntax) **   <a name="workspacesweb-CreateBrowserSettings-request-additionalEncryptionContext"></a>
Additional encryption context of the browser settings.
Type: String to string map
Key Length Constraints: Minimum length of 0. Maximum length of 131072.
Key Pattern: `[\s\S]*`
Value Length Constraints: Minimum length of 0. Maximum length of 131072.
Value Pattern: `[\s\S]*`
Required: No

 ** [browserPolicy](#API_CreateBrowserSettings_RequestSyntax) **   <a name="workspacesweb-CreateBrowserSettings-request-browserPolicy"></a>
A JSON string containing Chrome Enterprise policies that will be applied to all streaming sessions.
Type: String
Length Constraints: Minimum length of 2. Maximum length of 131072.
Pattern: `\{[\S\s]*\}\s*`
Required: No

 ** [clientToken](#API_CreateBrowserSettings_RequestSyntax) **   <a name="workspacesweb-CreateBrowserSettings-request-clientToken"></a>
A unique, case-sensitive identifier that you provide to ensure the idempotency of the request. Idempotency ensures that an API request completes only once. With an idempotent request, if the original request completes successfully, subsequent retries with the same client token returns the result from the original successful request.
If you do not specify a client token, one is automatically generated by the AWS SDK.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: No

 ** [customerManagedKey](#API_CreateBrowserSettings_RequestSyntax) **   <a name="workspacesweb-CreateBrowserSettings-request-customerManagedKey"></a>
The custom managed key of the browser settings.
Type: String
Length Constraints: Minimum length of 20. Maximum length of 2048.
Pattern: `arn:[\w+=\/,.@-]+:kms:[a-zA-Z0-9\-]*:[a-zA-Z0-9]{1,12}:key\/[a-zA-Z0-9-]+`
Required: No

 ** [tags](#API_CreateBrowserSettings_RequestSyntax) **   <a name="workspacesweb-CreateBrowserSettings-request-tags"></a>
The tags to add to the browser settings resource. A tag is a key-value pair.
Type: Array of [Tag](API_Tag.md) objects
Array Members: Minimum number of 0 items. Maximum number of 200 items.
Required: No

 ** [webContentFilteringPolicy](#API_CreateBrowserSettings_RequestSyntax) **   <a name="workspacesweb-CreateBrowserSettings-request-webContentFilteringPolicy"></a>
The policy that specifies which URLs end users are allowed to access or which URLs or domain categories they are restricted from accessing for enhanced security.
Type: [WebContentFilteringPolicy](API_WebContentFilteringPolicy.md) object
Required: No
