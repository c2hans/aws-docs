# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

Information about a field passed inside a request that resulted in an exception.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="workspacesweb-Type-ValidationExceptionField-message"></a>
The message describing why the field failed validation.
Type: String
Required: Yes

 ** name **   <a name="workspacesweb-Type-ValidationExceptionField-name"></a>
The name of the field that failed validation.
Type: String
Required: Yes
