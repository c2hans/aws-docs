# UpdateNetworkSettings
<a name="API_UpdateNetworkSettings"></a>

Updates network settings.

## Request Syntax
<a name="API_UpdateNetworkSettings_RequestSyntax"></a>

```
PATCH /networkSettings/{{networkSettingsArn+}} HTTP/1.1
Content-type: application/json

{
   "clientToken": "{{string}}",
   "securityGroupIds": [ "{{string}}" ],
   "subnetIds": [ "{{string}}" ],
   "vpcId": "{{string}}"
}
```

## URI Request Parameters
<a name="API_UpdateNetworkSettings_RequestParameters"></a>

The request uses the following URI parameters.

 ** [networkSettingsArn](#API_UpdateNetworkSettings_RequestSyntax) **   <a name="workspacesweb-UpdateNetworkSettings-request-uri-networkSettingsArn"></a>
The ARN of the network settings.
Length Constraints: Minimum length of 20. Maximum length of 2048.
Pattern: `arn:[\w+=\/,.@-]+:[a-zA-Z0-9\-]+:[a-zA-Z0-9\-]*:[a-zA-Z0-9]{1,12}:[a-zA-Z]+(\/[a-fA-F0-9\-]{36})+`
Required: Yes

## Request Body
<a name="API_UpdateNetworkSettings_RequestBody"></a>

The request accepts the following data in JSON format.

 ** [clientToken](#API_UpdateNetworkSettings_RequestSyntax) **   <a name="workspacesweb-UpdateNetworkSettings-request-clientToken"></a>
A unique, case-sensitive identifier that you provide to ensure the idempotency of the request. Idempotency ensures that an API request completes only once. With an idempotent request, if the original request completes successfully, subsequent retries with the same client token return the result from the original successful request.
If you do not specify a client token, one is automatically generated by the AWS SDK.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: No

 ** [securityGroupIds](#API_UpdateNetworkSettings_RequestSyntax) **   <a name="workspacesweb-UpdateNetworkSettings-request-securityGroupIds"></a>
One or more security groups used to control access from streaming instances to your VPC.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 5 items.
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `[\w+\-]+`
Required: No

 ** [subnetIds](#API_UpdateNetworkSettings_RequestSyntax) **   <a name="workspacesweb-UpdateNetworkSettings-request-subnetIds"></a>
The subnets in which network interfaces are created to connect streaming instances to your VPC. At least two of these subnets must be in different availability zones.
Type: Array of strings
Array Members: Minimum number of 2 items. Maximum number of 5 items.
Length Constraints: Minimum length of 1. Maximum length of 32.
Pattern: `subnet-([0-9a-f]{8}|[0-9a-f]{17})`
Required: No

 ** [vpcId](#API_UpdateNetworkSettings_RequestSyntax) **   <a name="workspacesweb-UpdateNetworkSettings-request-vpcId"></a>
The VPC that streaming instances will connect to.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `vpc-[0-9a-z]*`
Required: No
