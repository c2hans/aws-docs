# UpdateBrowserSettings
<a name="API_UpdateBrowserSettings"></a>

Updates browser settings.

## Request Syntax
<a name="API_UpdateBrowserSettings_RequestSyntax"></a>

```
PATCH /browserSettings/{{browserSettingsArn+}} HTTP/1.1
Content-type: application/json

{
   "browserPolicy": "{{string}}",
   "clientToken": "{{string}}",
   "webContentFilteringPolicy": {
      "allowedUrls": [ "{{string}}" ],
      "blockedCategories": [ "{{string}}" ],
      "blockedUrls": [ "{{string}}" ]
   }
}
```

## URI Request Parameters
<a name="API_UpdateBrowserSettings_RequestParameters"></a>

The request uses the following URI parameters.

 ** [browserSettingsArn](#API_UpdateBrowserSettings_RequestSyntax) **   <a name="workspacesweb-UpdateBrowserSettings-request-uri-browserSettingsArn"></a>
The ARN of the browser settings.
Length Constraints: Minimum length of 20. Maximum length of 2048.
Pattern: `arn:[\w+=\/,.@-]+:[a-zA-Z0-9\-]+:[a-zA-Z0-9\-]*:[a-zA-Z0-9]{1,12}:[a-zA-Z]+(\/[a-fA-F0-9\-]{36})+`
Required: Yes

## Request Body
<a name="API_UpdateBrowserSettings_RequestBody"></a>

The request accepts the following data in JSON format.

 ** [browserPolicy](#API_UpdateBrowserSettings_RequestSyntax) **   <a name="workspacesweb-UpdateBrowserSettings-request-browserPolicy"></a>
A JSON string containing Chrome Enterprise policies that will be applied to all streaming sessions.
Type: String
Length Constraints: Minimum length of 2. Maximum length of 131072.
Pattern: `\{[\S\s]*\}\s*`
Required: No

 ** [clientToken](#API_UpdateBrowserSettings_RequestSyntax) **   <a name="workspacesweb-UpdateBrowserSettings-request-clientToken"></a>
A unique, case-sensitive identifier that you provide to ensure the idempotency of the request. Idempotency ensures that an API request completes only once. With an idempotent request, if the original request completes successfully, subsequent retries with the same client token return the result from the original successful request.
If you do not specify a client token, one is automatically generated by the AWS SDK.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: No

 ** [webContentFilteringPolicy](#API_UpdateBrowserSettings_RequestSyntax) **   <a name="workspacesweb-UpdateBrowserSettings-request-webContentFilteringPolicy"></a>
The policy that specifies which URLs end users are allowed to access or which URLs or domain categories they are restricted from accessing for enhanced security.
Type: [WebContentFilteringPolicy](API_WebContentFilteringPolicy.md) object
Required: No
