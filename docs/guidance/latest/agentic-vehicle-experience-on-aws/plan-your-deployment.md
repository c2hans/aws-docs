# Plan Your Deployment
<a name="plan-your-deployment"></a>

Before deploying AVX, your AWS environment needs the CMS operational foundation, the ADP analytical foundation, an Amazon Connect instance, and Amazon Bedrock model access — each independently deployable but all contributing to the full AVX capability set.
