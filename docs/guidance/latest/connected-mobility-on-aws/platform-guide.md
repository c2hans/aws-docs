# Platform guide
<a name="platform-guide"></a>

This section explains how the platform behaves — the end-to-end flows for telemetry ingestion, trip detection, safety monitoring, maintenance alerting, remote commands, and simulation. For infrastructure details (VPC configuration, DynamoDB schemas, Kafka topic settings), see [Architecture details](architecture-details.md).
