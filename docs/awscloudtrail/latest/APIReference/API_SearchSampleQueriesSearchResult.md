# SearchSampleQueriesSearchResult
<a name="API_SearchSampleQueriesSearchResult"></a>

 A search result returned by the `SearchSampleQueries` operation.

## Contents
<a name="API_SearchSampleQueriesSearchResult_Contents"></a>

 ** Description **   <a name="awscloudtrail-Type-SearchSampleQueriesSearchResult-Description"></a>
 A longer description of a sample query.
Type: String
Required: No

 ** Name **   <a name="awscloudtrail-Type-SearchSampleQueriesSearchResult-Name"></a>
 The name of a sample query.
Type: String
Required: No

 ** Relevance **   <a name="awscloudtrail-Type-SearchSampleQueriesSearchResult-Relevance"></a>
 A value between 0 and 1 indicating the similarity between the search phrase and result.
Type: Float
Required: No

 ** SQL **   <a name="awscloudtrail-Type-SearchSampleQueriesSearchResult-SQL"></a>
 The SQL code of the sample query.
Type: String
Required: No
