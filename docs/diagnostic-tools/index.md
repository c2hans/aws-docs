# AWS Diagnostic Tools Documentation

AWS Diagnostic Tools is a service that provides partners in the AWS Partner-Led Support program with an integrated dashboard of tools to diagnose and troubleshoot their customer's AWS accounts.

## AWS Diagnostic Tools

- [AWS Diagnostic Tools User Guide](/diagnostic-tools/latest/userguide/): Provides a conceptual overview of AWS Diagnostic Tools and detailed instructions for using its various features.
- [AWS Diagnostic Tools API Reference](/diagnostic-tools/latest/APIReference/): Describes all the AWS Diagnostic Tools API operations in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
