# Data Types
<a name="API_Types"></a>

The AWS Diagnostic Service API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Execution](API_Execution.md)
+  [ExecutionSummary](API_ExecutionSummary.md)
+  [Tag](API_Tag.md)
+  [Tool](API_Tool.md)
+  [ToolSummary](API_ToolSummary.md)
+  [ToolVersion](API_ToolVersion.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
