# RelatedObservations
<a name="API_RelatedObservations"></a>

Describes observations related to the problem.

## Contents
<a name="API_RelatedObservations_Contents"></a>

 ** ObservationList **   <a name="appinsights-Type-RelatedObservations-ObservationList"></a>
The list of observations related to the problem.
Type: Array of [Observation](API_Observation.md) objects
Required: No
