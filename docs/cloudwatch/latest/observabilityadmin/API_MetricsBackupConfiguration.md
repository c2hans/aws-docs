# MetricsBackupConfiguration
<a name="API_MetricsBackupConfiguration"></a>

Configuration for backing up centralized metrics data to a secondary region.

## Contents
<a name="API_MetricsBackupConfiguration_Contents"></a>

 ** Region **   <a name="cwoa-Type-MetricsBackupConfiguration-Region"></a>
Metrics specific backup destination region within the primary destination account to which metrics data should be centralized.
Type: String
Length Constraints: Minimum length of 1.
Required: Yes
