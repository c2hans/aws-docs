# AWS Backup Documentation

AWS Backup is a fully managed backup service that makes it easy to centralize and automate the backup of data across AWS services in the cloud as well as on premises.

- [Developer Guide](/aws-backup/latest/devguide/whatisbackup.html): Provides a conceptual overview of AWS Backup and detailed instructions for using the various features.
- [API Reference](/aws-backup/latest/APIReference/Welcome.html): Describes the API operations for AWS Backup.
