# ScanResultInfo
<a name="API_ScanResultInfo"></a>

Contains information about the results of a scan job.

## Contents
<a name="API_ScanResultInfo_Contents"></a>

 ** ScanResultStatus **   <a name="Backup-Type-ScanResultInfo-ScanResultStatus"></a>
The status of the scan results.
Valid values: `THREATS_FOUND` \| `NO_THREATS_FOUND` \| `UNKNOWN`.
Type: String
Valid Values: `NO_THREATS_FOUND | THREATS_FOUND | UNKNOWN`
Required: Yes
