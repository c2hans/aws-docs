# BrowserConfig
<a name="API_BrowserConfig"></a>

A structure that specifies the browser type to use for a canary run.

## Contents
<a name="API_BrowserConfig_Contents"></a>

 ** BrowserType **   <a name="synthetics-Type-BrowserConfig-BrowserType"></a>
The browser type associated with this browser configuration.
Type: String
Valid Values: `CHROME | FIREFOX`
Required: No
