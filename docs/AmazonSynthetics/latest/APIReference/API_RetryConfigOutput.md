# RetryConfigOutput
<a name="API_RetryConfigOutput"></a>

This structure contains information about the canary's retry configuration.

## Contents
<a name="API_RetryConfigOutput_Contents"></a>

 ** MaxRetries **   <a name="synthetics-Type-RetryConfigOutput-MaxRetries"></a>
The maximum number of retries. The value must be less than or equal to 2.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 2.
Required: No
