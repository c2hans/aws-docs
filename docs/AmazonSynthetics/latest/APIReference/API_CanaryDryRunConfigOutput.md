# CanaryDryRunConfigOutput
<a name="API_CanaryDryRunConfigOutput"></a>

Returns the dry run configurations set for a canary.

## Contents
<a name="API_CanaryDryRunConfigOutput_Contents"></a>

 ** DryRunId **   <a name="synthetics-Type-CanaryDryRunConfigOutput-DryRunId"></a>
The DryRunId associated with an existing canary’s dry run. You can use this DryRunId to retrieve information about the dry run.
Type: String
Pattern: `^[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}$`
Required: No
