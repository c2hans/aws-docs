# ArtifactConfigOutput
<a name="API_ArtifactConfigOutput"></a>

A structure that contains the configuration for canary artifacts, including the encryption-at-rest settings for artifacts that the canary uploads to Amazon S3.

## Contents
<a name="API_ArtifactConfigOutput_Contents"></a>

 ** S3Encryption **   <a name="synthetics-Type-ArtifactConfigOutput-S3Encryption"></a>
A structure that contains the configuration of encryption settings for canary artifacts that are stored in Amazon S3.
Type: [S3EncryptionConfig](API_S3EncryptionConfig.md) object
Required: No
