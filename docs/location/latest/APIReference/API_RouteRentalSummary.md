# RouteRentalSummary
<a name="API_RouteRentalSummary"></a>

Summary of the rental leg.

## Contents
<a name="API_RouteRentalSummary_Contents"></a>

 ** Overview **   <a name="location-Type-RouteRentalSummary-Overview"></a>
Summary including duration and distance for the entire leg.
Type: [RouteRentalOverviewSummary](API_RouteRentalOverviewSummary.md) object
Required: No

 ** TravelOnly **   <a name="location-Type-RouteRentalSummary-TravelOnly"></a>
Summary including duration and distance for the travel portion of the leg only.
Type: [RouteRentalTravelOnlySummary](API_RouteRentalTravelOnlySummary.md) object
Required: No
