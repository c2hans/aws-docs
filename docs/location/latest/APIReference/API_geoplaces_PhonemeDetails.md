# PhonemeDetails
<a name="API_geoplaces_PhonemeDetails"></a>

The phoneme details.

 ** Title **   <a name="location-Type-geoplaces_PhonemeDetails-Title"></a>
List of `PhonemeTranscription`. See `PhonemeTranscription` for fields.
Type: Array of [PhonemeTranscription](API_geoplaces_PhonemeTranscription.md) objects
