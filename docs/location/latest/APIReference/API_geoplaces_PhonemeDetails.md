# PhonemeDetails
<a name="API_geoplaces_PhonemeDetails"></a>

The phoneme details.

## Contents
<a name="API_geoplaces_PhonemeDetails_Contents"></a>

 ** Address **   <a name="location-Type-geoplaces_PhonemeDetails-Address"></a>
How to pronounce the address.
Type: [AddressComponentPhonemes](API_geoplaces_AddressComponentPhonemes.md) object
Required: No

 ** Title **   <a name="location-Type-geoplaces_PhonemeDetails-Title"></a>
List of `PhonemeTranscription`. See `PhonemeTranscription` for fields.
Type: Array of [PhonemeTranscription](API_geoplaces_PhonemeTranscription.md) objects
Array Members: Minimum number of 0 items. Maximum number of 100 items.
Required: No
