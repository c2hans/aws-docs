# CellSignals
<a name="API_WaypointTracking_CellSignals"></a>

The cellular network communication infrastructure that the device uses.

## Contents
<a name="API_WaypointTracking_CellSignals_Contents"></a>

 ** LteCellDetails **   <a name="location-Type-WaypointTracking_CellSignals-LteCellDetails"></a>
Information about the Long-Term Evolution (LTE) network the device is connected to.
Type: Array of [LteCellDetails](API_WaypointTracking_LteCellDetails.md) objects
Array Members: Minimum number of 1 item. Maximum number of 16 items.
Required: Yes
