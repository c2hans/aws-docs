# Category
<a name="API_geoplaces_Category"></a>

Category of the `Place` returned.

## Contents
<a name="API_geoplaces_Category_Contents"></a>

 ** Id **   <a name="location-Type-geoplaces_Category-Id"></a>
The category ID.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: Yes

 ** Name **   <a name="location-Type-geoplaces_Category-Name"></a>
The category name.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: Yes

 ** LocalizedName **   <a name="location-Type-geoplaces_Category-LocalizedName"></a>
Localized name of the category type.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No

 ** Primary **   <a name="location-Type-geoplaces_Category-Primary"></a>
Boolean which indicates if this category is the primary offered by the place.
Type: Boolean
Required: No
