# WaypointOptimizationPedestrianOptions
<a name="API_WaypointOptimizationPedestrianOptions"></a>

 ** Speed **   <a name="location-Type-WaypointOptimizationPedestrianOptions-Speed"></a>

 **Unit**: `kilometers per hour`
Type: Double
Valid Range: Minimum value of 1.8. Maximum value of 7.2.
Required: No
