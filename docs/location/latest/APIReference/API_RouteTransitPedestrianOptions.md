# RouteTransitPedestrianOptions
<a name="API_RouteTransitPedestrianOptions"></a>

Options for the pedestrian leg of the transit route.

## Contents
<a name="API_RouteTransitPedestrianOptions_Contents"></a>

 ** MaxDistance **   <a name="location-Type-RouteTransitPedestrianOptions-MaxDistance"></a>
Maximum walking distance allowed.
 **Unit**: `meters`
Type: Long
Valid Range: Maximum value of 6000.
Required: No

 ** Speed **   <a name="location-Type-RouteTransitPedestrianOptions-Speed"></a>
Walking speed.
 **Unit**: `kilometers per hour`
Type: Double
Valid Range: Minimum value of 1.8. Maximum value of 7.2.
Required: No
