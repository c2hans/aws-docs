# RouteTaxiOverviewSummary
<a name="API_RouteTaxiOverviewSummary"></a>

Summary including duration and distance for the entire leg.

## Contents
<a name="API_RouteTaxiOverviewSummary_Contents"></a>

 ** Distance **   <a name="location-Type-RouteTaxiOverviewSummary-Distance"></a>
Distance of the entire leg.
 **Unit**: `meters`
Type: Long
Valid Range: Minimum value of 0. Maximum value of 4294967295.
Required: Yes

 ** Duration **   <a name="location-Type-RouteTaxiOverviewSummary-Duration"></a>
Duration of the entire leg.
 **Unit**: `seconds`
Type: Long
Valid Range: Minimum value of 0. Maximum value of 4294967295.
Required: Yes
