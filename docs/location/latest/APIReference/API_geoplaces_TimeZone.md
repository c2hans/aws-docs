# TimeZone
<a name="API_geoplaces_TimeZone"></a>

The time zone in which the place is located.

## Contents
<a name="API_geoplaces_TimeZone_Contents"></a>

 ** Name **   <a name="location-Type-geoplaces_TimeZone-Name"></a>
The time zone name.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 200.
Required: Yes

 ** Offset **   <a name="location-Type-geoplaces_TimeZone-Offset"></a>
Time zone offset of the timezone from UTC.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 6.
Required: No

 ** OffsetSeconds **   <a name="location-Type-geoplaces_TimeZone-OffsetSeconds"></a>
The offset of the time zone from UTC, in seconds.
Type: Long
Valid Range: Minimum value of 0.
Required: No
