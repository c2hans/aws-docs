# JobActionOptions
<a name="API_geojobs_JobActionOptions"></a>

Additional options for configuring job action parameters. Currently, only `ValidateAddress` is supported.

## Contents
<a name="API_geojobs_JobActionOptions_Contents"></a>

 ** ValidateAddress **   <a name="location-Type-geojobs_JobActionOptions-ValidateAddress"></a>
Options specific to address validation jobs.
Type: [ValidateAddressActionOptions](API_geojobs_ValidateAddressActionOptions.md) object
Required: No
