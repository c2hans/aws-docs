# TrackingFilterGeometry
<a name="API_WaypointTracking_TrackingFilterGeometry"></a>

The geometry used to filter device positions.

## Contents
<a name="API_WaypointTracking_TrackingFilterGeometry_Contents"></a>

 ** Polygon **   <a name="location-Type-WaypointTracking_TrackingFilterGeometry-Polygon"></a>
The set of arrays which define the polygon. A polygon can have between 4 and 1000 vertices.
Type: Array of arrays of arrays of doubles
Array Members: Minimum number of 1 item.
Array Members: Minimum number of 4 items.
Array Members: Fixed number of 2 items.
Required: No
