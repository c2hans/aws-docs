# RouteRentalTravelOnlySummary
<a name="API_RouteRentalTravelOnlySummary"></a>

Summary including duration and distance for the travel portion of the leg only.

## Contents
<a name="API_RouteRentalTravelOnlySummary_Contents"></a>

 ** Duration **   <a name="location-Type-RouteRentalTravelOnlySummary-Duration"></a>
Duration of the travel portion of the rental leg.
 **Unit**: `seconds`
Type: Long
Valid Range: Minimum value of 0. Maximum value of 4294967295.
Required: Yes
