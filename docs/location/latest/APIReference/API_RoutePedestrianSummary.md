# RoutePedestrianSummary
<a name="API_RoutePedestrianSummary"></a>

Summarized details for the leg including before travel, travel and after travel steps.

## Contents
<a name="API_RoutePedestrianSummary_Contents"></a>

 ** Overview **   <a name="location-Type-RoutePedestrianSummary-Overview"></a>
Summarized details for the leg including before travel, travel and after travel steps.
Type: [RoutePedestrianOverviewSummary](API_RoutePedestrianOverviewSummary.md) object
Required: No

 ** TravelOnly **   <a name="location-Type-RoutePedestrianSummary-TravelOnly"></a>
Summarized details for the leg including travel steps only. The Distance for the travel only portion of the journey is in meters
Type: [RoutePedestrianTravelOnlySummary](API_RoutePedestrianTravelOnlySummary.md) object
Required: No
