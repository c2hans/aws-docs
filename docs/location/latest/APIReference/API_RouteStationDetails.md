# RouteStationDetails
<a name="API_RouteStationDetails"></a>

Details about the station.

## Contents
<a name="API_RouteStationDetails_Contents"></a>

 ** Accessibility **   <a name="location-Type-RouteStationDetails-Accessibility"></a>
Wheelchair accessibility information for the station.
Type: [RouteAccessibilityAvailabilityDetails](API_RouteAccessibilityAvailabilityDetails.md) object
Required: No

 ** PlatformName **   <a name="location-Type-RouteStationDetails-PlatformName"></a>
Platform name or number.
Type: String
Required: No

 ** ShortName **   <a name="location-Type-RouteStationDetails-ShortName"></a>
Short text or a number that identifies the station.
Type: String
Required: No
