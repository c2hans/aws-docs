# RouteTaxiSummary
<a name="API_RouteTaxiSummary"></a>

Summary of the taxi leg.

## Contents
<a name="API_RouteTaxiSummary_Contents"></a>

 ** Overview **   <a name="location-Type-RouteTaxiSummary-Overview"></a>
Summary including duration and distance for the entire leg.
Type: [RouteTaxiOverviewSummary](API_RouteTaxiOverviewSummary.md) object
Required: No

 ** TravelOnly **   <a name="location-Type-RouteTaxiSummary-TravelOnly"></a>
Summary including duration and distance for the travel portion of the leg only.
Type: [RouteTaxiTravelOnlySummary](API_RouteTaxiTravelOnlySummary.md) object
Required: No
