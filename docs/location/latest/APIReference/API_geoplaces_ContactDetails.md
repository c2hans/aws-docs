# ContactDetails
<a name="API_geoplaces_ContactDetails"></a>

Details related to contacts.

## Contents
<a name="API_geoplaces_ContactDetails_Contents"></a>

 ** Categories **   <a name="location-Type-geoplaces_ContactDetails-Categories"></a>
Categories of results that results must belong too.
Type: Array of [Category](API_geoplaces_Category.md) objects
Array Members: Minimum number of 1 item. Maximum number of 100 items.
Required: No

 ** Label **   <a name="location-Type-geoplaces_ContactDetails-Label"></a>
The contact's label.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 200.
Required: No

 ** Value **   <a name="location-Type-geoplaces_ContactDetails-Value"></a>
The contact's value.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 200.
Required: No
