# RouteMatrixAllowOptions
<a name="API_RouteMatrixAllowOptions"></a>

Allow Options related to the route matrix.

## Contents
<a name="API_RouteMatrixAllowOptions_Contents"></a>

 ** Hot **   <a name="location-Type-RouteMatrixAllowOptions-Hot"></a>
Allow Hot (High Occupancy Toll) lanes while calculating the route.
Default value: `false`
Type: Boolean
Required: No

 ** Hov **   <a name="location-Type-RouteMatrixAllowOptions-Hov"></a>
Allow Hov (High Occupancy vehicle) lanes while calculating the route.
Default value: `false`
Type: Boolean
Required: No
