# UspsZip
<a name="API_geoplaces_UspsZip"></a>

The USPS zip code.

## Contents
<a name="API_geoplaces_UspsZip_Contents"></a>

 ** ZipClassificationCode **   <a name="location-Type-geoplaces_UspsZip-ZipClassificationCode"></a>
The ZIP Classification Code, or in other words what type of postal code is it.
Type: String
Valid Values: `Military | PostOfficeBoxes | Unique`
Required: No
