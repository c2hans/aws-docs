# CountryHighlights
<a name="API_geoplaces_CountryHighlights"></a>

Indicates the starting and ending index of the country in the text query that match the found title.

## Contents
<a name="API_geoplaces_CountryHighlights_Contents"></a>

 ** Code **   <a name="location-Type-geoplaces_CountryHighlights-Code"></a>
Indicates the starting and ending index of the country code in the text query that match the found title.
Type: Array of [Highlight](API_geoplaces_Highlight.md) objects
Array Members: Minimum number of 0 items. Maximum number of 200 items.
Required: No

 ** Name **   <a name="location-Type-geoplaces_CountryHighlights-Name"></a>
Indicates the starting and ending index of the country code in the text query that match the found title.
Type: Array of [Highlight](API_geoplaces_Highlight.md) objects
Array Members: Minimum number of 0 items. Maximum number of 200 items.
Required: No
