# WaypointOptimizationDrivingDistanceOptions
<a name="API_WaypointOptimizationDrivingDistanceOptions"></a>

Driving distance related options.

## Contents
<a name="API_WaypointOptimizationDrivingDistanceOptions_Contents"></a>

 ** DrivingDistance **   <a name="location-Type-WaypointOptimizationDrivingDistanceOptions-DrivingDistance"></a>
DrivingDistance assigns all the waypoints that are within driving distance of each other into a single cluster.
Type: Long
Valid Range: Minimum value of 5. Maximum value of 50000.
Required: Yes
