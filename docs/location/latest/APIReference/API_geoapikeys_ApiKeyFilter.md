# ApiKeyFilter
<a name="API_geoapikeys_ApiKeyFilter"></a>

Options for filtering API keys.

## Contents
<a name="API_geoapikeys_ApiKeyFilter_Contents"></a>

 ** KeyStatus **   <a name="location-Type-geoapikeys_ApiKeyFilter-KeyStatus"></a>
Filter on `Active` or `Expired` API keys.
Type: String
Valid Values: `Active | Expired`
Required: No
