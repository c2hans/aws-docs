# JobsFilter
<a name="API_geojobs_JobsFilter"></a>

Criteria for filtering jobs.

## Contents
<a name="API_geojobs_JobsFilter_Contents"></a>

 ** JobStatus **   <a name="location-Type-geojobs_JobsFilter-JobStatus"></a>
Filter by job status.
Type: String
Valid Values: `Pending | Running | Completed | Failed | Cancelling | Cancelled`
Required: No
