# BusinessChain
<a name="API_geoplaces_BusinessChain"></a>

A businesschain is a chain of businesses that belong to the same brand. For example `7-11`.

## Contents
<a name="API_geoplaces_BusinessChain_Contents"></a>

 ** Id **   <a name="location-Type-geoplaces_BusinessChain-Id"></a>
The Business Chain Id.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No

 ** Name **   <a name="location-Type-geoplaces_BusinessChain-Name"></a>
The business chain name.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: No
