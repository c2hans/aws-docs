# AccessRestriction
<a name="API_geoplaces_AccessRestriction"></a>

Indicates if the access location is restricted. Index correlates to that of an access point and indicates if access through this point has some form of restriction.

## Contents
<a name="API_geoplaces_AccessRestriction_Contents"></a>

 ** Categories **   <a name="location-Type-geoplaces_AccessRestriction-Categories"></a>
Categories of results that results must belong too.
Type: Array of [Category](API_geoplaces_Category.md) objects
Array Members: Minimum number of 1 item. Maximum number of 100 items.
Required: No

 ** Restricted **   <a name="location-Type-geoplaces_AccessRestriction-Restricted"></a>
The restriction.
Type: Boolean
Required: No
