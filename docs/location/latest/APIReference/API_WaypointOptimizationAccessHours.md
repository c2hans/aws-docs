# WaypointOptimizationAccessHours
<a name="API_WaypointOptimizationAccessHours"></a>

Access hours corresponding to when a destination can be visited.

## Contents
<a name="API_WaypointOptimizationAccessHours_Contents"></a>

 ** From **   <a name="location-Type-WaypointOptimizationAccessHours-From"></a>
Contains the ID of the starting waypoint in this connection.
Type: [WaypointOptimizationAccessHoursEntry](API_WaypointOptimizationAccessHoursEntry.md) object
Required: Yes

 ** To **   <a name="location-Type-WaypointOptimizationAccessHours-To"></a>
Contains the ID of the ending waypoint in this connection.
Type: [WaypointOptimizationAccessHoursEntry](API_WaypointOptimizationAccessHoursEntry.md) object
Required: Yes
