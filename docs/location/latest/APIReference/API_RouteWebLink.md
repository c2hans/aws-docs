# RouteWebLink
<a name="API_RouteWebLink"></a>

The URL to an external resource.

## Contents
<a name="API_RouteWebLink_Contents"></a>

 ** Description **   <a name="location-Type-RouteWebLink-Description"></a>
Text describing the URL.
Type: String
Required: Yes

 ** AnchorText **   <a name="location-Type-RouteWebLink-AnchorText"></a>
The interactive or clickable portion of the text.
Type: String
Required: No

 ** DeviceType **   <a name="location-Type-RouteWebLink-DeviceType"></a>
Device type for which the link is intended.
Type: String
Valid Values: `Android | Ios | Web`
Required: No

 ** Url **   <a name="location-Type-RouteWebLink-Url"></a>
The URL of the link.
Type: String
Required: No
