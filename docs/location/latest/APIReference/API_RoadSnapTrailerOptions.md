# RoadSnapTrailerOptions
<a name="API_RoadSnapTrailerOptions"></a>

Trailer options corresponding to the vehicle.

## Contents
<a name="API_RoadSnapTrailerOptions_Contents"></a>

 ** TrailerCount **   <a name="location-Type-RoadSnapTrailerOptions-TrailerCount"></a>
Number of trailers attached to the vehicle.
Default value: `0`
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 4.
Required: No
