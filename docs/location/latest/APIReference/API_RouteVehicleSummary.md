# RouteVehicleSummary
<a name="API_RouteVehicleSummary"></a>

Summarized details of the route.

## Contents
<a name="API_RouteVehicleSummary_Contents"></a>

 ** Overview **   <a name="location-Type-RouteVehicleSummary-Overview"></a>
Summarized details for the leg including before travel, travel and after travel steps.
Type: [RouteVehicleOverviewSummary](API_RouteVehicleOverviewSummary.md) object
Required: No

 ** TravelOnly **   <a name="location-Type-RouteVehicleSummary-TravelOnly"></a>
Summarized details for the leg including travel steps only. The Distance for the travel only portion of the journey is in meters
Type: [RouteVehicleTravelOnlySummary](API_RouteVehicleTravelOnlySummary.md) object
Required: No
