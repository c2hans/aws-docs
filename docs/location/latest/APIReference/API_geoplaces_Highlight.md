# Highlight
<a name="API_geoplaces_Highlight"></a>

Indicates the starting and ending index of the text query that match the found title.

## Contents
<a name="API_geoplaces_Highlight_Contents"></a>

 ** EndIndex **   <a name="location-Type-geoplaces_Highlight-EndIndex"></a>
End index of the highlight.
Type: Integer
Valid Range: Minimum value of 0.
Required: No

 ** StartIndex **   <a name="location-Type-geoplaces_Highlight-StartIndex"></a>
Start index of the highlight.
Type: Integer
Valid Range: Minimum value of 0.
Required: No

 ** Value **   <a name="location-Type-geoplaces_Highlight-Value"></a>
The highlight's value.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 200.
Required: No
