# RouteTollPaymentSite
<a name="API_RouteTollPaymentSite"></a>

Locations or sites where the toll fare is collected.

## Contents
<a name="API_RouteTollPaymentSite_Contents"></a>

 ** Position **   <a name="location-Type-RouteTollPaymentSite-Position"></a>
Position in World Geodetic System (WGS 84) format: [longitude, latitude].
Type: Array of doubles
Array Members: Minimum number of 2 items. Maximum number of 3 items.
Required: Yes

 ** Name **   <a name="location-Type-RouteTollPaymentSite-Name"></a>
Name of the payment site.
Type: String
Required: No
