# RouteIntermodalPedestrianOptions
<a name="API_RouteIntermodalPedestrianOptions"></a>

Options for the pedestrian leg of the intermodal route.

## Contents
<a name="API_RouteIntermodalPedestrianOptions_Contents"></a>

 ** MaxDistance **   <a name="location-Type-RouteIntermodalPedestrianOptions-MaxDistance"></a>
Maximum walking distance allowed.
 **Unit**: `meters`
Type: Long
Valid Range: Minimum value of 0. Maximum value of 6000.
Required: No

 ** Speed **   <a name="location-Type-RouteIntermodalPedestrianOptions-Speed"></a>
Walking speed.
 **Unit**: `kilometers per hour`
Type: Double
Valid Range: Minimum value of 1.8. Maximum value of 7.2.
Required: No
