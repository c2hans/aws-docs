# RouteTollSummary
<a name="API_RouteTollSummary"></a>

The toll summary for the complete route.

## Contents
<a name="API_RouteTollSummary_Contents"></a>

 ** Total **   <a name="location-Type-RouteTollSummary-Total"></a>
Total toll summary for the complete route. Total is the only summary available today.
Type: [RouteTollPriceSummary](API_RouteTollPriceSummary.md) object
Required: No
