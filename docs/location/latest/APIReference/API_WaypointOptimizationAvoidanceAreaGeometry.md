# WaypointOptimizationAvoidanceAreaGeometry
<a name="API_WaypointOptimizationAvoidanceAreaGeometry"></a>

Geometry of the area to be avoided.

## Contents
<a name="API_WaypointOptimizationAvoidanceAreaGeometry_Contents"></a>

 ** BoundingBox **   <a name="location-Type-WaypointOptimizationAvoidanceAreaGeometry-BoundingBox"></a>
Geometry defined as a bounding box. The first pair represents the X and Y coordinates (longitude and latitude,) of the southwest corner of the bounding box; the second pair represents the X and Y coordinates (longitude and latitude) of the northeast corner.
Type: Array of doubles
Array Members: Fixed number of 4 items.
Required: No
