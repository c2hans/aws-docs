# RouteTransitSummary
<a name="API_RouteTransitSummary"></a>

Summary of the transit leg.

## Contents
<a name="API_RouteTransitSummary_Contents"></a>

 ** Overview **   <a name="location-Type-RouteTransitSummary-Overview"></a>
Summary including duration and distance for the entire leg.
Type: [RouteTransitOverviewSummary](API_RouteTransitOverviewSummary.md) object
Required: No

 ** TravelOnly **   <a name="location-Type-RouteTransitSummary-TravelOnly"></a>
Summary including duration and distance for the travel portion of the leg only.
Type: [RouteTransitTravelOnlySummary](API_RouteTransitTravelOnlySummary.md) object
Required: No
