# RouteTrailerOptions
<a name="API_RouteTrailerOptions"></a>

Trailer options corresponding to the vehicle.

## Contents
<a name="API_RouteTrailerOptions_Contents"></a>

 ** AxleCount **   <a name="location-Type-RouteTrailerOptions-AxleCount"></a>
Total number of axles of the vehicle.
Type: Integer
Valid Range: Minimum value of 1.
Required: No

 ** TrailerCount **   <a name="location-Type-RouteTrailerOptions-TrailerCount"></a>
Number of trailers attached to the vehicle.
Default value: `0`
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 255.
Required: No
