# WaypointOptimizationTrafficOptions
<a name="API_WaypointOptimizationTrafficOptions"></a>

Options related to traffic.

## Contents
<a name="API_WaypointOptimizationTrafficOptions_Contents"></a>

 ** Usage **   <a name="location-Type-WaypointOptimizationTrafficOptions-Usage"></a>
Determines if traffic should be used or ignored while calculating the route.
Default value: `UseTrafficData`
Type: String
Valid Values: `IgnoreTrafficData | UseTrafficData`
Required: No
