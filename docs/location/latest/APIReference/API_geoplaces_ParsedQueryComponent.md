# ParsedQueryComponent
<a name="API_geoplaces_ParsedQueryComponent"></a>

Parsed components in the provided QueryText.

## Contents
<a name="API_geoplaces_ParsedQueryComponent_Contents"></a>

 ** EndIndex **   <a name="location-Type-geoplaces_ParsedQueryComponent-EndIndex"></a>
End index of the parsed query component.
Type: Integer
Valid Range: Minimum value of 0.
Required: No

 ** QueryComponent **   <a name="location-Type-geoplaces_ParsedQueryComponent-QueryComponent"></a>
The address component that the parsed query component corresponds to.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 11.
Required: No

 ** StartIndex **   <a name="location-Type-geoplaces_ParsedQueryComponent-StartIndex"></a>
Start index of the parsed query component.
Type: Integer
Valid Range: Minimum value of 0.
Required: No

 ** Value **   <a name="location-Type-geoplaces_ParsedQueryComponent-Value"></a>
Value of the parsed query component.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 200.
Required: No
