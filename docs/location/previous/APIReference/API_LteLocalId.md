# LteLocalId
<a name="API_LteLocalId"></a>

LTE local identification information (local ID).

## Contents
<a name="API_LteLocalId_Contents"></a>

 ** Earfcn **   <a name="location-Type-LteLocalId-Earfcn"></a>
E-UTRA (Evolved Universal Terrestrial Radio Access) absolute radio frequency channel number (EARFCN).
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 262143.
Required: Yes

 ** Pci **   <a name="location-Type-LteLocalId-Pci"></a>
Physical Cell ID (PCI).
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 503.
Required: Yes
