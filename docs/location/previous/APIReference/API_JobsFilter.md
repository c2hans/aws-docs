# JobsFilter
<a name="API_JobsFilter"></a>

Criteria for filtering jobs.

## Contents
<a name="API_JobsFilter_Contents"></a>

 ** JobStatus **   <a name="location-Type-JobsFilter-JobStatus"></a>
Filter by job status.
Type: String
Valid Values: `Pending | Running | Completed | Failed | Cancelling | Cancelled`
Required: No
