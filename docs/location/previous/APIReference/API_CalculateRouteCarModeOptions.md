# CalculateRouteCarModeOptions
<a name="API_CalculateRouteCarModeOptions"></a>

Contains details about additional route preferences for requests that specify `TravelMode` as `Car`.

## Contents
<a name="API_CalculateRouteCarModeOptions_Contents"></a>

 ** AvoidFerries **   <a name="location-Type-CalculateRouteCarModeOptions-AvoidFerries"></a>
Avoids ferries when calculating routes.
Default Value: `false`
Valid Values: `false` \| `true`
Type: Boolean
Required: No

 ** AvoidTolls **   <a name="location-Type-CalculateRouteCarModeOptions-AvoidTolls"></a>
Avoids tolls when calculating routes.
Default Value: `false`
Valid Values: `false` \| `true`
Type: Boolean
Required: No
