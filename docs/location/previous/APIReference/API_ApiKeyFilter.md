# ApiKeyFilter
<a name="API_ApiKeyFilter"></a>

Options for filtering API keys.

## Contents
<a name="API_ApiKeyFilter_Contents"></a>

 ** KeyStatus **   <a name="location-Type-ApiKeyFilter-KeyStatus"></a>
Filter on `Active` or `Expired` API keys.
Type: String
Valid Values: `Active | Expired`
Required: No
