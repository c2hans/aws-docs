# Document history
<a name="doc-history"></a>

The following table describes the documentation for Amazon Location Service. For notification about updates you can subscribe to an RSS feed.

| Change | Description | Date |
| --- |--- |--- |
| [Amazon Location Service releases a new SDK for JavaScript](#doc-history) | To make developing Amazon Location applications easier with in web front ends, Amazon Location adds a new open source SDK that supports AWS SDK for JavaScript v3, simplifying authentication and using GeoJSON. For mor information, see [Amazon Location SDK](https://docs.aws.amazon.com/location/previous/developerguide/dev-location-libraries.html). | July 6, 2023 |
| [Amazon Location Service releases API keys to general availability](#doc-history) | Amazon Location adds support for place and route and announce general availability of the API keys feature. For more information, see [Using API keys](https://docs.aws.amazon.com/location/previous/developerguide/using-apikeys.html). | July 6, 2023 |
| [Amazon Location Service adds Amazon EventBridge events for position updates](#doc-history) | Amazon Location adds support for sending tracker position update events to EventBridge. For more information, including how to enable the events for a tracker, see [Reacting to events with EventBridge](https://docs.aws.amazon.com/location/previous/developerguide/location-events.html). | July 6, 2023 |
| [Amazon Location adds metadata to geofences](#doc-history) | Using the Amazon Location API, you can now add metadata properties to your geofences. These are stored with your geofence, and included in events related to the geofence in Amazon EventBridge. For more information, see [Draw geofences](https://docs.aws.amazon.com/location/previous/developerguide/add-geofences.html#draw-geofences) and [Create event rules](https://docs.aws.amazon.com/location/previous/developerguide/location-events.html#create-event-rule). | June 15, 2023 |
| [Amazon Location adds categories for places](#doc-history) | Amazon Location add categories in place search results, and filtering results by category. For more information, see [Categories and filtering](https://docs.aws.amazon.com/location/previous/developerguide/category-filtering.html). | June 15, 2023 |
| [Amazon Location introduces political views](#doc-history) | Amazon Location adds political views to certain map styles. For more information, see [Political views](https://docs.aws.amazon.com/location/previous/developerguide/map-concepts.html#political-views). | May 23, 2023 |
| [Amazon Location introduces new demo and samples site](#doc-history) | Amazon Location announces a new web site that gives you access to Amazon Location demos and samples. For more information, see [Amazon Location demo site](https://docs.aws.amazon.com/location/previous/developerguide/samples.html#sample-demo-site). | May 3, 2023 |
| [Amazon Location introduces longer routes in CalculateRouteMatrix](#doc-history) | Amazon Location now allows unlimited length routes for route matrix routes created with the HERE data provider. For more information, see [Longer route planning](https://docs.aws.amazon.com/location/previous/developerguide/calculate-route-matrix.html#matrix-routing-position-limits). | April 24, 2023 |
| [Amazon Location documentation adds feature differences by data provider](#doc-history) | Amazon Location documentation has been updated with information regarding the differences between each data provider in Maps, Places search, and routing. For more information, see [Features by data provider](https://docs.aws.amazon.com/location/previous/developerguide/data-provider-features.html). | March 30, 2023 |
| [Amazon Location Open Data maps general availability](#doc-history) | General availability of Amazon Location Service data provider and style, based on OpenStreetMap's Daylight maps. For more information, see [Open Data](https://docs.aws.amazon.com/location/previous/developerguide/open-data.html). | March 7, 2023 |
| [Amazon Location adds new authorization method in preview](#doc-history) | Amazon Location Service adds API keys as a new authorization method for anonymous users, in preview mode. For more information, see [Allowing unauthenticated guest access to your application using API keys](https://docs.aws.amazon.com/location/previous/developerguide/using-apikeys.html). | February 23, 2023 |
| [Amazon Location documentation updated with latest IAM best practices](#doc-history) | Amazon Location Service documentation has been updated to meet the most recent AWS Identity and Access Management best practices. For more information, see [Security in Amazon Location Service](https://docs.aws.amazon.com/location/previous/developerguide/security.html). | January 26, 2023 |
| [Amazon Location Service adds GrabMaps as a data provider in Southeast Asia](#doc-history) | Amazon Location introduces GrabMaps as a data provider in Southeast Asia. For more information, see [GrabMaps](https://docs.aws.amazon.com/location/previous/developerguide/grab.html). | January 10, 2023 |
| [Amazon Location Service Open Data maps in preview](#doc-history) | New Amazon Location data provider and style added in public preview, based on OpenStreetMap's Daylight maps. For more information, see [Open Data (Preview)](https://docs.aws.amazon.com/location/previous/developerguide/open-data.html). | December 15, 2022 |
| [New HERE satellite imagery styles](#doc-history) | Two new map styles have been added for maps using HERE as a data provider, HERE Satellite Imagery and HERE Hybrid map styles. For more information, see [HERE map styles](https://docs.aws.amazon.com/location/previous/developerguide/HERE.html#HERE-map-styles). | October 25, 2022 |
| [Units in addresses](#doc-history) | Amazon Location Service now supports units in addresses, for example "123 Main St, *Apartment 3B*, Anytown, USA". | September 20, 2022 |
| [Get places by ID](#doc-history) | Amazon Location Service now includes support finding the exact location suggested by the `SearchPlaceIndexForSuggestions` operation using the `GetPlace` operation. See [ Using autocomplete](https://docs.aws.amazon.com/location/previous/developerguide/search-place-index-autocomplete.html#autocomplete). | September 20, 2022 |
| [Additional condition keys for IAM policy](#doc-history) | Amazon Location Service now supports additional condition keys that let you set access for specific geofences or devices in IAM policy. | [Circle geofences](#doc-history) | Amazon Location Service now supports geofences defined as a circle with a center point and a radius, to get events when devices are within a certain distance of a location. See [Adding circular geofences](https://docs.aws.amazon.com/location/previous/developerguide/add-geofences.html#draw-circle-geofences). | August 11, 2022 |
| [Combined API reference](#doc-history) | Amazon Location Service now has a single API reference guide, rather than separate guides for each subservice. | [Service Quotas integration](#doc-history) | Amazon Location is now [ integrated with Service Quotas](https://docs.aws.amazon.com/location/previous/developerguide/location-quotas.html#service-quotas-manage) allowing you to view and manage your quotas through the AWS Management Console or using the AWS CLI. | July 6, 2022 |
| [Updated concepts documentation chapter](#doc-history) | The [Amazon Location concepts chapter](https://docs.aws.amazon.com/location/previous/developerguide/how-it-works.html) has been updated with more information for users of Amazon Location. | April 22, 2022 |
| [New Android quick start tutorial](#doc-history) | A new [quick start tutorial](https://docs.aws.amazon.com/location/previous/developerguide/getting-started.html) for Android development using Kotlin has been added to get developers up and running quickly. | April 15, 2022 |
| [New HERE Map styles](#doc-history) | Two new map styles have been added for maps using HERE as a data provider. For more information, see [HERE map styles](https://docs.aws.amazon.com/location/previous/developerguide/HERE.html#HERE-map-styles). | March 15, 2022 |
