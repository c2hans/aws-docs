# PerformanceInsightsReferenceData
<a name="API_PerformanceInsightsReferenceData"></a>

Reference data used to evaluate Performance Insights to determine if its performance is anomalous or not.

## Contents
<a name="API_PerformanceInsightsReferenceData_Contents"></a>

 ** ComparisonValues **   <a name="DevOpsGuru-Type-PerformanceInsightsReferenceData-ComparisonValues"></a>
The specific reference values used to evaluate the Performance Insights. For more information, see ` [PerformanceInsightsReferenceComparisonValues](https://docs.aws.amazon.com/devops-guru/latest/APIReference/API_PerformanceInsightsReferenceComparisonValues.html) `.
Type: [PerformanceInsightsReferenceComparisonValues](API_PerformanceInsightsReferenceComparisonValues.md) object
Required: No

 ** Name **   <a name="DevOpsGuru-Type-PerformanceInsightsReferenceData-Name"></a>
The name of the reference data.
Type: String
Required: No
