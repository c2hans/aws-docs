# InsightHealth
<a name="API_InsightHealth"></a>

 Information about the number of open reactive and proactive insights that can be used to gauge the health of your system.

## Contents
<a name="API_InsightHealth_Contents"></a>

 ** MeanTimeToRecoverInMilliseconds **   <a name="DevOpsGuru-Type-InsightHealth-MeanTimeToRecoverInMilliseconds"></a>
 The Meant Time to Recover (MTTR) for the insight.
Type: Long
Required: No

 ** OpenProactiveInsights **   <a name="DevOpsGuru-Type-InsightHealth-OpenProactiveInsights"></a>
 The number of open proactive insights.
Type: Integer
Required: No

 ** OpenReactiveInsights **   <a name="DevOpsGuru-Type-InsightHealth-OpenReactiveInsights"></a>
 The number of open reactive insights.
Type: Integer
Required: No
