# EndTimeRange
<a name="API_EndTimeRange"></a>

 A range of time that specifies when anomalous behavior in an anomaly or insight ended.

## Contents
<a name="API_EndTimeRange_Contents"></a>

 ** FromTime **   <a name="DevOpsGuru-Type-EndTimeRange-FromTime"></a>
 The earliest end time in the time range.
Type: Timestamp
Required: No

 ** ToTime **   <a name="DevOpsGuru-Type-EndTimeRange-ToTime"></a>
 The latest end time in the time range.
Type: Timestamp
Required: No
