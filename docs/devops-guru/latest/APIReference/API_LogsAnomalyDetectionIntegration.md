# LogsAnomalyDetectionIntegration
<a name="API_LogsAnomalyDetectionIntegration"></a>

 Information about the integration of DevOps Guru with CloudWatch log groups for log anomaly detection.

## Contents
<a name="API_LogsAnomalyDetectionIntegration_Contents"></a>

 ** OptInStatus **   <a name="DevOpsGuru-Type-LogsAnomalyDetectionIntegration-OptInStatus"></a>
Specifies if DevOps Guru is configured to perform log anomaly detection on CloudWatch log groups.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: No
