# ServiceCollection
<a name="API_ServiceCollection"></a>

A collection of the names of AWS services.

## Contents
<a name="API_ServiceCollection_Contents"></a>

 ** ServiceNames **   <a name="DevOpsGuru-Type-ServiceCollection-ServiceNames"></a>
An array of strings that each specifies the name of an AWS service.
Type: Array of strings
Valid Values: `API_GATEWAY | APPLICATION_ELB | AUTO_SCALING_GROUP | CLOUD_FRONT | DYNAMO_DB | EC2 | ECS | EKS | ELASTIC_BEANSTALK | ELASTI_CACHE | ELB | ES | KINESIS | LAMBDA | NAT_GATEWAY | NETWORK_ELB | RDS | REDSHIFT | ROUTE_53 | S3 | SAGE_MAKER | SNS | SQS | STEP_FUNCTIONS | SWF`
Required: No
