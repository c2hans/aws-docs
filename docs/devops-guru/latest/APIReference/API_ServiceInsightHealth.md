# ServiceInsightHealth
<a name="API_ServiceInsightHealth"></a>

Contains the number of open proactive and reactive insights in an analyzed AWS service.

## Contents
<a name="API_ServiceInsightHealth_Contents"></a>

 ** OpenProactiveInsights **   <a name="DevOpsGuru-Type-ServiceInsightHealth-OpenProactiveInsights"></a>
The number of open proactive insights in the AWS service
Type: Integer
Required: No

 ** OpenReactiveInsights **   <a name="DevOpsGuru-Type-ServiceInsightHealth-OpenReactiveInsights"></a>
The number of open reactive insights in the AWS service
Type: Integer
Required: No
