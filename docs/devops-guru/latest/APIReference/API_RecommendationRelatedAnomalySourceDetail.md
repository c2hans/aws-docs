# RecommendationRelatedAnomalySourceDetail
<a name="API_RecommendationRelatedAnomalySourceDetail"></a>

 Contains an array of `RecommendationRelatedCloudWatchMetricsSourceDetail` objects that contain the name and namespace of an Amazon CloudWatch metric.

## Contents
<a name="API_RecommendationRelatedAnomalySourceDetail_Contents"></a>

 ** CloudWatchMetrics **   <a name="DevOpsGuru-Type-RecommendationRelatedAnomalySourceDetail-CloudWatchMetrics"></a>
 An array of `CloudWatchMetricsDetail` objects that contains information about the analyzed metrics that displayed anomalous behavior.
Type: Array of [RecommendationRelatedCloudWatchMetricsSourceDetail](API_RecommendationRelatedCloudWatchMetricsSourceDetail.md) objects
Required: No
