# LogAnomalyShowcase
<a name="API_LogAnomalyShowcase"></a>

 A cluster of similar anomalous log events found within a log group.

## Contents
<a name="API_LogAnomalyShowcase_Contents"></a>

 ** LogAnomalyClasses **   <a name="DevOpsGuru-Type-LogAnomalyShowcase-LogAnomalyClasses"></a>
 A list of anomalous log events that may be related.
Type: Array of [LogAnomalyClass](API_LogAnomalyClass.md) objects
Array Members: Minimum number of 0 items. Maximum number of 10 items.
Required: No
