# RecommendationRelatedEventResource
<a name="API_RecommendationRelatedEventResource"></a>

 Information about an AWS resource that emitted and event that is related to a recommendation in an insight.

## Contents
<a name="API_RecommendationRelatedEventResource_Contents"></a>

 ** Name **   <a name="DevOpsGuru-Type-RecommendationRelatedEventResource-Name"></a>
 The name of the resource that emitted the event. This corresponds to the `Name` field in an `EventResource` object.
Type: String
Required: No

 ** Type **   <a name="DevOpsGuru-Type-RecommendationRelatedEventResource-Type"></a>
 The type of the resource that emitted the event. This corresponds to the `Type` field in an `EventResource` object.
Type: String
Required: No
