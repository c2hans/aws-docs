# RecommendationRelatedCloudWatchMetricsSourceDetail
<a name="API_RecommendationRelatedCloudWatchMetricsSourceDetail"></a>

 Information about an Amazon CloudWatch metric that is analyzed by DevOps Guru. It is one of many analyzed metrics that are used to generate insights.

## Contents
<a name="API_RecommendationRelatedCloudWatchMetricsSourceDetail_Contents"></a>

 ** MetricName **   <a name="DevOpsGuru-Type-RecommendationRelatedCloudWatchMetricsSourceDetail-MetricName"></a>
The name of the CloudWatch metric.
Type: String
Required: No

 ** Namespace **   <a name="DevOpsGuru-Type-RecommendationRelatedCloudWatchMetricsSourceDetail-Namespace"></a>
The namespace of the CloudWatch metric. A namespace is a container for CloudWatch metrics.
Type: String
Required: No
