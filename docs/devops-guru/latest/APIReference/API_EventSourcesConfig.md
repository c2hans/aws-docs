# EventSourcesConfig
<a name="API_EventSourcesConfig"></a>

Information about the integration of DevOps Guru as consumer with another AWS service, such as AWS CodeGuru Profiler via EventBridge.

## Contents
<a name="API_EventSourcesConfig_Contents"></a>

 ** AmazonCodeGuruProfiler **   <a name="DevOpsGuru-Type-EventSourcesConfig-AmazonCodeGuruProfiler"></a>
Information about whether DevOps Guru is configured to consume recommendations which are generated from AWS CodeGuru Profiler.
Type: [AmazonCodeGuruProfilerIntegration](API_AmazonCodeGuruProfilerIntegration.md) object
Required: No
