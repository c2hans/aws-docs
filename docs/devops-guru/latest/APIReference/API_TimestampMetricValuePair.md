# TimestampMetricValuePair
<a name="API_TimestampMetricValuePair"></a>

A pair that contains metric values at the respective timestamp.

## Contents
<a name="API_TimestampMetricValuePair_Contents"></a>

 ** MetricValue **   <a name="DevOpsGuru-Type-TimestampMetricValuePair-MetricValue"></a>
Value of the anomalous metric data point at respective Timestamp.
Type: Double
Required: No

 ** Timestamp **   <a name="DevOpsGuru-Type-TimestampMetricValuePair-Timestamp"></a>
A `Timestamp` that specifies the time the event occurred.
Type: Timestamp
Required: No
