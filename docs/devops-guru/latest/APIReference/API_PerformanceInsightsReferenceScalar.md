# PerformanceInsightsReferenceScalar
<a name="API_PerformanceInsightsReferenceScalar"></a>

A reference value to compare Performance Insights metrics against to determine if the metrics demonstrate anomalous behavior.

## Contents
<a name="API_PerformanceInsightsReferenceScalar_Contents"></a>

 ** Value **   <a name="DevOpsGuru-Type-PerformanceInsightsReferenceScalar-Value"></a>
The reference value.
Type: Double
Required: No
