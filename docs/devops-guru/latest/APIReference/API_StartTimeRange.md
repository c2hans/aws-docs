# StartTimeRange
<a name="API_StartTimeRange"></a>

 A time range used to specify when the behavior of an insight or anomaly started.

## Contents
<a name="API_StartTimeRange_Contents"></a>

 ** FromTime **   <a name="DevOpsGuru-Type-StartTimeRange-FromTime"></a>
 The start time of the time range.
Type: Timestamp
Required: No

 ** ToTime **   <a name="DevOpsGuru-Type-StartTimeRange-ToTime"></a>
 The end time of the time range.
Type: Timestamp
Required: No
