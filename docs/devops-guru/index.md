# Amazon DevOps Guru Documentation

Amazon DevOps Guru generates operational insights using machine learning to help you improve the performance of your operational applications.

- [User Guide](/devops-guru/latest/userguide/welcome.html): Describes how to use Amazon DevOps Guru to generate insights using machine learning to help you improve the performance of your operational applications.
- [API Reference](/devops-guru/latest/APIReference/Welcome.html): Describes the API operations for Amazon DevOps Guru. Also provides details of related request and response syntax and errors.
