# Version 2.28.2 and 3.28.2
<a name="rn-2-28-2"></a>

This release of AWS Elemental Live and AWS Elemental Statmux version 2.28.2, and AWS Elemental Conductor Live version 3.28.2, applies the latest Red Hat security patches to the operating system of your appliances. It has no other changes from version 2.28.1 and 3.28.1. Upgrade to this release to keep your appliances current with security fixes.

## New features in version 2.28.2
<a name="rn-2-28-2-new-features"></a>

This release includes the following new features:

Security updates
This release includes operating system package and kernel updates that address potential security issues. These updates help protect your appliances against vulnerabilities that were identified after the previous release. AWS continues to apply Red Hat security patches to keep the appliance secure, in accordance with the shared responsibility model.
