# Simple Network Management Protocol (SNMP) traps
<a name="notification-trap"></a>

You can configure AWS Elemental Live to generate Simple Network Magement Protocol (SNMPv2) traps for the following activity:
+ All alerts that Elemental Live and worker nodes generate
+ Conductor node or worker node failure
