# AWS CloudFormation template
<a name="aws-cloudformation-template"></a>

 You can download the CloudFormation template for this solution before deploying it.

 [![View template button for the Video on Demand on AWS Foundation solution.](http://docs.aws.amazon.com/solutions/latest/video-on-demand-on-aws-foundation/images/view-template.png)](https://solutions-reference.s3.amazonaws.com/video-on-demand-on-aws-foundation/latest/video-on-demand-on-aws-foundation.template) **video-on-demand-on-aws-foundation.template** - Use this template to launch the solution and all associated components. The default configuration deploys the core and supporting services found in the [AWS services in this solution](architecture-details.md#aws-services-in-this-solution) section, but you can customize the template to meet your specific needs.
