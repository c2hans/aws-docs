# Shared leases

On a lease with more than one user, each user who owns the lease or was added to it individually has a separate Sandbox Space. Each user has a separate conversation, runtime session, memory namespace, and usage record. The agent runs with the permission set and the source identity of the user who sent the message. All users on the lease draw from the same lease budget, so the budget thresholds act on the combined spend. A user who has access only through a group cannot open a Sandbox Space. For the user view of shared leases, see [Viewing leases shared with you](user-section.md#shared-leases).
