# Configure the web application
<a name="webapp-config"></a>

After setting up SAML 2.0, mapping application attributes, setting up users and groups, and updating the SAML application with the Data stack outputs, you can configure the web application.

Log in to the AWS account where the solution Hub and data stacks are deployed. Make sure that you are in the correct home Region.

+  [Configure solution settings in the web application](updating-the-global-config.md)
