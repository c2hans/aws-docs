# Developer guide
<a name="developer-guide"></a>

This section provides the source code, and list of API endpoints for the solution.

## Source code
<a name="source-code"></a>

To download the templates and scripts for this solution, and to share your customizations with others, refer to the Innovation Sandbox on AWS [GitHub repository](https://github.com/aws-solutions/innovation-sandbox-on-aws).

## List of solution API endpoints
<a name="isb-apis"></a>

All features from the Innovation Sandbox on AWS solution are available as API endpoints.

To view the list of current API endpoints in an OpenAPI specification format, refer to the [Innovation Sandbox API specification](https://github.com/aws-solutions/innovation-sandbox-on-aws/tree/main/docs/openapi/innovation-sandbox-api.yaml).
