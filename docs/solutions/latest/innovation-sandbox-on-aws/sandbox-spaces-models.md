# Model catalog and pricing

Administrators choose the Amazon Bedrock models that users can select, in the **Sandbox Spaces** section of the **Settings** page. Managers can limit a lease template or a lease to a subset of those models. The solution prices each model from the AWS Price List or from Amazon Bedrock agreement offers, and users can’t use a model that has no price. For more information, see [Enabling models](administrator-guide.md#sandbox-spaces-add-models).
