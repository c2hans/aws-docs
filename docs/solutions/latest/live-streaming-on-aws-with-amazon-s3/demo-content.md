# Demo content
<a name="demo-content"></a>

The solution includes a link to a demo HTTP Live Streaming (HLS) stream hosted in an Amazon S3 bucket, which lets you test the solution without having to set up and configure a live stream. Deploying the solution with default parameters, launches the demo.
