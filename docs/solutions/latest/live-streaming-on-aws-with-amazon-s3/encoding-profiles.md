# Encoding profiles
<a name="encoding-profiles"></a>

The Live Streaming on AWS with Amazon S3 solution configures MediaLive with one of three progressive, 30 frames per second encoding profiles. Choose one of the following encoding profiles.
+  **HD-1080p profile** - 1920x1080, 1280x720, 960x540, 768x432, 640x360, 512x288
+  **HD-720p profile** - 1280x720, 960x540, 768x432, 640x360, 512x288
+  **SD-540p profile** - 960x540, 768x432, 640x360, 512x288
