# Uninstall the solution
<a name="uninstall-the-solution"></a>

You can uninstall the Live Streaming on AWS with Amazon S3 solution from the AWS Management Console, or by using the AWS Command Line Interface (AWS CLI). You must manually delete the Amazon S3 buckets created by this solution. AWS Solutions do not automatically delete these resources in case you have stored data to retain.
