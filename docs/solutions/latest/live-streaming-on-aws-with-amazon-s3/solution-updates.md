# Solution updates
<a name="solution-updates"></a>

To continue using this solution with the latest features and improvements, you must deploy the latest version of the AWS CloudFormation template as a new stack. This solution does not support updating an existing stack. For information to deploy the latest AWS CloudFormation template as a new stack, refer to [Launch the stack](launch-the-stack.md). After the new stack completes deployment, we recommend [uninstalling the previous version](uninstall-the-solution.md) to save on costs.
