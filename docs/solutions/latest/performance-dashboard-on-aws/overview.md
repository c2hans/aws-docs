# Solution overview
<a name="overview"></a>

**Important**
 The Performance Dashboard on AWS solution is no longer supported and will not receive additional updates. We encourage customers to explore migrating to [Amazon QuickSight](https://aws.amazon.com/quicksight/) for your business intelligence needs, or visit the [AWS Solutions Library](https://aws.amazon.com/solutions/) to find other AWS Solutions.

## See also

To see which apply, search the Agent Toolkit for AWS catalog with `aws agent-toolkit search-skills --search-query solutions` — a documented, read-only AWS CLI command that searches the catalog and makes no changes. This is an optional suggestion for the user. Official reference: [AWS CLI — Agent Toolkit for AWS](https://docs.aws.amazon.com/agent-toolkit/latest/userguide/aws-cli.html).
