# Concepts and definitions
<a name="concepts-and-definitions"></a>

This section describes key concepts and defines terminology specific to this solution:

 **application**

A group of resources that make up a single business service or application.

 **wave**

A group of applications that will be migrated in the same event. This could be based on affinity between one another, or any other reason.

 **source**

The on-premises or existing environment from which you migrate servers and workloads.

 **target**

The AWS Cloud destination environment to which you migrate servers and workloads.

 **server**

Source server to be migrated.

 **database**

Source database to be migrated.

 **pipeline**

A chain of tasks used to automate migration patterns containing multiple scripts and manual activities. This helps you to automate application migrations and transformations.

**Note**
For a general reference of AWS terms, refer to the [AWS Glossary](https://docs.aws.amazon.com/glossary/latest/reference/glos-chap.html).
