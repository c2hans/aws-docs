# Use cases
<a name="use-cases"></a>

 **Migrate and manage large-scale migrations of workloads to AWS**

Enable a single pane of glass view of large-scale workload migrations to AWS. Providing prebuilt automation, reporting and role-based access via a single web interface designed specifically for migrations.
