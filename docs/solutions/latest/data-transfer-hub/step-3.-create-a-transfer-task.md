# Step 3. Create a transfer task
<a name="step-3.-create-a-transfer-task"></a>

 Use the web console to create a transfer task for Amazon S3 or Amazon ECR. For more information, refer to [Create Amazon S3 Transfer Task](create-an-amazon-s3-transfer-task.md) and [Create Amazon ECR Transfer Task](create-an-amazon-ecr-transfer-task.md).
