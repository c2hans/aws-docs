# Plan your deployment
<a name="plan-your-deployment"></a>

 This section describes the Region, [Cost](cost.md), [Security](security-1.md), and [Quotas](quotas.md) considerations for planning your deployment.

## Supported AWS Regions
<a name="supported-aws-regions"></a>

 This Guidance uses services which may not be currently available in all AWS Regions. Launch this Guidance in an AWS Region where required services are available. For the most current availability by Region, refer to the [AWS Regional Services List](https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/).
