# Asset and Project Operations

## Add Users to a Project
<a name="add-users-to-project"></a>

You can grant users or groups access to a project and assign permission levels through the Access Management menu.

1. Open the project you want to manage.

1. On the Project Details screen, choose the **Access Management** tab.

1. Choose **Users** or **Groups**, then choose **Add user** or **Add group**.

1. For **User** or **Group**, select the one you want to add.

1. For **Membership level**, choose **Owner**, **Manager**, **Contributor**, **Consumer**, or **Viewer**.

1. Choose **Add user** or **Add group** to grant access.

The user or group now has access to the project with the specified permission level.
