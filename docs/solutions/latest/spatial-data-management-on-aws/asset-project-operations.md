## Add users to a project
<a name="add-users-to-project"></a>

You can grant users or groups access to a project and assign permission levels through the Access Management menu.

1. Open the project you want to manage.

1. On the Project Details screen, choose **Access Management**.

1. Choose **Add User** or **Add Group**.

1. Select the user or group you want to add.

1. Choose a permission level: **Owner**, **Contributor**, or **Viewer**.

1. Choose **Add** to grant access.

The user or group now has access to the project with the specified permission level.

![Access Management — add user or a group](https://docs.aws.amazon.com/solutions/latest/spatial-data-management-on-aws/images/add-user-to-project.png)
