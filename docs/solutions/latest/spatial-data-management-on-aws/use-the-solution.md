# Use the solution
<a name="use-the-solution"></a>

This section provides guidance on using the Spatial Data Management on AWS solution for managing spatial assets.

## Prerequisites
<a name="prerequisites"></a>

Before you can use the Spatial Data Management on AWS solution, ensure you have completed the following:
+ Successfully deployed the solution in your AWS account (see [Deploy the solution](deploy-the-solution.md))
+ Received your Amazon Cognito user credentials from your IT Administrator
+ Obtained the portal URL from your IT Administrator or AWS CloudFormation outputs
+ Completed client setup for your preferred access method (see [Client setup](client-setup.md)):
  + Web portal (browser-based, no installation required)
  + Desktop application (recommended for routine or large-scale data operations)
  + CLI (for automation and scripting)
+ Been assigned appropriate permissions by an administrator (Owner, Manager, Contributor, or Viewer role on at least one library or project)
