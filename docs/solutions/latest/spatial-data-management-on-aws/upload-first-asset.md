# Upload your first asset
<a name="upload-first-asset"></a>

This section walks you through creating your first project and uploading your first spatial asset to Spatial Data Management on AWS.

You will learn how to:
+ Create a project to organize your spatial assets
+ Upload files and create assets
+ Add and manage metadata
+ Preview files and review auto-extracted attributes
+ Verify and approve assets
+ Search for assets
+ Manage project access and permissions
