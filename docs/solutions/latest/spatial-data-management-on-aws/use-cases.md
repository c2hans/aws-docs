# Use cases
<a name="use-cases"></a>

## Manufacturing and Industrial
<a name="manufacturing-and-industrial"></a>

In manufacturing environments, the solution helps teams manage factory floor scans, equipment inspection models, and as-built documentation. Quality assurance teams can track equipment models over time, while maintenance teams can quickly locate relevant documentation.

## Infrastructure and Construction
<a name="infrastructure-and-construction"></a>

Construction projects benefit from centralized management of site surveys, Building Information Modeling (BIM) models, and progress tracking data. Project managers can monitor construction progress through temporal point cloud comparisons, while engineers can access detailed design models.

## Energy and Utilities
<a name="energy-and-utilities"></a>

Utility companies use the solution to organize pipeline surveys, facility maintenance records, and asset inspection data. Field teams can access up-to-date infrastructure models, while compliance teams can track inspection history.

## Geospatial and Mapping
<a name="geospatial-and-mapping"></a>

Mapping organizations leverage the solution to manage LiDAR data collections, photogrammetry projects, and survey datasets. Analysts can discover relevant datasets through geospatial and metadata-based search, while processing teams can automate data transformations.

## Media and Entertainment
<a name="media-and-entertainment"></a>

Media production teams leverage the solution to manage 3D character models, motion capture data, virtual environments, and VFX elements throughout production and post-production. Centralized asset libraries enable version control, remove data duplication, and provide access control.

## Game Development
<a name="game-development"></a>

Game development studios use the solution to track character models, environment assets, animations, and physics data across development iterations and platform variations. Manage asset dependencies, level-of-detail versions, and DLC updates while maintaining complete version history from development through deployment.
