# Notification center
<a name="notification-center"></a>

Notification center is a feature of Spatial Data Management on AWS (SDMA). It is built on the connector framework, and it alerts you when lifecycle events occur on spatial assets, so you learn about important changes without checking the portal. Examples include assets created, files uploaded, metadata that signals a problem, and other events you define. You configure notification rules that specify who to notify, through which channel, and on which events. Team members receive alerts in the Spatial Data Portal, in Slack, or by email without any per-user setup.

Notification rules use the same connector framework as all other integrations in SDMA: the same lifecycle triggers, template associations, failure policies, and invocation tracking. No separate notification infrastructure is required.
