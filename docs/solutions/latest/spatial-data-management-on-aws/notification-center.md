# Notification center
<a name="notification-center"></a>

The notification center alerts your team when lifecycle events occur on spatial assets — assets created, files uploaded, processing failures, state transitions, and other events you define. Administrators configure notification rules that specify who to notify, through which channel, and on which events. Team members receive alerts in the Spatial Data Portal, in Slack, or by email without any per-user setup.

Notification rules use the same connector framework as all other integrations in SDMA: the same lifecycle triggers, template associations, failure policies, and invocation tracking. No separate notification infrastructure is required.
