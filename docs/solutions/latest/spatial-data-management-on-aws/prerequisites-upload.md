# Prerequisites
<a name="prerequisites-upload"></a>

Before you begin, ensure you have:
+ Completed the solution deployment
+ Set up a Library Owner user (see [Use the solution](use-the-solution.md))
+ Installed the desktop application (see [Client setup](client-setup.md))
+ A spatial data file ready to upload (for example, point cloud, 3D model, or geospatial imagery)

**Note**
This tutorial uses the desktop application, which is recommended for routine data operations. For quick, convenient one-off tasks, you can also create assets and upload files from the web portal.
