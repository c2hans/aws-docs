# Create Your First Project
<a name="create-first-project"></a>

Projects organize related assets within the library. Create a project before uploading assets.

1. Launch the Spatial Data Management desktop application

1. Sign in with your Library Owner or Contributor credentials

1. From the navigation menu, choose **Projects**

1. Choose **Create Project**

1. Enter the project details:
   +  **Name** – Enter a descriptive name (for example, `Site Survey 2025`)
   +  **Description** – Provide context about the project purpose
   +  **Geolocation** – Add geographic coordinates to enable map-based discovery. You can enter coordinates manually, select a location on the map, or import from a file

1. Choose **Create project**

Your project is now ready to receive assets.
