# Developer guide
<a name="developer-guide"></a>

This section provides the source code for the guidance.

## Source code
<a name="source-code"></a>

Visit our [GitHub repository](https://github.com/aws-solutions/scalable-analytics-using-apache-druid-on-aws) to download the source files for this guidance and to share your customizations with others.

The Scalable Analytics using Apache Druid on AWS templates are generated using the [AWS Cloud Development Kit (AWS CDK)](https://aws.amazon.com/cdk/). Refer to the [README.md](https://github.com/aws-solutions/scalable-analytics-using-apache-druid-on-aws/blob/main/README.md) file for additional information.

## CDK deployment
<a name="cdk-deployment"></a>

For configuring advanced settings or customizing the guidance, it is recommended to download the source code from the [GitHub source repository](https://github.com/aws-solutions/scalable-analytics-using-apache-druid-on-aws) and build and deploy with AWS CDK. For more information, refer to the [README.md](https://github.com/aws-solutions/scalable-analytics-using-apache-druid-on-aws/blob/main/README.md) file.
