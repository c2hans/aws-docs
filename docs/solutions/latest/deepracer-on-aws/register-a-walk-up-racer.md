# Register a walk-up racer
<a name="register-a-walk-up-racer"></a>

Registration managers, race facilitators, and admins can create accounts for walk-up participants. To do this, choose **Register racer**, then enter the participant’s email address. You can add an optional two-letter country code. Choose **Register racer**.

![Register walk-up racer form with email and optional country-code fields](https://docs.aws.amazon.com/solutions/latest/deepracer-on-aws/images/deepracer_register_racer.png)

The solution creates a racer account and sends a temporary password to that email address. The participant can then sign in as a racer. If you provide a country code, the solution displays it on leaderboards.
