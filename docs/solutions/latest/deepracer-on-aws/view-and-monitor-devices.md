# View and monitor devices
<a name="view-and-monitor-devices"></a>

The device list shows all registered cars and timers. For each device, you can see the name, device type, online or offline status, assigned fleet, and last-seen time.

![The device list showing registered cars and timers with status and fleet](https://docs.aws.amazon.com/solutions/latest/deepracer-on-aws/images/device-management/device-management-list-devices-view.png)

You can filter the list by status (online or offline) and by device type (car or timer). You can also sort the table. Status updates appear in near real time.

**Note**
The online or offline status of an idle device can lag by up to about 5 minutes. The results of remote commands are reported promptly. For more information, see [Control a device remotely](control-a-device-remotely.md).
