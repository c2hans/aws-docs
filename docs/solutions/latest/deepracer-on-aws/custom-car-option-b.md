# Option B: Build from scratch
<a name="custom-car-option-b"></a>

To build an AWS DeepRacer compatible vehicle from scratch using a 1/18-scale RC truck chassis and 3D-printed components, follow the step-by-step guide, [Building a Modern AWS DeepRacer Replacement Using Off-the-Shelf Components](https://builder.aws.com/content/3CzhcPjj9cJE37Ft4j8JUWX5A5U/building-a-modern-aws-deepracer-replacement-using-off-the-shelf-components-part-1), on the AWS Builder Center website. The guide covers chassis preparation, 3D printing, compute stack assembly, wiring, power, and camera installation. After the hardware build is complete, proceed to [Install the software](custom-car-software.md).
