# Commentator view
<a name="commentator-view"></a>

Before you begin, confirm that an event and track are set up. **Commentator view** provides read-only, real-time data for a physical race. From the navigation pane, choose **Commentator view**. Select an **Event** and a **Track**, then choose **Subscribe**.

After you subscribe, the page shows the connection status, active-race statistics, current race laps, and the live leaderboard for the selected track.

![Commentator view showing the leaderboard at the top right and active racer statistics at the bottom left](https://docs.aws.amazon.com/solutions/latest/deepracer-on-aws/images/deepracer_commentator_view.png)

**Note**
 **Commentator view** is read-only. Commentators cannot start or stop runs, record laps, or change event results.
