# Parts list
<a name="custom-car-parts-list"></a>

The following table lists all components required for Option A (upgrading an existing AWS DeepRacer Evo). For information about building a vehicle from scratch, see [Option B](custom-car-option-b.md).

## Option A parts
<a name="option-a-parts"></a>

The following components are required to complete the Option A upgrade.
+ Raspberry Pi 5 (4GB)
+ Raspberry Pi Active Cooler
+ Waveshare PCA9685 Servo Driver HAT (16 channel)
+ GPIO Header Riser / Extender
+ M2.5 Nylon Standoff Hardware Kit
+ M2 Nylon Standoff Hardware Kit (for 3D-printed chassis assembly)
+ Raspberry Pi Camera Module 2
+ Raspberry Pi Camera Extension Cable (200mm)
+ Micro SD Card 128 GB
+ Zeee 2S 8000mAh Lipo Battery 7.4V
+ Right-Angle USB-C Cable 6"
+ Access to a 3D printer (or 3D printing service)

The following 3D-printed components are required. Print files are available in the [AWS DeepRacer Community custom car repository](https://github.com/aws-deepracer-community/deepracer-custom-car) on the GitHub website.
+ PiMount Front (front camera mount)
+ PiMount Plate with legs (main plate for DeepRacer chassis)
+ PiMount Back (rear mount)
+ Body mounts (×2)
