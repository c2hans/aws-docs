# Events
<a name="events"></a>

An **event** is a physical racing occasion, such as a workshop, a summit activation, a community meetup, or a track race. At an event, participants run real vehicles on a real track, and a race facilitator records their lap times. An event holds everything about that occasion: the scoring rules, the tracks it runs on, the runs each racer completes, and the leaderboards those runs produce.

**Note**
Admins and race facilitators can view events and operate timekeeping. Only admins can create, edit, delete, or advance an event, and only admins can correct a recorded lap time. Racers can view events and their own results. For the complete breakdown, see [Permissions matrix](types-of-users.md#permissions-matrix).
