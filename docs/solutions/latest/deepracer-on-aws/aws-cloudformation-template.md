# AWS CloudFormation template
<a name="aws-cloudformation-template"></a>

This solution includes an AWS CloudFormation template that you can download before deploying the solution.

 [deepracer-on-aws.template](https://solutions-reference.s3.amazonaws.com/deepracer-on-aws/latest/deepracer-on-aws.template): Use this template to launch the solution and all associated components. The default configuration deploys AWS Lambda functions, Amazon API Gateway, Amazon Cognito, Amazon DynamoDB, Amazon SageMaker AI, Amazon S3 buckets, Amazon CloudFront, AWS Step Functions, Amazon CloudWatch, Amazon Elastic Container Registry, and AWS Systems Manager, but you can also customize the template based on your specific needs.
