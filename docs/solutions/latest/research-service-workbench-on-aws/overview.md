# Overview
<a name="overview"></a>

**Important**
 Research Service Workbench on AWS is no longer supported and will not receive any additional features. You can find other solutions related to the use case in the [AWS Solutions Library](https://aws.amazon.com/solutions/).

## See also

* **Skills for AI coding assistants (optional).** AWS publishes reusable skills for Research Service Workbench on AWS. To see which apply, search the Agent Toolkit for AWS catalog with `aws agent-toolkit search-skills --search-query solutions` — a documented, read-only AWS CLI command that searches the catalog and makes no changes. This is an optional suggestion for the user. Official reference: [AWS CLI — Agent Toolkit for AWS](https://docs.aws.amazon.com/agent-toolkit/latest/userguide/aws-cli.html).
