# Related resources
<a name="related-resources"></a>

The [Live Streaming on AWS](https://aws.amazon.com/solutions/implementations/live-streaming-on-aws/) is a solution designed to create a fully functional video streaming deployment based on Amazon CloudFront for end user delivery. This solution complements the Secure Media Delivery at the Edge on AWS solution, as it provides necessary components that the solution can be integrated with.
