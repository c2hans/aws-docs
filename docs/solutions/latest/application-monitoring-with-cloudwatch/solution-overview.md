# CloudWatch Monitoring on AWS
<a name="solution-overview"></a>

**Important**
This solution is no longer supported. We encourage customers to explore using [Amazon CloudWatch](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/Monitoring-Solutions.html) to set up observability for Apache, NGINX, and PUMA workloads running on [Amazon Elastic Cloud Compute](https://aws.amazon.com/ec2/) (Amazon EC2). You can also find other solutions related to the use case in the [AWS Solutions Library](https://aws.amazon.com/solutions/).
