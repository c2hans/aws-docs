# Update using AWS Launch Wizard
<a name="update-using-aws-launch-wizard"></a>

The console automatically displays the newest available version of the solution in the **Deployment version** dropdown. If you have previously deployed the solution, follow this procedure to update your deployment to the latest version.

1. Go to [Launch Wizard Deployments](https://console.aws.amazon.com/launchwizard/home#/deployment/list).

1. Select the deployment you want to update.

1. Choose **Actions**, then **Update deployment version**.

1. Select the latest version from the available **Deployment versions**.

1. Review configuration.

1. Make changes needed on each step.

1. Confirm the update.
