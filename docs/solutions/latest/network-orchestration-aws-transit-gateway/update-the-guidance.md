# Update the Guidance
<a name="update-the-guidance"></a>

If you have previously deployed the Guidance, follow these procedures to update the stacks to get the latest version of the framework.

**Important**
To successfully update the hub stack from an earlier version of this Guidance to version 3.3.0 or later, provide input for the two required parameters for the hub stack: **Cognito Domain Prefix** and **Allow Listed Ranges**.
