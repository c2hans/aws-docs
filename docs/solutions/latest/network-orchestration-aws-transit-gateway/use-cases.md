# Use cases
<a name="use-cases"></a>

 **Network connectivity**

To meet your workloads' requirements, you can attach VPCs with Transit Gateway by tagging the VPCs and subnets across multiple accounts. Based on the VPC and subnet tags, it automatically updates the subnet’s associated route table with default routes to the transit gateway. It also creates association and enables propagation in the transit gateway route tables.

To connect your network across AWS Regions, you can create inter-Region transit gateway peering attachments.
