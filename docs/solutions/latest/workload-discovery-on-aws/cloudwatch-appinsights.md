# CloudWatch AppInsights
<a name="cloudwatch-appinsights"></a>

CloudWatch Application Insights helps you monitor your applications by identifying and setting up key metrics, logs, and alarms across your [application resources](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/appinsights-what-is.html#appinsights-components) and technology stack.It continuously monitors metrics and logs to detect and correlate anomalies and errors. To assist with troubleshooting, it creates automated dashboards for detected problems, which include correlated metric anomalies and log errors, along with additional insights to point you to a potential root cause.

To view the CloudWatch AppInsights dashboard for Workload Discovery on AWS:

1. Sign in to the [CloudWatch console](https://us-east-1.console.aws.amazon.com/cloudwatch/home).

1. In the left sidebar, choose **Insights, Application Insights**.

1. Select the **Applications** tab.

1. Type `workload-discovery` into searchbar to find the dashboard.

1. Select the dashboard.

1. Select the application.
