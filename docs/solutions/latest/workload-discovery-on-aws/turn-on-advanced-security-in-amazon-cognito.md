# Turn on advanced security in Amazon Cognito
<a name="turn-on-advanced-security-in-amazon-cognito"></a>

To turn on the advanced security features for Amazon Cognito, follow the instructions on [Adding advanced security to a user pool](https://docs.aws.amazon.com/cognito/latest/developerguide/cognito-user-pool-settings-advanced-security.html) in the *Amazon Cognito Developer Guide*.

**Note**
There is an additional cost for activating advanced security in Amazon Cognito.
