# Monitoring the solution
<a name="monitoring-the-solution"></a>

This solution uses [myApplications](https://docs.aws.amazon.com/awsconsolehelpdocs/latest/gsg/aws-myApplications.html) and [CloudWatch AppInsights](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/appinsights-what-is.html) to allow you to monitor your Workload Discovery on AWS deployment.
