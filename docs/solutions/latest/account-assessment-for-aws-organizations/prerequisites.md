# Prerequisites
<a name="prerequisites"></a>

When your accounts are part of AWS Organizations, you must manually activate AWS RAM in the Organizations console and obtain the AWS Organizations management account ID and organization ID before deploying the Account Assessment for AWS Organizations templates.

## Activate AWS RAM for AWS Organizations accounts
<a name="activate-aws-ram-for-aws-organizations-accounts"></a>

Follow the instructions to [Enable resource sharing within AWS Organizations](https://docs.aws.amazon.com/ram/latest/userguide/getting-started-sharing.html#getting-started-sharing-orgs) in the *AWS Organizations Resource access Manager User Guide.*
