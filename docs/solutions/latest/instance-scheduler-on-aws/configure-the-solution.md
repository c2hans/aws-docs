# Configure the solution
<a name="configure-the-solution"></a>

Now that the solution has been deployed, you can begin configuring schedules and tagging instances for scheduler. To learn more about how to do these things, refer to [Configure schedules](operator-guide.md#configure-schedules) and [Tag instances for scheduling](operator-guide.md#tag-instances-for-scheduling).
