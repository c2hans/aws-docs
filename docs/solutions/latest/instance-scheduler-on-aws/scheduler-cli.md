# Scheduler CLI
<a name="scheduler-cli"></a>

The solution includes a CLI that provides commands for configuring schedules and periods. The CLI allows you to estimate cost savings for a given schedule. The cost estimates provided by the schedule CLI are for approximation purposes only. For more information about configuring and using the scheduler CLI, refer to [Scheduler CLI](scheduler-cli-4.md).
