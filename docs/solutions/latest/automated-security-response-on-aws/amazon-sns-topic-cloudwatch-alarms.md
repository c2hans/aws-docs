# Amazon SNS topic - CloudWatch Alarms
<a name="amazon-sns-topic-cloudwatch-alarms"></a>

This solution creates an Amazon SNS topic, `SO0111-ASR_Alarm_Topic`. This topic is used to post alarm alerts.

Details of any Alarms that enter the ALARM state will be sent to this topic.
