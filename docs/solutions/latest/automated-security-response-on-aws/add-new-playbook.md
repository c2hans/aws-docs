# Adding a new playbook
<a name="add-new-playbook"></a>

Download the Automated Security Response on AWS solution playbooks and deployment source code from the [GitHub repository](https://github.com/aws-solutions/automated-security-response-on-aws/tree/main).

The AWS CloudFormation resources are created from [AWS CDK](https://aws.amazon.com/cdk/) components, and the resources contain the playbook template code that you can use to create and configure new playbooks. For more information about setting up your project and customizing your playbooks, refer to the [README.md](https://github.com/aws-solutions/automated-security-response-on-aws/blob/main/README.md#custom-playbooks) file in GitHub.
