# Subscribe to the SNS topic
<a name="subscribe-to-sns-topic"></a>

 **Remediation Updates**

 **Topic -**{https---us-east-1-console-aws-amazon-com-sns-v3-home-region-us-east-1—​topic-arn-aws-sns-us-east-1-221128147805-SO0111-ASR-Topic}[SO0111-ASR\_Topic]

In the admin account, subscribe to the Amazon SNS topic created by the admin stack. This will notify you when remediations are initiated and when the succeed or fail.

 **Alarms**

 **Topic -**{https---us-east-1-console-aws-amazon-com-sns-v3-home-region-us-east-1—​topic-arn-aws-sns-us-east-1-221128147805-SO0111-ASR-Alarm-Topic}[SO0111-ASR\_Alarm\_Topic]

In the admin account, subscribe to the Amazon SNS topic created by the admin stack. This will notify you when metric alarms initiate.
