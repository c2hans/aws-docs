# Subscribing to Alarm notifications
<a name="subscribing-to-alarm-notifications"></a>

In the admin account, subscribe to the Amazon SNS topic created by the admin stack, SO0111-ASR\_Alarm\_Topic. This will notify you when an alarm enters the ALARM state.
