# DeleteVectorIndexAction
<a name="API_DeleteVectorIndexAction"></a>

A vector index to be removed from a table.

## Contents
<a name="API_DeleteVectorIndexAction_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** IndexName **   <a name="DDB-Type-DeleteVectorIndexAction-IndexName"></a>
The name of the vector index to delete.
Type: String
Length Constraints: Minimum length of 3. Maximum length of 255.
Pattern: `[a-zA-Z0-9_.-]+`
Required: Yes
