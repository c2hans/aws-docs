# BulkOperationBytes
<a name="API_BulkOperationBytes"></a>

Contains the bulk put bytes used during a bulk operation.

## Contents
<a name="API_BulkOperationBytes_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BulkPutBytes **   <a name="DDB-Type-BulkOperationBytes-BulkPutBytes"></a>
The number of bulk put bytes.
Type: Long
Valid Range: Minimum value of 0.
Required: No
