# VectorAttributeDefinition
<a name="API_VectorAttributeDefinition"></a>

The definition of a vector attribute for a vector index.

## Contents
<a name="API_VectorAttributeDefinition_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** AttributeName **   <a name="DDB-Type-VectorAttributeDefinition-AttributeName"></a>
The name of the vector attribute.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: Yes
