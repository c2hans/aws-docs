# BulkOperationVectorBytes
<a name="API_BulkOperationVectorBytes"></a>

Contains the bulk put vector bytes used by a vector index during a bulk operation.

## Contents
<a name="API_BulkOperationVectorBytes_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** BulkPutVectorBytes **   <a name="DDB-Type-BulkOperationVectorBytes-BulkPutVectorBytes"></a>
The number of bulk put vector bytes used on the vector index.
Type: Long
Valid Range: Minimum value of 0.
Required: No
