# View existing qualification types
<a name="ViewingExistingQualificationTypes"></a>

The following procedure shows you how to view the qualification types you create.

**To view qualification types**

1. On the Mechanical Turk Requester website at [https://requester.mturk.com/](https://requester.mturk.com/), choose the **Manage** tab and then choose **Qualification Types**.

1. On the **Qualification Types** page, the table shows you all of your qualification types.
