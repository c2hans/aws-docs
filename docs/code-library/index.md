# AWS SDK Code Examples

AWS SDK Code Examples show you how to use AWS SDKs to build AWS applications in your preferred language. The code example library is a collection of code examples that are organized by service and by SDK. Code and instructions are hosted in a GitHub repository, where you can get everything you need to set up and run the examples.

- [AWS Developer Center Code Examples page](https://aws.amazon.com/developer/code-examples/): A searchable curated collection of code examples that show you how to use AWS SDKs with AWS. Search examples by service, programming language, and example and technology categories.
- [/code-library/latest/ug/](/code-library/latest/ug/)
- [Code Repository](https://github.com/awsdocs/aws-doc-sdk-examples): A GitHub repository that contains the code examples from the Code Library. The repository also contains instructions and setup scripts to help you deploy AWS resources, install prerequisites, and run the examples.
