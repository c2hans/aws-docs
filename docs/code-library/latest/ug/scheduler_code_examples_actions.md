# Actions for EventBridge Scheduler using AWS SDKs
<a name="scheduler_code_examples_actions"></a>

The following code examples demonstrate how to perform individual EventBridge Scheduler actions with AWS SDKs. Each example includes a link to GitHub, where you can find instructions for setting up and running the code.

These excerpts call the EventBridge Scheduler API and are code excerpts from larger programs that must be run in context. You can see actions in context in [Scenarios for EventBridge Scheduler using AWS SDKs](scheduler_code_examples_scenarios.md).

 The following examples include only the most commonly used actions. For a complete list, see the [Amazon EventBridge Scheduler API Reference](https://docs.aws.amazon.com/scheduler/latest/apireference/Welcome.html).
