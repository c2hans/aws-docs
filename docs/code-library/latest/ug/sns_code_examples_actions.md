# Actions for Amazon SNS using AWS SDKs
<a name="sns_code_examples_actions"></a>

The following code examples demonstrate how to perform individual Amazon SNS actions with AWS SDKs. Each example includes a link to GitHub, where you can find instructions for setting up and running the code.

These excerpts call the Amazon SNS API and are code excerpts from larger programs that must be run in context. You can see actions in context in [Scenarios for Amazon SNS using AWS SDKs](sns_code_examples_scenarios.md).
