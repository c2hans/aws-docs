# Scenarios for Systems Manager using AWS SDKs
<a name="ssm_code_examples_scenarios"></a>

The following code examples show you how to implement common scenarios in Systems Manager with AWS SDKs. These scenarios show you how to accomplish specific tasks by calling multiple functions within Systems Manager or combined with other AWS services. Each scenario includes a link to the complete source code, where you can find instructions on how to set up and run the code.

Scenarios target an intermediate level of experience to help you understand service actions in context.
