# Code examples for Amazon Transcribe Streaming using AWS SDKs
<a name="transcribe-streaming_code_examples"></a>

The following code examples show you how to use Amazon Transcribe Streaming with an AWS software development kit (SDK).

*Actions* are code excerpts from larger programs and must be run in context. While actions show you how to call individual service functions, you can see actions in context in their related scenarios.

*Scenarios* are code examples that show you how to accomplish specific tasks by calling multiple functions within a service or combined with other AWS services.
