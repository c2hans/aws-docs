# Actions for Aurora using AWS SDKs
<a name="aurora_code_examples_actions"></a>

The following code examples demonstrate how to perform individual Aurora actions with AWS SDKs. Each example includes a link to GitHub, where you can find instructions for setting up and running the code.

These excerpts call the Aurora API and are code excerpts from larger programs that must be run in context. You can see actions in context in [Scenarios for Aurora using AWS SDKs](aurora_code_examples_scenarios.md).
