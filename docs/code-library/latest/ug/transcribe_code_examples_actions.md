# Actions for Amazon Transcribe using AWS SDKs
<a name="transcribe_code_examples_actions"></a>

The following code examples demonstrate how to perform individual Amazon Transcribe actions with AWS SDKs. Each example includes a link to GitHub, where you can find instructions for setting up and running the code.

These excerpts call the Amazon Transcribe API and are code excerpts from larger programs that must be run in context. You can see actions in context in [Scenarios for Amazon Transcribe using AWS SDKs](transcribe_code_examples_scenarios.md).
