# Code examples for Amazon Bedrock Runtime using AWS SDKs
<a name="bedrock-runtime_code_examples"></a>

The following code examples show you how to use Amazon Bedrock Runtime with an AWS software development kit (SDK).

*Scenarios* are code examples that show you how to accomplish specific tasks by calling multiple functions within a service or combined with other AWS services.
