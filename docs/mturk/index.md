# Amazon Mechanical Turk Documentation

Amazon Mechanical Turk is a web service that provides an on-demand, scalable, human workforce to complete jobs that humans can do better than computers, such as recognizing objects in photographs.

**Amazon Mechanical Turk will permanently close on September 30, 2026.** For Workers and Requesters currently using the service, visit our [Amazon Mechanical Turk help page](https://www.mturk.com/help) to learn how you can prepare for this closure.

- [Developer Getting Started Guide](/AWSMechTurk/latest/AWSMechanicalTurkGettingStartedGuide/): Introduces you to Amazon Mechanical Turk key concepts and walks you through a simple example to use the Mechanical Turk API for the first time. Also provides tips and links to advanced product features and resources.
- [Requester User Interface](/AWSMechTurk/latest/RequesterUI/): Shows how to access Amazon Mechanical Turk functionality using a graphical user interface.
- [Developer Guide](/AWSMechTurk/latest/AWSMechanicalTurkRequester/): Provides a conceptual overview of Amazon Mechanical Turk and includes detailed development instructions for using the various features.
- [API Reference](/AWSMechTurk/latest/AWSMturkAPI/): Describes all the API operations for Amazon Mechanical Turk in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
