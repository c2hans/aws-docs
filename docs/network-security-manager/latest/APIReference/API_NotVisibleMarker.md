# NotVisibleMarker
<a name="API_NotVisibleMarker"></a>

Indicates that details are not visible because of cross-account restrictions.

## Contents
<a name="API_NotVisibleMarker_Contents"></a>

 ** reason **   <a name="networksecuritymanager-Type-NotVisibleMarker-reason"></a>
The reason the details are not visible.
Type: String
Required: Yes
