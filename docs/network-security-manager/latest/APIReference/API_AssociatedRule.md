# AssociatedRule
<a name="API_AssociatedRule"></a>

An association between a template and a rule, as returned in outputs. The corresponding request structure is `RuleReference`.

## Contents
<a name="API_AssociatedRule_Contents"></a>

 ** ruleArn **   <a name="networksecuritymanager-Type-AssociatedRule-ruleArn"></a>
The ARN of the associated rule.
Type: String
Length Constraints: Minimum length of 20. Maximum length of 1010.
Pattern: `arn(:[a-z0-9]+([.-][a-z0-9]+)*){2}(:([a-z0-9]+([.-][a-z0-9]+)*)?){2}:(.+)`
Required: Yes
