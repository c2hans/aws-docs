# ScopeReference
<a name="API_ScopeReference"></a>

A reference to a scope in a create or update request.

## Contents
<a name="API_ScopeReference_Contents"></a>

 ** scopeIdentifier **   <a name="networksecuritymanager-Type-ScopeReference-scopeIdentifier"></a>
The identifier of the scope. This is the scope's Amazon Resource Name (ARN).
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1010.
Required: Yes
