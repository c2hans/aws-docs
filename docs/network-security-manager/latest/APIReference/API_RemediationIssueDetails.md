# RemediationIssueDetails
<a name="API_RemediationIssueDetails"></a>

Details about a remediation issue for a firewall type.

## Contents
<a name="API_RemediationIssueDetails_Contents"></a>

 ** correctiveAction **   <a name="networksecuritymanager-Type-RemediationIssueDetails-correctiveAction"></a>
A recommended action for resolving the remediation issue.
Type: String
Required: No

 ** issueType **   <a name="networksecuritymanager-Type-RemediationIssueDetails-issueType"></a>
The type of remediation issue.
Type: String
Required: No

 ** message **   <a name="networksecuritymanager-Type-RemediationIssueDetails-message"></a>
A human-readable description of the remediation issue.
Type: String
Required: No
