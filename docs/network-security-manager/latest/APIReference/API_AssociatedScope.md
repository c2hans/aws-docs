# AssociatedScope
<a name="API_AssociatedScope"></a>

An association between a deployment and a scope, as returned in outputs. The corresponding request structure is `ScopeReference`.

## Contents
<a name="API_AssociatedScope_Contents"></a>

 ** scopeArn **   <a name="networksecuritymanager-Type-AssociatedScope-scopeArn"></a>
The ARN of the associated scope.
Type: String
Length Constraints: Minimum length of 20. Maximum length of 1010.
Pattern: `arn(:[a-z0-9]+([.-][a-z0-9]+)*){2}(:([a-z0-9]+([.-][a-z0-9]+)*)?){2}:(.+)`
Required: Yes
