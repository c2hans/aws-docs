# DeploymentConfiguration
<a name="API_DeploymentConfiguration"></a>

Configuration settings that control a deployment's behavior.

## Contents
<a name="API_DeploymentConfiguration_Contents"></a>

 ** enableCrossAccountVisibility **   <a name="networksecuritymanager-Type-DeploymentConfiguration-enableCrossAccountVisibility"></a>
Specifies whether aggregate synchronization status details for the resources covered by this deployment are visible across accounts. Default: `false`.
Type: Boolean
Required: Yes
