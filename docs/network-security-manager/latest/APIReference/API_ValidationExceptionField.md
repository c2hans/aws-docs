# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

Describes a single request field that failed validation.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="networksecuritymanager-Type-ValidationExceptionField-message"></a>
A message describing the validation error for the field.
Type: String
Required: Yes

 ** name **   <a name="networksecuritymanager-Type-ValidationExceptionField-name"></a>
The name of the field that failed validation.
Type: String
Required: Yes
