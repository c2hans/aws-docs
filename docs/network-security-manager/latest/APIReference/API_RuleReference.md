# RuleReference
<a name="API_RuleReference"></a>

A reference to a rule in a create or update request.

## Contents
<a name="API_RuleReference_Contents"></a>

 ** ruleIdentifier **   <a name="networksecuritymanager-Type-RuleReference-ruleIdentifier"></a>
The identifier of the rule. This is the rule's Amazon Resource Name (ARN).
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1010.
Required: Yes
