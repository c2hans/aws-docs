# CallerIdentity

The identity of a caller.

## Contents
<a name="API_marketplace-agreements_CallerIdentity_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** principalArn **   <a name="AWSMarketplaceService-Type-marketplace-agreements_CallerIdentity-principalArn"></a>
The ARN of the IAM principal that made the call.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Pattern: `arn:[^:]+:[^:]+:[^:]*:[^:]*:.+`
Required: Yes
