# ContainerOperatingSystem
<a name="API_marketplace-discovery_ContainerOperatingSystem"></a>

Describes an operating system supported by a container fulfillment option.

## Contents
<a name="API_marketplace-discovery_ContainerOperatingSystem_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** operatingSystemFamilyName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_ContainerOperatingSystem-operatingSystemFamilyName"></a>
The operating system family, such as Linux.
Type: String
Required: Yes

 ** operatingSystemName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_ContainerOperatingSystem-operatingSystemName"></a>
The specific operating system name.
Type: String
Required: Yes
