# Category
<a name="API_marketplace-discovery_Category"></a>

A category used to classify a listing or product into a logical group.

## Contents
<a name="API_marketplace-discovery_Category_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** categoryId **   <a name="AWSMarketplaceService-Type-marketplace-discovery_Category-categoryId"></a>
The machine-readable identifier of the category.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `.*\S.*`
Required: Yes

 ** displayName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_Category-displayName"></a>
The human-readable name of the category.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `.*\S.*`
Required: Yes
