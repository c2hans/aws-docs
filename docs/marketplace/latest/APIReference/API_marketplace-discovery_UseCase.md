# UseCase
<a name="API_marketplace-discovery_UseCase"></a>

A use case describing a scenario where the product can be applied.

## Contents
<a name="API_marketplace-discovery_UseCase_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** description **   <a name="AWSMarketplaceService-Type-marketplace-discovery_UseCase-description"></a>
A description of the use case.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `.*\S.*`
Required: Yes

 ** displayName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_UseCase-displayName"></a>
The human-readable name of the use case.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `.*\S.*`
Required: Yes

 ** value **   <a name="AWSMarketplaceService-Type-marketplace-discovery_UseCase-value"></a>
The machine-readable identifier of the use case.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `.*\S.*`
Required: Yes
