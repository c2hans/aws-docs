# ExpressPrivateOfferConfigurationStateFilter

The filter for the `State` of an express private offer configuration.

## Contents
<a name="API_ExpressPrivateOfferConfigurationStateFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-ExpressPrivateOfferConfigurationStateFilter-ValueList"></a>
A list of `State` values to filter on. Valid values are `ACTIVE` and `INACTIVE`.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Valid Values: `ACTIVE | INACTIVE`
Required: No
