# AmiProductLastModifiedDateFilter
<a name="API_AmiProductLastModifiedDateFilter"></a>

Object that allows filtering based on the last modified date of AMI products.

## Contents
<a name="API_AmiProductLastModifiedDateFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DateRange **   <a name="AWSMarketplaceService-Type-AmiProductLastModifiedDateFilter-DateRange"></a>
Dates between which the AMI product was last modified.
Type: [AmiProductLastModifiedDateFilterDateRange](API_AmiProductLastModifiedDateFilterDateRange.md) object
Required: No
