# MachineLearningProductLastModifiedDateFilter
<a name="API_MachineLearningProductLastModifiedDateFilter"></a>

The filter for machine learning product last modified date.

## Contents
<a name="API_MachineLearningProductLastModifiedDateFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DateRange **   <a name="AWSMarketplaceService-Type-MachineLearningProductLastModifiedDateFilter-DateRange"></a>
A date range to filter by. The operation returns machine learning products with last modified dates that fall within this range.
Type: [MachineLearningProductLastModifiedDateFilterDateRange](API_MachineLearningProductLastModifiedDateFilterDateRange.md) object
Required: No
