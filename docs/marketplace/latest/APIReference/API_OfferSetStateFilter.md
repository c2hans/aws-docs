# OfferSetStateFilter
<a name="API_OfferSetStateFilter"></a>

Allows filtering on the `State` of an offer set.

## Contents
<a name="API_OfferSetStateFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-OfferSetStateFilter-ValueList"></a>
Allows filtering on the `State` of an offer set with list input.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 2 items.
Valid Values: `Draft | Released`
Required: No
