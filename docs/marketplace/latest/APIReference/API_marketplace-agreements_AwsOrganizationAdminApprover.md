# AwsOrganizationAdminApprover

An approver that represents the administrators of the buyer's AWS organization. The management account or a delegated administrator of the organization can decide for this approver.

## Contents
<a name="API_marketplace-agreements_AwsOrganizationAdminApprover_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** organizationId **   <a name="AWSMarketplaceService-Type-marketplace-agreements_AwsOrganizationAdminApprover-organizationId"></a>
The ID of the AWS organization.
Type: String
Length Constraints: Minimum length of 12. Maximum length of 34.
Pattern: `o-[a-z0-9]{10,32}`
Required: Yes
