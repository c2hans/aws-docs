# UseCaseSummary

The use cases of a listing, in summary form.

## Contents
<a name="API_marketplace-discovery_UseCaseSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** useCases **   <a name="AWSMarketplaceService-Type-marketplace-discovery_UseCaseSummary-useCases"></a>
The use cases, in the order the seller defined them.
Type: Array of [UseCaseSummaryEntry](API_marketplace-discovery_UseCaseSummaryEntry.md) objects
Array Members: Minimum number of 0 items. Maximum number of 3 items.
Required: Yes
