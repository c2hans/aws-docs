# EngagementDates

Key implementation dates for a case study.

## Contents
<a name="API_marketplace-discovery_EngagementDates_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** startDate **   <a name="AWSMarketplaceService-Type-marketplace-discovery_EngagementDates-startDate"></a>
The implementation start date.
Type: Timestamp
Required: Yes

 ** completionDate **   <a name="AWSMarketplaceService-Type-marketplace-discovery_EngagementDates-completionDate"></a>
The implementation completion date. The service omits this field for an engagement in progress.
Type: Timestamp
Required: No
