# ResaleAuthorizationEntityIdFilter
<a name="API_ResaleAuthorizationEntityIdFilter"></a>

Allows filtering on `EntityId` of a ResaleAuthorization.

## Contents
<a name="API_ResaleAuthorizationEntityIdFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-ResaleAuthorizationEntityIdFilter-ValueList"></a>
Allows filtering on `EntityId` of a ResaleAuthorization with list input.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^[a-zA-Z0-9][.a-zA-Z0-9/-]+[a-zA-Z0-9]$`
Required: No
