# OfferTargetingFilter
<a name="API_OfferTargetingFilter"></a>

Allows filtering on the `Targeting` of an offer.

## Contents
<a name="API_OfferTargetingFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-OfferTargetingFilter-ValueList"></a>
Allows filtering on the `Targeting` of an offer with list input.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 4 items.
Valid Values: `BuyerAccounts | ParticipatingPrograms | CountryCodes | None`
Required: No
