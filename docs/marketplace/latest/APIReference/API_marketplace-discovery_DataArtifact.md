# DataArtifact
<a name="API_marketplace-discovery_DataArtifact"></a>

Describes a data artifact within a Data Exchange fulfillment option.

## Contents
<a name="API_marketplace-discovery_DataArtifact_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** dataClassification **   <a name="AWSMarketplaceService-Type-marketplace-discovery_DataArtifact-dataClassification"></a>
The classification of sensitive data contained in the dataset.
Type: String
Required: Yes

 ** resourceType **   <a name="AWSMarketplaceService-Type-marketplace-discovery_DataArtifact-resourceType"></a>
The type of the data artifact resource.
Type: String
Required: Yes

 ** description **   <a name="AWSMarketplaceService-Type-marketplace-discovery_DataArtifact-description"></a>
A description of the data artifact.
Type: String
Required: No

 ** resourceArn **   <a name="AWSMarketplaceService-Type-marketplace-discovery_DataArtifact-resourceArn"></a>
The Amazon Resource Name (ARN) of the data artifact.
Type: String
Required: No
