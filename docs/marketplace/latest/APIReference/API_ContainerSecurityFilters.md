# ContainerSecurityFilters
<a name="API_ContainerSecurityFilters"></a>

Filters that apply to assessments performed against the Container Security framework.

## Contents
<a name="API_ContainerSecurityFilters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DeliveryOptionId **   <a name="AWSMarketplaceService-Type-ContainerSecurityFilters-DeliveryOptionId"></a>
The unique ID of the delivery option whose Container Security assessments you want to list.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^[\w\-]+$`
Required: No
