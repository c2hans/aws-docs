# CaseStudiesAlternative

A proposed set of case studies for a solution.

## Contents
<a name="API_CaseStudiesAlternative_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Rationale **   <a name="AWSMarketplaceService-Type-CaseStudiesAlternative-Rationale"></a>
Why this set of case studies fits the solution.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1000.
Required: Yes

 ** Value **   <a name="AWSMarketplaceService-Type-CaseStudiesAlternative-Value"></a>
The proposed case studies.
Type: Array of [ListingCaseStudy](API_ListingCaseStudy.md) objects
Array Members: Minimum number of 1 item. Maximum number of 20 items.
Required: Yes
