# SubsidiaryAuthorizationCreatedDateFilter
<a name="API_SubsidiaryAuthorizationCreatedDateFilter"></a>

The filter for the date a subsidiary authorization was created.

## Contents
<a name="API_SubsidiaryAuthorizationCreatedDateFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DateRange **   <a name="AWSMarketplaceService-Type-SubsidiaryAuthorizationCreatedDateFilter-DateRange"></a>
A date range to filter by. The operation returns subsidiary authorizations with creation dates that fall within this range.
Type: [SubsidiaryAuthorizationCreatedDateFilterDateRange](API_SubsidiaryAuthorizationCreatedDateFilterDateRange.md) object
Required: No
