# OfferCreatedBySourceFilter
<a name="API_OfferCreatedBySourceFilter"></a>

Allows filtering on the `CreatedBySource` of an offer.

## Contents
<a name="API_OfferCreatedBySourceFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-OfferCreatedBySourceFilter-ValueList"></a>
Allows filtering on the `CreatedBySource` of an offer with list input.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 2 items.
Valid Values: `Seller | AwsMarketplace`
Required: No
