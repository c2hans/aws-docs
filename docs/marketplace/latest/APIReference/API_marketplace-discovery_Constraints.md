# Constraints
<a name="API_marketplace-discovery_Constraints"></a>

Constraints that control how a buyer can configure a rate card.

## Contents
<a name="API_marketplace-discovery_Constraints_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** multipleDimensionSelection **   <a name="AWSMarketplaceService-Type-marketplace-discovery_Constraints-multipleDimensionSelection"></a>
Whether the buyer can select multiple dimensions. Values are `Allowed` or `Disallowed`.
Type: String
Valid Values: `Allowed | Disallowed`
Required: Yes

 ** quantityConfiguration **   <a name="AWSMarketplaceService-Type-marketplace-discovery_Constraints-quantityConfiguration"></a>
Whether the buyer can configure quantities. Values are `Allowed` or `Disallowed`.
Type: String
Valid Values: `Allowed | Disallowed`
Required: Yes
