# UsageBasedRateCardItem
<a name="API_marketplace-agreements_UsageBasedRateCardItem"></a>

Within the pay-as-you-go model defined under `UsageBasedPricingTerm`, the `UsageBasedRateCardItem` defines an individual rate for a product dimension.

## Contents
<a name="API_marketplace-agreements_UsageBasedRateCardItem_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** rateCard **   <a name="AWSMarketplaceService-Type-marketplace-agreements_UsageBasedRateCardItem-rateCard"></a>
Defines the per unit rates for product dimensions.
Type: Array of [RateCardItem](API_marketplace-agreements_RateCardItem.md) objects
Required: No
