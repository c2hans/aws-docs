# FollowUpQuestion

A question that you can answer to get a better recommendation, and the reason that it's asked.

## Contents
<a name="API_FollowUpQuestion_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Justification **   <a name="AWSMarketplaceService-Type-FollowUpQuestion-Justification"></a>
Why the question is asked.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 5000.
Required: Yes

 ** Question **   <a name="AWSMarketplaceService-Type-FollowUpQuestion-Question"></a>
The question to answer.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: Yes
