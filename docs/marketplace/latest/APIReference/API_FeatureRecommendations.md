# FeatureRecommendations

The feature recommendations for a listing, for a product or a solution.

## Contents
<a name="API_FeatureRecommendations_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Recommendations **   <a name="AWSMarketplaceService-Type-FeatureRecommendations-Recommendations"></a>
The recommended features, in ranked order. The list has at most one entry for each feature and up to 5 entries.
Type: Array of [FeatureRecommendation](API_FeatureRecommendation.md) objects
Array Members: Minimum number of 0 items. Maximum number of 5 items.
Required: Yes
