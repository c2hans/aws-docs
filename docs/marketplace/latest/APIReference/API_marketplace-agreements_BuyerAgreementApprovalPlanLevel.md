# BuyerAgreementApprovalPlanLevel

A level of an approval plan.

## Contents
<a name="API_marketplace-agreements_BuyerAgreementApprovalPlanLevel_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** groups **   <a name="AWSMarketplaceService-Type-marketplace-agreements_BuyerAgreementApprovalPlanLevel-groups"></a>
The group of approvers at this level.
Type: Array of [BuyerAgreementApprovalPlanGroup](API_marketplace-agreements_BuyerAgreementApprovalPlanGroup.md) objects
Array Members: Fixed number of 1 item.
Required: Yes

 ** name **   <a name="AWSMarketplaceService-Type-marketplace-agreements_BuyerAgreementApprovalPlanLevel-name"></a>
The name of the level.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `(.)+`
Required: No
