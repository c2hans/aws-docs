# PurchaseIndicator

An indicator describing a purchase characteristic, such as availability for use without a subscription.

## Contents
<a name="API_marketplace-discovery_PurchaseIndicator_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** indicatorType **   <a name="AWSMarketplaceService-Type-marketplace-discovery_PurchaseIndicator-indicatorType"></a>
The type of purchase indicator.
Type: String
Valid Values: `NOT_AVAILABLE_FOR_SUBSCRIPTION | AVAILABLE_FOR_USE_WITHOUT_SUBSCRIPTION`
Required: Yes
