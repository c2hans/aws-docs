# FixedPercentage
<a name="API_marketplace-discovery_FixedPercentage"></a>

A single fixed price increase percentage applied at each renewal cycle.

## Contents
<a name="API_marketplace-discovery_FixedPercentage_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** percentageValue **   <a name="AWSMarketplaceService-Type-marketplace-discovery_FixedPercentage-percentageValue"></a>
The percentage value applied at each renewal cycle.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Pattern: `(.)+`
Required: Yes
