# OfferSetSort
<a name="API_OfferSetSort"></a>

Allows to sort offer sets.

## Contents
<a name="API_OfferSetSort_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SortBy **   <a name="AWSMarketplaceService-Type-OfferSetSort-SortBy"></a>
Allows to sort offer sets.
Type: String
Valid Values: `Name | State | ReleaseDate | SolutionId | EntityId | LastModifiedDate`
Required: No

 ** SortOrder **   <a name="AWSMarketplaceService-Type-OfferSetSort-SortOrder"></a>
Allows to sort offer sets.
Type: String
Valid Values: `ASCENDING | DESCENDING`
Required: No
