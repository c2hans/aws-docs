# AMISecurityFilters
<a name="API_AMISecurityFilters"></a>

Filters that apply to assessments performed against the AMI Security framework.

## Contents
<a name="API_AMISecurityFilters_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DeliveryOptionId **   <a name="AWSMarketplaceService-Type-AMISecurityFilters-DeliveryOptionId"></a>
The unique ID of the delivery option whose AMI Security assessments you want to list.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^[\w\-]+$`
Required: No
