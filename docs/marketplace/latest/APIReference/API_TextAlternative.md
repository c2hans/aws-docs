# TextAlternative

A proposed text value for a listing field.

## Contents
<a name="API_TextAlternative_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Rationale **   <a name="AWSMarketplaceService-Type-TextAlternative-Rationale"></a>
Why this alternative is recommended.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1000.
Required: Yes

 ** Value **   <a name="AWSMarketplaceService-Type-TextAlternative-Value"></a>
The proposed text. The limit of the field itself, such as 255 characters for a title, applies.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 5000.
Required: Yes
