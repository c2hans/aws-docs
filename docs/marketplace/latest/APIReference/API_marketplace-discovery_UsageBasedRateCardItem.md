# UsageBasedRateCardItem
<a name="API_marketplace-discovery_UsageBasedRateCardItem"></a>

A rate card within a usage-based pricing term, containing per-unit rates.

## Contents
<a name="API_marketplace-discovery_UsageBasedRateCardItem_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** rateCard **   <a name="AWSMarketplaceService-Type-marketplace-discovery_UsageBasedRateCardItem-rateCard"></a>
The per-unit rates for this usage-based rate card.
Type: Array of [RateCardItem](API_marketplace-discovery_RateCardItem.md) objects
Required: Yes
