# ListingAssociatedEntity
<a name="API_marketplace-discovery_ListingAssociatedEntity"></a>

A product and offer associated with a listing.

## Contents
<a name="API_marketplace-discovery_ListingAssociatedEntity_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** offer **   <a name="AWSMarketplaceService-Type-marketplace-discovery_ListingAssociatedEntity-offer"></a>
Information about the default offer associated with the listing.
Type: [OfferInformation](API_marketplace-discovery_OfferInformation.md) object
Required: No

 ** product **   <a name="AWSMarketplaceService-Type-marketplace-discovery_ListingAssociatedEntity-product"></a>
Information about the product associated with the listing.
Type: [ProductInformation](API_marketplace-discovery_ProductInformation.md) object
Required: No
