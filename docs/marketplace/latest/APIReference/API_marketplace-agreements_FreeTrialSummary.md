# FreeTrialSummary
<a name="API_marketplace-agreements_FreeTrialSummary"></a>

Contains details about the free trial of an agreement, including when the free trial ends.

## Contents
<a name="API_marketplace-agreements_FreeTrialSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** trialEndTime **   <a name="AWSMarketplaceService-Type-marketplace-agreements_FreeTrialSummary-trialEndTime"></a>
The date and time when the free trial ends. For an agreement that includes both a free trial and usage-based pricing, the agreement converts to paid usage at this time.
Type: Timestamp
Required: No
