# ResaleAuthorizationResellerRoleFilter
<a name="API_ResaleAuthorizationResellerRoleFilter"></a>

Allows filtering on the `ResellerRole` of a ResaleAuthorization.

## Contents
<a name="API_ResaleAuthorizationResellerRoleFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-ResaleAuthorizationResellerRoleFilter-ValueList"></a>
Allows filtering on the `ResellerRole` of a ResaleAuthorization with list input.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Valid Values: `ChannelPartner | Distributor`
Required: No
