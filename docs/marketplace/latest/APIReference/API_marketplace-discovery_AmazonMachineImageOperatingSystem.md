# AmazonMachineImageOperatingSystem
<a name="API_marketplace-discovery_AmazonMachineImageOperatingSystem"></a>

Describes an operating system supported by an AMI fulfillment option.

## Contents
<a name="API_marketplace-discovery_AmazonMachineImageOperatingSystem_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** operatingSystemFamilyName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_AmazonMachineImageOperatingSystem-operatingSystemFamilyName"></a>
The operating system family, such as Linux or Windows.
Type: String
Required: Yes

 ** operatingSystemName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_AmazonMachineImageOperatingSystem-operatingSystemName"></a>
The specific operating system name, such as Amazon Linux 2 or Windows Server 2022.
Type: String
Required: Yes

 ** operatingSystemVersion **   <a name="AWSMarketplaceService-Type-marketplace-discovery_AmazonMachineImageOperatingSystem-operatingSystemVersion"></a>
The version of the operating system.
Type: String
Required: No
