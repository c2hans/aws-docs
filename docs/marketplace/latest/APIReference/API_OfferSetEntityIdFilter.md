# OfferSetEntityIdFilter
<a name="API_OfferSetEntityIdFilter"></a>

Allows filtering on the entity id of an offer set.

## Contents
<a name="API_OfferSetEntityIdFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-OfferSetEntityIdFilter-ValueList"></a>
Allows filtering on entity id of an offer set with list input.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^offerset-[a-zA-Z0-9][.a-zA-Z0-9/-]+[a-zA-Z0-9]$`
Required: No
