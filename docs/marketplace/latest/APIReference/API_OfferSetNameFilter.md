# OfferSetNameFilter
<a name="API_OfferSetNameFilter"></a>

Allows filtering on the `Name` of an offer set.

## Contents
<a name="API_OfferSetNameFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-OfferSetNameFilter-ValueList"></a>
Allows filtering on the `Name` of an offer set with list input.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Length Constraints: Minimum length of 1. Maximum length of 150.
Pattern: `^(.)+$`
Required: No
