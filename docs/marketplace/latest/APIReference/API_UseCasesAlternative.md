# UseCasesAlternative

A proposed set of use cases for a solution.

## Contents
<a name="API_UseCasesAlternative_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Rationale **   <a name="AWSMarketplaceService-Type-UseCasesAlternative-Rationale"></a>
Why this alternative is recommended.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1000.
Required: Yes

 ** Value **   <a name="AWSMarketplaceService-Type-UseCasesAlternative-Value"></a>
The proposed use cases, in ranked order.
Type: Array of [ListingUseCase](API_ListingUseCase.md) objects
Array Members: Minimum number of 1 item. Maximum number of 5 items.
Required: Yes
