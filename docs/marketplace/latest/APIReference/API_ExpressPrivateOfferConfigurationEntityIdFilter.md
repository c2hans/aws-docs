# ExpressPrivateOfferConfigurationEntityIdFilter

The filter for the `EntityId` of an express private offer configuration.

## Contents
<a name="API_ExpressPrivateOfferConfigurationEntityIdFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-ExpressPrivateOfferConfigurationEntityIdFilter-ValueList"></a>
A list of `EntityId` values to filter on.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^[a-zA-Z0-9][.a-zA-Z0-9/-]+[a-zA-Z0-9]$`
Required: No
