# ExpressPrivateOfferConfigurationSort

The sort fields for express private offer configurations.

## Contents
<a name="API_ExpressPrivateOfferConfigurationSort_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SortBy **   <a name="AWSMarketplaceService-Type-ExpressPrivateOfferConfigurationSort-SortBy"></a>
The field to sort by. Valid values are `EntityId`, `LastModifiedDate`, `ProductId`, and `State`.
Type: String
Valid Values: `EntityId | LastModifiedDate | ProductId | State`
Required: No

 ** SortOrder **   <a name="AWSMarketplaceService-Type-ExpressPrivateOfferConfigurationSort-SortOrder"></a>
The sorting order. Valid values are `ASCENDING` and `DESCENDING`.
Type: String
Valid Values: `ASCENDING | DESCENDING`
Required: No
