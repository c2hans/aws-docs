# SubsidiaryAuthorizationLastModifiedDateFilter
<a name="API_SubsidiaryAuthorizationLastModifiedDateFilter"></a>

The filter for the date a subsidiary authorization was last modified.

## Contents
<a name="API_SubsidiaryAuthorizationLastModifiedDateFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DateRange **   <a name="AWSMarketplaceService-Type-SubsidiaryAuthorizationLastModifiedDateFilter-DateRange"></a>
A date range to filter by. The operation returns subsidiary authorizations with last modified dates that fall within this range.
Type: [SubsidiaryAuthorizationLastModifiedDateFilterDateRange](API_SubsidiaryAuthorizationLastModifiedDateFilterDateRange.md) object
Required: No
