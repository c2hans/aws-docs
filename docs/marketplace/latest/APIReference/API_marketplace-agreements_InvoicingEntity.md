# InvoicingEntity
<a name="API_marketplace-agreements_InvoicingEntity"></a>

The entity responsible for issuing the invoice.

## Contents
<a name="API_marketplace-agreements_InvoicingEntity_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** branchName **   <a name="AWSMarketplaceService-Type-marketplace-agreements_InvoicingEntity-branchName"></a>
The branch where the issuing entity is operating from.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Pattern: `(.)+`
Required: No

 ** legalName **   <a name="AWSMarketplaceService-Type-marketplace-agreements_InvoicingEntity-legalName"></a>
Legal name of the entity issuing the invoice.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Pattern: `(.)+`
Required: No
