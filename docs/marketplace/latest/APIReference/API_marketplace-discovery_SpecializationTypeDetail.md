# SpecializationTypeDetail

Describes a specialization type with its display information.

## Contents
<a name="API_marketplace-discovery_SpecializationTypeDetail_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** displayName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_SpecializationTypeDetail-displayName"></a>
The name of the specialization type displayed to you.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `.*\S.*`
Required: Yes

 ** specializationType **   <a name="AWSMarketplaceService-Type-marketplace-discovery_SpecializationTypeDetail-specializationType"></a>
The specialization type.
Type: String
Valid Values: `USE_CASE | INDUSTRY | SERVICES`
Required: Yes
