# ContainerProductSummary
<a name="API_ContainerProductSummary"></a>

Object that contains summarized information about a container product.

## Contents
<a name="API_ContainerProductSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ProductTitle **   <a name="AWSMarketplaceService-Type-ContainerProductSummary-ProductTitle"></a>
The title of the container product.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^(.)+$`
Required: No

 ** Visibility **   <a name="AWSMarketplaceService-Type-ContainerProductSummary-Visibility"></a>
The lifecycle of the product.
Type: String
Valid Values: `Limited | Public | Restricted | Draft`
Required: No
