# OfferProductIdFilter
<a name="API_OfferProductIdFilter"></a>

Allows filtering on the `ProductId` of an offer.

## Contents
<a name="API_OfferProductIdFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-OfferProductIdFilter-ValueList"></a>
Allows filtering on the `ProductId` of an offer with list input.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^(.)+$`
Required: No
