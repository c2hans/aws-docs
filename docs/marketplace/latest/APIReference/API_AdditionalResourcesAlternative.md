# AdditionalResourcesAlternative

A proposed set of additional resources for a listing.

## Contents
<a name="API_AdditionalResourcesAlternative_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Rationale **   <a name="AWSMarketplaceService-Type-AdditionalResourcesAlternative-Rationale"></a>
Why this alternative is recommended.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1000.
Required: Yes

 ** Value **   <a name="AWSMarketplaceService-Type-AdditionalResourcesAlternative-Value"></a>
The proposed additional resources.
Type: Array of [AdditionalResource](API_AdditionalResource.md) objects
Array Members: Minimum number of 1 item. Maximum number of 8 items.
Required: Yes
