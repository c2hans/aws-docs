# HelmOperatingSystem
<a name="API_marketplace-discovery_HelmOperatingSystem"></a>

Describes an operating system supported by a Helm chart fulfillment option.

## Contents
<a name="API_marketplace-discovery_HelmOperatingSystem_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** operatingSystemFamilyName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_HelmOperatingSystem-operatingSystemFamilyName"></a>
The operating system family, such as Linux.
Type: String
Required: Yes

 ** operatingSystemName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_HelmOperatingSystem-operatingSystemName"></a>
The specific operating system name.
Type: String
Required: Yes
