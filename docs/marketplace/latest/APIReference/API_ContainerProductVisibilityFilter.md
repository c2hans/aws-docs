# ContainerProductVisibilityFilter
<a name="API_ContainerProductVisibilityFilter"></a>

Object that allows filtering on the visibility of the product in the AWS Marketplace.

## Contents
<a name="API_ContainerProductVisibilityFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ValueList **   <a name="AWSMarketplaceService-Type-ContainerProductVisibilityFilter-ValueList"></a>
A string array of unique visibility values to be filtered on.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Valid Values: `Limited | Public | Restricted | Draft`
Required: No
