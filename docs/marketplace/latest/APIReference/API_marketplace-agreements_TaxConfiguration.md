# TaxConfiguration
<a name="API_marketplace-agreements_TaxConfiguration"></a>

Configuration controls for tax estimation in the agreement request.

## Contents
<a name="API_marketplace-agreements_TaxConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** taxEstimation **   <a name="AWSMarketplaceService-Type-marketplace-agreements_TaxConfiguration-taxEstimation"></a>
Toggle to estimate tax as part of the response. Values include `ENABLED` and `DISABLED`. Default is `DISABLED`.
Type: String
Valid Values: `DISABLED | ENABLED`
Required: No
