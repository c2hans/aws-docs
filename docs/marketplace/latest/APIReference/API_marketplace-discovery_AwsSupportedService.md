# AwsSupportedService
<a name="API_marketplace-discovery_AwsSupportedService"></a>

Describes an AWS service supported by a fulfillment option.

## Contents
<a name="API_marketplace-discovery_AwsSupportedService_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** description **   <a name="AWSMarketplaceService-Type-marketplace-discovery_AwsSupportedService-description"></a>
A description of the supported service.
Type: String
Required: Yes

 ** displayName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_AwsSupportedService-displayName"></a>
The human-readable name of the supported service.
Type: String
Required: Yes

 ** supportedServiceType **   <a name="AWSMarketplaceService-Type-marketplace-discovery_AwsSupportedService-supportedServiceType"></a>
The machine-readable identifier of the supported service.
Type: String
Required: Yes
