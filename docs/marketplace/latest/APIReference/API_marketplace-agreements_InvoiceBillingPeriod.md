# InvoiceBillingPeriod
<a name="API_marketplace-agreements_InvoiceBillingPeriod"></a>

The billing period for an invoice, specified by month and year.

## Contents
<a name="API_marketplace-agreements_InvoiceBillingPeriod_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** month **   <a name="AWSMarketplaceService-Type-marketplace-agreements_InvoiceBillingPeriod-month"></a>
The billing period month. Valid range: 1-12.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 12.
Required: Yes

 ** year **   <a name="AWSMarketplaceService-Type-marketplace-agreements_InvoiceBillingPeriod-year"></a>
The billing period year.
Type: Integer
Valid Range: Minimum value of 2023. Maximum value of 2050.
Required: Yes
