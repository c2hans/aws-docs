# OfferAssociatedEntity
<a name="API_marketplace-discovery_OfferAssociatedEntity"></a>

A product and optional offer set associated with an offer.

## Contents
<a name="API_marketplace-discovery_OfferAssociatedEntity_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** product **   <a name="AWSMarketplaceService-Type-marketplace-discovery_OfferAssociatedEntity-product"></a>
Information about the product associated with the offer.
Type: [ProductInformation](API_marketplace-discovery_ProductInformation.md) object
Required: Yes

 ** offerSet **   <a name="AWSMarketplaceService-Type-marketplace-discovery_OfferAssociatedEntity-offerSet"></a>
Information about the offer set, if the offer is part of a bundled offer set.
Type: [OfferSetInformation](API_marketplace-discovery_OfferSetInformation.md) object
Required: No
