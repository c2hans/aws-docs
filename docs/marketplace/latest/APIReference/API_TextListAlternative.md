# TextListAlternative

A proposed list of text values for a listing field.

## Contents
<a name="API_TextListAlternative_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Rationale **   <a name="AWSMarketplaceService-Type-TextListAlternative-Rationale"></a>
Why this alternative is recommended.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1000.
Required: Yes

 ** Value **   <a name="AWSMarketplaceService-Type-TextListAlternative-Value"></a>
The proposed list of text values. The list has 1–15 items.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 15 items.
Length Constraints: Minimum length of 1. Maximum length of 500.
Required: Yes
