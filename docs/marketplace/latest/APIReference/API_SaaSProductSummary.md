# SaaSProductSummary
<a name="API_SaaSProductSummary"></a>

Object that contains summarized information about a SaaS product.

## Contents
<a name="API_SaaSProductSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ProductTitle **   <a name="AWSMarketplaceService-Type-SaaSProductSummary-ProductTitle"></a>
The title of the SaaS product.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^(.)+$`
Required: No

 ** Visibility **   <a name="AWSMarketplaceService-Type-SaaSProductSummary-Visibility"></a>
The lifecycle of the SaaS product.
Type: String
Valid Values: `Limited | Public | Restricted | Draft`
Required: No
