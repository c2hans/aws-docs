# CaseStudiesSummary

A summary of the case studies associated with a listing.

## Contents
<a name="API_marketplace-discovery_CaseStudiesSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** caseStudyCount **   <a name="AWSMarketplaceService-Type-marketplace-discovery_CaseStudiesSummary-caseStudyCount"></a>
The total number of case studies associated with the listing.
Type: Long
Valid Range: Minimum value of 0.
Required: Yes
