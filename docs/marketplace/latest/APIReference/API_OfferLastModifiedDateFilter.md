# OfferLastModifiedDateFilter
<a name="API_OfferLastModifiedDateFilter"></a>

Allows filtering on the `LastModifiedDate` of an offer.

## Contents
<a name="API_OfferLastModifiedDateFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DateRange **   <a name="AWSMarketplaceService-Type-OfferLastModifiedDateFilter-DateRange"></a>
Allows filtering on the `LastModifiedDate` of an offer with date range as input.
Type: [OfferLastModifiedDateFilterDateRange](API_OfferLastModifiedDateFilterDateRange.md) object
Required: No
