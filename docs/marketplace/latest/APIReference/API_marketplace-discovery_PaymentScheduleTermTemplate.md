# PaymentScheduleTermTemplate
<a name="API_marketplace-discovery_PaymentScheduleTermTemplate"></a>

A template for the payment schedule term on the renewal offer.

## Contents
<a name="API_marketplace-discovery_PaymentScheduleTermTemplate_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** schedule **   <a name="AWSMarketplaceService-Type-marketplace-discovery_PaymentScheduleTermTemplate-schedule"></a>
An ordered list of installment entries for the renewal payment schedule.
Type: Array of [PaymentScheduleEntry](API_marketplace-discovery_PaymentScheduleEntry.md) objects
Array Members: Minimum number of 1 item. Maximum number of 200 items.
Required: Yes
