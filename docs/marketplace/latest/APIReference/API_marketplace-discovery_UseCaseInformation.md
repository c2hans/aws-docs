# UseCaseInformation

The name and identifier of a use case.

## Contents
<a name="API_marketplace-discovery_UseCaseInformation_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** displayName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_UseCaseInformation-displayName"></a>
The human-readable name of the use case.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `.*\S.*`
Required: Yes

 ** value **   <a name="AWSMarketplaceService-Type-marketplace-discovery_UseCaseInformation-value"></a>
The machine-readable identifier of the use case.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `.*\S.*`
Required: Yes
