# AssessmentTargetSummary
<a name="API_AssessmentTargetSummary"></a>

Identifies the entity or change set that was assessed.

## Contents
<a name="API_AssessmentTargetSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ChangeSetId **   <a name="AWSMarketplaceService-Type-AssessmentTargetSummary-ChangeSetId"></a>
The unique ID of the change set that was assessed.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^[\w\-]+$`
Required: No

 ** EntityId **   <a name="AWSMarketplaceService-Type-AssessmentTargetSummary-EntityId"></a>
The unique ID of the entity that was assessed.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^[\w\-]+$`
Required: No
