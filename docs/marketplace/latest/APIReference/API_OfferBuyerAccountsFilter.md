# OfferBuyerAccountsFilter
<a name="API_OfferBuyerAccountsFilter"></a>

Allows filtering on the `BuyerAccounts` of an offer.

## Contents
<a name="API_OfferBuyerAccountsFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** WildCardValue **   <a name="AWSMarketplaceService-Type-OfferBuyerAccountsFilter-WildCardValue"></a>
Allows filtering on the `BuyerAccounts` of an offer with wild card input.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^(.)+$`
Required: No
