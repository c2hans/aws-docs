# OfferAvailabilityEndDateFilter
<a name="API_OfferAvailabilityEndDateFilter"></a>

Allows filtering on the `AvailabilityEndDate` of an offer.

## Contents
<a name="API_OfferAvailabilityEndDateFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DateRange **   <a name="AWSMarketplaceService-Type-OfferAvailabilityEndDateFilter-DateRange"></a>
Allows filtering on the `AvailabilityEndDate` of an offer with date range as input.
Type: [OfferAvailabilityEndDateFilterDateRange](API_OfferAvailabilityEndDateFilterDateRange.md) object
Required: No
