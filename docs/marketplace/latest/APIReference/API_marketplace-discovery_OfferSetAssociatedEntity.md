# OfferSetAssociatedEntity
<a name="API_marketplace-discovery_OfferSetAssociatedEntity"></a>

A product and offer associated with an offer set.

## Contents
<a name="API_marketplace-discovery_OfferSetAssociatedEntity_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** offer **   <a name="AWSMarketplaceService-Type-marketplace-discovery_OfferSetAssociatedEntity-offer"></a>
Information about the offer associated with the offer set.
Type: [OfferInformation](API_marketplace-discovery_OfferInformation.md) object
Required: Yes

 ** product **   <a name="AWSMarketplaceService-Type-marketplace-discovery_OfferSetAssociatedEntity-product"></a>
Information about the product associated with the offer set.
Type: [ProductInformation](API_marketplace-discovery_ProductInformation.md) object
Required: Yes
