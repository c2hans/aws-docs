# RenewalSummary
<a name="API_marketplace-agreements_RenewalSummary"></a>

The details of the renewal that applies at the end date of an agreement.

## Contents
<a name="API_marketplace-agreements_RenewalSummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** offerId **   <a name="AWSMarketplaceService-Type-marketplace-agreements_RenewalSummary-offerId"></a>
The unique identifier of the offer that provides the terms for the next renewal cycle. For most renewals, this is the same offer that the agreement was created from.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Pattern: `\S{1,64}`
Required: No
