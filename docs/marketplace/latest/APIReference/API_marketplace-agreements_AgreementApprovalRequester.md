# AgreementApprovalRequester

The account that started an agreement approval.

## Contents
<a name="API_marketplace-agreements_AgreementApprovalRequester_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** accountId **   <a name="AWSMarketplaceService-Type-marketplace-agreements_AgreementApprovalRequester-accountId"></a>
The AWS account ID of the requester, which is the buyer of the agreement request.
Type: String
Length Constraints: Fixed length of 12.
Pattern: `[0-9]+`
Required: Yes
