# EksAddOnOperatingSystem
<a name="API_marketplace-discovery_EksAddOnOperatingSystem"></a>

Describes an operating system supported by an EKS add-on fulfillment option.

## Contents
<a name="API_marketplace-discovery_EksAddOnOperatingSystem_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** operatingSystemFamilyName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_EksAddOnOperatingSystem-operatingSystemFamilyName"></a>
The operating system family, such as Linux.
Type: String
Required: Yes

 ** operatingSystemName **   <a name="AWSMarketplaceService-Type-marketplace-discovery_EksAddOnOperatingSystem-operatingSystemName"></a>
The specific operating system name.
Type: String
Required: Yes
