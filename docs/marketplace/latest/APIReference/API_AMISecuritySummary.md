# AMISecuritySummary
<a name="API_AMISecuritySummary"></a>

The details of the resource assessed under the AMI Security framework.

## Contents
<a name="API_AMISecuritySummary_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** DeliveryOptionId **   <a name="AWSMarketplaceService-Type-AMISecuritySummary-DeliveryOptionId"></a>
The unique ID of the delivery option that was evaluated.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `^[\w\-]+$`
Required: No
