# Proposer
<a name="API_marketplace-agreements_Proposer"></a>

Details of the party proposing the agreement terms,. This is commonly the seller for `PurchaseAgreement`.

## Contents
<a name="API_marketplace-agreements_Proposer_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** accountId **   <a name="AWSMarketplaceService-Type-marketplace-agreements_Proposer-accountId"></a>
The AWS account ID of the proposer.
Type: String
Length Constraints: Fixed length of 12.
Pattern: `[0-9]+`
Required: No
