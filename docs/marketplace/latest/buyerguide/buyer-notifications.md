# Buyer notifications for AWS Marketplace events
<a name="buyer-notifications"></a>

AWS Marketplace provides timely notifications to keep you informed about important events related to your purchases. Notifications are delivered through email, chatbots, Amazon EventBridge events, and Amazon Simple Notification Service (Amazon SNS) topics.

By default, AWS Marketplace automatically sends email notifications to your account email address for key events. For more control over notification routing and delivery channels, you can use AWS User Notifications to send specific events to custom destinations like team email distribution lists, Slack channels, Microsoft Teams, or Amazon Chime.

For more information about AWS User Notifications, EventBridge and Amazon SNS, see the following topics:
+ [ Getting started with Amazon EventBridge](https://docs.aws.amazon.com/eventbridge/latest/userguide/eb-get-started.html), in the *EventBridge User Guide*.
+ [ Getting started with Notification Configurations](https://docs.aws.amazon.com/notifications/latest/userguide/managing-notifications.html), in the *AWS User Notifications User Guide*.
+ [ Learn how to create an Amazon Simple Notification Service topic and publish messages](https://docs.aws.amazon.com/sns/latest/dg/sns-getting-started.html), in the *Amazon SNS Developer Guide*.
