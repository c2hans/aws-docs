# SaaS products through AWS Marketplace
<a name="buyer-saas-products"></a>

 For software as a service (SaaS) products, you subscribe to products through AWS Marketplace, but you access the product in the software seller's environment.

AWS Marketplace offers the following pricing models:
+ [Subscribing with SaaS usage-based subscriptions](saas-subscriptions.md)
+ [Subscribing with SaaS upfront commitments](buyer-saas-contracts.md)
+ [Subscribing to SaaS free trials](saas-free-trials.md)

For products that offer the [Quick Launch option](quick-launch.md#saas-quick-launch), you can configure, deploy, and launch your software all at once.
