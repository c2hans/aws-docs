# ExampleCountByField

 The number of examples that have each field. An example can have more than one of these fields, so the counts can add up to more than `exampleCount`.

## Contents
<a name="API_ExampleCountByField_Contents"></a>

 ** actorProfile **   <a name="bedrockagentcorecontrol-Type-ExampleCountByField-actorProfile"></a>
 The number of examples that have `actor_profile`.
Type: Long
Required: Yes

 ** input **   <a name="bedrockagentcorecontrol-Type-ExampleCountByField-input"></a>
 The number of examples that have `input`.
Type: Long
Required: Yes

 ** turns **   <a name="bedrockagentcorecontrol-Type-ExampleCountByField-turns"></a>
 The number of examples that have `turns`.
Type: Long
Required: Yes
