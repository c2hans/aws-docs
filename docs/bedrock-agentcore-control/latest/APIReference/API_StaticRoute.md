# StaticRoute
<a name="API_StaticRoute"></a>

A static route to a single gateway target.

## Contents
<a name="API_StaticRoute_Contents"></a>

 ** targetName **   <a name="bedrockagentcorecontrol-Type-StaticRoute-targetName"></a>
The name of the target to route requests to.
Type: String
Pattern: `([0-9a-zA-Z][-]?){1,100}`
Required: Yes
