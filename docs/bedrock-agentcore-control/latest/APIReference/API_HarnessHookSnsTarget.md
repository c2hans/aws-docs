# HarnessHookSnsTarget
<a name="API_HarnessHookSnsTarget"></a>

The configuration for an Amazon SNS hook target.

## Contents
<a name="API_HarnessHookSnsTarget_Contents"></a>

 ** arn **   <a name="bedrockagentcorecontrol-Type-HarnessHookSnsTarget-arn"></a>
The ARN of the Amazon SNS topic to publish hook events to.
Type: String
Length Constraints: Minimum length of 20. Maximum length of 2048.
Pattern: `arn:aws(-[^:]+)?:sns:[a-z0-9-]+:[0-9]{12}:.+`
Required: Yes
