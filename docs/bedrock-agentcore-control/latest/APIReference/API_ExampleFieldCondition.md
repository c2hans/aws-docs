# ExampleFieldCondition

 A condition on the fields of an example.

## Contents
<a name="API_ExampleFieldCondition_Contents"></a>

 ** anyOf **   <a name="bedrockagentcorecontrol-Type-ExampleFieldCondition-anyOf"></a>
 Matches examples that have at least one of these fields. Required.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 3 items.
Valid Values: `TURNS | INPUT | ACTOR_PROFILE`
Required: No
