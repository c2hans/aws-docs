# PortRange
<a name="API_PortRange"></a>

An inclusive range of ports. The value of `from` must be less than or equal to the value of `to`.

## Contents
<a name="API_PortRange_Contents"></a>

 ** from **   <a name="bedrockagentcorecontrol-Type-PortRange-from"></a>
The first port in the inclusive range.
Type: Integer
Valid Range: Minimum value of 8000. Maximum value of 12000.
Required: Yes

 ** to **   <a name="bedrockagentcorecontrol-Type-PortRange-to"></a>
The last port in the inclusive range.
Type: Integer
Valid Range: Minimum value of 8000. Maximum value of 12000.
Required: Yes
