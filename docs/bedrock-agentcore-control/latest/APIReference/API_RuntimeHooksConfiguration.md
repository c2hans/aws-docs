# RuntimeHooksConfiguration
<a name="API_RuntimeHooksConfiguration"></a>

The lifecycle hooks that AgentCore Runtime runs at fixed points in the runtime's lifecycle.

## Contents
<a name="API_RuntimeHooksConfiguration_Contents"></a>

 ** build **   <a name="bedrockagentcorecontrol-Type-RuntimeHooksConfiguration-build"></a>
The hooks that run when you create or update the AgentCore Runtime, before any sessions are created.
Type: [BuildLifecycleHooks](API_BuildLifecycleHooks.md) object
Required: No
