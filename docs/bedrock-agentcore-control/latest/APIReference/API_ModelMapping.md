# ModelMapping
<a name="API_ModelMapping"></a>

The configuration that translates model IDs between client-facing names and provider model IDs.

## Contents
<a name="API_ModelMapping_Contents"></a>

 ** providerPrefix **   <a name="bedrockagentcorecontrol-Type-ModelMapping-providerPrefix"></a>
The provider prefix configuration used for model ID translation.
Type: [ProviderPrefix](API_ProviderPrefix.md) object
Required: No
