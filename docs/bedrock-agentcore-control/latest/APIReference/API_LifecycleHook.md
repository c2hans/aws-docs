# LifecycleHook
<a name="API_LifecycleHook"></a>

A lifecycle hook, which defines the action that AgentCore Runtime runs at a point in the runtime's lifecycle.

## Contents
<a name="API_LifecycleHook_Contents"></a>

 ** action **   <a name="bedrockagentcorecontrol-Type-LifecycleHook-action"></a>
The action that AgentCore Runtime runs for the hook. Specify exactly one action.
Type: [LifecycleHookAction](API_LifecycleHookAction.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes
