# HarnessSlidingWindowConfiguration
<a name="API_HarnessSlidingWindowConfiguration"></a>

Configuration for sliding window truncation strategy.

## Contents
<a name="API_HarnessSlidingWindowConfiguration_Contents"></a>

 ** messagesCount **   <a name="bedrockagentcorecontrol-Type-HarnessSlidingWindowConfiguration-messagesCount"></a>
The number of recent messages to retain in the context window.
Type: Integer
Required: No
