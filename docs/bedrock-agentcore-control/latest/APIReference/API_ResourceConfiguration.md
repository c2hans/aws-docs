# ResourceConfiguration
<a name="API_ResourceConfiguration"></a>

The resource configuration for an AgentCore Runtime.

## Contents
<a name="API_ResourceConfiguration_Contents"></a>

 ** minimumMemoryInMiB **   <a name="bedrockagentcorecontrol-Type-ResourceConfiguration-minimumMemoryInMiB"></a>
The minimum amount of memory, in mebibytes, to allocate to the AgentCore Runtime.
Type: Integer
Required: Yes
