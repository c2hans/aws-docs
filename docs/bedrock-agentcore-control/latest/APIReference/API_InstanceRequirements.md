# InstanceRequirements
<a name="API_InstanceRequirements"></a>

The requirements for Amazon EC2 instance types in a capacity provider.

## Contents
<a name="API_InstanceRequirements_Contents"></a>

 ** allowedInstanceTypes **   <a name="bedrockagentcorecontrol-Type-InstanceRequirements-allowedInstanceTypes"></a>
The list of allowed instance types. You can specify up to 30 instance types.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 30 items.
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: Yes
