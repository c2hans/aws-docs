# ListResourcesAssociatedToCustomLineItemFilter
<a name="API_ListResourcesAssociatedToCustomLineItemFilter"></a>

 A filter that specifies the type of resource associations that should be retrieved for a custom line item.

## Contents
<a name="API_ListResourcesAssociatedToCustomLineItemFilter_Contents"></a>

 ** Relationship **   <a name="billingconductor-Type-ListResourcesAssociatedToCustomLineItemFilter-Relationship"></a>
 The type of relationship between the custom line item and the associated resource.
Type: String
Valid Values: `PARENT | CHILD`
Required: No
