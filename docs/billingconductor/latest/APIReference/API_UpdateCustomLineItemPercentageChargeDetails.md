# UpdateCustomLineItemPercentageChargeDetails
<a name="API_UpdateCustomLineItemPercentageChargeDetails"></a>

 A representation of the new charge details that are associated with a percentage custom line item.

## Contents
<a name="API_UpdateCustomLineItemPercentageChargeDetails_Contents"></a>

 ** PercentageValue **   <a name="billingconductor-Type-UpdateCustomLineItemPercentageChargeDetails-PercentageValue"></a>
 The custom line item's new percentage value. This will be multiplied against the combined value of its associated resources to determine its charge value.
Type: Double
Valid Range: Minimum value of 0. Maximum value of 10000.
Required: Yes
