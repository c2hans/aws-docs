# ListCustomLineItemFlatChargeDetails
<a name="API_ListCustomLineItemFlatChargeDetails"></a>

 A representation of the charge details that are associated with a flat custom line item.

## Contents
<a name="API_ListCustomLineItemFlatChargeDetails_Contents"></a>

 ** ChargeValue **   <a name="billingconductor-Type-ListCustomLineItemFlatChargeDetails-ChargeValue"></a>
 The custom line item's fixed charge value in USD.
Type: Double
Valid Range: Minimum value of 0. Maximum value of 1000000.
Required: Yes
