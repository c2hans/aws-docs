# CustomLineItemFlatChargeDetails
<a name="API_CustomLineItemFlatChargeDetails"></a>

A representation of the charge details that are associated with a flat custom line item.

## Contents
<a name="API_CustomLineItemFlatChargeDetails_Contents"></a>

 ** ChargeValue **   <a name="billingconductor-Type-CustomLineItemFlatChargeDetails-ChargeValue"></a>
The custom line item's fixed charge value in USD.
Type: Double
Valid Range: Minimum value of 0. Maximum value of 1000000.
Required: Yes
