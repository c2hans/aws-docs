# Viewing the pricing rule table
<a name="table-pricingrule"></a>

After you create a pricing rule, you can view the details of the pricing rule in a filterable table. You can filter by the following dimensions:
+ Pricing rule name
+ Scope
+ Type
+ Details
+ Rate
