# AWS Data Transfer Terminal Documentation

AWS Data Transfer Terminal provides access to a network-ready, physical location for customers to bring their devices for near instantaneous data transfer to or from the cloud.

- [AWS Data Transfer Terminal User Guide](/datatransferterminal/latest/userguide/): Describes key concepts for AWS Data Transfer Terminal and provides instructions for scheduling reservations and accessing secure Data Transfer Terminal locations.
