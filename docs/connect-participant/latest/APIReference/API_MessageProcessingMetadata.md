# MessageProcessingMetadata
<a name="API_connect-participant_MessageProcessingMetadata"></a>

Contains metadata for chat messages.

## Contents
<a name="API_connect-participant_MessageProcessingMetadata_Contents"></a>

 ** MessageProcessingStatus **   <a name="connect-Type-connect-participant_MessageProcessingMetadata-MessageProcessingStatus"></a>
The status of Message Processing for the message.
Type: String
Valid Values: `PROCESSING | FAILED | REJECTED`
Required: No
