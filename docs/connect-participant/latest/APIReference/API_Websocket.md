# Websocket
<a name="API_connect-participant_Websocket"></a>

The websocket for the participant's connection.

## Contents
<a name="API_connect-participant_Websocket_Contents"></a>

 ** ConnectionExpiry **   <a name="connect-Type-connect-participant_Websocket-ConnectionExpiry"></a>
The URL expiration timestamp in ISO date format.
It's specified in ISO 8601 format: yyyy-MM-ddThh:mm:ss.SSSZ. For example, 2019-11-08T02:41:28.172Z.
Type: String
Required: No

 ** Url **   <a name="connect-Type-connect-participant_Websocket-Url"></a>
The URL of the websocket.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2000.
Required: No
