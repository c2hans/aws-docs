# EdgeStructure
<a name="API_EdgeStructure"></a>

An edge structure.

## Contents
<a name="API_EdgeStructure_Contents"></a>

 ** count **   <a name="neptunedata-Type-EdgeStructure-count"></a>
The number of edges that have this specific structure.
Type: Long
Required: No

 ** edgeProperties **   <a name="neptunedata-Type-EdgeStructure-edgeProperties"></a>
A list of edge properties present in this specific structure.
Type: Array of strings
Required: No
