# StatisticsSummary
<a name="API_StatisticsSummary"></a>

Information about the characteristic sets generated in the statistics.

## Contents
<a name="API_StatisticsSummary_Contents"></a>

 ** instanceCount **   <a name="neptunedata-Type-StatisticsSummary-instanceCount"></a>
The total number of characteristic-set instances.
Type: Integer
Required: No

 ** predicateCount **   <a name="neptunedata-Type-StatisticsSummary-predicateCount"></a>
The total number of unique predicates.
Type: Integer
Required: No

 ** signatureCount **   <a name="neptunedata-Type-StatisticsSummary-signatureCount"></a>
The total number of signatures across all characteristic sets.
Type: Integer
Required: No
