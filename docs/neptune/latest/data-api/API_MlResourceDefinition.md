# MlResourceDefinition
<a name="API_MlResourceDefinition"></a>

Defines a Neptune ML resource.

## Contents
<a name="API_MlResourceDefinition_Contents"></a>

 ** arn **   <a name="neptunedata-Type-MlResourceDefinition-arn"></a>
The resource ARN.
Type: String
Required: No

 ** cloudwatchLogUrl **   <a name="neptunedata-Type-MlResourceDefinition-cloudwatchLogUrl"></a>
The CloudWatch log URL for the resource.
Type: String
Required: No

 ** failureReason **   <a name="neptunedata-Type-MlResourceDefinition-failureReason"></a>
The failure reason, in case of a failure.
Type: String
Required: No

 ** name **   <a name="neptunedata-Type-MlResourceDefinition-name"></a>
The resource name.
Type: String
Required: No

 ** outputLocation **   <a name="neptunedata-Type-MlResourceDefinition-outputLocation"></a>
The output location.
Type: String
Required: No

 ** status **   <a name="neptunedata-Type-MlResourceDefinition-status"></a>
The resource status.
Type: String
Required: No
