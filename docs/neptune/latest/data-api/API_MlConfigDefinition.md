# MlConfigDefinition
<a name="API_MlConfigDefinition"></a>

The ARN for the configuration.
Type: String
Required: No

 ** name **   <a name="neptunedata-Type-MlConfigDefinition-name"></a>
The configuration name.
Type: String
Required: No
