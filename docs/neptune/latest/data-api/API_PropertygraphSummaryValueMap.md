# PropertygraphSummaryValueMap
<a name="API_PropertygraphSummaryValueMap"></a>

Payload for the property graph summary response.

## Contents
<a name="API_PropertygraphSummaryValueMap_Contents"></a>

 ** graphSummary **   <a name="neptunedata-Type-PropertygraphSummaryValueMap-graphSummary"></a>
The graph summary.
Type: [PropertygraphSummary](API_PropertygraphSummary.md) object
Required: No

 ** lastStatisticsComputationTime **   <a name="neptunedata-Type-PropertygraphSummaryValueMap-lastStatisticsComputationTime"></a>
The timestamp, in ISO 8601 format, of the time at which Neptune last computed statistics.
Type: Timestamp
Required: No

 ** version **   <a name="neptunedata-Type-PropertygraphSummaryValueMap-version"></a>
The version of this graph summary response.
Type: String
Required: No
