# CharacterSet
<a name="API_CharacterSet"></a>

Specifies a character set.

## Contents
<a name="API_CharacterSet_Contents"></a>

 ** CharacterSetDescription **
The description of the character set.
Type: String
Required: No

 ** CharacterSetName **
The name of the character set.
Type: String
Required: No
