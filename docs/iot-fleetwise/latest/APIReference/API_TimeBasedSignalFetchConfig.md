# TimeBasedSignalFetchConfig
<a name="API_TimeBasedSignalFetchConfig"></a>

Used to configure a frequency-based vehicle signal fetch.

## Contents
<a name="API_TimeBasedSignalFetchConfig_Contents"></a>

 ** executionFrequencyMs **   <a name="iotfleetwise-Type-TimeBasedSignalFetchConfig-executionFrequencyMs"></a>
The frequency with which the signal fetch will be executed.
Type: Long
Valid Range: Minimum value of 1. Maximum value of 9223372036854775807.
Required: Yes
