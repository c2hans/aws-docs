# InvalidSignal
<a name="API_InvalidSignal"></a>

A reason that a signal isn't valid.

## Contents
<a name="API_InvalidSignal_Contents"></a>

 ** name **   <a name="iotfleetwise-Type-InvalidSignal-name"></a>
The name of the signal that isn't valid.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 150.
Pattern: `[a-zA-Z0-9_.]+`
Required: No

 ** reason **   <a name="iotfleetwise-Type-InvalidSignal-reason"></a>
A message about why the signal isn't valid.
Type: String
Required: No
