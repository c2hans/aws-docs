# PeriodicStateTemplateUpdateStrategy
<a name="API_PeriodicStateTemplateUpdateStrategy"></a>

Vehicles associated with the state template will stream telemetry data during a specified time period.

## Contents
<a name="API_PeriodicStateTemplateUpdateStrategy_Contents"></a>

 ** stateTemplateUpdateRate **   <a name="iotfleetwise-Type-PeriodicStateTemplateUpdateStrategy-stateTemplateUpdateRate"></a>
The length of time between state template updates.
Type: [TimePeriod](API_TimePeriod.md) object
Required: Yes
