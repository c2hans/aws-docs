# UpdateVehicleResponseItem
<a name="API_UpdateVehicleResponseItem"></a>

Information about the updated vehicle.

## Contents
<a name="API_UpdateVehicleResponseItem_Contents"></a>

 ** arn **   <a name="iotfleetwise-Type-UpdateVehicleResponseItem-arn"></a>
The Amazon Resource Name (ARN) of the updated vehicle.
Type: String
Required: No

 ** vehicleName **   <a name="iotfleetwise-Type-UpdateVehicleResponseItem-vehicleName"></a>
The unique ID of the updated vehicle.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Pattern: `[a-zA-Z\d\-_:]+`
Required: No
