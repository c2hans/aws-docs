# SignalCatalogSummary
<a name="API_SignalCatalogSummary"></a>

Information about a collection of standardized signals, which can be attributes, branches, sensors, or actuators.

## Contents
<a name="API_SignalCatalogSummary_Contents"></a>

 ** arn **   <a name="iotfleetwise-Type-SignalCatalogSummary-arn"></a>
The Amazon Resource Name (ARN) of the signal catalog.
Type: String
Required: No

 ** creationTime **   <a name="iotfleetwise-Type-SignalCatalogSummary-creationTime"></a>
The time the signal catalog was created in seconds since epoch (January 1, 1970 at midnight UTC time).
Type: Timestamp
Required: No

 ** lastModificationTime **   <a name="iotfleetwise-Type-SignalCatalogSummary-lastModificationTime"></a>
The time the signal catalog was last updated in seconds since epoch (January 1, 1970 at midnight UTC time).
Type: Timestamp
Required: No

 ** name **   <a name="iotfleetwise-Type-SignalCatalogSummary-name"></a>
The name of the signal catalog.
Type: String
Required: No
