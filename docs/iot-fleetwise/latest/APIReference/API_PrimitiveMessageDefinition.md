# PrimitiveMessageDefinition
<a name="API_PrimitiveMessageDefinition"></a>

Represents a primitive type node of the complex data structure.

## Contents
<a name="API_PrimitiveMessageDefinition_Contents"></a>

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** ros2PrimitiveMessageDefinition **   <a name="iotfleetwise-Type-PrimitiveMessageDefinition-ros2PrimitiveMessageDefinition"></a>
Information about a `PrimitiveMessage` using a ROS 2 compliant primitive type message of the complex data structure.
Type: [ROS2PrimitiveMessageDefinition](API_ROS2PrimitiveMessageDefinition.md) object
Required: No
