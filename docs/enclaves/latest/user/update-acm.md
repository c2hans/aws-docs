# Update ACM for Nitro Enclaves
<a name="update-acm"></a>

If you have already installed [AWS Certificate Manager for Nitro Enclaves](nitro-enclave-refapp.md), use the following command to update it to the latest version.

```
$ sudo yum update aws-nitro-enclaves-acm
```
