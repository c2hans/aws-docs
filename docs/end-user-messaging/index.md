# AWS End User Messaging Documentation

AWS End User Messaging helps you engage your customers by sending them SMS, voice messages, WhatsApp, and push notifications.

## SMS

- [User Guide](/sms-voice/latest/userguide/what-is-service.html): Describes key concepts for AWS End User Messaging SMS and provides instructions for using the AWS End User Messaging SMS console.
- [API Reference for SMS and Voice, v2](/pinpoint/latest/apireference_smsvoicev2/): Describes the REST API resources and operations associated with version 2 of the AWS End User Messaging SMS and Voice API.

## Social Messaging

- [User Guide](/social-messaging/latest/userguide/what-is-service.html): Describes key concepts for AWS End User Messaging Social and provides instructions for using the AWS End User Messaging Social console.
- [API Reference for Social Messaging](/social-messaging/latest/APIReference/Welcome.html): Describes all the AWS End User Messaging Social API actions.

## Push

- [User Guide](/push-notifications/latest/userguide/what-is-service.html): Describes key concepts for AWS End User Messaging Push and provides instructions for using the AWS End User Messaging Push console.
