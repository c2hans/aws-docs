# Resource-based policies within AWS End User Messaging
<a name="nx-security-iam-service-resource-based"></a>

**Supports resource-based policies: No**

Resource-based policies are JSON policy documents that you attach to a resource. AWS End User Messaging does not support resource-based policies.
