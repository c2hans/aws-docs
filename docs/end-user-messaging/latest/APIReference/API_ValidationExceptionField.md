# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

Describes a field in the request that failed to satisfy the modeled constraints of the service.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="endusermessaging-Type-ValidationExceptionField-message"></a>
A detailed description of the validation failure.
Type: String
Required: Yes

 ** path **   <a name="endusermessaging-Type-ValidationExceptionField-path"></a>
A JSONPointer expression to the structure member whose value failed to satisfy the modeled constraints.
Type: String
Required: Yes
