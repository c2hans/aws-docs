# NewAsoDetail
<a name="API_NewAsoDetail"></a>

Details new Autonomous System Organizations (ASOs) used either at the resource or account level.

## Contents
<a name="API_NewAsoDetail_Contents"></a>

 ** Aso **   <a name="detective-Type-NewAsoDetail-Aso"></a>
Details about the new Autonomous System Organization (ASO).
Type: String
Required: No

 ** IsNewForEntireAccount **   <a name="detective-Type-NewAsoDetail-IsNewForEntireAccount"></a>
Checks if the Autonomous System Organization (ASO) is new for the entire account.
Type: Boolean
Required: No
