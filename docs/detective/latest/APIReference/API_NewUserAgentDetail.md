# NewUserAgentDetail
<a name="API_NewUserAgentDetail"></a>

Details new user agents used either at the resource or account level.

## Contents
<a name="API_NewUserAgentDetail_Contents"></a>

 ** IsNewForEntireAccount **   <a name="detective-Type-NewUserAgentDetail-IsNewForEntireAccount"></a>
Checks if the user agent is new for the entire account.
Type: Boolean
Required: No

 ** UserAgent **   <a name="detective-Type-NewUserAgentDetail-UserAgent"></a>
New user agent which accessed the resource.
Type: String
Required: No
