# TimestampForCollection
<a name="API_TimestampForCollection"></a>

Details on when data collection began for a source package.

## Contents
<a name="API_TimestampForCollection_Contents"></a>

 ** Timestamp **   <a name="detective-Type-TimestampForCollection-Timestamp"></a>
The data and time when data collection began for a source package. The value is an ISO8601 formatted string. For example, `2021-08-18T16:35:56.284Z`.
Type: Timestamp
Required: No
