# SortCriteria
<a name="API_SortCriteria"></a>

Details about the criteria used for sorting investigations.

## Contents
<a name="API_SortCriteria_Contents"></a>

 ** Field **   <a name="detective-Type-SortCriteria-Field"></a>
Represents the `Field` attribute to sort investigations.
Type: String
Valid Values: `SEVERITY | STATUS | CREATED_TIME`
Required: No

 ** SortOrder **   <a name="detective-Type-SortCriteria-SortOrder"></a>
The order by which the sorted findings are displayed.
Type: String
Valid Values: `ASC | DESC`
Required: No
