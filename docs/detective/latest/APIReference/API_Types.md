# Data Types
<a name="API_Types"></a>

The Amazon Detective API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

+  [Graph](API_Graph.md)
+  [ImpossibleTravelDetail](API_ImpossibleTravelDetail.md)

+  [NewAsoDetail](API_NewAsoDetail.md)
+  [NewGeolocationDetail](API_NewGeolocationDetail.md)
+  [NewUserAgentDetail](API_NewUserAgentDetail.md)
+  [RelatedFindingDetail](API_RelatedFindingDetail.md)
