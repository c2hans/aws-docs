# Data Types
<a name="API_Types"></a>

The Amazon Detective API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Account](API_Account.md)
+  [Administrator](API_Administrator.md)
+  [DatasourcePackageIngestDetail](API_DatasourcePackageIngestDetail.md)
+  [DatasourcePackageUsageInfo](API_DatasourcePackageUsageInfo.md)
+  [DateFilter](API_DateFilter.md)
+  [FilterCriteria](API_FilterCriteria.md)
+  [FlaggedIpAddressDetail](API_FlaggedIpAddressDetail.md)
+  [Graph](API_Graph.md)
+  [ImpossibleTravelDetail](API_ImpossibleTravelDetail.md)
+  [Indicator](API_Indicator.md)
+  [IndicatorDetail](API_IndicatorDetail.md)
+  [InvestigationDetail](API_InvestigationDetail.md)
+  [MemberDetail](API_MemberDetail.md)
+  [MembershipDatasources](API_MembershipDatasources.md)
+  [NewAsoDetail](API_NewAsoDetail.md)
+  [NewGeolocationDetail](API_NewGeolocationDetail.md)
+  [NewUserAgentDetail](API_NewUserAgentDetail.md)
+  [RelatedFindingDetail](API_RelatedFindingDetail.md)
+  [RelatedFindingGroupDetail](API_RelatedFindingGroupDetail.md)
+  [SortCriteria](API_SortCriteria.md)
+  [StringFilter](API_StringFilter.md)
+  [TimestampForCollection](API_TimestampForCollection.md)
+  [TTPsObservedDetail](API_TTPsObservedDetail.md)
+  [UnprocessedAccount](API_UnprocessedAccount.md)
+  [UnprocessedGraph](API_UnprocessedGraph.md)
