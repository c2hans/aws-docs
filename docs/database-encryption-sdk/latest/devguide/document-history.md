# Document history for the AWS Database Encryption SDK Developer Guide
<a name="document-history"></a>

The following table describes significant changes to this documentation. In addition to these major changes, we also update the documentation frequently to improve the descriptions and examples, and to address the feedback that you send to us. To be notified about significant changes, subscribe to the RSS feed.

| Change | Description | Date |
| --- |--- |--- |
| [General Availability (GA) release](https://docs.aws.amazon.com/database-encryption-sdk/latest/devguide/ddb-java.html) | Introducing 4.x version of Java client-side encryption library for DynamoDB which replaces AWS SDK for Java 1.x with AWS SDK for Java 2.x in the embedded Java client-side encryption library for DynamoDB version 2.x code. | March 26, 2026 |
| [New feature](https://docs.aws.amazon.com/database-encryption-sdk/latest/devguide/use-kms-ecdh-keyring.html) | Added documentation for the [AWS KMS ECDH keyring](https://docs.aws.amazon.com/database-encryption-sdk/latest/devguide/use-kms-ecdh-keyring.html) and [Raw ECDH keyring](https://docs.aws.amazon.com/database-encryption-sdk/latest/devguide/use-raw-ecdh-keyring.html). | June 17, 2024 |
| [General Availability (GA) release](https://docs.aws.amazon.com/database-encryption-sdk/latest/devguide/ddb-net.html) | Introducing support for the .NET client-side encryption library for DynamoDB. | January 17, 2024 |
| [General Availability (GA) release](https://docs.aws.amazon.com/database-encryption-sdk/latest/devguide/ddb-java.html) | Updated documentation for the GA release of version 3.*x* of the Java client-side encryption library for DynamoDB. Branch keys created during the developer preview release are no longer supported.  | July 24, 2023 |
| [Rebrand of DynamoDB Encryption Client](https://docs.aws.amazon.com/database-encryption-sdk/latest/devguide/DDBEC-rename.html) | The client-side encryption library is renamed to AWS Database Encryption SDK. | June 9, 2023 |
| [Preview release](https://docs.aws.amazon.com/database-encryption-sdk/latest/devguide/DDBEC-rename.html) | Added and updated documentation for version 3.*x* of the Java client-side encryption library for DynamoDB, which includes a new structured data format, improved multitenancy support, seamless schema changes, and searchable encryption support. | June 9, 2023 |
| [Documentation change](https://docs.aws.amazon.com/dynamodb-encryption-client/latest/devguide/direct-kms-provider.html) | Replace the AWS Key Management Service term *customer master key (CMK)* with *AWS KMS key* and *KMS key*. | August 30, 2021 |
| [New feature](https://docs.aws.amazon.com/dynamodb-encryption-client/latest/devguide/direct-kms-provider.html#provider-kms-how-to-use) | Added support for AWS Key Management Service (AWS KMS) multi-Region keys. Multi-Region keys are AWS KMS keys in different AWS Regions that can be used interchangeably because they have the same key ID and key material. | June 8, 2021 |
| [New example](https://docs.aws.amazon.com/dynamodb-encryption-client/latest/devguide/java-examples.html#java-example-dynamodb-mapper) | Added example of using the DynamoDBMapper in Java. | September 6, 2018 |
| [Python support](https://docs.aws.amazon.com/dynamodb-encryption-client/latest/devguide/python.html) | Added support for Python, in addition to Java. | May 2, 2018 |
| [Initial release](https://docs.aws.amazon.com/dynamodb-encryption-client/latest/devguide/) | Initial release of this documentation. | May 2, 2018 |
