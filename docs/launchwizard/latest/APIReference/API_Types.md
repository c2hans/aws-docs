# Data Types
<a name="API_Types"></a>

The AWS Launch Wizard API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [DeploymentConditionalField](API_DeploymentConditionalField.md)
+  [DeploymentData](API_DeploymentData.md)
+  [DeploymentDataSummary](API_DeploymentDataSummary.md)
+  [DeploymentEventDataSummary](API_DeploymentEventDataSummary.md)
+  [DeploymentFilter](API_DeploymentFilter.md)
+  [DeploymentPatternVersionDataSummary](API_DeploymentPatternVersionDataSummary.md)
+  [DeploymentPatternVersionFilter](API_DeploymentPatternVersionFilter.md)
+  [DeploymentSpecificationsField](API_DeploymentSpecificationsField.md)
+  [WorkloadData](API_WorkloadData.md)
+  [WorkloadDataSummary](API_WorkloadDataSummary.md)
+  [WorkloadDeploymentPatternData](API_WorkloadDeploymentPatternData.md)
+  [WorkloadDeploymentPatternDataSummary](API_WorkloadDeploymentPatternDataSummary.md)
