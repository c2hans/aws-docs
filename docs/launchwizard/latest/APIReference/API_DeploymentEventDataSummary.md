# DeploymentEventDataSummary
<a name="API_DeploymentEventDataSummary"></a>

A summary of the deployment event data.

## Contents
<a name="API_DeploymentEventDataSummary_Contents"></a>

 ** description **   <a name="launchwizard-Type-DeploymentEventDataSummary-description"></a>
The description of the deployment event.
Type: String
Required: No

 ** name **   <a name="launchwizard-Type-DeploymentEventDataSummary-name"></a>
The name of the deployment event.
Type: String
Required: No

 ** status **   <a name="launchwizard-Type-DeploymentEventDataSummary-status"></a>
The status of the deployment event.
Type: String
Valid Values: `CANCELED | CANCELING | COMPLETED | CREATED | FAILED | IN_PROGRESS | PENDING | TIMED_OUT`
Required: No

 ** statusReason **   <a name="launchwizard-Type-DeploymentEventDataSummary-statusReason"></a>
The reason of the deployment event status.
Type: String
Required: No

 ** timestamp **   <a name="launchwizard-Type-DeploymentEventDataSummary-timestamp"></a>
The timestamp of the deployment event.
Type: Timestamp
Required: No
