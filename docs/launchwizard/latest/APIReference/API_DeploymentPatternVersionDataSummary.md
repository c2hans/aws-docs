# DeploymentPatternVersionDataSummary
<a name="API_DeploymentPatternVersionDataSummary"></a>

Describes a deployment pattern version summary.

## Contents
<a name="API_DeploymentPatternVersionDataSummary_Contents"></a>

 ** deploymentPatternName **   <a name="launchwizard-Type-DeploymentPatternVersionDataSummary-deploymentPatternName"></a>
The name of the deployment pattern.
Type: String
Required: No

 ** deploymentPatternVersionName **   <a name="launchwizard-Type-DeploymentPatternVersionDataSummary-deploymentPatternVersionName"></a>
The name of the deployment pattern version.
Type: String
Required: No

 ** description **   <a name="launchwizard-Type-DeploymentPatternVersionDataSummary-description"></a>
The description of the deployment pattern version.
Type: String
Required: No

 ** documentationUrl **   <a name="launchwizard-Type-DeploymentPatternVersionDataSummary-documentationUrl"></a>
The URL of the documentation for the deployment pattern version.
Type: String
Required: No

 ** workloadName **   <a name="launchwizard-Type-DeploymentPatternVersionDataSummary-workloadName"></a>
The name of the workload.
Type: String
Required: No
