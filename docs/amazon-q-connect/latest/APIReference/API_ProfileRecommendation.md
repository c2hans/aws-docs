# ProfileRecommendation

Contains information about a recommendation that is associated with a customer profile, including the relevance score and the associated catalog item.

## Contents
<a name="API_amazon-q-connect_ProfileRecommendation_Contents"></a>

 ** catalogItem **   <a name="connect-Type-amazon-q-connect_ProfileRecommendation-catalogItem"></a>
The catalog item that is associated with the recommendation.
Type: [ProfileCatalogItem](API_amazon-q-connect_ProfileCatalogItem.md) object
Required: No

 ** score **   <a name="connect-Type-amazon-q-connect_ProfileRecommendation-score"></a>
The relevance score of the recommendation.
Type: Double
Valid Range: Minimum value of 0.0.
Required: No
