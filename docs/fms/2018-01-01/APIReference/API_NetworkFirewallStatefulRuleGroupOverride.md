# NetworkFirewallStatefulRuleGroupOverride
<a name="API_NetworkFirewallStatefulRuleGroupOverride"></a>

The setting that allows the policy owner to change the behavior of the rule group within a policy.

## Contents
<a name="API_NetworkFirewallStatefulRuleGroupOverride_Contents"></a>

 ** Action **   <a name="fms-Type-NetworkFirewallStatefulRuleGroupOverride-Action"></a>
The action that changes the rule group from `DROP` to `ALERT`. This only applies to managed rule groups.
Type: String
Valid Values: `DROP_TO_ALERT`
Required: No
