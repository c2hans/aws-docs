# Amazon WorkSpaces Core Documentation

WorkSpaces Core offers managed virtual desktop infrastructure (VDI) designed to work with third-party management solutions. It simplifies VDI migration by combining your existing VDI management software with the security and reliability of AWS Cloud infrastructure.

- [Administration Guide](/workspaces-core/latest/ag/): Provides links to partner guides for administrators who are using a partner solution built on WorkSpaces Core.
- [Technology Partner Integration Guide](/workspaces-core/latest/pg/): Describes key concepts and provides setup instructions for partners who want to build their own solution using WorkSpaces Core.
- [WorkSpaces API Reference](/workspaces/latest/api/workspaces_core.html): Describes the API operations for WorkSpaces Core. WorkSpaces Core uses API operations from the Amazon WorkSpaces service.
- [WorkSpaces Instances API Reference](/workspaces-instances/latest/api/): Describes the API operations for WorkSpaces Core Instances. WorkSpaces Core Instances uses API operations from the Amazon WorkSpaces Instances service.
