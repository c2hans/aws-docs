# ListNamedQueriesInput
<a name="API_ListNamedQueriesInput"></a>

## Contents
<a name="API_ListNamedQueriesInput_Contents"></a>

 ** MaxResults **   <a name="athena-Type-ListNamedQueriesInput-MaxResults"></a>
The maximum number of queries to return in this request.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 50.
Required: No

 ** NextToken **   <a name="athena-Type-ListNamedQueriesInput-NextToken"></a>
A token generated by the Athena service that specifies where to continue pagination if a previous request was truncated. To obtain the next set of pages, pass in the `NextToken` from the response object of the previous page call.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No

 ** WorkGroup **   <a name="athena-Type-ListNamedQueriesInput-WorkGroup"></a>
The name of the workgroup from which the named queries are being returned. If a workgroup is not specified, the saved queries for the primary workgroup are returned.
Type: String
Pattern: `[a-zA-Z0-9._-]{1,128}`
Required: No
