# ResultReuseConfiguration
<a name="API_ResultReuseConfiguration"></a>

Specifies the query result reuse behavior for the query.

## Contents
<a name="API_ResultReuseConfiguration_Contents"></a>

 ** ResultReuseByAgeConfiguration **   <a name="athena-Type-ResultReuseConfiguration-ResultReuseByAgeConfiguration"></a>
Specifies whether previous query results are reused, and if so, their maximum age.
Type: [ResultReuseByAgeConfiguration](API_ResultReuseByAgeConfiguration.md) object
Required: No
