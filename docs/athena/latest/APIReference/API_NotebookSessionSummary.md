# NotebookSessionSummary
<a name="API_NotebookSessionSummary"></a>

Contains the notebook session ID and notebook session creation time.

## Contents
<a name="API_NotebookSessionSummary_Contents"></a>

 ** CreationTime **   <a name="athena-Type-NotebookSessionSummary-CreationTime"></a>
The time when the notebook session was created.
Type: Timestamp
Required: No

 ** SessionId **   <a name="athena-Type-NotebookSessionSummary-SessionId"></a>
The notebook session ID.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
