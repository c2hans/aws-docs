# ListNamedQueries
<a name="API_ListNamedQueries"></a>

Provides a list of available query IDs only for queries saved in the specified workgroup. Requires that you have access to the specified workgroup. If a workgroup is not specified, lists the saved queries for the primary workgroup.

## Request Syntax
<a name="API_ListNamedQueries_RequestSyntax"></a>

```
{
   "MaxResults": {{number}},
   "NextToken": "{{string}}",
   "WorkGroup": "{{string}}"
}
```

## Request Parameters
<a name="API_ListNamedQueries_RequestParameters"></a>

For information about the parameters that are common to all actions, see [Common Parameters](CommonParameters.md).

The request accepts the following data in JSON format.

 ** [MaxResults](#API_ListNamedQueries_RequestSyntax) **   <a name="athena-ListNamedQueries-request-MaxResults"></a>
The maximum number of queries to return in this request.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 50.
Required: No

 ** [NextToken](#API_ListNamedQueries_RequestSyntax) **   <a name="athena-ListNamedQueries-request-NextToken"></a>
A token generated by the Athena service that specifies where to continue pagination if a previous request was truncated. To obtain the next set of pages, pass in the `NextToken` from the response object of the previous page call.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No

 ** [WorkGroup](#API_ListNamedQueries_RequestSyntax) **   <a name="athena-ListNamedQueries-request-WorkGroup"></a>
The name of the workgroup from which the named queries are being returned. If a workgroup is not specified, the saved queries for the primary workgroup are returned.
Type: String
Pattern: `[a-zA-Z0-9._-]{1,128}`
Required: No

## Response Syntax
<a name="API_ListNamedQueries_ResponseSyntax"></a>

```
{
   "NamedQueryIds": [ "string" ],
   "NextToken": "string"
}
```

## Response Elements
<a name="API_ListNamedQueries_ResponseElements"></a>

If the action is successful, the service sends back an HTTP 200 response.

The following data is returned in JSON format by the service.

 ** [NamedQueryIds](#API_ListNamedQueries_ResponseSyntax) **   <a name="athena-ListNamedQueries-response-NamedQueryIds"></a>
The list of unique query IDs.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 50 items.
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `\S+`

 ** [NextToken](#API_ListNamedQueries_ResponseSyntax) **   <a name="athena-ListNamedQueries-response-NextToken"></a>
A token generated by the Athena service that specifies where to continue pagination if a previous request was truncated. To obtain the next set of pages, pass in the `NextToken` from the response object of the previous page call.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
