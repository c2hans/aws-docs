# Row
<a name="API_Row"></a>

The rows that make up a query result table.

<a name="API_Row_Contents"></a>

 ** Data **   <a name="athena-Type-Row-Data"></a>

Type: Array of [Datum](API_Datum.md) objects
Required: No
