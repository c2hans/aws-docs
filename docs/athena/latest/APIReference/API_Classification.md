# Classification
<a name="API_Classification"></a>

A classification refers to a set of specific configurations.

## Contents
<a name="API_Classification_Contents"></a>

 ** Name **   <a name="athena-Type-Classification-Name"></a>
The name of the configuration classification.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: No

 ** Properties **   <a name="athena-Type-Classification-Properties"></a>
A set of properties specified within a configuration classification.
Type: String to string map
Key Length Constraints: Minimum length of 1. Maximum length of 255.
Key Pattern: `[\u0020-\uD7FF\uE000-\uFFFD\uD800\uDC00-\uDBFF\uDFFF\t]*`
Value Length Constraints: Maximum length of 51200.
Required: No
