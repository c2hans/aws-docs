# ListEngineVersions
<a name="API_ListEngineVersions"></a>

Returns a list of engine versions that are available to choose from, including the Auto option.

## Request Syntax
<a name="API_ListEngineVersions_RequestSyntax"></a>

```
{
   "MaxResults": {{number}},
   "NextToken": "{{string}}"
}
```

## Request Parameters
<a name="API_ListEngineVersions_RequestParameters"></a>

For information about the parameters that are common to all actions, see [Common Parameters](CommonParameters.md).

The request accepts the following data in JSON format.

 ** [MaxResults](#API_ListEngineVersions_RequestSyntax) **   <a name="athena-ListEngineVersions-request-MaxResults"></a>
The maximum number of engine versions to return in this request.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 10.
Required: No

 ** [NextToken](#API_ListEngineVersions_RequestSyntax) **   <a name="athena-ListEngineVersions-request-NextToken"></a>
A token generated by the Athena service that specifies where to continue pagination if a previous request was truncated. To obtain the next set of pages, pass in the `NextToken` from the response object of the previous page call.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No

## Response Syntax
<a name="API_ListEngineVersions_ResponseSyntax"></a>

```
{
   "EngineVersions": [
      {
         "EffectiveEngineVersion": "string",
         "SelectedEngineVersion": "string"
      }
   ],
   "NextToken": "string"
}
```

## Response Elements
<a name="API_ListEngineVersions_ResponseElements"></a>

If the action is successful, the service sends back an HTTP 200 response.

The following data is returned in JSON format by the service.

 ** [EngineVersions](#API_ListEngineVersions_ResponseSyntax) **   <a name="athena-ListEngineVersions-response-EngineVersions"></a>
A list of engine versions that are available to choose from.
Type: Array of [EngineVersion](API_EngineVersion.md) objects
Array Members: Minimum number of 0 items. Maximum number of 10 items.

 ** [NextToken](#API_ListEngineVersions_ResponseSyntax) **   <a name="athena-ListEngineVersions-response-NextToken"></a>
A token generated by the Athena service that specifies where to continue pagination if a previous request was truncated. To obtain the next set of pages, pass in the `NextToken` from the response object of the previous page call.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
