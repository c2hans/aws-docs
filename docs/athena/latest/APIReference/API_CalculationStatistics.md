# CalculationStatistics
<a name="API_CalculationStatistics"></a>

Contains statistics for a notebook calculation.

## Contents
<a name="API_CalculationStatistics_Contents"></a>

 ** DpuExecutionInMillis **   <a name="athena-Type-CalculationStatistics-DpuExecutionInMillis"></a>
The data processing unit execution time in milliseconds for the calculation.
Type: Long
Required: No

 ** Progress **   <a name="athena-Type-CalculationStatistics-Progress"></a>
The progress of the calculation.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No
