# ListNotebookMetadata
<a name="API_ListNotebookMetadata"></a>

Displays the notebook files for the specified workgroup in paginated format.

## Request Syntax
<a name="API_ListNotebookMetadata_RequestSyntax"></a>

```
{
   "Filters": {
      "Name": "{{string}}"
   },
   "MaxResults": {{number}},
   "NextToken": "{{string}}",
   "WorkGroup": "{{string}}"
}
```

## Request Parameters
<a name="API_ListNotebookMetadata_RequestParameters"></a>

For information about the parameters that are common to all actions, see [Common Parameters](CommonParameters.md).

The request accepts the following data in JSON format.

 ** [Filters](#API_ListNotebookMetadata_RequestSyntax) **   <a name="athena-ListNotebookMetadata-request-Filters"></a>
Search filter string.
Type: [FilterDefinition](API_FilterDefinition.md) object
Required: No

 ** [MaxResults](#API_ListNotebookMetadata_RequestSyntax) **   <a name="athena-ListNotebookMetadata-request-MaxResults"></a>
Specifies the maximum number of results to return.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 50.
Required: No

 ** [NextToken](#API_ListNotebookMetadata_RequestSyntax) **   <a name="athena-ListNotebookMetadata-request-NextToken"></a>
A token generated by the Athena service that specifies where to continue pagination if a previous request was truncated.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No

 ** [WorkGroup](#API_ListNotebookMetadata_RequestSyntax) **   <a name="athena-ListNotebookMetadata-request-WorkGroup"></a>
The name of the Spark enabled workgroup to retrieve notebook metadata for.
Type: String
Pattern: `[a-zA-Z0-9._-]{1,128}`
Required: Yes

## Response Syntax
<a name="API_ListNotebookMetadata_ResponseSyntax"></a>

```
{
   "NextToken": "string",
   "NotebookMetadataList": [
      {
         "CreationTime": number,
         "LastModifiedTime": number,
         "Name": "string",
         "NotebookId": "string",
         "Type": "string",
         "WorkGroup": "string"
      }
   ]
}
```

## Response Elements
<a name="API_ListNotebookMetadata_ResponseElements"></a>

If the action is successful, the service sends back an HTTP 200 response.

The following data is returned in JSON format by the service.

 ** [NextToken](#API_ListNotebookMetadata_ResponseSyntax) **   <a name="athena-ListNotebookMetadata-response-NextToken"></a>
A token generated by the Athena service that specifies where to continue pagination if a previous request was truncated. To obtain the next set of pages, pass in the `NextToken` from the response object of the previous page call.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.

 ** [NotebookMetadataList](#API_ListNotebookMetadata_ResponseSyntax) **   <a name="athena-ListNotebookMetadata-response-NotebookMetadataList"></a>
The list of notebook metadata for the specified workgroup.
Type: Array of [NotebookMetadata](API_NotebookMetadata.md) objects
