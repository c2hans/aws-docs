# Characters
<a name="API_Characters"></a>

 The number of characters in the input text to be analyzed.

## Contents
<a name="API_Characters_Contents"></a>

 ** OriginalTextCharacters **   <a name="comprehendmedical-Type-Characters-OriginalTextCharacters"></a>
 The number of characters present in the input text document as processed by Comprehend Medical.
Type: Integer
Required: No
