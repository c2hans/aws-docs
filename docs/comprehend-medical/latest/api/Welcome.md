# Welcome
<a name="Welcome"></a>

This is the *Amazon Comprehend Medical API Reference*. Amazon Comprehend Medical extracts structured information from unstructured clinical text. For an introduction to the service, see the [*Amazon Comprehend Medical Developer Guide*](https://docs.aws.amazon.com/comprehend-medical/latest/dev/comprehendmedical-welcome.html).

This document was last published on August 28, 2026.
