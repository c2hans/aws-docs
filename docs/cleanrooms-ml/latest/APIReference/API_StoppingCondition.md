# StoppingCondition
<a name="API_StoppingCondition"></a>

The criteria used to stop model training.

## Contents
<a name="API_StoppingCondition_Contents"></a>

 ** maxRuntimeInSeconds **   <a name="API-Type-StoppingCondition-maxRuntimeInSeconds"></a>
The maximum amount of time, in seconds, that model training can run before it is terminated.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 2419200.
Required: No
