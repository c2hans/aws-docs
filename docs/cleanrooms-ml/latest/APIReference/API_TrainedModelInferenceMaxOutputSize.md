# TrainedModelInferenceMaxOutputSize
<a name="API_TrainedModelInferenceMaxOutputSize"></a>

Information about the maximum output size for a trained model inference job.

## Contents
<a name="API_TrainedModelInferenceMaxOutputSize_Contents"></a>

 ** unit **   <a name="API-Type-TrainedModelInferenceMaxOutputSize-unit"></a>
The measurement unit to use.
Type: String
Valid Values: `GB`
Required: Yes

 ** value **   <a name="API-Type-TrainedModelInferenceMaxOutputSize-value"></a>
The maximum output size value.
Type: Double
Valid Range: Minimum value of 0.01. Maximum value of 100.0.
Required: Yes
