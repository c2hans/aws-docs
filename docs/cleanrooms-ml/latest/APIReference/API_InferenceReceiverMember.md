# InferenceReceiverMember
<a name="API_InferenceReceiverMember"></a>

Defines who will receive inference results.

## Contents
<a name="API_InferenceReceiverMember_Contents"></a>

 ** accountId **   <a name="API-Type-InferenceReceiverMember-accountId"></a>
The account ID of the member that can receive inference results.
Type: String
Length Constraints: Fixed length of 12.
Pattern: `[0-9]{12}`
Required: Yes
