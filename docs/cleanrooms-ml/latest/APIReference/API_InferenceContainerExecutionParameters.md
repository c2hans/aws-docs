# InferenceContainerExecutionParameters
<a name="API_InferenceContainerExecutionParameters"></a>

Provides execution parameters for the inference container.

## Contents
<a name="API_InferenceContainerExecutionParameters_Contents"></a>

 ** maxPayloadInMB **   <a name="API-Type-InferenceContainerExecutionParameters-maxPayloadInMB"></a>
The maximum size of the inference container payload, specified in MB.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 100.
Required: No
