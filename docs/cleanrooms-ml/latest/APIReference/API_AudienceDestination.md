# AudienceDestination
<a name="API_AudienceDestination"></a>

Defines the Amazon S3 bucket where the configured audience is stored.

## Contents
<a name="API_AudienceDestination_Contents"></a>

 ** s3Destination **   <a name="API-Type-AudienceDestination-s3Destination"></a>
The Amazon S3 bucket and path for the configured audience.
Type: [S3ConfigMap](API_S3ConfigMap.md) object
Required: Yes
