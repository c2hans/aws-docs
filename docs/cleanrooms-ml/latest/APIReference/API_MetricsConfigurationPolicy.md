# MetricsConfigurationPolicy
<a name="API_MetricsConfigurationPolicy"></a>

Provides the configuration policy for metrics generation.

## Contents
<a name="API_MetricsConfigurationPolicy_Contents"></a>

 ** noiseLevel **   <a name="API-Type-MetricsConfigurationPolicy-noiseLevel"></a>
The noise level for the generated metrics.
Type: String
Valid Values: `HIGH | MEDIUM | LOW | NONE`
Required: Yes
