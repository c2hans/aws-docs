# S3ConfigMap
<a name="API_S3ConfigMap"></a>

Provides information about an Amazon S3 bucket and path.

## Contents
<a name="API_S3ConfigMap_Contents"></a>

 ** s3Uri **   <a name="API-Type-S3ConfigMap-s3Uri"></a>
The Amazon S3 location URI.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1285.
Pattern: `s3://.+`
Required: Yes
