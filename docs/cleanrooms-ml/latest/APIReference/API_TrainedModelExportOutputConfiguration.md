# TrainedModelExportOutputConfiguration
<a name="API_TrainedModelExportOutputConfiguration"></a>

Information about the output of the trained model export job.

## Contents
<a name="API_TrainedModelExportOutputConfiguration_Contents"></a>

 ** members **   <a name="API-Type-TrainedModelExportOutputConfiguration-members"></a>
The members that will received the exported trained model output.
Type: Array of [TrainedModelExportReceiverMember](API_TrainedModelExportReceiverMember.md) objects
Array Members: Fixed number of 1 item.
Required: Yes
