# Data Types
<a name="API_Types"></a>

The AWS Systems Manager GUI Connect API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [ConnectionRecordingPreferences](API_ConnectionRecordingPreferences.md)
+  [RecordingDestinations](API_RecordingDestinations.md)
+  [S3Bucket](API_S3Bucket.md)
