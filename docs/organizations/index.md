# AWS Organizations and AWS Account Management Documentation

With AWS Organizations, you can centrally manage your environment as you scale your AWS resources. With AWS Account Management you create and manage individual AWS accounts.

## AWS Organizations

- [User Guide](/organizations/latest/userguide/orgs_introduction.html): Introduces you to AWS Organizations, which helps you set up an organization by creating accounts or inviting other accounts to join. It shows you how to manage your accounts as a group and provide organization-wide access control to your AWS resources by using policy-based controls.
- [API Reference](/organizations/latest/APIReference/Welcome.html): Describes all the API operations for AWS Organizations in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
- [AWS Organizations section of AWS CLI Reference](/cli/latest/reference/organizations/): Describes the AWS CLI commands that you can use to administer AWS Organizations. Provides syntax, options, and usage examples for each command.

## AWS Account Management

- [AWS Account Management Reference Guide](/accounts/latest/reference/accounts-welcome.html): Introduces you to creating and managing your individual AWS accounts. It includes detailed descriptions of the API operations, including sample requests, responses, and errors for the supported web services protocols.
- [API Reference](/accounts/latest/APIReference/API_Operations.html): Describes all the API operations for AWS Account Management in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
- [AWS Account Management section of AWS CLI Reference](/cli/latest/reference/account/): Describes the AWS CLI commands that you can use to manage your AWS accounts. Provides syntax, options, and usage examples for each command.

## Multi-party approval

- [User Guide](/mpa/latest/userguide/what-is.html): Introduces you to Multi-party approval, which is a capability of AWS Organizations that allows you to protect a predefined list of operations through a distributed approval process.
- [API Reference](/mpa/latest/APIReference/Welcome.html): Describes all the API operations for Multi-party approval in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
- [Multi-party approval section of AWS CLI Reference](/cli/latest/reference/mpa/): Describes the AWS CLI commands that you can use to administer Multi-party approval. Provides syntax, options, and usage examples for each command.
