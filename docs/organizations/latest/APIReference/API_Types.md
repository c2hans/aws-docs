# Data Types
<a name="API_Types"></a>

The AWS Organizations API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Account](API_Account.md)
+  [Child](API_Child.md)
+  [CreateAccountStatus](API_CreateAccountStatus.md)
+  [DelegatedAdministrator](API_DelegatedAdministrator.md)
+  [DelegatedService](API_DelegatedService.md)
+  [EffectivePolicy](API_EffectivePolicy.md)
+  [EffectivePolicyValidationError](API_EffectivePolicyValidationError.md)
+  [EnabledServicePrincipal](API_EnabledServicePrincipal.md)
+  [Handshake](API_Handshake.md)
+  [HandshakeFilter](API_HandshakeFilter.md)
+  [HandshakeParty](API_HandshakeParty.md)
+  [HandshakeResource](API_HandshakeResource.md)
+  [Organization](API_Organization.md)
+  [OrganizationalUnit](API_OrganizationalUnit.md)
+  [Parent](API_Parent.md)
+  [Policy](API_Policy.md)
+  [PolicySummary](API_PolicySummary.md)
+  [PolicyTargetSummary](API_PolicyTargetSummary.md)
+  [PolicyTypeSummary](API_PolicyTypeSummary.md)
+  [ResourcePolicy](API_ResourcePolicy.md)
+  [ResourcePolicySummary](API_ResourcePolicySummary.md)
+  [ResponsibilityTransfer](API_ResponsibilityTransfer.md)
+  [Root](API_Root.md)
+  [Tag](API_Tag.md)
+  [TransferParticipant](API_TransferParticipant.md)
