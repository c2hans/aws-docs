# ResourcePolicy
<a name="API_ResourcePolicy"></a>

A structure that contains details about a resource policy.

## Contents
<a name="API_ResourcePolicy_Contents"></a>

 ** Content **   <a name="organizations-Type-ResourcePolicy-Content"></a>
The policy text of the resource policy.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 40000.
Pattern: `[\s\S]*`
Required: No

 ** ResourcePolicySummary **   <a name="organizations-Type-ResourcePolicy-ResourcePolicySummary"></a>
A structure that contains resource policy ID and Amazon Resource Name (ARN).
Type: [ResourcePolicySummary](API_ResourcePolicySummary.md) object
Required: No
