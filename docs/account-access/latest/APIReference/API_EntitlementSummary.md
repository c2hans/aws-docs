# EntitlementSummary
<a name="API_EntitlementSummary"></a>

Contains summary information about an entitlement.

## Contents
<a name="API_EntitlementSummary_Contents"></a>

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** principalRole **   <a name="accountaccess-Type-EntitlementSummary-principalRole"></a>
The principal-to-role mapping summary for the entitlement.
Type: [PrincipalRoleEntitlementSummary](API_PrincipalRoleEntitlementSummary.md) object
Required: No
