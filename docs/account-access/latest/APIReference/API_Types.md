# Data Types
<a name="API_Types"></a>

The Account Access API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [ApplicationSummary](API_ApplicationSummary.md)
+  [Entitlement](API_Entitlement.md)
+  [EntitlementDetails](API_EntitlementDetails.md)
+  [EntitlementFilter](API_EntitlementFilter.md)
+  [EntitlementsListMember](API_EntitlementsListMember.md)
+  [EntitlementSummary](API_EntitlementSummary.md)
+  [ErrorDetails](API_ErrorDetails.md)
+  [IdentityCenter](API_IdentityCenter.md)
+  [IdentityCenterDetails](API_IdentityCenterDetails.md)
+  [IdentityCenterPrincipal](API_IdentityCenterPrincipal.md)
+  [IdentityCenterPrincipalFilter](API_IdentityCenterPrincipalFilter.md)
+  [IdentitySource](API_IdentitySource.md)
+  [IdentitySourceDetails](API_IdentitySourceDetails.md)
+  [Principal](API_Principal.md)
+  [PrincipalFilter](API_PrincipalFilter.md)
+  [PrincipalRoleEntitlement](API_PrincipalRoleEntitlement.md)
+  [PrincipalRoleEntitlementDetails](API_PrincipalRoleEntitlementDetails.md)
+  [PrincipalRoleEntitlementFilter](API_PrincipalRoleEntitlementFilter.md)
+  [PrincipalRoleEntitlementSummary](API_PrincipalRoleEntitlementSummary.md)
