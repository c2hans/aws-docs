# AnswerMachineDetectionConfig
<a name="API_connect-outbound-campaigns_AnswerMachineDetectionConfig"></a>

Contains information about answering machine detection.

## Contents
<a name="API_connect-outbound-campaigns_AnswerMachineDetectionConfig_Contents"></a>

 ** enableAnswerMachineDetection **   <a name="connect-Type-connect-outbound-campaigns_AnswerMachineDetectionConfig-enableAnswerMachineDetection"></a>
Whether answering machine detection is enabled.
Type: Boolean
Required: Yes

 ** awaitAnswerMachinePrompt **   <a name="connect-Type-connect-outbound-campaigns_AnswerMachineDetectionConfig-awaitAnswerMachinePrompt"></a>
Whether waiting for answer machine prompt is enabled.
Type: Boolean
Required: No
