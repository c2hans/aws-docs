# UnprocessedCluster
<a name="API_UnprocessedCluster"></a>

A cluster whose updates have failed

## Contents
<a name="API_UnprocessedCluster_Contents"></a>

 ** ClusterName **   <a name="MemoryDB-Type-UnprocessedCluster-ClusterName"></a>
The name of the cluster
Type: String
Required: No

 ** ErrorMessage **   <a name="MemoryDB-Type-UnprocessedCluster-ErrorMessage"></a>
The error message associated with the update failure
Type: String
Required: No

 ** ErrorType **   <a name="MemoryDB-Type-UnprocessedCluster-ErrorType"></a>
The error type associated with the update failure
Type: String
Required: No
