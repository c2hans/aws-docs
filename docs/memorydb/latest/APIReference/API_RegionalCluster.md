# RegionalCluster
<a name="API_RegionalCluster"></a>

Represents a Regional cluster

## Contents
<a name="API_RegionalCluster_Contents"></a>

 ** ARN **   <a name="MemoryDB-Type-RegionalCluster-ARN"></a>
The Amazon Resource Name (ARN) the Regional cluster
Type: String
Required: No

 ** ClusterName **   <a name="MemoryDB-Type-RegionalCluster-ClusterName"></a>
The name of the Regional cluster
Type: String
Required: No

 ** Region **   <a name="MemoryDB-Type-RegionalCluster-Region"></a>
The Region the current Regional cluster is assigned to.
Type: String
Required: No

 ** Status **   <a name="MemoryDB-Type-RegionalCluster-Status"></a>
The status of the Regional cluster.
Type: String
Required: No
