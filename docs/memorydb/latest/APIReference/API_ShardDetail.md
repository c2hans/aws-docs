# ShardDetail
<a name="API_ShardDetail"></a>

Provides details of a shard in a snapshot

## Contents
<a name="API_ShardDetail_Contents"></a>

 ** Configuration **   <a name="MemoryDB-Type-ShardDetail-Configuration"></a>
The configuration details of the shard
Type: [ShardConfiguration](API_ShardConfiguration.md) object
Required: No

 ** Name **   <a name="MemoryDB-Type-ShardDetail-Name"></a>
The name of the shard
Type: String
Required: No

 ** Size **   <a name="MemoryDB-Type-ShardDetail-Size"></a>
The size of the shard's snapshot
Type: String
Required: No

 ** SnapshotCreationTime **   <a name="MemoryDB-Type-ShardDetail-SnapshotCreationTime"></a>
The date and time that the shard's snapshot was created
Type: Timestamp
Required: No
