# EngineVersionInfo
<a name="API_EngineVersionInfo"></a>

Provides details of the Redis OSS engine version

## Contents
<a name="API_EngineVersionInfo_Contents"></a>

 ** Engine **   <a name="MemoryDB-Type-EngineVersionInfo-Engine"></a>
The name of the engine for which version information is provided.
Type: String
Required: No

 ** EnginePatchVersion **   <a name="MemoryDB-Type-EngineVersionInfo-EnginePatchVersion"></a>
The patched engine version
Type: String
Required: No

 ** EngineVersion **   <a name="MemoryDB-Type-EngineVersionInfo-EngineVersion"></a>
The engine version
Type: String
Required: No

 ** ParameterGroupFamily **   <a name="MemoryDB-Type-EngineVersionInfo-ParameterGroupFamily"></a>
Specifies the name of the parameter group family to which the engine default parameters apply.
Type: String
Required: No
