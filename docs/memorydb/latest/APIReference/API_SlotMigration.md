# SlotMigration
<a name="API_SlotMigration"></a>

Represents the progress of an online resharding operation.

## Contents
<a name="API_SlotMigration_Contents"></a>

 ** ProgressPercentage **   <a name="MemoryDB-Type-SlotMigration-ProgressPercentage"></a>
The percentage of the slot migration that is complete.
Type: Double
Required: No
