# RecurringCharge
<a name="API_RecurringCharge"></a>

The recurring charge to run this reserved node.

## Contents
<a name="API_RecurringCharge_Contents"></a>

 ** RecurringChargeAmount **   <a name="MemoryDB-Type-RecurringCharge-RecurringChargeAmount"></a>
The amount of the recurring charge to run this reserved node.
Type: Double
Required: No

 ** RecurringChargeFrequency **   <a name="MemoryDB-Type-RecurringCharge-RecurringChargeFrequency"></a>
The frequency of the recurring price charged to run this reserved node.
Type: String
Required: No
