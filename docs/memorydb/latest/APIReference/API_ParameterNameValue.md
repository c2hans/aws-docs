# ParameterNameValue
<a name="API_ParameterNameValue"></a>

Describes a name-value pair that is used to update the value of a parameter.

## Contents
<a name="API_ParameterNameValue_Contents"></a>

 ** ParameterName **   <a name="MemoryDB-Type-ParameterNameValue-ParameterName"></a>
The name of the parameter
Type: String
Required: No

 ** ParameterValue **   <a name="MemoryDB-Type-ParameterNameValue-ParameterValue"></a>
The value of the parameter
Type: String
Required: No
