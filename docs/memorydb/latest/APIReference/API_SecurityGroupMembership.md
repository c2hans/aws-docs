# SecurityGroupMembership
<a name="API_SecurityGroupMembership"></a>

Represents a single security group and its status.

## Contents
<a name="API_SecurityGroupMembership_Contents"></a>

 ** SecurityGroupId **   <a name="MemoryDB-Type-SecurityGroupMembership-SecurityGroupId"></a>
The identifier of the security group.
Type: String
Required: No

 ** Status **   <a name="MemoryDB-Type-SecurityGroupMembership-Status"></a>
The status of the security group membership. The status changes whenever a security group is modified, or when the security groups assigned to a cluster are modified.
Type: String
Required: No
