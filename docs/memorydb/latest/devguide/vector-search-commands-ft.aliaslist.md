# FT.\_ALIASLIST
<a name="vector-search-commands-ft.aliaslist"></a>

List the index aliases.

**Syntax**

```
FT._ALIASLIST
```

**Return**

Returns an array the size of the number of current aliases. Each element of the array is the alias-index pair.
