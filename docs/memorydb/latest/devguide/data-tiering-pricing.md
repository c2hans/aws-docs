# Data tiering pricing
<a name="data-tiering-pricing"></a>

R6gd nodes have 5x more total capacity (memory \+ SSD) and can help you achieve over 60 percent storage cost savings when running at maximum utilization compared to R6g nodes (memory only). For more information, see [MemoryDB pricing](https://aws.amazon.com/memorydb/pricing/).
