# AWS Support Documentation

AWS Support provides support for users of Amazon Web Services.

## AWS Support

All users have access to account and billing help in the [AWS Support Center](https://console.aws.amazon.com/support/home#/). In addition, customers with certain support plans have access to additional features, including AWS Trusted Advisor and an API for programmatic access to support cases and Trusted Advisor.

- [User Guide](/awssupport/latest/user/): Describes the components and features that AWS Support provides and how to use them. Also shows you how to access AWS Support through a web-based GUI, command line tools, and the AWS Support API.
- [API Reference](/awssupport/latest/APIReference/): Describes all of the AWS Support and Trusted Advisor API operations. Also provides sample requests, responses, and errors for the supported web services protocols.
- [AWS Support in the AWS CLI Reference](/cli/latest/reference/support/index.html): Describes the AWS CLI commands that you can use to work with AWS Support.
- [AWS Support authorization API Reference](/supportauthz/latest/APIReference/): Describes all of the support authorization API operations.
- [AWS Support Knowledge Center](https://aws.amazon.com/premiumsupport/knowledge-center/): Provides answers to common questions from AWS customers.

## AWS Support App

You can use the AWS Support App to create, manage, and receive notifications about your support cases directly in Slack. You can also start live chat sessions with support agents and request service quota increases.

- [AWS Support App Documentation](/awssupport/latest/user/aws-support-app-for-slack.html): Describes the components and features that the AWS Support App provides and how to use them.
- [AWS Support App API Reference](/supportapp/latest/APIReference/): Describes all of the AWS Support App API operations. Also provides sample requests, responses, and errors for the supported web services protocols.

## AWS Trusted Advisor

Trusted Advisor inspects your AWS environment and recommends ways to save money, close security gaps, and improve system availability and performance.

- [Trusted Advisor](/awssupport/latest/user/trusted-advisor.html): Describes how you can use Trusted Advisor to optimize your AWS account and resources.
- [API Reference](/trustedadvisor/latest/APIReference/): Describes all of the Trusted Advisor API operations. Also provides sample requests, responses, and errors for the supported web services protocols.

## AWS Incident Detection and Response

AWS Incident Detection and Response offers AWS Enterprise Support customers proactive monitoring and incident management for their selected workloads.

- [User Guide](/IDR/latest/userguide/): Describes how to use AWS Incident Detection and Response. This includes an overview of the service and how to onboard, details on using the service, and information about proactive monitoring and incident management for your selected workloads.
