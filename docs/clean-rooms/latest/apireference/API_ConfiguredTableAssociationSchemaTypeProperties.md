# ConfiguredTableAssociationSchemaTypeProperties
<a name="API_ConfiguredTableAssociationSchemaTypeProperties"></a>

Contains the schema type properties for a configured table association.

## Contents
<a name="API_ConfiguredTableAssociationSchemaTypeProperties_Contents"></a>

 ** configuredTableAssociationId **   <a name="API-Type-ConfiguredTableAssociationSchemaTypeProperties-configuredTableAssociationId"></a>
The unique identifier of the configured table association.
Type: String
Length Constraints: Fixed length of 36.
Pattern: `[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}`
Required: Yes
