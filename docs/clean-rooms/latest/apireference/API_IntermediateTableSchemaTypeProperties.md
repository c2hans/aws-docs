# IntermediateTableSchemaTypeProperties
<a name="API_IntermediateTableSchemaTypeProperties"></a>

Contains the schema type properties for an intermediate table.

## Contents
<a name="API_IntermediateTableSchemaTypeProperties_Contents"></a>

 ** intermediateTableId **   <a name="API-Type-IntermediateTableSchemaTypeProperties-intermediateTableId"></a>
The unique identifier of the intermediate table.
Type: String
Length Constraints: Fixed length of 36.
Pattern: `[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}`
Required: Yes
