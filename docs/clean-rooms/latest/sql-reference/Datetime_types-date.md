# DATE
<a name="Datetime_types-date"></a>

Use the DATE data type to store simple calendar dates without timestamps.

| Name | Storage | Range | Resolution |
| --- | --- | --- | --- |
| DATE | 4 bytes | 4713 BC to 294276 AD | 1 day |
