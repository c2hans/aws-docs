# Getting Started with AWS

Whether you're new to AWS or already building on AWS, start here. Create your AWS account and set up your environment, choose the right AWS services for your use case, then follow step-by-step tutorials to get hands-on with services like Amazon S3, AWS Lambda, and Amazon Bedrock. Explore training, videos, and the community to grow your AWS skills.

## What are you trying to do?

- **Explore what AWS offers**: You're new to or evaluating AWS and want to understand the big picture and which services fit your needs. Start here before diving into specifics. [Overview of Amazon Web Services](/whitepapers/latest/aws-overview/introduction.html) [Explore AI on AWS](https://aws.amazon.com/ai/) [Choose the right AWS services for your use case](/decision-guides/)
- **Learn AWS fundamentals**: Whether you're new to AWS or leveling up, learn at your own pace through training, videos, and community. [Learn in-demand cloud and AI skills with online training](https://skillbuilder.aws/) [Explore AWS video playlists on YouTube](https://www.youtube.com/@amazonwebservices/featured) [Learn from the AWS re:Post community](https://repost.aws/)
- **Set up my account and environment**: Create your AWS account to get started. Once you're in the console, you'll be guided to set up the AWS CLI, Agent Toolkit for AWS, and your environment. [Compare sign-up options](/accounts/latest/reference/sign-up-for-aws.html) [Sign up for AWS (new)](/accounts/latest/reference/sign-in-new.html) [Sign up for AWS (advanced)](/accounts/latest/reference/getting-started.html)
- **Get started with an AWS service**: Your account is ready and you want to get something running. Follow a guided walkthrough to get started with an AWS service. [Run code without managing servers with AWS Lambda](/lambda/latest/dg/getting-started.html) [Store and retrieve files with Amazon S3](/AmazonS3/latest/userguide/GetStartedWithS3.html) [Make your first AI request with Amazon Bedrock](/bedrock/latest/userguide/getting-started.html)
