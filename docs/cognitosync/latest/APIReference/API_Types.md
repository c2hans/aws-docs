# Data Types
<a name="API_Types"></a>

The Amazon Cognito Sync API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [CognitoStreams](API_CognitoStreams.md)
+  [Dataset](API_Dataset.md)
+  [IdentityPoolUsage](API_IdentityPoolUsage.md)
+  [IdentityUsage](API_IdentityUsage.md)
+  [PushSync](API_PushSync.md)
+  [Record](API_Record.md)
+  [RecordPatch](API_RecordPatch.md)
