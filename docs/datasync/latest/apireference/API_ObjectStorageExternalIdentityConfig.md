# ObjectStorageExternalIdentityConfig
<a name="API_ObjectStorageExternalIdentityConfig"></a>

Specifies cloud-provider-specific external identity parameters used when exchanging the AWS web token for an OpenID Connect token at the object storage provider.

## Contents
<a name="API_ObjectStorageExternalIdentityConfig_Contents"></a>

 ** GoogleOidc **   <a name="DataSync-Type-ObjectStorageExternalIdentityConfig-GoogleOidc"></a>
External identity parameters for Google Cloud Storage.
Type: [GoogleOidcConfig](API_GoogleOidcConfig.md) object
Required: No
