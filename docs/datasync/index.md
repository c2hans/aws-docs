# AWS DataSync Documentation

AWS DataSync is an online data movement and discovery service that simplifies data migration and helps you quickly, easily, and securely transfer your file or object data to, from, and between AWS storage services.

- [AWS DataSync User Guide](/datasync/latest/userguide/): Describes AWS DataSync concepts and provides instructions on using the service's features with the DataSync console and AWS Command Line Interface.
- [AWS DataSync API Reference](/datasync/latest/apireference/): Describes the AWS DataSync API operations and data types that you can use to manage and configure the service with the AWS SDKs.
- [AWS DataSync in the AWS CLI Reference](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/datasync/index.html): Describes the AWS CLI commands that you can use with DataSync transfers and storage discovery.
