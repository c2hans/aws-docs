# SignatureValidityPeriod
<a name="API_SignatureValidityPeriod"></a>

The validity period for a signing job.

## Contents
<a name="API_SignatureValidityPeriod_Contents"></a>

 ** type **   <a name="signer-Type-SignatureValidityPeriod-type"></a>
The time unit for signature validity.
Type: String
Valid Values: `DAYS | MONTHS | YEARS`
Required: No

 ** value **   <a name="signer-Type-SignatureValidityPeriod-value"></a>
The numerical value of the time unit for signature validity.
Type: Integer
Required: No
