# PartitionField
<a name="API_PartitionField"></a>

Represents a single field in a `PartitionSpec`.

Amazon Data Firehose is in preview release and is subject to change.

## Contents
<a name="API_PartitionField_Contents"></a>

 ** SourceName **   <a name="Firehose-Type-PartitionField-SourceName"></a>
 The column name to be configured in partition spec.
Amazon Data Firehose is in preview release and is subject to change.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `^\S+$`
Required: Yes
