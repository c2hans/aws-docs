# TableCreationConfiguration
<a name="API_TableCreationConfiguration"></a>

The configuration to enable automatic table creation.

Amazon Data Firehose is in preview release and is subject to change.

## Contents
<a name="API_TableCreationConfiguration_Contents"></a>

 ** Enabled **   <a name="Firehose-Type-TableCreationConfiguration-Enabled"></a>
 Specify whether you want to enable automatic table creation.
Amazon Data Firehose is in preview release and is subject to change.
Type: Boolean
Required: Yes
