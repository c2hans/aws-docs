# ProcessingConfiguration
<a name="API_ProcessingConfiguration"></a>

Describes a data processing configuration.

## Contents
<a name="API_ProcessingConfiguration_Contents"></a>

 ** Enabled **   <a name="Firehose-Type-ProcessingConfiguration-Enabled"></a>
Enables or disables data processing.
Type: Boolean
Required: No

 ** Processors **   <a name="Firehose-Type-ProcessingConfiguration-Processors"></a>
The data processors.
Type: Array of [Processor](API_Processor.md) objects
Required: No
