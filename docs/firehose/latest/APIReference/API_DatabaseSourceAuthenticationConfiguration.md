# DatabaseSourceAuthenticationConfiguration
<a name="API_DatabaseSourceAuthenticationConfiguration"></a>

 The structure to configure the authentication methods for Firehose to connect to source database endpoint.

Amazon Data Firehose is in preview release and is subject to change.

## Contents
<a name="API_DatabaseSourceAuthenticationConfiguration_Contents"></a>

 ** SecretsManagerConfiguration **   <a name="Firehose-Type-DatabaseSourceAuthenticationConfiguration-SecretsManagerConfiguration"></a>
