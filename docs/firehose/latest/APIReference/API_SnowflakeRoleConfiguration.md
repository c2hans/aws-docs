# SnowflakeRoleConfiguration
<a name="API_SnowflakeRoleConfiguration"></a>

Optionally configure a Snowflake role. Otherwise the default user role will be used.

## Contents
<a name="API_SnowflakeRoleConfiguration_Contents"></a>

 ** Enabled **   <a name="Firehose-Type-SnowflakeRoleConfiguration-Enabled"></a>
Enable Snowflake role
Type: Boolean
Required: No

 ** SnowflakeRole **   <a name="Firehose-Type-SnowflakeRoleConfiguration-SnowflakeRole"></a>
The Snowflake role you wish to configure
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No
