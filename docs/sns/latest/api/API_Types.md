# Data Types
<a name="API_Types"></a>

The Amazon Simple Notification Service API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [BatchResultErrorEntry](API_BatchResultErrorEntry.md)
+  [Endpoint](API_Endpoint.md)
+  [MessageAttributeValue](API_MessageAttributeValue.md)
+  [PhoneNumberInformation](API_PhoneNumberInformation.md)
+  [PlatformApplication](API_PlatformApplication.md)
+  [PublishBatchRequestEntry](API_PublishBatchRequestEntry.md)
+  [PublishBatchResultEntry](API_PublishBatchResultEntry.md)
+  [SMSSandboxPhoneNumber](API_SMSSandboxPhoneNumber.md)
+  [Subscription](API_Subscription.md)
+  [Tag](API_Tag.md)
+  [Topic](API_Topic.md)
