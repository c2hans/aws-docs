# BatchCreateRelatedItemIdentifier
<a name="API_connect-cases_BatchCreateRelatedItemIdentifier"></a>

Identifies a case to associate the related item with in a `BatchCreateRelatedItem` request.

## Contents
<a name="API_connect-cases_BatchCreateRelatedItemIdentifier_Contents"></a>

 ** caseIdentifier **   <a name="connect-Type-connect-cases_BatchCreateRelatedItemIdentifier-caseIdentifier"></a>
The identifier of the case to associate the related item with. Specify either the case ID or the reference ID.
Type: [CaseIdentifierUnion](API_connect-cases_CaseIdentifierUnion.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes
