# FieldValueInput
<a name="API_connect-cases_FieldValueInput"></a>

## Contents
<a name="API_connect-cases_FieldValueInput_Contents"></a>

Type: [FieldIdentifierUnion](API_connect-cases_FieldIdentifierUnion.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes

 ** value **   <a name="connect-Type-connect-cases_FieldValueInput-value"></a>
The value to set for the field.
Type: [FieldValueUnion](API_connect-cases_FieldValueUnion.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes
