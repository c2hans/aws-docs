# SlaUpdateConfiguration

Represents the SLA configuration to update.

## Contents
<a name="API_connect-cases_SlaUpdateConfiguration_Contents"></a>

 ** targetSlaMinutes **   <a name="connect-Type-connect-cases_SlaUpdateConfiguration-targetSlaMinutes"></a>
New target duration in minutes within which an SLA should be completed. The new deadline is counted from when the SLA was created.
Type: Long
Valid Range: Minimum value of 1. Maximum value of 1051200.
Required: Yes
