# FileContent
<a name="API_connect-cases_FileContent"></a>

An object that represents a content of an Connect Customer file object.

## Contents
<a name="API_connect-cases_FileContent_Contents"></a>

 ** fileArn **   <a name="connect-Type-connect-cases_FileContent-fileArn"></a>
The Amazon Resource Name (ARN) of a File in Connect Customer.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 500.
Required: Yes
