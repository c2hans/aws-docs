# SignalConfidenceReasoning
<a name="API_SignalConfidenceReasoning"></a>

A producer's structured rationale for a signal's confidence.

## Contents
<a name="API_SignalConfidenceReasoning_Contents"></a>

 ** summary **   <a name="continuum-Type-SignalConfidenceReasoning-summary"></a>
The summary.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 8192.
Required: Yes

 ** factors **   <a name="continuum-Type-SignalConfidenceReasoning-factors"></a>
The factors.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 50 items.
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: No
