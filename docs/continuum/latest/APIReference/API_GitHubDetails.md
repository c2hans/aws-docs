# GitHubDetails
<a name="API_GitHubDetails"></a>

Details for a GitHub.com integration.

## Contents
<a name="API_GitHubDetails_Contents"></a>

 ** organizationName **   <a name="continuum-Type-GitHubDetails-organizationName"></a>
The organization Name.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 39.
Pattern: `[a-zA-Z0-9]([a-zA-Z0-9\-]*[a-zA-Z0-9])?`
Required: No
