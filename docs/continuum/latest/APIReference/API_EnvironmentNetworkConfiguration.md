# EnvironmentNetworkConfiguration
<a name="API_EnvironmentNetworkConfiguration"></a>

Network policy for agent execution.

## Contents
<a name="API_EnvironmentNetworkConfiguration_Contents"></a>

 ** allowedDomains **   <a name="continuum-Type-EnvironmentNetworkConfiguration-allowedDomains"></a>
The allowed Domains.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 50 items.
Length Constraints: Minimum length of 1. Maximum length of 253.
Pattern: `([a-zA-Z0-9]([a-zA-Z0-9\-]{0,61}[a-zA-Z0-9])?\.)+[a-zA-Z]{2,}`
Required: No
