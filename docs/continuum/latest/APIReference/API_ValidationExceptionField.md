# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

Describes a single field in the request that failed to satisfy the service constraints.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="continuum-Type-ValidationExceptionField-message"></a>
A message describing why the request field failed validation.
Type: String
Required: Yes

 ** path **   <a name="continuum-Type-ValidationExceptionField-path"></a>
The path to the request field that failed validation.
Type: String
Required: Yes
