# CollectorDetails
<a name="API_CollectorDetails"></a>

Collector data access configuration returned for an environment.

## Contents
<a name="API_CollectorDetails_Contents"></a>

 ** collectorDataAccessRoleArn **   <a name="continuum-Type-CollectorDetails-collectorDataAccessRoleArn"></a>
The Amazon Resource Name (ARN) of the collector Data Access Role.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1011.
Pattern: `arn:[a-z0-9-]+:iam::[0-9]{12}:role/[a-zA-Z0-9_+=,.@/-]+`
Required: No
