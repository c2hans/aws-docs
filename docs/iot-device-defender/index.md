# AWS IoT Device Defender

AWS IoT Device Defender is an AWS IoT security service that allows you to audit the configuration of your devices, monitor your connected devices to detect abnormal behavior, and to mitigate security risks. It gives you the ability to enforce consistent security policies across your AWS IoT device fleet and respond quickly when devices are compromised.

- [Developer Guide](/iot-device-defender/latest/devguide/what-is-device-defender.html): Walks through how to set up the service and integrate with other AWS services.
- [API Reference](/iot/latest/apireference/Welcome.html): Describes all of the API operations for service. Also provides sample requests, responses, and errors for the supported web services protocols..
- [AWS IoT sections of the AWS CLI Reference](/cli/latest/reference/iot/): Describes the AWS CLI commands that you can use to administer and manipulate AWS IoT Device Defender.
