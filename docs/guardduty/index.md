# Amazon GuardDuty

Amazon GuardDuty is a continuous security monitoring service. Amazon GuardDuty can help to identify unexpected and potentially unauthorized or malicious activity in your AWS environment.

- [User Guide](/guardduty/latest/ug/what-is-guardduty.html): Walks through how to set up Amazon GuardDuty and evaluate the security of your AWS environment.
- [API Reference](/guardduty/latest/APIReference/Welcome.html): Describes all of the API operations for Amazon GuardDuty.
- [Amazon GuardDuty section of the AWS CLI Reference](/cli/latest/reference/guardduty/index.html): Provides syntax and examples for the AWS CLI commands for use with Amazon GuardDuty.
