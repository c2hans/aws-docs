# Configuring protection plans
<a name="protection-plans"></a>

The **Protection Plans** page in the GuardDuty console consolidates all protection plan configurations into a single page. You can enable or disable protection plans, configure auto-enable settings for AWS Organizations accounts, and view member account statistics from one location.
