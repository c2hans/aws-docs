# Organization statistics
<a name="protection-plans-org-statistics"></a>

Each protection plan container displays member account statistics showing how many accounts have the feature enabled. When organization statistics are not yet available (for example, within the first 24 hours after enabling), the page displays a pending status indicator with a message explaining that statistics are being collected.
