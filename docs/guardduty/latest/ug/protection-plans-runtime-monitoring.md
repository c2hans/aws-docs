# Runtime Monitoring configuration
<a name="protection-plans-runtime-monitoring"></a>

The Runtime Monitoring container has a parent-child structure with the following sub-features:
+ Runtime Monitoring (EKS)
+ Runtime Monitoring (ECS)
+ Runtime Monitoring (EC2)

The **Runtime Monitoring Infrastructure** setting is displayed in an expandable section. This setting is required for Runtime Monitoring for EKS, ECS, and EC2 to function but does not provide protection on its own.
