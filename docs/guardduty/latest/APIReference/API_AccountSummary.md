# AccountSummary
<a name="API_AccountSummary"></a>

Contains the number of findings in an AWS account.

## Contents
<a name="API_AccountSummary_Contents"></a>

 ** accountId **   <a name="guardduty-Type-AccountSummary-accountId"></a>
The ID of the AWS account.
Type: String
Required: No

 ** findingCount **   <a name="guardduty-Type-AccountSummary-findingCount"></a>
The number of findings in the account.
Type: Integer
Required: No
