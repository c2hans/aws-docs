# ActivityWindow
<a name="API_ActivityWindow"></a>

Contains the time range during which activity was observed.

## Contents
<a name="API_ActivityWindow_Contents"></a>

 ** firstSeenAt **   <a name="guardduty-Type-ActivityWindow-firstSeenAt"></a>
The timestamp at which the activity was first observed.
Type: Timestamp
Required: No

 ** lastSeenAt **   <a name="guardduty-Type-ActivityWindow-lastSeenAt"></a>
The timestamp at which the activity was last observed.
Type: Timestamp
Required: No
