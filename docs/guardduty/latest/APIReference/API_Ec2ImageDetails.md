# Ec2ImageDetails
<a name="API_Ec2ImageDetails"></a>

Contains details about the EC2 AMI that was scanned.

## Contents
<a name="API_Ec2ImageDetails_Contents"></a>

 ** imageArn **   <a name="guardduty-Type-Ec2ImageDetails-imageArn"></a>
The Amazon Resource Name (ARN) of the EC2 AMI.
Type: String
Required: No
