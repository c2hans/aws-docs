# ScanConfigurationContinuousScanDetails
<a name="API_ScanConfigurationContinuousScanDetails"></a>

Contains information about the time range within the continuous backup in AWS Backup that was scanned for a point-in-time recovery resource.

## Contents
<a name="API_ScanConfigurationContinuousScanDetails_Contents"></a>

 ** endTime **   <a name="guardduty-Type-ScanConfigurationContinuousScanDetails-endTime"></a>
The timestamp representing the end of the time range that was scanned.
Type: Timestamp
Required: Yes

 ** startTime **   <a name="guardduty-Type-ScanConfigurationContinuousScanDetails-startTime"></a>
The timestamp representing the start of the time range that was scanned.
Type: Timestamp
Required: No
