# EbsSnapshot
<a name="API_EbsSnapshot"></a>

Contains information about an EBS snapshot that was scanned for malware.

## Contents
<a name="API_EbsSnapshot_Contents"></a>

 ** deviceName **   <a name="guardduty-Type-EbsSnapshot-deviceName"></a>
The device name of the EBS snapshot that was scanned.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 200.
Required: No
