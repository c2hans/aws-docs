# Volume
<a name="API_Volume"></a>

Volume used by the Kubernetes workload.

## Contents
<a name="API_Volume_Contents"></a>

 ** hostPath **   <a name="guardduty-Type-Volume-hostPath"></a>
Represents a pre-existing file or directory on the host machine that the volume maps to.
Type: [HostPath](API_HostPath.md) object
Required: No

 ** name **   <a name="guardduty-Type-Volume-name"></a>
Volume name.
Type: String
Required: No
