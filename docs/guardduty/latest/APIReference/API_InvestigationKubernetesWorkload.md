# InvestigationKubernetesWorkload
<a name="API_InvestigationKubernetesWorkload"></a>

Contains details about a Kubernetes workload.

## Contents
<a name="API_InvestigationKubernetesWorkload_Contents"></a>

 ** containers **   <a name="guardduty-Type-InvestigationKubernetesWorkload-containers"></a>
The containers in the workload.
Type: String
Required: No

 ** securityContext **   <a name="guardduty-Type-InvestigationKubernetesWorkload-securityContext"></a>
The security context of the workload.
Type: String
Required: No

 ** volumes **   <a name="guardduty-Type-InvestigationKubernetesWorkload-volumes"></a>
The volumes of the workload.
Type: String
Required: No

 ** workloadName **   <a name="guardduty-Type-InvestigationKubernetesWorkload-workloadName"></a>
The name of the workload.
Type: String
Required: No

 ** workloadType **   <a name="guardduty-Type-InvestigationKubernetesWorkload-workloadType"></a>
The type of the workload.
Type: String
Required: No
