# Observations
<a name="API_Observations"></a>

Contains information about the observed behavior.

## Contents
<a name="API_Observations_Contents"></a>

 ** number **   <a name="guardduty-Type-Observations-number"></a>
The numeric values that were unusual.
Type: Array of longs
Required: No

 ** text **   <a name="guardduty-Type-Observations-text"></a>
The text that was unusual.
Type: Array of strings
Required: No
