# ScannedItemCount
<a name="API_ScannedItemCount"></a>

Total number of scanned files.

## Contents
<a name="API_ScannedItemCount_Contents"></a>

 ** files **   <a name="guardduty-Type-ScannedItemCount-files"></a>
Number of files scanned.
Type: Integer
Required: No

 ** totalGb **   <a name="guardduty-Type-ScannedItemCount-totalGb"></a>
Total GB of files scanned for malware.
Type: Integer
Required: No

 ** volumes **   <a name="guardduty-Type-ScannedItemCount-volumes"></a>
Total number of scanned volumes.
Type: Integer
Required: No
