# LocalIpDetails
<a name="API_LocalIpDetails"></a>

Contains information about the local IP address of the connection.

## Contents
<a name="API_LocalIpDetails_Contents"></a>

 ** ipAddressV4 **   <a name="guardduty-Type-LocalIpDetails-ipAddressV4"></a>
The IPv4 local address of the connection.
Type: String
Required: No

 ** ipAddressV6 **   <a name="guardduty-Type-LocalIpDetails-ipAddressV6"></a>
The IPv6 local address of the connection.
Type: String
Required: No
