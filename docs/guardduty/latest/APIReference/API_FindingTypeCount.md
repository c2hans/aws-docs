# FindingTypeCount
<a name="API_FindingTypeCount"></a>

Contains the number of findings of a finding type.

## Contents
<a name="API_FindingTypeCount_Contents"></a>

 ** count **   <a name="guardduty-Type-FindingTypeCount-count"></a>
The number of findings of this type.
Type: Integer
Required: No

 ** findingType **   <a name="guardduty-Type-FindingTypeCount-findingType"></a>
The finding type.
Type: String
Required: No
