# RuleDefinition
<a name="API_RuleDefinition"></a>

Contains the detection logic for a custom detection rule.

## Contents
<a name="API_RuleDefinition_Contents"></a>

 ** expression **   <a name="guardduty-Type-RuleDefinition-expression"></a>
The detection logic expression for the rule.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 4096.
Required: Yes
