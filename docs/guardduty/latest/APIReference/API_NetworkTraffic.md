# NetworkTraffic
<a name="API_NetworkTraffic"></a>

Contains the amount of data that network activity transferred.

## Contents
<a name="API_NetworkTraffic_Contents"></a>

 ** bytesReceived **   <a name="guardduty-Type-NetworkTraffic-bytesReceived"></a>
The number of bytes received.
Type: Long
Valid Range: Minimum value of 0.
Required: No

 ** bytesSent **   <a name="guardduty-Type-NetworkTraffic-bytesSent"></a>
The number of bytes sent.
Type: Long
Valid Range: Minimum value of 0.
Required: No
