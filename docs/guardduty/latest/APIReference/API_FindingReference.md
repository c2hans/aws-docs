# FindingReference
<a name="API_FindingReference"></a>

Contains a reference to a GuardDuty finding.

## Contents
<a name="API_FindingReference_Contents"></a>

 ** findingType **   <a name="guardduty-Type-FindingReference-findingType"></a>
The type of the finding.
Type: String
Required: No

 ** uid **   <a name="guardduty-Type-FindingReference-uid"></a>
The ID of the finding.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 300.
Required: No
