# QueryTimeWindow
<a name="API_QueryTimeWindow"></a>

Contains the start and end of a time window.

## Contents
<a name="API_QueryTimeWindow_Contents"></a>

 ** endTime **   <a name="guardduty-Type-QueryTimeWindow-endTime"></a>
The timestamp at which the time window ends.
Type: Timestamp
Required: No

 ** startTime **   <a name="guardduty-Type-QueryTimeWindow-startTime"></a>
The timestamp at which the time window starts.
Type: Timestamp
Required: No
