# ResourceDistribution
<a name="API_ResourceDistribution"></a>

Contains the number of findings for a resource.

## Contents
<a name="API_ResourceDistribution_Contents"></a>

 ** count **   <a name="guardduty-Type-ResourceDistribution-count"></a>
The number of findings for the resource.
Type: Long
Valid Range: Minimum value of 0.
Required: No

 ** identifier **   <a name="guardduty-Type-ResourceDistribution-identifier"></a>
The identifier of the resource.
Type: String
Required: No

 ** resourceType **   <a name="guardduty-Type-ResourceDistribution-resourceType"></a>
The display name of the resource type, such as `Instance`.
Type: String
Required: No
