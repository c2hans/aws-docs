# Tag
<a name="API_Tag"></a>

Contains information about a tag key-value pair.

## Contents
<a name="API_Tag_Contents"></a>

 ** key **   <a name="guardduty-Type-Tag-key"></a>
Describes the key associated with the tag.
Type: String
Required: No

 ** value **   <a name="guardduty-Type-Tag-value"></a>
Describes the value associated with the tag key.
Type: String
Required: No
