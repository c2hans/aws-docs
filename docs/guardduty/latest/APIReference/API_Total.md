# Total
<a name="API_Total"></a>

Contains the total usage with the corresponding currency unit for that value.

## Contents
<a name="API_Total_Contents"></a>

 ** amount **   <a name="guardduty-Type-Total-amount"></a>
The total usage.
Type: String
Required: No

 ** unit **   <a name="guardduty-Type-Total-unit"></a>
The currency unit that the amount is given in.
Type: String
Required: No
