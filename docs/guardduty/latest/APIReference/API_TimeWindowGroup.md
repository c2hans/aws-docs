# TimeWindowGroup
<a name="API_TimeWindowGroup"></a>

Contains the number of findings in a time window.

## Contents
<a name="API_TimeWindowGroup_Contents"></a>

 ** endTime **   <a name="guardduty-Type-TimeWindowGroup-endTime"></a>
The timestamp at which the time window ends.
Type: Timestamp
Required: No

 ** findingCount **   <a name="guardduty-Type-TimeWindowGroup-findingCount"></a>
The number of findings in the time window.
Type: Integer
Required: No

 ** startTime **   <a name="guardduty-Type-TimeWindowGroup-startTime"></a>
The timestamp at which the time window starts.
Type: Timestamp
Required: No
