# DnsContext
<a name="API_DnsContext"></a>

Contains DNS details about network activity.

## Contents
<a name="API_DnsContext_Contents"></a>

 ** domainSuffix **   <a name="guardduty-Type-DnsContext-domainSuffix"></a>
The suffix of the domain that was queried.
Type: String
Required: No

 ** otherDomains **   <a name="guardduty-Type-DnsContext-otherDomains"></a>
Other domains that were queried.
Type: String
Required: No

 ** resolverHistory **   <a name="guardduty-Type-DnsContext-resolverHistory"></a>
The DNS resolution history for the domain.
Type: String
Required: No
