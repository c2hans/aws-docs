# MetadataRecord
<a name="API_MetadataRecord"></a>

Contains operational details about an investigation, such as how long it took.

## Contents
<a name="API_MetadataRecord_Contents"></a>

 ** totalTimeMilliseconds **   <a name="guardduty-Type-MetadataRecord-totalTimeMilliseconds"></a>
The total time that the investigation took, in milliseconds.
Type: Long
Valid Range: Minimum value of 0.
Required: No
