# DetectionRuleEc2Requirements
<a name="API_DetectionRuleEc2Requirements"></a>

The requirements for running a Runtime Monitoring custom detection rule on Amazon EC2.

## Contents
<a name="API_DetectionRuleEc2Requirements_Contents"></a>

 ** minAgentVersion **   <a name="guardduty-Type-DetectionRuleEc2Requirements-minAgentVersion"></a>
The minimum GuardDuty agent version required to run the rule on Amazon EC2.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Pattern: `[0-9]+(\.[0-9]+){1,3}`
Required: No
