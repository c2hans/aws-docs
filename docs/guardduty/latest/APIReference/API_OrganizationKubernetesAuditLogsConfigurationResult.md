# OrganizationKubernetesAuditLogsConfigurationResult
<a name="API_OrganizationKubernetesAuditLogsConfigurationResult"></a>

The current configuration of Kubernetes audit logs as a data source for the organization.

## Contents
<a name="API_OrganizationKubernetesAuditLogsConfigurationResult_Contents"></a>

 ** autoEnable **   <a name="guardduty-Type-OrganizationKubernetesAuditLogsConfigurationResult-autoEnable"></a>
Whether Kubernetes audit logs data source should be auto-enabled for new members joining the organization.
Type: Boolean
Required: Yes
