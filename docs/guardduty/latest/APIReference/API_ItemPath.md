# ItemPath
<a name="API_ItemPath"></a>

Information about the nested item path and hash of the protected resource.

## Contents
<a name="API_ItemPath_Contents"></a>

 ** hash **   <a name="guardduty-Type-ItemPath-hash"></a>
The hash value of the infected resource.
Type: String
Required: No

 ** nestedItemPath **   <a name="guardduty-Type-ItemPath-nestedItemPath"></a>
The nested item path where the infected file was found.
Type: String
Required: No
