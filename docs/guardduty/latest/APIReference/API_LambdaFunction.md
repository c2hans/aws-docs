# LambdaFunction
<a name="API_LambdaFunction"></a>

Contains details about an AWS Lambda function.

## Contents
<a name="API_LambdaFunction_Contents"></a>

 ** description **   <a name="guardduty-Type-LambdaFunction-description"></a>
The description of the function.
Type: String
Required: No

 ** functionArn **   <a name="guardduty-Type-LambdaFunction-functionArn"></a>
The Amazon Resource Name (ARN) of the function.
Type: String
Required: No

 ** functionName **   <a name="guardduty-Type-LambdaFunction-functionName"></a>
The name of the function.
Type: String
Required: No

 ** functionVersion **   <a name="guardduty-Type-LambdaFunction-functionVersion"></a>
The version of the function.
Type: String
Required: No

 ** revisionId **   <a name="guardduty-Type-LambdaFunction-revisionId"></a>
The revision ID of the function version.
Type: String
Required: No

 ** role **   <a name="guardduty-Type-LambdaFunction-role"></a>
The execution role of the function.
Type: String
Required: No

 ** updatedAt **   <a name="guardduty-Type-LambdaFunction-updatedAt"></a>
The timestamp at which the function was last updated.
Type: Timestamp
Required: No

 ** vpcConfigurationSummary **   <a name="guardduty-Type-LambdaFunction-vpcConfigurationSummary"></a>
A summary of the VPC configuration of the function, as a single string.
Type: String
Required: No
