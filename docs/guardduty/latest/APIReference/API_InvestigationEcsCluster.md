# InvestigationEcsCluster
<a name="API_InvestigationEcsCluster"></a>

Contains details about an Amazon ECS cluster.

## Contents
<a name="API_InvestigationEcsCluster_Contents"></a>

 ** arn **   <a name="guardduty-Type-InvestigationEcsCluster-arn"></a>
The Amazon Resource Name (ARN) of the cluster.
Type: String
Required: No

 ** name **   <a name="guardduty-Type-InvestigationEcsCluster-name"></a>
The name of the cluster.
Type: String
Required: No

 ** status **   <a name="guardduty-Type-InvestigationEcsCluster-status"></a>
The status of the cluster.
Type: String
Required: No
