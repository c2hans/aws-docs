# UsageAccountResult
<a name="API_UsageAccountResult"></a>

Contains information on the total of usage based on account IDs.

## Contents
<a name="API_UsageAccountResult_Contents"></a>

 ** accountId **   <a name="guardduty-Type-UsageAccountResult-accountId"></a>
The Account ID that generated usage.
Type: String
Length Constraints: Fixed length of 12.
Required: No

 ** total **   <a name="guardduty-Type-UsageAccountResult-total"></a>
Represents the total of usage for the Account ID.
Type: [Total](API_Total.md) object
Required: No
