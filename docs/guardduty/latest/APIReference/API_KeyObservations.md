# KeyObservations
<a name="API_KeyObservations"></a>

Contains the key observations of an investigation.

## Contents
<a name="API_KeyObservations_Contents"></a>

 ** narrative **   <a name="guardduty-Type-KeyObservations-narrative"></a>
A narrative explanation of the key observations.
Type: String
Required: No

 ** observations **   <a name="guardduty-Type-KeyObservations-observations"></a>
The individual key observations.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 25 items.
Required: No

 ** title **   <a name="guardduty-Type-KeyObservations-title"></a>
A short title for the key observations.
Type: String
Required: No
