# BucketPolicy
<a name="API_BucketPolicy"></a>

Contains information on the current bucket policies for the S3 bucket.

## Contents
<a name="API_BucketPolicy_Contents"></a>

 ** allowsPublicReadAccess **   <a name="guardduty-Type-BucketPolicy-allowsPublicReadAccess"></a>
A value that indicates whether public read access for the bucket is enabled through a bucket policy.
Type: Boolean
Required: No

 ** allowsPublicWriteAccess **   <a name="guardduty-Type-BucketPolicy-allowsPublicWriteAccess"></a>
A value that indicates whether public write access for the bucket is enabled through a bucket policy.
Type: Boolean
Required: No
