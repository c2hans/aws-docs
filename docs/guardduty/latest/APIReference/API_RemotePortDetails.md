# RemotePortDetails
<a name="API_RemotePortDetails"></a>

Contains information about the remote port.

## Contents
<a name="API_RemotePortDetails_Contents"></a>

 ** port **   <a name="guardduty-Type-RemotePortDetails-port"></a>
The port number of the remote connection.
Type: Integer
Required: No

 ** portName **   <a name="guardduty-Type-RemotePortDetails-portName"></a>
The port name of the remote connection.
Type: String
Required: No
