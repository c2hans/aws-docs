# AddonDetails
<a name="API_AddonDetails"></a>

Information about the installed EKS add-on (GuardDuty security agent).

## Contents
<a name="API_AddonDetails_Contents"></a>

 ** addonStatus **   <a name="guardduty-Type-AddonDetails-addonStatus"></a>
Status of the installed EKS add-on.
Type: String
Required: No

 ** addonVersion **   <a name="guardduty-Type-AddonDetails-addonVersion"></a>
Version of the installed EKS add-on.
Type: String
Required: No
