# AddonDetails
<a name="API_AddonDetails"></a>

 ** addonStatus **   <a name="guardduty-Type-AddonDetails-addonStatus"></a>

Type: String
Required: No

 ** addonVersion **   <a name="guardduty-Type-AddonDetails-addonVersion"></a>

Type: String
Required: No
