# AnomalyUnusual
<a name="API_AnomalyUnusual"></a>

Contains information about the behavior of the anomaly that is new to GuardDuty.

## Contents
<a name="API_AnomalyUnusual_Contents"></a>

 ** behavior **   <a name="guardduty-Type-AnomalyUnusual-behavior"></a>
The behavior of the anomalous activity that caused GuardDuty to generate the finding.
Type: String to string to [AnomalyObject](API_AnomalyObject.md) object map map
Required: No
