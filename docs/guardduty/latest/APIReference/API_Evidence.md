# Evidence
<a name="API_Evidence"></a>

Contains information about the reason that the finding was generated.

## Contents
<a name="API_Evidence_Contents"></a>

 ** threatIntelligenceDetails **   <a name="guardduty-Type-Evidence-threatIntelligenceDetails"></a>
A list of threat intelligence details related to the evidence.
Type: Array of [ThreatIntelligenceDetail](API_ThreatIntelligenceDetail.md) objects
Required: No
