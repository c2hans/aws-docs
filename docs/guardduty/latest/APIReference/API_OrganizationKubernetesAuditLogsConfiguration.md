# OrganizationKubernetesAuditLogsConfiguration
<a name="API_OrganizationKubernetesAuditLogsConfiguration"></a>

Organization-wide Kubernetes audit logs configuration.

## Contents
<a name="API_OrganizationKubernetesAuditLogsConfiguration_Contents"></a>

 ** autoEnable **   <a name="guardduty-Type-OrganizationKubernetesAuditLogsConfiguration-autoEnable"></a>
A value that contains information on whether Kubernetes audit logs should be enabled automatically as a data source for the organization.
Type: Boolean
Required: Yes
