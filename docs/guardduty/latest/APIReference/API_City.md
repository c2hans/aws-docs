# City
<a name="API_City"></a>

Contains information about the city associated with the IP address.

## Contents
<a name="API_City_Contents"></a>

 ** cityName **   <a name="guardduty-Type-City-cityName"></a>
The city name of the remote IP address.
Type: String
Required: No
