# ScanResultDetails
<a name="API_ScanResultDetails"></a>

Represents the result of the scan.

## Contents
<a name="API_ScanResultDetails_Contents"></a>

 ** scanResult **   <a name="guardduty-Type-ScanResultDetails-scanResult"></a>
An enum value representing possible scan results.
Type: String
Valid Values: `CLEAN | INFECTED`
Required: No
