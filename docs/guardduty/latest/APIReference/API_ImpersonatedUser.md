# ImpersonatedUser
<a name="API_ImpersonatedUser"></a>

Contains information about the impersonated user.

## Contents
<a name="API_ImpersonatedUser_Contents"></a>

 ** groups **   <a name="guardduty-Type-ImpersonatedUser-groups"></a>
The `group` to which the user name belongs.
Type: Array of strings
Required: No

 ** username **   <a name="guardduty-Type-ImpersonatedUser-username"></a>
Information about the `username` that was being impersonated.
Type: String
Required: No
