# InvestigationMetadata
<a name="API_InvestigationMetadata"></a>

Contains metadata about the product and version that produced an investigation.

## Contents
<a name="API_InvestigationMetadata_Contents"></a>

 ** product **   <a name="guardduty-Type-InvestigationMetadata-product"></a>
Information about the product that produced the investigation.
Type: [Product](API_Product.md) object
Required: Yes

 ** version **   <a name="guardduty-Type-InvestigationMetadata-version"></a>
The version of the investigation engine that produced the results.
Type: String
Required: Yes
