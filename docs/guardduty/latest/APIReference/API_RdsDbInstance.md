# RdsDbInstance
<a name="API_RdsDbInstance"></a>

Contains details about an Amazon RDS database instance.

## Contents
<a name="API_RdsDbInstance_Contents"></a>

 ** dbClusterIdentifier **   <a name="guardduty-Type-RdsDbInstance-dbClusterIdentifier"></a>
The identifier of the database cluster that contains the instance.
Type: String
Required: No

 ** dbInstanceArn **   <a name="guardduty-Type-RdsDbInstance-dbInstanceArn"></a>
The Amazon Resource Name (ARN) of the database instance.
Type: String
Required: No

 ** dbInstanceIdentifier **   <a name="guardduty-Type-RdsDbInstance-dbInstanceIdentifier"></a>
The identifier of the database instance.
Type: String
Required: No

 ** dbiResourceId **   <a name="guardduty-Type-RdsDbInstance-dbiResourceId"></a>
The unique resource ID of the database instance.
Type: String
Required: No

 ** engine **   <a name="guardduty-Type-RdsDbInstance-engine"></a>
The database engine of the instance.
Type: String
Required: No

 ** engineVersion **   <a name="guardduty-Type-RdsDbInstance-engineVersion"></a>
The version of the database engine.
Type: String
Required: No
