# SharedBehavior
<a name="API_SharedBehavior"></a>

Contains information about a behavior that related findings share.

## Contents
<a name="API_SharedBehavior_Contents"></a>

 ** path **   <a name="guardduty-Type-SharedBehavior-path"></a>
The JSON path of the finding attribute that matched.
Type: String
Required: No

 ** value **   <a name="guardduty-Type-SharedBehavior-value"></a>
The value that matched.
Type: String
Required: No
