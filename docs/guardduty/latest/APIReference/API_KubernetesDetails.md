# KubernetesDetails
<a name="API_KubernetesDetails"></a>

Details about Kubernetes resources such as a Kubernetes user or workload resource involved in a Kubernetes finding.

## Contents
<a name="API_KubernetesDetails_Contents"></a>

 ** kubernetesUserDetails **   <a name="guardduty-Type-KubernetesDetails-kubernetesUserDetails"></a>
Details about the Kubernetes user involved in a Kubernetes finding.
Type: [KubernetesUserDetails](API_KubernetesUserDetails.md) object
Required: No

 ** kubernetesWorkloadDetails **   <a name="guardduty-Type-KubernetesDetails-kubernetesWorkloadDetails"></a>
Details about the Kubernetes workload involved in a Kubernetes finding.
Type: [KubernetesWorkloadDetails](API_KubernetesWorkloadDetails.md) object
Required: No
