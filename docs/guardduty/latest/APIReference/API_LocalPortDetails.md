# LocalPortDetails
<a name="API_LocalPortDetails"></a>

Contains information about the port for the local connection.

## Contents
<a name="API_LocalPortDetails_Contents"></a>

 ** port **   <a name="guardduty-Type-LocalPortDetails-port"></a>
The port number of the local connection.
Type: Integer
Required: No

 ** portName **   <a name="guardduty-Type-LocalPortDetails-portName"></a>
The port name of the local connection.
Type: String
Required: No
