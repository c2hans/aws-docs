# KubernetesDataSourceFreeTrial
<a name="API_KubernetesDataSourceFreeTrial"></a>

Provides details about the Kubernetes resources when it is enabled as a data source.

## Contents
<a name="API_KubernetesDataSourceFreeTrial_Contents"></a>

 ** auditLogs **   <a name="guardduty-Type-KubernetesDataSourceFreeTrial-auditLogs"></a>
Describes whether Kubernetes audit logs are enabled as a data source.
Type: [DataSourceFreeTrial](API_DataSourceFreeTrial.md) object
Required: No
