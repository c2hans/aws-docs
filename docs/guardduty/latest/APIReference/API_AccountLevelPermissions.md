# AccountLevelPermissions
<a name="API_AccountLevelPermissions"></a>

Contains information about the account level permissions on the S3 bucket.

## Contents
<a name="API_AccountLevelPermissions_Contents"></a>

 ** blockPublicAccess **   <a name="guardduty-Type-AccountLevelPermissions-blockPublicAccess"></a>
Describes the S3 Block Public Access settings of the bucket's parent account.
Type: [BlockPublicAccess](API_BlockPublicAccess.md) object
Required: No
