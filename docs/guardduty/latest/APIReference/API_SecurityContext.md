# SecurityContext
<a name="API_SecurityContext"></a>

Container security context.

## Contents
<a name="API_SecurityContext_Contents"></a>

 ** allowPrivilegeEscalation **   <a name="guardduty-Type-SecurityContext-allowPrivilegeEscalation"></a>
Whether or not a container or a Kubernetes pod is allowed to gain more privileges than its parent process.
Type: Boolean
Required: No

 ** privileged **   <a name="guardduty-Type-SecurityContext-privileged"></a>
Whether the container is privileged.
Type: Boolean
Required: No
