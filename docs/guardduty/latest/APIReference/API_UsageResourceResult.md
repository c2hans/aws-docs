# UsageResourceResult
<a name="API_UsageResourceResult"></a>

Contains information on the sum of usage based on an AWS resource.

## Contents
<a name="API_UsageResourceResult_Contents"></a>

 ** resource **   <a name="guardduty-Type-UsageResourceResult-resource"></a>
The AWS resource that generated usage.
Type: String
Required: No

 ** total **   <a name="guardduty-Type-UsageResourceResult-total"></a>
Represents the sum total of usage for the specified resource type.
Type: [Total](API_Total.md) object
Required: No
