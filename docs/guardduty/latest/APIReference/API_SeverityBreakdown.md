# SeverityBreakdown
<a name="API_SeverityBreakdown"></a>

Contains the number of findings at each severity level.

## Contents
<a name="API_SeverityBreakdown_Contents"></a>

 ** critical **   <a name="guardduty-Type-SeverityBreakdown-critical"></a>
The number of findings that have Critical severity.
Type: Integer
Required: No

 ** high **   <a name="guardduty-Type-SeverityBreakdown-high"></a>
The number of findings that have High severity.
Type: Integer
Required: No

 ** info **   <a name="guardduty-Type-SeverityBreakdown-info"></a>
The number of findings that have Info severity.
Type: Integer
Required: No

 ** low **   <a name="guardduty-Type-SeverityBreakdown-low"></a>
The number of findings that have Low severity.
Type: Integer
Required: No

 ** medium **   <a name="guardduty-Type-SeverityBreakdown-medium"></a>
The number of findings that have Medium severity.
Type: Integer
Required: No
