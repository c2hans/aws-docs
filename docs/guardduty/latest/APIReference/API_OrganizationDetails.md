# OrganizationDetails
<a name="API_OrganizationDetails"></a>

Information about GuardDuty coverage statistics for members in your AWS organization.

## Contents
<a name="API_OrganizationDetails_Contents"></a>

 ** organizationStatistics **   <a name="guardduty-Type-OrganizationDetails-organizationStatistics"></a>
Information about the GuardDuty coverage statistics for members in your AWS organization.
Type: [OrganizationStatistics](API_OrganizationStatistics.md) object
Required: No

 ** updatedAt **   <a name="guardduty-Type-OrganizationDetails-updatedAt"></a>
The timestamp at which the organization statistics was last updated. This is in UTC format.
Type: Timestamp
Required: No
