# ScanEc2InstanceWithFindingsResult
<a name="API_ScanEc2InstanceWithFindingsResult"></a>

An object that contains information on the status of whether Malware Protection for EC2 instances with findings will be enabled as a data source.

## Contents
<a name="API_ScanEc2InstanceWithFindingsResult_Contents"></a>

 ** ebsVolumes **   <a name="guardduty-Type-ScanEc2InstanceWithFindingsResult-ebsVolumes"></a>
Describes the configuration of scanning EBS volumes as a data source.
Type: [EbsVolumesResult](API_EbsVolumesResult.md) object
Required: No
