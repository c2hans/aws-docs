# AccessKeyDetails
<a name="API_AccessKeyDetails"></a>

Contains information about the access keys.

## Contents
<a name="API_AccessKeyDetails_Contents"></a>

 ** accessKeyId **   <a name="guardduty-Type-AccessKeyDetails-accessKeyId"></a>
The access key ID of the user.
Type: String
Required: No

 ** principalId **   <a name="guardduty-Type-AccessKeyDetails-principalId"></a>
The principal ID of the user.
Type: String
Required: No

 ** userName **   <a name="guardduty-Type-AccessKeyDetails-userName"></a>
The name of the user.
Type: String
Required: No

 ** userType **   <a name="guardduty-Type-AccessKeyDetails-userType"></a>
The type of the user.
Type: String
Required: No
