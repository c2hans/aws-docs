# InvestigationEksCluster
<a name="API_InvestigationEksCluster"></a>

Contains details about an Amazon EKS cluster.

## Contents
<a name="API_InvestigationEksCluster_Contents"></a>

 ** arn **   <a name="guardduty-Type-InvestigationEksCluster-arn"></a>
The Amazon Resource Name (ARN) of the cluster.
Type: String
Required: No

 ** name **   <a name="guardduty-Type-InvestigationEksCluster-name"></a>
The name of the cluster.
Type: String
Required: No

 ** status **   <a name="guardduty-Type-InvestigationEksCluster-status"></a>
The status of the cluster.
Type: String
Required: No

 ** vpcId **   <a name="guardduty-Type-InvestigationEksCluster-vpcId"></a>
The ID of the VPC that is associated with the cluster.
Type: String
Required: No
