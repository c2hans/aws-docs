# EbsSnapshotDetails
<a name="API_EbsSnapshotDetails"></a>

Contains details about the EBS snapshot that was scanned for malware.

## Contents
<a name="API_EbsSnapshotDetails_Contents"></a>

 ** snapshotArn **   <a name="guardduty-Type-EbsSnapshotDetails-snapshotArn"></a>
The Amazon Resource Name (ARN) of the EBS snapshot.
Type: String
Required: No
