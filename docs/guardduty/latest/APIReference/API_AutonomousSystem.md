# AutonomousSystem
<a name="API_AutonomousSystem"></a>

Contains information about the Autonomous System (AS) associated with the network endpoints involved in an attack sequence.

## Contents
<a name="API_AutonomousSystem_Contents"></a>

 ** name **   <a name="guardduty-Type-AutonomousSystem-name"></a>
Name associated with the Autonomous System (AS).
Type: String
Required: Yes

 ** number **   <a name="guardduty-Type-AutonomousSystem-number"></a>
The unique number that identifies the Autonomous System (AS).
Type: Integer
Required: Yes
