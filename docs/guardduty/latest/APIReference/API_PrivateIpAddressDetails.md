# PrivateIpAddressDetails
<a name="API_PrivateIpAddressDetails"></a>

Contains other private IP address information of the EC2 instance.

## Contents
<a name="API_PrivateIpAddressDetails_Contents"></a>

 ** privateDnsName **   <a name="guardduty-Type-PrivateIpAddressDetails-privateDnsName"></a>
The private DNS name of the EC2 instance.
Type: String
Required: No

 ** privateIpAddress **   <a name="guardduty-Type-PrivateIpAddressDetails-privateIpAddress"></a>
The private IP address of the EC2 instance.
Type: String
Required: No
