# SharedResource
<a name="API_SharedResource"></a>

Contains information about a resource that related findings share.

## Contents
<a name="API_SharedResource_Contents"></a>

 ** identifier **   <a name="guardduty-Type-SharedResource-identifier"></a>
The identifier of the resource.
Type: String
Required: No

 ** resourceType **   <a name="guardduty-Type-SharedResource-resourceType"></a>
The type of the resource. This value isn't limited to the resource types of `InvestigationResource`.
Type: String
Required: No
