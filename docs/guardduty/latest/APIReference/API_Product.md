# Product
<a name="API_Product"></a>

Contains information about the product that produced an investigation.

## Contents
<a name="API_Product_Contents"></a>

 ** name **   <a name="guardduty-Type-Product-name"></a>
The name of the product.
Type: String
Required: Yes

 ** feature **   <a name="guardduty-Type-Product-feature"></a>
The specific feature within the product that produced the investigation.
Type: String
Required: No
