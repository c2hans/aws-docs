# Amazon Chime SDK Documentation

The Amazon Chime SDK allows builders to add real-time voice, video, and messaging powered by machine learning into their applications.

- [Administrator Guide](/chime-sdk/latest/ag/): Helps you perform administrative tasks with the Amazon Chime SDK and SIP trunking to setup and manage phone numbers.
- [Developer Guide](/chime-sdk/latest/dg/): Helps you use the Amazon Chime SDK to embed real-time communication capabilities into their applications.
- [API Reference](/chime-sdk/latest/APIReference/): Describes the API operations for the Amazon Chime SDK.
