# PhoneNumberCountry
<a name="API_voice-chime_PhoneNumberCountry"></a>

The phone number's country.

## Contents
<a name="API_voice-chime_PhoneNumberCountry_Contents"></a>

 ** CountryCode **   <a name="chimesdk-Type-voice-chime_PhoneNumberCountry-CountryCode"></a>
The phone number country code. Format: ISO 3166-1 alpha-2.
Type: String
Pattern: `[A-Z]{2}`
Required: No

 ** SupportedPhoneNumberTypes **   <a name="chimesdk-Type-voice-chime_PhoneNumberCountry-SupportedPhoneNumberTypes"></a>
The supported phone number types.
Type: Array of strings
Valid Values: `Local | TollFree`
Required: No
