# PresenterOnlyConfiguration
<a name="API_media-pipelines-chime_PresenterOnlyConfiguration"></a>

Defines the configuration for a presenter-only video tile.

## Contents
<a name="API_media-pipelines-chime_PresenterOnlyConfiguration_Contents"></a>

 ** PresenterPosition **   <a name="chimesdk-Type-media-pipelines-chime_PresenterOnlyConfiguration-PresenterPosition"></a>
Defines the position of the presenter video tile. Default: `TopRight`.
Type: String
Valid Values: `TopLeft | TopRight | BottomLeft | BottomRight`
Required: No
