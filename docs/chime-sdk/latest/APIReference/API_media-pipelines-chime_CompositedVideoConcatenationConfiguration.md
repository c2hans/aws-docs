# CompositedVideoConcatenationConfiguration
<a name="API_media-pipelines-chime_CompositedVideoConcatenationConfiguration"></a>

The composited video configuration object for a specified media pipeline. `SourceType` must be `ChimeSdkMeeting`.

## Contents
<a name="API_media-pipelines-chime_CompositedVideoConcatenationConfiguration_Contents"></a>

 ** State **   <a name="chimesdk-Type-media-pipelines-chime_CompositedVideoConcatenationConfiguration-State"></a>
Enables or disables the configuration object.
Type: String
Valid Values: `Enabled | Disabled`
Required: Yes
