# Tag
<a name="API_media-pipelines-chime_Tag"></a>

A key/value pair that grants users access to meeting resources.

## Contents
<a name="API_media-pipelines-chime_Tag_Contents"></a>

 ** Key **   <a name="chimesdk-Type-media-pipelines-chime_Tag-Key"></a>
The key half of a tag.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** Value **   <a name="chimesdk-Type-media-pipelines-chime_Tag-Value"></a>
The value half of a tag.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: Yes
