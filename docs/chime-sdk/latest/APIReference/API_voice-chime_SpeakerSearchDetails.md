# SpeakerSearchDetails
<a name="API_voice-chime_SpeakerSearchDetails"></a>

The details of a speaker search task.

## Contents
<a name="API_voice-chime_SpeakerSearchDetails_Contents"></a>

 ** Results **   <a name="chimesdk-Type-voice-chime_SpeakerSearchDetails-Results"></a>
The result value in the speaker search details.
Type: Array of [SpeakerSearchResult](API_voice-chime_SpeakerSearchResult.md) objects
Required: No

 ** VoiceprintGenerationStatus **   <a name="chimesdk-Type-voice-chime_SpeakerSearchDetails-VoiceprintGenerationStatus"></a>
The status of a voice print generation operation, `VoiceprintGenerationSuccess` or `VoiceprintGenerationFailure`..
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `.*\S.*`
Required: No
