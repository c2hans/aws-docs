# LambdaFunctionSinkConfiguration
<a name="API_media-pipelines-chime_LambdaFunctionSinkConfiguration"></a>

A structure that contains the configuration settings for an AWS Lambda function's data sink.

## Contents
<a name="API_media-pipelines-chime_LambdaFunctionSinkConfiguration_Contents"></a>

 ** InsightsTarget **   <a name="chimesdk-Type-media-pipelines-chime_LambdaFunctionSinkConfiguration-InsightsTarget"></a>
The ARN of the sink.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `^arn[\/\:\-\_\.a-zA-Z0-9]+$`
Required: No
