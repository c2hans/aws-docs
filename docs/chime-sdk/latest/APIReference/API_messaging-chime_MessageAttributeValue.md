# MessageAttributeValue
<a name="API_messaging-chime_MessageAttributeValue"></a>

A list of message attribute values.

## Contents
<a name="API_messaging-chime_MessageAttributeValue_Contents"></a>

 ** StringValues **   <a name="chimesdk-Type-messaging-chime_MessageAttributeValue-StringValues"></a>
The strings in a message attribute value.
Type: Array of strings
Length Constraints: Minimum length of 1. Maximum length of 512.
Pattern: `[\s\S]*`
Required: No
