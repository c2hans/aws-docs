# MediaInsightsConfiguration
<a name="API_voice-chime_MediaInsightsConfiguration"></a>

The configuration for a call analytics task.

## Contents
<a name="API_voice-chime_MediaInsightsConfiguration_Contents"></a>

 ** ConfigurationArn **   <a name="chimesdk-Type-voice-chime_MediaInsightsConfiguration-ConfigurationArn"></a>
The configuration's ARN.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `^arn[\/\:\-\_\.a-zA-Z0-9]+$`
Required: No

 ** Disabled **   <a name="chimesdk-Type-voice-chime_MediaInsightsConfiguration-Disabled"></a>
Denotes the configuration as enabled or disabled.
Type: Boolean
Required: No
