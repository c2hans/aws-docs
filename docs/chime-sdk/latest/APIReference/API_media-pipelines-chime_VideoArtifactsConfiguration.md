# VideoArtifactsConfiguration
<a name="API_media-pipelines-chime_VideoArtifactsConfiguration"></a>

The video artifact configuration object.

## Contents
<a name="API_media-pipelines-chime_VideoArtifactsConfiguration_Contents"></a>

 ** State **   <a name="chimesdk-Type-media-pipelines-chime_VideoArtifactsConfiguration-State"></a>
Indicates whether the video artifact is enabled or disabled.
Type: String
Valid Values: `Enabled | Disabled`
Required: Yes

 ** MuxType **   <a name="chimesdk-Type-media-pipelines-chime_VideoArtifactsConfiguration-MuxType"></a>
The MUX type of the video artifact configuration object.
Type: String
Valid Values: `VideoOnly`
Required: No
