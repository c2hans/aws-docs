# LoggingConfiguration
<a name="API_voice-chime_LoggingConfiguration"></a>

The logging configuration associated with an Amazon Chime SDK Voice Connector. Specifies whether SIP message logs can be sent to Amazon CloudWatch Logs.

## Contents
<a name="API_voice-chime_LoggingConfiguration_Contents"></a>

 ** EnableMediaMetricLogs **   <a name="chimesdk-Type-voice-chime_LoggingConfiguration-EnableMediaMetricLogs"></a>
Enables or disables media metrics logging.
Type: Boolean
Required: No

 ** EnableSIPLogs **   <a name="chimesdk-Type-voice-chime_LoggingConfiguration-EnableSIPLogs"></a>
Boolean that enables sending SIP message logs to Amazon CloudWatch.
Type: Boolean
Required: No
