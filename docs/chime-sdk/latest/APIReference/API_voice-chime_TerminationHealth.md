# TerminationHealth
<a name="API_voice-chime_TerminationHealth"></a>

The termination health details, including the source IP address and timestamp of the last successful `SIP OPTIONS` message from your SIP infrastructure.

## Contents
<a name="API_voice-chime_TerminationHealth_Contents"></a>

 ** Source **   <a name="chimesdk-Type-voice-chime_TerminationHealth-Source"></a>
The source IP address.
Type: String
Required: No

 ** Timestamp **   <a name="chimesdk-Type-voice-chime_TerminationHealth-Timestamp"></a>
The timestamp, in ISO 8601 format.
Type: Timestamp
Required: No
