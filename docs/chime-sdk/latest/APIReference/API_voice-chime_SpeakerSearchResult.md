# SpeakerSearchResult
<a name="API_voice-chime_SpeakerSearchResult"></a>

The result of a speaker search analysis.

## Contents
<a name="API_voice-chime_SpeakerSearchResult_Contents"></a>

 ** ConfidenceScore **   <a name="chimesdk-Type-voice-chime_SpeakerSearchResult-ConfidenceScore"></a>
The confidence score in the speaker search analysis.
Type: Float
Valid Range: Minimum value of 0. Maximum value of 1.
Required: No

 ** VoiceProfileId **   <a name="chimesdk-Type-voice-chime_SpeakerSearchResult-VoiceProfileId"></a>
The voice profile ID.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `.*\S.*`
Required: No
