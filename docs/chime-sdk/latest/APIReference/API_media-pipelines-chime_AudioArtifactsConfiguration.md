# AudioArtifactsConfiguration
<a name="API_media-pipelines-chime_AudioArtifactsConfiguration"></a>

 ** MuxType **   <a name="chimesdk-Type-media-pipelines-chime_AudioArtifactsConfiguration-MuxType"></a>

Valid Values: `AudioOnly | AudioWithActiveSpeakerVideo | AudioWithCompositedVideo`
