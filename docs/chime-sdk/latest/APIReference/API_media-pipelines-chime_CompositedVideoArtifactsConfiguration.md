# CompositedVideoArtifactsConfiguration
<a name="API_media-pipelines-chime_CompositedVideoArtifactsConfiguration"></a>

Specifies the configuration for compositing video artifacts.

## Contents
<a name="API_media-pipelines-chime_CompositedVideoArtifactsConfiguration_Contents"></a>

 ** GridViewConfiguration **   <a name="chimesdk-Type-media-pipelines-chime_CompositedVideoArtifactsConfiguration-GridViewConfiguration"></a>
The `GridView` configuration setting.
Type: [GridViewConfiguration](API_media-pipelines-chime_GridViewConfiguration.md) object
Required: Yes

 ** Layout **   <a name="chimesdk-Type-media-pipelines-chime_CompositedVideoArtifactsConfiguration-Layout"></a>
The layout setting, such as `GridView` in the configuration object.
Type: String
Valid Values: `GridView`
Required: No

 ** Resolution **   <a name="chimesdk-Type-media-pipelines-chime_CompositedVideoArtifactsConfiguration-Resolution"></a>
The video resolution setting in the configuration object. Default: HD at 1280 x 720. FHD resolution: 1920 x 1080.
Type: String
Valid Values: `HD | FHD`
Required: No
