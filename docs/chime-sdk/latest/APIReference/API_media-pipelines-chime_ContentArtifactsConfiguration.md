# ContentArtifactsConfiguration
<a name="API_media-pipelines-chime_ContentArtifactsConfiguration"></a>

The content artifact object.

## Contents
<a name="API_media-pipelines-chime_ContentArtifactsConfiguration_Contents"></a>

 ** State **   <a name="chimesdk-Type-media-pipelines-chime_ContentArtifactsConfiguration-State"></a>
Indicates whether the content artifact is enabled or disabled.
Type: String
Valid Values: `Enabled | Disabled`
Required: Yes

 ** MuxType **   <a name="chimesdk-Type-media-pipelines-chime_ContentArtifactsConfiguration-MuxType"></a>
The MUX type of the artifact configuration.
Type: String
Valid Values: `ContentOnly`
Required: No
