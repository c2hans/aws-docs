# AppInstanceRetentionSettings
<a name="API_AppInstanceRetentionSettings"></a>

The details of the data-retention settings for an `AppInstance`.

## Contents
<a name="API_AppInstanceRetentionSettings_Contents"></a>

 ** ChannelRetentionSettings **   <a name="chimesdk-Type-AppInstanceRetentionSettings-ChannelRetentionSettings"></a>
The length of time in days to retain the messages in a channel.
Type: [ChannelRetentionSettings](API_ChannelRetentionSettings.md) object
Required: No
