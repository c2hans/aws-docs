# SourceConfiguration
<a name="API_media-pipelines-chime_SourceConfiguration"></a>

Source configuration for a specified media pipeline.

## Contents
<a name="API_media-pipelines-chime_SourceConfiguration_Contents"></a>

 ** SelectedVideoStreams **   <a name="chimesdk-Type-media-pipelines-chime_SourceConfiguration-SelectedVideoStreams"></a>
The selected video streams for a specified media pipeline. The number of video streams can't exceed 25.
Type: [SelectedVideoStreams](API_media-pipelines-chime_SelectedVideoStreams.md) object
Required: No
