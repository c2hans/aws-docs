# IssueDetectionConfiguration
<a name="API_media-pipelines-chime_IssueDetectionConfiguration"></a>

A structure that contains the configuration settings for an issue detection task.

## Contents
<a name="API_media-pipelines-chime_IssueDetectionConfiguration_Contents"></a>

 ** RuleName **   <a name="chimesdk-Type-media-pipelines-chime_IssueDetectionConfiguration-RuleName"></a>
The name of the issue detection rule.
Type: String
Length Constraints: Minimum length of 2. Maximum length of 64.
Pattern: `^[0-9a-zA-Z._-]+`
Required: Yes
