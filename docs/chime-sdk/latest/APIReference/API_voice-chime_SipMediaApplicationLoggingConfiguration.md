# SipMediaApplicationLoggingConfiguration
<a name="API_voice-chime_SipMediaApplicationLoggingConfiguration"></a>

 ** EnableSipMediaApplicationMessageLogs **   <a name="chimesdk-Type-voice-chime_SipMediaApplicationLoggingConfiguration-EnableSipMediaApplicationMessageLogs"></a>
