# ChannelRetentionSettings
<a name="API_ChannelRetentionSettings"></a>

The details of the retention settings for a channel.

## Contents
<a name="API_ChannelRetentionSettings_Contents"></a>

 ** RetentionDays **   <a name="chimesdk-Type-ChannelRetentionSettings-RetentionDays"></a>
The time in days to retain the messages in a channel.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 5475.
Required: No
