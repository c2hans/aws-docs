# ActiveSpeakerOnlyConfiguration
<a name="API_media-pipelines-chime_ActiveSpeakerOnlyConfiguration"></a>

Defines the configuration for an `ActiveSpeakerOnly` video tile.

## Contents
<a name="API_media-pipelines-chime_ActiveSpeakerOnlyConfiguration_Contents"></a>

 ** ActiveSpeakerPosition **   <a name="chimesdk-Type-media-pipelines-chime_ActiveSpeakerOnlyConfiguration-ActiveSpeakerPosition"></a>
The position of the `ActiveSpeakerOnly` video tile.
Type: String
Valid Values: `TopLeft | TopRight | BottomLeft | BottomRight`
Required: No
