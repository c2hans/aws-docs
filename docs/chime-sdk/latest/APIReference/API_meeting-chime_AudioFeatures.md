# AudioFeatures
<a name="API_meeting-chime_AudioFeatures"></a>

An optional category of meeting features that contains audio-specific configurations, such as operating parameters for Amazon Voice Focus.

## Contents
<a name="API_meeting-chime_AudioFeatures_Contents"></a>

 ** EchoReduction **   <a name="chimesdk-Type-meeting-chime_AudioFeatures-EchoReduction"></a>
Makes echo reduction available to clients who connect to the meeting.
Type: String
Valid Values: `AVAILABLE | UNAVAILABLE`
Required: No
