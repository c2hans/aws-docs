# KinesisVideoStreamPoolSummary
<a name="API_media-pipelines-chime_KinesisVideoStreamPoolSummary"></a>

A summary of the Kinesis video stream pool.

## Contents
<a name="API_media-pipelines-chime_KinesisVideoStreamPoolSummary_Contents"></a>

 ** PoolArn **   <a name="chimesdk-Type-media-pipelines-chime_KinesisVideoStreamPoolSummary-PoolArn"></a>
The ARN of the video stream pool.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `^arn[\/\:\-\_\.a-zA-Z0-9]+$`
Required: No

 ** PoolId **   <a name="chimesdk-Type-media-pipelines-chime_KinesisVideoStreamPoolSummary-PoolId"></a>
The ID of the video stream pool.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `^[0-9a-zA-Z._-]+`
Required: No

 ** PoolName **   <a name="chimesdk-Type-media-pipelines-chime_KinesisVideoStreamPoolSummary-PoolName"></a>
The name of the video stream pool.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `^[0-9a-zA-Z._-]+`
Required: No
