# RecordingStreamConfiguration
<a name="API_media-pipelines-chime_RecordingStreamConfiguration"></a>

A structure that holds the settings for recording media.

## Contents
<a name="API_media-pipelines-chime_RecordingStreamConfiguration_Contents"></a>

 ** StreamArn **   <a name="chimesdk-Type-media-pipelines-chime_RecordingStreamConfiguration-StreamArn"></a>
The ARN of the recording stream.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `arn:[a-z\d-]+:kinesisvideo:[a-z0-9-]+:[0-9]+:[a-z]+/[a-zA-Z0-9_.-]+/[0-9]+`
Required: No
