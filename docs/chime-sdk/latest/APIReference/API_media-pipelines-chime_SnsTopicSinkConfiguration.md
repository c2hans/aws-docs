# SnsTopicSinkConfiguration
<a name="API_media-pipelines-chime_SnsTopicSinkConfiguration"></a>

The configuration settings for the SNS topic sink.

## Contents
<a name="API_media-pipelines-chime_SnsTopicSinkConfiguration_Contents"></a>

 ** InsightsTarget **   <a name="chimesdk-Type-media-pipelines-chime_SnsTopicSinkConfiguration-InsightsTarget"></a>
The ARN of the SNS sink.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `^arn[\/\:\-\_\.a-zA-Z0-9]+$`
Required: No
