# SqsQueueSinkConfiguration
<a name="API_media-pipelines-chime_SqsQueueSinkConfiguration"></a>

The configuration settings for the SQS sink.

## Contents
<a name="API_media-pipelines-chime_SqsQueueSinkConfiguration_Contents"></a>

 ** InsightsTarget **   <a name="chimesdk-Type-media-pipelines-chime_SqsQueueSinkConfiguration-InsightsTarget"></a>
The ARN of the SQS sink.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `^arn[\/\:\-\_\.a-zA-Z0-9]+$`
Required: No
