# S3BucketSinkConfiguration
<a name="API_media-pipelines-chime_S3BucketSinkConfiguration"></a>

The configuration settings for the S3 bucket.

## Contents
<a name="API_media-pipelines-chime_S3BucketSinkConfiguration_Contents"></a>

 ** Destination **   <a name="chimesdk-Type-media-pipelines-chime_S3BucketSinkConfiguration-Destination"></a>
The destination URL of the S3 bucket.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Pattern: `^arn[\/\:\-\_\.a-zA-Z0-9]+$`
Required: Yes
