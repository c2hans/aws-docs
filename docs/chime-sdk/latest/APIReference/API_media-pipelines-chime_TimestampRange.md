# TimestampRange
<a name="API_media-pipelines-chime_TimestampRange"></a>

The range of timestamps to return.

## Contents
<a name="API_media-pipelines-chime_TimestampRange_Contents"></a>

 ** EndTimestamp **   <a name="chimesdk-Type-media-pipelines-chime_TimestampRange-EndTimestamp"></a>
The ending timestamp for the specified range.
Type: Timestamp
Required: Yes

 ** StartTimestamp **   <a name="chimesdk-Type-media-pipelines-chime_TimestampRange-StartTimestamp"></a>
The starting timestamp for the specified range.
Type: Timestamp
Required: Yes
