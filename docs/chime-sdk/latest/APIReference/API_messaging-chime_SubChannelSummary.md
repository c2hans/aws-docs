# SubChannelSummary
<a name="API_messaging-chime_SubChannelSummary"></a>

Summary of the sub-channels associated with the elastic channel.

## Contents
<a name="API_messaging-chime_SubChannelSummary_Contents"></a>

 ** MembershipCount **   <a name="chimesdk-Type-messaging-chime_SubChannelSummary-MembershipCount"></a>
The number of members in a SubChannel.
Type: Integer
Required: No

 ** SubChannelId **   <a name="chimesdk-Type-messaging-chime_SubChannelSummary-SubChannelId"></a>
The unique ID of a SubChannel.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `[-_a-zA-Z0-9]*`
Required: No
