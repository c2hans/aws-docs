# Tag
<a name="API_messaging-chime_Tag"></a>

A tag object containing a key-value pair.

## Contents
<a name="API_messaging-chime_Tag_Contents"></a>

 ** Key **   <a name="chimesdk-Type-messaging-chime_Tag-Key"></a>
The key in a tag.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** Value **   <a name="chimesdk-Type-messaging-chime_Tag-Value"></a>
The value in a tag.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes
