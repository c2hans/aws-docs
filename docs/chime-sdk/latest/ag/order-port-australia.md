# Australia
<a name="order-port-australia"></a>

The following tables list and describe the requirements for ordering and porting phone numbers in Australia.

**Ordering phone numbers**

- **Amazon Chime SDK SDK SIP media application dial-in**
  - **Number types:** Local / **ID requirements:** Yes / **Acceptable ID types:** +  Business address <br />+  Proof of location Business addresses must have the same geographic zone as their corresponding phone numbers.
  - **Number types:** Toll-free / **ID requirements:** Yes / **Acceptable ID types:** +  Business address International addresses accepted.

**Porting phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **Required ID:**  +  Last invoice from current provider <br />+  Letter of Authorization
  - **Number types:** Toll-free / **Required ID:**  +  Last invoice from current provider <br />+  Letter of Authorization
