# Australia
<a name="order-port-australia"></a>

The following tables list and describe the requirements for ordering and porting phone numbers in Australia.

**Ordering phone numbers**

- **Amazon Chime SDK SDK SIP media application dial-in**
  - **Number types:** Local / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-australia.html)Business addresses must have the same geographic zone as their corresponding phone numbers.
  - **Number types:** Toll-free / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-australia.html)International addresses accepted.

**Porting phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **Required ID:**  [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-australia.html)
  - **Number types:** Toll-free / **Required ID:**  [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-australia.html)
