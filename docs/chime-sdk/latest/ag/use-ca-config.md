# Using call analytics configurations
<a name="use-ca-config"></a>

After you create a configuration, you use it by associating it with one or more Amazon Chime SDK Voice Connectors. For more information, refer to [Configuring Voice Connectors to use call analytics](configure-voicecon.md), earlier in this guide.
