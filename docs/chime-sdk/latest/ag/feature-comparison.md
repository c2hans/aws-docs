# Amazon Chime SDK Voice Connector and Amazon Connect Customer feature comparison
<a name="feature-comparison"></a>

The following table compares the full capabilities of Amazon Chime SDK Voice Connector and Amazon Connect Customer.

| Capability | Amazon Chime SDK Voice Connector | Amazon Connect Customer |
| --- | --- | --- |
| SIP trunking (PBX to PSTN) | Yes | No |
| Multisite SIP routing | Yes | No |
| Meeting dial-in and dial-out | Yes | No |
| Agentic self-service (voice and chat) | No | Yes, AI-native, dynamic, generative |
| Agent routing and queuing | No | Yes, skill-based, priority-based |
| AI agents (agentic voice and chat) | No | Yes, context-aware, autonomous |
| Omnichannel | No | Yes, voice, chat, email, SMS, WhatsApp, and video |
| Conversational analytics | No | Yes, transcription, sentiment, themes |
| Workforce management | No | Yes, forecasting, scheduling, evaluations |
| Outbound campaigns | No | Yes, predictive, progressive, preview |
| Customer Profiles | No | Yes |
| Number masking | No | Yes |
| In-app, web, and video calling | No | Yes, built on Amazon Chime SDK |
| Pay-as-you-go pricing | Yes | Yes |
