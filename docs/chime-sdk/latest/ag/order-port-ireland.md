# Ireland
<a name="order-port-ireland"></a>

The following tables list and describe the requirements for ordering and porting phone numbers in Ireland.

**Ordering phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-ireland.html)Business addresses must be located in the same geographic regions as their corresponding phone numbers.
  - **Number types:** Universal access and VOIP prefixes: \+353 0818, \+353 076 / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-ireland.html)Address must be located in the country.
  - **Number types:** Toll-free / **ID requirements:** Yes / **Acceptable ID types:** Your business address and a copy of the business registration. A global address is acceptable.

**Porting phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **Required ID:**  [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-ireland.html)
  - **Number types:** Toll-free / **Required ID:**  [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-ireland.html)
