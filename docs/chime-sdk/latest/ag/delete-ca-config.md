# Deleting call analytics configurations
<a name="delete-ca-config"></a>

The steps in this section explain how to permanently delete an Amazon Chime SDK call analytics configuration.

**Important**
You cannot undo a deletion.

**To delete a configuration**

1. Open the Amazon Chime SDK console at [https://console.aws.amazon.com/chime-sdk/home](https://console.aws.amazon.com/chime-sdk/home).

1. In the navigation pane, under **Call Analytics**, choose **Configurations**, then choose the radio button next to the configuration that you want to delete.

1. Choose **Delete**.

1. In the **Delete configuration** dialog box, enter **confirm** to confirm the deletion, then choose **Delete**.
