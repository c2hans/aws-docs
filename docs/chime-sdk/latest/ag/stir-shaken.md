# STIR/SHAKEN for Amazon Chime SDK
<a name="stir-shaken"></a>

Amazon Chime SDK follows the same standards and policies as Connect Customer regarding STIR/SHAKEN attestation of outbound calls. For more information, see [Stir/Shaken attestation in Connect Customer](https://docs.aws.amazon.com/connect/latest/adminguide/stirshaken.html) in the *Connect Customer Administrator Guide*.
