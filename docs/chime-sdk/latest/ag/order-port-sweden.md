# Sweden
<a name="order-port-sweden"></a>

The following tables list and describe the requirements for ordering and porting phone numbers in Sweden.

**Ordering phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **ID requirements:** Yes / **Acceptable ID types:**  [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-sweden.html)
  - **Number types:** Toll-free / **ID requirements:** Yes / **Acceptable ID types:**  [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-sweden.html)

**Porting phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **Required ID:**  [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-sweden.html)
  - **Number types:** Toll-free / **Required ID:**  [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-sweden.html)
