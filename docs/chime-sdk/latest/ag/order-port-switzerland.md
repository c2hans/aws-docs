# Switzerland
<a name="order-port-switzerland"></a>

The following tables list and describe the requirements for ordering and porting phone numbers in Switzerland.

**Ordering phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-switzerland.html)Business addresses must have the same geographic zone as their corresponding phone numbers.
  - **Number types:** Business number prefixes: \+41 051, \+41 058 / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-switzerland.html)Address must be located in the country.
  - **Number types:** Toll-free / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-switzerland.html)Foreign address acceptable

**Porting phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **Required ID:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-switzerland.html)Foreign addresses acceptable
  - **Number types:** Toll-free / **Required ID:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-switzerland.html)Address must be within the country.
