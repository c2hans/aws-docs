# Switzerland
<a name="order-port-switzerland"></a>

The following tables list and describe the requirements for ordering and porting phone numbers in Switzerland.

**Ordering phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **ID requirements:** Yes / **Acceptable ID types:** +  Business address <br />+  Proof of location <br />+  A copy of business registration, or a copy of your ID, if you're an individual Business addresses must have the same geographic zone as their corresponding phone numbers.
  - **Number types:** Business number prefixes: \+41 051, \+41 058 / **ID requirements:** Yes / **Acceptable ID types:** +  Business address Address must be located in the country.
  - **Number types:** Toll-free / **ID requirements:** Yes / **Acceptable ID types:** +  Business address <br />+  A copy of business registration, or a copy of your ID, if you're an individual Foreign address acceptable

**Porting phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **Required ID:** +  Last invoice from current provider <br />+  Letter of Authorization <br />+  Business address Foreign addresses acceptable
  - **Number types:** Toll-free / **Required ID:** +  Last invoice from current provider <br />+  Letter of Authorization <br />+  Business address <br />+  Certificate from NRAs  Address must be within the country.
