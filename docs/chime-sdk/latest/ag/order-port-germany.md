# Germany
<a name="order-port-germany"></a>

The following tables list and describe the requirements for ordering and porting phone numbers in Germany.

**Ordering phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-germany.html)Business addresses must have the same geographic zone as their corresponding phone numbers.
  - **Number types:** National prefixes: \+49 32 / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-germany.html)Address must be located in the country.
  - **Number types:** Toll-free / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-germany.html)Address must be located in the country. <br />You must first obtain the number directly from the local regulator. Details about the process are provided when you make the request.

**Porting phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **Required ID:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-germany.html)Business addresses must have the same geographic zone as their corresponding phone numbers.
  - **Number types:** Toll-free / **Required ID:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-germany.html)You must first obtain the number directly from the local regulator. Details about the process are provided when you make the request
