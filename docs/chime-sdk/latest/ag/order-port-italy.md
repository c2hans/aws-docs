# Italy
<a name="order-port-italy"></a>

The following tables list and describe the requirements for ordering and porting phone numbers in Italy.

**Ordering phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **ID requirements:** Yes / **Acceptable ID types:** +  Business address <br />+  Proof of location <br />+  Copy of business registration <br />+  Passport or end-user ID Business addresses must be located in the same geographic regions as their corresponding phone numbers.
  - **Number types:** Toll-free / **ID requirements:** No / **Acceptable ID types:** N/A

**Porting phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **Required ID:**  +  Last invoice from current provider <br />+  Letter of Authorization <br />+  Copy of the company representative's passport or ID <br />+  Copy of the local business registration, or proof of address for an individual
  - **Number types:** Toll-free / **Required ID:**  +  Last invoice from current provider <br />+  Letter of Authorization
