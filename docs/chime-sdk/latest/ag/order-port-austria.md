# Austria
<a name="order-port-austria"></a>

The following tables list and describe the requirements for ordering and porting phone numbers in Austria.

**Ordering phone numbers**

- **SIP media application dial-in**
  - **Number types:** Local / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-austria.html)Business addresses must have the same geographic zone as their corresponding phone numbers.
  - **Number types:** National prefixes: \+43 720 / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-austria.html)Address must be located in the country.
  - **Number types:** Toll-free / **ID requirements:** Yes / **Acceptable ID types:** [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-austria.html)Foreign address acceptable

**Porting phone numbers**

- **SIP Media Application Dial-In**
  - **Number types:** Local / **Required ID:**  [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-austria.html)
  - **Number types:** Toll-free / **Required ID:**  [See the AWS documentation website for more details](http://docs.aws.amazon.com/chime-sdk/latest/ag/order-port-austria.html)
