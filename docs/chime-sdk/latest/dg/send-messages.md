# Sending messages in Amazon Chime SDK messaging
<a name="send-messages"></a>

Use the [SendChannelMessage](https://docs.aws.amazon.com/chime-sdk/latest/APIReference/API_messaging-chime_SendChannelMessage.html) API to send messages. Sample code is available in a [sample application on GitHub](https://github.com/aws-samples/amazon-chime-sdk/tree/main/apps/chat).
