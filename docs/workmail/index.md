# Amazon WorkMail Documentation

Amazon WorkMail is a managed email and calendaring service that offers strong security controls and support for existing desktop and mobile clients.

- [User Guide](/workmail/latest/userguide/what_is.html): Helps you configure your desktop email client or mobile device for Amazon WorkMail, and use the Amazon WorkMail web application.
- [Administrator Guide](/workmail/latest/adminguide/what_is.html): Helps you perform administrative tasks for Amazon WorkMail, such as setting up Amazon WorkMail for your organization, adding a domain, and managing users, groups, and mobile devices.
- [API Reference](/workmail/latest/APIReference/Welcome.html): Describes the API operations for Amazon WorkMail.
