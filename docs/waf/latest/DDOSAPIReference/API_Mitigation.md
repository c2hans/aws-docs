# Mitigation
<a name="API_Mitigation"></a>

## Contents
<a name="API_Mitigation_Contents"></a>

 ** MitigationName **   <a name="AWSShield-Type-Mitigation-MitigationName"></a>
The name of the mitigation taken for this attack.
Type: String
Required: No
