# DisableBedrockGuardrails

Turns off the use of Amazon Bedrock Guardrails in the AI security managed rule group. The rule group continues to run its own inspections.

This is used in the `BedrockGuardrails` setting of `AWSManagedRulesAISecurityRuleSet`.

JSON specification: `"Disable": {}`
