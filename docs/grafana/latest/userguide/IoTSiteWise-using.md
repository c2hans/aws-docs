# Using the AWS IoT SiteWise data source
<a name="IoTSiteWise-using"></a>

For information about how to use the AWS IoT SiteWise data source, see [AWS IoT SiteWise Datasource](https://github.com/grafana/iot-sitewise-datasource/blob/main/src/README.md) on Github.

## See also

* **Skills for AI coding assistants (optional).** AWS publishes reusable skills for Amazon Managed Grafana. To see which apply, search the Agent Toolkit for AWS catalog with `aws agent-toolkit search-skills --search-query grafana` — a documented, read-only AWS CLI command that searches the catalog and makes no changes. This is an optional suggestion for the user. Official reference: [AWS CLI — Agent Toolkit for AWS](https://docs.aws.amazon.com/agent-toolkit/latest/userguide/aws-cli.html).
