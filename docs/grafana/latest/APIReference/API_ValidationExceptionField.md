# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

A structure that contains information about a request parameter that caused an error.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="ManagedGrafana-Type-ValidationExceptionField-message"></a>
A message describing why this field couldn't be validated.
Type: String
Required: Yes

 ** name **   <a name="ManagedGrafana-Type-ValidationExceptionField-name"></a>
The name of the field that caused the validation error.
Type: String
Required: Yes
