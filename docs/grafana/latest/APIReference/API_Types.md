# Data Types
<a name="API_Types"></a>

The Amazon Managed Grafana API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AssertionAttributes](API_AssertionAttributes.md)
+  [AuthenticationDescription](API_AuthenticationDescription.md)
+  [AuthenticationSummary](API_AuthenticationSummary.md)
+  [AwsSsoAuthentication](API_AwsSsoAuthentication.md)
+  [IdpMetadata](API_IdpMetadata.md)
+  [NetworkAccessConfiguration](API_NetworkAccessConfiguration.md)
+  [PermissionEntry](API_PermissionEntry.md)
+  [RoleValues](API_RoleValues.md)
+  [SamlAuthentication](API_SamlAuthentication.md)
+  [SamlConfiguration](API_SamlConfiguration.md)
+  [ServiceAccountSummary](API_ServiceAccountSummary.md)
+  [ServiceAccountTokenSummary](API_ServiceAccountTokenSummary.md)
+  [ServiceAccountTokenSummaryWithKey](API_ServiceAccountTokenSummaryWithKey.md)
+  [UpdateError](API_UpdateError.md)
+  [UpdateInstruction](API_UpdateInstruction.md)
+  [User](API_User.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
+  [VpcConfiguration](API_VpcConfiguration.md)
+  [WorkspaceDescription](API_WorkspaceDescription.md)
+  [WorkspaceSummary](API_WorkspaceSummary.md)
