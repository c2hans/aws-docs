# Geographical redundancy
<a name="telcoops07"></a>

| TELCOOPS07: How do you address geographical redundancy requirements within data residency constraints? |
| --- |
|   |

 Telecommunication service providers often face strict requirements for geographical redundancy (for example, 200 or more kilometers of separation) while simultaneously needing to comply with data residency regulations. This creates unique challenges in cloud environments where multiple regions within a single country may not be available. This question explores strategies for balancing redundancy needs with regulatory adherence in cloud-based telecommunication architectures.
