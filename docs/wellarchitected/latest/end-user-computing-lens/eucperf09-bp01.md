# EUCPERF09-BP01 Follow AWS EUC news sources
<a name="eucperf09-bp01"></a>

 Many customers can benefit from keeping up with news from software publishers and partners in the end user computing domain. Stay updated on developments by following news feeds and social media.

 **Level of risk exposed if this best practice is not established:** Low

## Implementation guidance
<a name="implementation-guidance-22"></a>

 Subscribe to AWS feeds and blogs to keep up to date. Follow the [Desktop and Application Streaming blog](https://aws.amazon.com/blogs/desktop-and-application-streaming/) and [End User Computing What's New Feed](https://aws.amazon.com/new/?whats-new-content-all.sort-by=item.additionalFields.postDateTime&whats-new-content-all.sort-order=desc&awsf.whats-new-categories=marketing-marchitecture%23desktop-and-app-streaming).
