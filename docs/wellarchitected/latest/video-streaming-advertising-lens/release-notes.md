# Release notes
<a name="release-notes"></a>

## New lens version (11-10-2026)
<a name="update-2026-11-10"></a>

Key changes in this release:
+ **Best practice expansion:** All best practices have been expanded to cover Desired outcome, Common anti-patterns, Benefits of establishing the best practice, and Level of risk.
+ **Scenarios expanded:** New reference scenarios were added for AWS RTB Fabric, advertising agents using the Ad Context Protocol and the IAB Tech Lab Agentic RTB Framework, Prebid Server, server-guided ad insertion, FAST channel playout, contextual advertising with non-intrusive ads, and unified AdSales for converged television.
+ **Design principles reworked:** New themes cover designing for generative and agentic AI and designing publisher monetization for automation and linear and digital convergence.
+ **Operational excellence:** New capabilities were added for server-guided ad insertion operations, FAST channel operations, and continuous yield optimization, along with guidance on AI content-licensing traffic, unified campaign operations, Prebid Server integration, and shoppable-ad measurement.
+ **Security:** The pillar was consolidated into fewer capabilities, folding fraud detection, brand safety, and supply-chain transparency into a single content-integrity capability and merging regulatory adherence with user privacy. Supply-chain transparency was expanded across the full ads.txt, sellers.json, app-ads.txt, and SupplyChain object stack, and new coverage was added for converged delivery, including cross-platform identity, SCTE-35 feed integrity, confidential-computing measurement, and server-side ad insertion integrity.
+ **Reliability:** New advertising-specific resilience capabilities were added for RTB Fabric, media playout and ad formats, Prebid Server, and linear and digital convergence. Partner-SLA monitoring was added, while generic fault-tolerance evaluation and standalone backup guidance were removed.
+ **Cost optimization:** New cost domains were added for agentic AI, media delivery and creative, and converged ad-sales systems, and RTB connectivity, traffic-shaping, and compute right-sizing guidance was substantially expanded. Non-advertising generative AI cost mechanisms, such as prompt caching and inference pricing, are now consolidated here.
+ **Performance efficiency:** Media delivery performance capability covering Agentic RTB Framework agents, Prebid Server timeout budgets, server-guided ad-break latency, and contextual pre-classification. New guidance was also added for AI-agent serverless compute, low-latency storage, and a managed low-latency RTB network fabric.
+ **Sustainability:** Added new guidance on bid-stream waste, RTB Fabric efficiency, and agentic AI workloads.
