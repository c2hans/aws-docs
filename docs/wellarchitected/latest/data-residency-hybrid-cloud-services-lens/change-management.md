# Change management
<a name="change-management"></a>

| DRHCREL04: Have you planned your hybrid storage, compute, and network capacity ahead of time? |
| --- |
|   |

 As part of the [AWS Shared Responsibility Model](https://aws.amazon.com/compliance/shared-responsibility-model), customers are responsible for capacity planning while using AWS Outposts. Customers must forecast compute and storage needs in addition to data center space, power, and HVAC requirements along with associated lead times.
