# ProfileQuestionUpdate
<a name="API_ProfileQuestionUpdate"></a>

An update to a profile question.

## Contents
<a name="API_ProfileQuestionUpdate_Contents"></a>

 ** QuestionId **   <a name="wellarchitected-Type-ProfileQuestionUpdate-QuestionId"></a>
The ID of the question.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: No

 ** SelectedChoiceIds **   <a name="wellarchitected-Type-ProfileQuestionUpdate-SelectedChoiceIds"></a>
The selected choices.
Type: Array of strings
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No
