# Insight
<a name="API_Insight"></a>

An insight describing a usage pattern and the signals detected.

## Contents
<a name="API_Insight_Contents"></a>

 ** usagePattern **   <a name="wellarchitected-Type-Insight-usagePattern"></a>
A description of the usage pattern.
Type: String
Length Constraints: Minimum length of 100. Maximum length of 2000.
Required: Yes

 ** signalsDetected **   <a name="wellarchitected-Type-Insight-signalsDetected"></a>
A description of the signals detected.
Type: String
Length Constraints: Minimum length of 30. Maximum length of 1500.
Required: No
