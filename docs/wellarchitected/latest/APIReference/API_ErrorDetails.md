# ErrorDetails
<a name="API_ErrorDetails"></a>

Details about an error that occurred during recommendation generation.

## Contents
<a name="API_ErrorDetails_Contents"></a>

 ** code **   <a name="wellarchitected-Type-ErrorDetails-code"></a>
The status code identifying the type of error.
Type: String
Required: Yes

 ** message **   <a name="wellarchitected-Type-ErrorDetails-message"></a>
A human-readable description of the error.
Type: String
Required: Yes
