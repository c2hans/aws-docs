# JiraConfiguration
<a name="API_JiraConfiguration"></a>

Configuration of the Jira integration.

## Contents
<a name="API_JiraConfiguration_Contents"></a>

 ** JiraIssueUrl **   <a name="wellarchitected-Type-JiraConfiguration-JiraIssueUrl"></a>
The URL of the associated Jira issue.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: No

 ** LastSyncedTime **   <a name="wellarchitected-Type-JiraConfiguration-LastSyncedTime"></a>
The date and time recorded in Unix format (seconds).
Type: Timestamp
Required: No
