# ResourceLink
<a name="API_ResourceLink"></a>

An external reference associated with remediation steps.

## Contents
<a name="API_ResourceLink_Contents"></a>

 ** url **   <a name="wellarchitected-Type-ResourceLink-url"></a>
The URL of the external reference.
Type: String
Length Constraints: Minimum length of 10. Maximum length of 16384.
Required: Yes

 ** title **   <a name="wellarchitected-Type-ResourceLink-title"></a>
An optional human-readable title for the link.
Type: String
Length Constraints: Minimum length of 3. Maximum length of 100.
Required: No
