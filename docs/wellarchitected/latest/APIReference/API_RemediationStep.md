# RemediationStep
<a name="API_RemediationStep"></a>

One step within a remediation procedure.

## Contents
<a name="API_RemediationStep_Contents"></a>

 ** content **   <a name="wellarchitected-Type-RemediationStep-content"></a>
The content describing the step, which can include code examples and verification checklists.
Type: String
Length Constraints: Minimum length of 80. Maximum length of 8000.
Required: Yes

 ** title **   <a name="wellarchitected-Type-RemediationStep-title"></a>
An optional short label for the step.
Type: String
Length Constraints: Minimum length of 3. Maximum length of 80.
Required: No
