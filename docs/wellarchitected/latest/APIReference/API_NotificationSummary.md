# NotificationSummary
<a name="API_NotificationSummary"></a>

Type: [LensUpgradeSummary](API_LensUpgradeSummary.md) object

 ** Type **   <a name="wellarchitected-Type-NotificationSummary-Type"></a>
The type of notification.
Type: String
Valid Values: `LENS_VERSION_UPGRADED | LENS_VERSION_DEPRECATED`
Required: No
