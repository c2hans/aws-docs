# Roi
<a name="API_Roi"></a>

A return-on-investment estimate with context.

## Contents
<a name="API_Roi_Contents"></a>

 ** detail **   <a name="wellarchitected-Type-Roi-detail"></a>
A sentence providing context for the estimate.
Type: String
Length Constraints: Minimum length of 30. Maximum length of 300.
Required: Yes

 ** estimate **   <a name="wellarchitected-Type-Roi-estimate"></a>
A short statistic or key metric. Optional when there is no quantifiable figure.
Type: String
Length Constraints: Minimum length of 2. Maximum length of 40.
Required: No
