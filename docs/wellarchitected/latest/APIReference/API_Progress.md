# Progress
<a name="API_Progress"></a>

Progress information for a recommendation generation process.

## Contents
<a name="API_Progress_Contents"></a>

 ** completionPercentage **   <a name="wellarchitected-Type-Progress-completionPercentage"></a>
The completion percentage of the generation process (0-100).
Type: Double
Required: Yes

 ** stepsCompleted **   <a name="wellarchitected-Type-Progress-stepsCompleted"></a>
The number of generation steps that have been completed.
Type: Integer
Required: Yes

 ** totalSteps **   <a name="wellarchitected-Type-Progress-totalSteps"></a>
The total number of steps in the generation process.
Type: Integer
Required: Yes
