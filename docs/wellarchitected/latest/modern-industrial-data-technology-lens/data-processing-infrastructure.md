# Data processing infrastructure
<a name="data-processing-infrastructure"></a>

| MIDAPERF03: How do you measure performance of infrastructure that processes your data? |
| --- |
|   |

 Effective manufacturing infrastructure performance is measured through comprehensive metrics that track both throughput capacity and processing latency across the production data pipeline. Plant managers typically establish baseline KPIs for data processing systems, monitoring factors such as equipment data capture rates, analytics processing times, and dashboard refresh rates to base operational decisions on timely information.
