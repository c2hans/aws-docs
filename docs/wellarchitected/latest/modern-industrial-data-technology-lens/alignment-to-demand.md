# Alignment to demand
<a name="alignment-to-demand"></a>

| MIDASUS02: How do you optimize manufacturing workloads to align with production demands? |
| --- |
|   |

 Manufacturing IT infrastructures support various operational patterns - from enterprise planning systems and product design workflows to shop floor operations and seasonal demand variations. By optimizing cloud resources to match these actual production demands, manufacturers can reduce environmental impact without compromising operational efficiency.
