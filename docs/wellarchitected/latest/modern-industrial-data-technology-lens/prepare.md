# Prepare
<a name="prepare"></a>

|  MIDAOPS01: How do you assess your industrial data workload against compliance requirements?  |
| --- |
|   |

 Industrial data workloads must comply with relevant regulatory requirements and industry standards. Establishing a systematic approach to compliance assessment helps you continually adhere to relevant standards while maintaining data integrity and security in industrial data infrastructure.

|  MIDAOPS02: How do you observe the health of your industrial data infrastructure?  |
| --- |
|   |

 Industrial data infrastructure requires comprehensive monitoring across edge devices, networks, and cloud resources for reliable manufacturing operations. Effective observation of infrastructure health is crucial for maintaining data quality, system availability, and operational continuity from the shop floor to the cloud.
