# Identity and access management
<a name="identity-and-access-management"></a>

|  MIDASEC02: How do you establish identity controls and access management patterns between industrial systems and humans?  |
| --- |
|   |

 Establish secure identity controls and access management patterns between industrial systems and human operators in manufacturing environments. This emphasizes proper authentication, authorization, and security policies to help protect both IT and OT systems while providing appropriate access levels for different roles in the manufacturing environment.
