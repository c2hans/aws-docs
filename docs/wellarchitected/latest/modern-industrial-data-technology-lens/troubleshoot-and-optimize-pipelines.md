# Troubleshoot and optimize pipelines
<a name="troubleshoot-and-optimize-pipelines"></a>

|  MIDAPERF04: How do you troubleshoot and optimize your machine performance data ingestion and processing pipelines?  |
| --- |
|   |

 Manufacturing data pipelines require systematic troubleshooting protocols that isolate bottlenecks from sensor collection points through to visualization systems, providing production teams reliable access to equipment performance metrics. Advanced plants implement automated monitoring systems that continuously validate data quality and pipeline throughput, triggering alerts when latency increases or data gaps emerge, thereby maintaining the integrity of performance analytics used for critical production decisions.
