# Foundations
<a name="gamerel-f"></a>

 To achieve reliability, a system must have a well-planned foundation and monitoring in place with mechanisms for handling changes in demand or requirements. The system should be designed to detect failure and automatically heal itself.

 There are no foundations best practices specific to the Games Lens. Refer to the Well-Architected Framework whitepaper for best practices in [foundations](https://docs.aws.amazon.com/wellarchitected/latest/reliability-pillar/foundations.html) for reliability that apply to games workloads.
