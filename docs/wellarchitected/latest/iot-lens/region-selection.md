# Region selection
<a name="region-selection"></a>

 There are no best practices specific to region selection in the IoT Lens. Refer to the design principles discussed earlier as well as the [guidance](https://docs.aws.amazon.com/wellarchitected/latest/sustainability-pillar/region-selection.html) provided in the Sustainability Pillar of the AWS Well-Architected Framework.
