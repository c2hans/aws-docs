# Migration methodology
<a name="migration-methodology"></a>

 AWS has published various blogs, prescriptive guidance, and whitepapers to help customers plan and complete their migrations using migration methodology. This includes vetted solutions and guidance for business and technical use cases. For more information on our technical solutions, see:
+ [AWS Solutions Library](https://aws.amazon.com/solutions/)
+ [AWS Prescriptive Guidance](https://aws.amazon.com/prescriptive-guidance)
+ [AWS Whitepapers & Guides](https://aws.amazon.com/whitepapers)
+ [Oracle Applications on AWS resources](https://aws.amazon.com/oracle-apps/resources/)

For details on the AWS three-phase migration process, see [How to migrate](https://aws.amazon.com/cloud-migration/how-to-migrate/).
