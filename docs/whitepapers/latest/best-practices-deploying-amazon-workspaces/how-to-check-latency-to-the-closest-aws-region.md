# How to check latency to the closest AWS Region
<a name="how-to-check-latency-to-the-closest-aws-region"></a>

 The [Connection Health Check website](https://clients.amazonworkspaces.com/Health.html) quickly checks whether all the required services that use Amazon WorkSpaces can be reached. It also does a performance check to each AWS Region where Amazon WorkSpaces is available, and lets users know which one will be the fastest.
