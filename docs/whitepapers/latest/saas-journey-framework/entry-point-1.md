# Entry Point
<a name="entry-point-1"></a>

 The SaaS journey often begins with some notion of a product vision. To get here, you likely already have some view of what features and customer experience you are targeting. Yet, this vision generally lacks detail as you enter this phase of the SaaS journey. In the product strategy and roadmap development phase, we are looking to fill in all of the detail about the product, create a clearer picture of which features will be included, define how the product will be consumed, and how we expect to deliver value to different types of customers.
