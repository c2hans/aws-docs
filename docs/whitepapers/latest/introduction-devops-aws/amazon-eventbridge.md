# Amazon EventBridge
<a name="amazon-eventbridge"></a>

**Note**
 Amazon CloudWatch Events and EventBridge are the same underlying service and API, however, EventBridge provides more features.

[Amazon EventBridge](https://aws.amazon.com/eventbridge)is a serverless event bus that enables integrations between AWS services, Software as a services (SaaS), and your applications. In addition to build event driven applications, EventBridge can be used to notify about the events from the services such as CodeBuild, CodeDeploy, CodePipeline, and CodeCommit.
