# Amazon Managed Service for Prometheus
<a name="amazon-managed-service-for-prometheus"></a>

[Amazon Managed Service for Prometheus](https://aws.amazon.com/prometheus/) is a serverless monitoring service for metrics compatible with open-source Prometheus, making it easier for you to securely monitor and alert on container environments. Amazon Managed Service for Prometheus reduces the heavy lifting required to get started with monitoring applications across Amazon Elastic Kubernetes Service, Amazon Elastic Container Service, and AWS Fargate, as well as self-managed Kubernetes clusters.
