# AWS CloudShell
<a name="aws-cloudshell"></a>

[AWS CloudShell](https://aws.amazon.com/cloudshell/) is a browser-based shell that makes it easier to securely manage, explore, and interact with your AWS resources. AWS CloudShell is pre-authenticated with your console credentials. Common development and operations tools are pre-installed, so there’s no need to install or configure software on your local machine.
