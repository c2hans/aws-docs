# AWS Elastic Beanstalk
<a name="aws-elastic-beanstalk"></a>

 [AWS Elastic Beanstalk](https://aws.amazon.com/elasticbeanstalk) is a service to rapidly deploy and scale web applications developed with Java, .NET, PHP, Node.js, Python, Ruby, Go, and Docker on familiar servers such as Apache, NGINX, Passenger, and IIS.

 Elastic Beanstalk is an abstraction on top of Amazon EC2, Auto Scaling, and simplifies the deployment by giving additional features such as cloning, blue/green deployments, [Elastic Beanstalk Command Line Interface](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/eb-cli3.html) (EB CLI) and integration with [AWS Toolkit for Visual Studio](https://aws.amazon.com/visualstudio/), Visual Studio Code, Eclipse, and IntelliJ for increase developer productivity.
