# Modern Data architecture on AWS
<a name="modern-data-architecture-on-aws"></a>

 As data in data lakes, data warehouses, and purpose-built stores continues to grow, it becomes harder to move all this data around. We call this *data gravity*. To make decisions with speed and agility, you need to be able to use a central data lake and a ring of purpose-built data services around that data lake. You also need to acknowledge data gravity by easily moving the data you need between these data stores in a secure and governed way. AWS calls this modern approach to analytics the Modern Data Architecture. For more information, see the blog post [Build a Lake House Architecture on AWS](https://aws.amazon.com/blogs/big-data/build-a-lake-house-architecture-on-aws/).
