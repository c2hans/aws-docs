# Industry guidance
<a name="industry-guidance"></a>

The following guidance is at a minimum, a best practice for your environment. You should still work with your professionals to ensure you comply with applicable regulatory requirements.

The same basic principles that govern on-premises infrastructure qualification also apply to cloud-based systems. Therefore, this strategy uses a tactic of using and building upon that same industry guidance, using a cloud perspective, based on the following ISPE GAMP Good Practice Guides:
+ GAMP Good Practice Guide: IT Infrastructure Control and Compliance, Second Edition
+ GAMP 5: A Risk-Based Approach to Compliant GxP Computerized Systems
