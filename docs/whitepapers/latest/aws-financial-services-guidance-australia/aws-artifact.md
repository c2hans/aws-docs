# AWS Artifact
<a name="aws-artifact"></a>

 Customers can use [AWS Artifact](https://aws.amazon.com/artifact/) to review and download reports and details about more than 2,600 security controls. The AWS Artifact portal provides on-demand access to AWS security and compliance documents, including SOC reports, Payment Card Industry (PCI) reports, and certifications from accreditation bodies across geographies and compliance verticals.
