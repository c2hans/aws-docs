# Before you begin
<a name="before-you-begin"></a>

 Planning a VMware Cloud on AWS deployment requires a moderate level of familiarity with AWS. If you’re new to AWS, visit the [AWS Identity and Access Management](https://aws.amazon.com/iam/) (IAM) site and the [Amazon Virtual Private Cloud](https://aws.amazon.com/vpc/?vpc-blogs.sort-by=item.additionalFields.createdDate&vpc-blogs.sort-order=desc) (VPC) site. These will help provide you with the foundational constructs you need. These sites provide materials for learning how to design, deploy, and operate your infrastructure and applications on the AWS Cloud.
