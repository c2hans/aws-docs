# Magento versions
<a name="magento-versions"></a>

 Magento is available in two versions:
+ Magento Open Source (formerly known as Community Edition)
+ Magento Commerce

For version differences, see the [feature comparison on the Adobe Commerce website](https://magento.com/compare-open-source-and-magento-commerce).

Adobe Commerce Open Source is available only for self-hosting. Magento Commerce is available for self-hosting or as part of Magento Commerce Cloud, now known as [Adobe Commerce](https://business.adobe.com/products/magento/magento-commerce.html).
