# Building your environment on AWS
<a name="building-your-environment-on-aws"></a>

 The best way to get started building your environment on AWS is to use the AWS Solutions Implementation [Scale-Out Computing on AWS](https://aws.amazon.com/solutions/implementations/scale-out-computing-on-aws/) to launch your environment. AWS has many resources available to use on your own, but we suggest working with an AWS Solutions Architect to launch a test environment using Scale-Out Computing on AWS.
