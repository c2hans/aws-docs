# Additional Resources
<a name="additional-resources"></a>

See the following additional resources to help you get started running your semiconductor workloads on AWS.
+  For an overview of semiconductor, see the [Semiconductor Design on AWS whitepaper](https://docs.aws.amazon.com/whitepapers/latest/semiconductor-design-on-aws/semiconductor-design-on-aws.html).
+  For a comprehensive list of resources, see [Semiconductor and Electronics on AWS Resources](https://aws.amazon.com/manufacturing/semiconductor-electronics/resources/)
+  For infrastructure setup and automation, see AWS Solutions Implementation [Scale-Out Computing on AWS](https://aws.amazon.com/solutions/implementations/scale-out-computing-on-aws/).
+  For addition information for how AWS can help run your workflows, see [Semiconductor and Electronics on AWS](https://aws.amazon.com/manufacturing/semiconductor-electronics/).
+  For a hands-on workshop, contact your Account Manager or Solutions Architect. AWS offers hands-on workshops that go through the process of launching your environment on AWS and running a test workload in the same day.
