# Verifying your configuration
<a name="verifying-your-configuration"></a>

 After you configure your environment based on the IOPS and throughput numbers necessary for your environment, you can verify your configuration before you install the database with the Oracle Orion tool, which is available from Oracle. Oracle Orion simulates Oracle Database I/O workloads using the same I/O software stack as Oracle Database, which provides a measurement of IOPS and throughput that simulates what your database will experience. For more details about this tool and to download it, refer to the [Oracle](http://www.oracle.com/index.html) website.
