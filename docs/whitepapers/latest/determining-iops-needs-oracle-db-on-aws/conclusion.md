# Conclusion
<a name="conclusion"></a>

 AWS provides the option to run Oracle in Amazon RDS or Amazon EC2. Choose RDS for a fully managed service, or EC2 if you prefer full control.

 AWS offers various storage services that allow the workload to optimized for cost or performance. As workloads and requirements change, the solution can scale up or down elastically.
