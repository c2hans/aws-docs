# Data visualization
<a name="data-visualization"></a>

 [Quick](https://aws.amazon.com/quicksight) is a serverless BI tool that allows users to create visualizations and dashboards from your data. QuickSight can connect to many different data stores like Amazon S3, on-premises databases, Salesforce, Amazon RDS, Amazon Redshift, and more. With QuickSight, you can create dashboards for many gaming-specific use cases. QuickSight has ML insights built directly into the platform, where it can potentially detect fraud or an anomaly in player activity. QuickSight can also be used in conjunction with AWS CloudTrail, to help monitor, visualize, and audit your data lake operations.

 For more information, refer to [Run usage analytics on Quick using AWS CloudTrail](https://aws.amazon.com/blogs/big-data/run-usage-analytics-on-amazon-quicksight-using-aws-cloudtrail/) and [Ingest and visualize streaming data for games](https://aws.amazon.com/blogs/gametech/ingest-and-visualize-streaming-data-for-games/).
