# Resources
<a name="resources"></a>

There are numerous resources to help you get start with running your semiconductor workloads on AWS. Here are a few links that serve as top-level starting points:
+  For a comprehensive list of resources, see the [Semiconductor and Electronics on AWS Resources](https://aws.amazon.com/manufacturing/semiconductor-electronics/resources/) page. On this page you will find:
+  Whitepapers
+  Blogs and articles
+  Reference architectures
+  Videos and webinars
+  Technical tools and training
+  For infrastructure setup and automation, see [Scale-Out Computing on AWS](https://aws.amazon.com/solutions/implementations/scale-out-computing-on-aws/).
+  For addition information on how AWS can help run your workflows, see the official [Semiconductor and Electronics on AWS](https://aws.amazon.com/manufacturing/semiconductor-electronics/) website.
