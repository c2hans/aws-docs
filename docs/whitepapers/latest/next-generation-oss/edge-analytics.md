# Edge Analytics
<a name="edge-analytics"></a>

 Edge Analytics is an extension of the DSP Network Analytics solution. It provides the required analytics capabilities for low latency use cases by providing network functions with the capabilities to make real-time decisions based on users’ behaviors and network conditions. NFx such as near real-time RIC and distributed Network Data Analytics Function (NWDAF) require proximity with the network, the ability to scale, and support for innovation such as the deployment of new optimization algorithms.

 [AWS Outposts](https://aws.amazon.com/outposts/) (Outposts) is a service that addresses Edge Analytics use cases. It is a fully managed service that offers the same AWS infrastructure, AWS services, APIs, and tools to DSPs’ on-premises edge location. It provides you with a consistent development experience for your network analytics solution. For example, an [EMR](https://aws.amazon.com/emr) cluster can be spinned up on Amazon Outposts that contains 5G Core network functions, and it can feed of off performance events created by each NFx to provide a near-real time recommendation to the network.
