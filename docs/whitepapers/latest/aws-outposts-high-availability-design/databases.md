# Databases
<a name="databases"></a>

[Amazon Relational Database Service (RDS) on AWS Outposts](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/rds-on-outposts.html) extends RDS for SQL Server, RDS for MySQL and RDS for PostgreSQL databases to AWS Outposts deployments. For those deployments where a highly available architecture must be provided, Amazon RDS support [Multi-AZ instances deployment for PostgreSQL and MySQL on AWS Outposts](https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/rds-on-outposts.maz.html).
