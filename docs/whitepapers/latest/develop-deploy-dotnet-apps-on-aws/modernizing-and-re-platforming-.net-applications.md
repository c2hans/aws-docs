# Modernizing and Re-platforming .NET Applications
<a name="modernizing-and-re-platforming-.net-applications"></a>

With the push to unlock business agility by using modern development and operations practices known as DevOps, modern applications are increasingly designed for flexibility using the principles of evolutionary design and a variety of best practices.

From the use of immutable infrastructure to increase deployment consistency, to the use of automation, Continuous Integration (CI), and Continuous Deployment (CD) to speed up delivery, there are a growing number of practices that help deliver business value.

Although many of these approaches can be partially applied to traditional architectures, modern application architectures are evolving to best take advantage of these new development practices. With the AWS Cloud increasing the speed of evolution, now is the perfect time to design or re-platform .NET applications to align with modern practices.

**AWS Transform for .NET**

[AWS Transform for .NET](https://docs.aws.amazon.com/transform/latest/userguide/dotnet.html) is a generative AI-powered agent that helps you modernize .NET applications. You can use it to modernize .NET Framework applications to cross-platform modern .NET, and to upgrade modern .NET applications to later versions. New features and contributions are delivered in modern .NET; the .NET Framework no longer receives new features. Modern .NET applications are cross platform, and porting existing .NET Framework applications to modern .NET gives you extra versatility and the ability to run those applications on Linux to save cost and improve performance.

However, porting applications to modern .NET can be a significant manual effort. Application owners must spend valuable time identifying the dependencies and APIs that are incompatible with modern .NET, and estimating the level of effort involved. AWS Transform for .NET assesses your .NET repositories and provides a customizable modernization plan. It also validates transformed code with local build verification and unit test execution. This reduces the manual effort involved in modernizing your applications to Linux. (Porting Assistant for .NET, the earlier AWS tool for this task, is no longer open to new customers.)
