# REQ1 – Data residency
<a name="req1-data-residency"></a>

 **Key principles** **–** The Operator needs to ensure that the source of personal data is in the territory of the country in question. Copies of personal data outside of the country must be *less or equal* than primary copies. Collecting (writing new data, modifying existing data) of personal data is allowed only in the territory of the country.
