# Approaches to local data processing requirements
<a name="approaches-to-local-data-processing-requirements"></a>

 This section outlines individual elements of local Data Residency Requirements, and describes how AWS can assist the customer, who is typically the Operator, within these requirements. Architecture examples in the [*Reference architectures*](reference-architectures.md) section are built to meet one or several of the following requirements.

 This chapter briefly outlines how AWS understands the individual element of Data Processing Requirements, and some architecture approaches that the customer may consider to address them.
