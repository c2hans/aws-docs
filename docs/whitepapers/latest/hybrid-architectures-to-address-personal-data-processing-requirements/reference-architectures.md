# Reference architectures
<a name="reference-architectures"></a>

 This section provides three levels of conceptual architectures that address the requirements outlined previously:
+  The Network layer
+  The Application layer
+  The Data layer

 Architecture examples for each layer can be modified or used as-is, or combined together to build solutions that address multiple requirements.
