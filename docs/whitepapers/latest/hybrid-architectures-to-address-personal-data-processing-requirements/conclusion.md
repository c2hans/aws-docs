# Conclusion
<a name="conclusion"></a>

 AWS provides a set of services and best practices to build hybrid architectures. In this document, we collected a set of reference hybrid architecture diagrams, which helps you create your own solution through adoption or combining architectures that is specific for your case. Before creating a new hybrid solution, we recommend that you define Data Residency Requirements, which require a hybrid approach, and then combine our references diagrams to address this requirement.

 Current architecture diagrams address common questions and challenges in cases where it is not possible to use AWS Outposts Family hardware appliances, running native AWS services on premises. In the next whitepaper, we will cover use cases which allow you to store and process personal data in AWS services, hosted in on-premises customer locations.
