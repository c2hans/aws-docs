# Encryption in transit
<a name="msk-data-delivery-iceberg-security-transit"></a>

A Channel encrypts all data in transit between Amazon MSK Express brokers and the Channel service using TLS 1.2 or higher. Data delivered to S3 is also encrypted in transit.
