# Metric dimensions
<a name="msk-data-delivery-iceberg-metric-dimensions"></a>

| Dimension | Description |
| --- | --- |
| `ClusterName` | The name of the Amazon MSK cluster. |
| `ChannelName` | The name of the Channel. |
| `Topic` | The name of the source Kafka topic. |
