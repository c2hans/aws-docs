# FHIR R4 support for AWS HealthLake
<a name="reference-fhir"></a>

AWS HealthLake supports the FHIR R4 specification for health data exchange. The following sections provide supporting information on how HealthLake utilizes the FHIR R4 specification to help you [manage](managing-fhir-resources.md) and [search](searching-fhir-resources.md) FHIR resources in your HealthLake data store using FHIR R4 RESTful APIs.

+ [Capability Statement](reference-fhir-capability-statement.md)
+ [Profile validations](reference-fhir-profile-validations.md)
+ [Resource types](reference-fhir-resource-types.md)
+ [Search parameters](reference-fhir-search-parameters.md)
+ [$Operations](reference-fhir-operations.md)
