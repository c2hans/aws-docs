# Getting started with AWS HealthLake
<a name="getting-started"></a>

To start using AWS HealthLake, set up an AWS account and create an AWS Identity and Access Management user. To use the [AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) or the [AWS SDKs](https://aws.amazon.com/developer/tools/), you must install and configure them.

**Note**
The [Reference](reference.md) chapter of this guide provides supporting content for SMART on FHIR, FHIR R4, and AWS HealthLake. For instance, you can find information about SMART on FHIR configuration, supported FHIR profile validations, and HealthLake endpoints.

After learning about HealthLake concepts and setting up, a short tutorial with code examples is available to help get you started.

+ [Setting up](getting-started-setting-up.md)
