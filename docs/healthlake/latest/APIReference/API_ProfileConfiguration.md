# ProfileConfiguration
<a name="API_ProfileConfiguration"></a>

The profile configuration for a data store.

## Contents
<a name="API_ProfileConfiguration_Contents"></a>

 ** DefaultProfiles **   <a name="HealthLake-Type-ProfileConfiguration-DefaultProfiles"></a>
The list of default profiles for the data store.
Type: Array of strings
Length Constraints: Minimum length of 0. Maximum length of 10000.
Pattern: `[\P{M}\p{M}]{0,10000}`
Required: No
