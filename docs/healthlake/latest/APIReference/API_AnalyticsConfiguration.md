# AnalyticsConfiguration
<a name="API_AnalyticsConfiguration"></a>

The analytics configuration for a data store.

## Contents
<a name="API_AnalyticsConfiguration_Contents"></a>

 ** Status **   <a name="HealthLake-Type-AnalyticsConfiguration-Status"></a>
The status of the analytics configuration.
Type: String
Valid Values: `ENABLED | ENABLING | DISABLED | DISABLING | PAUSING | PAUSED`
Required: No
