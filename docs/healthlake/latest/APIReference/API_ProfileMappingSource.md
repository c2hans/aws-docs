# ProfileMappingSource
<a name="API_ProfileMappingSource"></a>

Contains raw content to use as the source when creating a data transformation profile directly from a mapping.

## Contents
<a name="API_ProfileMappingSource_Contents"></a>

 ** ProfileMapping **   <a name="HealthLake-Type-ProfileMappingSource-ProfileMapping"></a>
The content as a map of file paths to profile strings.
Type: String to string map
Required: Yes
