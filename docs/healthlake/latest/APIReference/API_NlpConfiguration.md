# NlpConfiguration
<a name="API_NlpConfiguration"></a>

The natural language processing (NLP) configuration for a data store.

## Contents
<a name="API_NlpConfiguration_Contents"></a>

 ** Status **   <a name="HealthLake-Type-NlpConfiguration-Status"></a>
The status of the NLP configuration.
Type: String
Valid Values: `ENABLED | ENABLING | DISABLED | DISABLING`
Required: No
