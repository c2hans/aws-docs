# SseConfiguration
<a name="API_SseConfiguration"></a>

The server-side encryption key configuration for a customer-provided encryption key.

## Contents
<a name="API_SseConfiguration_Contents"></a>

 ** KmsEncryptionConfig **   <a name="HealthLake-Type-SseConfiguration-KmsEncryptionConfig"></a>
The Key Management Service (AWS KMS) encryption configuration used to provide details for data encryption.
Type: [KmsEncryptionConfig](API_KmsEncryptionConfig.md) object
Required: Yes
