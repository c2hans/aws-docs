# PreloadDataConfig
<a name="API_PreloadDataConfig"></a>

The input properties for the preloaded (Synthea) data store.

## Contents
<a name="API_PreloadDataConfig_Contents"></a>

 ** PreloadDataType **   <a name="HealthLake-Type-PreloadDataConfig-PreloadDataType"></a>
The type of preloaded data. Only Synthea preloaded data is supported.
Type: String
Valid Values: `SYNTHEA`
Required: Yes
