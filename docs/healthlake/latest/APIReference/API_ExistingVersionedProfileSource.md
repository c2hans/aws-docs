# ExistingVersionedProfileSource
<a name="API_ExistingVersionedProfileSource"></a>

Identifies an existing data transformation profile and version to clone when creating a new profile.

## Contents
<a name="API_ExistingVersionedProfileSource_Contents"></a>

 ** ProfileId **   <a name="HealthLake-Type-ExistingVersionedProfileSource-ProfileId"></a>
The unique identifier of the existing profile to clone from.
Type: String
Required: Yes

 ** Version **   <a name="HealthLake-Type-ExistingVersionedProfileSource-Version"></a>
The version number of the existing profile to clone from.
Type: Integer
Required: Yes
