# Monitor and analyze with Performance Monitor
<a name="CloudWatch-PerformanceMonitor-monitor-and-analyze"></a>

The monitor details page provides the following views:
+ **Overview** tab – Aggregated impact level for the monitor, the top network paths table, and summary metrics.
+ **Monitor details** tab – General configuration information, and the list of VPCs included in the monitor with their associated tags and accounts.

From the overview, you can do the following:
+ Sort paths by impact, latency, or traffic volume.
+ Expand paths to see subnet-level flows.
+ Open the split panel to see latency graphs with baseline comparison.
+ Filter by path type, impact level, or VPC.
