# Box integration configuration
<a name="box-setup"></a>

Box is a cloud content management and collaboration platform that enables secure file sharing, storage, and workflow automation across organizations. With CloudWatch Pipelines, you can use the Box REST API to retrieve enterprise events, user inventories, group structures, group memberships, and group collaborations from your Box enterprise. The pipeline authenticates using OAuth2 Client Credentials Grant and polls the API at configurable intervals to collect security and administrative data for monitoring and analysis.
