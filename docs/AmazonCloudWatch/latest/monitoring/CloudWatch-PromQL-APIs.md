# Prometheus-compatible APIs
<a name="CloudWatch-PromQL-APIs"></a>

**Topics**
+ [QueryMetrics](CloudWatch-PromQL-API-QueryMetrics.md)
+ [GetSeries](CloudWatch-PromQL-API-GetSeries.md)
+ [GetLabels](CloudWatch-PromQL-API-GetLabels.md)

Amazon CloudWatch supports the following Prometheus-compatible APIs for querying PromQL data. For information about endpoint URLs, signing requests with Signature Version 4, and required IAM permissions, see [PromQL querying](CloudWatch-PromQL-Querying.md).

For the limits and restrictions that apply to all PromQL API requests, including per-account TPS, concurrency, and 24-hour scan windows, see [PromQL limits and restrictions](CloudWatch-PromQL.md#CloudWatch-PromQL-Limits).
