# Netskope integration configuration
<a name="netskope-setup"></a>

Netskope is a cloud-native Security Service Edge (SSE) and SASE platform that provides real-time data and threat protection for cloud services, websites, and private applications. CloudWatch pipelines use the Netskope REST API v2 endpoints to retrieve security events and alerts from your Netskope tenant, including application activity, network traffic, audit events, infrastructure logs, and threat detections across DLP, malware, and policy violations.
