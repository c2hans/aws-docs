# Ping Identity PingFederate integration configuration
<a name="pingidentity-pingfederate-setup"></a>

Ping Identity PingFederate is an enterprise-grade identity federation server that serves as a central broker for Single Sign-On (SSO), token issuance, and protocol translation across SAML 2.0, OAuth 2.0, OpenID Connect, WS-Federation, and WS-Trust. CloudWatch pipelines allow ingestion of Ping Identity PingFederate audit log data into CloudWatch Logs.
