# GitLab integration configuration
<a name="gitlab-setup"></a>

GitLab is a DevSecOps platform that provides source code management, CI/CD pipelines, project planning, and security scanning capabilities. CloudWatch Pipelines use the GitLab REST API and GraphQL API to retrieve audit events, project activity, merge request data, group membership information, and vulnerability findings from your GitLab environment.
