# Broadcom Carbon Black integration configuration
<a name="broadcom-carbonblack-setup"></a>

Broadcom Carbon Black Cloud is an endpoint detection and response (EDR) platform that provides threat detection, investigation, and containment capabilities. CloudWatch Pipelines ingest Carbon Black event data from Amazon S3 to normalize it into OCSF format for security analysis.
