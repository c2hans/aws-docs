# Cisco Duo integration configuration
<a name="cisco-duo-setup"></a>

Cisco Duo is a cloud-based identity and access management (IAM) platform that provides secure access through multi-factor authentication (MFA), device trust, and adaptive authentication policies. CloudWatch Pipelines use the Duo Admin API to retrieve audit logs, authentication activity, administrator actions, and policy-related events from your Cisco Duo environment.
