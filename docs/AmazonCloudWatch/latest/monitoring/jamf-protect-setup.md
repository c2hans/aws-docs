# Jamf Protect integration configuration
<a name="jamf-protect-setup"></a>

Jamf Protect is an endpoint security solution purpose-built for macOS and iOS environments, providing real-time threat detection, behavioral analytics, and compliance monitoring across Apple device fleets. CloudWatch pipelines allow ingestion of Jamf Protect data into CloudWatch Logs.
