# Infrastructure security in Performance Monitor
<a name="CloudWatch-PerformanceMonitor-infrastructure-security"></a>

Performance Monitor runs entirely within the AWS infrastructure. You don't need to open any network ports, configure security groups, or modify your VPC settings to use Performance Monitor.
