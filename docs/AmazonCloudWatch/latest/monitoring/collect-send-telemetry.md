# Collect and send telemetry
<a name="collect-send-telemetry"></a>

CloudWatch provides multiple methods to collect and send telemetry data from your applications and infrastructure. Use the CloudWatch agent to collect metrics and logs from Amazon EC2 instances and on-premises servers, embedded metric format to generate metrics from structured log data, or CloudWatch Pipelines to transform and route telemetry at scale.
