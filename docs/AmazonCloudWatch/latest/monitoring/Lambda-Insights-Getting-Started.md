# Get started with Lambda Insights
<a name="Lambda-Insights-Getting-Started"></a>

To enable Lambda Insights on a Lambda function, you can use a one-click toggle in the Lambda console. Alternatively, you can use the AWS CLI, CloudFormation, the AWS Serverless Application Model CLI, or the AWS Cloud Development Kit (AWS CDK).

The following sections provide detailed instructions for completing these steps.

**Topics**
+ [Available versions of the Lambda Insights extension](Lambda-Insights-extension-versions.md)
+ [Using the console to enable Lambda Insights on an existing Lambda function](Lambda-Insights-Getting-Started-console.md)
+ [Use the AWS CLI to enable Lambda Insights on an existing Lambda function](Lambda-Insights-Getting-Started-cli.md)
+ [Use the AWS SAM CLI to enable Lambda Insights on an existing Lambda function](Lambda-Insights-Getting-Started-SAM-CLI.md)
+ [Use CloudFormation to enable Lambda Insights on an existing Lambda function](Lambda-Insights-Getting-Started-cloudformation.md)
+ [Use the AWS CDK to enable Lambda Insights on an existing Lambda function](Lambda-Insights-Getting-Started-clouddevelopmentkit.md)
+ [Use Serverless Framework to enable Lambda Insights on an existing Lambda function](Lambda-Insights-Getting-Started-serverless.md)
+ [Enable Lambda Insights on a Lambda container image deployment](Lambda-Insights-Getting-Started-docker.md)
+ [Update the Lambda Insights extension version on a function](Lambda-Insights-Update-Extension.md)
