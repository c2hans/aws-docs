# InstanceSavingsEstimationMode
<a name="API_InstanceSavingsEstimationMode"></a>

 Describes the savings estimation mode used for calculating savings opportunity for Amazon EC2 instances.

## Contents
<a name="API_InstanceSavingsEstimationMode_Contents"></a>

 ** source **   <a name="computeoptimizer-Type-InstanceSavingsEstimationMode-source"></a>
 Describes the source for calculating the savings opportunity for Amazon EC2 instances.
Type: String
Valid Values: `PublicPricing | CostExplorerRightsizing | CostOptimizationHub`
Required: No
