# IdleDimension
<a name="API_IdleDimension"></a>

Describes the dimension of an idle resource utilization metric.

## Contents
<a name="API_IdleDimension_Contents"></a>

 ** key **   <a name="computeoptimizer-Type-IdleDimension-key"></a>
The name of the dimension key.
Type: String
Required: No

 ** values **   <a name="computeoptimizer-Type-IdleDimension-values"></a>
The value of the dimension.
Type: Array of strings
Required: No
