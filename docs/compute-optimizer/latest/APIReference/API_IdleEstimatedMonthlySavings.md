# IdleEstimatedMonthlySavings
<a name="API_IdleEstimatedMonthlySavings"></a>

Describes the estimated monthly savings possible for idle resources by adopting Compute Optimizer recommendations.

## Contents
<a name="API_IdleEstimatedMonthlySavings_Contents"></a>

 ** currency **   <a name="computeoptimizer-Type-IdleEstimatedMonthlySavings-currency"></a>
The currency of the estimated monthly savings.
Type: String
Valid Values: `USD | CNY`
Required: No

 ** value **   <a name="computeoptimizer-Type-IdleEstimatedMonthlySavings-value"></a>
The value of the estimated monthly savings for Idle resources.
Type: Double
Required: No
