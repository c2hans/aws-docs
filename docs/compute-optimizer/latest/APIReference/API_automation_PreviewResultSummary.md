# PreviewResultSummary
<a name="API_automation_PreviewResultSummary"></a>

Contains a summary of preview results for an automation rule.

## Contents
<a name="API_automation_PreviewResultSummary_Contents"></a>

 ** key **   <a name="computeoptimizer-Type-automation_PreviewResultSummary-key"></a>
The key identifier for this preview result summary.
Type: String
Required: Yes

 ** total **   <a name="computeoptimizer-Type-automation_PreviewResultSummary-total"></a>
Aggregate totals for automation rule preview results, including count and estimated savings.
Type: [RulePreviewTotal](API_automation_RulePreviewTotal.md) object
Required: Yes
