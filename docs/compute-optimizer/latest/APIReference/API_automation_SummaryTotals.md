# SummaryTotals
<a name="API_automation_SummaryTotals"></a>

Aggregate totals for automation events, including counts and estimated savings.

## Contents
<a name="API_automation_SummaryTotals_Contents"></a>

 ** automationEventCount **   <a name="computeoptimizer-Type-automation_SummaryTotals-automationEventCount"></a>
The total number of automation events in this summary group.
Type: Integer
Required: No

 ** estimatedMonthlySavings **   <a name="computeoptimizer-Type-automation_SummaryTotals-estimatedMonthlySavings"></a>
 Contains information about estimated monthly cost savings.
Type: [EstimatedMonthlySavings](API_automation_EstimatedMonthlySavings.md) object
Required: No
