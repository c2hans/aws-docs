# ECSSavingsEstimationMode
<a name="API_ECSSavingsEstimationMode"></a>

 Describes the savings estimation mode used for calculating savings opportunity for Amazon ECS services.

## Contents
<a name="API_ECSSavingsEstimationMode_Contents"></a>

 ** source **   <a name="computeoptimizer-Type-ECSSavingsEstimationMode-source"></a>
 Describes the source for calculating the savings opportunity for Amazon ECS services.
Type: String
Valid Values: `PublicPricing | CostExplorerRightsizing | CostOptimizationHub`
Required: No
