# LambdaEffectiveRecommendationPreferences
<a name="API_LambdaEffectiveRecommendationPreferences"></a>

 Describes the effective recommendation preferences for Lambda functions.

 ** savingsEstimationMode **   <a name="computeoptimizer-Type-LambdaEffectiveRecommendationPreferences-savingsEstimationMode"></a>
 Describes the savings estimation mode applied for calculating savings opportunity for Lambda functions.
Type: [LambdaSavingsEstimationMode](API_LambdaSavingsEstimationMode.md) object
