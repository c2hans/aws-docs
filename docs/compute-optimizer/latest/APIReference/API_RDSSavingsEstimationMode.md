# RDSSavingsEstimationMode
<a name="API_RDSSavingsEstimationMode"></a>

 Describes the savings estimation mode used for calculating savings opportunity for DB instances.

## Contents
<a name="API_RDSSavingsEstimationMode_Contents"></a>

 ** source **   <a name="computeoptimizer-Type-RDSSavingsEstimationMode-source"></a>
 Describes the source for calculating the savings opportunity for DB instances.
Type: String
Valid Values: `PublicPricing | CostExplorerRightsizing | CostOptimizationHub`
Required: No
