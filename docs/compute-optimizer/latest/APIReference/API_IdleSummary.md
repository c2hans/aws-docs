# IdleSummary
<a name="API_IdleSummary"></a>

Describes the findings summary of the idle resources.

## Contents
<a name="API_IdleSummary_Contents"></a>

 ** name **   <a name="computeoptimizer-Type-IdleSummary-name"></a>
The name of the finding group for the idle resources.
Type: String
Valid Values: `Idle | Unattached | Unused`
Required: No

 ** value **   <a name="computeoptimizer-Type-IdleSummary-value"></a>
The count of idle resources in the finding group.
Type: Double
Required: No
