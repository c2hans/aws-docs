# RecommendedActionTotal
<a name="API_automation_RecommendedActionTotal"></a>

Aggregate totals for a group of recommended actions, including count and estimated monthly savings.

## Contents
<a name="API_automation_RecommendedActionTotal_Contents"></a>

 ** estimatedMonthlySavings **   <a name="computeoptimizer-Type-automation_RecommendedActionTotal-estimatedMonthlySavings"></a>
 Contains information about estimated monthly cost savings.
Type: [EstimatedMonthlySavings](API_automation_EstimatedMonthlySavings.md) object
Required: Yes

 ** recommendedActionCount **   <a name="computeoptimizer-Type-automation_RecommendedActionTotal-recommendedActionCount"></a>
The total number of recommended actions in this group.
Type: Integer
Required: Yes
