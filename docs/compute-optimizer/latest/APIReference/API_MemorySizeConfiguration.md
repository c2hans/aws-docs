# MemorySizeConfiguration
<a name="API_MemorySizeConfiguration"></a>

 The memory size configurations of a container.

## Contents
<a name="API_MemorySizeConfiguration_Contents"></a>

 ** memory **   <a name="computeoptimizer-Type-MemorySizeConfiguration-memory"></a>
 The amount of memory in the container.
Type: Integer
Required: No

 ** memoryReservation **   <a name="computeoptimizer-Type-MemorySizeConfiguration-memoryReservation"></a>
 The limit of memory reserve for the container.
Type: Integer
Required: No
