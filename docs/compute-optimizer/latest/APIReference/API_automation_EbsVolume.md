# EbsVolume
<a name="API_automation_EbsVolume"></a>

Represents an Amazon EBS volume with its configuration and snapshot usage information.

## Contents
<a name="API_automation_EbsVolume_Contents"></a>

 ** configuration **   <a name="computeoptimizer-Type-automation_EbsVolume-configuration"></a>
The configuration details of the EBS volume, including type, size, IOPS, and throughput.
Type: [EbsVolumeConfiguration](API_automation_EbsVolumeConfiguration.md) object
Required: No
