# ReasonCodeSummary
<a name="API_ReasonCodeSummary"></a>

A summary of a finding reason code.

## Contents
<a name="API_ReasonCodeSummary_Contents"></a>

 ** name **   <a name="computeoptimizer-Type-ReasonCodeSummary-name"></a>
The name of the finding reason code.
Type: String
Valid Values: `MemoryOverprovisioned | MemoryUnderprovisioned`
Required: No

 ** value **   <a name="computeoptimizer-Type-ReasonCodeSummary-value"></a>
The value of the finding reason code summary.
Type: Double
Required: No
