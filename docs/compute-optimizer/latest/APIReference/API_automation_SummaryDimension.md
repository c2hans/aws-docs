# SummaryDimension
<a name="API_automation_SummaryDimension"></a>

A key-value pair used to categorize and group summary data for analysis and reporting.

## Contents
<a name="API_automation_SummaryDimension_Contents"></a>

 ** key **   <a name="computeoptimizer-Type-automation_SummaryDimension-key"></a>
The dimension key used for categorizing summary data.
Type: String
Valid Values: `EventStatus`
Required: Yes

 ** value **   <a name="computeoptimizer-Type-automation_SummaryDimension-value"></a>
The specific value for this dimension key used in the summary grouping.
Type: String
Required: Yes
