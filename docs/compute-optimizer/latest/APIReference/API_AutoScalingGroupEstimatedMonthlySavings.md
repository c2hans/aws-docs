# AutoScalingGroupEstimatedMonthlySavings
<a name="API_AutoScalingGroupEstimatedMonthlySavings"></a>

 An object that describes the estimated monthly savings possible by adopting Compute Optimizer’s Auto Scaling group recommendations. This is based on the Savings Plans and Reserved Instances discounts.

## Contents
<a name="API_AutoScalingGroupEstimatedMonthlySavings_Contents"></a>

 ** currency **   <a name="computeoptimizer-Type-AutoScalingGroupEstimatedMonthlySavings-currency"></a>
 The currency of the estimated monthly savings.
Type: String
Valid Values: `USD | CNY`
Required: No

 ** value **   <a name="computeoptimizer-Type-AutoScalingGroupEstimatedMonthlySavings-value"></a>
 The value of the estimated monthly savings.
Type: Double
Required: No
