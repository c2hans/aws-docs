# EBSSavingsEstimationMode
<a name="API_EBSSavingsEstimationMode"></a>

 Describes the savings estimation mode used for calculating savings opportunity for Amazon EBS volumes.

## Contents
<a name="API_EBSSavingsEstimationMode_Contents"></a>

 ** source **   <a name="computeoptimizer-Type-EBSSavingsEstimationMode-source"></a>
 Describes the source for calculating the savings opportunity for Amazon EBS volumes.
Type: String
Valid Values: `PublicPricing | CostExplorerRightsizing | CostOptimizationHub`
Required: No
