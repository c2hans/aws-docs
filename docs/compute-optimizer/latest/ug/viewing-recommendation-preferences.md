# Compute Optimizer recommendation preferences
<a name="viewing-recommendation-preferences"></a>

Recommendation preferences are features that you can activate in AWS Compute Optimizer to get resource recommendations that align more closely with your workload requirements. You can activate the following recommendation preferences in Compute Optimizer.

By configuring these preferences, you can fine-tune how Compute Optimizer evaluates your resources and the types of recommendations that it returns.
+ [Enhanced infrastructure metrics](enhanced-infrastructure-metrics.md)
+ [External metrics ingestion](external-metrics-ingestion.md)
+ [AWS Graviton-based instance recommendations](graviton-recommendations.md)
+ [Inferred workload type](inferred-workload-type.md)
+ [Rightsizing recommendation preferences](rightsizing-preferences.md)
+ [Savings estimation mode](savings-estimation-mode.md)
