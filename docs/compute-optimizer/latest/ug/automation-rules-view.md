# Viewing automation rules
<a name="automation-rules-view"></a>

In AWS Compute Optimizer, you can view, create, and manage your automation rules on the **Automation rules** page. You can choose a rule to view more details. This includes the specific rule criteria used to match recommended actions.

After your rules run, Compute Optimizer records the results as automation events. For more information, see [View automation events](automation-events-view-details.md).

**To view automation rules**

1. Open the Compute Optimizer console at [https://console.aws.amazon.com/compute-optimizer/](https://console.aws.amazon.com/compute-optimizer/).

1. In the navigation pane, choose **Automation rules** under the **Automation** section.

1. Choose the **rule name** of the rule for which you want to view details.

1. You can perform the following actions on the **rule details** page:
   + View rule details and criteria.
   + Enable and disable the rule.
   + Edit the rule.
   + Delete the rule.
   + Manage tags for the rule.
