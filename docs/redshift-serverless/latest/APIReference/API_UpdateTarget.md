# UpdateTarget
<a name="API_UpdateTarget"></a>

A track that you can switch the current track to.

## Contents
<a name="API_UpdateTarget_Contents"></a>

 ** trackName **   <a name="redshiftserverless-Type-UpdateTarget-trackName"></a>
The name of the new track.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `[a-zA-Z0-9_]+`
Required: No

 ** workgroupVersion **   <a name="redshiftserverless-Type-UpdateTarget-workgroupVersion"></a>
The workgroup version for the new track.
Type: String
Required: No
