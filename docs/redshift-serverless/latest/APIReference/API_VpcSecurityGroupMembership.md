# VpcSecurityGroupMembership
<a name="API_VpcSecurityGroupMembership"></a>

Describes the members of a VPC security group.

## Contents
<a name="API_VpcSecurityGroupMembership_Contents"></a>

 ** status **   <a name="redshiftserverless-Type-VpcSecurityGroupMembership-status"></a>
The status of the VPC security group.
Type: String
Required: No

 ** vpcSecurityGroupId **   <a name="redshiftserverless-Type-VpcSecurityGroupMembership-vpcSecurityGroupId"></a>
The unique identifier of the VPC security group.
Type: String
Required: No
