# ResourcePolicy
<a name="API_ResourcePolicy"></a>

The resource policy object. Currently, you can use policies to share snapshots across AWS accounts.

## Contents
<a name="API_ResourcePolicy_Contents"></a>

 ** policy **   <a name="redshiftserverless-Type-ResourcePolicy-policy"></a>
The resource policy.
Type: String
Required: No

 ** resourceArn **   <a name="redshiftserverless-Type-ResourcePolicy-resourceArn"></a>
The Amazon Resource Name (ARN) of the policy.
Type: String
Required: No
