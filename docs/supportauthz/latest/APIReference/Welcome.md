# Welcome
<a name="Welcome"></a>

 AWS Support authorization APIs enable you to control and authorize the actions that AWS Support operators can perform on your resources. You create cryptographically signed support permits specifying which actions operators can perform, on which resources, and under what time-window conditions. Permits are signed using a customer-managed AWS KMS key (ECC\_NIST\_P384, SIGN\_VERIFY) to ensure non-repudiation.
