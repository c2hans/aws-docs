# Data Types
<a name="API_Types"></a>

The SupportAuthZ API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [ActionSet](API_ActionSet.md)
+  [ActionSummary](API_ActionSummary.md)
+  [Condition](API_Condition.md)
+  [Permit](API_Permit.md)
+  [ResourceSet](API_ResourceSet.md)
+  [SigningKeyInfo](API_SigningKeyInfo.md)
+  [SupportPermitRequest](API_SupportPermitRequest.md)
+  [SupportPermitSummary](API_SupportPermitSummary.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
