# AWS Mobile SDK for Unity Documentation

The AWS Mobile SDK for Unity contains a set of .NET classes that enables games written with Unity to utilize AWS services. The AWS Unity Plug-in also contains sample code that illustrates how to call AWS services from a Unity game. The AWS Mobile SDK for Unity is compatible with Unity version 4.0 and greater.

- [Developer Guide](/mobile/sdkforunity/developerguide/): Walks through the steps for setting up the Unity SDK and integrating with AWS products and services.
- [API Reference](/AWSUnitySDK/latest/APIReference/index.html): Describes all the API operations for the Unity SDK in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
