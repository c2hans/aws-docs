# GitHubRepositoryResource
<a name="API_GitHubRepositoryResource"></a>

Represents a GitHub repository resource used in an integration.

## Contents
<a name="API_GitHubRepositoryResource_Contents"></a>

 ** name **   <a name="securityagent-Type-GitHubRepositoryResource-name"></a>
The name of the GitHub repository.
Type: String
Required: Yes

 ** owner **   <a name="securityagent-Type-GitHubRepositoryResource-owner"></a>
The owner of the GitHub repository.
Type: String
Required: Yes
