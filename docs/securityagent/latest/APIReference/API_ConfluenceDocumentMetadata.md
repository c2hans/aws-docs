# ConfluenceDocumentMetadata
<a name="API_ConfluenceDocumentMetadata"></a>

Metadata for an integrated Confluence document.

## Contents
<a name="API_ConfluenceDocumentMetadata_Contents"></a>

 ** name **   <a name="securityagent-Type-ConfluenceDocumentMetadata-name"></a>
Name of the resource e.g. repository name, etc.
Type: String
Required: Yes

 ** pageId **   <a name="securityagent-Type-ConfluenceDocumentMetadata-pageId"></a>
The Confluence page identifier.
Type: String
Required: Yes

 ** providerResourceId **   <a name="securityagent-Type-ConfluenceDocumentMetadata-providerResourceId"></a>
Provider Id of the resource e.g. GitHub repository id, etc.
Type: String
Required: Yes

 ** spaceKey **   <a name="securityagent-Type-ConfluenceDocumentMetadata-spaceKey"></a>
The Confluence space key containing the document.
Type: String
Required: Yes

 ** spaceTitle **   <a name="securityagent-Type-ConfluenceDocumentMetadata-spaceTitle"></a>
The display title of the Confluence space.
Type: String
Required: No

 ** title **   <a name="securityagent-Type-ConfluenceDocumentMetadata-title"></a>
The display title of the Confluence page.
Type: String
Required: No
