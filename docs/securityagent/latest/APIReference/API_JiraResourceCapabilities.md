# JiraResourceCapabilities
<a name="API_JiraResourceCapabilities"></a>

Capabilities for an integrated Jira project.

## Contents
<a name="API_JiraResourceCapabilities_Contents"></a>

 ** commentIssue **   <a name="securityagent-Type-JiraResourceCapabilities-commentIssue"></a>
Whether to post comments on issues in the integrated jira project.
Type: Boolean
Required: No

 ** createIssue **   <a name="securityagent-Type-JiraResourceCapabilities-createIssue"></a>
Whether to create issues in the integrated jira project.
Type: Boolean
Required: No
