# ConfluenceResourceCapabilities
<a name="API_ConfluenceResourceCapabilities"></a>

Capabilities for an integrated Confluence space.

## Contents
<a name="API_ConfluenceResourceCapabilities_Contents"></a>

 ** createDocument **   <a name="securityagent-Type-ConfluenceResourceCapabilities-createDocument"></a>
Whether to create documents in this space.
Type: Boolean
Required: No

 ** fetchDocument **   <a name="securityagent-Type-ConfluenceResourceCapabilities-fetchDocument"></a>
Whether to fetch documents from this space.
Type: Boolean
Required: No

 ** updateDocument **   <a name="securityagent-Type-ConfluenceResourceCapabilities-updateDocument"></a>
Whether to update documents in this space.
Type: Boolean
Required: No
