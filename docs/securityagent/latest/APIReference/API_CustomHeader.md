# CustomHeader
<a name="API_CustomHeader"></a>

A custom HTTP header to include in network traffic during penetration testing.

## Contents
<a name="API_CustomHeader_Contents"></a>

 ** name **   <a name="securityagent-Type-CustomHeader-name"></a>
The name of the custom header.
Type: String
Required: No

 ** value **   <a name="securityagent-Type-CustomHeader-value"></a>
The value of the custom header.
Type: String
Required: No
