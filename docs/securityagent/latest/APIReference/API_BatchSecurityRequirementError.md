# BatchSecurityRequirementError
<a name="API_BatchSecurityRequirementError"></a>

Contains information about an error that occurred for a specific security requirement during a batch operation.

## Contents
<a name="API_BatchSecurityRequirementError_Contents"></a>

 ** code **   <a name="securityagent-Type-BatchSecurityRequirementError-code"></a>
The error code.
Type: String
Required: Yes

 ** message **   <a name="securityagent-Type-BatchSecurityRequirementError-message"></a>
The error message.
Type: String
Required: Yes

 ** securityRequirementName **   <a name="securityagent-Type-BatchSecurityRequirementError-securityRequirementName"></a>
The name of the security requirement that caused the error.
Type: String
Required: Yes
