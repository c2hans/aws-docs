# IssueDestination
<a name="API_IssueDestination"></a>

The destination for filing findings as issues in an integrated issue tracker.

## Contents
<a name="API_IssueDestination_Contents"></a>

 ** integrationId **   <a name="securityagent-Type-IssueDestination-integrationId"></a>
The integration identifier for the issue-tracker provider.
Type: String
Required: Yes

 ** projectKey **   <a name="securityagent-Type-IssueDestination-projectKey"></a>
The identifier of the project the issues are filed under.
Type: String
Required: Yes
