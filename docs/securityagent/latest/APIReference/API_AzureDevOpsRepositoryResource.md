# AzureDevOpsRepositoryResource
<a name="API_AzureDevOpsRepositoryResource"></a>

An Azure DevOps repository integrated as a resource.

## Contents
<a name="API_AzureDevOpsRepositoryResource_Contents"></a>

 ** name **   <a name="securityagent-Type-AzureDevOpsRepositoryResource-name"></a>
Name of the resource e.g. repository name, etc.
Type: String
Required: Yes

 ** organization **   <a name="securityagent-Type-AzureDevOpsRepositoryResource-organization"></a>
The name of the Azure DevOps organization that owns the repository.
Type: String
Required: Yes

 ** project **   <a name="securityagent-Type-AzureDevOpsRepositoryResource-project"></a>
The name of the Azure DevOps project that contains the repository.
Type: String
Required: No
