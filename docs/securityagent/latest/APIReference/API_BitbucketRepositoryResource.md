# BitbucketRepositoryResource
<a name="API_BitbucketRepositoryResource"></a>

A Bitbucket repository integrated as a resource.

## Contents
<a name="API_BitbucketRepositoryResource_Contents"></a>

 ** name **   <a name="securityagent-Type-BitbucketRepositoryResource-name"></a>
Name of the resource e.g. repository name, etc.
Type: String
Required: Yes

 ** workspace **   <a name="securityagent-Type-BitbucketRepositoryResource-workspace"></a>
The workspace slug that owns the repository.
Type: String
Required: Yes
