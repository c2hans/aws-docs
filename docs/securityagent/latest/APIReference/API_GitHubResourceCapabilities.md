# GitHubResourceCapabilities
<a name="API_GitHubResourceCapabilities"></a>

The capabilities enabled for a GitHub resource integration.

## Contents
<a name="API_GitHubResourceCapabilities_Contents"></a>

 ** leaveComments **   <a name="securityagent-Type-GitHubResourceCapabilities-leaveComments"></a>
Indicates whether the integration can leave comments on pull requests.
Type: Boolean
Required: No

 ** remediateCode **   <a name="securityagent-Type-GitHubResourceCapabilities-remediateCode"></a>
Indicates whether the integration can create code remediation pull requests.
Type: Boolean
Required: No
