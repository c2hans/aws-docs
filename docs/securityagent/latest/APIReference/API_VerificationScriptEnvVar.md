# VerificationScriptEnvVar
<a name="API_VerificationScriptEnvVar"></a>

Represents an environment variable required to run a verification script.

## Contents
<a name="API_VerificationScriptEnvVar_Contents"></a>

 ** name **   <a name="securityagent-Type-VerificationScriptEnvVar-name"></a>
The name of the environment variable.
Type: String
Required: No

 ** value **   <a name="securityagent-Type-VerificationScriptEnvVar-value"></a>
The value of the environment variable.
Type: String
Required: No
