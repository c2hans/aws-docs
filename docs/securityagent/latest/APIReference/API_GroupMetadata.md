# GroupMetadata

Contains metadata about an IAM Identity Center group member, including the group display name and description.

## Contents
<a name="API_GroupMetadata_Contents"></a>

 ** description **   <a name="securityagent-Type-GroupMetadata-description"></a>
The description of the group.
Type: String
Required: No

 ** displayName **   <a name="securityagent-Type-GroupMetadata-displayName"></a>
The display name of the group.
Type: String
Required: No
