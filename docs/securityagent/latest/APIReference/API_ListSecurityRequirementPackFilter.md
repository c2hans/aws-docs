# ListSecurityRequirementPackFilter
<a name="API_ListSecurityRequirementPackFilter"></a>

Filter criteria for listing security requirement packs.

## Contents
<a name="API_ListSecurityRequirementPackFilter_Contents"></a>

 ** managementType **   <a name="securityagent-Type-ListSecurityRequirementPackFilter-managementType"></a>
Filter packs by management type. Valid values are AWS\_MANAGED and CUSTOMER\_MANAGED.
Type: String
Valid Values: `AWS_MANAGED | CUSTOMER_MANAGED`
Required: No

 ** status **   <a name="securityagent-Type-ListSecurityRequirementPackFilter-status"></a>
Filter packs by status. Valid values are ENABLED and DISABLED.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: No
