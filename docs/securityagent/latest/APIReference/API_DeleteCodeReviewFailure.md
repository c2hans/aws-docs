# DeleteCodeReviewFailure
<a name="API_DeleteCodeReviewFailure"></a>

Contains information about a code review that failed to delete.

## Contents
<a name="API_DeleteCodeReviewFailure_Contents"></a>

 ** codeReviewId **   <a name="securityagent-Type-DeleteCodeReviewFailure-codeReviewId"></a>
The unique identifier of the code review that failed to delete.
Type: String
Required: No

 ** reason **   <a name="securityagent-Type-DeleteCodeReviewFailure-reason"></a>
The reason the code review failed to delete.
Type: String
Required: No
