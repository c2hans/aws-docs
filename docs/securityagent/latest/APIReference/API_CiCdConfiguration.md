# CiCdConfiguration
<a name="API_CiCdConfiguration"></a>

The configuration that enables a pentest to run as part of a CI/CD pipeline, scoped to the code changes in each pipeline run.

## Contents
<a name="API_CiCdConfiguration_Contents"></a>

 ** enabled **   <a name="securityagent-Type-CiCdConfiguration-enabled"></a>
Whether CI/CD pentesting is enabled for this pentest.
Type: Boolean
Required: No
