# TrustedCaCertificate
<a name="API_TrustedCaCertificate"></a>

A trust anchor used when validating a target endpoint's TLS certificate.

## Contents
<a name="API_TrustedCaCertificate_Contents"></a>

 ** source **   <a name="securityagent-Type-TrustedCaCertificate-source"></a>
The source that Security Agent reads the certificate from.
Type: [CaCertificateSource](API_CaCertificateSource.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes
