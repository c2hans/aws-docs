# ConfluenceDocumentResource
<a name="API_ConfluenceDocumentResource"></a>

A Confluence document (page) integrated as a resource.

## Contents
<a name="API_ConfluenceDocumentResource_Contents"></a>

 ** name **   <a name="securityagent-Type-ConfluenceDocumentResource-name"></a>
Name of the resource e.g. repository name, etc.
Type: String
Required: Yes

 ** pageId **   <a name="securityagent-Type-ConfluenceDocumentResource-pageId"></a>
The Confluence page identifier.
Type: String
Required: Yes

 ** spaceKey **   <a name="securityagent-Type-ConfluenceDocumentResource-spaceKey"></a>
The Confluence space key containing the document.
Type: String
Required: Yes

 ** spaceTitle **   <a name="securityagent-Type-ConfluenceDocumentResource-spaceTitle"></a>
The display title of the Confluence space.
Type: String
Required: No

 ** title **   <a name="securityagent-Type-ConfluenceDocumentResource-title"></a>
The display title of the Confluence page.
Type: String
Required: No
