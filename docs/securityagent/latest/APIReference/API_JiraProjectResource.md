# JiraProjectResource
<a name="API_JiraProjectResource"></a>

Represents a Jira project resource used in an integration.

## Contents
<a name="API_JiraProjectResource_Contents"></a>

 ** name **   <a name="securityagent-Type-JiraProjectResource-name"></a>
Name of the resource e.g. repository name, etc.
Type: String
Required: Yes

 ** projectId **   <a name="securityagent-Type-JiraProjectResource-projectId"></a>
The Jira project identifier.
Type: String
Required: Yes

 ** projectKey **   <a name="securityagent-Type-JiraProjectResource-projectKey"></a>
The Jira project key, for example PROJ.
Type: String
Required: Yes

 ** projectName **   <a name="securityagent-Type-JiraProjectResource-projectName"></a>
The display name of the Jira project.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: No
