# BatchExportFindingResult
<a name="API_BatchExportFindingResult"></a>

A finding whose issue was created.

<a name="API_BatchExportFindingResult_Contents"></a>

 ** findingId **   <a name="securityagent-Type-BatchExportFindingResult-findingId"></a>
The identifier of the finding this result corresponds to.
Type: String
Required: Yes

 ** linkedIssue **   <a name="securityagent-Type-BatchExportFindingResult-linkedIssue"></a>
The issue that was created for the finding.
Type: [LinkedIssue](API_LinkedIssue.md) object
Required: Yes
