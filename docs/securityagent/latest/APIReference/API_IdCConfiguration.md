# IdCConfiguration
<a name="API_IdCConfiguration"></a>

The IAM Identity Center configuration for an application.

## Contents
<a name="API_IdCConfiguration_Contents"></a>

 ** idcApplicationArn **   <a name="securityagent-Type-IdCConfiguration-idcApplicationArn"></a>
The Amazon Resource Name (ARN) of the IAM Identity Center application.
Type: String
Required: No

 ** idcInstanceArn **   <a name="securityagent-Type-IdCConfiguration-idcInstanceArn"></a>
The Amazon Resource Name (ARN) of the IAM Identity Center instance.
Type: String
Required: No
