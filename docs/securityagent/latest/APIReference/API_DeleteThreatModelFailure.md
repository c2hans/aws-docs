# DeleteThreatModelFailure
<a name="API_DeleteThreatModelFailure"></a>

Contains information about a threat model that failed to delete.

## Contents
<a name="API_DeleteThreatModelFailure_Contents"></a>

 ** reason **   <a name="securityagent-Type-DeleteThreatModelFailure-reason"></a>
The reason the threat model failed to delete.
Type: String
Required: No

 ** threatModelId **   <a name="securityagent-Type-DeleteThreatModelFailure-threatModelId"></a>
The unique identifier of the threat model that failed to delete.
Type: String
Required: No
