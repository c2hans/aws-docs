# AgentSpaceSummary
<a name="API_AgentSpaceSummary"></a>

Contains summary information about an agent space.

## Contents
<a name="API_AgentSpaceSummary_Contents"></a>

 ** agentSpaceId **   <a name="securityagent-Type-AgentSpaceSummary-agentSpaceId"></a>
The unique identifier of the agent space.
Type: String
Required: Yes

 ** name **   <a name="securityagent-Type-AgentSpaceSummary-name"></a>
The name of the agent space.
Type: String
Required: Yes

 ** createdAt **   <a name="securityagent-Type-AgentSpaceSummary-createdAt"></a>
The date and time the agent space was created, in UTC format.
Type: Timestamp
Required: No

 ** updatedAt **   <a name="securityagent-Type-AgentSpaceSummary-updatedAt"></a>
The date and time the agent space was last updated, in UTC format.
Type: Timestamp
Required: No
