# SourceCodeRepository
<a name="API_SourceCodeRepository"></a>

Represents a source code repository used for security analysis during a pentest.

## Contents
<a name="API_SourceCodeRepository_Contents"></a>

 ** s3Location **   <a name="securityagent-Type-SourceCodeRepository-s3Location"></a>
The Amazon S3 location of the source code repository archive.
Type: String
Required: No
