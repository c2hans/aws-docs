# ThreatAnchorShape
<a name="API_ThreatAnchorShape"></a>

DFD element that a threat is anchored to.

## Contents
<a name="API_ThreatAnchorShape_Contents"></a>

 ** id **   <a name="securityagent-Type-ThreatAnchorShape-id"></a>
The identifier of the DFD element.
Type: String
Required: No

 ** kind **   <a name="securityagent-Type-ThreatAnchorShape-kind"></a>
The kind of DFD element.
Type: String
Required: No

 ** packageId **   <a name="securityagent-Type-ThreatAnchorShape-packageId"></a>
The package identifier containing the DFD element.
Type: String
Required: No
