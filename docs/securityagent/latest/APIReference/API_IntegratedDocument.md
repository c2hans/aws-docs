# IntegratedDocument
<a name="API_IntegratedDocument"></a>

A reference to a document in a third-party provider, such as a Confluence page linked via an integration.

## Contents
<a name="API_IntegratedDocument_Contents"></a>

 ** integrationId **   <a name="securityagent-Type-IntegratedDocument-integrationId"></a>
The identifier of the integration that provides access to the document.
Type: String
Required: Yes

 ** resourceId **   <a name="securityagent-Type-IntegratedDocument-resourceId"></a>
The provider-specific resource identifier for the document.
Type: String
Required: Yes
