# Category
<a name="API_Category"></a>

Represents a category assigned to a security testing task.

## Contents
<a name="API_Category_Contents"></a>

 ** isPrimary **   <a name="securityagent-Type-Category-isPrimary"></a>
Indicates whether this is the primary category for the task.
Type: Boolean
Required: No

 ** name **   <a name="securityagent-Type-Category-name"></a>
The name of the category.
Type: String
Required: No
