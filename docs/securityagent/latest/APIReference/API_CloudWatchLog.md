# CloudWatchLog
<a name="API_CloudWatchLog"></a>

The Amazon CloudWatch Logs configuration for pentest job logging.

## Contents
<a name="API_CloudWatchLog_Contents"></a>

 ** logGroup **   <a name="securityagent-Type-CloudWatchLog-logGroup"></a>
The name of the CloudWatch log group.
Type: String
Required: No

 ** logStream **   <a name="securityagent-Type-CloudWatchLog-logStream"></a>
The name of the CloudWatch log stream.
Type: String
Required: No
