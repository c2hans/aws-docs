# UserMetadata
<a name="API_UserMetadata"></a>

Contains metadata about a user member, including the username and email address.

## Contents
<a name="API_UserMetadata_Contents"></a>

 ** email **   <a name="securityagent-Type-UserMetadata-email"></a>
The email address of the user.
Type: String
Required: Yes

 ** username **   <a name="securityagent-Type-UserMetadata-username"></a>
The username of the user.
Type: String
Required: Yes
