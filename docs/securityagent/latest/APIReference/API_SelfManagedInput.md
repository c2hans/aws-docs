# SelfManagedInput
<a name="API_SelfManagedInput"></a>

The configuration for a self-managed private connection.

## Contents
<a name="API_SelfManagedInput_Contents"></a>

 ** resourceConfigurationId **   <a name="securityagent-Type-SelfManagedInput-resourceConfigurationId"></a>
The identifier or ARN of the resource configuration.
Type: String
Required: Yes

 ** certificate **   <a name="securityagent-Type-SelfManagedInput-certificate"></a>
The certificate for the private connection.
Type: String
Required: No
