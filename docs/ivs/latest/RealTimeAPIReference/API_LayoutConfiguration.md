# LayoutConfiguration
<a name="API_LayoutConfiguration"></a>

Configuration information of supported layouts for server-side composition.

## Contents
<a name="API_LayoutConfiguration_Contents"></a>

 ** grid **   <a name="ivsrealtimeeapireference-Type-LayoutConfiguration-grid"></a>
Configuration related to grid layout. Default: Grid layout.
Type: [GridConfiguration](API_GridConfiguration.md) object
Required: No

 ** pip **   <a name="ivsrealtimeeapireference-Type-LayoutConfiguration-pip"></a>
Configuration related to PiP layout.
Type: [PipConfiguration](API_PipConfiguration.md) object
Required: No
