# CompositionRecordingHlsConfiguration
<a name="API_CompositionRecordingHlsConfiguration"></a>

An object representing a configuration of HLS recordings for server-side composition.

## Contents
<a name="API_CompositionRecordingHlsConfiguration_Contents"></a>

 ** targetSegmentDurationSeconds **   <a name="ivsrealtimeeapireference-Type-CompositionRecordingHlsConfiguration-targetSegmentDurationSeconds"></a>
Defines the target duration for recorded segments generated when using composite recording. Default: 2.
Type: Integer
Valid Range: Minimum value of 2. Maximum value of 10.
Required: No
