# AudioTrackSettings
<a name="structures-AudioTrackSettings"></a>

Object specifying encoder-specific settings.

## Contents
<a name="structures-AudioTrackSettings-contente"></a>
+ **bitrate**
  + The expected audio bitrate in kilobits per second.
  + Type: Integer
  + Valid Range: Minimum value of 32. Maximum value of 256.
  + Required: Yes
