# Data Types
<a name="structures"></a>

The IVS Multitrack Video Broadcast Integration API contains several data types that various actions use. This section doescribes each data type in detail.

**Note:** The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+ [AudioConfiguration](structures-AudioConfiguration.md)
+ [AudioTrackConfiguration](structures-AudioTrackConfiguration.md)
+ [AudioTrackSettings](structures-AudioTrackSettings.md)
+ [CapabilitiesDescription](structures-CapabilitiesDescription.md)
+ [Client](structures-Client.md)
+ [ClientConfigurationStatus](structures-ClientConfigurationStatus.md)
+ [ClientDescription](structures-ClientDescription.md)
+ [ConfigurationMetadata](structures-ConfigurationMetadata.md)
+ [CpuDescription](structures-CpuDescription.md)
+ [EncoderConfiguration](structures-EncoderConfiguration.md)
+ [Framerate](structures-Framerate.md)
+ [GamingFeaturesDescription](structures-GamingFeaturesDescription.md)
+ [GpuDescription](structures-GpuDescription.md)
+ [Ingest](structures-Ingest.md)
+ [IngestEndpoint](structures-IngestEndpoint.md)
+ [MemoryDescription](structures-MemoryDescription.md)
+ [PreferencesDescription](structures-PreferencesDescription.md)
+ [SystemDescription](structures-SystemDescription.md)
+ [VideoTrackSettings](structures-VideoTrackSettings.md)
