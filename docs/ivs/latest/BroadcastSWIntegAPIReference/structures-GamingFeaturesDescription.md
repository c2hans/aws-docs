# GamingFeaturesDescription
<a name="structures-GamingFeaturesDescription"></a>

Object specifying the gaming features of the client.

## Contents
<a name="structures-GamingFeaturesDescription-contente"></a>
+ **game\_dvr\_allowed**
  + Game DVR allowed. Default: `false` (game DVR not allowed).
  + Type: Boolean
  + Required: No
+ **hags\_enabled**
  + Hardware-Assisted GPU Scheduling (HAGS) enabled. Default: `false` (HAGS not enabled).
  + Type: Boolean
  + Required: No
