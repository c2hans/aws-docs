# GetRoom
<a name="API_GetRoom"></a>

Gets the specified room.

## Request Syntax
<a name="API_GetRoom_RequestSyntax"></a>

```
POST /GetRoom HTTP/1.1
Content-type: application/json

{
   "identifier": "{{string}}"
}
```

## URI Request Parameters
<a name="API_GetRoom_RequestParameters"></a>

The request does not use any URI parameters.

## Request Body
<a name="API_GetRoom_RequestBody"></a>

The request accepts the following data in JSON format.

 ** [identifier](#API_GetRoom_RequestSyntax) **   <a name="ivs-GetRoom-request-identifier"></a>
Identifier of the room for which the configuration is to be retrieved. Currently this must be an ARN.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `arn:aws:ivschat:[a-z0-9-]+:[0-9]+:room/[a-zA-Z0-9-]+`
Required: Yes

## Response Syntax
<a name="API_GetRoom_ResponseSyntax"></a>

```
HTTP/1.1 200
Content-type: application/json

{
   "arn": "string",
   "createTime": "string",
   "id": "string",
   "loggingConfigurationIdentifiers": [ "string" ],
   "maximumMessageLength": number,

   "messageReviewHandler": {

   },

      "string" : "string"
   },
   "updateTime": "string"
}
```

## Response Elements
<a name="API_GetRoom_ResponseElements"></a>

If the action is successful, the service sends back an HTTP 200 response.

The following data is returned in JSON format by the service.

 ** [arn](#API_GetRoom_ResponseSyntax) **   <a name="ivs-GetRoom-response-arn"></a>
Room ARN, from the request (if `identifier` was an ARN).
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `arn:aws:ivschat:[a-z0-9-]+:[0-9]+:room/[a-zA-Z0-9-]+`

 ** [createTime](#API_GetRoom_ResponseSyntax) **   <a name="ivs-GetRoom-response-createTime"></a>
Time when the room was created. This is an ISO 8601 timestamp; *note that this is returned as a string*.
Type: Timestamp

 ** [id](#API_GetRoom_ResponseSyntax) **   <a name="ivs-GetRoom-response-id"></a>
Room ID, generated by the system. This is a relative identifier, the part of the ARN that uniquely identifies the room.
Type: String
Length Constraints: Fixed length of 12.
Pattern: `[a-zA-Z0-9]+`

 ** [loggingConfigurationIdentifiers](#API_GetRoom_ResponseSyntax) **   <a name="ivs-GetRoom-response-loggingConfigurationIdentifiers"></a>
Array of logging configurations attached to the room.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 3 items.
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `arn:aws:ivschat:[a-z0-9-]+:[0-9]+:logging-configuration/[a-zA-Z0-9-]+`

 ** [maximumMessageLength](#API_GetRoom_ResponseSyntax) **   <a name="ivs-GetRoom-response-maximumMessageLength"></a>
Maximum number of characters in a single message. Messages are expected to be UTF-8 encoded and this limit applies specifically to rune/code-point count, not number of bytes. Default: 500.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 500.

 ** [maximumMessageRatePerSecond](#API_GetRoom_ResponseSyntax) **   <a name="ivs-GetRoom-response-maximumMessageRatePerSecond"></a>
Maximum number of messages per second that can be sent to the room (by all clients). Default: 10.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 100.

 ** [messageReviewHandler](#API_GetRoom_ResponseSyntax) **   <a name="ivs-GetRoom-response-messageReviewHandler"></a>
Configuration information for optional review of messages.
Type: [MessageReviewHandler](API_MessageReviewHandler.md) object

 ** [name](#API_GetRoom_ResponseSyntax) **   <a name="ivs-GetRoom-response-name"></a>
Room name. The value does not need to be unique.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 128.
Pattern: `[a-zA-Z0-9-_]*`

 ** [tags](#API_GetRoom_ResponseSyntax) **   <a name="ivs-GetRoom-response-tags"></a>
Tags attached to the resource. Array of maps, each of the form `string:string (key:value)`.
Type: String to string map
Map Entries: Minimum number of 0 items. Maximum number of 50 items.
Key Length Constraints: Minimum length of 1. Maximum length of 128.
Value Length Constraints: Minimum length of 0. Maximum length of 256.

 ** [updateTime](#API_GetRoom_ResponseSyntax) **   <a name="ivs-GetRoom-response-updateTime"></a>
Time of the room’s last update. This is an ISO 8601 timestamp; *note that this is returned as a string*.
Type: Timestamp
