# Data Types
<a name="API_Types"></a>

The Amazon Interactive Video Service API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AdConfiguration](API_AdConfiguration.md)
+  [AdConfigurationSummary](API_AdConfigurationSummary.md)
+  [AudioConfiguration](API_AudioConfiguration.md)

+  [BatchStartViewerSessionRevocationViewerSession](API_BatchStartViewerSessionRevocationViewerSession.md)
+  [Channel](API_Channel.md)
+  [ChannelSummary](API_ChannelSummary.md)
+  [DestinationConfiguration](API_DestinationConfiguration.md)

+  [IngestConfigurations](API_IngestConfigurations.md)
