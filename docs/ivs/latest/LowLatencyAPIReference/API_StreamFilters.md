# StreamFilters
<a name="API_StreamFilters"></a>

Object specifying the stream attribute on which to filter.

## Contents
<a name="API_StreamFilters_Contents"></a>

 ** health **   <a name="ivs-Type-StreamFilters-health"></a>
The stream’s health.
Type: String
Valid Values: `HEALTHY | STARVING | UNKNOWN`
Required: No
