# AWS Security Hub Documentation

AWS Security Hub provides you with a comprehensive view of the security state of your AWS resources. Security Hub collects security data from across AWS accounts and services, and helps you analyze your security trends to identify and prioritize the security issues across your AWS environment.

- [AWS Security Hub User Guide](/securityhub/latest/userguide/): Describes how to set up, configure, and use AWS Security Hub and Security Hub CSPM to evaluate the security and compliance state of your AWS environment.
- [AWS Security Hub API Reference](/securityhub/1.0/APIReference/): Describes all the API operations for AWS Security Hub and Security Hub CSPM.
- [AWS Security Hub CSPM Partner Integration Guide](/securityhub/latest/partnerguide/): Describes how AWS Partner Network (APN) Partners set up an integration with AWS Security Hub CSPM.
