# AwsRoute53HostedZoneVpcDetails
<a name="API_AwsRoute53HostedZoneVpcDetails"></a>

 For private hosted zones, this is a complex type that contains information about an Amazon VPC.

## Contents
<a name="API_AwsRoute53HostedZoneVpcDetails_Contents"></a>

 ** Id **   <a name="securityhub-Type-AwsRoute53HostedZoneVpcDetails-Id"></a>
 The identifier of an Amazon VPC.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Region **   <a name="securityhub-Type-AwsRoute53HostedZoneVpcDetails-Region"></a>
 The AWS Region that an Amazon VPC was created in.
Type: String
Pattern: `.*\S.*`
Required: No
