# AwsIamPermissionsBoundary
<a name="API_AwsIamPermissionsBoundary"></a>

Information about the policy used to set the permissions boundary for an IAM principal.

## Contents
<a name="API_AwsIamPermissionsBoundary_Contents"></a>

 ** PermissionsBoundaryArn **   <a name="securityhub-Type-AwsIamPermissionsBoundary-PermissionsBoundaryArn"></a>
The ARN of the policy used to set the permissions boundary.
Type: String
Pattern: `.*\S.*`
Required: No

 ** PermissionsBoundaryType **   <a name="securityhub-Type-AwsIamPermissionsBoundary-PermissionsBoundaryType"></a>
The usage type for the permissions boundary.
Type: String
Pattern: `.*\S.*`
Required: No
