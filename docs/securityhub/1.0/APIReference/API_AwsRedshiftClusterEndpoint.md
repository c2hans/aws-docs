# AwsRedshiftClusterEndpoint
<a name="API_AwsRedshiftClusterEndpoint"></a>

The connection endpoint for an Amazon Redshift cluster.

## Contents
<a name="API_AwsRedshiftClusterEndpoint_Contents"></a>

 ** Address **   <a name="securityhub-Type-AwsRedshiftClusterEndpoint-Address"></a>
The DNS address of the cluster.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Port **   <a name="securityhub-Type-AwsRedshiftClusterEndpoint-Port"></a>
The port that the database engine listens on.
Type: Integer
Required: No
