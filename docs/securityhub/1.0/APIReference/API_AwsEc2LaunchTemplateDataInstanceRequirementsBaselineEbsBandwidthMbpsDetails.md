# AwsEc2LaunchTemplateDataInstanceRequirementsBaselineEbsBandwidthMbpsDetails
<a name="API_AwsEc2LaunchTemplateDataInstanceRequirementsBaselineEbsBandwidthMbpsDetails"></a>

 The minimum and maximum baseline bandwidth to Amazon Elastic Block Store (Amazon EBS), in Mbps. For more information, see [Amazon EBS–optimized instances ](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ebs-optimized.html) in the *Amazon EC2 User Guide*.

## Contents
<a name="API_AwsEc2LaunchTemplateDataInstanceRequirementsBaselineEbsBandwidthMbpsDetails_Contents"></a>

 ** Max **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataInstanceRequirementsBaselineEbsBandwidthMbpsDetails-Max"></a>
 The maximum baseline bandwidth, in Mbps. If this parameter is omitted, there's no maximum limit.
Type: Integer
Required: No

 ** Min **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataInstanceRequirementsBaselineEbsBandwidthMbpsDetails-Min"></a>
 The minimum baseline bandwidth, in Mbps. If this parameter is omitted, there's no minimum limit.
Type: Integer
Required: No
