# AwsEc2LaunchTemplateDataMaintenanceOptionsDetails
<a name="API_AwsEc2LaunchTemplateDataMaintenanceOptionsDetails"></a>

 ** AutoRecovery **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataMaintenanceOptionsDetails-AutoRecovery"></a>

Pattern: `.*\S.*`
Required: No
