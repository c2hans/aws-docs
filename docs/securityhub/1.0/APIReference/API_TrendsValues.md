# TrendsValues
<a name="API_TrendsValues"></a>

Contains the aggregated finding values for a specific point in the findings trend timeline.

## Contents
<a name="API_TrendsValues_Contents"></a>

 ** SeverityTrends **   <a name="securityhub-Type-TrendsValues-SeverityTrends"></a>
The count of findings organized by severity level for this data point in the trend timeline.
Type: [SeverityTrendsCount](API_SeverityTrendsCount.md) object
Required: Yes
