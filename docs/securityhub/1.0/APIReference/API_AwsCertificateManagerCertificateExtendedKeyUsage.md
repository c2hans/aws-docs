# AwsCertificateManagerCertificateExtendedKeyUsage
<a name="API_AwsCertificateManagerCertificateExtendedKeyUsage"></a>

Contains information about an extended key usage X.509 v3 extension object.

## Contents
<a name="API_AwsCertificateManagerCertificateExtendedKeyUsage_Contents"></a>

 ** Name **   <a name="securityhub-Type-AwsCertificateManagerCertificateExtendedKeyUsage-Name"></a>
The name of an extension value. Indicates the purpose for which the certificate public key can be used.
Type: String
Pattern: `.*\S.*`
Required: No

 ** OId **   <a name="securityhub-Type-AwsCertificateManagerCertificateExtendedKeyUsage-OId"></a>
An object identifier (OID) for the extension value.
The format is numbers separated by periods.
Type: String
Pattern: `.*\S.*`
Required: No
