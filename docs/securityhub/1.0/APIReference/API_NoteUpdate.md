# NoteUpdate
<a name="API_NoteUpdate"></a>

The updated note.

## Contents
<a name="API_NoteUpdate_Contents"></a>

 ** Text **   <a name="securityhub-Type-NoteUpdate-Text"></a>
The updated note text.
Type: String
Pattern: `.*\S.*`
Required: Yes

 ** UpdatedBy **   <a name="securityhub-Type-NoteUpdate-UpdatedBy"></a>
The principal that updated the note.
Type: String
Pattern: `.*\S.*`
Required: Yes
