# AwsAutoScalingLaunchConfigurationInstanceMonitoringDetails
<a name="API_AwsAutoScalingLaunchConfigurationInstanceMonitoringDetails"></a>

Information about the type of monitoring for instances in the group.

## Contents
<a name="API_AwsAutoScalingLaunchConfigurationInstanceMonitoringDetails_Contents"></a>

 ** Enabled **   <a name="securityhub-Type-AwsAutoScalingLaunchConfigurationInstanceMonitoringDetails-Enabled"></a>
If set to `true`, then instances in the group launch with detailed monitoring.
If set to `false`, then instances in the group launch with basic monitoring.
Type: Boolean
Required: No
