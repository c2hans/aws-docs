# AwsOpenSearchServiceDomainClusterConfigZoneAwarenessConfigDetails

 ** AvailabilityZoneCount **   <a name="securityhub-Type-AwsOpenSearchServiceDomainClusterConfigZoneAwarenessConfigDetails-AvailabilityZoneCount"></a>
