# AwsGuardDutyDetectorDataSourcesKubernetesDetails
<a name="API_AwsGuardDutyDetectorDataSourcesKubernetesDetails"></a>

 An object that contains information on the status of Kubernetes data sources for the detector.

<a name="API_AwsGuardDutyDetectorDataSourcesKubernetesDetails_Contents"></a>

 ** AuditLogs **   <a name="securityhub-Type-AwsGuardDutyDetectorDataSourcesKubernetesDetails-AuditLogs"></a>
 Describes whether Kubernetes audit logs are activated as a data source for the detector.
Type: [AwsGuardDutyDetectorDataSourcesKubernetesAuditLogsDetails](API_AwsGuardDutyDetectorDataSourcesKubernetesAuditLogsDetails.md) object
Required: No
