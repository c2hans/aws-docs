# AwsElasticBeanstalkEnvironmentTier
<a name="API_AwsElasticBeanstalkEnvironmentTier"></a>

Contains information about the tier of the environment.

## Contents
<a name="API_AwsElasticBeanstalkEnvironmentTier_Contents"></a>

 ** Name **   <a name="securityhub-Type-AwsElasticBeanstalkEnvironmentTier-Name"></a>
The name of the environment tier. Valid values are `WebServer` or `Worker`.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Type **   <a name="securityhub-Type-AwsElasticBeanstalkEnvironmentTier-Type"></a>
The type of environment tier. Valid values are `Standard` or `SQS/HTTP`.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Version **   <a name="securityhub-Type-AwsElasticBeanstalkEnvironmentTier-Version"></a>
The version of the environment tier.
Type: String
Pattern: `.*\S.*`
Required: No
