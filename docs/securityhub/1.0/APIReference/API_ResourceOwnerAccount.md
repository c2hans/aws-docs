# ResourceOwnerAccount
<a name="API_ResourceOwnerAccount"></a>

Information about the account that owns a resource, for example, an Azure Subscription or AWS Account.

## Contents
<a name="API_ResourceOwnerAccount_Contents"></a>

 ** Id **   <a name="securityhub-Type-ResourceOwnerAccount-Id"></a>
The unique identifier of the account that owns the resource, for example, Azure Subscription Id or AWS Account Id.
Type: String
Pattern: `.*\S.*`
Required: No
