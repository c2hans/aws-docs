# FeatureDetail
<a name="API_FeatureDetail"></a>

Contains the status and metadata for an opt-in feature.

## Contents
<a name="API_FeatureDetail_Contents"></a>

 ** FeatureStatus **   <a name="securityhub-Type-FeatureDetail-FeatureStatus"></a>
The current enablement status of the feature. Valid values: `ENABLED` \| `DISABLED`.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: No

 ** UpdatedAt **   <a name="securityhub-Type-FeatureDetail-UpdatedAt"></a>
The date and time when the feature status was last updated.
Type: Timestamp
Required: No
