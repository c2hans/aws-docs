# Result
<a name="API_Result"></a>

Details about the account that was not processed.

## Contents
<a name="API_Result_Contents"></a>

 ** AccountId **   <a name="securityhub-Type-Result-AccountId"></a>
An AWS account ID of the account that was not processed.
Type: String
Required: No

 ** ProcessingResult **   <a name="securityhub-Type-Result-ProcessingResult"></a>
The reason that the account was not processed.
Type: String
Pattern: `.*\S.*`
Required: No
