# AwsRdsDbSecurityGroupIpRange
<a name="API_AwsRdsDbSecurityGroupIpRange"></a>

IP range information for an RDS DB security group.

## Contents
<a name="API_AwsRdsDbSecurityGroupIpRange_Contents"></a>

 ** CidrIp **   <a name="securityhub-Type-AwsRdsDbSecurityGroupIpRange-CidrIp"></a>
Specifies the IP range.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Status **   <a name="securityhub-Type-AwsRdsDbSecurityGroupIpRange-Status"></a>
Specifies the status of the IP range.
Type: String
Pattern: `.*\S.*`
Required: No
