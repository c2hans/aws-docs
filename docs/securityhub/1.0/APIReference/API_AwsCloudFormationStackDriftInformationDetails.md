# AwsCloudFormationStackDriftInformationDetails
<a name="API_AwsCloudFormationStackDriftInformationDetails"></a>

Provides information about the stack's conformity to its expected template configuration.

## Contents
<a name="API_AwsCloudFormationStackDriftInformationDetails_Contents"></a>

 ** StackDriftStatus **   <a name="securityhub-Type-AwsCloudFormationStackDriftInformationDetails-StackDriftStatus"></a>
Status of the stack's actual configuration compared to its expected template configuration.
Type: String
Pattern: `.*\S.*`
Required: No
