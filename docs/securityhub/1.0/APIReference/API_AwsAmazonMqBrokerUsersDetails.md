# AwsAmazonMqBrokerUsersDetails
<a name="API_AwsAmazonMqBrokerUsersDetails"></a>

 Provides details about the broker usernames for the specified broker. Doesn't apply to RabbitMQ brokers.

## Contents
<a name="API_AwsAmazonMqBrokerUsersDetails_Contents"></a>

 ** PendingChange **   <a name="securityhub-Type-AwsAmazonMqBrokerUsersDetails-PendingChange"></a>
 The type of change pending for the broker user.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Username **   <a name="securityhub-Type-AwsAmazonMqBrokerUsersDetails-Username"></a>
 The username of the broker user.
Type: String
Pattern: `.*\S.*`
Required: No
