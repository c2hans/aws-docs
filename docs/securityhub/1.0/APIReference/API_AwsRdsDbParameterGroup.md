# AwsRdsDbParameterGroup
<a name="API_AwsRdsDbParameterGroup"></a>

Provides information about a parameter group for a DB instance.

## Contents
<a name="API_AwsRdsDbParameterGroup_Contents"></a>

 ** DbParameterGroupName **   <a name="securityhub-Type-AwsRdsDbParameterGroup-DbParameterGroupName"></a>
The name of the parameter group.
Type: String
Pattern: `.*\S.*`
Required: No

 ** ParameterApplyStatus **   <a name="securityhub-Type-AwsRdsDbParameterGroup-ParameterApplyStatus"></a>
The status of parameter updates.
Type: String
Pattern: `.*\S.*`
Required: No
