# AwsApiGatewayEndpointConfiguration
<a name="API_AwsApiGatewayEndpointConfiguration"></a>

Contains information about the endpoints for the API.

## Contents
<a name="API_AwsApiGatewayEndpointConfiguration_Contents"></a>

 ** Types **   <a name="securityhub-Type-AwsApiGatewayEndpointConfiguration-Types"></a>
A list of endpoint types for the REST API.
For an edge-optimized API, the endpoint type is `EDGE`. For a Regional API, the endpoint type is `REGIONAL`. For a private API, the endpoint type is `PRIVATE`.
Type: Array of strings
Pattern: `.*\S.*`
Required: No
