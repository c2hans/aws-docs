# AwsEc2LaunchTemplateDataIamInstanceProfileDetails
<a name="API_AwsEc2LaunchTemplateDataIamInstanceProfileDetails"></a>

 Provides details for an AWS Identity and Access Management (IAM) instance profile, which is a container for an IAM role for your instance.

## Contents
<a name="API_AwsEc2LaunchTemplateDataIamInstanceProfileDetails_Contents"></a>

 ** Arn **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataIamInstanceProfileDetails-Arn"></a>
 The Amazon Resource Name (ARN) of the instance profile.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Name **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataIamInstanceProfileDetails-Name"></a>
 The name of the instance profile.
Type: String
Pattern: `.*\S.*`
Required: No
