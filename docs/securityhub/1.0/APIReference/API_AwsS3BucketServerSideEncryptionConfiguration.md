# AwsS3BucketServerSideEncryptionConfiguration
<a name="API_AwsS3BucketServerSideEncryptionConfiguration"></a>

## Contents
<a name="API_AwsS3BucketServerSideEncryptionConfiguration_Contents"></a>

 ** Rules **   <a name="securityhub-Type-AwsS3BucketServerSideEncryptionConfiguration-Rules"></a>
The encryption rules that are applied to the S3 bucket.
Type: Array of [AwsS3BucketServerSideEncryptionRule](API_AwsS3BucketServerSideEncryptionRule.md) objects
