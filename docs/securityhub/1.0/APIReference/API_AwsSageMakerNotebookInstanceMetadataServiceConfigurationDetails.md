# AwsSageMakerNotebookInstanceMetadataServiceConfigurationDetails
<a name="API_AwsSageMakerNotebookInstanceMetadataServiceConfigurationDetails"></a>

 Information on the instance metadata service (IMDS) configuration of the notebook instance.

## Contents
<a name="API_AwsSageMakerNotebookInstanceMetadataServiceConfigurationDetails_Contents"></a>

 ** MinimumInstanceMetadataServiceVersion **   <a name="securityhub-Type-AwsSageMakerNotebookInstanceMetadataServiceConfigurationDetails-MinimumInstanceMetadataServiceVersion"></a>
 Indicates the minimum IMDS version that the notebook instance supports.
Type: String
Pattern: `.*\S.*`
Required: No
