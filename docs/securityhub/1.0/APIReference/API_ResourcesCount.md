# ResourcesCount
<a name="API_ResourcesCount"></a>

Contains counts of resources for trend analysis.

## Contents
<a name="API_ResourcesCount_Contents"></a>

 ** AllResources **   <a name="securityhub-Type-ResourcesCount-AllResources"></a>
The total count of all resources for the given time interval.
Type: Long
Valid Range: Minimum value of 0.
Required: Yes
