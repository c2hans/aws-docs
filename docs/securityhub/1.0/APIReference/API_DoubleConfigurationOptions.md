# DoubleConfigurationOptions
<a name="API_DoubleConfigurationOptions"></a>

 The options for customizing a security control parameter that is a double.

## Contents
<a name="API_DoubleConfigurationOptions_Contents"></a>

 ** DefaultValue **   <a name="securityhub-Type-DoubleConfigurationOptions-DefaultValue"></a>
 The Security Hub CSPM default value for a control parameter that is a double.
Type: Double
Required: No

 ** Max **   <a name="securityhub-Type-DoubleConfigurationOptions-Max"></a>
 The maximum valid value for a control parameter that is a double.
Type: Double
Required: No

 ** Min **   <a name="securityhub-Type-DoubleConfigurationOptions-Min"></a>
 The minimum valid value for a control parameter that is a double.
Type: Double
Required: No
