# BooleanConfigurationOptions
<a name="API_BooleanConfigurationOptions"></a>

 The options for customizing a security control parameter with a boolean. For a boolean parameter, the options are `true` and `false`.

## Contents
<a name="API_BooleanConfigurationOptions_Contents"></a>

 ** DefaultValue **   <a name="securityhub-Type-BooleanConfigurationOptions-DefaultValue"></a>
 The Security Hub CSPM default value for a boolean parameter.
Type: Boolean
Required: No
