# AwsEc2InstanceNetworkInterfacesDetails
<a name="API_AwsEc2InstanceNetworkInterfacesDetails"></a>

Identifies a network interface for the Amazon EC2 instance.

## Contents
<a name="API_AwsEc2InstanceNetworkInterfacesDetails_Contents"></a>

 ** NetworkInterfaceId **   <a name="securityhub-Type-AwsEc2InstanceNetworkInterfacesDetails-NetworkInterfaceId"></a>
The identifier of the network interface. The details are in a corresponding `AwsEc2NetworkInterfacesDetails` object.
Type: String
Pattern: `.*\S.*`
Required: No
