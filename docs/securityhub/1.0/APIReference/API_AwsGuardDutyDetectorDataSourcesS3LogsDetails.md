# AwsGuardDutyDetectorDataSourcesS3LogsDetails
<a name="API_AwsGuardDutyDetectorDataSourcesS3LogsDetails"></a>

 An object that contains information on the status of S3 data event logs as a data source for the detector.

## Contents
<a name="API_AwsGuardDutyDetectorDataSourcesS3LogsDetails_Contents"></a>

 ** Status **   <a name="securityhub-Type-AwsGuardDutyDetectorDataSourcesS3LogsDetails-Status"></a>
 A value that describes whether S3 data event logs are automatically enabled for new members of an organization.
Type: String
Pattern: `.*\S.*`
Required: No
