# AwsCloudWatchAlarmDimensionsDetails
<a name="API_AwsCloudWatchAlarmDimensionsDetails"></a>

Details about the dimensions for the metric associated with the alarm.

## Contents
<a name="API_AwsCloudWatchAlarmDimensionsDetails_Contents"></a>

 ** Name **   <a name="securityhub-Type-AwsCloudWatchAlarmDimensionsDetails-Name"></a>
The name of a dimension.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Value **   <a name="securityhub-Type-AwsCloudWatchAlarmDimensionsDetails-Value"></a>
The value of a dimension.
Type: String
Pattern: `.*\S.*`
Required: No
