# AwsCodeBuildProjectLogsConfigCloudWatchLogsDetails
<a name="API_AwsCodeBuildProjectLogsConfigCloudWatchLogsDetails"></a>

<a name="API_AwsCodeBuildProjectLogsConfigCloudWatchLogsDetails_Contents"></a>

 ** GroupName **   <a name="securityhub-Type-AwsCodeBuildProjectLogsConfigCloudWatchLogsDetails-GroupName"></a>

Type: String
Pattern: `.*\S.*`
Required: No

 ** Status **   <a name="securityhub-Type-AwsCodeBuildProjectLogsConfigCloudWatchLogsDetails-Status"></a>
The current status of the logs in CloudWatch Logs for a build project.
Type: String
Pattern: `.*\S.*`
Required: No

 ** StreamName **   <a name="securityhub-Type-AwsCodeBuildProjectLogsConfigCloudWatchLogsDetails-StreamName"></a>

Pattern: `.*\S.*`
Required: No
