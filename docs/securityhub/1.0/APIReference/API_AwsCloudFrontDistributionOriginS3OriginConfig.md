# AwsCloudFrontDistributionOriginS3OriginConfig
<a name="API_AwsCloudFrontDistributionOriginS3OriginConfig"></a>

Information about an origin that is an Amazon S3 bucket that is not configured with static website hosting.

## Contents
<a name="API_AwsCloudFrontDistributionOriginS3OriginConfig_Contents"></a>

 ** OriginAccessIdentity **   <a name="securityhub-Type-AwsCloudFrontDistributionOriginS3OriginConfig-OriginAccessIdentity"></a>
The CloudFront origin access identity to associate with the origin.
Type: String
Pattern: `.*\S.*`
Required: No
