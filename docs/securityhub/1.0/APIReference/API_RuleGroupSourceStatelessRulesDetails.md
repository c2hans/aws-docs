# RuleGroupSourceStatelessRulesDetails
<a name="API_RuleGroupSourceStatelessRulesDetails"></a>

A stateless rule in the rule group.

## Contents
<a name="API_RuleGroupSourceStatelessRulesDetails_Contents"></a>

 ** Priority **   <a name="securityhub-Type-RuleGroupSourceStatelessRulesDetails-Priority"></a>
Indicates the order in which to run this rule relative to all of the rules in the stateless rule group.
Type: Integer
Required: No

 ** RuleDefinition **   <a name="securityhub-Type-RuleGroupSourceStatelessRulesDetails-RuleDefinition"></a>
Provides the definition of the stateless rule.
Type: [RuleGroupSourceStatelessRuleDefinition](API_RuleGroupSourceStatelessRuleDefinition.md) object
Required: No
