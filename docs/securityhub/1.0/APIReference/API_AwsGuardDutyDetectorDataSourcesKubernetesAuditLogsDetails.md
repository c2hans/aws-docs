# AwsGuardDutyDetectorDataSourcesKubernetesAuditLogsDetails
<a name="API_AwsGuardDutyDetectorDataSourcesKubernetesAuditLogsDetails"></a>

 An object that contains information on the status of Kubernetes audit logs as a data source for the detector.

<a name="API_AwsGuardDutyDetectorDataSourcesKubernetesAuditLogsDetails_Contents"></a>

 ** Status **   <a name="securityhub-Type-AwsGuardDutyDetectorDataSourcesKubernetesAuditLogsDetails-Status"></a>
 Describes whether Kubernetes audit logs are activated as a data source for the detector.
Type: String
Pattern: `.*\S.*`
Required: No
