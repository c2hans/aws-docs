# KeywordFilter
<a name="API_KeywordFilter"></a>

A keyword filter for querying findings.

## Contents
<a name="API_KeywordFilter_Contents"></a>

 ** Value **   <a name="securityhub-Type-KeywordFilter-Value"></a>
A value for the keyword.
Type: String
Pattern: `.*\S.*`
Required: No
