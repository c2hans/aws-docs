# IntegerConfigurationOptions
<a name="API_IntegerConfigurationOptions"></a>

 The options for customizing a security control parameter that is an integer.

## Contents
<a name="API_IntegerConfigurationOptions_Contents"></a>

 ** DefaultValue **   <a name="securityhub-Type-IntegerConfigurationOptions-DefaultValue"></a>
 The Security Hub CSPM default value for a control parameter that is an integer.
Type: Integer
Required: No

 ** Max **   <a name="securityhub-Type-IntegerConfigurationOptions-Max"></a>
 The maximum valid value for a control parameter that is an integer.
Type: Integer
Required: No

 ** Min **   <a name="securityhub-Type-IntegerConfigurationOptions-Min"></a>
 The minimum valid value for a control parameter that is an integer.
Type: Integer
Required: No
