# AwsRedshiftClusterResizeInfo
<a name="API_AwsRedshiftClusterResizeInfo"></a>

Information about the resize operation for the cluster.

## Contents
<a name="API_AwsRedshiftClusterResizeInfo_Contents"></a>

 ** AllowCancelResize **   <a name="securityhub-Type-AwsRedshiftClusterResizeInfo-AllowCancelResize"></a>
Indicates whether the resize operation can be canceled.
Type: Boolean
Required: No

 ** ResizeType **   <a name="securityhub-Type-AwsRedshiftClusterResizeInfo-ResizeType"></a>
The type of resize operation.
Valid values: `ClassicResize`
Type: String
Pattern: `.*\S.*`
Required: No
