# AwsIamAccessKeySessionContext
<a name="API_AwsIamAccessKeySessionContext"></a>

Provides information about the session that the key was used for.

## Contents
<a name="API_AwsIamAccessKeySessionContext_Contents"></a>

 ** Attributes **   <a name="securityhub-Type-AwsIamAccessKeySessionContext-Attributes"></a>
Attributes of the session that the key was used for.
Type: [AwsIamAccessKeySessionContextAttributes](API_AwsIamAccessKeySessionContextAttributes.md) object
Required: No

 ** SessionIssuer **   <a name="securityhub-Type-AwsIamAccessKeySessionContext-SessionIssuer"></a>
Information about the entity that created the session.
Type: [AwsIamAccessKeySessionContextSessionIssuer](API_AwsIamAccessKeySessionContextSessionIssuer.md) object
Required: No
