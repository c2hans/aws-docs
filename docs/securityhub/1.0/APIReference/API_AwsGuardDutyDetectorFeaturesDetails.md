# AwsGuardDutyDetectorFeaturesDetails
<a name="API_AwsGuardDutyDetectorFeaturesDetails"></a>

 Describes which features are activated for the detector.

## Contents
<a name="API_AwsGuardDutyDetectorFeaturesDetails_Contents"></a>

 ** Name **   <a name="securityhub-Type-AwsGuardDutyDetectorFeaturesDetails-Name"></a>
 Indicates the name of the feature that is activated for the detector.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Status **   <a name="securityhub-Type-AwsGuardDutyDetectorFeaturesDetails-Status"></a>
 Indicates the status of the feature that is activated for the detector.
Type: String
Pattern: `.*\S.*`
Required: No
