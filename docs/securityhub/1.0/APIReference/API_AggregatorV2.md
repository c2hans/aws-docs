# AggregatorV2
<a name="API_AggregatorV2"></a>

Specifies a cross-Region data aggregation configuration, including the aggregation Region and any linked Regions.

## Contents
<a name="API_AggregatorV2_Contents"></a>

 ** AggregatorV2Arn **   <a name="securityhub-Type-AggregatorV2-AggregatorV2Arn"></a>
The ARN of the aggregatorV2.
Type: String
Pattern: `.*\S.*`
Required: No
