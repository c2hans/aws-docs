# AwsEc2LaunchTemplateDataNetworkInterfaceSetIpv4PrefixesDetails
<a name="API_AwsEc2LaunchTemplateDataNetworkInterfaceSetIpv4PrefixesDetails"></a>

 Provides details on one or more IPv4 prefixes for a network interface.

## Contents
<a name="API_AwsEc2LaunchTemplateDataNetworkInterfaceSetIpv4PrefixesDetails_Contents"></a>

 ** Ipv4Prefix **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataNetworkInterfaceSetIpv4PrefixesDetails-Ipv4Prefix"></a>
 The IPv4 prefix. For more information, see [Assigning prefixes to Amazon EC2 network interfaces](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-prefix-eni.html) in the *Amazon Elastic Compute Cloud User Guide*.
Type: String
Pattern: `.*\S.*`
Required: No
