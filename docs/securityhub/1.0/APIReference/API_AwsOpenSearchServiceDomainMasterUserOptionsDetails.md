# AwsOpenSearchServiceDomainMasterUserOptionsDetails
<a name="API_AwsOpenSearchServiceDomainMasterUserOptionsDetails"></a>

Specifies information about the master user of the domain.

## Contents
<a name="API_AwsOpenSearchServiceDomainMasterUserOptionsDetails_Contents"></a>

 ** MasterUserArn **   <a name="securityhub-Type-AwsOpenSearchServiceDomainMasterUserOptionsDetails-MasterUserArn"></a>
The Amazon Resource Name (ARN) for the master user.
Type: String
Pattern: `.*\S.*`
Required: No

 ** MasterUserName **   <a name="securityhub-Type-AwsOpenSearchServiceDomainMasterUserOptionsDetails-MasterUserName"></a>
The username for the master user.
Type: String
Pattern: `.*\S.*`
Required: No

 ** MasterUserPassword **   <a name="securityhub-Type-AwsOpenSearchServiceDomainMasterUserOptionsDetails-MasterUserPassword"></a>
The password for the master user.
Type: String
Pattern: `.*\S.*`
Required: No
