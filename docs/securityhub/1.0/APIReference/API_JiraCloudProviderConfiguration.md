# JiraCloudProviderConfiguration
<a name="API_JiraCloudProviderConfiguration"></a>

The initial configuration settings required to establish an integration between Security Hub and Jira Cloud.

## Contents
<a name="API_JiraCloudProviderConfiguration_Contents"></a>

 ** ProjectKey **   <a name="securityhub-Type-JiraCloudProviderConfiguration-ProjectKey"></a>
The project key for a JiraCloud instance.
Type: String
Pattern: `.*\S.*`
Required: No
