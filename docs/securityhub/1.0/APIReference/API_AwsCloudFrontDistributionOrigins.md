# AwsCloudFrontDistributionOrigins
<a name="API_AwsCloudFrontDistributionOrigins"></a>

A complex type that contains information about origins and origin groups for this CloudFront distribution.

<a name="API_AwsCloudFrontDistributionOrigins_Contents"></a>

 ** Items **   <a name="securityhub-Type-AwsCloudFrontDistributionOrigins-Items"></a>

Type: Array of [AwsCloudFrontDistributionOriginItem](API_AwsCloudFrontDistributionOriginItem.md) objects
Required: No
