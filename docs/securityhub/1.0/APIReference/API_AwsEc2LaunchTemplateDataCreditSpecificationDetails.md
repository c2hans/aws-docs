# AwsEc2LaunchTemplateDataCreditSpecificationDetails
<a name="API_AwsEc2LaunchTemplateDataCreditSpecificationDetails"></a>

 Specifies the credit option for CPU usage of a T2, T3, or T3a Amazon EC2 instance.

## Contents
<a name="API_AwsEc2LaunchTemplateDataCreditSpecificationDetails_Contents"></a>

 ** CpuCredits **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataCreditSpecificationDetails-CpuCredits"></a>
 The credit option for CPU usage of a T instance.
Type: String
Pattern: `.*\S.*`
Required: No
