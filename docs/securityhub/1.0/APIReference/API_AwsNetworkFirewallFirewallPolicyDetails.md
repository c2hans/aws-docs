# AwsNetworkFirewallFirewallPolicyDetails
<a name="API_AwsNetworkFirewallFirewallPolicyDetails"></a>

Details about a firewall policy. A firewall policy defines the behavior of a network firewall.

## Contents
<a name="API_AwsNetworkFirewallFirewallPolicyDetails_Contents"></a>

 ** Description **   <a name="securityhub-Type-AwsNetworkFirewallFirewallPolicyDetails-Description"></a>
A description of the firewall policy.
Type: String
Pattern: `.*\S.*`
Required: No

 ** FirewallPolicy **   <a name="securityhub-Type-AwsNetworkFirewallFirewallPolicyDetails-FirewallPolicy"></a>
The firewall policy configuration.
Type: [FirewallPolicyDetails](API_FirewallPolicyDetails.md) object
Required: No

 ** FirewallPolicyArn **   <a name="securityhub-Type-AwsNetworkFirewallFirewallPolicyDetails-FirewallPolicyArn"></a>
The ARN of the firewall policy.
Type: String
Pattern: `.*\S.*`
Required: No

 ** FirewallPolicyId **   <a name="securityhub-Type-AwsNetworkFirewallFirewallPolicyDetails-FirewallPolicyId"></a>
The identifier of the firewall policy.
Type: String
Pattern: `.*\S.*`
Required: No

 ** FirewallPolicyName **   <a name="securityhub-Type-AwsNetworkFirewallFirewallPolicyDetails-FirewallPolicyName"></a>
The name of the firewall policy.
Type: String
Pattern: `.*\S.*`
Required: No
