# AwsWafv2ActionAllowDetails
<a name="API_AwsWafv2ActionAllowDetails"></a>

 Specifies that AWS WAF should allow the request and optionally defines additional custom handling for the request.

## Contents
<a name="API_AwsWafv2ActionAllowDetails_Contents"></a>

 ** CustomRequestHandling **   <a name="securityhub-Type-AwsWafv2ActionAllowDetails-CustomRequestHandling"></a>
 Defines custom handling for the web request. For information about customizing web requests and responses, see [Customizing web requests and responses in AWS WAF](https://docs.aws.amazon.com/waf/latest/developerguide/waf-custom-request-response.html) in the * AWS WAF Developer Guide.*.
Type: [AwsWafv2CustomRequestHandlingDetails](API_AwsWafv2CustomRequestHandlingDetails.md) object
Required: No
