# AwsEcrRepositoryLifecyclePolicyDetails
<a name="API_AwsEcrRepositoryLifecyclePolicyDetails"></a>

Information about the lifecycle policy for the repository.

## Contents
<a name="API_AwsEcrRepositoryLifecyclePolicyDetails_Contents"></a>

 ** LifecyclePolicyText **   <a name="securityhub-Type-AwsEcrRepositoryLifecyclePolicyDetails-LifecyclePolicyText"></a>
The text of the lifecycle policy.
Type: String
Pattern: `.*\S.*`
Required: No

 ** RegistryId **   <a name="securityhub-Type-AwsEcrRepositoryLifecyclePolicyDetails-RegistryId"></a>
The AWS account identifier that is associated with the registry that contains the repository.
Type: String
Pattern: `.*\S.*`
Required: No
