# AwsEventsEndpointRoutingConfigDetails
<a name="API_AwsEventsEndpointRoutingConfigDetails"></a>

 Provides details about the routing configuration of the endpoint.

## Contents
<a name="API_AwsEventsEndpointRoutingConfigDetails_Contents"></a>

 ** FailoverConfig **   <a name="securityhub-Type-AwsEventsEndpointRoutingConfigDetails-FailoverConfig"></a>
 The failover configuration for an endpoint. This includes what triggers failover and what happens when it's triggered.
Type: [AwsEventsEndpointRoutingConfigFailoverConfigDetails](API_AwsEventsEndpointRoutingConfigFailoverConfigDetails.md) object
Required: No
