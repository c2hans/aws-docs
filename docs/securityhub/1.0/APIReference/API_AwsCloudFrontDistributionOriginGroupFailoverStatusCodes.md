# AwsCloudFrontDistributionOriginGroupFailoverStatusCodes
<a name="API_AwsCloudFrontDistributionOriginGroupFailoverStatusCodes"></a>

The status codes that cause an origin group to fail over.

## Contents
<a name="API_AwsCloudFrontDistributionOriginGroupFailoverStatusCodes_Contents"></a>

 ** Items **   <a name="securityhub-Type-AwsCloudFrontDistributionOriginGroupFailoverStatusCodes-Items"></a>
The list of status code values that can cause a failover to the next origin.
Type: Array of integers
Required: No

 ** Quantity **   <a name="securityhub-Type-AwsCloudFrontDistributionOriginGroupFailoverStatusCodes-Quantity"></a>
The number of status codes that can cause a failover.
Type: Integer
Required: No
