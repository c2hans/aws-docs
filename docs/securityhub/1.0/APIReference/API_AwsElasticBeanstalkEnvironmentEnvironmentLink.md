# AwsElasticBeanstalkEnvironmentEnvironmentLink
<a name="API_AwsElasticBeanstalkEnvironmentEnvironmentLink"></a>

Contains information about a link to another environment that is in the same group.

## Contents
<a name="API_AwsElasticBeanstalkEnvironmentEnvironmentLink_Contents"></a>

 ** EnvironmentName **   <a name="securityhub-Type-AwsElasticBeanstalkEnvironmentEnvironmentLink-EnvironmentName"></a>
The name of the linked environment.
Type: String
Pattern: `.*\S.*`
Required: No

 ** LinkName **   <a name="securityhub-Type-AwsElasticBeanstalkEnvironmentEnvironmentLink-LinkName"></a>
The name of the environment link.
Type: String
Pattern: `.*\S.*`
Required: No
