# AwsEc2LaunchTemplateDataCapacityReservationSpecificationCapacityReservationTargetDetails
<a name="API_AwsEc2LaunchTemplateDataCapacityReservationSpecificationCapacityReservationTargetDetails"></a>

 Information about the target Capacity Reservation or Capacity Reservation group in which to run an Amazon EC2 instance.

## Contents
<a name="API_AwsEc2LaunchTemplateDataCapacityReservationSpecificationCapacityReservationTargetDetails_Contents"></a>

 ** CapacityReservationId **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataCapacityReservationSpecificationCapacityReservationTargetDetails-CapacityReservationId"></a>
 The ID of the Capacity Reservation in which to run the instance.
Type: String
Pattern: `.*\S.*`
Required: No

 ** CapacityReservationResourceGroupArn **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataCapacityReservationSpecificationCapacityReservationTargetDetails-CapacityReservationResourceGroupArn"></a>
 The Amazon Resource Name (ARN) of the Capacity Reservation resource group in which to run the instance.
Type: String
Pattern: `.*\S.*`
Required: No
