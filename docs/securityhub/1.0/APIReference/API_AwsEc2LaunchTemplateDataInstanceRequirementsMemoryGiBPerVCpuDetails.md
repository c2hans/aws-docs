# AwsEc2LaunchTemplateDataInstanceRequirementsMemoryGiBPerVCpuDetails
<a name="API_AwsEc2LaunchTemplateDataInstanceRequirementsMemoryGiBPerVCpuDetails"></a>

 The minimum and maximum amount of memory per vCPU, in GiB.

<a name="API_AwsEc2LaunchTemplateDataInstanceRequirementsMemoryGiBPerVCpuDetails_Contents"></a>

 ** Max **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataInstanceRequirementsMemoryGiBPerVCpuDetails-Max"></a>
 The maximum amount of memory per vCPU, in GiB. If this parameter is omitted, there's no maximum limit.
Type: Double
Required: No

 ** Min **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataInstanceRequirementsMemoryGiBPerVCpuDetails-Min"></a>
 The minimum amount of memory per vCPU, in GiB. If this parameter is omitted, there's no maximum limit.
Type: Double
Required: No
