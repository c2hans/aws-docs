# AwsCloudFrontDistributionOriginGroups
<a name="API_AwsCloudFrontDistributionOriginGroups"></a>

Provides information about origin groups that are associated with the CloudFront distribution.

## Contents
<a name="API_AwsCloudFrontDistributionOriginGroups_Contents"></a>

 ** Items **   <a name="securityhub-Type-AwsCloudFrontDistributionOriginGroups-Items"></a>
The list of origin groups.
Type: Array of [AwsCloudFrontDistributionOriginGroup](API_AwsCloudFrontDistributionOriginGroup.md) objects
Required: No
