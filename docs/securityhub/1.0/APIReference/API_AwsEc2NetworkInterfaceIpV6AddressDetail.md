# AwsEc2NetworkInterfaceIpV6AddressDetail
<a name="API_AwsEc2NetworkInterfaceIpV6AddressDetail"></a>

Provides information about an IPV6 address that is associated with the network interface.

## Contents
<a name="API_AwsEc2NetworkInterfaceIpV6AddressDetail_Contents"></a>

 ** IpV6Address **   <a name="securityhub-Type-AwsEc2NetworkInterfaceIpV6AddressDetail-IpV6Address"></a>
The IPV6 address.
Type: String
Pattern: `.*\S.*`
Required: No
