# AwsEc2LaunchTemplateDataEnclaveOptionsDetails
<a name="API_AwsEc2LaunchTemplateDataEnclaveOptionsDetails"></a>

 Indicates whether the instance is enabled for AWS Nitro Enclaves.

## Contents
<a name="API_AwsEc2LaunchTemplateDataEnclaveOptionsDetails_Contents"></a>

 ** Enabled **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataEnclaveOptionsDetails-Enabled"></a>
 If this parameter is set to `true`, the instance is enabled for AWS Nitro Enclaves.
Type: Boolean
Required: No
