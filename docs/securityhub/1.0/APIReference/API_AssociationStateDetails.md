# AssociationStateDetails
<a name="API_AssociationStateDetails"></a>

 Describes the state of an association between a route table and a subnet or gateway.

## Contents
<a name="API_AssociationStateDetails_Contents"></a>

 ** State **   <a name="securityhub-Type-AssociationStateDetails-State"></a>
 The state of the association.
Type: String
Pattern: `.*\S.*`
Required: No

 ** StatusMessage **   <a name="securityhub-Type-AssociationStateDetails-StatusMessage"></a>
 The status message, if applicable.
Type: String
Pattern: `.*\S.*`
Required: No
