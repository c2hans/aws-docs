# AwsGuardDutyDetectorDataSourcesCloudTrailDetails
<a name="API_AwsGuardDutyDetectorDataSourcesCloudTrailDetails"></a>

 An object that contains information on the status of AWS CloudTrail as a data source for the detector.

## Contents
<a name="API_AwsGuardDutyDetectorDataSourcesCloudTrailDetails_Contents"></a>

 ** Status **   <a name="securityhub-Type-AwsGuardDutyDetectorDataSourcesCloudTrailDetails-Status"></a>
 Specifies whether CloudTrail is activated as a data source for the detector.
Type: String
Pattern: `.*\S.*`
Required: No
