# ActionLocalIpDetails
<a name="API_ActionLocalIpDetails"></a>

Provides information about the IP address where the scanned port is located.

## Contents
<a name="API_ActionLocalIpDetails_Contents"></a>

 ** IpAddressV4 **   <a name="securityhub-Type-ActionLocalIpDetails-IpAddressV4"></a>
The IP address.
Type: String
Pattern: `.*\S.*`
Required: No
