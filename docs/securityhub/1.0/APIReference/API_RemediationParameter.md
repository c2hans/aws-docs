# RemediationParameter
<a name="API_RemediationParameter"></a>

A parameter used in running the guidance steps.

## Contents
<a name="API_RemediationParameter_Contents"></a>

 ** Description **   <a name="securityhub-Type-RemediationParameter-Description"></a>
A description of the parameter.
Type: String
Pattern: `.*\S.*`
Required: Yes

 ** Name **   <a name="securityhub-Type-RemediationParameter-Name"></a>
The name of the parameter.
Type: String
Pattern: `.*\S.*`
Required: Yes

 ** Type **   <a name="securityhub-Type-RemediationParameter-Type"></a>
The type of the parameter.
Type: String
Pattern: `.*\S.*`
Required: Yes

 ** Required **   <a name="securityhub-Type-RemediationParameter-Required"></a>
Specifies whether the parameter is required for running the guidance steps.
Type: Boolean
Required: No
