# AutomationRulesResourceFieldsUpdateV2
<a name="API_AutomationRulesResourceFieldsUpdateV2"></a>

Allows you to define the structure for modifying specific fields of resources.

## Contents
<a name="API_AutomationRulesResourceFieldsUpdateV2_Contents"></a>

 ** Criticality **   <a name="securityhub-Type-AutomationRulesResourceFieldsUpdateV2-Criticality"></a>
The criticality level to be assigned to resources that match the automation rule criteria.
Type: String
Valid Values: `Very High | High | Medium | Low | Unknown`
Required: Yes
