# AwsRoute53QueryLoggingConfigDetails
<a name="API_AwsRoute53QueryLoggingConfigDetails"></a>

 Provides details about a specified Amazon Route 53 configuration for DNS query logging.

## Contents
<a name="API_AwsRoute53QueryLoggingConfigDetails_Contents"></a>

 ** CloudWatchLogsLogGroupArn **   <a name="securityhub-Type-AwsRoute53QueryLoggingConfigDetails-CloudWatchLogsLogGroupArn"></a>
 The Amazon Resource Name (ARN) of the Amazon CloudWatch Logs log group that Route 53 is publishing logs to.
Type: [CloudWatchLogsLogGroupArnConfigDetails](API_CloudWatchLogsLogGroupArnConfigDetails.md) object
Required: No
