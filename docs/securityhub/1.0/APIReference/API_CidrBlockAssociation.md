# CidrBlockAssociation
<a name="API_CidrBlockAssociation"></a>

An IPv4 CIDR block association.

## Contents
<a name="API_CidrBlockAssociation_Contents"></a>

 ** AssociationId **   <a name="securityhub-Type-CidrBlockAssociation-AssociationId"></a>
The association ID for the IPv4 CIDR block.
Type: String
Pattern: `.*\S.*`
Required: No

 ** CidrBlock **   <a name="securityhub-Type-CidrBlockAssociation-CidrBlock"></a>
The IPv4 CIDR block.
Type: String
Pattern: `.*\S.*`
Required: No

 ** CidrBlockState **   <a name="securityhub-Type-CidrBlockAssociation-CidrBlockState"></a>
Information about the state of the IPv4 CIDR block.
Type: String
Pattern: `.*\S.*`
Required: No
