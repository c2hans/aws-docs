# AwsLambdaFunctionLayer
<a name="API_AwsLambdaFunctionLayer"></a>

An AWS Lambda layer.

## Contents
<a name="API_AwsLambdaFunctionLayer_Contents"></a>

 ** Arn **   <a name="securityhub-Type-AwsLambdaFunctionLayer-Arn"></a>
The ARN of the function layer.
Type: String
Pattern: `.*\S.*`
Required: No

 ** CodeSize **   <a name="securityhub-Type-AwsLambdaFunctionLayer-CodeSize"></a>
The size of the layer archive in bytes.
Type: Integer
Required: No
