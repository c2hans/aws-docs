# RelatedFinding
<a name="API_RelatedFinding"></a>

Details about a related finding.

## Contents
<a name="API_RelatedFinding_Contents"></a>

 ** Id **   <a name="securityhub-Type-RelatedFinding-Id"></a>
The product-generated identifier for a related finding.
Type: String
Pattern: `.*\S.*`
Required: Yes

 ** ProductArn **   <a name="securityhub-Type-RelatedFinding-ProductArn"></a>
The ARN of the product that generated a related finding.
Type: String
Pattern: `.*\S.*`
Required: Yes
