# AwsSecurityFindingIdentifier
<a name="API_AwsSecurityFindingIdentifier"></a>

Identifies which finding to get the finding history for.

## Contents
<a name="API_AwsSecurityFindingIdentifier_Contents"></a>

 ** Id **   <a name="securityhub-Type-AwsSecurityFindingIdentifier-Id"></a>
The identifier of the finding that was specified by the finding provider.
Type: String
Pattern: `.*\S.*`
Required: Yes

 ** ProductArn **   <a name="securityhub-Type-AwsSecurityFindingIdentifier-ProductArn"></a>
The ARN generated by Security Hub CSPM that uniquely identifies a product that generates findings. This can be the ARN for a third-party product that is integrated with Security Hub CSPM, or the ARN for a custom integration.
Type: String
Pattern: `.*\S.*`
Required: Yes
