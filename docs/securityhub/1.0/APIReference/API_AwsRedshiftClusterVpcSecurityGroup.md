# AwsRedshiftClusterVpcSecurityGroup
<a name="API_AwsRedshiftClusterVpcSecurityGroup"></a>

A VPC security group that the cluster belongs to, if the cluster is in a VPC.

## Contents
<a name="API_AwsRedshiftClusterVpcSecurityGroup_Contents"></a>

 ** Status **   <a name="securityhub-Type-AwsRedshiftClusterVpcSecurityGroup-Status"></a>
The status of the VPC security group.
Type: String
Pattern: `.*\S.*`
Required: No

 ** VpcSecurityGroupId **   <a name="securityhub-Type-AwsRedshiftClusterVpcSecurityGroup-VpcSecurityGroupId"></a>
The identifier of the VPC security group.
Type: String
Pattern: `.*\S.*`
Required: No
