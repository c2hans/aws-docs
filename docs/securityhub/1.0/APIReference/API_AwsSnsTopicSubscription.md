# AwsSnsTopicSubscription
<a name="API_AwsSnsTopicSubscription"></a>

A wrapper type for the attributes of an Amazon SNS subscription.

## Contents
<a name="API_AwsSnsTopicSubscription_Contents"></a>

 ** Endpoint **   <a name="securityhub-Type-AwsSnsTopicSubscription-Endpoint"></a>
The subscription's endpoint (format depends on the protocol).
Type: String
Pattern: `.*\S.*`
Required: No

 ** Protocol **   <a name="securityhub-Type-AwsSnsTopicSubscription-Protocol"></a>
The subscription's protocol.
Type: String
Pattern: `.*\S.*`
Required: No
