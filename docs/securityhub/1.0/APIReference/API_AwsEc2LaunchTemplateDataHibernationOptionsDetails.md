# AwsEc2LaunchTemplateDataHibernationOptionsDetails
<a name="API_AwsEc2LaunchTemplateDataHibernationOptionsDetails"></a>

 Specifies whether your Amazon EC2 instance is configured for hibernation.

## Contents
<a name="API_AwsEc2LaunchTemplateDataHibernationOptionsDetails_Contents"></a>

 ** Configured **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataHibernationOptionsDetails-Configured"></a>
 If you set this parameter to `true`, the instance is enabled for hibernation.
Type: Boolean
Required: No
