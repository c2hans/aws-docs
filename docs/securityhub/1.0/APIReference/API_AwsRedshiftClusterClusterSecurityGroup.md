# AwsRedshiftClusterClusterSecurityGroup
<a name="API_AwsRedshiftClusterClusterSecurityGroup"></a>

A security group that is associated with the cluster.

## Contents
<a name="API_AwsRedshiftClusterClusterSecurityGroup_Contents"></a>

 ** ClusterSecurityGroupName **   <a name="securityhub-Type-AwsRedshiftClusterClusterSecurityGroup-ClusterSecurityGroupName"></a>
The name of the cluster security group.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Status **   <a name="securityhub-Type-AwsRedshiftClusterClusterSecurityGroup-Status"></a>
The status of the cluster security group.
Type: String
Pattern: `.*\S.*`
Required: No
