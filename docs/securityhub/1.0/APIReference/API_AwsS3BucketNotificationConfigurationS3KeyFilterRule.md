# AwsS3BucketNotificationConfigurationS3KeyFilterRule
<a name="API_AwsS3BucketNotificationConfigurationS3KeyFilterRule"></a>

Details for a filter rule.

## Contents
<a name="API_AwsS3BucketNotificationConfigurationS3KeyFilterRule_Contents"></a>

 ** Name **   <a name="securityhub-Type-AwsS3BucketNotificationConfigurationS3KeyFilterRule-Name"></a>
Indicates whether the filter is based on the prefix or suffix of the Amazon S3 key.
Type: String
Valid Values: `Prefix | Suffix`
Required: No

 ** Value **   <a name="securityhub-Type-AwsS3BucketNotificationConfigurationS3KeyFilterRule-Value"></a>
The filter value.
Type: String
Pattern: `.*\S.*`
Required: No
