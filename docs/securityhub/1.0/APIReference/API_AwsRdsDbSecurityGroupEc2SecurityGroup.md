# AwsRdsDbSecurityGroupEc2SecurityGroup
<a name="API_AwsRdsDbSecurityGroupEc2SecurityGroup"></a>

EC2 security group information for an RDS DB security group.

## Contents
<a name="API_AwsRdsDbSecurityGroupEc2SecurityGroup_Contents"></a>

 ** Ec2SecurityGroupId **   <a name="securityhub-Type-AwsRdsDbSecurityGroupEc2SecurityGroup-Ec2SecurityGroupId"></a>
Specifies the ID for the EC2 security group.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Ec2SecurityGroupName **   <a name="securityhub-Type-AwsRdsDbSecurityGroupEc2SecurityGroup-Ec2SecurityGroupName"></a>
Specifies the name of the EC2 security group.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Ec2SecurityGroupOwnerId **   <a name="securityhub-Type-AwsRdsDbSecurityGroupEc2SecurityGroup-Ec2SecurityGroupOwnerId"></a>
Provides the AWS ID of the owner of the EC2 security group.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Status **   <a name="securityhub-Type-AwsRdsDbSecurityGroupEc2SecurityGroup-Status"></a>
Provides the status of the EC2 security group.
Type: String
Pattern: `.*\S.*`
Required: No
