# RecommendationError
<a name="API_RecommendationError"></a>

Contains information about the reason that the retrieval of a recommended policy for a finding failed.

## Contents
<a name="API_RecommendationError_Contents"></a>

 ** Code **   <a name="securityhub-Type-RecommendationError-Code"></a>
The error code for a failed retrieval of a recommended policy for a finding.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Message **   <a name="securityhub-Type-RecommendationError-Message"></a>
The error message for a failed retrieval of a recommended policy for a finding.
Type: String
Pattern: `.*\S.*`
Required: No
