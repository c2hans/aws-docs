# AwsOpenSearchServiceDomainLogPublishingOption
<a name="API_AwsOpenSearchServiceDomainLogPublishingOption"></a>

Configuration details for a log publishing option.

## Contents
<a name="API_AwsOpenSearchServiceDomainLogPublishingOption_Contents"></a>

 ** CloudWatchLogsLogGroupArn **   <a name="securityhub-Type-AwsOpenSearchServiceDomainLogPublishingOption-CloudWatchLogsLogGroupArn"></a>
The ARN of the CloudWatch Logs group to publish the logs to.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Enabled **   <a name="securityhub-Type-AwsOpenSearchServiceDomainLogPublishingOption-Enabled"></a>
Whether the log publishing is enabled.
Type: Boolean
Required: No
