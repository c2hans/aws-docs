# AwsElbLoadBalancerConnectionSettings
<a name="API_AwsElbLoadBalancerConnectionSettings"></a>

Contains connection settings for the load balancer.

## Contents
<a name="API_AwsElbLoadBalancerConnectionSettings_Contents"></a>

 ** IdleTimeout **   <a name="securityhub-Type-AwsElbLoadBalancerConnectionSettings-IdleTimeout"></a>
The time, in seconds, that the connection can be idle (no data is sent over the connection) before it is closed by the load balancer.
Type: Integer
Required: No
