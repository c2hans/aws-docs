# AwsRoute53HostedZoneConfigDetails
<a name="API_AwsRoute53HostedZoneConfigDetails"></a>

 An object that contains an optional comment about your Amazon Route 53 hosted zone.

## Contents
<a name="API_AwsRoute53HostedZoneConfigDetails_Contents"></a>

 ** Comment **   <a name="securityhub-Type-AwsRoute53HostedZoneConfigDetails-Comment"></a>
 Any comments that you include about the hosted zone.
Type: String
Pattern: `.*\S.*`
Required: No
