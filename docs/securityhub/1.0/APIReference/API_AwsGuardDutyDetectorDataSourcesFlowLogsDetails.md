# AwsGuardDutyDetectorDataSourcesFlowLogsDetails
<a name="API_AwsGuardDutyDetectorDataSourcesFlowLogsDetails"></a>

 An object that contains information on the status of VPC Flow Logs as a data source for the detector.

## Contents
<a name="API_AwsGuardDutyDetectorDataSourcesFlowLogsDetails_Contents"></a>

 ** Status **   <a name="securityhub-Type-AwsGuardDutyDetectorDataSourcesFlowLogsDetails-Status"></a>
 Describes whether VPC Flow Logs are activated as a data source for the detector.
Type: String
Pattern: `.*\S.*`
Required: No
