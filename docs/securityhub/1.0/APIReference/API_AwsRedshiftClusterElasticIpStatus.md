# AwsRedshiftClusterElasticIpStatus
<a name="API_AwsRedshiftClusterElasticIpStatus"></a>

The status of the elastic IP (EIP) address for an Amazon Redshift cluster.

## Contents
<a name="API_AwsRedshiftClusterElasticIpStatus_Contents"></a>

 ** ElasticIp **   <a name="securityhub-Type-AwsRedshiftClusterElasticIpStatus-ElasticIp"></a>
The elastic IP address for the cluster.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Status **   <a name="securityhub-Type-AwsRedshiftClusterElasticIpStatus-Status"></a>
The status of the elastic IP address.
Type: String
Pattern: `.*\S.*`
Required: No
