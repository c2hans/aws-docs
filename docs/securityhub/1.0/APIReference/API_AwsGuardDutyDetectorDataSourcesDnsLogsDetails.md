# AwsGuardDutyDetectorDataSourcesDnsLogsDetails
<a name="API_AwsGuardDutyDetectorDataSourcesDnsLogsDetails"></a>

 An object that contains information on the status of DNS logs as a data source for the detector.

## Contents
<a name="API_AwsGuardDutyDetectorDataSourcesDnsLogsDetails_Contents"></a>

 ** Status **   <a name="securityhub-Type-AwsGuardDutyDetectorDataSourcesDnsLogsDetails-Status"></a>
 Describes whether DNS logs is enabled as a data source for the detector.
Type: String
Pattern: `.*\S.*`
Required: No
