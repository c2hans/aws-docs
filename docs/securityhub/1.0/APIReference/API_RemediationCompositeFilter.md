# RemediationCompositeFilter
<a name="API_RemediationCompositeFilter"></a>

Enables the creation of criteria for remediation targets.

## Contents
<a name="API_RemediationCompositeFilter_Contents"></a>

 ** StringFilters **   <a name="securityhub-Type-RemediationCompositeFilter-StringFilters"></a>
Enables filtering based on string field values.
Type: Array of [RemediationStringFilter](API_RemediationStringFilter.md) objects
Array Members: Minimum number of 0 items. Maximum number of 2 items.
Required: No
