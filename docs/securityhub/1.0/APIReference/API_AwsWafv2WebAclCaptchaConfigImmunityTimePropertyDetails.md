# AwsWafv2WebAclCaptchaConfigImmunityTimePropertyDetails
<a name="API_AwsWafv2WebAclCaptchaConfigImmunityTimePropertyDetails"></a>

 Used for CAPTCHA and challenge token settings. Determines how long a CAPTCHA or challenge timestamp remains valid after AWS WAF updates it for a successful CAPTCHA or challenge response.

## Contents
<a name="API_AwsWafv2WebAclCaptchaConfigImmunityTimePropertyDetails_Contents"></a>

 ** ImmunityTime **   <a name="securityhub-Type-AwsWafv2WebAclCaptchaConfigImmunityTimePropertyDetails-ImmunityTime"></a>
 The amount of time, in seconds, that a CAPTCHA or challenge timestamp is considered valid by AWS WAF.
Type: Long
Required: No
