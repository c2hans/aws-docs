# StandardsStatusReason
<a name="API_StandardsStatusReason"></a>

The reason for the current status of your subscription to the standard.

## Contents
<a name="API_StandardsStatusReason_Contents"></a>

 ** StatusReasonCode **   <a name="securityhub-Type-StandardsStatusReason-StatusReasonCode"></a>
The reason code that represents the reason for the current status of a standard subscription.
Type: String
Valid Values: `NO_AVAILABLE_CONFIGURATION_RECORDER | MAXIMUM_NUMBER_OF_CONFIG_RULES_EXCEEDED | NO_AVAILABLE_MULTICLOUD_CONNECTOR | INTERNAL_ERROR`
Required: Yes
