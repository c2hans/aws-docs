# PortRangeFromTo
<a name="API_PortRangeFromTo"></a>

A range of ports.

<a name="API_PortRangeFromTo_Contents"></a>

 ** From **   <a name="securityhub-Type-PortRangeFromTo-From"></a>
The first port in the port range.
Type: Integer
Required: No

 ** To **   <a name="securityhub-Type-PortRangeFromTo-To"></a>
The last port in the port range.
Type: Integer
Required: No
