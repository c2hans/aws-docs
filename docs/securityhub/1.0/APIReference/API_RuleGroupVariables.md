# RuleGroupVariables
<a name="API_RuleGroupVariables"></a>

Additional settings to use in the specified rules.

## Contents
<a name="API_RuleGroupVariables_Contents"></a>

 ** IpSets **   <a name="securityhub-Type-RuleGroupVariables-IpSets"></a>
A list of IP addresses and address ranges, in CIDR notation.
Type: [RuleGroupVariablesIpSetsDetails](API_RuleGroupVariablesIpSetsDetails.md) object
Required: No

 ** PortSets **   <a name="securityhub-Type-RuleGroupVariables-PortSets"></a>
A list of port ranges.
Type: [RuleGroupVariablesPortSetsDetails](API_RuleGroupVariablesPortSetsDetails.md) object
Required: No
