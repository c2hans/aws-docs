# WafExcludedRule
<a name="API_WafExcludedRule"></a>

Details about a rule to exclude from a rule group.

## Contents
<a name="API_WafExcludedRule_Contents"></a>

 ** RuleId **   <a name="securityhub-Type-WafExcludedRule-RuleId"></a>
The unique identifier for the rule to exclude from the rule group.
Type: String
Pattern: `.*\S.*`
Required: No
