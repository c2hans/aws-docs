# RemediationStringFilterCondition
<a name="API_RemediationStringFilterCondition"></a>

The condition to apply to the string filter.

## Contents
<a name="API_RemediationStringFilterCondition_Contents"></a>

 ** Value **   <a name="securityhub-Type-RemediationStringFilterCondition-Value"></a>
The value the string filter is comparing against.
Type: String
Pattern: `.*\S.*`
Required: Yes
