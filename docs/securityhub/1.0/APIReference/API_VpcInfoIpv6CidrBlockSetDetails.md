# VpcInfoIpv6CidrBlockSetDetails
<a name="API_VpcInfoIpv6CidrBlockSetDetails"></a>

Provides details about the IPv6 CIDR blocks for the VPC.

## Contents
<a name="API_VpcInfoIpv6CidrBlockSetDetails_Contents"></a>

 ** Ipv6CidrBlock **   <a name="securityhub-Type-VpcInfoIpv6CidrBlockSetDetails-Ipv6CidrBlock"></a>
The IPv6 CIDR block for the VPC.
Type: String
Pattern: `.*\S.*`
Required: No
