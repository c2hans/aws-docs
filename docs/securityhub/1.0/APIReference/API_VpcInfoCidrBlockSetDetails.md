# VpcInfoCidrBlockSetDetails
<a name="API_VpcInfoCidrBlockSetDetails"></a>

Provides details about the IPv4 CIDR blocks for the VPC.

## Contents
<a name="API_VpcInfoCidrBlockSetDetails_Contents"></a>

 ** CidrBlock **   <a name="securityhub-Type-VpcInfoCidrBlockSetDetails-CidrBlock"></a>
The IPv4 CIDR block for the VPC.
Type: String
Pattern: `.*\S.*`
Required: No
