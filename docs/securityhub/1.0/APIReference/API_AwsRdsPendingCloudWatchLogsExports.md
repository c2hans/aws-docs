# AwsRdsPendingCloudWatchLogsExports
<a name="API_AwsRdsPendingCloudWatchLogsExports"></a>

Identifies the log types to enable and disable.

## Contents
<a name="API_AwsRdsPendingCloudWatchLogsExports_Contents"></a>

 ** LogTypesToDisable **   <a name="securityhub-Type-AwsRdsPendingCloudWatchLogsExports-LogTypesToDisable"></a>
A list of log types that are being disabled.
Type: Array of strings
Pattern: `.*\S.*`
Required: No

 ** LogTypesToEnable **   <a name="securityhub-Type-AwsRdsPendingCloudWatchLogsExports-LogTypesToEnable"></a>
A list of log types that are being enabled.
Type: Array of strings
Pattern: `.*\S.*`
Required: No
