# AwsEc2VpnConnectionOptionsDetails
<a name="API_AwsEc2VpnConnectionOptionsDetails"></a>

 ** StaticRoutesOnly **   <a name="securityhub-Type-AwsEc2VpnConnectionOptionsDetails-StaticRoutesOnly"></a>
Whether the VPN connection uses static routes only.
Type: Boolean
Required: No

 ** TunnelOptions **   <a name="securityhub-Type-AwsEc2VpnConnectionOptionsDetails-TunnelOptions"></a>

Type: Array of [AwsEc2VpnConnectionOptionsTunnelOptionsDetails](API_AwsEc2VpnConnectionOptionsTunnelOptionsDetails.md) objects
