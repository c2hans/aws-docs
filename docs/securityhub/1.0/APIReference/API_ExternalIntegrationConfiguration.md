# ExternalIntegrationConfiguration
<a name="API_ExternalIntegrationConfiguration"></a>

Defines the settings and parameters required for integrating external security tools and services.

## Contents
<a name="API_ExternalIntegrationConfiguration_Contents"></a>

 ** ConnectorArn **   <a name="securityhub-Type-ExternalIntegrationConfiguration-ConnectorArn"></a>
The ARN of the connector that establishes the integration.
Type: String
Pattern: `.*\S.*`
Required: No
