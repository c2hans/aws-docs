# AwsIamAttachedManagedPolicy
<a name="API_AwsIamAttachedManagedPolicy"></a>

A managed policy that is attached to an IAM principal.

## Contents
<a name="API_AwsIamAttachedManagedPolicy_Contents"></a>

 ** PolicyArn **   <a name="securityhub-Type-AwsIamAttachedManagedPolicy-PolicyArn"></a>
The ARN of the policy.
Type: String
Pattern: `.*\S.*`
Required: No

 ** PolicyName **   <a name="securityhub-Type-AwsIamAttachedManagedPolicy-PolicyName"></a>
The name of the policy.
Type: String
Pattern: `.*\S.*`
Required: No
