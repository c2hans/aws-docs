# AwsRdsDbProcessorFeature
<a name="API_AwsRdsDbProcessorFeature"></a>

A processor feature.

## Contents
<a name="API_AwsRdsDbProcessorFeature_Contents"></a>

 ** Name **   <a name="securityhub-Type-AwsRdsDbProcessorFeature-Name"></a>
The name of the processor feature. Valid values are `coreCount` or `threadsPerCore`.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Value **   <a name="securityhub-Type-AwsRdsDbProcessorFeature-Value"></a>
The value of the processor feature.
Type: String
Pattern: `.*\S.*`
Required: No
