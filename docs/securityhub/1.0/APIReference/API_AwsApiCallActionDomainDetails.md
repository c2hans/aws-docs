# AwsApiCallActionDomainDetails
<a name="API_AwsApiCallActionDomainDetails"></a>

Provided if `CallerType` is `domain`. It provides information about the DNS domain that issued the API call.

## Contents
<a name="API_AwsApiCallActionDomainDetails_Contents"></a>

 ** Domain **   <a name="securityhub-Type-AwsApiCallActionDomainDetails-Domain"></a>
The name of the DNS domain that issued the API call.
Length Constraints: 128.
Type: String
Pattern: `.*\S.*`
Required: No
