# AwsEc2InstanceMonitoringDetails
<a name="API_AwsEc2InstanceMonitoringDetails"></a>

 The type of monitoring that’s turned on for an Amazon EC2 instance.

## Contents
<a name="API_AwsEc2InstanceMonitoringDetails_Contents"></a>

 ** State **   <a name="securityhub-Type-AwsEc2InstanceMonitoringDetails-State"></a>
 Indicates whether detailed monitoring is turned on. Otherwise, basic monitoring is turned on.
Type: String
Pattern: `.*\S.*`
Required: No
