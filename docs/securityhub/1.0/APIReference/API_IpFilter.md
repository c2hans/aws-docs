# IpFilter
<a name="API_IpFilter"></a>

The IP filter for querying findings.

## Contents
<a name="API_IpFilter_Contents"></a>

 ** Cidr **   <a name="securityhub-Type-IpFilter-Cidr"></a>
A finding's CIDR value.
Type: String
Pattern: `.*\S.*`
Required: No
