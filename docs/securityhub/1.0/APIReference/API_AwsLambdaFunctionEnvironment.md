# AwsLambdaFunctionEnvironment
<a name="API_AwsLambdaFunctionEnvironment"></a>

A function's environment variable settings.

## Contents
<a name="API_AwsLambdaFunctionEnvironment_Contents"></a>

 ** Error **   <a name="securityhub-Type-AwsLambdaFunctionEnvironment-Error"></a>
An `AwsLambdaFunctionEnvironmentError` object.
Type: [AwsLambdaFunctionEnvironmentError](API_AwsLambdaFunctionEnvironmentError.md) object
Required: No

 ** Variables **   <a name="securityhub-Type-AwsLambdaFunctionEnvironment-Variables"></a>
Environment variable key-value pairs.
Type: String to string map
Key Pattern: `.*\S.*`
Value Pattern: `.*\S.*`
Required: No
