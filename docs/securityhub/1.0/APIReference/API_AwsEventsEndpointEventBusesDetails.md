# AwsEventsEndpointEventBusesDetails
<a name="API_AwsEventsEndpointEventBusesDetails"></a>

 Provides details about the Amazon EventBridge event buses that the endpoint is associated with.

## Contents
<a name="API_AwsEventsEndpointEventBusesDetails_Contents"></a>

 ** EventBusArn **   <a name="securityhub-Type-AwsEventsEndpointEventBusesDetails-EventBusArn"></a>
 The Amazon Resource Name (ARN) of the event bus that the endpoint is associated with.
Type: String
Pattern: `.*\S.*`
Required: No
