# AwsEc2LaunchTemplateDataNetworkInterfaceSetIpv6AddressesDetails
<a name="API_AwsEc2LaunchTemplateDataNetworkInterfaceSetIpv6AddressesDetails"></a>

 Specifies an IPv6 address in an Amazon EC2 launch template.

## Contents
<a name="API_AwsEc2LaunchTemplateDataNetworkInterfaceSetIpv6AddressesDetails_Contents"></a>

 ** Ipv6Address **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataNetworkInterfaceSetIpv6AddressesDetails-Ipv6Address"></a>
 One or more specific IPv6 addresses from the IPv6 CIDR block range of your subnet.
Type: String
Pattern: `.*\S.*`
Required: No
