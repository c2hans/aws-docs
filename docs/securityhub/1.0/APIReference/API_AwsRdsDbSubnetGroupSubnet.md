# AwsRdsDbSubnetGroupSubnet
<a name="API_AwsRdsDbSubnetGroupSubnet"></a>

Information about a subnet in a subnet group.

<a name="API_AwsRdsDbSubnetGroupSubnet_Contents"></a>

 ** SubnetAvailabilityZone **   <a name="securityhub-Type-AwsRdsDbSubnetGroupSubnet-SubnetAvailabilityZone"></a>
Information about the Availability Zone for a subnet in the subnet group.
Type: [AwsRdsDbSubnetGroupSubnetAvailabilityZone](API_AwsRdsDbSubnetGroupSubnetAvailabilityZone.md) object
Required: No

 ** SubnetIdentifier **   <a name="securityhub-Type-AwsRdsDbSubnetGroupSubnet-SubnetIdentifier"></a>
The identifier of a subnet in the subnet group.
Type: String
Pattern: `.*\S.*`
Required: No

 ** SubnetStatus **   <a name="securityhub-Type-AwsRdsDbSubnetGroupSubnet-SubnetStatus"></a>

Pattern: `.*\S.*`
Required: No
