# StatelessCustomPublishMetricActionDimension
<a name="API_StatelessCustomPublishMetricActionDimension"></a>

Defines a CloudWatch dimension value to publish.

## Contents
<a name="API_StatelessCustomPublishMetricActionDimension_Contents"></a>

 ** Value **   <a name="securityhub-Type-StatelessCustomPublishMetricActionDimension-Value"></a>
The value to use for the custom metric dimension.
Type: String
Pattern: `.*\S.*`
Required: No
