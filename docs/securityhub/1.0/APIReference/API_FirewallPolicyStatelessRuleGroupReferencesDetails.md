# FirewallPolicyStatelessRuleGroupReferencesDetails
<a name="API_FirewallPolicyStatelessRuleGroupReferencesDetails"></a>

A stateless rule group that is used by the firewall policy.

## Contents
<a name="API_FirewallPolicyStatelessRuleGroupReferencesDetails_Contents"></a>

 ** Priority **   <a name="securityhub-Type-FirewallPolicyStatelessRuleGroupReferencesDetails-Priority"></a>
The order in which to run the stateless rule group.
Type: Integer
Required: No

 ** ResourceArn **   <a name="securityhub-Type-FirewallPolicyStatelessRuleGroupReferencesDetails-ResourceArn"></a>
The ARN of the stateless rule group.
Type: String
Pattern: `.*\S.*`
Required: No
