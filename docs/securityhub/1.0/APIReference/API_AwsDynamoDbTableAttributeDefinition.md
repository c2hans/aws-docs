# AwsDynamoDbTableAttributeDefinition
<a name="API_AwsDynamoDbTableAttributeDefinition"></a>

Contains a definition of an attribute for the table.

## Contents
<a name="API_AwsDynamoDbTableAttributeDefinition_Contents"></a>

 ** AttributeName **   <a name="securityhub-Type-AwsDynamoDbTableAttributeDefinition-AttributeName"></a>
The name of the attribute.
Type: String
Pattern: `.*\S.*`
Required: No

 ** AttributeType **   <a name="securityhub-Type-AwsDynamoDbTableAttributeDefinition-AttributeType"></a>
The type of the attribute.
Type: String
Pattern: `.*\S.*`
Required: No
