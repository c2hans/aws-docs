# AwsElbLoadBalancerConnectionDraining
<a name="API_AwsElbLoadBalancerConnectionDraining"></a>

Contains information about the connection draining configuration for the load balancer.

## Contents
<a name="API_AwsElbLoadBalancerConnectionDraining_Contents"></a>

 ** Enabled **   <a name="securityhub-Type-AwsElbLoadBalancerConnectionDraining-Enabled"></a>
Indicates whether connection draining is enabled for the load balancer.
Type: Boolean
Required: No

 ** Timeout **   <a name="securityhub-Type-AwsElbLoadBalancerConnectionDraining-Timeout"></a>
The maximum time, in seconds, to keep the existing connections open before deregistering the instances.
Type: Integer
Required: No
