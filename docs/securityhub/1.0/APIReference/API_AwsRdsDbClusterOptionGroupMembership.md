# AwsRdsDbClusterOptionGroupMembership
<a name="API_AwsRdsDbClusterOptionGroupMembership"></a>

Information about an option group membership for a DB cluster.

## Contents
<a name="API_AwsRdsDbClusterOptionGroupMembership_Contents"></a>

 ** DbClusterOptionGroupName **   <a name="securityhub-Type-AwsRdsDbClusterOptionGroupMembership-DbClusterOptionGroupName"></a>
The name of the DB cluster option group.
Type: String
Pattern: `.*\S.*`
Required: No

 ** Status **   <a name="securityhub-Type-AwsRdsDbClusterOptionGroupMembership-Status"></a>
The status of the DB cluster option group.
Type: String
Pattern: `.*\S.*`
Required: No
