# RemediationFilters
<a name="API_RemediationFilters"></a>

Contains the criteria used to filter remediation targets, such as resource type, priority, or status.

## Contents
<a name="API_RemediationFilters_Contents"></a>

 ** CompositeFilters **   <a name="securityhub-Type-RemediationFilters-CompositeFilters"></a>
A collection of complex filtering conditions that can be applied to remediation target data.
Type: Array of [RemediationCompositeFilter](API_RemediationCompositeFilter.md) objects
Array Members: Minimum number of 0 items. Maximum number of 1 item.
Required: No
