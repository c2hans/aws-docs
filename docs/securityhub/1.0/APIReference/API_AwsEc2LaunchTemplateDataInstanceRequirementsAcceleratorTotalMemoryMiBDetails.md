# AwsEc2LaunchTemplateDataInstanceRequirementsAcceleratorTotalMemoryMiBDetails
<a name="API_AwsEc2LaunchTemplateDataInstanceRequirementsAcceleratorTotalMemoryMiBDetails"></a>

 The minimum and maximum amount of memory, in MiB, for the accelerators on an Amazon EC2 instance.

## Contents
<a name="API_AwsEc2LaunchTemplateDataInstanceRequirementsAcceleratorTotalMemoryMiBDetails_Contents"></a>

 ** Max **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataInstanceRequirementsAcceleratorTotalMemoryMiBDetails-Max"></a>
 The maximum amount of memory, in MiB. If this parameter isn't specified, there's no maximum limit.
Type: Integer
Required: No

 ** Min **   <a name="securityhub-Type-AwsEc2LaunchTemplateDataInstanceRequirementsAcceleratorTotalMemoryMiBDetails-Min"></a>
 The minimum amount of memory, in MiB. If `0` is specified, there's no maximum limit.
Type: Integer
Required: No
