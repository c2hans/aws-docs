# AwsEc2ClientVpnEndpointAuthenticationOptionsActiveDirectoryDetails
<a name="API_AwsEc2ClientVpnEndpointAuthenticationOptionsActiveDirectoryDetails"></a>

 Provides details about an Active Directory that’s used to authenticate an AWS Client VPN endpoint.

## Contents
<a name="API_AwsEc2ClientVpnEndpointAuthenticationOptionsActiveDirectoryDetails_Contents"></a>

 ** DirectoryId **   <a name="securityhub-Type-AwsEc2ClientVpnEndpointAuthenticationOptionsActiveDirectoryDetails-DirectoryId"></a>
 The ID of the Active Directory used for authentication.
Type: String
Pattern: `.*\S.*`
Required: No
