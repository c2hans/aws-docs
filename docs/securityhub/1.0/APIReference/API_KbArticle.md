# KbArticle
<a name="API_KbArticle"></a>

A knowledge base article that provides additional guidance related to the remediation target.

## Contents
<a name="API_KbArticle_Contents"></a>

 ** Title **   <a name="securityhub-Type-KbArticle-Title"></a>
The title of the `KbArticle`.
Type: String
Pattern: `.*\S.*`
Required: Yes

 ** Url **   <a name="securityhub-Type-KbArticle-Url"></a>
The URL of the `KbArticle`.
Type: String
Pattern: `.*\S.*`
Required: Yes
