# CustomDataIdentifiersResult
<a name="API_CustomDataIdentifiersResult"></a>

Contains an instance of sensitive data that was detected by a customer-defined identifier.

## Contents
<a name="API_CustomDataIdentifiersResult_Contents"></a>

 ** Detections **   <a name="securityhub-Type-CustomDataIdentifiersResult-Detections"></a>
The list of detected instances of sensitive data.
Type: Array of [CustomDataIdentifiersDetections](API_CustomDataIdentifiersDetections.md) objects
Required: No

 ** TotalCount **   <a name="securityhub-Type-CustomDataIdentifiersResult-TotalCount"></a>
The total number of occurrences of sensitive data.
Type: Long
Required: No
