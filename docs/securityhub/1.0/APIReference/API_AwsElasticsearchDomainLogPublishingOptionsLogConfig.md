# AwsElasticsearchDomainLogPublishingOptionsLogConfig
<a name="API_AwsElasticsearchDomainLogPublishingOptionsLogConfig"></a>

 ** CloudWatchLogsLogGroupArn **   <a name="securityhub-Type-AwsElasticsearchDomainLogPublishingOptionsLogConfig-CloudWatchLogsLogGroupArn"></a>

Pattern: `.*\S.*`
Required: No
