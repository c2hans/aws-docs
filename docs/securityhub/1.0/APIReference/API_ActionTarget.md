# ActionTarget

An `ActionTarget` object.

## Contents
<a name="API_ActionTarget_Contents"></a>

Type: String
Pattern: `.*\S.*`
Required: Yes

 ** Description **   <a name="securityhub-Type-ActionTarget-Description"></a>

Type: String
Pattern: `.*\S.*`
Required: Yes

 ** Name **   <a name="securityhub-Type-ActionTarget-Name"></a>
The name of the action target.
Type: String
Pattern: `.*\S.*`
Required: Yes
