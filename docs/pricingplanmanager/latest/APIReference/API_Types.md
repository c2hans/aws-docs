# Data Types
<a name="API_Types"></a>

The PricingPlanManager API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [ScheduledChange](API_ScheduledChange.md)
+  [Subscription](API_Subscription.md)
+  [SubscriptionSummary](API_SubscriptionSummary.md)
