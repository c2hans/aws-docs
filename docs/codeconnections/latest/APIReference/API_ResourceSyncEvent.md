# ResourceSyncEvent
<a name="API_ResourceSyncEvent"></a>

Information about a resource sync event for the resource associated with a sync configuration.

## Contents
<a name="API_ResourceSyncEvent_Contents"></a>

 ** Event **   <a name="codeconnections-Type-ResourceSyncEvent-Event"></a>
The event for a resource sync event.
Type: String
Required: Yes

 ** Time **   <a name="codeconnections-Type-ResourceSyncEvent-Time"></a>
The time that a resource sync event occurred.
Type: Timestamp
Required: Yes

 ** Type **   <a name="codeconnections-Type-ResourceSyncEvent-Type"></a>
The type of resource sync event.
Type: String
Required: Yes

 ** ExternalId **   <a name="codeconnections-Type-ResourceSyncEvent-ExternalId"></a>
The ID for a resource sync event.
Type: String
Required: No
