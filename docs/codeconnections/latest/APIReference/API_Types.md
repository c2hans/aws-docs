# Data Types
<a name="API_Types"></a>

The AWS CodeConnections API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Connection](API_Connection.md)
+  [Host](API_Host.md)
+  [RepositoryLinkInfo](API_RepositoryLinkInfo.md)
+  [RepositorySyncAttempt](API_RepositorySyncAttempt.md)
+  [RepositorySyncDefinition](API_RepositorySyncDefinition.md)
+  [RepositorySyncEvent](API_RepositorySyncEvent.md)
+  [ResourceSyncAttempt](API_ResourceSyncAttempt.md)
+  [ResourceSyncEvent](API_ResourceSyncEvent.md)
+  [Revision](API_Revision.md)
+  [SyncBlocker](API_SyncBlocker.md)
+  [SyncBlockerContext](API_SyncBlockerContext.md)
+  [SyncBlockerSummary](API_SyncBlockerSummary.md)
+  [SyncConfiguration](API_SyncConfiguration.md)
+  [Tag](API_Tag.md)
+  [VpcConfiguration](API_VpcConfiguration.md)
