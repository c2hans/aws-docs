# RepositorySyncEvent
<a name="API_RepositorySyncEvent"></a>

Information about a repository sync event.

## Contents
<a name="API_RepositorySyncEvent_Contents"></a>

 ** Event **   <a name="codeconnections-Type-RepositorySyncEvent-Event"></a>
A description of a repository sync event.
Type: String
Required: Yes

 ** Time **   <a name="codeconnections-Type-RepositorySyncEvent-Time"></a>
The time that a repository sync event occurred.
Type: Timestamp
Required: Yes

 ** Type **   <a name="codeconnections-Type-RepositorySyncEvent-Type"></a>
The event type for a repository sync event.
Type: String
Required: Yes

 ** ExternalId **   <a name="codeconnections-Type-RepositorySyncEvent-ExternalId"></a>
The ID for a repository sync event.
Type: String
Required: No
