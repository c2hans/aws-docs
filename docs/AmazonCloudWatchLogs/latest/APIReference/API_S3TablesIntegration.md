# S3TablesIntegration
<a name="API_S3TablesIntegration"></a>

Contains information about the S3 Tables integration configuration for a configuration template.

## Contents
<a name="API_S3TablesIntegration_Contents"></a>

 ** datasourceName **   <a name="CWL-Type-S3TablesIntegration-datasourceName"></a>
The name of the S3 Tables datasource.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No

 ** datasourceType **   <a name="CWL-Type-S3TablesIntegration-datasourceType"></a>
The type of the S3 Tables datasource.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
