# Data Types
<a name="API_Types"></a>

The AWS Application Discovery Service API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AgentConfigurationStatus](API_AgentConfigurationStatus.md)
+  [AgentInfo](API_AgentInfo.md)
+  [AgentNetworkInfo](API_AgentNetworkInfo.md)
+  [BatchDeleteAgentError](API_BatchDeleteAgentError.md)
+  [BatchDeleteConfigurationTask](API_BatchDeleteConfigurationTask.md)
+  [BatchDeleteImportDataError](API_BatchDeleteImportDataError.md)
+  [ConfigurationTag](API_ConfigurationTag.md)
+  [ContinuousExportDescription](API_ContinuousExportDescription.md)
+  [CustomerAgentInfo](API_CustomerAgentInfo.md)
+  [CustomerAgentlessCollectorInfo](API_CustomerAgentlessCollectorInfo.md)
+  [CustomerConnectorInfo](API_CustomerConnectorInfo.md)
+  [CustomerMeCollectorInfo](API_CustomerMeCollectorInfo.md)
+  [DeleteAgent](API_DeleteAgent.md)
+  [DeletionWarning](API_DeletionWarning.md)
+  [Ec2RecommendationsExportPreferences](API_Ec2RecommendationsExportPreferences.md)
+  [ExportFilter](API_ExportFilter.md)
+  [ExportInfo](API_ExportInfo.md)
+  [ExportPreferences](API_ExportPreferences.md)
+  [FailedConfiguration](API_FailedConfiguration.md)
+  [Filter](API_Filter.md)
+  [ImportTask](API_ImportTask.md)

+  [NeighborConnectionDetail](API_NeighborConnectionDetail.md)
+  [OrderByElement](API_OrderByElement.md)

+  [UsageMetricBasis](API_UsageMetricBasis.md)
