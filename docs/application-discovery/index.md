# AWS Application Discovery Service Documentation

The AWS Application Discovery Service helps systems integrators quickly and reliably plan application migration projects by automatically identifying applications running in on-premises data centers, their associated dependencies, and their performance profile.

- [User Guide](/application-discovery/latest/userguide/what-is-appdiscovery.html): Walks through how to set up the AWS Application Discovery Service and integrate it with other services.
- [API Reference](/application-discovery/latest/APIReference/Welcome.html): Describes all the API operations for the AWS Application Discovery Service in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
