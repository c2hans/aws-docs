# Data Types
<a name="API_Types"></a>

The AWS Support App API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [SlackChannelConfiguration](API_SlackChannelConfiguration.md)
+  [SlackWorkspaceConfiguration](API_SlackWorkspaceConfiguration.md)
