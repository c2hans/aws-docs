# SelectOptionDescription
<a name="API_SelectOptionDescription"></a>

A description of each select option.

## Contents
<a name="API_SelectOptionDescription_Contents"></a>

 ** Option **   <a name="pinpoint-Type-SelectOptionDescription-Option"></a>
The value of the option.
Type: String
Required: Yes

 ** Description **   <a name="pinpoint-Type-SelectOptionDescription-Description"></a>
A description of the option meaning.
Type: String
Required: No

 ** Title **   <a name="pinpoint-Type-SelectOptionDescription-Title"></a>
The title of the select option.
Type: String
Required: No
