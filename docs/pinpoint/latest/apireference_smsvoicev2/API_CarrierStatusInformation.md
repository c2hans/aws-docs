# CarrierStatusInformation
<a name="API_CarrierStatusInformation"></a>

Contains carrier-level launch status details for an RCS agent within a country.

## Contents
<a name="API_CarrierStatusInformation_Contents"></a>

 ** CarrierName **   <a name="pinpoint-Type-CarrierStatusInformation-CarrierName"></a>
The name of the carrier.
Type: String
Required: Yes

 ** Status **   <a name="pinpoint-Type-CarrierStatusInformation-Status"></a>
The launch status for this carrier.
Type: String
Valid Values: `PENDING | ACTIVE | REJECTED`
Required: Yes
