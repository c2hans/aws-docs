# RegistrationSectionDefinition
<a name="API_RegistrationSectionDefinition"></a>

Provides information on the specified section definition.

## Contents
<a name="API_RegistrationSectionDefinition_Contents"></a>

 ** DisplayHints **   <a name="pinpoint-Type-RegistrationSectionDefinition-DisplayHints"></a>
The path to the section of the registration.
Type: [RegistrationSectionDisplayHints](API_RegistrationSectionDisplayHints.md) object
Required: Yes

 ** SectionPath **   <a name="pinpoint-Type-RegistrationSectionDefinition-SectionPath"></a>
The path to the section of the registration.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Pattern: `[A-Za-z0-9_]+`
Required: Yes
