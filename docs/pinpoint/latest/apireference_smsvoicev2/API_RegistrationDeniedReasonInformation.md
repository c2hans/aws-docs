# RegistrationDeniedReasonInformation
<a name="API_RegistrationDeniedReasonInformation"></a>

Provides the reason a registration was rejected.

## Contents
<a name="API_RegistrationDeniedReasonInformation_Contents"></a>

 ** Reason **   <a name="pinpoint-Type-RegistrationDeniedReasonInformation-Reason"></a>
The reason a registration was rejected.
Type: String
Required: Yes

 ** ShortDescription **   <a name="pinpoint-Type-RegistrationDeniedReasonInformation-ShortDescription"></a>
A short description of the rejection reason.
Type: String
Required: Yes

 ** DocumentationLink **   <a name="pinpoint-Type-RegistrationDeniedReasonInformation-DocumentationLink"></a>
The link to the document.
Type: String
Required: No

 ** DocumentationTitle **   <a name="pinpoint-Type-RegistrationDeniedReasonInformation-DocumentationTitle"></a>
The title of the document.
Type: String
Required: No

 ** LongDescription **   <a name="pinpoint-Type-RegistrationDeniedReasonInformation-LongDescription"></a>
A long description of the rejection reason.
Type: String
Required: No
