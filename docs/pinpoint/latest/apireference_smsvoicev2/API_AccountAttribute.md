# AccountAttribute
<a name="API_AccountAttribute"></a>

Displays the attributes associated with a single AWS account.

## Contents
<a name="API_AccountAttribute_Contents"></a>

 ** Name **   <a name="pinpoint-Type-AccountAttribute-Name"></a>
The name of the account attribute.
Type: String
Valid Values: `ACCOUNT_TIER | DEFAULT_PROTECT_CONFIGURATION_ID`
Required: Yes

 ** Value **   <a name="pinpoint-Type-AccountAttribute-Value"></a>
The value associated with the account attribute name.
Type: String
Required: Yes
