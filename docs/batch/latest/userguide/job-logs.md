# How to add the Job logs widget to the AWS Batch dashboard
<a name="job-logs"></a>

This widget displays different logs from your jobs in one convenient location. For more information about job logs, see [View AWS Batch job logs in CloudWatch Logs](review-job-logs.md).

To add this widget, follow these steps.

1. Open the [AWS Batch console](https://console.aws.amazon.com/batch).

1. From the navigation bar, choose the AWS Region that you want.

1. In the navigation pane, choose **Dashboard**.

1. Choose **Add widgets**.

1. For **Job logs**, choose **Add widget**.

1. For **Job id**, enter the job ID for the job that you want.

1. Choose **Add**.
