# The AWS Batch widget dashboard
<a name="custom-dashboard"></a>

Through the AWS Batch dashboard, you can monitor recent jobs, job queues, and compute environments. By default, the following dashboard widgets are displayed:
+ **Job overview** – For more information about AWS Batch jobs, see [Jobs](jobs.md).
+ **Job queue overview** – For more information about AWS Batch job queues, see [Job queues](job_queues.md).
+ **Compute environment overview** – For more information about AWS Batch compute environments, see [Compute environments for AWS Batch](compute_environments.md).

You can customize the widgets that are displayed on the Dashboard page. The following sections describe additional widgets that you can add.

**Topics**
+ [How to add the Single job queue widget to the AWS Batch dashboard](single-job-queue.md)
+ [How to add the CloudWatch Container Insights widget to the AWS Batch dashboard](container-insight.md)
+ [How to add the Job logs widget to the AWS Batch dashboard](job-logs.md)
