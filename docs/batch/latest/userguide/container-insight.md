# How to add the CloudWatch Container Insights widget to the AWS Batch dashboard
<a name="container-insight"></a>

This widget displays aggregated metrics for AWS Batch compute environments and jobs. For more information about Container Insights, see [AWS Batch CloudWatch Container Insights](cloudwatch-container-insights.md).

To add this widget, follow these steps.

1. Open the [AWS Batch console](https://console.aws.amazon.com/batch).

1. From the navigation bar, choose the AWS Region that you want.

1. In the navigation pane, choose **Dashboard**.

1. Choose **Add widgets**.

1. For **Container insights**, choose **Add widget**.

1. For **Compute environment**, choose the compute environment that you want.

1. Choose **Add**.
