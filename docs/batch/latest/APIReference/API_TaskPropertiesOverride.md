# TaskPropertiesOverride
<a name="API_TaskPropertiesOverride"></a>

An object that contains overrides for the task definition of a job.

## Contents
<a name="API_TaskPropertiesOverride_Contents"></a>

 ** containers **   <a name="Batch-Type-TaskPropertiesOverride-containers"></a>
The overrides for the container definition of a job.
Type: Array of [TaskContainerOverrides](API_TaskContainerOverrides.md) objects
Required: No
