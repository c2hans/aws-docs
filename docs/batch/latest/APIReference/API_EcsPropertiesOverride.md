# EcsPropertiesOverride
<a name="API_EcsPropertiesOverride"></a>

An object that contains overrides for the Amazon ECS task definition of a job.

## Contents
<a name="API_EcsPropertiesOverride_Contents"></a>

 ** taskProperties **   <a name="Batch-Type-EcsPropertiesOverride-taskProperties"></a>
The overrides for the Amazon ECS task definition of a job.
This object is currently limited to one element.
Type: Array of [TaskPropertiesOverride](API_TaskPropertiesOverride.md) objects
Required: No
