# ArrayProperties
<a name="API_ArrayProperties"></a>

An object that represents an AWS Batch array job.

## Contents
<a name="API_ArrayProperties_Contents"></a>

 ** size **   <a name="Batch-Type-ArrayProperties-size"></a>

Type: Integer
Required: No
