# ManagedInstancesStorageConfiguration
<a name="API_ManagedInstancesStorageConfiguration"></a>

The storage configuration for Amazon ECS Managed Instances.

## Contents
<a name="API_ManagedInstancesStorageConfiguration_Contents"></a>

 ** storageSizeGiB **   <a name="Batch-Type-ManagedInstancesStorageConfiguration-storageSizeGiB"></a>
The size of the root EBS volume in GiB for the managed instances.
Type: Integer
Required: No
