# EcsPropertiesDetail
<a name="API_EcsPropertiesDetail"></a>

An object that contains the details for the Amazon ECS resources of a job.

## Contents
<a name="API_EcsPropertiesDetail_Contents"></a>

 ** taskProperties **   <a name="Batch-Type-EcsPropertiesDetail-taskProperties"></a>
The properties for the Amazon ECS task definition of a job.
Type: Array of [EcsTaskDetails](API_EcsTaskDetails.md) objects
Required: No
