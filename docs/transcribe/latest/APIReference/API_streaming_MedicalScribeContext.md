# MedicalScribeContext
<a name="API_streaming_MedicalScribeContext"></a>

The `MedicalScribeContext` object that contains contextual information which is used during clinical note generation to add relevant context to the note.

## Contents
<a name="API_streaming_MedicalScribeContext_Contents"></a>

 ** PatientContext **   <a name="transcribe-Type-streaming_MedicalScribeContext-PatientContext"></a>
Contains patient-specific information used to customize the clinical note generation.
Type: [MedicalScribePatientContext](API_streaming_MedicalScribePatientContext.md) object
Required: No
