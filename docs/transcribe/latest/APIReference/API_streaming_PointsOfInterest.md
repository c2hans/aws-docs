# PointsOfInterest
<a name="API_streaming_PointsOfInterest"></a>

Contains the timestamps of matched categories.

## Contents
<a name="API_streaming_PointsOfInterest_Contents"></a>

 ** TimestampRanges **   <a name="transcribe-Type-streaming_PointsOfInterest-TimestampRanges"></a>
Contains the timestamp ranges (start time through end time) of matched categories and rules.
Type: Array of [TimestampRange](API_streaming_TimestampRange.md) objects
Required: No
