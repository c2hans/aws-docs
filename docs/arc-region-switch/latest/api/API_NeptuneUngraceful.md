# NeptuneUngraceful
<a name="API_NeptuneUngraceful"></a>

Configuration for handling failures when performing operations on Neptune global databases.

## Contents
<a name="API_NeptuneUngraceful_Contents"></a>

 ** ungraceful **   <a name="regionswitch-Type-NeptuneUngraceful-ungraceful"></a>
The settings for ungraceful execution.
Type: String
Valid Values: `failover`
Required: No
