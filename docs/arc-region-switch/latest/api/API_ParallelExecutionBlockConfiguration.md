# ParallelExecutionBlockConfiguration
<a name="API_ParallelExecutionBlockConfiguration"></a>

Configuration for steps that should be executed in parallel during a Region switch.

## Contents
<a name="API_ParallelExecutionBlockConfiguration_Contents"></a>

 ** steps **   <a name="regionswitch-Type-ParallelExecutionBlockConfiguration-steps"></a>
The steps for a parallel execution block.
Type: Array of [Step](API_Step.md) objects
Required: Yes
