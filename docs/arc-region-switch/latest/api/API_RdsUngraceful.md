# RdsUngraceful
<a name="API_RdsUngraceful"></a>

The ungraceful execution settings for an Amazon RDS switchover read replica execution block.

## Contents
<a name="API_RdsUngraceful_Contents"></a>

 ** ungraceful **   <a name="regionswitch-Type-RdsUngraceful-ungraceful"></a>
The ungraceful behavior to perform if switching to ungraceful execution.
Type: String
Valid Values: `promoteReadReplica`
Required: No
