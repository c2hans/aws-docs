# EksResourceScalingUngraceful
<a name="API_EksResourceScalingUngraceful"></a>

The ungraceful settings for AWS EKS resource scaling.

 ** minimumSuccessPercentage **   <a name="regionswitch-Type-EksResourceScalingUngraceful-minimumSuccessPercentage"></a>
The minimum success percentage for the configuration.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 99.
Required: Yes
