# MinimalWorkflow
<a name="API_MinimalWorkflow"></a>

A simplified representation of a workflow in a Region switch plan.

## Contents
<a name="API_MinimalWorkflow_Contents"></a>

 ** action **   <a name="regionswitch-Type-MinimalWorkflow-action"></a>
The action for a minimal workflow, which can be Activate or Deactivate.
Type: String
Valid Values: `activate | deactivate | postRecovery`
Required: No

 ** name **   <a name="regionswitch-Type-MinimalWorkflow-name"></a>
The name for a minimal workflow
Type: String
Required: No
