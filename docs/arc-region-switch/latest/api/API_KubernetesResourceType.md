# KubernetesResourceType
<a name="API_KubernetesResourceType"></a>

Defines the type of Kubernetes resource to scale in an Amazon EKS cluster.

Type: String
Required: Yes

 ** kind **   <a name="regionswitch-Type-KubernetesResourceType-kind"></a>
The kind for the Kubernetes resource.
Type: String
Required: Yes
