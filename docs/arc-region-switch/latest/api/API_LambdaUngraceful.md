# LambdaUngraceful
<a name="API_LambdaUngraceful"></a>

Configuration for handling failures when invoking Lambda functions.

## Contents
<a name="API_LambdaUngraceful_Contents"></a>

 ** behavior **   <a name="regionswitch-Type-LambdaUngraceful-behavior"></a>
The ungraceful behavior for a Lambda function, which must be set to `skip`.
Type: String
Valid Values: `skip`
Required: No
