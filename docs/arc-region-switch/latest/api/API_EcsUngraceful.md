# EcsUngraceful
<a name="API_EcsUngraceful"></a>

## Contents

 ** minimumSuccessPercentage **   <a name="regionswitch-Type-EcsUngraceful-minimumSuccessPercentage"></a>
The minimum success percentage specified for the configuration.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 99.
Required: Yes
