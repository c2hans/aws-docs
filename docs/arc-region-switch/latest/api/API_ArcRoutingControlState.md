# ArcRoutingControlState
<a name="API_ArcRoutingControlState"></a>

Represents the state of an ARC routing control.

## Contents
<a name="API_ArcRoutingControlState_Contents"></a>

 ** routingControlArn **   <a name="regionswitch-Type-ArcRoutingControlState-routingControlArn"></a>
The Amazon Resource Name (ARN) of a routing control.
Type: String
Required: Yes

 ** state **   <a name="regionswitch-Type-ArcRoutingControlState-state"></a>
The state of an ARC routing control, On or Off.
Type: String
Valid Values: `On | Off`
Required: Yes
