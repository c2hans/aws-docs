# SsmSendCommandUngraceful
<a name="API_SsmSendCommandUngraceful"></a>

The ungraceful execution settings for an AWS Systems Manager `SendCommand` execution block.

## Contents
<a name="API_SsmSendCommandUngraceful_Contents"></a>

 ** behavior **   <a name="regionswitch-Type-SsmSendCommandUngraceful-behavior"></a>
Specifies whether to skip running this command during an ungraceful execution. Set to `skip` to skip the command.
Type: String
Valid Values: `skip`
Required: No
