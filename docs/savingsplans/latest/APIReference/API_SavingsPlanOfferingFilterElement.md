# SavingsPlanOfferingFilterElement
<a name="API_SavingsPlanOfferingFilterElement"></a>

Information about a Savings Plan offering filter.

## Contents
<a name="API_SavingsPlanOfferingFilterElement_Contents"></a>

 ** name **   <a name="savingsplans-Type-SavingsPlanOfferingFilterElement-name"></a>
The filter name.
Type: String
Valid Values: `region | instanceFamily`
Required: No

 ** values **   <a name="savingsplans-Type-SavingsPlanOfferingFilterElement-values"></a>
The filter values.
Type: Array of strings
Pattern: `^[a-zA-Z0-9_ \/.\:\-\(\)]+$`
Required: No
