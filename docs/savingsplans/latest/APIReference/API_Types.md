# Data Types
<a name="API_Types"></a>

The Savings Plans API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:

+  [SavingsPlan](API_SavingsPlan.md)
+  [SavingsPlanFilter](API_SavingsPlanFilter.md)
+  [SavingsPlanOffering](API_SavingsPlanOffering.md)
+  [SavingsPlanOfferingFilterElement](API_SavingsPlanOfferingFilterElement.md)
+  [SavingsPlanOfferingProperty](API_SavingsPlanOfferingProperty.md)

+  [SavingsPlanRate](API_SavingsPlanRate.md)
