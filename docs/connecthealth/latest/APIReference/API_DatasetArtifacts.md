# DatasetArtifacts
<a name="API_DatasetArtifacts"></a>

The results of building a Dataset, by dataset type.

## Contents
<a name="API_DatasetArtifacts_Contents"></a>

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** medicalCoding **   <a name="connecthealth-Type-DatasetArtifacts-medicalCoding"></a>
The results of building a medical coding dataset.
Type: [MedicalCodingDatasetArtifacts](API_MedicalCodingDatasetArtifacts.md) object
Required: No
