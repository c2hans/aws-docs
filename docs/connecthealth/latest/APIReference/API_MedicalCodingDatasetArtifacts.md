# MedicalCodingDatasetArtifacts
<a name="API_MedicalCodingDatasetArtifacts"></a>

The results of building a medical coding dataset.

## Contents
<a name="API_MedicalCodingDatasetArtifacts_Contents"></a>

 ** evaluationS3Uri **   <a name="connecthealth-Type-MedicalCodingDatasetArtifacts-evaluationS3Uri"></a>
The Amazon S3 location, under the s3OutputPath of the dataset, of the evaluation scores for the dataset.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `s3://[a-z0-9][\.\-a-z0-9]{1,61}[a-z0-9](/.*)?`
Required: No
