# ManagedTemplate
<a name="API_ManagedTemplate"></a>

Configuration for using a managed note template

## Contents
<a name="API_ManagedTemplate_Contents"></a>

 ** templateType **   <a name="connecthealth-Type-ManagedTemplate-templateType"></a>
The type of managed template to use
Type: String
Valid Values: `HISTORY_AND_PHYSICAL | GIRPP | DAP | SIRP | BIRP | BEHAVIORAL_SOAP | PHYSICAL_SOAP`
Required: Yes
