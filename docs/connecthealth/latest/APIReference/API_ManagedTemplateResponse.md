# ManagedTemplateResponse
<a name="API_ManagedTemplateResponse"></a>

Response containing managed template information

## Contents
<a name="API_ManagedTemplateResponse_Contents"></a>

 ** templateType **   <a name="connecthealth-Type-ManagedTemplateResponse-templateType"></a>
The type of managed template used
Type: String
Valid Values: `HISTORY_AND_PHYSICAL | GIRPP | DAP | SIRP | BIRP | BEHAVIORAL_SOAP | PHYSICAL_SOAP`
Required: No
