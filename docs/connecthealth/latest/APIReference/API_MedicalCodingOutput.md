# MedicalCodingOutput

The location of the results of a medical coding job.

## Contents
<a name="API_MedicalCodingOutput_Contents"></a>

 ** uri **   <a name="connecthealth-Type-MedicalCodingOutput-uri"></a>
The Amazon S3 location of the medical codes that the job generated.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `s3://[a-z0-9][\.\-a-z0-9]{1,61}[a-z0-9](/.*)?`
Required: Yes
