# Data retrieval APIs for AWS Support App in Slack
<a name="awssupportappinslack"></a>

AWS Support App in Slack provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="supportapp-DescribeSlackChannels"></a>[https://docs.aws.amazon.com/awssupport/latest/user/slack-authorization-permissions.html](https://docs.aws.amazon.com/awssupport/latest/user/slack-authorization-permissions.html) | List all public Slack channels in a workspace that have invited the AWS Support App | Read |
| <a name="supportapp-GetAccountAlias"></a>[https://docs.aws.amazon.com/supportapp/latest/APIReference/API_GetAccountAlias.html](https://docs.aws.amazon.com/supportapp/latest/APIReference/API_GetAccountAlias.html) | Get the alias for your account | Read |
| <a name="supportapp-GetSlackOauthParameters"></a>[https://docs.aws.amazon.com/awssupport/latest/user/slack-authorization-permissions.html](https://docs.aws.amazon.com/awssupport/latest/user/slack-authorization-permissions.html) | Get parameters for the Slack OAuth code, which the AWS Support App uses to authorize the workspace | Read |
| <a name="supportapp-ListSlackChannelConfigurations"></a>[https://docs.aws.amazon.com/supportapp/latest/APIReference/API_ListSlackChannelConfigurations.html](https://docs.aws.amazon.com/supportapp/latest/APIReference/API_ListSlackChannelConfigurations.html) | List all Slack channel configurations for your account | Read |
| <a name="supportapp-ListSlackWorkspaceConfigurations"></a>[https://docs.aws.amazon.com/supportapp/latest/APIReference/API_ListSlackWorkspaceConfigurations.html](https://docs.aws.amazon.com/supportapp/latest/APIReference/API_ListSlackWorkspaceConfigurations.html) | List all Slack workspace configurations for your account | Read |
