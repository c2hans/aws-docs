# Data retrieval APIs for AWS CodeBuild

AWS CodeBuild provides the following APIs for data retrieval.

****

| <a name="codebuild-BatchGetFleets"></a>[https://docs.aws.amazon.com/codebuild/latest/APIReference/API_BatchGetFleets.html](https://docs.aws.amazon.com/codebuild/latest/APIReference/API_BatchGetFleets.html) | Return an array of the Fleet objects specified by the input parameter | Read |

| <a name="codebuild-BatchGetSandboxes"></a>[https://docs.aws.amazon.com/codebuild/latest/APIReference/API_BatchGetSandboxes.html](https://docs.aws.amazon.com/codebuild/latest/APIReference/API_BatchGetSandboxes.html) | Get information about one or more sandboxes | Read |

| <a name="codebuild-ListFleets"></a>[https://docs.aws.amazon.com/codebuild/latest/APIReference/API_ListFleets.html](https://docs.aws.amazon.com/codebuild/latest/APIReference/API_ListFleets.html) | Get a list of compute fleet ARNs, with each compute fleet ARN representing a single fleet | List |
| <a name="codebuild-ListProjects"></a>[https://docs.aws.amazon.com/codebuild/latest/APIReference/API_ListProjects.html](https://docs.aws.amazon.com/codebuild/latest/APIReference/API_ListProjects.html) | Get a list of build project names, with each build project name representing a single build project | List |
