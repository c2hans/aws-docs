# Data retrieval APIs for Amazon Route 53 Recovery Controls

Amazon Route 53 Recovery Controls provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="route53-recovery-control-config-DescribeCluster"></a>[https://docs.aws.amazon.com/recovery-cluster/latest/api/cluster-clusterarn.html](https://docs.aws.amazon.com/recovery-cluster/latest/api/cluster-clusterarn.html) | Describe a cluster | Read |
| <a name="route53-recovery-control-config-DescribeControlPanel"></a>[https://docs.aws.amazon.com/recovery-cluster/latest/api/controlpanel-controlpanelarn.html](https://docs.aws.amazon.com/recovery-cluster/latest/api/controlpanel-controlpanelarn.html) | Describe a control panel | Read |
| <a name="route53-recovery-control-config-DescribeRoutingControl"></a>[https://docs.aws.amazon.com/recovery-cluster/latest/api/routingcontrol-routingcontrolarn.html](https://docs.aws.amazon.com/recovery-cluster/latest/api/routingcontrol-routingcontrolarn.html) | Describe a routing control | Read |
| <a name="route53-recovery-control-config-DescribeSafetyRule"></a>[https://docs.aws.amazon.com/recovery-cluster/latest/api/safetyrule-safetyrulearn.html](https://docs.aws.amazon.com/recovery-cluster/latest/api/safetyrule-safetyrulearn.html) | Describe a safety rule | Read |
| <a name="route53-recovery-control-config-GetResourcePolicy"></a>[https://docs.aws.amazon.com/recovery-cluster/latest/api/cluster/resourcepolicy-resourcearn.html](https://docs.aws.amazon.com/recovery-cluster/latest/api/cluster/resourcepolicy-resourcearn.html) | Get the resource policy of a cluster | Read |
| <a name="route53-recovery-control-config-ListAssociatedRoute53HealthChecks"></a>[https://docs.aws.amazon.com/recovery-cluster/latest/api/routingcontrol-routingcontrolarn-associatedroute53healthchecks.html](https://docs.aws.amazon.com/recovery-cluster/latest/api/routingcontrol-routingcontrolarn-associatedroute53healthchecks.html) | List associated Route 53 health checks | List |
| <a name="route53-recovery-control-config-ListClusters"></a>[https://docs.aws.amazon.com/recovery-cluster/latest/api/cluster.html](https://docs.aws.amazon.com/recovery-cluster/latest/api/cluster.html) | List clusters | Read |
| <a name="route53-recovery-control-config-ListControlPanels"></a>[https://docs.aws.amazon.com/recovery-cluster/latest/api/controlpanels.html](https://docs.aws.amazon.com/recovery-cluster/latest/api/controlpanels.html) | List control panels | Read |
| <a name="route53-recovery-control-config-ListRoutingControls"></a>[https://docs.aws.amazon.com/recovery-cluster/latest/api/controlpanel-controlpanelarn-routingcontrols.html](https://docs.aws.amazon.com/recovery-cluster/latest/api/controlpanel-controlpanelarn-routingcontrols.html) | List routing controls | Read |

| <a name="route53-recovery-control-config-ListTagsForResource"></a>[https://docs.aws.amazon.com/recovery-cluster/latest/api/tags-resource-arn.html](https://docs.aws.amazon.com/recovery-cluster/latest/api/tags-resource-arn.html) | List tags for a resource | Read |
