# Data retrieval APIs for AWS Health APIs and Notifications
<a name="awshealthapisandnotifications"></a>

AWS Health APIs and Notifications provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="health-DescribeAffectedAccountsForOrganization"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeAffectedAccountsForOrganization.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeAffectedAccountsForOrganization.html) | Retrieve a list of accounts that have been affected by the specified events in organization | Read |
| <a name="health-DescribeAffectedEntities"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeAffectedEntities.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeAffectedEntities.html) | Retrieve a list of entities that have been affected by the specified events | Read |
| <a name="health-DescribeAffectedEntitiesForOrganization"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeAffectedEntitiesForOrganization.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeAffectedEntitiesForOrganization.html) | Retrieve a list of entities that have been affected by the specified events and accounts in organization | Read |
| <a name="health-DescribeEntityAggregates"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEntityAggregates.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEntityAggregates.html) | Retrieve the number of entities that are affected by each of the specified events | Read |
| <a name="health-DescribeEntityAggregatesForOrganization"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEntityAggregatesForOrganization.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEntityAggregatesForOrganization.html) | Retrieve the number of entities that are affected by each of the specified events in an organization | Read |
| <a name="health-DescribeEventAggregates"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEventAggregates.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEventAggregates.html) | Retrieve the number of events of each event type (issue, scheduled change, and account notification) | Read |
| <a name="health-DescribeEventDetails"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEventDetails.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEventDetails.html) | Retrieve detailed information about one or more specified events | Read |
| <a name="health-DescribeEventDetailsForOrganization"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEventDetailsForOrganization.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEventDetailsForOrganization.html) | Retrieve detailed information about one or more specified events for provided accounts in organization | Read |
| <a name="health-DescribeEventTypes"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEventTypes.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEventTypes.html) | Retrieve the event types that meet the specified filter criteria | Read |
| <a name="health-DescribeEvents"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEvents.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEvents.html) | Retrieve information about events that meet the specified filter criteria | Read |
| <a name="health-DescribeEventsForOrganization"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEventsForOrganization.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeEventsForOrganization.html) | Retrieve information about events that meet the specified filter criteria in organization | Read |
| <a name="health-DescribeHealthServiceStatusForOrganization"></a>[https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeHealthServiceStatusForOrganization.html](https://docs.aws.amazon.com/health/latest/APIReference/API_DescribeHealthServiceStatusForOrganization.html) | Retrieve the status of enabling or disabling the Organizational View feature | Read |
