# Data retrieval APIs for Amazon Managed Blockchain Query
<a name="amazonmanagedblockchainquery"></a>

Amazon Managed Blockchain Query provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="managedblockchain-query-BatchGetTokenBalance"></a>[${APIReferenceDocPage}API_BatchGetTokenBalance.html](${APIReferenceDocPage}API_BatchGetTokenBalance.html) | Batch calls for GetTokenBalance API | Read |
| <a name="managedblockchain-query-GetAssetContract"></a>[${APIReferenceDocPage}API_GetAssetContract.html](${APIReferenceDocPage}API_GetAssetContract.html) | Fetch information about a contract on the blockchain | Read |
| <a name="managedblockchain-query-GetTokenBalance"></a>[${APIReferenceDocPage}API_GetTokenBalance.html](${APIReferenceDocPage}API_GetTokenBalance.html) | Retrieve balance of a token for an address on the blockchain | Read |
| <a name="managedblockchain-query-GetTransaction"></a>[${APIReferenceDocPage}API_GetTransaction.html](${APIReferenceDocPage}API_GetTransaction.html) | Retrieve a transaction on the blockchain | Read |
| <a name="managedblockchain-query-ListAssetContracts"></a>[${APIReferenceDocPage}API_ListAssetContracts.html](${APIReferenceDocPage}API_ListAssetContracts.html) | Fetch multiple contracts on the blockchain | List |
| <a name="managedblockchain-query-ListFilteredTransactionEvents"></a>[${APIReferenceDocPage}API_ListFilteredTransactionEvents.html](${APIReferenceDocPage}API_ListFilteredTransactionEvents.html) | Retrieve events on the blockchain with additional filters | List |
| <a name="managedblockchain-query-ListTokenBalances"></a>[${APIReferenceDocPage}API_ListTokenBalances.html](${APIReferenceDocPage}API_ListTokenBalances.html) | Retrieve multiple balances on the blockchain | List |
| <a name="managedblockchain-query-ListTransactionEvents"></a>[${APIReferenceDocPage}API_ListTransactionEvents.html](${APIReferenceDocPage}API_ListTransactionEvents.html) | Retrieve events in a transaction on the blockchain | List |
| <a name="managedblockchain-query-ListTransactions"></a>[${APIReferenceDocPage}API_ListTransactions.html](${APIReferenceDocPage}API_ListTransactions.html) | Retrieve a multiple transactions on a blockchain | List |
