# Data retrieval APIs for AWS Activate
<a name="awsactivate"></a>

AWS Activate provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="activate-GetAccountContact"></a>[https://docs.aws.amazon.com/](https://docs.aws.amazon.com/) | Get the AWS account contact information | Read |
| <a name="activate-GetContentInfo"></a>[https://docs.aws.amazon.com/](https://docs.aws.amazon.com/) | Get Activate tech posts and offer information | Read |
| <a name="activate-GetCosts"></a>[https://docs.aws.amazon.com/](https://docs.aws.amazon.com/) | Get the AWS cost information | Read |
| <a name="activate-GetCredits"></a>[https://docs.aws.amazon.com/](https://docs.aws.amazon.com/) | Get the AWS credit information | Read |
| <a name="activate-GetMemberInfo"></a>[https://docs.aws.amazon.com/](https://docs.aws.amazon.com/) | Get the Activate member information | Read |
| <a name="activate-GetProgram"></a>[https://docs.aws.amazon.com/](https://docs.aws.amazon.com/) | Get an Activate program | Read |
