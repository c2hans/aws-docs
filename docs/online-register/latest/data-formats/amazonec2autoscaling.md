# Data retrieval APIs for Amazon EC2 Auto Scaling

| <a name="autoscaling-DescribeAutoScalingGroups"></a>[https://docs.aws.amazon.com/AutoScaling/latest/APIReference/API_DescribeAutoScalingGroups.html](https://docs.aws.amazon.com/AutoScaling/latest/APIReference/API_DescribeAutoScalingGroups.html) | Describe one or more Auto Scaling groups. | <a name="autoscaling-DescribeInstanceRefreshes"></a>[https://docs.aws.amazon.com/AutoScaling/latest/APIReference/API_DescribeInstanceRefreshes.html](https://docs.aws.amazon.com/AutoScaling/latest/APIReference/API_DescribeInstanceRefreshes.html) | Describe one or more instance refreshes for an Auto Scaling group | List |
