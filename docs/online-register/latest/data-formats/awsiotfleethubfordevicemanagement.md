# Data retrieval APIs for AWS IoT Fleet Hub for Device Management
<a name="awsiotfleethubfordevicemanagement"></a>

AWS IoT Fleet Hub for Device Management provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="iotfleethub-DescribeApplication"></a>[DescribeApplication](https://docs.aws.amazon.com/iot/latest/apireference/API_iotfleethub_DescribeApplication.html) | Describe an application | Read |
| <a name="iotfleethub-ListApplications"></a>[ListApplications](https://docs.aws.amazon.com/iot/latest/apireference/API_iotfleethub_ListApplications.html) | List all applications | List |
| <a name="iotfleethub-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/iot/latest/apireference/API_iotfleethub_ListTagsForResource.html) | List all tags for a resource | Read |
