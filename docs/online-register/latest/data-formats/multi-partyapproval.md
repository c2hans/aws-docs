# Data retrieval APIs for Multi-party approval
<a name="multi-partyapproval"></a>

Multi-party approval provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="mpa-GetApprovalTeam"></a>[GetApprovalTeam](https://docs.aws.amazon.com/mpa/latest/APIReference/API_GetApprovalTeam.html) | Retrieve details for an approval team | Read |
| <a name="mpa-GetIdentitySource"></a>[GetIdentitySource](https://docs.aws.amazon.com/mpa/latest/APIReference/API_GetIdentitySource.html) | Retrieve details for an identity source | Read |
| <a name="mpa-GetPolicyVersion"></a>[GetPolicyVersion](https://docs.aws.amazon.com/mpa/latest/APIReference/API_GetPolicyVersion.html) | Retrieve details for a policy | Read |
| <a name="mpa-GetResourcePolicy"></a>[GetResourcePolicy](https://docs.aws.amazon.com/mpa/latest/APIReference/API_GetResourcePolicy.html) | Retrieve details for a specific resource | Read |
| <a name="mpa-GetSession"></a>[GetSession](https://docs.aws.amazon.com/mpa/latest/APIReference/API_GetSession.html) | Retrieve details for an approval session | Read |
| <a name="mpa-ListApprovalTeams"></a>[ListApprovalTeams](https://docs.aws.amazon.com/mpa/latest/APIReference/API_ListApprovalTeams.html) | List approval teams | List |
| <a name="mpa-ListIdentitySources"></a>[ListIdentitySources](https://docs.aws.amazon.com/mpa/latest/APIReference/API_ListIdentitySources.html) | List identity sources | List |
| <a name="mpa-ListPolicies"></a>[ListPolicies](https://docs.aws.amazon.com/mpa/latest/APIReference/API_ListPolicies.html) | List policies | List |
| <a name="mpa-ListPolicyVersions"></a>[ListPolicyVersions](https://docs.aws.amazon.com/mpa/latest/APIReference/API_ListPolicyVersions.html) | List the versions for policies | List |
| <a name="mpa-ListResourcePolicies"></a>[ListResourcePolicies](https://docs.aws.amazon.com/mpa/latest/APIReference/API_ListResourcePolicies.html) | List policies for a resource | List |
| <a name="mpa-ListSessions"></a>[ListSessions](https://docs.aws.amazon.com/mpa/latest/APIReference/API_ListSessions.html) | List approval sessions | List |
| <a name="mpa-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/mpa/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | List |
