# Data retrieval APIs for AWS Control Catalog
<a name="awscontrolcatalog"></a>

AWS Control Catalog provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="controlcatalog-GetControl"></a>[GetControl](https://docs.aws.amazon.com/controlcatalog/latest/APIReference/API_GetControl.html) | Return details about a specific control | Read |
| <a name="controlcatalog-ListCommonControls"></a>[ListCommonControls](https://docs.aws.amazon.com/controlcatalog/latest/APIReference/API_ListCommonControls.html) | Return a paginated list of common controls from the AWS Control Catalog | List |
| <a name="controlcatalog-ListControlMappings"></a>[ListControlMappings](https://docs.aws.amazon.com/controlcatalog/latest/APIReference/API_ListControlMappings.html) | Return a paginated list of control mappings from the AWS Control Catalog | List |
| <a name="controlcatalog-ListControls"></a>[ListControls](https://docs.aws.amazon.com/controlcatalog/latest/APIReference/API_ListControls.html) | Return a paginated list of all available controls in the AWS Control Catalog library | List |
| <a name="controlcatalog-ListDomains"></a>[ListDomains](https://docs.aws.amazon.com/controlcatalog/latest/APIReference/API_ListDomains.html) | Return a paginated list of domains from the AWS Control Catalog | List |
| <a name="controlcatalog-ListObjectives"></a>[ListObjectives](https://docs.aws.amazon.com/controlcatalog/latest/APIReference/API_ListObjectives.html) | Return a paginated list of objectives from the AWS Control Catalog | List |
