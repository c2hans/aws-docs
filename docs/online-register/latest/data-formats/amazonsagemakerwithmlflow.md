# Data retrieval APIs for Amazon SageMaker with MLflow
<a name="amazonsagemakerwithmlflow"></a>

Amazon SageMaker with MLflow provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="sagemaker-mlflow-AccessUI"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Access the MLflow UI | Read |
| <a name="sagemaker-mlflow-GetDownloadURIForModelVersionArtifacts"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get a URI to download model artifacts for a specific model version | Read |
| <a name="sagemaker-mlflow-GetExperiment"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get metadata for an MLflow experiment | Read |
| <a name="sagemaker-mlflow-GetExperimentByName"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get metadata for an MLflow experiment by name | Read |
| <a name="sagemaker-mlflow-GetLatestModelVersions"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get the latest model versions | List |
| <a name="sagemaker-mlflow-GetLoggedModel"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get a logged model in MLflow | Read |
| <a name="sagemaker-mlflow-GetMetricHistory"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get a list of all values for the specified metric for a given run | Read |
| <a name="sagemaker-mlflow-GetModelVersion"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get a model version by model name and version | Read |
| <a name="sagemaker-mlflow-GetModelVersionByAlias"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get model version by alias in MLflow | Read |
| <a name="sagemaker-mlflow-GetRegisteredModel"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get a registered model | Read |
| <a name="sagemaker-mlflow-GetRun"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get metadata, metrics, parameters, and tags for a run | Read |
| <a name="sagemaker-mlflow-GetTraceInfo"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Get information about a trace in MLflow | Read |
| <a name="sagemaker-mlflow-ListArtifacts"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | List artifacts for a run | List |
| <a name="sagemaker-mlflow-ListLoggedModelArtifacts"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | List artifacts for a logged model in MLflow | List |
| <a name="sagemaker-mlflow-SearchExperiments"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Search for MLflow experiments | Read |
| <a name="sagemaker-mlflow-SearchLoggedModels"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Search for logged models in MLflow | Read |
| <a name="sagemaker-mlflow-SearchModelVersions"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Search for a model version | Read |
| <a name="sagemaker-mlflow-SearchRegisteredModels"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Search for registered models in MLflow | Read |
| <a name="sagemaker-mlflow-SearchRuns"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Search for runs that satisfy expressions | Read |
| <a name="sagemaker-mlflow-SearchTraces"></a>[${APIReferenceDocPage}](${APIReferenceDocPage}) | Search for traces in MLflow | Read |
