# Data retrieval APIs for AWS App Runner
<a name="awsapprunner"></a>

AWS App Runner provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="apprunner-DescribeAutoScalingConfiguration"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeAutoScalingConfiguration.html](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeAutoScalingConfiguration.html) | Retrieve the description of an AWS App Runner automatic scaling configuration resource | Read |
| <a name="apprunner-DescribeCustomDomains"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeCustomDomains.html](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeCustomDomains.html) | Retrieve descriptions of custom domain names associated with an AWS App Runner service | Read |
| <a name="apprunner-DescribeObservabilityConfiguration"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeObservabilityConfiguration.html](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeObservabilityConfiguration.html) | Retrieve the description of an AWS App Runner observability configuration resource | Read |
| <a name="apprunner-DescribeOperation"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeOperation.html](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeOperation.html) | Retrieve the description of an operation that occurred on an AWS App Runner service | Read |
| <a name="apprunner-DescribeService"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeService.html](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeService.html) | Retrieve the description of an AWS App Runner service resource | Read |
| <a name="apprunner-DescribeVpcConnector"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeVpcConnector.html](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeVpcConnector.html) | Retrieve the description of an AWS App Runner VPC connector resource | Read |
| <a name="apprunner-DescribeVpcIngressConnection"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeVpcIngressConnection.html](https://docs.aws.amazon.com/apprunner/latest/api/API_DescribeVpcIngressConnection.html) | Retrieve the description of an AWS App Runner VpcIngressConnection resource | Read |
| <a name="apprunner-DescribeWebAclForService"></a>[https://docs.aws.amazon.com/apprunner/latest/dg/waf-manage.html](https://docs.aws.amazon.com/apprunner/latest/dg/waf-manage.html) | Get the AWS WAF web ACL that is associated with an AWS App Runner service | Read |
| <a name="apprunner-ListAssociatedServicesForWebAcl"></a>[https://docs.aws.amazon.com/apprunner/latest/dg/waf-manage.html](https://docs.aws.amazon.com/apprunner/latest/dg/waf-manage.html) | List the services that are associated with an AWS WAF web ACL | List |
| <a name="apprunner-ListAutoScalingConfigurations"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_ListAutoScalingConfigurations.html](https://docs.aws.amazon.com/apprunner/latest/api/API_ListAutoScalingConfigurations.html) | Retrieve a list of AWS App Runner automatic scaling configurations in your AWS account | List |
| <a name="apprunner-ListConnections"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_ListConnections.html](https://docs.aws.amazon.com/apprunner/latest/api/API_ListConnections.html) | Retrieve a list of AWS App Runner connections in your AWS account | List |
| <a name="apprunner-ListObservabilityConfigurations"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_ListObservabilityConfigurations.html](https://docs.aws.amazon.com/apprunner/latest/api/API_ListObservabilityConfigurations.html) | Retrieve a list of AWS App Runner observability configurations in your AWS account | List |
| <a name="apprunner-ListOperations"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_ListOperations.html](https://docs.aws.amazon.com/apprunner/latest/api/API_ListOperations.html) | Retrieve a list of operations that occurred on an AWS App Runner service resource | List |
| <a name="apprunner-ListServices"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_ListServices.html](https://docs.aws.amazon.com/apprunner/latest/api/API_ListServices.html) | Retrieve a list of running AWS App Runner services in your AWS account | List |
| <a name="apprunner-ListServicesForAutoScalingConfiguration"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_ListServicesForAutoScalingConfiguration.html](https://docs.aws.amazon.com/apprunner/latest/api/API_ListServicesForAutoScalingConfiguration.html) | Retrieve a list of associated AppRunner services of an AWS App Runner automatic scaling configuration in your AWS account | List |
| <a name="apprunner-ListTagsForResource"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_ListTagsForResource.html](https://docs.aws.amazon.com/apprunner/latest/api/API_ListTagsForResource.html) | List tags associated with an AWS App Runner resource | Read |
| <a name="apprunner-ListVpcConnectors"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_ListVpcConnectors.html](https://docs.aws.amazon.com/apprunner/latest/api/API_ListVpcConnectors.html) | Retrieve a list of AWS App Runner VPC connectors in your AWS account | List |
| <a name="apprunner-ListVpcIngressConnections"></a>[https://docs.aws.amazon.com/apprunner/latest/api/API_ListVpcConnections.html](https://docs.aws.amazon.com/apprunner/latest/api/API_ListVpcConnections.html) | Retrieve a list of AWS App Runner VpcIngressConnections in your AWS account | List |
