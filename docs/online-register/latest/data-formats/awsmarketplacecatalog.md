# Data retrieval APIs for AWS Marketplace Catalog
<a name="awsmarketplacecatalog"></a>

AWS Marketplace Catalog provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="aws-marketplace-DescribeAssessment"></a>[https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_DescribeAssessment.html](https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_DescribeAssessment.html) | Return the details of an existing assessment | Read |
| <a name="aws-marketplace-DescribeChangeSet"></a>[https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_DescribeChangeSet.html](https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_DescribeChangeSet.html) | Return the details of an existing change set | Read |
| <a name="aws-marketplace-DescribeEntity"></a>[https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_DescribeEntity.html](https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_DescribeEntity.html) | Return the details of an existing entity | Read |
| <a name="aws-marketplace-GetInvoiceSubmissionTask"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | Retrieve details of an existing invoice submission task | Read |
| <a name="aws-marketplace-GetIssuedTaxInvoice"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | Retrieve details of a specific tax invoice issued by AWS on behalf of a seller | Read |
| <a name="aws-marketplace-GetResourcePolicy"></a>[https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_GetResourcePolicy.html](https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_GetResourcePolicy.html) | Get the resource policy of an existing entity | Read |
| <a name="aws-marketplace-GetTaxComplianceProfile"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | Retrieve details of a tax compliance profile including artifacts with download URLs | Read |
| <a name="aws-marketplace-GetVerification"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | Retrieve the detailed status of a specific verification process, including PSP validation results | Read |
| <a name="aws-marketplace-GetVerificationEvidence"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | Retrieve the complete content of a specific verification evidence resource | Read |
| <a name="aws-marketplace-ListAssessments"></a>[https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_ListAssessments.html](https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_ListAssessments.html) | List existing assessments | List |
| <a name="aws-marketplace-ListChangeSets"></a>[https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_ListChangeSets.html](https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_ListChangeSets.html) | List existing change sets | List |
| <a name="aws-marketplace-ListEntities"></a>[https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_ListEntities.html](https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_ListEntities.html) | List existing entities | List |
| <a name="aws-marketplace-ListInvoiceSubmissionTasks"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | List existing invoice submission tasks | List |
| <a name="aws-marketplace-ListIssuedTaxInvoices"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | List tax invoices issued by AWS on behalf of a seller | List |
| <a name="aws-marketplace-ListPayables"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | List payables of the specified payable provenance | List |
| <a name="aws-marketplace-ListTagsForResource"></a>[https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_ListTagsForResource.html](https://docs.aws.amazon.com/marketplace-catalog/latest/api-reference/API_ListTagsForResource.html) | List tags on an existing entity, change set, invoice submission task, issued tax invoice, VerificationEvidence, TaxComplianceProfile, or TaxComplianceProfileChangeTask | Read |
| <a name="aws-marketplace-ListTaxComplianceProfileChangeTasks"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | List tax compliance profile change tasks with optional filters | List |
| <a name="aws-marketplace-ListTaxComplianceProfiles"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | List tax compliance profiles with optional filters | List |
| <a name="aws-marketplace-ListVerificationEvidence"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | List verification evidence resources with summary metadata | List |
| <a name="aws-marketplace-ListVerifications"></a>[https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html](https://docs.aws.amazon.com/marketplace/latest/APIReference/compliance-api-access-control.html) | List all verification statuses across jurisdictions and verification types | List |
