# Data retrieval APIs for AWS Support Plans
<a name="awssupportplans"></a>

AWS Support Plans provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="supportplans-GetSupportAgreement"></a>[GetSupportAgreement](https://docs.aws.amazon.com/awssupport/latest/user/security-support-plans.html) | View details about a support agreement for this AWS account | Read |
| <a name="supportplans-GetSupportPlan"></a>[GetSupportPlan](https://docs.aws.amazon.com/awssupport/latest/user/security-support-plans.html) | View details about the current support plan for this AWS account | Read |
| <a name="supportplans-GetSupportPlanUpdateStatus"></a>[GetSupportPlanUpdateStatus](https://docs.aws.amazon.com/awssupport/latest/user/security-support-plans.html) | View details about the status for a request to update a support plan | Read |
| <a name="supportplans-ListSupportAgreementRevisions"></a>[ListSupportAgreementRevisions](https://docs.aws.amazon.com/awssupport/latest/user/security-support-plans.html) | List support agreement revisions for this AWS account | List |
| <a name="supportplans-ListSupportAgreements"></a>[ListSupportAgreements](https://docs.aws.amazon.com/awssupport/latest/user/security-support-plans.html) | List support agreements for this AWS account | List |
| <a name="supportplans-ListSupportPlanModifiers"></a>[ListSupportPlanModifiers](https://docs.aws.amazon.com/awssupport/latest/user/security-support-plans.html) | View a list of all support plan modifiers for this account | List |
