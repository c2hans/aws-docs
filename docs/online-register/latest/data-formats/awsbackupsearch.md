# Data retrieval APIs for AWS Backup Search
<a name="awsbackupsearch"></a>

AWS Backup Search provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="backup-search-GetSearchJob"></a>[GetSearchJob](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_GetSearchJob.html) | Get details of a search job | Read |
| <a name="backup-search-GetSearchResultExportJob"></a>[GetSearchResultExportJob](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_GetSearchResultExportJob.html) | Get details of a search result export job | Read |
| <a name="backup-search-ListSearchJobBackups"></a>[ListSearchJobBackups](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchJobBackups.html) | List backups in scope of a search job | Read |
| <a name="backup-search-ListSearchJobResults"></a>[ListSearchJobResults](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchJobResults.html) | List results of a search job | Read |
| <a name="backup-search-ListSearchJobs"></a>[ListSearchJobs](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchJobs.html) | List search jobs | List |
| <a name="backup-search-ListSearchResultExportJobs"></a>[ListSearchResultExportJobs](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchResultExportJobs.html) | List search result export jobs | List |
| <a name="backup-search-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListTagsForResource.html) | List tags for a resource | Read |
