# Data retrieval APIs for AWS Backup Search
<a name="awsbackupsearch"></a>

AWS Backup Search provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="backup-search-GetSearchJob"></a>[https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_GetSearchJob.html](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_GetSearchJob.html) | Get details of a search job | Read |
| <a name="backup-search-GetSearchResultExportJob"></a>[https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_GetSearchResultExportJob.html](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_GetSearchResultExportJob.html) | Get details of a search result export job | Read |
| <a name="backup-search-ListSearchJobBackups"></a>[https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchJobBackups.html](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchJobBackups.html) | List backups in scope of a search job | Read |
| <a name="backup-search-ListSearchJobResults"></a>[https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchJobResults.html](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchJobResults.html) | List results of a search job | Read |
| <a name="backup-search-ListSearchJobs"></a>[https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchJobs.html](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchJobs.html) | List search jobs | List |
| <a name="backup-search-ListSearchResultExportJobs"></a>[https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchResultExportJobs.html](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListSearchResultExportJobs.html) | List search result export jobs | List |
| <a name="backup-search-ListTagsForResource"></a>[https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListTagsForResource.html](https://docs.aws.amazon.com/aws-backup/latest/devguide/API_BKS_ListTagsForResource.html) | List tags for a resource | Read |
