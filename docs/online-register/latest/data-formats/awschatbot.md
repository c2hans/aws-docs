AWS Chatbot provides the following APIs for data retrieval.

****

| Actions | Description | Access level |

| <a name="chatbot-DescribeSlackUserIdentities"></a>[https://docs.aws.amazon.com/chatbot/latest/APIReference/API_DescribeSlackUserIdentities.html](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_DescribeSlackUserIdentities.html) | Describe AWS Chatbot Slack User Identities | Read |

| <a name="chatbot-GetCustomAction"></a>[https://docs.aws.amazon.com/chatbot/latest/APIReference/API_GetCustomAction.html](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_GetCustomAction.html) | Get a custom action | Read |
| <a name="chatbot-GetMicrosoftTeamsChannelConfiguration"></a>[https://docs.aws.amazon.com/chatbot/latest/APIReference/API_GetMicrosoftTeamsChannelConfiguration.html](https://docs.aws.amazon.com/chatbot/latest/APIReference/API_GetMicrosoftTeamsChannelConfiguration.html) | Get a single AWS Chatbot Microsoft Teams Channel Configurations in an AWS account | Read |
