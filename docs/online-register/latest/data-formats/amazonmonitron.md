# Data retrieval APIs for Amazon Monitron
<a name="amazonmonitron"></a>

Amazon Monitron provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="monitron-GetProject"></a>[GetProject](https://docs.aws.amazon.com/Monitron/latest/user-guide/mp-project-tasks.html) | Get information about a project | Read |
| <a name="monitron-GetProjectAdminUser"></a>[GetProjectAdminUser](https://docs.aws.amazon.com/Monitron/latest/user-guide/mp-project-tasks.html) | Describe an administrator who is associated with the project | Read |
| <a name="monitron-ListProjectUserAssociations"></a>[ListProjectUserAssociations](https://docs.aws.amazon.com/Monitron/latest/user-guide/user-management-chapter.html) | List all users associated with the project | List |
| <a name="monitron-ListProjects"></a>[ListProjects](https://docs.aws.amazon.com/Monitron/latest/user-guide/mp-project-tasks.html) | List all projects | List |
| <a name="monitron-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/Monitron/latest/user-guide/tagging.html) | List all tags for a resource | Read |
| <a name="monitron-ListUserAccessRoleAssociations"></a>[ListUserAccessRoleAssociations](https://docs.aws.amazon.com/Monitron/latest/user-guide/user-management-chapter.html) | List all access roles associated with the user | List |
