# Data retrieval APIs for Amazon Monitron
<a name="amazonmonitron"></a>

Amazon Monitron provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="monitron-GetProject"></a>[https://docs.aws.amazon.com/Monitron/latest/user-guide/mp-project-tasks.html](https://docs.aws.amazon.com/Monitron/latest/user-guide/mp-project-tasks.html) | Get information about a project | Read |
| <a name="monitron-GetProjectAdminUser"></a>[https://docs.aws.amazon.com/Monitron/latest/user-guide/mp-project-tasks.html](https://docs.aws.amazon.com/Monitron/latest/user-guide/mp-project-tasks.html) | Describe an administrator who is associated with the project | Read |
| <a name="monitron-ListProjectUserAssociations"></a>[https://docs.aws.amazon.com/Monitron/latest/user-guide/user-management-chapter.html](https://docs.aws.amazon.com/Monitron/latest/user-guide/user-management-chapter.html) | List all users associated with the project | List |
| <a name="monitron-ListProjects"></a>[https://docs.aws.amazon.com/Monitron/latest/user-guide/mp-project-tasks.html](https://docs.aws.amazon.com/Monitron/latest/user-guide/mp-project-tasks.html) | List all projects | List |
| <a name="monitron-ListTagsForResource"></a>[https://docs.aws.amazon.com/Monitron/latest/user-guide/tagging.html](https://docs.aws.amazon.com/Monitron/latest/user-guide/tagging.html) | List all tags for a resource | Read |
| <a name="monitron-ListUserAccessRoleAssociations"></a>[https://docs.aws.amazon.com/Monitron/latest/user-guide/user-management-chapter.html](https://docs.aws.amazon.com/Monitron/latest/user-guide/user-management-chapter.html) | List all access roles associated with the user | List |
