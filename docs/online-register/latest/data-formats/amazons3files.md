# Data retrieval APIs for Amazon S3 Files
<a name="amazons3files"></a>

Amazon S3 Files provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="s3files-ClientMount"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/s3files-client-authorization.html](https://docs.aws.amazon.com/AmazonS3/latest/API/s3files-client-authorization.html) | Allow an NFS client read-access to a file system | Read |
| <a name="s3files-GetAccessPoint"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_GetAccessPoint.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_GetAccessPoint.html) | Get resource information for a specified access point | Read |
| <a name="s3files-GetFileSystem"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_GetFileSystem.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_GetFileSystem.html) | Get resource information for a specified file system | Read |
| <a name="s3files-GetFileSystemPolicy"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_GetFileSystemPolicy.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_GetFileSystemPolicy.html) | Get the IAM resource policy for a specified file system | Read |
| <a name="s3files-GetMountTarget"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_GetMountTarget.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_GetMountTarget.html) | Get resource information for a specified mount target | Read |
| <a name="s3files-GetSynchronizationConfiguration"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_GetSynchronizationConfiguration.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_GetSynchronizationConfiguration.html) | Get a synchronization configuration for a specified file system | Read |
| <a name="s3files-ListAccessPoints"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_ListAccessPoints.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_ListAccessPoints.html) | Get a paginated list of all access points in the account | List |
| <a name="s3files-ListFileSystems"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_ListFileSystems.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_ListFileSystems.html) | Get a paginated list of all file systems in the account | List |
| <a name="s3files-ListMountTargets"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_ListMountTargets.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_ListMountTargets.html) | Get a paginated list of all mount targets in the account | List |
| <a name="s3files-ListTagsForResource"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_ListTagsForResource.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_S3Files_ListTagsForResource.html) | List tags for a specified S3 Files resource | Read |
