# Data retrieval APIs for Amazon DocumentDB Elastic Clusters
<a name="amazondocumentdbelasticclusters"></a>

Amazon DocumentDB Elastic Clusters provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="docdb-elastic-GetCluster"></a>[https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_GetCluster.html](https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_GetCluster.html) | View details about a cluster | Read |
| <a name="docdb-elastic-GetClusterSnapshot"></a>[https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_GetClusterSnapshot.html](https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_GetClusterSnapshot.html) | View details about a cluster snapshot | Read |
| <a name="docdb-elastic-GetPendingMaintenanceAction"></a>[https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_GetPendingMaintenanceAction.html](https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_GetPendingMaintenanceAction.html) | View details about pending maintenance actions on Amazon DocDB-Elastic cluster | Read |
| <a name="docdb-elastic-ListClusterSnapshots"></a>[https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_ListClusterSnapshots.html](https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_ListClusterSnapshots.html) | List the cluster snapshots in your account | List |
| <a name="docdb-elastic-ListClusters"></a>[https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_ListClusters.html](https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_ListClusters.html) | List the clusters in your account | List |
| <a name="docdb-elastic-ListPendingMaintenanceActions"></a>[https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_ListPendingMaintenanceActions.html](https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_ListPendingMaintenanceActions.html) | List details about pending maintenance actions on any Amazon DocDB-Elastic cluster | List |
| <a name="docdb-elastic-ListTagsForResource"></a>[https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_ListTagsForResource.html](https://docs.aws.amazon.com/documentdb/latest/developerguide/API_elastic_ListTagsForResource.html) | Lists tag for an DocumentDB Elastic resource | List |
