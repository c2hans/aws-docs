# Data retrieval APIs for Amazon Timestream InfluxDB
<a name="amazontimestreaminfluxdb"></a>

Amazon Timestream InfluxDB provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="timestream-influxdb-GetDbCluster"></a>[https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_GetDbCluster.html](https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_GetDbCluster.html) | Get information about a Timestream InfluxDB Cluster | Read |
| <a name="timestream-influxdb-GetDbInstance"></a>[https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_GetDbInstance.html](https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_GetDbInstance.html) | Get information about a Timestream InfluxDB instance | Read |
| <a name="timestream-influxdb-GetDbParameterGroup"></a>[https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_GetDbParameterGroup.html](https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_GetDbParameterGroup.html) | Get information about a Timestream InfluxDB parameter group | Read |
| <a name="timestream-influxdb-ListDbClusters"></a>[https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_ListDbClusters.html](https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_ListDbClusters.html) | List information about all Timestream InfluxDB clusters in the account | List |
| <a name="timestream-influxdb-ListDbInstances"></a>[https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_ListDbInstances.html](https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_ListDbInstances.html) | List information about all Timestream InfluxDB instances in the account | List |
| <a name="timestream-influxdb-ListDbInstancesForCluster"></a>[https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_ListDbInstancesForCluster.html](https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_ListDbInstancesForCluster.html) | List information about all Timestream InfluxDB Instances belonging to a cluster | Read |
| <a name="timestream-influxdb-ListDbParameterGroups"></a>[https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_ListDbParameterGroups.html](https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_ListDbParameterGroups.html) | List information about all Timestream InfluxDB parameter groups | List |
| <a name="timestream-influxdb-ListTagsForResource"></a>[https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_ListTagsForResource.html](https://docs.aws.amazon.com/ts-influxdb/latest/ts-influxdb-api/API_ListTagsForResource.html) | List tags for a Timestream InfluxDB resource | Read |
