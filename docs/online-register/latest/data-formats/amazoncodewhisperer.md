# Data retrieval APIs for Amazon CodeWhisperer
<a name="amazoncodewhisperer"></a>

Amazon CodeWhisperer provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="codewhisperer-GenerateRecommendations"></a>[GenerateRecommendations](https://docs.aws.amazon.com/codewhisperer/latest/userguide/security_iam_service-with-iam.html) | Invoke GenerateRecommendations on CodeWhisperer | Read |
| <a name="codewhisperer-GetCustomization"></a>[GetCustomization](https://docs.aws.amazon.com/codewhisperer/latest/userguide/security_iam_service-with-iam.html) | Invoke GetCustomization on CodeWhisperer | Read |
| <a name="codewhisperer-ListCustomizationPermissions"></a>[ListCustomizationPermissions](https://docs.aws.amazon.com/codewhisperer/latest/userguide/security_iam_service-with-iam.html) | Invoke ListCustomizationPermissions on CodeWhisperer | List |
| <a name="codewhisperer-ListCustomizationVersions"></a>[ListCustomizationVersions](https://docs.aws.amazon.com/codewhisperer/latest/userguide/security_iam_service-with-iam.html) | Invoke ListCustomizationVersions on CodeWhisperer | List |
| <a name="codewhisperer-ListCustomizations"></a>[ListCustomizations](https://docs.aws.amazon.com/codewhisperer/latest/userguide/security_iam_service-with-iam.html) | Invoke ListCustomizations on CodeWhisperer | List |
| <a name="codewhisperer-ListProfiles"></a>[ListProfiles](https://docs.aws.amazon.com/codewhisperer/latest/userguide/security_iam_service-with-iam.html) | Invoke ListProfiles on CodeWhisperer | List |
| <a name="codewhisperer-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/codewhisperer/latest/userguide/security_iam_service-with-iam.html) | Invoke ListTagsForResource on CodeWhisperer | List |
