# Data retrieval APIs for Amazon CodeCatalyst
<a name="amazoncodecatalyst"></a>

Amazon CodeCatalyst provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="codecatalyst-GetBillingAuthorization"></a>[https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections](https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections) | Describe the billing authorization for a connection | Read |
| <a name="codecatalyst-GetConnection"></a>[https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections](https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections) | Get a connection | Read |
| <a name="codecatalyst-GetIdentityCenterApplication"></a>[https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-applications](https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-applications) | Get information about an IAM Identity Center application | Read |
| <a name="codecatalyst-GetPendingConnection"></a>[https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections](https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections) | Get a pending request to connect this account to an Amazon CodeCatalyst space | Read |
| <a name="codecatalyst-ListConnections"></a>[https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections](https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections) | List connections that are not pending | List |
| <a name="codecatalyst-ListIamRolesForConnection"></a>[https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections](https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections) | List IAM roles associated with a connection | List |
| <a name="codecatalyst-ListIdentityCenterApplications"></a>[https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-applications](https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-applications) | View a list of all IAM Identity Center applications in the account | List |
| <a name="codecatalyst-ListIdentityCenterApplicationsForSpace"></a>[https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-applications](https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-applications) | View a list of IAM Identity Center applications by Amazon CodeCatalyst space | List |
| <a name="codecatalyst-ListSpacesForIdentityCenterApplication"></a>[https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-applications](https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-applications) | View a list of Amazon CodeCatalyst spaces by IAM Identity Center application | List |
| <a name="codecatalyst-ListTagsForResource"></a>[https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections](https://docs.aws.amazon.com/codecatalyst/latest/userguide/security-iam.html#permissions-reference-connections) | List tags for an Amazon CodeCatalyst resource | Read |
