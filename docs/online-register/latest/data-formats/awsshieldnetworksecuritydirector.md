# Data retrieval APIs for AWS Shield network security director
<a name="awsshieldnetworksecuritydirector"></a>

AWS Shield network security director provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="network-security-director-GetFinding"></a>[GetFinding](https://docs.aws.amazon.com/network-security-director/latest/APIReference/API_GetFinding.html) | Get a finding | Read |
| <a name="network-security-director-GetResource"></a>[GetResource](https://docs.aws.amazon.com/network-security-director/latest/APIReference/API_GetResource.html) | Get a resource | Read |
| <a name="network-security-director-ListAccountSummaries"></a>[ListAccountSummaries](https://docs.aws.amazon.com/network-security-director/latest/APIReference/API_ListAccountSummaries.html) | List account summaries for an account | List |
| <a name="network-security-director-ListFindings"></a>[ListFindings](https://docs.aws.amazon.com/network-security-director/latest/APIReference/API_ListFindings.html) | List findings | List |
| <a name="network-security-director-ListInsights"></a>[ListInsights](https://docs.aws.amazon.com/network-security-director/latest/APIReference/API_ListInsights.html) | List insights about the latest network security scan | List |
| <a name="network-security-director-ListRemediations"></a>[ListRemediations](https://docs.aws.amazon.com/network-security-director/latest/APIReference/API_ListRemediations.html) | List remediations for a finding | List |
| <a name="network-security-director-ListResources"></a>[ListResources](https://docs.aws.amazon.com/network-security-director/latest/APIReference/API_ListResources.html) | List resources | List |
