# Data retrieval APIs for AWS Snow Device Management
<a name="awssnowdevicemanagement"></a>

AWS Snow Device Management provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="snow-device-management-DescribeDevice"></a>[https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-describe-device](https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-describe-device) | Describe a remotely-managed device | Read |
| <a name="snow-device-management-DescribeDeviceEc2Instances"></a>[https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-describe-ec2-instances](https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-describe-ec2-instances) | Describe a remotely-managed device's EC2 instances | Read |
| <a name="snow-device-management-DescribeExecution"></a>[https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-describe-execution](https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-describe-execution) | Describe task executions | Read |
| <a name="snow-device-management-DescribeTask"></a>[https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-describe-task](https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-describe-task) | Describe a task | Read |
| <a name="snow-device-management-ListDeviceResources"></a>[https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-list-device-resources](https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-list-device-resources) | List a remotely-managed device's resources | List |
| <a name="snow-device-management-ListDevices"></a>[https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-list-devices](https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-list-devices) | List remotely-managed devices | List |
| <a name="snow-device-management-ListExecutions"></a>[https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-list-executions](https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-list-executions) | List task executions | List |
| <a name="snow-device-management-ListTagsForResource"></a>[https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-list-tags-for-resource](https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-list-tags-for-resource) | List the tags for a resource (device or task) | Read |
| <a name="snow-device-management-ListTasks"></a>[https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-list-tasks](https://docs.aws.amazon.com/snowball/latest/developer-guide/aws-sdm.html#sdm-cli-list-tasks) | List tasks | List |
