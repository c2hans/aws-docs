# Data retrieval APIs for AWS Free Tier
<a name="awsfreetier"></a>

AWS Free Tier provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="freetier-GetAccountActivity"></a>[https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_freetier_GetAccountActivity.html](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_freetier_GetAccountActivity.html) | Get a specific activity record | Read |
| <a name="freetier-GetAccountPlanState"></a>[https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_freetier_GetAccountPlanState.html](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_freetier_GetAccountPlanState.html) | Get all of the information related to the state of the account plan related to Free Tier | Read |
| <a name="freetier-GetFreeTierAlertPreference"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/tracking-free-tier-usage.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/tracking-free-tier-usage.html) | Get free tier alert preference (email address) | Read |
| <a name="freetier-GetFreeTierUsage"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/tracking-free-tier-usage.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/tracking-free-tier-usage.html) | Get free tier usage limits and MTD usage status | Read |
| <a name="freetier-ListAccountActivities"></a>[https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_freetier_ListAccountActivities.html](https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_freetier_ListAccountActivities.html) | List available activities | List |
