# Data retrieval APIs for AWS CodeStar
<a name="awscodestar"></a>

AWS CodeStar provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="codestar-DescribeProject"></a>[DescribeProject](https://docs.aws.amazon.com/codestar/latest/APIReference/API_DescribeProject.html) | Describe a project and its resources | Read |
| <a name="codestar-DescribeUserProfile"></a>[DescribeUserProfile](https://docs.aws.amazon.com/codestar/latest/APIReference/API_DescribeUserProfile.html) | Describe a user in AWS CodeStar and the user attributes across all projects | Read |
| <a name="codestar-GetExtendedAccess"></a>GetExtendedAccess | Extended read APIs | Read |
| <a name="codestar-ListProjects"></a>[ListProjects](https://docs.aws.amazon.com/codestar/latest/APIReference/API_ListProjects.html) | List all projects in CodeStar associated with your AWS account | List |
| <a name="codestar-ListResources"></a>[ListResources](https://docs.aws.amazon.com/codestar/latest/APIReference/API_ListResources.html) | List all resources associated with a project in CodeStar | List |
| <a name="codestar-ListTagsForProject"></a>[ListTagsForProject](https://docs.aws.amazon.com/codestar/latest/APIReference/API_ListTagsForProject.html) | List the tags associated with a project in CodeStar | List |
| <a name="codestar-ListTeamMembers"></a>[ListTeamMembers](https://docs.aws.amazon.com/codestar/latest/APIReference/API_ListTeamMembers.html) | List all team members associated with a project | List |
| <a name="codestar-ListUserProfiles"></a>[ListUserProfiles](https://docs.aws.amazon.com/codestar/latest/APIReference/API_ListUserProfiles.html) | List user profiles in AWS CodeStar | List |
| <a name="codestar-VerifyServiceRole"></a>VerifyServiceRole | Verify whether the AWS CodeStar service role exists in the customer's account | List |
