# Data retrieval APIs for AWS Elastic Load Balancing
<a name="awselasticloadbalancing"></a>

AWS Elastic Load Balancing provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="elasticloadbalancing-DescribeInstanceHealth"></a>[https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeInstanceHealth.html](https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeInstanceHealth.html) | Describe the state of the specified instances with respect to the specified load balancer | Read |
| <a name="elasticloadbalancing-DescribeLoadBalancerAttributes"></a>[https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerAttributes.html](https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerAttributes.html) | Describe the attributes for the specified load balancer | Read |
| <a name="elasticloadbalancing-DescribeLoadBalancerPolicies"></a>[https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerPolicies.html](https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerPolicies.html) | Describe the specified policies | Read |
| <a name="elasticloadbalancing-DescribeLoadBalancerPolicyTypes"></a>[https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerPolicyTypes.html](https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancerPolicyTypes.html) | Describe the specified load balancer policy types | Read |
| <a name="elasticloadbalancing-DescribeLoadBalancers"></a>[https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancers.html](https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeLoadBalancers.html) | Describe the specified the load balancers. If no load balancers are specified, the call describes all of your load balancers | List |
| <a name="elasticloadbalancing-DescribeTags"></a>[https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeTags.html](https://docs.aws.amazon.com/elasticloadbalancing/2012-06-01/APIReference/API_DescribeTags.html) | Describe the tags associated with the specified load balancers | Read |
