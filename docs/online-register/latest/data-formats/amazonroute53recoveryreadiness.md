# Data retrieval APIs for Amazon Route 53 Recovery Readiness
<a name="amazonroute53recoveryreadiness"></a>

Amazon Route 53 Recovery Readiness provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="route53-recovery-readiness-GetArchitectureRecommendations"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/recoverygroups-recoverygroupname-architecturerecommendations.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/recoverygroups-recoverygroupname-architecturerecommendations.html) | Get architecture recommendations for a recovery group | Read |
| <a name="route53-recovery-readiness-GetCell"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/cells-cellname.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/cells-cellname.html) | Get information about a cell | Read |
| <a name="route53-recovery-readiness-GetCellReadinessSummary"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/cellreadiness-cellname.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/cellreadiness-cellname.html) | Get a readiness summary for a cell | Read |
| <a name="route53-recovery-readiness-GetReadinessCheck"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/readinesschecks-readinesscheckname.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/readinesschecks-readinesscheckname.html) | Get information about a readiness check | Read |
| <a name="route53-recovery-readiness-GetReadinessCheckResourceStatus"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/readinesschecks-readinesscheckname-resource-resourceidentifier-status.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/readinesschecks-readinesscheckname-resource-resourceidentifier-status.html) | Get the readiness status for an individual resource | Read |
| <a name="route53-recovery-readiness-GetReadinessCheckStatus"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/readinesschecks-readinesscheckname-status.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/readinesschecks-readinesscheckname-status.html) | Get the status of a readiness check (for a resource set) | Read |
| <a name="route53-recovery-readiness-GetRecoveryGroup"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/recoverygroups-recoverygroupname.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/recoverygroups-recoverygroupname.html) | Get information about a recovery group | Read |
| <a name="route53-recovery-readiness-GetRecoveryGroupReadinessSummary"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/recoverygroupreadiness-recoverygroupname.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/recoverygroupreadiness-recoverygroupname.html) | Get a readiness summary for a recovery group | Read |
| <a name="route53-recovery-readiness-GetResourceSet"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/resourcesets-resourcesetname.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/resourcesets-resourcesetname.html) | Get information about a resource set | Read |
| <a name="route53-recovery-readiness-ListCells"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/cells.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/cells.html) | List cells | Read |
| <a name="route53-recovery-readiness-ListCrossAccountAuthorizations"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/crossaccountauthorizations.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/crossaccountauthorizations.html) | List cross account authorizations | Read |
| <a name="route53-recovery-readiness-ListReadinessChecks"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/readinesschecks.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/readinesschecks.html) | List readiness checks | Read |
| <a name="route53-recovery-readiness-ListRecoveryGroups"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/recoverygroups.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/recoverygroups.html) | List recovery groups | Read |
| <a name="route53-recovery-readiness-ListResourceSets"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/resourcesets.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/resourcesets.html) | List resource sets | Read |
| <a name="route53-recovery-readiness-ListRules"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/rules.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/rules.html) | List readiness rules | Read |
| <a name="route53-recovery-readiness-ListTagsForResources"></a>[https://docs.aws.amazon.com/recovery-readiness/latest/api/tags-resource-arn.html](https://docs.aws.amazon.com/recovery-readiness/latest/api/tags-resource-arn.html) | List tags for a resource | Read |
