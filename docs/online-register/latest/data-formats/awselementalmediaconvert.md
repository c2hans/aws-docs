# Data retrieval APIs for AWS Elemental MediaConvert
<a name="awselementalmediaconvert"></a>

AWS Elemental MediaConvert provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="mediaconvert-DescribeEndpoints"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/endpoints.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/endpoints.html) | Subscribe to the AWS Elemental MediaConvert service, by sending a request for an account-specific endpoint. All transcoding requests must be sent to the endpoint that the service returns | List |
| <a name="mediaconvert-GetJob"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobs-id.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobs-id.html) | Get an AWS Elemental MediaConvert job | Read |
| <a name="mediaconvert-GetJobTemplate"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobtemplates-name.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobtemplates-name.html) | Get an AWS Elemental MediaConvert job template | Read |
| <a name="mediaconvert-GetPolicy"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/policy.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/policy.html) | Get an AWS Elemental MediaConvert policy | Read |
| <a name="mediaconvert-GetPreset"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/presets-name.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/presets-name.html) | Get an AWS Elemental MediaConvert output preset | Read |
| <a name="mediaconvert-GetQueue"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/queues-name.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/queues-name.html) | Get an AWS Elemental MediaConvert job queue | Read |
| <a name="mediaconvert-ListJobTemplates"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobtemplates.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobtemplates.html) | List AWS Elemental MediaConvert job templates | List |
| <a name="mediaconvert-ListJobs"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobs.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/jobs.html) | List AWS Elemental MediaConvert jobs | List |
| <a name="mediaconvert-ListPresets"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/presets.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/presets.html) | List AWS Elemental MediaConvert output presets | List |
| <a name="mediaconvert-ListQueues"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/queues.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/queues.html) | List AWS Elemental MediaConvert job queues | List |
| <a name="mediaconvert-ListTagsForResource"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/tags-arn.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/tags-arn.html) | Retrieve the tags for a MediaConvert queue, preset, or job template | Read |
| <a name="mediaconvert-ListVersions"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/versions.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/versions.html) | List AWS Elemental MediaConvert job engine versions | List |
| <a name="mediaconvert-Probe"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/probe.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/probe.html) | Probe a file | Read |
| <a name="mediaconvert-SearchJobs"></a>[https://docs.aws.amazon.com/mediaconvert/latest/apireference/search.html](https://docs.aws.amazon.com/mediaconvert/latest/apireference/search.html) | Search AWS Elemental MediaConvert jobs | List |
