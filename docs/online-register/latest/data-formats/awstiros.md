# Data retrieval APIs for AWS Tiros
<a name="awstiros"></a>

AWS Tiros provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="tiros-GetQueryAnswer"></a>[GetQueryAnswer](https://docs.aws.amazon.com/vpc/latest/reachability/security_iam_required-API-permissions.html) | Get VPC reachability query answers | Read |
| <a name="tiros-GetQueryExplanation"></a>[GetQueryExplanation](https://docs.aws.amazon.com/vpc/latest/reachability/security_iam_required-API-permissions.html) | Get VPC reachability query explanations | Read |
| <a name="tiros-GetQueryExtensionAccounts"></a>[GetQueryExtensionAccounts](https://docs.aws.amazon.com/vpc/latest/reachability/security_iam_required-API-permissions.html) | List accounts that might be useful in a new query | Read |
