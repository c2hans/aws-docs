# Data retrieval APIs for AWS WorkSpaces Managed Instances
<a name="awsworkspacesmanagedinstances"></a>

AWS WorkSpaces Managed Instances provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="workspaces-instances-GetWorkspaceInstance"></a>[https://docs.aws.amazon.com/workspaces/latest/api/API_GetWorkspaceInstance.html](https://docs.aws.amazon.com/workspaces/latest/api/API_GetWorkspaceInstance.html) | Get details for a specific workspace managed instance in your account | Read |
| <a name="workspaces-instances-ListInstanceTypes"></a>[https://docs.aws.amazon.com/workspaces/latest/api/API_ListInstanceTypes.html](https://docs.aws.amazon.com/workspaces/latest/api/API_ListInstanceTypes.html) | List all supported instance types | List |
| <a name="workspaces-instances-ListRegions"></a>[https://docs.aws.amazon.com/workspaces/latest/api/API_ListRegions.html](https://docs.aws.amazon.com/workspaces/latest/api/API_ListRegions.html) | List all supported AWS regions | List |
| <a name="workspaces-instances-ListTagsForResource"></a>[https://docs.aws.amazon.com/workspaces/latest/api/API_ListTagsForResource.html](https://docs.aws.amazon.com/workspaces/latest/api/API_ListTagsForResource.html) | List user tags for resources in your account | List |
| <a name="workspaces-instances-ListWorkspaceInstances"></a>[https://docs.aws.amazon.com/workspaces/latest/api/API_ListWorkspaceInstances.html](https://docs.aws.amazon.com/workspaces/latest/api/API_ListWorkspaceInstances.html) | List workspace managed instances in your account | List |
