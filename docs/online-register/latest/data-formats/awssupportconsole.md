# Data retrieval APIs for AWS Support Console
<a name="awssupportconsole"></a>

AWS Support Console provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="support-console-CheckSubscription"></a>[${AuthZDocPage}](${AuthZDocPage}) | Check whether the account has access to given product | Read |
| <a name="support-console-DescribeDynamicHelp"></a>[${AuthZDocPage}](${AuthZDocPage}) | Get dynamic help resources for given service and category | Read |
| <a name="support-console-GetAccountGovCloudEnabled"></a>[${AuthZDocPage}](${AuthZDocPage}) | Determines whether the calling account is GovCloud enabled | Read |
| <a name="support-console-GetAccountState"></a>[${AuthZDocPage}](${AuthZDocPage}) | Get the state of the calling account | Read |
| <a name="support-console-GetBanner"></a>[${AuthZDocPage}](${AuthZDocPage}) | Get the support banner information | Read |
| <a name="support-console-GetCaseDraft"></a>[${AuthZDocPage}](${AuthZDocPage}) | Get a case draft for given case type | Read |
| <a name="support-console-GetIssueClassificationPredictions"></a>[${AuthZDocPage}](${AuthZDocPage}) | Get classification predictions of an issue | Read |
| <a name="support-console-GetIssueTextSummary"></a>[${AuthZDocPage}](${AuthZDocPage}) | Get a generated text summary of an issue | Read |
| <a name="support-console-GetQuestionnaire"></a>[${AuthZDocPage}](${AuthZDocPage}) | Get a feedback questionnaire | Read |
