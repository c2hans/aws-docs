# Data retrieval APIs for Amazon AI Operations
<a name="amazonaioperations"></a>

Amazon AI Operations provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="aiops-GetEphemeralInvestigationResults"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetEphemeralInvestigationResults.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetEphemeralInvestigationResults.html) | Run and retrieve ephemeral investigation results | List |
| <a name="aiops-GetFact"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetFact.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetFact.html) | Retrieve a fact in the specified investigation report | Read |
| <a name="aiops-GetFactVersions"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetFactVersions.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetFactVersions.html) | Retrieve all versions of a fact token in the specified investigation report | Read |
| <a name="aiops-GetInvestigation"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigation.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigation.html) | Retrieve an investigation in the specified investigation group | Read |
| <a name="aiops-GetInvestigationEvent"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationEvent.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationEvent.html) | Retrieve an investigation event in the specified investigation group | Read |
| <a name="aiops-GetInvestigationGroup"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationGroup.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationGroup.html) | Retrieve the specified investigation group | Read |
| <a name="aiops-GetInvestigationGroupPolicy"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationGroupPolicy.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationGroupPolicy.html) | Retrieve the investigation group policy attached to an investigation group | Read |
| <a name="aiops-GetInvestigationResource"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationResource.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetInvestigationResource.html) | Retrieve an investigation resource in the specified investigation group | Read |
| <a name="aiops-GetReport"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetReport.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_GetReport.html) | Retrieve a report in the specified investigation | Read |
| <a name="aiops-ListFacts"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListFacts.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListFacts.html) | List all facts in the specified investigation report | List |
| <a name="aiops-ListInvestigationEvents"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListInvestigationEvents.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListInvestigationEvents.html) | List all investigation events in the specified investigation group | List |
| <a name="aiops-ListInvestigationGroups"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListInvestigationGroups.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListInvestigationGroups.html) | List all investigation groups in the AWS account making the request | List |
| <a name="aiops-ListInvestigations"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListInvestigations.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListInvestigations.html) | List all investigations that are in the specified investigation group | List |
| <a name="aiops-ListReports"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListReports.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListReports.html) | List all reports in the specified investigation | List |
| <a name="aiops-ListTagsForResource"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListTagsForResource.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ListTagsForResource.html) | List the tags for the specified resource | List |
| <a name="aiops-ValidateInvestigationGroup"></a>[https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ValidateInvestigationGroup.html](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/API_ValidateInvestigationGroup.html) | Validate the specified investigation group | Read |
