# Data retrieval APIs for AWS Cloud Map
<a name="awscloudmap"></a>

AWS Cloud Map provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="servicediscovery-DiscoverInstances"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_DiscoverInstances.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_DiscoverInstances.html) | Discover registered instances for a specified namespace and service | Read |
| <a name="servicediscovery-DiscoverInstancesRevision"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_DiscoverInstancesRevision.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_DiscoverInstancesRevision.html) | Discover the revision of the instances for a specified namespace and service | Read |
| <a name="servicediscovery-GetInstance"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_GetInstance.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_GetInstance.html) | Get information about a specified instance | Read |
| <a name="servicediscovery-GetInstancesHealthStatus"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_GetInstancesHealthStatus.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_GetInstancesHealthStatus.html) | Get the current health status (Healthy, Unhealthy, or Unknown) of one or more instances | Read |
| <a name="servicediscovery-GetNamespace"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_GetNamespace.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_GetNamespace.html) | Get information about a namespace | Read |
| <a name="servicediscovery-GetOperation"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_GetOperation.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_GetOperation.html) | Get information about a specific operation | Read |
| <a name="servicediscovery-GetResourcePolicy"></a>[https://docs.aws.amazon.com/cloud-map/latest/dg/sharing-namespaces.html](https://docs.aws.amazon.com/cloud-map/latest/dg/sharing-namespaces.html) | Read the RAM access control policy for a namespace | Read |
| <a name="servicediscovery-GetService"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_GetService.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_GetService.html) | Get the settings for a specified service | Read |
| <a name="servicediscovery-GetServiceAttributes"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_GetServiceAttributes.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_GetServiceAttributes.html) | Get the attributes for a specified service | Read |
| <a name="servicediscovery-ListInstances"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_ListInstances.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_ListInstances.html) | Get summary information about the instances that were registered with a specified service | Read |
| <a name="servicediscovery-ListNamespaces"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_ListNamespaces.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_ListNamespaces.html) | Get information about the namespaces | Read |
| <a name="servicediscovery-ListOperations"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_ListOperations.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_ListOperations.html) | List operations that match the criteria that you specify | List |
| <a name="servicediscovery-ListServices"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_ListServices.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_ListServices.html) | Get settings for all the services that match specified filters | Read |
| <a name="servicediscovery-ListTagsForResource"></a>[https://docs.aws.amazon.com/cloud-map/latest/api/API_ListTagsForResource.html](https://docs.aws.amazon.com/cloud-map/latest/api/API_ListTagsForResource.html) | Lists tags for the specified resource | Read |
