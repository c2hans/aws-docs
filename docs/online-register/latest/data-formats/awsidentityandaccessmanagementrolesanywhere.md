# Data retrieval APIs for AWS Identity and Access Management Roles Anywhere
<a name="awsidentityandaccessmanagementrolesanywhere"></a>

AWS Identity and Access Management Roles Anywhere provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="rolesanywhere-GetCrl"></a>[https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetCrl.html](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetCrl.html) | Get a certificate revocation list (crl) | Read |
| <a name="rolesanywhere-GetProfile"></a>[https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetProfile.html](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetProfile.html) | Get a profile | Read |
| <a name="rolesanywhere-GetSubject"></a>[https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetSubject.html](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetSubject.html) | Get a subject | Read |
| <a name="rolesanywhere-GetTrustAnchor"></a>[https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetTrustAnchor.html](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_GetTrustAnchor.html) | Get a trust anchor | Read |
| <a name="rolesanywhere-ListCrls"></a>[https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListCrls.html](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListCrls.html) | List certificate revocation lists (crls) | List |
| <a name="rolesanywhere-ListProfiles"></a>[https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListProfiles.html](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListProfiles.html) | List profiles | List |
| <a name="rolesanywhere-ListSubjects"></a>[https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListSubjects.html](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListSubjects.html) | List subjects | List |
| <a name="rolesanywhere-ListTagsForResource"></a>[https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListTagsForResource.html](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | List |
| <a name="rolesanywhere-ListTrustAnchors"></a>[https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListTrustAnchors.html](https://docs.aws.amazon.com/rolesanywhere/latest/APIReference/API_ListTrustAnchors.html) | List trust anchors | List |
