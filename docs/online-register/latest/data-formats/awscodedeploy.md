# Data retrieval APIs for AWS CodeDeploy
<a name="awscodedeploy"></a>

AWS CodeDeploy provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="codedeploy-BatchGetApplicationRevisions"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_BatchGetApplicationRevisions.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_BatchGetApplicationRevisions.html) | Get information about one or more application revisions | Read |
| <a name="codedeploy-BatchGetApplications"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_BatchGetApplications.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_BatchGetApplications.html) | Get information about multiple applications associated with the IAM user | Read |

This method works with all compute types and should be used instead of the deprecated BatchGetDeploymentInstances. The maximum number of targets that can be returned is 25 | Read |
| <a name="codedeploy-BatchGetDeployments"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_BatchGetDeployments.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_BatchGetDeployments.html) | Get information about multiple deployments associated with the IAM user | Read |
| <a name="codedeploy-BatchGetOnPremisesInstances"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_BatchGetOnPremisesInstances.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_BatchGetOnPremisesInstances.html) | Get information about one or more on-premises instances | Read |
| <a name="codedeploy-GetApplication"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_GetApplication.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_GetApplication.html) | Get information about a single application associated with the IAM user | List |

| <a name="codedeploy-GetDeploymentGroup"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_GetDeploymentGroup.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_GetDeploymentGroup.html) | Get information about a single deployment group for an application associated with the IAM user | List |

| <a name="codedeploy-GetOnPremisesInstance"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_GetOnPremisesInstance.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_GetOnPremisesInstance.html) | Get information about a single on-premises instance | List |

| <a name="codedeploy-ListDeploymentConfigs"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_ListDeploymentConfigs.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_ListDeploymentConfigs.html) | Get information about all deployment configurations associated with the IAM user | List |
| <a name="codedeploy-ListDeploymentGroups"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_ListDeploymentGroups.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_ListDeploymentGroups.html) | Get information about all deployment groups for an application associated with the IAM user | List |
| <a name="codedeploy-ListDeploymentInstances"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_ListDeploymentInstances.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_ListDeploymentInstances.html) | Get information about all instances in a deployment associated with the IAM user | List |
| <a name="codedeploy-ListDeploymentTargets"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_ListDeploymentTargets.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_ListDeploymentTargets.html) | Return an array of target IDs that are associated a deployment | List |

| <a name="codedeploy-ListOnPremisesInstances"></a>[https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_ListOnPremisesInstances.html](https://docs.aws.amazon.com/codedeploy/latest/APIReference/API_ListOnPremisesInstances.html) | Get a list of one or more on-premises instance names | List |
