# Data retrieval APIs for Amazon Location Service Routes
<a name="amazonlocationserviceroutes"></a>

Amazon Location Service Routes provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="geo-routes-CalculateIsolines"></a>[https://docs.aws.amazon.com/location/latest/APIReference/API_CalculateIsolines.html](https://docs.aws.amazon.com/location/latest/APIReference/API_CalculateIsolines.html) | Determine destinations or service areas reachable within a specified time | Read |
| <a name="geo-routes-CalculateRouteMatrix"></a>[https://docs.aws.amazon.com/location/latest/APIReference/API_CalculateRouteMatrix.html](https://docs.aws.amazon.com/location/latest/APIReference/API_CalculateRouteMatrix.html) | Calculate routing matrice which providing travel time and distances between sets of origins and destinations | Read |
| <a name="geo-routes-CalculateRoutes"></a>[https://docs.aws.amazon.com/location/latest/APIReference/API_CalculateRoutes.html](https://docs.aws.amazon.com/location/latest/APIReference/API_CalculateRoutes.html) | Calculates routes between two or more locations | Read |
| <a name="geo-routes-OptimizeWaypoints"></a>[https://docs.aws.amazon.com/location/latest/APIReference/API_OptimizeWaypoints.html](https://docs.aws.amazon.com/location/latest/APIReference/API_OptimizeWaypoints.html) | Calculate the most efficient sequence for visiting multiple waypoints or locations along a route | Read |
| <a name="geo-routes-SnapToRoads"></a>[https://docs.aws.amazon.com/location/latest/APIReference/API_SnapToRoads.html](https://docs.aws.amazon.com/location/latest/APIReference/API_SnapToRoads.html) | Enhances the accuracy of geographic positioning by aligning GPS coordinates to the nearest road segments on a digital map | Read |
