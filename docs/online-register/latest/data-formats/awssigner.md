# Data retrieval APIs for AWS Signer
<a name="awssigner"></a>

AWS Signer provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="signer-DescribeSigningJob"></a>[https://docs.aws.amazon.com/signer/latest/api/API_DescribeSigningJob.html](https://docs.aws.amazon.com/signer/latest/api/API_DescribeSigningJob.html) | Return information about a specific Signing Job | Read |
| <a name="signer-GetRevocationStatus"></a>[https://docs.aws.amazon.com/signer/latest/api/API_GetRevocationStatus.html](https://docs.aws.amazon.com/signer/latest/api/API_GetRevocationStatus.html) | Query revocation info of signing resources | Read |
| <a name="signer-GetSigningPlatform"></a>[https://docs.aws.amazon.com/signer/latest/api/API_GetSigningPlatform.html](https://docs.aws.amazon.com/signer/latest/api/API_GetSigningPlatform.html) | Return information about a specific Signing Platform | Read |
| <a name="signer-GetSigningProfile"></a>[https://docs.aws.amazon.com/signer/latest/api/API_GetSigningProfile.html](https://docs.aws.amazon.com/signer/latest/api/API_GetSigningProfile.html) | Return information about a specific Signing Profile | Read |
| <a name="signer-ListProfilePermissions"></a>[https://docs.aws.amazon.com/signer/latest/api/API_ListProfilePermissions.html](https://docs.aws.amazon.com/signer/latest/api/API_ListProfilePermissions.html) | List the cross-account permissions associated with a Signing Profile | Read |
| <a name="signer-ListSigningJobs"></a>[https://docs.aws.amazon.com/signer/latest/api/API_ListSigningJobs.html](https://docs.aws.amazon.com/signer/latest/api/API_ListSigningJobs.html) | List all Signing Jobs in your account | List |
| <a name="signer-ListSigningPlatforms"></a>[https://docs.aws.amazon.com/signer/latest/api/API_ListSigningPlatforms.html](https://docs.aws.amazon.com/signer/latest/api/API_ListSigningPlatforms.html) | List all available Signing Platforms | List |
| <a name="signer-ListSigningProfiles"></a>[https://docs.aws.amazon.com/signer/latest/api/API_ListSigningProfiles.html](https://docs.aws.amazon.com/signer/latest/api/API_ListSigningProfiles.html) | List all Signing Profiles in your account | List |
| <a name="signer-ListTagsForResource"></a>[https://docs.aws.amazon.com/signer/latest/api/API_ListTagsForResource.html](https://docs.aws.amazon.com/signer/latest/api/API_ListTagsForResource.html) | List the tags associated with a Signing Profile | Read |
