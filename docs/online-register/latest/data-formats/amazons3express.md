# Data retrieval APIs for Amazon S3 Express
<a name="amazons3express"></a>

Amazon S3 Express provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="s3express-GetAccessPoint"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_control_GetAccessPoint.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_control_GetAccessPoint.html) | Return configuration information about the specified access point | Read |
| <a name="s3express-GetAccessPointPolicy"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_control_GetAccessPointPolicy.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_control_GetAccessPointPolicy.html) | Return the access point policy associated with the specified access point | Read |
| <a name="s3express-GetAccessPointScope"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_control_GetAccessPointScope.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_control_GetAccessPointScope.html) | Return the scope configuration associated with the specified access point | Read |
| <a name="s3express-GetBucketPolicy"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetBucketPolicy.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetBucketPolicy.html) | Return the policy of the specified bucket | Read |
| <a name="s3express-GetEncryptionConfiguration"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetBucketEncryption.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetBucketEncryption.html) | Return the default encryption configuration for a directory bucket | Read |
| <a name="s3express-GetInventoryConfiguration"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetBucketInventoryConfiguration.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetBucketInventoryConfiguration.html) | Return an inventory configuration identified by the inventory configuration ID for a S3 directory bucket | Read |
| <a name="s3express-GetLifecycleConfiguration"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetBucketLifecycleConfiguration.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetBucketLifecycleConfiguration.html) | Return the lifecycle configuration information set on a directory bucket | Read |
| <a name="s3express-GetMetricsConfiguration"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetBucketMetricsConfiguration.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetBucketMetricsConfiguration.html) | Get a metrics configuration of a directory bucket | Read |
| <a name="s3express-ListAccessPointsForDirectoryBuckets"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_control_ListAccessPointsForDirectoryBuckets.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_control_ListAccessPointsForDirectoryBuckets.html) | List access points | List |
| <a name="s3express-ListAllMyDirectoryBuckets"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListDirectoryBuckets.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListDirectoryBuckets.html) | List all directory buckets owned by the authenticated sender of the request | List |
| <a name="s3express-ListTagsForResource"></a>[https://docs.aws.amazon.com/AmazonS3/latest/API/API_control_ListTagsForResource.html](https://docs.aws.amazon.com/AmazonS3/latest/API/API_control_ListTagsForResource.html) | Lists all of the tags for a specified resource | List |
