# Data retrieval APIs for Tag Editor
<a name="tageditor"></a>

Tag Editor provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="resource-explorer-ListResourceTypes"></a>[ListResourceTypes](https://docs.aws.amazon.com/ARG/latest/userguide/gettingstarted-prereqs.html#rg-permissions-te) | Retrieve the resource types currently supported by Tag Editor | List |
| <a name="resource-explorer-ListResources"></a>[ListResources](https://docs.aws.amazon.com/ARG/latest/userguide/gettingstarted-prereqs.html#rg-permissions-te) | Retrieve the identifiers of the resources in the AWS account | List |
| <a name="resource-explorer-ListTags"></a>[ListTags](https://docs.aws.amazon.com/ARG/latest/userguide/gettingstarted-prereqs.html#rg-permissions-te) | Retrieve the tags attached to the specified resource identifiers | Read |
