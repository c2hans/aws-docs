# Data retrieval APIs for AWS Marketplace Vendor Insights
<a name="awsmarketplacevendorinsights"></a>

AWS Marketplace Vendor Insights provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="vendor-insights-GetDataSource"></a>[GetDataSource](https://docs.aws.amazon.com/marketplace/latest/userguide/vendor-insights-seller-controlling-access.html) | Retrieve the details of an existing data source | Read |
| <a name="vendor-insights-GetEntitledSecurityProfileSnapshot"></a>[GetEntitledSecurityProfileSnapshot](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.html) | Return the details of a security profile snapshot that requester is entitled to read | Read |
| <a name="vendor-insights-GetProfileAccessTerms"></a>[GetProfileAccessTerms](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.html) | Get the access terms for a vendor insights profile | Read |
| <a name="vendor-insights-GetSecurityProfile"></a>[GetSecurityProfile](https://docs.aws.amazon.com/marketplace/latest/userguide/vendor-insights-seller-controlling-access.html) | Return the details of an existing security profile | Read |
| <a name="vendor-insights-GetSecurityProfileSnapshot"></a>[GetSecurityProfileSnapshot](https://docs.aws.amazon.com/marketplace/latest/userguide/vendor-insights-seller-controlling-access.html) | Return the details of a security profile snapshot | Read |
| <a name="vendor-insights-ListDataSources"></a>[ListDataSources](https://docs.aws.amazon.com/marketplace/latest/userguide/vendor-insights-seller-controlling-access.html) | List existing data sources | List |
| <a name="vendor-insights-ListEntitledSecurityProfileSnapshots"></a>[ListEntitledSecurityProfileSnapshots](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.html) | Return the snapshot summary list for an existing security profile that requester is entitled to list | List |
| <a name="vendor-insights-ListEntitledSecurityProfiles"></a>[ListEntitledSecurityProfiles](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-vendor-insights-controlling-access.html) | List entitled security profiles | List |
| <a name="vendor-insights-ListSecurityProfileSnapshots"></a>[ListSecurityProfileSnapshots](https://docs.aws.amazon.com/marketplace/latest/userguide/vendor-insights-seller-controlling-access.html) | Return the snapshot summary list for an existing security profile | List |
| <a name="vendor-insights-ListSecurityProfiles"></a>[ListSecurityProfiles](https://docs.aws.amazon.com/marketplace/latest/userguide/vendor-insights-seller-controlling-access.html) | List existing security profiles | List |
| <a name="vendor-insights-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/marketplace/latest/userguide/vendor-insights-seller-controlling-access.html) | List tags for vendor insights resource | Read |
