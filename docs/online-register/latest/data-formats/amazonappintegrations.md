# Data retrieval APIs for Amazon AppIntegrations
<a name="amazonappintegrations"></a>

Amazon AppIntegrations provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="app-integrations-GetApplication"></a>[GetApplication](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_GetApplication.html) | View details about Application | Read |
| <a name="app-integrations-GetDataIntegration"></a>[GetDataIntegration](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_GetDataIntegration.html) | View details about DataIntegrations | Read |
| <a name="app-integrations-GetDataIntegrationExecution"></a>[GetDataIntegrationExecution](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_GetDataIntegrationExecution.html) | Get details about a data integration execution | Read |
| <a name="app-integrations-GetDataIntegrationSchedule"></a>[GetDataIntegrationSchedule](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_GetDataIntegrationSchedule.html) | Get details about a data integration schedule | Read |
| <a name="app-integrations-GetEventIntegration"></a>[GetEventIntegration](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_GetEventIntegration.html) | View details about EventIntegrations | Read |
| <a name="app-integrations-ListApplicationAssociations"></a>[ListApplicationAssociations](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_ListApplicationAssociations.html) | List ApplicationAssociations | List |
| <a name="app-integrations-ListApplications"></a>[ListApplications](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_ListApplications.html) | List Applications | List |
| <a name="app-integrations-ListDataIntegrationAssociations"></a>[ListDataIntegrationAssociations](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_ListDataIntegrationAssociations.html) | List DataIntegrationAssociations | List |
| <a name="app-integrations-ListDataIntegrationExecutions"></a>[ListDataIntegrationExecutions](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_ListDataIntegrationExecutions.html) | List data integration executions | List |
| <a name="app-integrations-ListDataIntegrationSchedules"></a>[ListDataIntegrationSchedules](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_ListDataIntegrationSchedules.html) | List data integration schedules | List |
| <a name="app-integrations-ListDataIntegrations"></a>[ListDataIntegrations](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_ListDataIntegrations.html) | List DataIntegrations | List |
| <a name="app-integrations-ListEventIntegrationAssociations"></a>[ListEventIntegrationAssociations](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_ListEventIntegrationAssociations.html) | List EventIntegrationAssociations | Read |
| <a name="app-integrations-ListEventIntegrations"></a>[ListEventIntegrations](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_ListEventIntegrations.html) | List EventIntegrations | List |
| <a name="app-integrations-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/appintegrations/latest/APIReference/API_ListTagsForResource.html) | Lists tag for an Amazon AppIntegration resource | Read |
