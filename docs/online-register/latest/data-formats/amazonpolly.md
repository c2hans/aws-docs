# Data retrieval APIs for Amazon Polly
<a name="amazonpolly"></a>

Amazon Polly provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="polly-DescribeVoices"></a>[DescribeVoices](https://docs.aws.amazon.com/polly/latest/dg/API_DescribeVoices.html) | Describe the list of voices that are available for use when requesting speech synthesis | List |
| <a name="polly-GetLexicon"></a>[GetLexicon](https://docs.aws.amazon.com/polly/latest/dg/API_GetLexicon.html) | Retrieve the content of the specified pronunciation lexicon stored in an AWS Region | Read |
| <a name="polly-GetSpeechSynthesisTask"></a>[GetSpeechSynthesisTask](https://docs.aws.amazon.com/polly/latest/dg/API_GetSpeechSynthesisTask.html) | Get information about specific speech synthesis task | Read |
| <a name="polly-ListLexicons"></a>[ListLexicons](https://docs.aws.amazon.com/polly/latest/dg/API_ListLexicons.html) | List the pronunciation lexicons stored in an AWS Region | List |
| <a name="polly-ListSpeechSynthesisTasks"></a>[ListSpeechSynthesisTasks](https://docs.aws.amazon.com/polly/latest/dg/API_ListSpeechSynthesisTasks.html) | List requested speech synthesis tasks | List |
| <a name="polly-StartSpeechSynthesisStream"></a>[StartSpeechSynthesisStream](https://docs.aws.amazon.com/polly/latest/dg/API_StartSpeechSynthesisStream.html) | Perform synthesis with bidirectional streaming | Read |
| <a name="polly-SynthesizeSpeech"></a>[SynthesizeSpeech](https://docs.aws.amazon.com/polly/latest/dg/API_SynthesizeSpeech.html) | Synthesize speech | Read |
