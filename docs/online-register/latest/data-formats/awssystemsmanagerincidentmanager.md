# Data retrieval APIs for AWS Systems Manager Incident Manager

AWS Systems Manager Incident Manager provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |

| <a name="ssm-incidents-GetIncidentRecord"></a>[https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetIncidentRecord.html](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetIncidentRecord.html) | View the contents of an incident record | Read |
| <a name="ssm-incidents-GetReplicationSet"></a>[https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetReplicationSet.html](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetReplicationSet.html) | View the replication set | Read |
| <a name="ssm-incidents-GetResourcePolicies"></a>[https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetResourcePolicies.html](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetResourcePolicies.html) | View resource policies of a response plan | Read |
| <a name="ssm-incidents-GetResponsePlan"></a>[https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetResponsePlan.html](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetResponsePlan.html) | View the contents of a specified response plan | Read |
| <a name="ssm-incidents-GetTimelineEvent"></a>[https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetTimelineEvent.html](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_GetTimelineEvent.html) | View a timeline event | Read |
| <a name="ssm-incidents-ListIncidentFindings"></a>[https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListIncidentFindings.html](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListIncidentFindings.html) | List findings for an incident record | List |
| <a name="ssm-incidents-ListIncidentRecords"></a>[https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListIncidentRecords.html](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListIncidentRecords.html) | List the contents of all incident records | List |
| <a name="ssm-incidents-ListRelatedItems"></a>[https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListRelatedItems.html](https://docs.aws.amazon.com/incident-manager/latest/APIReference/API_ListRelatedItems.html) | List related items of an incident record | List |
