| <a name="cases-GetCaseAuditEvents"></a>[https://docs.aws.amazon.com/cases/latest/APIReference/API_GetCaseAuditEvents.html](https://docs.aws.amazon.com/cases/latest/APIReference/API_GetCaseAuditEvents.html) | View audit history of a case | Read |
| <a name="cases-GetCaseEventConfiguration"></a>[https://docs.aws.amazon.com/cases/latest/APIReference/API_GetCaseEventConfiguration.html](https://docs.aws.amazon.com/cases/latest/APIReference/API_GetCaseEventConfiguration.html) | Retrieve information about the case event configuraton in the case domain | Read |

| <a name="cases-ListCaseRules"></a>[https://docs.aws.amazon.com/cases/latest/APIReference/API_ListCaseRules.html](https://docs.aws.amazon.com/cases/latest/APIReference/API_ListCaseRules.html) | List case rules in the case domain | List |
