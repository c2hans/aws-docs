| <a name="textract-DetectDocumentText"></a>[https://docs.aws.amazon.com/textract/latest/dg/API_DetectDocumentText.html](https://docs.aws.amazon.com/textract/latest/dg/API_DetectDocumentText.html) | Detect text in document images | Read |

| <a name="textract-GetExpenseAnalysis"></a>[https://docs.aws.amazon.com/textract/latest/dg/API_GetExpenseAnalysis.html](https://docs.aws.amazon.com/textract/latest/dg/API_GetExpenseAnalysis.html) | Return information about an expense analysis job | Read |
