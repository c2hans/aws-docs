| <a name="transcribe-GetMedicalScribeJob"></a>[https://docs.aws.amazon.com/transcribe/latest/dg/API_GetMedicalScribeJob.html](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetMedicalScribeJob.html) | Return information about a Medical Scribe job | Read |

| <a name="transcribe-GetTranscriptionJob"></a>[https://docs.aws.amazon.com/transcribe/latest/dg/API_GetTranscriptionJob.html](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetTranscriptionJob.html) | Return information about a transcription job | Read |
| <a name="transcribe-GetVocabulary"></a>[https://docs.aws.amazon.com/transcribe/latest/dg/API_GetVocabulary.html](https://docs.aws.amazon.com/transcribe/latest/dg/API_GetVocabulary.html) | To get information about a vocabulary | Read |
