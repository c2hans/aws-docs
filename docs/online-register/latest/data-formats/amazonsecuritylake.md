# Data retrieval APIs for Amazon Security Lake
<a name="amazonsecuritylake"></a>

Amazon Security Lake provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="securitylake-GetDataLakeExceptionSubscription"></a>[https://docs.aws.amazon.com/security-lake/latest/APIReference/API_GetDataLakeExceptionSubscription.html](https://docs.aws.amazon.com/security-lake/latest/APIReference/API_GetDataLakeExceptionSubscription.html) | Query the protocol and endpoint that were provided when subscribing to SNS topics for exception notifications | Read |
| <a name="securitylake-GetDataLakeOrganizationConfiguration"></a>[https://docs.aws.amazon.com/security-lake/latest/APIReference/API_GetDataLakeOrganizationConfiguration.html](https://docs.aws.amazon.com/security-lake/latest/APIReference/API_GetDataLakeOrganizationConfiguration.html) | Get an organization's configuration setting for automatically enabling Amazon Security Lake access for new organization accounts | Read |
| <a name="securitylake-GetDataLakeSources"></a>[https://docs.aws.amazon.com/security-lake/latest/APIReference/API_GetDataLakeSources.html](https://docs.aws.amazon.com/security-lake/latest/APIReference/API_GetDataLakeSources.html) | Get a static snapshot of the security data lake in the current region. The snapshot includes enabled accounts and log sources | Read |
| <a name="securitylake-GetSubscriber"></a>[https://docs.aws.amazon.com/security-lake/latest/APIReference/API_GetSubscriber.html](https://docs.aws.amazon.com/security-lake/latest/APIReference/API_GetSubscriber.html) | Get information about subscriber that is already created | Read |
| <a name="securitylake-ListDataLakeExceptions"></a>[https://docs.aws.amazon.com/security-lake/latest/APIReference/API_ListDataLakeExceptions.html](https://docs.aws.amazon.com/security-lake/latest/APIReference/API_ListDataLakeExceptions.html) | Get the list of all non-retryable failures | List |
| <a name="securitylake-ListDataLakes"></a>[https://docs.aws.amazon.com/security-lake/latest/APIReference/API_ListDataLakes.html](https://docs.aws.amazon.com/security-lake/latest/APIReference/API_ListDataLakes.html) | List information about the security data lakes | List |
| <a name="securitylake-ListLogSources"></a>[https://docs.aws.amazon.com/security-lake/latest/APIReference/API_ListLogSources.html](https://docs.aws.amazon.com/security-lake/latest/APIReference/API_ListLogSources.html) | View the enabled accounts. You can view the enabled sources in the enabled regions | List |
| <a name="securitylake-ListSubscribers"></a>[https://docs.aws.amazon.com/security-lake/latest/APIReference/API_ListSubscribers.html](https://docs.aws.amazon.com/security-lake/latest/APIReference/API_ListSubscribers.html) | List all subscribers | List |
| <a name="securitylake-ListTagsForResource"></a>[https://docs.aws.amazon.com/security-lake/latest/APIReference/API_ListTagsForResource.html](https://docs.aws.amazon.com/security-lake/latest/APIReference/API_ListTagsForResource.html) | List all tags for the resource | List |
