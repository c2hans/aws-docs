| <a name="managedblockchain-GetNetwork"></a>[https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_GetNetwork.html](https://docs.aws.amazon.com/managed-blockchain/latest/APIReference/API_GetNetwork.html) | Return detailed information about an Amazon Managed Blockchain network | Read |
