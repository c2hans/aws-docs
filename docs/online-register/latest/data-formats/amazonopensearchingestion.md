# Data retrieval APIs for Amazon OpenSearch Ingestion
<a name="amazonopensearchingestion"></a>

Amazon OpenSearch Ingestion provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="osis-GetPipeline"></a>[https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_GetPipeline.html](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_GetPipeline.html) | Retrieve configuration information for an OpenSearch Ingestion pipeline | Read |
| <a name="osis-GetPipelineBlueprint"></a>[https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_GetPipelineBlueprint.html](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_GetPipelineBlueprint.html) | Get the contents of an OpenSearch Ingestion pipeline blueprint | Read |
| <a name="osis-GetPipelineChangeProgress"></a>[https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_GetPipelineChangeProgress.html](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_GetPipelineChangeProgress.html) | Get granular information about the status of an OpenSearch Ingestion pipeline | Read |
| <a name="osis-GetResourcePolicy"></a>[https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_GetResourcePolicy.html](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_GetResourcePolicy.html) | Get a resource policy for an OpenSearch Ingestion resource | Read |
| <a name="osis-ListPipelineBlueprints"></a>[https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ListPipelineBlueprints.html](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ListPipelineBlueprints.html) | List the names of available blueprints for an OpenSearch Ingestion pipeline configuration | List |
| <a name="osis-ListPipelineEndpointConnections"></a>[https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ListPipelineEndpointConnections.html](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ListPipelineEndpointConnections.html) | List OpenSearch Ingestion pipeline endpoint connections to pipelines in the current account | List |
| <a name="osis-ListPipelineEndpoints"></a>[https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ListPipelineEndpoints.html](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ListPipelineEndpoints.html) | List OpenSearch Ingestion pipeline endpoints in the current account | List |
| <a name="osis-ListPipelines"></a>[https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ListPipelines.html](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ListPipelines.html) | List basic configuration for each OpenSearch Ingestion pipeline in the current account and Region | List |
| <a name="osis-ListTagsForResource"></a>[https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ListTagsForResource.html](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ListTagsForResource.html) | List all resource tags associated with an OpenSearch Ingestion pipeline | Read |
| <a name="osis-ValidatePipeline"></a>[https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ValidatePipeline.html](https://docs.aws.amazon.com/opensearch-service/latest/APIReference/API_osis_ValidatePipeline.html) | Validate the configuration of an OpenSearch Ingestion pipeline | Read |
