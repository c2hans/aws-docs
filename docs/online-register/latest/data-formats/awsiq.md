# Data retrieval APIs for AWS IQ
<a name="awsiq"></a>

AWS IQ provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="iq-DownloadAttachment"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Download existing attachment | Read |
| <a name="iq-GetBuyer"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read buyer information | Read |
| <a name="iq-GetCall"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read details of a voice/video call | Read |
| <a name="iq-GetChatInfo"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read the chat environment details about a conversation | Read |
| <a name="iq-GetChatMessages"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read chat messages in a conversation | Read |
| <a name="iq-GetChatToken"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Request a websocket token for the conversation notifications | Read |
| <a name="iq-GetCompanyChatMessages"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read chat messages in a company conversation | Read |
| <a name="iq-GetCompanyProfile"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read a company profile | Read |
| <a name="iq-GetConversation"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read details of a conversation | Read |
| <a name="iq-GetExpert"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read expert information | Read |
| <a name="iq-GetListing"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read a listing | Read |
| <a name="iq-GetMarketplaceSeller"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read a seller profile information | Read |
| <a name="iq-GetPaymentRequest"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read a payment request | Read |
| <a name="iq-GetProposal"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read a proposal | Read |
| <a name="iq-GetRequest"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Get a created request | Read |
| <a name="iq-GetReview"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | Read a review for an expert | Read |
| <a name="iq-ListAttachments"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | List existing attachments | List |
| <a name="iq-ListConversations"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | List existing conversations | Read |
| <a name="iq-ListExpertAccessLogs"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | List access logs of expert activity | Read |
| <a name="iq-ListListings"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | List listings | Read |
| <a name="iq-ListPaymentRequests"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | List payment requests | Read |
| <a name="iq-ListProposals"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | List proposals | Read |
| <a name="iq-ListRequests"></a>[https://aws.amazon.com/iq/](https://aws.amazon.com/iq/) | List requests that are created | Read |
