# Data retrieval APIs for Amazon Interactive Video Service Chat
<a name="amazoninteractivevideoservicechat"></a>

Amazon Interactive Video Service Chat provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="ivschat-GetLoggingConfiguration"></a>[https://docs.aws.amazon.com/ivs/latest/ChatAPIReference/API_GetLoggingConfiguration.html](https://docs.aws.amazon.com/ivs/latest/ChatAPIReference/API_GetLoggingConfiguration.html) | Get the logging configuration for a specified logging configuration ARN | Read |
| <a name="ivschat-GetRoom"></a>[https://docs.aws.amazon.com/ivs/latest/ChatAPIReference/API_GetRoom.html](https://docs.aws.amazon.com/ivs/latest/ChatAPIReference/API_GetRoom.html) | Get the room configuration for a specified room ARN | Read |
| <a name="ivschat-ListLoggingConfigurations"></a>[https://docs.aws.amazon.com/ivs/latest/ChatAPIReference/API_ListLoggingConfigurations.html](https://docs.aws.amazon.com/ivs/latest/ChatAPIReference/API_ListLoggingConfigurations.html) | Get summary information about logging configurations | List |
| <a name="ivschat-ListRooms"></a>[https://docs.aws.amazon.com/ivs/latest/ChatAPIReference/API_ListRooms.html](https://docs.aws.amazon.com/ivs/latest/ChatAPIReference/API_ListRooms.html) | Get summary information about rooms | List |
| <a name="ivschat-ListTagsForResource"></a>[https://docs.aws.amazon.com/ivs/latest/ChatAPIReference/API_ListTagsForResource.html](https://docs.aws.amazon.com/ivs/latest/ChatAPIReference/API_ListTagsForResource.html) | Get information about the tags for a specified ARN | Read |
