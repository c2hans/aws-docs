# Data retrieval APIs for AWS Support Authorization
<a name="awssupportauthorization"></a>

AWS Support Authorization provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="supportauthz-GetAction"></a>[https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_GetAction.html](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_GetAction.html) | Retrieve details about a support action | Read |
| <a name="supportauthz-GetSupportPermit"></a>[https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_GetSupportPermit.html](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_GetSupportPermit.html) | Retrieve a support permit | Read |
| <a name="supportauthz-ListActions"></a>[https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListActions.html](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListActions.html) | List available support actions | List |
| <a name="supportauthz-ListSupportPermitRequests"></a>[https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListSupportPermitRequests.html](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListSupportPermitRequests.html) | List support permit requests | List |
| <a name="supportauthz-ListSupportPermits"></a>[https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListSupportPermits.html](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListSupportPermits.html) | List support permits | List |
| <a name="supportauthz-ListTagsForResource"></a>[https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListTagsForResource.html](https://docs.aws.amazon.com/supportauthz/latest/APIReference/API_ListTagsForResource.html) | List tags for a resource | Read |
