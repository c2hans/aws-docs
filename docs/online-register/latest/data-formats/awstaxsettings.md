# Data retrieval APIs for AWS Tax Settings
<a name="awstaxsettings"></a>

AWS Tax Settings provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="tax-GetDocument"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | Retrieve documents such as withholding slips | Read |
| <a name="tax-GetDocumentUploadUrl"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | Retrieve a generated URL to upload documents | Read |
| <a name="tax-GetExemptions"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View tax exemptions data | Read |
| <a name="tax-GetTaxInfoReportingDocument"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View/download tax documents/forms | Read |
| <a name="tax-GetTaxInheritance"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View tax inheritance status | Read |
| <a name="tax-GetTaxInterview"></a>[https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html) | Retrieve tax interview data | Read |
| <a name="tax-GetTaxRegistration"></a>[https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html) | View tax registrations data | Read |
| <a name="tax-GetTaxRegistrationDocument"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | Download tax registration documents | Read |
| <a name="tax-ListDocuments"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View documents such as withholding slips | Read |
| <a name="tax-ListSupplementalTaxRegistrations"></a>[https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html](https://docs.aws.amazon.com/marketplace/latest/userguide/detailed-management-portal-permissions.html) | View supplemental tax registrations | Read |
| <a name="tax-ListTaxRegistrations"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View tax registrations | Read |
| <a name="tax-ListWithholdingEligibleInvoices"></a>[https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html) | View eligible withholding invoices | Read |
