# Data retrieval APIs for AWS Systems Manager Quick Setup
<a name="awssystemsmanagerquicksetup"></a>

AWS Systems Manager Quick Setup provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="ssm-quicksetup-GetConfiguration"></a>[https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_GetConfiguration.html](https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_GetConfiguration.html) | Get Quick Setup configuration | Read |
| <a name="ssm-quicksetup-GetConfigurationManager"></a>[https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_GetConfigurationManager.html](https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_GetConfigurationManager.html) | Get a configuration manager | Read |
| <a name="ssm-quicksetup-GetServiceSettings"></a>[https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_GetServiceSettings.html](https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_GetServiceSettings.html) | Get settings configured for Quick Setup in the requesting AWS account and AWS Region | Read |
| <a name="ssm-quicksetup-ListConfigurationManagers"></a>[https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_ListConfigurationManagers.html](https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_ListConfigurationManagers.html) | List Quick Setup configuration managers | List |
| <a name="ssm-quicksetup-ListConfigurations"></a>[https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_ListConfigurations.html](https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_ListConfigurations.html) | List Quick Setup configurations | List |
| <a name="ssm-quicksetup-ListQuickSetupTypes"></a>[https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_ListQuickSetupTypes.html](https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_ListQuickSetupTypes.html) | List the available Quick Setup types | Read |
| <a name="ssm-quicksetup-ListTagsForResource"></a>[https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_ListTagsForResource.html](https://docs.aws.amazon.com/quick-setup/latest/APIReference/API_ListTagsForResource.html) | List tags assigned to the resource | Read |
