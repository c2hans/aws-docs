# Data retrieval APIs for AWS Elemental MediaPackage VOD
<a name="awselementalmediapackagevod"></a>

AWS Elemental MediaPackage VOD provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="mediapackage-vod-DescribeAsset"></a>[https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/assets-id.html#assets-idget](https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/assets-id.html#assets-idget) | View the details of an asset in AWS Elemental MediaPackage | Read |
| <a name="mediapackage-vod-DescribePackagingConfiguration"></a>[https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/packaging_configurations-id.html#packaging_configurations-idget](https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/packaging_configurations-id.html#packaging_configurations-idget) | View the details of a packaging configuration in AWS Elemental MediaPackage | Read |
| <a name="mediapackage-vod-DescribePackagingGroup"></a>[https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/packaging_groups-id.html#packaging_groups-idget](https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/packaging_groups-id.html#packaging_groups-idget) | View the details of a packaging group in AWS Elemental MediaPackage | Read |
| <a name="mediapackage-vod-ListAssets"></a>[https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/assets.html#assetsget](https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/assets.html#assetsget) | View a list of assets in AWS Elemental MediaPackage | List |
| <a name="mediapackage-vod-ListPackagingConfigurations"></a>[https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/packaging_configurations.html#packaging_configurationsget](https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/packaging_configurations.html#packaging_configurationsget) | View a list of packaging configurations in AWS Elemental MediaPackage | List |
| <a name="mediapackage-vod-ListPackagingGroups"></a>[https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/packaging_groups.html#packaging_groupsget](https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/packaging_groups.html#packaging_groupsget) | View a list of packaging groups in AWS Elemental MediaPackage | List |
| <a name="mediapackage-vod-ListTagsForResource"></a>[https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/tags-resource-arn.html#tags-resource-arnget](https://docs.aws.amazon.com/mediapackage-vod/latest/apireference/tags-resource-arn.html#tags-resource-arnget) | List the tags assigned to a PackagingGroup, PackagingConfiguration, or Asset | Read |
