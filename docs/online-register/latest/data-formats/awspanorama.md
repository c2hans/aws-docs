# Data retrieval APIs for AWS Panorama

AWS Panorama provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="panorama-DescribeApplicationInstance"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_DescribeApplicationInstance.html](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeApplicationInstance.html) | View details about an AWS Panorama application instance | Read |
| <a name="panorama-DescribeApplicationInstanceDetails"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_DescribeApplicationInstanceDetails.html](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeApplicationInstanceDetails.html) | View details about an AWS Panorama application instance | Read |
| <a name="panorama-DescribeDevice"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_DescribeDevice.html](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeDevice.html) | View details about an AWS Panorama Appliance | Read |
| <a name="panorama-DescribeDeviceJob"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_DescribeDeviceJob.html](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeDeviceJob.html) | View job details for an AWS Panorama Appliance | Read |
| <a name="panorama-DescribeNode"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_DescribeNode.html](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeNode.html) | View details about an AWS Panorama application node | Read |
| <a name="panorama-DescribeNodeFromTemplateJob"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_DescribeNodeFromTemplateJob.html](https://docs.aws.amazon.com/panorama/latest/api/API_DescribeNodeFromTemplateJob.html) | View details about AWS Panorama application node | Read |

| <a name="panorama-DescribePackageImportJob"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_DescribePackageImportJob.html](https://docs.aws.amazon.com/panorama/latest/api/API_DescribePackageImportJob.html) | View details about an AWS Panorama package | Read |
| <a name="panorama-DescribePackageVersion"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_DescribePackageVersion.html](https://docs.aws.amazon.com/panorama/latest/api/API_DescribePackageVersion.html) | View details about an AWS Panorama package version | Read |

| <a name="panorama-ListApplicationInstanceDependencies"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_ListApplicationInstanceDependencies.html](https://docs.aws.amazon.com/panorama/latest/api/API_ListApplicationInstanceDependencies.html) | Retrieve a list of application instance dependencies in AWS Panorama | List |

| <a name="panorama-ListPackageImportJobs"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_ListPackageImportJobs.html](https://docs.aws.amazon.com/panorama/latest/api/API_ListPackageImportJobs.html) | Retrieve a list of packages in AWS Panorama | List |
| <a name="panorama-ListPackages"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_ListPackages.html](https://docs.aws.amazon.com/panorama/latest/api/API_ListPackages.html) | Retrieve a list of packages in AWS Panorama | List |
| <a name="panorama-ListTagsForResource"></a>[https://docs.aws.amazon.com/panorama/latest/api/API_ListTagsForResource.html](https://docs.aws.amazon.com/panorama/latest/api/API_ListTagsForResource.html) | Retrieve a list of tags for a resource in AWS Panorama | Read |
