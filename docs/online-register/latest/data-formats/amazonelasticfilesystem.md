# Data retrieval APIs for Amazon Elastic File System
<a name="amazonelasticfilesystem"></a>

Amazon Elastic File System provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="elasticfilesystem-ClientMount"></a>[https://docs.aws.amazon.com/efs/latest/ug/efs-client-authorization.html](https://docs.aws.amazon.com/efs/latest/ug/efs-client-authorization.html) | Allow an NFS client read-access to a file system | Read |
| <a name="elasticfilesystem-DescribeAccessPoints"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_DescribeAccessPoints.html](https://docs.aws.amazon.com/efs/latest/ug/API_DescribeAccessPoints.html) | View the descriptions of Amazon EFS access points | List |
| <a name="elasticfilesystem-DescribeAccountPreferences"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_DescribeAccountPreferences.html](https://docs.aws.amazon.com/efs/latest/ug/API_DescribeAccountPreferences.html) | View the account preferences in effect for an account | List |
| <a name="elasticfilesystem-DescribeBackupPolicy"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_DescribeBackupPolicy.html](https://docs.aws.amazon.com/efs/latest/ug/API_DescribeBackupPolicy.html) | View the BackupPolicy object for an Amazon EFS file system | Read |
| <a name="elasticfilesystem-DescribeFileSystemPolicy"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_DescribeFileSystemPolicy.html](https://docs.aws.amazon.com/efs/latest/ug/API_DescribeFileSystemPolicy.html) | View the resource-level policy for an Amazon EFS file system | Read |
| <a name="elasticfilesystem-DescribeFileSystems"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_DescribeFileSystems.html](https://docs.aws.amazon.com/efs/latest/ug/API_DescribeFileSystems.html) | View the description of an Amazon EFS file system specified by file system CreationToken or FileSystemId; or to view the description of all file systems owned by the caller's AWS account in the AWS region of the endpoint that is being called | List |
| <a name="elasticfilesystem-DescribeLifecycleConfiguration"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_DescribeLifecycleConfiguration.html](https://docs.aws.amazon.com/efs/latest/ug/API_DescribeLifecycleConfiguration.html) | View the LifecycleConfiguration object for an Amazon EFS file system | Read |
| <a name="elasticfilesystem-DescribeMountTargetSecurityGroups"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_DescribeMountTargetSecurityGroups.html](https://docs.aws.amazon.com/efs/latest/ug/API_DescribeMountTargetSecurityGroups.html) | View the security groups in effect for a mount target | Read |
| <a name="elasticfilesystem-DescribeMountTargets"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_DescribeMountTargets.html](https://docs.aws.amazon.com/efs/latest/ug/API_DescribeMountTargets.html) | View the descriptions of all mount targets, or a specific mount target, for a file system | Read |
| <a name="elasticfilesystem-DescribeReplicationConfigurations"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_DescribeReplicationConfigurations.html](https://docs.aws.amazon.com/efs/latest/ug/API_DescribeReplicationConfigurations.html) | View the description of an Amazon EFS replication configuration specified by FileSystemId; or to view the description of all replication configurations owned by the caller's AWS account in the AWS region of the endpoint that is being called | List |
| <a name="elasticfilesystem-DescribeTags"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_DescribeTags.html](https://docs.aws.amazon.com/efs/latest/ug/API_DescribeTags.html) | View the tags associated with a file system | Read |
| <a name="elasticfilesystem-ListTagsForResource"></a>[https://docs.aws.amazon.com/efs/latest/ug/API_ListTagsForResource.html](https://docs.aws.amazon.com/efs/latest/ug/API_ListTagsForResource.html) | View the tags associated with the specified Amazon EFS resource | Read |
| <a name="elasticfilesystem-ReplicationRead"></a>[https://docs.aws.amazon.com/efs/latest/ug/efs-replication.html](https://docs.aws.amazon.com/efs/latest/ug/efs-replication.html) | Read file system data for replication | Read |
