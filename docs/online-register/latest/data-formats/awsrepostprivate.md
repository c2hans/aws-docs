# Data retrieval APIs for AWS rePost Private
<a name="awsrepostprivate"></a>

AWS rePost Private provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="repostspace-GetChannel"></a>[GetChannel](https://docs.aws.amazon.com/repostprivate/latest/APIReference/API_GetChannel.html) | Get the description for a channel in private re:Post in your account | Read |
| <a name="repostspace-GetSpace"></a>[GetSpace](https://docs.aws.amazon.com/repostprivate/latest/APIReference/API_GetSpace.html) | Get the description for a private re:Post in your account | Read |
| <a name="repostspace-ListChannels"></a>[ListChannels](https://docs.aws.amazon.com/repostprivate/latest/APIReference/API_ListChannels.html) | List all channels in a private re:Post in your account | Read |
| <a name="repostspace-ListSpaces"></a>[ListSpaces](API_ListSpaces.html) | List all private re:Posts in your account | Read |
| <a name="repostspace-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/repostprivate/latest/APIReference/API_ListTagsForResource.html) | List the tags associated with a resource | Read |
