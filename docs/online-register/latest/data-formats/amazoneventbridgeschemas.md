# Data retrieval APIs for Amazon EventBridge Schemas
<a name="amazoneventbridgeschemas"></a>

Amazon EventBridge Schemas provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="schemas-DescribeCodeBinding"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-language-language.html#DescribeCodeBinding](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-language-language.html#DescribeCodeBinding) | Retrieve metadata for generated code for specific schema in your account | Read |
| <a name="schemas-DescribeDiscoverer"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-discoverers-id-discovererid.html#DescribeDiscoverer](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-discoverers-id-discovererid.html#DescribeDiscoverer) | Retrieve discoverer metadata in your account | Read |
| <a name="schemas-DescribeRegistry"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname.html#DescribeRegistry](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname.html#DescribeRegistry) | Describe an existing registry metadata in your account | Read |
| <a name="schemas-DescribeSchema"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname.html#DescribeSchema](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname.html#DescribeSchema) | Retrieve an existing schema in your account | Read |
| <a name="schemas-ExportSchema"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-policy.html#ExportSchema](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-policy.html#ExportSchema) | Export the AWS registry or discovered schemas in OpenAPI 3 format to JSONSchema format | Read |
| <a name="schemas-GetCodeBindingSource"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-language-language-source.html#GetCodeBindingSource](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-language-language-source.html#GetCodeBindingSource) | Retrieve metadata for generated code for specific schema in your account | Read |
| <a name="schemas-GetDiscoveredSchema"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-discover.html#GetDiscoveredSchema](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-discover.html#GetDiscoveredSchema) | Retrieve a schema for the provided list of sample events | Read |
| <a name="schemas-GetResourcePolicy"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-policy.html#GetResourcePolicy](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-policy.html#GetResourcePolicy) | Retrieve the resource-based policy attached to a given registry | Read |
| <a name="schemas-ListDiscoverers"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-discoverers.html#ListDiscoverers](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-discoverers.html#ListDiscoverers) | List all discoverers in your account | List |
| <a name="schemas-ListRegistries"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries.html#ListRegistries](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries.html#ListRegistries) | List all registries in your account | List |
| <a name="schemas-ListSchemaVersions"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-versions.html#ListSchemaVersions](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-name-schemaname-versions.html#ListSchemaVersions) | List all versions of a schema | List |
| <a name="schemas-ListSchemas"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas.html#ListSchemas](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas.html#ListSchemas) | List all schemas | List |
| <a name="schemas-ListTagsForResource"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/tags-resource-arn.html#ListTagsForResource](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/tags-resource-arn.html#ListTagsForResource) | Lists tags for a resource | Read |
| <a name="schemas-SearchSchemas"></a>[https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-search.html#SearchSchemas](https://docs.aws.amazon.com/eventbridge/latest/schema-reference/v1-registries-name-registryname-schemas-search.html#SearchSchemas) | Search schemas based on specified keywords in your account | List |
