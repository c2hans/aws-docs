# Data retrieval APIs for AWS Customer Verification Service
<a name="awscustomerverificationservice"></a>

AWS Customer Verification Service provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="customer-verification-GetCustomerVerificationDetails"></a>[GetCustomerVerificationDetails](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Get customer verification data | Read |
| <a name="customer-verification-GetCustomerVerificationEligibility"></a>[GetCustomerVerificationEligibility](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Get customer verification eligibility | Read |
| <a name="customer-verification-GetInheritanceConfig"></a>[GetInheritanceConfig](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-permissions-ref.html#user-permissions) | Get inheritance configuration | Read |
