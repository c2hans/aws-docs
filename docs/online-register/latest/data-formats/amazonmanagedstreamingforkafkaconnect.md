# Data retrieval APIs for Amazon Managed Streaming for Kafka Connect
<a name="amazonmanagedstreamingforkafkaconnect"></a>

Amazon Managed Streaming for Kafka Connect provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="kafkaconnect-DescribeConnector"></a>[https://docs.aws.amazon.com/MSKC/latest/mskc/API_DescribeConnector.html](https://docs.aws.amazon.com/MSKC/latest/mskc/API_DescribeConnector.html) | Describe an MSK Connect connector | Read |
| <a name="kafkaconnect-DescribeConnectorOperation"></a>[https://docs.aws.amazon.com/MSKC/latest/mskc/API_DescribeConnectorOperation.html](https://docs.aws.amazon.com/MSKC/latest/mskc/API_DescribeConnectorOperation.html) | Describe a MSK Connect connector operation | Read |
| <a name="kafkaconnect-DescribeCustomPlugin"></a>[https://docs.aws.amazon.com/MSKC/latest/mskc/API_DescribeCustomPlugin.html](https://docs.aws.amazon.com/MSKC/latest/mskc/API_DescribeCustomPlugin.html) | Describe an MSK Connect custom plugin | Read |
| <a name="kafkaconnect-DescribeWorkerConfiguration"></a>[https://docs.aws.amazon.com/MSKC/latest/mskc/API_DescribeWorkerConfiguration.html](https://docs.aws.amazon.com/MSKC/latest/mskc/API_DescribeWorkerConfiguration.html) | Describe an MSK Connect worker configuration | Read |
| <a name="kafkaconnect-ListConnectorOperations"></a>[https://docs.aws.amazon.com/MSKC/latest/mskc/API_ListConnectorOperations.html](https://docs.aws.amazon.com/MSKC/latest/mskc/API_ListConnectorOperations.html) | List all operations of a given MSK Connect connector | Read |
| <a name="kafkaconnect-ListConnectors"></a>[https://docs.aws.amazon.com/MSKC/latest/mskc/API_ListConnectors.html](https://docs.aws.amazon.com/MSKC/latest/mskc/API_ListConnectors.html) | List all MSK Connect connectors in this account | Read |
| <a name="kafkaconnect-ListCustomPlugins"></a>[https://docs.aws.amazon.com/MSKC/latest/mskc/API_ListCustomPlugins.html](https://docs.aws.amazon.com/MSKC/latest/mskc/API_ListCustomPlugins.html) | List all MSK Connect custom plugins in this account | Read |
| <a name="kafkaconnect-ListTagsForResource"></a>[https://docs.aws.amazon.com/MSKC/latest/mskc/API_ListTagsForResource.html](https://docs.aws.amazon.com/MSKC/latest/mskc/API_ListTagsForResource.html) | List tags of an MSK Connect resource | Read |
| <a name="kafkaconnect-ListWorkerConfigurations"></a>[https://docs.aws.amazon.com/MSKC/latest/mskc/API_ListWorkerConfigurations.html](https://docs.aws.amazon.com/MSKC/latest/mskc/API_ListWorkerConfigurations.html) | List all MSK Connect worker configurations in this account | Read |
