# Data retrieval APIs for AWS License Manager Linux Subscriptions Manager
<a name="awslicensemanagerlinuxsubscriptionsmanager"></a>

AWS License Manager Linux Subscriptions Manager provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="license-manager-linux-subscriptions-GetRegisteredSubscriptionProvider"></a>[GetRegisteredSubscriptionProvider](https://docs.aws.amazon.com/license-manager-linux-subscriptions/latest/APIReference/API_GetRegisteredSubscriptionProvider.html) | Get a subscription provider in AWS License Manager | Read |
| <a name="license-manager-linux-subscriptions-GetServiceSettings"></a>[GetServiceSettings](https://docs.aws.amazon.com/license-manager-linux-subscriptions/latest/APIReference/API_GetServiceSettings.html) | Get the service settings for Linux subscriptions in AWS License Manager | Read |
| <a name="license-manager-linux-subscriptions-ListLinuxSubscriptionInstances"></a>[ListLinuxSubscriptionInstances](https://docs.aws.amazon.com/license-manager-linux-subscriptions/latest/APIReference/API_ListLinuxSubscriptionInstances.html) | List all instances with Linux subscriptions in AWS License Manager | Read |
| <a name="license-manager-linux-subscriptions-ListLinuxSubscriptions"></a>[ListLinuxSubscriptions](https://docs.aws.amazon.com/license-manager-linux-subscriptions/latest/APIReference/API_ListLinuxSubscriptions.html) | List all Linux subscriptions in AWS License Manager | Read |
| <a name="license-manager-linux-subscriptions-ListRegisteredSubscriptionProviders"></a>[ListRegisteredSubscriptionProviders](https://docs.aws.amazon.com/license-manager-linux-subscriptions/latest/APIReference/API_ListRegisteredSubscriptionProviders.html) | List subscription providers in AWS License Manager | Read |
| <a name="license-manager-linux-subscriptions-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/license-manager-linux-subscriptions/latest/APIReference/API_ListTagsForResource.html) | List tags for a selected resource | Read |
