# Data retrieval APIs for Amazon Redshift Data API
<a name="amazonredshiftdataapi"></a>

Amazon Redshift Data API provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="redshift-data-DescribeStatement"></a>[https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_DescribeStatement.html](https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_DescribeStatement.html) | Retrieve detailed information about a statement execution | Read |
| <a name="redshift-data-DescribeTable"></a>[https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_DescribeTable.html](https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_DescribeTable.html) | Retrieve metadata about a particular table | Read |
| <a name="redshift-data-GetStagingBucketLocation"></a>[https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_GetStagingBucketLocation.html](https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_GetStagingBucketLocation.html) | Get staging bucket location for a given managed workgroup | Read |
| <a name="redshift-data-GetStatementResult"></a>[https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_GetStatementResult.html](https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_GetStatementResult.html) | Fetch the result of a query | Read |
| <a name="redshift-data-ListDatabases"></a>[https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_ListDatabases.html](https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_ListDatabases.html) | List databases for a given cluster | Read |
| <a name="redshift-data-ListSchemas"></a>[https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_ListSchemas.html](https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_ListSchemas.html) | List schemas for a given cluster | Read |
| <a name="redshift-data-ListSessions"></a>[https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_ListSessions.html](https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_ListSessions.html) | List sessions for a given principal | List |
| <a name="redshift-data-ListStatements"></a>[https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_ListStatements.html](https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_ListStatements.html) | List queries for a given principal | List |
| <a name="redshift-data-ListTables"></a>[https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_ListTables.html](https://docs.aws.amazon.com/redshift-data/latest/APIReference/API_ListTables.html) | List tables for a given cluster | List |
