# Data retrieval APIs for Amazon Aurora DSQL
<a name="amazonauroradsql"></a>

Amazon Aurora DSQL provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="dsql-GetBackupJob"></a>[GetBackupJob](https://docs.aws.amazon.com/aurora-dsql/latest/userguide/backup-aurora-dsql.html) | Get the status of an Aurora DSQL cluster backup job | Read |
| <a name="dsql-GetCluster"></a>[GetCluster](https://docs.aws.amazon.com/aurora-dsql/latest/APIReference/API_GetCluster.html) | Get information about a cluster | Read |
| <a name="dsql-GetClusterPolicy"></a>[GetClusterPolicy](https://docs.aws.amazon.com/aurora-dsql/latest/APIReference/rbp-api-operations.html) | Retrieve the inline resource-based policy attached to a cluster | Read |
| <a name="dsql-GetRestoreJob"></a>[GetRestoreJob](https://docs.aws.amazon.com/aurora-dsql/latest/userguide/backup-aurora-dsql.html) | Get the status of an Aurora DSQL cluster restore job | Read |
| <a name="dsql-GetStream"></a>[GetStream](https://docs.aws.amazon.com/aurora-dsql/latest/userguide/cdc-streams.html) | Get information about a Change Stream | Read |
| <a name="dsql-GetVpcEndpointServiceName"></a>[GetVpcEndpointServiceName](https://docs.aws.amazon.com/aurora-dsql/latest/APIReference/API_GetVpcEndpointServiceName.html) | Retrieve the VPC endpoint service name for a cluster | Read |
| <a name="dsql-ListClusters"></a>[ListClusters](https://docs.aws.amazon.com/aurora-dsql/latest/APIReference/API_ListClusters.html) | Retrieve a list of clusters | List |
| <a name="dsql-ListStreams"></a>[ListStreams](https://docs.aws.amazon.com/aurora-dsql/latest/userguide/cdc-streams.html) | Retrieve a list of Change Streams for a cluster | List |
| <a name="dsql-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/aurora-dsql/latest/APIReference/API_ListTagsForResource.html) | List all tags on an Aurora DSQL resource | Read |
