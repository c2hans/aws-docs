# Data retrieval APIs for AWS Identity Store Auth
<a name="awsidentitystoreauth"></a>

AWS Identity Store Auth provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="identitystore-auth-BatchGetSession"></a>[BatchGetSession](https://docs.aws.amazon.com/singlesignon/latest/userguide/manage-app-session.html) | Return session attributes for a batch of specified sessions | Read |
| <a name="identitystore-auth-ListSessions"></a>[ListSessions](https://docs.aws.amazon.com/singlesignon/latest/userguide/manage-app-session.html) | Retrieve a list of active sessions for the specified user | List |
