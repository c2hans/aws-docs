# Data retrieval APIs for Amazon GroundTruth Labeling
<a name="amazongroundtruthlabeling"></a>

Amazon GroundTruth Labeling provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="groundtruthlabeling-DescribeConsoleJob"></a>[DescribeConsoleJob](https://docs.aws.amazon.com/sagemaker/latest/dg/sms-data-input.html#sms-console-create-manifest-file) | Get status of GroundTruthLabeling Jobs | Read |
| <a name="groundtruthlabeling-GetBatch"></a>[GetBatch](https://docs.aws.amazon.com/sagemaker/latest/dg/sms-data-input.html#sms-console-create-manifest-file) | Get a GT\+ Batch | Read |
| <a name="groundtruthlabeling-GetIntakeFormStatus"></a>[GetIntakeFormStatus](https://docs.aws.amazon.com/sagemaker/latest/dg/sms-data-input.html#sms-console-create-manifest-file) | Get a intake forms | Read |
| <a name="groundtruthlabeling-ListBatches"></a>[ListBatches](https://docs.aws.amazon.com/sagemaker/latest/dg/sms-data-input.html#sms-console-create-manifest-file) | List a GT\+ Batchs | Read |
| <a name="groundtruthlabeling-ListDatasetObjects"></a>[ListDatasetObjects](https://docs.aws.amazon.com/sagemaker/latest/dg/sms-data-input.html#sms-console-create-manifest-file) | List dataset objects in a manifest file | Read |
| <a name="groundtruthlabeling-ListProjects"></a>[ListProjects](https://docs.aws.amazon.com/sagemaker/latest/dg/sms-data-input.html#sms-console-create-manifest-file) | List a GT\+ Projects | Read |
