# Data retrieval APIs for Amazon Braket
<a name="amazonbraket"></a>

Amazon Braket provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="braket-GetDevice"></a>[GetDevice](https://docs.aws.amazon.com/braket/latest/APIReference/API_GetDevice.html) | Retrieve information about the devices available in Amazon Braket | Read |
| <a name="braket-GetJob"></a>[GetJob](https://docs.aws.amazon.com/braket/latest/APIReference/API_GetJob.html) | Retrieve jobs | Read |
| <a name="braket-GetQuantumTask"></a>[GetQuantumTask](https://docs.aws.amazon.com/braket/latest/APIReference/API_GetQuantumTask.html) | Retrieve quantum tasks | Read |
| <a name="braket-GetServiceLinkedRoleStatus"></a>[GetServiceLinkedRoleStatus](${UserGuideDocPage}) | Check if the Amazon Braket service linked role has been created | Read |
| <a name="braket-GetUserAgreementStatus"></a>[GetUserAgreementStatus](${UserGuideDocPage}) | Check if the account has accepted the Amazon Braket user agreement | Read |
| <a name="braket-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/braket/latest/APIReference/API_ListTagsForResource.html) | Listing the tags that have been applied to the quantum task resource or the job | Read |
| <a name="braket-SearchDevices"></a>[SearchDevices](https://docs.aws.amazon.com/braket/latest/APIReference/API_SearchDevices.html) | Search for devices available in Amazon Braket | List |
| <a name="braket-SearchJobs"></a>[SearchJobs](https://docs.aws.amazon.com/braket/latest/APIReference/API_SearchJobs.html) | Search for jobs | List |
| <a name="braket-SearchQuantumTasks"></a>[SearchQuantumTasks](https://docs.aws.amazon.com/braket/latest/APIReference/API_SearchQuantumTasks.html) | Search for quantum tasks | List |
| <a name="braket-SearchSpendingLimits"></a>[SearchSpendingLimits](https://docs.aws.amazon.com/braket/latest/APIReference/API_SearchSpendingLimits.html) | Search for spending limit | Read |
