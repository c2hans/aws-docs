# Data retrieval APIs for Amazon Elastic Container Registry Public
<a name="amazonelasticcontainerregistrypublic"></a>

Amazon Elastic Container Registry Public provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="ecr-public-BatchCheckLayerAvailability"></a>[https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_BatchCheckLayerAvailability.html](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_BatchCheckLayerAvailability.html) | Check the availability of multiple image layers in a specified registry and repository | Read |
| <a name="ecr-public-DescribeImageTags"></a>[https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeImageTags.html](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeImageTags.html) | Describe all the image tags for a given repository | List |
| <a name="ecr-public-DescribeImages"></a>[https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeImages.html](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeImages.html) | Get metadata about the images in a repository, including image size, image tags, and creation date | Read |
| <a name="ecr-public-DescribeRegistries"></a>[https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeRegistries.html](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeRegistries.html) | Retrieve the catalog data associated with a registry | List |
| <a name="ecr-public-DescribeRepositories"></a>[https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeRepositories.html](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_DescribeRepositories.html) | Describe image repositories in a registry | List |
| <a name="ecr-public-GetAuthorizationToken"></a>[https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_GetAuthorizationToken.html](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_GetAuthorizationToken.html) | Retrieve a token that is valid for a specified registry for 12 hours | Read |
| <a name="ecr-public-GetRegistryCatalogData"></a>[https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_GetRegistryCatalogData.html](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_GetRegistryCatalogData.html) | Retrieve the catalog data associated with a registry | Read |
| <a name="ecr-public-GetRepositoryCatalogData"></a>[https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_GetRepositoryCatalogData.html](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_GetRepositoryCatalogData.html) | Retrieve the catalog data associated with a repository | Read |
| <a name="ecr-public-GetRepositoryPolicy"></a>[https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_GetRepositoryPolicy.html](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_GetRepositoryPolicy.html) | Retrieve the repository policy for a specified repository | Read |
| <a name="ecr-public-ListTagsForResource"></a>[https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_ListTagsForResource.html](https://docs.aws.amazon.com/AmazonECRPublic/latest/APIReference/API_ListTagsForResource.html) | List the tags for an Amazon ECR resource | Read |
