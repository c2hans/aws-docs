# Data retrieval APIs for AWS Diagnostic tools
<a name="awsdiagnostictools"></a>

AWS Diagnostic tools provides the following APIs for data retrieval.

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="ts-GetExecution"></a>[GetExecution](https://docs.aws.amazon.com/diagnostic-tools/latest/APIReference/API_GetExecution.html) | Get details about specific execution within AWS Diagnostic tools | Read |
| <a name="ts-GetExecutionOutput"></a>[GetExecutionOutput](https://docs.aws.amazon.com/diagnostic-tools/latest/APIReference/API_GetExecutionOutput.html) | Get details about specific execution output within AWS Diagnostic tools | Read |
| <a name="ts-GetTool"></a>[GetTool](https://docs.aws.amazon.com/diagnostic-tools/latest/APIReference/API_GetTool.html) | Get details about specific tool within AWS Diagnostic tools | Read |
| <a name="ts-ListExecutions"></a>[ListExecutions](https://docs.aws.amazon.com/diagnostic-tools/latest/APIReference/API_ListExecutions.html) | List all available execution within AWS Diagnostic tools | List |
| <a name="ts-ListTagsForResource"></a>[ListTagsForResource](https://docs.aws.amazon.com/diagnostic-tools/latest/APIReference/API_ListTagsForResource.html) | List the tags for an AWS Diagnostic tools resource | Read |
| <a name="ts-ListTools"></a>[ListTools](https://docs.aws.amazon.com/diagnostic-tools/latest/APIReference/API_ListTools.html) | List all available tools within AWS Diagnostic tools | List |
