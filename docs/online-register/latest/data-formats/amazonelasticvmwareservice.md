# Data retrieval APIs for Amazon Elastic VMware Service
<a name="amazonelasticvmwareservice"></a>

Amazon Elastic VMware Service provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="evs-GetDepotUrl"></a>[https://docs.aws.amazon.com/evs/latest/APIReference/API_GetDepotUrl.html](https://docs.aws.amazon.com/evs/latest/APIReference/API_GetDepotUrl.html) | Get an Amazon EVS environment depot url | Read |
| <a name="evs-GetEnvironment"></a>[https://docs.aws.amazon.com/evs/latest/APIReference/API_GetEnvironment.html](https://docs.aws.amazon.com/evs/latest/APIReference/API_GetEnvironment.html) | Get an Amazon EVS environment | Read |
| <a name="evs-GetVersions"></a>[https://docs.aws.amazon.com/evs/latest/APIReference/API_GetVersions.html](https://docs.aws.amazon.com/evs/latest/APIReference/API_GetVersions.html) | Get versions provided for launch by Amazon EVS | Read |
| <a name="evs-ListEnvironmentConnectors"></a>[https://docs.aws.amazon.com/evs/latest/APIReference/API_ListEnvironmentConnectors.html](https://docs.aws.amazon.com/evs/latest/APIReference/API_ListEnvironmentConnectors.html) | Retrieve a list of connectors associated with an Amazon EVS environment | List |
| <a name="evs-ListEnvironmentHosts"></a>[https://docs.aws.amazon.com/evs/latest/APIReference/API_ListEnvironmentHosts.html](https://docs.aws.amazon.com/evs/latest/APIReference/API_ListEnvironmentHosts.html) | Retrieve a list of hosts associated with an Amazon EVS environment | List |
| <a name="evs-ListEnvironmentVlans"></a>[https://docs.aws.amazon.com/evs/latest/APIReference/API_ListEnvironmentVlans.html](https://docs.aws.amazon.com/evs/latest/APIReference/API_ListEnvironmentVlans.html) | Retrieve a list of Amazon EVS environment VLANs | List |
| <a name="evs-ListEnvironments"></a>[https://docs.aws.amazon.com/evs/latest/APIReference/API_ListEnvironments.html](https://docs.aws.amazon.com/evs/latest/APIReference/API_ListEnvironments.html) | Retrieve a list of Amazon EVS environments in an account | List |
| <a name="evs-ListTagsForResource"></a>[https://docs.aws.amazon.com/evs/latest/APIReference/API_ListTagsForResource.html](https://docs.aws.amazon.com/evs/latest/APIReference/API_ListTagsForResource.html) | List the tags on a specified resource ARN | Read |
| <a name="evs-ListVmEntitlements"></a>[https://docs.aws.amazon.com/evs/latest/APIReference/API_ListVmEntitlements.html](https://docs.aws.amazon.com/evs/latest/APIReference/API_ListVmEntitlements.html) | Retrieve a list of entitlements associated with an Amazon EVS environment | List |
