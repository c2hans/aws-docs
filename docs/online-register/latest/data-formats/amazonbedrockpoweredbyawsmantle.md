# Data retrieval APIs for Amazon Bedrock Powered by AWS Mantle
<a name="amazonbedrockpoweredbyawsmantle"></a>

Amazon Bedrock Powered by AWS Mantle provides the following APIs for data retrieval.

****

| Actions | Description | Access level |
| --- | --- | --- |
| <a name="bedrock-mantle-CallWithBearerToken"></a>[#welcome](#welcome) | Make API calls using bearer token authentication | List |

| <a name="bedrock-mantle-GetCustomizedModel"></a>[https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Get customized model | Read |
| <a name="bedrock-mantle-GetFile"></a>[https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve information about a specific file | Read |
| <a name="bedrock-mantle-GetFineTuningJob"></a>[https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve details of a specific fine tuning job | Read |
| <a name="bedrock-mantle-GetInference"></a>[https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve details of a specific inference request | Read |
| <a name="bedrock-mantle-GetModel"></a>[https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve information about a specific model | Read |
| <a name="bedrock-mantle-GetProject"></a>[https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Retrieve details of a specific project | Read |
| <a name="bedrock-mantle-GetReservation"></a>[https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | Get reservation | Read |
| <a name="bedrock-mantle-ListCustomizedModelAssociations"></a>[https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | List project associations for a customized model | List |
| <a name="bedrock-mantle-ListCustomizedModels"></a>[https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome](https://docs.aws.amazon.com/bedrock/latest/APIReference/#welcome) | List customized models | List |
