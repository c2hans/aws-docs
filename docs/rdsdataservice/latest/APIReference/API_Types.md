# Data Types
<a name="API_Types"></a>

The AWS RDS DataService API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [ArrayValue](API_ArrayValue.md)
+  [ColumnMetadata](API_ColumnMetadata.md)
+  [Field](API_Field.md)
+  [Record](API_Record.md)
+  [ResultFrame](API_ResultFrame.md)
+  [ResultSetMetadata](API_ResultSetMetadata.md)
+  [ResultSetOptions](API_ResultSetOptions.md)
+  [SqlParameter](API_SqlParameter.md)
+  [SqlStatementResult](API_SqlStatementResult.md)
+  [StructValue](API_StructValue.md)
+  [UpdateResult](API_UpdateResult.md)
+  [Value](API_Value.md)
