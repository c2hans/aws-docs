# Trusted identity propagation with IAM Roles Anywhere

IAM Roles Anywhere enables workloads running outside AWS to create role sessions by using X.509 certificates. To configure and use trusted identity propagation (TIP) for these workloads, see [Trusted identity propagation in the IAM Roles Anywhere User Guide](https://docs.aws.amazon.com/rolesanywhere/latest/userguide/trusted-identity-propagation.html).
