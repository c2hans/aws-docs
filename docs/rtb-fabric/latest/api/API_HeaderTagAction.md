# HeaderTagAction
<a name="API_HeaderTagAction"></a>

Describes the header tag for a bid action.

## Contents
<a name="API_HeaderTagAction_Contents"></a>

 ** name **   <a name="rtbfabric-Type-HeaderTagAction-name"></a>
The name of the bid action.
Type: String
Required: Yes

 ** value **   <a name="rtbfabric-Type-HeaderTagAction-value"></a>
The value of the bid action.
Type: String
Required: Yes
