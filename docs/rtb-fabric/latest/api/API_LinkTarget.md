# LinkTarget

The link an update targeted.

## Contents
<a name="API_LinkTarget_Contents"></a>

 ** linkId **   <a name="rtbfabric-Type-LinkTarget-linkId"></a>
The unique identifier of the link.
Type: String
Length Constraints: Minimum length of 6. Maximum length of 30.
Pattern: `link-[a-z0-9-]{1,25}`
Required: Yes
