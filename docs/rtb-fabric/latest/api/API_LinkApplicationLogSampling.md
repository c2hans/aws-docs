# LinkApplicationLogSampling
<a name="API_LinkApplicationLogSampling"></a>

Describes a link application log sample.

## Contents
<a name="API_LinkApplicationLogSampling_Contents"></a>

 ** errorLog **   <a name="rtbfabric-Type-LinkApplicationLogSampling-errorLog"></a>
An error log entry.
Type: Double
Valid Range: Minimum value of 0.0. Maximum value of 100.0.
Required: Yes

 ** filterLog **   <a name="rtbfabric-Type-LinkApplicationLogSampling-filterLog"></a>
A filter log entry.
Type: Double
Valid Range: Minimum value of 0.0. Maximum value of 100.0.
Required: Yes
