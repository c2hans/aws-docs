# ListenerConfig
<a name="API_ListenerConfig"></a>

Listener configuration for the protocols (HTTP, HTTPS, or both) accepted by the gateway.

## Contents
<a name="API_ListenerConfig_Contents"></a>

 ** protocols **   <a name="rtbfabric-Type-ListenerConfig-protocols"></a>
The protocol for connections from clients to the gateway
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 2 items.
Valid Values: `HTTP | HTTPS`
Required: Yes
