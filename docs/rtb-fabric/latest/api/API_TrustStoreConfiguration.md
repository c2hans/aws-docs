# TrustStoreConfiguration
<a name="API_TrustStoreConfiguration"></a>

Describes the configuration of a trust store.

## Contents
<a name="API_TrustStoreConfiguration_Contents"></a>

 ** certificateAuthorityCertificates **   <a name="rtbfabric-Type-TrustStoreConfiguration-certificateAuthorityCertificates"></a>
The certificate authority certificate.
Type: Array of strings
Array Members: Minimum number of 0 items. Maximum number of 2 items.
Length Constraints: Minimum length of 1. Maximum length of 2097152.
Required: Yes
