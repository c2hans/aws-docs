# LinkConfigParameters

A requested link configuration.

## Contents
<a name="API_LinkConfigParameters_Contents"></a>

 ** logSettings **   <a name="rtbfabric-Type-LinkConfigParameters-logSettings"></a>
Describes the settings for a link log.
Type: [LinkLogSettings](API_LinkLogSettings.md) object
Required: No

 ** timeoutInMillis **   <a name="rtbfabric-Type-LinkConfigParameters-timeoutInMillis"></a>
The timeout value in milliseconds.
Type: Long
Valid Range: Minimum value of 100. Maximum value of 5000.
Required: No
