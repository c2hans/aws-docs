# Configuring link logging
<a name="configuring-link-logging"></a>

You can configure individual links to deliver logs Amazon S3, Amazon Data Firehose, or Amazon CloudWatch Logs using the RTB Fabric API. Before configuring link logging, you must first set up log delivery infrastructure. For more information about setting up log delivery destinations, see [UpdateLink](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_UpdateLink.html) in the *RTB Fabric API Reference* and [Logging RTB Fabric link activity using vended logs](monitoring-cloudwatch-logs.md).
