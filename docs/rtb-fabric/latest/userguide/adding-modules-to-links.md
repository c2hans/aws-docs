# Adding modules to links

You can only add modules to existing links using the RTB Fabric API. Modules run inline on your links and can filter bid requests, enrich them with additional data, or observe traffic without changing it. For more information, see [Modules](modules.md).

To find the modules that you can attach and attach them as a flow, use the `PutLinkFlows` operation. For more information, see [Discovering and attaching modules](discovering-attaching-modules.md).
