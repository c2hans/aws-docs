# Adding modules to links
<a name="adding-modules-to-links"></a>

You can only add modules to existing links using the RTB Fabric API. Modules enable you to implement rate limiting, filtering, error handling, and other traffic management capabilities on your links. For more information, see [Modules](modules.md).
