# Editing links
<a name="editing-links-api"></a>

You can only edit existing links using the API. To modify a link created in the console, you must delete the existing link and create a new one with the updated configuration. For more information, see [UpdateLink](https://docs.aws.amazon.com/rtb-fabric/latest/api/API_UpdateLink.html) in the *RTB Fabric API Reference*.
