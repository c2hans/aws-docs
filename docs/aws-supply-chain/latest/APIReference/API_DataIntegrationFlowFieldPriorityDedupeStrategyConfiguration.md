# DataIntegrationFlowFieldPriorityDedupeStrategyConfiguration
<a name="API_DataIntegrationFlowFieldPriorityDedupeStrategyConfiguration"></a>

The field priority deduplication strategy details.

## Contents
<a name="API_DataIntegrationFlowFieldPriorityDedupeStrategyConfiguration_Contents"></a>

 ** fields **   <a name="supplychain-Type-DataIntegrationFlowFieldPriorityDedupeStrategyConfiguration-fields"></a>
The list of field names and their sort order for deduplication, arranged in descending priority from highest to lowest.
Type: Array of [DataIntegrationFlowFieldPriorityDedupeField](API_DataIntegrationFlowFieldPriorityDedupeField.md) objects
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Required: Yes
