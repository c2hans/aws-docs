# DataIntegrationFlowDatasetSourceConfiguration
<a name="API_DataIntegrationFlowDatasetSourceConfiguration"></a>

The dataset DataIntegrationFlow source configuration parameters.

## Contents
<a name="API_DataIntegrationFlowDatasetSourceConfiguration_Contents"></a>

 ** datasetIdentifier **   <a name="supplychain-Type-DataIntegrationFlowDatasetSourceConfiguration-datasetIdentifier"></a>
The ARN of the dataset.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1011.
Pattern: `[-_/A-Za-z0-9:]+`
Required: Yes

 ** options **   <a name="supplychain-Type-DataIntegrationFlowDatasetSourceConfiguration-options"></a>
The dataset DataIntegrationFlow source options.
Type: [DataIntegrationFlowDatasetOptions](API_DataIntegrationFlowDatasetOptions.md) object
Required: No
