# DataIntegrationFlowExecutionOutputMetadata
<a name="API_DataIntegrationFlowExecutionOutputMetadata"></a>

The output metadata of the flow execution.

## Contents
<a name="API_DataIntegrationFlowExecutionOutputMetadata_Contents"></a>

 ** diagnosticReportsRootS3URI **   <a name="supplychain-Type-DataIntegrationFlowExecutionOutputMetadata-diagnosticReportsRootS3URI"></a>
The S3 URI under which all diagnostic files (such as deduped records if any) are stored.
Type: String
Pattern: `s3://[a-z0-9][a-z0-9.-]{1,61}[a-z0-9]/.{1,1024}`
Required: No
