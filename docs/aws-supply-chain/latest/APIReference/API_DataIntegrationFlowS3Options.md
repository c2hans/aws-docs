# DataIntegrationFlowS3Options
<a name="API_DataIntegrationFlowS3Options"></a>

The Amazon S3 options used in S3 source and target configurations.

## Contents
<a name="API_DataIntegrationFlowS3Options_Contents"></a>

 ** fileType **   <a name="supplychain-Type-DataIntegrationFlowS3Options-fileType"></a>
The Amazon S3 file type in S3 options.
Type: String
Valid Values: `CSV | PARQUET | JSON`
Required: No
