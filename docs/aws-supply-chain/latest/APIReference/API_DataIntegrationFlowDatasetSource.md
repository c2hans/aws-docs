# DataIntegrationFlowDatasetSource
<a name="API_DataIntegrationFlowDatasetSource"></a>

The details of a flow execution with dataset source.

## Contents
<a name="API_DataIntegrationFlowDatasetSource_Contents"></a>

 ** datasetIdentifier **   <a name="supplychain-Type-DataIntegrationFlowDatasetSource-datasetIdentifier"></a>
The ARN of the dataset source.
Type: String
Length Constraints: Minimum length of 20. Maximum length of 1011.
Pattern: `arn:aws:scn:([a-z0-9-]+):([0-9]+):instance/([a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12})/namespaces/[^/]+/datasets/[^/]+`
Required: Yes
