# DataIntegrationEventDatasetLoadExecutionDetails
<a name="API_DataIntegrationEventDatasetLoadExecutionDetails"></a>

The target dataset load execution details.

## Contents
<a name="API_DataIntegrationEventDatasetLoadExecutionDetails_Contents"></a>

 ** status **   <a name="supplychain-Type-DataIntegrationEventDatasetLoadExecutionDetails-status"></a>
The event load execution status to target dataset.
Type: String
Valid Values: `SUCCEEDED | IN_PROGRESS | FAILED`
Required: Yes

 ** message **   <a name="supplychain-Type-DataIntegrationEventDatasetLoadExecutionDetails-message"></a>
The failure message (if any) of failed event load execution to dataset.
Type: String
Required: No
