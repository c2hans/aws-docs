# Data Types
<a name="API_Types"></a>

The Amazon RDS Performance Insights API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AnalysisReport](API_AnalysisReport.md)
+  [AnalysisReportSummary](API_AnalysisReportSummary.md)
+  [Data](API_Data.md)
+  [DataPoint](API_DataPoint.md)
+  [DimensionDetail](API_DimensionDetail.md)
+  [DimensionGroup](API_DimensionGroup.md)
+  [DimensionGroupDetail](API_DimensionGroupDetail.md)
+  [DimensionKeyDescription](API_DimensionKeyDescription.md)
+  [DimensionKeyDetail](API_DimensionKeyDetail.md)
+  [FeatureMetadata](API_FeatureMetadata.md)
+  [Insight](API_Insight.md)
+  [MetricDimensionGroups](API_MetricDimensionGroups.md)
+  [MetricKeyDataPoints](API_MetricKeyDataPoints.md)
+  [MetricQuery](API_MetricQuery.md)
+  [PerformanceInsightsMetric](API_PerformanceInsightsMetric.md)
+  [Recommendation](API_Recommendation.md)
+  [ResponsePartitionKey](API_ResponsePartitionKey.md)
+  [ResponseResourceMetric](API_ResponseResourceMetric.md)
+  [ResponseResourceMetricKey](API_ResponseResourceMetricKey.md)
+  [Tag](API_Tag.md)
