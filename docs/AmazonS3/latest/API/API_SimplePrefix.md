# SimplePrefix
<a name="API_SimplePrefix"></a>

To use simple format for S3 keys for log objects, set SimplePrefix to an empty object.

 `[DestinationPrefix][YYYY]-[MM]-[DD]-[hh]-[mm]-[ss]-[UniqueString]`
