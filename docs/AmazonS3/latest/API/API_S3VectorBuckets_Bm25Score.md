# Bm25Score
<a name="API_S3VectorBuckets_Bm25Score"></a>

The raw BM25 relevance score for a single searchable metadata key.

## Contents
<a name="API_S3VectorBuckets_Bm25Score_Contents"></a>

 ** metadataKey **   <a name="AmazonS3-Type-S3VectorBuckets_Bm25Score-metadataKey"></a>
The searchable metadata key that the score applies to.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 63.
Required: Yes

 ** score **   <a name="AmazonS3-Type-S3VectorBuckets_Bm25Score-score"></a>
The BM25 relevance score.
Type: Float
Required: Yes
