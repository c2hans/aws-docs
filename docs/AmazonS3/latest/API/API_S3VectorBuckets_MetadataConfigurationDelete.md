# MetadataConfigurationDelete

 ** textSearchConfigurations **   <a name="AmazonS3-Type-S3VectorBuckets_MetadataConfigurationDelete-textSearchConfigurations"></a>

Type: Array of [TextSearchConfigurationKey](API_S3VectorBuckets_TextSearchConfigurationKey.md) objects
Array Members: Minimum number of 1 item. Maximum number of 10 items.
Required: No
