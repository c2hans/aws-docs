# TextSearchConfigurationKey

A searchable metadata key that identifies a text search configuration.

## Contents
<a name="API_S3VectorBuckets_TextSearchConfigurationKey_Contents"></a>

 ** metadataKey **   <a name="AmazonS3-Type-S3VectorBuckets_TextSearchConfigurationKey-metadataKey"></a>
The searchable metadata key whose text search configuration to delete.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 63.
Required: Yes
