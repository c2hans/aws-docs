# Tag
<a name="API_Tag"></a>

A container of a key value name pair.

## Contents
<a name="API_Tag_Contents"></a>

 ** Key **   <a name="AmazonS3-Type-Tag-Key"></a>
Name of the object key.
Type: String
Length Constraints: Minimum length of 1.
Required: Yes

 ** Value **   <a name="AmazonS3-Type-Tag-Value"></a>
Value of the tag.
Type: String
Required: Yes
