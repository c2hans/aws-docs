# StorageLensCostAndUsageReportsPublish

A container for the configuration used to publish S3 Storage Lens cost data to AWS Cost and Usage Reports (AWS CUR).

## Contents
<a name="API_control_StorageLensCostAndUsageReportsPublish_Contents"></a>

 ** PrefixLevel **   <a name="AmazonS3-Type-control_StorageLensCostAndUsageReportsPublish-PrefixLevel"></a>
A container for the prefix-level configuration that determines the prefixes for which S3 Storage Lens publishes cost data to AWS CUR.
Type: [StorageLensCostAndUsageReportsPrefixLevel](API_control_StorageLensCostAndUsageReportsPrefixLevel.md) data type
Required: No
