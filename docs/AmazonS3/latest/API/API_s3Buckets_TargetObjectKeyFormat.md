# TargetObjectKeyFormat
<a name="API_s3Buckets_TargetObjectKeyFormat"></a>

The key format of the log objects. Only `partitionedPrefix` is supported.

## Contents
<a name="API_s3Buckets_TargetObjectKeyFormat_Contents"></a>

 ** partitionedPrefix **   <a name="AmazonS3-Type-s3Buckets_TargetObjectKeyFormat-partitionedPrefix"></a>
Partitions log object keys by date.
Type: [PartitionedPrefix](API_s3Buckets_PartitionedPrefix.md) object
Required: Yes
