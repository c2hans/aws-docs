# Delivering logs to an Amazon S3 general purpose bucket
<a name="sal-gp-section"></a>

When you deliver server access logs to an Amazon S3 general purpose bucket, logs are written in space-delimited text format. There is no charge for log delivery. The destination bucket must be in the same AWS Region and AWS account as the source bucket.
