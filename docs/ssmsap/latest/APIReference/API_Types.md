# Data Types
<a name="API_Types"></a>

The AWS Systems Manager for SAP API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Application](API_Application.md)
+  [ApplicationCredential](API_ApplicationCredential.md)
+  [ApplicationSummary](API_ApplicationSummary.md)
+  [AssociatedHost](API_AssociatedHost.md)
+  [BackintConfig](API_BackintConfig.md)
+  [Component](API_Component.md)
+  [ComponentInfo](API_ComponentInfo.md)
+  [ComponentSummary](API_ComponentSummary.md)
+  [ConfigurationCheckDefinition](API_ConfigurationCheckDefinition.md)
+  [ConfigurationCheckOperation](API_ConfigurationCheckOperation.md)
+  [Database](API_Database.md)
+  [DatabaseConnection](API_DatabaseConnection.md)
+  [DatabaseSummary](API_DatabaseSummary.md)
+  [Filter](API_Filter.md)
+  [Host](API_Host.md)
+  [IpAddressMember](API_IpAddressMember.md)
+  [Operation](API_Operation.md)
+  [OperationEvent](API_OperationEvent.md)
+  [Resilience](API_Resilience.md)
+  [Resource](API_Resource.md)
+  [RuleResult](API_RuleResult.md)
+  [RuleStatusCounts](API_RuleStatusCounts.md)
+  [SubCheckResult](API_SubCheckResult.md)
