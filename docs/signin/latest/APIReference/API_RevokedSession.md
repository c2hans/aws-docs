# RevokedSession

A session that was revoked.

## Contents
<a name="API_RevokedSession_Contents"></a>

 ** sessionArn **   <a name="signin-Type-RevokedSession-sessionArn"></a>
The ARN of the revoked session.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes
