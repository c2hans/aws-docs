# SigninResourceBasedPolicy
<a name="API_SigninResourceBasedPolicy"></a>

The consolidated AWS Sign-In resource-based policy document for an account.

## Contents
<a name="API_SigninResourceBasedPolicy_Contents"></a>

 ** statement **   <a name="signin-Type-SigninResourceBasedPolicy-statement"></a>
The list of statements in the policy.
Type: Array of [PolicyStatement](API_PolicyStatement.md) objects
Required: No

 ** version **   <a name="signin-Type-SigninResourceBasedPolicy-version"></a>
The version of the policy language.
Type: String
Required: No
