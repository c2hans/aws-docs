# AWS Sign-In Documentation

AWS Sign-In helps you to sign in to Amazon Web Services (AWS), depending on what type of user you are and what AWS services you want to access.

- [AWS Sign-In User Guide](/signin/latest/userguide/): Introduces you to AWS user types and how to sign in to the AWS Management Console and other AWS services.
- [AWS Sign-In API Reference](/signin/latest/APIReference/): Describes all the API operations for AWS Sign-In in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
