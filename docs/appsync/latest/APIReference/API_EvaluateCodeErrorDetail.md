# EvaluateCodeErrorDetail
<a name="API_EvaluateCodeErrorDetail"></a>

Contains the list of errors from a code evaluation response.

## Contents
<a name="API_EvaluateCodeErrorDetail_Contents"></a>

 ** codeErrors **   <a name="appsync-Type-EvaluateCodeErrorDetail-codeErrors"></a>
Contains the list of `CodeError` objects.
Type: Array of [CodeError](API_CodeError.md) objects
Required: No

 ** message **   <a name="appsync-Type-EvaluateCodeErrorDetail-message"></a>
The error payload.
Type: String
Required: No
