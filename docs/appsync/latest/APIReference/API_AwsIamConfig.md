# AwsIamConfig
<a name="API_AwsIamConfig"></a>

The AWS Identity and Access Management (IAM) configuration.

## Contents
<a name="API_AwsIamConfig_Contents"></a>

 ** signingRegion **   <a name="appsync-Type-AwsIamConfig-signingRegion"></a>
The signing AWS Region for IAM authorization.
Type: String
Required: No

 ** signingServiceName **   <a name="appsync-Type-AwsIamConfig-signingServiceName"></a>
The signing service name for IAM authorization.
Type: String
Required: No
