# Runtime features
<a name="runtime-features-overview"></a>

The APPSYNC\_JS runtime environment provides features and utilities to help you work with data, and write functions and AWS AppSync Event API handlers. The topics in this section describe the language features that are supported for AWS AppSync Event APIs.
