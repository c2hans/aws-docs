# Document history
<a name="doc-history"></a>

The following table describes the documentation changes for the *AWS AppSync Developer Guide* since July 18, 2024. For notification about updates to this documentation, you can subscribe to an RSS feed.

| Change | Description | Date |
| --- |--- |--- |
| [Resolver context `sourceIp` ordering](#doc-history) | Added information about the order of `sourceIp` entries in the resolver context and how the `x-forwarded-for` header affects them, so you can use the correct address for authorization decisions. For more information, see [AWS AppSync JavaScript resolver context object reference](https://docs.aws.amazon.com/appsync/latest/devguide/resolver-context-reference-js.html) and [AWS AppSync resolver mapping template context reference](https://docs.aws.amazon.com/appsync/latest/devguide/resolver-context-reference.html). | October 7, 2026 |
| [CloudWatch metric dimension notes](#doc-history) | Added information about the `ApiId` and `EventAPIId` dimensions that Amazon CloudWatch uses for AWS AppSync GraphQL API and Event API metrics, so you can filter metrics by API type. For more information, see [Using CloudWatch to monitor and log GraphQL API data](https://docs.aws.amazon.com/appsync/latest/devguide/monitoring.html). | September 3, 2026 |
| [Resolver removal troubleshooting](#doc-history) | Added information about why AWS AppSync removes a resolver when you remove the schema field it is attached to, and how AWS CloudFormation tracks that resolver afterward, so you can recover from missing resolvers after a schema change. For more information, see [Troubleshooting and common mistakes in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/troubleshooting-and-common-mistakes.html). | September 1, 2026 |
| [Merged API shared-field authorization](#doc-history) | Added information about how the `@canonical` directive and authorization modes apply to shared fields in AWS AppSync Merged APIs, so you can control access to fields that multiple source APIs contribute. For more information, see [Merging APIs in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/merged-api.html). | August 21, 2026 |
| [Support for Amazon Bedrock runtime](#doc-history) | Added documentation for the Amazon Bedrock runtime in AWS AppSync JavaScript resolvers and functions, so you can invoke foundation models and inference profiles directly from your API and shape your request and response payloads before returning them to your clients. For more information, see [AWS AppSync JavaScript resolver and function reference for Amazon Bedrock runtime](https://docs.aws.amazon.com/appsync/latest/devguide/resolver-reference-bedrock-js.html). | April 16, 2026 |
| [Powertools for AWS Lambda GraphQL handler](#doc-history) | Added information about the Powertools for AWS Lambda GraphQL event handler, so you can simplify the routing and processing of GraphQL events in your Lambda resolvers. For more information, see [Using AWS Lambda resolvers in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/tutorial-lambda-resolvers-js.html) and [Using AWS Lambda resolvers in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/tutorial-lambda-resolvers.html). | April 16, 2026 |
| [Lambda authorizer timeout guidance](#doc-history) | Updated documentation for Lambda authorizer timeout behavior, so you can design authorizer functions that run quickly enough to scale your API under peak traffic. For more information, see [Configuring authorization and authentication to secure your GraphQL APIs](https://docs.aws.amazon.com/appsync/latest/devguide/security-authz.html). | April 16, 2026 |
| [HTTP header utilities for resolvers](#doc-history) | Added information about HTTP header utilities for resolvers and functions, so you can copy request headers and set response headers with `copyHeaders`, `addResponseHeader`, and `addResponseHeaders`. AWS AppSync ignores invalid response headers and returns a `ResponseHeaderError`. For more information, see [AWS AppSync JavaScript runtime features for resolvers and functions](https://docs.aws.amazon.com/appsync/latest/devguide/resolver-util-reference-js.html) and [AWS AppSync resolver mapping template utility reference](https://docs.aws.amazon.com/appsync/latest/devguide/resolver-util-reference.html). | April 16, 2026 |
| [DynamoDB condition check handling](#doc-history) | Added information about how the AWS AppSync DynamoDB resolver handles condition check failures, so you can manage common edge cases such as the `Reject` strategy. For more information, see [AWS AppSync resolver mapping template reference for DynamoDB](https://docs.aws.amazon.com/appsync/latest/devguide/resolver-mapping-template-reference-dynamodb.html) and [AWS AppSync JavaScript resolver function reference for DynamoDB](https://docs.aws.amazon.com/appsync/latest/devguide/js-resolver-reference-dynamodb.html). | April 16, 2026 |
| [AWS PrivateLink for Private APIs](#doc-history) | Added documentation for AWS PrivateLink support in AWS AppSync, so you can access data plane and control plane operations privately without traffic leaving the AWS network. You can manage AWS AppSync resources from your VPC using the AWS CLI or SDKs. For more information, see [Using AWS AppSync Private APIs](https://docs.aws.amazon.com/appsync/latest/devguide/using-private-apis.html). | April 16, 2026 |
| [AWS AppSync Merged API considerations](#doc-history) | Added information about design and performance considerations for Merged APIs, so you can test and optimize your merged schemas under realistic load. For more information, see [Merging APIs in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/merged-api.html). | December 18, 2025 |
| [Real-time subscription updates](#doc-history) | Added information about the WebSocket handshake and the authorization header formats for real-time subscriptions in AWS AppSync. You can also use arguments to filter GraphQL subscriptions for real-time data. For more information, see [Using subscriptions for real-time data applications in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/aws-appsync-real-time-data.html). | July 4, 2025 |
| [Aurora Serverless v2 Data API](#doc-history) | Added documentation for connecting your GraphQL API to Amazon Aurora PostgreSQL databases through the Data API, so you can run SQL queries and mutations against Aurora Serverless v2 clusters. The tutorials also cover how to create and configure a cluster and connect it to your API. For more information, see [Using Aurora PostgreSQL with Data API in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/aurora-serverless-tutorial-js.html) and [Using Aurora Serverless v2 with AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/tutorial-rds-resolvers.html). | June 25, 2025 |
| [Server-side cache encryption](#doc-history) | Updated documentation for server-side caching in AWS AppSync to explain that encryption at rest and in transit is always enabled for new caches and can't be disabled. For more information, see [Configuring server-side caching and API payload compression in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/enabling-caching.html). | June 9, 2025 |
| [API configuration change propagation](#doc-history) | Added information about how AWS AppSync propagates API configuration changes and about authentication security best practices for your GraphQL APIs. For more information, see [Configuring authorization and authentication to secure your GraphQL APIs](https://docs.aws.amazon.com/appsync/latest/devguide/security-authz.html) and [Security best practices for AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/best-practices.html). | May 7, 2025 |
| [Lambda authorizer response caching](#doc-history) | Added information about how AWS AppSync caches Lambda authorizer responses and validates the JWT issuer for APIs that use multiple authorization types. For more information, see [Configuring authorization and authentication to secure your GraphQL APIs](https://docs.aws.amazon.com/appsync/latest/devguide/security-authz.html) and [Sharing AWS AppSync GraphQL APIs](https://docs.aws.amazon.com/appsync/latest/devguide/sharing-graphql-apis.html). | April 1, 2025 |
| [Server-side caching and compression](#doc-history) | Updated documentation for server-side caching and API payload compression in AWS AppSync, so you can improve performance and reduce your data transfer charges. Added information about operation-level caching, so you can cache entire GraphQL query operation responses until their TTL expires. For more information, see [Configuring server-side caching and API payload compression in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/enabling-caching.html). | February 11, 2025 |
| [CloudTrail requestID guidance](#doc-history) | Added information about the `requestID` field in AWS CloudTrail logs, noting that it isn't an authoritative unique identifier because clients can overwrite it. For more information, see [Logging AWS AppSync API calls using AWS CloudTrail](https://docs.aws.amazon.com/appsync/latest/devguide/cloudtrail-logging.html). | January 24, 2025 |
| [Log size limits](#doc-history) | Added information about the default 1 MB log size limit per request, so you can reduce log sizes by choosing the `ERROR` logging level or disabling `VERBOSE` field-level logs. For more information, see [Using CloudWatch to monitor and log GraphQL API data](https://docs.aws.amazon.com/appsync/latest/devguide/monitoring.html). | December 17, 2024 |
| [Sharing AWS AppSync GraphQL APIs](#doc-history) | Added documentation for sharing your AWS AppSync GraphQL APIs across accounts through AWS Resource Access Manager, so you can grant other accounts access to invoke operations on your APIs. For more information, see [Sharing AWS AppSync GraphQL APIs](https://docs.aws.amazon.com/appsync/latest/devguide/sharing-graphql-apis.html). | November 22, 2024 |
| [GraphQL API logging](#doc-history) | Added information about logging AWS AppSync data events for the `AWS::AppSync::GraphQL` resource type with AWS CloudTrail, so you can record resource operations on your GraphQL APIs. You can also set field-level CloudWatch logging levels and use the `$util.log.debug` utility to log messages from your resolvers. For more information, see [Logging AWS AppSync API calls using AWS CloudTrail](https://docs.aws.amazon.com/appsync/latest/devguide/cloudtrail-logging.html), [Using CloudWatch to monitor and log GraphQL API data](https://docs.aws.amazon.com/appsync/latest/devguide/monitoring.html), and [AWS AppSync resolver mapping template utility reference](https://docs.aws.amazon.com/appsync/latest/devguide/resolver-util-reference.html). | November 19, 2024 |
| [DynamoDB batch and transaction limits](#doc-history) | Added information about conflict detection and resolution constraints for the DynamoDB `BatchPutItem`, `BatchDeleteItem`, and `TransactWriteItems` operations, so you can disable these settings to prevent errors. For more information, see [Using DynamoDB batch operations in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/tutorial-dynamodb-batch-js.html), [Using DynamoDB batch operations in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/tutorial-dynamodb-batch.html), [Performing DynamoDB transactions in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/tutorial-dynamodb-transact-js.html), and [Performing DynamoDB transactions in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/tutorial-dynamodb-transact.html). | August 2, 2024 |
| [CloudWatch per-resolver metrics](#doc-history) | Added information about per-resolver CloudWatch metrics, including `GraphQLError`, `Request`, `Latency`, and `CacheHit`, so you can monitor individual resolver performance. For more information, see [Using CloudWatch to monitor and log GraphQL API data](https://docs.aws.amazon.com/appsync/latest/devguide/monitoring.html), [Building GraphQL APIs with RDS introspection](https://docs.aws.amazon.com/appsync/latest/devguide/rds-introspection.html), [Using subscriptions for real-time data applications in AWS AppSync](https://docs.aws.amazon.com/appsync/latest/devguide/aws-appsync-real-time-data.html), [AWS AppSync resolver mapping template context reference](https://docs.aws.amazon.com/appsync/latest/devguide/resolver-context-reference.html), [AWS AppSync resolver mapping template reference for DynamoDB](https://docs.aws.amazon.com/appsync/latest/devguide/resolver-mapping-template-reference-dynamodb.html), and [AWS AppSync resolver mapping template reference for OpenSearch](https://docs.aws.amazon.com/appsync/latest/devguide/resolver-mapping-template-reference-elasticsearch.html). | July 18, 2024 |
