# Eirp
<a name="API_Eirp"></a>

Object that represents EIRP.

## Contents
<a name="API_Eirp_Contents"></a>

 ** units **   <a name="groundstation-Type-Eirp-units"></a>
Units of an EIRP.
Type: String
Valid Values: `dBW`
Required: Yes

 ** value **   <a name="groundstation-Type-Eirp-value"></a>
Value of an EIRP. Valid values are between 20.0 to 50.0 dBW.
Type: Double
Required: Yes
