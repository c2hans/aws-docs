# OemProgramTrackSettings
<a name="API_OemProgramTrackSettings"></a>

Program track settings for [OEMEphemeris](API_OEMEphemeris.md).

## Contents
<a name="API_OemProgramTrackSettings_Contents"></a>

 ** ephemerisId **   <a name="groundstation-Type-OemProgramTrackSettings-ephemerisId"></a>
Unique identifier of the OEM ephemeris.
Type: String
Length Constraints: Fixed length of 36.
Pattern: `[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}`
Required: Yes
