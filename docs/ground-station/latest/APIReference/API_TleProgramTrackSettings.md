# TleProgramTrackSettings
<a name="API_TleProgramTrackSettings"></a>

Program track settings for [TLEEphemeris](API_TLEEphemeris.md).

## Contents
<a name="API_TleProgramTrackSettings_Contents"></a>

 ** ephemerisId **   <a name="groundstation-Type-TleProgramTrackSettings-ephemerisId"></a>
Unique identifier of the TLE ephemeris.
Type: String
Length Constraints: Fixed length of 36.
Pattern: `[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}`
Required: Yes
