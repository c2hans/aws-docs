# DecodeConfig

 ** unvalidatedJSON **   <a name="groundstation-Type-DecodeConfig-unvalidatedJSON"></a>
Unvalidated JSON of a decode `Config`.
Type: String
Length Constraints: Minimum length of 2. Maximum length of 8192.
Pattern: `[{}\[\]:.,"0-9A-Za-z\-_\s]{2,8192}`
Required: Yes
