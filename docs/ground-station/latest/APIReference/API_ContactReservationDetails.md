# ContactReservationDetails
<a name="API_ContactReservationDetails"></a>

Details of a contact reservation.

## Contents
<a name="API_ContactReservationDetails_Contents"></a>

 ** contactId **   <a name="groundstation-Type-ContactReservationDetails-contactId"></a>
UUID of a contact.
Type: String
Length Constraints: Fixed length of 36.
Pattern: `[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}`
Required: No
