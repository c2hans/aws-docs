# AWS Ground Station Documentation

AWS Ground Station is a fully managed service that enables you to control satellite communications, process satellite data, and scale your satellite operations. With AWS Ground Station, you don't have to build or manage your own ground station infrastructure.

- [API Reference](/ground-station/latest/APIReference/): Describes all the API operations for AWS Ground Station in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
- [AWS Ground Station in the AWS CLI Reference](/cli/latest/reference/groundstation/index.html): Describes the Ground Station commands in the AWS CLI that you can use to schedule contacts from a ground station location. Provides syntax, options, and usage examples for each command.
