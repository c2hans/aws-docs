# Data Types
<a name="API_Types"></a>

The Timestream InfluxDB API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [DbClusterSummary](API_DbClusterSummary.md)
+  [DbInstanceForClusterSummary](API_DbInstanceForClusterSummary.md)
+  [DbInstanceSummary](API_DbInstanceSummary.md)
+  [DbParameterGroupSummary](API_DbParameterGroupSummary.md)
+  [Duration](API_Duration.md)
+  [InfluxDBv2Parameters](API_InfluxDBv2Parameters.md)
+  [InfluxDBv3CoreParameters](API_InfluxDBv3CoreParameters.md)
+  [InfluxDBv3EnterpriseParameters](API_InfluxDBv3EnterpriseParameters.md)
+  [LogDeliveryConfiguration](API_LogDeliveryConfiguration.md)
+  [Parameters](API_Parameters.md)
+  [PercentOrAbsoluteLong](API_PercentOrAbsoluteLong.md)
+  [S3Configuration](API_S3Configuration.md)
