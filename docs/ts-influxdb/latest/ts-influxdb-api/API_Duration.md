# Duration
<a name="API_Duration"></a>

Duration for InfluxDB parameters in Timestream for InfluxDB.

## Contents
<a name="API_Duration_Contents"></a>

 ** durationType **   <a name="tsinfluxdb-Type-Duration-durationType"></a>
The type of duration for InfluxDB parameters.
Type: String
Valid Values: `hours | minutes | seconds | milliseconds | days`
Required: Yes

 ** value **   <a name="tsinfluxdb-Type-Duration-value"></a>
The value of duration for InfluxDB parameters.
Type: Long
Valid Range: Minimum value of 0.
Required: Yes
