# ServiceOperationEntity
<a name="API_ServiceOperationEntity"></a>

A structure that contains identifying information for a service operation entity.

## Contents
<a name="API_ServiceOperationEntity_Contents"></a>

 ** MetricType **   <a name="applicationsignals-Type-ServiceOperationEntity-MetricType"></a>
The type of metric associated with this service operation.
Type: String
Required: No

 ** Operation **   <a name="applicationsignals-Type-ServiceOperationEntity-Operation"></a>
The name of the operation.
Type: String
Required: No

 ** Service **   <a name="applicationsignals-Type-ServiceOperationEntity-Service"></a>
The service entity that contains this operation.
Type: [ServiceEntity](API_ServiceEntity.md) object
Required: No
