# RecurrenceRule
<a name="API_RecurrenceRule"></a>

The recurrence rule for the SLO time window exclusion .

## Contents
<a name="API_RecurrenceRule_Contents"></a>

 ** Expression **   <a name="applicationsignals-Type-RecurrenceRule-Expression"></a>
A cron or rate expression that specifies the schedule for the exclusion window.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1024.
Required: Yes
