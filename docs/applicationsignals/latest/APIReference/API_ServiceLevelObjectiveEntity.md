# ServiceLevelObjectiveEntity
<a name="API_ServiceLevelObjectiveEntity"></a>

A structure that contains identifying information for a service level objective entity.

## Contents
<a name="API_ServiceLevelObjectiveEntity_Contents"></a>

 ** SloArn **   <a name="applicationsignals-Type-ServiceLevelObjectiveEntity-SloArn"></a>
The ARN of the service level objective. The SLO must be provided with ARN for cross-account access.
Type: String
Required: No

 ** SloName **   <a name="applicationsignals-Type-ServiceLevelObjectiveEntity-SloName"></a>
The name of the service level objective.
Type: String
Required: No
