# Document history for the Amazon Route 53 Global Resolver User Guide
<a name="doc-history"></a>

The following table describes the documentation releases for Route 53 Global Resolver.

| Change | Description | Date |
| --- |--- |--- |
| [Route 53 Global Resolver now supports core network endpoints](#doc-history) | You can connect a global resolver to an AWS Cloud WAN (Cloud WAN) core network with a core network endpoint, so that the core network's segments can be used as access sources for DNS resolution. For more information about core network endpoints, see [Core network endpoints](https://docs.aws.amazon.com/core-network-endpoints.html). | December 1, 2026 |
| [Route 53 Global Resolver has released a new managed policy](#doc-history) | Route 53 Global Resolver has released a new managed policy `AmazonRoute53GlobalResolverFullAccess` that provides full administrative access to Route 53 Global Resolver resources. For information, see [Route 53 Global Resolver updates to AWS managed policies](https://docs.aws.amazon.com/security-iam-awsmanpol.html#security-iam-awsmanpol-updates). | February 5, 2026 |
| [Route 53 Global Resolver has released a new managed policy](#doc-history) | Route 53 Global Resolver has released a new managed policy `AmazonRoute53GlobalResolverReadOnlyAccess` that provides read-only access to Route 53 Global Resolver resources. | January 7, 2026 |
| [Initial release](#doc-history) | Initial release of the Amazon Route 53 Global Resolver User Guide | December 31, 2020 |
