# Data Types
<a name="API_Types"></a>

The Service Quotas API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [ErrorReason](API_ErrorReason.md)
+  [MetricInfo](API_MetricInfo.md)
+  [QuotaContextInfo](API_QuotaContextInfo.md)
+  [QuotaInfo](API_QuotaInfo.md)
+  [QuotaPeriod](API_QuotaPeriod.md)
+  [QuotaUtilizationInfo](API_QuotaUtilizationInfo.md)
+  [RequestedServiceQuotaChange](API_RequestedServiceQuotaChange.md)
+  [ServiceInfo](API_ServiceInfo.md)
+  [ServiceQuota](API_ServiceQuota.md)
+  [ServiceQuotaIncreaseRequestInTemplate](API_ServiceQuotaIncreaseRequestInTemplate.md)
+  [Tag](API_Tag.md)
