# QuotaPeriod
<a name="API_QuotaPeriod"></a>

Information about the quota period.

## Contents
<a name="API_QuotaPeriod_Contents"></a>

 ** PeriodUnit **   <a name="servicequotas-Type-QuotaPeriod-PeriodUnit"></a>
The time unit.
Type: String
Valid Values: `MICROSECOND | MILLISECOND | SECOND | MINUTE | HOUR | DAY | WEEK`
Required: No

 ** PeriodValue **   <a name="servicequotas-Type-QuotaPeriod-PeriodValue"></a>
The value associated with the reported `PeriodUnit`.
Type: Integer
Required: No
