# Firewall rule group capacity
<a name="rule-group-capacity-firewall"></a>

Estimate a firewall rule group's capacity as the number of rules that you expect to have in it during its lifetime. You can't change this setting after you create the rule group.

The maximum capacity setting for a firewall rule group is 30,000.
