# Classic Network Firewall policies in AWS Network Firewall
<a name="firewall-policies-classic"></a>

A Classic Network Firewall policy filters traffic using a stateless engine and a stateful engine. The following sections describe the Classic policy settings and how to create, update, and delete a Classic policy. For new firewalls, **Next Generation** policies are recommended; see [Next Generation policies](firewall-policies-v2.md).
