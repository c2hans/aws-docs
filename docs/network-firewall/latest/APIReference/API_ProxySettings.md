# ProxySettings
<a name="API_ProxySettings"></a>

The listener configuration for a proxy mode firewall. This specifies the ports and protocols on which the firewall's proxy listens for traffic.

## Contents
<a name="API_ProxySettings_Contents"></a>

 ** ListenerProperties **   <a name="networkfirewall-Type-ProxySettings-ListenerProperties"></a>
Listener properties for HTTP and HTTPS traffic.
Type: Array of [ListenerProperty](API_ListenerProperty.md) objects
Required: Yes
