# AWS Toolkit for Microsoft Azure DevOps Documentation

The AWS Toolkit for Azure DevOps contains tasks you can use in build and release definitions in Azure DevOps to interact with AWS services. The AWS Toolkit for Azure DevOps is available through the Visual Studio Marketplace.

- [User Guide](/vsts/latest/userguide/): Describes the various features of the AWS Toolkit for Azure DevOps and how to use them.
- [AWS Code Examples Repository](https://github.com/awsdocs/aws-doc-sdk-examples): Contains code examples and other types of examples to help accelerate your development of applications that work with AWS services. The examples show how to perform specific tasks for AWS services using various programming languages and supported technologies.
