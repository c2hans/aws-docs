# Release: Elastic Beanstalk Amazon Linux 2023 PHP platform updates for PHP 8.5 and PHP 8.4 on October 21, 2026
<a name="release-2026-10-21-al2023-php84-php85"></a>

This release provides new versions for AWS Elastic Beanstalk PHP 8.5 and PHP 8.4 platforms based on Amazon Linux 2023. The release includes security updates. It also includes PHP updates, and restores the default values of two PHP configuration settings.

**Release date:** October 21, 2026
