# Release: Elastic Beanstalk Amazon Linux 2023 platform updates on March 26, 2024
<a name="release-2024-03-26-al2023"></a>

This release provides new versions for AWS Elastic Beanstalk platforms based on Amazon Linux 2023. The release includes security updates. It also includes AMI, Docker, ECS based Docker, Corretto, .NET Core, and Node.js updates.

**Release date:** March 26, 2024

## Changes
<a name="release-2024-03-26-al2023.changes"></a>

The following table lists the changes included in this release.

**Notes**
These release notes focus on changes to currently supported platform branches. For full version information of Elastic Beanstalk retiring (deprecated) platform branches, see [Elastic Beanstalk platform versions scheduled for retirement](https://docs.aws.amazon.com/elasticbeanstalk/latest/platforms/platforms-retiring.html) in the *AWS Elastic Beanstalk Platforms* guide.
Be aware that at the time these release notes are published, the new platform versions might not yet be available in all the AWS Regions that Elastic Beanstalk supports. It might take a few hours for the release to complete.

| **Category** | **Description** |
| --- | --- |
| **Component** | **Update** |
| --- | --- |
| **Platform** | **Update** |

| **Security updates** | Applied all security updates published in the [Amazon Linux Security Center](https://alas.aws.amazon.com/alas2023.html) on or before **March 26, 2024** to all AL2023 platforms.<br />  |
| **Cross-platform updates** | Made these cross-platform updates:[See the AWS documentation website for more details](http://docs.aws.amazon.com/elasticbeanstalk/latest/relnotes/release-2024-03-26-al2023.html) |

| **Node.js** | **Language runtime updates**+  Updated Node.js 20 to version [20.11.1](https://nodejs.org/en/blog/release/v20.11.1) <br />This is a security release.<br /> **Additional changes to the Node.js platform branch with this release** +  Starting with this release, the `npx` command is available by default on the Node.js 20 platform branch. [Previously](release-2024-01-25-al2023.md) it was only available as the `npx-20` command.  |
