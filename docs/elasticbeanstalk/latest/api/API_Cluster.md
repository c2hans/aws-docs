# Cluster
<a name="API_Cluster"></a>

Describes the Amazon EKS cluster that an environment runs on.

## Contents
<a name="API_Cluster_Contents"></a>

 ** ClusterArn **
The Amazon Resource Name (ARN) of the Amazon EKS cluster.
Type: String
Required: No
