# CustomAmi
<a name="API_CustomAmi"></a>

A custom AMI available to platforms.

## Contents
<a name="API_CustomAmi_Contents"></a>

 ** ImageId **
THe ID of the image used to create the custom AMI.
Type: String
Required: No

 ** VirtualizationType **
The type of virtualization used to create the custom AMI.
Type: String
Required: No
