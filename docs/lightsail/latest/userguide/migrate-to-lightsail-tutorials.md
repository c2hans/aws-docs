# Migrate to Lightsail
<a name="migrate-to-lightsail-tutorials"></a>

This section covers the following topics related to migrating to Lightsail:

**Topics**
+ [Migrate your WordPress blog to Lightsail](migrate-your-wordpress-blog-to-amazon-lightsail.md)
+ [Migrating from Bitnami blueprints to Lightsail blueprints](migrate-from-bitnami-to-lightsail-blueprints.md)

Follow the step-by-step instructions to migrate your existing WordPress blog or Bitnami-based instance to Lightsail. The tutorials cover backing up your application data, creating a new instance with a Lightsail blueprint, restoring your content, and updating DNS settings.
