# ResourceRecord
<a name="API_ResourceRecord"></a>

Describes the domain name system (DNS) records to add to your domain's DNS to validate it for an Amazon Lightsail certificate.

## Contents
<a name="API_ResourceRecord_Contents"></a>

 ** name **   <a name="Lightsail-Type-ResourceRecord-name"></a>
The name of the record.
Type: String
Required: No

 ** type **   <a name="Lightsail-Type-ResourceRecord-type"></a>
The DNS record type.
Type: String
Required: No

 ** value **   <a name="Lightsail-Type-ResourceRecord-value"></a>
The value for the DNS record.
Type: String
Required: No
