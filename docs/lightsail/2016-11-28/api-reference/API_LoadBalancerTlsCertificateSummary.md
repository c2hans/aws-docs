# LoadBalancerTlsCertificateSummary
<a name="API_LoadBalancerTlsCertificateSummary"></a>

Provides a summary of SSL/TLS certificate metadata.

## Contents
<a name="API_LoadBalancerTlsCertificateSummary_Contents"></a>

 ** isAttached **   <a name="Lightsail-Type-LoadBalancerTlsCertificateSummary-isAttached"></a>
When `true`, the SSL/TLS certificate is attached to the Lightsail load balancer.
Type: Boolean
Required: No

 ** name **   <a name="Lightsail-Type-LoadBalancerTlsCertificateSummary-name"></a>
The name of the SSL/TLS certificate.
Type: String
Pattern: `\w[\w\-]*\w`
Required: No
