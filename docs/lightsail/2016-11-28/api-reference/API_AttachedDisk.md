# AttachedDisk
<a name="API_AttachedDisk"></a>

Describes a block storage disk that is attached to an instance, and is included in an automatic snapshot.

## Contents
<a name="API_AttachedDisk_Contents"></a>

 ** path **   <a name="Lightsail-Type-AttachedDisk-path"></a>
The path of the disk (`/dev/xvdf`).
Type: String
Required: No

 ** sizeInGb **   <a name="Lightsail-Type-AttachedDisk-sizeInGb"></a>
The size of the disk in GB.
Type: Integer
Required: No
