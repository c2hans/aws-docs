# RelationalDatabaseHardware
<a name="API_RelationalDatabaseHardware"></a>

Describes the hardware of a database.

## Contents
<a name="API_RelationalDatabaseHardware_Contents"></a>

 ** cpuCount **   <a name="Lightsail-Type-RelationalDatabaseHardware-cpuCount"></a>
The number of vCPUs for the database.
Type: Integer
Required: No

 ** diskSizeInGb **   <a name="Lightsail-Type-RelationalDatabaseHardware-diskSizeInGb"></a>
The size of the disk for the database.
Type: Integer
Required: No

 ** ramSizeInGb **   <a name="Lightsail-Type-RelationalDatabaseHardware-ramSizeInGb"></a>
The amount of RAM in GB for the database.
Type: Float
Required: No
