# InstanceState
<a name="API_InstanceState"></a>

Describes the virtual private server (or *instance*) status.

## Contents
<a name="API_InstanceState_Contents"></a>

 ** code **   <a name="Lightsail-Type-InstanceState-code"></a>
The status code for the instance.
Type: Integer
Required: No

 ** name **   <a name="Lightsail-Type-InstanceState-name"></a>
The state of the instance (`running` or `pending`).
Type: String
Required: No
