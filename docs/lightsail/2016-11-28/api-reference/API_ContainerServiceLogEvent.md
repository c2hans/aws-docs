# ContainerServiceLogEvent
<a name="API_ContainerServiceLogEvent"></a>

Describes the log events of a container of an Amazon Lightsail container service.

## Contents
<a name="API_ContainerServiceLogEvent_Contents"></a>

 ** createdAt **   <a name="Lightsail-Type-ContainerServiceLogEvent-createdAt"></a>
The timestamp when the container service log event was created.
Type: Timestamp
Required: No

 ** message **   <a name="Lightsail-Type-ContainerServiceLogEvent-message"></a>
The message of the container service log event.
Type: String
Required: No
