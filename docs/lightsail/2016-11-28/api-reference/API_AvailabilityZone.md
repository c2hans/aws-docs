# AvailabilityZone
<a name="API_AvailabilityZone"></a>

Describes an Availability Zone. This is returned only as part of a `GetRegions` request.

## Contents
<a name="API_AvailabilityZone_Contents"></a>

 ** state **   <a name="Lightsail-Type-AvailabilityZone-state"></a>
The state of the Availability Zone.
Type: String
Pattern: `.*\S.*`
Required: No

 ** zoneName **   <a name="Lightsail-Type-AvailabilityZone-zoneName"></a>
The name of the Availability Zone. The format is `us-east-2a` (case-sensitive).
Type: String
Pattern: `.*\S.*`
Required: No
