# PendingModifiedRelationalDatabaseValues
<a name="API_PendingModifiedRelationalDatabaseValues"></a>

Describes a pending database value modification.

## Contents
<a name="API_PendingModifiedRelationalDatabaseValues_Contents"></a>

 ** backupRetentionEnabled **   <a name="Lightsail-Type-PendingModifiedRelationalDatabaseValues-backupRetentionEnabled"></a>
A Boolean value indicating whether automated backup retention is enabled.
Type: Boolean
Required: No

 ** engineVersion **   <a name="Lightsail-Type-PendingModifiedRelationalDatabaseValues-engineVersion"></a>
The database engine version.
Type: String
Required: No

 ** masterUserPassword **   <a name="Lightsail-Type-PendingModifiedRelationalDatabaseValues-masterUserPassword"></a>
The password for the master user of the database.
Type: String
Required: No
