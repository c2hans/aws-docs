# RelationalDatabaseEndpoint
<a name="API_RelationalDatabaseEndpoint"></a>

Describes an endpoint for a database.

## Contents
<a name="API_RelationalDatabaseEndpoint_Contents"></a>

 ** address **   <a name="Lightsail-Type-RelationalDatabaseEndpoint-address"></a>
Specifies the DNS address of the database.
Type: String
Pattern: `.*\S.*`
Required: No

 ** port **   <a name="Lightsail-Type-RelationalDatabaseEndpoint-port"></a>
Specifies the port that the database is listening on.
Type: Integer
Required: No
