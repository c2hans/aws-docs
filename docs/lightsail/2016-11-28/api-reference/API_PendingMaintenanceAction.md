# PendingMaintenanceAction
<a name="API_PendingMaintenanceAction"></a>

Describes a pending database maintenance action.

## Contents
<a name="API_PendingMaintenanceAction_Contents"></a>

 ** action **   <a name="Lightsail-Type-PendingMaintenanceAction-action"></a>
The type of pending database maintenance action.
Type: String
Pattern: `.*\S.*`
Required: No

 ** currentApplyDate **   <a name="Lightsail-Type-PendingMaintenanceAction-currentApplyDate"></a>
The effective date of the pending database maintenance action.
Type: Timestamp
Required: No

 ** description **   <a name="Lightsail-Type-PendingMaintenanceAction-description"></a>
Additional detail about the pending database maintenance action.
Type: String
Pattern: `.*\S.*`
Required: No
