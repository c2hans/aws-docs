# MonthlyTransfer
<a name="API_MonthlyTransfer"></a>

Describes the monthly data transfer in and out of your virtual private server (or *instance*).

## Contents
<a name="API_MonthlyTransfer_Contents"></a>

 ** gbPerMonthAllocated **   <a name="Lightsail-Type-MonthlyTransfer-gbPerMonthAllocated"></a>
The amount allocated per month (in GB).
Type: Integer
Required: No
