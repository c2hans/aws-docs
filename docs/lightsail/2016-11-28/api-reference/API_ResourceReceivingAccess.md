# ResourceReceivingAccess
<a name="API_ResourceReceivingAccess"></a>

Describes an Amazon Lightsail instance that has access to a Lightsail bucket.

## Contents
<a name="API_ResourceReceivingAccess_Contents"></a>

 ** name **   <a name="Lightsail-Type-ResourceReceivingAccess-name"></a>
The name of the Lightsail instance.
Type: String
Pattern: `.*\S.*`
Required: No

 ** resourceType **   <a name="Lightsail-Type-ResourceReceivingAccess-resourceType"></a>
The Lightsail resource type (for example, `Instance`).
Type: String
Pattern: `.*\S.*`
Required: No
