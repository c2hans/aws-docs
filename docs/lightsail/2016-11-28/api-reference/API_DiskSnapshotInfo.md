# DiskSnapshotInfo
<a name="API_DiskSnapshotInfo"></a>

<a name="API_DiskSnapshotInfo_Contents"></a>

 ** sizeInGb **   <a name="Lightsail-Type-DiskSnapshotInfo-sizeInGb"></a>

Type: Integer
Required: No
