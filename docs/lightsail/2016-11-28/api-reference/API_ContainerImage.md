# ContainerImage
<a name="API_ContainerImage"></a>

Describes a container image that is registered to an Amazon Lightsail container service.

## Contents
<a name="API_ContainerImage_Contents"></a>

 ** createdAt **   <a name="Lightsail-Type-ContainerImage-createdAt"></a>
The timestamp when the container image was created.
Type: Timestamp
Required: No

 ** digest **   <a name="Lightsail-Type-ContainerImage-digest"></a>
The digest of the container image.
Type: String
Required: No

 ** image **   <a name="Lightsail-Type-ContainerImage-image"></a>
The name of the container image.
Type: String
Required: No
