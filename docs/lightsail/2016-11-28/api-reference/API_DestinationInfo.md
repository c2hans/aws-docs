# DestinationInfo
<a name="API_DestinationInfo"></a>

Describes the destination of a record.

## Contents
<a name="API_DestinationInfo_Contents"></a>

 ** id **   <a name="Lightsail-Type-DestinationInfo-id"></a>
The ID of the resource created at the destination.
Type: String
Pattern: `.*\S.*`
Required: No

 ** service **   <a name="Lightsail-Type-DestinationInfo-service"></a>
The destination service of the record.
Type: String
Pattern: `.*\S.*`
Required: No
