# GatewayElbAccessLogS3Destination
<a name="API_GatewayElbAccessLogS3Destination"></a>

The Amazon S3 destination for the access logs of a gateway's load balancers.

## Contents
<a name="API_GatewayElbAccessLogS3Destination_Contents"></a>

 ** bucket **   <a name="ECS-Type-GatewayElbAccessLogS3Destination-bucket"></a>
The name of the Amazon S3 bucket where access logs are delivered.
Type: String
Required: Yes

 ** prefix **   <a name="ECS-Type-GatewayElbAccessLogS3Destination-prefix"></a>
The object key prefix for the access logs in the Amazon S3 bucket.
Type: String
Required: No
