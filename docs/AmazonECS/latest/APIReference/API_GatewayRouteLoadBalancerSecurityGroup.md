# GatewayRouteLoadBalancerSecurityGroup
<a name="API_GatewayRouteLoadBalancerSecurityGroup"></a>

A security group attached to the load balancer for a gateway route.

## Contents
<a name="API_GatewayRouteLoadBalancerSecurityGroup_Contents"></a>

 ** arn **   <a name="ECS-Type-GatewayRouteLoadBalancerSecurityGroup-arn"></a>
The Amazon Resource Name (ARN) of the security group.
Type: String
Required: No

 ** ruleArns **   <a name="ECS-Type-GatewayRouteLoadBalancerSecurityGroup-ruleArns"></a>
The Amazon Resource Names (ARNs) of the security group rules.
Type: Array of strings
Required: No
