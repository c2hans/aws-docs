# IngressPathSummary
<a name="API_IngressPathSummary"></a>

The entry point into an Express service.

## Contents
<a name="API_IngressPathSummary_Contents"></a>

 ** accessType **   <a name="ECS-Type-IngressPathSummary-accessType"></a>
The type of access to the endpoint for the Express service.
Type: String
Valid Values: `PUBLIC | PRIVATE`
Required: Yes

 ** endpoint **   <a name="ECS-Type-IngressPathSummary-endpoint"></a>
The endpoint for access to the service.
Type: String
Required: Yes
