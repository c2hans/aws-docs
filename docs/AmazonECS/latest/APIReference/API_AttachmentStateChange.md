# AttachmentStateChange
<a name="API_AttachmentStateChange"></a>

An object representing a change in state for a task attachment.

## Contents
<a name="API_AttachmentStateChange_Contents"></a>

 ** attachmentArn **   <a name="ECS-Type-AttachmentStateChange-attachmentArn"></a>
The Amazon Resource Name (ARN) of the attachment.
Type: String
Required: Yes

 ** status **   <a name="ECS-Type-AttachmentStateChange-status"></a>
The status of the attachment.
Type: String
Required: Yes
