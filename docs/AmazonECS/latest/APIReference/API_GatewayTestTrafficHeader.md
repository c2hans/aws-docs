# GatewayTestTrafficHeader
<a name="API_GatewayTestTrafficHeader"></a>

A header-based rule that identifies test traffic for progressive deployments.

## Contents
<a name="API_GatewayTestTrafficHeader_Contents"></a>

 ** name **   <a name="ECS-Type-GatewayTestTrafficHeader-name"></a>
The name of the header to match for test traffic routing.
Type: String
Required: Yes

 ** values **   <a name="ECS-Type-GatewayTestTrafficHeader-values"></a>
The header values to match for test traffic routing.
Type: Array of strings
Required: Yes
