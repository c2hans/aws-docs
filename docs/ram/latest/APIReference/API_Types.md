# Data Types
<a name="API_Types"></a>

The AWS RAM API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AssociatedPermission](API_AssociatedPermission.md)
+  [AssociatedSource](API_AssociatedSource.md)
+  [Principal](API_Principal.md)
+  [ReplacePermissionAssociationsWork](API_ReplacePermissionAssociationsWork.md)
+  [Resource](API_Resource.md)
+  [ResourceShare](API_ResourceShare.md)
+  [ResourceShareAssociation](API_ResourceShareAssociation.md)
+  [ResourceShareConfiguration](API_ResourceShareConfiguration.md)
+  [ResourceShareInvitation](API_ResourceShareInvitation.md)
+  [ResourceSharePermissionDetail](API_ResourceSharePermissionDetail.md)
+  [ResourceSharePermissionSummary](API_ResourceSharePermissionSummary.md)
+  [ServiceNameAndResourceType](API_ServiceNameAndResourceType.md)
+  [Tag](API_Tag.md)
+  [TagFilter](API_TagFilter.md)
