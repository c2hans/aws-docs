# ResourceShareConfiguration
<a name="API_ResourceShareConfiguration"></a>

The configuration of the resource share

## Contents
<a name="API_ResourceShareConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** retainSharingOnAccountLeaveOrganization **   <a name="ram-Type-ResourceShareConfiguration-retainSharingOnAccountLeaveOrganization"></a>
Specifies whether the consumer account retains access to the resource share after leaving the organization.
Type: Boolean
Required: No
