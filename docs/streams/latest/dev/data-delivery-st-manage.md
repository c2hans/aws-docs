# Manage streaming table deliveries
<a name="data-delivery-st-manage"></a>

 After you understand the prerequisites and IAM requirements, you can create and manage streaming table deliveries with the AWS Management Console or the AWS CLI. The following topics describe each operation. In the API and AWS CLI, a delivery is represented by a channel resource, so the operations use channel terminology (for example, `CreateChannel` and `DescribeChannel`).

**Topics**
+ [Create a streaming table delivery](data-delivery-st-create.md)
+ [Describe a streaming table delivery](data-delivery-st-describe.md)
+ [Update a streaming table delivery](data-delivery-st-update.md)
+ [Delete a streaming table delivery](data-delivery-st-delete.md)
+ [List streaming table deliveries](data-delivery-st-list.md)
