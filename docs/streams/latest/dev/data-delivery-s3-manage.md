# Manage Amazon S3 general purpose deliveries
<a name="data-delivery-s3-manage"></a>

 After you understand the prerequisites and IAM requirements, you can create and manage Amazon S3 deliveries with the AWS Management Console or the AWS CLI. The following topics describe each operation. In the API and AWS CLI, a delivery is represented by a channel resource, so the operations use channel terminology (for example, `CreateChannel` and `DescribeChannel`).

**Topics**
+ [Create an Amazon S3 delivery](data-delivery-s3-create.md)
+ [Describe an Amazon S3 delivery](data-delivery-s3-describe.md)
+ [Update an Amazon S3 delivery](data-delivery-s3-update.md)
+ [Delete an Amazon S3 delivery](data-delivery-s3-delete.md)
+ [List Amazon S3 deliveries](data-delivery-s3-list.md)
