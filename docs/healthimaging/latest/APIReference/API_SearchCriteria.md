# SearchCriteria
<a name="API_SearchCriteria"></a>

The search criteria.

## Contents
<a name="API_SearchCriteria_Contents"></a>

 ** filters **   <a name="healthimaging-Type-SearchCriteria-filters"></a>
The filters for the search criteria.
Type: Array of [SearchFilter](API_SearchFilter.md) objects
Array Members: Minimum number of 1 item. Maximum number of 2 items.
Required: No

 ** sort **   <a name="healthimaging-Type-SearchCriteria-sort"></a>
The sort input for search criteria.
Type: [Sort](API_Sort.md) object
Required: No
