# ImageFrameInformation
<a name="API_ImageFrameInformation"></a>

Information about the image frame (pixel data) identifier.

## Contents
<a name="API_ImageFrameInformation_Contents"></a>

 ** imageFrameId **   <a name="healthimaging-Type-ImageFrameInformation-imageFrameId"></a>
The image frame (pixel data) identifier.
Type: String
Pattern: `[0-9a-z]{32}`
Required: Yes
