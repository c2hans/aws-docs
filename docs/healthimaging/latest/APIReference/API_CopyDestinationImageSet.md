# CopyDestinationImageSet
<a name="API_CopyDestinationImageSet"></a>

Copy the destination image set.

## Contents
<a name="API_CopyDestinationImageSet_Contents"></a>

 ** imageSetId **   <a name="healthimaging-Type-CopyDestinationImageSet-imageSetId"></a>
The image set identifier for the destination image set.
Type: String
Pattern: `[0-9a-z]{32}`
Required: Yes

 ** latestVersionId **   <a name="healthimaging-Type-CopyDestinationImageSet-latestVersionId"></a>
The latest version identifier for the destination image set.
Type: String
Pattern: `\d+`
Required: Yes
