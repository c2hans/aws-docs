# Sort
<a name="API_Sort"></a>

Sort search results.

## Contents
<a name="API_Sort_Contents"></a>

 ** sortField **   <a name="healthimaging-Type-Sort-sortField"></a>
The sort field for search criteria.
Type: String
Valid Values: `updatedAt | createdAt | DICOMStudyDateAndTime`
Required: Yes

 ** sortOrder **   <a name="healthimaging-Type-Sort-sortOrder"></a>
The sort order for search criteria.
Type: String
Valid Values: `ASC | DESC`
Required: Yes
