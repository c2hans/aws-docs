# DicomJsonMetadataImportConfiguration
<a name="API_DicomJsonMetadataImportConfiguration"></a>

The configuration parameters that are specific to DICOM JSON metadata import operations.

## Contents
<a name="API_DicomJsonMetadataImportConfiguration_Contents"></a>

 ** dicomMetadataMappings **   <a name="healthimaging-Type-DicomJsonMetadataImportConfiguration-dicomMetadataMappings"></a>
Maps DCM files to their metadata.
Type: Array of [DicomMetadataMapping](API_DicomMetadataMapping.md) objects
Array Members: Minimum number of 1 item. Maximum number of 1000 items.
Required: Yes
