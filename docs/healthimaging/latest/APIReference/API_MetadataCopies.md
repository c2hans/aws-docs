# MetadataCopies
<a name="API_MetadataCopies"></a>

Contains copiable `Attributes` structure and wraps information related to specific copy use cases. For example, when copying subsets.

## Contents
<a name="API_MetadataCopies_Contents"></a>

 ** copiableAttributes **   <a name="healthimaging-Type-MetadataCopies-copiableAttributes"></a>
The JSON string used to specify a subset of SOP Instances to copy from source to destination image set.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 260000.
Required: Yes
