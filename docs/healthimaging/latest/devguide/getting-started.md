# Getting started with AWS HealthImaging
<a name="getting-started"></a>

To start using AWS HealthImaging, set up an AWS account and create an AWS Identity and Access Management user. To use the [AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) or the [AWS SDKs](https://aws.amazon.com/developer/tools/), you must install and configure them.

After learning about HealthImaging concepts and setting up, a short tutorial with code examples is available to help get you started.

**Topics**
+ [Concepts](getting-started-concepts.md)
+ [Setting up](getting-started-setting-up.md)
+ [Tutorial](getting-started-tutorial.md)
