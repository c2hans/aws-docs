# SourceAuthenticationConfiguration
<a name="API_SourceAuthenticationConfiguration"></a>

The authentication configuration for connecting to the source during migration.

## Contents
<a name="API_SourceAuthenticationConfiguration_Contents"></a>

**Note**

 ** SecretManagerConfig **
The Secrets Manager configuration used for authenticating with the source during migration.

Required: No
