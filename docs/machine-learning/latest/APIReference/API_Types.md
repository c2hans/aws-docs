# Data Types
<a name="API_Types"></a>

The Amazon Machine Learning API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [BatchPrediction](API_BatchPrediction.md)
+  [DataSource](API_DataSource.md)
+  [Evaluation](API_Evaluation.md)
+  [MLModel](API_MLModel.md)
+  [PerformanceMetrics](API_PerformanceMetrics.md)
+  [Prediction](API_Prediction.md)
+  [RDSDatabase](API_RDSDatabase.md)
+  [RDSDatabaseCredentials](API_RDSDatabaseCredentials.md)
+  [RDSDataSpec](API_RDSDataSpec.md)
+  [RDSMetadata](API_RDSMetadata.md)
+  [RealtimeEndpointInfo](API_RealtimeEndpointInfo.md)
+  [RedshiftDatabase](API_RedshiftDatabase.md)
+  [RedshiftDatabaseCredentials](API_RedshiftDatabaseCredentials.md)
+  [RedshiftDataSpec](API_RedshiftDataSpec.md)
+  [RedshiftMetadata](API_RedshiftMetadata.md)
+  [S3DataSpec](API_S3DataSpec.md)
+  [Tag](API_Tag.md)
