# Working with Amazon Simple Storage Service

With the AWS SDK for Rust, you have more than one way to work with Amazon S3. The following table describes each tool and when to use it.

| Tool | When to use it |
| --- | --- |
| The aws-sdk-s3 client | Any Amazon S3 operation, with one request per call. Use it for bucket and object management, presigned URLs, and single-object requests. |
| The Transfer Manager for Amazon S3 | Recommended for uploads and downloads. It runs multipart uploads and downloads and manages request concurrency for you, and it performs well across object sizes. |

For moving object data to and from Amazon S3 (the data plane), we recommend the Transfer Manager for Amazon S3 as the default choice. It manages multipart concurrency for you and performs well for objects of any size. Use the `aws-sdk-s3` client directly for bucket and object management, presigned URLs, and operations the transfer manager doesn't cover.

To share object access without sharing credentials, see [Creating presigned URLs using the AWS SDK for Rust](presigned-urls.md). For runnable Amazon S3 code examples, see [Code examples](rust_code_examples.md).
