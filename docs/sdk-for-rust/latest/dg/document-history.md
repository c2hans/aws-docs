# Document history

This topic describes important changes to the AWS SDK for Rust Developer Guide over the course of its history.

| Change | Description | Date |
| --- |--- |--- |
| [Transfer Manager for Amazon S3](document-history.md) | Added documentation for the Transfer Manager for Amazon S3 for high-throughput uploads and downloads. | November 10, 2026 |
| [Unit testing](document-history.md) | Updates made to supported options of unit testing in the SDK. | May 2, 2025 |
| [Content reorganization](document-history.md) | Updating the table of contents and content organization to better align with other AWS SDKs. | April 7, 2025 |
| [Update HTTP](document-history.md) | Updates to default HTTP functionality of service clients. | March 11, 2025 |
| [Reorganizing the Table of Contents](document-history.md) | Reorganizing the Table of Contents to better differentiate configuration from usage. | July 1, 2024 |
| [General availability of the AWS SDK for Rust](document-history.md) | Updated the guide to include new security information, new and updated code examples, new details on unit testing with examples, and other new and updated content for the new General Availability release of the SDK. | November 27, 2023 |
| [Enforcing a minimum TLS version](document-history.md) | Added information about how to enforce a version of TLS in the SDK. | May 4, 2022 |
| [AWS SDK for Rust developer preview release](document-history.md) |  [Developer preview release](https://github.com/awslabs/aws-sdk-rust/releases)  | December 2, 2021 |
