# EncodedTextChunk
<a name="API_EncodedTextChunk"></a>

A chunk of pre-tokenized text represented as a list of token IDs.

## Contents
<a name="API_EncodedTextChunk_Contents"></a>

 ** tokens **   <a name="sagemakertrainingsession-Type-EncodedTextChunk-tokens"></a>
The token IDs representing the encoded text.
Type: Array of integers
Required: Yes

 ** type **   <a name="sagemakertrainingsession-Type-EncodedTextChunk-type"></a>
The type of the chunk encoding.
Type: String
Valid Values: `encoded_text`
Required: Yes
