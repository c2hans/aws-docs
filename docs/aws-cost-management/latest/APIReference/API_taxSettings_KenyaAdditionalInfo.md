# KenyaAdditionalInfo
<a name="API_taxSettings_KenyaAdditionalInfo"></a>

Additional tax information associated with your TRN in Kenya.

## Contents
<a name="API_taxSettings_KenyaAdditionalInfo_Contents"></a>

 ** personType **   <a name="awscostmanagement-Type-taxSettings_KenyaAdditionalInfo-personType"></a>
The legal person or physical person assigned to this TRN in Kenya.
Type: String
Valid Values: `Legal Person | Physical Person | Business`
Required: Yes
