# Group
<a name="API_Group"></a>

One level of grouped data in the results.

## Contents
<a name="API_Group_Contents"></a>

 ** Keys **   <a name="awscostmanagement-Type-Group-Keys"></a>
The keys that are included in this group.
Type: Array of strings
Required: No

 ** Metrics **   <a name="awscostmanagement-Type-Group-Metrics"></a>
The metrics that are included in this group.
Type: String to [MetricValue](API_MetricValue.md) object map
Key Length Constraints: Minimum length of 0. Maximum length of 1024.
Key Pattern: `[\S\s]*`
Required: No
