# ActiveTimeRange
<a name="API_billing_ActiveTimeRange"></a>

A time range with a start and end time.

## Contents
<a name="API_billing_ActiveTimeRange_Contents"></a>

 ** activeAfterInclusive **   <a name="awscostmanagement-Type-billing_ActiveTimeRange-activeAfterInclusive"></a>
The inclusive time range start date.
Type: Timestamp
Required: Yes

 ** activeBeforeInclusive **   <a name="awscostmanagement-Type-billing_ActiveTimeRange-activeBeforeInclusive"></a>
 The inclusive time range end date.
Type: Timestamp
Required: Yes
