# RequestFilter
<a name="API_BillingAndCostManagementRecommendedActions_RequestFilter"></a>

Enables filtering of results based on specified action criteria. You can define multiple action filters to refine results using combinations of feature type, severity level, and recommendation type.

## Contents
<a name="API_BillingAndCostManagementRecommendedActions_RequestFilter_Contents"></a>

 ** actions **   <a name="awscostmanagement-Type-BillingAndCostManagementRecommendedActions_RequestFilter-actions"></a>
A list of action filters that define criteria for filtering results. Each filter specifies a key, match option, and corresponding values to filter on.
Type: Array of [ActionFilter](API_BillingAndCostManagementRecommendedActions_ActionFilter.md) objects
Required: No
