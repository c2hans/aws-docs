# MonacoAdditionalInfo
<a name="API_taxSettings_MonacoAdditionalInfo"></a>

Additional tax information associated with your TRN in Monaco.

## Contents
<a name="API_taxSettings_MonacoAdditionalInfo_Contents"></a>

 ** businessNumber **   <a name="awscostmanagement-Type-taxSettings_MonacoAdditionalInfo-businessNumber"></a>
The business number for the company in Monaco. Can be up to 12 alphanumeric characters.
Type: String
Pattern: `[a-zA-Z0-9]{1,12}`
Required: Yes
