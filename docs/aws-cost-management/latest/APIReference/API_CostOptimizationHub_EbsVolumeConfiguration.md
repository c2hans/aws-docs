# EbsVolumeConfiguration
<a name="API_CostOptimizationHub_EbsVolumeConfiguration"></a>

The Amazon Elastic Block Store volume configuration used for recommendations.

## Contents
<a name="API_CostOptimizationHub_EbsVolumeConfiguration_Contents"></a>

 ** attachmentState **   <a name="awscostmanagement-Type-CostOptimizationHub_EbsVolumeConfiguration-attachmentState"></a>
The Amazon Elastic Block Store attachment state.
Type: String
Required: No

 ** performance **   <a name="awscostmanagement-Type-CostOptimizationHub_EbsVolumeConfiguration-performance"></a>
The Amazon Elastic Block Store performance configuration.
Type: [BlockStoragePerformanceConfiguration](API_CostOptimizationHub_BlockStoragePerformanceConfiguration.md) object
Required: No

 ** storage **   <a name="awscostmanagement-Type-CostOptimizationHub_EbsVolumeConfiguration-storage"></a>
The disk storage of the Amazon Elastic Block Store volume.
Type: [StorageConfiguration](API_CostOptimizationHub_StorageConfiguration.md) object
Required: No
