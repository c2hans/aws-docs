# BillingPeriod
<a name="API_invoicing_BillingPeriod"></a>

 The billing period for which you want to retrieve invoice-related documents.

## Contents
<a name="API_invoicing_BillingPeriod_Contents"></a>

 ** Month **   <a name="awscostmanagement-Type-invoicing_BillingPeriod-Month"></a>
 The billing period month.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 12.
Required: Yes

 ** Year **   <a name="awscostmanagement-Type-invoicing_BillingPeriod-Year"></a>
 The billing period year.
Type: Integer
Valid Range: Minimum value of 2005. Maximum value of 2050.
Required: Yes
