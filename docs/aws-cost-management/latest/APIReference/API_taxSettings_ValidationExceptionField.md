# ValidationExceptionField
<a name="API_taxSettings_ValidationExceptionField"></a>

The information about the specified parameter in the request that caused an error.

## Contents
<a name="API_taxSettings_ValidationExceptionField_Contents"></a>

 ** name **   <a name="awscostmanagement-Type-taxSettings_ValidationExceptionField-name"></a>
The name of the parameter that caused a `ValidationException` error.
Type: String
Pattern: `(?!\s*$)[\s\S]+`
Required: Yes
