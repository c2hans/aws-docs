# ValidationExceptionField
<a name="API_AWSBCMPricingCalculator_ValidationExceptionField"></a>

 Represents a field that failed validation in a request.

## Contents
<a name="API_AWSBCMPricingCalculator_ValidationExceptionField_Contents"></a>

 ** message **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_ValidationExceptionField-message"></a>
 The error message describing why the field failed validation.
Type: String
Required: Yes

 ** name **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_ValidationExceptionField-name"></a>
 The name of the field that failed validation.
Type: String
Required: Yes
