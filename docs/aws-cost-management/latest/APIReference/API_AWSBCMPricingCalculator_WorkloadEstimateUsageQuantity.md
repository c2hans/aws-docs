# WorkloadEstimateUsageQuantity
<a name="API_AWSBCMPricingCalculator_WorkloadEstimateUsageQuantity"></a>

 Represents a usage quantity for a workload estimate.

<a name="API_AWSBCMPricingCalculator_WorkloadEstimateUsageQuantity_Contents"></a>

 ** amount **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_WorkloadEstimateUsageQuantity-amount"></a>
 The numeric value of the usage quantity.
Type: Double
Required: No

 ** unit **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_WorkloadEstimateUsageQuantity-unit"></a>
 The unit of measurement for the usage quantity.
Type: String
Required: No
