# NatGatewayConfiguration
<a name="API_CostOptimizationHub_NatGatewayConfiguration"></a>

The NAT Gateway configuration used for recommendations.

## Contents
<a name="API_CostOptimizationHub_NatGatewayConfiguration_Contents"></a>

 ** activeConnectionCount **   <a name="awscostmanagement-Type-CostOptimizationHub_NatGatewayConfiguration-activeConnectionCount"></a>
The number of active connections through the NAT Gateway.
Type: Long
Required: No

 ** packetsInFromDestination **   <a name="awscostmanagement-Type-CostOptimizationHub_NatGatewayConfiguration-packetsInFromDestination"></a>
The number of packets received from the destination through the NAT Gateway.
Type: Long
Required: No

 ** packetsInFromSource **   <a name="awscostmanagement-Type-CostOptimizationHub_NatGatewayConfiguration-packetsInFromSource"></a>
The number of packets received from the source through the NAT Gateway.
Type: Long
Required: No
