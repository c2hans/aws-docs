# AdditionalRecipient
<a name="API_billing_AdditionalRecipient"></a>

A recipient copied as a viewer on the executive approval request, in addition to the approver.

## Contents
<a name="API_billing_AdditionalRecipient_Contents"></a>

 ** email **   <a name="awscostmanagement-Type-billing_AdditionalRecipient-email"></a>
The email address of the recipient. This value is 3–256 characters and must be a valid email address.
Type: String
Length Constraints: Minimum length of 3. Maximum length of 256.
Pattern: `[A-Za-z0-9._%+\-]+@[A-Za-z0-9.\-]+\.[A-Za-z]{2,}`
Required: Yes
