# BlockStoragePerformanceConfiguration
<a name="API_CostOptimizationHub_BlockStoragePerformanceConfiguration"></a>

Describes the Amazon Elastic Block Store performance configuration of the current and recommended resource configuration for a recommendation.

## Contents
<a name="API_CostOptimizationHub_BlockStoragePerformanceConfiguration_Contents"></a>

 ** iops **   <a name="awscostmanagement-Type-CostOptimizationHub_BlockStoragePerformanceConfiguration-iops"></a>
The number of I/O operations per second.
Type: Double
Required: No

 ** throughput **   <a name="awscostmanagement-Type-CostOptimizationHub_BlockStoragePerformanceConfiguration-throughput"></a>
The throughput that the volume supports.
Type: Double
Required: No
