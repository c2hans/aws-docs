# ValidationExceptionField
<a name="API_billing_ValidationExceptionField"></a>

The field's information of a request that resulted in an exception.

## Contents
<a name="API_billing_ValidationExceptionField_Contents"></a>

 ** message **   <a name="awscostmanagement-Type-billing_ValidationExceptionField-message"></a>
The message describing why the field failed validation.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: Yes

 ** name **   <a name="awscostmanagement-Type-billing_ValidationExceptionField-name"></a>
The name of the field.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 100.
Required: Yes
