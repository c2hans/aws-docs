# ReservationCoverageGroup
<a name="API_ReservationCoverageGroup"></a>

A group of reservations that share a set of attributes.

## Contents
<a name="API_ReservationCoverageGroup_Contents"></a>

 ** Attributes **   <a name="awscostmanagement-Type-ReservationCoverageGroup-Attributes"></a>
The attributes for this group of reservations.
Type: String to string map
Required: No

 ** Coverage **   <a name="awscostmanagement-Type-ReservationCoverageGroup-Coverage"></a>
How much instance usage this group of reservations covered.
Type: [Coverage](API_Coverage.md) object
Required: No
