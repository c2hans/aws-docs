# EbsVolume
<a name="API_CostOptimizationHub_EbsVolume"></a>

Describes the Amazon Elastic Block Store volume configuration of the current and recommended resource configuration for a recommendation.

## Contents
<a name="API_CostOptimizationHub_EbsVolume_Contents"></a>

 ** configuration **   <a name="awscostmanagement-Type-CostOptimizationHub_EbsVolume-configuration"></a>
The Amazon Elastic Block Store volume configuration used for recommendations.
Type: [EbsVolumeConfiguration](API_CostOptimizationHub_EbsVolumeConfiguration.md) object
Required: No

 ** costCalculation **   <a name="awscostmanagement-Type-CostOptimizationHub_EbsVolume-costCalculation"></a>
Cost impact of the recommendation.
Type: [ResourceCostCalculation](API_CostOptimizationHub_ResourceCostCalculation.md) object
Required: No
