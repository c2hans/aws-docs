# RomaniaAdditionalInfo
<a name="API_taxSettings_RomaniaAdditionalInfo"></a>

Additional tax information to specify for a TRN in Romania.

## Contents
<a name="API_taxSettings_RomaniaAdditionalInfo_Contents"></a>

 ** taxRegistrationNumberType **   <a name="awscostmanagement-Type-taxSettings_RomaniaAdditionalInfo-taxRegistrationNumberType"></a>
 The tax registration number type. The value can be `TaxRegistrationNumber` or `LocalRegistrationNumber`.
Type: String
Valid Values: `TaxRegistrationNumber | LocalRegistrationNumber`
Required: Yes
