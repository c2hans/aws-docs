# TaxesBreakdown
<a name="API_invoicing_TaxesBreakdown"></a>

 The details of the taxes.

## Contents
<a name="API_invoicing_TaxesBreakdown_Contents"></a>

 ** Breakdown **   <a name="awscostmanagement-Type-invoicing_TaxesBreakdown-Breakdown"></a>
 A list of tax information.
Type: Array of [TaxesBreakdownAmount](API_invoicing_TaxesBreakdownAmount.md) objects
Required: No

 ** TotalAmount **   <a name="awscostmanagement-Type-invoicing_TaxesBreakdown-TotalAmount"></a>
 The total amount for your taxes.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `[\s\S]*`
Required: No
