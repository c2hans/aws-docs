# FranceAdditionalInfo
<a name="API_taxSettings_FranceAdditionalInfo"></a>

Additional tax information associated with your TRN in France.

## Contents
<a name="API_taxSettings_FranceAdditionalInfo_Contents"></a>

 ** sirenNumber **   <a name="awscostmanagement-Type-taxSettings_FranceAdditionalInfo-sirenNumber"></a>
The SIREN number for the company in France. Must be a 9-digit number.
Type: String
Pattern: `[0-9]{9}`
Required: Yes

 ** eInvoiceRoutingCode **   <a name="awscostmanagement-Type-taxSettings_FranceAdditionalInfo-eInvoiceRoutingCode"></a>
The routing code used for electronic invoicing (e-invoicing) for the company in France.
Type: String
Required: No
