# UzbekistanAdditionalInfo
<a name="API_taxSettings_UzbekistanAdditionalInfo"></a>

 Additional tax information to specify for a TRN in Uzbekistan.

## Contents
<a name="API_taxSettings_UzbekistanAdditionalInfo_Contents"></a>

 ** taxRegistrationNumberType **   <a name="awscostmanagement-Type-taxSettings_UzbekistanAdditionalInfo-taxRegistrationNumberType"></a>
 The tax registration number type. The tax registration number type valid values are `Business` and `Individual`.
Type: String
Valid Values: `Business | Individual`
Required: No

 ** vatRegistrationNumber **   <a name="awscostmanagement-Type-taxSettings_UzbekistanAdditionalInfo-vatRegistrationNumber"></a>
 The unique 12-digit number issued to identify VAT-registered identities in Uzbekistan.
Type: String
Pattern: `[0-9]{12}`
Required: No
