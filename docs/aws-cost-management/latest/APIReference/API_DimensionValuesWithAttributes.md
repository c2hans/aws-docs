# DimensionValuesWithAttributes
<a name="API_DimensionValuesWithAttributes"></a>

The metadata of a specific type that you can use to filter and group your results. You can use `GetDimensionValues` to find specific values.

## Contents
<a name="API_DimensionValuesWithAttributes_Contents"></a>

 ** Attributes **   <a name="awscostmanagement-Type-DimensionValuesWithAttributes-Attributes"></a>
The attribute that applies to a specific `Dimension`.
Type: String to string map
Required: No

 ** Value **   <a name="awscostmanagement-Type-DimensionValuesWithAttributes-Value"></a>
The value of a dimension with a specific attribute.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `[\S\s]*`
Required: No
