# NegateSavingsPlanAction
<a name="API_AWSBCMPricingCalculator_NegateSavingsPlanAction"></a>

 Represents an action to remove a Savings Plan from a bill scenario.

 This is the ID of an existing Savings Plan in your account.

## Contents
<a name="API_AWSBCMPricingCalculator_NegateSavingsPlanAction_Contents"></a>

 ** savingsPlanId **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_NegateSavingsPlanAction-savingsPlanId"></a>
 The ID of the Savings Plan to remove.
Type: String
Length Constraints: Fixed length of 36.
Pattern: `[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}`
Required: No
