# CnBankRedirect

The details of a China bank redirect instrument. A retail instrument is registered with one bank and carries that bank's code. A corporate instrument isn't registered with a bank.

## Contents
<a name="API_payments_CnBankRedirect_Contents"></a>

 ** bankCode **   <a name="awscostmanagement-Type-payments_CnBankRedirect-bankCode"></a>
The code of the bank that the instrument is registered with. This member is present only for retail instruments.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No
