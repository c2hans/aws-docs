# ServiceLevelAccountUsage
<a name="API_billing_ServiceLevelAccountUsage"></a>

Service-level usage details by account.

## Contents
<a name="API_billing_ServiceLevelAccountUsage_Contents"></a>

 ** serviceCode **   <a name="awscostmanagement-Type-billing_ServiceLevelAccountUsage-serviceCode"></a>
The service code for which to return Support-eligible spend data.
Type: String
Required: No

 ** totalSupportEligibleSpend **   <a name="awscostmanagement-Type-billing_ServiceLevelAccountUsage-totalSupportEligibleSpend"></a>
The total support-eligible spend for the service.
Type: String
Required: No
