# RefreshCadence
<a name="API_DataExports_RefreshCadence"></a>

The cadence for AWS to update the data export in your S3 bucket.

## Contents
<a name="API_DataExports_RefreshCadence_Contents"></a>

 ** Frequency **   <a name="awscostmanagement-Type-DataExports_RefreshCadence-Frequency"></a>
The frequency that data exports are updated. The export refreshes each time the source data updates, up to three times daily.
Type: String
Valid Values: `SYNCHRONOUS`
Required: Yes
