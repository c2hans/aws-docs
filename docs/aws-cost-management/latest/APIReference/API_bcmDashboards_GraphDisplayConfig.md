# GraphDisplayConfig
<a name="API_bcmDashboards_GraphDisplayConfig"></a>

Defines the visual representation settings for widget data, including the visualization type, styling options, and display preferences for different metric types.

## Contents
<a name="API_bcmDashboards_GraphDisplayConfig_Contents"></a>

 ** visualType **   <a name="awscostmanagement-Type-bcmDashboards_GraphDisplayConfig-visualType"></a>
The type of visualization to use for the data.
Type: String
Valid Values: `LINE | BAR | STACK`
Required: Yes
