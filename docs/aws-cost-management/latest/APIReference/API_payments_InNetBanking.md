# InNetBanking

The details of an India net banking instrument. The instrument is registered with one bank.

## Contents
<a name="API_payments_InNetBanking_Contents"></a>

 ** bankCode **   <a name="awscostmanagement-Type-payments_InNetBanking-bankCode"></a>
The code of the bank that the instrument is registered with.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: Yes

 ** bankName **   <a name="awscostmanagement-Type-payments_InNetBanking-bankName"></a>
The name of the bank that the instrument is registered with.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
