# ExecutionReference
<a name="API_DataExports_ExecutionReference"></a>

The reference for the data export update.

## Contents
<a name="API_DataExports_ExecutionReference_Contents"></a>

 ** ExecutionId **   <a name="awscostmanagement-Type-DataExports_ExecutionReference-ExecutionId"></a>
The ID for this specific execution.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `[\S\s]*`
Required: Yes

 ** ExecutionStatus **   <a name="awscostmanagement-Type-DataExports_ExecutionReference-ExecutionStatus"></a>
The status of this specific execution.
Type: [ExecutionStatus](API_DataExports_ExecutionStatus.md) object
Required: Yes
