# SummaryMetricsResult
<a name="API_CostOptimizationHub_SummaryMetricsResult"></a>

The results or descriptions for the additional metrics, based on whether the metrics were or were not requested.

## Contents
<a name="API_CostOptimizationHub_SummaryMetricsResult_Contents"></a>

 ** savingsPercentage **   <a name="awscostmanagement-Type-CostOptimizationHub_SummaryMetricsResult-savingsPercentage"></a>
The savings percentage based on your AWS spend over the past 30 days.
Savings percentage is only supported when filtering by Region, account ID, or tags.
Type: String
Required: No
