# OrderBy
<a name="API_CostOptimizationHub_OrderBy"></a>

Defines how rows will be sorted in the response.

## Contents
<a name="API_CostOptimizationHub_OrderBy_Contents"></a>

 ** dimension **   <a name="awscostmanagement-Type-CostOptimizationHub_OrderBy-dimension"></a>
Sorts by dimension values.
Type: String
Required: No

 ** order **   <a name="awscostmanagement-Type-CostOptimizationHub_OrderBy-order"></a>
The order that's used to sort the data.
Type: String
Valid Values: `Asc | Desc`
Required: No
