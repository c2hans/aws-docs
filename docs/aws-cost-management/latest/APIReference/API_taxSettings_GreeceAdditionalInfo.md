# GreeceAdditionalInfo
<a name="API_taxSettings_GreeceAdditionalInfo"></a>

Additional tax information to specify for a TRN in Greece.

## Contents
<a name="API_taxSettings_GreeceAdditionalInfo_Contents"></a>

 ** contractingAuthorityCode **   <a name="awscostmanagement-Type-taxSettings_GreeceAdditionalInfo-contractingAuthorityCode"></a>
The code of contracting authority for e-invoicing.
Type: String
Pattern: `\d{4}\.[A-Z]\d{5}\.\d{4}`
Required: No
