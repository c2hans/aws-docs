# ValidationExceptionField
<a name="API_BillingAndCostManagementRecommendedActions_ValidationExceptionField"></a>

Provides specific details about why a particular field failed validation.

## Contents
<a name="API_BillingAndCostManagementRecommendedActions_ValidationExceptionField_Contents"></a>

 ** message **   <a name="awscostmanagement-Type-BillingAndCostManagementRecommendedActions_ValidationExceptionField-message"></a>
Provides a message explaining why the field failed validation.
Type: String
Required: Yes

 ** name **   <a name="awscostmanagement-Type-BillingAndCostManagementRecommendedActions_ValidationExceptionField-name"></a>
Provides the name of the field that failed validation.
Type: String
Required: Yes
