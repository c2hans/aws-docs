# RdsDbInstanceStorageConfiguration
<a name="API_CostOptimizationHub_RdsDbInstanceStorageConfiguration"></a>

The Amazon RDS DB instance storage configuration used for recommendations.

## Contents
<a name="API_CostOptimizationHub_RdsDbInstanceStorageConfiguration_Contents"></a>

 ** allocatedStorageInGb **   <a name="awscostmanagement-Type-CostOptimizationHub_RdsDbInstanceStorageConfiguration-allocatedStorageInGb"></a>
The new amount of storage in GB to allocate for the DB instance.
Type: Double
Required: No

 ** iops **   <a name="awscostmanagement-Type-CostOptimizationHub_RdsDbInstanceStorageConfiguration-iops"></a>
The amount of Provisioned IOPS (input/output operations per second) to be initially allocated for the DB instance.
Type: Double
Required: No

 ** storageThroughput **   <a name="awscostmanagement-Type-CostOptimizationHub_RdsDbInstanceStorageConfiguration-storageThroughput"></a>
The storage throughput for the DB instance.
Type: Double
Required: No

 ** storageType **   <a name="awscostmanagement-Type-CostOptimizationHub_RdsDbInstanceStorageConfiguration-storageType"></a>
The storage type to associate with the DB instance.
Type: String
Required: No
