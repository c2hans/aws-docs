# SortDefinition
<a name="API_SortDefinition"></a>

The details for how to sort the data.

## Contents
<a name="API_SortDefinition_Contents"></a>

 ** Key **   <a name="awscostmanagement-Type-SortDefinition-Key"></a>
The key that's used to sort the data.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `[\S\s]*`
Required: Yes

 ** SortOrder **   <a name="awscostmanagement-Type-SortDefinition-SortOrder"></a>
The order that's used to sort the data.
Type: String
Valid Values: `ASCENDING | DESCENDING`
Required: No
