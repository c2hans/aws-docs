# DynamoDBCapacityDetails
<a name="API_DynamoDBCapacityDetails"></a>

The DynamoDB reservations that AWS recommends that you purchase.

## Contents
<a name="API_DynamoDBCapacityDetails_Contents"></a>

 ** CapacityUnits **   <a name="awscostmanagement-Type-DynamoDBCapacityDetails-CapacityUnits"></a>
The capacity unit of the recommended reservation.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `[\S\s]*`
Required: No

 ** Region **   <a name="awscostmanagement-Type-DynamoDBCapacityDetails-Region"></a>
The AWS Region of the recommended reservation.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `[\S\s]*`
Required: No
