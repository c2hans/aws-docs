# TaxExemptionType
<a name="API_taxSettings_TaxExemptionType"></a>

The tax exemption type.

## Contents
<a name="API_taxSettings_TaxExemptionType_Contents"></a>

 ** applicableJurisdictions **   <a name="awscostmanagement-Type-taxSettings_TaxExemptionType-applicableJurisdictions"></a>
The tax exemption's applicable jurisdictions.
Type: Array of [Authority](API_taxSettings_Authority.md) objects
Required: No

 ** description **   <a name="awscostmanagement-Type-taxSettings_TaxExemptionType-description"></a>
The tax exemption's type description.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 200.
Pattern: `[\s\S]*`
Required: No

 ** displayName **   <a name="awscostmanagement-Type-taxSettings_TaxExemptionType-displayName"></a>
The tax exemption's type display name.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 50.
Pattern: `[\s\S]*`
Required: No
