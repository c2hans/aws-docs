# Coverage
<a name="API_Coverage"></a>

The amount of instance usage that a reservation covered.

## Contents
<a name="API_Coverage_Contents"></a>

 ** CoverageCost **   <a name="awscostmanagement-Type-Coverage-CoverageCost"></a>
The amount of cost that the reservation covered.
Type: [CoverageCost](API_CoverageCost.md) object
Required: No

 ** CoverageHours **   <a name="awscostmanagement-Type-Coverage-CoverageHours"></a>
The amount of instance usage that the reservation covered, in hours.
Type: [CoverageHours](API_CoverageHours.md) object
Required: No

 ** CoverageNormalizedUnits **   <a name="awscostmanagement-Type-Coverage-CoverageNormalizedUnits"></a>
The amount of instance usage that the reservation covered, in normalized units.
Type: [CoverageNormalizedUnits](API_CoverageNormalizedUnits.md) object
Required: No
