# Ec2Instance
<a name="API_CostOptimizationHub_Ec2Instance"></a>

Describes the EC2 instance configuration of the current and recommended resource configuration for a recommendation.

## Contents
<a name="API_CostOptimizationHub_Ec2Instance_Contents"></a>

 ** configuration **   <a name="awscostmanagement-Type-CostOptimizationHub_Ec2Instance-configuration"></a>
The EC2 instance configuration used for recommendations.
Type: [Ec2InstanceConfiguration](API_CostOptimizationHub_Ec2InstanceConfiguration.md) object
Required: No

 ** costCalculation **   <a name="awscostmanagement-Type-CostOptimizationHub_Ec2Instance-costCalculation"></a>
Cost impact of the recommendation.
Type: [ResourceCostCalculation](API_CostOptimizationHub_ResourceCostCalculation.md) object
Required: No
