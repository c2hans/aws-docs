# Upi

The details of a Unified Payments Interface (UPI) instrument.

## Contents
<a name="API_payments_Upi_Contents"></a>

 ** appName **   <a name="awscostmanagement-Type-payments_Upi-appName"></a>
The name of the UPI app that the instrument is registered with.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
