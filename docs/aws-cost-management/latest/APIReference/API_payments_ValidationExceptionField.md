# ValidationExceptionField

A request member that failed validation.

## Contents
<a name="API_payments_ValidationExceptionField_Contents"></a>

 ** message **   <a name="awscostmanagement-Type-payments_ValidationExceptionField-message"></a>
A description of why this member failed validation.
Type: String
Required: Yes

 ** name **   <a name="awscostmanagement-Type-payments_ValidationExceptionField-name"></a>
The name of the request member that failed validation. For a member nested inside another member, the name is a path from the request root, with the segments separated by periods.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes
