# MonetaryAmount
<a name="API_freetier_MonetaryAmount"></a>

 The monetary amount of the credit.

## Contents
<a name="API_freetier_MonetaryAmount_Contents"></a>

 ** amount **   <a name="awscostmanagement-Type-freetier_MonetaryAmount-amount"></a>
 The aggregated monetary amount of credits earned.
Type: Double
Required: Yes

 ** unit **   <a name="awscostmanagement-Type-freetier_MonetaryAmount-unit"></a>
 The unit that the monetary amount is given in.
Type: String
Valid Values: `USD`
Required: Yes
