# Interval
<a name="API_billing_Interval"></a>

A time period bounded by an inclusive start date and an inclusive end date.

## Contents
<a name="API_billing_Interval_Contents"></a>

 ** endDateInclusive **   <a name="awscostmanagement-Type-billing_Interval-endDateInclusive"></a>
The end date of the interval. This date is included in the interval.
Type: Timestamp
Required: Yes

 ** startDateInclusive **   <a name="awscostmanagement-Type-billing_Interval-startDateInclusive"></a>
The start date of the interval. This date is included in the interval.
Type: Timestamp
Required: Yes
