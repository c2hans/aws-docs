# PhilippinesAdditionalInfo
<a name="API_taxSettings_PhilippinesAdditionalInfo"></a>

Additional tax information associated with your TRN in the Philippines.

## Contents
<a name="API_taxSettings_PhilippinesAdditionalInfo_Contents"></a>

 ** isVatRegistered **   <a name="awscostmanagement-Type-taxSettings_PhilippinesAdditionalInfo-isVatRegistered"></a>
Indicates whether the account is VAT-registered with the Philippines Bureau of Internal Revenue (BIR).
Type: Boolean
Required: No
