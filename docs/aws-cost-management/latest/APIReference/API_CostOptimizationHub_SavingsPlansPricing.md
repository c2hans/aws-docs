# SavingsPlansPricing
<a name="API_CostOptimizationHub_SavingsPlansPricing"></a>

Pricing information about a Savings Plans.

## Contents
<a name="API_CostOptimizationHub_SavingsPlansPricing_Contents"></a>

 ** estimatedMonthlyCommitment **   <a name="awscostmanagement-Type-CostOptimizationHub_SavingsPlansPricing-estimatedMonthlyCommitment"></a>
Estimated monthly commitment for the Savings Plans.
Type: Double
Required: No

 ** estimatedOnDemandCost **   <a name="awscostmanagement-Type-CostOptimizationHub_SavingsPlansPricing-estimatedOnDemandCost"></a>
Estimated On-Demand cost you will pay after buying the Savings Plans.
Type: Double
Required: No

 ** monthlySavingsPlansEligibleCost **   <a name="awscostmanagement-Type-CostOptimizationHub_SavingsPlansPricing-monthlySavingsPlansEligibleCost"></a>
The cost of paying for the recommended Savings Plans monthly.
Type: Double
Required: No

 ** savingsPercentage **   <a name="awscostmanagement-Type-CostOptimizationHub_SavingsPlansPricing-savingsPercentage"></a>
Estimated savings as a percentage of your overall costs after buying the Savings Plans.
Type: Double
Required: No
