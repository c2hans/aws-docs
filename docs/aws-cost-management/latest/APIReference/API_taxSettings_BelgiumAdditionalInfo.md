# BelgiumAdditionalInfo
<a name="API_taxSettings_BelgiumAdditionalInfo"></a>

Additional tax information associated with your TRN in Belgium.

## Contents
<a name="API_taxSettings_BelgiumAdditionalInfo_Contents"></a>

 ** isMercuriusBoxEnabled **   <a name="awscostmanagement-Type-taxSettings_BelgiumAdditionalInfo-isMercuriusBoxEnabled"></a>
Indicates whether the Mercurius e-invoicing box is enabled for business-to-government (B2G) invoicing in Belgium.
Type: Boolean
Required: No

 ** peppolId **   <a name="awscostmanagement-Type-taxSettings_BelgiumAdditionalInfo-peppolId"></a>
The Peppol ID for electronic invoicing in Belgium.
Type: String
Pattern: `[0-9]{10}`
Required: No
