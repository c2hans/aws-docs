# InvestmentRestriction
<a name="API_billing_InvestmentRestriction"></a>

A restriction that caps the value that can be disbursed for an investment. The cap applies for each attestation window.

## Contents
<a name="API_billing_InvestmentRestriction_Contents"></a>

 ** amount **   <a name="awscostmanagement-Type-billing_InvestmentRestriction-amount"></a>
The maximum monetary amount allowed under the restriction.
Type: [Amount](API_billing_Amount.md) object
Required: Yes
