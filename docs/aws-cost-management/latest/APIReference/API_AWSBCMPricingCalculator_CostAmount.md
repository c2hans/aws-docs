# CostAmount
<a name="API_AWSBCMPricingCalculator_CostAmount"></a>

 Represents a monetary amount with associated currency.

## Contents
<a name="API_AWSBCMPricingCalculator_CostAmount_Contents"></a>

 ** amount **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_CostAmount-amount"></a>
 The numeric value of the cost.
Type: Double
Required: No

 ** currency **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_CostAmount-currency"></a>
 The currency code for the cost amount.
Type: String
Valid Values: `USD`
Required: No
