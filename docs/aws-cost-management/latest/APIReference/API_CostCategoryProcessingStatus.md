# CostCategoryProcessingStatus
<a name="API_CostCategoryProcessingStatus"></a>

The list of processing statuses for Cost Management products for a specific cost category.

## Contents
<a name="API_CostCategoryProcessingStatus_Contents"></a>

 ** Component **   <a name="awscostmanagement-Type-CostCategoryProcessingStatus-Component"></a>
The Cost Management product name of the applied status.
Type: String
Valid Values: `COST_EXPLORER`
Required: No

 ** Status **   <a name="awscostmanagement-Type-CostCategoryProcessingStatus-Status"></a>
The process status for a specific cost category.
Type: String
Valid Values: `PROCESSING | APPLIED`
Required: No
