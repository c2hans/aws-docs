# GeorgiaAdditionalInfo
<a name="API_taxSettings_GeorgiaAdditionalInfo"></a>

 Additional tax information associated with your TRN in Georgia.

## Contents
<a name="API_taxSettings_GeorgiaAdditionalInfo_Contents"></a>

 ** personType **   <a name="awscostmanagement-Type-taxSettings_GeorgiaAdditionalInfo-personType"></a>
 The legal person or physical person assigned to this TRN in Georgia.
Type: String
Valid Values: `Legal Person | Physical Person | Business`
Required: Yes
