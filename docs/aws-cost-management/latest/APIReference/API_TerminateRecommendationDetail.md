# TerminateRecommendationDetail
<a name="API_TerminateRecommendationDetail"></a>

Details on termination recommendation.

## Contents
<a name="API_TerminateRecommendationDetail_Contents"></a>

 ** CurrencyCode **   <a name="awscostmanagement-Type-TerminateRecommendationDetail-CurrencyCode"></a>
The currency code that AWS used to calculate the costs for this instance.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `[\S\s]*`
Required: No

 ** EstimatedMonthlySavings **   <a name="awscostmanagement-Type-TerminateRecommendationDetail-EstimatedMonthlySavings"></a>
The estimated savings that result from modification, on a monthly basis.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `[\S\s]*`
Required: No
