# FeesBreakdown
<a name="API_invoicing_FeesBreakdown"></a>

 The details of fees.

## Contents
<a name="API_invoicing_FeesBreakdown_Contents"></a>

 ** Breakdown **   <a name="awscostmanagement-Type-invoicing_FeesBreakdown-Breakdown"></a>
The list of fees information.
Type: Array of [FeesBreakdownAmount](API_invoicing_FeesBreakdownAmount.md) objects
Required: No

 ** TotalAmount **   <a name="awscostmanagement-Type-invoicing_FeesBreakdown-TotalAmount"></a>
 The total amount of fees.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `[\s\S]*`
Required: No
