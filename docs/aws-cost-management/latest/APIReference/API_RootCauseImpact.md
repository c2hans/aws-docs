# RootCauseImpact
<a name="API_RootCauseImpact"></a>

The dollar value of the root cause.

## Contents
<a name="API_RootCauseImpact_Contents"></a>

 ** Contribution **   <a name="awscostmanagement-Type-RootCauseImpact-Contribution"></a>
The dollar amount that this root cause contributed to the anomaly's TotalImpact.
Type: Double
Required: Yes
