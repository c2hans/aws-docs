# ResourceTag
<a name="API_billing_ResourceTag"></a>

 The tag structure that contains a tag key and value.

## Contents
<a name="API_billing_ResourceTag_Contents"></a>

 ** key **   <a name="awscostmanagement-Type-billing_ResourceTag-key"></a>
 The key that's associated with the tag.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: Yes

 ** value **   <a name="awscostmanagement-Type-billing_ResourceTag-value"></a>
 The value that's associated with the tag.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
