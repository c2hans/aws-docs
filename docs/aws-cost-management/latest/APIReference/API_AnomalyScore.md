# AnomalyScore
<a name="API_AnomalyScore"></a>

Quantifies the anomaly. The higher score means that it's more anomalous.

## Contents
<a name="API_AnomalyScore_Contents"></a>

 ** CurrentScore **   <a name="awscostmanagement-Type-AnomalyScore-CurrentScore"></a>
The last observed score.
Type: Double
Required: Yes

 ** MaxScore **   <a name="awscostmanagement-Type-AnomalyScore-MaxScore"></a>
The maximum score that's observed during the `AnomalyDateInterval`.
Type: Double
Required: Yes
