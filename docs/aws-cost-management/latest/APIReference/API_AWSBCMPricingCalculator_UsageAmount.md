# UsageAmount
<a name="API_AWSBCMPricingCalculator_UsageAmount"></a>

 Represents a usage amount for a specific time period.

## Contents
<a name="API_AWSBCMPricingCalculator_UsageAmount_Contents"></a>

 ** amount **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_UsageAmount-amount"></a>
 The usage amount for the period.
Type: Double
Required: Yes

 ** startHour **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_UsageAmount-startHour"></a>
 The start hour of the usage period.
Type: Timestamp
Required: Yes
