# MetricValue
<a name="API_MetricValue"></a>

The aggregated value for a metric.

## Contents
<a name="API_MetricValue_Contents"></a>

 ** Amount **   <a name="awscostmanagement-Type-MetricValue-Amount"></a>
The actual number that represents the metric.
Type: String
Required: No

 ** Unit **   <a name="awscostmanagement-Type-MetricValue-Unit"></a>
The unit that the metric is given in.
Type: String
Required: No
