# DiscountsBreakdown
<a name="API_invoicing_DiscountsBreakdown"></a>

The discounts details.

## Contents
<a name="API_invoicing_DiscountsBreakdown_Contents"></a>

 ** Breakdown **   <a name="awscostmanagement-Type-invoicing_DiscountsBreakdown-Breakdown"></a>
The list of discounts information.
Type: Array of [DiscountsBreakdownAmount](API_invoicing_DiscountsBreakdownAmount.md) objects
Required: No

 ** TotalAmount **   <a name="awscostmanagement-Type-invoicing_DiscountsBreakdown-TotalAmount"></a>
 The discount's total amount.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `[\s\S]*`
Required: No
