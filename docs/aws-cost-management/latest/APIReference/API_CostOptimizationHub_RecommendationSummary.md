# RecommendationSummary
<a name="API_CostOptimizationHub_RecommendationSummary"></a>

The summary of rightsizing recommendations, including de-duped savings from all types of recommendations.

## Contents
<a name="API_CostOptimizationHub_RecommendationSummary_Contents"></a>

 ** estimatedMonthlySavings **   <a name="awscostmanagement-Type-CostOptimizationHub_RecommendationSummary-estimatedMonthlySavings"></a>
The estimated total savings resulting from modifications, on a monthly basis.
Type: Double
Required: No

 ** group **   <a name="awscostmanagement-Type-CostOptimizationHub_RecommendationSummary-group"></a>
The grouping of recommendations.
Type: String
Required: No

 ** recommendationCount **   <a name="awscostmanagement-Type-CostOptimizationHub_RecommendationSummary-recommendationCount"></a>
The total number of instance recommendations.
Type: Integer
Required: No
