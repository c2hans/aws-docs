# BudgetQuery
<a name="API_bcmDashboards_BudgetQuery"></a>

Defines the parameters for querying budget data. Budget widgets display budget names, spend amounts, forecasted spend, and budget thresholds. Supports optional filtering by budget dimensions such as `BUDGET_NAME` or `BUDGET_TYPE`.

## Contents
<a name="API_bcmDashboards_BudgetQuery_Contents"></a>

 ** filter **   <a name="awscostmanagement-Type-bcmDashboards_BudgetQuery-filter"></a>
The filter expression to apply to budget data. Supports filtering by budget-specific dimensions such as `BUDGET_NAME`, `BUDGET_TYPE`, and `BUDGET_THRESHOLD`.
Type: [Expression](API_bcmDashboards_Expression.md) object
Required: No
