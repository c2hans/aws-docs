# AdditionalCharge
<a name="API_billing_AdditionalCharge"></a>

An additional charge applied to an Enterprise Support contract.

## Contents
<a name="API_billing_AdditionalCharge_Contents"></a>

 ** description **   <a name="awscostmanagement-Type-billing_AdditionalCharge-description"></a>
A description of the additional charge.
Type: String
Required: Yes

 ** amount **   <a name="awscostmanagement-Type-billing_AdditionalCharge-amount"></a>
The charge amount.
Type: String
Required: No

 ** chargeType **   <a name="awscostmanagement-Type-billing_AdditionalCharge-chargeType"></a>
The type of additional charge.
Type: String
Required: No
