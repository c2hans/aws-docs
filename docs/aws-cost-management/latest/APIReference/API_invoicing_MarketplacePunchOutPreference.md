# MarketplacePunchOutPreference
<a name="API_invoicing_MarketplacePunchOutPreference"></a>

Represents the AWS Marketplace PunchOut configuration for a procurement portal preference.

## Contents
<a name="API_invoicing_MarketplacePunchOutPreference_Contents"></a>

 ** ApprovalRequestRedirectUrl **   <a name="awscostmanagement-Type-invoicing_MarketplacePunchOutPreference-ApprovalRequestRedirectUrl"></a>
The URL that buyers are redirected to for approval requests in the procurement portal. This is only supported for Coupa. When provided together with the procurement portal instance endpoint, its host must match the host of that endpoint.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `\S+`
Required: No
