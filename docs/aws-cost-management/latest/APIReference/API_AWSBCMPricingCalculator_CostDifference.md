# CostDifference
<a name="API_AWSBCMPricingCalculator_CostDifference"></a>

 Represents the difference between historical and estimated costs.

## Contents
<a name="API_AWSBCMPricingCalculator_CostDifference_Contents"></a>

 ** estimatedCost **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_CostDifference-estimatedCost"></a>
 The estimated cost amount.
Type: [CostAmount](API_AWSBCMPricingCalculator_CostAmount.md) object
Required: No

 ** historicalCost **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_CostDifference-historicalCost"></a>
 The historical cost amount.
Type: [CostAmount](API_AWSBCMPricingCalculator_CostAmount.md) object
Required: No
