# IndiaAdditionalInfo
<a name="API_taxSettings_IndiaAdditionalInfo"></a>

 Additional tax information in India.

## Contents
<a name="API_taxSettings_IndiaAdditionalInfo_Contents"></a>

 ** pan **   <a name="awscostmanagement-Type-taxSettings_IndiaAdditionalInfo-pan"></a>
 India pan information associated with the account.
Type: String
Pattern: `[A-Z]{5}[0-9]{4}[A-Z]{1}`
Required: No
