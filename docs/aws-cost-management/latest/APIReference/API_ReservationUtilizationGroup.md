# ReservationUtilizationGroup
<a name="API_ReservationUtilizationGroup"></a>

A group of reservations that share a set of attributes.

## Contents
<a name="API_ReservationUtilizationGroup_Contents"></a>

 ** Attributes **   <a name="awscostmanagement-Type-ReservationUtilizationGroup-Attributes"></a>
The attributes for this group of reservations.
Type: String to string map
Required: No

 ** Key **   <a name="awscostmanagement-Type-ReservationUtilizationGroup-Key"></a>
The key for a specific reservation attribute.
Type: String
Required: No

 ** Utilization **   <a name="awscostmanagement-Type-ReservationUtilizationGroup-Utilization"></a>
How much you used this group of reservations.
Type: [ReservationAggregates](API_ReservationAggregates.md) object
Required: No

 ** Value **   <a name="awscostmanagement-Type-ReservationUtilizationGroup-Value"></a>
The value of a specific reservation attribute.
Type: String
Required: No
