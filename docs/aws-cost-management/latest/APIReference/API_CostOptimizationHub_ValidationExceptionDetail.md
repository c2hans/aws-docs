# ValidationExceptionDetail
<a name="API_CostOptimizationHub_ValidationExceptionDetail"></a>

The input failed to meet the constraints specified by the AWS service in a specified field.

## Contents
<a name="API_CostOptimizationHub_ValidationExceptionDetail_Contents"></a>

 ** fieldName **   <a name="awscostmanagement-Type-CostOptimizationHub_ValidationExceptionDetail-fieldName"></a>
The field name where the invalid entry was detected.
Type: String
Required: Yes

 ** message **   <a name="awscostmanagement-Type-CostOptimizationHub_ValidationExceptionDetail-message"></a>
A message with the reason for the validation exception error.
Type: String
Required: Yes
