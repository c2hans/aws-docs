# UsageQuantityResult
<a name="API_AWSBCMPricingCalculator_UsageQuantityResult"></a>

 Represents the result of a usage quantity calculation.

## Contents
<a name="API_AWSBCMPricingCalculator_UsageQuantityResult_Contents"></a>

 ** amount **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_UsageQuantityResult-amount"></a>
 The numeric value of the usage quantity result.
Type: Double
Required: No

 ** unit **   <a name="awscostmanagement-Type-AWSBCMPricingCalculator_UsageQuantityResult-unit"></a>
 The unit of measurement for the usage quantity result.
Type: String
Required: No
