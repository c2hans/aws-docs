# Enable message feedback for a configuration set AWS End User Messaging SMS
<a name="message-feedback-configuraiton-set-enable"></a>

When the message feedback setting is enabled on a configuration set then messages sent using the configuration set will have message feedback enabled, unless message feedback has been disabled in the API call. To enable message feedback for a configuration set using the AWS End User Messaging SMS console, follow these steps:

1. Open the AWS End User Messaging SMS console at [https://console.aws.amazon.com/sms-voice/](https://console.aws.amazon.com/sms-voice/).

1. In the navigation pane, under **Configurations**, choose **Configuration sets**.

1. On the **Configuration sets** page, choose a configuration set.

1. Select the **Set settings** tab and then choose **Edit settings**.

1. For **Message feedback** choose **Not enabled** to enable message feedback.

1. Choose **Save changes**.
