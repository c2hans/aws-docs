# Industry vertical guides
<a name="registration-help-verticals"></a>

Certain industries face additional scrutiny during registration review due to regulatory requirements or content restrictions imposed by mobile operators. The following guides provide industry-specific checklists, common rejection patterns, and compliant messaging examples for each vertical.
