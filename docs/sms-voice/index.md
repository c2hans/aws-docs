# AWS End User Messaging SMS

AWS End User Messaging SMS is an application-to-person (A2P) SMS and voice messaging service that provides the global scale, resiliency, and flexibility required to deliver SMS messaging in any web, mobile, or business applications.

- [User Guide](/sms-voice/latest/userguide/what-is-service.html): Describes key concepts for AWS End User Messaging SMS and provides instructions for using the AWS End User Messaging SMS console.
- [API Reference for SMS and Voice, v2](/pinpoint/latest/apireference_smsvoicev2/): Describes the REST API resources and operations associated with version 2 of the AWS End User Messaging SMS and Voice API.
