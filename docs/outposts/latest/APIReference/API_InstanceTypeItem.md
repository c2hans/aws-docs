# InstanceTypeItem
<a name="API_InstanceTypeItem"></a>

Information about an instance type.

## Contents
<a name="API_InstanceTypeItem_Contents"></a>

 ** InstanceType **   <a name="outposts-Type-InstanceTypeItem-InstanceType"></a>
The instance type.
Type: String
Required: No

 ** VCPUs **   <a name="outposts-Type-InstanceTypeItem-VCPUs"></a>
The number of default VCPUs in an instance type.
Type: Integer
Required: No
