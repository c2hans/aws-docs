# EC2Capacity
<a name="API_EC2Capacity"></a>

 Information about EC2 capacity.

## Contents
<a name="API_EC2Capacity_Contents"></a>

 ** Family **   <a name="outposts-Type-EC2Capacity-Family"></a>
 The family of the EC2 capacity.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 10.
Pattern: `^[a-z0-9]+[a-z0-9-]*[a-z0-9]+$`
Required: No

 ** MaxSize **   <a name="outposts-Type-EC2Capacity-MaxSize"></a>
 The maximum size of the EC2 capacity.
Type: String
Required: No

 ** Quantity **   <a name="outposts-Type-EC2Capacity-Quantity"></a>
 The quantity of the EC2 capacity.
Type: String
Required: No
