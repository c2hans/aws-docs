# PricingOption
<a name="API_PricingOption"></a>

A pricing option for the specified Outpost.

## Contents
<a name="API_PricingOption_Contents"></a>

 ** PricingType **   <a name="outposts-Type-PricingOption-PricingType"></a>
The type of pricing model.
Type: String
Valid Values: `SUBSCRIPTION`
Required: No

 ** SubscriptionPricingDetails **   <a name="outposts-Type-PricingOption-SubscriptionPricingDetails"></a>
The subscription pricing details for this pricing option.
Type: [SubscriptionPricingDetails](API_SubscriptionPricingDetails.md) object
Required: No
