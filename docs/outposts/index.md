# AWS Outposts Family Documentation

AWS Outposts brings native AWS services, infrastructure, and operating models to virtually any data center, co-location space, or on-premises facility. You can use the same services, tools, and partner solutions to develop for the cloud and on premises.

## AWS Outposts racks

- [User guide for first-generation Outposts racks](/outposts/latest/userguide/): Describes the key concepts, requirements, and tasks for a first-generation AWS Outposts rack.
- [User guide for second-generation Outposts racks](/outposts/latest/network-userguide/): Describes the key concepts, requirements, and tasks for a second-generation AWS Outposts rack.
- [AWS Outposts section in the API Reference for Amazon EC2](/AWSEC2/latest/APIReference/operation-list-outposts.html): Describes the AWS Outposts API operations for local gateways and customer-owned IP addresses.

## AWS Outposts servers

- [User guide for Outposts servers](/outposts/latest/server-userguide/): Describes the key concepts and tasks for an AWS Outposts server.
- [Installation guide for Outposts servers](/outposts/latest/install-server/): Lists the requirements and describes how to install an AWS Outposts server.
- [Outposts server safety and compliance guides](https://aws.amazon.com/outposts/safety-and-compliance-guide/): Provides the CE Declaration of Conformity (DoC) for AWS Outposts servers.

## AWS Outposts API and CLI Reference

- [API Reference for AWS Outposts](/outposts/latest/APIReference/): Describes the API operations for AWS Outposts.
- [AWS CLI Reference](/cli/latest/reference/outposts/): Describes the AWS CLI commands for Outposts.
