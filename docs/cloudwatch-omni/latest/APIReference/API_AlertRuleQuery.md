# AlertRuleQuery
<a name="API_AlertRuleQuery"></a>

Query expression and the language it's written in.

## Contents
<a name="API_AlertRuleQuery_Contents"></a>

 ** expression **   <a name="cloudwatchomni-Type-AlertRuleQuery-expression"></a>
The query expression to evaluate.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 10000.
Required: Yes

 ** language **   <a name="cloudwatchomni-Type-AlertRuleQuery-language"></a>
The query language of the expression.
Type: String
Valid Values: `SQL | PROMQL`
Required: Yes
