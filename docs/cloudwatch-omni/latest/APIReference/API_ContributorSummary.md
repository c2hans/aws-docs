# ContributorSummary
<a name="API_ContributorSummary"></a>

Counts of contributors currently breaching each severity threshold.

## Contents
<a name="API_ContributorSummary_Contents"></a>

 ** criticalCount **   <a name="cloudwatchomni-Type-ContributorSummary-criticalCount"></a>
Number of contributors currently breaching the critical threshold.
Type: Integer
Required: No

 ** warningCount **   <a name="cloudwatchomni-Type-ContributorSummary-warningCount"></a>
Number of contributors currently breaching the warning threshold.
Type: Integer
Required: No
