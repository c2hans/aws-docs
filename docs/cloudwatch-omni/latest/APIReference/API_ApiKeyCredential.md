# ApiKeyCredential
<a name="API_ApiKeyCredential"></a>

An API key used to authenticate an integration with its external system.

## Contents
<a name="API_ApiKeyCredential_Contents"></a>

 ** apiKeyValue **   <a name="cloudwatchomni-Type-ApiKeyCredential-apiKeyValue"></a>
The API key value used to authenticate with the external system.
Type: String
Length Constraints: Minimum length of 1.
Required: Yes
