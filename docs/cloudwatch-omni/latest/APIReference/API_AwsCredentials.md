# AwsCredentials
<a name="API_AwsCredentials"></a>

A set of temporary AWS credentials.

## Contents
<a name="API_AwsCredentials_Contents"></a>

 ** accessKeyId **   <a name="cloudwatchomni-Type-AwsCredentials-accessKeyId"></a>
The AWS access key ID.
Type: String
Required: Yes

 ** expiration **   <a name="cloudwatchomni-Type-AwsCredentials-expiration"></a>
The timestamp when the credentials expire.
Type: Timestamp
Required: Yes

 ** secretAccessKey **   <a name="cloudwatchomni-Type-AwsCredentials-secretAccessKey"></a>
The AWS secret access key.
Type: String
Required: Yes

 ** sessionToken **   <a name="cloudwatchomni-Type-AwsCredentials-sessionToken"></a>
The AWS session token.
Type: String
Required: Yes
