# AlertStateData
<a name="API_AlertStateData"></a>

Structured detail about the current evaluation.

## Contents
<a name="API_AlertStateData_Contents"></a>

 ** thresholdBreached **   <a name="cloudwatchomni-Type-AlertStateData-thresholdBreached"></a>
For COUNT\_OF\_RESULTS alerts, the row count that breached; null for FIELD\_VALUE (multi-contributor) alerts.
Type: Double
Required: No
