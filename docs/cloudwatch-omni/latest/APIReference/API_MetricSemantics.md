# MetricSemantics
<a name="API_MetricSemantics"></a>

The meaning and unit of a single metric.

## Contents
<a name="API_MetricSemantics_Contents"></a>

 ** description **   <a name="cloudwatchomni-Type-MetricSemantics-description"></a>
Human-readable description of what the metric measures.
Type: String
Required: No

 ** unit **   <a name="cloudwatchomni-Type-MetricSemantics-unit"></a>
The unit the metric is reported in.
Type: String
Required: No
