# NodeSemantics
<a name="API_NodeSemantics"></a>

Semantic description of the service a context graph node represents.

## Contents
<a name="API_NodeSemantics_Contents"></a>

 ** framework **   <a name="cloudwatchomni-Type-NodeSemantics-framework"></a>
The application framework the service is built on.
Type: String
Required: No

 ** kind **   <a name="cloudwatchomni-Type-NodeSemantics-kind"></a>
The kind of workload the service is.
Type: String
Required: No

 ** language **   <a name="cloudwatchomni-Type-NodeSemantics-language"></a>
The primary programming language the service is written in.
Type: String
Required: No

 ** purpose **   <a name="cloudwatchomni-Type-NodeSemantics-purpose"></a>
What the service does.
Type: String
Required: No

 ** repository **   <a name="cloudwatchomni-Type-NodeSemantics-repository"></a>
The source repository the service is built from.
Type: String
Required: No
