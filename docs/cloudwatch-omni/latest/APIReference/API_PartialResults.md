# PartialResults
<a name="API_PartialResults"></a>

Indicates whether a query returned partial results.

## Contents
<a name="API_PartialResults_Contents"></a>

 ** partialResultsDetected **   <a name="cloudwatchomni-Type-PartialResults-partialResultsDetected"></a>
True when the query returned partial results (some data could not be read).
Type: Boolean
Required: No
