# AWS Transfer Family Documentation

AWS Transfer Family is a secure transfer service that stores your data in Amazon Simple Storage Service or Amazon Elastic File System and simplifies the migration of Secure File Transfer Protocol (SFTP), File Transfer Protocol Secure (FTPS), File Transfer Protocol (FTP), and Applicability Statement 2 (AS2) workflows to AWS.

- [AWS Transfer Family User Guide](/transfer/latest/userguide/): Describes all AWS Transfer Family concepts and provides instructions on using the various features with the console, the command line interface, and the AWS Transfer Family API.
- [AWS Transfer Family API reference](/transfer/latest/APIReference/api_welcome.html): Describes all the API operations for AWS Transfer Family in detail. Also provides sample requests, responses, and errors for the supported web service protocols.
- [AWS Transfer Family AWS CLI reference](https://awscli.amazonaws.com/v2/documentation/api/latest/reference/transfer/index.html): Describes the AWS CLI operations for AWS Transfer Family in detail.
- [AWS Transfer Family Web App User Guide](/transfer/latest/userguide/webapp-end-users.html): Describes the user interface for an AWS Transfer Family web app.
