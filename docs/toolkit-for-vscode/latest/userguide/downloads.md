# Downloading the Toolkit for VS Code
<a name="downloads"></a>

You can download, install, and set up the AWS Toolkit for Visual Studio Code through the VS Code Marketplace in your IDE. For detailed instructions, see the [Download and install](https://docs.aws.amazon.com/toolkit-for-vscode/latest/userguide/setup-toolkit.html#setup-install) section in the *Getting started* topic of this User Guide.

## Downloading the Toolkit from the VS Code Marketplace
<a name="download"></a>

Alternatively, you can download the AWS Toolkit for Visual Studio Code installation files by navigating to the **[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=AmazonWebServices.aws-toolkit-vscode)** from your web browser.

## Additional IDE Toolkits from AWS
<a name="toolkits"></a>

In addition to the AWS Toolkit for Visual Studio Code, AWS also offers IDE Toolkits for JetBrains and Visual Studio.

**AWS Toolkit for JetBrains links**
+ Follow this link to [Download the AWS Toolkit for JetBrains](https://plugins.jetbrains.com/plugin/11349-aws-toolkit) from the JetBrains Marketplace.
+ To learn more about the AWS Toolkit for JetBrains, see the [AWS Toolkit for JetBrains](https://docs.aws.amazon.com/toolkit-for-jetbrains/latest/userguide/welcome.html) User Guide.

**Toolkit for Visual Studio links**
+ Follow this link to [Download the Toolkit for Visual Studio](https://marketplace.visualstudio.com/items?itemName=AmazonWebServices.aws-toolkit-vscode) from the Visual Studio Marketplace.
+ To learn more about the Toolkit for Visual Studio, see the [Toolkit for Visual Studio](https://docs.aws.amazon.com/toolkit-for-vscode/latest/userguide/welcome.html) User Guide.
