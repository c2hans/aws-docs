# AWS IAM Identity Center
<a name="sso-credentials"></a>

AWS IAM Identity Center is the recommended best practice for managing your AWS account authentication.

For detailed instructions on how to set up IAM Identity Center for Software Development Kits (SDKs), see the [IAM Identity Center authentication](https://docs.aws.amazon.com/sdkref/latest/guide/access-sso.html) section of the *AWS SDKs and Tools Reference Guide*.

For details on how to authenticate and connect the AWS toolkit with your existing IAM Identity Center credentials, see the [Connect to AWS](https://docs.aws.amazon.com/toolkit-for-vscode/latest/userguide/connect.html) topic in this User Guide.
