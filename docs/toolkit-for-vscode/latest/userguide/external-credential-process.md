# Using an external credential process
<a name="external-credential-process"></a>

You can configure the AWS Toolkit for Visual Studio Code for credential processes that aren't directly supported by AWS, by modifying your `shared config file`.

Modifying your `shared config file` for credential processes is the same for both the AWS Toolkit for Visual Studio Code and the AWS Command Line Interface. For detailed information about how to set up external credentials, see the [Sourcing credentials with an external process](https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-sourcing-external.html) topic in the *AWS Command Line Interface User Guide*.
