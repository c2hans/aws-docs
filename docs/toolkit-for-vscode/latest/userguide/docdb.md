# Amazon DocumentDB
<a name="docdb"></a>

You can manage your Amazon DocumentDB clusters and instances directly in VS Code with the AWS Toolkit for Visual Studio Code. Amazon DocumentDB (with MongoDB compatibility) is a fast, reliable, and fully-managed database service that simplifies the set up, operation, and scaling of MongoDB-compatible databases in the cloud. For detailed information about the Amazon DocumentDB service, see the [Amazon DocumentDB](https://docs.aws.amazon.com/documentdb/latest/developerguide/what-is.html) Developer Guide.
