# Amazon Elastic Compute Cloud
<a name="ec2"></a>

Amazon Elastic Compute Cloud for the AWS Toolkit for Visual Studio Code allows you to launch and connect to your Amazon EC2 instances from VS Code. For detailed information about Amazon EC2, see the [What is Amazon EC2?](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/concepts.html) topic in the *Amazon Elastic Compute Cloud* User Guide.

The following topics describe how to work with AWS Application Builder from the AWS Toolkit for Visual Studio Code.

+ [Troubleshooting Amazon EC2](ec2-troubleshoot.md)
