# AWS Builder ID for developers
<a name="builder-id"></a>

An AWS Builder ID is an additional AWS account that is optional or required for certain AWS services. For detailed information about the AWS Builder ID authentication method, see the [Sign in with AWS Builder ID](https://docs.aws.amazon.com/signin/latest/userguide/sign-in-aws_builder_id.html) topic in the *AWS Sign-in* User Guide.

For details about how to authenticate and connect the AWS toolkit with your existing AWS Builder ID, see the [Connect to AWS](https://docs.aws.amazon.com/toolkit-for-vscode/latest/userguide/connect.html) topic in this User Guide.
