# Amazon SageMaker Unified Studio for VS Code
<a name="sagemaker-unifiedstudio"></a>

As a part of the next generation of Amazon SageMaker, the Amazon SageMaker Unified Studio is a unified development experience that brings together AWS data, analytics, artificial intelligence (AI), and machine learning (ML) services. It provides a place to build, deploy, execute, and monitor workflows from a single interface. For more information about setting up the Amazon SageMaker Unifed Studio integration with the VS Code IDE, see [ Setting up the Amazon SageMaker Unified Studio integration in VS Code](https://docs.aws.amazon.com/sagemaker-unified-studio/latest/userguide/local-ide-support.html) in the Amazon SageMaker Unified Studio User Guide.
