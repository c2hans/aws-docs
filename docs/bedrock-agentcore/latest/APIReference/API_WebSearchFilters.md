# WebSearchFilters

The filters to apply to a web search.

## Contents
<a name="API_WebSearchFilters_Contents"></a>

 ** domainFilter **   <a name="BedrockAgentCore-Type-WebSearchFilters-domainFilter"></a>
The domains to include in or exclude from the results.
Type: [DomainFilter](API_DomainFilter.md) object
Required: No

 ** publishedDateFilter **   <a name="BedrockAgentCore-Type-WebSearchFilters-publishedDateFilter"></a>
The publication time range of the results.
Type: [PublishedDateFilter](API_PublishedDateFilter.md) object
Required: No
