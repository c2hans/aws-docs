# WebSearchResult

A web search result.

## Contents
<a name="API_WebSearchResult_Contents"></a>

 ** text **   <a name="BedrockAgentCore-Type-WebSearchResult-text"></a>
A text extract from the page.
Type: String
Required: Yes

 ** publishedAt **   <a name="BedrockAgentCore-Type-WebSearchResult-publishedAt"></a>
The time the page was published. This field is absent when the publication time is not known.
Type: Timestamp
Required: No

 ** title **   <a name="BedrockAgentCore-Type-WebSearchResult-title"></a>
The title of the page.
Type: String
Required: No

 ** url **   <a name="BedrockAgentCore-Type-WebSearchResult-url"></a>
The URL of the page.
Type: String
Required: No
