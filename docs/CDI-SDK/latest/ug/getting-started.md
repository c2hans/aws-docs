# Getting started with the AWS Cloud Digital Interface SDK
<a name="getting-started"></a>

This section describes the resources for AWS Cloud Digital Interface (CDI) SDK. These resources are available on GitHub.

The AWS CDI SDK provides detailed information about how to successfully migrate your uncompressed video workflows to the cloud. You can find detailed instructions on GitHub that explain how to integrate the AWS CDI SDK into your code base.
+ Access the [AWS CDI SDK GitHub repository](https://github.com/aws/aws-cdi-sdk)
+ Access the [AWS CDI SDK Getting Started Guide](https://github.com/aws/aws-cdi-sdk/blob/mainline/README.md) on GitHub

You can find support through [https://console.aws.amazon.com/support/](https://console.aws.amazon.com/support/) To ensure that you reach the correct team, open a case under the EC2 Linux service or the EC2 Windows service.
