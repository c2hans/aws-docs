# ListRecoveryPlanExecutionStepsFilter
<a name="API_ListRecoveryPlanExecutionStepsFilter"></a>

Filters for listing Recovery Plan execution steps.

## Contents
<a name="API_ListRecoveryPlanExecutionStepsFilter_Contents"></a>

 ** status **   <a name="drs-Type-ListRecoveryPlanExecutionStepsFilter-status"></a>
Filter by execution step status.
Type: String
Valid Values: `NOT_STARTED | EXECUTING | WAITING | COMPLETED | FAILED | TIMED_OUT | SKIPPED`
Required: No
