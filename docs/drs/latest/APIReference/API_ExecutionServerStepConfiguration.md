# ExecutionServerStepConfiguration
<a name="API_ExecutionServerStepConfiguration"></a>

Configuration for a `SERVER` type execution step.

## Contents
<a name="API_ExecutionServerStepConfiguration_Contents"></a>

 ** servers **   <a name="drs-Type-ExecutionServerStepConfiguration-servers"></a>
The list of servers in this execution step.
Type: Array of [RecoveryPlanExecutionServer](API_RecoveryPlanExecutionServer.md) objects
Array Members: Minimum number of 1 item. Maximum number of 100 items.
Required: Yes
