# LaunchIntoInstanceProperties
<a name="API_LaunchIntoInstanceProperties"></a>

Launch into existing instance.

## Contents
<a name="API_LaunchIntoInstanceProperties_Contents"></a>

 ** launchIntoEC2InstanceID **   <a name="drs-Type-LaunchIntoInstanceProperties-launchIntoEC2InstanceID"></a>
Optionally holds EC2 instance ID of an instance to launch into, instead of launching a new instance during drill, recovery or failback.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 255.
Pattern: `i-[0-9a-fA-F]{8,}`
Required: No
