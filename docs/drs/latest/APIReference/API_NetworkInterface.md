# NetworkInterface
<a name="API_NetworkInterface"></a>

Network interface.

## Contents
<a name="API_NetworkInterface_Contents"></a>

 ** ips **   <a name="drs-Type-NetworkInterface-ips"></a>
Network interface IPs.
Type: Array of strings
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No

 ** isPrimary **   <a name="drs-Type-NetworkInterface-isPrimary"></a>
Whether this is the primary network interface.
Type: Boolean
Required: No

 ** macAddress **   <a name="drs-Type-NetworkInterface-macAddress"></a>
The MAC address of the network interface.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
