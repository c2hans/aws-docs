# LaunchActionParameter
<a name="API_LaunchActionParameter"></a>

Launch action parameter.

## Contents
<a name="API_LaunchActionParameter_Contents"></a>

 ** type **   <a name="drs-Type-LaunchActionParameter-type"></a>
Type.
Type: String
Valid Values: `SSM_STORE | DYNAMIC`
Required: No

 ** value **   <a name="drs-Type-LaunchActionParameter-value"></a>
Value.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1011.
Pattern: `[A-Za-z0-9.-]+`
Required: No
