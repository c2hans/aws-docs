# ServerStepConfiguration
<a name="API_ServerStepConfiguration"></a>

Configuration for a `SERVER` type step.

## Contents
<a name="API_ServerStepConfiguration_Contents"></a>

 ** servers **   <a name="drs-Type-ServerStepConfiguration-servers"></a>
The list of servers to recover in this step.
Type: Array of [RecoveryPlanServer](API_RecoveryPlanServer.md) objects
Array Members: Minimum number of 1 item. Maximum number of 100 items.
Required: Yes
