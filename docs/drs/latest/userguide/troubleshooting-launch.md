# Troubleshooting launch errors
<a name="troubleshooting-launch"></a>

Use this section to troubleshoot issues that occur when launching drill or recovery instances.

| If you see... | See |
| --- | --- |
| "Conversion failed", "Failed to connect using HTTP channel", or snapshot errors | [Conversion errors](launch-conversion-errors.md) |
| Lifecycle state errors, BYOL conflicts, EBS key issues, IAM permission errors, or instance store conflicts | [Configuration errors](launch-configuration-errors.md) |
| Windows license activation failures, drive letter changes, or Dynamic Disk showing as Foreign | [Windows post-launch issues](launch-windows-issues.md) |

**Topics**
+ [Launch conversion errors](launch-conversion-errors.md)
+ [Launch configuration errors](launch-configuration-errors.md)
+ [Windows post-launch issues](launch-windows-issues.md)
