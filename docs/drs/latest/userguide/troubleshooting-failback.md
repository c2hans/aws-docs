# Troubleshooting failback errors
<a name="troubleshooting-failback"></a>

Use this section to troubleshoot issues that occur during the failback process — from Failback Client setup through reverse replication.

| If you see... | See |
| --- | --- |
| "Could not associate failback client", "Failback client not seen", credential errors, or connectivity errors during failback setup | [Failback Client errors](failback-client-errors.md) |
| "Agent is not connected to DRS", credential retrieval errors (clock skew), or "Recovery instances could not be processed" | [Failback replication errors](failback-replication-errors.md) |

+ [Failback Client errors](failback-client-errors.md)
+ [Failback replication errors](failback-replication-errors.md)
