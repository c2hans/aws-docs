# ErrorDetail
<a name="API_ErrorDetail"></a>

An object that contains error details for an entitlement.

## Contents
<a name="API_ErrorDetail_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** errorCode **   <a name="evs-Type-ErrorDetail-errorCode"></a>
The error code.
Type: String
Required: Yes

 ** errorMessage **   <a name="evs-Type-ErrorDetail-errorMessage"></a>
The error message.
Type: String
Required: Yes
