# Service-specific Errors
<a name="API_Errors"></a>

The Amazon Elastic VMware Service API contains service-specific exceptions that various actions return. This section describes each exception in detail.

The following service-specific exceptions are returned:
+  [InternalServerException](API_InternalServerException.md)
+  [ResourceNotFoundException](API_ResourceNotFoundException.md)
+  [ServiceQuotaExceededException](API_ServiceQuotaExceededException.md)
+  [TagPolicyException](API_TagPolicyException.md)
+  [ThrottlingException](API_ThrottlingException.md)
+  [TooManyTagsException](API_TooManyTagsException.md)
+  [ValidationException](API_ValidationException.md)
