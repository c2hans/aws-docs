# Data Types
<a name="API_Types"></a>

The Amazon Elastic VMware Service API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:

+  [ConnectivityInfo](API_ConnectivityInfo.md)
+  [Connector](API_Connector.md)

+  [Host](API_Host.md)
+  [HostInfoForCreate](API_HostInfoForCreate.md)
