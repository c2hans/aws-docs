# Data Types
<a name="API_Types"></a>

The AWS CloudHSM V2 API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Backup](API_Backup.md)
+  [BackupRetentionPolicy](API_BackupRetentionPolicy.md)
+  [Certificates](API_Certificates.md)
+  [Cluster](API_Cluster.md)
+  [DestinationBackup](API_DestinationBackup.md)
+  [Hsm](API_Hsm.md)
+  [Tag](API_Tag.md)
