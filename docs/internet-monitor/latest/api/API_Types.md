# Data Types
<a name="API_Types"></a>

The Amazon CloudWatch Internet Monitor API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AvailabilityMeasurement](API_AvailabilityMeasurement.md)
+  [ClientLocation](API_ClientLocation.md)
+  [FilterParameter](API_FilterParameter.md)
+  [HealthEvent](API_HealthEvent.md)
+  [HealthEventsConfig](API_HealthEventsConfig.md)
+  [ImpactedLocation](API_ImpactedLocation.md)
+  [InternetEventSummary](API_InternetEventSummary.md)
+  [InternetHealth](API_InternetHealth.md)
+  [InternetMeasurementsLogDelivery](API_InternetMeasurementsLogDelivery.md)
+  [LocalHealthEventsConfig](API_LocalHealthEventsConfig.md)
+  [Monitor](API_Monitor.md)
+  [Network](API_Network.md)
+  [NetworkImpairment](API_NetworkImpairment.md)
+  [PerformanceMeasurement](API_PerformanceMeasurement.md)
+  [QueryField](API_QueryField.md)
+  [RoundTripTime](API_RoundTripTime.md)
+  [S3Config](API_S3Config.md)
