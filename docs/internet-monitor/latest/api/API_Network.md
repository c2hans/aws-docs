# Network
<a name="API_Network"></a>

An internet service provider (ISP) or network (ASN) in Internet Monitor.

## Contents
<a name="API_Network_Contents"></a>

 ** ASName **   <a name="internetmonitor-Type-Network-ASName"></a>
The name of the internet service provider (ISP) or network (ASN).
Type: String
Required: Yes

 ** ASNumber **   <a name="internetmonitor-Type-Network-ASNumber"></a>
The Autonomous System Number (ASN) of the internet provider or network.
Type: Long
Required: Yes
