# Managing just-in-time access requests
<a name="systems-manager-just-in-time-node-access-manage-requests"></a>

For increased visibility across your organization, Systems Manager replicates access requests to the delegated administrator account for your organization. To help you meet compliance requirements, Systems Manager retains all access requests for 1 year. The following topics describe how to manage just-in-time node access requests. This information is intended for access request approvers. Before you begin, we commend reviewing your IAM policies and making sure you have the required permissions for administering just-in-time node access. For more information see, [Setting up just-in-time access with Systems Manager](systems-manager-just-in-time-node-access-setting-up.md).
