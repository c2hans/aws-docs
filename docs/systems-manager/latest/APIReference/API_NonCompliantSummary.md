# NonCompliantSummary
<a name="API_NonCompliantSummary"></a>

A summary of resources that aren't compliant. The summary is organized according to resource type.

## Contents
<a name="API_NonCompliantSummary_Contents"></a>

 ** NonCompliantCount **   <a name="systemsmanager-Type-NonCompliantSummary-NonCompliantCount"></a>
The total number of compliance items that aren't compliant.
Type: Integer
Required: No

 ** SeveritySummary **   <a name="systemsmanager-Type-NonCompliantSummary-SeveritySummary"></a>
A summary of the non-compliance severity by compliance type
Type: [SeveritySummary](API_SeveritySummary.md) object
Required: No
