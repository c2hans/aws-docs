# OutputSource
<a name="API_OutputSource"></a>

Information about the source where the association execution details are stored.

## Contents
<a name="API_OutputSource_Contents"></a>

 ** OutputSourceId **   <a name="systemsmanager-Type-OutputSource-OutputSourceId"></a>
The ID of the output source, for example the URL of an S3 bucket.
Type: String
Length Constraints: Fixed length of 36.
Required: No

 ** OutputSourceType **   <a name="systemsmanager-Type-OutputSource-OutputSourceType"></a>
The type of source where the association execution details are stored, for example, Amazon S3.
Type: String
Required: No
