# ValidationFindingScope
<a name="API_ValidationFindingScope"></a>

Identifies the specific resource scope of a validation finding.

## Contents
<a name="API_ValidationFindingScope_Contents"></a>

 ** Id **   <a name="systemsmanager-Type-ValidationFindingScope-Id"></a>
The ID of the resource within the scope.
Type: String
Required: No

 ** Type **   <a name="systemsmanager-Type-ValidationFindingScope-Type"></a>
The type of the resource scope.
Type: String
Valid Values: `azure:tenant | azure:subscription`
Required: No
