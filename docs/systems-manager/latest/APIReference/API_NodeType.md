# NodeType
<a name="API_NodeType"></a>

Information about a managed node's type.

## Contents
<a name="API_NodeType_Contents"></a>

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** Instance **   <a name="systemsmanager-Type-NodeType-Instance"></a>
Information about a specific managed node.
Type: [InstanceInfo](API_InstanceInfo.md) object
Required: No
