# ResolvedTargets
<a name="API_ResolvedTargets"></a>

Information about targets that resolved during the Automation execution.

## Contents
<a name="API_ResolvedTargets_Contents"></a>

 ** ParameterValues **   <a name="systemsmanager-Type-ResolvedTargets-ParameterValues"></a>
A list of parameter values sent to targets that resolved during the Automation execution.
Type: Array of strings
Required: No

 ** Truncated **   <a name="systemsmanager-Type-ResolvedTargets-Truncated"></a>
A boolean value indicating whether the resolved target list is truncated.
Type: Boolean
Required: No
