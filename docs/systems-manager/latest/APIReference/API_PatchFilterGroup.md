# PatchFilterGroup
<a name="API_PatchFilterGroup"></a>

A set of patch filters, typically used for approval rules.

## Contents
<a name="API_PatchFilterGroup_Contents"></a>

 ** PatchFilters **   <a name="systemsmanager-Type-PatchFilterGroup-PatchFilters"></a>
The set of patch filters that make up the group.
Type: Array of [PatchFilter](API_PatchFilter.md) objects
Array Members: Minimum number of 0 items. Maximum number of 4 items.
Required: Yes
