# ResourceDataSyncOrganizationalUnit
<a name="API_ResourceDataSyncOrganizationalUnit"></a>

The AWS Organizations organizational unit data source for the sync.

## Contents
<a name="API_ResourceDataSyncOrganizationalUnit_Contents"></a>

 ** OrganizationalUnitId **   <a name="systemsmanager-Type-ResourceDataSyncOrganizationalUnit-OrganizationalUnitId"></a>
The AWS Organizations unit ID data source for the sync.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `^ou-[0-9a-z]{4,32}-[a-z0-9]{8,32}$`
Required: No
