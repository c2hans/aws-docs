# TargetPreview
<a name="API_TargetPreview"></a>

Information about the resources that would be included in the actual runbook execution, if it were to be run.

## Contents
<a name="API_TargetPreview_Contents"></a>

 ** Count **   <a name="systemsmanager-Type-TargetPreview-Count"></a>
The number of resources of a certain type included in an execution preview.
Type: Integer
Required: No

 ** TargetType **   <a name="systemsmanager-Type-TargetPreview-TargetType"></a>
A type of resource that was included in the execution preview.
Type: String
Required: No
