# Guided code examples for the AWS SDK for .NET
<a name="tutorials-examples"></a>

The following sections contain code examples and provide guidance for the examples. They can help you learn how to use the AWS SDK for .NET to work with AWS services. For additional code examples, see [Code examples](csharp_code_examples.md).

**Note**
Code examples that are specific to V3 of the AWS SDK for .NET are also available. To find them, see [Code examples with guidance](https://docs.aws.amazon.com/sdk-for-net/v3/developer-guide/tutorials-examples.html) and [Code examples](https://docs.aws.amazon.com/sdk-for-net/v3/developer-guide/csharp_code_examples.html) in the AWS SDK for .NET (V3) Developer Guide. However, be aware that if you use the V3-specific code examples with V4 of the SDK (the latest version), you might need to make adjustments according to the information in [Migrating to version 4](net-dg-v4.md).

If you're new to the AWS SDK for .NET, you might want to check out the [Creating a simple application](quick-start.md) topic first. It gives you an introduction to the SDK.

Before you begin, be sure you have [set up your environment](net-dg-config.md) and [configured your project](configuring-the-sdk.md). Also review the information in [Using the SDK](net-dg-sdk-features.md).
