# Tag
<a name="API_Tag"></a>

Describes a tag.

## Contents
<a name="API_Tag_Contents"></a>

 ** Key **   <a name="ebs-Type-Tag-Key"></a>
The key of the tag.
Type: String
Length Constraints: Maximum length of 127.
Pattern: `^[\S\s]+$`
Required: No

 ** Value **   <a name="ebs-Type-Tag-Value"></a>
The value of the tag.
Type: String
Length Constraints: Maximum length of 255.
Pattern: `^[\S\s]*$`
Required: No
