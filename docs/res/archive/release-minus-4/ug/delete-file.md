# Delete file(s)
<a name="delete-file"></a>

1. Select the file(s) you want to delete.
![File browser](http://docs.aws.amazon.com/res/archive/release-minus-4/ug/images/res-filebrowser.jpg)

1. Choose **Actions**.

1. Select **Delete files**.

Alternatively, you can also right-click any file or folder and select **Delete files**.
