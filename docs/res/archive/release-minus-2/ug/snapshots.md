# Snapshot management
<a name="snapshots"></a>

Snapshot management simplifies the process of saving and migrating data between environments, ensuring consistency and accuracy. With snapshots, you can save your environment state and migrate data into a new environment with the same state.

![Snapshot management page](http://docs.aws.amazon.com/res/archive/release-minus-2/ug/images/res-snapshotmanagement.png)

From the **Snapshot management** page, you can:

1. View all created snapshots and their status.

1. Create a snapshot. Before you can create a snapshot, you will need to create a bucket with the appropriate permissions.

1. View all applied snapshots and their status.

1. Apply a snapshot.

**Topics**
+ [Create a snapshot](create-snapshot.md)
+ [Apply a snapshot](apply-snapshot.md)
