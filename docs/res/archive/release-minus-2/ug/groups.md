# Groups
<a name="groups"></a>

All Groups synced from the active directory appear on the Groups page. For more information on group configuration and management, see the [Configuration guide](configuration-guide.md).

![Groups](http://docs.aws.amazon.com/res/archive/release-minus-2/ug/images/res-groups.jpg)

From the **Groups** page, you can:

1. Search for user groups.

1. When a user group is selected, use the **Actions** menu to disable or enable a group.

1. When a user group is selected, you can expand the **Users** pane at the bottom of the screen to view users in the group.
