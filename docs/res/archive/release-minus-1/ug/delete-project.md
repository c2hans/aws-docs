# Delete a project
<a name="delete-project"></a>

To delete a project:

1. Select a project in the project list.

1. From the **Actions** menu, choose **Delete Project**.
![Projects page showing actions dropdown options](http://docs.aws.amazon.com/res/archive/release-minus-1/ug/images/res-delete-project1.png)

1. A confirmation pop-up appears. Enter the name of the project, then choose **Yes** to delete it.
![Delete projects confirmation pop-up](http://docs.aws.amazon.com/res/archive/release-minus-1/ug/images/res-delete-project-confirm.png)

1. If a project is deleted, all VDI sessions associated with that project are terminated.
![Projects page under environment management with banner showing successful project deletion](http://docs.aws.amazon.com/res/archive/release-minus-1/ug/images/res-delete-project3.png)
