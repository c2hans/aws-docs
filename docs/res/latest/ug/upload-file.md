# Upload files
<a name="upload-file"></a>

1. Choose **Upload files**.
![File browser](http://docs.aws.amazon.com/res/latest/ug/images/res-filebrowser.jpg)

1. Either drop files or browse for files to upload.

1. Choose **Upload (n) files**.
