# UpdatedSignatureAgentCardDescriptor

The signature agent card descriptor patch wrapper. Omit to leave the descriptor unchanged; supply an empty object to remove it; supply optionalValue to patch its fields.

## Contents
<a name="API_UpdatedSignatureAgentCardDescriptor_Contents"></a>

 ** optionalValue **   <a name="agentregistrycontrol-Type-UpdatedSignatureAgentCardDescriptor-optionalValue"></a>
The value to set for this field. Omit the wrapper to leave the field unchanged.
Type: [UpdatedSignatureAgentCardDescriptorFields](API_UpdatedSignatureAgentCardDescriptorFields.md) object
Required: No
