# UpdatedAgentSkillsRepositoryProvider

The repository provider patch wrapper. Omit to leave the repository provider unchanged; supply an empty object to remove it; supply optionalValue to set it. When you remove it, also remove or replace the GitHub source in the same request.

## Contents
<a name="API_UpdatedAgentSkillsRepositoryProvider_Contents"></a>

 ** optionalValue **   <a name="agentregistrycontrol-Type-UpdatedAgentSkillsRepositoryProvider-optionalValue"></a>
The value to set for this field. Omit the wrapper to leave the field unchanged.
Type: String
Valid Values: `GITHUB`
Required: No
