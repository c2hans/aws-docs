# UpdatedRegistryRecordArtifact

The skill package patch wrapper. Omit to leave the package unchanged; supply an empty object to remove an uploaded package; supply optionalValue to upload a new package.

## Contents
<a name="API_UpdatedRegistryRecordArtifact_Contents"></a>

 ** optionalValue **   <a name="agentregistrycontrol-Type-UpdatedRegistryRecordArtifact-optionalValue"></a>
The skill package to upload. It replaces the record's current package or its synchronized content.
Type: [RegistryRecordArtifactUpload](API_RegistryRecordArtifactUpload.md) object
Required: No
