# UpdatedAgentSkillsPackageDescriptor

The skill package source patch wrapper. Omit to leave the source unchanged; supply an empty object to remove it and stop synchronizing the package; supply optionalValue to replace it.

## Contents
<a name="API_UpdatedAgentSkillsPackageDescriptor_Contents"></a>

 ** optionalValue **   <a name="agentregistrycontrol-Type-UpdatedAgentSkillsPackageDescriptor-optionalValue"></a>
The value to set for this field. Omit the wrapper to leave the field unchanged.
Type: [AgentSkillsPackageDescriptor](API_AgentSkillsPackageDescriptor.md) object
Required: No
