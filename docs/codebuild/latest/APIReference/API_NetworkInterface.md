# NetworkInterface
<a name="API_NetworkInterface"></a>

Describes a network interface.

## Contents
<a name="API_NetworkInterface_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** networkInterfaceId **   <a name="CodeBuild-Type-NetworkInterface-networkInterfaceId"></a>
The ID of the network interface.
Type: String
Length Constraints: Minimum length of 1.
Required: No

 ** subnetId **   <a name="CodeBuild-Type-NetworkInterface-subnetId"></a>
The ID of the subnet.
Type: String
Length Constraints: Minimum length of 1.
Required: No
