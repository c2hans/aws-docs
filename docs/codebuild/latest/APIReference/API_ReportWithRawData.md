# ReportWithRawData
<a name="API_ReportWithRawData"></a>

Contains the unmodified data for the report. For more information, see [GetReportGroupTrend](API_GetReportGroupTrend.md).

## Contents
<a name="API_ReportWithRawData_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** data **   <a name="CodeBuild-Type-ReportWithRawData-data"></a>
The value of the requested data field from the report.
Type: String
Required: No

 ** reportArn **   <a name="CodeBuild-Type-ReportWithRawData-reportArn"></a>
The ARN of the report.
Type: String
Length Constraints: Minimum length of 1.
Required: No
