We recommend that you migrate to [AWS Tools for PowerShell V5](https://docs.aws.amazon.com/powershell/v5/userguide/). For additional details and information on how to migrate, please refer to our [end of support announcement](https://aws.amazon.com/blogs/developer/aws-tools-for-powershell-v4-end-of-support-announcement/).

# Features of the AWS Tools for Windows PowerShell
<a name="pstools-features"></a>

Some topics in this section provide information about features of the Tools for Windows PowerShell that you might need to consider when creating your projects and scripts. Other topics in this section provide information about advanced ways that you can configure the tools, your environment, and your projects. Be sure you have [installed](pstools-getting-set-up.md) and [set up](pstools-getting-started.md) the tools first.

For information about developing software for specific AWS services along with code examples, see [Work with AWS services](pstools-using.md). For additional code examples, see [Tools for PowerShell V4 code examples](powershell_code_examples.md).
