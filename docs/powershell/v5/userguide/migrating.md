# Migrating your scripts for the AWS Tools for PowerShell
<a name="migrating"></a>

This section provides information about migration tasks for version 5 of the AWS Tools for PowerShell, and instructions about how to perform those tasks. For information about migrating to earlier versions (for example, migrating from V3 to V4, see the [migration topic](https://docs.aws.amazon.com/powershell/v4/userguide/v4migration.html) in the [AWS Tools for PowerShell User Guide (version 4)](https://docs.aws.amazon.com/powershell/v4/userguide/).

Also see [Revision history](revision-history.md) and [What's new](whats-new.md) in this guide.
