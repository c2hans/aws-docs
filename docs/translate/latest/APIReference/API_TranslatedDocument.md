# TranslatedDocument
<a name="API_TranslatedDocument"></a>

The translated content.

## Contents
<a name="API_TranslatedDocument_Contents"></a>

 ** Content **   <a name="translate-Type-TranslatedDocument-Content"></a>

Type: Base64-encoded binary data object
