# Data Types
<a name="API_Types"></a>

The AWS Health API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AccountEntityAggregate](API_AccountEntityAggregate.md)
+  [AffectedEntity](API_AffectedEntity.md)
+  [DateTimeRange](API_DateTimeRange.md)
+  [EntityAccountFilter](API_EntityAccountFilter.md)
+  [EntityAggregate](API_EntityAggregate.md)
+  [EntityFilter](API_EntityFilter.md)
+  [Event](API_Event.md)
+  [EventAccountFilter](API_EventAccountFilter.md)
+  [EventAggregate](API_EventAggregate.md)
+  [EventDescription](API_EventDescription.md)
+  [EventDetails](API_EventDetails.md)
+  [EventDetailsErrorItem](API_EventDetailsErrorItem.md)
+  [EventFilter](API_EventFilter.md)
+  [EventType](API_EventType.md)
+  [EventTypeFilter](API_EventTypeFilter.md)
+  [OrganizationAffectedEntitiesErrorItem](API_OrganizationAffectedEntitiesErrorItem.md)
+  [OrganizationEntityAggregate](API_OrganizationEntityAggregate.md)
+  [OrganizationEvent](API_OrganizationEvent.md)
+  [OrganizationEventDetails](API_OrganizationEventDetails.md)
+  [OrganizationEventDetailsErrorItem](API_OrganizationEventDetailsErrorItem.md)
