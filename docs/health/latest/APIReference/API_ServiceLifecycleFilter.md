# ServiceLifecycleFilter
<a name="API_ServiceLifecycleFilter"></a>

A filter for narrowing down service lifecycle results.

## Contents
<a name="API_ServiceLifecycleFilter_Contents"></a>

 ** service **   <a name="AWSHealth-Type-ServiceLifecycleFilter-service"></a>
The AWS service name to filter by.
Type: String
Length Constraints: Minimum length of 2. Maximum length of 30.
Pattern: `[^:/]{2,30}`
Required: No
