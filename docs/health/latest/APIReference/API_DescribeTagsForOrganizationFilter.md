# DescribeTagsForOrganizationFilter

A filter for narrowing down the tags returned by DescribeTagsForOrganization.

## Contents
<a name="API_DescribeTagsForOrganizationFilter_Contents"></a>

 ** tagTypes **   <a name="AWSHealth-Type-DescribeTagsForOrganizationFilter-tagTypes"></a>
The types of tags to include in the results.
Type: Array of strings
Array Members: Minimum number of 1 item. Maximum number of 2 items.
Valid Values: `ORGANIZATION_RESOURCE_TAG | ORGANIZATION_ACCOUNT_TAG`
Required: No
