# AWS Health Documentation

AWS Health provides personalized information about events that can affect your AWS infrastructure, guides you through scheduled changes, and accelerates the troubleshooting of issues that affect your AWS resources and accounts.

- [User Guide](/health/latest/ug/): AWS Health provides information about events that can affect your AWS resources. Information is presented in the AWS Management Console as the AWS Health Dashboard and is also available by using the AWS Health API.
- [API Reference](/health/latest/APIReference/): Documents the AWS Health API, which provides programmatic access to the AWS Health information that appears in the AWS Health Dashboard.
- [AWS Health in the AWS CLI Reference](/cli/latest/reference/health/index.html): Describes the AWS CLI commands that you can use for AWS Health.
