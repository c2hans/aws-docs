## Announcements
<a name="announcements-20261109"></a>

**Note**
 Amazon Linux 2 (AL2) reached end of life on June 30, 2026. For more information, see [Amazon Linux 2 FAQs](https://aws.amazon.com/amazon-linux-2/faqs/#topic-0).
 We strongly recommend that customers migrate to [Amazon Linux 2023](https://aws.amazon.com/linux/amazon-linux-2023/) as soon as possible.

## Release Summary
<a name="release-summary-20261109"></a>

This release of Amazon Linux 2 includes the latest security updates.

**Notable updates**
+  `rclone` 1.55.1 has received security fixes for HTTP/2 Trailer accounting, selfupdate checksum verification, and WebDAV path validation. Oversized HTTP/2 Trailer declarations are now rejected, and selfupdate uses checksums only from authenticated signed content. WebDAV requests and COPY/MOVE destinations containing `.` or `..` path components are now rejected, including in-root paths such as `a/../b`. Clients should use paths without dot components that remain within the served root. Existing Go runtime compatibility defaults and SSH policies are retained.

**Security updates**
+ For information on the CVEs addressed in this release, see the [ Amazon Linux Security Center](https://alas.aws.amazon.com/alas2.html).
+ For visibility into the status of CVEs that haven't been addressed yet, see the [ Amazon Linux Security Center](https://explore.alas.aws.amazon.com/).
