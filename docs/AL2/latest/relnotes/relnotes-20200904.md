# Amazon Linux 2 version 2.0.20200904.0 release notes
<a name="relnotes-20200904"></a>

These are the release notes for Amazon Linux 2 version 2.0.20200904.0.

## Major updates
<a name="major-updates-20200904"></a>
+ This update primarily contains an update for two kernel CVEs as well as a fix for CVE-2019-20907 in python 2.7.18.

## Package updates
<a name="package-updates-20200904"></a>

Amazon Linux 2 includes the following packages.
+ kernel-4.14.193-149.317.amzn2.x86\_64
+ kernel-devel-4.14.193-149.317.amzn2.x86\_64
+ kernel-headers-4.14.193-149.317.amzn2.x86\_64
+ kernel-tools-4.14.193-149.317.amzn2.x86\_64
+ python-2.7.18-1.amzn2.0.2.x86\_64
+ python-devel-2.7.18-1.amzn2.0.2.x86\_64
+ python-libs-2.7.18-1.amzn2.0.2.x86\_64

## Kernel updates
<a name="kernel-updates-20200904"></a>

Rebase kernel to upstream stable 4.14.193.

Updated EFA to ver 1.9.0g.

CVEs fixed:
+ CVE-2020-16166 [random32: update the net random state on interrupt and activity]
+ CVE-2020-14386 [net/packet: fix overflow in tpacket\_rcv]
