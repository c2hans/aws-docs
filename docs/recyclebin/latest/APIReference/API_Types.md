# Data Types
<a name="API_Types"></a>

The Amazon Recycle Bin API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [LockConfiguration](API_LockConfiguration.md)
+  [ResourceTag](API_ResourceTag.md)
+  [RetentionPeriod](API_RetentionPeriod.md)
+  [RuleSummary](API_RuleSummary.md)
+  [Tag](API_Tag.md)
+  [UnlockDelay](API_UnlockDelay.md)
