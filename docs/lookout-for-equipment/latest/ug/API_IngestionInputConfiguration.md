# IngestionInputConfiguration
<a name="API_IngestionInputConfiguration"></a>

 Specifies configuration information for the input data for the data ingestion job, including input data S3 location.

## Contents
<a name="API_IngestionInputConfiguration_Contents"></a>

 ** S3InputConfiguration **   <a name="LookoutForEquipment-Type-IngestionInputConfiguration-S3InputConfiguration"></a>
The location information for the S3 bucket used for input data for the data ingestion.
Type: [IngestionS3InputConfiguration](API_IngestionS3InputConfiguration.md) object
Required: Yes
