# ListWhatsAppFlowAssets
<a name="API_ListWhatsAppFlowAssets"></a>

Lists the assets (Flow JSON definition) of a WhatsApp Flow with presigned download URLs. Download URLs are generated by Meta and expire after a short period.

## Request Syntax
<a name="API_ListWhatsAppFlowAssets_RequestSyntax"></a>

```
GET /v1/whatsapp/flow/assets?flowId={{flowId}}&id={{id}}&maxResults={{maxResults}}&nextToken={{nextToken}} HTTP/1.1
```

## URI Request Parameters
<a name="API_ListWhatsAppFlowAssets_RequestParameters"></a>

The request uses the following URI parameters.

 ** [flowId](#API_ListWhatsAppFlowAssets_RequestSyntax) **   <a name="Social-ListWhatsAppFlowAssets-request-uri-flowId"></a>
The unique identifier of the Flow whose assets to list.
Length Constraints: Minimum length of 1. Maximum length of 100.
Pattern: `[0-9]+`
Required: Yes

 ** [id](#API_ListWhatsAppFlowAssets_RequestSyntax) **   <a name="Social-ListWhatsAppFlowAssets-request-uri-id"></a>
The ID of the WhatsApp Business Account associated with this Flow.
Length Constraints: Minimum length of 1. Maximum length of 115.
Pattern: `.*(^waba-.*$)|(^arn:.*:waba/[0-9a-zA-Z]+$).*`
Required: Yes

 ** [maxResults](#API_ListWhatsAppFlowAssets_RequestSyntax) **   <a name="Social-ListWhatsAppFlowAssets-request-uri-maxResults"></a>
The maximum number of results to return per page.
Valid Range: Minimum value of 1. Maximum value of 100.

 ** [nextToken](#API_ListWhatsAppFlowAssets_RequestSyntax) **   <a name="Social-ListWhatsAppFlowAssets-request-uri-nextToken"></a>
The token for the next page of results.
Length Constraints: Minimum length of 1. Maximum length of 600.

## Request Body
<a name="API_ListWhatsAppFlowAssets_RequestBody"></a>

The request does not have a request body.

<a name="API_ListWhatsAppFlowAssets_ResponseSyntax"></a>

```
HTTP/1.1 200
Content-type: application/json

{
   "flowAssets": [
      {
         "assetType": "string",
         "downloadUrl": "string",
         "name": "string"
      }
   ],
   "nextToken": "string"
}
```

## Response Elements
<a name="API_ListWhatsAppFlowAssets_ResponseElements"></a>

If the action is successful, the service sends back an HTTP 200 response.

The following data is returned in JSON format by the service.

 ** [flowAssets](#API_ListWhatsAppFlowAssets_ResponseSyntax) **   <a name="Social-ListWhatsAppFlowAssets-response-flowAssets"></a>
A list of Flow assets with download URLs.
Type: Array of [MetaFlowAsset](API_MetaFlowAsset.md) objects

 ** [nextToken](#API_ListWhatsAppFlowAssets_ResponseSyntax) **   <a name="Social-ListWhatsAppFlowAssets-response-nextToken"></a>
The token to retrieve the next page of results, if any.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 600.
