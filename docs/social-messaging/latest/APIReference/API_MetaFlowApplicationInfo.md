# MetaFlowApplicationInfo
<a name="API_MetaFlowApplicationInfo"></a>

Contains the Meta application metadata associated with a WhatsApp Flow.

## Contents
<a name="API_MetaFlowApplicationInfo_Contents"></a>

 ** id **   <a name="Social-Type-MetaFlowApplicationInfo-id"></a>
The unique identifier of the Meta application.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 100.
Required: Yes

 ** name **   <a name="Social-Type-MetaFlowApplicationInfo-name"></a>
The name of the Meta application.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 200.
Required: Yes

 ** link **   <a name="Social-Type-MetaFlowApplicationInfo-link"></a>
The URL link for the Meta application.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: No
