# WhatsAppSignupCallback
<a name="API_WhatsAppSignupCallback"></a>

Contains the `accessToken` provided by Meta during signup.

## Contents
<a name="API_WhatsAppSignupCallback_Contents"></a>

 ** accessToken **   <a name="Social-Type-WhatsAppSignupCallback-accessToken"></a>
The access token for your WhatsApp Business Account. The `accessToken` value is provided by Meta.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1000.
Required: Yes

 ** callbackUrl **   <a name="Social-Type-WhatsAppSignupCallback-callbackUrl"></a>
The URL where WhatsApp will send callback notifications for this account.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 100.
Required: No
