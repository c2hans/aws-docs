# Amazon Managed Workflows for Apache Airflow Documentation

Amazon Managed Workflows for Apache Airflow (Amazon MWAA) is a managed service for Apache Airflow that you can use to build and manage your workflows in the cloud.

## Amazon MWAA provisioned

Manually configure environment capacity and scale while Amazon MWAA manages the provisioning of infrastructure.

- [User Guide](/mwaa/latest/userguide/): Describes how to build and manage an Apache Airflow pipeline using an Amazon MWAA environment.
- [API Reference](/mwaa/latest/API/): Describes the API operations for Amazon MWAA.
- [Migration Guide](/mwaa/latest/migrationguide/): Describes migrating to a new Amazon MWAA environment from an existing Amazon MWAA environment, or from a self-managed Apache Airflow deployment.

## Amazon MWAA Serverless

Create and orchestrate data pipelines without managing underlying infrastructure.

- [User Guide](/mwaa/latest/mwaa-serverless-userguide/): Describes how to create and manage Amazon MWAA Serverless workflows.
- [API Reference](/mwaa-serverless/latest/APIReference/): Describes the API operations for Amazon MWAA Serverless workflows.
