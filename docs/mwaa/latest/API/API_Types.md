# Data Types
<a name="API_Types"></a>

The AmazonMWAA API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Dimension](API_Dimension.md)
+  [Environment](API_Environment.md)
+  [LastUpdate](API_LastUpdate.md)
+  [LoggingConfiguration](API_LoggingConfiguration.md)
+  [LoggingConfigurationInput](API_LoggingConfigurationInput.md)
+  [MetricDatum](API_MetricDatum.md)
+  [ModuleLoggingConfiguration](API_ModuleLoggingConfiguration.md)
+  [ModuleLoggingConfigurationInput](API_ModuleLoggingConfigurationInput.md)
+  [NetworkConfiguration](API_NetworkConfiguration.md)
+  [StatisticSet](API_StatisticSet.md)
+  [UpdateError](API_UpdateError.md)
+  [UpdateNetworkConfigurationInput](API_UpdateNetworkConfigurationInput.md)
