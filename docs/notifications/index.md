# AWS User Notifications Documentation

AWS User Notifications is an AWS service that provides a central location for your AWS notifications in the AWS Management Console. This includes AWS managed notifications from AWS Health and user-configured notifications generated by AWS services and events you specify. You can receive notifications for events through multiple channels, including email, Amazon Q Developer chat notifications, or AWS Console Mobile Application push notifications.

- [AWS User Notifications User Guide](/notifications/latest/userguide/): Describes key concepts and how to use AWS User Notifications.
- [AWS User Notifications API Reference](/notifications/latest/APIReference/): Describes all non-email contact API operations for AWS User Notifications in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
- [AWS User Notifications Contacts API Reference](/notificationscontacts/latest/APIReference/): Describes all email contact API operations for AWS User Notifications in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
