# SummarizationDimensionDetail
<a name="API_SummarizationDimensionDetail"></a>

Provides detailed information about the dimensions used for event summarization and aggregation.

## Contents
<a name="API_SummarizationDimensionDetail_Contents"></a>

 ** name **   <a name="Notifications-Type-SummarizationDimensionDetail-name"></a>
The name of the SummarizationDimensionDetail.
Type: String
Required: Yes

 ** value **   <a name="Notifications-Type-SummarizationDimensionDetail-value"></a>
Value of the property used to summarize aggregated events.
Type: String
Required: Yes
