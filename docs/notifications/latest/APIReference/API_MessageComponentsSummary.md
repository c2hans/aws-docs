# MessageComponentsSummary
<a name="API_MessageComponentsSummary"></a>

Contains the headline message component.

## Contents
<a name="API_MessageComponentsSummary_Contents"></a>

 ** headline **   <a name="Notifications-Type-MessageComponentsSummary-headline"></a>
A sentence long summary. For example, titles or an email subject line.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes
