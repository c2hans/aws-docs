# AggregationKey
<a name="API_AggregationKey"></a>

Key-value collection that indicate how notifications are grouped.

## Contents
<a name="API_AggregationKey_Contents"></a>

 ** name **   <a name="Notifications-Type-AggregationKey-name"></a>
Indicates the type of aggregation key.
Type: String
Required: Yes

 ** value **   <a name="Notifications-Type-AggregationKey-value"></a>
Indicates the value associated with the aggregation key name.
Type: String
Required: Yes
