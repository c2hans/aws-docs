# AggregationDetail
<a name="API_AggregationDetail"></a>

Provides detailed information about the dimensions used for aggregation.

## Contents
<a name="API_AggregationDetail_Contents"></a>

 ** summarizationDimensions **   <a name="Notifications-Type-AggregationDetail-summarizationDimensions"></a>
Properties used to summarize aggregated events.
Type: Array of [SummarizationDimensionDetail](API_SummarizationDimensionDetail.md) objects
Required: No
