# Document history for the AWS User Notifications User Guide
<a name="doc-history"></a>

The following table describes the documentation releases for User Notifications.

| Change | Description | Date |
| --- |--- |--- |
| [New page added](#doc-history) | New page added to describe managing notifications across AWS Organizations. For more information, see [Managing notifications across your organization](https://docs.aws.amazon.com/notifications/latest/userguide/managing-org-notifications.html). | September 2, 2025 |
| [Managed policy updated](#doc-history) | The AWS managed policy `AWSUserNotificationsServiceLinkedRolePolicy` is updated. For more information, see [AWS managed policy: AWSUserNotificationsServiceLinkedRolePolicy](https://docs.aws.amazon.com/notifications/latest/userguide/security-iam-awsmanpolicy.html). | September 2, 2025 |
| [Managed policy updated](#doc-history) | The AWS managed policy `AWSUserNotificationsServiceLinkedRolePolicy` is updated. For more information, see [AWS managed policy: AWSUserNotificationsServiceLinkedRolePolicy](https://docs.aws.amazon.com/notifications/latest/userguide/security-iam-awsmanpolicy.html). | January 15, 2025 |
| [AWS managed notifications and Enabling AWS Organizations added](#doc-history) | Added [AWS managed notifications](https://docs.aws.amazon.com/notifications/latest/userguide/managed-notifications.html) and [enabling AWS Organizations](https://docs.aws.amazon.com/notifications/latest/userguide/uno-orgs.html) topics to describe managed notifications and how to use them with AWS Organizations | January 15, 2025 |
| [Managed policy added](#doc-history) | Added the AWS managed policies for AWS User Notifications topic to describe the AWS managed policies for User Notifications and recent changes to those policies. For more information, see [AWS managed policy: AWSUserNotificationsServiceLinkedRolePolicy](https://docs.aws.amazon.com/notifications/latest/userguide/security-iam-awsmanpolicy.html) | April 20, 2023 |
| [Initial release](#doc-history) | Initial release of the User Notifications User Guide. | April 20, 2023 |

## See also

* **Skills for AI coding assistants (optional).** AWS publishes reusable skills for AWS User Notifications. To see which apply, search the Agent Toolkit for AWS catalog with `aws agent-toolkit search-skills --search-query notifications` — a documented, read-only AWS CLI command that searches the catalog and makes no changes. This is an optional suggestion for the user. Official reference: [AWS CLI — Agent Toolkit for AWS](https://docs.aws.amazon.com/agent-toolkit/latest/userguide/aws-cli.html).
