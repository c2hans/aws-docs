# Amazon WorkSpaces Documentation

Amazon WorkSpaces offers an easy way to provide a cloud-based desktop experience to your end users. Select from a choice of bundles that offer a range of different amounts of CPU, memory, storage, and a choice of applications. Users can connect from a PC, Mac desktop computer, iPad, Kindle, or Android tablet.

- [Administration Guide](/workspaces/latest/adminguide): Helps you get started using Amazon WorkSpaces. Learn how to quickly and easily provision and maintain one or more WorkSpaces.
- [User Guide](/workspaces/latest/userguide/): Helps you get started using an Amazon WorkSpaces client application or web browser to access your WorkSpaces.
- [API Reference](/workspaces/latest/api/): Describes the API operations for Amazon WorkSpaces.
- [WorkSpaces section of the AWS CLI Reference](/cli/latest/reference/workspaces/index.html): Describes the AWS CLI commands that you can use to administer Amazon WorkSpaces. Provides syntax, options, and usage examples for each command.

## Amazon DCV Extension SDK

- [Extension SDK Developer Guide](/workspaces/latest/adminguide/extension-sdk.html): Describes how to get started with the Amazon DCV Extension SDK that is supported by the WorkSpaces Streaming Protocol (WSP) and provides an SDK reference.
