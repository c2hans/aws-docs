# Tag
<a name="API_Tag"></a>

Describes a tag.

## Contents
<a name="API_Tag_Contents"></a>

 ** Key **   <a name="WorkSpaces-Type-Tag-Key"></a>
The key of the tag.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 127.
Required: Yes

 ** Value **   <a name="WorkSpaces-Type-Tag-Value"></a>
The value of the tag.
Type: String
Length Constraints: Maximum length of 255.
Required: No
