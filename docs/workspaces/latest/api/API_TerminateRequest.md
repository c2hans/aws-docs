# TerminateRequest
<a name="API_TerminateRequest"></a>

Describes the information used to terminate a WorkSpace.

## Contents
<a name="API_TerminateRequest_Contents"></a>

 ** WorkspaceId **   <a name="WorkSpaces-Type-TerminateRequest-WorkspaceId"></a>
The identifier of the WorkSpace.
Type: String
Pattern: `^ws-[0-9a-z]{8,63}$`
Required: Yes
