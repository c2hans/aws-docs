# StopRequest
<a name="API_StopRequest"></a>

Describes the information used to stop a WorkSpace.

## Contents
<a name="API_StopRequest_Contents"></a>

 ** WorkspaceId **   <a name="WorkSpaces-Type-StopRequest-WorkspaceId"></a>
The identifier of the WorkSpace.
Type: String
Pattern: `^ws-[0-9a-z]{8,63}$`
Required: No
