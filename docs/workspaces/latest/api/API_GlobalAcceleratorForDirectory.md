# GlobalAcceleratorForDirectory
<a name="API_GlobalAcceleratorForDirectory"></a>

Describes the Global Accelerator for directory

## Contents
<a name="API_GlobalAcceleratorForDirectory_Contents"></a>

 ** Mode **   <a name="WorkSpaces-Type-GlobalAcceleratorForDirectory-Mode"></a>
Indicates if Global Accelerator for directory is enabled or disabled.
Type: String
Valid Values: `ENABLED_AUTO | DISABLED`
Required: Yes

 ** PreferredProtocol **   <a name="WorkSpaces-Type-GlobalAcceleratorForDirectory-PreferredProtocol"></a>
Indicates the preferred protocol for Global Accelerator.
Type: String
Valid Values: `TCP | NONE`
Required: No
