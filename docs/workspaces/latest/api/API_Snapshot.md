# Snapshot
<a name="API_Snapshot"></a>

## Contents
<a name="API_Snapshot_Contents"></a>

 ** SnapshotTime **   <a name="WorkSpaces-Type-Snapshot-SnapshotTime"></a>

Type: Timestamp
Required: No
