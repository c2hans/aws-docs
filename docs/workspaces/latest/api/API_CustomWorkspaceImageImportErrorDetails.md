# CustomWorkspaceImageImportErrorDetails
<a name="API_CustomWorkspaceImageImportErrorDetails"></a>

Describes in-depth details about the error. These details include the possible causes of the error and troubleshooting information.

## Contents
<a name="API_CustomWorkspaceImageImportErrorDetails_Contents"></a>

 ** ErrorCode **   <a name="WorkSpaces-Type-CustomWorkspaceImageImportErrorDetails-ErrorCode"></a>
The error code that is returned for the image import.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No

 ** ErrorMessage **   <a name="WorkSpaces-Type-CustomWorkspaceImageImportErrorDetails-ErrorMessage"></a>
The text of the error message that is returned for the image import.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: No
