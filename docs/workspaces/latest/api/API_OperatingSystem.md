# OperatingSystem
<a name="API_OperatingSystem"></a>

The operating system that the image is running.

## Contents
<a name="API_OperatingSystem_Contents"></a>

 ** Type **   <a name="WorkSpaces-Type-OperatingSystem-Type"></a>
The operating system.
Type: String
Valid Values: `WINDOWS | LINUX`
Required: No
