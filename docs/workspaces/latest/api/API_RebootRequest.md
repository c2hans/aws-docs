# RebootRequest
<a name="API_RebootRequest"></a>

Describes the information used to reboot a WorkSpace.

## Contents
<a name="API_RebootRequest_Contents"></a>

 ** WorkspaceId **   <a name="WorkSpaces-Type-RebootRequest-WorkspaceId"></a>
The identifier of the WorkSpace.
Type: String
Pattern: `^ws-[0-9a-z]{8,63}$`
Required: Yes
