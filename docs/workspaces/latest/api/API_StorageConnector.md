# StorageConnector
<a name="API_StorageConnector"></a>

Describes the storage connector.

## Contents
<a name="API_StorageConnector_Contents"></a>

 ** ConnectorType **   <a name="WorkSpaces-Type-StorageConnector-ConnectorType"></a>
The type of connector used to save user files.
Type: String
Valid Values: `HOME_FOLDER`
Required: Yes

 ** Status **   <a name="WorkSpaces-Type-StorageConnector-Status"></a>
Indicates if the storage connetor is enabled or disabled.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: Yes
