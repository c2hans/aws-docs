# IpRuleItem
<a name="API_IpRuleItem"></a>

Describes a rule for an IP access control group.

## Contents
<a name="API_IpRuleItem_Contents"></a>

 ** ipRule **   <a name="WorkSpaces-Type-IpRuleItem-ipRule"></a>
The IP address range, in CIDR notation.
Type: String
Required: No

 ** ruleDesc **   <a name="WorkSpaces-Type-IpRuleItem-ruleDesc"></a>
The description.
Type: String
Required: No
