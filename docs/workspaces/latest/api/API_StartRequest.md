# StartRequest
<a name="API_StartRequest"></a>

Information used to start a WorkSpace.

## Contents
<a name="API_StartRequest_Contents"></a>

 ** WorkspaceId **   <a name="WorkSpaces-Type-StartRequest-WorkspaceId"></a>
The identifier of the WorkSpace.
Type: String
Pattern: `^ws-[0-9a-z]{8,63}$`
Required: No
