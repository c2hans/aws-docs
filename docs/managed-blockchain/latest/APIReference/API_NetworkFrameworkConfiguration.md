# NetworkFrameworkConfiguration
<a name="API_NetworkFrameworkConfiguration"></a>

 Configuration properties relevant to the network for the blockchain framework that the network uses.

## Contents
<a name="API_NetworkFrameworkConfiguration_Contents"></a>

 ** Fabric **   <a name="ManagedBlockchain-Type-NetworkFrameworkConfiguration-Fabric"></a>
 Hyperledger Fabric configuration properties for a Managed Blockchain network that uses Hyperledger Fabric.
Type: [NetworkFabricConfiguration](API_NetworkFabricConfiguration.md) object
Required: No
