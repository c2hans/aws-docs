# NetworkFrameworkAttributes
<a name="API_NetworkFrameworkAttributes"></a>

Attributes relevant to the network for the blockchain framework that the network uses.

## Contents
<a name="API_NetworkFrameworkAttributes_Contents"></a>

 ** Ethereum **   <a name="ManagedBlockchain-Type-NetworkFrameworkAttributes-Ethereum"></a>
Attributes of an Ethereum network for Managed Blockchain resources participating in an Ethereum network.
Type: [NetworkEthereumAttributes](API_NetworkEthereumAttributes.md) object
Required: No

 ** Fabric **   <a name="ManagedBlockchain-Type-NetworkFrameworkAttributes-Fabric"></a>
Attributes of Hyperledger Fabric for a Managed Blockchain network that uses Hyperledger Fabric.
Type: [NetworkFabricAttributes](API_NetworkFabricAttributes.md) object
Required: No
