# NetworkFabricAttributes
<a name="API_NetworkFabricAttributes"></a>

Attributes of Hyperledger Fabric for a network.

## Contents
<a name="API_NetworkFabricAttributes_Contents"></a>

 ** Edition **   <a name="ManagedBlockchain-Type-NetworkFabricAttributes-Edition"></a>
The edition of Amazon Managed Blockchain that Hyperledger Fabric uses. For more information, see [Amazon Managed Blockchain Pricing](http://aws.amazon.com/managed-blockchain/pricing/).
Type: String
Valid Values: `STARTER | STANDARD`
Required: No

 ** OrderingServiceEndpoint **   <a name="ManagedBlockchain-Type-NetworkFabricAttributes-OrderingServiceEndpoint"></a>
The endpoint of the ordering service for the network.
Type: String
Required: No
