# MemberFrameworkAttributes
<a name="API_MemberFrameworkAttributes"></a>

Attributes relevant to a member for the blockchain framework that the Managed Blockchain network uses.

## Contents
<a name="API_MemberFrameworkAttributes_Contents"></a>

 ** Fabric **   <a name="ManagedBlockchain-Type-MemberFrameworkAttributes-Fabric"></a>
Attributes of Hyperledger Fabric relevant to a member on a Managed Blockchain network that uses Hyperledger Fabric.
Type: [MemberFabricAttributes](API_MemberFabricAttributes.md) object
Required: No
