# NetworkFabricConfiguration
<a name="API_NetworkFabricConfiguration"></a>

Hyperledger Fabric configuration properties for the network.

## Contents
<a name="API_NetworkFabricConfiguration_Contents"></a>

 ** Edition **   <a name="ManagedBlockchain-Type-NetworkFabricConfiguration-Edition"></a>
The edition of Amazon Managed Blockchain that the network uses. For more information, see [Amazon Managed Blockchain Pricing](http://aws.amazon.com/managed-blockchain/pricing/).
Type: String
Valid Values: `STARTER | STANDARD`
Required: Yes
