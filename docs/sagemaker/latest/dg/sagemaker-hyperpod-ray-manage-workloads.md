# Managing Ray workloads
<a name="sagemaker-hyperpod-ray-manage-workloads"></a>

Ray workloads on HyperPod are KubeRay custom resources. You manage them from the Amazon SageMaker Studio web interface or by applying manifests with `kubectl`. Both surfaces act on the same resources, so you can move between them on the same workload.

**Topics**
+ [Managing Ray workloads with Studio](sagemaker-hyperpod-ray-manage-studio.md)
+ [Managing Ray workloads with kubectl](sagemaker-hyperpod-ray-manage-kubectl.md)
