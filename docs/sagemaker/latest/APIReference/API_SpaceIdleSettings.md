# SpaceIdleSettings
<a name="API_SpaceIdleSettings"></a>

Settings related to idle shutdown of Studio applications in a space.

## Contents
<a name="API_SpaceIdleSettings_Contents"></a>

 ** IdleTimeoutInMinutes **   <a name="sagemaker-Type-SpaceIdleSettings-IdleTimeoutInMinutes"></a>
The time that SageMaker waits after the application becomes idle before shutting it down.
Type: Integer
Valid Range: Minimum value of 60. Maximum value of 525600.
Required: No
