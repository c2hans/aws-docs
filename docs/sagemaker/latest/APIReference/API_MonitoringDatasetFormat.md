# MonitoringDatasetFormat
<a name="API_MonitoringDatasetFormat"></a>

Represents the dataset format used when running a monitoring job.

## Contents
<a name="API_MonitoringDatasetFormat_Contents"></a>

 ** Csv **   <a name="sagemaker-Type-MonitoringDatasetFormat-Csv"></a>
The CSV dataset used in the monitoring job.
Type: [MonitoringCsvDatasetFormat](API_MonitoringCsvDatasetFormat.md) object
Required: No

 ** Json **   <a name="sagemaker-Type-MonitoringDatasetFormat-Json"></a>
The JSON dataset used in the monitoring job
Type: [MonitoringJsonDatasetFormat](API_MonitoringJsonDatasetFormat.md) object
Required: No

 ** Parquet **   <a name="sagemaker-Type-MonitoringDatasetFormat-Parquet"></a>
The Parquet dataset used in the monitoring job
Type: [MonitoringParquetDatasetFormat](API_MonitoringParquetDatasetFormat.md) object
Required: No
