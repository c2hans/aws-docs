# OutputConfigInput
<a name="API_geospatial_OutputConfigInput"></a>

The response structure for an OutputConfig returned by an ExportEarthObservationJob.

## Contents
<a name="API_geospatial_OutputConfigInput_Contents"></a>

 ** S3Data **   <a name="sagemaker-Type-geospatial_OutputConfigInput-S3Data"></a>
Path to Amazon S3 storage location for the output configuration file.
Type: [ExportS3DataInput](API_geospatial_ExportS3DataInput.md) object
Required: Yes
