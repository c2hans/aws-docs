# ViewSunElevationInput
<a name="API_geospatial_ViewSunElevationInput"></a>

The input structure for specifying ViewSunElevation angle property filter.

## Contents
<a name="API_geospatial_ViewSunElevationInput_Contents"></a>

 ** LowerBound **   <a name="sagemaker-Type-geospatial_ViewSunElevationInput-LowerBound"></a>
The lower bound to view the sun elevation.
Type: Float
Required: Yes

 ** UpperBound **   <a name="sagemaker-Type-geospatial_ViewSunElevationInput-UpperBound"></a>
The upper bound to view the sun elevation.
Type: Float
Required: Yes
