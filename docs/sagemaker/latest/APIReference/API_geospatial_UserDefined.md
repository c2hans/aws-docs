# UserDefined
<a name="API_geospatial_UserDefined"></a>

The output resolution (in target georeferenced units) of the result of the operation

## Contents
<a name="API_geospatial_UserDefined_Contents"></a>

 ** Unit **   <a name="sagemaker-Type-geospatial_UserDefined-Unit"></a>
The units for output resolution of the result.
Type: String
Valid Values: `METERS`
Required: Yes

 ** Value **   <a name="sagemaker-Type-geospatial_UserDefined-Value"></a>
The value for output resolution of the result.
Type: Float
Required: Yes
