# PropertyNameSuggestion
<a name="API_PropertyNameSuggestion"></a>

A property name returned from a `GetSearchSuggestions` call that specifies a value in the `PropertyNameQuery` field.

## Contents
<a name="API_PropertyNameSuggestion_Contents"></a>

 ** PropertyName **   <a name="sagemaker-Type-PropertyNameSuggestion-PropertyName"></a>
A suggested property name based on what you entered in the search textbox in the SageMaker console.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `.+`
Required: No
