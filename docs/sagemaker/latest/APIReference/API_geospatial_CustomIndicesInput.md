# CustomIndicesInput
<a name="API_geospatial_CustomIndicesInput"></a>

Input object defining the custom BandMath indices to compute.

## Contents
<a name="API_geospatial_CustomIndicesInput_Contents"></a>

 ** Operations **   <a name="sagemaker-Type-geospatial_CustomIndicesInput-Operations"></a>
A list of BandMath indices to compute.
Type: Array of [Operation](API_geospatial_Operation.md) objects
Array Members: Minimum number of 1 item.
Required: No
