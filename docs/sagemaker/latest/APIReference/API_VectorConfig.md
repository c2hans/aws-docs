# VectorConfig
<a name="API_VectorConfig"></a>

Configuration for your vector collection type.

## Contents
<a name="API_VectorConfig_Contents"></a>

 ** Dimension **   <a name="sagemaker-Type-VectorConfig-Dimension"></a>
The number of elements in your vector.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 8192.
Required: Yes
