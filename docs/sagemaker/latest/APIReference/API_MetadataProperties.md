# MetadataProperties
<a name="API_MetadataProperties"></a>

Metadata properties of the tracking entity, trial, or trial component.

## Contents
<a name="API_MetadataProperties_Contents"></a>

 ** CommitId **   <a name="sagemaker-Type-MetadataProperties-CommitId"></a>
The commit ID.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `.*`
Required: No

 ** GeneratedBy **   <a name="sagemaker-Type-MetadataProperties-GeneratedBy"></a>
The entity this entity was generated by.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `.*`
Required: No

 ** ProjectId **   <a name="sagemaker-Type-MetadataProperties-ProjectId"></a>
The project ID.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `.*`
Required: No

 ** Repository **   <a name="sagemaker-Type-MetadataProperties-Repository"></a>
The repository.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `.*`
Required: No
