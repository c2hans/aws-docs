# ArtifactSourceType
<a name="API_ArtifactSourceType"></a>

The ID and ID type of an artifact source.

## Contents
<a name="API_ArtifactSourceType_Contents"></a>

 ** SourceIdType **   <a name="sagemaker-Type-ArtifactSourceType-SourceIdType"></a>
The type of ID.
Type: String
Valid Values: `MD5Hash | S3ETag | S3Version | Custom`
Required: Yes

 ** Value **   <a name="sagemaker-Type-ArtifactSourceType-Value"></a>
The ID.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: Yes
