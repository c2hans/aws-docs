# FSxLustreFileSystem
<a name="API_FSxLustreFileSystem"></a>

A custom file system in Amazon FSx for Lustre.

## Contents
<a name="API_FSxLustreFileSystem_Contents"></a>

 ** FileSystemId **   <a name="sagemaker-Type-FSxLustreFileSystem-FileSystemId"></a>
Amazon FSx for Lustre file system ID.
Type: String
Length Constraints: Minimum length of 11. Maximum length of 21.
Pattern: `(fs-[0-9a-f]{8,})`
Required: Yes
