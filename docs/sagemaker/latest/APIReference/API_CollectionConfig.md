# CollectionConfig
<a name="API_CollectionConfig"></a>

Configuration for your collection.

## Contents
<a name="API_CollectionConfig_Contents"></a>

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** VectorConfig **   <a name="sagemaker-Type-CollectionConfig-VectorConfig"></a>
Configuration for your vector collection type.
+  `Dimension`: The number of elements in your vector.
Type: [VectorConfig](API_VectorConfig.md) object
Required: No
