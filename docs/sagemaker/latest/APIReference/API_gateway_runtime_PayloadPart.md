# PayloadPart

A part of the streamed response.

## Contents
<a name="API_gateway_runtime_PayloadPart_Contents"></a>

 ** Bytes **   <a name="sagemaker-Type-gateway_runtime_PayloadPart-Bytes"></a>
The bytes of this part: a chunk of the model server's server-sent event (SSE) stream.
Type: Base64-encoded binary data object
Required: No
