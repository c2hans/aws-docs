# PropertyFilters
<a name="API_geospatial_PropertyFilters"></a>

A list of PropertyFilter objects.

## Contents
<a name="API_geospatial_PropertyFilters_Contents"></a>

 ** LogicalOperator **   <a name="sagemaker-Type-geospatial_PropertyFilters-LogicalOperator"></a>
The Logical Operator used to combine the Property Filters.
Type: String
Valid Values: `AND`
Required: No

 ** Properties **   <a name="sagemaker-Type-geospatial_PropertyFilters-Properties"></a>
A list of Property Filters.
Type: Array of [PropertyFilter](API_geospatial_PropertyFilter.md) objects
Required: No
