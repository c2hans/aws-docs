# SampleTokenUsage
<a name="API_training_session_runtime_SampleTokenUsage"></a>

The token usage statistics for a sample generation.

## Contents
<a name="API_training_session_runtime_SampleTokenUsage_Contents"></a>

 ** decode **   <a name="sagemaker-Type-training_session_runtime_SampleTokenUsage-decode"></a>
The number of tokens generated (decode phase).
Type: Integer
Required: Yes

 ** prefill **   <a name="sagemaker-Type-training_session_runtime_SampleTokenUsage-prefill"></a>
The number of tokens in the input prompt (prefill phase).
Type: Integer
Required: Yes
