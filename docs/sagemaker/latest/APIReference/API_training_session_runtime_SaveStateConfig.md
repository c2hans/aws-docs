# SaveStateConfig
<a name="API_training_session_runtime_SaveStateConfig"></a>

The configuration for saving full training state, including model weights and optimizer state. Use this to create resumable checkpoints.

## Contents
<a name="API_training_session_runtime_SaveStateConfig_Contents"></a>

 ** description **   <a name="sagemaker-Type-training_session_runtime_SaveStateConfig-description"></a>
A human-readable description for the saved state checkpoint.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: No
