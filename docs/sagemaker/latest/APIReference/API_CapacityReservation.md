# CapacityReservation
<a name="API_CapacityReservation"></a>

Information about the Capacity Reservation used by an instance or instance group.

## Contents
<a name="API_CapacityReservation_Contents"></a>

 ** Arn **   <a name="sagemaker-Type-CapacityReservation-Arn"></a>
The Amazon Resource Name (ARN) of the Capacity Reservation.
Type: String
Required: No

 ** Type **   <a name="sagemaker-Type-CapacityReservation-Type"></a>
The type of Capacity Reservation. Valid values are `ODCR` (On-Demand Capacity Reservation) or `CRG` (Capacity Reservation Group).
Type: String
Valid Values: `ODCR | CRG`
Required: No
