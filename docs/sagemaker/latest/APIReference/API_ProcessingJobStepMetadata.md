# ProcessingJobStepMetadata
<a name="API_ProcessingJobStepMetadata"></a>

Metadata for a processing job step.

## Contents
<a name="API_ProcessingJobStepMetadata_Contents"></a>

 ** Arn **   <a name="sagemaker-Type-ProcessingJobStepMetadata-Arn"></a>
The Amazon Resource Name (ARN) of the processing job.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `arn:aws[a-z\-]*:sagemaker:[a-z0-9\-]*:[0-9]{12}:processing-job/[a-zA-Z0-9](-*[a-zA-Z0-9]){0,62}`
Required: No
