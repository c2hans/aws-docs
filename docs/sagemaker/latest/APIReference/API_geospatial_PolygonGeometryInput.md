# PolygonGeometryInput
<a name="API_geospatial_PolygonGeometryInput"></a>

The structure representing Polygon Geometry based on the [GeoJson spec](https://www.rfc-editor.org/rfc/rfc7946#section-3.1.6).

## Contents
<a name="API_geospatial_PolygonGeometryInput_Contents"></a>

 ** Coordinates **   <a name="sagemaker-Type-geospatial_PolygonGeometryInput-Coordinates"></a>
Coordinates representing a Polygon based on the [GeoJson spec](https://www.rfc-editor.org/rfc/rfc7946#section-3.1.6).
Type: Array of arrays of arrays of doubles
Array Members: Minimum number of 1 item.
Array Members: Minimum number of 4 items.
Array Members: Fixed number of 2 items.
Required: Yes
