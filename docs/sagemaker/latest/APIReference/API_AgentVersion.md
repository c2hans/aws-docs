# AgentVersion
<a name="API_AgentVersion"></a>

Edge Manager agent version.

## Contents
<a name="API_AgentVersion_Contents"></a>

 ** AgentCount **   <a name="sagemaker-Type-AgentVersion-AgentCount"></a>
The number of Edge Manager agents.
Type: Long
Required: Yes

 ** Version **   <a name="sagemaker-Type-AgentVersion-Version"></a>
Version of the agent.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 30.
Pattern: `[a-zA-Z0-9\ \_\.]+`
Required: Yes
