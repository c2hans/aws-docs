# ModelMetrics
<a name="API_ModelMetrics"></a>

Contains metrics captured from a model.

## Contents
<a name="API_ModelMetrics_Contents"></a>

 ** Bias **   <a name="sagemaker-Type-ModelMetrics-Bias"></a>
Metrics that measure bias in a model.
Type: [Bias](API_Bias.md) object
Required: No

 ** Explainability **   <a name="sagemaker-Type-ModelMetrics-Explainability"></a>
Metrics that help explain a model.
Type: [Explainability](API_Explainability.md) object
Required: No

 ** ModelDataQuality **   <a name="sagemaker-Type-ModelMetrics-ModelDataQuality"></a>
Metrics that measure the quality of the input data for a model.
Type: [ModelDataQuality](API_ModelDataQuality.md) object
Required: No

 ** ModelQuality **   <a name="sagemaker-Type-ModelMetrics-ModelQuality"></a>
Metrics that measure the quality of a model.
Type: [ModelQuality](API_ModelQuality.md) object
Required: No
