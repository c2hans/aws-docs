# BillableTokenUsage
<a name="API_BillableTokenUsage"></a>

The billable token usage for a training session, broken down by operation type.

## Contents
<a name="API_BillableTokenUsage_Contents"></a>

 ** PrefillTokenCount **   <a name="sagemaker-Type-BillableTokenUsage-PrefillTokenCount"></a>
The number of prefill tokens consumed.
Type: Long
Required: No

 ** SampleTokenCount **   <a name="sagemaker-Type-BillableTokenUsage-SampleTokenCount"></a>
The number of sample tokens consumed.
Type: Long
Required: No

 ** TrainingTokenCount **   <a name="sagemaker-Type-BillableTokenUsage-TrainingTokenCount"></a>
The number of training tokens consumed.
Type: Long
Required: No
