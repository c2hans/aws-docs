# KendraSettings
<a name="API_KendraSettings"></a>

The Amazon SageMaker Canvas application setting where you configure document querying.

## Contents
<a name="API_KendraSettings_Contents"></a>

 ** Status **   <a name="sagemaker-Type-KendraSettings-Status"></a>
Describes whether the document querying feature is enabled or disabled in the Canvas application.
Type: String
Valid Values: `ENABLED | DISABLED`
Required: No
