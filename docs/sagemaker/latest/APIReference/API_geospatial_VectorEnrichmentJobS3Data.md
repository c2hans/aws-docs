# VectorEnrichmentJobS3Data
<a name="API_geospatial_VectorEnrichmentJobS3Data"></a>

The Amazon S3 data for the Vector Enrichment job.

## Contents
<a name="API_geospatial_VectorEnrichmentJobS3Data_Contents"></a>

 ** S3Uri **   <a name="sagemaker-Type-geospatial_VectorEnrichmentJobS3Data-S3Uri"></a>
The URL to the Amazon S3 data for the Vector Enrichment job.
Type: String
Pattern: `s3://([^/]+)/?(.*)`
Required: Yes

 ** KmsKeyId **   <a name="sagemaker-Type-geospatial_VectorEnrichmentJobS3Data-KmsKeyId"></a>
The Key Management Service key ID for server-side encryption.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Required: No
