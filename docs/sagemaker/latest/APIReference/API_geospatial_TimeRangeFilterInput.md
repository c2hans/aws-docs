# TimeRangeFilterInput
<a name="API_geospatial_TimeRangeFilterInput"></a>

<a name="API_geospatial_TimeRangeFilterInput_Contents"></a>

 ** EndTime **   <a name="sagemaker-Type-geospatial_TimeRangeFilterInput-EndTime"></a>
The end time for the time-range filter.
Type: Timestamp
Required: Yes

 ** StartTime **   <a name="sagemaker-Type-geospatial_TimeRangeFilterInput-StartTime"></a>

Type: Timestamp
Required: Yes
