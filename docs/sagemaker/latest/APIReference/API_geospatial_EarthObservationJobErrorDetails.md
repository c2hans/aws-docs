# EarthObservationJobErrorDetails
<a name="API_geospatial_EarthObservationJobErrorDetails"></a>

The structure representing the errors in an EarthObservationJob.

## Contents
<a name="API_geospatial_EarthObservationJobErrorDetails_Contents"></a>

 ** Message **   <a name="sagemaker-Type-geospatial_EarthObservationJobErrorDetails-Message"></a>
A detailed message describing the error in an Earth Observation job.
Type: String
Required: No

 ** Type **   <a name="sagemaker-Type-geospatial_EarthObservationJobErrorDetails-Type"></a>
The type of error in an Earth Observation job.
Type: String
Valid Values: `CLIENT_ERROR | SERVER_ERROR`
Required: No
