# ClusterNetworkInterfaceDetails
<a name="API_ClusterNetworkInterfaceDetails"></a>

The network interface configuration details for a Amazon SageMaker HyperPod cluster instance group.

## Contents
<a name="API_ClusterNetworkInterfaceDetails_Contents"></a>

 ** InterfaceType **   <a name="sagemaker-Type-ClusterNetworkInterfaceDetails-InterfaceType"></a>
The type of network interface for the instance group. Valid values are `efa` and `efa-only`.
Type: String
Valid Values: `efa | efa-only`
Required: No
