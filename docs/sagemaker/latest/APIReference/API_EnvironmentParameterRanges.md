# EnvironmentParameterRanges
<a name="API_EnvironmentParameterRanges"></a>

Specifies the range of environment parameters

## Contents
<a name="API_EnvironmentParameterRanges_Contents"></a>

 ** CategoricalParameterRanges **   <a name="sagemaker-Type-EnvironmentParameterRanges-CategoricalParameterRanges"></a>
Specified a list of parameters for each category.
Type: Array of [CategoricalParameter](API_CategoricalParameter.md) objects
Array Members: Minimum number of 1 item. Maximum number of 5 items.
Required: No
