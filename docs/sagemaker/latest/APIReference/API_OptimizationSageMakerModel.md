# OptimizationSageMakerModel
<a name="API_OptimizationSageMakerModel"></a>

A SageMaker model to use as the source or destination for an optimization job.

## Contents
<a name="API_OptimizationSageMakerModel_Contents"></a>

 ** ModelName **   <a name="sagemaker-Type-OptimizationSageMakerModel-ModelName"></a>
The name of a SageMaker model.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 63.
Pattern: `[a-zA-Z0-9]([\-a-zA-Z0-9]*[a-zA-Z0-9])?`
Required: No
