# EventDetails
<a name="API_EventDetails"></a>

Detailed information about a specific event, including event metadata.

## Contents
<a name="API_EventDetails_Contents"></a>

 ** EventMetadata **   <a name="sagemaker-Type-EventDetails-EventMetadata"></a>
Metadata specific to the event, which may include information about the cluster, instance group, or instance involved.
Type: [EventMetadata](API_EventMetadata.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: No
