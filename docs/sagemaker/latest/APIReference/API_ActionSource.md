# ActionSource
<a name="API_ActionSource"></a>

A structure describing the source of an action.

## Contents
<a name="API_ActionSource_Contents"></a>

 ** SourceUri **   <a name="sagemaker-Type-ActionSource-SourceUri"></a>
The URI of the source.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Pattern: `.*`
Required: Yes

 ** SourceId **   <a name="sagemaker-Type-ActionSource-SourceId"></a>
The ID of the source.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No

 ** SourceType **   <a name="sagemaker-Type-ActionSource-SourceType"></a>
The type of the source.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
