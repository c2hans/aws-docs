# EbsStorageSettings
<a name="API_EbsStorageSettings"></a>

A collection of EBS storage settings that apply to both private and shared spaces.

## Contents
<a name="API_EbsStorageSettings_Contents"></a>

 ** EbsVolumeSizeInGb **   <a name="sagemaker-Type-EbsStorageSettings-EbsVolumeSizeInGb"></a>
The size of an EBS storage volume for a space.
Type: Integer
Valid Range: Minimum value of 5. Maximum value of 16384.
Required: Yes
