# EnvironmentParameter
<a name="API_EnvironmentParameter"></a>

A list of environment parameters suggested by the Amazon SageMaker Inference Recommender.

## Contents
<a name="API_EnvironmentParameter_Contents"></a>

 ** Key **   <a name="sagemaker-Type-EnvironmentParameter-Key"></a>
The environment key suggested by the Amazon SageMaker Inference Recommender.
Type: String
Required: Yes

 ** Value **   <a name="sagemaker-Type-EnvironmentParameter-Value"></a>
The value suggested by the Amazon SageMaker Inference Recommender.
Type: String
Required: Yes

 ** ValueType **   <a name="sagemaker-Type-EnvironmentParameter-ValueType"></a>
The value type suggested by the Amazon SageMaker Inference Recommender.
Type: String
Required: Yes
