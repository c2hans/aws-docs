# JobConfigSchemaVersionSummary
<a name="API_JobConfigSchemaVersionSummary"></a>

Provides summary information about a job configuration schema version.

## Contents
<a name="API_JobConfigSchemaVersionSummary_Contents"></a>

 ** JobConfigSchemaVersion **   <a name="sagemaker-Type-JobConfigSchemaVersionSummary-JobConfigSchemaVersion"></a>
The version of the job configuration schema.
Type: String
Length Constraints: Minimum length of 5. Maximum length of 16.
Pattern: `\d+\.\d+\.\d+`
Required: Yes
