# EndpointPerformance
<a name="API_EndpointPerformance"></a>

The performance results from running an Inference Recommender job on an existing endpoint.

## Contents
<a name="API_EndpointPerformance_Contents"></a>

 ** EndpointInfo **   <a name="sagemaker-Type-EndpointPerformance-EndpointInfo"></a>
Details about a customer endpoint that was compared in an Inference Recommender job.
Type: [EndpointInfo](API_EndpointInfo.md) object
Required: Yes

 ** Metrics **   <a name="sagemaker-Type-EndpointPerformance-Metrics"></a>
The metrics for an existing endpoint.
Type: [InferenceMetrics](API_InferenceMetrics.md) object
Required: Yes
