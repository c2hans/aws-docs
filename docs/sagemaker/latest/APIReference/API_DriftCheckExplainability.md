# DriftCheckExplainability
<a name="API_DriftCheckExplainability"></a>

Represents the drift check explainability baselines that can be used when the model monitor is set using the model package.

## Contents
<a name="API_DriftCheckExplainability_Contents"></a>

 ** ConfigFile **   <a name="sagemaker-Type-DriftCheckExplainability-ConfigFile"></a>
The explainability config file for the model.
Type: [FileSource](API_FileSource.md) object
Required: No

 ** Constraints **   <a name="sagemaker-Type-DriftCheckExplainability-Constraints"></a>
The drift check explainability constraints.
Type: [MetricsSource](API_MetricsSource.md) object
Required: No
