# OutputBand
<a name="API_geospatial_OutputBand"></a>

A single EarthObservationJob output band.

## Contents
<a name="API_geospatial_OutputBand_Contents"></a>

 ** BandName **   <a name="sagemaker-Type-geospatial_OutputBand-BandName"></a>
The name of the band.
Type: String
Required: Yes

 ** OutputDataType **   <a name="sagemaker-Type-geospatial_OutputBand-OutputDataType"></a>
The datatype of the output band.
Type: String
Valid Values: `INT32 | FLOAT32 | INT16 | FLOAT64 | UINT16`
Required: Yes
