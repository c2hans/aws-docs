# AIWorkloadConfigs
<a name="API_AIWorkloadConfigs"></a>

The benchmark tool configuration for an AI workload.

## Contents
<a name="API_AIWorkloadConfigs_Contents"></a>

 ** WorkloadSpec **   <a name="sagemaker-Type-AIWorkloadConfigs-WorkloadSpec"></a>
The workload specification that defines benchmark parameters.
Type: [WorkloadSpec](API_WorkloadSpec.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes
