# AIRecommendationPerformanceTarget
<a name="API_AIRecommendationPerformanceTarget"></a>

The performance targets for an AI recommendation job.

## Contents
<a name="API_AIRecommendationPerformanceTarget_Contents"></a>

 ** Constraints **   <a name="sagemaker-Type-AIRecommendationPerformanceTarget-Constraints"></a>
An array of performance constraints that define the optimization objectives.
Type: Array of [AIRecommendationConstraint](API_AIRecommendationConstraint.md) objects
Required: Yes
