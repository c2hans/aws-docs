# InferenceHubAccessConfig
<a name="API_InferenceHubAccessConfig"></a>

Configuration information specifying which hub contents have accessible deployment options.

## Contents
<a name="API_InferenceHubAccessConfig_Contents"></a>

 ** HubContentArn **   <a name="sagemaker-Type-InferenceHubAccessConfig-HubContentArn"></a>
The ARN of the hub content for which deployment access is allowed.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 255.
Pattern: `.*`
Required: Yes
