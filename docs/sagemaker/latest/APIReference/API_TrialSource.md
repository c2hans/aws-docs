# TrialSource
<a name="API_TrialSource"></a>

The source of the trial.

## Contents
<a name="API_TrialSource_Contents"></a>

 ** SourceArn **   <a name="sagemaker-Type-TrialSource-SourceArn"></a>
The Amazon Resource Name (ARN) of the source.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `arn:aws[a-z\-]*:sagemaker:[a-z0-9\-]*:[0-9]{12}:.*`
Required: Yes

 ** SourceType **   <a name="sagemaker-Type-TrialSource-SourceType"></a>
The source job type.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 128.
Required: No
