# VectorEnrichmentJobDataSourceConfigInput
<a name="API_geospatial_VectorEnrichmentJobDataSourceConfigInput"></a>

The input structure for the data source that represents the storage type of the input data objects.

## Contents
<a name="API_geospatial_VectorEnrichmentJobDataSourceConfigInput_Contents"></a>

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** S3Data **   <a name="sagemaker-Type-geospatial_VectorEnrichmentJobDataSourceConfigInput-S3Data"></a>
The input structure for the Amazon S3 data that represents the Amazon S3 location of the input data objects.
Type: [VectorEnrichmentJobS3Data](API_geospatial_VectorEnrichmentJobS3Data.md) object
Required: No
