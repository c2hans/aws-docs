# ResourceConfigForUpdate
<a name="API_ResourceConfigForUpdate"></a>

The `ResourceConfig` to update `KeepAlivePeriodInSeconds`. Other fields in the `ResourceConfig` cannot be updated.

## Contents
<a name="API_ResourceConfigForUpdate_Contents"></a>

 ** KeepAlivePeriodInSeconds **   <a name="sagemaker-Type-ResourceConfigForUpdate-KeepAlivePeriodInSeconds"></a>
The `KeepAlivePeriodInSeconds` value specified in the `ResourceConfig` to update.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 21600.
Required: Yes
