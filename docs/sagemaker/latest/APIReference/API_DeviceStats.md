# DeviceStats
<a name="API_DeviceStats"></a>

Status of devices.

## Contents
<a name="API_DeviceStats_Contents"></a>

 ** ConnectedDeviceCount **   <a name="sagemaker-Type-DeviceStats-ConnectedDeviceCount"></a>
The number of devices connected with a heartbeat.
Type: Long
Required: Yes

 ** RegisteredDeviceCount **   <a name="sagemaker-Type-DeviceStats-RegisteredDeviceCount"></a>
The number of registered devices.
Type: Long
Required: Yes
