# OptimizerStepConfig
<a name="API_training_session_runtime_OptimizerStepConfig"></a>

The configuration for an optimizer step that updates model weights using gradients accumulated from previous forward-backward passes.

## Contents
<a name="API_training_session_runtime_OptimizerStepConfig_Contents"></a>

 ** adamParamsConfig **   <a name="sagemaker-Type-training_session_runtime_OptimizerStepConfig-adamParamsConfig"></a>
The Adam optimizer hyperparameters for this step.
Type: [AdamParamsConfig](API_training_session_runtime_AdamParamsConfig.md) object
Required: Yes
