# KernelSpec
<a name="API_KernelSpec"></a>

The specification of a Jupyter kernel.

## Contents
<a name="API_KernelSpec_Contents"></a>

 ** Name **   <a name="sagemaker-Type-KernelSpec-Name"></a>
The name of the Jupyter kernel in the image. This value is case sensitive.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: Yes

 ** DisplayName **   <a name="sagemaker-Type-KernelSpec-DisplayName"></a>
The display name of the kernel.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: No
