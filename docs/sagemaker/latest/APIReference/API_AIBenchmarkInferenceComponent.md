# AIBenchmarkInferenceComponent
<a name="API_AIBenchmarkInferenceComponent"></a>

An inference component to benchmark.

## Contents
<a name="API_AIBenchmarkInferenceComponent_Contents"></a>

 ** Identifier **   <a name="sagemaker-Type-AIBenchmarkInferenceComponent-Identifier"></a>
The name or Amazon Resource Name (ARN) of the inference component.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `(arn:aws[a-z\-]*:sagemaker:[a-z0-9\-]*:[0-9]{12}:[a-z\-]*/)?([a-zA-Z0-9]([a-zA-Z0-9\-]){0,62})(?<!-)`
Required: Yes
