# MonitoringOutput
<a name="API_MonitoringOutput"></a>

The output object for a monitoring job.

## Contents
<a name="API_MonitoringOutput_Contents"></a>

 ** S3Output **   <a name="sagemaker-Type-MonitoringOutput-S3Output"></a>
The Amazon S3 storage location where the results of a monitoring job are saved.
Type: [MonitoringS3Output](API_MonitoringS3Output.md) object
Required: Yes
