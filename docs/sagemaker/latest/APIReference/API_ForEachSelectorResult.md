# ForEachSelectorResult
<a name="API_ForEachSelectorResult"></a>

The result of the selector that identifies an iteration of a ForEach step.

## Contents
<a name="API_ForEachSelectorResult_Contents"></a>

 ** Index **   <a name="sagemaker-Type-ForEachSelectorResult-Index"></a>
The index of the iteration within the ForEach step.
Type: Integer
Required: No

 ** StepName **   <a name="sagemaker-Type-ForEachSelectorResult-StepName"></a>
The name of the step associated with the iteration.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
