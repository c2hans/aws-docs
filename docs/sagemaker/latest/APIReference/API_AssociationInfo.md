# AssociationInfo
<a name="API_AssociationInfo"></a>

 The data type used to describe the relationship between different sources.

## Contents
<a name="API_AssociationInfo_Contents"></a>

 ** DestinationArn **   <a name="sagemaker-Type-AssociationInfo-DestinationArn"></a>
 The Amazon Resource Name (ARN) of the `AssociationInfo` destination.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Required: Yes

 ** SourceArn **   <a name="sagemaker-Type-AssociationInfo-SourceArn"></a>
 The Amazon Resource Name (ARN) of the `AssociationInfo` source.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Required: Yes
