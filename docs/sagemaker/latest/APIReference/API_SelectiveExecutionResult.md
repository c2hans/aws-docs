# SelectiveExecutionResult
<a name="API_SelectiveExecutionResult"></a>

The ARN from an execution of the current pipeline.

## Contents
<a name="API_SelectiveExecutionResult_Contents"></a>

 ** SourcePipelineExecutionArn **   <a name="sagemaker-Type-SelectiveExecutionResult-SourcePipelineExecutionArn"></a>
The ARN from an execution of the current pipeline.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Pattern: `arn:aws[a-z\-]*:sagemaker:[a-z0-9\-]*:[0-9]{12}:pipeline\/.*\/execution\/.*`
Required: No
