# InferenceComponentDataCacheConfigSummary
<a name="API_InferenceComponentDataCacheConfigSummary"></a>

Settings that affect how the inference component caches data.

## Contents
<a name="API_InferenceComponentDataCacheConfigSummary_Contents"></a>

 ** EnableCaching **   <a name="sagemaker-Type-InferenceComponentDataCacheConfigSummary-EnableCaching"></a>
Indicates whether the inference component caches model artifacts as part of the auto scaling process.
Type: Boolean
Required: Yes
