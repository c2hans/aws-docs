# UiTemplateInfo
<a name="API_UiTemplateInfo"></a>

Container for user interface template information.

## Contents
<a name="API_UiTemplateInfo_Contents"></a>

 ** ContentSha256 **   <a name="sagemaker-Type-UiTemplateInfo-ContentSha256"></a>
The SHA-256 digest of the contents of the template.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128000.
Required: No

 ** Url **   <a name="sagemaker-Type-UiTemplateInfo-Url"></a>
The URL for the user interface template.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: No
