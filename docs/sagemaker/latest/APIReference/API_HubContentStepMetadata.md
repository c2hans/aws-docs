# HubContentStepMetadata
<a name="API_HubContentStepMetadata"></a>

The hub and the hub content that a HubContent step imported.

## Contents
<a name="API_HubContentStepMetadata_Contents"></a>

 ** HubArn **   <a name="sagemaker-Type-HubContentStepMetadata-HubArn"></a>
The Amazon Resource Name (ARN) of the hub that the step imported the content into.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Required: No

 ** HubContentArn **   <a name="sagemaker-Type-HubContentStepMetadata-HubContentArn"></a>
The Amazon Resource Name (ARN) of the hub content that was imported by this step execution.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Required: No
