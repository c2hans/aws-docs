# ModelInput
<a name="API_training_session_runtime_ModelInput"></a>

The tokenized model input composed of ordered encoded text chunks.

## Contents
<a name="API_training_session_runtime_ModelInput_Contents"></a>

 ** chunks **   <a name="sagemaker-Type-training_session_runtime_ModelInput-chunks"></a>
The ordered list of encoded text chunks forming the input sequence.
Type: Array of [EncodedTextChunk](API_training_session_runtime_EncodedTextChunk.md) objects
Required: Yes
