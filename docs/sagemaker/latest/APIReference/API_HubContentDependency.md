# HubContentDependency
<a name="API_HubContentDependency"></a>

Any dependencies related to hub content, such as scripts, model artifacts, datasets, or notebooks.

## Contents
<a name="API_HubContentDependency_Contents"></a>

 ** DependencyCopyPath **   <a name="sagemaker-Type-HubContentDependency-DependencyCopyPath"></a>
The hub content dependency copy path.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1023.
Pattern: `.*`
Required: No

 ** DependencyOriginPath **   <a name="sagemaker-Type-HubContentDependency-DependencyOriginPath"></a>
The hub content dependency origin path.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1023.
Pattern: `.*`
Required: No
