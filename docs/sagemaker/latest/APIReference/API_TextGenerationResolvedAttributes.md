# TextGenerationResolvedAttributes
<a name="API_TextGenerationResolvedAttributes"></a>

The resolved attributes specific to the text generation problem type.

## Contents
<a name="API_TextGenerationResolvedAttributes_Contents"></a>

 ** BaseModelName **   <a name="sagemaker-Type-TextGenerationResolvedAttributes-BaseModelName"></a>
The name of the base model to fine-tune.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Pattern: `[a-zA-Z0-9](-*[a-zA-Z0-9])*`
Required: No
