# InstanceRequirementsEniConfiguration
<a name="API_InstanceRequirementsEniConfiguration"></a>

The customer ENI and additional ENIs associated with a network interface category.

## Contents
<a name="API_InstanceRequirementsEniConfiguration_Contents"></a>

 ** AdditionalEnis **   <a name="sagemaker-Type-InstanceRequirementsEniConfiguration-AdditionalEnis"></a>
Information about additional Elastic Network Interfaces (ENIs) associated with the instance type category.
Type: [AdditionalEnis](API_AdditionalEnis.md) object
Required: No

 ** CustomerEni **   <a name="sagemaker-Type-InstanceRequirementsEniConfiguration-CustomerEni"></a>
The ID of the customer-managed Elastic Network Interface (ENI) associated with the instance type category.
Type: String
Required: No
