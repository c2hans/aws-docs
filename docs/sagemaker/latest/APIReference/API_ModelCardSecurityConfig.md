# ModelCardSecurityConfig
<a name="API_ModelCardSecurityConfig"></a>

Configure the security settings to protect model card data.

## Contents
<a name="API_ModelCardSecurityConfig_Contents"></a>

 ** KmsKeyId **   <a name="sagemaker-Type-ModelCardSecurityConfig-KmsKeyId"></a>
A Key Management Service [key ID](https://docs.aws.amazon.com/kms/latest/developerguide/concepts.html#key-id-key-id) to use for encrypting a model card.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Pattern: `[a-zA-Z0-9:/_-]*`
Required: No
