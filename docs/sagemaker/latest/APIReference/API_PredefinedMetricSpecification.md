# PredefinedMetricSpecification
<a name="API_PredefinedMetricSpecification"></a>

A specification for a predefined metric.

## Contents
<a name="API_PredefinedMetricSpecification_Contents"></a>

 ** PredefinedMetricType **   <a name="sagemaker-Type-PredefinedMetricSpecification-PredefinedMetricType"></a>
The metric type. You can only apply SageMaker metric types to SageMaker endpoints.
Type: String
Required: No
