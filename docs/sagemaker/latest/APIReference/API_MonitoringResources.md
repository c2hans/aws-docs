# MonitoringResources
<a name="API_MonitoringResources"></a>

## Contents
<a name="API_MonitoringResources_Contents"></a>

 ** ClusterConfig **   <a name="sagemaker-Type-MonitoringResources-ClusterConfig"></a>

Required: Yes
