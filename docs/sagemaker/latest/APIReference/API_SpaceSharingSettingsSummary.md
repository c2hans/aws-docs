# SpaceSharingSettingsSummary
<a name="API_SpaceSharingSettingsSummary"></a>

Specifies summary information about the space sharing settings.

## Contents
<a name="API_SpaceSharingSettingsSummary_Contents"></a>

 ** SharingType **   <a name="sagemaker-Type-SpaceSharingSettingsSummary-SharingType"></a>
Specifies the sharing type of the space.
Type: String
Valid Values: `Private | Shared`
Required: No
