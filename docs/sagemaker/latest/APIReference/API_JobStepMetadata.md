# JobStepMetadata
<a name="API_JobStepMetadata"></a>

Metadata for a SageMaker job step.

## Contents
<a name="API_JobStepMetadata_Contents"></a>

 ** Arn **   <a name="sagemaker-Type-JobStepMetadata-Arn"></a>
The Amazon Resource Name (ARN) of the SageMaker job that was run by this step execution.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: No
