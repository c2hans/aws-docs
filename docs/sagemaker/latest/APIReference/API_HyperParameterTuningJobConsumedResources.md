# HyperParameterTuningJobConsumedResources
<a name="API_HyperParameterTuningJobConsumedResources"></a>

The total resources consumed by your hyperparameter tuning job.

## Contents
<a name="API_HyperParameterTuningJobConsumedResources_Contents"></a>

 ** RuntimeInSeconds **   <a name="sagemaker-Type-HyperParameterTuningJobConsumedResources-RuntimeInSeconds"></a>
The wall clock runtime in seconds used by your hyperparameter tuning job.
Type: Integer
Required: No
