# OptimizationOutput
<a name="API_OptimizationOutput"></a>

Output values produced by an optimization job.

## Contents
<a name="API_OptimizationOutput_Contents"></a>

 ** RecommendedInferenceImage **   <a name="sagemaker-Type-OptimizationOutput-RecommendedInferenceImage"></a>
The image that SageMaker recommends that you use to host the optimized model that you created with an optimization job.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 255.
Pattern: `[\S]+`
Required: No
