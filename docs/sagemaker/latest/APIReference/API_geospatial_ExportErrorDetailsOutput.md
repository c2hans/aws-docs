# ExportErrorDetailsOutput
<a name="API_geospatial_ExportErrorDetailsOutput"></a>

The structure representing the errors in an export EarthObservationJob operation.

## Contents
<a name="API_geospatial_ExportErrorDetailsOutput_Contents"></a>

 ** Message **   <a name="sagemaker-Type-geospatial_ExportErrorDetailsOutput-Message"></a>
A detailed message describing the error in an export EarthObservationJob operation.
Type: String
Required: No

 ** Type **   <a name="sagemaker-Type-geospatial_ExportErrorDetailsOutput-Type"></a>
The type of error in an export EarthObservationJob operation.
Type: String
Valid Values: `CLIENT_ERROR | SERVER_ERROR`
Required: No
