# AIRecommendationInferenceSpecification
<a name="API_AIRecommendationInferenceSpecification"></a>

The inference framework for an AI recommendation job.

## Contents
<a name="API_AIRecommendationInferenceSpecification_Contents"></a>

 ** Framework **   <a name="sagemaker-Type-AIRecommendationInferenceSpecification-Framework"></a>
The inference framework. Valid values are `LMI` and `VLLM`.
Type: String
Valid Values: `LMI | VLLM`
Required: No
