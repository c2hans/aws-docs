# MonitoringAlertActions
<a name="API_MonitoringAlertActions"></a>

A list of alert actions taken in response to an alert going into `InAlert` status.

## Contents
<a name="API_MonitoringAlertActions_Contents"></a>

 ** ModelDashboardIndicator **   <a name="sagemaker-Type-MonitoringAlertActions-ModelDashboardIndicator"></a>
An alert action taken to light up an icon on the Model Dashboard when an alert goes into `InAlert` status.
Type: [ModelDashboardIndicatorAction](API_ModelDashboardIndicatorAction.md) object
Required: No
