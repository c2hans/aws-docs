# ContextSource
<a name="API_ContextSource"></a>

A structure describing the source of a context.

## Contents
<a name="API_ContextSource_Contents"></a>

 ** SourceUri **   <a name="sagemaker-Type-ContextSource-SourceUri"></a>
The URI of the source.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Pattern: `.*`
Required: Yes

 ** SourceId **   <a name="sagemaker-Type-ContextSource-SourceId"></a>
The ID of the source.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No

 ** SourceType **   <a name="sagemaker-Type-ContextSource-SourceType"></a>
The type of the source.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
