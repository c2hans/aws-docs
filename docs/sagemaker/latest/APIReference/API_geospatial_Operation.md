# Operation
<a name="API_geospatial_Operation"></a>

Represents an arithmetic operation to compute spectral index.

## Contents
<a name="API_geospatial_Operation_Contents"></a>

 ** Equation **   <a name="sagemaker-Type-geospatial_Operation-Equation"></a>
Textual representation of the math operation; Equation used to compute the spectral index.
Type: String
Required: Yes

 ** Name **   <a name="sagemaker-Type-geospatial_Operation-Name"></a>
The name of the operation.
Type: String
Required: Yes

 ** OutputType **   <a name="sagemaker-Type-geospatial_Operation-OutputType"></a>
The type of the operation.
Type: String
Valid Values: `INT32 | FLOAT32 | INT16 | FLOAT64 | UINT16`
Required: No
