# VectorEnrichmentJobExportErrorDetails
<a name="API_geospatial_VectorEnrichmentJobExportErrorDetails"></a>

VectorEnrichmentJob export error details in response from GetVectorEnrichmentJob.

## Contents
<a name="API_geospatial_VectorEnrichmentJobExportErrorDetails_Contents"></a>

 ** Message **   <a name="sagemaker-Type-geospatial_VectorEnrichmentJobExportErrorDetails-Message"></a>
The message providing details about the errors generated during the Vector Enrichment job.
Type: String
Required: No

 ** Type **   <a name="sagemaker-Type-geospatial_VectorEnrichmentJobExportErrorDetails-Type"></a>
The output error details for an Export operation on a Vector Enrichment job.
Type: String
Valid Values: `CLIENT_ERROR | SERVER_ERROR`
Required: No
