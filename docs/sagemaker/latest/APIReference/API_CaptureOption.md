# CaptureOption
<a name="API_CaptureOption"></a>

Specifies data Model Monitor will capture.

## Contents
<a name="API_CaptureOption_Contents"></a>

 ** CaptureMode **   <a name="sagemaker-Type-CaptureOption-CaptureMode"></a>
Specify the boundary of data to capture.
Type: String
Valid Values: `Input | Output | InputAndOutput`
Required: Yes
