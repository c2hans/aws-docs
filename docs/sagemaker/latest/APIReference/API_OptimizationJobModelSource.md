# OptimizationJobModelSource
<a name="API_OptimizationJobModelSource"></a>

The location of the source model to optimize with an optimization job.

## Contents
<a name="API_OptimizationJobModelSource_Contents"></a>

 ** S3 **   <a name="sagemaker-Type-OptimizationJobModelSource-S3"></a>
The Amazon S3 location of a source model to optimize with an optimization job.
Type: [OptimizationJobModelSourceS3](API_OptimizationJobModelSourceS3.md) object
Required: No

 ** SageMakerModel **   <a name="sagemaker-Type-OptimizationJobModelSource-SageMakerModel"></a>
The name of an existing SageMaker model to optimize with an optimization job.
Type: [OptimizationSageMakerModel](API_OptimizationSageMakerModel.md) object
