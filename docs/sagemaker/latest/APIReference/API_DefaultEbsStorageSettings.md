# DefaultEbsStorageSettings
<a name="API_DefaultEbsStorageSettings"></a>

A collection of default EBS storage settings that apply to spaces created within a domain or user profile.

## Contents
<a name="API_DefaultEbsStorageSettings_Contents"></a>

 ** DefaultEbsVolumeSizeInGb **   <a name="sagemaker-Type-DefaultEbsStorageSettings-DefaultEbsVolumeSizeInGb"></a>
The default size of the EBS storage volume for a space.
Type: Integer
Valid Range: Minimum value of 5. Maximum value of 16384.
Required: Yes

 ** MaximumEbsVolumeSizeInGb **   <a name="sagemaker-Type-DefaultEbsStorageSettings-MaximumEbsVolumeSizeInGb"></a>
The maximum size of the EBS storage volume for a space.
Type: Integer
Valid Range: Minimum value of 5. Maximum value of 16384.
Required: Yes
