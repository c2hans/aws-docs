# CfnStackCreateParameter
<a name="API_CfnStackCreateParameter"></a>

 A key-value pair that represents a parameter for the CloudFormation stack.

## Contents
<a name="API_CfnStackCreateParameter_Contents"></a>

 ** Key **   <a name="sagemaker-Type-CfnStackCreateParameter-Key"></a>
 The name of the CloudFormation parameter.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Pattern: `.{1,255}`
Required: Yes

 ** Value **   <a name="sagemaker-Type-CfnStackCreateParameter-Value"></a>
 The value of the CloudFormation parameter.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 4096.
Pattern: `.{0,4096}`
Required: No
