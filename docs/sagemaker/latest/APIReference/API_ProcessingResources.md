# ProcessingResources
<a name="API_ProcessingResources"></a>

Identifies the resources, ML compute instances, and ML storage volumes to deploy for a processing job. In distributed training, you specify more than one instance.

## Contents
<a name="API_ProcessingResources_Contents"></a>

 ** ClusterConfig **   <a name="sagemaker-Type-ProcessingResources-ClusterConfig"></a>
The configuration for the resources in a cluster used to run the processing job.
Type: [ProcessingClusterConfig](API_ProcessingClusterConfig.md) object
Required: Yes
