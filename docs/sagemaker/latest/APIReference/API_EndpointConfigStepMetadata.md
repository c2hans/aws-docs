# EndpointConfigStepMetadata
<a name="API_EndpointConfigStepMetadata"></a>

Metadata for an endpoint configuration step.

## Contents
<a name="API_EndpointConfigStepMetadata_Contents"></a>

 ** Arn **   <a name="sagemaker-Type-EndpointConfigStepMetadata-Arn"></a>
The Amazon Resource Name (ARN) of the endpoint configuration used in the step.
Type: String
Length Constraints: Minimum length of 20. Maximum length of 2048.
Pattern: `arn:aws[a-z\-]*:sagemaker:[a-z0-9\-]*:[0-9]{12}:endpoint-config/.*`
Required: No
