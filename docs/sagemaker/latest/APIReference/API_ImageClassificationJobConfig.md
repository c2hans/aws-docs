# ImageClassificationJobConfig
<a name="API_ImageClassificationJobConfig"></a>

The collection of settings used by an AutoML job V2 for the image classification problem type.

## Contents
<a name="API_ImageClassificationJobConfig_Contents"></a>

 ** CompletionCriteria **   <a name="sagemaker-Type-ImageClassificationJobConfig-CompletionCriteria"></a>
How long a job is allowed to run, or how many candidates a job is allowed to generate.
Type: [AutoMLJobCompletionCriteria](API_AutoMLJobCompletionCriteria.md) object
Required: No
