# DriftCheckModelQuality
<a name="API_DriftCheckModelQuality"></a>

Represents the drift check model quality baselines that can be used when the model monitor is set using the model package.

## Contents
<a name="API_DriftCheckModelQuality_Contents"></a>

 ** Constraints **   <a name="sagemaker-Type-DriftCheckModelQuality-Constraints"></a>
The drift check model quality constraints.
Type: [MetricsSource](API_MetricsSource.md) object
Required: No

 ** Statistics **   <a name="sagemaker-Type-DriftCheckModelQuality-Statistics"></a>
The drift check model quality statistics.
Type: [MetricsSource](API_MetricsSource.md) object
Required: No
