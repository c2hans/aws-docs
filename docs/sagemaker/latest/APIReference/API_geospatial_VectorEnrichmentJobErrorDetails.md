# VectorEnrichmentJobErrorDetails
<a name="API_geospatial_VectorEnrichmentJobErrorDetails"></a>

VectorEnrichmentJob error details in response from GetVectorEnrichmentJob.

## Contents
<a name="API_geospatial_VectorEnrichmentJobErrorDetails_Contents"></a>

 ** ErrorMessage **   <a name="sagemaker-Type-geospatial_VectorEnrichmentJobErrorDetails-ErrorMessage"></a>
A message that you define and then is processed and rendered by the Vector Enrichment job when the error occurs.
Type: String
Required: No

 ** ErrorType **   <a name="sagemaker-Type-geospatial_VectorEnrichmentJobErrorDetails-ErrorType"></a>
The type of error generated during the Vector Enrichment job.
Type: String
Valid Values: `CLIENT_ERROR | SERVER_ERROR`
Required: No
