# PropertyFilter
<a name="API_geospatial_PropertyFilter"></a>

The structure representing a single PropertyFilter.

## Contents
<a name="API_geospatial_PropertyFilter_Contents"></a>

 ** Property **   <a name="sagemaker-Type-geospatial_PropertyFilter-Property"></a>
Represents a single property to match with when searching a raster data collection.
Type: [Property](API_geospatial_Property.md) object
 **Note: **This object is a Union. Only one member of this object can be specified or returned.
Required: Yes
