# TimeRangeFilterOutput
<a name="API_geospatial_TimeRangeFilterOutput"></a>

The output structure of the time range filter.

## Contents
<a name="API_geospatial_TimeRangeFilterOutput_Contents"></a>

 ** EndTime **   <a name="sagemaker-Type-geospatial_TimeRangeFilterOutput-EndTime"></a>
The ending time for the time range filter.
Type: Timestamp
Required: Yes

 ** StartTime **   <a name="sagemaker-Type-geospatial_TimeRangeFilterOutput-StartTime"></a>
The starting time for the time range filter.
Type: Timestamp
Required: Yes
