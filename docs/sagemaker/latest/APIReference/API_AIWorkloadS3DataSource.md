# AIWorkloadS3DataSource
<a name="API_AIWorkloadS3DataSource"></a>

The Amazon S3 data source for an AI workload.

## Contents
<a name="API_AIWorkloadS3DataSource_Contents"></a>

 ** S3Uri **   <a name="sagemaker-Type-AIWorkloadS3DataSource-S3Uri"></a>
The Amazon S3 URI of the data.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Pattern: `(https|s3)://([^/]+)/?(.*)`
Required: Yes
