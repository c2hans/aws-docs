# SpaceAppLifecycleManagement
<a name="API_SpaceAppLifecycleManagement"></a>

Settings that are used to configure and manage the lifecycle of Amazon SageMaker Studio applications in a space.

## Contents
<a name="API_SpaceAppLifecycleManagement_Contents"></a>

 ** IdleSettings **   <a name="sagemaker-Type-SpaceAppLifecycleManagement-IdleSettings"></a>
Settings related to idle shutdown of Studio applications.
Type: [SpaceIdleSettings](API_SpaceIdleSettings.md) object
Required: No
