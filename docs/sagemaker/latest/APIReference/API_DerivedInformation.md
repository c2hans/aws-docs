# DerivedInformation
<a name="API_DerivedInformation"></a>

Information that SageMaker Neo automatically derived about the model.

## Contents
<a name="API_DerivedInformation_Contents"></a>

 ** DerivedDataInputConfig **   <a name="sagemaker-Type-DerivedInformation-DerivedDataInputConfig"></a>
The data input configuration that SageMaker Neo automatically derived for the model. When SageMaker Neo derives this information, you don't need to specify the data input configuration when you create a compilation job.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 16384.
Pattern: `[\S\s]+`
Required: No
