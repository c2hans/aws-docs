# TrainingSessionOutputConfig
<a name="API_TrainingSessionOutputConfig"></a>

The output configuration for a training session, including the Amazon S3 location for checkpoints and model artifacts, and optional encryption settings.

## Contents
<a name="API_TrainingSessionOutputConfig_Contents"></a>

 ** S3Location **   <a name="sagemaker-Type-TrainingSessionOutputConfig-S3Location"></a>
The Amazon S3 location where training session outputs, including checkpoints and model artifacts, are stored.
Type: [TrainingSessionS3Location](API_TrainingSessionS3Location.md) object
Required: Yes
