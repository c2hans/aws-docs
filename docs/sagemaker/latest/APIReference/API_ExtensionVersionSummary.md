# ExtensionVersionSummary

A version of an extension that you can install on a SageMaker HyperPod cluster.

## Contents
<a name="API_ExtensionVersionSummary_Contents"></a>

 ** ExtensionVersion **   <a name="sagemaker-Type-ExtensionVersionSummary-ExtensionVersion"></a>
The version of the extension, in `MAJOR.MINOR.PATCH` format, for example `1.0.0`.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Pattern: `[0-9]+\.[0-9]+\.[0-9]+`
Required: Yes
