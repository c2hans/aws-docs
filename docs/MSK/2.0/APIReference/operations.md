# Operations
<a name="operations"></a>

The Amazon Managed Streaming for Apache Kafka REST API includes the following operations.
+ [CreateClusterV2](v2-clusters.md#CreateClusterV2)

  Creates a serverless or provisioned cluster.
+ [DescribeClusterOperationV2](v2-operations-clusteroperationarn.md#DescribeClusterOperationV2)
+ [DescribeClusterV2](v2-clusters-clusterarn.md#DescribeClusterV2)

  Returns information about a cluster.
+ [ListClusterOperationsV2](v2-clusters-clusterarn-operations.md#ListClusterOperationsV2)
+ [ListClustersV2](v2-clusters.md#ListClustersV2)

  Lists all serverless and provisioned clusters.
