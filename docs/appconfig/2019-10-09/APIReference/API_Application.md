# Application
<a name="API_Application"></a>

## Contents
<a name="API_Application_Contents"></a>

 ** Description **   <a name="appconfig-Type-Application-Description"></a>
The description of the application.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1024.
Required: No

 ** Id **   <a name="appconfig-Type-Application-Id"></a>
The application ID.
Type: String
Pattern: `[a-z0-9]{4,7}`
Required: No

 ** Name **   <a name="appconfig-Type-Application-Name"></a>
The application name.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No
