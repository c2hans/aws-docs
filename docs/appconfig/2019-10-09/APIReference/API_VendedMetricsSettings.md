# VendedMetricsSettings
<a name="API_VendedMetricsSettings"></a>

The configuration settings for vended metrics in your AWS AppConfig account.

## Contents
<a name="API_VendedMetricsSettings_Contents"></a>

 ** Enabled **   <a name="appconfig-Type-VendedMetricsSettings-Enabled"></a>
Specifies whether vended metrics are enabled for the account.
Type: Boolean
Required: No
