# InvalidParameterDetail
<a name="API_appconfigdata_InvalidParameterDetail"></a>

Information about an invalid parameter.

## Contents
<a name="API_appconfigdata_InvalidParameterDetail_Contents"></a>

 ** Problem **   <a name="appconfig-Type-appconfigdata_InvalidParameterDetail-Problem"></a>
The reason the parameter is invalid.
Type: String
Valid Values: `Corrupted | Expired | PollIntervalNotSatisfied`
Required: No
