# Mapping Amazon RDS personas to this guide
<a name="personas"></a>

This guide is structured around common Amazon RDS user roles to provide targeted, actionable guidance based on your responsibilities and objectives. The following table helps you identify the sections most relevant to your needs, whether you’re a data professional optimizing database performance, a developer connecting applications, or a security professional ensuring compliance.

By aligning each chapter with specific challenges and goals, this guide offers a tailored approach to getting started with Amazon RDS.

| Persona | Where to start | Why start here? |
| --- | --- | --- |
| Cloud implementer | [Creating your first DB instance](creating.md) | This chapter guides you through the process of creating a DB instance, including selecting the appropriate engine and configuring instance settings.<br />**Your goals**:[See the AWS documentation website for more details](http://docs.aws.amazon.com/AmazonRDS/latest/gettingstartedguide/personas.html) |
| Security professional | [Securing your DB instance](security.md) | This chapter focuses on setting up critical security configurations, including IAM roles, encryption, and networking best practices.<br />**Your goals**:[See the AWS documentation website for more details](http://docs.aws.amazon.com/AmazonRDS/latest/gettingstartedguide/personas.html) |
| Developer | [Connecting to your DB instance](connecting.md) | This chapter guides developers through connecting to RDS, including using CLI commands with practical examples.<br />**Your goals**:[See the AWS documentation website for more details](http://docs.aws.amazon.com/AmazonRDS/latest/gettingstartedguide/personas.html) |
| Data engineer or manager | [Managing your DB instance](managing.md) and [Optimizing and scaling your DB instance](advanced.md) | These chapters provide guidance on monitoring, diagnosing, and optimizing your RDS database to ensure reliable performance and operational efficiency.<br />**Your goals**:[See the AWS documentation website for more details](http://docs.aws.amazon.com/AmazonRDS/latest/gettingstartedguide/personas.html) |
