# Creating and connecting to an Aurora PostgreSQL DB cluster
<a name="CHAP_GettingStartedAurora.CreatingConnecting.AuroraPostgreSQL"></a>

There are two ways of creating an Aurora PostgreSQL cluster: full configuration and express configuration. With express configuration, you can create and query an Aurora Serverless database in seconds. Pre-configured settings accelerate initial setup and reduce time to first query. You have the flexibility to modify certain settings during creation and most other settings afterward. Full configuration provides complete flexibility to choose all settings at create time, but it takes a few minutes before you can run the first query. Please refer to the sections below to understand more about these 2 types of creates.
