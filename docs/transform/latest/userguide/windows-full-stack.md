# Full-stack Windows modernization
<a name="windows-full-stack"></a>

AWS Transform provides full-stack Windows modernization, including .NET modernization and SQL Server modernization.

The AWS Transform agent for .NET can help you modernize your .NET applications to be compatible with cross-platform .NET. You can modernize .NET using the [.NET web app](dotnet-web-app.md) or the [.NET IDE](dotnet-ide.md).

AWS Transform for [SQL Server modernization](https://docs.aws.amazon.com/sql-server-modernization.html) is an AI-powered service that automates the full-stack modernization of Microsoft SQL Server databases and their associated .NET applications to Amazon Aurora PostgreSQL. The service orchestrates the entire migration journey from schema conversion, data migration and modifying application code to match the new target PostgreSQL, making your teams more productive by automating complex and labor-intensive tasks.
