# ResourceProperty
<a name="API_ResourceProperty"></a>

A structure that describes a property of a resource.

## Contents
<a name="API_ResourceProperty_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Data **   <a name="resourceexplorer-Type-ResourceProperty-Data"></a>
Details about this property. The content of this field is a JSON object that varies based on the resource type.
Type: JSON value
Required: No

 ** LastReportedAt **   <a name="resourceexplorer-Type-ResourceProperty-LastReportedAt"></a>
The date and time that the information about this resource property was last updated.
Type: Timestamp
Required: No

 ** Name **   <a name="resourceexplorer-Type-ResourceProperty-Name"></a>
The name of this property of the resource.
Type: String
Required: No
