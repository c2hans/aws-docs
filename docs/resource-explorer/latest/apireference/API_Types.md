# Data Types
<a name="API_Types"></a>

The AWS Resource Explorer API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [BatchGetViewError](API_BatchGetViewError.md)
+  [ErrorDetails](API_ErrorDetails.md)
+  [IncludedProperty](API_IncludedProperty.md)
+  [Index](API_Index.md)
+  [IndexStatus](API_IndexStatus.md)
+  [ManagedView](API_ManagedView.md)
+  [MemberIndex](API_MemberIndex.md)
+  [OrgConfiguration](API_OrgConfiguration.md)
+  [RegionStatus](API_RegionStatus.md)
+  [Resource](API_Resource.md)
+  [ResourceCount](API_ResourceCount.md)
+  [ResourceProperty](API_ResourceProperty.md)
+  [SearchFilter](API_SearchFilter.md)
+  [ServiceView](API_ServiceView.md)
+  [StreamingAccessDetails](API_StreamingAccessDetails.md)
+  [SupportedResourceType](API_SupportedResourceType.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
+  [View](API_View.md)
+  [ViewStatus](API_ViewStatus.md)
