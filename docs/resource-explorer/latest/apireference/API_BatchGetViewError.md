# BatchGetViewError
<a name="API_BatchGetViewError"></a>

A collection of error messages for any views that AWS Resource Explorer couldn't retrieve details.

## Contents
<a name="API_BatchGetViewError_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ErrorMessage **   <a name="resourceexplorer-Type-BatchGetViewError-ErrorMessage"></a>
The description of the error for the specified view.
Type: String
Required: Yes

 ** ViewArn **   <a name="resourceexplorer-Type-BatchGetViewError-ViewArn"></a>
The [Amazon resource name (ARN)](https://docs.aws.amazon.com/general/latest/gr/aws-arns-and-namespaces.html) of the view for which Resource Explorer failed to retrieve details.
Type: String
Required: Yes
