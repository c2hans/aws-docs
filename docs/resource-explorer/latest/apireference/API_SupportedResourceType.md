# SupportedResourceType
<a name="API_SupportedResourceType"></a>

A structure that describes a resource type supported by AWS Resource Explorer.

## Contents
<a name="API_SupportedResourceType_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** ResourceType **   <a name="resourceexplorer-Type-SupportedResourceType-ResourceType"></a>
The unique identifier of the resource type.
Type: String
Required: No

 ** Service **   <a name="resourceexplorer-Type-SupportedResourceType-Service"></a>
The AWS service that is associated with the resource type. This is the primary service that lets you create and interact with resources of this type.
Type: String
Required: No
