# ErrorDetails
<a name="API_ErrorDetails"></a>

Contains information about an error that occurred during a Resource Explorer setup operation.

## Contents
<a name="API_ErrorDetails_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** Code **   <a name="resourceexplorer-Type-ErrorDetails-Code"></a>
The error code that identifies the type of error that occurred.
Type: String
Required: No

 ** Message **   <a name="resourceexplorer-Type-ErrorDetails-Message"></a>
A human-readable description of the error that occurred.
Type: String
Required: No
