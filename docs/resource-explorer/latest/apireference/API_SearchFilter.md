# SearchFilter
<a name="API_SearchFilter"></a>

A search filter defines which resources can be part of a search query result set.

## Contents
<a name="API_SearchFilter_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** FilterString **   <a name="resourceexplorer-Type-SearchFilter-FilterString"></a>
The string that contains the search keywords, prefixes, and operators to control the results that can be returned by a [Search](API_Search.md) operation. For more details, see [Search query syntax](https://docs.aws.amazon.com/resource-explorer/latest/APIReference/about-query-syntax.html).
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Required: Yes
