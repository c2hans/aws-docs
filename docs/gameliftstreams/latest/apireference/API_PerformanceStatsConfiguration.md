# PerformanceStatsConfiguration
<a name="API_PerformanceStatsConfiguration"></a>

Configuration settings for sharing the stream session's performance stats with the client

## Contents
<a name="API_PerformanceStatsConfiguration_Contents"></a>

**Note**
In the following list, the required parameters are described first.

 ** SharedWithClient **   <a name="gameliftstreams-Type-PerformanceStatsConfiguration-SharedWithClient"></a>
Performance stats for the session are streamed to the client when set to `true`. Defaults to `false`.
Type: Boolean
Required: No
