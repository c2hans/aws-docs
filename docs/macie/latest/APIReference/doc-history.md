# Document history for the Amazon Macie API Reference
<a name="doc-history"></a>

The following table describes the important changes to the documentation since the last release of Amazon Macie. For notification about updates to this documentation, you can subscribe to an RSS feed.
+ **API version:** 2020-01-01 (latest)
+ **Latest documentation update:** July 22, 2024

| Change | Description | Date |
| --- |--- |--- |
| [Updated API descriptions](#doc-history) | Updated descriptions of [data source statistics](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3-statistics.html), [resource sensitivity profiles](https://docs.aws.amazon.com/macie/latest/APIReference/resource-profiles.html), and other information that Macie provides about the results of automated sensitive data discovery. Members of an organization now have read access to this information for their Amazon S3 data, if their Macie administrator [enables automated sensitive data discovery](https://docs.aws.amazon.com/macie/latest/APIReference/automated-discovery-configuration.html). | July 22, 2024 |
| [Added APIs](#doc-history) | Added support for [enabling or disabling automated sensitive data discovery for individual accounts](https://docs.aws.amazon.com/macie/latest/APIReference/automated-discovery-accounts.html) in an organization, and [enabling automated sensitive data discovery automatically for particular types of accounts](https://docs.aws.amazon.com/macie/latest/APIReference/automated-discovery-configuration.html) in an organization. Also added [metadata](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3.html) indicating whether individual Amazon Simple Storage Service (Amazon S3) buckets are included in the scope of the analyses. | June 14, 2024 |
| [Updated API descriptions](#doc-history) | Updated descriptions of [statistics](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3-statistics.html) and [metadata](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3.html) that Macie provides about encryption settings for Amazon Simple Storage Service (Amazon S3) buckets and objects. Statistics and metadata now include data for buckets and objects that use dual-layer server-side encryption with AWS KMS keys (DSSE-KMS). In addition, Macie can now analyze objects that use DSSE-KMS encryption. For information about DSSE-KMS, see [Using dual-layer server-side encryption with AWS KMS keys](https://docs.aws.amazon.com/AmazonS3/latest/userguide/UsingDSSEncryption.html) in the *Amazon Simple Storage Service User Guide*. | January 16, 2024 |
| [Added APIs](#doc-history) | Added support for configuring Macie to assume an AWS Identity and Access Management (IAM) role when retrieving [sample occurrences of sensitive data](https://docs.aws.amazon.com/macie/latest/APIReference/reveal-configuration.html) reported by findings. | November 16, 2023 |
| [Changed APIs](#doc-history) | The default `ManagedDataIdentifierSelector` setting for new [classification jobs](https://docs.aws.amazon.com/macie/latest/APIReference/jobs.html) is now `RECOMMENDED`. By default, new classification jobs now use the recommended set of managed data identifiers. For a list of the managed data identifiers included in the set, see [Managed data identifiers recommended for jobs](https://docs.aws.amazon.com/macie/latest/user/discovery-jobs-mdis-recommended.html) in the *Amazon Macie User Guide*. | September 18, 2023 |
| [Added APIs](#doc-history) | Added support for configuring new [classification jobs](https://docs.aws.amazon.com/macie/latest/APIReference/jobs.html) to automatically use the set of managed data identifiers that we recommend for jobs. | June 27, 2023 |
| [Updated API descriptions](#doc-history) | Updated descriptions of [statistics](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3-statistics.html) and [metadata](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3.html) that Macie provides about default encryption settings for Amazon Simple Storage Service (Amazon S3) buckets. Amazon S3 now automatically applies server-side encryption with Amazon S3 managed keys (SSE-S3) as the base level of encryption for objects that are added to new and existing buckets. For information about this change in Amazon S3, see [Setting default server-side encryption behavior for S3 buckets](https://docs.aws.amazon.com/AmazonS3/latest/userguide/bucket-encryption.html) in the *Amazon Simple Storage Service User Guide*. | February 27, 2023 |
| [Added APIs](#doc-history) | Added support for a new type of [policy finding](https://docs.aws.amazon.com/macie/latest/APIReference/findings-describe.html), `Policy:IAMUser/S3BucketSharedWithCloudFront`. Also updated descriptions of [statistics](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3-statistics.html) and [metadata](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3.html) that Macie provides about shared access to S3 buckets. The data now indicates whether a bucket is shared with an Amazon CloudFront origin access identity (OAI) or CloudFront origin access control (OAC). | February 23, 2023 |
| [Added APIs](#doc-history) | Added support for analyzing S3 objects that use the S3 Glacier Instant Retrieval (`Glacier_IR`) storage class. For sensitive data discovery and in data source [statistics](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3-statistics.html) and [metadata](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3.html), S3 objects that use this Amazon S3 storage class are now considered *classifiable objects*. | December 21, 2022 |
| [Added APIs](#doc-history) | Added support for configuring Macie to perform [automated sensitive data discovery](https://docs.aws.amazon.com/macie/latest/APIReference/automated-discovery-configuration.html) for Amazon S3 data, and accessing the results in data source statistics, resource sensitivity profiles, findings, and other information that Macie provides about Amazon S3 data. | November 28, 2022 |
| [Added APIs](#doc-history) | Added support for using [allow lists](https://docs.aws.amazon.com/macie/latest/APIReference/allow-lists.html) to define specific text and text patterns to ignore when inspecting data sources for sensitive data. | August 30, 2022 |
| [Added APIs](#doc-history) | Added support for configuring and using Macie to retrieve [sample occurrences of sensitive data](https://docs.aws.amazon.com/macie/latest/APIReference/findings-findingid-reveal.html) reported by findings. | July 26, 2022 |
| [Added APIs](#doc-history) | Added support for specifying the severity of findings that a [custom data identifier](https://docs.aws.amazon.com/macie/latest/APIReference/custom-data-identifiers.html) produces. | November 3, 2021 |
| [Added APIs](#doc-history) | Added S3 bucket [metadata](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3.html) that indicates whether a bucket's permissions settings or an error prevented Macie from retrieving and processing information about the bucket or the bucket's objects. Also updated references to AWS KMS keys and customer managed keys to reflect current terminology. | September 30, 2021 |
| [Added APIs](#doc-history) | Added support for specifying which managed data identifiers are used by a [classification job](https://docs.aws.amazon.com/macie/latest/APIReference/jobs.html) to detect sensitive data. Also added the [Managed Data Identifiers](https://docs.aws.amazon.com/macie/latest/APIReference/managed-data-identifiers-list.html) resource for retrieving a list of the managed data identifiers that are currently available. | September 16, 2021 |
| [Added APIs](#doc-history) | Added support for defining runtime criteria that determine which S3 buckets a [classification job](https://docs.aws.amazon.com/macie/latest/APIReference/jobs.html) analyzes. Also added the [Search Data Sources](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-search-resources.html) resource for querying data about the AWS resources that Macie monitors and analyzes for an account. | May 14, 2021 |
| [Added APIs](#doc-history) | Added support for [publishing sensitive data findings](https://docs.aws.amazon.com/macie/latest/APIReference/findings-publication-configuration.html) to AWS Security Hub CSPM and specifying which categories of findings to publish to Security Hub CSPM. | March 22, 2021 |
| [Added and deprecated APIs](#doc-history) | Replaced the term *master account* with the term *administrator account*. This includes adding APIs that use the new term and deprecating APIs that use the previous term. The new APIs provide the same functionality as the deprecated APIs. An *administrator account* is used to centrally manage multiple accounts.  | February 12, 2021 |
| [Added APIs](#doc-history) | Added support for using Amazon S3 object prefixes in property-based conditions that refine the scope of a [classification job](https://docs.aws.amazon.com/macie/latest/APIReference/jobs.html). | January 29, 2021 |
| [Added APIs](#doc-history) | Added Amazon S3 bucket [metadata](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3.html) that indicates whether any one-time or recurring classification jobs are configured to analyze data in a bucket. | November 20, 2020 |
| [Added APIs](#doc-history) | Added support for pausing and resuming classification jobs by using the [UpdateClassificationJob](https://docs.aws.amazon.com/macie/latest/APIReference/jobs-jobid.html#UpdateClassificationJob) operation. Also, [sensitive data findings](https://docs.aws.amazon.com/macie/latest/APIReference/findings-describe.html) now include location data for up to 15 occurrences of sensitive data in an affected Amazon S3 object. | October 15, 2020 |
| [Added APIs](#doc-history) | Added Amazon S3 bucket [metadata](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3.html) and [statistics](https://docs.aws.amazon.com/macie/latest/APIReference/datasources-s3-statistics.html) that indicate the size and count of objects that Macie can analyze as part of a classification job. | September 2, 2020 |
| [Added APIs](#doc-history) | Added criteria for sorting and filtering query results for [account quotas and usage statistics](https://docs.aws.amazon.com/macie/latest/APIReference/usage-statistics.html). | July 24, 2020 |
| [Removed APIs](#doc-history) | Removed support for the **ArchiveFindings** and **UnarchiveFindings** operations. To suppress findings, use the `action` parameter of the [CreateFindingsFilter](https://docs.aws.amazon.com/macie/latest/APIReference/findingsfilters.html#CreateFindingsFilter) and [UpdateFindingsFilter](https://docs.aws.amazon.com/macie/latest/APIReference/findingsfilters-id.html#UpdateFindingsFilter) operations. | June 11, 2020 |
| [General availability](#doc-history) | This release introduces version 2020-01-01 of the Amazon Macie API. | May 13, 2020 |
