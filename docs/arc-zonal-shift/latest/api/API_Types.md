# Data Types
<a name="API_Types"></a>

The ARC - Zonal Shift API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AutoshiftInResource](API_AutoshiftInResource.md)
+  [AutoshiftSummary](API_AutoshiftSummary.md)
+  [ControlCondition](API_ControlCondition.md)
+  [ManagedResourceSummary](API_ManagedResourceSummary.md)
+  [PracticeRunConfiguration](API_PracticeRunConfiguration.md)
+  [ZonalShiftInResource](API_ZonalShiftInResource.md)
+  [ZonalShiftSummary](API_ZonalShiftSummary.md)
