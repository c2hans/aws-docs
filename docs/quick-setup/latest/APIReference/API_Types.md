# Data Types
<a name="API_Types"></a>

The AWS Systems Manager QuickSetup API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [ConfigurationDefinition](API_ConfigurationDefinition.md)
+  [ConfigurationDefinitionInput](API_ConfigurationDefinitionInput.md)
+  [ConfigurationDefinitionSummary](API_ConfigurationDefinitionSummary.md)
+  [ConfigurationManagerSummary](API_ConfigurationManagerSummary.md)
+  [ConfigurationSummary](API_ConfigurationSummary.md)
+  [Filter](API_Filter.md)
+  [QuickSetupTypeOutput](API_QuickSetupTypeOutput.md)
+  [ServiceSettings](API_ServiceSettings.md)
+  [StatusSummary](API_StatusSummary.md)
+  [TagEntry](API_TagEntry.md)
