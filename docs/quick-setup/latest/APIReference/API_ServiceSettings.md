# ServiceSettings
<a name="API_ServiceSettings"></a>

Settings configured for Quick Setup.

## Contents
<a name="API_ServiceSettings_Contents"></a>

 ** ExplorerEnablingRoleArn **   <a name="quicksetup-Type-ServiceSettings-ExplorerEnablingRoleArn"></a>
The IAM role used to enable Explorer.
Type: String
Pattern: `arn:aws(-cn|-us-gov)?:iam::\d{12}:role/?[a-zA-Z_0-9+=,.@\-_/]+.*`
Required: No
