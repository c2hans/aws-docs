# IpamInternetRegistryAssociationCidr
<a name="API_IpamInternetRegistryAssociationCidr"></a>

Contains information about an IP address CIDR registered at an internet registry and associated with an IPAM.

## Contents
<a name="API_IpamInternetRegistryAssociationCidr_Contents"></a>

 ** cidr **
The IP address prefix in CIDR notation.
Type: String
Required: No

 ** lastObservedAt **
The time when the CIDR was last observed at the internet registry.
Type: Timestamp
Required: No
