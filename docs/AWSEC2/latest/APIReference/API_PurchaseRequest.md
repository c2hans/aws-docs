# PurchaseRequest
<a name="API_PurchaseRequest"></a>

Describes a request to purchase Scheduled Instances.

## Contents
<a name="API_PurchaseRequest_Contents"></a>

 ** InstanceCount **
The number of instances.
Type: Integer
Required: Yes

 ** PurchaseToken **
The purchase token.
Type: String
Required: Yes
