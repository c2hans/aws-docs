# ServiceTypeDetail
<a name="API_ServiceTypeDetail"></a>

Describes the type of service for a VPC endpoint.

## Contents
<a name="API_ServiceTypeDetail_Contents"></a>

 ** serviceType **
The type of service.
Type: String
Valid Values: `Interface | Gateway | GatewayLoadBalancer`
Required: No
