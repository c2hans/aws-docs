# DiskInfo
<a name="API_DiskInfo"></a>

Describes a disk.

## Contents
<a name="API_DiskInfo_Contents"></a>

 ** count **
The number of disks with this configuration.
Type: Integer
Required: No

 ** sizeInGB **
The size of the disk in GB.
Type: Long
Required: No

 ** type **
The type of disk.
Type: String
Valid Values: `hdd | ssd`
Required: No
