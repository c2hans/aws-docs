# HealthCheckPathResponseObject
<a name="API_HealthCheckPathResponseObject"></a>

Describes a health check path for an application status check.

## Contents
<a name="API_HealthCheckPathResponseObject_Contents"></a>

 ** DestinationSet.N **
The destinations for the health check path.
Type: Array of [HealthCheckPathDestinationResponseObject](API_HealthCheckPathDestinationResponseObject.md) objects
Required: No

 ** source **
The source for the health check path.
Type: [HealthCheckPathSourceResponseObject](API_HealthCheckPathSourceResponseObject.md) object
Required: No
