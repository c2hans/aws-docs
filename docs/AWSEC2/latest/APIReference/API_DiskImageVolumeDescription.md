# DiskImageVolumeDescription
<a name="API_DiskImageVolumeDescription"></a>

Describes a disk image volume.

## Contents
<a name="API_DiskImageVolumeDescription_Contents"></a>

 ** id **
The volume identifier.
Type: String
Required: No

 ** size **
The size of the volume, in GiB.
Type: Long
Required: No
