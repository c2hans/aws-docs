# CapacityReservationConfiguration
<a name="API_CapacityReservationConfiguration"></a>

Describes the configuration of a Capacity Reservation.

## Contents
<a name="API_CapacityReservationConfiguration_Contents"></a>

 ** instanceCount **
The number of instances in the Capacity Reservation.
Type: Integer
Required: No

 ** reservationState **
The current state of the Capacity Reservation.
Type: String
Required: No
