# PortRange
<a name="API_PortRange"></a>

Describes a range of ports.

## Contents
<a name="API_PortRange_Contents"></a>

 ** From ** (request), ** from ** (response)
The first port in the range.
Type: Integer
Required: No

 ** To ** (request), ** to ** (response)
The last port in the range.
Type: Integer
Required: No
