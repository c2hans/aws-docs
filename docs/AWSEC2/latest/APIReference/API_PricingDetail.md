# PricingDetail
<a name="API_PricingDetail"></a>

Describes a Reserved Instance offering.

## Contents
<a name="API_PricingDetail_Contents"></a>

 ** count **
The number of reservations available for the price.
Type: Integer
Required: No

 ** price **
The price per instance.
Type: Double
Required: No
