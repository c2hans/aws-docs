# DevicePostureResponseOptions
<a name="API_DevicePostureResponseOptions"></a>

Information about the device posture options for a Client VPN endpoint.

## Contents
<a name="API_DevicePostureResponseOptions_Contents"></a>

 ** TrustProviderSet.N **
The device trust providers configured for the Client VPN endpoint.
Type: Array of [ClientVpnTrustProvider](API_ClientVpnTrustProvider.md) objects
Required: No
