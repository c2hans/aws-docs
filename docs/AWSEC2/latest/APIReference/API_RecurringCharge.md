# RecurringCharge
<a name="API_RecurringCharge"></a>

Describes a recurring charge.

## Contents
<a name="API_RecurringCharge_Contents"></a>

 ** amount **
The amount of the recurring charge.
Type: Double
Required: No

 ** frequency **
The frequency of the recurring charge.
Type: String
Valid Values: `Hourly`
Required: No
