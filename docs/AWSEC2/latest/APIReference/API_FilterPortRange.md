# FilterPortRange
<a name="API_FilterPortRange"></a>

Describes a port range.

## Contents
<a name="API_FilterPortRange_Contents"></a>

 ** fromPort **
The first port in the range.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 65535.
Required: No

 ** toPort **
The last port in the range.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 65535.
Required: No
