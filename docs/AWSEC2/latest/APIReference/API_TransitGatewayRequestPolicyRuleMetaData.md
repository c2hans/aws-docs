# TransitGatewayRequestPolicyRuleMetaData
<a name="API_TransitGatewayRequestPolicyRuleMetaData"></a>

A metadata key-value pair for a transit gateway policy rule.

## Contents
<a name="API_TransitGatewayRequestPolicyRuleMetaData_Contents"></a>

 ** MetaDataKey **
The key of the metadata pair for the policy rule.
Type: String
Required: No

 ** MetaDataValue **
The value of the metadata pair for the policy rule.
Type: String
Required: No
