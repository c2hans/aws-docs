# TargetGroup
<a name="API_TargetGroup"></a>

Describes a load balancer target group.

## Contents
<a name="API_TargetGroup_Contents"></a>

 ** Arn ** (request), ** arn ** (response)
The Amazon Resource Name (ARN) of the target group.
Type: String
Required: No
