# HealthCheckPathRequestObject
<a name="API_HealthCheckPathRequestObject"></a>

Describes a health check path for an application status check request.

## Contents
<a name="API_HealthCheckPathRequestObject_Contents"></a>

 ** Destination.N **
The destinations for the health check path.
Type: Array of [HealthCheckPathDestinationRequestObject](API_HealthCheckPathDestinationRequestObject.md) objects
Required: No

 ** Source **
The source for the health check path.
Type: [HealthCheckPathSourceRequestObject](API_HealthCheckPathSourceRequestObject.md) object
Required: No
