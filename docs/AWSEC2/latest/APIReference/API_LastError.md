# LastError
<a name="API_LastError"></a>

The last error that occurred for a VPC endpoint.

## Contents
<a name="API_LastError_Contents"></a>

 ** code **
The error code for the VPC endpoint error.
Type: String
Required: No

 ** message **
The error message for the VPC endpoint error.
Type: String
Required: No
