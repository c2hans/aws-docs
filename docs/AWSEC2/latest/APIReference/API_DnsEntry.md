# DnsEntry
<a name="API_DnsEntry"></a>

Describes a DNS entry.

## Contents
<a name="API_DnsEntry_Contents"></a>

 ** dnsName **
The DNS name.
Type: String
Required: No

 ** hostedZoneId **
The ID of the private hosted zone.
Type: String
Required: No
