# MemoryInfo
<a name="API_MemoryInfo"></a>

Describes the memory for the instance type.

## Contents
<a name="API_MemoryInfo_Contents"></a>

 ** sizeInMiB **
The size of the memory, in MiB.
Type: Long
Required: No
