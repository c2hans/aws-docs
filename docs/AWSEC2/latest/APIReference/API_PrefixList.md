# PrefixList
<a name="API_PrefixList"></a>

Describes prefixes for AWS services.

## Contents
<a name="API_PrefixList_Contents"></a>

 ** CidrSet.N **
The IP address range of the AWS service.
Type: Array of strings
Required: No

 ** prefixListId **
The ID of the prefix.
Type: String
Required: No

 ** prefixListName **
The name of the prefix.
Type: String
Required: No
