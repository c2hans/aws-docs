# Ipv6CidrAssociation
<a name="API_Ipv6CidrAssociation"></a>

Describes an IPv6 CIDR block association.

## Contents
<a name="API_Ipv6CidrAssociation_Contents"></a>

 ** associatedResource **
The resource that's associated with the IPv6 CIDR block.
Type: String
Required: No

 ** ipv6Cidr **
The IPv6 CIDR block.
Type: String
Required: No
