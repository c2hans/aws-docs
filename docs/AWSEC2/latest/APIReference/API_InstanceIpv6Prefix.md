# InstanceIpv6Prefix
<a name="API_InstanceIpv6Prefix"></a>

Information about an IPv6 prefix.

## Contents
<a name="API_InstanceIpv6Prefix_Contents"></a>

 ** ipv6Prefix **
One or more IPv6 prefixes assigned to the network interface.
Type: String
Required: No
