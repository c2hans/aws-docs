# HealthCheckPathSourceResponseObject
<a name="API_HealthCheckPathSourceResponseObject"></a>

Describes the source for a health check path.

## Contents
<a name="API_HealthCheckPathSourceResponseObject_Contents"></a>

 ** securityGroupId **
The ID of the security group for the source.
Type: String
Required: No

 ** subnetId **
The ID of the subnet for the source.
Type: String
Required: No
