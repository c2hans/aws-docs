# ModificationTerms
<a name="API_ModificationTerms"></a>

Describes the terms of a Capacity Reservation modification quote.

## Contents
<a name="API_ModificationTerms_Contents"></a>

 ** reservationUpdate **
The changes that will be applied to the Capacity Reservation if you accept the modification terms.
Type: [ModificationReservationUpdate](API_ModificationReservationUpdate.md) object
Required: No
