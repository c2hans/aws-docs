# TransitGatewayConfigurationDescribeEndpointStructure
<a name="API_TransitGatewayConfigurationDescribeEndpointStructure"></a>

Describes the Transit Gateway configuration for a Client VPN endpoint.

## Contents
<a name="API_TransitGatewayConfigurationDescribeEndpointStructure_Contents"></a>

 ** AvailabilityZoneIdSet.N **
The Availability Zone IDs for the Transit Gateway association.
Type: Array of strings
Required: No

 ** AvailabilityZoneSet.N **
The Availability Zone names for the Transit Gateway association.
Type: Array of strings
Required: No

 ** transitGatewayAttachmentId **
The ID of the Transit Gateway attachment.
Type: String
Required: No

 ** transitGatewayId **
The ID of the Transit Gateway.
Type: String
Required: No
