# InstanceIpv4Prefix
<a name="API_InstanceIpv4Prefix"></a>

Information about an IPv4 prefix.

## Contents
<a name="API_InstanceIpv4Prefix_Contents"></a>

 ** ipv4Prefix **
One or more IPv4 prefixes assigned to the network interface.
Type: String
Required: No
