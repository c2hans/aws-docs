# PrivateDnsDetails
<a name="API_PrivateDnsDetails"></a>

Information about the Private DNS name for interface endpoints.

## Contents
<a name="API_PrivateDnsDetails_Contents"></a>

 ** privateDnsName **
The private DNS name assigned to the VPC endpoint service.
Type: String
Required: No
