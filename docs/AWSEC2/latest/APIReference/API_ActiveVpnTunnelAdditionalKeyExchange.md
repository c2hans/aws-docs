# ActiveVpnTunnelAdditionalKeyExchange

Describes an additional key exchange round negotiated for an active VPN tunnel.

## Contents
<a name="API_ActiveVpnTunnelAdditionalKeyExchange_Contents"></a>

 ** additionalKeyExchangeRound **
The additional key exchange round number.
Type: Integer
Required: No

 ** keyExchangeMethod **
The key exchange method number negotiated for this round.
Type: Integer
Required: No
