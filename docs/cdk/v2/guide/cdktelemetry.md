# AWS CDK telemetry
<a name="cdktelemetry"></a>

 AWS Cloud Development Kit (AWS CDK) applications are configured to collect and report on usage data to gain insight into how the AWS CDK is being used. To understand the data that is collected, how it’s used, and how to opt in or out of data reporting, see [Configure AWS CDK Library usage data reporting](usage-data.md).

 AWS CDK collects telemetry data on CLI usage to provide aggregate usage patterns and error frequencies that will help us identify widespread issues affecting the CDK CLI user base. In CDK CLI version 2.1100.0 and up, customers will be opted in to CDK CLI usage data collection and reporting by default. To learn what data is collected and how to opt out of CDK CLI telemetry, see [Configure AWS CDK CLI telemetry](cli-telemetry.md).
