# ConnectivityResourceConfigurationArn
<a name="API_ConnectivityResourceConfigurationArn"></a>

The Amazon Resource Name (ARN) of the Amazon VPC Lattice resource configuration for the resource endpoint.

## Contents
<a name="API_ConnectivityResourceConfigurationArn_Contents"></a>

 ** ResourceConfigurationArn **   <a name="eventbridge-Type-ConnectivityResourceConfigurationArn-ResourceConfigurationArn"></a>
The Amazon Resource Name (ARN) of the Amazon VPC Lattice resource configuration for the resource endpoint.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Pattern: `^(?:^arn:[a-z0-9\-]+:vpc-lattice:[a-zA-Z0-9\-]+:\d{12}:resourceconfiguration/rcfg-[0-9a-z]{17}$|^$)`
Required: Yes
