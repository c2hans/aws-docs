# ConnectionBasicAuthResponseParameters
<a name="API_ConnectionBasicAuthResponseParameters"></a>

The authorization parameters for the connection if Basic is specified as the authorization type.

## Contents
<a name="API_ConnectionBasicAuthResponseParameters_Contents"></a>

 ** Username **   <a name="eventbridge-Type-ConnectionBasicAuthResponseParameters-Username"></a>
The user name to use for Basic authorization.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Pattern: `^[ \t]*[^\x00-\x1F:\x7F]+([ \t]+[^\x00-\x1F:\x7F]+)*[ \t]*$`
Required: No
