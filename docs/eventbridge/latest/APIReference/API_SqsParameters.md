# SqsParameters
<a name="API_SqsParameters"></a>

The custom parameters for EventBridge to use for a target that is an Amazon SQS fair or FIFO queue.

## Contents
<a name="API_SqsParameters_Contents"></a>

 ** MessageGroupId **   <a name="eventbridge-Type-SqsParameters-MessageGroupId"></a>
The ID of the message group to use as the target.
Type: String
Length Constraints: Maximum length of 100.
Required: No
