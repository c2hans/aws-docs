# SdkConfigurationProperty
<a name="API_SdkConfigurationProperty"></a>

A configuration property of an SDK type.

## Contents
<a name="API_SdkConfigurationProperty_Contents"></a>

 ** defaultValue **   <a name="apigw-Type-SdkConfigurationProperty-defaultValue"></a>
The default value of an SdkType configuration property.
Type: String
Required: No

 ** description **   <a name="apigw-Type-SdkConfigurationProperty-description"></a>
The description of an SdkType configuration property.
Type: String
Required: No

 ** friendlyName **   <a name="apigw-Type-SdkConfigurationProperty-friendlyName"></a>
The user-friendly name of an SdkType configuration property.
Type: String
Required: No

 ** name **   <a name="apigw-Type-SdkConfigurationProperty-name"></a>
The name of a an SdkType configuration property.
Type: String
Required: No

 ** required **   <a name="apigw-Type-SdkConfigurationProperty-required"></a>
A boolean flag of an SdkType configuration property to indicate if the associated SDK configuration property is required (`true`) or not (`false`).
Type: Boolean
Required: No
