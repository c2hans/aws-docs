# EventVariableSummary
<a name="API_EventVariableSummary"></a>

 Information about the summary of an event variable that was evaluated for generating prediction.

## Contents
<a name="API_EventVariableSummary_Contents"></a>

 ** name **   <a name="FraudDetector-Type-EventVariableSummary-name"></a>
 The event variable name.
Type: String
Required: No

 ** source **   <a name="FraudDetector-Type-EventVariableSummary-source"></a>
 The event variable source.
Type: String
Required: No

 ** value **   <a name="FraudDetector-Type-EventVariableSummary-value"></a>
 The value of the event variable.
Type: String
Required: No
