# TFITrainingMetricsValue
<a name="API_TFITrainingMetricsValue"></a>

 The Transaction Fraud Insights (TFI) model training metric details.

## Contents
<a name="API_TFITrainingMetricsValue_Contents"></a>

 ** metricDataPoints **   <a name="FraudDetector-Type-TFITrainingMetricsValue-metricDataPoints"></a>
 The model's performance metrics data points.
Type: Array of [TFIMetricDataPoint](API_TFIMetricDataPoint.md) objects
Required: No

 ** modelPerformance **   <a name="FraudDetector-Type-TFITrainingMetricsValue-modelPerformance"></a>
 The model performance score.
Type: [TFIModelPerformance](API_TFIModelPerformance.md) object
Required: No
