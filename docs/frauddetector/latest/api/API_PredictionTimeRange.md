# PredictionTimeRange
<a name="API_PredictionTimeRange"></a>

 The time period for when the predictions were generated.

## Contents
<a name="API_PredictionTimeRange_Contents"></a>

 ** endTime **   <a name="FraudDetector-Type-PredictionTimeRange-endTime"></a>
 The end time of the time period for when the predictions were generated.
Type: String
Length Constraints: Minimum length of 11. Maximum length of 30.
Required: Yes

 ** startTime **   <a name="FraudDetector-Type-PredictionTimeRange-startTime"></a>
 The start time of the time period for when the predictions were generated.
Type: String
Length Constraints: Minimum length of 11. Maximum length of 30.
Required: Yes
