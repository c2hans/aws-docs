# Amazon DCV

Amazon DCV is a remote visualization technology that you can use to connect securely to graphic-intensive 3D applications hosted on remote servers. With Amazon DCV, you can bring high-performance processing capabilities to remote users through secure client sessions.

## Amazon DCV

- [Administrator Guide](/dcv/latest/adminguide/what-is-dcv.html): Provides a conceptual overview of Amazon DCV and includes instructions for installing and configuring the server and managing sessions.
- [User Guide](/dcv/latest/userguide/what-is.html): Provides a conceptual overview of Amazon DCV and includes instructions for installing and using the client applications.
- [Access Console Guide](/dcv/latest/access-console/what-is-sm.html): Describes how to get started with the Amazon DCV Access Console and provides instructions on how to connect to sessions, manage users, and customize branding.
- [Web Client SDK Developer Guide](/dcv/latest/websdkguide/what-is.html): Describes how to get started with the Amazon DCV Web Client SDK and provides an SDK reference and code samples.
- [Extension SDK Developer Guide](/dcv/latest/extsdkguide/what-is.html): Describes how to get started with the Amazon DCV Extension SDK and provides an SDK reference.

## Amazon DCV Session Manager

- [Administrator Guide](/dcv/latest/sm-admin/what-is-sm.html): Provides a conceptual overview of Amazon DCV Session Manager and includes instructions for installing and configuring the Session Manager Broker and Agent.
- [Developer Guide](/dcv/latest/sm-dev/what-is-sm.html): Provides a conceptual overview of Amazon DCV Session Manager. It explains how to get started with the Session Manager APIs and includes an API reference.
- [CLI Guide](/dcv/latest/sm-cli/): Provides a conceptual overview of Amazon DCV Session Manager CLI and instructions for installing, configuring, and using the command line interface.

## Amazon DCV Connection Gateway

- [Administrator Guide](/dcv/latest/gw-admin/what-is-gw.html): Provides information about how to install, manage, and work with Amazon DCV Connection Gateway.
