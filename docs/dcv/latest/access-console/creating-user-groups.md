# Creating user groups
<a name="creating-user-groups"></a>

You can create a user group directly from the Access Console, by selecting users and assigning templates.

**To create a user group**

1. Go to the **User groups** page.

1. Select the **Create user group** button.

1. In **Group ID**, enter a unique identifier for your group. After you create the group, you cannot edit the ID.

1. In **Name**, enter a user friendly name for your group.

1. In **Add users**, select the users you wish to add to the group.

1. In **Template**, select the templates you wish to assign to the group.

1. Select the **Submit** button.
