# KubernetesMetadata
<a name="API_KubernetesMetadata"></a>

Meta data about Kubernetes resources.

## Contents
<a name="API_KubernetesMetadata_Contents"></a>

 ** localPodName **   <a name="networkflowmonitor-Type-KubernetesMetadata-localPodName"></a>
The name of the pod for a local resource.
Type: String
Required: No

 ** localPodNamespace **   <a name="networkflowmonitor-Type-KubernetesMetadata-localPodNamespace"></a>
The namespace of the pod for a local resource.
Type: String
Required: No

 ** localServiceName **   <a name="networkflowmonitor-Type-KubernetesMetadata-localServiceName"></a>
The service name for a local resource.
Type: String
Required: No

 ** remotePodName **   <a name="networkflowmonitor-Type-KubernetesMetadata-remotePodName"></a>
The name of the pod for a remote resource.
Type: String
Required: No

 ** remotePodNamespace **   <a name="networkflowmonitor-Type-KubernetesMetadata-remotePodNamespace"></a>
The namespace of the pod for a remote resource.
Type: String
Required: No

 ** remoteServiceName **   <a name="networkflowmonitor-Type-KubernetesMetadata-remoteServiceName"></a>
The service name for a remote resource.
Type: String
Required: No
