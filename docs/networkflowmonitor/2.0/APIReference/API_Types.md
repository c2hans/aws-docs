# Data Types
<a name="API_Types"></a>

The Network Flow Monitor API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [KubernetesMetadata](API_KubernetesMetadata.md)
+  [MonitorLocalResource](API_MonitorLocalResource.md)
+  [MonitorRemoteResource](API_MonitorRemoteResource.md)
+  [MonitorSummary](API_MonitorSummary.md)
+  [MonitorTopContributorsRow](API_MonitorTopContributorsRow.md)
+  [ScopeSummary](API_ScopeSummary.md)
+  [TargetId](API_TargetId.md)
+  [TargetIdentifier](API_TargetIdentifier.md)
+  [TargetResource](API_TargetResource.md)
+  [TraversedComponent](API_TraversedComponent.md)
+  [WorkloadInsightsTopContributorsDataPoint](API_WorkloadInsightsTopContributorsDataPoint.md)
+  [WorkloadInsightsTopContributorsRow](API_WorkloadInsightsTopContributorsRow.md)
