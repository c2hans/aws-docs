# OntapError

An error returned by ONTAP for an operation on an Amazon FSx for NetApp ONTAP resource.

## Contents
<a name="API_OntapError_Contents"></a>

 ** Code **   <a name="FSx-Type-OntapError-Code"></a>
The error code returned by ONTAP.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: No

 ** Message **   <a name="FSx-Type-OntapError-Message"></a>
The error message returned by ONTAP.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: No
