# ClusterPeerAuthenticationStatus

Describes the authentication status of an Amazon FSx for NetApp ONTAP cluster peer relationship.

## Contents
<a name="API_ClusterPeerAuthenticationStatus_Contents"></a>

 ** InUse **   <a name="FSx-Type-ClusterPeerAuthenticationStatus-InUse"></a>
The status of the authentication that the cluster peer relationship is using.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No

 ** State **   <a name="FSx-Type-ClusterPeerAuthenticationStatus-State"></a>
The authentication state of the cluster peer relationship.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No
