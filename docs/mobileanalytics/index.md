# Amazon Mobile Analytics Documentation

We discontinued Amazon Mobile Analytics on April 30, 2018. Amazon Pinpoint now provides the analytics features that Amazon Mobile Analytics previously offered.

[Migrate to Amazon Pinpoint](/mobileanalytics/latest/ug/migrate.html)

## Amazon Mobile Analytics

Amazon Mobile Analytics is a service for collecting, visualizing, and understanding app usage data at scale. The service is built to scale with your business, allowing you to collect and process billions of events per day from many millions of users. Simply add the AWS Mobile SDK in your iOS and Android/Fire OS apps, or use the Amazon Mobile Analytics REST API, and start accessing your Amazon Mobile Analytics Reports to learn about how your app is being used.

- [User Guide](/mobileanalytics/latest/ug/): Provides information to help you use Amazon Mobile Analytics on the AWS Management Console.
- [AWS Mobile SDK for Android Developer Guide](/aws-mobile/latest/developerguide/getting-started.html): Walks through the steps for setting up the Android SDK and integrating Amazon Mobile Analytics and other services.
- [AWS Mobile SDK for iOS Developer Guide](/aws-mobile/latest/developerguide/getting-started.html): Walks through the steps for setting up the iOS SDK and integrating Amazon Mobile Analytics and other services.
