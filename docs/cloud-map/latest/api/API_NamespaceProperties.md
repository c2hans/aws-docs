# NamespaceProperties
<a name="API_NamespaceProperties"></a>

A complex type that contains information that's specific to the namespace type.

## Contents
<a name="API_NamespaceProperties_Contents"></a>

 ** DnsProperties **   <a name="cloudmap-Type-NamespaceProperties-DnsProperties"></a>
A complex type that contains the ID for the Route 53 hosted zone that AWS Cloud Map creates when you create a namespace.
Type: [DnsProperties](API_DnsProperties.md) object
Required: No

 ** HttpProperties **   <a name="cloudmap-Type-NamespaceProperties-HttpProperties"></a>
A complex type that contains the name of an HTTP namespace.
Type: [HttpProperties](API_HttpProperties.md) object
Required: No
