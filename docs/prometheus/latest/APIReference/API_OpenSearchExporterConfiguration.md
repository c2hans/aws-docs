# OpenSearchExporterConfiguration
<a name="API_OpenSearchExporterConfiguration"></a>

The configuration for exporting metrics to an Amazon OpenSearch Service domain.

## Contents
<a name="API_OpenSearchExporterConfiguration_Contents"></a>

 ** domainArn **   <a name="prometheus-Type-OpenSearchExporterConfiguration-domainArn"></a>
The Amazon Resource Name (ARN) of the Amazon OpenSearch Service domain.
Type: String
Pattern: `arn:aws[-a-z]*:es:[-a-z0-9]+:[0-9]{12}:domain\/.+`
Required: Yes
