# WorkspaceStatus
<a name="API_WorkspaceStatus"></a>

The status of the workspace.

## Contents
<a name="API_WorkspaceStatus_Contents"></a>

 ** statusCode **   <a name="prometheus-Type-WorkspaceStatus-statusCode"></a>
The current status of the workspace.
Type: String
Valid Values: `CREATING | ACTIVE | UPDATING | DELETING | CREATION_FAILED`
Required: Yes
