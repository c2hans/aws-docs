# EventPayload
<a name="API_EventPayload"></a>

Information about the payload of an event recording Amazon CodeCatalyst activity.

## Contents
<a name="API_EventPayload_Contents"></a>

 ** contentType **   <a name="codecatalyst-Type-EventPayload-contentType"></a>
The type of content in the event payload.
Type: String
Required: No

 ** data **   <a name="codecatalyst-Type-EventPayload-data"></a>
The data included in the event payload.
Type: String
Required: No
