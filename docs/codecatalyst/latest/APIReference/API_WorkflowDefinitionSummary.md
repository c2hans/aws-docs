# WorkflowDefinitionSummary
<a name="API_WorkflowDefinitionSummary"></a>

Information about a workflow definition.

## Contents
<a name="API_WorkflowDefinitionSummary_Contents"></a>

 ** path **   <a name="codecatalyst-Type-WorkflowDefinitionSummary-path"></a>
The path to the workflow definition file stored in the source repository for the project, including the file name.
Type: String
Required: Yes
