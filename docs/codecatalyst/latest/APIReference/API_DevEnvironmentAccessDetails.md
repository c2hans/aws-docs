# DevEnvironmentAccessDetails
<a name="API_DevEnvironmentAccessDetails"></a>

Information about connection details for a Dev Environment.

## Contents
<a name="API_DevEnvironmentAccessDetails_Contents"></a>

 ** streamUrl **   <a name="codecatalyst-Type-DevEnvironmentAccessDetails-streamUrl"></a>
The URL used to send commands to and from the Dev Environment.
Type: String
Required: Yes

 ** tokenValue **   <a name="codecatalyst-Type-DevEnvironmentAccessDetails-tokenValue"></a>
An encrypted token value that contains session and caller information used to authenticate the connection.
Type: String
Required: Yes
