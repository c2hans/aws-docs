# ProjectInformation
<a name="API_ProjectInformation"></a>

Information about a project in a space.

## Contents
<a name="API_ProjectInformation_Contents"></a>

 ** name **   <a name="codecatalyst-Type-ProjectInformation-name"></a>
The name of the project in the space.
Type: String
Required: No

 ** projectId **   <a name="codecatalyst-Type-ProjectInformation-projectId"></a>
The system-generated unique ID of the project.
Type: String
Required: No
