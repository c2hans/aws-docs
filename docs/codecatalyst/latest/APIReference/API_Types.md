# Data Types
<a name="API_Types"></a>

The Amazon CodeCatalyst API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AccessTokenSummary](API_AccessTokenSummary.md)
+  [DevEnvironmentAccessDetails](API_DevEnvironmentAccessDetails.md)
+  [DevEnvironmentRepositorySummary](API_DevEnvironmentRepositorySummary.md)
+  [DevEnvironmentSessionConfiguration](API_DevEnvironmentSessionConfiguration.md)
+  [DevEnvironmentSessionSummary](API_DevEnvironmentSessionSummary.md)
+  [DevEnvironmentSummary](API_DevEnvironmentSummary.md)
+  [EmailAddress](API_EmailAddress.md)
+  [EventLogEntry](API_EventLogEntry.md)
+  [EventPayload](API_EventPayload.md)

+  [Filter](API_Filter.md)
+  [Ide](API_Ide.md)
+  [IdeConfiguration](API_IdeConfiguration.md)
+  [ListSourceRepositoriesItem](API_ListSourceRepositoriesItem.md)

+  [PersistentStorage](API_PersistentStorage.md)

+  [ProjectInformation](API_ProjectInformation.md)
