# EmailAddress
<a name="API_EmailAddress"></a>

Information about an email address.

## Contents
<a name="API_EmailAddress_Contents"></a>

 ** email **   <a name="codecatalyst-Type-EmailAddress-email"></a>
The email address.
Type: String
Required: No

 ** verified **   <a name="codecatalyst-Type-EmailAddress-verified"></a>
Whether the email address has been verified.
Type: Boolean
Required: No
