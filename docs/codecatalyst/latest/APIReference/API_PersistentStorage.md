# PersistentStorage
<a name="API_PersistentStorage"></a>

Information about the persistent storage for a Dev Environment.

## Contents
<a name="API_PersistentStorage_Contents"></a>

 ** sizeInGiB **   <a name="codecatalyst-Type-PersistentStorage-sizeInGiB"></a>
The size of the persistent storage in gigabytes (specifically GiB).
Valid values for storage are based on memory sizes in 16GB increments. Valid values are 16, 32, and 64.
Type: Integer
Valid Range: Minimum value of 0. Maximum value of 64.
Required: Yes
