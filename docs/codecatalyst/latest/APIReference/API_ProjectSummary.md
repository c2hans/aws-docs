# ProjectSummary
<a name="API_ProjectSummary"></a>

Information about a project.

## Contents
<a name="API_ProjectSummary_Contents"></a>

 ** name **   <a name="codecatalyst-Type-ProjectSummary-name"></a>
The name of the project in the space.
Type: String
Required: Yes

 ** description **   <a name="codecatalyst-Type-ProjectSummary-description"></a>
The description of the project.
Type: String
Required: No

 ** displayName **   <a name="codecatalyst-Type-ProjectSummary-displayName"></a>
The friendly name displayed to users of the project in Amazon CodeCatalyst.
Type: String
Required: No
