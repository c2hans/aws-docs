# WorkflowDefinition
<a name="API_WorkflowDefinition"></a>

Information about a workflow definition file.

## Contents
<a name="API_WorkflowDefinition_Contents"></a>

 ** path **   <a name="codecatalyst-Type-WorkflowDefinition-path"></a>
The path to the workflow definition file stored in the source repository for the project, including the file name.
Type: String
Required: Yes
