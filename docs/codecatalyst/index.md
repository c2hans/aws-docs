# Amazon CodeCatalyst Documentation

Amazon CodeCatalyst is a cloud-based collaboration space for software development teams. CodeCatalyst provides one place where you can plan work, collaborate on code, and build, test, and deploy applications with continuous integration/continuous delivery (CI/CD) tools.

- [User Guide](/codecatalyst/latest/userguide): Learn how to use Amazon CodeCatalyst to track work, develop code, and build, test, and deploy your applications.
- [API Reference](/codecatalyst/latest/APIReference): Describes API operations for Amazon CodeCatalyst in detail. Also provides details of request and response syntax and errors for the supported web services protocols.
- [Administrator Guide](/codecatalyst/latest/adminguide): Learn how to set up an Amazon CodeCatalyst space where users can collaborate on projects. Find out how to view your billing information and upgrade your subscription.
- **Blueprints Resources**: Learn how to use blueprints to create new projects or apply them to existing projects. Also learn how to develop custom blueprints for your spaces. The open-source GitHub repository provides access to the blueprints SDK and sample blueprints.

[Documentation](/codecatalyst/latest/userguide/blueprints)
[GitHub repository](https://github.com/aws/codecatalyst-blueprints)

- [Action Developer Guide](/codecatalyst/latest/adk): Learn how to create custom actions for your workflows using the Amazon CodeCatalyst Action Developer Guide.
- [Set up Support for Amazon CodeCatalyst](/codecatalyst/latest/userguide/support): Learn how administrators can set up the support plan and roles required to create and manage support cases for their CodeCatalyst space. Once configured, space and project members can create support cases through Support for Amazon CodeCatalyst.
- **Additional Resources**: Learn more about how to use Amazon CodeCatalyst, common questions, and how to get help from the community when using CodeCatalyst.
