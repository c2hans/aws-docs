# Amazon Q Documentation

Amazon Q Business is a generative artificial intelligence (generative AI)-powered assistant that you can tailor to your business needs. Amazon Q Developer is an AWS generative AI assistant that helps you understand, build, extend, and operate applications and workloads on AWS.

## Amazon Q Business

- [Amazon Q Business User Guide](/amazonq/latest/business-use-dg/what-is.html): Provides a conceptual overview of Amazon Q Business and detailed instructions for using its various features.
- [Amazon Q Business API Reference](/amazonq/latest/api-reference/Welcome.html): Describes the API operations for Amazon Q Business. This includes the request parameters and response elements for each API operation, and common errors.

## Amazon Q Developer

- [Amazon Q Developer User Guide](/amazonq/latest/qdeveloper-ug/what-is.html): Provides a conceptual overview of Amazon Q Developer and detailed instructions for using its various features.
- [Amazon Q Detector Library](https://docs.aws.amazon.com/amazonq/detector-library/index.html): Lists all detectors that Amazon Q Developer uses to review code. Provides detailed information about the detectors, their impact on applications, and ways to mitigate risk.
- [Amazon Q Developer in chat applications Administrator Guide](/chatbot/latest/adminguide/what-is.html): Describes how to set up, configure, and use Amazon Q Developer in chat applications.
