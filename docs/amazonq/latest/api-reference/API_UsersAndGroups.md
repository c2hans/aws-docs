# UsersAndGroups
<a name="API_UsersAndGroups"></a>

Provides information about users and group names associated with a topic control rule.

## Contents
<a name="API_UsersAndGroups_Contents"></a>

 ** userGroups **   <a name="qbusiness-Type-UsersAndGroups-userGroups"></a>
The user group names associated with a topic control rule.
Type: Array of strings
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: No

 ** userIds **   <a name="qbusiness-Type-UsersAndGroups-userIds"></a>
The user ids associated with a topic control rule.
Type: Array of strings
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: No
