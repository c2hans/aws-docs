## Contents

 ** documentId **   <a name="qbusiness-Type-DeleteDocument-documentId"></a>
The identifier of the deleted document.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1825.
Pattern: `\P{C}*`
Required: Yes
