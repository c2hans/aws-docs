# TextInputEvent
<a name="API_TextInputEvent"></a>

An input event for a end user message in an Amazon Q Business web experience.

## Contents
<a name="API_TextInputEvent_Contents"></a>

 ** userMessage **   <a name="qbusiness-Type-TextInputEvent-userMessage"></a>
A user message in a text message input event.
Type: String
Required: Yes
