# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

The input failed to meet the constraints specified by Amazon Q Business in a specified field.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="qbusiness-Type-ValidationExceptionField-message"></a>
A message about the validation exception.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: Yes

 ** name **   <a name="qbusiness-Type-ValidationExceptionField-name"></a>
The field name where the invalid entry was detected.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Required: Yes
