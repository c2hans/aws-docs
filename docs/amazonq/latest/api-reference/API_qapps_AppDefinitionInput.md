# AppDefinitionInput
<a name="API_qapps_AppDefinitionInput"></a>

The input for defining an Q App.

## Contents
<a name="API_qapps_AppDefinitionInput_Contents"></a>

 ** cards **   <a name="qbusiness-Type-qapps_AppDefinitionInput-cards"></a>
The cards that make up the Q App definition.
Type: Array of [CardInput](API_qapps_CardInput.md) objects
Array Members: Minimum number of 0 items. Maximum number of 20 items.
Required: Yes

 ** initialPrompt **   <a name="qbusiness-Type-qapps_AppDefinitionInput-initialPrompt"></a>
The initial prompt displayed when the Q App is started.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 10000.
Required: No
