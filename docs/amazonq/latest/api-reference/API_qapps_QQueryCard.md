# QQueryCard
<a name="API_qapps_QQueryCard"></a>

A card in a Amazon Q App that generates a response based on the Amazon Q Business service.

## Contents
<a name="API_qapps_QQueryCard_Contents"></a>

 ** dependencies **   <a name="qbusiness-Type-qapps_QQueryCard-dependencies"></a>
Any dependencies or requirements for the query card.
Type: Array of strings
Required: Yes

 ** id **   <a name="qbusiness-Type-qapps_QQueryCard-id"></a>
The unique identifier of the query card.
Type: String
Pattern: `[\da-f]{8}-[\da-f]{4}-[45][\da-f]{3}-[89ABab][\da-f]{3}-[\da-f]{12}`
Required: Yes

 ** outputSource **   <a name="qbusiness-Type-qapps_QQueryCard-outputSource"></a>
The source or type of output generated by the query card.
Type: String
Valid Values: `approved-sources | llm`
Required: Yes

 ** prompt **   <a name="qbusiness-Type-qapps_QQueryCard-prompt"></a>
The prompt or instructions displayed for the query card.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 50000.
Required: Yes

 ** title **   <a name="qbusiness-Type-qapps_QQueryCard-title"></a>
The title or label of the query card.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 100.
Pattern: `[^{}\\"<>]+`
Required: Yes

 ** type **   <a name="qbusiness-Type-qapps_QQueryCard-type"></a>
The type of the card.
Type: String
Valid Values: `text-input | q-query | file-upload | q-plugin | form-input`
Required: Yes

 ** attributeFilter **   <a name="qbusiness-Type-qapps_QQueryCard-attributeFilter"></a>
The Amazon Q Business filters applied in this query card when resolving data sources
Type: [AttributeFilter](API_qapps_AttributeFilter.md) object
Required: No

 ** memoryReferences **   <a name="qbusiness-Type-qapps_QQueryCard-memoryReferences"></a>
Any dependencies for the query card, where the dependencies are references to the collected responses.
Type: Array of strings
Required: No
