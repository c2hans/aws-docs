# ScoreAttributes
<a name="API_ScoreAttributes"></a>

Provides information about the relevance score of content.

## Contents
<a name="API_ScoreAttributes_Contents"></a>

 ** scoreConfidence **   <a name="qbusiness-Type-ScoreAttributes-scoreConfidence"></a>
The confidence level of the relevance score.
Type: String
Valid Values: `VERY_HIGH | HIGH | MEDIUM | LOW | NOT_AVAILABLE`
Required: No
