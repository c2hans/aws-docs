# CustomerProfilesDestinationProperties
<a name="API_CustomerProfilesDestinationProperties"></a>

 The properties that are applied when Connect Customer Customer Profiles is used as a destination.

## Contents
<a name="API_CustomerProfilesDestinationProperties_Contents"></a>

 ** domainName **   <a name="appflow-Type-CustomerProfilesDestinationProperties-domainName"></a>
 The unique name of the Connect Customer Customer Profiles domain.
Type: String
Length Constraints: Maximum length of 64.
Pattern: `\S+`
Required: Yes

 ** objectTypeName **   <a name="appflow-Type-CustomerProfilesDestinationProperties-objectTypeName"></a>
 The object specified in the Connect Customer Customer Profiles flow destination.
Type: String
Length Constraints: Maximum length of 255.
Pattern: `\S+`
Required: No
