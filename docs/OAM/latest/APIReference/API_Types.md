# Data Types
<a name="API_Types"></a>

The CloudWatch Observability Access Manager API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [LinkConfiguration](API_LinkConfiguration.md)
+  [ListAttachedLinksItem](API_ListAttachedLinksItem.md)
+  [ListLinksItem](API_ListLinksItem.md)
+  [ListSinksItem](API_ListSinksItem.md)
+  [LogGroupConfiguration](API_LogGroupConfiguration.md)
+  [MetricConfiguration](API_MetricConfiguration.md)
