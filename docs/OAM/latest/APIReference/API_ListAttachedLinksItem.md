# ListAttachedLinksItem
<a name="API_ListAttachedLinksItem"></a>

A structure that contains information about one link attached to this monitoring account sink.

## Contents
<a name="API_ListAttachedLinksItem_Contents"></a>

 ** Label **   <a name="OAM-Type-ListAttachedLinksItem-Label"></a>
The label that was assigned to this link at creation, with the variables resolved to their actual values.
Type: String
Required: No

 ** LinkArn **   <a name="OAM-Type-ListAttachedLinksItem-LinkArn"></a>
The ARN of the link.
Type: String
Required: No

 ** ResourceTypes **   <a name="OAM-Type-ListAttachedLinksItem-ResourceTypes"></a>
The resource types supported by this link.
Type: Array of strings
Required: No
