# ListSinksItem
<a name="API_ListSinksItem"></a>

A structure that contains information about one of this monitoring account's sinks.

## Contents
<a name="API_ListSinksItem_Contents"></a>

 ** Arn **   <a name="OAM-Type-ListSinksItem-Arn"></a>
The ARN of the sink.
Type: String
Required: No

 ** Id **   <a name="OAM-Type-ListSinksItem-Id"></a>
The random ID string that AWS generated as part of the sink ARN.
Type: String
Required: No

 ** Name **   <a name="OAM-Type-ListSinksItem-Name"></a>
The name of the sink.
Type: String
Required: No
