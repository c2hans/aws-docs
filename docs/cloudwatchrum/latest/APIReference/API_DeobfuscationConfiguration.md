# DeobfuscationConfiguration
<a name="API_DeobfuscationConfiguration"></a>

 A structure that contains the configuration for how an app monitor can deobfuscate stack traces.

## Contents
<a name="API_DeobfuscationConfiguration_Contents"></a>

 ** JavaScriptSourceMaps **   <a name="cloudwatchrum-Type-DeobfuscationConfiguration-JavaScriptSourceMaps"></a>
 A structure that contains the configuration for how an app monitor can unminify JavaScript error stack traces using source maps.
Type: [JavaScriptSourceMaps](API_JavaScriptSourceMaps.md) object
Required: No
