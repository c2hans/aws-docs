# Data Types
<a name="API_Types"></a>

The CloudWatch RUM API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AppMonitor](API_AppMonitor.md)
+  [AppMonitorConfiguration](API_AppMonitorConfiguration.md)
+  [AppMonitorDetails](API_AppMonitorDetails.md)
+  [AppMonitorSummary](API_AppMonitorSummary.md)
+  [BatchCreateRumMetricDefinitionsError](API_BatchCreateRumMetricDefinitionsError.md)
+  [BatchDeleteRumMetricDefinitionsError](API_BatchDeleteRumMetricDefinitionsError.md)
+  [CustomEvents](API_CustomEvents.md)
+  [CwLog](API_CwLog.md)
+  [DataStorage](API_DataStorage.md)
+  [DeobfuscationConfiguration](API_DeobfuscationConfiguration.md)
+  [JavaScriptSourceMaps](API_JavaScriptSourceMaps.md)
+  [MetricDefinition](API_MetricDefinition.md)
+  [MetricDefinitionRequest](API_MetricDefinitionRequest.md)
+  [MetricDestinationSummary](API_MetricDestinationSummary.md)
+  [QueryFilter](API_QueryFilter.md)
+  [RumEvent](API_RumEvent.md)
+  [TimeRange](API_TimeRange.md)
+  [UserDetails](API_UserDetails.md)
