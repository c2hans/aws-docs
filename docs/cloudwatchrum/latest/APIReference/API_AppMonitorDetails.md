# AppMonitorDetails
<a name="API_AppMonitorDetails"></a>

A structure that contains information about the RUM app monitor.

## Contents
<a name="API_AppMonitorDetails_Contents"></a>

 ** id **   <a name="cloudwatchrum-Type-AppMonitorDetails-id"></a>
The unique ID of the app monitor.
Type: String
Required: No

 ** name **   <a name="cloudwatchrum-Type-AppMonitorDetails-name"></a>
The name of the app monitor.
Type: String
Required: No

 ** version **   <a name="cloudwatchrum-Type-AppMonitorDetails-version"></a>
The version of the app monitor.
Type: String
Required: No
