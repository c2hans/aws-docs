# Video tutorials
<a name="video-references"></a>

## Videos
<a name="videos"></a>

The following list includes video tutorials for AWS IoT Greengrass V2.
+ [AWS IoT Greengrass nucleus lite tutorial: Getting started](https://www.youtube.com/watch?v=5g5nSFciYk0)

  *April 10, 2025* – In this tutorial, you will learn about Greengrass nucleus lite and when to select it for your AWS IoT devices. You will learn how to install nucleus lite and deploy your components to it.
+ [AWS IoT Greengrass V2 tutorial: Getting started](https://www.youtube.com/watch?v=DcppAQ9ENvA)

  *December 16, 2021* – Get started with AWS IoT Greengrass V2. In this tutorial, you will learn how to install Greengrass and complete your first deployment.
+ [AWS IoT Greengrass V2 component development with local debug console](https://www.youtube.com/watch?v=adx3zUGRoWw)

  *August 21, 2023* – Learn how to use the Greengrass V2 local debug console to develop and debug your components quickly.
+ [Connect MQTT client devices to AWS IoT Greengrass V2](https://www.youtube.com/watch?v=tN0DQlQy2kM)

  *August 2, 2023* – In this tutorial, you will learn about how to configure a core device to interact with local AWS IoT devices that connect to the core device over MQTT.
+ [AWS IoT Greengrass V2 tutorial: Using MQTT applications](https://www.youtube.com/watch?v=hAZ-nlAaSvw)

  *December 16, 2021* – Create, test, and deploy an AWS IoT Greengrass V2 native component to publish and subscribe to MQTT through AWS IoT Core.
