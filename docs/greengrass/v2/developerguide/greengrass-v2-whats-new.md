# What's new in AWS IoT Greengrass Version 2
<a name="greengrass-v2-whats-new"></a>

AWS IoT Greengrass Version 2 is a major version of AWS IoT Greengrass that introduces the following features:
+ **AWS IoT Greengrass nucleus lite** – AWS IoT Greengrass nucleus versions 2.14.0 and later offers AWS IoT Greengrass nucleus lite. Greengrass nucleus lite is a lightweight, open-source runtime that lets you run Greengrass on resource-constrained devices. This can be useful for low-cost, single-board computers with high-volume applications, such as smart home hubs, smart energy meters, smart vehicles, edge AI, and robotics. For more information, see [Greengrass nucleus lite](greengrass-nucleus-lite-component.md).
+ **Publisher-supported components** – AWS IoT Greengrass now offers Publisher-supported components. These components are developed, offered, and serviced by third-party vendors. For more information, see [Publisher-supported components](publisher-supported-components.md).
+ **Operate a Greengrass device in VPC** – Operating a Greengrass core device in VPC is now available. This enables you to perform deployments in VPC without public internet access. For more information, see [Operate an AWS IoT Greengrass core device in VPC](vpc-interface-endpoints.md#vpc-operate-device-vpce).
+ **Greengrass Testing Framework (GTF)** – GTF for AWS IoT Greengrass Version 2 is now available. GTF is a collection of building blocks to support end-to-end automation. It enables AWS IoT Greengrass Version 2 internal customers to use the same testing framework that the service team uses for qualifying software changes, automated acceptance, and quality assurance purposes. For more information, see [Greengrass Testing Framework on Github](https://github.com/aws-greengrass/aws-greengrass-testing).
+ **PSA-certified** – AWS IoT Greengrass nucleus versions 2.7.0 and later are now Platform Security Architecture (PSA) certified. For more information, see [AWS IoT Greengrass is PSA-certified](https://www.psacertified.org/products/aws-iot-greengrass/).
