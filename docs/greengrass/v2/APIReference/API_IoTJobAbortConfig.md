# IoTJobAbortConfig
<a name="API_IoTJobAbortConfig"></a>

Contains a list of criteria that define when and how to cancel a configuration deployment.

## Contents
<a name="API_IoTJobAbortConfig_Contents"></a>

 ** criteriaList **   <a name="greengrassv2-Type-IoTJobAbortConfig-criteriaList"></a>
The list of criteria that define when and how to cancel the configuration deployment.
Type: Array of [IoTJobAbortCriteria](API_IoTJobAbortCriteria.md) objects
Array Members: Minimum number of 1 item.
Required: Yes
