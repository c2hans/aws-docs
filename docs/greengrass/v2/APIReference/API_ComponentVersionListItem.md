# ComponentVersionListItem
<a name="API_ComponentVersionListItem"></a>

Contains information about a component version in a list.

## Contents
<a name="API_ComponentVersionListItem_Contents"></a>

 ** arn **   <a name="greengrassv2-Type-ComponentVersionListItem-arn"></a>
The [ARN](https://docs.aws.amazon.com/general/latest/gr/aws-arns-and-namespaces.html) of the component version.
Type: String
Length Constraints: Minimum length of 1.
Required: No

 ** componentName **   <a name="greengrassv2-Type-ComponentVersionListItem-componentName"></a>
The name of the component.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Required: No

 ** componentVersion **   <a name="greengrassv2-Type-ComponentVersionListItem-componentVersion"></a>
The version of the component.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Required: No
