# Amazon Route 53 Documentation

Amazon Route 53 is a highly available and scalable Domain Name System (DNS) web service.

- [Developer Guide](/Route53/latest/DeveloperGuide/): Provides an overview of Amazon Route 53, detailed feature descriptions, and procedures for using the console.
- [API Reference](/Route53/latest/APIReference/): Describes all the API operations for Amazon Route 53 in detail. Also provides sample requests, responses, and errors for the supported web services protocols.
- [Amazon Route 53 DNS and health checking in the AWS CLI Reference](/cli/latest/reference/route53/index.html): Describes the Amazon Route 53 commands in the AWS CLI that you can use to configure DNS and health checks. Provides syntax, options, and usage examples for each command.
- [Amazon Route 53 domain registration in the AWS CLI Reference](/cli/latest/reference/route53domains/index.html): Describes the Amazon Route 53 commands in the AWS CLI that you can use for domain registration. Provides syntax, options, and usage examples for each command.
- [Amazon Route 53 Resolver in the AWS CLI Reference](/cli/latest/reference/route53resolver/index.html): Describes the Amazon Route 53 Resolver commands in the AWS CLI that you can use for forwarding DNS queries to Resolver in a specified VPC. Provides syntax, options, and usage examples for each command.
- [Amazon Route 53 Profiles in the AWS CLI Reference](/cli/latest/reference/route53profiles/index.html): Describes the Amazon Route 53 Profiles commands in the AWS CLI that you can use for sharing Route 53 configurations in VPCs and AWS accounts. Provides syntax, options, and usage examples for each command.
