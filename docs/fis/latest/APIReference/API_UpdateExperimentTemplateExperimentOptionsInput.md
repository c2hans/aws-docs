# UpdateExperimentTemplateExperimentOptionsInput
<a name="API_UpdateExperimentTemplateExperimentOptionsInput"></a>

Specifies an experiment option for an experiment template.

## Contents
<a name="API_UpdateExperimentTemplateExperimentOptionsInput_Contents"></a>

 ** emptyTargetResolutionMode **   <a name="fis-Type-UpdateExperimentTemplateExperimentOptionsInput-emptyTargetResolutionMode"></a>
The empty target resolution mode of the experiment template.
Type: String
Valid Values: `fail | skip`
Required: No
