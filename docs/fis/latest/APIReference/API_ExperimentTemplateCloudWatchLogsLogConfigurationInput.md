# ExperimentTemplateCloudWatchLogsLogConfigurationInput
<a name="API_ExperimentTemplateCloudWatchLogsLogConfigurationInput"></a>

Specifies the configuration for experiment logging to Amazon CloudWatch Logs.

## Contents
<a name="API_ExperimentTemplateCloudWatchLogsLogConfigurationInput_Contents"></a>

 ** logGroupArn **   <a name="fis-Type-ExperimentTemplateCloudWatchLogsLogConfigurationInput-logGroupArn"></a>
The Amazon Resource Name (ARN) of the destination Amazon CloudWatch Logs log group.
Type: String
Length Constraints: Minimum length of 20. Maximum length of 2048.
Pattern: `[\S]+`
Required: Yes
