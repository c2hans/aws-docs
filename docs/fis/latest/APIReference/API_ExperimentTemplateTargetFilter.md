# ExperimentTemplateTargetFilter
<a name="API_ExperimentTemplateTargetFilter"></a>

Describes a filter used for the target resources in an experiment template.

## Contents
<a name="API_ExperimentTemplateTargetFilter_Contents"></a>

 ** path **   <a name="fis-Type-ExperimentTemplateTargetFilter-path"></a>
The attribute path for the filter.
Type: String
Length Constraints: Maximum length of 256.
Pattern: `[\S]+`
Required: No

 ** values **   <a name="fis-Type-ExperimentTemplateTargetFilter-values"></a>
The attribute values for the filter.
Type: Array of strings
Length Constraints: Maximum length of 128.
Pattern: `[\S]+`
Required: No
