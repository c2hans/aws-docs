# ExperimentTemplateExperimentOptions
<a name="API_ExperimentTemplateExperimentOptions"></a>

Describes the experiment options for an experiment template.

## Contents
<a name="API_ExperimentTemplateExperimentOptions_Contents"></a>

 ** accountTargeting **   <a name="fis-Type-ExperimentTemplateExperimentOptions-accountTargeting"></a>
The account targeting setting for an experiment template.
Type: String
Valid Values: `single-account | multi-account`
Required: No

 ** emptyTargetResolutionMode **   <a name="fis-Type-ExperimentTemplateExperimentOptions-emptyTargetResolutionMode"></a>
The empty target resolution mode for an experiment template.
Type: String
Valid Values: `fail | skip`
Required: No
