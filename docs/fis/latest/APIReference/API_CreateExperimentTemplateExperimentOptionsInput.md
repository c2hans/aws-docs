# CreateExperimentTemplateExperimentOptionsInput
<a name="API_CreateExperimentTemplateExperimentOptionsInput"></a>

Specifies experiment options for an experiment template.

## Contents
<a name="API_CreateExperimentTemplateExperimentOptionsInput_Contents"></a>

 ** accountTargeting **   <a name="fis-Type-CreateExperimentTemplateExperimentOptionsInput-accountTargeting"></a>
Specifies the account targeting setting for experiment options.
Type: String
Valid Values: `single-account | multi-account`
Required: No

 ** emptyTargetResolutionMode **   <a name="fis-Type-CreateExperimentTemplateExperimentOptionsInput-emptyTargetResolutionMode"></a>
Specifies the empty target resolution mode for experiment options.
Type: String
Valid Values: `fail | skip`
Required: No
