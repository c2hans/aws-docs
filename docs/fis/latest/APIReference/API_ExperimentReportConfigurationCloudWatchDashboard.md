# ExperimentReportConfigurationCloudWatchDashboard
<a name="API_ExperimentReportConfigurationCloudWatchDashboard"></a>

Specifies the CloudWatch dashboard to include in the experiment report. The dashboard widgets will be captured as snapshot graphs within the report.

## Contents
<a name="API_ExperimentReportConfigurationCloudWatchDashboard_Contents"></a>

 ** dashboardIdentifier **   <a name="fis-Type-ExperimentReportConfigurationCloudWatchDashboard-dashboardIdentifier"></a>
The Amazon Resource Name (ARN) of the CloudWatch dashboard to include in the experiment report.
Type: String
Length Constraints: Maximum length of 512.
Pattern: `[\S]+`
Required: No
