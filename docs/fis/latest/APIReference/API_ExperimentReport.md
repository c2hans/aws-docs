# ExperimentReport
<a name="API_ExperimentReport"></a>

Describes the experiment report.

## Contents
<a name="API_ExperimentReport_Contents"></a>

 ** s3Reports **   <a name="fis-Type-ExperimentReport-s3Reports"></a>
The S3 destination of the experiment report.
Type: Array of [ExperimentReportS3Report](API_ExperimentReportS3Report.md) objects
Required: No

 ** state **   <a name="fis-Type-ExperimentReport-state"></a>
The state of the experiment report.
Type: [ExperimentReportState](API_ExperimentReportState.md) object
Required: No
