# ExperimentReportConfigurationDataSources
<a name="API_ExperimentReportConfigurationDataSources"></a>

Describes the data sources for the experiment report.

## Contents
<a name="API_ExperimentReportConfigurationDataSources_Contents"></a>

 ** cloudWatchDashboards **   <a name="fis-Type-ExperimentReportConfigurationDataSources-cloudWatchDashboards"></a>
The CloudWatch dashboards to include as data sources in the experiment report.
Type: Array of [ExperimentReportConfigurationCloudWatchDashboard](API_ExperimentReportConfigurationCloudWatchDashboard.md) objects
Required: No
