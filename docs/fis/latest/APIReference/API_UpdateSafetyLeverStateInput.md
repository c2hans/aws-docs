# UpdateSafetyLeverStateInput
<a name="API_UpdateSafetyLeverStateInput"></a>

 Specifies a state for a safety lever.

## Contents
<a name="API_UpdateSafetyLeverStateInput_Contents"></a>

 ** reason **   <a name="fis-Type-UpdateSafetyLeverStateInput-reason"></a>
 The reason for updating the state of the safety lever.
Type: String
Required: Yes

 ** status **   <a name="fis-Type-UpdateSafetyLeverStateInput-status"></a>
 The updated state of the safety lever.
Type: String
Valid Values: `disengaged | engaged`
Required: Yes
