# ExperimentTemplateCloudWatchLogsLogConfiguration
<a name="API_ExperimentTemplateCloudWatchLogsLogConfiguration"></a>

Describes the configuration for experiment logging to Amazon CloudWatch Logs.

## Contents
<a name="API_ExperimentTemplateCloudWatchLogsLogConfiguration_Contents"></a>

 ** logGroupArn **   <a name="fis-Type-ExperimentTemplateCloudWatchLogsLogConfiguration-logGroupArn"></a>
The Amazon Resource Name (ARN) of the destination Amazon CloudWatch Logs log group.
Type: String
Length Constraints: Minimum length of 20. Maximum length of 2048.
Pattern: `[\S]+`
Required: No
