# SafetyLeverState
<a name="API_SafetyLeverState"></a>

 Describes the state of the safety lever.

## Contents
<a name="API_SafetyLeverState_Contents"></a>

 ** reason **   <a name="fis-Type-SafetyLeverState-reason"></a>
 The reason for the state of the safety lever.
Type: String
Required: No

 ** status **   <a name="fis-Type-SafetyLeverState-status"></a>
 The state of the safety lever.
Type: String
Valid Values: `disengaged | engaged | engaging`
Required: No
