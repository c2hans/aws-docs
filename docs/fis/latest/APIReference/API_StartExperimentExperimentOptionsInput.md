# StartExperimentExperimentOptionsInput
<a name="API_StartExperimentExperimentOptionsInput"></a>

Specifies experiment options for running an experiment.

## Contents
<a name="API_StartExperimentExperimentOptionsInput_Contents"></a>

 ** actionsMode **   <a name="fis-Type-StartExperimentExperimentOptionsInput-actionsMode"></a>
Specifies the actions mode for experiment options.
Type: String
Valid Values: `skip-all | run-all`
Required: No
