# ExperimentReportError
<a name="API_ExperimentReportError"></a>

Describes the error when experiment report generation has failed.

## Contents
<a name="API_ExperimentReportError_Contents"></a>

 ** code **   <a name="fis-Type-ExperimentReportError-code"></a>
The error code for the failed experiment report generation.
Type: String
Length Constraints: Maximum length of 128.
Pattern: `[\s\S]+`
Required: No
