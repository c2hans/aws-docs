# ReportConfigurationCloudWatchDashboardInput
<a name="API_ReportConfigurationCloudWatchDashboardInput"></a>

Specifies the CloudWatch dashboard for the experiment report.

## Contents
<a name="API_ReportConfigurationCloudWatchDashboardInput_Contents"></a>

 ** dashboardIdentifier **   <a name="fis-Type-ReportConfigurationCloudWatchDashboardInput-dashboardIdentifier"></a>
The Amazon Resource Name (ARN) of the CloudWatch dashboard to include in the experiment report.
Type: String
Length Constraints: Maximum length of 512.
Pattern: `[\S]+`
Required: No
