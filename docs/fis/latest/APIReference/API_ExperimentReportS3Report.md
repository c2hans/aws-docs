# ExperimentReportS3Report
<a name="API_ExperimentReportS3Report"></a>

Describes the S3 destination for the report.

## Contents
<a name="API_ExperimentReportS3Report_Contents"></a>

 ** arn **   <a name="fis-Type-ExperimentReportS3Report-arn"></a>
The Amazon Resource Name (ARN) of the generated report.
Type: String
Pattern: `[\s\S]+`
Required: No

 ** reportType **   <a name="fis-Type-ExperimentReportS3Report-reportType"></a>
The report type for the experiment report.
Type: String
Pattern: `[\s\S]+`
Required: No
