# TargetResourceTypeParameter
<a name="API_TargetResourceTypeParameter"></a>

Describes the parameters for a resource type. Use parameters to determine which tasks are identified during target resolution.

## Contents
<a name="API_TargetResourceTypeParameter_Contents"></a>

 ** description **   <a name="fis-Type-TargetResourceTypeParameter-description"></a>
A description of the parameter.
Type: String
Length Constraints: Maximum length of 512.
Pattern: `[\s\S]+`
Required: No

 ** required **   <a name="fis-Type-TargetResourceTypeParameter-required"></a>
Indicates whether the parameter is required.
Type: Boolean
Required: No
