# ExperimentTemplateReportConfigurationCloudWatchDashboard
<a name="API_ExperimentTemplateReportConfigurationCloudWatchDashboard"></a>

The CloudWatch dashboards to include as data sources in the experiment report.

## Contents
<a name="API_ExperimentTemplateReportConfigurationCloudWatchDashboard_Contents"></a>

 ** dashboardIdentifier **   <a name="fis-Type-ExperimentTemplateReportConfigurationCloudWatchDashboard-dashboardIdentifier"></a>
The Amazon Resource Name (ARN) of the CloudWatch dashboard to include in the experiment report.
Type: String
Length Constraints: Maximum length of 512.
Pattern: `[\S]+`
Required: No
