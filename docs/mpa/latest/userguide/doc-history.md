# Document history for the Multi-party approval User Guide
<a name="doc-history"></a>

The following table describes the documentation releases for Multi-party approval.

| Change | Description | Date |
| --- |--- |--- |
| [Updated AWS managed policies](https://docs.aws.amazon.com/mpa/latest/userguide/security-iam-awsmanpol.html) | Added the `kms:Decrypt` permission to the `MultiPartyApprovalFullAccess` and `MultiPartyApprovalReadOnlyAccess` managed policies for AWS IAM Identity Center to support customer managed keys. | September 8, 2025 |
