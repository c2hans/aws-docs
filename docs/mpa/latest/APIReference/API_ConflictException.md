# ConflictException
<a name="API_ConflictException"></a>

The request cannot be completed because it conflicts with the current state of a resource.

HTTP Status Code returned: 409

## Contents
<a name="API_ConflictException_Contents"></a>

 ** Message **   <a name="mpa-Type-ConflictException-Message"></a>
Message for the `ConflictException` error.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 1000.
Required: Yes
