# BlacklistEntry
<a name="API_BlacklistEntry"></a>

An object that contains information about a blacklisting event that impacts one of the dedicated IP addresses that is associated with your account.

## Contents
<a name="API_BlacklistEntry_Contents"></a>

 ** Description **   <a name="pinpoint-Type-BlacklistEntry-Description"></a>
Additional information about the blacklisting event, as provided by the blacklist maintainer.
Type: String
Required: No

 ** ListingTime **   <a name="pinpoint-Type-BlacklistEntry-ListingTime"></a>
The time when the blacklisting event occurred, shown in Unix time format.
Type: Timestamp
Required: No

 ** RblName **   <a name="pinpoint-Type-BlacklistEntry-RblName"></a>
The name of the blacklist that the IP address appears on.
Type: String
Required: No
