# EnabledControlParameterSummary
<a name="API_EnabledControlParameterSummary"></a>

Returns a summary of information about the parameters of an enabled control.

## Contents
<a name="API_EnabledControlParameterSummary_Contents"></a>

 ** key **   <a name="controltower-Type-EnabledControlParameterSummary-key"></a>
The key of a key/value pair.
Type: String
Required: Yes

 ** value **   <a name="controltower-Type-EnabledControlParameterSummary-value"></a>
The value of a key/value pair.
Type: JSON value
Required: Yes
