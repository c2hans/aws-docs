# EnabledControlParameter
<a name="API_EnabledControlParameter"></a>

A key/value pair, where `Key` is of type `String` and `Value` is of type `Document`.

## Contents
<a name="API_EnabledControlParameter_Contents"></a>

 ** key **   <a name="controltower-Type-EnabledControlParameter-key"></a>
The key of a key/value pair.
Type: String
Required: Yes

 ** value **   <a name="controltower-Type-EnabledControlParameter-value"></a>
The value of a key/value pair.
Type: JSON value
Required: Yes
