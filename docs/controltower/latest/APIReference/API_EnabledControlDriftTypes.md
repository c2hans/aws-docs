# EnabledControlDriftTypes
<a name="API_EnabledControlDriftTypes"></a>

Defines the various categories of drift that can occur for an enabled control resource.

## Contents
<a name="API_EnabledControlDriftTypes_Contents"></a>

 ** inheritance **   <a name="controltower-Type-EnabledControlDriftTypes-inheritance"></a>
Indicates drift related to inheritance configuration between parent and child controls.
Type: [EnabledControlInheritanceDrift](API_EnabledControlInheritanceDrift.md) object
Required: No

 ** resource **   <a name="controltower-Type-EnabledControlDriftTypes-resource"></a>
Indicates drift related to the underlying AWS resources managed by the control.
Type: [EnabledControlResourceDrift](API_EnabledControlResourceDrift.md) object
Required: No
