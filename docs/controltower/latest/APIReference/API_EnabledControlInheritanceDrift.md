# EnabledControlInheritanceDrift
<a name="API_EnabledControlInheritanceDrift"></a>

Represents drift information related to control inheritance between organizational units.

## Contents
<a name="API_EnabledControlInheritanceDrift_Contents"></a>

 ** status **   <a name="controltower-Type-EnabledControlInheritanceDrift-status"></a>
The status of inheritance drift for the enabled control, indicating whether inheritance configuration matches expectations.
Type: String
Valid Values: `DRIFTED | IN_SYNC | NOT_CHECKING | UNKNOWN`
Required: No
