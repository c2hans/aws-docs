# BaselineSummary
<a name="API_BaselineSummary"></a>

Returns a summary of information about a `Baseline` object.

## Contents
<a name="API_BaselineSummary_Contents"></a>

 ** arn **   <a name="controltower-Type-BaselineSummary-arn"></a>
The full ARN of a Baseline.
Type: String
Required: Yes

 ** name **   <a name="controltower-Type-BaselineSummary-name"></a>
The human-readable name of a Baseline.
Type: String
Required: Yes

 ** description **   <a name="controltower-Type-BaselineSummary-description"></a>
A summary description of a Baseline.
Type: String
Required: No
