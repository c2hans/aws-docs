# EnabledBaselineSourceDrift

The source drift summary for the enabled baseline. Source drift occurs when an enabled baseline no longer matches the landing zone's configuration.

## Contents
<a name="API_EnabledBaselineSourceDrift_Contents"></a>

 ** status **   <a name="controltower-Type-EnabledBaselineSourceDrift-status"></a>
The source drift status for the enabled baseline.
Type: String
Valid Values: `IN_SYNC | DRIFTED`
Required: No
