# AWS Backup options available
<a name="with-backup"></a>

AWS Backup allows you to create a backup plan for your AWS Control Tower landing zone. You can incorporate a data backup and recovery workflow directly into your landing zone. The backup plan includes predefined rules, such as retention days, backup frequency, and the time window during which backup occurs. For more information, see [AWS Backup and AWS Control Tower](https://docs.aws.amazon.com/controltower/latest/userguide/backup.html).
