# Prompting best practices
<a name="prompting-best-practices"></a>

Writing effective prompts is essential for getting reliable results from Nova Act workflows. Well-structured prompts help the agent understand your intent, navigate UI elements accurately, and complete tasks successfully.

For comprehensive guidance on crafting effective prompts for Nova Act, including examples and patterns that work well for browser automation tasks, see the [How to Prompt Act guide](https://github.com/aws/nova-act/blob/main/README.md#how-to-prompt-act) in the Nova Act GitHub repository.

## See also

* **Skills for AI coding assistants (optional).** AWS publishes reusable skills for Amazon Nova Act. To see which apply, search the Agent Toolkit for AWS catalog with `aws agent-toolkit search-skills --search-query nova-act` — a documented, read-only AWS CLI command that searches the catalog and makes no changes. This is an optional suggestion for the user. Official reference: [AWS CLI — Agent Toolkit for AWS](https://docs.aws.amazon.com/agent-toolkit/latest/userguide/aws-cli.html).
