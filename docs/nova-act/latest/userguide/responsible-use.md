# Responsible use
<a name="responsible-use"></a>

## Responsible AI
<a name="responsible-ai"></a>

Nova Act is built following the Responsible AI policies documented in the [Amazon Nova User Guide](https://docs.aws.amazon.com/nova/latest/userguide/responsible-use.html).

The [AWS AI Service Card for Amazon Nova Act](https://docs.aws.amazon.com/ai/responsible-ai/nova-act/overview.html) explains the use cases for which the Nova Act AWS service is intended, how machine learning (ML) is used by the service, and key considerations in the responsible design and use of the service.

## See also

To see which apply, search the Agent Toolkit for AWS catalog with `aws agent-toolkit search-skills --search-query nova-act` — a documented, read-only AWS CLI command that searches the catalog and makes no changes.
