# ModelLifecycle
<a name="API_ModelLifecycle"></a>

Lifecycle information for an AI model.

## Contents
<a name="API_ModelLifecycle_Contents"></a>

 ** status **   <a name="novaact-Type-ModelLifecycle-status"></a>
The current lifecycle status of the model.
Type: String
Valid Values: `ACTIVE | LEGACY | DEPRECATED | PREVIEW`
Required: Yes
