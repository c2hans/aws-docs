# Data Types
<a name="API_Types"></a>

The Nova Act Service API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [ActError](API_ActError.md)
+  [ActSummary](API_ActSummary.md)
+  [Call](API_Call.md)
+  [CallResult](API_CallResult.md)
+  [CallResultContent](API_CallResultContent.md)
+  [ClientInfo](API_ClientInfo.md)
+  [CompatibilityInformation](API_CompatibilityInformation.md)
+  [ModelAlias](API_ModelAlias.md)
+  [ModelLifecycle](API_ModelLifecycle.md)
+  [ModelSummary](API_ModelSummary.md)
+  [SessionSummary](API_SessionSummary.md)
+  [ToolInputSchema](API_ToolInputSchema.md)
+  [ToolSpec](API_ToolSpec.md)
+  [TraceLocation](API_TraceLocation.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
+  [WorkflowDefinitionSummary](API_WorkflowDefinitionSummary.md)
+  [WorkflowExportConfig](API_WorkflowExportConfig.md)
+  [WorkflowRunSummary](API_WorkflowRunSummary.md)
