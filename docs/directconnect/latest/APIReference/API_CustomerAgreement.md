# CustomerAgreement
<a name="API_CustomerAgreement"></a>

The name and status of a customer agreement.

## Contents
<a name="API_CustomerAgreement_Contents"></a>

 ** agreementName **   <a name="DX-Type-CustomerAgreement-agreementName"></a>
The name of the agreement.
Type: String
Length Constraints: Maximum length of 100.
Required: No

 ** status **   <a name="DX-Type-CustomerAgreement-status"></a>
The status of the customer agreement. This will be either `signed` or `unsigned`
Type: String
Length Constraints: Maximum length of 30.
Required: No
