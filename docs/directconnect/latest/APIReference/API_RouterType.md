# RouterType
<a name="API_RouterType"></a>

Information about the virtual router.

## Contents
<a name="API_RouterType_Contents"></a>

 ** platform **   <a name="DX-Type-RouterType-platform"></a>
The virtual interface router platform.
Type: String
Required: No

 ** routerTypeIdentifier **   <a name="DX-Type-RouterType-routerTypeIdentifier"></a>
Identifies the router by a combination of vendor, platform, and software version. For example, `CiscoSystemsInc-2900SeriesRouters-IOS124`.
Type: String
Required: No

 ** software **   <a name="DX-Type-RouterType-software"></a>
The router software.
Type: String
Required: No

 ** vendor **   <a name="DX-Type-RouterType-vendor"></a>
The vendor for the virtual interface's router.
Type: String
Required: No

 ** xsltTemplateName **   <a name="DX-Type-RouterType-xsltTemplateName"></a>
The template for the virtual interface's router.
Type: String
Required: No

 ** xsltTemplateNameForMacSec **   <a name="DX-Type-RouterType-xsltTemplateNameForMacSec"></a>
The MAC Security (MACsec) template for the virtual interface's router.
Type: String
Required: No
