# Location
<a name="API_Location"></a>

Information about an Direct Connect location.

## Contents
<a name="API_Location_Contents"></a>

 ** availableMacSecPortSpeeds **   <a name="DX-Type-Location-availableMacSecPortSpeeds"></a>
The available MAC Security (MACsec) port speeds for the location.
Type: Array of strings
Required: No

 ** availablePortSpeeds **   <a name="DX-Type-Location-availablePortSpeeds"></a>
The available port speeds for the location.
Type: Array of strings
Required: No

 ** availableProviders **   <a name="DX-Type-Location-availableProviders"></a>
The name of the service provider for the location.
Type: Array of strings
Required: No

 ** locationCode **   <a name="DX-Type-Location-locationCode"></a>
The code for the location.
Type: String
Required: No

 ** locationName **   <a name="DX-Type-Location-locationName"></a>
The name of the location. This includes the name of the colocation partner and the physical site of the building.
Type: String
Required: No

 ** region **   <a name="DX-Type-Location-region"></a>
The AWS Region for the location.
Type: String
Required: No
