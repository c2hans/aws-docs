# CodegenJobRenderConfig
<a name="API_CodegenJobRenderConfig"></a>

Describes the configuration information for rendering the UI component associated with the code generation job.

## Contents
<a name="API_CodegenJobRenderConfig_Contents"></a>

**Important**
This data type is a UNION, so only one of the following members can be specified when used or returned.

 ** react **   <a name="amplifyuibuilder-Type-CodegenJobRenderConfig-react"></a>
The name of the `ReactStartCodegenJobData` object.
Type: [ReactStartCodegenJobData](API_ReactStartCodegenJobData.md) object
Required: No
