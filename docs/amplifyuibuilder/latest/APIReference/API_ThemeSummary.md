# ThemeSummary
<a name="API_ThemeSummary"></a>

Describes the basic information about a theme.

## Contents
<a name="API_ThemeSummary_Contents"></a>

 ** appId **   <a name="amplifyuibuilder-Type-ThemeSummary-appId"></a>
The unique ID for the app associated with the theme summary.
Type: String
Required: Yes

 ** environmentName **   <a name="amplifyuibuilder-Type-ThemeSummary-environmentName"></a>
The name of the backend environment that is part of the Amplify app.
Type: String
Required: Yes

 ** id **   <a name="amplifyuibuilder-Type-ThemeSummary-id"></a>
The ID of the theme.
Type: String
Required: Yes

 ** name **   <a name="amplifyuibuilder-Type-ThemeSummary-name"></a>
The name of the theme.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 255.
Required: Yes
