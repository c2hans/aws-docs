# ValueMappings
<a name="API_ValueMappings"></a>

Represents the data binding configuration for a value map.

## Contents
<a name="API_ValueMappings_Contents"></a>

 ** values **   <a name="amplifyuibuilder-Type-ValueMappings-values"></a>
The value and display value pairs.
Type: Array of [ValueMapping](API_ValueMapping.md) objects
Required: Yes

 ** bindingProperties **   <a name="amplifyuibuilder-Type-ValueMappings-bindingProperties"></a>
The information to bind fields to data at runtime.
Type: String to [FormInputBindingPropertiesValue](API_FormInputBindingPropertiesValue.md) object map
Required: No
