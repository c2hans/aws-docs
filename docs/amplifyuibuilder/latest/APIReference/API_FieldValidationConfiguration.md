# FieldValidationConfiguration
<a name="API_FieldValidationConfiguration"></a>

Describes the validation configuration for a field.

## Contents
<a name="API_FieldValidationConfiguration_Contents"></a>

 ** type **   <a name="amplifyuibuilder-Type-FieldValidationConfiguration-type"></a>
The validation to perform on an object type.``
Type: String
Required: Yes

 ** numValues **   <a name="amplifyuibuilder-Type-FieldValidationConfiguration-numValues"></a>

Required: No

 ** strValues **   <a name="amplifyuibuilder-Type-FieldValidationConfiguration-strValues"></a>
