# CodegenFeatureFlags
<a name="API_CodegenFeatureFlags"></a>

Describes the feature flags that you can specify for a code generation job.

## Contents
<a name="API_CodegenFeatureFlags_Contents"></a>

 ** isNonModelSupported **   <a name="amplifyuibuilder-Type-CodegenFeatureFlags-isNonModelSupported"></a>
Specifies whether a code generation job supports non models.
Type: Boolean
Required: No

 ** isRelationshipSupported **   <a name="amplifyuibuilder-Type-CodegenFeatureFlags-isRelationshipSupported"></a>
Specifes whether a code generation job supports data relationships.
Type: Boolean
Required: No
