# ServiceNodePortRange
<a name="API_ServiceNodePortRange"></a>

The port range for Kubernetes NodePort services.

## Contents
<a name="API_ServiceNodePortRange_Contents"></a>

 ** maxPort **   <a name="AmazonEKS-Type-ServiceNodePortRange-maxPort"></a>
The maximum port number in the range.
Type: Integer
Required: No

 ** minPort **   <a name="AmazonEKS-Type-ServiceNodePortRange-minPort"></a>
The minimum port number in the range.
Type: Integer
Required: No
