# NodegroupHealth
<a name="API_NodegroupHealth"></a>

An object representing the health status of the node group.

## Contents
<a name="API_NodegroupHealth_Contents"></a>

 ** issues **   <a name="AmazonEKS-Type-NodegroupHealth-issues"></a>
Any issues that are associated with the node group.
Type: Array of [Issue](API_Issue.md) objects
Required: No
