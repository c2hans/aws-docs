# CertificateAuthorityValidity
<a name="API_CertificateAuthorityValidity"></a>

The validity period of a certificate authority's certificate.

## Contents
<a name="API_CertificateAuthorityValidity_Contents"></a>

 ** notAfter **   <a name="AmazonEKS-Type-CertificateAuthorityValidity-notAfter"></a>
The Unix epoch timestamp in seconds for the end of the certificate authority's validity period.
Type: Timestamp
Required: No

 ** notBefore **   <a name="AmazonEKS-Type-CertificateAuthorityValidity-notBefore"></a>
The Unix epoch timestamp in seconds for the start of the certificate authority's validity period.
Type: Timestamp
Required: No
