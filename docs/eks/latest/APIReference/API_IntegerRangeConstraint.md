# IntegerRangeConstraint
<a name="API_IntegerRangeConstraint"></a>

An integer range constraint specifying minimum and maximum allowed values.

## Contents
<a name="API_IntegerRangeConstraint_Contents"></a>

 ** max **   <a name="AmazonEKS-Type-IntegerRangeConstraint-max"></a>
The maximum allowed value.
Type: Integer
Required: No

 ** min **   <a name="AmazonEKS-Type-IntegerRangeConstraint-min"></a>
The minimum allowed value.
Type: Integer
Required: No
