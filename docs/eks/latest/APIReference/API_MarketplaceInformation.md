# MarketplaceInformation
<a name="API_MarketplaceInformation"></a>

Information about an Amazon EKS add-on from the AWS Marketplace.

## Contents
<a name="API_MarketplaceInformation_Contents"></a>

 ** productId **   <a name="AmazonEKS-Type-MarketplaceInformation-productId"></a>
The product ID from the AWS Marketplace.
Type: String
Required: No

 ** productUrl **   <a name="AmazonEKS-Type-MarketplaceInformation-productUrl"></a>
The product URL from the AWS Marketplace.
Type: String
Required: No
