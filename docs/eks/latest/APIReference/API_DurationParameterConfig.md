# DurationParameterConfig
<a name="API_DurationParameterConfig"></a>

A duration parameter configuration with default value and constraints.

## Contents
<a name="API_DurationParameterConfig_Contents"></a>

 ** constraints **   <a name="AmazonEKS-Type-DurationParameterConfig-constraints"></a>
The constraints for the duration parameter.
Type: [DurationConstraints](API_DurationConstraints.md) object
Required: No

 ** defaultValue **   <a name="AmazonEKS-Type-DurationParameterConfig-defaultValue"></a>
The default value for the duration parameter.
Type: String
Required: No
