# HorizontalPodAutoscalerControllerConfigResponse
<a name="API_HorizontalPodAutoscalerControllerConfigResponse"></a>

The horizontal pod autoscaler controller configuration for the Kubernetes controller manager.

## Contents
<a name="API_HorizontalPodAutoscalerControllerConfigResponse_Contents"></a>

 ** horizontalPodAutoscalerSyncPeriod **   <a name="AmazonEKS-Type-HorizontalPodAutoscalerControllerConfigResponse-horizontalPodAutoscalerSyncPeriod"></a>
The interval between each sync of the horizontal pod autoscaler.
Type: String
Required: No
