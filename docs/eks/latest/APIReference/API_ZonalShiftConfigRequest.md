# ZonalShiftConfigRequest
<a name="API_ZonalShiftConfigRequest"></a>

The configuration for zonal shift for the cluster.

## Contents
<a name="API_ZonalShiftConfigRequest_Contents"></a>

 ** enabled **   <a name="AmazonEKS-Type-ZonalShiftConfigRequest-enabled"></a>
If zonal shift is enabled, AWS configures zonal autoshift for the cluster.
Type: Boolean
Required: No
