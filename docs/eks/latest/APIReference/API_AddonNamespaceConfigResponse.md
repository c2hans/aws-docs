# AddonNamespaceConfigResponse
<a name="API_AddonNamespaceConfigResponse"></a>

The namespace configuration response object containing information about the namespace where an addon is installed.

## Contents
<a name="API_AddonNamespaceConfigResponse_Contents"></a>

 ** namespace **   <a name="AmazonEKS-Type-AddonNamespaceConfigResponse-namespace"></a>
The name of the Kubernetes namespace where the addon is installed.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 63.
Required: No
