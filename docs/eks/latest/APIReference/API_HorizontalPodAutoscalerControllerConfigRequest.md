# HorizontalPodAutoscalerControllerConfigRequest
<a name="API_HorizontalPodAutoscalerControllerConfigRequest"></a>

The horizontal pod autoscaler controller configuration for the Kubernetes controller manager.

## Contents
<a name="API_HorizontalPodAutoscalerControllerConfigRequest_Contents"></a>

 ** horizontalPodAutoscalerSyncPeriod **   <a name="AmazonEKS-Type-HorizontalPodAutoscalerControllerConfigRequest-horizontalPodAutoscalerSyncPeriod"></a>
The interval between each sync of the horizontal pod autoscaler. Valid values are single-unit durations such as `15s` or `1m`.
Type: String
Required: No
