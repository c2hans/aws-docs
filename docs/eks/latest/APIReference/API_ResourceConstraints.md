# ResourceConstraints
<a name="API_ResourceConstraints"></a>

Constraints for resource weight entries.

## Contents
<a name="API_ResourceConstraints_Contents"></a>

 ** name **   <a name="AmazonEKS-Type-ResourceConstraints-name"></a>
The allowed values for resource names.
Type: [AllowedValuesConstraint](API_AllowedValuesConstraint.md) object
Required: No

 ** weight **   <a name="AmazonEKS-Type-ResourceConstraints-weight"></a>
The allowed range for resource weight values.
Type: [IntegerRangeConstraint](API_IntegerRangeConstraint.md) object
Required: No
