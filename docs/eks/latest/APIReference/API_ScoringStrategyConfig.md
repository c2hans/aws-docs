# ScoringStrategyConfig
<a name="API_ScoringStrategyConfig"></a>

The scoring strategy configuration with default value and constraints.

## Contents
<a name="API_ScoringStrategyConfig_Contents"></a>

 ** constraints **   <a name="AmazonEKS-Type-ScoringStrategyConfig-constraints"></a>
The constraints for the scoring strategy.
Type: [ScoringStrategyConstraints](API_ScoringStrategyConstraints.md) object
Required: No

 ** defaultValue **   <a name="AmazonEKS-Type-ScoringStrategyConfig-defaultValue"></a>
The default scoring strategy.
Type: [ScoringStrategy](API_ScoringStrategy.md) object
Required: No
