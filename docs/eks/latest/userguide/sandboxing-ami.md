# Build a compatible AMI
<a name="sandboxing-ami"></a>

Pods running in Nitro Sandboxes are available on EKS Auto Mode clusters without additional configuration. For self-managed or managed node groups outside of Auto Mode, build a compatible AMI using the Nitro Sandboxes binaries provided by AWS. For instructions, see [Create and update a Nitro Sandbox AMI](sandboxing-ami-create-update.md).
