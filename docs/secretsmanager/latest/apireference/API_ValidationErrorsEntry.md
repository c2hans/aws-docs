# ValidationErrorsEntry
<a name="API_ValidationErrorsEntry"></a>

Displays errors that occurred during validation of the resource policy.

## Contents
<a name="API_ValidationErrorsEntry_Contents"></a>

 ** CheckName **   <a name="SecretsManager-Type-ValidationErrorsEntry-CheckName"></a>
Checks the name of the policy.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 512.
Required: No

 ** ErrorMessage **   <a name="SecretsManager-Type-ValidationErrorsEntry-ErrorMessage"></a>
Displays error messages if validation encounters problems during validation of the resource policy.
Type: String
Required: No
