# RecurringCharge
<a name="API_RecurringCharge"></a>

Specifies whether charges for devices are recurring.

## Contents
<a name="API_RecurringCharge_Contents"></a>

 ** cost **   <a name="devicefarm-Type-RecurringCharge-cost"></a>
The cost of the recurring charge.
Type: [MonetaryAmount](API_MonetaryAmount.md) object
Required: No

 ** frequency **   <a name="devicefarm-Type-RecurringCharge-frequency"></a>
The frequency in which charges recur.
Type: String
Valid Values: `MONTHLY`
Required: No
