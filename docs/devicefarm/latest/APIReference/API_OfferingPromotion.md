# OfferingPromotion
<a name="API_OfferingPromotion"></a>

Represents information about an offering promotion.

## Contents
<a name="API_OfferingPromotion_Contents"></a>

 ** description **   <a name="devicefarm-Type-OfferingPromotion-description"></a>
A string that describes the offering promotion.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 16384.
Required: No

 ** id **   <a name="devicefarm-Type-OfferingPromotion-id"></a>
The ID of the offering promotion.
Type: String
Length Constraints: Minimum length of 4.
Required: No
