# FeedAssociation
<a name="API_FeedAssociation"></a>

Contains information about the resource that is associated with a feed. It is used in the FeedSummary that is used in the response of a ListFeeds action.

## Contents
<a name="API_FeedAssociation_Contents"></a>

 ** associatedResourceName **   <a name="elementalinference-Type-FeedAssociation-associatedResourceName"></a>
The name of the associated resource.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 2048.
Pattern: `[\w \-\.',@:;/]*`
Required: Yes
