# Data Types
<a name="API_Types"></a>

The AWS Elemental Inference API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AspectRatio](API_AspectRatio.md)
+  [ClippingConfig](API_ClippingConfig.md)
+  [CreateOutput](API_CreateOutput.md)
+  [CroppingConfig](API_CroppingConfig.md)
+  [DictionarySummary](API_DictionarySummary.md)
+  [FeedAssociation](API_FeedAssociation.md)
+  [FeedSummary](API_FeedSummary.md)
+  [GetOutput](API_GetOutput.md)
+  [OutputConfig](API_OutputConfig.md)
+  [SubtitlingConfig](API_SubtitlingConfig.md)
+  [UpdateOutput](API_UpdateOutput.md)
