# ServiceInsertionSegments
<a name="API_ServiceInsertionSegments"></a>

Describes the segments associated with the service insertion action.

## Contents
<a name="API_ServiceInsertionSegments_Contents"></a>

 ** SendTo **   <a name="networkmanager-Type-ServiceInsertionSegments-SendTo"></a>
The list of segments associated with the `send-to` action.
Type: Array of strings
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No

 ** SendVia **   <a name="networkmanager-Type-ServiceInsertionSegments-SendVia"></a>
The list of segments associated with the `send-via` action.
Type: Array of strings
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No
