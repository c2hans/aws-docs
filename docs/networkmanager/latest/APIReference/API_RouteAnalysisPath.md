# RouteAnalysisPath
<a name="API_RouteAnalysisPath"></a>

Describes a route analysis path.

## Contents
<a name="API_RouteAnalysisPath_Contents"></a>

 ** CompletionStatus **   <a name="networkmanager-Type-RouteAnalysisPath-CompletionStatus"></a>
The status of the analysis at completion.
Type: [RouteAnalysisCompletion](API_RouteAnalysisCompletion.md) object
Required: No

 ** Path **   <a name="networkmanager-Type-RouteAnalysisPath-Path"></a>
The route analysis path.
Type: Array of [PathComponent](API_PathComponent.md) objects
Required: No
