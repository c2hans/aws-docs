# AccountStatus
<a name="API_AccountStatus"></a>

Describes the current status of an account within an Amazon Web Services Organization, including service-linked roles (SLRs).

## Contents
<a name="API_AccountStatus_Contents"></a>

 ** AccountId **   <a name="networkmanager-Type-AccountStatus-AccountId"></a>
The ID of an account within the Amazon Web Services Organization.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 50.
Required: No

 ** SLRDeploymentStatus **   <a name="networkmanager-Type-AccountStatus-SLRDeploymentStatus"></a>
The status of SLR deployment for the account.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 50.
Required: No
