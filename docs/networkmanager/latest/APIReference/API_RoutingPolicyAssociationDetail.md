# RoutingPolicyAssociationDetail
<a name="API_RoutingPolicyAssociationDetail"></a>

Information about a routing policy association.

## Contents
<a name="API_RoutingPolicyAssociationDetail_Contents"></a>

 ** RoutingPolicyNames **   <a name="networkmanager-Type-RoutingPolicyAssociationDetail-RoutingPolicyNames"></a>
The names of the routing policies in the association.
Type: Array of strings
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No

 ** SharedSegments **   <a name="networkmanager-Type-RoutingPolicyAssociationDetail-SharedSegments"></a>
The names of the segments that are shared with each other in the association.
Type: Array of strings
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No
