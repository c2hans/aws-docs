# ConnectionHealth
<a name="API_ConnectionHealth"></a>

Describes connection health.

## Contents
<a name="API_ConnectionHealth_Contents"></a>

 ** Status **   <a name="networkmanager-Type-ConnectionHealth-Status"></a>
The connection status.
Type: String
Valid Values: `UP | DOWN`
Required: No

 ** Timestamp **   <a name="networkmanager-Type-ConnectionHealth-Timestamp"></a>
The time the status was last updated.
Type: Timestamp
Required: No

 ** Type **   <a name="networkmanager-Type-ConnectionHealth-Type"></a>
The connection type.
Type: String
Valid Values: `BGP | IPSEC`
Required: No
