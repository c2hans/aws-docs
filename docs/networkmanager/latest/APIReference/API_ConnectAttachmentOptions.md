# ConnectAttachmentOptions
<a name="API_ConnectAttachmentOptions"></a>

Describes a core network Connect attachment options.

## Contents
<a name="API_ConnectAttachmentOptions_Contents"></a>

 ** Protocol **   <a name="networkmanager-Type-ConnectAttachmentOptions-Protocol"></a>
The protocol used for the attachment connection.
Type: String
Valid Values: `GRE | NO_ENCAP`
Required: No
