# WhenSentTo
<a name="API_WhenSentTo"></a>

Displays a list of the destination segments. Used only when the service insertion action is `send-to`.

## Contents
<a name="API_WhenSentTo_Contents"></a>

 ** WhenSentToSegmentsList **   <a name="networkmanager-Type-WhenSentTo-WhenSentToSegmentsList"></a>
The list of destination segments when the service insertion action is `send-to`.
Type: Array of strings
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No
