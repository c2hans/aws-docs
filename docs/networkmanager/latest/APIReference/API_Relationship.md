# Relationship
<a name="API_Relationship"></a>

Describes a resource relationship.

## Contents
<a name="API_Relationship_Contents"></a>

 ** From **   <a name="networkmanager-Type-Relationship-From"></a>
The ARN of the resource.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No

 ** To **   <a name="networkmanager-Type-Relationship-To"></a>
The ARN of the resource.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No
