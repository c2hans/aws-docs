# Location
<a name="API_Location"></a>

Describes a location.

## Contents
<a name="API_Location_Contents"></a>

 ** Address **   <a name="networkmanager-Type-Location-Address"></a>
The physical address.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No

 ** Latitude **   <a name="networkmanager-Type-Location-Latitude"></a>
The latitude.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No

 ** Longitude **   <a name="networkmanager-Type-Location-Longitude"></a>
The longitude.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No
