# MultipathResilienceChangeValues
<a name="API_MultipathResilienceChangeValues"></a>

Information about a change in multipath resilience.

## Contents
<a name="API_MultipathResilienceChangeValues_Contents"></a>

 ** EdgeSets **   <a name="networkmanager-Type-MultipathResilienceChangeValues-EdgeSets"></a>
A set of two edge locations.
Type: Array of arrays of strings
Length Constraints: Minimum length of 0. Maximum length of 256.
Pattern: `[\s\S]*`
Required: No

 ** Mode **   <a name="networkmanager-Type-MultipathResilienceChangeValues-Mode"></a>
The mode (best-effort/disabled) of multipath resilience.
Type: String
Valid Values: `best-effort | disabled`
Required: No
