# PermissionsErrorContext
<a name="API_PermissionsErrorContext"></a>

Describes additional information about missing permissions.

## Contents
<a name="API_PermissionsErrorContext_Contents"></a>

 ** MissingPermission **   <a name="networkmanager-Type-PermissionsErrorContext-MissingPermission"></a>
The missing permissions.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 10000000.
Pattern: `[\s\S]*`
Required: No
