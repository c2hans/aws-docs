# RegionMapInputValue
<a name="API_RegionMapInputValue"></a>

The mapping between a AWS Region and the key that's used to encrypt the data.

## Contents
<a name="API_RegionMapInputValue_Contents"></a>

 ** sseKmsKeyId **   <a name="IncidentManager-Type-RegionMapInputValue-sseKmsKeyId"></a>
The AWS KMS key used to encrypt the data in your replication set.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Required: No
