# FindingSummary
<a name="API_FindingSummary"></a>

Identifying information about the finding.

## Contents
<a name="API_FindingSummary_Contents"></a>

 ** id **   <a name="IncidentManager-Type-FindingSummary-id"></a>
The ID of the finding.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 128.
Required: Yes

 ** lastModifiedTime **   <a name="IncidentManager-Type-FindingSummary-lastModifiedTime"></a>
The timestamp for when the finding was last updated.
Type: Timestamp
Required: Yes
