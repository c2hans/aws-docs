# DeleteRegionAction
<a name="API_DeleteRegionAction"></a>

Defines the information about the AWS Region you're deleting from your replication set.

## Contents
<a name="API_DeleteRegionAction_Contents"></a>

 ** regionName **   <a name="IncidentManager-Type-DeleteRegionAction-regionName"></a>
The name of the AWS Region you're deleting from the replication set.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 20.
Required: Yes
