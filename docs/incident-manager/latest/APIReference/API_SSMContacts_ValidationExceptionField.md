# ValidationExceptionField
<a name="API_SSMContacts_ValidationExceptionField"></a>

Provides information about which field caused the exception.

## Contents
<a name="API_SSMContacts_ValidationExceptionField_Contents"></a>

 ** Message **   <a name="IncidentManager-Type-SSMContacts_ValidationExceptionField-Message"></a>
Information about what caused the field to cause an exception.
Type: String
Required: Yes

 ** Name **   <a name="IncidentManager-Type-SSMContacts_ValidationExceptionField-Name"></a>
The name of the field that caused the exception.
Type: String
Required: Yes
