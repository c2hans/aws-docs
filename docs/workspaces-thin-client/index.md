# Amazon WorkSpaces Thin Client

Cost-effective, easy-to-manage thin client to securely access AWS End User Computing services.

- [Administrator Guide](/workspaces-thin-client/latest/ag/): Helps administrators get started with configuring the Amazon WorkSpaces Thin Client service. Learn how to quickly and easily provision and maintain one or more thin clients.
- [User Guide](/workspaces-thin-client/latest/ug/): Helps end users get started using a thin client device. Learn how to set up and sign in to your thin client.
- [API Reference](/workspaces-thin-client/latest/api/): Describes the API operations for the Amazon WorkSpaces Thin Client service. It also provides the basic structure and elements of an API request and response.
