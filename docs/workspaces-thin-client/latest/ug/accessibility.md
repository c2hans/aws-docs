# Using WorkSpaces Thin Client accessibility features
<a name="accessibility"></a>

Amazon WorkSpaces Thin Client provides accessibility features designed to help you use your device. With VoiceView, you can navigate your WorkSpaces Thin Client using text-to-speech functionality, while Screen Magnifier allows for custom zoom levels to enlarge on-screen content. These features seamlessly integrate with the WorkSpaces Thin Client.
