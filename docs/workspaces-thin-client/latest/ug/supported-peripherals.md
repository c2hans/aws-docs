# Supported peripherals
<a name="supported-peripherals"></a>

You can use WorkSpaces Thin Client with different peripherals. Refer to the following to see if a specific peripheral is compatible with your WorkSpaces Thin Client.

**Note**
These devices have been verified to work with Amazon WorkSpaces Thin Client. Other peripherals can be used, but they may not be supported.
