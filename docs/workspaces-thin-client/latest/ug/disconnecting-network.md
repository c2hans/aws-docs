# Disconnecting a network
<a name="disconnecting-network"></a>

You can disconnect from a network that is currently in use.

1. Go to **Settings**, **Network**, **Known Networks**.

1. Select **Disconnect** from the network you are using.

Your WorkSpaces Thin Client device will then sign on to the next available network listed. To reconnect, double-click the network form the **Known Networks** list.
