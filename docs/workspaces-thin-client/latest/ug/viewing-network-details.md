# Viewing network details
<a name="viewing-network-details"></a>

Each network will have addresses associated with it.

1. Go to **Settings**, **Network**, **Known Networks**.

1. Select the horizontal ellipsis icon (**...**).

A list with the address information will appear as shown in the image below.

![Network settings showing IP address 10.144.12.206 and router address 10.144.0.1.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/network1.png)
