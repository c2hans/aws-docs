# Using the toolbar
<a name="using-toolbar"></a>

You can access all of WorkSpaces Thin Client device functions through a toolbar on your display. From this toolbar, you are able to control the basic settings of your WorkSpaces Thin Client device.

The toolbar, in its collapsed form, is located on the right side of your display represented as a dark bar.

## Accessing your toolbar
<a name="accessing-toolbar"></a>

 To access the toolbar functions, you need to expand it. Once expanded, the available functions will appear. The toolbar collapses once you are finished using it.

1. Select the dark bar on the right of your display.
![Amazon WorkSpaces login screen showing disconnected status and option to return to sign-in page.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/toolbar-3.png)

1. Select the function you want to use. For a list of functions, see [Toolbar functions](#toolbar-functions).

1. Select any area on the primary display to collapse the toolbar.
![Amazon WorkSpaces disconnected status screen with Return to sign in page button.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/toolbar-2.png)

1. If you want to use your keyboard, press CTRL\+ALT\+SHIFT\+T to expand or collapse the toolbar.

## Positioning your toolbar
<a name="toolbar-position"></a>

The toolbar is located on the side of your WorkSpaces Thin Client display. It is located along the right edge of the screen on your primary monitor by default. You can change the position of your toolbar.

**Changing your toolbar position**

1. Go to **Settings** then **About**.

1. Go to the **Toolbar position on the screen** section.

1. Click on the switch to select either **Right** or **Left**.
![Settings page showing software details, toolbar position options, and reset device section.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/tb-settings-left.png)

The toolbar will show up along the edge of the screen on your primary monitor on the side your have selected.

![Amazon WorkSpaces sign-in page with left sidebar menu showing options like Sign In and Settings.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/tb-expanded-left.png)

## Toolbar functions
<a name="toolbar-functions"></a>

When the toolbar is expanded, a list of functions is available for you to use. These are the basic settings of your WorkSpaces Thin Client device.

| Button | Function | Description |
| --- | --- | --- |
|  ![Sign In button with arrow icon.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/Sign_In_Button.png)  | Sign in | Selecting **Sign In** takes you to your virtual desktop session sign in page. You need to enter your virtual desktop session username and password to start a session. If you are using WorkSpaces, this function changes to **Exit Session**. |
|  ![Exit Session button with an arrow icon pointing to the right.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/Exit_Session_Button.png)  | Exit Session | Selecting **Exit Session** will end your current session and require re-authentication to regain access. Please note that some preferences may not be preserved.<br />If you are using WorkSpaces Applications or WorkSpaces Secure Browser, this button is removed from the toolbar. Use the Disconnect function within the virtual desktop to sign out of your session. |
|  ![Settings icon represented by a gear or cog symbol.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/settings.png)  | Settings | Accesses the settings for your device.<br />These settings include:+ About<br />+ Languages<br />+ Network<br />+ Notifications<br />+ Peripheral devices<br />+ Power and sleep<br />+ Time zone |
|  ![Network icon with Wi-Fi symbol indicating wireless connectivity.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/network.png)  | Network | Accesses the network settings of your device. For more information, see [Managing networks](managing-networks.md). |
|  ![Icon representing sleep or night mode, showing a crescent moon symbol.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/sleep-button.png)  | Sleep | Puts the device into Sleep mode. For more information, see [Setting the Sleep mode](device-sleep.md). |
|  ![Lock icon representing security or access control in cloud services.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/lock.png)  | Lock | Ends the current session and takes you to the lock page. Once locked, you can select **Unlock** to access your Sign In page. |
|  ![Restart button with circular arrow icon.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/restart.png)  | Restart | Restarts the device. For more information, see [Rebooting by using the toolbar](rebooting-device.md#reboot-ui). |
|  ![Power icon with "Shutdown" text, indicating a shutdown or power off option.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/shutdown.png)  | Shutdown | Logs you out of the session and shuts down the device. |
|  ![Bell icon representing notifications in a user interface.](http://docs.aws.amazon.com/workspaces-thin-client/latest/ug/images/notifications.png)  | Notifications | Accesses the Notifications for your device. |
