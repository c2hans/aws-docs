# Using shortcuts on Windows keyboards
<a name="keyboard-shortcuts"></a>

WorkSpaces Thin Client has the capability to use keyboard shortcuts for some of its functions. The following table shows the enabled shortcuts and their associated functions.

**Note**
This features is available for Windows sessions only.

| Keyboard shortcut | Device function |
| --- | --- |
| Windows logo key \+ Shift \+ S | Create part of the screen screenshot. |
| Windows logo key \+ Ctrl \+ Enter | Turn [Windows Narrator](using-voiceview.md#windows-narrator) on and off. |
| Windows logo key \+ Plus(\+) | Zoom in using the [Magnifier](using-screen-magnifier.md#windows-magnifier). |
| Windows logo key \+ Left arrow | Snap app or window left. |
| Windows logo key \+ Right arrow | Snap app or window right. |
| Windows logo key \+ Up arrow | Maximize app windows. |
| Windows logo key \+ Down | Minimize app windows. |
| Windows logo key \+ D | Display and hide the desktop. |
