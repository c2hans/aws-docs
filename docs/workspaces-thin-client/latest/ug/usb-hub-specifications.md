# USB hub specifications
<a name="usb-hub-specifications"></a>

The WorkSpaces Thin Client device requires a USB hub to connect to all of your peripherals. These are the USB hubs that work with WorkSpaces Thin Client.

## Zhenyou EVT hub (USB-A) - ZYHB03 USB hub
<a name="zhenyou-usb-hub"></a>

**Note**
This USB hub comes shipped with your WorkSpaces Thin Client device.

|  |  |
| --- |--- |
| **Display Port** | 1 x HDMI port (support up to 1080p @ 30 Hz, mirror or extended display) |
| **USB Port** | 4 x USB 3.0 ports |
| **Power** | 1 x DC jack (support 5 V @ 3 A, O.D. 3.5 mm x I.D. 1.35 mm barrel connector) |
| **Support OS** | Android |

## Plugable UD-3900Z USB Docking Station
<a name="ud-usb-hub"></a>

|  |  |
| --- |--- |
| **Display Port** | 2 x HDMI ports (support up to 1080p @ 30 Hz, mirror or extended display)<br />Only 1 HDMI port can be used with WorkSpaces Thin Client at a time. |
| **USB Port** | 2 x USB-A 3.0 ports on the front<br />4 x USB-A 2.0 ports on the back |
| **Ethernet port** | Not supported |
| **Audio port** | Not supported |
| **Power** | 1 x DC jack (support 5 V @ 3 A, O.D. 3.5 mm x I.D. 1.35 mm barrel connector) |
| **Support OS** | Android |
