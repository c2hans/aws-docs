# Data Types
<a name="API_Types"></a>

The Amazon WorkSpaces Thin Client API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [Device](API_Device.md)
+  [DeviceSummary](API_DeviceSummary.md)
+  [Environment](API_Environment.md)
+  [EnvironmentSummary](API_EnvironmentSummary.md)
+  [MaintenanceWindow](API_MaintenanceWindow.md)
+  [Software](API_Software.md)
+  [SoftwareSet](API_SoftwareSet.md)
+  [SoftwareSetSummary](API_SoftwareSetSummary.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
