# CreditSpecificationRequest
<a name="API_CreditSpecificationRequest"></a>

 ** CpuCredits **   <a name="workspacesinstances-Type-CreditSpecificationRequest-CpuCredits"></a>

Type: String
Valid Values: `standard | unlimited`
