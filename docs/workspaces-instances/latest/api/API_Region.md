# Region
<a name="API_Region"></a>

Represents an AWS region supported by WorkSpaces Instances.

## Contents
<a name="API_Region_Contents"></a>

 ** RegionName **   <a name="workspacesinstances-Type-Region-RegionName"></a>
Name of the AWS region.
Type: String
Pattern: `[-0-9a-z]{1,31}`
Required: No
