# EnaSrdUdpSpecificationRequest
<a name="API_EnaSrdUdpSpecificationRequest"></a>

Specifies UDP configuration for ENA SRD.

## Contents
<a name="API_EnaSrdUdpSpecificationRequest_Contents"></a>

 ** EnaSrdUdpEnabled **   <a name="workspacesinstances-Type-EnaSrdUdpSpecificationRequest-EnaSrdUdpEnabled"></a>
Enables or disables ENA SRD for UDP traffic.
Type: Boolean
Required: No
