# EC2ManagedInstance
<a name="API_EC2ManagedInstance"></a>

Represents an EC2 instance managed by WorkSpaces.

## Contents
<a name="API_EC2ManagedInstance_Contents"></a>

 ** InstanceId **   <a name="workspacesinstances-Type-EC2ManagedInstance-InstanceId"></a>
Unique identifier of the managed EC2 instance.
Type: String
Required: No
