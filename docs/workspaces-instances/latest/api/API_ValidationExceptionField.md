# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

Represents a validation error field in an API request.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** Message **   <a name="workspacesinstances-Type-ValidationExceptionField-Message"></a>
Detailed error message describing the validation issue.
Type: String
Required: Yes

 ** Name **   <a name="workspacesinstances-Type-ValidationExceptionField-Name"></a>
Name of the field that failed validation.
Type: String
Required: Yes

 ** Reason **   <a name="workspacesinstances-Type-ValidationExceptionField-Reason"></a>
Reason for the validation failure.
Type: String
Required: Yes
