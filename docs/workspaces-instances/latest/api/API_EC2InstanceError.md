# EC2InstanceError
<a name="API_EC2InstanceError"></a>

Captures detailed error information for EC2 instance operations.

## Contents
<a name="API_EC2InstanceError_Contents"></a>

 ** EC2ErrorCode **   <a name="workspacesinstances-Type-EC2InstanceError-EC2ErrorCode"></a>
Unique error code identifying the specific EC2 instance error.
Type: String
Required: No

 ** EC2ErrorMessage **   <a name="workspacesinstances-Type-EC2InstanceError-EC2ErrorMessage"></a>
Detailed description of the EC2 instance error.
Type: String
Required: No

 ** EC2ExceptionType **   <a name="workspacesinstances-Type-EC2InstanceError-EC2ExceptionType"></a>
Type of exception encountered during EC2 instance operation.
Type: String
Required: No
