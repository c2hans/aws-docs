# EnaSrdSpecificationRequest
<a name="API_EnaSrdSpecificationRequest"></a>

Defines Elastic Network Adapter (ENA) Scalable Reliable Datagram (SRD) configuration.

## Contents
<a name="API_EnaSrdSpecificationRequest_Contents"></a>

 ** EnaSrdEnabled **   <a name="workspacesinstances-Type-EnaSrdSpecificationRequest-EnaSrdEnabled"></a>
Enables or disables ENA SRD for network performance.
Type: Boolean
Required: No

 ** EnaSrdUdpSpecification **   <a name="workspacesinstances-Type-EnaSrdSpecificationRequest-EnaSrdUdpSpecification"></a>
Configures UDP-specific ENA SRD settings.
Type: [EnaSrdUdpSpecificationRequest](API_EnaSrdUdpSpecificationRequest.md) object
Required: No
