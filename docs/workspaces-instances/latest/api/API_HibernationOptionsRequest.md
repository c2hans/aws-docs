# HibernationOptionsRequest
<a name="API_HibernationOptionsRequest"></a>

Defines hibernation configuration for the WorkSpace Instance.

## Contents
<a name="API_HibernationOptionsRequest_Contents"></a>

 ** Configured **   <a name="workspacesinstances-Type-HibernationOptionsRequest-Configured"></a>
Enables or disables instance hibernation capability.
Type: Boolean
Required: No
