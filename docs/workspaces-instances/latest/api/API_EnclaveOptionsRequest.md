# EnclaveOptionsRequest
<a name="API_EnclaveOptionsRequest"></a>

Configures AWS Nitro Enclave options for the WorkSpace Instance.

## Contents
<a name="API_EnclaveOptionsRequest_Contents"></a>

 ** Enabled **   <a name="workspacesinstances-Type-EnclaveOptionsRequest-Enabled"></a>
Enables or disables AWS Nitro Enclaves for enhanced security.
Type: Boolean
Required: No
