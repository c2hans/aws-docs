# InstanceIpv6Address
<a name="API_InstanceIpv6Address"></a>

Represents an IPv6 address configuration for a WorkSpace Instance.

## Contents
<a name="API_InstanceIpv6Address_Contents"></a>

 ** Ipv6Address **   <a name="workspacesinstances-Type-InstanceIpv6Address-Ipv6Address"></a>
Specific IPv6 address assigned to the instance.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 128.
Required: No

 ** IsPrimaryIpv6 **   <a name="workspacesinstances-Type-InstanceIpv6Address-IsPrimaryIpv6"></a>
Indicates if this is the primary IPv6 address for the instance.
Type: Boolean
Required: No
