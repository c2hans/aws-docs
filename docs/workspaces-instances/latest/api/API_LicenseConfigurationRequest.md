# LicenseConfigurationRequest
<a name="API_LicenseConfigurationRequest"></a>

Specifies license configuration for WorkSpace Instance.

## Contents
<a name="API_LicenseConfigurationRequest_Contents"></a>

 ** LicenseConfigurationArn **   <a name="workspacesinstances-Type-LicenseConfigurationRequest-LicenseConfigurationArn"></a>
ARN of the license configuration for the WorkSpace Instance.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Pattern: `arn:.*`
Required: No
