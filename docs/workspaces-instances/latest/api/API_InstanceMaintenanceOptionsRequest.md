# InstanceMaintenanceOptionsRequest
<a name="API_InstanceMaintenanceOptionsRequest"></a>

Configures automatic maintenance settings for WorkSpace Instance.

## Contents
<a name="API_InstanceMaintenanceOptionsRequest_Contents"></a>

 ** AutoRecovery **   <a name="workspacesinstances-Type-InstanceMaintenanceOptionsRequest-AutoRecovery"></a>
Enables or disables automatic instance recovery.
Type: String
Valid Values: `disabled | default`
Required: No
