# Ipv4PrefixSpecificationRequest
<a name="API_Ipv4PrefixSpecificationRequest"></a>

Specifies IPv4 prefix configuration for network interfaces.

## Contents
<a name="API_Ipv4PrefixSpecificationRequest_Contents"></a>

 ** Ipv4Prefix **   <a name="workspacesinstances-Type-Ipv4PrefixSpecificationRequest-Ipv4Prefix"></a>
Specific IPv4 prefix for network interface configuration.
Type: String
Pattern: `.*(?:(?:\d|[01]?\d\d|2[0-4]\d|25[0-5])\.){3}(?:25[0-5]|2[0-4]\d|[01]?\d\d|\d)(?:/\d{1,2})?.*`
Required: No
