# IamInstanceProfileSpecification
<a name="API_IamInstanceProfileSpecification"></a>

Defines IAM instance profile configuration for WorkSpace Instance.

## Contents
<a name="API_IamInstanceProfileSpecification_Contents"></a>

 ** Arn **   <a name="workspacesinstances-Type-IamInstanceProfileSpecification-Arn"></a>
Amazon Resource Name (ARN) of the IAM instance profile.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 2048.
Pattern: `arn:.*`
Required: No

 ** Name **   <a name="workspacesinstances-Type-IamInstanceProfileSpecification-Name"></a>
Name of the IAM instance profile.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 64.
Required: No
