# AWS Toolkit for Eclipse Documentation

The AWS Toolkit for Eclipse is an open source plug-in for the Eclipse Java integrated development environment (IDE). The Toolkit for Eclipse makes it easier for developers to develop, debug, and deploy Java applications that use Amazon Web Services.

- [User Guide](/toolkit-for-eclipse/v1/user-guide/): Introduces you to the AWS Toolkit for Eclipse and provides tips and links to advanced features and resources.
- [Code Sample Catalog](/code-samples/latest/catalog/welcome.html): Contains code examples and other types of examples to help accelerate your development of applications that work with AWS services. The examples show how to perform specific tasks for AWS services using various programming languages and supported technologies. Note that the PDF has a large file size.
