# CallbackTimedOutDetails
<a name="API_CallbackTimedOutDetails"></a>

Contains details about a callback operation that timed out, including timeout duration and any partial results.

## Contents
<a name="API_CallbackTimedOutDetails_Contents"></a>

 ** Error **   <a name="lambda-Type-CallbackTimedOutDetails-Error"></a>
Details about the callback timeout.
Type: [EventError](API_EventError.md) object
Required: Yes
