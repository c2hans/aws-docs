# TraceHeader
<a name="API_TraceHeader"></a>

Contains trace headers for the Lambda durable execution.

## Contents
<a name="API_TraceHeader_Contents"></a>

 ** XAmznTraceId **   <a name="lambda-Type-TraceHeader-XAmznTraceId"></a>
The AWS X-Ray trace header associated with the durable execution.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 8192.
Required: No
