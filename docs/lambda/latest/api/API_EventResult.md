# EventResult
<a name="API_EventResult"></a>

Result information for an event.

## Contents
<a name="API_EventResult_Contents"></a>

 ** Payload **   <a name="lambda-Type-EventResult-Payload"></a>
The result payload.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 6291456.
Required: No

 ** Truncated **   <a name="lambda-Type-EventResult-Truncated"></a>
Indicates if the error payload was truncated due to size limits.
Type: Boolean
Required: No
