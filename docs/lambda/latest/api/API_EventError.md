# EventError
<a name="API_EventError"></a>

Error information for an event.

## Contents
<a name="API_EventError_Contents"></a>

 ** Payload **   <a name="lambda-Type-EventError-Payload"></a>
The error payload.
Type: [ErrorObject](API_ErrorObject.md) object
Required: No

 ** Truncated **   <a name="lambda-Type-EventError-Truncated"></a>
Indicates if the error payload was truncated due to size limits.
Type: Boolean
Required: No
