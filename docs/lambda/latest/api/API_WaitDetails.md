# WaitDetails
<a name="API_WaitDetails"></a>

Details about a wait operation.

## Contents
<a name="API_WaitDetails_Contents"></a>

 ** ScheduledEndTimestamp **   <a name="lambda-Type-WaitDetails-ScheduledEndTimestamp"></a>
The date and time when the wait operation is scheduled to complete, in [ISO-8601 format](https://www.w3.org/TR/NOTE-datetime) (YYYY-MM-DDThh:mm:ss.sTZD).
Type: Timestamp
Required: No
