# WaitOptions
<a name="API_WaitOptions"></a>

Specifies how long to pause the durable execution.

## Contents
<a name="API_WaitOptions_Contents"></a>

 ** WaitSeconds **   <a name="lambda-Type-WaitOptions-WaitSeconds"></a>
The duration to wait, in seconds.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 31622400.
Required: No
