# StepOptions
<a name="API_StepOptions"></a>

Configuration options for a step operation.

## Contents
<a name="API_StepOptions_Contents"></a>

 ** NextAttemptDelaySeconds **   <a name="lambda-Type-StepOptions-NextAttemptDelaySeconds"></a>
The delay in seconds before the next retry attempt.
Type: Integer
Valid Range: Minimum value of 1. Maximum value of 31622400.
Required: No
