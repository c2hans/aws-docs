# RuntimeVersionError
<a name="API_RuntimeVersionError"></a>

Any error returned when the runtime version information for the function could not be retrieved.

<a name="API_RuntimeVersionError_Contents"></a>

 ** ErrorCode **   <a name="lambda-Type-RuntimeVersionError-ErrorCode"></a>
The error code.
Type: String
Required: No

 ** Message **   <a name="lambda-Type-RuntimeVersionError-Message"></a>
The error message.
Type: String
Required: No
