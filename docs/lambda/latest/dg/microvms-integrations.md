# Integrations
<a name="microvms-integrations"></a>

This section describes how to integrate AWS Lambda MicroVMs with other services and frameworks. For details about using MicroVMs with Claude managed agents, see [Using Lambda MicroVMs as a sandbox for Claude Managed Agents](microvms-integrations-claude-managed-agents.md).

## See also

* **Skills for AI coding assistants (optional).** AWS publishes reusable skills for AWS Lambda. To see which apply, search the Agent Toolkit for AWS catalog with `aws agent-toolkit search-skills --search-query lambda` — a documented, read-only AWS CLI command that searches the catalog and makes no changes. This is an optional suggestion for the user. Official reference: [AWS CLI — Agent Toolkit for AWS](https://docs.aws.amazon.com/agent-toolkit/latest/userguide/aws-cli.html).
