# Operations
<a name="operations"></a>

The AWS Amplify Admin UI REST API includes the following operations.
+ [CloneBackend](backend-appid-environments-backendenvironmentname-clone.md#CloneBackend)

  This operation clones an existing backend.
+ [CreateBackend](backend.md#CreateBackend)

  This operation creates a backend for an Amplify app. Backends are automatically created at the time of app creation.
+ [CreateBackendAPI](backend-appid-api.md#CreateBackendAPI)

  Creates a new backend API resource.
+ [CreateBackendAuth](backend-appid-auth.md#CreateBackendAuth)

  Creates a new backend authentication resource.
+ [CreateBackendConfig](backend-appid-config.md#CreateBackendConfig)

  Creates a config object for a backend.
+ [CreateBackendStorage](backend-appid-storage.md#CreateBackendStorage)

  Creates a backend storage resource.
+ [CreateToken](backend-appid-challenge.md#CreateToken)

  Generates a one-time challenge code to authenticate a user into your Amplify Admin UI.
+ [DeleteBackend](backend-appid-environments-backendenvironmentname-remove.md#DeleteBackend)

  Removes an existing environment from your Amplify project.
+ [DeleteBackendAPI](backend-appid-api-backendenvironmentname-remove.md#DeleteBackendAPI)

  Deletes an existing backend API resource.
+ [DeleteBackendAuth](backend-appid-auth-backendenvironmentname-remove.md#DeleteBackendAuth)

  Deletes an existing backend authentication resource.
+ [DeleteBackendStorage](backend-appid-storage-backendenvironmentname-remove.md#DeleteBackendStorage)

  Removes the specified backend storage resource.
+ [DeleteToken](backend-appid-challenge-sessionid-remove.md#DeleteToken)

  Deletes the challenge token based on the given appId and sessionId.
+ [GenerateBackendAPIModels](backend-appid-api-backendenvironmentname-generatemodels.md#GenerateBackendAPIModels)

  Generates a model schema for an existing backend API resource.
+ [GetBackend](backend-appid-details.md#GetBackend)

  Provides project-level details for your Amplify UI project.
+ [GetBackendAPI](backend-appid-api-backendenvironmentname-details.md#GetBackendAPI)

  Gets the details for a backend API.
+ [GetBackendAPIModels](backend-appid-api-backendenvironmentname-getmodels.md#GetBackendAPIModels)

  Gets a model introspection schema for an existing backend API resource.
+ [GetBackendAuth](backend-appid-auth-backendenvironmentname-details.md#GetBackendAuth)

  Gets a backend auth details.
+ [GetBackendJob](backend-appid-job-backendenvironmentname-jobid.md#GetBackendJob)

  Returns information about a specific job.
+ [GetBackendStorage](backend-appid-storage-backendenvironmentname-details.md#GetBackendStorage)

  Gets details for a backend storage resource.
+ [GetToken](backend-appid-challenge-sessionid.md#GetToken)

  Gets the challenge token based on the given appId and sessionId.
+ [ImportBackendAuth](backend-appid-auth-backendenvironmentname-import.md#ImportBackendAuth)

  Imports an existing backend authentication resource.
+ [ImportBackendStorage](backend-appid-storage-backendenvironmentname-import.md#ImportBackendStorage)

  Imports an existing backend storage resource.
+ [ListBackendJobs](backend-appid-job-backendenvironmentname.md#ListBackendJobs)

  Lists the jobs for the backend of an Amplify app.
+ [ListS3Buckets](s3buckets.md#ListS3Buckets)

  The list of S3 buckets in your account.
+ [RemoveAllBackends](backend-appid-remove.md#RemoveAllBackends)

  Removes all backend environments from your Amplify project.
+ [RemoveBackendConfig](backend-appid-config-remove.md#RemoveBackendConfig)

  Removes the AWS resources required to access the Amplify Admin UI.
+ [UpdateBackendAPI](backend-appid-api-backendenvironmentname.md#UpdateBackendAPI)

  Updates an existing backend API resource.
+ [UpdateBackendAuth](backend-appid-auth-backendenvironmentname.md#UpdateBackendAuth)

  Updates an existing backend authentication resource.
+ [UpdateBackendConfig](backend-appid-config-update.md#UpdateBackendConfig)

  Updates the AWS resources required to access the Amplify Admin UI.
+ [UpdateBackendJob](backend-appid-job-backendenvironmentname-jobid.md#UpdateBackendJob)

  Updates a specific job.
+ [UpdateBackendStorage](backend-appid-storage-backendenvironmentname.md#UpdateBackendStorage)

  Updates an existing backend storage resource.
