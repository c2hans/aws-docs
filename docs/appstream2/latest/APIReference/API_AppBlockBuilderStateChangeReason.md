# AppBlockBuilderStateChangeReason
<a name="API_AppBlockBuilderStateChangeReason"></a>

Describes the reason why the last app block builder state change occurred.

## Contents
<a name="API_AppBlockBuilderStateChangeReason_Contents"></a>

 ** Code **   <a name="WorkSpacesApplications-Type-AppBlockBuilderStateChangeReason-Code"></a>
The state change reason code.
Type: String
Valid Values: `INTERNAL_ERROR`
Required: No

 ** Message **   <a name="WorkSpacesApplications-Type-AppBlockBuilderStateChangeReason-Message"></a>
The state change reason message.
Type: String
Length Constraints: Minimum length of 1.
Required: No
