# ThemeFooterLink
<a name="API_ThemeFooterLink"></a>

The website links that display in the catalog page footer.

## Contents
<a name="API_ThemeFooterLink_Contents"></a>

 ** DisplayName **   <a name="WorkSpacesApplications-Type-ThemeFooterLink-DisplayName"></a>
The name of the websites that display in the catalog page footer.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 300.
Pattern: `^[-@./#&+\w\s]*$`
Required: No

 ** FooterLinkURL **   <a name="WorkSpacesApplications-Type-ThemeFooterLink-FooterLinkURL"></a>
The URL of the websites that display in the catalog page footer.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 1000.
Required: No
