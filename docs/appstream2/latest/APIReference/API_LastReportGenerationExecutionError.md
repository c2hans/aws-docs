# LastReportGenerationExecutionError
<a name="API_LastReportGenerationExecutionError"></a>

Describes the error that is returned when a usage report can't be generated.

## Contents
<a name="API_LastReportGenerationExecutionError_Contents"></a>

 ** ErrorCode **   <a name="WorkSpacesApplications-Type-LastReportGenerationExecutionError-ErrorCode"></a>
The error code for the error that is returned when a usage report can't be generated.
Type: String
Valid Values: `RESOURCE_NOT_FOUND | ACCESS_DENIED | INTERNAL_SERVICE_ERROR`
Required: No

 ** ErrorMessage **   <a name="WorkSpacesApplications-Type-LastReportGenerationExecutionError-ErrorMessage"></a>
The error message for the error that is returned when a usage report can't be generated.
Type: String
Length Constraints: Minimum length of 1.
Required: No
