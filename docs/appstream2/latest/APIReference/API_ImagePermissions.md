# ImagePermissions
<a name="API_ImagePermissions"></a>

Describes the permissions for an image.

## Contents
<a name="API_ImagePermissions_Contents"></a>

 ** allowFleet **   <a name="WorkSpacesApplications-Type-ImagePermissions-allowFleet"></a>
Indicates whether the image can be used for a fleet.
Type: Boolean
Required: No

 ** allowImageBuilder **   <a name="WorkSpacesApplications-Type-ImagePermissions-allowImageBuilder"></a>
Indicates whether the image can be used for an image builder.
Type: Boolean
Required: No
