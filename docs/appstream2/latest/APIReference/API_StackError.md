# StackError
<a name="API_StackError"></a>

Describes a stack error.

## Contents
<a name="API_StackError_Contents"></a>

 ** ErrorCode **   <a name="WorkSpacesApplications-Type-StackError-ErrorCode"></a>
The error code.
Type: String
Valid Values: `STORAGE_CONNECTOR_ERROR | INTERNAL_SERVICE_ERROR`
Required: No

 ** ErrorMessage **   <a name="WorkSpacesApplications-Type-StackError-ErrorMessage"></a>
The error message.
Type: String
Length Constraints: Minimum length of 1.
Required: No
