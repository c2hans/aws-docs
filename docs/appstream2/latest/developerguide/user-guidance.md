# Guidance for WorkSpaces Applications Users
<a name="user-guidance"></a>

If you are an WorkSpaces Applications administrator, you can provide your users with the guidance in this section to help them get started with using WorkSpaces Applications.

If you are a user who now has access to WorkSpaces Applications, the topics in this section will help you use WorkSpaces Applications for application streaming. With WorkSpaces Applications, your administrator makes your applications available for you to access remotely, so that you don't have to install the applications on your own device. To access your applications, connect to WorkSpaces Applications and start an application streaming session.
