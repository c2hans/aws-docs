# LambdaFunctionFailedEventDetails
<a name="API_LambdaFunctionFailedEventDetails"></a>

Contains details about a Lambda function that failed during an execution.

## Contents
<a name="API_LambdaFunctionFailedEventDetails_Contents"></a>

 ** cause **   <a name="StepFunctions-Type-LambdaFunctionFailedEventDetails-cause"></a>
A more detailed explanation of the cause of the failure.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 32768.
Required: No

 ** error **   <a name="StepFunctions-Type-LambdaFunctionFailedEventDetails-error"></a>
The error code of the failure.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
