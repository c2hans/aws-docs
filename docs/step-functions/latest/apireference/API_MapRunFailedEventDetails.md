# MapRunFailedEventDetails
<a name="API_MapRunFailedEventDetails"></a>

Contains details about a Map Run failure event that occurred during a state machine execution.

## Contents
<a name="API_MapRunFailedEventDetails_Contents"></a>

 ** cause **   <a name="StepFunctions-Type-MapRunFailedEventDetails-cause"></a>
A more detailed explanation of the cause of the failure.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 32768.
Required: No

 ** error **   <a name="StepFunctions-Type-MapRunFailedEventDetails-error"></a>
The error code of the Map Run failure.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
