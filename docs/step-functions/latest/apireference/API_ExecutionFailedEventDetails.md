# ExecutionFailedEventDetails
<a name="API_ExecutionFailedEventDetails"></a>

Contains details about an execution failure event.

## Contents
<a name="API_ExecutionFailedEventDetails_Contents"></a>

 ** cause **   <a name="StepFunctions-Type-ExecutionFailedEventDetails-cause"></a>
A more detailed explanation of the cause of the failure.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 32768.
Required: No

 ** error **   <a name="StepFunctions-Type-ExecutionFailedEventDetails-error"></a>
The error code of the failure.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
