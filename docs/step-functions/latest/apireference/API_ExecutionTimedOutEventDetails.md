# ExecutionTimedOutEventDetails
<a name="API_ExecutionTimedOutEventDetails"></a>

Contains details about the execution timeout that occurred during the execution.

## Contents
<a name="API_ExecutionTimedOutEventDetails_Contents"></a>

 ** cause **   <a name="StepFunctions-Type-ExecutionTimedOutEventDetails-cause"></a>
A more detailed explanation of the cause of the timeout.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 32768.
Required: No

 ** error **   <a name="StepFunctions-Type-ExecutionTimedOutEventDetails-error"></a>
The error code of the failure.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
