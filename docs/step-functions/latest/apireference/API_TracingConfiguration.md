# TracingConfiguration
<a name="API_TracingConfiguration"></a>

Selects whether or not the state machine's AWS X-Ray tracing is enabled. Default is `false`

## Contents
<a name="API_TracingConfiguration_Contents"></a>

 ** enabled **   <a name="StepFunctions-Type-TracingConfiguration-enabled"></a>
When set to `true`, AWS X-Ray tracing is enabled.
Type: Boolean
Required: No
