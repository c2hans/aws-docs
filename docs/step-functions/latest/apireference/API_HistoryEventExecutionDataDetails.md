# HistoryEventExecutionDataDetails
<a name="API_HistoryEventExecutionDataDetails"></a>

Provides details about input or output in an execution history event.

## Contents
<a name="API_HistoryEventExecutionDataDetails_Contents"></a>

 ** truncated **   <a name="StepFunctions-Type-HistoryEventExecutionDataDetails-truncated"></a>
Indicates whether input or output was truncated in the response. Always `false` for API calls. In CloudWatch logs, the value will be true if the data is truncated due to size limits.
Type: Boolean
Required: No
