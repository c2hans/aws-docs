# CharacterOffsets
<a name="API_connect-contact-lens_CharacterOffsets"></a>

For characters that were detected as issues, where they occur in the transcript.

## Contents
<a name="API_connect-contact-lens_CharacterOffsets_Contents"></a>

 ** BeginOffsetChar **   <a name="connect-Type-connect-contact-lens_CharacterOffsets-BeginOffsetChar"></a>
The beginning of the issue.
Type: Integer
Valid Range: Minimum value of 0.
Required: Yes

 ** EndOffsetChar **   <a name="connect-Type-connect-contact-lens_CharacterOffsets-EndOffsetChar"></a>
The end of the issue.
Type: Integer
Valid Range: Minimum value of 0.
Required: Yes
