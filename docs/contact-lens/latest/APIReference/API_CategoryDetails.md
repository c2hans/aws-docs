# CategoryDetails
<a name="API_connect-contact-lens_CategoryDetails"></a>

Provides information about the category rule that was matched.

## Contents
<a name="API_connect-contact-lens_CategoryDetails_Contents"></a>

 ** PointsOfInterest **   <a name="connect-Type-connect-contact-lens_CategoryDetails-PointsOfInterest"></a>
The section of audio where the category rule was detected.
Type: Array of [PointOfInterest](API_connect-contact-lens_PointOfInterest.md) objects
Array Members: Minimum number of 0 items. Maximum number of 20 items.
Required: Yes
