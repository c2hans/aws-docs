# Amazon Simple Email Service Documentation

Amazon Simple Email Service (Amazon SES) is a reliable, scalable, and cost-effective email service. Digital marketers and application developers can use Amazon SES to send marketing, notification, and transactional emails.

## Amazon SES

- [Developer Guide](/ses/latest/dg/): Learn about Amazon SES and how to use its features through the redesigned new console experience.
- [API Reference](/ses/latest/APIReference/): Get syntax and examples for the Amazon SES API.
- [AWS AWS CLI Reference for Amazon SES](/cli/latest/reference/ses/index.html): Describes the AWS AWS CLI commands for the Amazon SES API.
- [API v2 Reference](/ses/latest/APIReference-V2/): Get syntax and examples for version 2 of the Amazon SES API.
- [AWS AWS CLI Reference for Amazon SES v2](/cli/latest/reference/sesv2/index.html): Describes the AWS AWS CLI commands for version 2 of the Amazon SES API.
