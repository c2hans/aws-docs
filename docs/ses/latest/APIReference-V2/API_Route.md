# Route
<a name="API_Route"></a>

An object which contains an AWS-Region and routing status.

## Contents
<a name="API_Route_Contents"></a>

 ** Region **   <a name="SES-Type-Route-Region"></a>
The name of an AWS-Region.
Type: String
Required: Yes
