# SmimeSigningScheme
<a name="API_SmimeSigningScheme"></a>

Specifies that Amazon SES API v2 signs messages sent with the configuration set using S/MIME.

## Contents
<a name="API_SmimeSigningScheme_Contents"></a>

 ** SignatureFormat **   <a name="SES-Type-SmimeSigningScheme-SignatureFormat"></a>
The format of the S/MIME signature that Amazon SES API v2 applies to messages.
Type: String
Valid Values: `DETACHED`
Required: No
