# TemplateMetadata
<a name="API_TemplateMetadata"></a>

Contains information about an email template.

## Contents
<a name="API_TemplateMetadata_Contents"></a>

 ** CreatedTimestamp **
The time and date the template was created.
Type: Timestamp
Required: No

 ** Name **
The name of the template.
Type: String
Required: No
