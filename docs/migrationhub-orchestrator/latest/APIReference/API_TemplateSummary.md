# TemplateSummary
<a name="API_TemplateSummary"></a>

The summary of the template.

## Contents
<a name="API_TemplateSummary_Contents"></a>

 ** arn **   <a name="migrationhuborchestrator-Type-TemplateSummary-arn"></a>
The Amazon Resource Name (ARN) of the template.
Type: String
Required: No

 ** description **   <a name="migrationhuborchestrator-Type-TemplateSummary-description"></a>
The description of the template.
Type: String
Required: No

 ** id **   <a name="migrationhuborchestrator-Type-TemplateSummary-id"></a>
The ID of the template.
Type: String
Required: No

 ** name **   <a name="migrationhuborchestrator-Type-TemplateSummary-name"></a>
The name of the template.
Type: String
Required: No
