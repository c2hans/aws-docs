# TemplateStepGroupSummary
<a name="API_TemplateStepGroupSummary"></a>

The summary of the step group in the template.

## Contents
<a name="API_TemplateStepGroupSummary_Contents"></a>

 ** id **   <a name="migrationhuborchestrator-Type-TemplateStepGroupSummary-id"></a>
The ID of the step group.
Type: String
Required: No

 ** name **   <a name="migrationhuborchestrator-Type-TemplateStepGroupSummary-name"></a>
The name of the step group.
Type: String
Required: No

 ** next **   <a name="migrationhuborchestrator-Type-TemplateStepGroupSummary-next"></a>
The next step group.
Type: Array of strings
Length Constraints: Minimum length of 0. Maximum length of 500.
Required: No

 ** previous **   <a name="migrationhuborchestrator-Type-TemplateStepGroupSummary-previous"></a>
The previous step group.
Type: Array of strings
Length Constraints: Minimum length of 0. Maximum length of 500.
Required: No
