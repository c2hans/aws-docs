# EdiPartyName
<a name="API_EdiPartyName"></a>

Describes an Electronic Data Interchange (EDI) entity as described in as defined in [Subject Alternative Name](https://datatracker.ietf.org/doc/html/rfc5280) in RFC 5280.

## Contents
<a name="API_EdiPartyName_Contents"></a>

 ** PartyName **   <a name="privateca-Type-EdiPartyName-PartyName"></a>
Specifies the party name.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: Yes

 ** NameAssigner **   <a name="privateca-Type-EdiPartyName-NameAssigner"></a>
Specifies the name assigner.
Type: String
Length Constraints: Minimum length of 0. Maximum length of 256.
Required: No
