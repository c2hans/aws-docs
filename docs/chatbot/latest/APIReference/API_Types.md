# Data Types
<a name="API_Types"></a>

The AWS Chatbot API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [AccountPreferences](API_AccountPreferences.md)
+  [AssociationListing](API_AssociationListing.md)
+  [ChimeWebhookConfiguration](API_ChimeWebhookConfiguration.md)
+  [ConfiguredTeam](API_ConfiguredTeam.md)
+  [CustomAction](API_CustomAction.md)
+  [CustomActionAttachment](API_CustomActionAttachment.md)
+  [CustomActionAttachmentCriteria](API_CustomActionAttachmentCriteria.md)
+  [CustomActionDefinition](API_CustomActionDefinition.md)
+  [SlackChannelConfiguration](API_SlackChannelConfiguration.md)
+  [SlackUserIdentity](API_SlackUserIdentity.md)
+  [SlackWorkspace](API_SlackWorkspace.md)
+  [Tag](API_Tag.md)
+  [TeamsChannelConfiguration](API_TeamsChannelConfiguration.md)
+  [TeamsUserIdentity](API_TeamsUserIdentity.md)
