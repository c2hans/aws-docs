# AwsJobAbortConfig
<a name="API_AwsJobAbortConfig"></a>

The criteria that determine when and how a job abort takes place.

## Contents
<a name="API_AwsJobAbortConfig_Contents"></a>

 ** abortCriteriaList **   <a name="iot-Type-AwsJobAbortConfig-abortCriteriaList"></a>
The list of criteria that determine when and how to abort the job.
Type: Array of [AwsJobAbortCriteria](API_AwsJobAbortCriteria.md) objects
Array Members: Minimum number of 1 item.
Required: Yes
