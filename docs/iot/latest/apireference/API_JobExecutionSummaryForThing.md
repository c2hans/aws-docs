# JobExecutionSummaryForThing
<a name="API_JobExecutionSummaryForThing"></a>

The job execution summary for a thing.

## Contents
<a name="API_JobExecutionSummaryForThing_Contents"></a>

 ** jobExecutionSummary **   <a name="iot-Type-JobExecutionSummaryForThing-jobExecutionSummary"></a>
Contains a subset of information about a job execution.
Type: [JobExecutionSummary](API_JobExecutionSummary.md) object
Required: No

 ** jobId **   <a name="iot-Type-JobExecutionSummaryForThing-jobId"></a>
The unique identifier you assigned to this job when it was created.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 64.
Pattern: `[a-zA-Z0-9_-]+`
Required: No
