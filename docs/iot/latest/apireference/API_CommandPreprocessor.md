# CommandPreprocessor
<a name="API_CommandPreprocessor"></a>

Configuration that determines how the `payloadTemplate` is processed by the service to generate the final payload sent to devices at `StartCommandExecution` API invocation.

## Contents
<a name="API_CommandPreprocessor_Contents"></a>

 ** awsJsonSubstitution **   <a name="iot-Type-CommandPreprocessor-awsJsonSubstitution"></a>
Configuration for the JSON substitution preprocessor.
Type: [AwsJsonSubstitutionCommandPreprocessorConfig](API_AwsJsonSubstitutionCommandPreprocessorConfig.md) object
Required: No
