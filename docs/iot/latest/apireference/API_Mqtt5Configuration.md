# Mqtt5Configuration
<a name="API_Mqtt5Configuration"></a>

The configuration to add user-defined properties to enrich MQTT 5 messages.

## Contents
<a name="API_Mqtt5Configuration_Contents"></a>

 ** propagatingAttributes **   <a name="iot-Type-Mqtt5Configuration-propagatingAttributes"></a>
An object that represents the propagating thing attributes and the connection attributes.
Type: Array of [PropagatingAttribute](API_PropagatingAttribute.md) objects
Required: No
