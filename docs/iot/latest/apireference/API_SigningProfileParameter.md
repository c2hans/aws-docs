# SigningProfileParameter
<a name="API_SigningProfileParameter"></a>

Describes the code-signing profile.

## Contents
<a name="API_SigningProfileParameter_Contents"></a>

 ** certificateArn **   <a name="iot-Type-SigningProfileParameter-certificateArn"></a>
Certificate ARN.
Type: String
Required: No

 ** certificatePathOnDevice **   <a name="iot-Type-SigningProfileParameter-certificatePathOnDevice"></a>
The location of the code-signing certificate on your device.
Type: String
Required: No

 ** platform **   <a name="iot-Type-SigningProfileParameter-platform"></a>
The hardware platform of your device.
Type: String
Required: No
