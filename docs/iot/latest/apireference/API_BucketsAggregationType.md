# BucketsAggregationType
<a name="API_BucketsAggregationType"></a>

The type of bucketed aggregation performed.

## Contents
<a name="API_BucketsAggregationType_Contents"></a>

 ** termsAggregation **   <a name="iot-Type-BucketsAggregationType-termsAggregation"></a>
Performs an aggregation that will return a list of buckets. The list of buckets is a ranked list of the number of occurrences of an aggregation field value.
Type: [TermsAggregation](API_TermsAggregation.md) object
Required: No
