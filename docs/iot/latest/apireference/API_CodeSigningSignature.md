# CodeSigningSignature
<a name="API_CodeSigningSignature"></a>

Describes the signature for a file.

## Contents
<a name="API_CodeSigningSignature_Contents"></a>

 ** inlineDocument **   <a name="iot-Type-CodeSigningSignature-inlineDocument"></a>
A base64 encoded binary representation of the code signing signature.
Type: Base64-encoded binary data object
Required: No
