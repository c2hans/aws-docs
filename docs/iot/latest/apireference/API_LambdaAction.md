# LambdaAction
<a name="API_LambdaAction"></a>

Describes an action to invoke a Lambda function.

## Contents
<a name="API_LambdaAction_Contents"></a>

 ** functionArn **   <a name="iot-Type-LambdaAction-functionArn"></a>
The ARN of the Lambda function.
Type: String
Required: Yes
