# ViolationEventOccurrenceRange
<a name="API_ViolationEventOccurrenceRange"></a>

 Specifies the time period of which violation events occurred between.

## Contents
<a name="API_ViolationEventOccurrenceRange_Contents"></a>

 ** endTime **   <a name="iot-Type-ViolationEventOccurrenceRange-endTime"></a>
 The end date and time of a time period in which violation events occurred.
Type: Timestamp
Required: Yes

 ** startTime **   <a name="iot-Type-ViolationEventOccurrenceRange-startTime"></a>
 The start date and time of a time period in which violation events occurred.
Type: Timestamp
Required: Yes
