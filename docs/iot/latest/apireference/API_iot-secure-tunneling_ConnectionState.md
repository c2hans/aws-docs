# ConnectionState
<a name="API_iot-secure-tunneling_ConnectionState"></a>

The state of a connection.

## Contents
<a name="API_iot-secure-tunneling_ConnectionState_Contents"></a>

 ** lastUpdatedAt **   <a name="iot-Type-iot-secure-tunneling_ConnectionState-lastUpdatedAt"></a>
The last time the connection status was updated.
Type: Timestamp
Required: No

 ** status **   <a name="iot-Type-iot-secure-tunneling_ConnectionState-status"></a>
The connection status of the tunnel. Valid values are `CONNECTED` and `DISCONNECTED`.
Type: String
Valid Values: `CONNECTED | DISCONNECTED`
Required: No
