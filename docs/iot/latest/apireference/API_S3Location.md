# S3Location
<a name="API_S3Location"></a>

The S3 location.

## Contents
<a name="API_S3Location_Contents"></a>

 ** bucket **   <a name="iot-Type-S3Location-bucket"></a>
The S3 bucket.
Type: String
Length Constraints: Minimum length of 1.
Required: No

 ** key **   <a name="iot-Type-S3Location-key"></a>
The S3 key.
Type: String
Length Constraints: Minimum length of 1.
Required: No

 ** version **   <a name="iot-Type-S3Location-version"></a>
The S3 bucket version.
Type: String
Required: No
