# AuthorizerSummary
<a name="API_AuthorizerSummary"></a>

The authorizer summary.

## Contents
<a name="API_AuthorizerSummary_Contents"></a>

 ** authorizerArn **   <a name="iot-Type-AuthorizerSummary-authorizerArn"></a>
The authorizer ARN.
Type: String
Length Constraints: Maximum length of 2048.
Required: No

 ** authorizerName **   <a name="iot-Type-AuthorizerSummary-authorizerName"></a>
The authorizer name.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `[\w=,@-]+`
Required: No
