# JobExecutionSummaryForJob
<a name="API_JobExecutionSummaryForJob"></a>

Contains a summary of information about job executions for a specific job.

## Contents
<a name="API_JobExecutionSummaryForJob_Contents"></a>

 ** jobExecutionSummary **   <a name="iot-Type-JobExecutionSummaryForJob-jobExecutionSummary"></a>
Contains a subset of information about a job execution.
Type: [JobExecutionSummary](API_JobExecutionSummary.md) object
Required: No

 ** thingArn **   <a name="iot-Type-JobExecutionSummaryForJob-thingArn"></a>
The ARN of the thing on which the job execution is running.
Type: String
Required: No
