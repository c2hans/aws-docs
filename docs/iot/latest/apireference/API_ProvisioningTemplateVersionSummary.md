# ProvisioningTemplateVersionSummary
<a name="API_ProvisioningTemplateVersionSummary"></a>

A summary of information about a fleet provision template version.

## Contents
<a name="API_ProvisioningTemplateVersionSummary_Contents"></a>

 ** creationDate **   <a name="iot-Type-ProvisioningTemplateVersionSummary-creationDate"></a>
The date when the provisioning template version was created
Type: Timestamp
Required: No

 ** isDefaultVersion **   <a name="iot-Type-ProvisioningTemplateVersionSummary-isDefaultVersion"></a>
True if the provisioning template version is the default version, otherwise false.
Type: Boolean
Required: No

 ** versionId **   <a name="iot-Type-ProvisioningTemplateVersionSummary-versionId"></a>
The ID of the fleet provisioning template version.
Type: Integer
Required: No
