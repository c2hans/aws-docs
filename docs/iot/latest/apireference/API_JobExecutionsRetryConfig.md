# JobExecutionsRetryConfig
<a name="API_JobExecutionsRetryConfig"></a>

The configuration that determines how many retries are allowed for each failure type for a job.

## Contents
<a name="API_JobExecutionsRetryConfig_Contents"></a>

 ** criteriaList **   <a name="iot-Type-JobExecutionsRetryConfig-criteriaList"></a>
The list of criteria that determines how many retries are allowed for each failure type for a job.
Type: Array of [RetryCriteria](API_RetryCriteria.md) objects
Array Members: Minimum number of 1 item. Maximum number of 2 items.
Required: Yes
