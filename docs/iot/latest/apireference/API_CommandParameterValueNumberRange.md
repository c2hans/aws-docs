# CommandParameterValueNumberRange
<a name="API_CommandParameterValueNumberRange"></a>

The numerical range value type to compare a command parameter value against.

## Contents
<a name="API_CommandParameterValueNumberRange_Contents"></a>

 ** max **   <a name="iot-Type-CommandParameterValueNumberRange-max"></a>
The maximum value of a numerical range of a command parameter value.
Type: String
Length Constraints: Minimum length of 1.
Required: Yes

 ** min **   <a name="iot-Type-CommandParameterValueNumberRange-min"></a>
The minimum value of a numerical range of a command parameter value.
Type: String
Length Constraints: Minimum length of 1.
Required: Yes
