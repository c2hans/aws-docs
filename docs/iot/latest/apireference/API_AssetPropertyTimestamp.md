# AssetPropertyTimestamp
<a name="API_AssetPropertyTimestamp"></a>

An asset property timestamp entry containing the following information.

## Contents
<a name="API_AssetPropertyTimestamp_Contents"></a>

 ** timeInSeconds **   <a name="iot-Type-AssetPropertyTimestamp-timeInSeconds"></a>
A string that contains the time in seconds since epoch. Accepts substitution templates.
Type: String
Required: Yes

 ** offsetInNanos **   <a name="iot-Type-AssetPropertyTimestamp-offsetInNanos"></a>
Optional. A string that contains the nanosecond time offset. Accepts substitution templates.
Type: String
Required: No
