# HttpAuthorization
<a name="API_HttpAuthorization"></a>

The authorization method used to send messages.

## Contents
<a name="API_HttpAuthorization_Contents"></a>

 ** sigv4 **   <a name="iot-Type-HttpAuthorization-sigv4"></a>
Use Sig V4 authorization. For more information, see [Signature Version 4 Signing Process](https://docs.aws.amazon.com/general/latest/gr/signature-version-4.html).
Type: [SigV4Authorization](API_SigV4Authorization.md) object
Required: No
