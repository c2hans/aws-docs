# HttpActionHeader
<a name="API_HttpActionHeader"></a>

The HTTP action header.

## Contents
<a name="API_HttpActionHeader_Contents"></a>

 ** key **   <a name="iot-Type-HttpActionHeader-key"></a>
The HTTP header key.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 256.
Required: Yes

 ** value **   <a name="iot-Type-HttpActionHeader-value"></a>
The HTTP header value. Substitution templates are supported.
Type: String
Required: Yes
