# SecurityProfileTargetMapping
<a name="API_SecurityProfileTargetMapping"></a>

Information about a security profile and the target associated with it.

## Contents
<a name="API_SecurityProfileTargetMapping_Contents"></a>

 ** securityProfileIdentifier **   <a name="iot-Type-SecurityProfileTargetMapping-securityProfileIdentifier"></a>
Information that identifies the security profile.
Type: [SecurityProfileIdentifier](API_SecurityProfileIdentifier.md) object
Required: No

 ** target **   <a name="iot-Type-SecurityProfileTargetMapping-target"></a>
Information about the target (thing group) associated with the security profile.
Type: [SecurityProfileTarget](API_SecurityProfileTarget.md) object
Required: No
