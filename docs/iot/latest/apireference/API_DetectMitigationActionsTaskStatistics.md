# DetectMitigationActionsTaskStatistics
<a name="API_DetectMitigationActionsTaskStatistics"></a>

 The statistics of a mitigation action task.

## Contents
<a name="API_DetectMitigationActionsTaskStatistics_Contents"></a>

 ** actionsExecuted **   <a name="iot-Type-DetectMitigationActionsTaskStatistics-actionsExecuted"></a>
 The actions that were performed.
Type: Long
Required: No

 ** actionsFailed **   <a name="iot-Type-DetectMitigationActionsTaskStatistics-actionsFailed"></a>
 The actions that failed.
Type: Long
Required: No

 ** actionsSkipped **   <a name="iot-Type-DetectMitigationActionsTaskStatistics-actionsSkipped"></a>
 The actions that were skipped.
Type: Long
Required: No
