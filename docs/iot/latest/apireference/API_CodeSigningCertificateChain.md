# CodeSigningCertificateChain
<a name="API_CodeSigningCertificateChain"></a>

Describes the certificate chain being used when code signing a file.

## Contents
<a name="API_CodeSigningCertificateChain_Contents"></a>

 ** certificateName **   <a name="iot-Type-CodeSigningCertificateChain-certificateName"></a>
The name of the certificate.
Type: String
Required: No

 ** inlineDocument **   <a name="iot-Type-CodeSigningCertificateChain-inlineDocument"></a>
A base64 encoded binary representation of the code signing certificate chain.
Type: String
Required: No
