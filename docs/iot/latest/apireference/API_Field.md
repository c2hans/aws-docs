# Field
<a name="API_Field"></a>

Describes the name and data type at a field.

## Contents
<a name="API_Field_Contents"></a>

 ** name **   <a name="iot-Type-Field-name"></a>
The name of the field.
Type: String
Required: No

 ** type **   <a name="iot-Type-Field-type"></a>
The data type of the field.
Type: String
Valid Values: `Number | String | Boolean`
Required: No
