# ClientCertificateConfig
<a name="API_ClientCertificateConfig"></a>

An object that speciﬁes the client certificate conﬁguration for a domain.

## Contents
<a name="API_ClientCertificateConfig_Contents"></a>

 ** clientCertificateCallbackArn **   <a name="iot-Type-ClientCertificateConfig-clientCertificateCallbackArn"></a>
The ARN of the Lambda function that AWS IoT invokes after mutual TLS authentication during the connection.
Type: String
Length Constraints: Maximum length of 2048.
Pattern: `[\s\S]*`
Required: No
