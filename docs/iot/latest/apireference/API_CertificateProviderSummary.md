# CertificateProviderSummary
<a name="API_CertificateProviderSummary"></a>

The certificate provider summary.

## Contents
<a name="API_CertificateProviderSummary_Contents"></a>

 ** certificateProviderArn **   <a name="iot-Type-CertificateProviderSummary-certificateProviderArn"></a>
The ARN of the certificate provider.
Type: String
Length Constraints: Maximum length of 2048.
Required: No

 ** certificateProviderName **   <a name="iot-Type-CertificateProviderSummary-certificateProviderName"></a>
The name of the certificate provider.
Type: String
Length Constraints: Minimum length of 1. Maximum length of 128.
Pattern: `[\w=,@-]+`
Required: No
