# SigV4Authorization
<a name="API_SigV4Authorization"></a>

For more information, see [Signature Version 4 signing process](https://docs.aws.amazon.com/general/latest/gr/signature-version-4.html).

## Contents
<a name="API_SigV4Authorization_Contents"></a>

 ** roleArn **   <a name="iot-Type-SigV4Authorization-roleArn"></a>
The ARN of the signing role.
Type: String
Required: Yes

 ** serviceName **   <a name="iot-Type-SigV4Authorization-serviceName"></a>
The service name to use while signing with Sig V4.
Type: String
Required: Yes

 ** signingRegion **   <a name="iot-Type-SigV4Authorization-signingRegion"></a>
The signing region.
Type: String
Required: Yes
