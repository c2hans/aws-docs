# Data Types
<a name="API_Types"></a>

The AWS Amplify API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [App](API_App.md)
+  [Artifact](API_Artifact.md)
+  [AutoBranchCreationConfig](API_AutoBranchCreationConfig.md)
+  [Backend](API_Backend.md)
+  [BackendEnvironment](API_BackendEnvironment.md)
+  [Branch](API_Branch.md)
+  [CacheConfig](API_CacheConfig.md)
+  [Certificate](API_Certificate.md)
+  [CertificateSettings](API_CertificateSettings.md)
+  [CustomRule](API_CustomRule.md)
+  [DomainAssociation](API_DomainAssociation.md)
+  [Job](API_Job.md)
+  [JobConfig](API_JobConfig.md)
+  [JobSummary](API_JobSummary.md)
+  [ProductionBranch](API_ProductionBranch.md)
+  [Step](API_Step.md)
+  [SubDomain](API_SubDomain.md)
+  [SubDomainSetting](API_SubDomainSetting.md)
+  [WafConfiguration](API_WafConfiguration.md)
+  [Webhook](API_Webhook.md)
