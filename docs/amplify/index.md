# AWS Amplify Documentation

Use AWS Amplify to develop and deploy cloud-powered mobile and web applications. Amplify provides frontend libraries, UI components, and backend building for fullstack applications on AWS. Amplify Hosting provides a continuous delivery and hosting service for fullstack cloud applications.

- [Amplify Hosting User Guide](/amplify/latest/userguide/): Provides a conceptual overview of Amplify and detailed instructions for using the hosting and deployment features.
- **Amplify Documentation**: Provides documentation for getting started with popular web and mobile frameworks to build and deploy fullstack applications on AWS. Provides the Amplify UI components library that enables you to build web app user interfaces that are connected to backend services.

[React](https://docs.amplify.aws/react/start/quickstart/)
[Next.js](https://docs.amplify.aws/nextjs/start/quickstart/)
[All frameworks](https://docs.amplify.aws/react/start/)

- [Amplify API Reference](/amplify/latest/APIReference/): Describes all the Amplify API operations in detail. Also provides sample requests, responses, and errors for the supported web services protocols. These APIs provide programmatic access to the Amplify hosting operations in the AWS Management Console.
- [Admin UI API Reference](/amplify-admin-ui/latest/APIReference/what-is-admin-ui.html): Describes all the Amplify Admin UI API operations in detail. Also provides sample requests, responses, and errors. This guide is provided for reference purposes. We strongly recommend that you use Amplify Gen 2 to create and manage your Amplify app's backend.
- [Amplify UI Builder API Reference](/amplifyuibuilder/latest/APIReference/welcome.html): Describes all the Amplify UI Builder API operations in detail. Also provides sample requests, responses, and errors. These APIs provide programmatic access to the UI component designer operations in Amplify Studio.
