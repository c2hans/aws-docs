# Data Types
<a name="API_Types"></a>

The Resource Groups Tagging API API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [ComplianceDetails](API_ComplianceDetails.md)
+  [FailureInfo](API_FailureInfo.md)
+  [RequiredTag](API_RequiredTag.md)
+  [ResourceTagMapping](API_ResourceTagMapping.md)
+  [Summary](API_Summary.md)
+  [Tag](API_Tag.md)
+  [TagFilter](API_TagFilter.md)
