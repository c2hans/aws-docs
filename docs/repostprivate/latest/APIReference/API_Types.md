# Data Types
<a name="API_Types"></a>

The AWS re:Post Private API contains several data types that various actions use. This section describes each data type in detail.

**Note**
The order of each element in a data type structure is not guaranteed. Applications should not assume a particular order.

The following data types are supported:
+  [BatchError](API_BatchError.md)
+  [ChannelData](API_ChannelData.md)
+  [SpaceData](API_SpaceData.md)
+  [SupportedEmailDomainsParameters](API_SupportedEmailDomainsParameters.md)
+  [SupportedEmailDomainsStatus](API_SupportedEmailDomainsStatus.md)
+  [ValidationExceptionField](API_ValidationExceptionField.md)
