# ValidationExceptionField
<a name="API_ValidationExceptionField"></a>

Stores information about a field that’s passed inside a request that resulted in an exception.

## Contents
<a name="API_ValidationExceptionField_Contents"></a>

 ** message **   <a name="repostprivate-Type-ValidationExceptionField-message"></a>
The name of the field.
Type: String
Required: Yes

 ** name **   <a name="repostprivate-Type-ValidationExceptionField-name"></a>
Message describing why the field failed validation.
Type: String
Required: Yes
